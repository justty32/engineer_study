**只列還沒做的**——做完即移除（不留已完成清單，歷史看 git log）。

> **膨脹就拆**：待使用者項堆多時，在 `wf/` 下建立 **`wait_todo/`** 並按類別拆檔，本檔退回只保留分類導航（照 [DEV-GUIDE「結構整理原則」](DEV-GUIDE.md)）。
