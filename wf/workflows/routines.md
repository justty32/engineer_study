# routines — 例行事務與定期待辦

← [INDEX](../INDEX.md)｜[WORKFLOWS](../WORKFLOWS.md)｜由 [tick](tick.md) 派發

記錄在固定時機或週期下要做的事，例如每次開始研究前、每週整理一次索引，或每隔一段時間檢查 open 項目。這些事項固定循環，與 [schedule](schedule.md) 的一次性行程不同。清單就在本檔。

**何時用**：① **登記**——使用者說「這是常規事務，幫我加進 routine」「每 N 天要做一次…」；② **執行**——[tick](tick.md) 心跳叫起本檔。
**何時不用**：臨時、指定時刻、做一次就沒了的 → [schedule](schedule.md)。重活（深度研究、大規模整理）不在心跳裡跑。

## Done when

- **登記**：下面「時機分區」或「間隔型登記表」多一列，**執行者**與**內容**兩欄非空。
- **執行**：到期項做完，且間隔型登記表該列「上次執行」已改成今天。

## 兩種入口

- **登記或維護**：使用者要求新增、修改或刪除 routine 時，只更新下面的清單。
- **執行**：tick 派發後，判斷目前時間，執行已到期的項目。

## 執行流程

1. 取得 `Asia/Taipei` 的當地日期與時間：

   ```bash
   TZ='Asia/Taipei' date '+%Y-%m-%d %A %H:%M'
   ```

2. 對照「時機分區」與「間隔型登記表」，找出已到期項目。
3. 唯讀盤點可直接執行；涉及工作樹、外部服務或不可逆影響時，守鐵律 3（授權來源）：使用者親自登記在本清單的項目即有授權，情況有變仍先問。
4. 重度研究或大規模整理不在心跳內展開，改記入 [SESSION-LOG](../SESSION-LOG.md) 後另行執行。
5. 間隔型項目完成後，更新「上次執行」欄位；沒有到期項目就略過。
