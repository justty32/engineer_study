# learn — 長期吸收一個主題，長出可回訪的筆記樹

[WORKFLOWS](../WORKFLOWS.md)｜[INDEX](../INDEX.md)

主題開放、會一讀再讀：建主題地圖、逐子主題做筆記、把不懂的留成 open questions。**learn 是 [digest](digest.md) 的升級形態**——差在目的是長期吸收而不是讀完即止。本庫的主題地圖＝以典型大學課綱建立的該領域 `學習計畫.md`；深度、分層與名詞對照依 [PROJECT-GUIDE](../PROJECT-GUIDE.md)。

**何時用**：使用者說「我想學 X」「建立 X 領域 / 科目的筆記」，而且之後還會回來繼續；新領域或新主題一律從這裡起步。
**何時不用**：只要一次看懂一份材料 → [digest](digest.md)。查一次就忘的事實直接查。

## Done when

- 該領域 `學習計畫.md` 的主題地圖每列狀態欄是 `已懂 / 在學 / 待學` 其中之一，沒有空欄。
- 這輪讀的每個子主題各有一個筆記檔（繁中、UTF-8），每節末有來源（URL / 書名頁碼）；首次出現的專有名詞有英文對照，且該科對照表有對應詞條。
- open questions 段存在（放在 `學習計畫.md` 或該領域 `questions.md`），且記下這輪冒出來、還沒答的問題。

## 流程

1. **畫主題地圖**：依大學課綱把主題拆成子主題，各標已懂 / 在學 / 待學；大學層級為主、碩士簡介、博士只列方向（PROJECT-GUIDE「內容模型」）。
2. 逐子主題讀來源、做筆記，**用自己的話重述**——複製貼上不算學會。
3. 不懂的進 open questions，不假裝懂；答掉了就從 questions 移進筆記。
4. 來源記清楚，一手勝二手。
5. 每輪結束更新主題地圖的狀態欄——這份地圖就是下次回訪的入口。

## 交接

- 材料本身還沒讀懂、或材料很多 → 先跑一輪 [digest](digest.md) 再回來。
- 學到能產出東西 → [write](write.md)（正式筆記）或 interactive-study-site（互動課）；筆記樹亂到難找 → [organize](organize.md)。
- 跨 session 的「讀到哪、下一步讀什麼」→ [SESSION-LOG](../SESSION-LOG.md) 一行。
