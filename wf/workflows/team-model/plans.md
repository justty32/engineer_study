# 方案與時間軸

本頁由 [`../team-model.md`](../team-model.md) 拆出。

這頁是 **project-owned**——隨每月帳單與錢包變動，**每次改動要標日期**，kernel 升級不會覆蓋它。

2026-09-18 定案：

| 角色 | 現在 | 變動後（替代方案，尚未觸發）|
|---|---|---|
| 頂層 | Claude Opus 5 | 不變（頂層只轉達與調度，降級也可，但要使用者同意）|
| 領導（架構師／建置指揮官／獨立驗收者）| Claude Opus 5 | Opus 額度吃緊時：驗收者維持 Opus，指揮官可降 Sonnet 5 但只做派工與收件、不寫 `app.js` |
| 工人（大量、便宜：機械複製、格式修正、盤點、唯讀掃描）| Claude Sonnet 5 | Sonnet 不可用時退回 Opus，工人層消耗速度整體上升，headcount 由使用者下修 |
| 工人（重要部分：章節作者、筆記撰寫）| Claude Opus 5 子 agent | 額度吃緊時改 codex CLI 批次（驗收層仍 Opus，錯字掃描不可省）|

某一層的模型要消失時（方案到期、漲價、下架），**先在這裡寫替代方案與連帶效果**，並標日期；headcount 要不要跟著下修也在這裡定。
