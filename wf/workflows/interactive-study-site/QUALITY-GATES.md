# 互動學習網站品質關卡

← [工作流入口](README.md)｜[agent 編組](AGENT-TEAM.md)

## 1. 內容正確性

- 每個核心概念、公式、預設值與診斷結論都能回指本地來源。
- 簡化模型明確標示假設與適用範圍，不把教學近似說成工程保證。
- 繁體中文術語與來源筆記一致；新增名詞依專案名詞對照規則處理。
- 互動回饋說明「為什麼」，不能只顯示對錯。

## 2. 學習有效性

- 每個模組有可觀察學習成果。
- 至少包含一次取捨判斷、一次參數實驗、一次故障診斷與一次跨層整合。
- 控制值改變後，結果、解釋或狀態必須立即改變。
- 讀者可以重設單元並重新嘗試；進度只作輔助，不阻擋自由瀏覽。

### 原理優先加驗

當讀者缺乏 prerequisite 或網站採用 [principles-first](PRINCIPLES-FIRST.md) 時，以下全數適用：

- 任一診斷、選擇或預測所需的概念，已在前文教過；不可先考後教。
- 每節先回答「為什麼」，並指出狀態、回路、電流／電荷／能量去向與結果；不能只列規則。
- 術語首次出現可原地讀懂：白話動作、真實機制、可觀察現象與易混概念俱全。
- 類比後回到真實元件與適用限制；公式附符號、單位、假設、量綱與極端案例。
- 自由實驗無計分與強制答對；控制值改變時，數值、現象與 why 說明同步改變。
- 每個核心概念至少指出一種量測工具、能證明什麼與不能證明什麼。
- 明確拆開易混概念，例如上拉≠終端≠偏壓、直流電阻≠特性阻抗、RS-485≠Modbus。

## 3. 介面與可及性

- 第一個 viewport 就是學習工作台，不是 landing page。
- 桌面與手機皆無文字截斷、控制項位移、內容重疊或橫向溢出。
- 所有互動可用鍵盤操作，有可見 focus，表單有 label，狀態不只靠顏色表達。
- 尊重 `prefers-reduced-motion`；不使用閃爍、無意義背景動畫或裝飾性漸層球。
- 使用穩定尺寸的控制列、圖表與模擬器，狀態切換不造成版面跳動。

## 4. 離線與節流

- HTML、CSS、JavaScript 與所有必要資產都在主題目錄內。
- 不含外部字型、圖片、分析碼、CDN、遠端 API 或第三方執行期依賴。
- 開發與測試不新增套件鎖檔；若環境已有工具可以用，直接使用既有版本。
- 瀏覽器開發者工具的 Network 應只有本機請求。

## 5. 技術驗證

依環境可用能力由上而下執行，不為測試下載新工具：

1. `node --check <script>`：JavaScript 語法。
2. 本機連結與檔案存在性檢查。
3. 啟動靜態 HTTP server，驗證所有模組、重設與 localStorage。
4. 若既有 Playwright/Chromium 可用，檢查 console error、桌面 `1440×900`、手機 `390×844` 截圖與主要互動。
5. 檢查頁面沒有外部網路請求；公式以獨立測試值人工交叉驗算至少一組。

## 驗收紀錄

每個案例在自己的 `驗收紀錄.md` 記錄：測試日期、環境、通過項、失敗項、已知限制與是否允許交付。沒有證據的項目不得標為通過。
