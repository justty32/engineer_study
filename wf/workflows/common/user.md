## 聽課教材偏好（2026-10-14）

使用者希望邊打遊戲邊聽課：單一核心觀念至少講 10–15 分鐘，低資訊密度，交代來由、用途與例子，允許漏聽後接回。需要公式或圖時語音明確指出教材圖號與觀察重點，停下等使用者看完再繼續。短暫查看以大圖、短句為主，推導可摺疊或連到原課；主課必要知識不能藏成選讀。此偏好針對聽課版本，既有高密度筆記與速查頁保留原用途。

本次起點是電路學的相位與複數運算；歐姆定律及電容、電感基礎已會。長期順序為電路分析 → 電子學 → 電磁學，工程數學在需要時穿插。聲音偏好中文初音未來；中文效果不佳時再試胡桃，是否可實作依本機模型與使用者參考素材，不把系統語音當角色配音。工作盡量交給 agent，可由隊長帶子 agent，主 agent 專注交流與整合。教材和完整口語稿完成就先給使用者看，語速可在試聽後小幅調整。

聽課播放器需能拖曳真實音檔進度並調整倍速；可直接嵌入網頁，亦接受下載後自行用 VLC。瀏覽器即時朗讀無精確時間軸時應清楚說明，不能用估算進度冒充可拖曳音檔。
