## 分工與領地

root 統籌及最終放行；後半輪由 visual_publish 接管共享行政，hosting_operator 接管 Sites 隔離發布。visual_builder 持有 `共通基礎/數學/圖解線性代數/`，排除 `.openai/` 和 `驗收紀錄.md`；先制定圖解教學方案並交一份入門試作，root 審過再派最多四位作者覆蓋全部章節，明列互斥檔案。visual_pedagogy 唯讀審教學跳步與每圖教學意義，報告在 `/tmp/linear-visual-pedagogy/`。visual_math 唯讀審新增圖的數值、幾何與模型條件，報告在 `/tmp/linear-visual-math/`。visual_qa 僅持有驗收紀錄與 `/tmp/linear-visual-qa/`。visual_publish 放行後持有精確 commit／push／GitHub 部署與工作流收線。本輪不預設修改原始筆記或學科名詞表。

## 沿途教材查核

使用者於改版途中追加要求：「做的途中，也要稍微檢查一下有無錯誤，最好是從網上抓教材來做參照。」visual_math 因此獲授權成為本輪唯一外部教材查詢者，使用 web 工具讀 MIT 等一手教材，每批至多四頁，後續批次向 root 放行；禁止直接抓外部圖片到產品。每張新增圖仍為原創，核對數字、推理及適用條件，將精確來源交 builder 更新網站引用。其他作者維持不自行上網。

## 驗收

1. 每章有具體情境與可依序讀的圖像步驟；術語與符號出現前可由圖與白話理解其角色。
2. 新圖的數字、箭頭、比例與前後狀態符合數學；補足原版省略的步驟與反例。
3. 首頁與全章圖文節奏適合初學者，PC 可讀；手機、鍵盤、離線、連結與既有互動不退化。
4. 獨立教學審查與技術 QA 分開記錄，模型條件保留，不能以測試數字聲稱真人已看懂。
5. 更新原 GitHub 與 Sites 地址，線上版本對上受驗雜湊，記錄所有子線收線與人工待驗。
