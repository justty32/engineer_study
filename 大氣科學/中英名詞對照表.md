# 大氣科學 中英名詞對照表

通用數學與物理名詞請參閱 [共通基礎/](../共通基礎/)。

| 中文名稱 | 英文名稱 | 備註 |

| 被測量 | Measurand | 被明確定義、預定量測的物理量 |

| 量測可追溯性 | Metrological Traceability | 透過附不確定度的校正鏈連至認可標準 |
| 量測不確定度 | Measurement Uncertainty | 可合理歸於被測量之值的散布程度 |
| 偏差 | Bias | 量測或估計在平均意義下的系統性偏離 |
| 代表性誤差 | Representativeness Error | 觀測尺度與比較目標尺度不一致所生誤差 |

| 中介資料 | Metadata | 描述站址、儀器、處理版本與資料脈絡的資訊 |

| 無線電探空儀 | Radiosonde | 氣球攜帶的溫壓濕垂直觀測儀器 |

| 氣象雷達 | Weather Radar | 以微波回波觀測降水與徑向速度 |
| 雷達反射率因子 | Radar Reflectivity Factor ($Z$) | 瑞利近似下受粒徑六次方加權的回波量 |
| 徑向速度 | Radial Velocity | 目標速度在雷達視線方向的分量 |
| 脈衝重複頻率 | Pulse Repetition Frequency (PRF) | 雷達單位時間發射脈衝的次數 |

| 超級觀測 | Superobservation / Superob | 將密集相關觀測聚合後供同化使用 |
| 觀測系統實驗 | Observing System Experiment (OSE) | 移除或加入既有觀測以評估預報影響 |
| 觀測系統模擬實驗 | Observing System Simulation Experiment (OSSE) | 以模擬觀測評估未來系統價值 |
