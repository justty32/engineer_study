# 生化工程概論（Introduction to Biochemical Engineering）

> 名詞對照見 [中英名詞對照表 → 生化工程概論](../中英名詞對照表.md#生化工程概論)。

## 0. 本科在本系的定位

- **它是什麼**：生化工程把化工的核心技能（反應工程、質傳、熱傳、分離）應用在生物系統上——用活的細胞或酵素來生產化學品、藥物、食品與能源。可以說就是「生物版的化學工程」。
- **往上游銜接什麼**：有機化學（生物分子結構）、物理化學（酵素動力學其實是化學動力學的特例）、反應工程（生物反應器的設計方程與攪拌槽 CSTR 完全相同）、分離程序（下游純化使用萃取、層析、薄膜等標準化工單元操作）。
- **往下游銜接什麼**：製藥工業（抗生素、單株抗體）、食品工業（發酵、酵素加工）、生質能源（乙醇發酵、藻類生質柴油）、環境工程（廢水生物處理）。
- **核心心法**：生化工程 = 化工方法論 × 生物系統。你不需要成為生物學家，但需要了解「生物催化劑」（酵素與細胞）和化學觸媒有什麼不同——酵素對溫度與 pH 極度敏感、對受質有驚人的專一性、且反應條件必須溫和（常溫常壓、水相）。

### 對擁有者的提醒

你在信號處理中學過的**非線性飽和動力學**（如放大器飽和曲線）與酵素動力學的 Michaelis–Menten 方程形式上一模一樣（都是雙曲線飽和曲線，$v = V_{\text{max}}[S]/(K_m + [S])$）。你在控制理論中學過的**Monod 方程**（細胞生長速率 vs 基質濃度）也是同一種雙曲線形式。這些數學結構對你來說應該是老朋友了。

## 1. 生物催化：酵素與細胞

### 1.1 酵素是什麼

酵素（enzyme）是蛋白質構成的生物催化劑。與傳統化學觸媒相比：

| 特性 | 酵素 | 化學觸媒 |
|------|------|----------|
| 專一性 | 極高（通常只催化一種受質） | 中低（可能催化多種反應） |
| 操作條件 | 常溫、常壓、中性 pH | 高溫高壓常見 |
| 速率 | 可極快（carbonic anhydrase: $10^6$/s） | 變異大 |
| 失活 | 熱變性、pH 變性，不可逆 | 燒結、毒化、可部分再生 |
| 來源 | 生物體（發酵生產） | 礦物、合成 |

### 1.2 Michaelis–Menten 動力學

酵素催化反應的最基本模型：

$$E + S \underset{k_{-1}}{\overset{k_1}{\rightleftharpoons}} ES \overset{k_{\text{cat}}}{\longrightarrow} E + P.$$

穩態近似下（$d[ES]/dt = 0$），反應速率：

$$v = \frac{V_{\text{max}}[S]}{K_m + [S]},$$

- $V_{\text{max}} = k_{\text{cat}}[E]_0$：最大速率（所有酵素都被受質占滿時）
- $K_m = (k_{-1}+k_{\text{cat}})/k_1$：Michaelis 常數（速率達 $V_{\text{max}}/2$ 時的受質濃度），反映酵素對受質的親和力——$K_m$ 愈小，親和力愈強

- $[S] \ll K_m$：一級反應（$v \propto [S]$）
- $[S] \gg K_m$：零級反應（$v = V_{\text{max}}$，所有酵素飽和）

### 1.3 酵素抑制（Inhibition）

- **競爭性抑制**：抑制劑與受質競爭同一活性位點。表觀 $K_m$ 增加（需要更多受質才能達到相同速率），$V_{\text{max}}$ 不變
- **非競爭性抑制**：抑制劑結合在酵素的其他部位，改變構形使催化效率降低。$V_{\text{max}}$ 下降，$K_m$ 不變
- **不競爭性抑制**（uncompetitive）：抑制劑只與 ES 複合體結合。$V_{\text{max}}$ 與 $K_m$ 等比例下降

## 2. 細胞培養與發酵

### 2.1 細胞生長動力學

**Monod 方程**（類比 Michaelis–Menten，以細胞生長速率取代酵素速率）：

$$\mu = \frac{\mu_{\text{max}}[S]}{K_s + [S]},$$

- $\mu$：比生長速率（specific growth rate，$\mathrm{h^{-1}}$）
- $\mu_{\text{max}}$：最大比生長速率
- $K_s$：半飽和常數

細胞濃度的變化：

$$\frac{dX}{dt} = \mu X\quad \text{（指數生長期）}.$$

### 2.2 批次發酵的生長曲線

| 階段 | 特徵 |
|------|------|
| 遲滯期（lag phase） | 接種後細胞適應新環境，不分裂 |
| 指數生長期（exponential / log phase） | 以最大速率倍增，$X(t) = X_0 e^{\mu t}$ |
| 穩定期（stationary phase） | 基質耗盡或有毒代謝物累積，生長與死亡平衡 |
| 死亡期（death phase） | 細胞大量死亡 |

### 2.3 發酵操作模式

| 模式 | 描述 | 適合 |
|------|------|------|
| 批次（batch） | 一次加料、發酵、收穫 | 簡單、傳統、適合小量多樣 |
| 饋料批次（fed-batch） | 發酵過程中持續補料（不排料） | 避免受質抑制、控制生長速率、抗生素生產 |
| 連續（continuous / chemostat） | 恆定進料與出料，穩態操作 | 研究用、實驗室規模（工業上少用因長時間易染雜菌） |

### 2.4 氧氣傳遞

好氧發酵需要持續供應氧氣。但氧氣在水中溶解度極低（約 8 mg/L，25°C），而細胞消耗氧的速率很快。**氧氣質傳速率（OTR, Oxygen Transfer Rate）通常是好氧發酵的瓶頸**：

$$OTR = k_L a\,(C^* - C_L).$$

- $k_L a$：體積質傳係數（$a$ 是氣泡界面積/體積比）
- 提升 $k_L a$ 的手段：增加通氣量、提高攪拌轉速（把氣泡打得更細）、使用純氧代替空氣

反應器設計的挑戰：高攪拌提升 $k_L a$ → 高剪切可能傷害細胞（尤其是動物細胞，沒有細胞壁保護）。

## 3. 生物反應器

### 3.1 攪拌槽式生物反應器

最常見的類型，就是一台攪拌槽加上通氣與無菌設計。化工反應工程的全部設計方程在此完全適用，只需要把反應速率項換成生長動力學或酵素動力學。

### 3.2 特殊設計

| 反應器類型 | 結構 | 適用 |
|------------|------|------|
| 氣舉式（airlift） | 利用通氣產生的密度差驅動循環，無機械攪拌 | 剪切敏感細胞、廢水處理 |
| 填充床 | 細胞固定在固體載體上，培養基流過 | 固定化酵素或細胞連續操作 |
| 中空纖維（hollow fiber） | 細胞在毛細纖維外側生長，培養基從內側流過 | 動物細胞高密度培養 |

### 3.3 無菌操作與滅菌

生物反應器的頭號天敵是**染菌（contamination）**——雜菌一旦入侵，會消耗基質、產生不明代謝物、甚至殺死生產菌株。培養基與設備在發酵前必須**滅菌（sterilization）**——最常用的是 121°C 飽和蒸汽滅菌（高壓滅菌釜，autoclave）。滅菌不是「把菌殺到零」，而是「把存活機率降到可接受的低值」（通常目標是 $10^{-6}$，即一百萬批中只有一批染菌）。滅菌動力學是一級熱致死：

$$\frac{dN}{dt} = -k_d N,\quad k_d = A e^{-E_a/RT}.$$

## 4. 下游分離純化

### 4.1 為什麼下游是瓶頸

生物產品的純化（downstream processing）往往占總生產成本的 50–80%——因為：
- 產物濃度極低（發酵液中產物可能只佔總質量的 1–5%）
- 培養基成分複雜（含細胞碎片、殘餘基質、副產物、其他蛋白質……）
- 產物（尤其是蛋白質藥物）對溫度、pH、剪切、有機溶劑極度敏感

### 4.2 純化序列

典型的下游純化步驟從粗到精：

1. **細胞分離**：離心、微過濾（從發酵液中分離出細胞）
2. **細胞破碎**（產物在胞內時）：高壓均質、超音波、酵素溶菌
3. **初級回收**：鹽析（硫酸銨沉澱蛋白質）、溶劑萃取
4. **精製**：各種**層析法（chromatography）**——離子交換（IEX）、疏水交互作用（HIC）、親和層析（affinity，如 Protein A 專一抓抗體）、膠體過濾（SEC，依大小分離）
5. **最終純化與配方**：超過濾濃縮、透析緩衝液置換、無菌過濾、凍乾（lyophilization）

層析是純化蛋白質藥物的核心技術，也是一個經典的化工分離問題——固定相（樹脂顆粒）+ 移動相（緩衝液溶劑），溶質在兩相間反覆分配。你在分離程序中學過的 van Deemter 方程（層析板高 vs 流速）在這裡直接適用。

## 5. 生化工程的主要產品領域

### 5.1 製藥

- **抗生素**：青黴素（Penicillium chrysogenum 發酵）、頭孢菌素，是生化工程最成功的工業案例
- **重組蛋白質藥物**：胰島素（第一個基因工程藥物，1982）、人類生長激素、EPO（紅血球生成素）
- **單株抗體（mAb）**：目前生物藥物的最大宗，用 CHO（中國倉鼠卵巢）細胞生產，是抗癌與自體免疫疾病的主力治療

### 5.2 食品與飲料

- 啤酒（Saccharomyces cerevisiae）、紅酒、醬油、味噌、優格——人類使用發酵技術已數千年，生化工程把這些傳統工藝科學化與規模化
- 酵素加工：高果糖玉米糖漿（葡萄糖異構酶）、乳糖分解（乳糖酶）、起司（凝乳酶）

### 5.3 生質能源與化學品

- 生質乙醇：酵母發酵玉米/甘蔗中的糖 → 蒸餾分離
- 生質柴油：植物油 + 甲醇 → 轉酯化（鹼觸媒）→ 脂肪酸甲酯（即生質柴油）+ 甘油
- 生物可降解塑膠：PHA 由細菌在養分不平衡條件下累積於胞內

## 6. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 代謝工程與合成生物學 | 用基因編輯（CRISPR）改造細胞的代謝路徑，使其過量生產目標代謝產物。相當於「對細胞重新程式設計」。 |
| 連續式層析與模擬移動床（SMB） | 把批次層析變成連續操作，大幅提升產能與收率。胰島素與果糖分離的標準工業技術。 |
| 動物細胞培養工程 | 動物細胞比微生物脆弱得多（無細胞壁），對剪切、pH、溶氧極為敏感。高密度灌流式培養（perfusion）的工程挑戰。 |

## 7. 博士層級研究方向

- 無細胞合成生物學（cell-free synthetic biology）——取細胞的酵素系統於試管中運作，規避活細胞的限制
- 連續生產（continuous manufacturing）在製藥業的推進——從批次走向連續，提升品質一致性與產能
- 單次使用生物反應器（single-use / disposable bioreactor）的規模放大與材料相容性
- 機器學習輔助的培養基配方最佳化與即時發酵監控（PAT, Process Analytical Technology）
