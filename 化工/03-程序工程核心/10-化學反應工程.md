# 化學反應工程（Chemical Reaction Engineering）

> 名詞對照見 [中英名詞對照表 → 化學反應工程](../中英名詞對照表.md#化學反應工程)。

## 0. 本科在本系的定位

- **它是什麼**：化學反應工程（CRE）把化學動力學（反應速率）與輸送現象（熱傳、質傳、流動）結合起來，回答化工最核心的問題：**要多大的反應器才能生產出指定量的產品？**
- **往上游銜接什麼**：物理化學（化學動力學、Arrhenius 方程、速率定律）、質能均衡（反應器的物料與能量守恆方程）、流體力學（停留時間分布）。
- **往下游銜接什麼**：程序設計（反應器選型與尺寸計算）、程序控制（反應器的溫度控制與安全）。
- **核心心法**：反應器設計方程的本質是「**對反應器內一個微小體積做物料均衡，把反應速率塞進生成/消耗項**」——這和你在化工第一門課學的質能均衡是同一套邏輯，只是現在多了一個反應速率項 $r_A$。

### 對擁有者的提醒

反應工程的設計方程在數學上與電路中的**RC 充放電方程**（一階線性 ODE）非常相似。CSTR（連續攪拌槽反應器）的穩態設計方程是代數方程（類比直流穩態），PFR（柱塞流反應器）的設計方程是常微分方程（類比 RC 暫態），批次反應器的設計方程也是 ODE 但用時間作為自變數。你在微分方程上的訓練在這裡完全適用。

## 1. 反應速率與動力學回顧

### 1.1 速率定律的形式

對反應 $a\mathrm{A} + b\mathrm{B} \to \text{products}$：

$$-r_A = k(T) \cdot f(C_A, C_B, \ldots).$$

- $k(T)$：速率常數，由 Arrhenius 方程 $k = A e^{-E_a/RT}$ 描述
- $f(C_A, C_B)$：濃度函數，常見形式為冪次律 $C_A^\alpha C_B^\beta$（$\alpha, \beta$ 為實驗測定的反應級數）

### 1.2 可逆反應

可逆反應 $\mathrm{A \rightleftharpoons B}$ 的淨速率：

$$-r_A = k_f C_A - k_r C_B.$$

平衡時 $-r_A = 0$，得到 $K_{\text{eq}} = k_f/k_r = C_{B,\text{eq}}/C_{A,\text{eq}}$。注意：反應器設計時，產物濃度逼近平衡時淨速率趨近於零——**熱力學決定了反應器能做到的極限**。

## 2. 理想反應器設計方程

### 2.1 批次反應器（Batch Reactor, BR）

所有反應物一次性加入，反應進行一段時間後全部排出。無進出流，因此非穩態操作。

對物種 A 的莫耳均衡（定容）：

$$\frac{dC_A}{dt} = r_A \quad (\text{注意 } r_A \text{ 本身為負值}).$$

積分得到所需的**反應時間** $t$。反應器體積由**批次週期**（反應時間 + 加料/排料/清洗時間）與所需的年產量決定。

批次反應器適合小批量、多品種生產（藥品、精細化工）。

### 2.2 連續攪拌槽反應器（CSTR）

充分攪拌 → 槽內組成完全均勻，出口組成 = 槽內組成（完全混合假設）。穩態下的物料均衡（莫耳流率基礎）：

$$F_{A0} - F_A + r_A V = 0 \quad\Rightarrow\quad V = \frac{F_{A0} - F_A}{-r_A}.$$

因為出口濃度等於槽內濃度，$C_A = C_{A,\text{out}}$，設計方程是**代數方程**（不需要積分）。這使得 CSTR 在數學上極其簡單，但也意味著整個反應器都在低濃度（出口濃度）下操作——對於正級數反應，CSTR 需要的體積比 PFR 大。

### 2.3 柱塞流反應器（Plug Flow Reactor, PFR）

流體以「柱塞」形式沿管軸向前推進，**無軸向混合、無徑向濃度梯度**（理想化）。穩態下對一個微小管段做物料均衡：

$$F_A(z) - F_A(z+\Delta z) + r_A \Delta V = 0 \quad\Rightarrow\quad \frac{dF_A}{dV} = r_A.$$

用轉化率 $X_A = (F_{A0} - F_A)/F_{A0}$ 表示：

$$V = F_{A0}\int_0^{X_A} \frac{dX}{-r_A}.$$

這叫**Levenspiel 圖積分**——以 $F_{A0}/(-r_A)$ 對 $X$ 作圖，曲線下面積就是所需的 $V$。

PFR 的優點：反應物濃度高（入口）、體積效率好。缺點：換熱困難（管式反應器的熱傳面積/體積比小）。

### 2.4 CSTR 與 PFR 的比較

對正級數反應（$n > 0$），在相同轉化率下，CSTR 需要的體積**永遠大於** PFR。因為 CSTR 內濃度一跳就掉到出口濃度，而 PFR 內濃度沿管軸逐漸下降，平均濃度高、平均反應速率大。

對零級反應，兩者體積相同。對負級數反應（罕見），CSTR 反而較小——但負級數通常暗示速率模型的問題（例如分母中有吸附項的 Langmuir–Hinshelwood 動力學）。

## 3. 轉化率與選擇率

### 3.1 轉化率（Conversion）

$$X_A = \frac{\text{反應掉的 A 莫耳數}}{\text{進料的 A 莫耳數}}.$$

轉化率是單一反應物的視角。反應器體積直接對應於指定的轉化率。

### 3.2 選擇率（Selectivity）與產率（Yield）

當有多重反應同時發生時，轉化率不夠看——我們更關心「多少反應物變成**想要**的產品」：

- **選擇率**：$S_{D/A} = \dfrac{\text{生成 D 的莫耳數}}{\text{消耗的 A 莫耳數}} \times \text{計量因子}$
- **產率**：$Y_D = X_A \cdot S_{D/A}$（反應掉的原料中真正變成目標產品的比例）

在並聯競爭反應中（$\mathrm{A \to D\ (desired),\ A \to U\ (undesired)}$）：
- 若目標反應級數 > 副反應級數：高濃度有利 → 用 PFR 或批次
- 若目標反應級數 < 副反應級數：低濃度有利 → 用 CSTR、或慢慢進料（半批次）

### 3.3 串聯反應

$\mathrm{A \to B \to C}$（B 為目標產品、C 為副產物）。這是最經典的選擇率問題——B 的濃度存在最佳反應時間/最佳轉化率，過了最佳點 B 繼續反應生成 C。對於串聯反應，**PFR 通常比 CSTR 給出更高的 B 選擇率**（因為 PFR 避免了 B 與 A 在同一空間中均勻混合）。

## 4. 非等溫反應器

### 4.1 能量均衡與熱穩定性

放熱反應中，反應速率隨溫度升高（Arrhenius），而溫度的升高又來自反應放熱——這是一個**正回授**迴路。CSTR 的能量均衡：

$$Q_{\text{生成}} \propto (-r_A) \cdot (-\Delta H_{\text{rxn}}) \quad\text{vs}\quad Q_{\text{移除}} = \dot{m} C_p (T - T_c).$$

$Q_{\text{生成}}$ 隨溫度呈 S 形曲線（由 Arrhenius 與濃度消耗的競爭決定），$Q_{\text{移除}}$ 是直線。兩者的交點決定穩態操作點。當直線斜率不足以「壓制」S 形曲線時，存在**多重穩態**——系統可能突然從低溫操作點跳到高溫操作點（點火，ignition），或反向跳回（熄火，extinction）。

### 4.2 熱失控與安全

放熱反應器最危險的情況是**冷卻失效**：一旦冷卻系統故障，溫度上升 → 速率加快 → 放熱更多 → 溫度再上升。這個正回授可能導致**熱失控（thermal runaway）**——壓力暴升、緊急排放、甚至爆炸。Semenov 理論給出了熱失控的無因次判據。化工人設計反應器時必須確保即使冷卻全失，系統也不會進入失控區域——這是化工安全的核心課題之一。

## 5. 觸媒與觸媒反應器

### 5.1 觸媒基本概念

觸媒降低活化能而不改變平衡——它同時加速正反應與逆反應，所以只能讓系統**更快達到平衡**，不能改變平衡位置。觸媒的活性以**轉換頻率（TOF, turnover frequency）**衡量：每秒每活性位點發生幾次催化循環。

### 5.2 固體觸媒反應器的類型

| 反應器類型 | 觸媒狀態 | 特點 |
|------------|----------|------|
| 填充床（packed bed） | 固定，裝在管內 | 最簡單，但換熱難、壓降大 |
| 流體化床（fluidized bed） | 懸浮，被氣流托起 | 等溫好、可連續換觸媒，但觸媒磨損 |
| 漿態床（slurry bed） | 懸浮在液體中 | 傳熱好、觸媒粒子可很小，但需後續分離 |

### 5.3 固體觸媒中的擴散與反應

在固體觸媒粒子內部，反應物必須先從粒子外表面擴散進孔道，才能到達活性位點。**有效因子（effectiveness factor）** $\eta$ 衡量內部擴散阻力導致實際速率偏離「表面濃度條件下應有速率」的程度：

$$\eta = \frac{\text{實際觀測速率}}{\text{若無內部擴散阻力的速率}}.$$

$\eta$ 是 **Thiele 模數（Thiele modulus）** $\phi$ 的函數。$\phi$ 大 → 擴散慢/反應快 → $\eta \ll 1$（反應只在粒子表層發生，內部浪費）。$\phi$ 小 → $\eta \approx 1$（內部充分利用）。

## 6. 停留時間分布（RTD）

### 6.1 為什麼需要 RTD

真實反應器既不是完美的 CSTR（瞬時完全混合），也不是完美的 PFR（無任何軸向混合）。RTD 衡量流體元素在反應器內「停留多久」，從而推斷實際混合程度。這對反應器診斷與放大極其重要。

### 6.2 RTD 函數

- **$E(t)$：停留時間分布函數**——$E(t)\,dt$ 是流體元素在反應器內停留時間介於 $t$ 與 $t+dt$ 之間的概率
- **$F(t)$：累積分布函數**——停留時間小於 $t$ 的比例

用脈衝注入或階梯注入示蹤劑（tracer）實驗來量測 RTD。

理想 PFR：$E(t) = \delta(t - \tau)$（Dirac delta 函數，所有元素在相同的 $\tau$ 時間內通過）

理想 CSTR：$E(t) = (1/\tau)e^{-t/\tau}$（指數分布，完全混合意味著任何時間都有元素離開）

### 6.3 巨觀混合模型

當真實反應器既非 PFR 也非 CSTR 時，可用**組合模型**來逼近：
- **軸向擴散模型（axial dispersion model）**：在 PFR 基礎上添加沿軸向的擴散項，擴散係數 $D_a$ 愈大 → 愈偏離 PFR、愈接近 CSTR
- **槽串聯模型（tanks-in-series model）**：用 $N$ 個等體積 CSTR 串聯逼近真實行為，$N=1$ 就是 CSTR，$N \to \infty$ 逼近 PFR

## 7. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 多相反應器設計 | 氣–液–固三相系統（如加氫脫硫反應器）涉及氣液質傳、液固質傳、粒子內擴散與表面反應的串聯。 |
| 反應蒸餾與反應萃取 | 反應與分離在同一設備中進行——產物即時移除，破壞平衡限制，達成單一反應器內的高轉化率。MTBE 合成是代表案例。 |
| 微反應器技術 | 特徵尺寸在微米級，傳熱傳質速率極高、可精準控制停留時間，適合強放熱/危險反應與高價值藥品合成。 |

## 8. 博士層級研究方向

- 從頭算動力學（microkinetic modeling）——直接從 DFT 計算建立基元反應網路
- 單原子觸媒的反應機構與金屬–載體交互作用
- 電化學反應工程（CO₂ 還原、水電解）中的電極微觀動力學與氣泡管理
- 機器學習輔助的動力學模型判別與觸媒篩選
