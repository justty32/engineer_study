# 質量傳遞（Mass Transfer）

> 名詞對照見 [中英名詞對照表 → 質量傳遞](../中英名詞對照表.md#質量傳遞)。

## 0. 本科在本系的定位

- **它是什麼**：質量傳遞研究物質在空間中的輸送——一個成分因為濃度差（或化學位能差）而從高濃度往低濃度移動。它是**輸送現象三部曲的最後一部**（動量、熱、質量），三者的數學結構幾乎可以逐字翻譯。
- **往上游銜接什麼**：流體力學（對流質傳的流場決定質傳速率）、熱力學（相平衡決定質傳的驅動力上限）、偏微分方程（暫態擴散方程）。
- **往下游銜接什麼**：
  - **分離程序**：蒸餾、吸收、萃取、乾燥、薄膜分離——這些是化工的「招牌技術」，其設計核心就是質傳速率與平衡的交互作用。
  - **反應工程**：氣–固觸媒反應中，反應物要先從氣相主體擴散到觸媒表面（外部質傳）再擴散進孔道（內部質傳），然後才發生化學反應。
  - **生化工程**：氧氣從氣泡傳入培養液、養分傳入細胞、代謝產物傳出——全是質傳。
- **核心心法**：質量傳遞 = Fick 定律（擴散）+ 對流（流體帶著溶質跑）+ 相間傳遞（跨越氣液或液液界面）。第一件事是擴散，第二件事是對流質傳（$Sh$ 關聯式），第三件事是雙膜理論——這三樣涵蓋了分離程序的絕大部分設計計算。

### 對擁有者的提醒

質量傳遞的數學與熱傳遞完全同構，把熱傳的符號直接替換就能得到質傳的方程：

| 熱傳 | 質傳 |
|------|------|
| 溫度 $T$ | 濃度 $C$（或莫耳分率） |
| Fourier 定律 $q = -k\nabla T$ | Fick 定律 $J = -D\nabla C$ |
| 熱擴散係數 $\alpha$ | 質擴散係數 $D$ |
| Nusselt 數 $Nu = hL/k$ | Sherwood 數 $Sh = k_c L/D$ |
| Prandtl 數 $Pr = \nu/\alpha$ | Schmidt 數 $Sc = \nu/D$ |

你在電路分析中熟練的類比推理，在這裡可以讓你快速掌握質傳的核心——先理解熱傳的對應概念，再把符號換掉，八九不離十。

## 1. 擴散：Fick 定律

### 1.1 Fick 第一定律（穩態擴散）

$$J = -D \frac{dC}{dx},$$

- $J$：擴散通量（$\mathrm{mol/(m^2\!\cdot\!s)}$ 或 $\mathrm{kg/(m^2\!\cdot\!s)}$）
- $D$：擴散係數（diffusivity，$\mathrm{m^2/s}$）
- 氣體中 $D \sim 10^{-5}$、液體中 $D \sim 10^{-9}$、固體中 $D \sim 10^{-12}$ 或更小

這個形式與 Fourier 熱傳導定律 $q = -k\,dT/dx$ 完全同構。負號表示物質從高濃度往低濃度流（熱從高溫往低溫流）。

### 1.2 擴散的物理根源

氣體中的擴散來自分子隨機運動（平均自由徑與平均速度決定 $D$），可以用氣體動力論推導。液體中的擴散比氣體慢四個數量級，因為液體分子之間的空隙極小，分子要「擠」過去。固體中的擴散更慢，機制是原子在晶格中跳躍（空位機制、間隙機制）。

### 1.3 Fick 第二定律（暫態擴散）

$$\frac{\partial C}{\partial t} = D \frac{\partial^2 C}{\partial x^2}.$$

這是**擴散方程（diffusion equation）**，與熱傳導方程 $\partial T/\partial t = \alpha\,\partial^2 T/\partial x^2$ 數學上完全相同。解的形式也一樣：誤差函數（error function）解、分離變數 Fourier 級數解、或數值解。

一個經典應用：鋼的表面滲碳（carburizing）——在含碳氣氛中加熱鋼，碳原子從表面往內擴散。給定時間後碳濃度分布就由 $\mathrm{erf}(x/2\sqrt{Dt})$ 決定。

## 2. 對流質量傳遞

### 2.1 質傳係數

類比 Newton 冷卻定律，定義**質傳係數（mass transfer coefficient）** $k_c$：

$$N_A = k_c (C_{A,s} - C_{A,\infty}).$$

$k_c$ 不是物質常數——它取決於流場、幾何、擴散係數。量測與計算 $k_c$ 是質傳的工程核心。

### 2.2 無因次群與類比

| 無因次數 | 定義 | 物理意義 |
|----------|------|----------|
| Sherwood 數 $Sh$ | $\dfrac{k_c L}{D}$ | 無因次質傳係數：對流質傳 vs 停滯流體的擴散 |
| Schmidt 數 $Sc$ | $\dfrac{\nu}{D}$ | 動量擴散 vs 質量擴散（流體性質） |
| Lewis 數 $Le$ | $\dfrac{\alpha}{D} = \dfrac{Sc}{Pr}$ | 熱擴散 vs 質量擴散 |
| Stanton 數（質傳）$St_m$ | $\dfrac{Sh}{Re\,Sc} = \dfrac{k_c}{v}$ | 質傳速率 vs 對流速率 |

### 2.3 Chilton–Colburn 類比

輸送現象最美麗的結果之一：對相同的幾何與流場，熱傳、質傳與動量傳遞的無因次關聯式可以互相轉換：

$$\frac{f}{2} = j_H = j_D,$$

其中 $j_H = St_H\,Pr^{2/3}$（熱傳 $j$ 因子）、$j_D = St_m\,Sc^{2/3}$（質傳 $j$ 因子）。這意味著：**只要知道摩擦因子 $f$，就可以推估 $h$ 和 $k_c$**——在不方便做熱傳或質傳實驗時，這個類比提供了極其有用的近似。

適用範圍：$0.6 < Pr < 60$、$0.6 < Sc < 3000$、無形狀阻力（form drag）主導的場合。

## 3. 相間質量傳遞與雙膜理論

### 3.1 為什麼需要理論

當兩相接觸時（例如氣泡通過液體、液滴通過氣體），溶質會從一相傳到另一相。但**界面上的濃度是多少？**——這個問題本身沒有簡單答案，因為界面上的濃度取決於兩側的擴散阻力與相平衡的交互作用。

### 3.2 雙膜理論（Two-Film Theory）

Lewis 與 Whitman（1924）提出的雙膜模型是質傳最實用的工程框架，至今仍是分離程序設計的標準假設：

1. 兩相主體各自充分混合（濃度均勻）
2. 界面兩側各有一層**停滯膜（stagnant film）**，質傳阻力集中在這兩層膜內
3. 界面上兩相瞬間達到相平衡（$C_{A,i}^G$ 與 $C_{A,i}^L$ 滿足 Henry 定律或 VLE 關係）

質傳通量：

$$N_A = k_G (P_A - P_{A,i}) = k_L (C_{A,i} - C_A).$$

兩式與平衡關係聯立，消去未知的界面濃度，得到以**總質傳係數（overall mass transfer coefficient）**表達的形式：

$$N_A = K_G (P_A - P_A^*) = K_L (C_A^* - C_A),$$

其中 $C_A^*$ 是與氣相主體壓力平衡的液相濃度，$P_A^*$ 是與液相主體濃度平衡的氣相分壓。總質傳係數與各側膜係數的關係：

$$\frac{1}{K_G} = \frac{1}{k_G} + \frac{H}{k_L},\qquad \frac{1}{K_L} = \frac{1}{k_L} + \frac{1}{H k_G},$$

其中 $H$ 為 Henry 常數。

**關鍵判據**：
- 當 $H$ 很大（溶質難溶於液體，如 $\mathrm{O_2}$ 在水中）→ 液相膜阻力主導 → $K_L \approx k_L$
- 當 $H$ 很小（溶質易溶於液體，如 $\mathrm{NH_3}$ 在水中）→ 氣相膜阻力主導 → $K_G \approx k_G$

### 3.3 HTU/NTU 概念

在填充塔中，質傳發生在氣液接觸的填充物表面。塔高 = 傳質單元高度（HTU）× 傳質單元數（NTU）：

$$Z = H_{OG} \cdot N_{OG},$$

其中 $H_{OG} = G/(K_G a S)$（$a$ 為填充物單位體積的界面積），$N_{OG}$ 僅取決於進出口濃度與平衡線。這與熱交換器的 NTU 法完全平行。

## 4. 輸送現象的統一視角

Bird、Stewart、Lightfoot 的經典教科書《Transport Phenomena》建立了三者統一的數學框架。三種輸送的通量都可以寫成：

$$\begin{pmatrix} \text{通量} \end{pmatrix} = -\begin{pmatrix} \text{擴散係數} \end{pmatrix} \cdot \begin{pmatrix} \text{驅動力梯度} \end{pmatrix}.$$

| 輸送量 | 通量符號 | 擴散係數 | 驅動力 | 守恆方程 |
|--------|----------|----------|--------|----------|
| 動量 | $\tau$（剪切應力） | $\nu = \mu/\rho$ | 速度梯度 $\nabla v$ | Navier–Stokes |
| 熱量 | $q$（熱通量） | $\alpha = k/(\rho C_p)$ | 溫度梯度 $\nabla T$ | 熱傳導方程 |
| 質量 | $J$（質通量） | $D$ | 濃度梯度 $\nabla C$ | 擴散方程 |

三者的一維暫態方程完全相同（擴散方程），三者的穩態殼層均衡解法套路也相同。化工人把這個統一性內化後，可以在一科學會的解法立刻套用到另外兩科。

## 5. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| Maxwell–Stefan 多成分擴散 | 當系統有三種以上成分時，Fick 定律的簡單形式失效——各成分的擴散通量會互相耦合（成分 A 的擴散受成分 B 的濃度梯度影響）。 |
| 多孔介質中的擴散與反應 | 觸媒粒子內部的 Knudsen 擴散（孔徑 < 平均自由徑時，分子與孔壁碰撞比分子間碰撞更頻繁）與表面擴散的建模。 |
| 穿透與滲透蒸發膜分離 | 溶解–擴散模型描述滲透分子如何先溶入膜內再擴散通過，選擇性 = 溶解度選擇性 × 擴散選擇性。 |
