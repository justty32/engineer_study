# 化工概論與質能均衡（Introduction to Chemical Engineering & Material and Energy Balances）

> 名詞對照見 [中英名詞對照表 → 化工概論與質能均衡](../中英名詞對照表-1.md#化工概論與質能均衡)。

## 0. 本科在本系的定位

- **它是什麼**：化工系的「第一門專業課」，兩個任務同時進行：(1) 建立對化學工程的宏觀認識（化工在做什麼、整座工廠長怎樣）；(2) 學會對任何程序做「記帳」——追蹤物質（質量）與能量從哪裡進去、從哪裡出來、中間發生了什麼。
- **往上游銜接什麼**：只需要高中程度的化學（莫耳概念、化學計量、反應式平衡）和基礎代數。微積分與物理在能量均衡時會用到，但本科只用到最基本的形式。
- **往下游銜接什麼**：**質能均衡是整個化工系的共同語言**。熱力學需要它來框定系統邊界、輸送現象用它寫出殼層均衡（shell balance）、反應工程用它推導設計方程、程序設計用它做全廠物料與能量結算。如果這科沒學好，後面的科目會像「聽得懂單字但看不懂句子」。
- **核心心法**：化工從頭到尾都在算「**進來 = 出去 + 累積 + 消耗/生成**」，差別只在於「算的東西是物質還是能量、有沒有化學反應、是穩態還是隨時間變」。

### 對擁有者的提醒

這科的數學非常簡單（聯立一次方程為主），但「**系統思維**」跟寫程式很像：定義系統邊界 → 確認輸入輸出 → 寫下守恆式 → 求解。你軟體很強，這科的邏輯對你來說應該很直觀。真正需要花心力的是**化學方面的名詞與觀念**（莫耳、反應計量、相變化潛熱等），我會在文中把這些講清楚。

## 1. 化學工程是什麼

### 1.1 化工 vs 化學

| | 化學家（Chemist） | 化工工程師（Chemical Engineer） |
|---|---|---|
| 關心的問題 | 這個反應能不能發生？產物是什麼？機構是什麼？ | 要多大的反應器？要多少原料、能量？產物怎麼分離純化？整件事要花多少錢、安不安全？ |
| 操作規模 | 試管、燒瓶（克級） | 反應塔、蒸餾塔（噸級） |
| 核心技能 | 合成、分析、光譜判讀 | 數學建模、規模放大、經濟評估、安全設計 |

一句話總結：**化學家發明新分子，化工工程師讓這個分子能以合理成本大量生產。**

### 1.2 化工的典型工作場景

一座化工廠（或煉油廠、製藥廠、食品廠）可以抽象成：

```
原料（進料）→ [前處理] → [反應器] → [分離純化] → [產品]
                   ↑            ↑            ↑
              質能均衡     反應工程     分離程序
```

每個箭頭之間都有一堆管線、泵、熱交換器、控制閥，而化工人要對這整條線上的每一段做物料與能量的結算——這就是質能均衡。

### 1.3 化工的四大支柱

整本化工課程繞著四個「守恆/平衡」的概念轉：

1. **質量守恆（Conservation of Mass）**：物質不生不滅（不含核反應），進出要對得起來。
2. **能量守恆（Conservation of Energy）**：熱力學第一定律，能量形式可轉換但總量不變。
3. **動量守恆（Conservation of Momentum）**：流體受力與運動的關係（Navier–Stokes 方程即其微分形式）。
4. **化學平衡與速率**：熱力學告訴你「最多能做到哪裡」，動力學告訴你「做到那裡要多久」。

## 2. 單位、因次與單位換算

### 2.1 因次 vs 單位

- **因次（dimension）**：物理量的本質類別，例如質量 $[M]$、長度 $[L]$、時間 $[T]$、溫度 $[\Theta]$。
- **單位（unit）**：量測該因次的具體尺度，例如公斤、磅都是質量的單位。

方程式兩邊的**因次必須一致**（因次一致性，dimensional homogeneity），這是檢驗推導是否有誤的第一關。

### 2.2 兩種常用單位制

| 單位制 | 質量 | 長度 | 時間 | 力 | 能量 |
|--------|------|------|------|-----|------|
| SI | kg | m | s | N = kg·m/s² | J = N·m |
| 英制工程 | lbm | ft | s | lbf = 32.174 lbm·ft/s² | Btu |

**關鍵陷阱**：英制中「磅質量（lbm）」和「磅力（lbf）」數值在日常地表重力下相同，但物理上不是同一個量。計算時經常需要 $g_c = 32.174\ \mathrm{lb_m\!\cdot ft/(lb_f\!\cdot s^2)}$ 這個轉換因子，它就像英制版的牛頓第二定律「校正常數」。化工人常用 SI，但美國業界仍大量使用英制，所以兩個都要認得。

### 2.3 莫耳與質量分率

化學反應的本質是「分子與分子碰撞」，所以化工人更常用**莫耳（mole）**而非質量來計數。兩者間的橋樑是**分子量（molecular weight, MW）**：

$$n\ \mathrm{(mol)} = \frac{m\ \mathrm{(g)}}{MW\ \mathrm{(g/mol)}}.$$

**質量分率（mass fraction）** $x_i$ 與**莫耳分率（mole fraction）** $y_i$ 在多成分系統中頻繁互轉，要熟練。

## 3. 程序流程圖與系統邊界

### 3.1 三種流程圖層級

工程上三種圖的精細度不同，化工人要能讀、能畫：

| 圖種 | 英文 | 內容 |
|------|------|------|
| 方塊流程圖 | Block Flow Diagram (BFD) | 大方塊 + 主物流線，給高層看的「地圖」 |
| 程序流程圖 | Process Flow Diagram (PFD) | 標出主要設備、物流編號、操作條件（T, P, 流量） |
| 管線與儀表圖 | Piping & Instrumentation Diagram (P&ID) | 每條管線、每個閥、每個儀表都畫出來，施工與操作依據 |

本科質能均衡主要用 BFD 與簡化 PFD 的等級：知道有哪些單元、物流怎麼走就夠了。

### 3.2 系統與邊界

做均衡的第一步永遠是**畫一個虛線框，決定你要算「什麼範圍」**：

- **系統（system）**：框內的東西（一個設備、一段管線、或整座工廠）。
- **邊界（boundary）**：虛線框本身。
- **周圍（surroundings）**：框外的一切。

框畫在哪，哪些物流算「進」、哪些算「出」就跟著定下來。這一步畫錯，後面全部白算——就像寫程式時 scope 搞錯。

## 4. 物料均衡（Material Balance）

### 4.1 通用守恆式

對任何系統中的任何物質：

$$\begin{Bmatrix} \text{輸入} \end{Bmatrix} - \begin{Bmatrix} \text{輸出} \end{Bmatrix} + \begin{Bmatrix} \text{生成} \end{Bmatrix} - \begin{Bmatrix} \text{消耗} \end{Bmatrix} = \begin{Bmatrix} \text{累積} \end{Bmatrix}$$

或簡寫：

$$\text{In} - \text{Out} + \text{Gen} - \text{Cons} = \text{Acc}$$

### 4.2 穩態 vs 非穩態

- **穩態（steady-state）**：系統內任何一點的性質不隨時間改變。累積項 $=0$，所有對時間的導數為零。實務上連續運轉的工廠大部分時間都處於穩態。
- **非穩態（unsteady-state / transient）**：系統隨時間變化，例如開機、停機、進料切換、反應槽的升溫階段。累積項 $\neq 0$，通常會變成微分方程。

**穩態物料均衡（無化學反應時）**簡化為：

$$\sum \dot{m}_{\text{in}} = \sum \dot{m}_{\text{out}}.$$

也就是「總質量進 = 總質量出」（注意：**總質量**守恆，但若有化學反應，每一種「化學物種」的質量可以不守恆）。

### 4.3 有反應時的物種均衡

發生化學反應時，對**單一物種 $i$**：

$$\dot{n}_{i,\text{in}} - \dot{n}_{i,\text{out}} + \dot{n}_{i,\text{gen}} = 0 \quad \text{（穩態）}.$$

其中 $\dot{n}_{i,\text{gen}}$ 是該物種在反應中的**淨生成莫耳流率**。它與反應計量係數 $\nu_i$ 和反應程度 $\xi$ 有關：

$$\dot{n}_{i,\text{gen}} = \nu_i \cdot \dot{\xi}.$$

- $\nu_i > 0$：產物（生成）
- $\nu_i < 0$：反應物（消耗）
- $\nu_i = 0$：惰性物質（不參與反應）

例如反應 $\mathrm{2A + B \to 3C}$，$\nu_A = -2,\ \nu_B = -1,\ \nu_C = +3$。

### 4.4 解題策略

化工系解物料均衡題的標準 SOP：

1. **畫流程圖**（標上所有已知與未知的物流）。
2. **選定計算基準（basis）**：通常選給定流量或某進料量 = 100 mol/h，因為均衡方程式是線性的，可以等比例縮放。
3. **寫下所有獨立方程式**（每成分一個物料均衡，加上組成關係式、反應計量關係）。
4. **做自由度分析（degree-of-freedom analysis）**：
   $$N_{\text{df}} = N_{\text{unknowns}} - N_{\text{independent equations}}.$$
   若 $N_{\text{df}} = 0$ → 恰定，可解。$N_{\text{df}} > 0$ → 少條件（欠定）。$N_{\text{df}} < 0$ → 過約束。
5. **解聯立方程**（通常為線性代數，手算或寫程式）。

## 5. 能量均衡（Energy Balance）

### 5.1 能量守恆的幾種形式

能量均衡的第一定律（對密閉系統）：

$$\Delta U = Q - W,$$

- $U$：內能（internal energy）
- $Q$：系統吸收的熱（$Q>0$ 表吸熱）
- $W$：系統對外做的功（$W>0$ 表系統對外做功）

對**開放系統**（有物質進出，絕大多數化工設備都是），需改用**焓（enthalpy）** $H = U + PV$：

$$\Delta H + \Delta E_k + \Delta E_p = Q - W_s,$$

- $\Delta E_k$：動能變化（進出口流速不同時）
- $\Delta E_p$：位能變化（進出口高度不同時）
- $W_s$：軸功（shaft work，透過旋轉軸傳遞的機械功）

在大多數化工設備中，動能與位能項相對於焓變可以忽略：

$$\Delta H \approx Q - W_s.$$

### 5.2 需要能量均衡的典型情境

1. **加熱/冷卻**：用熱交換器把某物流從 $T_1$ 升/降到 $T_2$，計算需要多少蒸汽或冷卻水——這叫**顯熱（sensible heat）**計算：$Q = \dot{m} C_p \Delta T$。
2. **相變化**：蒸發、冷凝需要**潛熱（latent heat）**：$Q = \dot{m} \cdot \Delta H_{\text{vap}}$。
3. **化學反應**：反應會吸收或放出熱量（反應熱 $\Delta H_{\text{rxn}}$）。放熱反應需要冷卻（否則可能失控），吸熱反應需要持續供熱。
4. **混合**：不同物質混合可能有混合熱（heat of mixing）。

### 5.3 參考狀態與焓的計算

焓本身沒有絕對值，我們只能算「相對於某參考狀態的差值」。常見做法：

- 選定參考溫度 $T_{\text{ref}}$（例如 25°C）與參考相態。
- 列出**顯熱**部分：$\Delta H_{\text{sensible}} = \int_{T_{\text{ref}}}^{T} C_p(T)\,dT$。
- 若涉及相變化，在相變溫度加上 $\Delta H_{\text{phase change}}$。
- 若有反應，加上標準反應熱 $\Delta H_{\text{rxn}}^\circ$（從標準生成焓計算）。

這整個流程稱為**焓路徑法（hypothetical process path）**：把實際程序拆成一系列「虛擬步驟」（升溫 → 相變 → 升溫 → 反應 → …），每一步的焓變都可以查表或計算。

### 5.4 同時做質能均衡

實務上，物料與能量均衡是**耦合**的：反應速率可能隨溫度變化（Arrhenius 定律），而溫度又取決於反應放出多少熱。所以要聯立求解。這在反應工程中會深入討論，本科只需建立「質與能要一起算」的觀念。

## 6. 含循環與旁通的流程

### 6.1 循環（recycle）

未反應完的原料經過分離後送回反應器入口，提升總轉化率與原料利用率：

```
進料 → [混合點] → [反應器] → [分離器] → 產品
              ↑                      ↓
              └── 循環物流 ←─────────┘
```

對含循環的流程做均衡時，有兩種策略：

- **整體均衡（overall balance）**：把整條循環線路框在一個大系統裡，直接算外部進出。優點：循環內部細節消去。
- **逐單元均衡 + 疊代**：若循環量未知，需假設一個值 → 算一遍 → 檢查是否收斂 → 修正再算。這正是程序模擬軟體（如 Aspen Plus）在做的事。

### 6.2 旁通（bypass）

讓一部分物流跳過某單元（例如跳過熱交換器以調節出口溫度）。均衡邏輯類似，只是分流而非循環。

### 6.3 排放（purge）

在含循環的系統中，惰性物質（不參與反應但隨進料帶入的雜質、或反應副產物）若不被移除會在循環中累積到無限大。解決方法是從循環中抽出一小股「排放流（purge stream）」把惰性物排掉——這在實際工廠中非常重要。

## 7. 非穩態質能均衡入門

### 7.1 何時需要非穩態

- 開機（startup）與停機（shutdown）
- 批次反應器（加料 → 反應 → 出料，全程都是暫態）
- 進料組成或流量變動
- 緊急排放與安全分析

### 7.2 基本形式

非穩態物料均衡（對均勻攪拌槽）：

$$\frac{d(\rho V)}{dt} = \dot{m}_{\text{in}} - \dot{m}_{\text{out}}.$$

若體積固定、密度不變：

$$\frac{dC_i}{dt} = \frac{\dot{m}_{\text{in},i} - \dot{m}_{\text{out},i}}{V} + r_i,$$

其中 $r_i$ 為物種 $i$ 的反應速率（以單位體積計）。這是一個常微分方程（ODE），解它需要初始條件（$t=0$ 時的濃度）。這也是為什麼**工程數學中的 ODE** 對化工人如此重要。

### 7.3 非穩態能量均衡

$$\frac{d(U + E_k + E_p)_{\text{sys}}}{dt} = \dot{Q} - \dot{W} + \sum \dot{m}_{\text{in}} \hat{H}_{\text{in}} - \sum \dot{m}_{\text{out}} \hat{H}_{\text{out}}.$$

典型應用：計算一個攪拌槽加熱器從室溫升到操作溫度需要多少時間。
