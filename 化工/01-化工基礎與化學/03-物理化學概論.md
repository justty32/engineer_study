# 物理化學概論（Introduction to Physical Chemistry）

> 名詞對照見 [中英名詞對照表 → 物理化學概論](../中英名詞對照表.md#物理化學概論)。

## 0. 本科在本系的定位

- **它是什麼**：物理化學（物化）用物理學的原理（熱力學、量子力學、動力學）來理解化學系統的行為。如果說有機化學教「什麼東西可以變什麼」，物化就教「變化的極限在哪裡、有多快、為什麼」。
- **往上游銜接什麼**：微積分（對熱力學推導）、微分方程（動力學）、普通物理（能量守恆、氣體分子運動論）。
- **往下游銜接什麼**：
  - **化工熱力學**：把物化的理想系統推廣到真實混合物，加入逸壓（fugacity）與活性（activity）來處理非理想性。
  - **化學反應工程**：動力學是反應器設計的核心輸入——沒有速率方程就無法算反應器體積。
  - **分離程序**：相平衡（VLE、LLE）決定蒸餾與萃取的可行性與極限。
  - **輸送現象**：熱力學給定趨動力（driving force），輸送現象給定速率。
- **核心心法**：物化的主軸是「**平衡、速率、結構**」三個問題——熱力學回答「平衡在哪」，動力學回答「到平衡要多久」，量子化學回答「為什麼分子長這樣」。

### 對擁有者的提醒

物化用到大量微積分與微分方程，但化工系通常只要求「看得懂推導、會用公式」而非像物理系那樣從第一原理出發。你在電機學過的熱力學（熵、自由能）與統計概念在這裡會重逢，只是應用的對象從電子變成分子。化學熱力學的符號系統（$\Delta H$、$\Delta G$、$\Delta S$）與各種標準狀態的定義需要花時間熟悉——它們是化工人一輩子的語言。

## 1. 氣體與狀態方程

### 1.1 理想氣體定律

$$PV = nRT$$

- $P$：壓力、$V$：體積、$n$：莫耳數、$T$：絕對溫度
- $R = 8.314\ \mathrm{J/(mol \cdot K)} = 0.08206\ \mathrm{L \cdot atm/(mol \cdot K)}$

理想氣體的假設：分子本身的體積可忽略、分子間無作用力。真實氣體在低壓（分子間距離遠）、高溫（動能遠大於分子間位能）時接近理想行為。

### 1.2 真實氣體的修正

**van der Waals 方程**：

$$\left(P + \frac{a n^2}{V^2}\right)(V - n b) = nRT.$$

- $a$ 項修正分子間的吸引力（使實際壓力低於理想值，分子彼此拉住所以撞壁的力道減小）
- $b$ 項修正分子本身占據的體積（不可壓縮的硬核，使實際可用體積小於容器體積）

化工常用的其他狀態方程：**Redlich–Kwong、Soave–Redlich–Kwong（SRK）、Peng–Robinson（PR）**——這些在計算氣液相平衡（VLE）時比 van der Waals 準得多，是程序模擬軟體的內建選項。

### 1.3 對應狀態原理（principle of corresponding states）

用**對比變數**（reduced variables）$T_r = T/T_c$、$P_r = P/P_c$、$V_r = V/V_c$ 歸一化後，不同氣體的 $PVT$ 行為相當接近（van der Waals 首先觀察到）。**壓縮因子（compressibility factor）** $Z = \dfrac{PV}{nRT}$ 是衡量偏離理想程度的常用指標；理想氣體 $Z = 1$，真實氣體在不同 $T_r, P_r$ 下 $Z$ 可能遠離 1。

## 2. 化學熱力學

### 2.1 三大定律

| 定律 | 陳述（化學版） | 工程意義 |
|------|---------------|----------|
| 第零定律 | 若 A 與 B 熱平衡、B 與 C 熱平衡，則 A 與 C 熱平衡 | 定義了「溫度」這個概念 |
| 第一定律 | $\Delta U = Q - W$，能量守恆 | 做能量均衡的基礎 |
| 第二定律 | 孤立系統的熵永不減少，$\Delta S_{\text{univ}} \ge 0$ | 決定了程序是否可能自發、效率上限 |
| 第三定律 | 完美晶體在 0 K 時 $S = 0$ | 提供熵的絕對參考點 |

### 2.2 熵與自發性

- **熵（entropy, $S$）**：衡量系統「混亂度」或微觀狀態數的物理量。$\Delta S_{\text{univ}} = \Delta S_{\text{sys}} + \Delta S_{\text{surr}} > 0$ 是自發程序的必要條件。
- **Gibbs 自由能（$G$）**：定溫定壓下，$\Delta G < 0$ 表示程序自發。這是化學熱力學使用最頻繁的判據：
  $$\Delta G = \Delta H - T\Delta S.$$

- $\Delta H < 0$（放熱）有利自發（貢獻負的 $\Delta G$）
- $\Delta S > 0$（混亂度增加）有利自發（貢獻負的 $-T\Delta S$）
- 當兩者競爭時，溫度決定誰贏

### 2.3 化學位能（chemical potential）

**化學位能 $\mu_i$** 是物化中最重要的核心概念之一——它是「在定溫定壓下，加入一莫耳物質 $i$ 所引起的自由能變化」：

$$\mu_i = \left(\frac{\partial G}{\partial n_i}\right)_{T,P,n_{j \neq i}}.$$

一個化學反應會自發往前的條件是：

$$\sum_{\text{products}} \nu_i \mu_i < \sum_{\text{reactants}} \nu_i \mu_i.$$

當兩邊相等時，反應達到平衡。這就是質量作用定律的熱力學根源。

### 2.4 化學平衡

對反應 $a\mathrm{A} + b\mathrm{B} \rightleftharpoons c\mathrm{C} + d\mathrm{D}$（理想系統）：

$$\Delta G^\circ = -RT \ln K,\quad K = \frac{[\mathrm{C}]^c[\mathrm{D}]^d}{[\mathrm{A}]^a[\mathrm{B}]^b}.$$

- $K \gg 1$：平衡強烈傾向產物（$\Delta G^\circ \ll 0$）
- $K \ll 1$：平衡強烈傾向反應物（$\Delta G^\circ \gg 0$）
- van't Hoff 方程描述 $K$ 如何隨溫度變化：
  $$\frac{d\ln K}{dT} = \frac{\Delta H^\circ}{RT^2}.$$

放熱反應（$\Delta H^\circ < 0$）：升溫使 $K$ 下降，平衡往反應物移動（Le Châtelier 原理）。

## 3. 相平衡與相律

### 3.1 Gibbs 相律

$$F = C - P + 2.$$

- $F$：自由度（可獨立改變的變數數目，如溫度、壓力、組成）
- $C$：成分數（chemically independent components）
- $P$：共存相數

例如純水在三相點：$C=1, P=3 \Rightarrow F=0$，沒有任何自由度——只有一個唯一的溫度與壓力可以使三相共存。

### 3.2 相圖（phase diagram）

- **單成分相圖**：$P$–$T$ 圖，畫出固/液/氣的穩定區域，曲線是兩相共存線（Clausius–Clapeyron 方程描述其斜率），三條線交於三相點，液氣線終止於臨界點。
- **雙成分相圖**：定壓下的 $T$–$x$ 圖（常用於蒸餾分析），標出泡點線（bubble point curve）與露點線（dew point curve），兩者中間是兩相區。

### 3.3 Clausius–Clapeyron 方程

描述相變曲線的斜率：

$$\frac{dP}{dT} = \frac{\Delta H_{\text{phase change}}}{T \Delta V}.$$

對液–氣平衡，假設蒸氣為理想氣體且液體體積可忽略，可得常用形式：

$$\ln\frac{P_2}{P_1} = -\frac{\Delta H_{\text{vap}}}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right).$$

這是計算沸點隨壓力變化、蒸氣壓隨溫度變化的實用公式。

## 4. 化學動力學（Chemical Kinetics）

### 4.1 反應速率定律

對反應 $a\mathrm{A} \to \text{products}$：

$$r = -\frac{1}{a}\frac{d[\mathrm{A}]}{dt} = k[\mathrm{A}]^n.$$

- $k$：速率常數（rate constant），隨溫度變化（見 Arrhenius）
- $n$：反應級數（order），可以是整數、分數、零，**必須由實驗測定，不能從計量係數推斷**
- 常見級數：零級（$r = k$，速率與濃度無關，表面觸媒飽和時）、一級（$r = k[A]$，放射性衰變、異構化）、二級（$r = k[A][B]$ 或 $k[A]^2$）

### 4.2 積分速率定律

| 級數 | 積分形式 | 半生期 $t_{1/2}$ |
|------|----------|------------------|
| 0 級 | $[A] = [A]_0 - kt$ | $[A]_0/(2k)$ |
| 1 級 | $\ln[A] = \ln[A]_0 - kt$ | $\ln 2/k$（與初濃度無關！） |
| 2 級（單一反應物） | $1/[A] = 1/[A]_0 + kt$ | $1/(k[A]_0)$ |

### 4.3 Arrhenius 方程

$$k = A \exp\!\left(-\frac{E_a}{RT}\right).$$

- $A$：頻率因子（pre-exponential factor），代表碰撞頻率與位向因素的乘積
- $E_a$：活化能（activation energy），分子要越過的能障高度
- **經驗法則**：室溫下，$E_a$ 每增加約 5.7 kJ/mol，反應速率約減半；溫度每升 10°C，速率大約加倍（$Q_{10} \approx 2$）

### 4.4 反應機構與速率決定步驟

複雜反應常由多步**基元反應（elementary reaction）**組成。**速率決定步驟（rate-determining step, RDS）**是其中最慢的一步，整體反應速率由此步控制。常見的分析手法是**穩態近似（steady-state approximation）**：假設反應中間體濃度始終極低且不隨時間變化（$d[\text{intermediate}]/dt \approx 0$），從而把複雜機構簡化成代數方程。

## 5. 表面化學與電化學入門

### 5.1 表面與界面

化工中大量使用**觸媒（catalyst）**——一種降低活化能、加速反應、但自身不被消耗的物質。固體觸媒的反應發生在**表面**，所以**比表面積（specific surface area）**至關重要。常見載體如氧化鋁、二氧化矽、活性碳，它們提供巨大的表面積讓貴金屬（Pt, Pd, Rh）以奈米粒子形式分散其上。

吸附分兩種：
- **物理吸附（physisorption）**：van der Waals 力，弱、可逆、低溫有利
- **化學吸附（chemisorption）**：形成化學鍵，強、可能不可逆、決定了觸媒的活性位點數目

Langmuir 等溫吸附式描述單層吸附：

$$\theta = \frac{KP}{1 + KP},$$

其中 $\theta$ 為表面覆蓋率、$K$ 為吸附平衡常數。

### 5.2 電化學基礎

電化學處理「化學能 ↔ 電能」的轉換。電池（放電）與電解（充電/電解水產氫）是同一枚硬幣的兩面：

- **Nernst 方程**：非標準條件下的電極電位
  $$E = E^\circ - \frac{RT}{nF}\ln Q,$$

  其中 $Q$ 為反應商（與平衡常數同樣形式但用當前濃度而非平衡濃度）。
- **Faraday 定律**：$m = \dfrac{M I t}{n F}$，電極上沉積或溶解的質量與通過的電量成正比。

化工中電化學的主要應用：氯鹼工業（電解鹽水產氯氣與燒鹼）、鋁冶煉（Hall–Héroult 法）、電鍍、燃料電池、電解水產氫氣。

## 6. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 統計熱力學 | 從分子配分函數（partition function）出發，推導出所有宏觀熱力學量，是連結量子力學與古典熱力學的橋樑。 |
| 非平衡態熱力學 | 處理不可逆程序的熱力學框架（Onsager 倒易關係、熵產生率極小化原理），是薄膜分離與生物傳輸的理論基礎。 |
| 表面科學與觸媒表徵 | XPS、TPD、BET 等實驗技術用於了解觸媒表面的活性位點結構與數量。 |

## 7. 博士層級研究方向

- 單原子觸媒（single-atom catalyst）的活性位點設計與表徵
- 電化學 CO₂ 還原（CO₂RR）的機構與觸媒篩選
- 從頭算分子動力學（AIMD）用於模擬高溫高壓下的反應機構
- 密度泛函理論（DFT）在觸媒篩選中的高通量應用
