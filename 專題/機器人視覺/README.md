# 機器人視覺

本專題從光如何成為影像陣列開始，依序建立投影、標定、深度、姿態估測、點雲、視覺伺服與可診斷 C++ 管線。

- 讀者基線：預設讀者具程式基礎（C++ 例子另附說明），機器人視覺零基礎；不假設影像處理、相機、線性代數或機器學習知識。
- 線上版本：[GitHub Pages / 機器人視覺](https://justty32.github.io/engineer_study/robot-vision/)（正式發布路徑 `/robot-vision/`）
- 互動課程入口：[互動課程首頁](互動課程/index.html)；第一站 [00 光像素與座標系](互動課程/00-光像素與座標系.html)、[00A 影像資料先修](互動課程/00A-影像資料先修.html)、[可搜尋白話字典](互動課程/名詞與概念字典.html)
- 頁面地圖：[互動課程/README.md](互動課程/README.md)
- 課程專案簡報：[互動課程/PROJECT-BRIEF.md](互動課程/PROJECT-BRIEF.md)

每章固定先教後操作：白話問題、最小前置、物理到數值的因果、手算例、自由實驗、可觀察證據、常見誤解與適用邊界。字典用於隨時回查，不要求先背。
