# 機器人視覺

本專題面向「會 C++、但機器人視覺零基礎」的讀者。課程從光如何成為影像陣列開始，不假設影像處理、相機、線性代數或機器學習知識；再依序建立投影、標定、深度、姿態估測、點雲、視覺伺服與可診斷 C++ 管線。

- [影像資料先修](互動課程/00A-影像資料先修.html)
- [可搜尋白話字典](互動課程/名詞與概念字典.html)
- 正式發布路徑：`/robot-vision/`

每章固定先教後操作：白話問題、最小前置、物理到數值的因果、手算例、自由實驗、可觀察證據、常見誤解與適用邊界。字典用於隨時回查，不要求先背。
