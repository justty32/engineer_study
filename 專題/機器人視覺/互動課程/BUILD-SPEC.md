# 建置規格

## 靜態結構

原生 HTML、CSS、JavaScript，多頁離線課程。共用 `styles.css` 與具元素存在檢查的 `app.js`。主線為首頁、`00`、`00A`、`01–08` 與可搜尋字典；所有頁具上一頁／下一頁，無孤兒頁。

## 教學頁契約

每個教學章至少約 1100 個純文字字元，且依序提供：讀者的白話 why、一句話答案、最小前置、首次術語展開、從物理／角色到數值／資料流的逐步因果、至少一個可手算例、互動前完整說明、可觀察證據、常見誤解與適用邊界。互動不計分、不鎖頁。

`00A-影像資料先修.html` 專責影像陣列、灰階、顏色通道、亮度、空間取樣、量化、雜訊、模糊、列步距與 C++ 緩衝區契約。字典純文字至少 5000 字元，每條必備「白話、位置／角色、如何生效、具體例子、不要混淆」。

## 既有互動與公式

- 投影：`u=f_x X/Z+c_x`、`v=f_y Y/Z+c_y`。
- 焦距偏差示意：`|e|r/100` 像素。
- RANSAC 理想抽樣命中率：`P=1-(1-w^s)^N`。
- 雙目深度與局部敏感度：`Z=fb/d`、`|dZ/dd|=fb/d²`。
- 延遲位移尺度：`Δx=vΔt`。
- 感知輸出契約：擷取時間、來源／目標座標系、品質／不確定度。
- 一維 Kalman 更新：`K=P/(P+R)`、`μ⁺=μ⁻+K(z−μ⁻)`、`P⁺=(1−K)P`。
- 漂移示意：系統項 `距離×比例`、隨機項 `尺度×√距離`，閉環只按指定比例縮減示意漂移，不聲稱等同真實 SLAM 圖最佳化。

所有模型均在正文標示假設；不繪製或載入圖片，不使用外部字型、分析碼、內容傳遞網路、遠端 API 或第三方執行期依賴。
