A–Z · SEARCHABLE GLOSSARY

名詞與概念字典

搜尋繁中、英文或縮寫；每個條目說明位置、功能與易混邊界。

像素

Pixel

影像陣列的取樣單元；數值不是三維位置。

曝光

Exposure

感測器積分光訊號的時間與過程。

針孔模型

Pinhole Camera Model

忽略複雜鏡頭效應的中心投影模型。

內參

Intrinsics

焦距、主點等相機內部投影參數。

外參

Extrinsics

兩個座標系間的旋轉與平移。

主點

Principal Point

光軸與理想影像平面的交點像素。

徑向畸變

Radial Distortion

像素偏移隨離主點距離改變的鏡頭效應。

重投影誤差

Reprojection Error

預測像素與觀測像素的差。

手眼標定

Hand–Eye Calibration

估計相機與末端或基座間的剛體變換。

眼在手上

Eye-in-Hand

相機固定在機器人末端。

眼在手外

Eye-to-Hand

相機固定在外部環境。

特徵

Feature

可偵測並描述、用於建立對應的影像結構。

描述子

Descriptor

用來比較局部特徵相似度的表示。

對應

Correspondence

兩個量測代表同一物理點的假設。

PnP

Perspective-n-Point

由三維點與二維投影估位姿。

RANSAC

Random Sample Consensus

反覆抽樣並以一致集合抵抗離群值。

內點

Inlier

在指定模型與閾值下相容的量測。

退化

Degeneracy

幾何配置不足以穩定決定模型。

視差

Disparity

雙目左右對應點的像素位移。

基線

Baseline

雙目兩相機中心間距。

點雲

Point Cloud

一組三維量測點，不等同已辨識物體。

配準

Registration

估計兩組幾何資料間的變換。

IBVS

Image-Based Visual Servoing

直接以影像特徵誤差閉迴路控制。

PBVS

Position-Based Visual Servoing

以估測三維位姿誤差控制。

協方差

Covariance

描述估測誤差尺度與方向關聯的矩陣。

時間同步

Time Synchronization

把影像與機器人狀態對齊同一時間基準。

延遲

Latency

事件發生到結果可用的時間差。
