# 機器人視覺互動課程

入口：[index.html](index.html)。建議順序：`00 光形成量測 → 00A 影像資料 → 01 投影 → 02 標定 → 03 對應與姿態 → 04 深度與點雲 → 05 視覺伺服 → 06 C++ 證據 → 07 機率融合 → 08 視覺里程計與 SLAM`。

進階擴展新增 `07-機率估測協方差與感測融合.html` 與 `08-視覺里程計SLAM與閉環校正.html`；前者補上先驗、創新、協方差、Kalman 更新與門控，後者補上 VO 前後端、漂移、姿態圖、閉環、重定位與地圖版本。

本課採 foundations-first：每章至少包含白話問題、最小前置、首次術語展開、逐步因果、可手算數值例、互動前教學、可觀察證據、常見誤解與模型邊界。字典是回查工具，不是入場測驗。

執行期只有本目錄 HTML、CSS 與 JavaScript；不使用圖片、外部字型、內容傳遞網路或遠端 API。
