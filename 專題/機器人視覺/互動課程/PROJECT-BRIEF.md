# 機器人視覺互動課程 Brief

## 讀者基線與理解債

讀者是資深 C++ 工程師，但機器人視覺為零基礎。不得因其軟體能力假設已懂光學、影像陣列、相機模型、線性代數、估測、控制或機器學習。既有版本以短定義直接引入 PnP、RANSAC、點雲、IBVS 等術語，造成「看得到名詞但無法建立因果」的理解債；本版先從物理光與資料表示補起。

## 目標能力

讀者完成後能解釋光如何成為數字陣列；正確區分像素、通道、取樣、量化、雜訊與模糊；用手算追蹤三維點的投影、雙目深度與延遲位移；區分內參、外參、畸變、相機標定與手眼標定；解釋對應、PnP、RANSAC、退化、點雲與視覺伺服；設計帶時間、座標、品質、版本與失敗狀態的 C++ 感知契約。

## 概念依賴與頁面責任

`光的能量與曝光 → 影像陣列／通道／取樣／量化 → 針孔投影 → 相機標定 → 手眼座標鏈 → 特徵與對應 → PnP／RANSAC → 深度與點雲 → 視覺伺服與延遲 → C++ 證據管線 → 機率估測與融合 → 視覺里程計／SLAM／閉環`

- `00`：物理光、曝光、增益、焦點與座標種類。
- `00A`：影像記憶體、灰階／顏色、取樣、量化、雜訊與模糊。
- `01–06`：依上述依賴逐章推進；互動一律放在完整教學與數值例之後。
- `名詞與概念字典`：每條固定含白話、位置／角色、如何生效、具體例子與不要混淆。

## 語言、互動與證據契約

正文與 UI 使用繁體中文；英文術語與縮寫首次出現完整展開。無計分、無答對解鎖，控制值改變立即更新數值與 why。每章指出可由原始像素、metadata、殘差、內點分布、深度有效遮罩、時間戳、延遲分布或控制 log 觀察的證據，也明示證據不能單獨證明什麼。

## 教學與模型邊界

使用理想針孔、標準校直雙目、簡化誤差敏感度與常速延遲位移模型。內容不取代鏡頭模型選型、實機標定、完整不確定度傳播、控制穩定性證明、碰撞避免、功能安全認證或真實裝置驗證。不使用圖片與外部 runtime。
