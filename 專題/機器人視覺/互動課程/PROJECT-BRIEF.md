# 機器人視覺互動課程 Brief

## 讀者與目標

讀者會 C++ 與機械手臂運動學，但不假設懂影像、相機或估測。完成後能追蹤三維點如何成為像素、區分內外參與畸變、理解標定／手眼標定、估測姿態與深度、解釋視覺伺服的延遲風險，並建立可觀察的 C++ 感知管線。

## 概念依賴

`光與像素 → 針孔投影 → 相機標定 → 特徵與姿態估測 → 深度與點雲 → 視覺伺服 → C++ 證據`

## 邊界

使用理想針孔、簡化徑向畸變與獨立誤差模型；不取代實機標定、鏡頭模型選擇、功能安全或量測不確定度分析。
