隨查隨用

名詞與概念字典

金屬氧化物半導體場效電晶體

Metal-Oxide-Semiconductor Field-Effect Transistor, MOSFET。以閘極電壓控制通道導通的元件；本課只取受控開關抽象。
位置／機制／邊界：位置在邏輯閘的物理底層；n 型與 p 型元件組成上拉、下拉網路。閘極控制的是通道導電程度，不是理想機械接點。示波器與電源量測能看到電壓、延遲與功耗，真值表不能證明類比邊緣品質。

反及閘

NAND gate。AND 結果再反相；具功能完備性，可合成任意布林函數。
位置／機制／邊界：位置在電晶體與複雜邏輯之間；只有所有輸入為 1 時輸出 0。它的功能完備性回答「能否表達」，不回答面積、延遲或功耗是否最佳。真值表證明穩態函數，時序波形補上毛刺與傳播時間。

布林代數

Boolean algebra。以 0、1 與 NOT、AND、OR 等運算描述邏輯，不等同真實電壓瞬間一定完美。
位置／機制／邊界：角色是描述離散邏輯關係，資料流是輸入位元經運算得到輸出位元。它忽略連續電壓、負載與時間，因此不能單靠代數式保證實體電路在取樣時已穩定。

組合邏輯

Combinational logic。穩定輸出只由當前輸入決定，不保存歷史狀態。
位置／機制／邊界：位置在兩組狀態元件之間，負責由目前輸入計算候選下一值。沒有保存狀態不代表沒有延遲；閘級模擬與示波器可見毛刺，單純軟體參考函式通常看不到。

時序邏輯

Sequential logic。輸出還依賴先前保存的狀態，常由時脈協調更新。
位置／機制／邊界：位置在需要記住歷史的資料路徑，以目前狀態與輸入形成下一狀態，再於規定事件更新。它受 setup、hold、時脈偏斜與亞穩態限制；逐邊緣波形能核對狀態序列。

多工器

Multiplexer, MUX。由選擇訊號決定把哪個輸入送到輸出，是資料路徑選路核心。
位置／機制／邊界：位置在資料路徑交會處，由選擇值決定唯一輸入成為輸出。它選的是來源，不會替資料增加能量或永久保存資料；觀察所有輸入、選擇線與輸出即可驗證因果。

正反器

Flip-flop。在特定時脈事件保存一個位元；不同型式與觸發規則不可混稱。
位置／機制／邊界：位置在同步邊界，功能是在有效邊緣取樣 D 並保存到 Q。它和啟用期間透明的 latch 不同，且可能因時序違反而亞穩；波形能觀察 clock-to-Q，布林表不能。

暫存器

Register。由多個儲存位元與控制邏輯構成的快速狀態；也是組合語言可見操作位置。
位置／機制／邊界：在硬體上是一組同步儲存位元，在 ISA 上是軟體可見的命名狀態。兩層不可混淆：實體核心可重新命名，除錯器通常只顯示提交後的架構值。

算術邏輯單元

Arithmetic Logic Unit, ALU。執行加減、位元邏輯、位移或比較等組合運算。
位置／機制／邊界：位置在處理器執行資料路徑，接受運算元與控制碼，產生算術／邏輯結果及可能的條件資訊。它不負責長期保存結果；除錯器只能看到架構結果，不能直接證明內部加法器拓樸。

中央處理器

Central Processing Unit, CPU。取指、解碼並執行指令的處理核心；不等同整台計算機。
位置／機制／邊界：位置是系統中執行 ISA 的核心，狀態沿取指、解碼、執行、記憶體與提交前進。CPU 可含多核心與快取但不等於整個 SoC；指令追蹤與計數器觀察的層級也不同。

指令集架構

Instruction Set Architecture, ISA。軟體可見的指令、暫存器、資料型別、位址與例外契約。
位置／機制／邊界：位於軟體與處理器實作的契約邊界，規定可見指令與狀態結果。它不規定管線深度、快取大小或同一指令實際延遲；反組譯證明 ISA 編碼，不證明微架構時序。

微架構

Microarchitecture。某個處理器實作 ISA 的內部方法，例如管線、快取與亂序執行。
位置／機制／邊界：位於 ISA 契約之下，安排管線、預測、快取、重新命名與執行單元以完成同一可見語意。不同微架構可跑相同機器碼；效能計數器只能依特定核心事件解讀。

組合語言

Assembly language。機器指令的助記文字表示；語法與指令語意都依架構與工具而異。
位置／機制／邊界：位於人類文字與 machine bytes 之間，由 assembler 依目標架構與語法模式編碼。助記符、虛擬指令與標籤不一定一對一存在於檔案；顯示 machine bytes 才能核對實際編碼。

x86-64

x86 指令集的 64 位元擴充；具可變長度指令與豐富定址形式，平台 ABI 另行規定呼叫細節。
位置／機制／邊界：位於 ISA 層，特色包括可變長指令、部分暫存器別名與豐富定址。Intel／AT&T 語法只是表示差異；參數位置則由 System V 或 Windows 等 ABI 決定。

AArch64

64-bit Arm execution state。64 位元 Arm 執行狀態與其指令集，採明確載入／儲存模型。
位置／機制／邊界：位於 64 位元 Arm ISA 層，多數算術採三暫存器形式，記憶體由 load/store 存取。X/W 是同一暫存器不同寬度視圖；固定編碼寬度也不代表固定執行時間。

RISC-V

開放指令集架構，以基礎整數指令集加選用擴充組成；實作與 ABI 仍可有差異。
位置／機制／邊界：位於開放模組化 ISA 家族，基本集與 M、A、F、D、C、V 等擴充共同決定可執行內容。ISA 名稱不代表特定晶片或 ABI；檔案屬性與建置選項是判定邊界的證據。

程式計數器

Program counter, PC。指示當前或下一條指令位置的架構狀態；精確可見語意依 ISA。
位置／機制／邊界：位於控制流狀態，順序執行時前進，分支、呼叫、返回或例外時改用其他位址。反組譯地址是靜態候選，除錯器或硬體追蹤才能證明某次 PC 真的到過。

位元組序

Endianness。多位元組值由低位址到高位址的位元組排列方式。
位置／機制／邊界：位於多位元組值與逐 byte 記憶體之間，決定最低有效 byte 放低位址還是高位址。它不改變單一 byte 內的位元編號，也不決定網路協定欄位；記憶體 dump 可直接核對。

快取

Cache。以局部性保存近期資料區塊，縮小處理器與較慢記憶體的延遲差。
位置／機制／邊界：位於較快運算單元與較慢儲存層之間，以 cache line 與標籤利用時間、空間局部性。命中只說某級找到資料，不等於位址轉譯命中；效能計數器提供統計但不是完整逐次軌跡。

虛擬記憶體

Virtual memory。讓程序使用虛擬位址，由硬體與作業系統映射、隔離與管理。
位置／機制／邊界：位於程序位址與實體資源之間，提供映射、保護、共享與按需配置。虛擬地址可相同而對應不同頁框；程序 maps 顯示映射，通常不直接顯示實體 DRAM 位置。

頁表

Page table。描述虛擬頁到實體頁框、存在狀態與權限的分層資料結構。
位置／機制／邊界：位置在硬體／核心合作的位址轉譯路徑，記錄頁框、存在與權限。它不是程式的一般陣列 API；頁表查找失敗的結果依項目狀態，可能是缺頁、權限 fault 或無效映射。

轉譯旁觀緩衝區

Translation Lookaside Buffer, TLB。快取近期位址轉譯；失誤不必然等於缺頁。
位置／機制／邊界：位置在地址轉譯的快取層，保存近期虛擬頁到頁框與權限資訊。TLB miss 只表示要重新查頁表，不等於去磁碟；硬體計數器可統計但事件名稱依核心。

應用程式二進位介面

Application Binary Interface, ABI。二進位模組對呼叫、暫存器、堆疊、資料布局與名稱的契約。
位置／機制／邊界：位於分開產生的二進位模組邊界，涵蓋 calling convention、資料布局、名稱、物件格式等。相同 ISA 不保證 ABI 相同；反組譯與暫存器快照需配合平台規範解讀。

呼叫慣例

Calling convention。ABI 的一部分，規定參數、回傳值、保存暫存器與堆疊責任。
位置／機制／邊界：角色是分配參數、結果、暫存器保存與 stack alignment 責任。caller-saved 並非不重要，callee-saved 也非不能改；函式進出時的暫存器與 stack 可作證。

系統呼叫

System call。使用受控入口請求作業系統核心服務，不等同一般函式呼叫。
位置／機制／邊界：位於使用者模式與核心服務的受控邊界，以架構入口、編號與專用參數規則運作。包裝函式可能先後做其他事；system-call trace 能證明核心請求，普通 call 不能。

預處理器

Preprocessor。處理引入檔、巨集與條件編譯，輸出仍是語言文字。
位置／機制／邊界：位置在 C/C++ 語意分析前，處理 token 級巨集、include 與條件選擇。輸出可證明編譯器實際看見的文字，不能證明後端保留相同行或產生特定指令。

中介表示

Intermediate Representation, IR。編譯器內部介於來源語言與目標指令間的程式表示。
位置／機制／邊界：位置在編譯器前端與後端之間，以較適合分析轉換的形式保存語意與資料流。IR 不是單一跨工具標準，也不一定寫進成品；它只能代表指定版本與選項的一次編譯。

組譯器

Assembler。把組合語言編碼成機器碼，並可依輸入與目的檔格式產生區段、符號與重定位資訊。
位置／機制／邊界：位置在 assembly text 與 object file 之間，解析助記符、標籤、directive 與虛擬指令，再產生 machine bytes、symbol 與 relocation。成功組譯不表示外部符號已找到。

目的檔

Object file。含機器碼與資料，但常仍可重定位且有外部符號未解析。
位置／機制／邊界：位置在單一翻譯單元與最終映像之間，保存可重定位 code/data 及連結中繼資料。其 section offset 通常不是執行期虛擬位址；object inspector 可核對內容。

區段

Section。依用途、權限或連結規則分類的目的檔內容；不應直接與載入後記憶體區域混為一談。
位置／機制／邊界：位置在 object/linker 的內容分類，讓相同用途與權限需求的資料被布局。section 與載入後 mapping/segment 有關但不等同；檔案標頭能顯示兩者對應。

符號

Symbol。替函式、物件或位置命名，供解析、重定位、除錯與動態連結使用。
位置／機制／邊界：位置在名稱與某定義／引用之間，可具有局部、全域、弱、可見性等屬性。符號缺失可能只是被 strip，不證明程式碼缺失；symbol table 與 link map 回答來源。

名稱修飾

Name mangling。把 C++ 名稱空間、類別與函式型別等編入連結名稱的工具鏈規則。
位置／機制／邊界：位置在 C++ 語言實體與外部 symbol 名稱之間，使多載得以區分。規則依 ABI，不是可攜原始碼介面；demangler 能解讀名稱但不能還原函式內容。

重定位

Relocation。記錄某位置要在布局或符號位址確定後如何修正。
位置／機制／邊界：位置在尚未確定的地址欄位與日後布局之間，描述類型、symbol、加數及待修位置。它是計算指示而不是目標內容；relocation table 能證明待修關係。

連結器

Linker。解析符號、安排區段並套用重定位，產生另一目的檔、函式庫或最終映像。
位置／機制／邊界：位置在多個 object/library 與輸出映像之間，解析符號、合併布局、套用 relocation 並可能移除未用內容。連結成功只證明此階段契約成立，不保證部署相依或執行語意正確。

靜態連結

Static linking。把選取的目的碼與資料納入輸出成品；不代表執行期完全沒有任何外部依賴。
位置／機制／邊界：位置在建置期，將 archive 中被選取的 object 內容納入輸出。archive 不一定整包複製，順序與抽取規則可能影響結果；link map 是直接證據。

動態連結

Dynamic linking。保留共享函式庫相依與部分載入期或執行期符號解析。
位置／機制／邊界：位置在映像、共享函式庫與 loader 之間，把部分符號地址留到載入或執行期完成。lazy binding 只是可選策略；載入診斷與 GOT/PLT 狀態可提供證據。

載入器

Loader。驗證映像、建立虛擬映射、處理相依與初始程序狀態後移交控制。
位置／機制／邊界：位置在檔案映像與新程序之間，建立 mapping、初始 stack/register 與必要相依後移交入口。載入不等於把整檔立即複製進 RAM；maps 與缺頁事件觀察不同面向。

位置無關程式碼

Position-Independent Code, PIC。可在不同位址執行，通常使用相對定址或間接表格。
位置／機制／邊界：位置在可變映像基底與指令定址之間，以 PC-relative 或間接表格減少固定絕對位址。PIC 不表示完全沒有 relocation，也不表示任何資料地址都免解析。

位址空間配置隨機化

Address Space Layout Randomization, ASLR。讓映像等區域的基底變動，增加固定位置假設的不可靠性。
位置／機制／邊界：位置在程序每次建立的布局策略，改變映像、stack 或其他區域基底以破壞固定地址假設。相對位移仍可穩定；程序 maps 能顯示當次布局，不代表所有熵或安全性。

除錯資訊

Debug information。描述機器位址與來源行、型別、函式或變數位置的對照資料。
位置／機制／邊界：位置在 machine address 與來源概念之間，支援行號、型別、變數位置與 unwind。最佳化後一行可分散、變數可消失；資訊是映射線索，不是未最佳化執行的保證。

深化課程新增核心詞

傳播延遲

Propagation delay。位置在輸入切換與可靠輸出之間；閘與配線需要有限時間充放電。它限制最長資料路徑，示波器可量測；真值表不含這個維度。

建立時間與保持時間

Setup time and hold time。位置在正反器取樣邊界，要求資料在時脈邊緣前後保持穩定。違反可能導致錯值或亞穩態；時序分析與高速波形提供證據。

亞穩態

Metastability。儲存元件在取樣邊界附近可能暫時無法迅速落到可靠 0／1。同步器降低傳播到後級的機率但不能使機率為零；數位模擬常看不到完整類比行為。

快取列

Cache line。快取搬運與標記的固定大小資料區塊；讀一個 byte 也可能帶入整列。地址低位選列內 byte，其他位元參與組索引與標籤；大小依具體微架構。

快取失誤

Cache miss。目標資料未在查詢的某級快取命中，必須往下一層取得。它不同於 TLB miss 與 page fault；效能計數器可統計但未必重建每次存取。

缺頁

Page fault。位址轉譯需要核心介入的例外，可能源於按需配置、檔案頁、寫時複製、權限或無效位址。它不必然代表磁碟 I/O，也不是 cache miss 的同義詞。

全域偏移表與程序連結表

Global Offset Table / Procedure Linkage Table, GOT / PLT。ELF 平台常用的間接位址與呼叫跳板機制，支援 PIC 與動態解析。這不是所有二進位格式共同的固定名稱；relocation 與執行期表項可佐證。

延遲綁定

Lazy binding。把某些外部函式地址解析延到第一次呼叫，之後快取結果。它可降低未使用符號的啟動成本，也把部分錯誤延後；安全設定或平台可選擇立即綁定。

執行緒區域儲存

Thread-Local Storage, TLS。讓同一個符號在每個執行緒有獨立實例，需要 loader、runtime 與 ABI 共同定位。它不是一般 stack local，也不代表存取不需同步其他共享狀態。

連結映射

Link map。連結器輸出的布局報告，可追查 section、symbol、位址與來源 object/library。它證明建置時如何組合，不證明執行時函式必然被呼叫。
