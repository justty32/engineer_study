隨查隨用

名詞與概念字典

金屬氧化物半導體場效電晶體

Metal-Oxide-Semiconductor Field-Effect Transistor, MOSFET。以閘極電壓控制通道導通的元件；本課只取受控開關抽象。

位置／機制：CMOS 邏輯用 n 型下拉與 p 型上拉網路替輸出節點充放電。示波器可觀察門檻、斜率與延遲；邏輯分析儀只能看到門檻化結果。邊界：導通不是零電阻，閘極也有電容、漏電與製程差異。

反及閘

NAND gate。AND 結果再反相；具功能完備性，可合成任意布林函數。

角色／因果：只有所有輸入皆為 1 時輸出 0；反相、AND、OR 皆可由它建構。真值表證明穩定函數，波形量測才顯示傳播延遲與毛刺；功能完備不等於面積或速度最佳。

布林代數

Boolean algebra。以 0、1 與 NOT、AND、OR 等運算描述邏輯，不等同真實電壓瞬間一定完美。

角色：把電路需求化成可推理、可化簡與可窮舉的離散函數。證據／邊界：真值表可驗證所有有限輸入的穩定輸出，但不能證明電氣門檻、耗能與輸出何時穩定。

組合邏輯

Combinational logic。穩定輸出只由當前輸入決定，不保存歷史狀態。

資料流：輸入經閘網路形成候選結果，例如加法、比較與選路。功能模擬可核對輸入輸出；含延遲波形才看得到臨界路徑。沒有狀態不等於沒有傳播時間。

時序邏輯

Sequential logic。輸出還依賴先前保存的狀態，常由時脈協調更新。

狀態流：組合邏輯由舊狀態算下一狀態，儲存元件在允許事件收下它。波形可對照 D、時脈與 Q；若違反建立／保持時間，純布林模擬不能完整描述亞穩態。

多工器

Multiplexer, MUX。由選擇訊號決定把哪個輸入送到輸出，是資料路徑選路核心。

位置／機制：常放在 ALU 輸入、寫回來源與下一個 PC 候選之間。選擇訊號只決定哪條路影響輸出，不是把類比能量無損搬運；真實路徑仍有延遲與負載。

正反器

Flip-flop。在特定時脈事件保存一個位元；不同型式與觸發規則不可混稱。

機制：D 正反器在有效邊緣取樣 D，延遲後從 Q 提供新狀態。波形能證明一次取樣結果；不能把鎖存器的「啟用期間透明」語意直接套到邊緣觸發正反器。

暫存器

Register。由多個儲存位元與控制邏輯構成的快速狀態；也是組合語言可見操作位置。

位置／功能：暫存器檔供指令快速讀寫運算元，PC 與狀態暫存器則有專門角色。除錯器通常顯示 ISA 可見暫存器；它不等同微架構中的實體暫存器或所有管線暫存狀態。

算術邏輯單元

Arithmetic Logic Unit, ALU。執行加減、位元邏輯、位移或比較等組合運算。

資料流：來源運算元進入 ALU，控制碼選運算，結果送往寫回或位址路徑，並可能產生旗標。目的暫存器與旗標的單步變化是 ISA 證據；不直接揭露內部用了哪種加法器。

中央處理器

Central Processing Unit, CPU。取指、解碼並執行指令的處理核心；不等同整台計算機。

位置／機制：CPU 連接暫存器、控制與資料路徑，透過記憶體系統與周邊互動。反組譯與架構狀態說明軟體契約；核心數、快取、管線與亂序能力要另查具體微架構證據。

指令集架構

Instruction Set Architecture, ISA。軟體可見的指令、暫存器、資料型別、位址與例外契約。

角色：讓編譯器、作業系統與處理器對機器碼語意有共同理解。同一 ISA 可有不同快慢的實作；二進位標頭與反組譯能證明目標 ISA，不能證明具體管線設計。

微架構

Microarchitecture。某個處理器實作 ISA 的內部方法，例如管線、快取與亂序執行。

機制／證據：它決定指令如何分解、排程與使用內部資源，效能計數器和硬體文件可提供線索。ISA 結果相同不代表週期數、功耗或側通道行為相同。

組合語言

Assembly language。機器指令的助記文字表示；語法與指令語意都依架構與工具而異。

位置：位於人類可讀文字與機器編碼之間，標籤、虛擬指令與指示詞還需組譯器處理。反組譯是從位元組解碼出的表示，不保證重建原作者的標籤或來源結構。

x86-64

x86 指令集的 64 位元擴充；具可變長度指令與豐富定址形式，平台 ABI 另行規定呼叫細節。

閱讀重點：追運算元寬度、部分暫存器寫入、旗標與記憶體定址。Intel 與 AT&T 語法表面順序可不同；反組譯語法選擇不改變底層位元組。

AArch64

64-bit Arm execution state。64 位元 Arm 執行狀態與其指令集，採明確載入／儲存模型。

閱讀重點：X/W 寬度視圖、NZCV 是否更新、X30 返回位址與基底回寫。AArch64 不等於所有 Arm，32 位元執行狀態的暫存器與編碼不能混用。

RISC-V

開放指令集架構，以基礎整數指令集加選用擴充組成；實作與 ABI 仍可有差異。

閱讀重點：先確認 RV32／RV64、擴充集合與 ABI，再分辨真實及虛擬指令。二進位屬性與機器位元組能證明需求；「RISC-V」名稱本身不能保證兩個成品相容。

程式計數器

Program counter, PC。指示當前或下一條指令位置的架構狀態；精確可見語意依 ISA。

因果：循序執行讓 PC 前進，分支、呼叫、返回與例外選擇其他位置。除錯器可在停點顯示 PC；它不呈現處理器內部所有已預取或推測中的指令。

位元組序

Endianness。多位元組值由低位址到高位址的位元組排列方式。

例：0x12345678 的小端記憶體位元組為 78 56 34 12。十六進位傾印能看排列；位元組序不會把單一位元組內的位元反轉，也不等於網路協定必然採主機順序。

快取

Cache。以局部性保存近期資料區塊，縮小處理器與較慢記憶體的延遲差。

資料流：存取先查較近層級，失誤再向下一層取得整個區塊。效能計數器可統計部分命中／失誤事件；快取失誤不表示虛擬頁不存在，也不一定造成作業系統介入。

虛擬記憶體

Virtual memory。讓程序使用虛擬位址，由硬體與作業系統映射、隔離與管理。

機制：虛擬頁經頁表映到實體頁框並附權限，同一虛擬值在不同程序可指向不同位置。程序映射表顯示虛擬範圍；通常不能單靠它判定資料此刻在哪級快取。

頁表

Page table。描述虛擬頁到實體頁框、存在狀態與權限的分層資料結構。

位置／機制：由作業系統建立，硬體頁表走訪依架構格式查詢。頁表項存在仍可能禁止寫入或執行；系統工具呈現的映射是較高層證據，不一定暴露所有硬體項目。

轉譯旁觀緩衝區

Translation Lookaside Buffer, TLB。快取近期位址轉譯；失誤不必然等於缺頁。

因果：命中可快速取得頁框與權限，失誤通常觸發頁表查詢；只有頁表結果要求處理時才可能進入核心。效能事件可觀察統計，不能把每次 TLB 失誤都算成磁碟存取。

應用程式二進位介面

Application Binary Interface, ABI。二進位模組對呼叫、暫存器、堆疊、資料布局與名稱的契約。

角色：讓獨立編譯模組在同一平台交換控制與資料。反組譯可檢查參數與保存行為；ISA 相同不保證 ABI 相同，API 宣告相同也不保證二進位布局相容。

呼叫慣例

Calling convention。ABI 的一部分，規定參數、回傳值、保存暫存器與堆疊責任。

狀態流：呼叫端安排參數與返回位置，被呼叫端遵守保存、對齊與回傳規則。入口中斷點可核對一次實際呼叫；最佳化、內聯與尾呼叫可能讓典型框架消失。

系統呼叫

System call。使用受控入口請求作業系統核心服務，不等同一般函式呼叫。

邊界：特定指令與系統呼叫 ABI 把控制轉入核心，核心驗證後返回結果。系統呼叫追蹤能看跨界事件；一般函式包裝可能緩衝或根本不在每次呼叫都跨界。

預處理器

Preprocessor。處理引入檔、巨集與條件編譯，輸出仍是語言文字。

位置：在 C++ 語法與型別分析之前依指示詞改寫 token。預處理輸出能證明編譯器前端實際收到的文字；巨集展開成功不代表展開後語意合法。

中介表示

Intermediate Representation, IR。編譯器內部介於來源語言與目標指令間的程式表示。

角色：把高階語意轉成便於分析、最佳化與降階的資料流。IR 能解釋編譯器在某階段的決策；它依工具而異，且不是 CPU 直接執行的機器碼。

組譯器

Assembler。把組合語言編碼成機器碼，並可依輸入與目的檔格式產生區段、符號與重定位資訊。

機制：解析標籤、指示詞與虛擬指令，能確定的位元立即編碼，未知位址留下重定位。組譯清單可對照文字與位元組；最終連結仍可能改變位置與部分編碼。

目的檔

Object file。含機器碼與資料，但常仍可重定位且有外部符號未解析。

位置：是單一或部分翻譯成果與連結器輸入，還保存區段、符號、重定位及選用除錯資訊。它已不是原始碼，卻通常也不是具完整程序入口與布局的可執行映像。

區段

Section。依用途、權限或連結規則分類的目的檔內容；不應直接與載入後記憶體區域混為一談。

資料流：連結器合併與排列輸入區段，載入器再依映像描述建立映射。目的檔檢視可見區段屬性；名稱相近不保證在記憶體中一對一獨立映射。

符號

Symbol。替函式、物件或位置命名，供解析、重定位、除錯與動態連結使用。

功能：定義提供實體，未定義引用要求供應者，綁定與可見性限制解析方式。符號表能證明檔案記錄的名稱狀態；名稱存在不保證型別與 ABI 實際安全。

名稱修飾

Name mangling。把 C++ 名稱空間、類別與函式型別等編入連結名稱的工具鏈規則。

因果：它讓多載可在連結層區分，也使宣告差一個型別就形成另一個符號。反修飾只改善閱讀，不會修正不匹配；規則屬工具鏈 ABI，不是跨平台統一字串。

重定位

Relocation。記錄某位置要在布局或符號位址確定後如何修正。

機制：記錄待修位置、計算種類、目標符號與可能的加數，連結器或動態連結器取得地址後套用。重定位表是補丁說明，不是符號表，也不代表每次執行都重新修改。

連結器

Linker。解析符號、安排區段並套用重定位，產生另一目的檔、函式庫或最終映像。

資料流：多個目的檔與函式庫進入，解析後的布局與補丁成為輸出。連結映射可追每個符號來源；連結成功只證明這一階段契約成立，不保證載入環境或執行行為。

靜態連結

Static linking。把選取的目的碼與資料納入輸出成品；不代表執行期完全沒有任何外部依賴。

機制／邊界：連結器通常按引用從封存庫抽取所需成員，輸出因此含對應副本。檔案較自足不等於沒有核心、載入器或其他動態元件需求，也不自動解決授權與更新問題。

動態連結

Dynamic linking。保留共享函式庫相依與部分載入期或執行期符號解析。

因果：載入時映射相依模組，立即或延遲把外部引用綁到供應者。相依清單與載入器診斷可觀察過程；檔名找到不保證符號版本與 ABI 相容。

載入器

Loader。驗證映像、建立虛擬映射、處理相依與初始程序狀態後移交控制。

位置：平台可能由核心映像載入器、使用者空間動態連結器與啟動碼分工。程序映射與載入診斷能看結果；「載入成功」不表示全域初始化或 main 後一定成功。

位置無關程式碼

Position-Independent Code, PIC。可在不同位址執行，通常使用相對定址或間接表格。

角色：避免把每個內部引用焊成固定絕對位址，便於共享映像與隨機化。PIC 不等於完全沒有重定位，資料與外部符號仍可能需要表格或載入期處理。

位址空間配置隨機化

Address Space Layout Randomization, ASLR。讓映像等區域的基底變動，增加固定位置假設的不可靠性。

證據：比較多次程序映射可看到基底變化，崩潰位址減去該次基底可得模組相對位移。它提高攻擊者預測成本，不是記憶體安全保證，也不會讓每個位移都隨機。

除錯資訊

Debug information。描述機器位址與來源行、型別、函式或變數位置的對照資料。

角色／邊界：除錯器依它顯示名稱、行號、型別與展開規則；成品機器碼不靠它才能執行。最佳化會讓變數移動或消失，配錯版本的除錯資訊更可能產生看似合理卻錯誤的對照。
