# 計算機組織、編譯與連結零基礎互動課程專案簡報

## 讀者基線

- 讀者是資深 C++ 工程師，熟悉原始碼、型別、記憶體管理、執行緒與除錯。
- 不假設懂電晶體、數位邏輯、處理器資料路徑、指令集架構、組合語言、虛擬記憶體硬體、應用程式二進位介面、編譯器後端、目的檔、符號、重定位、連結器或載入器。
- 本課是「逆向工程零基礎互動課程」的必要前置；逆向工程不得再把這些概念壓成一頁。

## 目標能力

完成後，讀者能沿同一條因果鏈解釋：

```text
C++ 原始碼
→ 前處理與編譯
→ 組合語言與機器指令
→ 目的檔、區段、符號與重定位
→ 靜態／動態連結
→ 可執行檔與共享函式庫
→ 載入器建立虛擬位址空間
→ 處理器取指、解碼、執行與存取記憶體
→ 作業系統、程序與硬體留下的證據
```

## 概念依賴

1. 電晶體開關抽象、位元與反及閘。
2. 由反及閘合成組合邏輯、加法器與算術邏輯單元。
3. 回授、時脈、正反器、暫存器與記憶體。
4. 資料路徑、指令週期、指令集架構、分支、呼叫與例外。
5. x86-64、64 位元 Arm 與 RISC-V 組合語言的共同問題與不同解法。
6. 資料表示、快取、虛擬記憶體、頁表與權限。
7. 應用程式二進位介面、呼叫慣例、堆疊與系統呼叫。
8. 前處理、編譯、最佳化、組譯與目的檔。
9. 符號解析、重定位、靜態／動態連結。
10. 載入、動態函式庫、延遲綁定與執行期映像。
11. 由原始碼跨層追蹤到執行證據。

## 教學邊界

- 繁體中文、純靜態、離線、無圖片、無外部套件與無計分互動。
- 使用虛構的簡化指令與目的檔模型；不宣稱對應特定處理器、作業系統或工具鏈的完整格式。
- 電晶體只教足以建構邏輯閘的受控開關模型；不取代半導體物理、類比電路、時序、功耗與製程分析。
- 「只用反及閘」是可驗證的功能完備教學路徑，不暗示量產晶片只使用單一閘型。
- 三套真實指令集分頁說明，不把暫存器名稱、語法、呼叫慣例或平台細節混成通則。
- 不推導編譯器最佳化演算法，不取代處理器、目的檔或工具鏈官方規格。
