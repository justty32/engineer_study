從物理元件跨到布林模型

電晶體怎麼變成反及閘？

一句話答案：互補式金屬氧化物半導體電路用兩類電晶體組成上拉與下拉網路，先造出反及閘（NOT AND, NAND gate）；輸入電壓決定哪條路徑導通，輸出節點因此被拉向電源或接地，再被解讀成 1 或 0。

這章假設已懂：只要知道電壓是兩點之間的電位差即可。這裡從零建立電晶體、邏輯準位與閘的關係。

模型邊界：先把真實電路與布林抽象分開

本章使用的模型

金屬氧化物半導體場效電晶體（Metal-Oxide-Semiconductor Field-Effect Transistor, MOSFET）先近似成「閘極電壓控制的開關」。n 型元件在控制輸入為高時傾向導通；p 型元件在控制輸入為低時傾向導通。

模型刻意省略什麼

真實元件不是理想開關：有臨界電壓、導通電阻、寄生電容、漏電、切換延遲、短暫直通電流與製程差異。邏輯 0／1 也各是一段允許電壓範圍，不是宇宙固定的 0 V 與某個固定電壓。

第一步：反相器把電壓變成邏輯

互補式金屬氧化物半導體（Complementary Metal-Oxide-Semiconductor, CMOS）反相器同時使用 p 型與 n 型電晶體。輸出節點位於上拉與下拉之間：

輸入為低：p 型導通，n 型關閉 輸出節點經上拉連到電源 接收器判成邏輯 1
輸入為高：p 型關閉，n 型導通 輸出節點經下拉連到接地 接收器判成邏輯 0
輸入 A反相輸出 NOT A穩定後主要導通路徑
01電源 → p 型元件 → 輸出
10輸出 → n 型元件 → 接地

穩定在 0 或 1 時，理想 CMOS 沒有電源到接地的持續直流路徑；真實 CMOS 的主要耗能包含切換、漏電與切換瞬間的短暫直通。切換時是在替輸出與連線的等效電容充電或放電。

第二步：兩個輸入造出反及閘

NAND 的規則是：只有 A 與 B 都是 1，輸出才是 0。CMOS 兩輸入反及閘把兩顆 n 型元件串聯成下拉網路，把兩顆 p 型元件並聯成上拉網路。

AB下拉串聯路徑上拉並聯路徑Y = NAND(A,B)
00中斷至少一條導通1
01中斷至少一條導通1
10中斷至少一條導通1
11完整導通全部中斷0

手算互動：先追路徑，再看輸出

情境：A=0、B=1。先在心中回答：串聯的下拉路徑完整嗎？並聯上拉是否還有路？

展開逐步追蹤
  1. A 對應的 n 型元件關閉，因此下拉串聯路徑中斷。
  2. A 對應的 p 型元件導通，因此上拉並聯至少有一條路。
  3. 輸出節點被拉向電源，接收器判成 1。
  4. 這與 NAND(0,1)=1 相符。
極端案例：輸入停在門檻附近

p 型與 n 型元件可能同時部分導通，輸出未必是可靠的 0 或 1，且可能出現較大直通電流。數位抽象只在輸入落入規格允許的低、高範圍且留足穩定時間後成立。

怎麼在實機看見這條因果鏈

用示波器可量輸入與輸出的電壓隨時間變化，看到反相、有限上升／下降時間與傳播延遲；用電源量測可看到切換頻率提高時動態功耗上升。邏輯分析儀通常只顯示判定後的 0／1，無法代替類比波形檢查。

不要混淆：「NAND 的布林函數」是邏輯規格；「四顆 MOSFET 的 CMOS 實作」是一種電路實現。不同電路家族也能實作相同函數。

從單顆 MOSFET 的三個端點重新建立直覺

閘極（gate）是控制端，汲極（drain）與源極（source）位於導電通道兩端。教學開關模型只說「控制電壓足夠時，通道電阻變小」；它沒有說閘極電流像水龍頭把水推進通道。MOSFET 的閘極由絕緣層隔開，穩態直流閘極電流理想上很小，但切換時必須替閘極電容充放電。這也是上一級邏輯閘看到的負載之一。

nMOS 下拉

在常見 CMOS 邏輯連接中，nMOS 適合在輸入高時把輸出拉向接地。說它「傳 0 很強」是電路設計直覺，不表示所有端點可任意互換，也不表示導通後電阻為零。

pMOS 上拉

pMOS 在輸入低時傾向導通，用來把輸出拉向供應電壓。泡泡或低有效記號表示控制極性，不能誤讀成輸出永遠反相。

為什麼 CMOS NAND 的上下網路互為對偶？

輸出不能在穩態同時有低阻路徑連到電源與接地，否則會形成大的直通電流；也不應兩邊都斷開而長時間浮動。下拉串聯表示只有 A、B 同高才完整導通。上拉必須恰好在「不是兩者同高」時導通，依德摩根關係就是 A 低或 B 低，因此用 pMOS 並聯。這個互補設計使四個穩定輸入組合都有一邊負責把 Y 拉到明確準位。

負載增加會發生什麼

假設原輸出等效電容為 10 fF，某近似條件下上升時間為 40 ps；若它要驅動四倍閘極與長配線，使總電容近似增為 40 fF，而等效上拉電阻相近，上升時間會約按 R×C 趨勢增長到四倍。這只是第一階 RC 直覺，真實元件電阻非線性、配線分布且接收器門檻有限。扇出（fan-out）因此不只是「邏輯上可接幾個」，還是速度、功耗與訊號完整性的負擔。

短脈衝為何可能根本傳不到下一級？

若輸入高脈衝短到輸出電容尚未越過接收器門檻就結束，類比節點雖有小幅變化，邏輯分析儀仍可能完全看不到 1。這種慣性式效果不能用零延遲 NAND 真值表預測。要判斷需知道驅動強度、負載、脈衝寬度與門檻。

拿示波器做一個不騙自己的量測

  1. 先確認探棒接地、頻寬與輸入電容，因為探棒也是負載。
  2. 同時觀察一個輸入與輸出，以相同百分比門檻量輸入到輸出的延遲。
  3. 分別量 10%→90% 上升時間與 90%→10% 下降時間；兩者不必相等。
  4. 改變切換頻率與負載，記錄延遲與供應電流是否隨之變化。
  5. 量到的波形證明這塊板、這顆元件、這個條件下的行為；不能直接推廣到所有 CMOS 製程。
再拆四個混淆：邏輯低不等於絕對 0 V；閘極控制不等於閘極提供輸出電流；NAND 函數不等於只可由四顆 MOSFET 實作；穩態低功耗不等於切換不耗能。
