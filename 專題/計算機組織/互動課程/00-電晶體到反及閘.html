從物理元件跨到布林模型

電晶體怎麼變成反及閘？

一句話答案：互補式金屬氧化物半導體電路用兩類電晶體組成上拉與下拉網路，先造出反及閘（NOT AND, NAND gate）；輸入電壓決定哪條路徑導通，輸出節點因此被拉向電源或接地，再被解讀成 1 或 0。

這章假設已懂：只要知道電壓是兩點之間的電位差即可。這裡從零建立電晶體、邏輯準位與閘的關係。

模型邊界：先把真實電路與布林抽象分開

本章使用的模型

金屬氧化物半導體場效電晶體（Metal-Oxide-Semiconductor Field-Effect Transistor, MOSFET）先近似成「閘極電壓控制的開關」。n 型元件在控制輸入為高時傾向導通；p 型元件在控制輸入為低時傾向導通。

模型刻意省略什麼

真實元件不是理想開關：有臨界電壓、導通電阻、寄生電容、漏電、切換延遲、短暫直通電流與製程差異。邏輯 0／1 也各是一段允許電壓範圍，不是宇宙固定的 0 V 與某個固定電壓。

第一步：反相器把電壓變成邏輯

互補式金屬氧化物半導體（Complementary Metal-Oxide-Semiconductor, CMOS）反相器同時使用 p 型與 n 型電晶體。輸出節點位於上拉與下拉之間：

輸入為低：p 型導通，n 型關閉 輸出節點經上拉連到電源 接收器判成邏輯 1
輸入為高：p 型關閉，n 型導通 輸出節點經下拉連到接地 接收器判成邏輯 0
輸入 A反相輸出 NOT A穩定後主要導通路徑
01電源 → p 型元件 → 輸出
10輸出 → n 型元件 → 接地

穩定在 0 或 1 時，理想 CMOS 沒有電源到接地的持續直流路徑；真實 CMOS 的主要耗能包含切換、漏電與切換瞬間的短暫直通。切換時是在替輸出與連線的等效電容充電或放電。

第二步：兩個輸入造出反及閘

NAND 的規則是：只有 A 與 B 都是 1，輸出才是 0。CMOS 兩輸入反及閘把兩顆 n 型元件串聯成下拉網路，把兩顆 p 型元件並聯成上拉網路。

AB下拉串聯路徑上拉並聯路徑Y = NAND(A,B)
00中斷至少一條導通1
01中斷至少一條導通1
10中斷至少一條導通1
11完整導通全部中斷0

手算互動：先追路徑，再看輸出

情境：A=0、B=1。先在心中回答：串聯的下拉路徑完整嗎？並聯上拉是否還有路？

展開逐步追蹤
  1. A 對應的 n 型元件關閉，因此下拉串聯路徑中斷。
  2. A 對應的 p 型元件導通，因此上拉並聯至少有一條路。
  3. 輸出節點被拉向電源，接收器判成 1。
  4. 這與 NAND(0,1)=1 相符。
極端案例：輸入停在門檻附近

p 型與 n 型元件可能同時部分導通，輸出未必是可靠的 0 或 1，且可能出現較大直通電流。數位抽象只在輸入落入規格允許的低、高範圍且留足穩定時間後成立。

怎麼在實機看見這條因果鏈

用示波器可量輸入與輸出的電壓隨時間變化，看到反相、有限上升／下降時間與傳播延遲；用電源量測可看到切換頻率提高時動態功耗上升。邏輯分析儀通常只顯示判定後的 0／1，無法代替類比波形檢查。

先看痛點：為什麼不能直接把電壓當成 0 與 1？

假如每一級電路都必須精確分辨 1.800 V、1.799 V 與 1.798 V，幾十億個元件中任何雜訊、壓降或溫度變化都會一路累積，後級很快就不知道前級想表達什麼。數位電路的關鍵不是「只有兩種電壓」，而是把一段低電壓範圍統一解讀成 0、把一段高電壓範圍統一解讀成 1，中間保留不保證判讀的區域。只要前級輸出落進後級保證接受的範圍，後級就把稍微失真的波形重新整理成乾淨的邏輯準位。

可以把這想成程式介面的型別契約：呼叫者不必知道函式內部每顆電晶體的連續電壓，只要交付符合輸入規格的 0 或 1；但這個比喻有界線。軟體型別錯誤通常是離散事件，電路輸入卻可能停在中間、帶雜訊或在取樣附近變動，所以規格還必須包含時間、負載與電壓裕量。

把一個切換過程逐格拆開

例一：反相器由 0 變 1

  1. 假設電源為 1.8 V，輸入原先接近 0 V，輸出電容已由 p 型元件充到接近 1.8 V。
  2. 輸入開始上升時，n 型逐漸變得能導電，p 型逐漸失去導電能力；短暫期間兩者都可能部分導通。
  3. 輸出節點的等效電容經 n 型元件放電，電壓不會瞬間跳到 0 V，而是用有限時間下降。
  4. 當輸出越過下一級的低準位判定範圍，下一級才可靠地把它視為 0。這段輸入變動到輸出可用的時間就是傳播延遲的一部分。

例二：NAND 的 A=1、B=1

  1. 兩顆串聯 n 型都導通，因此輸出到接地出現完整放電路徑。
  2. 兩顆並聯 p 型都關閉，因此沒有穩定的上拉路徑與下拉競爭。
  3. 輸出電容的電荷經串聯路徑移走，輸出降到低準位，故 Y=0。
  4. 若只把 B 改成 0，B 對應的 n 型切斷串聯路徑，而 p 型導通並替輸出充電，穩定後 Y 回到 1。

串聯元件通常讓等效下拉電阻增加，因此兩輸入 NAND 的下降速度不一定與單顆反相器相同。這不改變穩定後的真值表，卻會影響可用的最高速度與閘尺寸設計。

想更深入：量測各自能證明什麼？
  • 示波器：同時探測輸入與輸出，可量電壓、上升／下降時間與兩波形跨過指定門檻的時間差；探棒本身也會增加負載，所以量到的是「含量測系統」的結果。
  • 邏輯分析儀：適合長時間查看 0／1 序列與事件先後；它把類比電壓再次門檻化，不能證明波形沒有振鈴或安全地遠離門檻。
  • 電源電流：可比較靜止與持續切換時的消耗，支持「切換要替電容充放電」；但單看總電流無法指出是哪一顆閘造成。
  • 電晶體級模擬：能在指定模型與製程角落下觀察內部節點；它證明模型的預測，不等於每一顆實物都已被量過。

不要混淆的四件事

  • 輸入為高，不等於閘極有大量穩態電流流入。MOSFET 主要由電場控制通道，切換時仍需替閘極電容充放電。
  • 導通，不等於零電阻。真實導通電阻與負載共同決定轉換速度與壓降。
  • 真值表正確，不等於任何時刻都正確。真值表描述輸入穩定且延遲過後的結果。
  • 邏輯 0／1，不等於 C++ 的型別值。前者是硬體介面的電壓與時間契約；後者還受語言物件模型與編碼規則約束。
不要混淆：「NAND 的布林函數」是邏輯規格；「四顆 MOSFET 的 CMOS 實作」是一種電路實現。不同電路家族也能實作相同函數。
