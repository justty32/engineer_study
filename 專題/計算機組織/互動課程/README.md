# 從電晶體到 C++ 執行：計算機組織、組合語言、編譯與連結互動課程

由 `index.html` 開始。這是逆向工程的必要前置，讀者雖是資深 C++ 工程師，仍從電晶體、反及閘、狀態、暫存器與資料路徑建立硬體世界觀。

| 頁面 | 責任 |
|---|---|
| `00-電晶體到反及閘.html` | 電晶體開關抽象、反相器與反及閘 |
| `01-只用反及閘造邏輯.html` | 由反及閘合成 NOT、AND、OR、XOR、多工與解多工 |
| `02-組合邏輯與算術.html` | 加法器、比較器與算術邏輯單元 |
| `03-時序邏輯與記憶.html` | 鎖存器、正反器、暫存器、記憶體與時脈 |
| `04-處理器資料路徑與指令週期.html` | 程式計數器、資料路徑、指令集架構與控制流 |
| `05-x86-64組合語言.html` | x86-64 暫存器、指令、定址、呼叫與 C++ 對照 |
| `06-AArch64組合語言.html` | 64 位元 Arm 暫存器、載入／儲存、分支與呼叫 |
| `07-RISC-V組合語言.html` | RISC-V 暫存器、指令格式、分支與呼叫 |
| `08-記憶體階層與虛擬記憶體.html` | 資料表示、快取、頁表、位址轉譯、缺頁與權限 |
| `09-程序ABI呼叫與系統邊界.html` | 程序、應用程式二進位介面、呼叫慣例、堆疊與系統呼叫 |
| `10-編譯組譯與目的檔.html` | 前處理、編譯、最佳化、組譯、區段與目的檔 |
| `11-符號重定位與連結.html` | 名稱修飾、符號解析、重定位、靜態與動態連結 |
| `12-載入器動態函式庫與執行期.html` | 可執行檔映射、共享函式庫、延遲綁定與程序啟動 |
| `13-從C++原始碼到執行證據.html` | 跨層整合與故障定位 |
| `名詞與概念字典.html` | 可搜尋中英名詞、縮寫、位置與易混邊界 |

執行期只有 HTML、`styles.css` 與 `app.js`。
