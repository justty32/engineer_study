指令集實例 3／3

RISC-V：用小而可組合的規則讀程式

RISC-V 是開放、模組化的指令集架構。基本整數指令集只給出核心能力，乘除、原子、浮點、壓縮與向量等能力由擴充加入。閱讀任何 RISC-V 二進位檔前，要先問位元寬度與啟用哪些擴充。

這章假設已懂：暫存器、載入／儲存、比較分支、呼叫、立即值與通用指令模型。範例以 RISC-V 64 位元基本整數指令集（RV64I）為主；它只是一個明確教學邊界，不代表所有 RISC-V 系統。

最小可執行心智模型

用 load 類指令把記憶體值放進暫存器 用三運算元指令產生新暫存器值 分支直接比較兩個暫存器，不依賴全域旗標 用 store 寫回，或以跳躍並連結實作呼叫

RISC-V 定義 ISA，不指定某顆晶片必須有幾級管線、是否亂序、快取多大或效能如何。同一份合法機器碼可由極小的微控制器核心或高效能處理器執行。

暫存器：硬體編號與 ABI 名稱並存

整數暫存器

x0 到 x31 是整數暫存器。x0 永遠讀出 0，寫入被忽略；它讓清零、比較與無條件跳躍可重用既有指令形式。

人類可讀別名

ABI 另把 x1 稱為 ra（返回位址）、x2 稱為 sp（堆疊指標），並分成參數 a0 起、暫存 t0 起與需保存 s0 起等角色。

沒有整數條件旗標

基本整數指令不維護像 x86-64 或 AArch64 那樣供後續分支共用的零／進位旗標。beq a0, a1, label 在分支指令本身比較兩個暫存器。

程式計數器不是 x 暫存器

程式計數器保存目前控制流位置，但不能像一般 x 暫存器任意讀寫。auipc、jal 與 jalr 提供相對位址與跳躍能力。

六類動作

資料搬移

li a0, 7 與 mv a0, a1 是虛擬指令，組譯器會展成一條或多條真實指令。記憶體資料用 lb、lw、ld 等載入，寬度與符號擴展必須分清。

算術

add a0, a1, a2 表示 a0 = a1 + a2；addi 的第三個運算元是編碼範圍內的立即值。乘法 mul 屬於整數乘除擴充，不是基本 I 指令集必備。

比較與分支

beq、bne 比較相等；blt 與 bge 依有號值比較，帶 u 的形式依無號值比較。slt 則把比較結果 0 或 1 寫入暫存器。

呼叫與返回

jal ra, target 把下一條位址寫進 ra 並跳躍；jalr 從暫存器形成目標。call 與 ret 通常是組譯器提供的虛擬指令。

記憶體定址

lw a0, 12(sp) 的格式是「立即位移（基底）」。基本載入／儲存沒有 x86-64 的比例索引；陣列索引通常先用移位和加法算出位址。

程序邊界

常見 ABI 以 a0 起傳整數參數與回傳結果，並規定哪些暫存器由呼叫者或被呼叫者保存。嵌入式與作業系統環境仍可能採不同 ABI 或擴充組合。

從 C++ 對照：索引位址拆成明確步驟

int load_at(const int* p, std::size_t i) {
    return p[i];
}
# 示意：a0=p，a1=i，int 為 4 位元組
slli t0, a1, 2   # t0 = i * 4
add  t0, a0, t0  # t0 = p + i*4
lw   a0, 0(t0)   # 載入有號 32 位元並擴展
ret

slli 左移兩位在這個無溢位位址計算中相當於乘 4。若編譯器掌握更佳資料流，可能改用其他合法序列；虛擬指令與連結期鬆弛也可能讓最終反組譯不同。

手工追蹤 1：分支自己做比較

初始：a0 = 7、a1 = 7、t0 = 99。執行：

bne  a0, a1, .miss
addi t0, x0, 1
beq  t0, x0, .zero
addi a0, a0, 3

每一步只記錄被改寫的暫存器與程式控制流，不需要維護隱藏旗標。

展開追蹤結果
  1. a0 等於 a1，所以 bne 不跳。
  2. addi t0, x0, 1 利用 x0 的固定零值，使 t0 = 1。
  3. t0 不等於 x0，所以 beq 不跳。
  4. 最後 a0 = 10。過程沒有一個供所有指令共用的整數零旗標。

手工追蹤 2：呼叫會覆寫返回位址

初始：呼叫者的下一條位址是 0x1004。函式 outer 內又呼叫 inner，該次呼叫的下一條位址是 0x2008。

# 呼叫者
jal ra, outer
# outer 內
jal ra, inner
ret
展開追蹤結果
  1. 第一次 jal 使 ra = 0x1004，控制流進入 outer。
  2. 第二次 jal 使 ra = 0x2008，原返回位址被覆寫。
  3. inner 可藉 ret 回到 0x2008；但若 outer 未先保存並還原 ra，自己的 ret 也只會回到 0x2008。
  4. 因此會再呼叫其他函式的非葉函式通常依 ABI 把 ra 保存到堆疊。

證據與邊界

可查證的證據包括：二進位檔宣告的目標架構與擴充、反組譯器顯示的真實或虛擬指令、程式計數器 pc、返回位址 ra、堆疊指標 sp 與參數／返回值暫存器 a0、堆疊上保存的暫存器、重定位，以及載入／儲存前後的位址與資料。若要重現機器碼，須固定組譯器選項，因為虛擬指令可能有多種展開方式。

本頁只建立 RV64I 的閱讀骨架，未教授特權架構、控制與狀態暫存器、原子、浮點、向量、壓縮指令或弱記憶體排序。看到 mul、原子操作或較短指令編碼時，先確認所需擴充。

常見誤解

  • RISC-V 不是一顆處理器。它是 ISA 家族；晶片實作、效能、周邊與特權環境可完全不同。
  • 所有 RISC-V 二進位檔不一定相容。位元寬度、擴充集合與 ABI 必須匹配。
  • li、mv、call 與 ret 不一定各自對應一種機器指令。它們多半是虛擬指令。
  • 沒有旗標不等於不能比較。分支直接比較來源暫存器，或由 slt 類指令保存布林結果。
  • 指令較少不代表程式一定較慢或較快。效能必須看編譯結果、工作負載與具體微架構。
