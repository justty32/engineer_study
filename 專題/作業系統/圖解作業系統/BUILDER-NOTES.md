共用產品檔為 `dist/app.js`、`dist/lab.css`、`dist/index.html`、`dist/glossary.html`。章節由各作者維護，共用程式不覆寫章節正文。首頁的六群課程地圖、46 個詞條與逐頁 trace 規格由 `tools/build-support.py` 重建；腳本只輸出 builder 的首頁、字典及互動規格，規格透過資料表工具寫入。章節文字有 focused 修正後，需重建一次以保持步驟快照同步。

## 漸進增強

側欄在 HTML 保留首頁、字典與前後課連結，程式載入後補成 20 課導覽。完整例題與練習解在 HTML 內。一般 trace 不隱藏步驟或 SVG，僅變更當前狀態及原因文字；沒有 JavaScript 也能依完整例解閱讀。

圖表在窄畫面使用容器內的橫向捲動，具有可見提示；程式加上鍵盤焦點與區域名稱，圖說固定在容器可視部分。桌面固定側欄，窄螢幕改為頂部橫向章節導覽。系統偏好減少動態時停用平滑捲動；沒有播放動畫或時間壓力。

## 計算核心

`app.js` 的純函式 `roundRobin` 與 `translate` 可在 Node 以 CommonJS 載入，也以 `window.OSLab` 提供瀏覽器驗算。兩者都先驗證輸入，使用安全整數的四則運算與餘數，沒有位元運算、隨機或外部請求。API 是驗收入口，不是產品流程的一部分。

輪轉排程只模擬單 CPU、無阻塞 I/O、零切換成本。片內與片末到達先加入原佇列，再放回當前未完成的行程；同時到達依 A、B、C。逐片表與最終指標表均常駐，最終指標明標「把完整排程走完後」。無效輸入顯示具體範圍原因並隱藏舊結果，避免把舊答案當成新計算。

位址教具固定 16 位元與 1 KiB 頁，只描述目前輸入 VPN 的映射。有效 TLB 命中必須對應駐留頁；不駐留或未映射時，介面解釋為沒有有效快取，改走查頁表路徑。先排除未映射，再檢查權限和駐留；任何失敗都不輸出可存取 PA，且明示不保證發生磁碟 I/O。零、頁面邊界與最大位址均保留完整量綱。

## 交接與驗證

互動規格共 21 列：18 個實際 trace（106 個步驟）、兩個參數教具與字典搜尋，包含範圍、預設、公式或轉移、判準、實例和邊界。已以瀏覽器實際 DOM 逐項比對所有元件 id、步驟文字、狀態 token 與 SVG 狀態存在性。首頁沒有額外互動，不建立虛構規格。字典內的名詞與因果概念分開呈現，常見中文別名可搜尋。

builder 自檢包括 JavaScript 語法、RR 預設完整序列與 T/R/W、VA 0x1234 對應 0x2634、首頁 1440×900 的完整地圖可見、字典別名搜尋與清空。獨立驗收與正式交付結論由機制、教學、技術 reviewer 的報告保存；本檔不代替獨立驗收。
