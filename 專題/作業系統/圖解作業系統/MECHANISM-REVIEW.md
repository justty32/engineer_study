# 作業系統演算與機制獨立審核

20 課的主例、遷移練習、圖與互動機制皆通過獨立審核；4 項發現已修正並複驗，未結案項目為 0。逐課演算式、預期值、實際位置、模型邊界、來源證據及頁面 SHA-256 收於 [mechanism-review.json](evidence/mechanism-review.json)；缺陷履歷收於 [mechanism-findings.json](evidence/mechanism-findings.json)。本審核者未參與產品建置，也未修改產品檔。已綁定 24 個公開資產的 final_public_sha256：`4f590b6366fe086376adce858198f5020bebbb8da70db4135f9d7c22bb952e28`；20 課逐頁 SHA-256 均與此版本一致。

獨立逐毫秒輪轉算器與整除／餘數位址算器共比對網站實際輸出 2,498 組：輪轉 2,191 組、位址轉譯 252 組、無效輸入 55 組。預期值不取自網站函式。另以現有 Chromium 操作所有課程：18 個固定互動共 106 個狀態的文字、高亮、前後端點與重設通過；兩個參數原型的預設值、12 種 TLB／頁面狀態／權限組合、無效輸入與重設通過。字典搜尋的清空、大小寫、空白與無結果分支亦通過，合計 21 個元件；頁面 JavaScript 錯誤為 0。

修正涵蓋虛擬頁次與頁號混淆、初版 JavaScript 字串語法、單一執行緒的總工作量措辭，以及舊課工作集／顛簸範圍的承接。新增工作集例獨立重算為兩頁框 LRU 六次缺頁、三頁框三次缺頁與三次命中；正文正確限制此例不能單獨證明實機顛簸。13 列舊站勘誤分類已核對，保留原本正確的 TLB、FIFO／LRU 與檔案生命期結論。

完整演算保留精確分數，近似小數使用近似等號。條件變數的原子等待與 while、號誌的許可、單實例死結環、多實例安全性、fd／OFD 共用位置，以及檔案與目錄同步的不同責任皆已核對。官方來源中，C++ 資料競態草案、OSTEP 條件變數及 Linux man-pages 維護者的 dup／fsync／rename 原稿另經審核者獨立開啟；其他精確節點與來源員的查證表交叉對照。

可重跑的獨立算器為 [check-mechanisms.py](tools/check-mechanisms.py)，支援全體與指定頁面的聚焦複驗。審核範圍包含機制與數值；畫面布局、完整可及性及發布檢查由各專責驗收報告負責。

審核程序已收尾：Chromium 均在 `finally` 呼叫 `close()`，本審核未啟動 HTTP server；程序檢查無自身瀏覽器或伺服器殘留。兩份證據表連結與 UTF-8 檢查通過；全域 wf-lint 仍有歷史 reviews 兩筆斷鏈，未修改共享工作流程。
