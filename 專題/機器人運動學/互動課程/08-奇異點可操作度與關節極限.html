08 · 有七軸也可能失去任務方向

奇異點、可操作度與關節極限

若六維任務的 6×7 雅可比矩陣列秩小於 6，末端至少失去一個瞬時可達方向。因 J 不是方陣，不能用 det(J)=0；應看秩、奇異值分解（Singular Value Decomposition, SVD）的最小奇異值，或 √det(JJᵀ) 等可操作度指標。

白話定位：把 J 想成一個多通道增益器。某個奇異值很小，表示那條末端方向的增益幾乎關閉；逆運算為了補償就會要求很大的關節動作。

怎麼玩：先把肘保持彎曲，再逐步伸直到 0°，同時改腕部俯仰。觀察最小奇異值與弱方向如何變化。數字逐漸接近 0 比「到某角度突然壞掉」更符合數值系統的實際行為。

伸直肘腕，觀察弱方向

三種限制要分開

限制 發生什麼 處理方向
運動學奇異 J 失秩，某任務方向需要極大關節速度或不可達 阻尼、降速、改姿勢、重新選路
關節極限 幾何仍可能可達，但目前解分支撞上下限 零空間置中、約束最佳化、換 IK 分支
自碰／環境碰撞 純 FK/IK 解在幾何上成立但不可安全執行 碰撞幾何與運動規劃；不是雅可比單獨能保證
可操作度是局部尺度，且混合 m/s 與 rad/s 時會受單位與權重影響；它適合比較明確定義下的姿勢，不是跨機器人的絕對安全分數。

奇異點是「失去瞬時方向」

當雅可比的獨立方向數量下降，某些末端速度方向需要極大的關節速度，甚至在一階模型中無法產生，這叫運動學奇異。二連桿完全伸直時，末端很難沿手臂伸長方向瞬間再向外移，就是可看見的例子。

用一個 2×2 縮小例子看速度放大

若 J 的兩個奇異值為 σ1=1 與 σ2=0.01，沿第一方向要求 0.1 m/s，大約只需尺度 0.1 的關節速度；沿第二弱方向要求相同 0.1 m/s，無阻尼反解會需要尺度 0.1/0.01=10 的關節速度。若 σ2 再降為 0，就沒有有限關節速度能產生該方向。

這個比值只示範奇異值的放大效果。真實 J 同時含線速度與角速度，必須先明定特徵長度或權重；否則 0.1 m/s 與 0.1 rad/s 的數值比較沒有唯一物理意義。

可操作度與最小奇異值在說什麼

把單位大小的關節速度經 J 映到末端，可形成速度橢球。長軸是容易移動方向，短軸是困難方向。最小奇異值接近 0 表示至少一個弱方向；所有奇異值乘積形成常見可操作度指標，但它把不同方向壓成一個數，不能告訴你哪個方向弱。

關節極限不是奇異點

奇異來自 J 的秩；關節極限是硬體允許範圍。兩者可以同時發生，也可以各自發生。接近極限時可用加權廣義逆或零空間目標提早遠離，但不能把超限角度交給「阻尼」假裝處理。

阻尼為何有用又有代價？

阻尼最小平方不把很小的奇異值直接倒數，限制關節速度爆增；代價是末端速度／位姿會留下誤差。阻尼越大越穩，但追蹤越鈍。

奇異附近要看方向，不只看一個警報燈

例如最小奇異值很小時，對應的左奇異向量指出末端的弱速度方向，右奇異向量則指出會被放大的關節組合。這能回答「哪個方向做不到」與「哪些關節會暴衝」，比單一可操作度閾值更能指導退讓或重新規劃。

閾值依單位、特徵尺度與任務而定；位置與角速度混在同一 J 時，尺度選擇會改變奇異值，不能跨機器直接複製魔法數字。

章末能說明：奇異是失去哪個瞬時方向、最小奇異值與速度橢球如何揭露弱方向、阻尼交換了什麼，以及關節極限、歐拉角萬向節鎖與手臂雅可比奇異為何不同。

證據要能指出哪個方向變弱

控制 log 至少保存 q、所有奇異值、最小奇異值對應的左右奇異向量、要求的 V、解出的 q̇、阻尼與是否限速。這能區分「弱方向造成放大」與「單純命令太大」。互動畫面與 SVD log 都只能描述模型；真機還需編碼器速度、跟隨誤差與驅動器限速／故障狀態。

  • 奇異與關節極限：前者是 J 的獨立方向減少；後者是允許區間邊界。
  • 可操作度與安全裕度：可操作度不含碰撞、負載、煞車或人員距離。
  • 最小奇異值與條件數：一個看最弱絕對尺度，一個看最強／最弱比值；兩者都受尺度定義影響。
  • 阻尼與修復：阻尼限制放大但留下任務誤差，沒有把奇異構型變成非奇異。

遇到警報時先降低速度、保存當下 q 與奇異方向，再決定退回、改姿態或重規劃。

奇異點不存在的話，反解就不會暴衝

控制器希望末端沿弱方向移動時，普通偽逆會用 1/σ 放大命令。σ 越接近 0，關節速度越大；真機最後會撞上速度上限、跟隨誤差或保護停機。奇異不是矩陣函式的偶發錯誤，而是目前機構幾何真的缺少一個瞬時方向。

SVD 可看成把輸入先換到一組獨立關節方向、逐方向乘上 σ，再換到末端方向。若這個拆解太陌生，可先從機器人數學基礎第 10 章：解方程式與逆理解「小增益的反解為何放大誤差」。

用二連桿伸直看可見的弱方向

兩段各 0.5 m、都沿 x 伸直。兩個關節微小轉動都讓末端主要沿 y 掃動；一階近似下，x 方向變化為零，因 cosθ 在 θ=0 附近的斜率為 0。末端要再向 +x 移，沒有任何微小角速度組合能立即做到，只能先彎曲再改變半徑。

這也解釋「位置明明就在旁邊，IK 為何很難走」：有限路徑可能存在，但當下的一階方向不存在。奇異分析回答瞬時能力，不等同全域工作空間判斷。

阻尼的第二組數字

取 σ=0.005、要求弱方向誤差尺度 0.02。普通倒數給更新尺度 0.02/0.005=4；若 λ=0.05，DLS 增益 g=0.005/(0.0052+0.052)≈1.98，更新約 0.0396。命令縮小約百倍，代價是只修正一小部分誤差。這是穩定與精確的明確交換，不是把 λ 調大就「治好」奇異。

警報數字該如何判讀？

不要只顯示紅燈。至少列出最小 σ、對應末端弱方向、要求速度在該方向的投影、未限速與已限速 q̇、λ、關節極限距離。若 σ 小但命令沒有弱方向成分，未必需要劇烈反應；若 σ 尚可卻已貼近關節極限，處理方式應是換分支或約束求解，不是加阻尼。

同一個可操作度可能掩蓋不同風險

奇異值 [1,1,0.1] 與 [1,0.316,0.316] 的乘積都約 0.1，但第一組只有一個特別弱方向，第二組有兩個中等弱方向。只報乘積無法決定該往哪個方向退讓；要保留完整奇異值與對應方向。

位置列用 m/rad、角速度列近似無因次時，直接一起 SVD 會受單位尺度影響。可用特徵長度或任務容許值尺度化，但不同選擇回答不同工程問題，必須寫進 log 與門檻版本。

關節極限要提前處理

若 q 上限 120°、目前 119°，數學 J 可能完全健康，但再向正方向 2° 已不可執行。硬夾到 120° 會改變原本求得的任務速度。較好的做法是提前加權、零空間置中或使用真正含邊界的最佳化，並以裁切後 q̇ 重新預測末端誤差。

能教別人的檢核：分別說出最小奇異值、弱方向、條件數、關節極限距離能回答什麼，以及它們各不能證明碰撞安全。

條件數大代表什麼？

條件數 κ=σmax/σmin。若 σmax=1、σmin=0.001，κ=1000，表示不同方向的增益相差千倍；輸入或模型中的小誤差在反解弱方向時可能被大幅放大。若所有 σ 都很小但比例相近，κ 可能不大，絕對運動能力卻仍弱，所以要與最小奇異值一起看。

設定警報時應用實際速度上限反推：弱方向要求 Vw，估計關節速度尺度約 Vw/σmin。這比跨機器複製固定 σ 門檻更接近任務，但仍要納入多方向組合與權重。
