# 七軸機械手臂運動學互動課程

由 `index.html` 開始。頁面依真正的數學依賴排列：

| 頁面 | 教學責任 |
|---|---|
| `00-機械手臂自由度與座標.html` | 連桿、關節、7R、位置、姿態、座標系與單位 |
| `00A-角度弧度三角函數與單位.html` | 度／弧度、sin／cos、向量長度、內積／外積與單位檢查 |
| `01-向量矩陣與二維旋轉.html` | 向量表示、基底、矩陣乘法與旋轉方向 |
| `02-二連桿正逆運動學.html` | 先在平面手算正運動學、多解與不可達 |
| `03-三維旋轉與姿態.html` | 旋轉矩陣、歐拉角、軸角、四元數與奇異表示 |
| `04-齊次變換與座標鏈.html` | 位置＋姿態、變換方向、連乘順序與逆變換 |
| `05-七軸正運動學.html` | 七個局部關節變換、DH／POE 角色與末端位姿 |
| `06-雅可比與速度運動學.html` | `6×7` 幾何雅可比、扭量與有限差分驗證 |
| `07-冗餘零空間與肘部姿態.html` | 偽逆、零空間、自運動與次要目標 |
| `08-奇異點可操作度與關節極限.html` | 秩、最小奇異值、阻尼、極限與權衡 |
| `09-七軸數值逆運動學.html` | 位置／姿態誤差、阻尼最小平方、迭代與停止條件 |
| `10-C++實作與驗證.html` | 資料型別、座標契約、測試、日誌與除錯證據 |
| `名詞與概念字典.html` | 可搜尋中英名詞、縮寫與易混邊界 |

執行期只有本目錄內的 HTML、`styles.css` 與 `app.js`。
