# 七軸機械手臂運動學互動課程專案簡報

## 讀者基線

- 讀者是資深 C++ 工程師，熟悉向量／矩陣的程式表示，但不假設線性代數、空間幾何、機構學或機器人學基礎穩固。
- 不先考。每章先建立座標意義、輸入、運算、狀態改變與模型邊界，再提供無計分即時實驗。
- 正文與介面使用繁體中文；縮寫第一次出現給繁中、英文全名、縮寫與白話功能。

## 主題邊界

本課只處理七個旋轉關節串聯手臂（7R serial manipulator）的運動學：

```text
點、向量、座標系
→ 二維旋轉與二連桿手臂
→ 三維旋轉與齊次變換
→ 七關節正運動學
→ 6×7 幾何雅可比矩陣
→ 冗餘、零空間與肘部姿態
→ 奇異點、可操作度與關節極限
→ 阻尼最小平方數值逆運動學
→ C++ 實作、驗證與除錯證據
```

不教動力學、馬達轉矩、軌跡時間參數化、碰撞檢查、運動規劃、控制器或特定廠牌通訊介面；這些是後續課程。

## 七軸核心模型

- 教學機器人是虛構的七旋轉關節手臂，不對應任何商用型號。
- 關節序列用基座偏航、肩部俯仰、肩部滾轉、肘部俯仰、前臂滾轉、腕部俯仰、腕部滾轉建立直覺。
- 正運動學採明確局部旋轉與連桿平移連乘；另教標準 Denavit–Hartenberg 表與指數積形式的角色，但不混用慣例。
- 末端任務速度以六維扭量表示，因此一般雅可比矩陣為 `6×7`。七軸冗餘不保證每個姿勢都有完整一維可用零空間；當矩陣秩下降時，零空間維度會增加且任務可達方向會減少。
- 非方陣雅可比矩陣不得用 `det(J)=0` 判斷奇異；本課使用秩、最小奇異值與可操作度的概念。

## 可觀察成果

讀者完成後能：

1. 說清楚點、自由向量、座標表示、主動／被動旋轉與變換方向。
2. 手算二連桿正逆運動學，辨認多解與不可達目標。
3. 從七個關節角算出末端位置與姿態，並以獨立檢查驗證。
4. 解釋 `6×7` 雅可比矩陣、偽逆與零空間投影的尺寸及物理意義。
5. 說明七軸手臂如何在末端近似不動時改變肘部姿態。
6. 以阻尼最小平方迭代處理目標、關節極限與近奇異姿勢，並區分收斂、停滯與不可達。
