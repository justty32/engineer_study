# 建置規格

- 純靜態、離線、無圖片、無外部套件、無提交答案或分數。
- 16 個 HTML：首頁、00、00A、01–12 與可搜尋字典。
- 即時互動：度／弧度與單位向量、座標表示、二維旋轉、2R 正逆運動學、三維旋轉順序、變換連乘、七關節正運動學、雅可比欄直覺、零空間權衡、奇異／極限診斷、數值 IK 迭代、C++ 契約檢查、平面扭量指數積分，以及校正偏差與隨機不確定度分離。
- 每個教學章節的純文字內容不得低於約 1,100 字元；字典每條具白話、角色、機制、例子與易混邊界。
- 所有角度控制介面使用度數，進入三角函數前轉為弧度；長度統一使用公尺。
- 教學七軸模型固定採 `Rz–Ry–Rx–Ry–Rx–Ry–Rx` 局部旋轉序列與三段主要連桿平移；它只是可重現模型，不對應商用手臂。
- 公式要交代矩陣尺寸：`q∈R⁷`、末端扭量 `V∈R⁶`、`J∈R^(6×7)`、零空間投影 `N=I₇−J⁺J`。
- 至少以零角、單一關節轉動、2R 已知案例與有限差分做公式交叉驗算。
- 進階章節使用 Modern Robotics 的 SE(3)、扭量、Adjoint 與 space／body Jacobian 慣例作為追溯來源；本課既有六維向量順序為 `[v;ω]`，不得與來源常見的 `[ω;v]` 靜默混用。
