# 建置規格

- 純靜態、離線、無圖片、無外部套件、無提交答案或分數。
- 13 個 HTML：首頁、00–10 與可搜尋字典。
- 即時互動：座標表示、二維旋轉、2R 正逆運動學、三維旋轉順序、變換連乘、七關節正運動學、雅可比欄直覺、零空間權衡、奇異／極限診斷、數值 IK 迭代與 C++ 契約檢查。
- 所有角度控制介面使用度數，進入三角函數前轉為弧度；長度統一使用公尺。
- 教學七軸模型固定採 `Rz–Ry–Rx–Ry–Rx–Ry–Rx` 局部旋轉序列與三段主要連桿平移；它只是可重現模型，不對應商用手臂。
- 公式要交代矩陣尺寸：`q∈R⁷`、末端扭量 `V∈R⁶`、`J∈R^(6×7)`、零空間投影 `N=I₇−J⁺J`。
- 至少以零角、單一關節轉動、2R 已知案例與有限差分做公式交叉驗算。
