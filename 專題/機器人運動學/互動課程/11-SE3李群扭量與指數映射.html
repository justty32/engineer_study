11 · 從矩陣計算走到剛體運動的結構

SE(3)、扭量與指數映射

白話問題：齊次變換已能描述位姿，為什麼還需要李群、扭量和指數映射？一句話答案：位姿不是能任意相加的普通向量；李群保留合法旋轉與剛體運動的結構，扭量則描述它在某一瞬間如何改變。

最小前置：先理解齊次變換、雅可比與六維速度。本章不要求抽象代數，只把每個符號接回可觀察的位姿與速度。

位姿集合不是一般向量空間

剛體位姿由旋轉矩陣 R 與平移 p 組成 T=[R p; 0 1]。所有合法三維剛體變換形成特殊歐氏群（Special Euclidean Group, SE(3)）。「群」在這裡只需記四件事：兩個合法變換相乘仍合法、有單位變換、每個變換有逆、連乘結合方式一致。直接把兩個旋轉矩陣逐格平均，結果通常不再滿足 RᵀR=I 與 det(R)=1；這就是不能把位姿當普通十二維數字向量處理的原因。

SE(3) 的小寫版本 se(3) 是單位位姿附近的切空間，可用六個速度量描述：三個角速度與三個線速度。這六維物件稱為扭量（twist）。本課前面採 [v;ω]，先列線速度再列角速度；Modern Robotics 等教材常採 [ω;v]。兩種都可用，但矩陣區塊、叉積位置與 API 必須跟順序一起固定，不能只交換文件文字。

指數與對數是速度、位姿之間的橋

把固定扭量的矩陣表示記成 [V]，維持時間 Δt 後的相對位姿可寫成 exp([V]Δt)。矩陣指數不是把每格取自然指數；它把無窮級數依剛體結構組合，使結果仍落在 SE(3)。反方向的矩陣對數 log(T) 會找出能生成相對變換的局部運動。這使「從目前位姿走到目標位姿」可先轉成具座標意義的六維誤差，再交給雅可比反解。

以平面車體為例，車體 x 軸速度為 v、角速度為 ω。若 ω=0，經過 t 秒就是直走 x=vt；若 ω≠0，它沿半徑 v/ω 的圓弧走，位移為 x=(v/ω)sin(ωt)、y=(v/ω)(1−cos(ωt))。把「同時平移與旋轉」分成先直走再原地轉，通常得到不同終點；指數映射處理的是同一段時間內同時發生的剛體運動。

讀完再操作：積分一段平面扭量

螺旋軸、POE 與 Adjoint 各做什麼

螺旋軸（screw axis）把一個關節的旋轉軸、軸線位置與可能的沿軸平移包成六維運動方向。旋轉關節是節距為零的螺旋；移動關節則沒有角速度。指數積形式（Product of Exponentials, POE）把每個關節在零位時的螺旋軸依序指數化，再乘上工具零位姿。它與 Denavit–Hartenberg 表都能建正運動學，重點是選一套一致的座標契約，不要把兩套參數慣例拼接。

伴隨表示（adjoint representation）Ad(T) 是由 4×4 變換建立的 6×6 矩陣，用來把同一個扭量或螺旋軸改用另一座標系表示。它不是再做一次物理運動。空間雅可比（space Jacobian）把末端扭量表示在固定空間框架；本體雅可比（body Jacobian）把它表示在末端框架。兩者描述同一真實速度，可由 Adjoint 轉換；混用會讓數值看似合理但方向錯誤。

證據、誤解與適用邊界

  • 群結構證據：每次積分後檢查 RᵀR≈I、det(R)≈1、底列為 [0 0 0 1]。
  • 往返證據：小運動可檢查 exp(log(T))≈T，但旋轉接近 π 時要處理對數分支。
  • 框架證據：同一扭量分別以 space／body 表示，經正確 Ad(T) 轉換後應對應同一有限差分位姿。

常見誤解是把 se(3) 的六維座標直接當成有限位姿相加，或認為矩陣對數永遠有唯一答案。指數座標是局部且有分支的表示；大角度插值、接近 π 的旋轉與數值噪聲都需要明確策略。本章只建立運動學結構，不處理質量、力矩、接觸或控制穩定性。
