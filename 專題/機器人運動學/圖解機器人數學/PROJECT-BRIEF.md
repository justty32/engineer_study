# 圖解機器人數學 — 立案

工作流：[零基礎建課](../../../wf/workflows/interactive-study-site/FOUNDATIONS-FIRST.md)｜[建置契約](BUILD-SPEC.md)

## 一句話定位

從「怎麼告訴手臂往哪裡走」出發，以同一組積木手臂、座標紙和小數字，建立能銜接大學機器人運動學與基礎控制的數學。產品放在本目錄 `dist/`；新 slug 為 `robotics-math-little-lab`，既有機器人數學及七軸運動學網站完整保留。

## 讀者基線與理解債

讀者軟體能力強，但不假設三角函數、線性代數或微積分穩固。向量、矩陣、座標系、雅可比與四元數即使看過，也須從可追蹤的動作重新建立意義。程式實作只補座標、角度與單位契約，不將 C++ 或 ROS 當作本課主線。

## 目標能力

學完能在圖上指出位置數字屬於哪個座標框，區分物體轉動與換一把座標尺；能手算二連桿端點、檢查逆解與不可達；能用每個關節造成的速度箭頭讀雅可比，說明伸直時失去的是哪個瞬時運動方向；能分清軌跡幾何、時間安排、力矩及回授，並指出教學模型沒有包含的實機限制。

## 概念依賴與 prerequisite gap

位置與單位 → 角度／弧度 → 位移向量 → 座標框 → 平面與空間旋轉 → 點與方向的剛體變換 → 座標鏈 → 正／逆運動學 → 局部速度與奇異 → 軌跡時間 → 力矩 → 單關節動力學 → 回授。四元數列為最後一課的姿態表示橋接。

導數不牢時，雅可比先用「只轉一個關節一小格，看筆尖去哪裡」引入，再連接微積分。矩陣乘法先用兩根基底箭頭的份數引入，再連接線代。新工程數學尚未發布時只標先備概念，不建立會失效的跨站連結。所有主線內容仍能獨立在本站讀完。

## 語言與名詞契約

正文、按鈕、回饋一律繁體中文，採臺灣用語。首次術語附英文與白話動作；固定使用「座標框、連桿、關節、末端、雅可比矩陣、奇異姿態、角速度、力矩」。不用「坐標、矢量、質點慣量」混稱。矩陣列向量與欄向量的方向必須明確。本課一律使用欄向量，角度控制可用度，三角函數及導數計算使用弧度。

## 頁面、來源與續接

十七課的概念、先備、互動與數值例收在 [課程契約](課程契約.json)。正文從小問題、逐步原創圖走到圖中符號與公式的對應、完整逐行帶數字的算例，再接同例自由實驗、遷移練習與詳解、反例及可觀察證據。核心公式和計算不藏在折疊中。首頁提供零基礎入口與頁面地圖；字典供回查，來源頁提供教材章節與使用方式。

本地來源是既有 `專題/機器人數學基礎/互動課程/` 以及 `專題/機器人運動學/互動課程/`。官方教材主張與條件由研究員整理至 `教材對照.json`，以 Modern Robotics 作者教材及 MIT 開放講義為主。外部連結僅供使用者主動查閱；頁面不依賴外部執行期資源。

## 教學與模型邊界

二連桿主要採兩支各 1 m 的理想平面旋轉連桿，忽略碰撞、背隙與彈性，關節無機械角度限制。逆解的幾何可達不等於安全可執行。雅可比是指定姿態與座標框下的瞬時關係，大角度變化須重新計算。動力學及控制章切換為一個固定軸剛體轉子的模型，清楚標示切換理由，不把單關節結果套成整隻手臂的保證。

力、角速度、線速度、角加速度均附單位。三維 SVG 是明示的投影，三維長度不能靠投影畫面的像素直接量。量測證據包含編碼器角度、末端位置差分、力矩／力感測；每章都說明模型輸出不能證明碰撞安全或真機精度。

## 不做事項

不展開 ROS、視覺、SLAM、路徑搜尋或完整多連桿控制課；不新增依賴、外部點陣圖、字型、CDN、分析碼或遠端 API；不以答對解鎖、計分或進度百分比代替理解。不修改舊網站與原筆記，確證錯誤先提出證據及精確修正範圍。

## 交付與可延續性

產品為二十個 HTML 頁面（十七課、首頁、字典、來源）與本地 CSS／JavaScript；至少十七個有數值、單位、即時因果及重設的自由實驗。每課約四至七個有推理用途的圖組，實際以教學步驟是否完整判斷，不以圖數當作成效。

下一位執行者可由本檔找到讀者與依賴，由首頁找到章節角色，由 BUILD-SPEC 與課程契約找到規約／公式／邊界，由教材對照找到來源，由驗收紀錄找到通過與待人工項。獨立驗收包含數學規約、圖形、桌機／手機、鍵盤與離線；真人理解程度留待使用者實際閱讀回饋。
