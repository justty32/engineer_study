## 產品與所有權

原生多頁 HTML／CSS／JavaScript，無下載依賴、無外部執行期請求；數學用 Unicode、上下標與可讀的公式區塊，不依賴 LaTeX 渲染器。可使用自己的 `lab.css` 與原創 inline SVG，不改原十七站 `styles.css`。此選擇承接使用者要求大量圖解新站的授權，不受舊模板只能沿用 CSS 的版面限制。

隊長寫本檔、立案、課程契約與派工資料；建置員寫 dist 與 README，並指定單檔唯一作者；研究員獨占教材對照；驗收員獨占驗收紀錄及驗收數據／成品清單；hosting 獨占 `.openai/`。共用 git、入口與發布由根隊發布員串行處理。建置進度為臨時文件，交付前刪除。

## 頁面骨架

每頁先有回首頁／主站、章節編號、具體問題型標題、一句話回答與最少先備，再進入三至七步同例圖解。每課須有明確「給定什麼、要求什麼」的題目，圖中逐項標出公式符號、數值與單位，說明為何選此式、每一項從哪個動作或投影而來，再以可見的逐行計算得到答案。互動接在完整算例後，預設重現同例。接著是近似遷移練習（提示與詳細解答）、重要條件與反例、可量測證據、上／下一課。第一屏用能讀懂的圖解，不強迫陌生公式搶先。

每個圖組都須有可見圖名、解說與 SVG 的 `title`／`desc` 或對應可及文字。圖中只靠顏色的資訊必須有標籤、線型或符號補足。連續步驟使用同一物件、相同顏色意義、同一座標尺度與例子；若換座標或換模型，先可見地說明。不能把「係數份數」畫成「物體位置」而不交代。

## 座標與單位的固定規約

所有向量採欄向量。世界框記 A，局部框記 B；`p_A = R_AB p_B + t_AB` 表示同一點換座標數字，R_AB 的欄是 B 各軸在 A 的方向，t_AB 是 B 原點在 A 的位置。逆為 `p_B = R_ABᵀ(p_A − t_AB)`。齊次點最後一格為 1，純方向為 0。二維為 3×3，三維為 4×4。

描述物體主動旋轉時，明說固定世界軸、右手正向、矩陣左乘；先 Rx 再 Rz 寫 Rz Rx。三維圖固定投影，不靠模糊透視判斷符號。右手系 x×y=z；二維正角從 x 朝 y 逆時針。SVG 的 y 向下須在繪圖映射中反轉，不能偷換數學正向。

二連桿固定 L₁=L₂=1 m，q₁ 是世界 x 軸到第一桿角，q₂ 是第一桿到第二桿相對角。末端 `[cos q₁ + cos(q₁+q₂), sin q₁ + sin(q₁+q₂)]` m。控制使用度時，每次計算先轉弧度。速度用 rad/s、線速度 m/s、力 N、力矩 N·m、慣量 kg·m²。

## 互動契約與程式要求

逐頁 `id/type/range/default/options/formula/fixture/boundary` 固定於課程契約。每頁至少一個自由實驗，所有 range/select 有 label、數值 output、結果文字及重設按鈕；控制即時更新所有數字、圖與「為什麼」。預設與前面的主要計算例一致，不為程式方便換例子。重設回代表性教學值。核心公式與數值代入不得藏在 details，動態「這次怎麼算」也須直接可見；details 只留進階推導或練習詳解。

## 使用者新增的算式圖解關卡（2026-10-11）

使用者回饋：「圖很多，但要用圖講解公式；全部圖能懂概念，實際應用不知道怎麼用；相關計算過程也是。」因此概念圖只是起點，每課必須讓讀者能照著算一題。每個核心式子需回答：什麼情況用它、哪些量已知、要求哪個量、圖上的哪一段對應式子的哪一項，以及怎麼用圖或另一種算法檢查結果。省略中間值、只給最後答案、只讓滑桿報數字都不合格。

先行範例為 forward：L₁=L₂=1 m、q₁=30°、q₂=60°；第二桿世界角為 90°。四段投影分別標 L₁ cos q₁、L₁ sin q₁、L₂ cos(q₁+q₂)、L₂ sin(q₁+q₂)。逐行算得第一段 (√3/2,1/2) m、第二段 (0,1) m、末端 (√3/2,3/2) m。主實驗預設同步 30°／60°；原 0°／90° 的概念例保留並用快捷按鈕回訪。遷移題 30°／30° 使第二桿世界角 60°，兩段水平投影皆非零，得 ((√3+1)/2,(√3+1)/2) m，完整解答須獨立核驗。

雅可比頁須把至少一欄的兩個偏導逐項畫出、代入角度，再將每欄乘關節速度並相加，m/rad 乘 rad/s 成 m/s 的單位也畫清楚。其他課同樣將圖片直接連到式子與計算，不把方法只用在先行頁。

每頁用 `data-page` 或獨立 JS 安全掛載，不讀不存在的 DOM，不亂數、不 fetch、不計時動畫。動畫若有只由使用者主動觸發，尊重 reduced-motion；本課優先用時間滑桿而非自動播放。鍵盤 focus 明顯，320 px 也能讀，公式可局部換行但整頁不得橫向溢出。

不可達、無限多解、逆解合併、零向量、剛好奇異與零阻尼須有明確狀態，不能漏 NaN／Infinity。浮點容差只解決誤差，不把真正不可達的目標夾到邊界假裝有解。IK 求得每一支解後再代回 FK 顯示殘差。

## 圖與範圍的額外關卡

位置與位移不同、主動旋轉與被動換框不同、速度空間與工作空間不同、瞬時不可動與有限時間路徑不同、單關節慣量與整隻手臂質量矩陣不同、姿態表示奇異與機構奇異不同，這六組邊界必須在對應正文可見，不只藏於進階折疊。

力量章定義 F 為手臂希望對外物施加的力；外物反作用力為 −F，忽略重力與慣性時致動器需 τ=JᵀF。若改採外界施於手臂的 F_ext，平衡式須寫 τ+JᵀF_ext=0。不得在故事、箭頭與公式切換力的角色。

軌跡採三次時間比例 s=3u²−2u³；只保證端點速度為零，端點加速度不為零，接靜止段會跳變。控制採固定目標、單軸剛體、無飽和／延遲／重力的 PD 示範，不能宣稱穩定就等於真機安全。

## 驗收

獨立審查先核教材、公式、單位、規約與 fixture，再核 ready 圖形是否忠實表達。技術驗收全二十頁 1440／390／320 px、console、外部請求、UTF-8、內部連結、鍵盤、重設與邊界，另以實際截圖核代表課及可疑區。每個公式至少一個獨立重算案例；所有實驗確認預設與至少兩端狀態。離線 file:// 開啟不得依賴伺服器。

舊機器人站建立雜湊基準並確認未變；共用樣式檢查不得漂移；wf-lint 不新增既存兩條歷史引文斷鏈。最終留下 dist 清單與 SHA-256、獨立驗收紀錄、教材索引，作者停筆且測試行程退出後才宣告可發布。人類理解與真機觸控不由自動測試代為宣稱。
