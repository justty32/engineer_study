# 圖解機器人數學

從「用哪把尺描述手臂」出發，以原創分鏡、完整演算與自由實驗，銜接大學機器人運動學、單軸動力學及控制。新站獨立放在 `dist/`，不覆蓋既有機器人數學與七軸運動學課程。

## 閱讀入口

直接開啟 [學習地圖](dist/index.html)，或從 [00 格子與位置](dist/00-start.html) 開始。所有文字、靜態 SVG 與互動均可離線使用，無套件、CDN、外部字型、圖片下載或遠端 API。部署路徑使用 `robotics-math-little-lab`；實際發布狀態以獨立驗收與部署紀錄為準。

公開入口：[GitHub Pages 圖解機器人數學](https://justty32.github.io/engineer_study/robotics-math-little-lab/)。獨立數學、教學與技術結果見 [驗收紀錄](驗收紀錄.md)；本站使用既有 GitHub Pages 管線，不另建 Sites 鏡像。

每課依序提供具體問題、同例逐步圖解、完整計算、遷移練習、自由實驗、正式記號、適用限制及可量測證據。計算例明列給定與求量，把圖中符號對應公式各項，逐行代入中間值與單位，再回圖檢查。練習提示與詳解可自行展開；核心算例與即時代入全程可見。

正運動學以直角手臂引入，再完整計算肩 30°、肘 60° 的例子；實驗預設接此算例，另有按鈕回看 0°／90° 概念例。遷移題改成 30°／30°，需要同時加上兩段的水平與垂直投影。

## 產品與維護

`dist/` 共 23 檔：20 個 HTML、本站獨立 `lab.css`、導航 `site.js`、17 個實驗的 `experiments.js`。HTML 直接保留 112 個原創靜態 SVG；另有即時重畫圖。這些數量只描述資產，不代表學習效果。雅可比另從正運動學固定另一角，逐項推導第一欄的兩個偏導，並把每弧度效果與乘角速度後的速度分開。四元數以限定 z 軸、輸入 eₓ 的可代入簡式驗證正負號；PD 解析式明列衰減常數的每秒單位。每課可見完整計算例與一組附解遷移練習；不使用分數或解鎖進度。

HTML 是可直接維護的成品來源，無必需建置工具。靜態故事改動須同步核對實驗預設、圖上單位、計算步驟及契約。每頁以 `data-page` 掛載，控制 ID 固定於課程契約；`window.roboticsResult` 提供本次精確計算結果，方便獨立驗收取得資料。顯示小數有捨入，計算保留原精度。

所有 SVG 由程式原創。三維圖明示固定投影，不能拿螢幕像素量三維距離；力量、速度與位置用不同圖尺並明列單位。手機版先呈現該步標題和圖，再讀說明；刻度避讓標籤，不以自動檢查無溢出取代實際可讀性檢視。

## 固定數學規約

使用欄向量與右手系，`p_A=R_AB p_B+t_AB` 是同一點從 B 換成 A 的讀數。主動旋轉與換框明確分開；角度控制可用度，三角函數及角度微分用弧度。二連桿各 1 m，q₂ 是相對第一桿的角。等長桿目標原點有無限多組肩角，目標半徑大於 2 m 明示不可達。

雅可比只描述當下的平移速度；奇異不等於有限時間永遠不能移動。力 F 固定為手臂對外物的力，忽略重力慣性時馬達需求為 `τ=JᵀF`。三次時間比例的端點速度為零、端點加速度非零。PD 只示範指定理想單軸模型，Kᴅ=0 持續振盪；單位四元數採 Hamilton、wxyz，q 與 −q 是同一旋轉。
