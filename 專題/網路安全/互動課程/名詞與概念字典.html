怎麼讀這本字典

名詞條目回答它位於哪一層、負責什麼、如何運作、保證到哪裡，以及可從哪裡看到證據。概念條目則從參與角色與資料流出發，追蹤操作如何造成狀態與結果。類比只用來建立入口；「機制」與「邊界」才是真實工程判斷的依據。

搜尋會比對卡片內全部文字。可輸入繁中、英文全名、縮寫、工具名稱或動作，例如「拒絕」「路由」「追蹤識別碼」。

資產（Asset）

白話
你不希望被讀、改、刪、冒用或中斷的東西。
位置／層級
可位於資料、身分、應用、設備、營運與組織層，也包含金錢、聲譽或人身安全。
功能
作為安全目標與影響分析的對象，讓控制有明確保護標的。
機制
威脅模型把資產連到擁有者、資料流、允許狀態與損害情境，再依影響排序。
邊界
資產不是只指硬體；同一資料的內容、可用性與控制權可分別是資產。
可觀察證據
資產清冊、資料分類、擁有者紀錄、資料流與實際存取稽核；清冊只能證明已登記，不能證明沒有未知資產。

安全主體（Security Principal）

白話
系統能賦予身分與權限的實體。
位置／層級
身分與存取層；可代表使用者、程序、服務或裝置。
功能
成為驗證、授權與稽核決策中的「誰」。
機制
由帳號、權杖、憑證或作業系統識別碼表示，程序在執行時攜帶或代理該主體。
邊界
主體名稱不等於已驗證身分；一個真人也可能操作多個主體。
可觀察證據
權杖宣告、憑證主體、程序使用者與身分日誌；它們證明系統採用的身分，不必然證明真人。

驗證（Authentication）

白話
確認某個身分聲稱有足夠可信的憑證。
位置／層級
登入、服務連線、裝置佈建與權限提升入口。
功能
把未證實的名稱轉成具有一定保證程度的安全主體與工作階段。
機制
驗證密碼、私鑰、安全金鑰或其他因素，通過後簽發具範圍與期限的權杖或工作階段。
邊界
驗證不等於授權；憑證也可能由攻擊者持有。
可觀察證據
嘗試時間、方法、結果、裝置、來源與工作階段識別碼；成功只證明系統接受憑證。

授權（Authorization）

白話
決定已知主體能否對特定資源執行特定動作。
位置／層級
作業系統、應用程式、介面、資料庫與網路政策的資源邊界。
功能
把身分轉成有限的允許狀態改變，預設拒絕未明示的動作。
機制
根據角色、屬性、能力或存取控制清單，結合資源與情境求出決策。
邊界
登入成功不代表所有操作都允許；角色允許也不一定代表可讀任意物件。
可觀察證據
主體、動作、資源、政策版本、決策與理由；只有超文字傳輸協定（Hypertext Transfer Protocol, HTTP）狀態碼通常不足以還原政策。

最小權限（Least Privilege）

白話
只給完成任務所需的最小權限、範圍與時間。
位置／層級
人員、程序、服務、金鑰、資料與網路各層。
功能
限制憑證外洩、程式漏洞或誤操作後可改變的狀態範圍。
機制
拆分角色、短效授權、按需提升、目的限制與預設拒絕。
邊界
不是讓所有人都無法工作，也不能阻止被允許範圍內的濫用。
可觀察證據
權限清冊、實際使用紀錄、提升與撤銷事件；政策很小不代表執行期權杖真的很小。

網際網路協定（Internet Protocol, IP）

白話
用位址把封包從來源轉送到目的地。
位置／層級
網路層，位於本地連結與 TCP／UDP 等傳輸協定之間。
功能
提供跨網路的位址與盡力而為轉送，讓每一跳能選下一跳。
機制
主機建立含來源與目的位址的 IP 封包，路由器逐跳查路由表並更新轉送相關欄位。
邊界
可達性不等於可靠、保密或可信；來源位址也不等於真人身分。
可觀察證據
路由表、追蹤路徑與封包標頭能支持位址及路徑判斷；單一觀測點看不到完整網路。

傳輸控制協定（Transmission Control Protocol, TCP）

白話
在兩個通訊端間提供有順序、可靠的位元組流。
位置／層級
傳輸層，承接應用資料並交給 IP。
功能
處理遺失、重複、亂序、流量控制與壅塞反應。
機制
以連線狀態、序號、確認、重傳、視窗與旗標協調兩端。
邊界
可靠交付不等於應用交易提交，也不提供內容機密性。
可觀察證據
封包中的 SYN、ACK、序號、重傳與重設，以及主機通訊端狀態；封包不能說明應用為何關閉連線。

使用者資料包協定（User Datagram Protocol, UDP）

白話
以低開銷送出一份份保留邊界的資料報。
位置／層級
傳輸層，位於應用與 IP 之間。
功能
以連接埠把資料多工給程序，不強制建立 TCP 式連線狀態。
機制
每份資料報帶來源／目的連接埠、長度與檢查碼；不提供 TCP 的重傳與順序。
邊界
「無連線」不表示應用不能自行維護會話、確認或壅塞控制。
可觀察證據
封包可見資料報時序、大小、端點與可見酬載；看不到封包不證明應用沒有重試。

網域名稱系統（Domain Name System, DNS）

白話
查詢名稱對應的位址與其他紀錄。
位置／層級
應用層的分散式命名資料庫，常在連線建立前使用。
功能
把人與服務使用的名稱解析成位址、郵件交換等紀錄。
機制
用戶端詢問遞迴解析器；解析器查快取或沿委派找到權威伺服器，並依存活時間快取。
邊界
解析成功不證明端點身分，也不保證該位址可達。
可觀察證據
查詢／回覆封包、解析器快取與權威紀錄；加密 DNS 或觀測點位置會限制可見性。

傳輸層安全性協定（Transport Layer Security, TLS）

白話
驗證端點並保護傳輸中的應用資料。
位置／層級
位於 HTTP 等應用協定與 TCP 等傳輸服務之間。
功能
提供通道端點身分、機密性與紀錄完整性。
機制
握手協商、驗證憑證、以公鑰密碼學建立祕密、導出流量金鑰，再用已驗證加密保護紀錄。
邊界
不保護遭入侵的端點，也不取代應用授權或判斷內容是否可信。
可觀察證據
握手、版本、公開憑證、警示與加密紀錄；封包通常看不到加密後的應用明文。

密碼雜湊函式（Cryptographic Hash Function）

白話
把任意長度內容轉成固定長度指紋。
位置／層級
密碼學原語，作為檔案驗證、簽章與密碼推導等機制的組成。
功能
讓內容變化反映為摘要變化，並使反推原文或刻意找碰撞在計算上困難。
機制
確定性地處理全部輸入位元；相同輸入得到相同摘要，微小變化通常造成不可預測的摘要差異。
邊界
雜湊不是加密，也沒有來源證明；若攻擊者能同時改資料與摘要，單獨比對無效。
可觀察證據
演算法名稱、輸入範圍與重新計算的摘要；相同摘要支持內容一致，仍需可信管道保護基準摘要。

訊息鑑別碼（Message Authentication Code, MAC）

白話
用共享秘密驗證訊息完整性與來源群組。
位置／層級
密碼學原語，常用於協定訊息與儲存資料。
功能
讓持有共享金鑰者偵測訊息是否被未授權修改。
機制
發送端以金鑰與訊息產生標記，接收端用同一秘密重算並以安全方式比較。
邊界
共享者都能產生標記，所以不能向第三方證明是哪一位共享者產生；也不等於媒體存取控制（Media Access Control）位址。
可觀察證據
金鑰識別碼、驗證成功或失敗與協定序號；日誌不得記錄秘密金鑰。

數位簽章（Digital Signature）

白話
私鑰簽署，持有對應公鑰者可驗證。
位置／層級
公鑰密碼學機制，用於憑證、軟體更新、文件與協定握手。
功能
支持內容完整性與私鑰持有者來源的驗證，將簽署能力和驗證能力分開。
機制
簽署演算法對明確編碼的內容或其摘要產生簽章，驗證者以公鑰檢查。
邊界
簽章不隱藏內容，也不自動證明公鑰屬於誰或簽署行為獲授權。
可觀察證據
簽章、演算法、公鑰或憑證、驗證結果與撤銷狀態；私鑰本身不應出現在紀錄。

威脅模型（Threat Model）

白話
針對特定系統描述可能出錯、如何處理與如何驗證。
位置／層級
貫穿設計、實作、部署、營運與變更生命週期。
功能
把有限資源集中到明確資產、攻擊路徑與可驗證控制。
機制
分解元件與資料流，明示攻擊者能力，識別與排序情境，選擇緩解並用證據重審。
邊界
不是一次性的攻擊名稱清單，也不保證列出未知威脅。
可觀察證據
資料流、假設、決策、責任人、控制測試與變更紀錄；文件存在不證明模型仍符合部署。

信任邊界（Trust Boundary）

白話
資料或控制跨過信任等級、身分或管理責任改變的位置。
位置／層級
可存在於網路區段、程序、服務、租戶、供應商與人員之間。
功能
標出不能沿用上游假設、必須重新檢查的交界。
機制
資料跨越時重新驗證來源與格式、授權動作、限制資源並留下紀錄。
邊界
內網邊界不是唯一信任邊界；同程序內不同解析器也可能有邊界。
可觀察證據
介面規格、驗證與授權設定、跨界請求日誌；網路拓撲只能顯示部分邊界。

縱深防禦（Defense in Depth）

白話
不同失效模式的控制共同降低單點失效後果。
位置／層級
人員、身分、應用、主機、網路、資料、供應鏈與復原。
功能
在預防失敗後仍能偵測、限制、回應與恢復。
機制
把獨立或互補控制放在攻擊因果鏈不同位置，並測試控制彼此失效時的行為。
邊界
不是無目的堆疊產品；共享同一盲點的多層控制可能同時失效。
可觀察證據
控制對應的威脅、設定、測試、告警、抑制與復原演練；產品數量不能證明縱深。

入侵偵測系統（Intrusion Detection System, IDS）

白話
分析活動並產生疑似入侵告警。
位置／層級
部署於網路觀測點或主機，屬於偵測控制。
功能
把封包、事件或行為與規則及基線比較，找出值得調查的訊號。
機制
以特徵、協定狀態、行為或異常分析產生告警與上下文。
邊界
告警不是已證實事件，也不一定自動阻擋；加密、取樣與未知行為會形成盲點。
可觀察證據
規則版本、觸發事件、流量片段與告警處理結果；只有告警標題不足以驗證根因。

端點偵測與回應（Endpoint Detection and Response, EDR）

白話
收集端點程序、檔案與網路遙測並支援調查處置。
位置／層級
工作站與伺服器作業系統，接近程序與核心事件。
功能
連接「哪個程序做了什麼」並支援查詢、隔離或終止等回應。
機制
代理程式收集事件，後端關聯並產生告警，再由人員或程序執行處置。
邊界
不能取代安全設計、備份或所有網路可見性；代理停用或遭竄改會有盲點。
可觀察證據
程序樹、檔案、模組、通訊端、使用者、感測器健康與處置紀錄；命令列文字不必然等於實際意圖。

安全資訊與事件管理（Security Information and Event Management, SIEM）

白話
集中、搜尋並關聯多來源安全日誌。
位置／層級
組織遙測、安全營運與調查層。
功能
把分散事件轉為可跨來源查詢、告警與保存的共同時間線。
機制
收集、解析、正規化、加上上下文，再用規則或分析關聯並管理保存。
邊界
不能補回未記錄、遭取樣或語意錯誤的資料；集中本身也成為敏感資產。
可觀察證據
來源健康、收集延遲、解析失敗、原始事件與查詢結果；關聯命中只代表條件符合。

日誌（Log）

白話
某元件對事件與狀態的時間序列紀錄。
位置／層級
身分、應用、作業系統、網路設備、資料庫與控制平面。
功能
支援除錯、稽核、偵測、效能分析與事件時間線。
機制
元件依程式語意產生欄位，經傳輸、解析、儲存、存取、保留與處置生命週期。
邊界
日誌是觀測，不是完整真相；不可寫入密碼、權杖或私鑰，也可能遭漏記或竄改。
可觀察證據
時間、來源、主體、動作、資源、結果與關聯識別碼，加上收集管線健康；文字存在不保證欄位正確。

封包擷取（Packet Capture, PCAP）

白話
保存網路介面看見的封包供後續分析。
位置／層級
端點、交換器鏡像埠、網路分流器或感測器。
功能
保留線上標頭、時序、大小與可見酬載，以分析協定與通訊事實。
機制
介面或感測器複製封包並記錄時間與擷取長度，分析工具再解碼與重組。
邊界
看不到未經觀測點的流量；也可能漏包、截短，且加密內容通常不可讀。
可觀察證據
位址、連接埠、旗標、序號、時序與可見酬載；它不能直接證明端點內的程序、真人或業務授權。

概念：識別到稽核的存取鏈

角色
請求者、身分提供者、政策決策點、資源服務與稽核系統。
狀態／資料流
名稱與憑證進入驗證，產生工作階段；主體、動作、資源與情境進入授權，決策再交給資源執行。
因果
憑證有效只建立主體；政策允許才讓特定動作發生，兩階段都應留下可關聯紀錄。
結果
允許或拒絕一次明確存取，並把決策範圍限制在該資源與情境。
可觀察證據
身分、工作階段、政策版本、資源、決策與結果；只能支持系統如何判斷，不能單獨確認真人意圖。

概念：TLS 受保護通道

角色
客戶端、伺服器、憑證簽發與信任來源，以及可能觀察或修改路徑的攻擊者。
狀態／資料流
握手交換公開參數與憑證，雙方導出短期流量金鑰，應用資料再成為已驗證加密紀錄。
因果
客戶端驗證預期名稱與信任鏈，握手完成後才把受保護紀錄交給應用；驗證失敗應中止。
結果
在通道端點間提供機密性、完整性與端點身分保證。
可觀察證據
握手、公開憑證、協商結果、警示與加密紀錄；不能證明端點未失陷或應用授權正確。

概念：威脅到控制的驗證循環

角色
資產擁有者、系統設計與營運者、攻擊者、控制執行元件與驗證者。
狀態／資料流
系統資料流跨越信任邊界；攻擊者能力與入口形成威脅情境；控制改變可達性、權限、可偵測性或復原能力。
因果
明示威脅後選擇控制，再以測試與遙測驗證；系統或假設改變便重做循環。
結果
風險被避免、降低、轉移或明確接受，並保留剩餘風險。
可觀察證據
模型版本、控制設定、測試、告警、事件與復原演練；控制存在不等於在所有路徑有效。

概念：事件證據時間線

角色
身分服務、應用、主機、網路感測器、資料庫、調查者與證據保管者。
狀態／資料流
各來源產生帶時間與關聯鍵的觀測，收集管線保存原始事件並建立可查詢副本。
因果
以工作階段、追蹤識別碼、端點、主體與資源對齊多來源，再區分直接觀察、支持推論與假設。
結果
形成可重查的事件範圍、處置決策與不確定性說明。
可觀察證據
原始事件、雜湊、收集方式、時鐘誤差、查詢與調查者操作；時間相近本身不能證明因果。
