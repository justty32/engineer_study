# 網路安全零基礎互動課程專案簡報

## 讀者基線

- 讀者是資深 C++ 工程師，熟悉程式、記憶體、執行緒與除錯；程式語法只作銜接。
- 不假設已懂網路協定、通用作業系統安全模型、數位身分、存取控制、密碼學、威脅模型或數位鑑識。
- 正文與介面使用繁體中文；術語首次出現寫出繁中、英文全名、縮寫與白話功能。

## 目標能力

完成主線後，讀者能：

1. 沿「資產 → 身分 → 權限 → 程序 → 網路資料流 → 證據」描述一個系統。
2. 分開解釋識別、驗證、授權、稽核，以及雜湊、加密、訊息鑑別碼與數位簽章。
3. 建立最小威脅模型，寫出資產、角色、攻擊者能力、信任邊界、威脅、控制與剩餘風險。
4. 依攻擊所需前置、狀態改變與可觀察證據理解常見攻擊，而非背名稱。
5. 把預防、偵測、回應與復原控制配置到正確層次。
6. 關聯封包、身分、程序、應用程式與稽核日誌，形成可驗證的事件時間線。

## 教學邊界

- 純靜態、離線、無圖片、無外部字型、內容傳遞網路、遠端介面或第三方執行期套件。
- 不提供針對真實目標的入侵步驟、武器化程式碼、密碼破解、規避偵測或持久化操作。
- 互動是教學模型，不取代滲透測試、正式風險評估、事件鑑識、法規遵循或法律意見。
- 「常見攻擊手法細講」與「逆向工程」另作進階課程；本主線只建立其必要模型。
