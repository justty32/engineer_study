# 網路安全零基礎互動課程建置規格

## 全域契約

- 所有頁面載入 `styles.css` 與 `app.js`；程式必須先偵測元素是否存在。
- 每頁具有首頁、字典、上一頁與下一頁相對連結；目前頁以 `aria-current="page"` 標示。
- 無計分、提交答案、答對解鎖、倒數或強制進度；控制值變動後立即更新結果與原因。
- 狀態不能只靠顏色；動態回饋使用 `aria-live="polite"`。

## 互動契約

1. `00` 資料流追蹤：選角色與事件，即時更新資產、狀態變化、控制與證據。
2. `01` 連線拆解：變更目的位址、連接埠與傳輸方式，即時顯示封裝路徑及能／不能證明的事。
3. `02` 存取決策：變更主體、驗證狀態、角色與資源，即時顯示允許／拒絕原因與稽核欄位。
4. `03` 密碼工具選擇器：依目標顯示正確原語、金鑰需求、提供與不提供的性質。
5. `04` 威脅模型工作台：資產、入口、攻擊者能力與控制改變時更新威脅敘述、影響與證據。
6. `05` 攻擊因果追蹤：選攻擊類別，顯示前置、機制、狀態改變、防禦與證據，不提供操作步驟。
7. `06` 防禦缺口：切換事件階段與控制，顯示第一缺口、原因與剩餘風險。
8. `07` 時間線關聯：切換情境與證據來源，重建事件序列並提示缺少的資料與推論限制。
9. 字典搜尋：依繁中、英文、縮寫與白話文字即時篩選；無結果時顯示訊息。

## 驗收

- JavaScript 通過 `node --check`。
- 所有相對 `href`、`src` 均存在；所有 HTML 宣告 `utf-8` 與 `zh-Hant`。
- 人工檢查 `1440×900` 與 `390×844`，無橫向溢位、重疊或鍵盤不可達控制。
- 至少操作每類互動一個非預設值，確認結果與「為什麼」同步改變。
