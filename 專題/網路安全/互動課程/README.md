# 網路安全零基礎互動課程

以資深 C++ 工程師為讀者，但不預設網路、作業系統安全、身分、權限、密碼學與威脅模型基礎。由 `index.html` 開始；字典供隨時回查，不是進入主線前的考試。

## 頁面地圖

| 頁面 | 責任 |
|---|---|
| `index.html` | 課程地圖、讀者基線與依賴 |
| `00-零基礎起點.html` | 資產、角色、狀態、資料流、控制與證據 |
| `01-網路最小前置.html` | 位址、連接埠、封包、路由與連線 |
| `02-作業系統身分權限.html` | 程序、使用者、驗證、授權、最小權限與稽核 |
| `03-密碼學最小前置.html` | 雜湊、金鑰、加密、訊息鑑別碼、簽章與傳輸層安全性協定 |
| `04-威脅模型.html` | 資產、攻擊者能力、信任邊界、威脅、控制與剩餘風險 |
| `05-常見攻擊.html` | 攻擊機制概觀與進階課程銜接 |
| `06-防禦與事件處理.html` | 縱深防禦與治理到復原的閉環 |
| `07-封包與日誌證據.html` | 多來源事件時間線與證據限制 |
| `名詞與概念字典.html` | 可搜尋的中英名詞、白話功能與易混概念 |

本機啟動：

```powershell
python -m http.server 4180 --directory "專題/網路安全/互動課程"
```

關鍵方法、來源與邊界見 `PROJECT-BRIEF.md`；互動契約見 `BUILD-SPEC.md`；實測結果見 `驗收紀錄.md`。
