# 網路安全專題

本專題依 foundations-first 工作流分成兩條課程：

- 線上版本：[網路安全主課](https://justty32.github.io/engineer_study/network-security/)｜[進階攻擊手法](https://justty32.github.io/engineer_study/attack-techniques/)

- [網路安全零基礎互動課程](互動課程/index.html)：先修網路、作業系統、身分、權限、密碼學與威脅模型，再進攻擊、防禦、封包與日誌證據。
- [常見網路攻擊手法細講](攻擊手法細講/index.html)：完成主課後，以前置、機制、狀態改變、控制與證據逐類深挖。

讀者基線為資深 C++ 工程師，但不假設具備網路安全先備知識。兩門課皆為繁體中文、純靜態、離線、無圖片且無計分。
