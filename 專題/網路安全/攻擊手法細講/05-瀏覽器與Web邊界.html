05 / 瀏覽器、代理、後端取址

同一個網址，經過多個解析器

瀏覽器管理來源、憑證與文件；反向代理切分請求；應用框架解析參數；後端客戶端再依網址取資料。進階 Web 攻擊常利用兩個元件對「來源、邊界、長度或目的地」的理解不一致。

進階診斷不是找關鍵字

  1. 畫出瀏覽器、邊緣快取、反向代理、應用框架與後端客戶端。
  2. 逐一寫出每個元件如何解析來源、主機、長度、路徑、重新導向與快取鍵。
  3. 找兩個元件解釋不一致的位置，才形成可驗證假說。
  4. 以關聯識別碼與原始位元組證明狀態變化，不把單一錯誤回應當成利用成功。
