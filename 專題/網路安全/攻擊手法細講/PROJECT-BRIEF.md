# 常見網路攻擊手法細講專案簡報

## 定位

這是「網路安全零基礎互動課程」的進階分支。讀者是資深 C++ 工程師；必須先具備主課的網路、身分與權限、密碼學、威脅模型及證據模型。

## 目標與範圍

- 用「前置條件 → 被濫用機制 → 狀態改變 → 安全影響 → 控制 → 封包／日誌證據」細講常見手法。
- 涵蓋身分與工作階段、輸入與記憶體、網路與通訊、權限與橫向移動，以及下列進階面向：
  - 瀏覽器來源邊界、伺服器端請求與代理解析差異。
  - 聯合身分、企業目錄、權杖與委派。
  - 原生程式控制流劫持與緩解措施的角色。
  - 密碼協定、亂數值重用、預言機與側通道。
  - 雲端身分、容器、控制平面與執行環境邊界。
  - 路由、名稱、位址自動設定與傳輸狀態的基礎設施攻擊。
  - 軟體供應鏈、合法工具濫用、指揮控制與資料外傳的失陷後鏈條。
- 每章使用無計分的情境切換器；不提供對真實目標的掃描、利用、持久化、規避偵測、密碼破解或資料外洩操作。
- 純靜態、離線、繁體中文、零外部資產；另建進階可搜尋字典，新增縮寫仍須在正文首次出現時原地展開。
