# 常見網路攻擊手法細講

由 `index.html` 開始。這是防禦導向的進階課程，先修為 `../互動課程/` 全部主線。

| 頁面 | 主題 |
|---|---|
| `01-身分與工作階段.html` | 釣魚、憑證填充、工作階段竊取與驗證疲勞 |
| `02-輸入解譯器與記憶體.html` | 注入、路徑穿越、反序列化與記憶體破壞 |
| `03-網路與通訊路徑.html` | 偵察、名稱／鄰居欺騙、中間人、重放與降級 |
| `04-權限可用性與供應鏈.html` | 權限提升、橫向移動、阻斷服務、勒索與供應鏈 |
| `05-瀏覽器與Web邊界.html` | 跨網站指令碼、跨網站請求偽造、伺服器端請求偽造、請求不同步與快取污染 |
| `06-聯合身分與權杖.html` | 開放授權、開放識別連線、權杖替換、重新導向與裝置碼釣魚 |
| `07-企業身分與委派.html` | 企業目錄、Kerberos、雜湊／票證重放、委派與驗證轉送 |
| `08-原生程式利用概念.html` | 控制流劫持、程式導向重用、資訊洩漏與平台緩解 |
| `09-密碼協定與側通道.html` | 亂數值重用、預言機、降級、憑證信任與時間側通道 |
| `10-雲端容器與控制平面.html` | 雲端中繼資料、混淆代理人、容器逃逸、控制平面與秘密 |
| `11-網路基礎設施.html` | 路由劫持、名稱快取污染、惡意自動設定與傳輸狀態耗盡 |
| `12-供應鏈與失陷後活動.html` | 相依套件、建置鏈、合法工具濫用、指揮控制、資料集結與外傳 |
| `進階名詞字典.html` | 本分支新增名詞的可搜尋中英字典 |

執行期為多頁 HTML 與 `app.js`，共用上一層主課的 `styles.css`。所有情境都只作防禦分析，不是攻擊操作手冊。
