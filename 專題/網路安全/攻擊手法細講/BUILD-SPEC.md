# 常見網路攻擊手法細講建置規格

- 所有頁面共用 `../互動課程/styles.css` 與本目錄 `app.js`，僅使用相對路徑。
- 每章的 `attack-scenario` 選單以 `data-*` 攜帶前置、機制、狀態、影響、控制與證據，變更即更新 `attack-detail`。
- `進階名詞字典.html` 以 `term-search` 即時篩選 `.term-card`，顯示 `term-count`，不要求背誦。
- 不含提交、分數、答對解鎖或可直接對目標執行的命令。
- 每頁必須有主課先修連結、首頁、上一頁、下一頁與進階字典連結；01–12 形成單一路徑且首頁可直接進入每頁。
- 進階頁只能描述攻擊者能力、被濫用機制、狀態與觀測；不得包含有效利用酬載、逐步入侵、持久化、規避偵測或外傳資料的操作程序。
