查字典時固定問四件事

位置：它存在於瀏覽器、身分系統、程序、控制平面還是網路路徑？功能：正常情況下解決什麼問題？機制：輸入、狀態與輸出如何流動？邊界：它沒有保證什麼？條目最後再列出可用證據，避免把名詞辨識誤當成事件已證實。

搜尋只過濾本頁條目；結果數證明字串符合，不代表概念間有因果。要重建因果鏈，請回到各章的互動情境與證據說明。

同源政策（Same-Origin Policy, SOP）

白話：瀏覽器以方案、主機與連接埠限制不同來源文件互讀。

位置／機制：瀏覽器在文件與指令碼存取敏感介面時比較來源。

功能／資料流：允許頁面送出某些跨來源請求，但限制回應內容被指令碼讀取；跨來源資源共享另由伺服器明確放寬讀取。

結果／證據：主控台與網路面板可顯示請求已送出及回應被政策阻擋；它們不能證明伺服器沒有執行動作。

不要混淆：限制讀取不等於阻止送出跨來源請求。

跨網站指令碼（Cross-Site Scripting, XSS）

白話：不可信資料被瀏覽器當成目標網站來源下的程式。

位置／機制：輸入抵達可執行輸出位置，文件解析器把資料轉成指令碼或事件處理。

功能／資料流：原本的渲染資料流越界成目標來源內的程式執行，能使用該來源允許的瀏覽器能力。

結果／證據：保存原始輸入、回應、文件物件模型變化、內容安全政策告警與後續工作階段動作；只有輸入含標記不能證明已執行。

不要混淆：不是「任何含標記的輸入」。

跨網站請求偽造（Cross-Site Request Forgery, CSRF）

白話：誘使瀏覽器帶著既有憑證向另一網站做非預期動作。

位置／機制：瀏覽器自動附帶 Cookie 等憑證，伺服器若沒有驗證動作意圖便接受。

功能／資料流：受害者瀏覽惡意來源 → 瀏覽器向目標送請求 → 目標把自動憑證映射成受害者工作階段。

結果／證據：來源標頭、防偽權杖驗證、工作階段與操作時間線可支持判斷；缺少來源標頭不單獨等於攻擊。

不要混淆：攻擊者不一定讀得到回應。

伺服器端請求偽造（Server-Side Request Forgery, SSRF）

白話：讓後端替攻擊者連到其原本不可達的位置。

位置／機制：後端網址取回經名稱解析與重新導向，最後以伺服器網路身分建立連線。

功能／資料流：原本的代理取回功能被借來跨過網路邊界；影響受後端可達性、回應可見性與目標授權限制。

結果／證據：關聯應用輸入、每次解析結果、重新導向鏈、實際連線目的與目標稽核；只檢查原始字串不足。

不要混淆：只檢查網址字串不等於驗證最終目的位址。

HTTP 請求不同步

白話：前後端對同一位元組流的請求邊界判斷不同。

位置／機制：代理、負載平衡器與應用伺服器採用不同長度或訊息結束規則。

功能／資料流：前端認為請求已結束，後端卻把殘餘位元組當成下一請求，使共用連線上的對應失去同步。

結果／證據：比較前後端原始位元組、關聯識別碼、連線重用及後續請求受影響情形；單一錯誤回應不能證明成功。

不要混淆：HTTP 的正常管線化不是漏洞。

Web 快取污染（Web Cache Poisoning）

白話：讓共享快取保存受攻擊者影響的回應並交給其他人。

位置／機制：某輸入影響來源站回應，卻未納入共享快取鍵。

功能／資料流：第一個請求填入物件 → 其他使用者命中相同鍵 → 收到攻擊者影響的表示法。

結果／證據：快取鍵、Age／Vary 類標頭、填入者與多使用者命中可證明跨使用者重用；不同節點的自然差異需排除。

不要混淆：只影響攻擊者自己的私人快取通常不構成跨使用者污染。

開放授權第二版（OAuth 2.0）

白話：讓資源擁有者把有限權限委派給客戶端。

位置／功能／機制：授權伺服器簽發有範圍、受眾與期限的權杖，客戶端持它呼叫資源伺服器，避免把資源密碼交給第三方。

結果／證據：授權請求、同意、授權碼兌換與資源呼叫形成資料流；日誌不可保存完整權杖。

不要混淆：核心用途是授權，不是單獨定義使用者登入。

開放識別連線（OpenID Connect, OIDC）

白話：在 OAuth 2.0 上加入可驗證的登入身分結果。

位置／功能／機制：識別提供者把驗證結果放入識別權杖，依賴方驗證後建立本地工作階段。

結果／證據：簽發者、受眾、時間、nonce 與本地工作階段可證明流程綁定；登入正確不保證後續授權正確。

不要混淆：仍須驗證簽發者、受眾、時間與流程狀態。

JSON 網頁權杖（JSON Web Token, JWT）

白話：可攜帶宣告並附簽章或加密保護的權杖格式。

位置／功能／機制：在聯合身分與介面授權中攜帶可獨立驗證的宣告；接收端仍須套用演算法、簽發者、受眾與時間政策。

結果／證據：記錄驗證決策與權杖識別摘要，不記可重放字串；解析成功不等於驗證成功。

不要混淆：格式不是協定；簽章有效也不代表用途正確。

簽發者（Issuer）

白話：聲稱產生並對權杖負責的身分系統。

位置／功能／機制：接收端以固定簽發者值選擇預期中繼資料與金鑰，把宣告綁到特定信任域。

結果／證據：保存簽發者、租戶、金鑰集合版本與驗證政策；只看到金鑰匹配不能證明租戶正確。

不要混淆：金鑰可驗證不代表簽發者就是預期租戶。

受眾（Audience）

白話：權杖預定要交給的服務或資源。

位置／功能／機制：資源伺服器把權杖受眾與自己的固定識別比對，以阻止跨服務替換。

結果／證據：權杖宣告與驗證分支可說明接受原因；程式有讀欄位不代表確實拒絕不符值。

不要混淆：同一簽發者給另一服務的權杖不可直接通用。

具證明金鑰的授權碼交換（Proof Key for Code Exchange, PKCE）

白話：讓兌換授權碼者證明自己持有發起流程時的秘密材料。

位置／功能／機制：客戶端在授權請求送挑戰值，兌換時交驗證值，將一次性授權碼綁到原發起者。

結果／證據：挑戰方法、客戶端、兌換時間與驗證結果可追蹤；不可記錄驗證秘密。

不要混淆：它不取代重新導向、狀態與受眾驗證。

Kerberos

白話：用金鑰分配中心與票證進行網路身分驗證的協定。

位置／功能／機制：企業網路由金鑰分配中心簽發票證與工作階段金鑰，讓使用者向服務驗證而不反覆傳密碼。

結果／證據：票證簽發、服務主體、來源主機、加密類型與使用時間可重建流程；有效票證不證明使用情境正常。

不要混淆：票證有效不表示來源主機或使用情境正常。

雜湊重放（Pass-the-Hash）

白話：直接使用可重用驗證材料完成協定，不先還原明文密碼。

位置／功能／機制：舊式挑戰回應驗證接受密碼衍生材料產生的回應，攻擊者借此建立原帳號工作階段。

結果／證據：協定類型、來源主機、帳號、服務與材料存取遙測需關聯；登入成功不證明明文密碼外洩。

不要混淆：不同於離線猜測密碼。

票證重放（Pass-the-Ticket）

白話：使用遭取得且仍有效的 Kerberos 票證冒用主體。

位置／功能／機制：票證從快取提交給指定服務，或以票證授予能力取得後續票證，使服務建立相符主體。

結果／證據：簽發與使用時間、來源主機、服務主體及正常活動基線共同支持判斷。

不要混淆：票證使用本身是正常流程，異常需靠情境判斷。

驗證轉送（Authentication Relay）

白話：把一端的即時驗證互動轉送給另一服務。

位置／功能／機制：兩條連線間代理挑戰回應；缺少通道綁定或訊息簽章時，第二服務誤認受害者直接登入。

結果／證據：兩端同步時間、來源不一致、協定保護與第二服務動作構成因果證據。

不要混淆：不一定保存或破解驗證材料。

委派（Delegation）

白話：允許服務代表使用者呼叫下游服務。

位置／功能／機制：票證或權杖把使用者意圖交給中介服務，再由中介向受限下游行動。

結果／證據：委派設定、原使用者、中介與下游票證可還原資料流；合法功能仍須限制下游、帳號與時間。

不要混淆：委派不是把使用者全部權限永久交給服務。

回傳導向程式設計（Return-Oriented Programming, ROP）

白話：把既有程式碼片段沿非預期控制流組合成行為。

位置／功能／機制：在資料頁不可執行時重用模組內既有指令，靠受控回傳或間接轉移改變程序狀態。

結果／證據：異常回傳鏈、堆疊不一致與 CFI 例外可顯示偏離；只看到片段存在不證明能串成利用。

不要混淆：本課只用來解釋緩解，未提供片段鏈構造。

位址空間配置隨機化（Address Space Layout Randomization, ASLR）

白話：每次執行改變模組、堆積與堆疊等位置。

位置／功能／機制：載入器與作業系統為各區域選擇隨機基底，提高預測控制目標的成本。

結果／證據：多次啟動的模組基底與平台設定可證明啟用情形；資訊洩漏會削弱效果。

不要混淆：它不修正記憶體錯誤，也不單獨阻止控制流偏離。

資料執行防護（Data Execution Prevention, DEP）

白話：阻止資料頁面直接當處理器指令執行。

位置／功能／機制：作業系統頁面權限配合處理器不可執行位元，在取指時拒絕資料頁。

結果／證據：頁面映射與執行違規例外可證明攔截；不代表原越界寫入不存在。

不要混淆：不阻止重用既有可執行程式碼。

控制流完整性（Control-Flow Integrity, CFI）

白話：限制間接分支只能前往允許目標。

位置／功能／機制：編譯器、執行期或硬體在間接呼叫與回傳時檢查目標集合。

結果／證據：建置旗標、二進位屬性與違規事件可說明涵蓋；允許集合仍可能較寬。

不要混淆：精度與涵蓋範圍依平台而異。

亂數值（Nonce）

白話：協定中只使用一次或需符合特定唯一／不可預測要求的值。

位置／功能／機制：加密模式用它區分訊息，挑戰協定用它提供新鮮度，接收端依模式檢查或保存狀態。

結果／證據：金鑰識別、nonce、重啟與重複值可檢查生命週期；不可把公開 nonce 當秘密洩漏。

不要混淆：通常不必保密；需求由具體模式決定。

預言機（Oracle）

白話：可透過輸入與回應查詢秘密相關資訊的介面。

位置／功能／機制：解密、驗證或解析端把內部判斷映射成可區分的錯誤、時間、長度或成功狀態。

結果／證據：大量相似輸入與穩定回應差異可支持假說；差異存在不等於已能復原秘密。

不要混淆：不是特定工具或單一加密演算法。

側通道（Side Channel）

白話：由時間、功耗、快取或其他非功能輸出洩漏內部狀態。

位置／功能／機制：實作與硬體把秘密相關分支或資源使用轉成旁觀者可量測訊號。

結果／證據：受控輸入、樣本分布、硬體配置與統計檢驗可支持相關性；網路雜訊需排除。

不要混淆：功能結果正確不代表沒有側通道。

身分與存取管理（Identity and Access Management, IAM）

白話：定義雲端主體、角色、政策、信任與資源動作。

位置／功能／機制：雲端控制平面把帶身分的 API 請求與多層政策、條件及資源比對。

結果／證據：完整政策、信任關係、模擬結果與實際稽核呼叫可重建允許原因。

不要混淆：角色名稱不等於有效權限；需分析政策組合。

混淆代理人（Confused Deputy）

白話：高權限服務被誘導替低權限呼叫者操作不該碰的資源。

位置／功能／機制：委派服務沒有把呼叫者、租戶、目標資源與授權關係綁定，於是借出自身能力。

結果／證據：原呼叫者、代理身分、資源擁有者與雲端稽核鏈可顯示跨界結果。

不要混淆：服務可能完全按設計執行，只是授權設計錯誤。

容器逃逸（Container Escape）

白話：容器內程序跨過隔離取得主機或鄰近工作負載能力。

位置／功能／機制：共享核心上的名稱空間、能力、掛載、裝置與系統呼叫政策原本限制程序；錯誤設定或核心弱點使邊界失效。

結果／證據：容器設定、核心事件、節點程序與控制平面稽核可顯示跨界；容器內 root 不必然等於主機 root。

不要混淆：容器不是硬體虛擬機器。

角色型存取控制（Role-Based Access Control, RBAC）

白話：把允許動作分配給角色，再把主體綁到角色。

位置／功能／機制：企業應用、雲端與叢集控制平面在請求時展開角色、動作、資源與條件。

結果／證據：角色規則、綁定、准入結果與 API 稽核可重建有效權限；間接建立能力也要展開。

不要混淆：建立某種資源的間接能力可能遠大於動詞名稱。

邊界閘道協定（Border Gateway Protocol, BGP）

白話：自治系統之間交換網路前綴可達路徑。

位置／功能／機制：網際網路域間路由控制平面依前綴與路徑屬性選路，再由資料平面轉送封包。

結果／證據：BGP 更新、AS 路徑、多觀測點與流量變化可顯示導向；路由異常不單獨證明惡意。

不要混淆：路由宣告可達不證明應用端點身分。

網域名稱系統安全擴充（Domain Name System Security Extensions, DNSSEC）

白話：用簽章讓解析器驗證名稱資料來源與完整性。

位置／功能／機制：驗證解析器沿名稱委派鏈檢查簽章，將回覆標成安全、無簽章或驗證失敗。

結果／證據：查詢、回覆、金鑰、簽章期限與驗證狀態可說明判定。

不要混淆：不加密查詢，也不保證目的服務安全。

反射與放大（Reflection and Amplification）

白話：第三方服務把大回覆送到遭偽造的受害者來源位址。

位置／功能／機制：無連線服務未驗證來源，小請求觸發較大回覆，將多個反射者頻寬聚向受害者。

結果／證據：請求／回覆大小比、流量方向、偽造跡象與多來源分布可證明機制。

不要混淆：反射者可能是遭濫用而非原始攻擊者。

相依套件混淆（Dependency Confusion）

白話：套件解析器從錯誤來源選到同名或較高版本成品。

位置／功能／機制：套件管理器合併公私來源後依命名與版本規則選成品，未固定來源便可能替換內部相依。

結果／證據：解析來源、版本、下載位址、鎖定檔與成品材料清單可重建選擇。

不要混淆：不同於使用者拼錯套件名稱。

軟體材料清單（Software Bill of Materials, SBOM）

白話：列出成品包含的元件、版本與關係。

位置／功能／機制：建置或分析流程輸出供應鏈清冊，供漏洞查詢、授權盤點與事件影響分析。

結果／證據：元件識別、版本、關係、產生工具與成品雜湊可驗證清單對象。

不要混淆：清單本身不證明元件安全或建置未遭竄改。

指揮控制（Command and Control, C2）

白話：外部操作者與受控內部程序交換任務與狀態的通道。

位置／功能／機制：端點程序建立出口工作階段，接收任務並回報結果，使外部影響能持續。

結果／證據：程序、目的名稱、週期、資料量與後續端點動作需關聯。

不要混淆：固定週期和雲端目的也常見於合法遙測。

資料集結（Data Staging）

白話：在外傳前先搜尋、整理、壓縮或集中資料。

位置／功能／機制：檔案、資料庫或雲端資料由受控主體讀取，再形成暫存集合以便處理或傳輸。

結果／證據：查詢量、暫存檔、程序、資料分類與生命週期可證明集結；未必已跨邊界。

不要混淆：備份與報表也會集結資料，需看身分與目的。

資料外傳（Data Exfiltration）

白話：資料跨出原本授權的信任或管理邊界。

位置／功能／機制：網路、雲端分享、同步、實體媒介或應用介面把資料交給未授權控制域。

結果／證據：資料讀取、程序、目的端、傳輸量、分享權限與授權紀錄共同證明跨界。

不要混淆：大量傳輸不必然是外洩；需證明資料、主體、目的地與授權。
