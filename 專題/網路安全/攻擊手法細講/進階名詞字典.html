同源政策（Same-Origin Policy, SOP）

白話：瀏覽器以方案、主機與連接埠限制不同來源文件互讀。

位置／機制：瀏覽器文件與指令碼隔離。

不要混淆：限制讀取不等於阻止送出跨來源請求。

跨網站指令碼（Cross-Site Scripting, XSS）

白話：不可信資料被瀏覽器當成目標網站來源下的程式。

位置／機制：輸出編碼、文件解析與指令碼執行邊界。

不要混淆：不是「任何含標記的輸入」。

跨網站請求偽造（Cross-Site Request Forgery, CSRF）

白話：誘使瀏覽器帶著既有憑證向另一網站做非預期動作。

位置／機制：瀏覽器自動憑證與伺服器動作授權。

不要混淆：攻擊者不一定讀得到回應。

伺服器端請求偽造（Server-Side Request Forgery, SSRF）

白話：讓後端替攻擊者連到其原本不可達的位置。

位置／機制：後端網址取回、名稱解析、重新導向與出口。

不要混淆：只檢查網址字串不等於驗證最終目的位址。

HTTP 請求不同步

白話：前後端對同一位元組流的請求邊界判斷不同。

位置／機制：代理、負載平衡器與應用伺服器解析。

不要混淆：超文字傳輸協定（Hypertext Transfer Protocol, HTTP）的正常管線化不是漏洞。

Web 快取污染（Web Cache Poisoning）

白話：讓共享快取保存受攻擊者影響的回應並交給其他人。

位置／機制：快取鍵、變異輸入與回應可快取性。

不要混淆：只影響攻擊者自己的私人快取通常不構成跨使用者污染。

開放授權第二版（OAuth 2.0）

白話：讓資源擁有者把有限權限委派給客戶端。

位置／機制：授權伺服器、客戶端、資源伺服器與權杖。

不要混淆：核心用途是授權，不是單獨定義使用者登入。

開放識別連線（OpenID Connect, OIDC）

白話：在 OAuth 2.0 上加入可驗證的登入身分結果。

位置／機制：識別提供者、識別權杖與依賴方。

不要混淆：仍須驗證簽發者、受眾、時間與流程狀態。

JSON 網頁權杖（JSON Web Token, JWT）

白話：可攜帶宣告並附簽章或加密保護的權杖格式。

位置／機制：聯合身分與介面授權。

不要混淆：格式不是協定；簽章有效也不代表用途正確。

簽發者（Issuer）

白話：聲稱產生並對權杖負責的身分系統。

位置／機制：權杖宣告、金鑰與中繼資料信任。

不要混淆：金鑰可驗證不代表簽發者就是預期租戶。

受眾（Audience）

白話：權杖預定要交給的服務或資源。

位置／機制：資源伺服器驗證政策。

不要混淆：同一簽發者給另一服務的權杖不可直接通用。

具證明金鑰的授權碼交換（Proof Key for Code Exchange, PKCE）

白話：讓兌換授權碼者證明自己持有發起流程時的秘密材料。

位置／機制：授權請求與權杖交換綁定。

不要混淆：它不取代重新導向、狀態與受眾驗證。

Kerberos

白話：用金鑰分配中心與票證進行網路身分驗證的協定。

位置／機制：企業目錄、使用者／服務票證與工作階段金鑰。

不要混淆：票證有效不表示來源主機或使用情境正常。

雜湊重放（Pass-the-Hash）

白話：直接使用可重用驗證材料完成協定，不先還原明文密碼。

位置／機制：舊式挑戰回應驗證。

不要混淆：不同於離線猜測密碼。

票證重放（Pass-the-Ticket）

白話：使用遭取得且仍有效的 Kerberos 票證冒用主體。

位置／機制：票證快取、服務票證與票證授予票證。

不要混淆：票證使用本身是正常流程，異常需靠情境判斷。

驗證轉送（Authentication Relay）

白話：把一端的即時驗證互動轉送給另一服務。

位置／機制：挑戰回應、通道綁定與訊息簽章。

不要混淆：不一定保存或破解驗證材料。

委派（Delegation）

白話：允許服務代表使用者呼叫下游服務。

位置／機制：票證、權杖與服務信任圖。

不要混淆：合法功能仍須限制下游、帳號與時間。

回傳導向程式設計（Return-Oriented Programming, ROP）

白話：把既有程式碼片段沿非預期控制流組合成行為。

位置／機制：原生程序控制流與間接轉移。

不要混淆：本課只用來解釋緩解，未提供片段鏈構造。

位址空間配置隨機化（Address Space Layout Randomization, ASLR）

白話：每次執行改變模組、堆積與堆疊等位置。

位置／機制：載入器與作業系統記憶體配置。

不要混淆：資訊洩漏可能降低其效果；它不修正記憶體錯誤。

資料執行防護（Data Execution Prevention, DEP）

白話：阻止資料頁面直接當處理器指令執行。

位置／機制：頁面權限與處理器不可執行位元。

不要混淆：不阻止重用既有可執行程式碼。

控制流完整性（Control-Flow Integrity, CFI）

白話：限制間接分支只能前往允許目標。

位置／機制：編譯器、執行期與硬體控制流保護。

不要混淆：精度與涵蓋範圍依平台而異。

亂數值（Nonce）

白話：協定中只使用一次或需符合特定唯一／不可預測要求的值。

位置／機制：加密、挑戰與重放防護。

不要混淆：通常不必保密；需求由具體模式決定。

預言機（Oracle）

白話：可透過輸入與回應查詢秘密相關資訊的介面。

位置／機制：錯誤、時間、長度或成功／失敗差異。

不要混淆：不是特定工具或單一加密演算法。

側通道（Side Channel）

白話：由時間、功耗、快取或其他非功能輸出洩漏內部狀態。

位置／機制：實作、硬體與共享資源。

不要混淆：功能結果正確不代表沒有側通道。

身分與存取管理（Identity and Access Management, IAM）

白話：定義雲端主體、角色、政策、信任與資源動作。

位置／機制：雲端控制平面。

不要混淆：角色名稱不等於有效權限；需分析政策組合。

混淆代理人（Confused Deputy）

白話：高權限服務被誘導替低權限呼叫者操作不該碰的資源。

位置／機制：委派、租戶與資源所有權綁定。

不要混淆：服務可能完全按設計執行，只是授權設計錯誤。

容器逃逸（Container Escape）

白話：容器內程序跨過隔離取得主機或鄰近工作負載能力。

位置／機制：共享核心、能力、掛載、裝置與執行環境。

不要混淆：容器不是硬體虛擬機器。

角色型存取控制（Role-Based Access Control, RBAC）

白話：把允許動作分配給角色，再把主體綁到角色。

位置／機制：企業應用、雲端與叢集控制平面。

不要混淆：建立某種資源的間接能力可能遠大於動詞名稱。

邊界閘道協定（Border Gateway Protocol, BGP）

白話：自治系統之間交換網路前綴可達路徑。

位置／機制：網際網路域間路由控制平面。

不要混淆：路由宣告可達不證明應用端點身分。

網域名稱系統安全擴充（Domain Name System Security Extensions, DNSSEC）

白話：用簽章讓解析器驗證名稱資料來源與完整性。

位置／機制：名稱系統委派與簽章鏈。

不要混淆：不加密查詢，也不保證目的服務安全。

反射與放大（Reflection and Amplification）

白話：第三方服務把大回覆送到遭偽造的受害者來源位址。

位置／機制：無連線服務、來源驗證與回覆倍率。

不要混淆：反射者可能是遭濫用而非原始攻擊者。

相依套件混淆（Dependency Confusion）

白話：套件解析器從錯誤來源選到同名或較高版本成品。

位置／機制：套件來源、命名空間、版本與解析優先序。

不要混淆：不同於使用者拼錯套件名稱。

軟體材料清單（Software Bill of Materials, SBOM）

白話：列出成品包含的元件、版本與關係。

位置／機制：建置來源與供應鏈追溯。

不要混淆：清單本身不證明元件安全或建置未遭竄改。

指揮控制（Command and Control, C2）

白話：外部操作者與受控內部程序交換任務與狀態的通道。

位置／機制：端點程序、出口網路與工作階段。

不要混淆：固定週期和雲端目的也常見於合法遙測。

資料集結（Data Staging）

白話：在外傳前先搜尋、整理、壓縮或集中資料。

位置／機制：檔案、資料庫、雲端儲存與暫存程序。

不要混淆：備份與報表也會集結資料，需看身分與目的。

資料外傳（Data Exfiltration）

白話：資料跨出原本授權的信任或管理邊界。

位置／機制：網路、雲端分享、同步、實體媒介與應用介面。

不要混淆：大量傳輸不必然是外洩；需證明資料、主體、目的地與授權。
