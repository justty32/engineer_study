# 01 安裝與基本概念

這章說明怎麼把這份設定接上 Neovim、LazyVim 是什麼東西，以及幾個你一定要知道的基本觀念。

---

## 把這份設定接上 Neovim

Neovim 啟動時會去讀 `~/.config/nvim`。這份 repo 不放在那裡，所以要用 **symbolic link** 把它接過去：

```sh
# 先備份原來的設定（如果有的話）
mv ~/.config/nvim ~/.config/nvim.bak

# 建立 symbolic link
ln -s /path/to/my_lazyvim_settings ~/.config/nvim
```

把 `/path/to/my_lazyvim_settings` 換成你實際 clone 下來的路徑，例如 `~/repo/my_lazyvim_settings`。

做完之後，開 `nvim` 就會載入這份設定。第一次開會自動下載安裝所有 plugin，要等一下。

> 如果不用 symbolic link，改用複製或同步的方式也行，但那樣每次改了 repo 就要自己手動同步過去。

## LazyVim 是什麼

[LazyVim](https://github.com/LazyVim/LazyVim) 是一套 Neovim 的「預設組合包」，幫你把常見的 plugin（語法高亮、補全、檔案樹、模糊搜尋⋯⋯）都裝好、設好，讓你不用從零開始配置。

這份設定以 LazyVim 為底，再加上個人的自訂 plugin 和設定。

Plugin 的管理由 [lazy.nvim](https://github.com/folke/lazy.nvim) 負責。要看現在裝了哪些 plugin、更新、除錯，可以執行：

```
:Lazy
```

## Leader 鍵與 LocalLeader 鍵

很多快捷鍵都以 `<leader>` 或 `<localleader>` 開頭，這兩個是「前綴鍵」的概念。

- **`<leader>`** 是 `Space`（空白鍵）—— LazyVim 預設。大部分 LazyVim 內建功能都用這個，例如 `<leader>gg` 開 LazyGit、`<leader>ff` 搜尋檔案。
- **`<localleader>`** 在這份設定裡是 `,`（逗號）—— 在 `lua/config/options.lua` 設定的。Conjure REPL、C-Mera、codegen 的自訂鍵都用這個。

注意：`,` 原本是 Vim 的「反向重複上一次 `f`/`t` 動作」的鍵。把它設成 localleader 之後，那個功能就沒了。如果你很依賴那個功能，要知道這個取捨。

## 其他視覺設定

這份設定還開了幾個 options：

- **相對行號**（`relativenumber`）：游標所在那行顯示絕對行號，其他行顯示與游標的距離。跳行很方便，例如看到某行顯示 `5` 就知道要 `5j` 跳過去。
- **捲動邊界 8 行**（`scrolloff=8`）：游標靠近上下邊界時，畫面會先開始捲動，讓游標前後保持 8 行可視範圍。
- **100 欄標線**（`colorcolumn=100`）：第 100 欄有一條細線，提醒行長不要超過。

## 補全的 Tab 鍵行為

補全使用的是 blink.cmp，preset 設為 `super-tab`：按 `Tab` 選下一個補全項目，按 `Shift-Tab` 選上一個。這跟 LazyVim 預設略有不同，留意一下。
