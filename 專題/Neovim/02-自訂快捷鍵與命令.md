# 02 自訂快捷鍵與命令

這章把這份設定加的所有鍵和命令整理清楚，並說明每個是幹嘛的、什麼情況下用。

---

## 快速離開 Insert Mode：jk

在 insert mode 下快速按 `j` 再按 `k`，等同於按 `Esc`。

不用把手移到 Esc 鍵，在家鍵區就能完成。這是很常見的個人習慣設定。

## LazyVim 內建（這份設定沒有另外定義的）

以下是 LazyVim 本來就有的鍵，提醒一下，不用找設定檔：

| 鍵 | 功能 |
| --- | --- |
| `<leader>gg` | 開 LazyGit |
| `<C-s>` | 存檔（任何 mode 都能用） |
| `<C-方向鍵>` | 調整視窗大小 |

## C-Mera 工具

[C-Mera](https://github.com/kiselgra/c-mera) 是一套用 Common Lisp 語法寫 C/C++ 的工具——你寫 `.cmera` 檔，它幫你產生 `.c` 或 `.cpp`。

這份設定讓你在 `.cmera` 檔裡直接觸發 C-Mera、預覽或輸出產生的 C 程式碼。

### 快捷鍵

`<localleader>` 是 `,`。

| 鍵 | 模式 | 功能 |
| --- | --- | --- |
| `,cb` | Normal | 預覽 C-Mera 產生的程式碼（側邊視窗） |
| `,cw` | Normal | 把產生的程式碼寫成旁邊的 `.c` / `.cpp` 檔 |
| `,co` | Normal | 寫出並直接開啟產生的檔案 |

### 命令

| 命令 | 功能 |
| --- | --- |
| `:CmeraPreview [generator]` | 預覽 C-Mera 輸出 |
| `:CmeraWrite [generator]` | 寫出輸出檔 |
| `:CmeraOpen [generator]` | 寫出並開啟輸出檔 |
| `:CmeraBuild [generator]` | `:CmeraPreview` 的舊名別名（相容用） |

`[generator]` 是可選參數，指定要產生什麼語言，支援：`c`、`c++`、`cxx`、`cuda`、`glsl`、`ocl`、`opencl`。

不給 generator 時，設定會自動偵測：看檔案第一行有沒有 `cm: c++` 或 `cm: cxx` 這類標記，有的話就用那個；沒有就預設用 `c`。

### 預覽視窗的行為

預覽視窗（`,cb`）開在右側，按 `q` 關掉。**重複執行 `:CmeraPreview` 不會疊出多個視窗**，會更新同一個視窗的內容。就算把視窗關掉，背後的 buffer 還是保留著，下次開還是用同一個。

### .cmera 檔的 filetype

`.cmera` 副檔名會被自動辨識成 `lisp` filetype，所以語法高亮和 parinfer（括號補全）都會生效。但 `.cmera` 不做 format-on-save，因為它的縮排和括號結構要靠 parinfer 而不是 formatter。

## codegen 工具

codegen 是一套 Python 工具，能根據設定對原始碼做自動化的程式碼產生（code generation）。

這份設定讓你在 nvim 裡直接觸發 codegen，不用切出去跑命令列。

### 快捷鍵

| 鍵 | 模式 | 功能 |
| --- | --- | --- |
| `,cgr` | Normal | 對目前檔案執行 codegen（`run`） |
| `,cgd` | Normal | 對目前檔案執行 codegen dry-run（只預覽不寫檔） |
| `,cgl` | Normal | 列出可用的 rollback 備份 |
| `,cgR` | Normal | 還原目前檔案（`rollback`） |

注意大小寫：`r` 是 run，`R` 是 rollback。

### 命令

| 命令 | 功能 |
| --- | --- |
| `:CodegenRun [路徑...]` | 對指定路徑執行 codegen；不給路徑就用目前檔案 |
| `:CodegenDryRun [路徑...]` | dry-run 模式，只看結果不實際寫檔 |
| `:CodegenRollbackList [路徑...]` | 列出 rollback 備份 |
| `:CodegenRollback [路徑...]` | 從備份還原 |

### codegen 的路徑設定

這份設定優先用 `~/repo/codegen/src` 搭配 `~/repo/codegen/.venv/bin/python` 來跑 codegen，不需要把 codegen 安裝到全域。如果你把 codegen repo 放在別的地方，設環境變數：

```sh
export CODEGEN_REPO=/你的/codegen/路徑
```

沒設的話，fallback 是 `~/repo/codegen`。

執行結果會顯示在底部視窗，按 `q` 關掉。
