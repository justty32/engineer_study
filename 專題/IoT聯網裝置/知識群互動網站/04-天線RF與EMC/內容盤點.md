## 使用方式

- 每個模組包含：核心概念、來源對應、常見誤解、模型邊界、回饋素材。
- 「來源對應」只引用本次指定閱讀的五份筆記，避免把未盤點內容當成已驗證的教材來源。
- 回饋宜先指出計算或 gate 的結果，再說明工程上下一步；不要只顯示「正確／錯誤」。
- 互動結果是學習用的初篩，不取代板廠疊層資料、模組廠商 layout guideline、VNA、暗室、OTA、EMC 實驗室或認證機構判定。

## 1. `wave-region`：波長、電氣長度與遠場

### 核心概念

- 自由空間波長為 \(\lambda_0=c/f\)。頻率越高，波長越短，同一段走線的電氣長度越長。
- 介質會改變導波速度；教學模型以有效介電常數估算
  \(\lambda_g=\lambda_0/\sqrt{\varepsilon_{eff}}\)。
- 長度 \(\ell\) 相對於 \(\lambda_g\) 會造成相位變化：
  \[
  \phi=360^\circ\frac{\ell}{\lambda_g}
  \]
- 天線最大尺寸為 \(D\) 時，遠場距離的粗略邊界為
  \(r_F=2D^2/\lambda_0\)。這是在判斷區域，不是量測場地合格條件。
- 2.4 GHz、\(\varepsilon_{eff}=4\)、走線 50 mm、最大尺寸 80 mm、距離 1000 mm 的預設結果約為：\(\lambda_0=124.91\) mm、\(\lambda_g=62.46\) mm、相位 288.2°、\(r_F=102.47\) mm，觀測點落在遠場粗分區。

### 來源對應

- [A1 天線理論](../../../../電機/08-天線特化/A1-天線理論.md)：遠場條件 \(r>2D^2/\lambda\)、近場／遠場區分，以及遠場場的幾何關係。
- [A2 微波工程](../../../../電機/08-天線特化/A2-微波工程.md)：電氣長度 \(\ell/\lambda\) 的判準；走線達到波長可比尺度時不能只用集總電路直覺。
- [A3 傳輸線與波導](../../../../電機/08-天線特化/A3-傳輸線與波導.md)：微帶與 CPW 的有效介電常數、準 TEM 與色散。
- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：RF 走線要依板疊層確認，而非只套用自由空間波長。

### 常見誤解

- 「時脈只有幾 MHz，所以幾公分走線一定不用管傳輸線。」實際應先看上升時間與電氣長度。
- 「距離大於 \(2D^2/\lambda\) 就代表暗室或天線量測已符合標準。」該公式只作區域粗分。
- 「導波波長就是自由空間波長。」PCB 介質與幾何會改變有效速度，且 \(\varepsilon_{eff}\) 是近似量。
- 「相位接近 360° 等於訊號被消失。」相位週期本身不是功率損耗的量；還要看反射、損耗與終端條件。

### 模型邊界

- \(\lambda_g=\lambda_0/\sqrt{\varepsilon_{eff}}\) 假設單一有效介電常數，不描述頻散、銅損、介質損耗、彎角、過孔或模式轉換。
- 遠場邊界只用最大尺寸 \(D\) 作幾何估算，不描述 Fresnel 區細節、場地反射、探頭校正、極化或量測標準。
- 不可由此推導天線增益、效率、阻抗或 OTA 結果。

### 回饋素材

- 通過型：「以目前尺寸估算，觀測點超過遠場粗略邊界；這只表示可用遠場模型做第一步判斷，仍需依量測規範確認場地與距離。」
- 電氣長度提醒：「這段走線已不是零相位延遲的理想導線。請把阻抗、回流路徑與終端一起納入，而不要只看標稱時脈頻率。」
- 有效介電常數提醒：「這是準 TEM 的教學近似；實際線寬、介質厚度、銅厚與板材疊層會改變導波波長。」

## 2. `link-budget`：自由空間鏈路預算

### 核心概念

- 自由空間路徑損耗：
  \[
  FSPL=32.44+20\log_{10}(f_{MHz})+20\log_{10}(d_{km})
  \]
- 接收功率：\(P_R=P_T+G_T+G_R-L-FSPL\)。鏈路餘裕為
  \(margin=P_R-sensitivity\)，相對於需求的 headroom 為
  \(margin-required\ margin\)。
- 預設值的結果約為 FSPL 80.04 dB、接收功率 −68.04 dBm、餘裕 26.96 dB、headroom 16.96 dB，通過需求門檻。
- headroom 小於 0 dB 是阻擋；0–3 dB 是警告。餘裕不是「一定能連線」的保證。
- 天線增益與方向性、效率、極化、饋線損耗及安裝姿態共同影響有效鏈路。

### 來源對應

- [A1 天線理論](../../../../電機/08-天線特化/A1-天線理論.md)：Friis 傳輸式、有效面積、增益與效率的關係；實際環境還有多徑、繞射與大氣損耗。
- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：RF 饋線、天線淨空與實體佈局會影響天線效率與可用距離。
- [A2 微波工程](../../../../電機/08-天線特化/A2-微波工程.md)：前端 LNA、PA、濾波器與系統雜訊／線性度會改變鏈路的實際能力。

### 常見誤解

- 「有正的 link margin 就一定可用。」自由空間公式未包含遮蔽、多徑、干擾、封包重送、人體或機構吸收。
- 「天線標稱增益可以直接加進預算。」增益可能是特定方向、頻率、極化與量測條件下的值；整機安裝後可能改變。
- 「距離加倍只要少一點功率。」自由空間損耗隨距離平方變化，dB 形式為距離加倍增加約 6 dB。
- 「接收靈敏度是固定且與資料率無關。」實際靈敏度受頻寬、調變、編碼、封包錯誤率與接收器設定影響。

### 模型邊界

- 只適用於自由空間、視線與已知頻率／距離的第一階估算，不是室內、城市、地下或近人體的通道模型。
- 不含多徑衰落、遮蔽、繞射、干擾、極化失配、天線效率、連接器與線纜損耗的詳細模型；其中饋線損耗只能以輸入的簡化 loss 代表。
- 不評估吞吐量、封包錯誤率、重送時間、電池壽命或電信商覆蓋。

### 回饋素材

- 通過型：「目前自由空間預算有足夠 headroom，但它不是現場保證。請再加上環境衰落、極化、天線效率與實測封包表現。」
- 餘裕不足：「鏈路預算不足以支撐需求門檻。先檢查距離與頻率單位，再評估天線效率、饋線損耗、發射功率、接收靈敏度與環境衰落。」
- 天線提醒：「增加 dBi 不必然等於所有方向都變好；方向圖、安裝姿態與極化可能使實際覆蓋變差。」

## 3. `impedance-match`：阻抗失配

### 核心概念

- 對負載 \(Z_L=R+jX\) 與參考阻抗 \(Z_0\)，反射係數幅度為
  \[
  |\Gamma|=\left|\frac{Z_L-Z_0}{Z_L+Z_0}\right|
  \]
- 回波損失 \(RL=-20\log_{10}|\Gamma|\)，VSWR 為
  \(\frac{1+|\Gamma|}{1-|\Gamma|}\)，反射功率比例為 \(|\Gamma|^2\)。
- mismatch loss 為 \(-10\log_{10}(1-|\Gamma|^2)\)。
- 預設 50 Ω 系統接 75 Ω 純電阻負載時，\(|\Gamma|=0.200\)、RL 約 13.98 dB、VSWR 1.50、反射功率 4.00%、失配損耗約 0.18 dB。
- 判定：VSWR ≤ 2 通過，2–3 警告，>3 阻擋；完美匹配的 RL 以 `∞` 顯示，完全反射的 VSWR／損耗也以 `∞` 顯示但不把 Infinity 當數值輸出。

### 來源對應

- [A1 天線理論](../../../../電機/08-天線特化/A1-天線理論.md)：輸入阻抗由輻射電阻、損耗電阻與電抗構成；匹配可降低反射，但增益還受效率影響。
- [A2 微波工程](../../../../電機/08-天線特化/A2-微波工程.md)：反射係數、VSWR、Smith 圖、S11、集總／分布匹配、π 網路與頻寬取捨。
- [A3 傳輸線與波導](../../../../電機/08-天線特化/A3-傳輸線與波導.md)：特性阻抗、傳播常數、反射與駐波的傳輸線背景。
- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：RF 饋線通常以 50 Ω 受控阻抗及 π 型匹配位置實作。

### 常見誤解

- 「VSWR 越低就代表天線輻射效率越高。」低反射只代表饋入功率較少被反射，功率仍可能在損耗電阻、介質、屏蔽或機構中耗散。
- 「把所有天線都做成 50 Ω 就能完成匹配。」天線端的阻抗、饋線、連接器、匹配元件與量測參考面必須一起看。
- 「回波損失很高，所以頻寬也很寬。」匹配網路常有頻寬與匹配品質的取捨；Bode–Fano 邊界提醒不能同時追求任意完美與寬頻。
- 「S11 好看就是空間中一定輻射得好。」仍需測量效率、增益、方向圖與極化。

### 模型邊界

- 公式假設單一頻率、明確的實數 \(Z_0\) 與負載阻抗，不模擬匹配網路的寄生、元件 Q、頻率掃描、校正參考面或連接器不連續。
- 不由 VSWR 單點結果推導天線頻寬、效率、增益、方向圖、極化或整機 OTA。
- 完美匹配與完全反射是邊界案例；顯示用符號要避免讓 `Infinity` 污染後續計算。

### 回饋素材

- 通過型：「此點的反射與 VSWR 落在教學門檻內；下一步仍要確認天線效率、頻寬、方向圖與整機安裝後的 S11。」
- 阻擋型：「VSWR 超過目前門檻，代表反射過大。檢查 50 Ω 參考、饋線幾何、連接器、匹配元件與天線周圍環境。」
- 完美匹配型：「理想模型中沒有反射；實物仍會有導體、介質、連接器與量測誤差，不應把此結果解讀成零損耗。」

## 4. `rf-layout`：RF 饋線與 layout gate

### 核心概念

- Gate 固定順序：受控阻抗 → 連續地平面 → 短且無殘段 → 接地過孔／連接器 launch → π 型匹配 → 天線淨空 → 模組廠 guideline。
- PCB 與晶片天線的七項都必須完成；外接天線不要求天線淨空，但其餘六項仍需完成。
- 任何一項缺失即阻擋，不以總勾選數抵銷第一個缺口。
- RF 走線宜短、避免不必要過孔與直角，參考地要連續；實際線寬、間距與過孔數量由板疊層與模組規範決定。
- 回流路徑若跨越平面裂縫而繞遠，迴路面積增大，可能增加反射、串擾與 EMI。

### 來源對應

- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：4 層板地平面、回流路徑、RF 50 Ω microstrip／CPWG、短線、π 匹配、keep-out 與 guideline。
- [A3 傳輸線與波導](../../../../電機/08-天線特化/A3-傳輸線與波導.md)：微帶、CPW、準 TEM、彎角／step／via 不連續與過渡的反射／模式轉換。
- [A2 微波工程](../../../../電機/08-天線特化/A2-微波工程.md)：電氣長度、分布參數與匹配網路。

### 常見誤解

- 「只要總共勾了五項就算通過。」RF layout 是鏈式條件，關鍵缺口不能用其他項目抵銷。
- 「線寬套用網路上的 50 Ω 表格即可。」線寬依介質厚度、介電常數、銅厚、阻焊與結構而變，應由板廠疊層確認。
- 「天線下方鋪地可以增加屏蔽，所以一定比較好。」對許多 PCB／晶片天線，keep-out 受破壞會失諧或降低效率；需依天線拓樸與廠商規範判斷。
- 「分割數位地與類比地越多越乾淨。」不恰當分割會切斷回流；通常先以分區與連續地平面控制，而非任意割地。
- 「外接天線沒有 keep-out，所以 RF 佈局其餘項目可省略。」饋線、接地、匹配與連接器 launch 仍會影響結果。

### 模型邊界

- Checkbox gate 只確認設計意圖是否被檢查，不驗證實際線寬、阻抗、via 電感、連接器品質、板廠製程或量測數據。
- 不推導特定疊層的阻抗；不能取代板廠阻抗計算、TDR、VNA、近場掃描或模組廠實體 guideline。
- `chip`、`pcb`、`external` 是教學分類；真實天線可能同時受外殼、電池、排線、顯示器與人體影響。

### 回饋素材

- 第一缺口：「第一個尚未閉合的 gate 是『受控阻抗』。先取得板廠疊層與目標阻抗，再決定線寬、間距及參考平面。」
- 回流缺口：「請確認 RF 線下方有連續參考地；跨平面裂縫會迫使回流繞路，增加迴路面積與 EMI 風險。」
- 匹配缺口：「保留 π 型匹配位置是為了讓原型量測後可調，不代表放上三個元件就一定匹配。」
- guideline 缺口：「模組廠的天線淨空、接地過孔與連接器配置是整合條件；完成 gate 後仍需照原廠圖面逐項核對。」

## 5. `antenna-choice`：天線型式初篩

### 核心概念

- PCB 走線天線：成本低、易整合，但佔板面、需調諧且容易受周邊影響。
- 晶片天線：體積小，但對 keep-out、匹配、板材與機構環境敏感。
- 外接天線：通常較穩定、較容易處理機構與認證，但成本、連接器、線纜與空間代價較高。
- 初篩先看五個條件：外殼、可用空間、是否沿用預認證、調諧能力、成本彈性。
- 預設條件 `plastic + tiny + reuse + limited + low` 的結果是「認證清單內的外接天線」，備選為晶片天線。
- 決策順序的教學意義：金屬外殼或「沿用認證但調諧能力有限」時優先外接；小空間且有 VNA 時優先晶片；空間足、有 VNA 且成本敏感時可考慮 PCB。

### 來源對應

- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：PCB、晶片、外接天線的取捨；外接天線的 IPEX／u.FL → SMA 及 keep-out／匹配要求。
- [量產：測試與法規認證](../../量產-測試與法規認證.md)：預認證模組通常綁定天線清單、增益與整合條件，換天線可能需要重測。
- [A1 天線理論](../../../../電機/08-天線特化/A1-天線理論.md)：patch、PIFA、偶極、單極、頻寬、增益、效率與量測流程。

### 常見誤解

- 「體積最小就是最佳天線。」尺寸只是條件之一，效率、頻寬、淨空、機構與認證風險同樣重要。
- 「預認證模組讓任何天線都能直接沿用。」預認證通常受指定天線清單、增益、位置、屏蔽與市場範圍限制。
- 「PCB 天線免費，所以總成本最低。」調諧、重板、暗室與認證迭代成本可能超過元件成本差異。
- 「外接天線穩定，所以不需要量測。」線纜損耗、連接器、外殼、安裝方向與整機環境仍要確認。

### 模型邊界

- 決策樹只做架構初篩，不計算實際共振頻率、效率、方向圖、極化、SAR、線纜損耗或機構耦合。
- `reuse` 只表示「可能沿用既有認證路線」，不是對特定市場或整機的法律結論。
- `vna` 代表具備調諧量測能力的前提，不代表已完成暗室、OTA、EMC 或量產一致性驗證。

### 回饋素材

- 初篩結果：「這是架構初篩，不是最終選型。請接著核對工作頻段、天線清單、最大增益、機構位置、線纜損耗與實測效率。」
- 外接天線取捨：「外接天線可降低板上天線與機構耦合的風險，但會引入連接器、線纜、成本與結構配置。」
- PCB／晶片提醒：「兩者都需要依板疊層與 keep-out 實體調諧；沒有 VNA 或可調匹配位置時，風險會上升。」

## 6. `detuning`：介質負載與失諧

### 核心概念

- 以固定幾何的簡化比例模型估算介質變化造成的共振頻移：
  \[
  f_{new}=f_0\sqrt{\frac{\varepsilon_{before}}{\varepsilon_{after}}}
  \]
- \(\varepsilon\) 增加時，模型預測共振頻率下降；頻率位移為 `new − original`。
- 原本頻帶用 \(f_0\pm BW/2\) 粗略表示，再檢查新頻率是否落在頻帶外。
- 預設 \(f_0=2400\) MHz、介電常數由 2.5 變 3.2、頻寬 100 MHz，估算新頻率約 2121.32 MHz、位移 −278.68 MHz、−11.61%，落在原頻帶外並阻擋。
- 可能的介質／環境負載包括外殼、電池、顯示器、泡棉、排線、手掌與人體；方向與幅度需靠實體設計與量測確認。

### 來源對應

- [A1 天線理論](../../../../電機/08-天線特化/A1-天線理論.md)：天線性能受機械位置與周邊結構影響；設計流程需模擬、製造、量測與修正。
- [A3 傳輸線與波導](../../../../電機/08-天線特化/A3-傳輸線與波導.md)：介質、有效介電常數、色散與介質損耗會改變導波結構。
- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：天線 keep-out，及電池、金屬、周邊元件造成失諧與效率下降的實務風險。

### 常見誤解

- 「頻率位移方向正確，就能直接修正天線尺寸。」真實結構還有場分布、耦合、損耗、寄生與多個共振模態。
- 「外殼材料只影響天線，不影響認證與機構。」外殼改動可能同時影響 RF、EMC、SAR、標示與整機測試範圍。
- 「加寬頻帶就能消除所有失諧。」寬頻設計仍有效率、尺寸、匹配與干擾取捨，且失諧幅度可能超出可用頻帶。
- 「VNA 的 S11 谷值移動就是 OTA 一定等比例變差。」匹配與輻射效率並非同一量，需配合效率、增益與 OTA 量測。

### 模型邊界

- 固定幾何、單一有效介電常數的比例式只顯示方向與敏感度，不模擬實際 3D 結構、耦合、材料損耗、手握姿態、頻寬變化或多模態。
- `band-edge` 是原始頻帶的教學邊界，不等於法規頻段、通訊協定頻寬或天線規格。
- 不可取代 VNA、全波模擬、暗室、OTA、近人體評估或整機調諧。

### 回饋素材

- 頻帶外：「簡化模型預測共振移到原頻帶外，表示機構／介質負載值得優先調查；請用實體樣品與 VNA 驗證，不要直接把此位移當成修板尺寸。」
- 頻帶內：「目前估算仍在原頻帶內，但不代表效率、VSWR、增益與頻寬都符合；周邊材料與安裝姿態仍需測量。」
- 模型提醒：「這裡只呈現介電常數變化的方向與敏感度，實際結果會受幾何、距離、損耗與耦合共同影響。」

## 7. `edge-emi`：Edge rate 與 EMI 邊界

### 核心概念

- 數位訊號的高頻內容主要受邊緣速度影響；不能只看標稱 clock frequency。
- 教學 knee frequency：\(f_{knee}=0.5/t_r\)。再用有效介電常數估算導波波長
  \(\lambda_g=c/(f_{knee}\sqrt{\varepsilon_{eff}})\)，臨界長度取 \(\lambda_g/10\)。
- `edge-length-ratio = trace / critical length`：ratio ≥ 1 警告，≥ 2 阻擋。
- 預設上升時間 2 ns、\(\varepsilon_{eff}=3.5\)、走線 80 mm，knee frequency 250 MHz、導波波長約 641.0 mm、臨界長度約 64.1 mm、ratio 約 1.25，應以傳輸線／回流觀點處理。
- 降低不必要的 slew rate、縮小高頻迴路、維持連續地平面、適當端接與處理外接線，都是可能的工程對策。

### 來源對應

- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：上升時間比時脈更關鍵、受控阻抗、反射、串擾、完整地與 EMI 的迴路面積。
- [A3 傳輸線與波導](../../../../電機/08-天線特化/A3-傳輸線與波導.md)：高速數位互連就是傳輸線；反射、過衝、振鈴、串擾、眼圖與 TDR。
- [A2 微波工程](../../../../電機/08-天線特化/A2-微波工程.md)：頻率與電氣長度的分布參數觀點。

### 常見誤解

- 「100 MHz clock 的訊號只有 100 MHz。」2 ns 邊緣包含遠高於基頻的頻率成分。
- 「走線短就沒有 EMI。」是否短要相對於導波波長與回流路徑判斷；封裝、過孔與外接線也會形成輻射結構。
- 「只加電容就能解決 EMI。」額外負載可能改善邊緣卻引入振鈴、功耗、時序或電源完整性問題。
- 「分割地能隔離噪聲。」錯誤分割可能讓回流繞路，反而放大 EMI 與串擾。

### 模型邊界

- knee frequency 的係數與臨界長度是教學判準，不是所有介面、驅動器或法規測試的完整頻譜模型。
- 不含輸出驅動器、封裝、端接、連接器、平面共振、串擾網路、共模／差模轉換、屏蔽與量測探頭。
- ratio ≥ 1 只表示需要進一步以傳輸線與回流觀點處理，不直接等於一定輻射超標。

### 回饋素材

- 警告型：「這段長度已達簡化臨界長度以上；請檢查參考平面、回流是否連續、是否有 stub，並視介面需求評估端接與 slew rate。」
- 阻擋型：「長度約為臨界長度的兩倍以上，反射與 EMI 風險不可只靠數位邏輯頻率判斷；需要 SI／EMI 分析或量測。」
- 邊緣提醒：「控制 edge rate 可能降低高頻能量，但要同時驗證時序、眼圖、功耗與接收端容限。」

## 8. `compliance`：預認證與整機法規 gate

### 核心概念

- 預認證模組可縮小無線部分的工作量，但認證通常綁定市場、頻段、模組整合條件與允許天線清單。
- 固定 gate 順序：市場範圍 → 模組認證範圍 → 天線清單 → RF prescan → EMC prescan → SAR／暴露評估 → 文件。
- `same-integration` 需要市場、模組範圍、天線清單、EMC prescan、文件；天線變更、外殼變更、新市場另需 RF prescan；near-body=yes 一律另需 SAR／暴露評估。
- 第一個缺口即為阻擋，不以勾選總數抵銷。全部閉合只代表送測前 gate 完成，不代表已取得認證。
- 法規／測試範圍可能包括 FCC、CE／RED、NCC、MIC、SRRC、KC、EMC、RF、SAR、安規、RoHS／REACH；實際應依銷售地、產品型態與最新規範確認。

### 來源對應

- [量產：測試與法規認證](../../量產-測試與法規認證.md)：EVT／DVT／PVT／MP、DFT、ICT／FCT、RF 測試、屏蔽箱、預認證、各地法規、SAR、文件與時程。
- [硬體：PCB 設計實務](../../硬體-PCB設計實務.md)：模組預認證的選料、layout guideline、天線匹配、EMC／EMI／ESD 對策與產測可達性。
- [A1 天線理論](../../../../電機/08-天線特化/A1-天線理論.md)：增益、效率、極化、方向圖與量測項目是認證前理解天線狀態的基礎。

### 常見誤解

- 「模組有 FCC／CE／NCC 就等於整機自動通過。」整機仍可能需要 EMC、安規、標示、文件及特定 RF／SAR 評估。
- 「只要天線型號相同，換外殼不會影響測試。」外殼會改變天線失諧、方向圖、效率、EMC 與近人體暴露條件。
- 「RF prescan 通過就是正式認證。」prescan 是找問題與降低送測風險，不是主管機關核准。
- 「near-body 只跟手機有關。」任何靠近人體使用的 IoT 產品都應先確認暴露與 SAR／等效評估要求。
- 「文件最後再補即可。」DoC、測試報告、天線清單、整合條件、標示與產測追溯應在設計與量產流程中建立。

### 模型邊界

- Checkbox gate 不是法規判定器，也不代表選定市場的完整標準版本、頻段表、功率限制或測試方法。
- 不評估實際 RF 輸出、頻譜遮罩、雜散、抗擾度、安規、SAR 數值、標示內容或文件法律效力。
- 預認證沿用可能受天線增益、位置、屏蔽、韌體功率設定、外殼、線纜與市場條件限制；變更控制應交由合規工程師／測試實驗室確認。
- 這個學習模組不提供法律意見，也不取代主管機關、認證機構、電信商或測試實驗室的正式解釋。

### 回饋素材

- 第一缺口：「目前第一個未閉合的 gate 是『市場範圍』。先確認銷售地、產品類別、頻段與適用認證，再談能否沿用模組資料。」
- 天線變更：「天線不在既有允許清單內，不能假設模組預認證仍完整適用；請核對最大增益、位置、整合條件與是否需 RF 重測。」
- 外殼變更：「外殼是 RF 與機構共同變更，可能造成失諧、方向圖、EMC 或近人體暴露改變；至少安排 RF／EMC 影響評估。」
- near-body：「產品使用情境靠近人體，需另行確認 SAR／暴露評估要求；此 checkbox 不是 SAR 測試結果。」
- 全部閉合：「送測前 gate 已閉合，但這不是認證通過。仍需依目標市場完成正式測試、報告、標示與文件。」

## 跨模組回饋素材

### 由計算走向量測

1. 先用波長／電氣長度判斷是否必須使用傳輸線或場的觀點。
2. 用鏈路預算建立自由空間的數量級，再補上多徑、遮蔽、極化與效率。
3. 用阻抗匹配檢查反射，但把 S11 與輻射效率、增益分開看。
4. 用 RF layout gate 找出最早的設計缺口，再以疊層資料、VNA、TDR、近場或 OTA 驗證。
5. 機構材料或天線型式改動後，重新檢查失諧、整機性能與認證範圍。

### 適合在網站中反覆出現的提醒

- 「模型結果是方向與數量級，不是實體保證。」
- 「匹配良好不等於高效率；鏈路餘裕不等於現場覆蓋。」
- 「第一個 gate 缺口比勾選總數重要。」
- 「天線、機構、PCB、韌體功率設定與法規是同一個整機問題。」
- 「任何換天線、換外殼、換板疊層或換市場，都應重新確認變更影響。」
