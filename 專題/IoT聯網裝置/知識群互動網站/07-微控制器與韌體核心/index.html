HOW

用「程式動作 → 硬體狀態 → 外部證據」讀這門課

每章都把熟悉的 C／C++ 操作接回晶片：一個 pointer store 可能改變周邊暫存器，一次 interrupt 可能改變控制流，一個 timer event 可能直接觸發 ADC 或 DMA。閱讀時先說出你預期哪個 register／memory 會變，再決定用 debugger、邏輯分析儀或示波器驗證；三者看到的層級不同。

Debugger看 CPU、記憶體與暫存器狀態；停機可能改變即時行為。
邏輯分析儀看數位腳位的時序與解碼；看不到類比門檻裕度。
示波器看真實電壓、rise time 與雜訊；不自動知道 firmware 語意。
