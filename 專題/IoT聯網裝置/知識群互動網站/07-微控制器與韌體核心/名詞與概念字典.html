A

晶片與執行

微控制器（MCU, Microcontroller）

白話：把 CPU、Flash、RAM、GPIO、timer、ADC 與通訊周邊放進同一顆晶片的小電腦。

不要混淆：MPU 通常要外接 DRAM 並跑完整 OS；MCU 常跑 bare-metal 或 RTOS。

CPU／Core（處理器核心）

白話：負責取指令、解碼、運算與 load/store 的部分。

不要混淆：CPU 不是整顆 MCU；GPIO、ADC、DMA 是核心旁邊的周邊硬體。

Clock（時脈）

白話：週期性高低切換的同步節拍，告訴數位電路何時更新狀態。

不要混淆：clock frequency 不等於 C++ statement 每秒執行數，也不等於 timer 最終頻率。

Instruction／Machine code（指令／機器碼）

白話：CPU 能直接辨認的 bit pattern，例如載入、相加、儲存、跳轉。

不要混淆：一行 C++ 可能變成零條、一條或多條機器指令，取決於最佳化與目標架構。

ISA（Instruction Set Architecture，指令集架構）

白話：CPU 對軟體承諾的指令、register、例外與基本執行規則；ARM Cortex-M、RISC-V 都有自己的 ISA。

不要混淆：ISA 是介面規格，不是特定一顆晶片的全部周邊。

Firmware（韌體）

白話：編譯後燒進裝置 Flash，直接管理硬體啟動、周邊、時序與產品功能的軟體。

不要混淆：它仍是軟體；「韌」不是介於軟硬體之間的特殊物質。

B

記憶體與編譯

Address（位址）

白話：CPU 用來指定「要存取哪個位置」的數字。

不要混淆：位址不是內容；同一數值資料可以被放在不同位址。

Bus（匯流排）

白話：搬運位址、資料與讀寫控制的共享連接系統。

不要混淆：片內 memory bus 與板外 I²C bus 都叫 bus，但電氣、時序與用途完全不同。

Flash

白話：斷電仍保存的非揮發記憶體，常放程式與常數。

不要混淆：它不是無限次寫入的硬碟；需要先擦除，寫入慢且有磨耗。

SRAM／RAM

白話：程式執行時放變數、buffer、stack 的工作記憶體，斷電消失。

不要混淆：MCU 的 RAM 通常很小；成功編譯不代表最壞 stack 一定放得下。

Stack／Heap（堆疊／動態配置區）

白話：stack 自動保存呼叫 frame、區域變數與中斷現場；heap 供 allocator 動態分配。

不要混淆：兩者都用 RAM，但生命週期、失敗模式與上限分析不同。

Linker（連結器）

白話：把 object files 與 library 的符號、區段和位址組成最終 firmware image。

不要混淆：compiler 決定單個翻譯單元如何變成機器碼；linker 決定它們最後放哪裡。

Vector table（向量表）

白話：一張入口位址表，reset 與各種 exception／interrupt 用它找到 handler。

不要混淆：它不是 C++ `std::vector`，也不是數學向量。

C

周邊與腳位

Peripheral（周邊）

白話：CPU 旁邊負責特定工作的硬體狀態機，例如 GPIO、UART、timer、ADC。

不要混淆：它不一定在晶片外；MCU 的 peripheral 多半就在晶片內。

Register（暫存器）

白話：少量、固定寬度的狀態格。CPU register 給核心運算；peripheral register 給軟體控制硬體。

不要混淆：register 不是普通變數；周邊 register 讀寫可能有硬體副作用。

MMIO（Memory-Mapped I/O）

白話：把周邊 register 分配進 CPU 位址空間，讓 load/store 指令也能操作硬體。

不要混淆：位址看起來像 pointer，不代表目標是 RAM。

GPIO

白話：可設定成輸入、輸出、類比或交給其他周邊的通用腳位。

不要混淆：GPIO HIGH 是真實電壓與有限驅動電流，不是抽象 bool。

Pin mux／Alternate function（腳位多工／替代功能）

白話：晶片內部選擇器，決定同一支實體 pin 此刻接 GPIO、UART、SPI、timer 還是 ADC。

不要混淆：開了 UART clock 不代表 TX 已接到外部 pin；還要設定 pin mux。

Timer／Counter（計時器／計數器）

白話：跟著時脈或外部脈衝自動加數的硬體，能在指定數值產生事件。

不要混淆：它不是 `sleep()`；CPU 可同時做別的事。

ADC

白話：把輸入電壓相對 Vref 的位置量化成整數 code。

不要混淆：更多 bit 不會自動消除雜訊、參考誤差與前端問題。

PWM

白話：固定週期、調整高電位時間比例的數位方波。

不要混淆：PWM pin 不是直接輸出連續類比電壓；負載或濾波器看到平均效果。

D

事件、並行與時間

Polling（輪詢）

白話：CPU 反覆讀硬體狀態，主動問「好了沒」。

不要混淆：輪詢不一定錯；短、低速、啟動階段可能最簡單可靠。

Interrupt／ISR（中斷／中斷服務常式）

白話：硬體事件要求 CPU 暫停目前流程，跳到指定 handler 處理。

不要混淆：它不是另一顆 CPU，也不是一般 thread；ISR 仍佔用同一核心。

DMA

白話：專門在周邊與記憶體間搬資料的硬體單元。

不要混淆：DMA 不理解資料意義，也不免除 buffer ownership、cache 與完成事件管理。

Latency／Jitter（延遲／抖動）

白話：latency 是事件到反應隔多久；jitter 是這段時間每次變動多少。

不要混淆：平均很快不代表最壞 latency 符合 deadline。

Real-time（即時）

白話：結果不只要正確，也要在明確時間限制內完成。

不要混淆：即時不是單純 CPU 很快；可預測的慢系統也可能是即時系統。

Atomic（原子操作）

白話：其他執行流看不到「做到一半」的不可分割操作。

不要混淆：`volatile` 只影響 compiler 存取，不自動提供 atomicity。

E

啟動、除錯與可靠度

Reset

白話：把 CPU 與一組硬體狀態帶回規格定義的起始條件，再從 reset vector 開始。

不要混淆：reset 不一定切斷電源；power cycle 才是實際斷電重上。

Bootloader

白話：正式應用前先執行的小程式，負責選 image、驗證、更新與恢復。

不要混淆：startup code 建立 C runtime；bootloader 是可選的獨立 firmware 階段。

SWD／JTAG

白話：外部 debugger 與晶片核心溝通的硬體除錯介面，可燒錄、停機、單步與讀記憶體。

不要混淆：debugger 看到 register 值，不代表外部腳的類比波形一定正常。

HardFault

白話：Cortex-M 無法正常繼續某些錯誤時進入的 fault handler。

不要混淆：它不是單一原因；非法位址、bus error、stack 問題等都可能匯入。

Watchdog（看門狗）

白話：若軟體未在期限內證明健康，就強制 reset 的獨立 timer。

不要混淆：它是恢復機制，不是 bug 修復；仍需保存 reset cause 與故障證據。

Brown-out reset

白話：電源掉到不可靠區域時先重置核心，避免在電壓不足時亂執行。

不要混淆：它不能替代足夠的電源容量、走線與去耦。

CONCEPT

八組最容易混淆的概念

CPU register ≠ peripheral register一個在核心運算資料；一個是硬體周邊的控制／狀態入口。
Clock ≠ timerclock 是節拍來源；timer 是利用節拍自動計數的周邊。
Reset ≠ power cyclereset 回起始狀態但可能仍供電；power cycle 真正切斷再恢復電源。
Interrupt ≠ parallel execution單核心 ISR 只是插入同一條控制流，不是同時多做一件事。
volatile ≠ atomic前者限制 compiler 最佳化；後者保證操作不可被觀察到半成品。
Fast ≠ real-time快是平均效能；即時要求最壞情況仍趕上 deadline。
PWM ≠ DACPWM 是高低方波；DAC 直接產生連續電壓階級。
RS-485 ≠ ModbusRS-485 規定實體電氣；Modbus 規定封包與資料意義。
