Timer 是接在時脈上的硬體計數器

它會在 CPU 執行別的程式甚至睡眠時持續數。數到指定值可產生更新事件、翻轉腳位、觸發 ADC 或鎖存外部邊緣時間；這些動作不必等軟體剛好跑到某一行。

03

Capture、Compare、PWM 是同一個 counter 的不同用法

Input capture

外部邊緣到來時，把當前 counter 硬體鎖進 CCR；兩次差值就是週期或脈寬，不受 ISR 到達延遲污染。

Output compare

counter 等於 CCR 時，由硬體翻轉／置位／清除輸出或產生事件。

PWM

counter 在 CCR 前後輸出不同電位；改 CCR 就改 duty，週期仍由 ARR 決定。

PWM 不是類比電壓。腳位仍只有高／低；LED、馬達慣性或外部低通看到的是平均能量。接到 ADC 看則會看到方波，除非先濾波。

真正量的是Vin / Vref

Sample-and-hold

ADC 先用小電容接到輸入並充電。訊號源阻抗太高、取樣時間太短，電容來不及到達 Vin，數字會偏低或受前一通道影響。

Aliasing

取樣率不足時，高頻訊號會偽裝成較低頻。ADC 前的低通與 timer 觸發能控制頻寬與取樣時刻。

深讀

Timer 把 CPU 時間改成硬體事件圖

計時器／計數器（Timer/Counter）從 peripheral clock 經預除頻器（prescaler）得到計數節拍，再在 counter 到達 compare／auto-reload 時產生事件。事件可直接翻轉 PWM pin、觸發 ADC 或 DMA，不必靠 CPU 精準 `delay()`。

Timer 頻率例80 MHz clock，prescaler = 79 表示除以 80，counter tick = 1 MHz；ARR = 999 時每 1000 tick 更新一次，頻率約 1 kHz。實際是否用 ARR + 1、clock 是否倍頻，以晶片手冊為準。
PWM duty 例同一 1000-count 週期，compare = 250，邊緣對齊且 active-high 時 duty 約 25%。PWM 是數位方波，不是直接 0.825 V DAC；負載或低通濾波器才形成平均效果。
ADC 量化例12-bit ADC、Vref = 3.3 V，理想 LSB = 3.3/4096 ≈ 0.806 mV。code 2048 對應約 1.65 V；此值未含 offset、gain、Vref 誤差與雜訊。

取樣不是讀一個 register 那麼簡單

ADC 的 sample-and-hold 電容必須在 acquisition time 內由訊號源充到足夠接近輸入。來源阻抗太高、取樣時間太短時，code 會隨前一通道與取樣率偏移。Timer trigger → ADC sample → conversion complete → DMA 寫 buffer 可形成低 jitter 的量測鏈；CPU log 只看到結果值，無法證明取樣瞬間與外部波形對齊。

證據：示波器看 PWM pin 與類比輸入；以 timer trigger pin 或 debug pin 建立時間基準；buffer dump 看 ADC code。更多 bit ≠ 更準確，PWM 頻率高 ≠ 平均值更準，timer interrupt 準時 ≠ ISR 一定在同一瞬間開始。
