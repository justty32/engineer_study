## 本機驗收

| 項目 | 結果 | 證據 |
| --- | --- | --- |
| runtime 語法與相對資源 | 通過 | `node --check app.js`；HTML 只載入 `./styles.css`、`./app.js` |
| 8 個模組與 DOM 契約 | 通過 | 130 個唯一 ID；section、nav、complete、reset 鍵值皆為同一組 8 模組 |
| 預設公式與阻擋案例 | 通過 | Node 純函式 suite：8 模組預設值、RF／ESD／SI／ESR 與輸入錯誤案例 |
| 導覽、完成進度與重設 | 通過 | 最小假 DOM suite：導覽、ARIA、localStorage、全域進度、checkbox reset、空值錯誤 |
| 無外部執行期資源 | 通過 | HTML 無外部 `src`／`href`；無圖片、SVG、Canvas、CDN 或 API |
| UTF-8 與靜態檔案服務 | 通過 | `127.0.0.1:4175` 的 HTML／CSS／JS 均回傳 200 |
| 唯讀 verifier | 通過 | 找到的 rail bar 空白與手機數值換行問題已修正並完成回歸測試 |
| 桌面與 390px 實際渲染 | 待驗 | 本機未安裝瀏覽器時保留待使用者實機確認 |

## 模型邊界

- 本站公式是教學近似，不替代 regulator、電池、電容或通訊模組 datasheet 的 worst-case analysis。
- 疊層、RF、EMC、ESD 與 DFM 是 review gate，不是阻抗場解算、法規認證或量產 sign-off。
- 未下載瀏覽器、套件或其他執行期資產。
