# IoT 板級電源與 PCB 互動網站專案簡報

## 目標

把 IoT 板級硬體從「元件名詞」轉成可檢查的設計流程：先建立電源樹與負載裕度，再處理穩壓器熱、睡眠漏電、通訊脈衝、原理圖完整性、回流路徑、RF 佈局及製造 bring-up。

## 讀者與深度

- 讀者軟體能力強，但板級電源、PCB、SI/PI 與 RF layout 基礎不穩。
- 以大學基礎加實作判斷為主；公式只使用本地兩篇筆記可支撐的模型。
- 目標是知道「先算什麼、先量什麼、哪種錯誤會造成什麼症狀」，不代替 datasheet、板廠阻抗表或正式 EMC/RF 測試。

## 8 個模組

1. 電源樹與電流裕度。
2. LDO、buck 的效率、熱與 dropout。
3. 睡眠漏電、$I_q$ 與電池壽命。
4. 通訊脈衝、ESR、bulk cap 與 target impedance。
5. 原理圖、ERC、封裝、BOM 與測試點。
6. 疊層、完整地、回流路徑與 SI 風險。
7. 50 Ω 饋線、π 匹配、天線淨空與 vendor guideline。
8. EMC/ESD/DFM release gate 與 bring-up 診斷。

## 來源與非目標

- 來源只限 `硬體-電源與電池.md`、`硬體-PCB設計實務.md`。
- 不提供特定 IC 選型、實際 PCB trace 電流表、阻抗幾何公式或法規限值。
- 不把 checklist 通過稱為可製造、可認證或可量產保證。
- 不重做 IoT 整合工作台的連線、韌體狀態機與量產全貌。
