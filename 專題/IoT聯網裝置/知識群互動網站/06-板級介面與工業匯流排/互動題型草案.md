# 互動教學草案

原則：先教後用。原理頁使用無評分自由實驗，控制量一改，數值、現象與因果解釋同步改變；主線只在模型已建立後提供工程情境。

- 名詞翻譯器：名詞 → 白話動作 → 真實機制 → 實機可觀察現象。
- 上拉自由實驗：開漏放手／接地 → 回路是否閉合 → 節點電壓、限流與 RC 速度。
- 終端自由實驗：調負載 → 反射係數正負與振幅 → 匹配時能量進電阻成熱。
- I²C 參數實驗：調上拉電阻、電容與速度，預測上升時間；再做 NACK／卡線診斷。
- SPI 時序判斷：依資料表的 Mode 3 選取樣設定，錯誤時說明位元錯位原因。
- 介面取捨：多顆慢速感測器選 I²C；高速 Flash 選 SPI。
- RS-485 修復器：拓樸、終端、偏壓與 DE 切換共同產生診斷。
- Modbus frame builder：把人類文件地址轉成 PDU 起點，產生 CRC 與靜默時間。
- 跨層 incident：長線才出錯時，先量 A/B 波形而非重寫 parser。
