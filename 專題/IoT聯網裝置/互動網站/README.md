# IoT 聯網裝置互動學習網站

← [專題總覽](../index.md)｜[專案簡報](PROJECT-BRIEF.md)｜[建置規格](BUILD-SPEC.md)

這是一個零依賴、可離線運作的互動學習工作台。內容涵蓋系統分層、連線選型、功耗與瞬態供電、韌體狀態機、現場診斷與量產閘門。

## 本機啟動

在 repo 根目錄執行：

```bash
python3 -m http.server 4173 --directory '專題/IoT聯網裝置/互動網站'
```

瀏覽 `http://127.0.0.1:4173/`。網站只有 `index.html`、`styles.css` 與 `app.js` 三個執行期檔案，不需安裝套件。

## 模型邊界

- 連線排序是教學啟發式，不能取代現場涵蓋、資費、法規與認證評估。
- 電池壽命是平均電流與容量折扣的理想估算，未涵蓋溫度、老化、自放電與脈衝能力。
- 瞬態供電使用「電容獨力支撐短暫電流階躍」近似，正式設計仍須依 datasheet、電源動態響應與 PCB 佈局驗證。
- 量產清單不代表已取得 FCC、CE、NCC 或電信商認證。
