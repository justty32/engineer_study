## 驗收資訊

- 日期：2026-08-09

- 執行期檔案：`index.html`、`styles.css`、`app.js`

## 通過項目

- `node --check app.js` 通過。
- `xmllint --html --noout index.html` 通過。
- 54 個 HTML `id` 無重複；`app.js` 使用的 36 個 ID 選擇器皆有對應元素。
- 8 個學習模組及相對路徑 `./styles.css`、`./app.js` 皆存在。
- 本機 HTTP 回應：HTML、CSS、JavaScript 均為 `200`，MIME type 正確。
- 執行期檔案不含外部 URL、CDN、遠端字型、`fetch`、XHR 或 WebSocket。
- 預設功耗案例交叉計算為 `0.4799 mA`、`3334.0 h`、`138.9 d`。
- 預設瞬態案例交叉計算為總壓降 `0.238 V`、最低電容 `363.636 µF`。
- 表單控制具有 label；自訂系統節點具有 button role、鍵盤 Enter/Space 事件與可見 focus。
- `700px` 以下改為單欄內容、可橫向捲動的模組導覽與垂直系統圖；靜態檢查未發現固定寬度造成的明顯溢位。
- Pages 組裝測試只產生入口頁與 `iot-device/` 下三個執行期檔案，不發布筆記及規劃文件。
- 唯讀驗收代理回報的無效模組錯誤分支已修正；最終靜態覆核無未解決 findings。

## 未驗證與限制

- 本機沒有 Playwright、Chromium、Chrome 或其他可用瀏覽器，因此未執行 `1440×900`、`390×844` 真實渲染截圖、console 與 localStorage 瀏覽器驗證。
- 未連接真實 IoT 裝置、電源量測設備、無線網路或雲端服務；所有結果皆為教學模型。
- 連線排序、電池壽命、瞬態供電與量產閘門的適用邊界見 [README](README.md)。

## 交付判定

允許發布靜態初版。線上 Pages 發布後需以手機實際開啟，確認無水平頁面溢位、文字重疊及控制項不可操作；若任一項失敗，視為發布後缺陷並修正。
