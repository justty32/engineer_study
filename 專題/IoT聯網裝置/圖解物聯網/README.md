# 物聯網小小實驗室

以 IoT 專題為骨架、用一盆植物串連的 ELI5 圖解網站，與舊網站並存。

- [本地入口](dist/index.html)：直接開啟即可，不需安裝或建置。
- [GitHub Pages 公開入口](https://justty32.github.io/engineer_study/iot-little-lab/)：已發布，可直接開啟。
- [Sites 入口](https://iot-little-lab.bronzetern2.chatgpt.site)：已發布，保留 Sites 的私人存取範圍。

主線依序為感測、MCU、電力、連線、MQTT、安全、可靠性。七課可以任意選；首頁另有完整的端到端小實驗，小字典可搜尋。手機長圖提供局部橫移，所有控制可用鍵盤。使用原生 HTML、CSS、JavaScript 及原創 inline SVG，無外部執行期依賴。

[專案簡報](PROJECT-BRIEF.md) 說明讀者與教學邊界，[建置契約](BUILD-SPEC.md) 保存介面與互動規格；[來源與模型限制](dist/sources.html) 提供查核路徑。
