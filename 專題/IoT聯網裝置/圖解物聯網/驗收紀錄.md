## 通過項

**互動與數值：通過。** 桌機 183 項、手機 183 項狀態斷言，以及導覽、鍵盤、字典與離線共 91 項檢查通過。首頁測試本機讀值與手機最後資料分離、斷電、斷網、恢復後須另行傳送及重設；感測器測試兩端點、中間值和斷線不可當零；判斷頁測試小於、等於、大於界線及無效讀值。電力測試 3 種週期 × 3 種容量、開路及重設；網路測試兩模式下的 16 種連線組合；訊息測試主題、QoS 與確認遺失的組合，以及恢復會話後可能重複；安全測試 8 種來源、完整性與驗簽組合；恢復頁測試緩存溢出、丟最舊、送出後清空、重設及重新載入不持久化。

**獨立重算：通過。** 以各狀態的時間比例加權重算，60 秒週期的電池端平均電流為 `15×0.2/60 + 120×1/60 + 0.02×58.8/60 = 2.0696 mA`；2000 mAh 理想續航為 `2000/2.0696/24 = 40.2654` 天，畫面顯示 40.27 天。10 秒與 300 秒分別得到 12.3176、0.42992 mA，以及 6.77、193.83 天。ADC 依明示的端點線性教學模型重算：刻度 0／40／50／100 對應 0／1.32／1.65／3.30 V 與代碼 0／102／128／255；不是宣稱所有實際 ADC 的轉換門檻皆如此。退避步進為 2、4、8、16、32、60、60 秒。

**導覽與離線：通過。** 最終 10 頁在兩種視窗共 20 次載入，179 個相對連結與錨點全部存在；逐課實際點擊下一頁、返回首頁，沒有孤兒頁。18 條字典搜尋涵蓋英文大小寫、中文、找不到與清空。10 頁另以 `file://` 在離線瀏覽器環境開啟，主內容正常、無 JavaScript 例外。外部參考文獻只有使用者可點的連結，執行期外部請求為零。

**程式與編碼：通過。** 11 份 JavaScript 的 `node --check` 均成功；UTF-8 strict、BOM／替換字元／控制碼／私用區、LaTeX 殘留及已列高頻簡體用字掃描均無異常。最終瀏覽器 console error、頁面 JavaScript 例外、HTTP 錯誤、重複 id 與缺失表單標籤均為零。

**圖解與版面：通過 headless 檢查。** 全頁無整頁橫向溢出。20 張完整頁面截圖已產生，代表性的首頁、感測、電力、網路、訊息與安全圖另經目視檢查；圖中的箭頭、斷點、格子、供電回路與信任閘門承擔因果教學，控制會同步改變圖、數值與原因。桌機深底文字可讀。手機長圖保留字級，放在有名稱的局部橫移區，不把整頁撐寬；首頁另提供本機／手機讀值摘要。320 與 390 像素首頁控制標籤已確認不逐字直排。

**鍵盤與減少動態：通過。** 原生控制有標籤；range 可用方向鍵、checkbox 可用空白鍵、寄送可用 Enter，焦點可見且操作後保留。七課的「動手試」在手機首屏可見，按下後焦點移到控制台、第一個控制進入視窗，Tab 可繼續操作；「看圖解」可回到圖區，方向鍵能橫移。SVG 有 title／desc 或明確裝飾標記，狀態有文字替代。`prefers-reduced-motion: reduce` 下沒有動畫，頁面捲動採 auto。

**舊站保留：通過。** 以新站首版 commit 的父版本為基準檢查 `互動網站/` 與 `知識群互動網站/`，差異為零。新站使用獲授權的獨立 `lab.css`；整合者另執行共用樣式檢查，17 門舊課相同、0 漂移、0 缺檔，exit 0。

## 已修正與未通過項

驗收曾發現共用 SVG 文字樣式覆蓋深底白字、手機圖面縮字與操作入口太低、首頁 checkbox 標籤被壓成直排，以及瀏覽器預設 favicon 請求 404。建置者已修正；最後一輪針對字級、手機捷徑、320／390 控制布局、全部頁面請求與 console 再驗，均通過。驗收者未自行修改產品。

**全庫工作流 lint：失敗，屬既有問題。** `bash wf/tools/wf-lint.sh wf` 仍有兩個歷史審稿引述路徑壞連結，位於 `05-電機特化05-09與對照表-md.md` 與 `06-電子-md.md`。整合者已將兩檔與原 HEAD 做 bytes 比對，確認本次未改；新增壞連結為零。本案不改寫歷史審稿，也不宣稱全庫 lint 全通過。

原文查證已修正三處：安全 OTA 不可把 CRC 當作來源簽章，並補試啟動確認及受安全版本政策限制的回滾；睡眠電流是否可用電表量測，應依 µA 檔位、解析度、準確度與負擔電壓判斷；退避加入隨機倍率後須再次截限，才真的不超過 60 秒。依據分別為 Espressif 官方安全／OTA 文件、Fluke 87V 官方規格與手冊，以及 `60×1.2=72` 的直接算術。詳證存於 `/tmp/iot-source-audit.txt`，修正落在上層三份既有筆記；網站模型來源另見 [來源頁](dist/sources.html)。

## 待人工與已知限制

**真人／實機驗收：待人工。** 尚未用真正手機觸控、Safari、Firefox、螢幕閱讀器或真人學習流程測試。手機長圖需要左右移動；圖與控制有時需切換視窗位置。字典提供縮寫回查，但完全零基礎讀者是否能獨立理解全部術語，仍需實際閱讀回饋。這些項目由整合者登記至專題 IoT 實機驗收清單。

所有實驗都是確定性教學模型，沒有接真感測器、MQTT 服務或執行密碼學簽章；不能拿結果當產品續航、量測準確度、無線距離或安全保證。畫面有本地來源、模型假設與限制，來源頁附一手資料及開源教材參考。
