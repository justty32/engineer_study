# 物聯網小小實驗室：專案簡報

這是一份依 IoT 專題重做、獨立於既有網站的圖解入口。成品位於 [dist/index.html](dist/index.html)，教學主線是一盆會傳訊息的植物。2026-10-11 使用者授權新站、自由技術棧、多 agent、push 與部署，並要求 ELI5、大量圖解及查證後修正原文。

## 讀者基線

不假設理解電路、通訊或韌體。讀者有軟體經驗，但每頁先用生活問題與一句因果建立心智模型，再操作。圖面傳達主要資訊，正文只保留必要說明。全站繁體中文，首見術語附英文，字典供回查；類比會收回真實機制。

## 目標能力與教學邊界

讀者可沿「感測 → 微控制器 → 連線 → 訊息 → 手機」描述資料流；知道電力是整條鏈的前提；能調閾值、估平均電流、分辨區域連線與網際網路、解釋訂閱與重送、判斷更新的信任以及斷線後如何恢復。所有數字是明示的教學模型，不是特定產品規格，也不替代真機校正、天線量測或安全評估。

## prerequisite gap

缺口是把環境變數、數字、判斷規則、電路供電與網路服務串成因果。首頁即零基礎起點，不需背術語。感測與 MCU 先建立本機行為，再學電力；網路先講可達性，訊息才講分送與確認；安全與可靠性接在最後。各頁可直接進入，頁首提供前置連結，沒有考試、分數或解鎖。

## 來源與延續

本地來源是上層專題 index、硬體電源與電池、韌體架構與電源管理、韌體連線模組整合，以及原專題指向的 E1、E3、E5 課程。關鍵模型與數值的逐項契約在 [互動契約.json](互動契約.json)，來源查證由獨立 source-audit agent 處理。網站來源頁用章節文字及公開的一手資料連結，不連部署不存在的 Markdown。

## 交付物與不做事項

首頁、七個獨立課頁、可搜尋字典、來源與模型限制頁，共用 lab.css 及原生 JavaScript；無 build、無執行期網路請求，可離線開啟。圖只用 inline SVG/CSS；不抓圖片、字型，不裝依賴，不改舊站。共用樣式同步規則由使用者明確新站與自由技術棧授權取代。內容與互動見 BUILD-SPEC；獨立 QA 記在驗收紀錄，後續執行者可由這三份檔案復原決策。

## 預算與分工

四位互斥模組作者，由 builder 整合；只有指定的 source-audit 與 reference 研究線做外部查詢。互動均為確定性模擬，不使用真實感測器、broker 或遠端服務。部署、來源 commit 與 push 由 root 負責。

## 圖解優先的補充授權

使用者另明確允許依圖量調整分頁、布局與章節分派，並補充入門、額外資訊及必要細節。本站因此採一頁一個主要因果、手機長圖局部橫向滑動以維持字級；必要銜接包含電力路徑與訊號路徑不同、濕潤刻度不是真實含水率，以及區域網路不等於服務可達。深入限制放可展開說明與來源頁，不把主線變成長文。
