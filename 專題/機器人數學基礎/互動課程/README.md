# 機器人數學基礎（互動課程）

給「只記得三角函數、其餘理工基礎近乎零」的自學者的**機器人數學先修課**。從三角函數一路蓋到機器人四門課（運動學、路徑規劃、視覺、學習）需要的數學，當高中生教、深入淺出、每章至少一個可玩互動。

## 技術

- 課程本體是純原生 HTML/CSS/JS，不需外部資產即可離線使用；「回到工程學習主站」連結需網路。
- 公式純文字（Unicode + `<sub>/<sup>`），無數學渲染器依賴。
- 互動採「每個 widget 一個 `if(!$('id'))return` 守衛函式、檔尾統一註冊」模式（比照機器人運動學課）。
- 已封存的建置契約見 [`archive/BUILD-SPEC.md`](archive/BUILD-SPEC.md)；驗收證據見 [`archive/驗收紀錄.md`](archive/驗收紀錄.md)。
