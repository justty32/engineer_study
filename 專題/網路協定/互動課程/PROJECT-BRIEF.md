# 網路協定細講：專案簡報

## 讀者基線

- 讀者是資深 C++ 工程師，熟悉程式、記憶體、資料結構與除錯。
- 不假設具備計算機網路基礎；不以會用 socket 推定懂封包、分層、路由或信任鏈。
- 正文與介面使用繁體中文。術語第一次出現寫成「繁中（English full name, acronym）」並補白話功能。

## 目標能力

完成主線後，讀者能沿一筆網頁請求解釋：名稱如何變成位址、資料如何逐層封裝、區域網路如何找到下一站、路由器如何轉送、傳輸層如何提供不同保證、應用協定如何表達意圖，以及加密通道如何建立機密性、完整性與伺服器身分保證。讀者也能把封包欄位與事件紀錄對回每一層。

## 概念依賴

```text
端點、鏈路、封包、分層與封裝
  → 乙太網路、硬體位址、位址解析
  → 網際網路協定位址、前綴、閘道與路由
  → 埠、使用者資料包協定、傳輸控制協定
  → 網域名稱系統
  → 超文字傳輸協定
  → 傳輸層安全性協定與憑證信任
  → 跨層追蹤：名稱 → 連線 → 請求 → 證據
```

## 教學方法與互動契約

- 先教後操作，不設題目、分數、提交、倒數或答對解鎖。
- 控制項一改就同步更新結果與原因；每個互動可重設。
- 一頁一個概念群；每頁標出前置、角色、機制、狀態變化、結果、證據與反例。
- 字典供隨時搜尋，不要求先背。
