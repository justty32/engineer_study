# 網路協定細講：離線互動課程

直接以瀏覽器開啟 [index.html](index.html) 即可。所有資產都在本目錄，無需建置或網路連線。

## 頁面地圖

1. `index.html`：課程地圖、讀者基線與主線。
2. `00-封包與分層.html`：零基礎起點；端點、鏈路、協定、封裝與證據。
3. `01-乙太網路與位址解析.html`：區域鏈路、硬體位址、交換與位址解析。
4. `02-網際網路協定與路由.html`：位址、前綴、閘道、逐跳轉送。
5. `03-傳輸控制與使用者資料包.html`：埠、可靠位元組流與資料包服務。
6. `04-網域名稱系統.html`：階層名稱、遞迴查詢、快取與存活時間。
7. `05-超文字傳輸協定.html`：請求、回應、方法、狀態碼與連線復用。
8. `06-傳輸層安全性協定.html`：握手、憑證、金鑰協議與受保護紀錄。
9. `07-跨層追蹤.html`：從網址到回應的跨層整合與故障定位。
10. `名詞與概念字典.html`：可搜尋中英名詞、白話功能、位置與易混邊界。

共用 `styles.css` 負責版面與可及性；`app.js` 負責導覽、字典搜尋及各頁即時互動。規格見 `BUILD-SPEC.md`，已執行的檢查見 `驗收紀錄.md`。
