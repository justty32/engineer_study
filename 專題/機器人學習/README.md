# 機器人學習與訓練

本專題把「機器人訓練」具體化為模仿學習、強化學習、模擬訓練、模擬轉真實與安全部署；不把訓練成功率等同實機安全。讀者基線：C++ 資深；機器人學習與機器學習數學零基礎。課程另設函數、機率、損失、梯度與最佳化先修頁；不要求先背字典或先作答。

數學先修：[機器人數學基礎](../機器人數學基礎/README.md)（第 01–05、08–09、11–12 章）。本課 00A 專注機器學習語境中的函數、參數、損失、梯度與最佳化；其中梯度與機率是數學基礎第 11–12 章在訓練問題中的應用。
