A–Z · SEARCHABLE GLOSSARY

名詞與概念字典

搜尋繁中、英文或縮寫；字典用來回查，不要求背誦。

觀測

Observation

策略實際收到的感測與歷史，不一定等於完整狀態。

狀態

State

足以描述決策所需環境情況的變數。

動作

Action

策略可選的命令，需明確單位、範圍與頻率。

策略

Policy

由觀測或狀態映射到動作分布／動作。

episode

Episode

從起始到終止的一次互動序列。

label

Label

監督學習希望模型預測的目標。

資料洩漏

Data Leakage

評估資訊直接或間接進入訓練。

分布偏移

Distribution Shift

部署輸入分布不同於訓練資料。

行為複製

Behavioral Cloning, BC

用專家觀測—動作對做監督學習。

模仿學習

Imitation Learning, IL

由示範或專家回饋學習行為。

DAgger

Dataset Aggregation

由目前策略造訪狀態並請專家補標資料。

強化學習

Reinforcement Learning, RL

由互動獎勵改善循序決策策略。

MDP

Markov Decision Process

狀態、動作、轉移、獎勵與折扣的決策模型。

獎勵

Reward

單步的訓練訊號，不等於完整任務價值。

回報

Return

從某時刻起的累積折扣獎勵。

折扣因子

Discount Factor, γ

控制未來獎勵權重的 0–1 參數。

狀態價值

State Value, V

在狀態遵循策略的期望回報。

動作價值

Action Value, Q

先做特定動作後的期望回報。

actor–critic

Actor–Critic

由策略元件選動作、價值元件估評分。

同策略

On-policy

主要用目前策略產生的資料更新。

異策略

Off-policy

可用其他行為策略產生的資料更新目標策略。

探索

Exploration

嘗試不確定動作以取得資訊，實機有成本。

replay buffer

Experience Replay Buffer

儲存轉移供重複抽樣，不等於獨立資料。

領域隨機化

Domain Randomization

訓練時改變模擬參數以增加覆蓋。

系統辨識

System Identification

由實測輸入輸出估模型參數。

sim-to-real

Simulation-to-Real Transfer

把模擬訓練結果轉移到真實系統。

影子模式

Shadow Mode

策略產生輸出但不接管致動，用於比對。

安全過濾器

Safety Filter

在策略與控制器間限制或拒絕危險動作。

分布外

Out-of-Distribution, OOD

輸入落在訓練分布支撐之外或附近不足區。
