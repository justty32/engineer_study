# 建置與內容規格

原生靜態多頁網站；繁體中文、UTF-8、無圖片、無外部字型、內容傳遞網路、遠端介面或套件依賴。共用程式只在對應 DOM 存在時啟動。

## 頁面與互動契約

- 主線為 `00 → 00A → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 字典 → 首頁`，每頁皆有上一頁／下一頁。
- 八項即時自由互動：切分洩漏、行為複製誤差累積、折扣回報、探索暴露、模擬支撐、部署閘門、離線動作支撐距離與模型 rollout 誤差。無提交、分數或解鎖。
- DOM 根節點依序為 `split-scenes`、`bc-error`、`ret-gamma`、`exp-rate`、`sim-range`、`gate-baseline`；輸出皆為 `aria-live`。
- 字典搜尋 `term-search` 過濾 `.term-card`，每條固定五個語義欄位。

## 公式、假設與證據邊界

- 誤差示意：`P(至少一次)=1-(1-e)^T`，假設每步錯誤獨立；真實閉迴路通常不成立，僅建直覺。
- 折扣回報：`G=Σ γ^k r_k`，`0≤γ≤1`。
- 梯度更新例：`θ_new=θ_old-α∇L`，只展示方向與步幅，不聲稱收斂。
- 探索暴露：探索率 × 粗略危險動作比例 × 回合數，是教學指標而非事故機率。
- 模擬支撐以一維區間說明覆蓋；不代表多維聯合分布或真機成功保證。
- 離線 RL 支撐互動同樣是一維區間，只呈現外插距離與線性保守懲罰，不冒充高維密度或安全證明。
- 模型 rollout 誤差上界為 `εΣ L^k`；固定 `L` 與每步誤差只是敏感度示意，MPC 重規劃也不等於取得無誤真值。

驗收門檻：每個教學章去標籤純文字至少約 1100 字元；字典去標籤純文字至少 5000 字元；JavaScript 語法、相對連結、DOM 契約、UTF-8 與外部執行期資產檢查通過。
