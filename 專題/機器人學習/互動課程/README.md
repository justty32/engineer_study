# 機器人學習與訓練互動課程

給軟體能力強、但機器人學習與相關數學零基礎的讀者。採 foundations-first：先世界觀與數學，後資料、演算法與部署；互動均在完整教學之後，無計分。

## 頁面地圖

1. `index.html`：讀者基線、學習順序與全部入口。
2. `00-從控制程式到可學習策略.html`：估測、規劃、控制、策略與訓練迴路。
3. `00A-機器學習數學先修.html`：機率、函數、參數、損失、梯度與最佳化。
4. `01-資料觀測動作與切分.html`：資料契約、時間對齊與洩漏互動。
5. `02-模仿學習與分布偏移.html`：行為複製、閉迴路誤差與資料集聚合。
6. `03-MDP回報價值與策略.html`：循序決策、獎勵、回報與價值。
7. `04-策略改善探索與穩定性.html`：行動者—評論者、資料關係與探索成本。
8. `05-模擬訓練與sim-to-real.html`：落差、系統辨識、領域隨機化與驗證階梯。
9. `06-安全評估與C++部署.html`：前後處理、安全層、影子模式與證據。
10. `名詞與概念字典.html`：可搜尋長版字典；每條固定五部分。

共用 `styles.css` 與 `app.js`，無外部執行期依賴。
