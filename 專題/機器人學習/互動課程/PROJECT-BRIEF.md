# 機器人學習與訓練互動課程 Brief

## 讀者基線與理解債

讀者是資深 C++ 工程師，熟悉函式、型別、狀態機與系統整合；不假設懂機器人學習、神經網路、機率、微積分、損失、梯度或最佳化。舊版因章節與字典過度精簡，形成縮寫、數學與因果理解債；本版不可用軟體資歷推定這些先修。

## 目標能力與依賴

讀者能從真實機器人資料流解釋策略與訓練；定義可追溯的觀測／動作契約；辨識洩漏與閉迴路分布偏移；用白話及數值解釋模仿學習、循序決策、回報、價值與策略改善；設計模擬轉真實的證據階梯；描述模型到 C++ 致動之間的安全邊界。

`函式世界觀 → 機率／參數／損失／梯度 → 資料契約 → 模仿學習 → 強化學習 → 策略改善 → 模擬轉真實 → 安全部署 → 離線強化學習與資料支撐 → 模型式學習與滾動規劃`

## 教學與語言契約

每章依「白話問題 → 一句話答案 → 最小前置 → 角色與逐步因果 → 具體數值例 → 完整教學後的自由互動 → 證據 → 誤解與邊界」撰寫。繁體中文為主；英文術語與縮寫首次出現必須展開。字典每條均有白話、位置／角色、如何生效、具體例子與不要混淆。

## 邊界與來源

互動只展示小型數值模型，不訓練神經網路、不連接真實機器人、不保證收斂或實機安全。來源基礎包括本地七軸運動學與系統動態筆記、Sutton 與 Barto《Reinforcement Learning: An Introduction》（尤其模型式方法與規劃章節），以及 Ross 等人的 DAgger 論文；公式與簡化指標列於 `BUILD-SPEC.md`。
