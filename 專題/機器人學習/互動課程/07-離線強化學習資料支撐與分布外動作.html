07 · 不讓策略在真機上邊試邊撞

離線強化學習、資料支撐與分布外動作

白話問題：已經有大量機器人操作紀錄，能否完全不碰真機就學出更好的策略？一句話答案：可以只用固定資料訓練，但只能可靠比較資料真正涵蓋的狀態—動作；演算法若高估沒見過的動作，策略會專挑模型最不可靠之處。

最小前置：先讀資料契約、回報與價值、策略改善。離線強化學習（Offline Reinforcement Learning, Offline RL）不是一般監督學習，也不是上線後仍持續探索的線上 RL。

固定資料改變了「試錯」的意義

資料集由行為策略（behavior policy）產生，保存 (s,a,r,s′,done) 轉移。訓練期間環境不接受新查詢；演算法可反覆讀資料，但無法親自驗證「若在狀態 s 改做另一個動作會怎樣」。因此價值函數在資料密集區有直接證據，在分布外（out-of-distribution, OOD）的狀態或動作上只靠函數近似外插。

傳統離線評估若只看資料中實際執行的行為，無法證明新策略。更危險的是最大化步驟：對每個候選動作取預測價值最高者，會系統性偏好偶然高估的 OOD 動作。這不是模型「有惡意」，而是最佳化器會尋找誤差。保守離線 RL 的共同直覺，是限制新策略靠近資料支撐、降低未觀測動作價值，或對不確定區加懲罰；不同演算法的數學與保證條件不相同。

為什麼取最大值會放大估計誤差

假設資料充分的動作 A 真實價值為 5 分，估計也是 5；沒見過的 B、C 真實價值都只有 1 分，但模型因外插分別估成 4 與 7。策略做 arg maxa Q̂(s,a) 時會選 C，因為 7 最大；最佳化器看不到「7 是無證據的誤差」。保守方法可能使用 Qconservative(s,a) = Q̂(s,a) − λu(s,a)，其中 u 是不確定或離支撐的懲罰、λ 控制強度。若 C 的 λu = 4，保守值降為 3，策略才可能回到 A。u 與 Q 必須使用相容尺度；這個例子只示意機制，實際不確定度不一定可靠。

資料中的動作到底是哪一個

一筆轉移若只存模型原提議 aproposal，但安全層實際執行的是 aexecuted，環境的 s′ 與 r 是由後者造成。把前者當成因果動作會教錯動態與價值。資料格式應同時保存兩者、裁切原因、控制器回授與人工接管；用於轉移學習的動作欄必須明確對應真正致動命令。

資料支撐不只是每軸最小最大值

資料支撐（data support）是資料分布有實際涵蓋的狀態—動作組合。單看每個動作分量範圍會忽略關聯：資料可能包含肩速度 ±1 rad/s、肘速度 ±1 rad/s，卻從未在手臂伸直時同時高速向外。高維空間的邊界不能由一個區間完整表示，互動故意只用一維，讓「內插與外插」先可視化。

例如資料中的單關節速度位於 [-0.5,0.8] rad/s。候選 0.6 在一維區間內，至少不是明顯外插；候選 1.2 超出上界 0.4 rad/s。這不代表 0.6 一定安全，也不代表 1.2 一定失敗；它只說證據強弱不同。狀態條件、資料密度、回報品質與感測偏差仍要一起檢查。

互動的一維距離可寫成 d = max(amin − a, 0, a − amax)。a、上下界與 d 的單位都是 rad/s。代入 amin = −0.5、amax = 0.8、a = 1.2 rad/s，得到 d = max(−1.7, 0, 0.4) = 0.4 rad/s。若每超出 0.1 rad/s 懲罰 0.5 分，簡化懲罰是 (0.4÷0.1)×0.5 = 2 分。這是假設一維、線性且區間內零懲罰的教學近似，不是密度估計或安全成本。

讀完再操作：策略提議離資料有多遠

怎麼玩：先保留資料範圍 −0.5 到 0.8 rad/s，把策略提議由 0.6 拉到 1.2，觀察距離與保守分數何時開始改變；再提高每 0.1 rad/s 的懲罰，看演算法如何降低外插吸引力。若把上下界填反，輸出警示的是契約錯誤；工具無法檢查高維關聯或目前狀態是否相似。

離線策略評估為何困難

離線策略評估（Off-Policy Evaluation, OPE）想在不執行新策略時估它的回報。重要性抽樣可用「新策略選到資料中動作的機率／行為策略機率」修正分布，但長序列的比例連乘可能造成極高變異，且行為機率常未被記錄。模型式評估可學環境模型後模擬新策略，卻又承受模型在 OOD 區域的誤差。實務上應並列多種估計、信賴區間、壓力測試與非學習基線，而不是只報單一預測回報。

資料品質也包含 coverage 與 outcome。若所有操作者都成功，資料可能缺少失敗前兆；若只有事故資料，策略又不知道正常完成長什麼樣。回報重算、終止標記、逾時、人工接管與安全層裁切必須留在資料契約，否則學到的「動作」可能其實從未被真機執行。

重要性權重的最小例子：行為策略在某狀態選 A 的機率 μ(A∣s) = 0.5，新策略機率 π(A∣s) = 0.75，單步比率 w = π÷μ = 1.5；該樣本在估新策略時被放大 1.5 倍。若連續 20 步的比率都為 1.5，乘積是 1.520 ≈ 3,325，少數軌跡便可能主宰估計。π、μ、w 都無單位；若 μ = 0 而 π > 0，比率無法定義，直接反映資料沒有支撐。

安全部署證據與邊界

  • 按狀態群、操作者、硬體與場景報資料密度、動作距離、OOD 比例與新舊策略差異，不只畫總體直方圖。
  • 保留行為策略版本、原提議、經安全層裁切的實際命令、結果與終止原因，避免把不同因果混成同一資料欄。
  • 新策略先做資料回放、反事實敏感度、模擬、影子模式與低風險小流量；任一 OOD 或品質警示都應有獨立回退。

互動的區間距離不是高維密度估計，也不是安全證明；線性懲罰只是展示保守目標如何壓低外插吸引力。離線 RL 無法從資料中創造未曾涵蓋的因果證據。若任務需要全新動作或狀態，仍要透過模擬、受控資料收集、人工示範或安全線上試驗擴展支撐。

不要混淆離線、異策略與保守

  • 離線 RL 與異策略 RL：離線表示訓練期間資料固定；異策略表示資料策略與目標策略可不同。異策略演算法也可以一邊收新資料。
  • BC 與離線 RL：BC 模仿資料動作；離線 RL 利用獎勵與下一狀態嘗試改善長期回報，因此更容易走離資料。
  • 範圍內與有支撐：每軸都在最小最大值內，不代表該狀態下的聯合動作曾出現。
  • 保守與安全：保守價值降低 OOD 高估，不等於符合速度、碰撞與人員安全限制。

可觀察證據應串起資料版本、行為策略、每個狀態群的密度、新舊策略動作距離、OPE 分歧與影子模式提議。密度圖能指出少資料區，OPE 能在假設下比較策略，影子模式能看到真實輸入上的提議；三者都不能單獨證明接管後的閉迴路結果。

先用一張查表想懂「沒資料卻很有自信」

假設某狀態下，資料只執行過速度 0.0、0.2、0.4 rad/s，各有約 100 筆，平均回報分別是 2、5、6。對 0.3 rad/s，模型是在兩個有資料點之間內插；對 1.5 rad/s，則完全靠函式形狀外插。神經網路仍會輸出一個數，例如 Q̂=20，但「有輸出」不等於「有證據」。離線最佳化若直接選最大 Q̂，便會把 1.5 當成寶藏。

可把它類比成資料庫查詢與程式猜值：查得到的列有來源，查不到時某些系統仍會回傳預設值。類比限制是高維連續空間沒有清楚的單一 key；狀態相近但接觸模式不同，可能完全不能互相支撐。因此實務上要看條件密度、模型不確定、鄰近距離與領域限制，不只看每軸範圍。

高維支撐為何不能逐欄看

假設資料只有兩組雙關節速度：(1,1) 與 (−1,−1) rad/s。每一軸的範圍都是 [−1,1]，候選 (1,−1) 每一欄都在範圍內，卻從未共同出現。若兩關節必須同向移動以維持末端姿態，這個組合可能完全不合理。幾何上，候選到 (1,1) 的差向量是 (0,−2)，距離 √(02+(−2)2)=2；到 (−1,−1) 也為 2，並不靠近任何資料點。

向量與距離若不熟，可讀機器人數學基礎第 3 章：向量與第 2 章：座標與距離。即使歐氏距離很小，也不保證動態相似：角度跨過接觸邊界時，0.01 rad 的差可能讓夾爪從未接觸變成碰撞。

重要性權重再算一條有正有負的軌跡

行為策略兩步都以 0.5 機率選到資料中的動作，新策略相應機率為 0.75 與 0.25，軌跡權重 w=(0.75÷0.5)×(0.25÷0.5)=1.5×0.5=0.75。若這條軌跡回報為 8，未正規化貢獻為 0.75×8=6。另一條權重 3、回報 −4，貢獻為 −12，少數大權重失敗便會強烈影響估計。

這不是缺點可以靠更多小數位修好，而是新舊策略差異與長序列造成的統計困難。若行為策略機率沒有記錄，只能估計它，又多一層模型誤差。報告 OPE 時應同時列有效樣本量、權重最大值、截斷方式與多種估計器差異，不能只給最後平均。

從固定資料到受控部署的實際流程

  1. 資料稽核：確認實際執行動作、獎勵、終止、接管與安全裁切對齊，按狀態群統計覆蓋。
  2. 訓練比較：至少保留行為複製與原行為策略作基線；若複雜方法只在預測 Q 上勝出，證據還不夠。
  3. 反事實壓力測試：逐步擾動動作，觀察價值是否在資料邊界外異常上升、不同模型是否分歧。
  4. 影子模式：把真實觀測餵給新策略但不致動，記錄它離實際安全動作與資料支撐多遠。
  5. 受限試驗：通過獨立安全閘門後才用低速、小範圍、人工監看測閉迴路，任一 OOD 指標越界立即回退。
  • 不要混淆保守分數與物理安全：價值懲罰只處理證據不足，不會自動理解碰撞。
  • 不要混淆重看資料與增加資料：訓練一千個 epoch 仍是同一批轉移。
  • 不要混淆行為策略差與資料無用：資料可能包含可學的成功、失敗與恢復，只是改善幅度受支撐限制。
  • 不要混淆 OPE 與上線結果：OPE 是在假設下估計，真實閉迴路仍需分階段驗證。
