名詞與概念字典

輸入繁中、英文、縮寫或用途即可篩選。每張卡不只給定義，也指出名詞在系統哪一層、靠什麼生效，以及最容易誤套的邊界。

使用方式：遇到陌生詞就回來查；不必讀完或背完才能開始 00。

核心（kernel）

白話：作業系統中真正掌管受保護資源的程式。

位置或角色：位於硬體與使用者空間之間，以特權模式執行。

用途：管理 CPU、記憶體、裝置、檔案系統與行程。

機制：應用程式以系統呼叫進入核心；硬體以中斷通知核心。

邊界或常見誤解：Linux 嚴格說是核心，不等於整個發行版；用 uname -sr 看核心版本。

殼層（shell）／bash

白話：把人輸入的命令文字解析成程式與連接方式。

位置或角色：是使用者空間的命令直譯器；bash 是其中一種實作。

用途：展開變數與 glob、建立管道和重導向、啟動程式，也能執行腳本。

機制：shell 先解析命令列，再以系統呼叫建立行程與檔案描述子。

邊界或常見誤解：殼層不是終端也不是核心；用 echo $SHELL 與 ps -p "$BASHPID" 觀察。

發行版（distribution）

白話：一套可安裝、可維護的完整 Linux 系統組合。

位置或角色：包住 Linux 核心、使用者工具、函式庫、安裝程式與套件庫。

用途：提供一致的安裝、更新、預設設定與支援政策。

機制：維護者建置並簽署套件，套件管理器依發行版軟體庫處理交易。

邊界或常見誤解：不同發行版可用相近核心但工具與版本不同；看 /etc/os-release。

終端（terminal）

白話：讓你輸入與觀看文字的介面。

位置或角色：現代桌面常是終端模擬器；它連到 shell 或其他文字程式。

用途：傳送按鍵、顯示程式寫出的字元，支援遠端與多工作階段。

機制：透過偽終端裝置交換位元組與控制資訊。

邊界或常見誤解：關掉終端不代表 Linux 關機；終端也不負責解讀 grep 或管道。

絕對路徑／相對路徑

白話：完整指定起點，或從目前位置描述目標。

位置或角色：絕對路徑從根目錄 / 開始；相對路徑從行程的 cwd 開始。

用途：精確指定檔案與目錄，讓命令找到操作目標。

機制：核心逐層解析目錄名稱；. 保持本層，.. 前往父目錄。

邊界或常見誤解：路徑不是檔案內容；用 pwd 與 realpath 對照解析結果。

家目錄（~）

白話：使用者通常存放個人檔案與設定的起點。

位置或角色：常見路徑是 /home/名稱；~ 是 shell 的波浪號展開語法。

用途：快速引用自己或指定使用者的家目錄。

機制：shell 在命令執行前把開頭的 ~ 展開；HOME 則是環境變數。

邊界或常見誤解：~ 不等於根目錄 /，也不等於 cwd；用 printf 與 pwd 比較。

檔案系統階層標準（FHS）

白話：Linux 類系統安排常見目錄用途的共享慣例。

位置或角色：描述 /etc、/var、/usr、/tmp 等階層通常放什麼。

用途：讓管理員、程式與套件知道設定、可變資料與工具的大致位置。

機制：發行版依標準與自身政策配置目錄，掛載點仍可跨不同裝置。

邊界或常見誤解：FHS 不是每台機器完全相同的保證；用 findmnt 與 ls 觀察實機。

萬用字元（glob）

白話：用簡短樣式選出一組現有路徑名稱。

位置或角色：通常由 shell 在啟動命令前處理。

用途：讓 cp、ls、rm 等命令一次接收多個符合的參數。

機制：* 配任意長度、? 配一字元、方括號配集合，通常不跨 /。

邊界或常見誤解：glob 不是正規表達式；用 printf '<%s>\n' *.txt 看展開參數。

權限（rwx）

白話：三種基本操作許可：讀、寫、執行或穿越。

位置或角色：分成擁有者、群組、其他人三段，記在檔案中繼資料。

用途：限制行程能否對檔案或目錄做指定操作。

機制：核心依行程身分選一段模式位元，再檢查所需權限。

邊界或常見誤解：目錄的 x 是穿越，不是執行目錄；用 ls -l 與 stat 觀察。

chmod

白話：修改檔案或目錄的模式位元。

位置或角色：是使用者空間命令，要求核心變更檔案中繼資料。

用途：以 755 等八進位或 u+x 等符號寫法調整權限。

機制：每位數由 r=4、w=2、x=1 相加，分別對應 u、g、o。

邊界或常見誤解：chmod 不會改擁有者；也不應用 777 迴避理解問題。

擁有者／群組

白話：檔案記錄的一個使用者與一個群組歸屬。

位置或角色：屬於檔案中繼資料，與行程的有效 UID、群組集合比較。

用途：決定基本 rwx 判定要套用 u、g 或 o 哪一段。

機制：先比擁有者，再比群組，否則使用其他人；只取第一個類別。

邊界或常見誤解：三段權限不聯集；用 ls -l、id、chown 與 chgrp 查改。

sudo

白話：依政策暫時以另一個使用者身分執行命令。

位置或角色：位於使用者空間，常被設定為允許核准者切換到 root。

用途：在需要系統權限時執行明確、受稽核的管理操作。

機制：驗證呼叫者與 sudoers 政策，建立具有目標身分的行程。

邊界或常見誤解：sudo 不是修好 Permission denied 的通用前綴；先查目標與所需權限。

行程／PID

白話：程式的一次執行現場，以及核心給它的數字編號。

位置或角色：由核心管理，包含位址空間、執行緒、開啟檔案與憑證。

用途：讓系統排程工作，也讓工具指定要觀察或傳訊號的對象。

機制：載入程式時建立行程；PID 在行程結束後可被重複使用。

邊界或常見誤解：行程不等於磁碟上的程式檔；用 ps 與 /proc/數字 觀察。

行程狀態（R／S／D／Z／T）

白話：行程目前能否執行、在等什麼或是否已結束的摘要。

位置或角色：出現在核心排程與等待狀態，ps 的 STAT 欄會顯示。

用途：快速區分可執行、睡眠、I/O 等待、殭屍與停止。

機制：事件、排程、訊號與父行程回收會使狀態轉換。

邊界或常見誤解：S 通常不是故障，Z 也不再耗 CPU；用 ps -o pid,ppid,stat,cmd 查看。

訊號（signal）

白話：送給行程的非同步通知。

位置或角色：由核心遞送；可來自終端、另一行程或核心事件。

用途：要求中止、重新載入、暫停、繼續，或通知特定事件。

機制：可處理訊號觸發預設動作或使用者處理器；SIGKILL、SIGSTOP 不可攔截。

邊界或常見誤解：訊號不等於函式呼叫，也不保證程式立刻結束；用 kill -l 查名稱。

前景／背景與作業控制

白話：決定哪個行程群組接收終端輸入，以及 shell 是否等待。

位置或角色：由互動 shell、終端與核心的工作階段及行程群組共同維持。

用途：暫停、恢復並切換同一終端中的互動工作。

機制：Ctrl-Z 常送 SIGTSTP；bg 讓作業背景繼續，fg 拉回前景。

邊界或常見誤解：背景不等於常駐服務；登出後是否存活另受 SIGHUP 與服務管理影響。

標準輸入／輸出／錯誤

白話：每個新行程慣用的三條預設資料通道。

位置或角色：通常是檔案描述子 0、1、2，可連到終端、檔案或管道。

用途：分開正常輸入、正常結果與診斷訊息，便於自由接線。

機制：shell 在啟動行程時開啟、複製或改接檔案描述子。

邊界或常見誤解：stdout 與 stderr 同時顯示在螢幕仍是兩條通道；看 /proc/PID/fd。

重導向（redirection）

白話：把行程的標準通道改接到檔案或另一個描述子。

位置或角色：由 shell 在程式開始執行前配置。

用途：保存輸出、分離錯誤、從檔案供應輸入或合併通道。

機制：> 覆寫 stdout、>> 附加、2> 改接 stderr、< 改接 stdin。

邊界或常見誤解：順序會影響 2>&1 的目標；重導向不是程式把畫面截圖。

管道（pipe）

白話：把一個行程的 stdout 直接接到另一行程的 stdin。

位置或角色：是核心管理的位元組流與有限緩衝區，shell 建立兩端。

用途：讓小工具串成篩選、轉換與統計流程。

機制：兩端可同時執行；寫端產生資料，讀端消費資料。

邊界或常見誤解：管道不自動接 stderr，也不理解文字欄位；需要雙方約定格式。

grep／正規表達式

白話：逐行找出符合文字樣式的內容。

位置或角色：grep 是使用者程式；正規表達式是它採用的樣式語言。

用途：從檔案或 stdin 篩出日誌、設定與命令輸出的相關行。

機制：依樣式逐行匹配，符合行寫到 stdout，結束狀態回報是否命中。

邊界或常見誤解：正規表達式不等於 glob；基本與擴充語法也有差異。

環境變數／PATH

白話：父行程可傳給子行程的一組名稱與字串值。

位置或角色：存在於每個行程的環境；PATH 是 shell 尋找命令的目錄清單。

用途：提供家目錄、語系、程式搜尋路徑與應用設定。

機制：export 讓 shell 變數進入之後建立的子行程；shell 依 PATH 順序搜尋。

邊界或常見誤解：環境變數不是全機唯一值，子行程也不能反改父行程；用 env 觀察。

套件管理器（apt／dnf）

白話：替發行版安裝、升級、移除與追蹤軟體的工具。

位置或角色：apt 常見於 Debian／Ubuntu，dnf 常見於 Fedora／RHEL 系列。

用途：解析相依、驗證來源、執行交易並維護已安裝套件資料庫。

機制：先取得軟體庫中繼資料，再下載、驗證並依交易順序變更檔案。

邊界或常見誤解：update 常只更新清單，不等於 upgrade；安裝完成也不等於服務正常。
