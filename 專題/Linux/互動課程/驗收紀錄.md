## app.js 單元測試（Node）

- resolvePath("/home/alice","../bob/./f")→/home/bob/f；絕對路徑 /etc/passwd→原樣；"../../x" from /a/b/c→/a/x；"~/docs"→/home/user/docs。
- globToRe：*.txt 命中 a.txt,c.txt；file? 只命中 file1；[ab]* 命中 apple,banana；[!a]* 命中 banana（反向類別正確）。
- rwx：7=rwx、6=rw-、5=r-x、4=r--、0=---。
- `node --check` 通過；app.js 內 0 個 Math.random／Date；載入自執行以 `typeof document` 守衛（可在 Node require 測試）。

## 靜態驗收

- 27 個依賴 id 全存在於 HTML；缺 id 0。
