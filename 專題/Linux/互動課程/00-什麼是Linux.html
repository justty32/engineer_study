00・先分清畫面背後的四層

什麼是 Linux：核心不是整套桌面，也不是黑色視窗

你在終端輸入 ls，不是直接「對 Linux 說話」。終端承載文字介面，殼層解讀命令，使用者程式執行工作，最後由 Linux 核心管理硬體與受保護資源。

這章假設已懂：程式會接收輸入並產生輸出；不假設用過命令列。

痛點：大家都把 Linux 指向不同東西

有人說 Linux 是核心，有人把 Ubuntu 桌面叫 Linux，也有人指著終端視窗說「這就是 Linux」。像把引擎、方向盤、車上用品與整台車混叫成車，日常溝通勉強可行，除錯時卻會找錯層。精確地說，Linux 是核心（kernel）；可安裝使用的完整系統通常是發行版（distribution）。

一次命令實際穿過哪些層

alice@host:~$ ls /home/alice
notes.txt  projects

終端顯示字元；bash 這類殼層解析 ls /home/alice；ls 是使用者程式；它透過系統呼叫請核心讀取目錄。Ubuntu 則把核心、GNU 工具、函式庫與 apt 套件管理器整理成發行版。

為什麼／不要混淆

  • 終端不等於殼層：關掉終端會失去那個互動畫面，但 bash 也能從別的終端或遠端連線執行。
  • 殼層不等於核心：殼層能解讀管道、變數與萬用字元，硬體保護與行程管理仍由核心執行。
  • 發行版不等於版本名稱：Ubuntu 與 Fedora 都可使用 Linux 核心，但預設工具、套件格式及更新政策不同。

可觀察證據

uname -sr 顯示核心名稱與版本；cat /etc/os-release 顯示發行版；echo $SHELL 顯示登入殼層路徑；在 bash 可用 ps -p "$BASHPID" 觀察目前殼層行程。

動手玩：辨認 Linux 系統的層次

示範什麼：四個常被混叫成 Linux 的角色。怎麼玩：逐項切換。看什麼：輸出中的管理範圍，以及誰需要透過核心取得 I/O。
