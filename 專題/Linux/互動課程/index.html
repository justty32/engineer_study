Linux（零基礎實務互動課）

你不必先背指令。這門課從核心、殼層與終端的分工開始，沿著路徑、權限、行程、資料流與套件管理，建立可以用指令輸出驗證的 Linux 心智模型。

概念依賴

Linux 各層角色路徑與檔案操作身分與權限行程與訊號文字資料流Shell 環境與套件

建議依 00 到 09 閱讀。所有互動都會立即回饋、沒有分數；先用預設值對照正文，再故意改成不符合或無權限的案例。

00 什麼是 Linux

分清核心、殼層、使用者程式與發行版，不再把終端視窗當成 Linux 本身。

01 檔案系統與路徑

從根目錄、目前目錄與家目錄，實際解析絕對及相對路徑。

02 檔案與目錄操作

用 pwd、ls、cp、mv、rm 操作物件，並看懂 shell 如何展開 glob。

03 權限與擁有者

把 rwx 與 0 到 7 互相轉換，分清檔案與目錄權限的含義。

04 使用者、群組與存取

依擁有者、群組、其他人的順序，重建核心會套用哪一段權限。

05 行程與訊號

讀懂 ps 的狀態碼，並選擇讓程式中止、暫停或繼續的訊號。

06 管道與重導向

追蹤 stdin、stdout、stderr 被接到檔案或下一個行程的資料流。

07 文字處理與 grep

用逐行篩選與正規表達式，從日誌中留下真正要看的證據。

08 環境變數與 shell

看懂變數展開、引號與 PATH，理解 shell 在程式啟動前做了什麼。

09 套件管理

分清搜尋、更新清單、安裝、升級與移除，避免照抄危險安裝指令。
