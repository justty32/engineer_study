06 · C++ CONTRACTS AND EVIDENCE

C++ 架構與驗證證據

規劃系統最難除錯的不是 template，而是模型、座標、時間戳與失敗原因被壓成一個 bool。讓型別和 log 保存推理鏈。

前置：完整規劃管線。
struct PlanRequest {
  RobotState start;
  GoalConstraint goal;
  WorldSnapshot world;
  Limits limits;
  PlanningBudget budget;
};
struct PlanResult {
  PlanStatus status;
  GeometricPath path;
  TimedTrajectory trajectory;
  VerificationEvidence evidence;
};

分層測試

層輸入證據
狀態有效性已知碰撞／非碰撞組態碰撞對、距離、模型版本
局部連接穿過薄障礙的邊連續檢查或最大步距
規劃器固定 seed 的小場景狀態、成本、終止原因
時間化速度／加速度邊界逐點限制最大值
執行感知更新與延遲軌跡版本、停止／重規劃事件
不能只記成功率：同一場景的模型版本、亂數種子、時間預算、最小間隙、成本與失敗分類缺一，就無法重現或比較。
