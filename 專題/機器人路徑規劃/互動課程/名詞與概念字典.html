A–Z · SEARCHABLE GLOSSARY

名詞與概念字典

輸入繁中、英文或縮寫即可過濾；字典是回查工具，不是進入課程前的考試。

組態空間

Configuration Space, C-space

所有可能組態的空間；禁區代表碰撞或違反限制。

狀態有效性

State Validity

檢查單一狀態是否符合關節、碰撞與其他限制。

路徑

Path

沒有時間資訊的狀態空間曲線。

軌跡

Trajectory

帶時間的狀態序列或函數。

局部規劃器

Local Planner

嘗試連接兩個鄰近狀態並驗證中間段。

間隙

Clearance

機器人與障礙的最小距離；模型誤差會影響它。

Dijkstra 演算法

Dijkstra's Algorithm

依起點累積成本搜尋非負權重圖。

A* 搜尋

A* Search

以 g+h 排序；h 是剩餘成本估計。

可採納啟發式

Admissible Heuristic

從不高估真實剩餘成本的 h。

完備性

Completeness

若有解，方法是否保證找到；需說明條件與時間。

機率完備

Probabilistic Completeness

樣本增加時，找到既存解的機率趨近一。

PRM

Probabilistic Roadmap

先建立可重用的取樣路網。

RRT

Rapidly-exploring Random Tree

朝隨機樣本擴張的探索樹。

RRT*

RRT Star

透過重接讓成本漸近改善的 RRT 變體。

狹窄通道

Narrow Passage

可行區體積很小、難被隨機樣本命中的區域。

成本函數

Cost Function

比較候選路徑的標量準則，不等同硬限制。

限制條件

Constraint

必須滿足的條件；違反通常使狀態或邊無效。

平滑

Smoothing

減少折角或多餘繞行，但仍需重新驗證碰撞。

時間參數化

Time Parameterization

為幾何路徑配置時間以形成軌跡。

jerk

Jerk

加速度的時間變化率。

重規劃

Replanning

世界或目標更新後重新產生或修補計畫。

IK 分支

Inverse Kinematics Branch

同一末端目標的不同關節解族。

允許碰撞矩陣

Allowed Collision Matrix

明確列出可忽略的幾何接觸對。

規劃時間預算

Planning Budget

規劃器可用時間／樣本等資源，不是成功保證。

驗證證據

Verification Evidence

模型、成本、間隙、限制與失敗原因的可重現紀錄。
