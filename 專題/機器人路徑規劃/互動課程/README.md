# 頁面地圖

- `index.html`：課程入口與依賴圖
- `00-從移動問題到規劃問題.html`：狀態、路徑、軌跡、限制
- `00A-搜尋與圖論先修.html`：節點、邊、成本、路線與連續空間離散化
- `01-組態空間碰撞與間隙.html`：組態空間、碰撞與間隙
- `02-圖搜尋Dijkstra與A-star.html`：成本、啟發式與完備性
- `03-PRM-RRT與RRT-star.html`：取樣規劃
- `04-平滑與時間參數化.html`：速度、加速度、jerk
- `05-七軸冗餘與線上重規劃.html`：IK 分支、零空間與動態環境
- `06-C++架構與驗證證據.html`：介面、測試、log
- `名詞與概念字典.html`：可搜尋深度字典；每條固定五部分

## 閱讀方式

資深 C++ 背景只用於 C++ 類比與最後一章，不當成機器人、圖論或數學先備知識。依 `00 → 00A → 01…06` 閱讀；遇到名詞可隨時開字典，不需先背。各章固定先回答白話問題，再補最小前置、逐步因果、可手算數值例，最後才操作既有自由實驗。
