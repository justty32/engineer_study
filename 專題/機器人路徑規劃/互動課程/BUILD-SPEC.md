# 建置規格

## 執行與頁面契約

原生 HTML、CSS、JavaScript，無外部執行期資產、圖片、字型或遠端 API。主線為 `index → 00 → 00A → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 字典 → index`，每頁有上一頁／下一頁且不得成為孤兒頁。`app.js` 對缺少的 DOM 採安全偵測，既有互動 ID 不得任意更名。

## 教學契約

每個主線教學章節純文字至少約 1100 個字元，順序為：白話問題與一句話答案、最小前置、首次術語繁中／英文展開、逐步因果、可手算或具體數值例、互動前教學、可觀察證據、常見誤解與適用邊界。字典全文至少 5000 個純文字字元，每個條目必須有「白話、位置／角色、如何生效、具體例子、不要混淆」五部分。

## 互動與公式

共七項即時、無計分自由實驗：間隙計算、A* 啟發式取捨、取樣成功機率、關節最短時間下界、七軸規劃管線診斷、約束投影殘差與動力煞停包絡；另有字典搜尋。核心教學公式新增 `f(q+Δq)≈f(q)+J_fΔq`、`Δq≈−J_f⁺f(q)`、`d_stop=vτ+v²/(2a)`。每個輸出必須說明是教學近似以及不能證明的事項。

## 靜態驗證

執行 `node --check app.js`；解析所有本地 `href`／`src` 並確認檔案存在；所有 HTML 需有 `lang="zh-Hant"`、UTF-8 meta、main、pager、CSS 與 JavaScript；檢查 JavaScript 查詢的互動 ID 至少存在一次；逐頁移除標籤後計算純文字長度。真人瀏覽器、鍵盤、手機版與主控台驗收若未實際執行，不得標為通過。
