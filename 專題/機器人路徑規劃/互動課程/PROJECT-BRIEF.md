# 機器人路徑與運動規劃互動課程 Brief

## 讀者與目標

讀者是資深 C++ 工程師，已完成七軸機械手臂運動學，但不假設熟悉搜尋、碰撞幾何或軌跡生成。完成後能分辨路徑與軌跡、解釋組態空間、比較圖搜尋與取樣規劃、建立限制條件、定位規劃失敗並設計 C++ 驗證契約。

## 概念依賴

`機器人狀態 → 組態空間與碰撞 → 圖搜尋 → 取樣規劃 → 時間參數化 → 七軸冗餘與線上重規劃 → C++ 驗證`

## 教學與範圍

- 繁體中文為主；英文全名與縮寫首次出現即展開。
- 自由實驗即時回饋，不計分、不鎖頁。
- 使用二維與七軸教學模型；不宣稱可直接控制真實機械手臂。
- 不提供特定廠牌 API、完整碰撞引擎或即時安全認證流程。
