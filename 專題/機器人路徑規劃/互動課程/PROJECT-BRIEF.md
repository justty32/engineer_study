# 機器人路徑與運動規劃互動課程 Brief

## 讀者與目標

讀者是資深 C++ 工程師，但機器人學、圖論、搜尋、碰撞幾何與軌跡生成皆視為零基礎。不可把「會寫程式」推論成懂機器人術語或數學；英文縮寫不得代替解釋。完成後能從節點與邊建立規劃世界觀，分辨路徑與軌跡、解釋組態空間、手算基本搜尋與機率例、比較圖搜尋與取樣規劃、建立限制條件、定位規劃失敗並設計 C++ 驗證契約。

## 概念依賴

`狀態／路徑／軌跡 → 節點／邊／成本／離散化 → 組態空間與碰撞 → Dijkstra 與 A* → PRM／RRT／RRT* → 時間參數化 → 七軸冗餘與線上重規劃 → C++ 驗證`

## 教學與範圍

- 繁體中文為主；英文全名與縮寫首次出現即展開。
- 自由實驗即時回饋，不計分、不鎖頁。
- 每章在互動前完整教學：白話問題、最小前置、首次術語展開、因果鏈、至少一個可手算或具體數字例、證據、誤解與適用邊界。
- 字典是回查工具，每條固定包含白話、位置／角色、如何生效、具體例子、不要混淆。
- 使用二維與七軸教學模型；不宣稱可直接控制真實機械手臂。
- 不提供特定廠牌 API、完整碰撞引擎或即時安全認證流程。
