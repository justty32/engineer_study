# 逆向工程零基礎互動課程：專案簡報

## 讀者基線

- 讀者是資深 C++ 工程師；C++ 語法、型別、記憶體與除錯思維可精簡。
- 開始本課前應先完成 `專題/計算機組織/互動課程/`；該課負責電晶體到處理器、x86-64／AArch64／RISC-V、記憶體、應用程式二進位介面、編譯、目的檔、連結與載入。
- 本課不再假裝能用單章補完上述基礎；仍不假設會除錯器、靜態／動態分析或惡意程式分析。
- 正文與介面使用繁體中文；縮寫第一次出現一律給繁中、英文全名、縮寫與白話功能。

## 目標能力

學完能在合法授權範圍內，從位元組、指令、暫存器、堆疊、檔案結構、載入後記憶體、控制流與執行證據，逐步重建未知程式「可能做什麼」並區分事實、推論與待驗假說；能規劃隔離的防禦性惡意程式分流，不執行攻擊操作。

## 概念依賴

```text
計算機組織前置課：硬體 → 指令 → ABI → 編譯 → 連結 → 載入
  → 授權、樣本、觀察與推論邊界
  → 位元組、位址、暫存器與指令語意複習
  → 呼叫慣例、堆疊框架、參數與回傳
  → 檔案區段、符號、重定位、載入
  → 靜態分析
  → 動態分析與除錯器
  → 控制流、資料流與去混淆
  → 防禦性惡意程式分析與證據保全
```

## 教學與安全契約

- 所有互動先教後操作、即時更新、無提交、無分數、無解鎖。
- 只分析自有、明確授權或課程提供的無害教學模型。
- 不提供破解授權、繞過存取控制、規避偵測、持久化、憑證竊取、投遞或武器化惡意程式的方法。
- 惡意程式章聚焦隔離、雜湊、行為時間線、指標交叉驗證、事件紀錄與通報。

## 來源與限制

- 本儲存庫未找到專門的軟體逆向工程教材；內容依通用計算機系統模型撰寫，具體格式與慣例標示平台相依。
- 方法來源：`wf/workflows/interactive-study-site/FOUNDATIONS-FIRST.md`、`QUALITY-GATES.md`、`wf/workflows/common/writing.md`。
- 離線純文字，不使用圖片、外部字型、遠端程式或第三方依賴；教學指令集與載入器互動是簡化模型，不取代處理器手冊、作業系統文件或司法鑑識程序。
