# 逆向工程零基礎互動課程

以瀏覽器開啟 `index.html`，不需建置或連網。

## 頁面地圖

1. `index.html`：課程地圖、讀者基線與安全入口。
2. `00-合法授權與執行世界觀.html`：合法範圍、證據層次、檔案到行程。
3. `01-位元組位址暫存器與組合語言.html`：最小機器狀態與指令語意。
4. `02-呼叫慣例與堆疊.html`：函式邊界、參數、回傳與堆疊框架。
5. `03-可執行檔與載入.html`：區段、符號、重定位與載入器。
6. `04-靜態分析.html`：不執行樣本時建立可驗證假說。
7. `05-動態分析與除錯器.html`：暫停行程、觀察狀態改變。
8. `06-控制流資料流與去混淆.html`：由圖與定義使用鏈重建語意。
9. `07-惡意程式防禦分析與證據.html`：安全分流、隔離、時間線與通報。
10. `名詞與概念字典.html`：可搜尋中英名詞與易混邊界。

共用 `styles.css` 與 `app.js`；互動契約及簡化模型見 `BUILD-SPEC.md`，檢查證據見 `驗收紀錄.md`。
