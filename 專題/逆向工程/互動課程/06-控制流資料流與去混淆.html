06・從圖回到語意

控制流、資料流與去混淆

控制流回答「下一步可能去哪裡」；資料流回答「值從哪裡來、在哪裡被改、影響什麼」。去混淆不是追求漂亮程式碼，而是移除不影響目標問題的噪音，保留可驗證語意。

這章假設已懂： 比較與分支、交叉參照假說與受控驗證。

自由實驗：同時做向前資料切片與分支追蹤

基本區塊與控制流圖

基本區塊（basic block）是一段只有入口進入、末端才轉移控制的連續指令。控制流圖（Control Flow Graph, CFG）以基本區塊為節點、可能轉移為邊。圖顯示可能性；間接跳躍、例外與錯誤解碼會讓邊不完整。

定義使用鏈

定義使用鏈（definition-use chain）連接一個值被寫入的位置與後續讀取位置。向前切片找「這個輸入會影響哪些輸出」，向後切片找「這個危險呼叫的參數來自哪裡」。別名、指標、全域狀態與跨執行緒會增加不確定性。

常見混淆與安全邊界

不透明條件

看似依賴複雜運算、實際固定真假的分支。需以代數、範圍或動態觀察證明，不能只憑直覺刪除。

控制流平坦化

以狀態變數與分派器取代自然結構。先追狀態定義使用鏈，重建真正轉移。

資料編碼

字串或常數在使用前才還原。防禦分析只需識別還原點與行為證據，不延伸為規避偵測技巧。

本章不教授修改保護邏輯、繞過授權檢查或讓惡意行為避開偵測。

痛點：控制流很複雜，真正影響結果的值可能只有一個

反編譯畫面若出現幾十個跳躍與暫存變數，直覺會叫你從第一行一路讀到底；結果常是迷失在不影響目標的紀錄、錯誤處理與編譯器樣板。控制流告訴你有哪些路可走，資料流告訴你哪個值沿路傳遞。把兩者合起來，才能回答「檔案讀入的第 5 個位元組，是否真的影響最後的接受／拒絕？」

控制流圖可類比成道路圖，資料流像追蹤某輛車；但程式的邊由條件、間接跳躍、呼叫、例外與執行緒共同形成，值也會被複製、合併或經指標寫入。圖只是分析模型，不是作業系統實際保存的一張完整地圖。

先用四個基本區塊重建 if

假設區塊 B0 從參數讀到長度 n，計算 n − 4 並設定旗標；條件邊分到 B1 或 B2。B1 把結果 r 定義為 1，B2 把 r 定義為 0，兩條路在 B3 匯合並回傳 r。控制流是 B0 → B1 → B3 或 B0 → B2 → B3；向前資料切片則是 n → 比較旗標 → 分支選擇 → r → 回傳值。這一小段很可能對應高階的「n 等於 4 就回傳真」，但精確比較條件仍要查使用的是等於、有號大小或無號大小。

再把 n 換成具體值：n = 4 時，n − 4 = 0，零旗標為 1，若條件是零時跳躍便走 B1，回傳 1；n = 7 時結果非零，走 B2，回傳 0。若上方互動選「檔案讀入位元組」與「非零」，輸出顯示的是同一種向前切片概念；它是簡化教學路徑，不代表真實程式只有一個來源或一個分支。

向後切片：從結果倒問來源

假設你在 0x402000 看見檔案寫入呼叫，第二個參數是暫存器 R2。先找 R2 最近一次定義，發現它來自 0x401F80 的解碼函式回傳；再看該呼叫的輸入指標，追到 0x401E20 的檔案讀取緩衝區。這條鏈支持「寫入內容可能由輸入檔案轉換而來」。若中途 R2 也可能由另一分支、全域變數或其他執行緒寫入，就要把多個定義都保留，不能只挑符合預期的一條。

去混淆的精確目標與步驟

  1. 先寫問題，例如「哪個輸入決定是否建立檔案」，不要企圖一次恢復整個程式。
  2. 以外部效果或回傳值為切片終點，向後找直接參數、旗標與控制相依。
  3. 標記可證明不影響終點的區塊。只有經資料相依、控制相依或動態觀察支持，才把它視為目前問題的噪音；不要修改原樣本。
  4. 對疑似不透明條件帶入邊界值，例如 0、1、0xFFFFFFFF，檢查固定寬度溢位與有號解讀。數學上看似恆真的式子，在有限位元寬度下可能不同。
  5. 以至少兩組輸入在除錯器驗證預測路徑，保留未走到的邊。驗證成功表示模型解釋了這些案例，不等於已證明所有輸入。

不要混淆

  • 控制相依與資料相依：分支決定某區塊會不會執行是控制相依；某值參與另一值計算是資料相依，兩者可以同時存在。
  • 不可達與本次沒走：靜態不可達需要證明沒有可行入口；一次動態執行沒走只表示該案例未覆蓋。
  • 複雜與混淆：編譯器最佳化、狀態機、錯誤處理與 C++ 例外本來就可能複雜；混淆需要「刻意增加理解成本」的額外證據。
  • 簡化表示與修改程式：在筆記中把多個區塊整理成 if 是分析表示，不代表可以刪改原始位元組或保護邏輯。

可觀察證據與工具限制

  • 控制流圖能列出工具辨認到的區塊與邊；間接分派目標、例外邊或錯誤反組譯會造成缺漏。
  • 資料流與切片工具能自動追暫存器及部分記憶體定義；指標別名、函式外副作用與跨執行緒資料常需要人工補充。
  • 除錯器的分支追蹤可證明特定輸入實際走過哪些邊，觀察不到的邊仍可能對其他輸入可行。
  • 系統事件能確認切片終點對應的外部效果，但不能自行指出所有上游計算；要靠時間、執行緒與參數把兩邊接起來。
