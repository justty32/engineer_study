# 建置規格

## 頁面契約

- 所有 HTML 使用相對連結；頁首可回首頁、00 起點、字典，頁尾有上一頁／下一頁。
- `<body data-page>` 標示頁面責任；`app.js` 缺少元素時安全略過。
- 輸入皆有標籤，動態結果使用 `aria-live="polite"`，狀態不只靠色彩。
- 第一個畫面直接呈現問題、答案或安全工作台，不設宣傳頁。

## 互動模型

| 頁 | 即時操作 | 輸出與邊界 |
| --- | --- | --- |
| 00 | 選樣本來源與分析目的 | 授權／隔離起點；不是法律意見 |
| 01 | 逐步執行六條虛構指令 | 暫存器、記憶體與旗標；非真實處理器編碼 |
| 02 | 改參數數量、區域變數與呼叫深度 | 堆疊用途與對齊示意；非特定平台 ABI 保證 |
| 03 | 改載入基底與區段相對位移 | 虛擬位址與重定位；簡化單一映像 |
| 04 | 勾選靜態證據 | 假說強度與替代解釋；無真實樣本解析 |
| 05 | 移動程式計數器與切換中斷點 | 暫停前後狀態差異；無反除錯繞過 |
| 06 | 選擇資料來源與分支 | 控制流／資料流切片；無自動解混淆器 |
| 07 | 選觀察現象 | 防禦性證據優先序；不產生攻擊步驟 |

## 品質覆蓋

- 參數實驗：01、02、03。
- 取捨判斷：04 證據量與可信度。
- 故障／假說診斷：05、07。
- 跨層整合：07 串接檔案、行程、系統與網路證據。

## 來源與可延續性

本庫沒有專門逆向工程來源；使用通用、平台中立的概念模型。需要擴充實際格式時，下一位維護者應先選定平台（例如 Windows／Linux、x86-64／AArch64）並加入可追溯的官方格式與 ABI 文件，不能把本課簡化值當規格。
