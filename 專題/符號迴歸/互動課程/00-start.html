實驗 01 / 從輸入、輸出與誤差開始

公式怎麼貼近資料

公式是可執行的規則。先看見每個係數如何改變它，再讓電腦替你搜尋。

這章假設已懂：x 是輸入、y 是輸出。先看下面的數值例，再動旋鈕。

先把「貼近」變成可計算的事

每個橘點是一筆觀測，青線是公式預測。這裡預先用 y = x² + x + 1 產生九個點，x 從 −1 到 1；所有量都沒有單位。你先扮演調參數的人：選好二次式 y = ax² + bx + c，只改 a、b、c。

例如 x = 1 時，資料的 y = 3；若預測 y = 2，差是 −1，平方誤差是 1。均方誤差（mean squared error, MSE）就是把每一點的平方誤差相加，再除以點數。值越小，這批點貼得越近；MSE = 0 代表每個點都吻合。

改係數，還是換公式？

a 控制彎曲程度；a = 0 時，二次項消失，公式只剩直線。b 改一次項，c 把整條曲線上下平移。把 a、b、c 都設成 1，無擾動時 MSE 會回到 0。

現在把擾動幅度拉到 0.6。資料點偏離了原始規律；即使你知道真正公式，對「帶擾動的觀測」也未必能得到零誤差。追逐每個偏移，可能把量測擾動當成規律。

小練習：若只准用 y = bx + c，能讓這九點的誤差變成零嗎？

不能。這九點來自有曲率的二次式，一條直線無法全部穿過。調係數只能在已選的形狀內移動；符號迴歸還必須搜尋形狀。下一章會把這個選擇交給小型列舉器。

這個實驗證明到哪裡？

它能核對一個候選公式對已知資料的誤差。它無法證明這是唯一規律，也無法證明新範圍仍成立。有限資料可能同時符合多條公式。
