# 符號迴歸

[互動實驗室](互動課程/index.html)｜[線上課程](https://justty32.github.io/engineer_study/symbolic-regression/)

從「調整一條公式的係數」開始，走到「搜尋公式的結構」，再用新資料檢查它。四頁短課以人造資料、真實最小平方法與可重設實驗，建立符號迴歸（symbolic regression）的基本直覺。

- [01 公式怎麼貼近資料](互動課程/00-start.html)：係數、曲線與均方誤差。
- [02 在公式空間裡搜尋](互動課程/01-search.html)：基底子集合的完整列舉、節點成本與取捨前緣。
- [03 換一批資料再看](互動課程/02-validation.html)：過度擬合、區間內驗證、外插與 CSV 匯出。

課程無依賴、可直接開啟，不呼叫外部 API，也不執行 PySR。外部一手概念來源與教學模型邊界列於每頁「來源與實驗邊界」。開發延續見 [PROJECT-BRIEF](互動課程/PROJECT-BRIEF.md)、[BUILD-SPEC](互動課程/BUILD-SPEC.md) 與 [驗收紀錄](互動課程/驗收紀錄.md)。
