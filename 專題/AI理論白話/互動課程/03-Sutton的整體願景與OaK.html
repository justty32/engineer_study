03 · Sutton 的 OaK 藍圖要讓智能從持續經驗中，自建預測、技能、模型與更高階抽象

03 — Sutton 的整體願景與 OaK

閱讀時間：約 18 分鐘

為什麼你會在意

本設計也在追問：能否少灌人類規則，讓系統從經驗累積出可重用能力。 可先對照OaK 架構參考理論。本篇補上這張藍圖的地基、五步進程，以及 Sutton 到 2026 年仍承認的三個缺口。

重點不是膜拜一張總藍圖，而是知道每個元件靠什麼經驗學、如何被驗錯，以及哪一段目前仍只有研究問題。 藍圖的價值，在於把缺口也畫進去。

名詞速查

術語白話一句例子
獎賞假說（Reward Hypothesis）把各種目標表成最大化單一累積訊號贏棋與存活都寫成回報
苦澀的教訓（The Bitter Lesson）長期押注可擴張的搜尋與學習自我對弈取代手寫棋譜
Dyna真實互動與模型想像共用一套學習更新下完一手棋，再在腦中推演十手
一般化價值函數（General Value Function, GVF）把知識寫成能由經驗驗錯的預測「伸手靠火，溫度會上升」
Horde同時學很多個 GVF 預測的小單元群一份感測串流養出上千個預測
選項與知識（Options and Knowledge, OaK）由技能與預測知識構成的終身學習藍圖自造「搬障礙」技能並學它的後果
可塑性流失（loss of plasticity）網路持續訓練後逐漸學不進新東西神經元飽和，換新任務也不動
災難性遺忘（catastrophic forgetting）學新資料時把舊能力沖掉新關係學會後忘記舊關係
生成認知（enactive cognition）認知由行動、知覺、身體與環境共同構成看見什麼取決於能怎麼行動
外部接地（external grounding）從系統外持續取得真實校正訊號自我訓練仍保留真人或環境資料

一、獎賞假說與苦澀的教訓：這套願景押注什麼

想解決什麼：AI 研究常把語音、視覺、規劃與控制各自做成專用技巧。Sutton 想找一個能貫穿它們、並隨計算資源擴張的共同原則，而不是每個領域重新灌規則。

核心想法：Sutton 與 Barto 的《Reinforcement Learning: An Introduction》（1998；2018 二版）把多臂老虎機、動態規劃、蒙地卡羅、TD、函數逼近與 policy gradient 放進同一套語言。背後的獎賞假說主張：所有目標與意圖都可表述為最大化某個純量獎賞訊號的累積期望值。2019 年〈The Bitter Lesson〉再補一個工程判斷：回顧棋類、語音與視覺，通用搜尋和學習會持續吃到算力紅利，人手知識短期有效，長期容易封頂。

AlphaZero 是直觀例子。早期棋類程式塞入大量開局與定式；自我對弈路線較少依賴人類棋譜，卻能靠通用搜尋與學習快速提升。苦澀之處不在「人類知識完全無用」，而是人很容易把短期有效的巧思誤認為可長期擴張的地基。

教科書的重要性也不只是整理名詞。它把 prediction 與 control、on-policy 與 off-policy、tabular 與 approximation 放在同一個經驗驅動框架。這使研究者可以問同一組問題：資料從哪個行為策略來，更新目標是否含自己的估計，保證建立在哪些假設上。Sutton 的後續願景仍沿用這套座標。

獎賞假說的力量來自介面簡單。環境每步只要回一個純量，agent 就能比較不同長期行動。它的風險也來自同一處：純量把多重價值壓成單一排序，設計者若漏掉安全、成本或他人偏好，agent 沒有理由自行補回。OaK 會讓能力自己長出來，不會讓缺失的價值規格自己變完整。

和相近理論差在哪：監督學習依賴標註答案；RL 讓行動後果與獎賞提供學習訊號。符號 AI 直接交付命題和規則；Sutton 的路線希望知識以可學、可驗的預測長出來。獎賞假說說明「目標用什麼形式表」，苦澀的教訓則說明「研究資源長期押在哪類方法」。

常見誤解與限制：苦澀的教訓不是「任何領域知識都該刪掉」。環境介面、獎賞函數、感測器與評測仍由人選，這些本身就在注入偏好。獎賞假說也有爭議：道德、好奇心與多重目標是否真能安全壓成一個數字？reward hacking 正是代理數字與真實意圖分離後的陰暗面。

二、TD、策略梯度與 Dyna：從真實經驗擴出想像經驗

想解決什麼：只靠真實互動學習很浪費。一個機器人摔一次的成本很高，如果那筆經驗用完就丟，學習速度很難提升。另一方面，連續動作也不能只靠列舉 Q-table。

核心想法：TD（1988）用下一步估計修正這一步，不必等結局。策略梯度定理（Sutton, McAllester, Singh, Mansour, 2000）證明，可以直接對參數化策略求改進方向，而且公式不需要顯式環境動態，靠採樣就能估。Dyna（1990–91）則一邊和真實環境互動，一邊學環境模型，再從模型生成想像經驗；真實與想像轉移用同一套 TD 規則訓練。

下棋時，人不只記住真正走過的棋，也會在腦中推演未走的變化。Dyna 讓一筆真實互動衍生多筆規劃更新。它把 model-free 學習、model learning 與 planning 放進一個迴圈。

和相近理論差在哪：純 model-free 方法直接從真實轉移更新，不顯式預測環境；純規劃方法假設模型已知。Dyna 同時學模型與價值，再讓模型服務規劃。策略梯度直接改策略，TD value learning 則先估價值；Actor-Critic 把兩者接起來。

常見誤解與限制：想像經驗不是免費真相。模型若把錯誤累積進長推演，規劃更新會污染真實學習。多做 imagined rollouts 只有在模型誤差受控、分布沒有跑太遠時才有幫助。

Dyna 迴圈可拆成四步：真實互動產生 transition；用它更新 value 或 policy；同一筆資料更新環境模型；再從過去狀態抽樣，請模型生成額外 transition 做 planning update。model-free 與 planning 沒有兩套互不相干的學習器，而是共享更新規則，差別只在樣本來自世界還是模型。

這個設計也讓除錯更具體。若真實資料上的 TD error 下降、模型想像上的 error 卻持續升高，問題可能在 world model；若兩者都穩定但策略不進步，可能是規劃抽樣沒有碰到關鍵狀態。把真實與想像來源分開記錄，比只看混合 loss 更容易發現污染。

三、GVF 與 Horde：把知識改寫成可驗證預測

想解決什麼：傳統知識常寫成符號命題，例如「火會燙」。這種句子對人容易懂，對只接收感覺—動作串流的 agent 卻很難自學，也難以用經驗直接推翻。

核心想法：一般化價值函數（General Value Function, GVF）把知識改寫為條件式、帶時間尺度的預測：「若依某策略行動，某個訊號未來的折扣累積值是多少？」Horde（Sutton et al., 2011）讓幾千個預測小單元並行，共用同一份經驗串流，各學自己的 GVF。

「火會燙」可改成「若把手伸向火，溫度感測器在 0.5 秒內會快速上升」。後一句有政策、訊號與時間範圍，能實際測試。知識因此不是永遠正確的字串，而是一群會被新經驗修正的預測。

和相近理論差在哪：知識圖譜保存離散事實；GVF 保存的是在指定策略下對未來訊號的數值預測。一般 value function 常只預測任務獎賞；GVF 可以預測溫度、碰撞、持續時間等任意 cumulant。

常見誤解與限制：可驗證不等於人類可讀。GVF 的問題定義、訊號與策略若選得不好，只會得到大量精確卻無用的預測。Horde 能平行學很多知識，沒有自動回答「哪些預測值得建立」以及如何把它們組成高階概念。

GVF 至少要說清楚三件事：預測累積哪個訊號、在什麼 policy 下預測，以及何時終止或如何折扣。少一項，「未來會怎樣」就沒有可操作語意。同一個溫度感測器，在「向火靠近」和「站著不動」兩個 policy 下，是兩條不同知識。

Horde 的好處是 off-policy：同一條行為經驗可以同時餵給很多個假想 policy 的預測問題。這提高資料利用率，也把致命三角帶回來。大量 demon 並行不表示每一個都穩定，仍需選擇可收斂的更新或監測預測發散。

四、終身學習的障礙：可塑性流失

想解決什麼：OaK 要求所有元件永遠在線學習。深度神經網路卻會在持續訓練中逐漸僵化：新任務來了，梯度仍在算，模型卻再也學不動。

核心想法：Dohare、Sutton 等人在 Nature 2024 系統化描述可塑性流失。神經元飽和、有效自由度崩塌後，模型吸收新資訊的能力衰退。continual backprop 會持續重置少用神經元，像擦掉白板上沒在用的角落，替新內容騰出空間。

和相近理論差在哪：災難性遺忘是「學新後忘舊」；可塑性流失是「連新東西都愈來愈學不進去」。replay、正則化或抽象訓練可能改善前者，不能因此宣稱已解決後者。

常見誤解與限制：continual backprop 是一條緩解路線，不是終身學習已被解完。截至 2026 年中，本輪掃描 342 篇 2025H2–2026 論文，仍沒有找到直接解決 Sutton 意義下可塑性流失的突破性方法。相鄰的災難性遺忘已有零歷史緩衝區方案，但兩個問題不能混稱。

診斷兩者時可做一個簡單對照：保存一個新、容易、從未見過的小任務，定期測目前網路還能否像初始化時一樣快速學會。舊任務掉分主要指向遺忘；連這個新任務的學習速度也持續下降，才是在看可塑性。只量歷史準確率，會把兩種失效混在一條曲線裡。

重置少用神經元也有代價。它可能擦掉尚未頻繁叫用、但在少數重要情境才有用的特徵。所謂「少用」必須配合效用估計、年齡與替換率，不能只按當前 activation 小就刪除。

五、Alberta Plan 與 OaK：抽象如何一層層長出來

想解決什麼：TD、Dyna、GVF 與 options 各自能運作，卻還不是完整智能架構。真正困難的是讓 agent 在不中斷的串流中，自行決定要建立什麼特徵、學什麼技能、做哪些預測，還能用這些資產再往上組合。

核心想法：Alberta Plan（Sutton, Bowling, Pilarski, 2022）提出分步研究路線：agent 從感覺—動作串流出發，用 GVF 自建預測，把預測組成 options，用技能做規劃，在永不停止的設定下持續學習，再逐步形成抽象概念。OaK 是 Options and Knowledge，將這些元件收攏成一張「純從經驗長出智能」的藍圖。

三個招牌特徵是：所有元件持續學習，沒有訓練完就凍結；每個權重可有自己學得的學習率，讓不同部分用不同速度更新；系統反覆跑以下五步進程，自造更高階抽象。

假設 agent 反覆遇到「先搬開障礙，才能抵達目標」：先建立「障礙已移除」特徵，再把移除障礙設成子目標；接著學出搬障礙的 option，學它對環境的影響，最後規劃時把整個技能當成高階動作。下一輪又可在這個基礎上建立更抽象的特徵。

OaK 這一步「學到技能的模型，再把模型拿去規劃」如何接到 2025–26 的可驗證世界模型路線，可接著看20 世界模型。

五步不是只跑一次的流水線。新 option 的模型會改變規劃能看見的未來；新規劃又暴露哪些狀態值得建立特徵。若「門已打開」成為特徵，下一輪可能再形成「房間可通行」；多個房間技能又可組成「抵達建築另一側」。抽象層級是循環累積結果，不是預先畫好的固定樹。

每個權重有自己的學習率，則是處理不同時間尺度的嘗試。短期感測規律可以快速更新，穩定技能模型要慢一些。若全部共用一個全域 learning rate，快訊號會嫌太慢，長期知識又會被新資料沖掉。自動調速的難點在於評估訊號本身也隨 agent 改變。

和相近理論差在哪：單一 HRL 方法通常假設技能或子目標的某些結構已知；OaK 想把特徵發現、技能學習、世界模型與規劃都納入持續成長。符號認知架構多半提供人類可讀的規則與型別；OaK 長出的元件主要是數值函數，不保證可命名或可讀。

常見誤解與限制：OaK 是研究藍圖，不是已跑通的成品。可塑性流失、非平穩、模型誤差、抽象選擇與收斂都仍是開放題。Sutton 與 Rafiee 在 2026 年又明確指出 RL/OaK 還缺三塊：評估判準仍由外部獎賞指定；行動與知覺的不可分割性未充分實現；具身性仍被當成實作細節，而非認知成立的構成條件。

這三個缺口會互相牽動。若身體與環境只是可替換輸入介面，系統很難讓「能做什麼」參與「看見什麼」的形成；若評估仍由外部純量完全指定，agent 也沒有內生判準決定哪些新預測或技能值得建立。生成認知的批評不是替 OaK 多加一個模組，而是要求重新看待 agent、身體與環境的邊界。

因此「純從經驗」不能解讀成「沒有外部世界也行」。經驗正是系統與外界互動後的約束。若資料逐漸全由自身模型生成，錯誤會在自指迴圈裡失去校正來源；2026 的理論結果把外部接地比例不能歸零寫成了明確條件。

  2. 問：Dyna 為什麼可能加速，也可能害到學習？ 答：模型能生成額外更新；模型若錯，想像經驗也會把錯誤灌回價值與策略。
  3. 問：可塑性流失和災難性遺忘差在哪？ 答：前者是新東西學不進去，後者是學新時把舊能力忘掉。
  4. 問：2026 年 Sutton 自己認為 RL/OaK 還缺什麼？ 答：內生評估判準、行動—知覺不可分割性，以及把具身性視為構成條件。
