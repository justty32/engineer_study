20 · agent 腦中那個「環境會怎麼變」的模型，2026 年已不只是一團權重，而是一疊可分開驗收的層

20 — 世界模型

閱讀時間：約 20 分鐘

為什麼你會在意

10 符號接地與具身認知問的是「符號的意義從哪裡來」，世界模型只是讓動作、感知與後果接起來的一種工程解法；本篇專講這個解法內部應怎麼拆、怎麼驗。16 ARC-AGI泛化量尺講的是 ARC 這把尺與多種解法典範，世界模型也只是其中一條路線。

這條線接到世界模型、ARC 與因果歸因的設計筆記：內部模擬器不只要生成未來，還要回答哪個物件變了、換動作會怎樣，並留下可重播的反例。

名詞速查

術語白話一句例子
世界模型（world model）agent 對環境狀態與轉移規則的內部近似在腦中試踩煞車，先看車會不會停
狀態（state）足以支援預測與決策的當下資訊玩家座標、門是否打開、剩餘鑰匙數
轉移函數（transition function）狀態加動作如何產生下一狀態門關著 + 使用鑰匙 → 門打開
前向模型（forward model）從現在與動作預測後果往右走後，玩家會到哪一格
逆模型（inverse model）從想要的結果反推動作想到門外，應先撿鑰匙再開門
rollout在模型裡連續向前模擬多步比較兩條各十步的假想路線
潛在狀態（latent state）網路內部壓縮出的狀態表示，未必可讀一串向量同時編碼位置與速度
介面（interface）模組間允許交換的資訊契約背景只接收接觸力，不讀機器人的全部姿態
物件中心（object-centric）把世界拆成物件及其屬性與互動分開追蹤球、球拍與牆壁
可辨識性（identifiability）資料是否足以排除不等價的內部解釋物件改名可接受，因果方向顛倒則不行
state feedback模擬器直接回傳可查詢的結構化狀態查 player.x，不用再從畫面猜位置
policy exploitation策略專門鑽世界模型的錯誤模型漏算撞牆，策略便反覆穿牆取分

一、2018 的基準案例：在夢裡先走一遍

想解決什麼：真實試錯很貴；機器人每摔一次、agent 每走一條長岔路，都花時間與環境步數。

核心想法：Ha 與 Schmidhuber（2018）先壓縮觀測、再學狀態如何隨動作變化，讓控制器在內部「夢境」練習。前向模型 state + action → next_state 預測後果；逆模型由目標結果反推動作。例如門、鑰匙格子世界可先 rollout「撿鑰匙→開門→前進」，再去真環境執行。這也接到 03 Sutton 的整體願景與 OaK的 Dyna：用真實經驗學模型，再讓模型產生規劃經驗。

和相近理論差在哪：model-free RL 直接學價值或策略；規劃需要可向前推演的模型。逆模型只提動作，不自動處理多步先後；生成影片看似連續，也不代表有可查狀態。

常見誤解與限制：夢境不是免費真相。小偏差會沿長 rollout 累積，policy 還會主動鑽漏洞；因此要分開量單步誤差、長期漂移與回到真環境後的效用。

二、理論邊界：夠通用的能力會洩露環境模型

想解決什麼：世界模型只是可選技巧，還是通用多步能力必然含有的結構？知識可能散在 policy 權重裡，不能只找名為 world_model 的模組。

核心想法：從 agent 面對一族多步目標的選擇，反推它對轉移機率的判斷。例：A 電梯快但會故障，B 慢而穩；單問下一步不足以辨識故障率，要求先取物、再轉樓層並準備備援，穩定成功就會洩露更完整的動態模型。

和相近理論差在哪：定理說能力內含「可重建的轉移資訊」，不保證 agent 採用人類可讀物件、因果圖或物理定律；模仿常見動作也不等於能解新的複合目標。

常見誤解與限制：結論仰賴受控馬可夫過程、多樣深目標與有界失敗率等假設；只做 depth-1 反應不成立。合成環境結果不能直接外推成 production agent 已理解現實。

三、準確的反例：會預測，卻沒有那套物理

想解決什麼：有限資料可讓多條規則同樣擬合；下一步很準，不等於抓到資料背後的機制。

核心想法：歸納偏誤探針看模型在許多小型新任務上自然往哪種規律外推。例如兩段行星軌跡若共享相對位置、速度與質量，牛頓式表示應給一致定律；若不同資料切片各產生一條「物理」，原準確率可能只來自局部捷徑。

和相近理論差在哪：一般測試集量同分布預測；探針量少樣本外推偏好。能從激活讀出變數，也不證明模型實際用它做因果推理；換切片與介入後仍一致才是較強證據。

常見誤解與限制：探針失敗只否定指定結構，不證明模型毫無世界知識；通過也不等於找到唯一真物理。同分布準確率、定律一致性、介入預測與規劃效用應分開報。

四、拆成一疊：潛在模組與程式專家

想解決什麼：單體模型把 agent、背景、規則與獎勵揉成一團；換載體或修局部錯誤時，只能整包重訓。

核心想法：BRICKS-WM 把潛在動力學拆成 Agent、Background 與受限 interface，讓背景可凍結重用。PoE-World 則用許多確定性 Python expert 分別描述移動、碰撞或生成，再加權組合、個別剔除。例：「球撞牆反彈」可讓連續接觸留在神經模組，硬限制與具名狀態留在程式層。

和相近理論差在哪：object-centric 只拆表示，不保證轉移模組可重用；單一大程式雖可讀，也缺少局部降權粒度。神經符號方法還可把動態與獎勵拆開，只改目標便不重學物理。

常見誤解與限制：模組有名字不代表已接地；介面太寬會洩漏細節，太窄會丟物理量，小程式也可能衝突。需測元件、介面、組合、歷史 replay 與遷移表現。

五、生成得像，離 simulator 還差哪些介面

想解決什麼：漂亮、可控制的影片常被叫作 simulator；規劃器卻需要精確 action、state query、重播與規則檢查。

核心想法：把畫質拆成八類能力：資產、物理、互動、可控性、穩定性、state feedback、多樣性與評估。例如車輛影片若只能收「往左」並回 RGB，卻查不到 speed、collision，就不能當控制 ground truth。

驗收面較強的證據
狀態runtime 可查 entity／physical fields
重播固定條件可重現並報變異
用途模型內規劃的 policy 回真環境仍成功

和相近理論差在哪：從 RGB 再估狀態不等於 simulator 直接給真值，兩者的誤差與責任邊界不同；開放域生成模型也不能借用數位孿生的校準保證。

常見誤解與限制：論文未公開介面只能標 absent 或 unresolved，不證明私下沒有；文獻數量也不是成熟度排名。回歸測試要保存 action、初始 state、seed、rollout 與反例。

六、接到 ARC：把規則當可執行的世界

想解決什麼：ARC-1／2 從少數範例推出網格轉換；ARC-AGI-3 則要求 agent 用有限動作邊玩邊發現規則。

核心想法：Loop-OWM 先從示範歸納轉移，再對內部狀態反覆 rollout。Tycho 與 OPINE-World 邊玩邊寫可執行程式，以歷史 transition replay、失敗反例修補。例：紅方塊移動、藍方塊不動時，下一次應探測「紅色」還是「玩家身分」造成可控，而非重複同一動作。

和相近理論差在哪：16 ARC-AGI泛化量尺講整把尺與多種典範，本節只講世界模型路線。Loop-OWM 的中間步驟未必可讀；程式模型可執行，也未必找對目標。

常見誤解與限制：歷史 replay 全對不保證未見介入或規劃有效。ARC-AGI-3 結果還要附底座、harness 是否看過遊戲、run 次數與 action-efficiency；不同底座不能做元件歸因。

七、誠實的難處：辨識、組合與被鑽漏洞

想解決什麼：觀測未必鎖定唯一結構；元件各自合格不代表串接正確；policy 還會主動放大模型漏洞。

核心想法：先聲明容許的等價，再驗介面與整條鏈。物件只換編號可能無害，因果方向顛倒則不行。例如門鎖模型各層單測都過，介面卻把鑰匙 0 對到門 1；或模型漏記鑰匙消耗，policy 就用一把鑰匙開十扇門。

幻覺也要分層：「門已開」與 reference world 衝突是 world-modeling error；知道門沒開卻走錯路是 planning error；知道不確定仍宣稱成功是 incentive error。

和相近理論差在哪：可辨識性問資料能否鎖定結構；組合性問保證能否穿過介面；robust planning 問模型有誤時策略是否仍安全。平均校準擋不住 policy 集中造訪罕見漏洞。

常見誤解與限制：因果階梯與幻覺統一定義是立場／定義框架，不是萬用演算法。本輪材料也未證明逐元件認證能消除 exploitation；部署仍需限制 horizon、真環境抽查、unknown／abstain 與反例回滾。

自我檢核

  1. 問：next-frame 預測很準，為什麼仍不能證明模型學到真實物理？ 答：同一資料分布可能有多條捷徑同樣擬合；要換切片、換任務或做介入，檢查外推規律是否一致。
  2. 問：一個世界模型若要供規劃使用，除了生成畫面還要提供什麼？ 答：至少要有明確 action、可查詢 state、重播與長期穩定度，並量模型內規劃的 policy 回到真環境後是否有效。
  3. 問：模組各自通過測試，為什麼端到端仍可能失敗？ 答：相鄰模組可能使用不一致的物件對應、座標或等價變換；局部保證不會自動穿過介面。
  4. 問：歷史 transition 全部 replay 正確，能否證明規劃可靠？ 答：不能；它只覆蓋已見資料，還要測未見介入、prediction coverage、目標辨識與實際任務效用。
  5. 問：hallucination、planning error 與 incentive error 怎麼分？ 答：前者是對世界狀態的 claim 與 reference world 衝突；後兩者分別是已知狀態下選錯計畫，以及明知不確定仍因誘因裝作確定。

一句話總結

世界模型的重點已從「能不能在夢裡生成未來」移到「能否把感知、具名狀態、轉移、規則、獎勵與驗證拆成可查詢的層」：每層都要說清楚學到了什麼、容許什麼等價、如何被反例推翻，以及串起來後是否真的讓 policy 在真世界做得更好。
