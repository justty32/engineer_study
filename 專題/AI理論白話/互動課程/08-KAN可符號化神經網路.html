08 · KAN 把可學的一維曲線放在網路的邊上，嘗試用梯度找到函數，再把整張網路讀回數學公式

08 — KAN 可符號化神經網路

閱讀時間：約 18 分鐘

為什麼你會在意

本設計希望梯度負責連續搜尋，符號層負責可讀、可驗證的最終表示。KAN 的設計參考提供一座少見的雙向橋：公式可以編成網路，網路也可嘗試還原成公式。關鍵是別把「網路能表示」誤讀成「訓練一定找得回」。

一般的神經網路（MLP）是個黑箱：訓練完之後你拿到的是一大堆權重數字，沒有人看得懂它們的意義，也沒辦法把它變回一條人能讀、能驗算的公式。這在很多場合很要命——尤其是科學研究，科學要的是「公式、定律、可解釋的因果」，而不是一團摸不透的數字。

KAN 想當「神經（連結主義）」和「符號（科學公式）」之間的那座橋：梯度照樣訓練，但最後吐出來的是人看得懂的式子。

名詞速查

術語白話一句例子
KAN（Kolmogorov–Arnold Network）邊上放可學一維函數的神經網路一條邊可以學成近似 sin(x) 的曲線
MLP（多層感知器）邊上是純量權重的傳統網路每條邊只學一個乘數
樣條（spline）用多段平滑曲線拼成的函數調控制點即可改變曲線形狀
符號回歸（symbolic regression）由資料反推可讀公式從觀測值找回 y=x²+1
grid樣條劃分輸入區間的格點數grid 越密，參數通常越多
spline 階 k控制樣條多項式階數的設定階數會影響平滑度與參數量
MultKAN加入乘法節點的 KAN可直接表達兩個子式相乘
kanpiler把既有公式編成 KAN 的工具先把物理公式裝入網路再微調
可回復性（recoverability）訓練能否找回真正公式容得下答案，不代表找得到

一、數學底牌：Kolmogorov–Arnold 表示定理

Kolmogorov 1957、Arnold。

想解決什麼：多變數函數看起來需要直接處理高維交互作用。這條定理替「用一維小函數拼複雜函數」提供數學底牌。

核心想法：任何一個多變數的連續函數，原則上都能寫成「一堆單變數函數的相加與複合」。

白話講：一個牽涉很多變數、看起來很複雜的函數，理論上保證可以拆解成許多「一次只吃一個變數」的簡單一維函數，再把它們加起來、套起來組合。

這條定理長年被認為「只是存在性、不實用」——它告訴你「能拆」，但沒告訴你「怎麼拆、拆出來能不能訓練」。KAN 的貢獻就是把這條定理真的做成了一個可訓練的網路結構。

對程式設計師的比喻：把一個多參數的複雜函數，重構成一堆「單參數小函數」的組合呼叫——這條定理保證這種重構在數學上一定做得到。

和相近理論差在哪：通用近似定理也說 MLP 可以逼近廣泛函數，但不要求內部邊是可直接畫出的單變數曲線。KAN 把函數分解放進架構偏好，讓讀回局部函數成為可能。

常見誤解與限制：存在性只回答「有沒有表示」，不回答指定深度、寬度、變數路由與最佳化器能否找到。同一目標式可以存在於函數空間中，訓練仍可能完全回復失敗。

二、KAN 架構：把可學的曲線放在「邊」上

Liu, Tegmark 等 2024.04。

想解決什麼：MLP 訓練後留下大量純量權重。單看某個權重，很難知道它對應哪個科學關係。KAN 希望每個局部變換都能被畫出、剪枝與命名。

核心想法：KAN 跟傳統 MLP 的設計剛好對著幹：

激活函數（固定的）可學的東西
MLP（傳統）放在節點上放在邊上的是純量權重
KAN——放在邊上的是可學的一維函數（樣條 spline）；節點只做相加

也就是說，KAN 把傳統網路邊上那個「沒意義的純量權重」，換成了一條可以學、而且畫得出來的一維曲線。節點不做別的，只負責把進來的東西加起來。

於是每一條邊都是一條看得見的曲線。這就直接解決了「MLP 是黑箱、權重沒意義、無法解讀」的問題。

為什麼它能直接吐出公式（符號回歸）： 訓練完之後，每條邊上學到的那條樣條曲線，可以被擬合成一個封閉式——看它像 sin、像 exp、還是像 x²，就把它換成對應的數學函數。每條邊都換完之後，整張網路就直接組合成一條方程式。這就是所謂的「符號回歸（symbolic regression）」：用資料反推出背後的公式。

這也巧妙繞過了神經符號的老難題——別人卡在「神經網路那團向量要怎麼接成符號」的斷崖上，KAN 的答案是「讓每一條邊一開始就是一條可解釋的一維函數」，於是符號化只是「擬合一條曲線」，根本不必跨那道斷崖。

和相近理論差在哪：一般符號回歸直接在運算子與語法樹空間搜尋，容易遇到組合爆炸。KAN 先在連續空間找曲線，再做離散化；它少掉部分枚舉，卻增加 spline 參數、最佳化與符號化誤差。

常見誤解與限制：曲線看得見，不代表因果關係正確。兩個高度相關的輸入可以讓邊呈現漂亮形狀，模型仍可能抓到偽相關。評估不能只展示曲線圖，還要測分布外資料、干預與不同種子的一致性。

三、KAN 2.0（MultKAN + kanpiler）：往科學發現走

KANs Meet Science；Liu & Tegmark 2024.08。

想解決什麼：原版 KAN 的節點只做加法，但科學公式常有乘積，也常需要把已知公式先裝入模型再微調。KAN 2.0 想找出相關特徵、揭露模組化結構、發現符號公式。

核心想法：它加了兩個工具：

  • MultKAN：原版 KAN 的節點只會做加法，表達力受限。MultKAN 加入了「乘法節點」，更貼近真實世界公式裡常出現的相乘關係。
  • kanpiler：能把一條符號公式「編譯」成一張 KAN。重點是這是雙向的—— 神經和符號可以來回互轉，這在神經符號領域是很罕見的「可逆介面」。
    • 公式 → KAN（kanpiler）
    • KAN → 公式（符號回歸）

和相近理論差在哪：純神經模型通常只支援「資料到權重」；電腦代數系統只處理已知符號。KAN 2.0 嘗試讓已知公式與可學曲線來回轉換，這是它對科學發現流程最有吸引力的部分。

常見誤解與限制：雙向介面不是無損序列化。公式編成 KAN 後可精確表達，不代表從帶噪資料訓練出的 KAN 能還原同一條短式。乘法節點也增加架構選擇；變數送到不合適的支路時，真正公式可能永遠回不來。

四、誠實的限制（別把它當銀彈）

想解決什麼：一句「會吐公式」漏掉三道關卡：先擬合資料、再把曲線化成短式、最後確認短式穩定且可泛化。任何一道失敗，都不能算找回定律。

核心想法：KAN 很迷人，但有幾個要老實標記的問題：

  • 訓練慢、不穩定：邊上的 B-spline 最佳化容易不穩，許多論文只報「單次跑出來的結果」，其實藏了訓練不穩的事實（換個隨機種子可能結果就不一樣）。
  • 公式未必真好讀：它確實能吐公式，但學出來的式子有時仍然很複雜，不見得是那種一眼看懂的漂亮短式。
  • 準確度不是壓倒性更好：多數情況下，它的準確度只是和 MLP 差不多，不是大幅領先。
  • 參數量是結構性成本：同樣寬深配置下，KAN 的參數量約為 MLP 的 G+k+3 倍，其中 G 是 grid 數，k 是 spline 階。每條邊存的是曲線，不只是一個數。
  • 可表示不等於可回復：同一目標式只因變數路由不同，回復率就能從 0/64 到 64/64；平衡樹拓樸在 3,776 次受控試驗中全面失敗，95% CI 上界為 0.10%。

特別提醒一個容易踩的誤解：「能畫出每條邊的函數」不等於「一定能得到簡短、穩定、且因果正確的公式」。 能可視化、能剪枝，是它的優點；但要真的壓出一條短而正確的式子，還得自己額外下功夫去控制複雜度。

和相近理論差在哪：MLP 的參數主要花在連線權重，KAN 每條邊要表示一整條曲線。MetaKAN 壓縮係數表示；GA-KAN 搜尋連接、grid 與深度，砍掉不需要的結構。兩者處理的是不同成本。

常見誤解與限制：架構容得下答案，只是表達力；訓練能否找到答案，才是可回復性。若只報最好種子與測試內插，這兩件事看起來會被混成一件事。

五、怎麼用它：兩種典型管線

想解決什麼：直接要求 KAN 從原始資料一次吐出最終公式，會把連續擬合、結構分解、符號選擇與驗證擠在同一步。失敗時很難定位。

核心想法：有兩種典型用法：

  1. 當 encoder 或數值子模組：拿它輸出那種「比較容易檢查」的連續變換。
  2. 當符號候選的產生器：先用梯度找出函數大概長什麼形狀，再把這個形狀交給程式搜尋器去離散化、驗證。第二種更符合「梯度負責感知／連續搜尋，符號層負責最終動作」的分工。

KAN-SR 把第二種做法變成完整管線：先用可微 KAN 擬合，再用對稱性與可分離性拆子問題，把網路拆成模組化代數組件，最後匹配符號函數庫，不暴力枚舉完整公式樹。

評估它時，除了看預測誤差，還該量：公式有多長、不同隨機種子跑出來的公式一不一致、在沒見過的分佈上穩不穩、剪枝後性能掉多少、符號化前後誤差差多少。如果到頭來只能得到一堆複雜的 spline，那就不能算真的完成「可控的符號化」。

和相近理論差在哪：端到端 KAN 把希望押在同一張網路；管線式用法允許外部搜尋器重組候選，再用獨立資料或符號驗證器淘汰錯式。後者更符合「梯度找方向，符號層拍板」。

常見誤解與限制：把 spline 替換成 sin 後預測仍準，只表示替換在測試範圍內近似成功。它不證明公式在未觀測區域成立，也不證明變數有因果意義。驗收要加入外插、噪聲、無關變數與種子重跑。

一個可重現的評估流程

第一步先切開「預測」與「回復」。預測測試只看保留資料的誤差；回復測試則把輸出公式正規化後，檢查是否與目標式代數等價。R²>0.99 可能來自一條局部近似式，不能算精確回復。若真實公式未知，就只能報候選式的外插與干預表現，不能宣稱發現定律。

第二步固定資料，系統性改變架構。至少測不同寬度、深度、grid、spline 階與變數路由。每種配置跑多個種子，報成功次數而非只報最佳公式。這能分辨「資料沒有訊息」「最佳化不穩」與「架構路由根本不利回復」。平衡樹 0/3,776 的結果之所以重要，就是它把第三種失敗單獨抓了出來。

第三步記錄符號化的每次手術。剪掉哪條邊、把哪條 spline 換成哪個函式、替換前後誤差各多少，都應留下軌跡。人工看圖後選 sin 也是搜尋的一部分，不能在報告裡當作模型自動發現。GA-KAN 與 KAN-SR 的價值，正是把部分人工判斷轉成可重跑的搜尋步驟。

最後用兩套資料驗證。內插資料檢查曲線在觀測範圍內是否貼合；外插資料檢查公式是否抓到較穩定的結構。若公式在內插準、外插崩，最誠實的稱呼是可讀近似器，不是科學定律。這個區分也適用於所有符號回歸方法，不只 KAN。

符號回歸還有一個報表陷阱：數值擬合與精確式子常被放在同一欄。兩條公式在觀測區間可以幾乎重合，離開區間後卻往相反方向走。若任務目的是壓縮或快速模擬，近似式可能已足夠；若任務目的是科學發現，就必須要求代數等價、單位一致、外插與可重現。先寫清用途，才知道「成功」究竟是哪一種成功。

參數公平比較也不能只配相同層數與寬度。KAN 每條邊的自由度由 grid 與 spline 階決定；MLP 每條邊只有純量。較合理的比較至少要同時提供同寬深、同參數量與同計算預算三組。否則「同結構」可能讓 KAN 取得多很多參數，而「同參數」又會迫使它縮窄，兩種問題回答的其實不同。

自我檢核

  1. 問：KAN 與 MLP 最直觀的架構差異是什麼？ 答：MLP 的邊學純量權重、節點套固定激活函數；KAN 的邊學一維函數、節點主要相加。
  2. 問：表示定理為什麼不能保證找回公式？ 答：它只保證表示存在，不保證指定架構、資料與最佳化能找到。
  3. 問：參數量為什麼可能大很多？ 答：每條邊不是一個數，而是一條由 grid 與 spline 係數描述的曲線。
  4. 問：把 KAN 當候選產生器後還要驗什麼？ 答：公式長度、種子一致性、外插、無關變數、符號化誤差與因果干預。

一句話總結

KAN 是一種「用梯度訓練、但輸出是人看得懂的數學公式」的神經網路——它把可學的一維曲線放在邊上、節點只做加法，於是每條邊都畫得出來，整張網路能直接擬合成一條方程式。

為什麼有人會對它感興趣：因為它證明了「梯度真的可以吐出符號」這條路是通的，等於在神經和符號之間架了一座少見的雙向橋——雖然目前它還慢、還不穩、公式也未必夠漂亮。
