06 · 神經符號 AI 讓神經網路處理模糊感知、符號層執行可檢查推理，再用外部記憶保存可查證知識

06 — 神經符號與外部記憶

閱讀時間：約 19 分鐘

為什麼你會在意

本設計既需要模型從雜訊中辨認模式，也需要規則、記憶與驗證器能追查它為何做出決定。 可先看神經符號與記憶檢索參考理論。本篇把感知、符號化、檢索三個目標拆開，避免把 RAG 或邏輯層誤當成一顆包辦可靠性的銀彈。

名詞速查

術語白話一句例子
神經符號 AI（Neuro-Symbolic AI, NeSy）把學習感知與明確推理接在一起網路認數字，邏輯層做加法
符號接地（symbol grounding）讓符號真的對應世界中的概念pedestrian 必須指行人，不是紅燈
推理捷徑（Reasoning Shortcut, RS）概念接錯，最後標籤卻碰巧正確把行人與紅燈對調仍輸出「停」
外部記憶（external memory）權重以外可讀寫的資訊儲存解題時新增一條概念筆記
神經圖靈機（Neural Turing Machine, NTM）帶可微讀寫頭的神經網路學會把序列寫入矩陣再複製
鍵值記憶（key-value memory）key 用來匹配，value 用來讀取以問題找文件 id，再取正文
檢索增強生成（Retrieval-Augmented Generation, RAG）先找文件，再依文件生成查手冊後回答 API 參數
可微邏輯（differentiable logic）讓推理結果能回傳學習訊號加法答案的誤差回頭教數字辨識
組合泛化（compositional generalization）重組已學元件處理新組合學過紅方塊與藍球後辨認藍方塊

一、NTM 與 DNC：讓網路學會讀寫記憶體

想解決什麼：一般 RNN 把工作記憶塞進固定大小的隱藏狀態。序列一長就容易忘，也很難學出排序、複製或圖遍歷等需要明確暫存的操作。

核心想法：神經圖靈機（NTM；Graves et al., 2014）與可微神經電腦（DNC；2016）在網路旁接一塊矩陣記憶體，再配置讀寫頭。讀取時對每個格子算 0 到 1 的權重，加權取值；寫入時也以軟權重擦除或加入內容。整條路徑可微，所以「該存哪格、何時讀」能由訓練學出來。

程式比喻是：原本只有函式內固定欄位，現在多了一個可隨機存取的 array，連索引策略都要模型自己學。早期實驗讓模型從資料中學會複製、排序與圖上最短路徑等像程式的任務。

和相近理論差在哪：RNN 隱藏狀態是固定容量的壓縮記憶；NTM/DNC 有顯式外部矩陣與尋址機制。RAG 的文件庫通常以離散檢索讀取，NTM 則使用軟性、可微的端到端讀寫。

常見誤解與限制：可微不等於容易訓練。讀寫頭可能分散到太多格、覆寫舊內容，長序列梯度也會不穩。原始 NTM/DNC 在小型演算法任務上漂亮，擴到大容量、長期持續寫入仍很難。

  • NTM 的序列訓練瓶頸可用平行掃描緩解：P-NTM（arXiv 2602.18508）：原文事實（作者自報）：P-NTM 重新設計讀寫與定址後，在 6 個演算法任務上和標準 NTM 同樣達到 100% 完美泛化，測試長度外推到訓練長度的 3 倍；在 A100、序列長度 8 到 65,536 的實驗中，訓練加速為 3.6×–18.5×。證據限於這 6 個帶中間監督的演算法任務，推論仍為序列式，不能直接推出大型長期記憶已解。對本篇的意義：NTM「難以做大」的一部分來自不可平行的時間依賴；平行掃描能直接處理訓練吞吐，但不會順便解掉所有記憶穩定性問題。摘要檔：2602.18508_P_NTM.摘要.md

二、記憶網路、鍵值記憶與 RAG：把知識搬到權重外

想解決什麼：把所有事實壓進模型權重有三個問題：改一條事實可能要重訓，冷門長尾知識記不牢，回答也無法指回來源。外部記憶希望把「知道什麼」和「怎麼生成」分開。

核心想法：Memory Networks（Weston, 2014）把知識存成可查條目。Key-Value Memory Networks（Miller, 2016）把 key 用於相似度匹配，value 用於讀出內容。RAG（Lewis et al., 2020）再把檢索接到語言模型：問題 → 查詢向量 → 檢索文件 → 放入 context → 生成答案。修改事實只需更新外部資料，回答也能附來源。

它像把常數從二進位檔搬到資料庫。與其每改一筆就重新編譯整包，不如 query 相關記錄，再交給模型組織答案。標準 RAG 多半只讀不寫；可寫記憶則能把新解題軌跡、摘要或概念在測試期間加入庫中。

和相近理論差在哪：檢索取回事實；符號化把特徵變成有名稱、型別與組合規則的單位；表徵學習從原始輸入找到可用特徵。RAG 主要解第一件事，不自動解接地或邏輯一致性。概念級記憶保存跨案例可重用的規則，實例級記憶則保存個別軌跡，兩者的干擾模式不同。

常見誤解與限制：檢索是上限。抓錯文件，後面就依錯材料生成；抓對文件，模型仍可能在文件外補寫。可寫也不等於結構能長期維持：記帳、去重、覆寫與時間順序需要專門資料結構與更新規則。ArcMemo 是可寫概念記憶的正面例子；StructMemEval 則顯示純檢索與一般記憶 agent 在結構任務上仍有巨大落差。

外部記憶至少有四種操作，不能只測搜尋：insert 新事實、update 改現有事實、delete 移除失效內容、query 回答問題。若每次更新都只是再插一條文字，舊值和新值會同時被檢索，模型只能猜哪一條較新。真正的可寫記憶需要 id、時間、版本或 supersession 關係。

檢索指標也要和回答指標拆開。召回文件正確卻答錯，問題在 reader 或生成器；文件根本沒取回，才是 retriever 上限。只報最終 accuracy，會把索引、查詢改寫、排序、context 截斷與生成幻覺混成一個數字。

  • 有些問法不是向量記憶檢索得不夠準，而是結構上答不出來（arXiv 2608.13662）：原文事實（作者自報）：單一作者以 835 筆型別化記錄的中立公開語料，比較本體接地方法與生產級向量記憶工具 mem0；在集合完整性、否定（確認某物不存在）與 supersession 追溯三類問題上，前者答對率為 0.98–1.00，mem0 只有 6–27%，而相關性檢索與 token 成本大致打平。這不是多資料集、多作者團隊或長期 production 部署結果。對本篇的意義：完整列舉、證明不存在與追溯取代鏈需要型別化邊和確定性遍歷，不能只靠把向量相似度調得更準。摘要檔：2608.13662_OntologyProjectMemory.摘要.md

三、神經模組網路：把問題拆成可重組操作

想解決什麼：端到端黑箱可能記住訓練組合，換個組合就失效。若「找紅色」「數數量」「比較大小」每次都由整個網路重新學，已知能力很難重用。

核心想法：Neural Module Networks（Andreas et al., 2016）把複雜問題拆成原子神經模組，再依問題語意臨時拼成運算圖。學過找紅色、找方塊與計數後，可以重組成「數紅色方塊」，而不必替這句話另訓一個完整模型。

程式比喻是把推理拆成小函式，再依題目動態組裝呼叫鏈。模組仍可從資料學參數，但連接結構給出較明確的中介步驟。

和相近理論差在哪：單體 Transformer 用同一套參數處理所有問題；NMN 依題目建立不同模組圖。符號程式的模組通常有離散語意與精確執行，神經模組則仍是近似函式。

常見誤解與限制：模組化不會自動產生正確解析。系統仍要判斷題目該呼叫哪些模組、順序為何；解析錯一次，後面每個模組都可能正確執行錯問題。模組名稱也不保證其內部真的學到名稱宣稱的概念。

例如題目問「紅色物件是否比藍色物件多」，合理圖是 find(red) → count、find(blue) → count、再 compare。若 parser 把第一個顏色解析成藍色，所有模組仍可正常執行，最終解釋甚至看起來結構完整。可讀的呼叫圖只證明流程顯式，不證明每個中介語意正確。

四、DeepProbLog 與 Target Propagation：把學習訊號送回去

想解決什麼：神經感知與符號推理若各自訓練，介面錯誤很難從最終答案回傳。標準 backprop 又要求精確導數，生物合理性與深層梯度傳遞也常受質疑。

核心想法：DeepProbLog（Manhaeve et al., 2018）讓 ProbLog 某些事實機率由神經網路輸出，使「神經 → 機率 → 邏輯推理」可端到端微分。只提供加法答案，推理誤差也能回頭教前端辨認數字。Target Propagation（Bengio & Lee, 2015）不逐層傳梯度，而以近似逆映射把頂層目標倒推成各層局部目標，每層只需靠近自己的目標值。

和相近理論差在哪：DeepProbLog 保留明確邏輯程式，把梯度穿過機率推理；Target Propagation 仍是神經網路訓練方法，改的是層間信用訊號。前者處理神經—符號介面，後者試圖替代標準反向傳播。

常見誤解與限制：可微邏輯不保證輸入事實為真，也不保證接地正確。邏輯推理會組合爆炸，難以擴大；Target Propagation 的逆映射難學準，實際效果常輸給 backprop。能把誤差傳回去，只代表可訓練，不代表已可驗證。

「先認數字，再做加法」是好示範，因為規則短且答案容易核對。換成長鏈知識庫後，一個查詢可能展開大量證明路徑，機率質量還要在多條路徑間合併。推理層愈完整，時間與記憶成本愈高；剪枝愈積極，又可能把正確證明剪掉。

五、ECOC 與預測編碼：用冗餘或誤差提高可靠性

想解決什麼：單一分類器一錯就全錯，深層系統也不必把所有輸入原封不動往上傳。兩條老路線分別問：能否用冗餘修正局部錯誤，以及能否只處理「沒料到的部分」。

核心想法：Error-Correcting Output Codes（Dietterich & Bakiri, 1995）把多類分類編成多個二元問題，每個類別對應一串冗餘碼字。預測時收集各位元，找漢明距離最近的合法碼字。碼距夠大時，少數分類器出錯仍可還原。Predictive Coding / Free Energy（Friston）把大腦視為分層預測機：高層預測低層，低層只往上傳預測誤差，系統持續減少驚奇。

和相近理論差在哪：ECOC 是分類輸出結構，可靠性來自碼字冗餘；ensemble 以多模型投票，沒有必然的碼距保證。預測編碼關注訊息流與生成預測，不是分類糾錯碼，也不是一般 RAG。

常見誤解與限制：ECOC 要求碼設計得好，且子分類器錯誤不能高度相關；它不會消除生成幻覺。自由能框架龐大，工程驗證與可反駁性仍有爭議。腦啟發不等於已優於主流 backprop。

六、原型與概念空間：模糊概念怎麼落地

想解決什麼：古典定義要求充要條件，卻很難表達典型性與漸層。知更鳥和企鵝都是鳥，但前者通常更像人心中的典型鳥。

核心想法：Prototype Theory 與 Conceptual Spaces（Rosch, 1970s；Gärdenfors, 2000）把概念視為多維特徵空間中的區域或原型。相似度是空間距離。「黃、弦月形、軟、香、甜」多種感官特徵共現，可共同接地香蕉概念。

和相近理論差在哪：符號定義用離散規則劃界；原型方法以距離表達典型程度。一般 embedding 也有向量距離，但不一定替每個維度提供可解釋品質，也不保證幾何關係符合概念語意。

常見誤解與限制：原型不是接地的完整答案。維度、尺度與權重常仍由人選；多義詞、關係概念與文化差異也難靠單一中心表示。少量概念標註能幫助固定語意，卻增加標註成本。

七、推理捷徑：標籤答對，概念仍可能全錯

想解決什麼：神經符號模型常以最終標籤正確率訓練。若多組概念都會導向同一標籤，模型可能把概念接錯，卻得到零標籤損失。這種錯誤平時看不出來，遇到分布外資料或重用概念時才爆發。

核心想法：推理捷徑（Reasoning Shortcut, RS）指錯誤接地仍得到正確標籤。自駕例子裡，行人和紅燈都導向「停」，模型即使把兩者對調，駕駛標籤仍正確。Theorem 4.10 給出確定性 RS 數目的公式，並指出所有神經符號推理層在 one-hot 概念上的這組捷徑與架構無關；一個標籤可由 k 個概念向量推出時，數量會乘上 k!。Theorem 4.16 更指出，知識複雜度不足時，即使標籤風險為零，概念風險仍可任意大。

和相近理論差在哪：一般 overfitting 是訓練表現好、測試表現差；RS 在分布內測試標籤上也可能一直正確，錯的是中介概念語意。換 DeepProbLog、LTN 或其他推理層不會自動消掉這組確定性捷徑。

常見誤解與限制：接地問題已證明不可能只靠換架構消除，剩下的是選哪種診斷與緩解。以下方法各有代價，沒有萬靈丹。

為什麼標籤測不到？假設規則只有「行人或紅燈出現就停」。真實概念 (行人=1, 紅燈=0) 和錯誤重映射 (行人=0, 紅燈=1) 都輸出「停」。再多收同一種停車標籤，仍無法辨認哪個接地才對。必須加入能破除對稱的概念監督、其他任務或知識限制。

緩解需要概念標註有證明減少 RS主要代價
概念監督是是最直接，也最昂貴
知識編輯否是必須能加入破除對稱的規則
多任務學習是是任務組合不對時仍消不掉捷徑
原型接地少量是假設嵌入可分群
重建否是真實影像重建很難
對比學習否否增強可能改變語意
架構解耦否是需要能可靠切分輸入物件

八、三個目標別混在一起

想解決什麼：看到外部記憶、符號模組或可微邏輯，人很容易把「能查」「能命名」「能推理」當成同一件事，最後替系統宣稱它沒有提供的保證。

核心想法：把目標分開驗收。表徵學習從原始輸入找特徵；符號化把特徵轉成有名稱、型別與組合規則的單位；檢索從外部記憶找回事實。

目標在做什麼對應方法
表徵學習從原始輸入找可用特徵神經網路、對比學習
符號化建立有名稱與規則的單位NeSy、概念空間、邏輯層
檢索取回外部事實Memory Networks、RAG

和相近理論差在哪：RAG 解檢索，不自動解接地；可微邏輯讓規則和梯度共存，不保證前提為真；ECOC 提高分類抗錯，不等於消除生成幻覺。三者可以組合，但驗收證據不能互借。

常見誤解與限制：「神經模組接符號模組」只是架構圖。真正需要測的是概念有沒有接對、記憶更新後是否一致、推理是否合規，以及引用是否真的支持答案。缺一項，就只完成其中一段管線。

一個務實驗收表可以分四欄。接地欄用概念標註或干預測中介語意；記憶欄測插入、更新、刪除、去重與追溯；推理欄以證明器或規則檢查每一步；引用欄確認來源真的支持句子。四欄分開，才能知道錯誤應修 retriever、memory manager、concept encoder 還是 symbolic executor。

自我檢核

  1. 問：RAG、符號化與表徵學習分別解什麼？ 答：RAG 取回事實；符號化建立有名稱與規則的單位；表徵學習從原始輸入找特徵。
  2. 問：可寫記憶為什麼仍不保證可靠？ 答：更新可能破壞記帳、去重、時間順序與覆寫關係，還需要結構化不變量。
  3. 問：推理捷徑和一般測試錯誤差在哪？ 答：RS 可讓最終標籤一直正確，中介概念卻接錯，所以只看標籤測不到。
  4. 問：換一種神經符號推理層能消除確定性 RS 嗎？ 答：不能。one-hot 概念下，確定性捷徑集合與架構無關，只能診斷與緩解。

一句話總結

神經符號 AI 想讓會感知但可能幻覺的神經網路，和可檢查卻依賴正確前提的符號系統分工，再外接可查、可寫、可引用的記憶。RAG 是最落地的檢索管線之一；2026 的關鍵提醒則是：記憶會寫壞，概念也可能接錯而標籤仍正確，所以可靠性必須分別驗收接地、結構更新、推理與引用。
