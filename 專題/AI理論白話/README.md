# AI 理論白話介紹

本專題是**閱讀型導讀**：用白話介紹強化學習、元學習、神經符號、認知架構、對齊、世界模型等 20 篇 AI 理論主題，每篇先講問題與直覺，再講機制與限制；不要求寫程式或作答。

- 讀者基線：預設讀者懂程式，但不熟機器學習數學；術語首次出現時中英對照並附白話說明。
- 線上版本：[GitHub Pages / AI 理論白話介紹](https://justty32.github.io/engineer_study/ai-theory-primer/)（正式發布路徑 `/ai-theory-primer/`）
- 互動課程入口：[互動課程](互動課程/index.html)
- 頁面地圖：[互動課程/README.md](互動課程/README.md)

## 原稿位置與改稿入口

本目錄**沒有 md 原稿**。內容真相層在另一個 repo `machine_learning` 的 `理論白話介紹/*.md`（`00_索引.md`、`01_強化學習入門.md` … `20_世界模型.md`）；`互動課程/` 內的 html、`README.md` 都是產生器 `理論白話介紹/tools/build_html.py` 的輸出。要改內容，改 `machine_learning` 的 md 再重建，不要直接改 `互動課程/` 內的檔案。本檔不在產生器輸出範圍內，可直接編輯。
