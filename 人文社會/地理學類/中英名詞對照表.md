## 4. 計量地理術語

| 中文 | 英文 | 說明 |
| --- | --- | --- |
| 計量地理 | Quantitative Geography | 以數學、統計與計算模型研究地理現象 |
| 空間異質性 | Spatial Heterogeneity | 關係或變異結構隨位置改變的性質 |
| 可調整地區單元問題 | Modifiable Areal Unit Problem (MAUP) | 統計結果隨彙總尺度或分區方式改變的問題 |
| 生態謬誤 | Ecological Fallacy | 由群體層級關係不當推論個體的錯誤 |
| 空間平衡抽樣 | Spatially Balanced Sampling | 使樣點在研究區內均勻涵蓋的抽樣設計 |
| 空間權重矩陣 | Spatial Weights Matrix | 量化各空間單元鄰接或影響關係的矩陣 |
| 空間自相關 | Spatial Autocorrelation | 鄰近位置的屬性值彼此相關的現象 |
| 莫蘭指數 | Moran's I | 衡量全域或局部空間自相關的統計量 |
| 局部空間關聯指標 | Local Indicators of Spatial Association (LISA) | 辨識局部群聚與空間離群的統計量 |
| 熱點分析 | Hot Spot Analysis | 尋找高值或低值顯著聚集區的方法 |
| 距離衰減 | Distance Decay | 互動強度隨距離或成本增加而降低的規律 |
| 重力模型 | Gravity Model | 以起訖規模與阻抗估計空間互動流量的模型 |
| 點型態分析 | Point Pattern Analysis | 分析事件位置之強度、群聚或離散的方法 |
| 完全空間隨機 | Complete Spatial Randomness (CSR) | 均質 Poisson 點過程的常用基準假設 |
| 核密度估計 | Kernel Density Estimation | 以核心函數平滑估計空間事件強度的方法 |
| 雷普利 K 函數 | Ripley's K Function | 在多個距離尺度檢驗點群聚或離散的函數 |
| 空間落後模型 | Spatial Lag Model (SAR) | 將鄰近結果變數納入解釋的空間迴歸模型 |
| 空間誤差模型 | Spatial Error Model (SEM) | 讓誤差項具有空間相依的迴歸模型 |
| 地理加權迴歸 | Geographically Weighted Regression (GWR) | 估計局部且隨位置改變係數的探索方法 |
| 空間插值 | Spatial Interpolation | 由已知樣點推估未觀測位置數值的方法 |
| 反距離權重法 | Inverse Distance Weighting (IDW) | 以距離倒數加權進行插值的方法 |
| 克利金法 | Kriging | 依空間共變異模型進行線性無偏預測的方法 |
| 半變異函數 | Semivariogram | 描述變數差異如何隨距離與方向改變的函數 |
| 塊金 | Nugget | 半變異函數原點附近的微尺度變異或測量誤差 |
| 基臺 | Sill | 半變異函數趨於穩定時的變異水準 |
| 變程 | Range | 空間相關性大致消失的距離 |
| 區位—配置模型 | Location-Allocation Model | 同時選擇設施位置並配置需求的最佳化模型 |
| 最大覆蓋模型 | Maximal Covering Model | 在資源限制下最大化門檻範圍內需求的模型 |
| 網路分析 | Network Analysis | 依節點、邊與成本研究路徑和可及性的方法 |
| 空間分塊交叉驗證 | Spatial Block Cross-Validation | 以空間區塊分離訓練與測試資料的驗證方法 |

## 5. 地理學導論與思想史術語
| 中文 | 英文 | 說明 |
| --- | --- | --- |

| 區域地理學 | Regional Geography | 綜合研究特定地區自然與人文特徵的分支 |

| 空間分析思維 | Spatial Thinking | 以位置、距離與關係推理問題的思考方式 |
