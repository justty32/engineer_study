# 可壓縮流與氣體動力學（Compressible Flow & Gas Dynamics）

> 名詞對照見 [中英名詞對照表-1 → 可壓縮流](../中英名詞對照表-1.md#空氣動力學)。

## 0. 本科定位

當飛行速度超過約 Mach 0.3 時，空氣密度的變化不能再忽略——這就是可壓縮流的世界。本科涵蓋等熵流、正/斜震波、Prandtl–Meyer 膨脹波、噴嘴流，是超音速飛行、噴射引擎進氣道與噴嘴、以及火箭排氣設計的理論基礎。可壓縮流與不可壓縮流最根本的物理差異是：**在超音速流中，下游的擾動無法傳播到上游**——這是震波形成的根源。

### 對擁有者的提醒

可壓縮流的守恆方程（連續、動量、能量）建立了一組非線性代數關係，將熱力學（溫度、壓力、密度、內能）與流體力學（速度、Mach 數）耦合。你在訊號處理中熟悉的「特徵線」（characteristics——沿某些特定方向資訊以有限速度傳播）在可壓縮流中扮演核心角色——超音速流場中 Mach 線（Mach waves）就是數學上的特徵線，沿著這些線物理資訊（壓力擾動）傳播。

## 1. 音速與 Mach 數的物理

### 1.1 音速——氣體的「剛度」

音速 $a = \sqrt{\gamma RT}$（理想氣體——$\gamma = c_p/c_v$）。音速本質上是氣體的「彈性剛度與密度的比值」的平方根——就像彈簧的波速 = $\sqrt{k/m}$。氣體溫度愈高 → 分子動能愈大 → 壓力對密度的回應愈快 → 音速愈大。對空氣（$\gamma=1.4$, $R=287$ J/kg·K）：海平面 15°C → $a \approx 340$ m/s；同溫層 −57°C → $a \approx 295$ m/s（慢了 13%——所以同樣的真實速度在高空 Mach 數更大）。

### 1.2 三種流態的物理直覺

Mach 數 $M = v/a$ 不僅是速度的無因次化——它決定了流場的**資訊傳播結構**。

- **$M < 1$（次音速）**：壓力擾動（以音速傳播的球面波）在流體本身被往下游帶的同時也往上游擴散——上游「知道」下游有一個障礙物，流線在到達障礙物之前就開始偏轉（流線在物體前方就開始彎曲繞開）
- **$M \approx 0.8$–$1.2$（穿音速）**：物體表面的局部流速在某些區域超過音速（形成局部超音速區 + 終止震波），阻力係數暴增——**音障（sound barrier）** 的本質是震波引致的巨大波阻力（wave drag——震波中的不可逆熵增將動能耗散為熱）
- **$M > 1$（超音速）**：壓力擾動無法往上游傳播——上游「不知道」下游有障礙物，直到氣流撞上震波表面才被迫突然轉向。流線在震波處**不連續地**改變方向、速度、壓力、密度

## 2. 等熵流與面積–速度關係

### 2.1 等熵流的守恆

絕熱（無熱交換）+ 可逆（無震波、無摩擦）= **等熵**（$s =$ const）。等熵流的總溫（stagnation temperature $T_0 = T + v^2/(2c_p)$——氣流被絕熱停滯時達到的溫度）與總壓（$P_0$——氣流被等熵停滯時達到的壓力）守恆。從總溫守恆可導出溫度與 Mach 數的關係：

$$\frac{T_0}{T} = 1 + \frac{\gamma-1}{2}M^2.$$

當 $M=2$（$\gamma=1.4$）：$T_0/T = 1.8$——靜溫必須降到只有總溫的 56% 才能達成 $M=2$ 的流速（動能來自熱能的轉化）。

### 2.2 面積–速度關係——收斂–發散噴嘴的物理必然性

可壓縮流在變截面管道中的面積–速度關係：

$$\frac{dA}{A} = (M^2 - 1)\frac{dv}{v}.$$

這是可壓縮流**最違反直覺**的結果。直覺來自次音速日常經驗（花園水管—用手指按住出口縮小截面 = 水噴得更快，$dA < 0 \Rightarrow dv > 0$），但這個直覺在超音速時完全逆轉：

- **$M < 1$**（次音速）：$M^2-1 < 0$ → $dA$ 與 $dv$ 異號 → 截面縮小加速、截面擴大減速（符合直覺）
- **$M > 1$**（超音速）：$M^2-1 > 0$ → $dA$ 與 $dv$ 同號 → 截面縮小減速、**截面擴大大幅加速**（違反日常直覺）

物理原因：超音速時，密度的下降速率比速度的上升速率更快（$\rho v A =$ const——連續方程，當 $dv/v$ 為正時，密度以更大幅度下降，因此面積必須增加來容納體積膨脹的氣體）。**收斂–發散噴嘴（de Laval nozzle）是此關係的必然產物**——先用收斂段加速到音速（喉部 $M=1$），再用發散段繼續加速到超音速。

### 2.3 塞塞流——喉部的物理極限

喉部達到 $M=1$（塞塞 choke）後，再降低出口背壓也不會增加質量流率——因為喉部的流速已達音速，來自出口的壓力降低資訊以音速往上游傳播，但喉部的流速本身也是音速 → 壓力波被「卡在」喉部無法再往上游傳遞 → 喉部上游的流場不再受出口背壓影響。喉部的質量流率僅由上游總壓 $P_0$、總溫 $T_0$、與喉部面積 $A^*$ 決定：

$$\dot{m}_{\max} = \frac{P_0 A^*}{\sqrt{T_0}} \sqrt{\frac{\gamma}{R}\left(\frac{2}{\gamma+1}\right)^{(\gamma+1)/(\gamma-1)}}.$$

這是超音速風洞、火箭引擎、蒸氣渦輪設計中最基本也最重要的公式——給定上游條件與喉部面積，你能獲得的最大質量流率是固定且有限的。

## 3. 震波——超音速流的「價格」

### 3.1 正震波（Normal Shock）的守恆方程

震波是氣體性質的**不連續面**——穿越正震波（垂直於流向）時，守恆方程（質量、動量、能量）給出前後狀態的唯一關係：

$$\frac{P_2}{P_1} = 1 + \frac{2\gamma}{\gamma+1}(M_1^2 - 1),$$

$$\frac{\rho_2}{\rho_1} = \frac{(\gamma+1)M_1^2}{(\gamma-1)M_1^2 + 2},$$

$$M_2^2 = \frac{(\gamma-1)M_1^2 + 2}{2\gamma M_1^2 - (\gamma-1)}.$$

關鍵物理後果：
- 穿越正震波後 Mach 數**必定**降至次音速（$M_2 < 1$）——不管來流多快（$M_1=10$ 穿越正震波後 $M_2 \approx 0.39$——永遠次音速。震波是超音速↔次音速的唯一可能轉換點）
- 壓力、溫度、密度**必定**上升（震波壓縮——但壓縮來源不是活塞而是動能的不可逆轉化）
- **總壓必定下降**（熵必定增加——震波中的黏性耗散與熱傳導是不可逆的。$M_1$ 愈大，總壓損失愈大——這就是為什麼超音速進氣道的設計要盡量用斜震波而非正震波）

### 3.2 斜震波（Oblique Shock）——轉向的代價

氣流通過楔形物體或凹角時被迫轉向，形成附體的斜震波（與流向夾 $\beta$ 角）。氣流穿越斜震波後偏轉 $\theta$ 角。$\theta$–$\beta$–$M$ 關係（斜震波極線圖 shock polar）給出：給定 $M_1$ 與偏轉角 $\theta$，有兩個可能的 $\beta$——強震波解（$\beta$ 接近 90°→近似正震波→穿越後 $M_2<1$）與弱震波解（$\beta$ 較小→穿越後 $M_2$ 可能仍 > 1——超音速進氣道設計的基礎）。

當 $\theta$ 超過最大偏轉角 $\theta_{\max}$（取決於 $M_1$），斜震波從物體表面**脫離**（detached shock——在鈍頭體前方形成弓形震波 bow shock）。太空船的返回艙（鈍體——故意設計成弧形大面積）前方的弓形震波正是脫體震波的經典案例——震波脫體後在中心處接近正震波（最強的減速與加熱），提供回返艙的熱防護。

### 3.3 Prandtl–Meyer 膨脹波——轉向不付代價

超音速氣流通過凸角時，不需震波——而是以**扇形膨脹波（Prandtl–Meyer expansion fan）**連續地加速、降壓、降溫，同時轉向。通過膨脹扇的流動是**等熵的**（無總壓損失——與震波最大的差異）。Prandtl–Meyer 函數 $\nu(M)$ 給出從 $M=1$ 開始膨脹到 $M$ 所需的轉角：

$$\nu(M) = \sqrt{\frac{\gamma+1}{\gamma-1}}\tan^{-1}\!\sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)} - \tan^{-1}\!\sqrt{M^2-1}.$$

當超音速氣流通過機翼後緣的上表面（從高壓的下表面往上轉）——這就是膨脹波使上表面的氣流加速降壓、以配合下表面壓力（滿足 Kutta 條件）。

## 4. 碩士/博士層級延伸

碩士：**穿音速面積律（Transonic Area Rule, Whitcomb 1952）**——飛行器跨音速時波阻力與整機截面積沿軸向的分布的二階導數有關。截面積的突然變化（如機翼與機身的接合處）產生強震波；平滑的截面積分布（將機身腰部捏細——「可樂瓶曲線」coke-bottle shape，讓機翼處的額外面積被機身縮腰補償）可大幅降低跨音速波阻。這是 F-102 從跨不過音速到輕鬆超音速的關鍵改良。**震波–邊界層交互作用**（震波施加的強逆壓梯度使邊界層分離→在震波腳處形成局部氣泡→改變有效外形→震波位置移動→形成非穩態振盪——這是穿音速抖振 buffet 的主要來源）。

博士：**高超声速氣動熱力學**（$M>5$——空氣的動能大到使分子在通過震波後的溫度足以激發分子振動（~800 K）、解離 O₂→2O（~2500 K）、解離 N₂→2N（~4000 K）、甚至電離 N→N⁺+e⁻（~9000 K）——氣體不再是熱量完全（$\gamma=1.4$）的理想氣體，而是發生化學反應的高溫真實氣體，比熱比 $\gamma$ 隨溫度變化，傳統的等熵關係與震波關係全部需要修正）。**震波裝配（shock fitting / shock capturing）**的數值方法——如何在 CFD 中精確捕捉震波的尖銳不連續面而不產生數值振盪（Godunov 法、Roe 近似 Riemann 解、WENO 格式等）。
