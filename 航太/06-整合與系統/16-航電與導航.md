# 航電與導航（Avionics & Navigation）

> 名詞對照見 [中英名詞對照表 → 航電與導航](../中英名詞對照表.md#航電與導航)。

## 0. 本科定位

航電（avionics——aviation + electronics）是飛行器的電子大腦與神經系統：感測、通訊、導航、飛控電腦、顯示與人機介面。對擁有者（電機/通訊背景）而言，這是航太系中與你最直接相關的領域——慣性導航的 Kalman 濾波器、GNSS 訊號處理、感測器融合、冗餘系統的投票表決——這些全都是你的核心技能在航空場景中的應用。

## 1. 慣性導航系統（INS）——自主且不可干擾

### 1.1 IMU 的物理基礎

IMU（慣性量測單元）= 三軸加速度計 + 三軸陀螺儀。傳統機電陀螺儀利用高速旋轉的轉子（~24,000 RPM）的角動量守恆——轉子軸在慣性空間中保持固定方向，飛機繞此軸的旋轉從轉子與殼體之間的相對角度測得（精度可達 0.01°/hr——相當於每小時累積的角誤差只有地球自轉速率的幾百分之一）。現代**環形雷射陀螺 RLG**或**光纖陀螺 FOG**利用 Sagnac 效應——兩束雷射光在閉合光路中沿相反方向傳播，當感測器繞光路平面法線旋轉時，順/逆時針的光路長度不同（因為光路終點在光傳播期間隨旋轉移動了）→兩束光到達偵測器時的相位差正比於旋轉角速度。RLG 無旋轉機械部件→無磨損、啟動快、可靠度極高（民用客機的標準）。

MEMS 陀螺儀（手機、無人機中的微小矽振動結構——Coriolis 力使振動模式耦合到垂直方向→電容變化→角速度）精度較低（漂移率 ~1–10°/s），但體積、重量、成本與功耗極小，適用於短期姿態估計（搭配 Kalman 濾波器以加速度計的重力向量校正）。

### 1.2 積分漂移——INS 的阿基里斯腱

加速度一次積分得速度 → 二次積分得位置。問題：加速度計的微小直流偏壓誤差（~100 µg 對航空級 IMU）在積分中被時間平方放大。10 µg 的偏壓在 1 分鐘後產生的位置誤差 = $\frac{1}{2} \times 10^{-4} \times 60^2 \approx 180$ m——數分鐘後 INS 單獨的位置估算是無用的。**解決方案：Kalman 濾波器融合 INS + GNSS**——GNSS 提供絕對位置（精度數公尺）但更新率低（1–10 Hz）且有訊號遮蔽風險（隧道、都市峽谷）；INS 更新率高（100–1000 Hz）且完全自主但會漂移。Kalman 濾波器用 GNSS 的偶發絕對位置測量來校正 INS 的漂移狀態（位置、速度、姿態誤差 + 加速度計/陀螺儀的偏壓誤差——全部同時在線估計），而 INS 的高頻更新填補兩次 GNSS 量測之間的空白。這是你通訊/訊號處理背景最核心的應用場景——導航就是一個即時的狀態估計問題。

## 2. GNSS——天上的羅盤

四顆衛星即可三維定位（三顆測距確定空間中的交點 + 一顆校正接收端的廉價石英時鐘誤差——因為光速太快，1 µs 的時鐘誤差 = 300 m 的距離誤差，所以接收端的時鐘誤差必須被當作第四個未知數來聯立求解）。

GNSS 誤差來源：**電離層延遲**——太陽輻射使高層大氣（~50–1000 km）的部分原子電離，自由電子使電磁波的相速度與群速度改變，引入數公尺的距離誤差。雙頻接收機（L1 + L2）利用兩個頻率在電離層中的色散關係（延遲 $\propto 1/f^2$）來消除此誤差達 99%+。**多路徑效應**——衛星訊號經地面/建築物反射後間接到達天線（比直達路徑多走了額外距離）→相關器追蹤到的是直達+反射的混合訊號而非真正的直達訊號→距離誤差。高階接收機用 choke ring 天線（同心金屬環的阻抗表面抑制地面反射）與多路徑估測演算法來減輕。

**差分 GNSS**：在已知精確位置的基準站量測 GNSS 的誤差（收到的衛星距離 − 已知的幾何距離 = 誤差），將此誤差修正量透過無線電廣播給附近的移動接收機。大部分共模誤差（衛星時鐘、軌道、電離層——只要基準站與移動站距離不太遠，電離層狀態相似）可以被大幅消除，精度從數公尺提升到數十公分。

**RTK（即時動態定位）**可達 cm 級：除了偽距（pseudorange——從 PRN 碼的相關峰值取得）的誤差修正外，RTK 還利用載波相位（L1 載波的波長僅 ~19 cm——若能追蹤載波的整數週波數，距離解析度可比偽距精細數百倍）。RTK 演算法需要解「整數週波模糊度（integer ambiguity）」——接收機知道載波相位的小數部分（精確到 < 1 mm），但不知道從衛星到接收機之間經過了多少個完整波長。一旦整數解被鎖定（ambiguity resolution——通常需要幾秒到幾十秒的連續觀測），定位精度跳升至公分級。GNSS 現代化的新民用訊號（GPS L5、Galileo E5——更寬的頻寬→更銳利的自相關峰→更佳的多路徑抗性）持續提升可用性。

## 3. 空中資料系統——從壓力到飛行參數

**皮托管（Pitot tube）**：面朝氣流的開口量測**總壓** $P_0$（氣流被停滯於管口的壓力）；**靜壓孔（static port）**：垂直於氣流方向的機身側面小孔量測**靜壓** $P$（氣流未受干擾時的環境壓力）。兩者之差 $P_0 - P$ = **動壓** $q = \frac{1}{2}\rho v^2$ → 校正空速 CAS。從靜壓推導**氣壓高度**（標準大氣的壓力–高度關係——$P$ 每下降 ~1 hPa，高度上升 ~8.3 m 近海平面）。從總溫感測器量測的**總溫** $T_0$ 與靜溫 $T$ 之間的關係（$T_0/T = 1 + 0.2M^2$）推導 **Mach 數**。

**皮托管的致命失效模式**：堵塞（結冰——在雲中飛行時過冷水滴撞擊管口瞬間凍結、昆蟲、火山灰）→無法量測正確的總壓。最危險的場景是**靜壓孔也同時堵塞**（結冰或維護膠帶未撕）→飛機失去所有氣壓參考，飛行員無法得知空速、高度、垂直速度。法航 447 空難（2009）的直接觸發器就是皮托管結冰導致空速指示短暫喪失→飛行員在無可靠空速資訊下操作飛機進入氣動失速。現代飛機配備加熱皮托管（電力加熱——數百 W）、備援的大氣資料系統、以及**合成空速**模式（從 GNSS 地速 + 風速模型 + INS 姿態推算空速，作為皮托管故障時的備援估測）。

## 4. 碩士/博士層級延伸

碩士：**ADS-B（廣播式自動位置回報）**——取代傳統雷達的下一代空管技術：每架飛機以 GNSS 定位自己的精確位置，自發每秒廣播（ID、位置、高度、速度向量）給所有鄰近飛機與地面站。相較於傳統雷達（地面站輪詢掃描→更新率低、只能提供距離方位無 ID），ADS-B 實現了飛機之間的「互相看見」，是自由飛行（free flight——飛行員自主選擇最優航線而非依固定航路）的技術基礎。**合成視覺系統 SVS**：在駕駛艙顯示器上呈現一個以地形資料庫 + GNSS/INS 姿態驅動的虛擬 3D 視野——即使在完全無視野（夜間 + 雲中 + 山區），飛行員看到的是一個清晰的數位合成地形透視圖，標示跑道、障礙物、地形警告著色。SVS 大幅提升了情境意識，降低了可控飛行撞地 CFIT 的風險。

博士：**視覺輔助導航**（無 GNSS 環境——其他行星登陸：光學相機拍攝隕石坑分布→與預載的隕石坑地圖進行圖案匹配→自主確定位置——NASA 的 ALHAT 系統用於月球精準著陸、LVS 用於火星 2020 Perseverance 的自主避障降落。這是一個即時影像特徵匹配 + 6-DOF 位姿最佳化的問題，是你通訊背景中電腦視覺的直接延伸）、**量子慣性感測器**（原子干涉儀利用冷原子的量子波函數干涉來量測加速度與旋轉——精度可比傳統機械陀螺儀高數千倍，且無機械漂移。目前仍處於實驗室階段——需要雷射冷卻與真空腔——但終極目標是提供不依賴 GNSS 的絕對導航能力，可能徹底改變潛艇與太空船的自主導航）。
