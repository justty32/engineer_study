# 飛行器穩定與控制（Aircraft Stability & Control）

> 名詞對照見 [中英名詞對照表-2 → 飛行器穩定與控制](../中英名詞對照表-2.md#飛行器穩定與控制)。

## 0. 本科定位

穩定與控制回答兩個問題：**飛機會不會自己保持姿態**（穩定），以及**飛行員（或自動駕駛）如何操控它**（控制）。分為靜穩定（受到微小擾動後初始反應是往復原還是往更偏離的方向）與動穩定（擾動後的運動隨時間衰減還是發散）。

分析方法的核心是將六自由度非線性運動方程（三個平移 + 三個旋轉——12 個非線性狀態變數：$u, v, w$ 速度分量、$p, q, r$ 角速度分量、$\phi, \theta, \psi$ 姿態角、$x, y, z$ 位置）在穩定飛行工作點（trim point）線性化，得到狀態空間模型 $\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}$——對擁有者而言這與控制系統課程的內容完全同源。

## 1. 靜穩定——被推開後會自己回來嗎

### 1.1 縱向靜穩定

**縱向靜穩定**是飛機最基本的穩定需求：受到陣風使攻角增加 $\Delta\alpha$ 時，氣動力中心（距前緣 ~1/4 弦長處——繞這一點的俯仰力矩係數不隨 $\alpha$ 改變）的升力增量 $\Delta L$ 繞重心產生一個俯仰力矩。若重心在氣動力中心**之前**，此力矩傾向壓低機鼻、復原攻角→**靜穩定**。若重心在氣動力中心之後，力矩傾向繼續抬高機鼻→**靜不穩定**。

**靜穩定裕度（static margin）**：重心位於氣動力中心之前多遠（以弦長比例表示）。大靜裕度 = 非常穩定但升降舵需要提供較大的向下力量來配平（trim——維持想要的攻角）→較大的配平阻力。**放寬靜穩定（Relaxed Static Stability, RSS）**：將重心後移到接近甚至略微在氣動力中心之後→大幅降低配平阻力（配平所需的升降舵負升力接近零→沒有誘導阻力的配平損失），提升航程與機動性。代價是飛機變得不穩定——需要**線傳飛控（fly-by-wire, FBW）**電腦每秒數十次自動修正以維持穩定性。F-16 是最早採用 RSS 的量產機，而這在機械連桿時代（飛行員的駕駛桿透過鋼繩直接連到操縱面）根本不可能實現。

### 1.2 橫向靜穩定——上反角效應

側滑角 $\beta$（飛機不是正對氣流，而是稍微斜著飛）的穩定性來自**上反角效應（dihedral effect）**：側滑產生的橫向氣流（從側面吹向機翼）使側滑側的機翼有效攻角增加→升力增大→滾轉力矩使機翼扶正。上反角（機翼從翼根到翼尖往上翹——從正面看像一個很扁的 V）增強此效應；反之，下反角（anhedral——機翼往下垂，像鷂式戰鬥機的負 V）用於高機動戰機，因為過強的橫向穩定性會使戰機對飛行員的滾轉輸入反應緩慢。

**後掠翼**（sweepback——機翼從翼根到翼尖往後斜）也提供等效上反角效應——側滑使側滑側的機翼相對氣流的有效後掠角減小→升力增加。後掠角愈大，此效應愈強，甚至過強時需要下反角來平衡。

## 2. 動穩定——四種典型模態

### 2.1 縱向雙模態

**短週期模態（short period）**：攻角與俯仰角速度的高頻（1–10 rad/s）、強阻尼振盪。飛行員的感受是「機鼻的快速上下點晃」。此模態必須是**高阻尼**的（$\zeta \ge 0.35$，理想 > 0.5）——阻尼不足的短週期會使飛行員在試圖精確追蹤目標時（空對空瞄準、儀器降落的最後進場）產生操控誘發振盪 PIO（pilot-induced oscillation——飛行員的修正輸入與飛機的自然頻率接近，反而把振幅愈修愈大）。

**長週期模態（phugoid）**：速度與高度的低頻（0.01–0.1 rad/s）、弱阻尼振盪——飛機以長波長的正弦軌跡爬升/下降，但近乎保持定攻角。機械能（位能+動能）在爬升轉下降、下降轉爬升之間來回交換。此模態可以容許輕微不穩定或極弱阻尼——週期長達數十秒，飛行員有充分的時間修正。實際上的 phugoid 阻尼通常來自阻力——速度增加→阻力增加→能量耗散→振幅逐漸衰減，即使沒有飛行員介入也不危險。

### 2.2 橫向雙模態

**螺旋模態（spiral mode）**：極慢的收斂或發散——若發散，飛機以緩慢的螺旋軌跡逐漸進入俯衝轉彎，時間常數可達數十秒。輕微的螺旋發散通常被認為是可以接受的——飛行員有足夠的時間在偏航發展成危險之前將其修正。事實上許多飛機的螺旋模態是刻意設計為輕微發散的——讓飛機在長時間無干擾巡航時不會擅自慢慢轉彎偏離航線（若是收斂的螺旋模態，輕微的初始偏航會緩慢自動修正，使飛機不知不覺中偏離原定航向）。

**荷蘭滾模態（Dutch roll）**：滾轉與偏航的耦合振盪——飛機像溜冰一樣左右來回擺動，中頻（1–3 rad/s）。荷蘭滾模態之所以「Dutch」——荷蘭的溜冰選手左右交替推冰的動作與飛機的滾轉–偏航耦合振盪的模樣相似。此模態必須有足夠的阻尼，否則乘客極度不舒服（後排座位在機尾的最大側向振幅可達數公尺），飛行員也難以精準操控。**偏航阻尼器（yaw damper）**是現代飛機上專門壓制荷蘭滾的自動控制系統——感知偏航角速度（陀螺儀），自動驅動方向舵產生反向偏航力矩來壓制振盪。

## 3. 線傳飛控——從機械連桿到軟體定義飛行

### 3.1 FBW 架構

傳統飛機：飛行員的駕駛桿/踏板以鋼繩（cable）或推拉管（pushrod）**機械式**連接至操縱面（升降舵、副翼、方向舵）的液壓致動器。飛行員直接移動操縱面——飛機的動態直接由飛行員的肌肉感受。

線傳飛控（FBW）：飛行員的駕駛桿輸入 → 位移感測器轉為電訊號 → **飛控電腦**（冗餘的多通道飛行控制電腦——民航機通常 3–4 通道，軍用機通常 4 通道）→ 飛控律（control law——將飛行員的輸入轉譯為操縱面指令的演算法，可在輸出前疊加增穩、包絡保護、陣風減緩）→ 電訊號驅動液壓伺服閥移動操縱面。

### 3.2 包絡保護（Envelope Protection）

FBW 的最大安全價值不是在於取代機械連桿，而是**防止飛行員因失向（spatial disorientation——在雲中或夜間失去地平線參考而誤判飛機姿態）或不當操作而超出飛機的氣動/結構安全邊界**：

- **失速保護**：當攻角接近 $C_{L,\max}$ 時，飛控電腦自動限制進一步的抬頭輸入（駕駛桿拉到底也只到失速邊界而不超越——Airbus 自 A320 起的標準設計）
- **過速保護**：當速度接近 $V_{D}$（設計俯衝速度）時，自動限制進一步的推頭或增加推力
- **過 G 保護**：當正常加速度接近結構正/負 G 極限時，自動限制進一步的俯仰輸入
- **偏航保護**：防止方向舵過度偏轉產生的側向加速度導致垂直尾翼結構超載（AA587 空難——飛行員在遭遇尾渦時反覆激烈蹬舵，方向舵結構最終因過度側向荷載而從垂直尾翼上整片撕裂）

Airbus 的設計哲學是「硬保護」——系統在安全邊界處用硬限制（hard limit）阻止飛行員超出；Boeing 的設計哲學是「軟保護」——系統以增加桿力或警告來提示飛行員正在接近邊界，但仍保留飛行員以更大力量突破保護的能力。兩派哲學各有優劣，沒有絕對的正確答案。

## 4. 碩士/博士延伸

碩士：**LQR/LQG 在飛控律設計的應用**（將穩定度、乘客舒適、操縱品質、致動器飽和等多重目標融合為一個二次型代價函數，自動求解最優的狀態回授增益——F-16 的數位飛控就是用 LQR 設計的）、**非線性動態逆（Nonlinear Dynamic Inversion, NDI）**——用非線性座標變換將原系統的非線性動態轉化為等價的線性系統，然後用線性控制理論設計控制器。NDI 的優點是可以在整個飛行包絡線內以同一控制結構處理強非線性（大攻角機動、失速後機動），而非 Gain Scheduling（在不同飛行條件下切換不同的線性控制器增益）需要在數百個工作點設計控制器並小心內插。博士：**自適應飛控**（飛機在戰鬥中部分氣動面受損——機翼被打出一個大洞或部分尾翼被擊碎——飛控系統自動偵測飛機的動態響應與預期模型之間的差異，即時重新識別氣動模型並調整控制律以維持可控飛行。NASA 的 F-15 ACTIVE 驗證機展示了一種驚人的能力：在右側水平尾翼被刻意鎖死於最大偏轉角的情況下，飛機仍能成功著陸——自適應飛控自動發現並補償了不對稱的氣動力）、**強化學習在飛控的應用**（不基於物理模型，而是讓 AI 在飛行模擬器中嘗試數百萬次——學習哪些控制輸入組合在哪些飛行狀態下能達成目標而不破壞飛機。類似 AlphaGo 的方法論應用在連續控制的物理系統中）。
