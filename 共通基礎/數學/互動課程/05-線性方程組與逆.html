05・從限制條件判斷解的形狀

線性方程組與逆：先判斷有幾種解，再穩健地求解

Ax = b 不一定都有一個漂亮答案：限制可能剛好相交、彼此重複，也可能互相矛盾。這章用消去法、秩與行列式把三種情況分清楚，並說明反矩陣為何存在、又為何實務上通常不直接計算它。

這章假設已懂：04 向量與矩陣、聯立一次方程式與代入法。

痛點：算不出答案，不代表只是算術做錯

電路節點分析、感測器校正與通訊解碼都會產生聯立方程式。初學時常把目標縮成「求 x」，但工程上更早要問的是：資料是否足以決定唯一 x？兩條限制是不是其實說同一件事？量測與模型是否互相矛盾？如果不先分類，除以 0、自由變數或矛盾列便容易被誤認成計算失誤。

二元方程的幾何圖像最直接：每條非退化方程是一條直線。兩線相交有唯一解；兩線重合有無限多解；平行但不重合則無解。高維問題無法總靠畫圖，於是需要秩（rank）把「真正獨立的限制數」數出來，再比較係數矩陣與增廣矩陣的秩。

電機系常見的真實卡關是電路模擬器回報矩陣奇異：學生反覆檢查歐姆定律的正負號，卻沒發現整個浮接子電路缺少參考節點，所有節點電壓一起平移仍滿足原限制。此時不是算術算不出來，而是模型根本沒有提供足夠資訊。另一種情況是兩個感測器校正式互相衝突；硬挑其中一式會產生數字，卻掩蓋資料不一致。

白話直覺：消去是剝掉重複資訊，秩是剩下幾條獨立限制

可以先把高斯消去想成整理會議紀錄：把重複敘述相減，留下真正新增的資訊。比喻到此為止；精確地說，線性方程組（linear system） Ax = b 由若干線性方程構成，高斯消去法（Gaussian elimination）用不改變解集合的基本列運算，把增廣矩陣化成列梯形，再由最後一列向上回代。

rank(A) 是 A 的獨立列數，也等於獨立欄數。把 b 接到 A 右側得到增廣矩陣 [A|b]。若 rank(A) = rank([A|b]) = 未知數個數，每個方向都有獨立限制，因此唯一解；若兩個秩相等但小於未知數個數，限制一致卻不足，因此有自由變數與無限多解；若 rank(A) < rank([A|b])，加入 b 後冒出新的矛盾限制，因此無解。

行列式（determinant）是方陣所代表線性轉換的有向面積或體積倍率。對 2×2 矩陣 A = [[a11,a12],[a21,a22]]，det A = a11a22 − a12a21。det A ≠ 0 表示空間沒有被壓扁，A 有反矩陣（inverse matrix） A−1，且 Ax = b 對每個 b 都有唯一解。det A = 0 則表示至少一個方向消失，無法把轉換完整倒回。

「整理紀錄」的直覺只適用於精確線性關係；帶雜訊的量測幾乎不會剛好化出完全矛盾或完全相同的列，而且數值很小不等於數學上的零。精確地說，基本列運算是交換兩列、把一列乘非零常數、或把一列的倍數加到另一列，這些操作都有可逆步驟，因此保持同一解集合。若問題是近似相依，還必須搭配容許誤差與條件數，不能只靠肉眼判秩。

來源：02-線性代數 §3–§5、§10。

推導：消去到最後，行列式自然出現在分母

從一般二元系統開始：

a11x + a12y = b1

a21x + a22y = b2

先假設 a11 ≠ 0。用第二式減去 (a21/a11) 倍第一式，x 項會抵消：

(a22 − a21a12/a11)y = b2 − a21b1/a11

兩邊乘 a11，得到：

(a11a22 − a12a21)y = a11b2 − a21b1

消去時之所以用第二式減去那個倍數，是因為新的 x 係數成為 a21 − (a21/a11)a11，恰好抵消；同一倍數也必須作用到 y 項與等號右側，才不會改變解集合。接著乘回 a11只是清除分母，前提仍是先前假設它非零。若跳過這些理由，容易把消去誤解成可以只改某一個係數，或在主元為零時仍偷偷做了除以零。

左邊 y 的係數正是 det A。若 det A ≠ 0，就可相除而得 y = (a11b2 − b1a21)/det A；代回第一式整理，可得 x = (b1a22 − a12b2)/det A。這就是 2×2 的克拉瑪法則。det 不是突然定義的神秘量，而是消去到最後必須拿來當分母的數；它為 0 時，唯一解的推導就在此停住。

把兩個答案同時整理成矩陣形式：

A−1 = (1/det A) ⋅ [[a22,−a12],[−a21,a11]]

驗證不能只背外觀。直接相乘 A A−1：左上角為 (a11a22 − a12a21)/det A = 1；右上角為 (−a11a12 + a12a11)/det A = 0；左下角為 (a21a22 − a22a21)/det A = 0；右下角為 (−a21a12 + a22a11)/det A = 1。因此 A A−1 = I，確實能把 A 的作用倒回。

若資料列多於未知數，Ax = b 往往沒有精確解。最小平方法（least squares）改求讓殘差 |Ax − b| 最小的 x̂。最佳殘差必須與 A 的每一欄正交，所以 AT(Ax̂ − b) = 0，展開為 ATAx̂ = ATb；在 ATA 可逆時，x̂ = (ATA)−1ATb。幾何上，Ax̂ 是 b 投影到 A 欄空間後的最近點。

正交條件來自「最近點」：若殘差沿欄空間還留有分量，就能沿某個 A 的欄方向微調 x̂，使距離繼續縮短，因此最小值處的殘差必須垂直所有可調方向。乘上 AT正是一次收集殘差與每一欄的內積。若直接背最後公式，常會誤以為最小平方讓殘差消失，或忘了 ATA 可能病態甚至不可逆。

數值實例：唯一解、重合與矛盾三種情況

取 2x + y = 5、x − y = 1，故 A = [[2,1],[1,−1]]，b = (5,1)。det A = 2⋅(−1) − 1⋅1 = −3 ≠ 0，所以 rank(A) = rank([A|b]) = 2，存在唯一解。兩式相加得 3x = 6，因此 x = 2；代回 2x + y = 5，得 y = 1。

反矩陣為 A−1 = (1/−3)[[−1,−1],[−1,2]] = [[0.333333,0.333333],[0.333333,−0.666667]]。乘上 b：第一分量為 0.333333⋅5 + 0.333333⋅1 = 2，第二分量為 0.333333⋅5 − 0.666667⋅1 = 1，所以 A−1b = (2,1)，與消去法一致。回代也得到 2⋅2 + 1 = 5、2 − 1 = 1。

作為對照，把第二式改成 4x + 2y = 10；它只是第一式乘 2，所以 det A = 0，rank(A) = rank([A|b]) = 1，解是整條 2x + y = 5，有無限多個。若第二式改成 4x + 2y = 7，左側方向仍相同，右側卻不相容，rank(A) = 1 而 rank([A|b]) = 2，兩條平行線無交點，因此無解。

把唯一解的算式拆開看，兩式相加會讓 y 與 −y 抵消，剩下的 3x = 6 只含一個未知數；求得 x = 2 後回代，2x 已貢獻 4，所以要補到右側 5，y 必須是 1。反矩陣乘 b 則把同一組消去係數預先收在矩陣內。這組數字告訴你：答案可信不只因兩條路都得到 (2,1)，還因回代同時滿足兩條原始限制；後兩組對照則說明係數相依後，右側是否以相同比例變化才決定相容性。

自由實驗：判斷二元方程組有幾種解

這裡示範係數與常數如何決定唯一解、無限多解或無解。拖動六個值，先看 det 與兩種秩，再看回代或幾何判讀。

為什麼／不要混淆

  • det A = 0 不等於方程組一定無解。它只否定唯一解；若 b 與重複限制相容就有無限多解，不相容才是無解。
  • 反矩陣只對方陣討論，而且方陣也不保證可逆。非方陣或奇異方陣應改用消去、分解或最小平方觀點。
  • rank(A) 數的是獨立限制，不是非零元素個數。兩列都有很多非零數，仍可能因一列是另一列的倍數而只有秩 1。
  • A−1b 是正確的數學表示，不代表數值程式應先形成 A−1。實務通常用 LU 分解（LU decomposition）或求解器直接解 Ax = b，計算更省且誤差通常更好控制。
  • 列運算會保留方程組的解集合，但通常不保留原矩陣所代表的幾何轉換。消去是在解方程，不是在說新矩陣與舊矩陣做完全相同的變換。
  • 最小平方不是硬把無解說成有解；它明確改了問題，求的是殘差平方和最小的近似解，並應同時檢查殘差大小。
  • det A 很小與 det A 恰為 0 不同。前者仍可能有唯一解，卻對量測誤差非常敏感；這種數值不穩定要看尺度與條件數，不能用單一固定門檻武斷分類。

可觀察證據

在電路節點方程中，唯一解代表每個節點電壓被元件與來源完整決定；少接一條參考地可能讓矩陣秩不足，模擬器便回報奇異矩陣。感測器校正若收集許多帶雜訊的量測，方程通常不會精確相交，最小平方輸出的殘差就是模型與資料不一致的可觀察量。

在程式中，把預設係數輸入求解器，應看到 det = −3、rank(A) = 2、rank([A|b]) = 2 與解 (2,1)，兩條回代式也應分別回到 5 與 1。將第二列設成第一列的兩倍，再只改 b2，輸出會從無限多解跳到無解；這個跳變正是增廣秩辨認矛盾的證據。

還可讓程式印出殘差向量 r = Ax − b 及其長度：精確唯一解的每個分量應接近零，過定量測的最小平方解則可再印 ATr，檢查殘差是否與各欄近似正交。實驗桌上若是節點分析，可用電表逐點量電壓並代回各節點的電流平衡式；這能檢查解是否符合模型與量測，卻不能單獨證明元件模型在所有工作區都正確。

連到哪門課

本章服務電路學的節點與網孔分析、通訊系統的通道解碼、控制系統的平衡點計算，以及機器學習的線性迴歸。第 06 章會把 det(A − λI) = 0 當成一個特殊方程組，用它找出矩陣保留方向的模式。機器人課程另有以幾何與求解流程為主的解方程式與逆可交叉練習。

在電路學中，節點分析要解導納矩陣與來源向量；通訊原理在迫零等化與通道估測會面對可逆性、秩與雜訊放大；控制課在求平衡點及穩態增益時要解聯立限制；機器學習的線性迴歸則用最小平方處理樣本多於參數的情形。這些課真正重視的不只是解向量，而是能說明唯一性、殘差與數值敏感度各自代表什麼工程風險。
