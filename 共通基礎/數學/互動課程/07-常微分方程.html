07・用方程描述系統如何隨時間演化

常微分方程：從 RC 充電讀懂自然響應與數值穩定

工程系統的未知量往往不是一個數，而是整段隨時間變化的波形。這章從一階 RC 電路建立時間常數，再走到二階阻尼、狀態空間與 Euler 前向法，讓方程、物理響應和程式近似接在一起。

這章假設已懂：01 極限與導數、06 特徵值與分解。

痛點：未知的是整條曲線，不是代回去就能得到的數

代數方程 2x + 1 = 5 的未知數是 x；常微分方程（ordinary differential equation, ODE）的未知數卻是函式 y(t)，方程同時限制它的值、斜率與更高階導數。只知道某一刻的斜率不等於知道整條曲線，還必須給初始值，才能從起點沿著方程指定的方向往前走。電容電壓、馬達轉速、機械位移與控制器狀態都屬於這類問題。

ODE 的最高導數決定階數（order）；未知函式及其導數只以一次方出現且不彼此相乘時稱線性（linear）；係數不隨時間變叫常係數。右側為零的齊次（homogeneous）方程描述系統離開平衡後自己留下的自然響應，右側非零則有外力造成的強迫響應。這些分類不是名詞遊戲，而是在告訴我們可用哪種解法、需要幾個初始條件，以及響應能否疊加。

階數也對應系統必須記住多少初始資訊。一階 RC 只需一個初始電壓；二階 RLC 通常需要電容電壓與電感電流，或等價的輸出初值與一階導數。這些初值代表儲能元件當下保存的能量狀態，不能只靠外加輸入推回。若漏掉初值，求到的不是唯一時間波形，而是一族都滿足微分式的候選解。

白話直覺：時間常數像每秒吃掉固定比例的距離

可先把 RC 充電想成每隔一段時間就補掉「距離目標還差多少」的一部分：差距大時改變快，快到目標時改變慢。比喻到此為止；精確地說，RC dv/dt + v = vs，也就是 dv/dt = (vs − v)/τ，且 τ = RC。導數正比於目前誤差，因此誤差不是每秒減固定伏特，而是按固定比例指數衰減。

一階線性標準型是 dy/dt + p(t)y = q(t)。乘上積分因子（integrating factor） μ(t) = e∫p dt 後，左側合成 d(μy)/dt，積分便能求 y。二階常係數式 ay″ + by′ + cy = f(t) 則先看特徵方程 aλ² + bλ + c = 0：兩相異實根給過阻尼，重根給臨界阻尼，共軛複根給欠阻尼。標準式 y″ + 2ζωny′ + ωn²y = ωn²u(t) 中，自然頻率 ωn 描述無阻尼時想振多快，阻尼比 ζ 決定振盪是否出現及包絡衰減程度。

完整解是齊次解加特解：前者承載初始能量，後者追隨輸入。把高階方程改寫成狀態空間（state space） ẋ = Ax + Bu、y = Cx + Du，可得 x(t) = eAtx(0) + ∫0t eA(t−τ)Bu(τ) dτ。第一項是自然響應，第二項是輸入累積的強迫響應；矩陣 A 的特徵值實部決定自然響應衰減或放大，正好接回第 06 章。

這也解釋線性系統為何能使用疊加：若輸入拆成兩段，積分項可拆成兩個積分，輸出就是兩份響應相加。不過元件飽和、摩擦死區或電晶體非線性會破壞這個性質；此時線性 ODE 常只是工作點附近的小訊號近似，不能把局部模型外推到任意振幅。

來源：03-工程數學-上 第 1 章 §1.1–§1.5。

推導：從 RC 分離變數到 Euler 的誤差倍率

（a）解析解。由 RC dv/dt + v = vs 且 τ = RC，移項得 dv/dt = (vs − v)/τ。把 v 與 t 分到兩側：

dv/(vs − v) = dt/τ

兩邊積分，左側因分母對 v 的導數為 −1，所以得到 −ln|vs − v| = t/τ + C。指數化後可把常數合併為 K，寫成 vs − v = K e−t/τ。代入 v(0) = v0 得 K = vs − v0，再整理便是：

v(t) = vs + (v0 − vs)e−t/τ

（b）Euler 前向法。若程式只保存離散時刻 vk，就在 tk 用前向差商近似導數：dv/dt ≈ (vk+1 − vk)/Δt。代回 dv/dt = (vs − v)/τ，得到 (vk+1 − vk)/Δt = (vs − vk)/τ。兩邊乘 Δt 並移項：

vk+1 = vk + (Δt/τ)(vs − vk)

這不是另一套神祕公式，而是第 01 章「導數就是極限差商」在有限步長下的直接應用。每一步用當下斜率畫一小段切線；曲率使這段直線與真正曲線產生局部誤差，累積後形成全域一階誤差。

（c）數值穩定性。把穩態 vs 從遞迴兩側扣掉，可得 vk+1 − vs = (1 − Δt/τ)(vk − vs)。所以每一步的誤差都乘 q = 1 − Δt/τ。當 Δt/τ < 1，q 在 0 與 1 之間，誤差同號且單調縮小；當 1 < Δt/τ < 2，q 在 −1 與 0 之間，誤差交替換邊但幅度縮小；當 Δt/τ > 2，|q| > 1，誤差越乘越大而發散。邊界 Δt/τ = 2 時 |q| = 1，誤差不消失。這是演算法自己的穩定性，不能反過來宣稱真實 RC 電路會振盪或爆掉。

數值實例：同一秒，解析曲線與離散切線走出不同位置

取 τ = 1 s、v0 = 0 V、vs = 5 V，解析解為 v(t) = 5(1 − e−t)。在 t = 1 s，也就是一個時間常數時，e−1 = 0.367879，所以 v = 5⋅0.632121 = 3.160603 V，完成總變化的 63.2 %。到 t = 5τ 時仍非數學上的 100 %，但已達 99.3 %，工程上常視為接近穩態。

改用 Δt = 0.1 s 走 10 步，誤差倍率是 (1 − 0.1)10 = 0.910 = 0.348678，得到 v = 5(1 − 0.348678) = 3.256608 V，比真值高 0.096005 V。步長減為 0.05 s 時全域誤差約減半，顯示 Euler 前向法是一階方法。另取 ζ = 0.5、ωn = 2 rad/s，根為 λ = −ζωn ± ωn√(ζ²−1) = −1 ± j1.732051；負實部造成衰減，非零虛部造成振盪，因此是欠阻尼。

自由實驗：比較 RC 解析解與 Euler 步進

這裡示範同一個穩定 RC 方程如何因步長不同而得到準確、假振盪或發散的數值解。調整時間常數、初值、外加電壓、觀察時刻與步長，觀察解析值、Euler 誤差及 Δt/τ 的判讀。

為什麼／不要混淆

  • τ 是完成總變化 63.2 % 所需的時間，不是到達 100 % 的時間；指數曲線只會漸近穩態。
  • 數值不穩定不等於物理不穩定。穩定 RC 電路也會被過大的 Euler 步長算出假振盪與發散。
  • 齊次解是系統由初始能量產生的自然響應；特解是外部輸入維持的強迫響應，兩者相加才是完整解。
  • ζ = 1 的「最快」有條件：它是在不產生超調的解之中最快，不代表所有性能指標下的絕對最快。
  • ωn 是無阻尼自然頻率；欠阻尼實際振盪頻率還受 ζ 影響，不能把兩者直接當同一個量。

可觀察證據

在麵包板接 RC 串聯電路並輸入步階，示波器上從初值走完 63.2 % 所需的時間就是 τ；改變 R 或 C，曲線時間尺度會按乘積 RC 改變。RLC 或控制迴路的步階響應若出現超調與振鈴，可由峰值、週期和包絡估計 ζ 與 ωn。在程式模擬裡固定物理參數只放大 Δt，若曲線開始左右跳過穩態甚至增幅，便是數值方法造成的可重現證據。

還可做步長收斂檢查：以同一觀察時刻分別使用 Δt、Δt/2 與 Δt/4，若 Euler 誤差大致依序減半，就符合一階方法的預測。若減小步長後結果不收斂，問題可能來自程式索引、單位、停止時刻取整或方程本身，而不是用一句「電路有雜訊」就能帶過。

連到哪門課

ODE 直接服務電路學的 RC、RL、RLC 暫態，控制系統的狀態空間與穩定性，信號與系統的線性時不變模型，以及馬達與機械系統動態。下一章會把導數轉成 s 的乘法，使含初值的微分方程變成代數方程；第 11 章則把單一時間變數擴展成同時依賴時間與空間的偏微分方程。

學到這裡，應能沿著一條完整因果鏈閱讀模型：先由元件定律與守恆關係寫出 ODE，再由初值決定自然響應的權重，由輸入決定特解，最後檢查特徵根與數值步長。面對模擬結果異常時，也應先分層判斷：若解析解本身成長，是模型的動態不穩定；若解析解衰減而離散值爆掉，是演算法步長問題；若兩者都合理但量測不同，才回頭檢查元件容差、未建模效應與量測條件。這套分層診斷比只會代公式更接近後續控制與電路課的實際用法。
