09・把乘法看成旋轉加伸縮

複變入門：用複數代數處理幅值、相位與交流電路

複數不是為了容納「算不出的平方根」而已；它把平面旋轉與伸縮壓進一次乘法。當弦波寫成複指數，微分、相位移與交流阻抗便能在同一套代數中處理。

這章假設已懂：08 拉氏轉換、三角函數與平面座標。

痛點：弦波的振幅與相位若分開算，微分與串接很快失控

交流電壓 V cos(ωt + φ) 同時帶有振幅、頻率和相位。多個元件串接後，直接展開 sin、cos 加法公式會產生大量交叉項；每微分一次又要換函式並乘 ω。若只用實數，旋轉看起來像兩條互相耦合的式子，很難像一般增益那樣直接相乘。

複數 z = x + jy 的直角形式把平面點記成一個數，電機慣用 j 代表 √(−1)，避免與電流 i 混淆。它的極形式是 z = r ejθ，其中 r = |z| = √(x²+y²)，θ = arg z = atan2(y,x)。歐拉公式（Euler's formula） ejθ = cos θ + j sin θ 把代數乘法與平面旋轉接起來。

直角形式適合相加，因為實部與虛部分別相加即可；極形式適合相乘與相除，因為模長相乘除、幅角相加減。工程計算常在兩種形式間切換，而不是選一種永遠使用。atan2 同時看 x、y 的正負，能判斷象限；只算一般的反正切 y/x 會在 x = 0 失效，也會把相差 180° 的方向混在一起。

白話直覺：每個複數都是一個「轉幾度、放大幾倍」的指令

可以先把非零複數想成旋鈕：模長 r 決定放大倍率，幅角 θ 決定逆時針旋轉角度。比喻到此為止；精確地說，乘法遵守 |zw| = |z||w| 與 arg(zw) = arg z + arg w，而幅角只在相差 2π 的意義下相同。程式常用主值範圍 (−180°, 180°] 顯示結果。

由歐拉公式可得 cos θ = (ejθ + e−jθ)/2，以及 sin θ = (ejθ − e−jθ)/(2j)。更關鍵的是 d/dt ejωt = jωejωt：微分不再把 cos 換成 sin，而是讓同一複指數乘上 jω。把 v(t) = V cos(ωt + φ) 的共同時間因子暫時省略，只保留 相量（phasor） V = V ejφ，就能用複數代數算單一頻率的正弦穩態。

因此電阻、電感、電容的阻抗分別是 ZR = R、ZL = jωL、ZC = 1/(jωC)。相量版歐姆定律 V = ZI 同時處理幅值比與相位差。但相量固定在單一 ω，不能描述開關瞬間或多頻率暫態；那些問題要回到時間域或拉氏域。

電容關係 i = C dv/dt 同樣給 I = jωC V，所以 ZC = V/I = 1/(jωC) = −j/(ωC)。它的負九十度幅角表示電容電壓落後電流；頻率越高，阻抗模長越小。電感與電容的相位方向、頻率趨勢正好相反，這可由微分作用與變數位於分子或分母直接推得，不必孤立背誦。

來源：03-工程數學-中 第 3 章 §3.1–§3.6。

推導：同一次乘法的極形式與直角形式必須會合

（a）旋轉與伸縮。令 z = r1ejθ1、w = r2ejθ2。指數相乘時指數相加：

(r1ejθ1)(r2ejθ2) = r1r2ej(θ1+θ2)

結果模長是 r1r2，幅角是 θ1 + θ2，所以 w 的效果確實是把 z 的長度乘 |w| 並把方向加上 arg w。再改用 z = x1 + jy1、w = x2 + jy2 展開。利用 j² = −1：

(x1+jy1)(x2+jy2) = (x1x2 − y1y2) + j(x1y2 + y1x2)

兩式只是同一乘積的不同座標描述，所以數值必須完全一致。極形式容易看幾何效果；直角形式適合直接由實部、虛部運算。

（b）從微分推出電感阻抗。以複指數代表電流 i(t) 的正弦穩態核心 I ejωt。電感關係 v = L di/dt 變成 v = L(jωI ejωt)。兩側都有相同 ejωt，取相量後得到 V = jωL I，因此 ZL = V/I = jωL。乘 j 表示電壓比電流超前 90°，乘 ωL 表示幅值比隨頻率增大。

複變不只處理相量。若 f(z) = u(x,y) + jv(x,y) 在鄰域內複可微，稱為解析（analytic），並須滿足柯西—黎曼方程（Cauchy–Riemann equations） ∂u/∂x = ∂v/∂y、∂u/∂y = −∂v/∂x。解析比沿實軸可微強得多。若閉曲線內解析，柯西積分定理給 ∮C f(z) dz = 0；柯西積分公式則寫成 f(z0) = (1/(2πj))∮C f(z)/(z−z0) dz，表示內部一點的值受邊界值決定。有孤立極點時，留數定理（residue theorem）給 ∮C f(z) dz = 2πj Σ Res(f,zk)，可用於反拉氏與反傅立葉。解析映射在導數非零處保角，史密斯圖就是工程上常見的保角映射應用。

解析性的嚴格要求帶來強大結果：函數內部值受邊界約束，封閉路徑積分可由少數奇點資訊決定。這也說明留數不是憑空加上的技巧，而是把每個極點附近最關鍵的係數彙總，再取代整條複雜路徑積分。對工程學習者而言，先抓住「奇點決定反轉換中的自然模式」，再逐步學圍道選擇，比只背公式更能與上一章的極點觀念接軌。

數值實例：乘以純 j 就是轉九十度

取 z = 1 + j，w = 0 + j。z 的模 |z| = √2 = 1.414214，幅角為 45°；w 的模為 1，幅角為 90°。直角形式展開：

(1+j)(0+j) = 1⋅0 − 1⋅1 + j(1⋅1 + 1⋅0) = −1 + j

極形式則預測 |zw| = 1.414214⋅1 = 1.414214，arg(zw) = 45° + 90° = 135°。−1 + j 的模確為 √2，幅角也確為 135°，兩種算法會合。因 |w| = 1，長度不變；因 arg w = 90°，方向逆時針轉 90°。這就是「乘以 j」的精確幾何意義。

自由實驗：把複數乘法拆成旋轉與伸縮

這裡示範直角展開與極形式其實給同一個乘積。調整 z、w 的實部與虛部，觀察模長相乘、幅角相加以及純 j 或單位圓乘數的特殊判讀。

為什麼／不要混淆

  • j 是 √(−1) 的數學記號，不是電流；電機改用 j 正是為了避開電流符號 i。
  • 幅角具有 2π 多值性。135°、495° 描述同一方向，程式顯示主值不代表其他表示錯誤。
  • 複解析要求從平面任意方向逼近都得到同一導數，比實變函數可微強得多，不能只檢查一條方向。
  • 相量只適用於線性系統的單一頻率正弦穩態；開關暫態、變頻訊號與非線性產生的新頻率不能只靠一個相量。
  • 複數乘法會旋轉並伸縮；只有乘數模長等於 1 時才是純旋轉，不能把所有複數乘法都當作保長。

可觀察證據

向量電壓表與網路分析儀直接輸出幅值與相位，正是複數極形式的量測版本。傳輸線在史密斯圖上沿等駐波比圓轉動，可讀成反射係數相位變化；電感電壓在正弦穩態下超前電流 90°，可用雙通道示波器驗證。程式中的複數陣列與快速傅立葉轉換則把每個頻率槽保存為實部加虛部，讓振幅和相位都不丟失。

還可用兩條獨立計算路徑做自我檢查：先用直角公式求乘積，再把兩個輸入的模長相乘、幅角相加後轉回直角。若答案不同，常見原因是角度與弧度混用、象限判斷錯誤，或把 j² 寫成正一。這種交叉驗證在相量網路與通訊星座計算中特別實用。

連到哪門課

複數與相量直接服務電路學交流分析、信號與系統、通訊調變、控制頻率響應、傳輸線與微波工程；解析函數和留數再通往反轉換與場論。若要把同一個平面旋轉改用實數矩陣理解，可對照機器人數學基礎：二維旋轉矩陣。下一章會把複指數當成頻率積木，疊出一般訊號。

因此複數在電機裡扮演的不是額外維度，而是把兩個互相耦合的實數分量包成一個可組合物件。交流電路把同頻率訊號的實、虛部包在相量，通訊把同相與正交分量包成星座點，控制把衰減率與振盪率包成複極點。每次使用前都要問清楚兩個軸的物理意義以及共同假設；同一個 j 在相量、拉氏平面與複分析中遵守相同代數，但被包裝的量與允許的推論並不完全相同。能在幾何、代數和量測三種表示間往返，才算真正掌握這章。計算後也應把結果轉回幅值、相位或波形，確認它能被實際儀器觀察。
