01・從平均變化逼近瞬間變化

極限與導數：輸入動一點，輸出當下動多快

導數不是一張要背的微分表，它把「很小的輸入變化」換成「預測輸出會變多少」的局部模型。我們會先從兩點的平均斜率出發，再用極限說清楚為什麼它可以成為一點的瞬時斜率。

這章假設已懂：00 工程數學地圖、函式是「輸入對應輸出」的規則。

痛點：瞬間沒有時間間隔，怎麼可能算變化率

在實驗課量 RC 電路時，學生常把示波器游標停在某一點，卻不知道怎麼由離散取樣估出該刻的 dv/dt；若直接拿相鄰兩點相減，答案又會隨取樣間隔與雜訊大幅跳動。這不是儀器「沒有導數功能」而已，而是連續時間的瞬時量必須由有限間隔資料逼近，步長選擇也會成為誤差的一部分。

平均速度容易算：位置變化除以經過時間。但若要問某一瞬間的速度，直覺上時間間隔必須是 0，這會變成 0 當分母。電路中的 i = C dv/dt 也有同樣困難：我們想知道電壓當下變得多快，可是儀器與程式只能取到相隔某個步長的兩筆數值。

極限的作用正是避免「直接代入 0」。我們先保留一個非 0 的步長 h，計算平均變化率，再問 h 越來越靠近 0 時整個比值越來越靠近什麼。計算過程中 h 始終不是 0，所以不會發生除以 0；極限描述的是逼近趨勢，而非把間隔一開始就設成 0。

白話直覺：局部放大後，平滑曲線看起來像直線

再精確收束一次：在 x 附近若存在一個有限數 m，使輸出增量可寫成 f(x+Δx) − f(x) = mΔx + 相對於 Δx 更小的誤差，那麼 m 就是 f′(x)。因此「像直線」不是視覺感受，而是當 Δx 趨近零時，非線性剩餘量相對於 Δx 變得可忽略。

這個放大比喻在尖角、跳躍、強雜訊或有限解析度下會失效。|x| 的尖角無論放多大，左右斜率仍不同；量測波形放得過細時，看到的也可能是 ADC 量化階梯與雜訊，而非理想曲線。此時不能僅憑畫面看似平滑就宣稱導數存在。

想像把曲線上某一點不斷放大，只要曲線在該點夠平滑，視野內的小段會越來越像一條直線。這是很有用的比喻，但精確定義是：極限（Limit） lim(x→a) f(x) = L 表示當 x 逼近 a 時，f(x) 可以任意逼近 L；它不要求 x = a，也不先要求 f(a) 有定義。

連續（Continuity）則多了在該點的條件：lim(x→a) f(x) = f(a)。導數（Derivative）定義為 f′(x) = lim(h→0) (f(x+h) − f(x)) / h，它同時是曲線在 x 的切線斜率與輸出對輸入的瞬時變化率。此定義假設上述極限存在且為有限值；尖角、跳躍或垂直切線都要另行判斷。

導數能生成局部的一次模型：f(x+Δx) ≈ f(x) + f′(x) Δx。這叫線性近似（Linear approximation），也是工程小訊號近似的根本。它的適用條件是 Δx 夠小、展開點附近可微，而且被省略的高階項相對不大；它不是對任意大變化都成立的工程保證。

來源：01-微積分 §1–§3。

推導：從 x² 的差商看見 2x，並比較兩種數值誤差

展開平方後之所以能消去 x²，是因為差商比較的是兩個函式值的增量；接著把 2xh + h² 提出共同因子 h，才有 h(2x+h)/h。約分只對 h ≠ 0 合法，而極限定義恰好只要求 h 靠近零、不要求 h 等於零，所以代數約分與極限條件彼此相容。

若跳過「先提因子、再約分、最後取極限」，很容易誤解成導數允許把零當分母，或以為 h 可以任意刪掉。中央差商也不是因為取樣點較多就必然較準；真正原因是左右展開後的偶對稱與奇對稱項按代數抵消。沒有平滑性或左右取樣不對稱時，這個誤差結論便不能直接沿用。

把 f(x) = x² 完整代入導數定義：

f′(x) = lim(h→0) ((x+h)² − x²) / h

先展開平方：(x+h)² = x² + 2xh + h²，所以

((x+h)² − x²) / h = (x² + 2xh + h² − x²) / h = (2xh + h²) / h

在 h 仍非 0 時可以約去共同因子 h，得到 2x + h。現在才取 h → 0 的極限，得 f′(x) = 2x。所以 h 沒有被憑空丟掉；它先讓差商合法，約分後再由極限使剩餘的 h 項趨近 0。對 x² 而言，用有限 h 計算前向差商時得到 2x + h，所以殘留的 h 正是誤差主項。

一般平滑函式可在 x 附近寫成 f(x+h) = f(x) + f′(x)h + f″(x)h²/2 + f‴(x)h³/6 + …。放入前向差商後，得 (f(x+h) − f(x)) / h = f′(x) + f″(x)h/2 + …，因此主誤差與 h 成正比，是一階近似。

中央差商同時取左右兩點：(f(x+h) − f(x−h)) / (2h)。將兩邊展開：f(x+h) = f(x) + f′(x)h + f″(x)h²/2 + f‴(x)h³/6 + …，f(x−h) = f(x) − f′(x)h + f″(x)h²/2 − f‴(x)h³/6 + …。相減時常數項與 h² 項互相抵消，除以 2h 後得 f′(x) + f‴(x)h²/6 + …，因此一次誤差項消失，誤差降到 h² 等級。

常用的符號規則都能回到這個定義：乘冪律 d/dx xn = n xn−1；乘法律 (fg)′ = f′g + fg′；連鎖律 d/dx f(g(x)) = f′(g(x)) g′(x)。要找局部極值時，對可微函式先解 f′(x) = 0 只能得到候選點，尚需由導數正負變化、二階導數或邊界值判斷是極大、極小還是都不是。

數值實例：x = 1、h = 0.1 時的前向與中央差商

把前向計算拆成動作，就是先求右側函式值，再減去觀察點函式值，所得輸出增量除以輸入增量；中央計算則先取等距左右兩側的函式值，其輸入總距離正好是兩個 h。這組數字告訴我們：對二次函式，對稱取樣可完全消去造成偏差的二次彎曲項；對正弦函式仍有更高階彎曲，因此只是大幅減少而非消滅誤差。

以 f(x) = x²、x0 = 1、h = 0.1 為預設值。前向差商是 (1.1² − 1²) / 0.1 = (1.21 − 1) / 0.1 = 2.100000。解析導數 f′(1) = 2，所以絕對誤差是 0.100000，正好等於 h。這不是巧合，因為 x² 的前向差商已被化簡為 2x + h。

中央差商是 (1.1² − 0.9²) / 0.2 = (1.21 − 0.81) / 0.2 = 2.000000，對這個二次函式剛好沒有截斷誤差，因為它的三階導數為 0。這不表示中央差商對所有函式都精確；它通常只是誤差階數較高。

換成 f(x) = sin x，仍用 x0 = 1、h = 0.1，且 x 以弧度計：前向差商為 0.497364，真實導數 cos 1 約為 0.540302，誤差 0.042939，約對應 h/2 ⋅ |f″|。中央差商為 0.539402，誤差 0.000900，約對應 h²/6 ⋅ |f‴|。同一個 h 下，一次誤差項抵消帶來的改善很明顯。

自由實驗：看差商怎麼逼近導數

這個實驗示範前向與中央差商如何估計解析導數。選函式、移動觀察點，再縮小 h，注意誤差先下降、h 極小時又因浮點相消上升。

為什麼／不要混淆

  • 極限存在不等於該點有定義：極限看附近的趨勢，f(a) 卻是該點本身的值；只有連續時兩者才相等。
  • 可微可以推出連續，反向不成立：|x| 在 0 連續，但左右斜率分別為 −1 與 1，因此不可微。
  • 導數是局部變化率，不是總變化量：要從變化率恢復一段區間的總變化，需要下一章的積分。
  • sin 的導數為 cos 假設弧度制：若輸入用度數，連鎖律會額外產生 π/180 因子。
  • h 不是越小就永遠越好：截斷誤差會隨 h 縮小，但 f(x+h) 與 f(x) 太接近時，浮點減法會吃掉有效位數。
  • 差商估計不等於解析導數：前者受步長、取樣率、量化與雜訊影響；只有在條件合適並觀察收斂趨勢時，才能把它當成後者的近似。

可觀察證據

可把示波器兩條數學軌跡分別設成電壓與相鄰樣本差分，緩慢提高輸入正弦波頻率；在振幅相同下，差分軌跡的幅度應隨波形變快而增加。游標量到的峰值能支持變化率關係，但也要檢查取樣率是否足以排除混疊。

程式驗證時，逐列印出 h、前向差商、中央差商、解析值與絕對誤差，再計算縮小步長前後的誤差比。這比只印最後答案更能分辨截斷誤差與浮點誤差，也能直接看見中央法在哪一段步長範圍內呈現較快收斂。

在示波器上把時間軸縮短，任一平滑波形在局部都會越來越像直線，而這條局部直線的斜率就對應導數。電容兩端電壓變化越快，量到的電流就越大，這是 i = C dv/dt 可在實驗上觀察的對應。控制系統中，誤差的導數則告訴控制器誤差正在改善還是惡化。

在程式中固定 x，把 h 由 1 持續縮小，再把數值差商與解析導數的誤差列出，通常會看到誤差先下降後上升。前半段是截斷誤差變小，後半段是浮點相消開始主導；這條 V 形趨勢正是「數學極限」與「有限精度電腦」之間差異的直接證據。

連到哪門課

在電路學的電容與電感元件方程中，導數把端電壓或電流連到儲能狀態的變化；控制系統的根軌跡之前，先要能由狀態方程辨認速度與加速度；信號與系統則在微分器、斜率限制與連續時間系統模型使用本章。電子學的小訊號跨導與機器學習的反向傳播，則分別把局部斜率解讀為工作點增益與參數敏感度。

電路學用導數表示電容電壓與電感電流的瞬時變化；控制系統用它描述位置、速度、加速度與誤差變化率；機器學習則用梯度尋找參數改變時目標函式下降最快的方向。更偏機器人應用的版本見 機器人數學基礎 11 變化率、導數與梯度。
