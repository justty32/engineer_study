06・找出轉換最自然的方向

特徵值與分解：從混合變化中拆出獨立模式

矩陣通常同時改變向量的方向與長度，但有些特殊方向只被伸縮，不會偏轉。找到這些方向與倍率，就能把耦合系統拆成較簡單的模式，直接讀出反覆作用、振動與穩定性。

這章假設已懂：05 線性方程組與逆、2×2 行列式與二次方程求根。

痛點：知道 Ax，仍看不出反覆作用後會怎樣

給一個矩陣與一個向量，直接相乘不難；真正的工程問題往往是同一轉換反覆發生。離散系統要算 Akx，連續狀態方程要理解 eAtx(0)，結構振動要分辨多個自然模式。若每一步都回到原座標逐項展開，耦合項會快速增多，也很難看出哪個模式主導長期行為。

我們需要一組「適合這個矩陣」的方向，使矩陣沿每個方向只做單純伸縮。換到這組座標後，原本互相牽動的分量可望分開處理。這便是特徵值、特徵向量與對角化的核心；其他矩陣分解則把類似思想推廣到正交化、最小平方及任意形狀矩陣。

具體卡關常出現在控制實驗：學生看到兩個狀態波形一邊振盪一邊衰減，只能逐點讀圖，改了一個回授增益後也不知道為何整體突然發散。原座標中的每個狀態往往混有多個模式，單看某一條曲線不等於看見某一個物理機制。把狀態拆到特徵方向後，才能分辨哪個模式衰減最慢、哪個模式被增益推向不穩定。

白話直覺：特徵向量是經過機器仍不轉彎的方向

可以把矩陣想成一台會拉伸、壓縮、翻轉並混合方向的機器。大部分箭頭送進去後都會轉彎，但少數箭頭只變長、變短或反向。比喻之後要回到精確定義：若非零向量 v 滿足 Av = λv，則 v 是特徵向量（eigenvector），純量 λ 是對應的特徵值（eigenvalue）。v ≠ 0 很重要，因為零向量對任何 λ 都滿足等式，卻不能提供方向。

λ 的大小表示該模式每次作用的伸縮倍率；λ 為負還會翻向。連續系統 ẋ = Ax 的模式隨時間帶有 eλt：λ 實部為負時衰減，為正時成長，非零虛部造成振盪。這就是為何控制系統不必把每條時間響應都畫完，先看 A 的特徵值位置就能判斷內部模式是否衰減。

內積（inner product） u⋅v = Σ uivi衡量兩向量的方向關係；內積為 0 稱為正交（orthogonal）。把向量投影到正交基底上，就是逐一取出彼此不干擾的分量。傅立葉分析把訊號投影到正交弦波，與本章把狀態拆成模式，是同一種「選對基底，複雜耦合會變簡單」的思考。

「不轉彎的方向」在二維實平面很好想像，但這個直覺會在剪切矩陣、重根缺少方向或複數特徵值時失效：實平面上可能找不到足夠多條互不相依的特徵方向，也未必能畫出複數模式。精確定義仍只有 Av = λv、v 非零；是否能用一整組特徵向量當基底，則是額外的可對角化條件，不能由「矩陣一定有模式」直接推得。

來源：02-線性代數 §6–§9。

推導：從非零解條件得到特徵多項式

從定義 Av = λv 開始，把右側移到左側：

Av − λv = 0

因為 Iv = v，可把 λv 寫成 λIv，再提出 v：

(A − λI)v = 0

這裡必須引入 I，因為純量 λ 不能直接與矩陣 A 相減；λI 才是與 A 同尺寸、且對 v 產生 λv 的線性轉換。把兩項合併後，問題從「輸出平行於輸入」改寫為「哪個矩陣具有非零零空間」。若跳過 I 與尺寸檢查，容易把 A − λ 當成每個元素都減 λ，連非對角元素也錯誤改動。

這是一個齊次線性方程組。若 A − λI 可逆，兩邊乘它的反矩陣只會得到 v = 0；但特徵向量要求 v ≠ 0。因此要有非零解，A − λI 必須不可逆，也就是：

det(A − λI) = 0

對 A = [[a11,a12],[a21,a22]]，先寫 A − λI = [[a11−λ,a12],[a21,a22−λ]]。展開行列式：

(a11−λ)(a22−λ) − a12a21 = 0

乘開並依 λ 次方整理：

λ² − (a11+a22)λ + (a11a22 − a12a21) = 0

令跡 T = a11 + a22，行列式 D = a11a22 − a12a21，便得到特徵多項式 λ² − Tλ + D = 0。用求根公式：

λ = (T ± √(T² − 4D)) / 2

判別式 T² − 4D 大於 0 時有兩個相異實根，等於 0 時有重根，小於 0 時有一對共軛複根。找到 λ 後代回 (A − λI)v = 0。若 a12 ≠ 0，可取 v = (a12, λ − a11)；代入第一列得到 (a11−λ)a12 + a12(λ−a11) = 0，確實成立，第二列則因特徵行列式為 0 而相依。若 a12 = 0，應改從另一列或另一欄挑不退化的表示，不能硬套這個方便公式。

若 n×n 矩陣有 n 個線性獨立特徵向量，把它們依序放成 P 的欄，把對應特徵值放在對角矩陣 D 的對角線，便有 AP = PD。右乘 P−1 得對角化（diagonalization） A = P D P−1。因此 Ak = P Dk P−1，因為中間的 P−1P 逐次消成 I；同理 eAt = P eDt P−1。難算的矩陣冪或矩陣指數，轉成對每個 λ 分別算 λk 或 eλt。

AP = PD 的每一欄其實就是 Avj = λjvj，所以不是憑空猜出矩陣等式。P 的欄獨立才使 P 可逆，P−1先把原座標轉成模式座標，D 分別縮放各模式，P 再轉回原座標。若省略座標轉換的次序，容易誤以為 D 的對角元素直接對應原本各狀態，或認為只要找到特徵值就一定能寫出 P−1。

數值實例：兩個正交模式與一個非特徵方向

取 A = [[2,1],[1,2]]。跡 T = 2 + 2 = 4，行列式 D = 2⋅2 − 1⋅1 = 3，判別式 T² − 4D = 16 − 12 = 4，大於 0。因此 λ = (4 ± 2)/2，得到 λ1 = 3、λ2 = 1。

對 λ = 3，用 v = (a12,λ−a11) 得 v1 = (1,1)。驗證 A(1,1) = (2⋅1 + 1⋅1, 1⋅1 + 2⋅1) = (3,3) = 3⋅(1,1)。對 λ = 1，得 v2 = (1,−1)，而 A(1,−1) = (1,−1) = 1⋅(1,−1)。兩者內積為 1⋅1 + 1⋅(−1) = 0，所以正交；實對稱矩陣可選到彼此正交的特徵向量。

下方預設測試向量是 v = (1,0)。Av = (2,1)，點積 v⋅Av = 2，兩者長度分別為 1 與 √5，因此夾角 = acos(2/(1⋅√5)) = 26.565° ≠ 0。輸出並未與輸入平行，所以 (1,0) 不是特徵向量。這個反例提醒：每個向量都能被矩陣作用，但只有方向保持平行的非零向量才配稱特徵向量。

逐步解讀前兩個模式：沿 (1,1) 的兩個分量同向變化，矩陣作用後兩個輸出都累加成 3，因此整個方向被放大；沿 (1,−1) 時，交叉項與自身項部分抵消，結果維持原向量。相反地，(1,0) 可視為這兩個正交方向的混合，所以作用後兩種倍率不同，重新合成便產生偏轉。這組數字告訴你，原座標看見的轉向其實可以來自多個不轉向模式以不同倍率演化。

為什麼／不要混淆

  • 特徵向量不是被矩陣「完全不改變」；它的方向保持平行，但長度可乘 λ，λ 為負時方向還會翻轉。只有 λ = 1 才是向量本身不變。
  • 零向量不能當特徵向量。否則 Av = λv 對所有 λ 都成立，特徵值便失去辨識矩陣模式的能力。
  • det A 是所有特徵值的乘積，跡是所有特徵值的和；但 det A 本身不是「最大的特徵值」，跡也不是任一單獨模式。
  • 有特徵值不保證能對角化。重根可能缺少足夠的線性獨立特徵向量，此時不能組成可逆的 P。
  • ẋ = Ax 的漸近穩定條件是所有特徵值實部皆負，不是特徵值必須都是負實數。帶負實部的複數特徵值代表振盪衰減。
  • 對稱矩陣的不同特徵值所對應特徵向量可取為正交，但一般矩陣的特徵向量不必正交，甚至可能是複數。
  • 特徵分解與奇異值分解不是同一件事。奇異值分解（Singular Value Decomposition, SVD） A = U Σ VT 適用任意矩陣，奇異值皆非負；特徵分解對矩陣形狀與可對角化性有額外條件。
  • 特徵向量的長度沒有唯一標準。同一方向乘上任何非零常數仍是特徵向量；比較模式形狀前通常先正規化，不能把表示尺度誤當成物理振幅。

可觀察證據

控制系統的狀態輸出若含有 eλt 模式，量測曲線會直接呈現特徵值的效果：負實部讓包絡衰減，正實部讓振幅成長，虛部決定振盪頻率。結構與電路的模態分析會得到各自的自然頻率與模式形狀；把系統沿某個模式激發，量測到的各節點或各質點會依該特徵向量的比例共同變化。

QR 分解（QR decomposition） A = QR 把欄方向正交化，常用來穩健求最小平方；SVD 則把輸入先沿 VT 的正交方向重排，再由 Σ 分別伸縮，最後由 U 轉到輸出方向。主成分分析（Principal Component Analysis, PCA）以此找資料變異最大的方向，影像壓縮保留較大的奇異值，多天線預編碼則用奇異向量拆出較獨立的通道。這些結果都可在程式輸出的模態倍率、重建誤差或通道增益中觀察。

程式驗證可同時印出每組 λ、v 以及殘差 Av − λv 的長度；殘差接近零才表示數值上吻合，而只看到特徵多項式接近零還不足以確認向量配對正確。控制或電路實驗中，可給系統短暫擾動，從量測波形估計相鄰峰值的衰減與振盪週期，再與特徵值預測的包絡和頻率比對；量到吻合支持線性化模型在該工作點附近有效，不能證明大訊號或飽和區仍適用。
