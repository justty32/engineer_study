08・把微分問題搬到複數代數平面

拉氏轉換：用極點直接讀出衰減、振盪與穩定性

拉氏轉換把一整段時間波形編碼成複變數 s 的函式，使導數成為乘法並把初值一起帶進去。你不只會少算微分方程，還能從極點位置直接預測暫態會消失、持續振盪或放大。

這章假設已懂：07 常微分方程、基本積分與複數記號。

痛點：解出式子以前，我們就想知道系統會不會穩

微分方程在時間域裡同時有 y、y′、y″ 與輸入，初始條件又要另外處理。當電路串接、控制方塊相乘或輸入改變時，每次從頭積分並不划算。工程師更常先問：系統受到擾動會不會回來？衰減多快？會振幾次？這些問題若只盯著原始微分式，關係藏在係數與解的指數裡，不容易一眼辨認。

拉氏轉換（Laplace transform）把 f(t) 映成 F(s) = ∫0∞ f(t)e−st dt，其中 s = σ + jω。實部 σ 提供指數加權，虛部 ω 掃描振盪，因此它比只取 s = jω 的傅立葉觀點更能處理暫態與可能不絕對可積分的訊號。積分是否收斂還取決於收斂域（Region of Convergence, ROC），常見形式是 Re(s) > σ0。

白話直覺：把微分機器換成乘法標籤

可先把轉換想成替每種「衰減加振盪」模式貼上權重，然後在另一張工作桌上組合它們。比喻到此為止；精確定義仍是加權積分 F(s)，而「微分變乘 s」並非口訣硬規定，是分部積分後產生的結果，而且必須保留邊界上的初值。

核心對應包括 f′ → sF(s) − f(0)、f″ → s²F(s) − sf(0) − f′(0)、時間積分 → F(s)/s、時移 → e−asF(s)、頻移 → F(s−a)，以及卷積 → F(s)G(s)。常見轉換對是 1 → 1/s、t → 1/s²、e−at → 1/(s+a)、sin ωt → ω/(s²+ω²)、cos ωt → s/(s²+ω²)、δ(t) → 1。這張表讓微分方程依序經過取拉氏、解代數、部分分式與反查表四步回到時間域。

零初始條件下，輸出與輸入之比 H(s) = Y(s)/U(s) 稱轉移函數（transfer function）。使分母為零的 s 是極點（pole），對應自然響應的指數速率；使分子為零的是零點（zero），會改變各模式在輸出中的權重。連續系統所有極點都在左半平面才會衰減。初值定理 f(0⁺) = lim(s→∞) sF(s) 可檢查起點；終值定理 f(∞) = lim(s→0) sF(s) 只在相關極點符合穩定條件時可用。

極點位置還能拆成兩個可量測尺度。共軛極點的實部越負，包絡下降越快，安定時間通常越短；虛部絕對值越大，相同時間內來回振盪的圈數越多。兩者共同決定阻尼比，不能只看極點離原點多遠。零點雖不直接新增自然模式，卻可能放大、壓低甚至抵消某個輸出成分，因此只看分母也不足以重建完整波形。

在電路的 s 域中，電容阻抗成為 1/(sC)，電感阻抗成為 sL，因此 KVL、KCL 與歐姆定律仍可用代數方式聯立。這不是說元件停止儲能，而是儲能造成的微分關係已被 s 與初值編碼。

ROC 提醒我們轉換並非對所有 s 都有意義。eat 的單邊積分需要 Re(s) > a，因為加權衰減必須壓過原訊號的成長；若 σ 太小，積分上界不會消失，前述微分推導的邊界條件也隨之失效。於是「公式長得一樣」與「代表同一個可逆訊號」是兩層不同的判斷。

來源：03-工程數學-上 第 2 章 §2.1–§2.7。

推導：初值從邊界項進來，極點從特徵式浮出來

（a）微分性質。從定義對 f′(t) 取拉氏：

∫0∞ f′(t)e−st dt

令一部分微分 f′(t)dt，另一部分保留 e−st，分部積分得到 [f(t)e−st]0∞ + s∫0∞ f(t)e−st dt。若 s 位於 ROC，使 e−stf(t) 在無窮遠趨於 0，上界為 0；下界被相減，留下 −f(0)。第二項正是 sF(s)，所以：

拉氏{f′} = sF(s) − f(0)

再對 f′ 套用一次，就得 f″ → s(sF − f(0)) − f′(0) = s²F − sf(0) − f′(0)。因此初值不是額外補丁，而是每次分部積分的邊界項。

（b）完整解一題。考慮 y″ + 3y′ + 2y = 0，y(0) = 1，y′(0) = 0。各項取拉氏：

(s²Y − s⋅1 − 0) + 3(sY − 1) + 2Y = 0

合併 Y 的係數，Y(s² + 3s + 2) = s + 3；因 s² + 3s + 2 = (s+1)(s+2)，所以 Y(s) = (s+3)/((s+1)(s+2))。設 Y = A/(s+1) + B/(s+2)。兩側乘共同分母後令 s = −1，得 A = (−1+3)/(−1+2) = 2；令 s = −2，得 B = (−2+3)/(−2+1) = −1。反查 e−at → 1/(s+a)，得到 y(t) = 2e−t − e−2t。代 t = 0 可驗證 y = 1，再微分也可驗證 y′(0) = 0。

（c）極點與二階參數。二階標準分母 s² + 2ζωns + ωn² = 0。用二次公式得到 s = −ζωn ± ωn√(ζ²−1)。若觀察到共軛極點 σ ± jω，比較實部與模長可得 σ = −ζωn，且 σ² + ω² = ωn²，因此 ωn = √(σ² + ω²)，ζ = −σ/ωn。實部控制包絡 eσt，虛部控制 cos(ωt) 的快慢。

數值實例：把一對極點翻譯成時間波形

取共軛極點 s = −1 ± j2。自然頻率 ωn = √(1 + 4) = √5 = 2.236068 rad/s；阻尼比 ζ = 1/√5 = 0.447214，介於 0 與 1，故為欠阻尼。實部絕對值的倒數給時間常數 τ = 1/|σ| = 1 s；虛部給振盪週期 2π/ω = 3.141593 s。

模態取 eσtcos(ωt)。在 t = 1 s，包絡 e−1 = 0.367879，cos 2 = −0.416147，因此模態值為 0.367879⋅(−0.416147) = −0.153092。負號只表示當下位於振盪的另一側，不表示能量成長；包絡持續遞減才是穩定性的關鍵。因 σ < 0，任何由這對極點產生的初始擾動都會逐漸消失。

自由實驗：移動極點並讀出時域行為

這裡示範共軛極點的實部與虛部如何分別控制衰減和振盪。調整 σ、ω 與觀察時刻，查看 ωn、ζ、時間常數、週期、模態值及穩定性判讀。

為什麼／不要混淆

  • 拉氏使用 s = σ + jω，可處理衰減、初值與暫態；傅立葉沿 s = jω 觀察穩態頻譜，兩者不是可隨意互換的名字。
  • 極點是分母的根，決定系統自然模式；零點是分子的根，調整輸入到輸出的模式權重，作用不同。
  • 只寫 F(s) 的代數式仍可能不夠，ROC 不同可對應不同時間訊號；收斂域也是轉換資訊的一部分。
  • 單邊拉氏從 0 到 ∞，自然帶入初值；雙邊拉氏涵蓋負時間，與傅立葉及 z 轉換的理論對應更直接。
  • 連續系統看左半 s 平面；離散系統的 z 轉換看單位圓內，不能把兩個穩定判準混用。
  • 終值定理有極點條件。若系統持續振盪或發散，直接代 s→0 得出的數不代表真實終值。

可觀察證據

控制軟體的根軌跡直接顯示閉迴路極點如何隨增益移動；示波器量得的步階超調、振鈴週期與安定時間可反推 ζ、ωn 和實部衰減率。電路模擬器的交流分析把電容與電感改寫為 s 域阻抗後求頻率響應；波德圖的轉折與相位也反映極點、零點的位置。若把極點實部從負調到正，下方實驗會把同一個小擾動由衰減改成放大。

數值上還能把部分分式反查出的時間式重新取拉氏，檢查是否回到原 Y(s)；也能把 y(t) 代回原 ODE 與兩個初值。這兩條獨立路徑若同時成立，才比只核對一個時刻更有力。實驗中的 σ = 0 是特別清楚的邊界：包絡固定為 1，能看見「不衰減」和「發散」並不是同一種行為。

連到哪門課

拉氏轉換是電路學暫態分析、信號與系統的系統函數、控制系統的根軌跡與穩定設計，以及類比濾波器設計的共同語言。下一章以複數乘法說清楚 jω 為何代表旋轉與微分；第 10 章再把視線限制到虛軸，分析訊號的頻率組成。

實際解題時可把拉氏域視為三層資訊：代數式說明輸入輸出如何組合，極點與零點說明哪些模式存在及如何被觀察，ROC 與初值則決定這個式子究竟對應哪一段時間行為。只做部分分式卻不看極點位置，容易算出答案卻無法判斷是否合理；只畫極點卻忽略零點與輸入，又會高估某些模式在輸出中的可見程度。完整工程判讀應同時回到時間波形、系統結構與適用條件，並以代回方程、初終值或量測響應交叉檢查。還要核對秒、弧度每秒與係數量綱，避免數值正確卻物理單位錯誤。
