02・把無數個小貢獻收成一個累積量

積分：將曲線下的小矩形加起來

積分不是只靠反微分公式表才能完成的手算技巧。它的核心是把一段區間切小，每小段估計一點點貢獻，全部累加後再看分割無限變細的極限。這個觀念能直接連到電能、訊號能量、機率與數值程式。

這章假設已懂：01 極限與導數中的極限、導數與局部變化率。

痛點：知道每一刻的速率或功率，卻不知道總共累積了多少

電力電子實驗裡常會同時擷取負載電壓與電流，學生知道逐點相乘可得瞬時功率，卻直接把所有功率值相加就宣稱得到能量。這會漏掉每筆樣本代表的時間寬度，也可能忽略負功率代表能量回送。真正要累積的是「功率乘上一小段時間」的局部能量，再把整段量測中的貢獻加總。

若一台設備的功率始終是 100 W，運作 3 s 的能量可直接用長方形面積 100 × 3 得到。但真實電路的功率會隨時間變化，每一小段的高度不同，不能只選一個功率值乘上總時間。同樣地，若已知速度 v(t)，想求總位移，或已知機率密度，想求某區間的機率，都要處理「每一處都不同」的累積。

實際量測只能給有限個樣本，所以我們必須先決定每段要用左端、右端、中點，還是兩端平均來代表該段。不同選法在分割很粗時會得到不同答案；積分理論要說清楚的，就是當最寬的小段趨近 0 時，這些合理求和會不會走向同一個數。

白話直覺：先用許多小矩形鋪滿，再讓縫隙消失

把鋪地板的比喻收回定義：先選一串分點，把區間切成小段；每段選代表點，將函式值乘以該段寬度，再對全部小段求和。當最大段寬趨近零，而且不同合理取樣方式都趨向同一有限值時，這個共同極限才是定積分。重點不只是矩形數量增加，而是所有小段都確實變窄。

這個面積直覺遇到負值、奇異點與不等寬取樣時容易失效。負值是方向相反的貢獻，不是不存在的面積；函式在區間內無界時，普通黎曼積分可能不存在；實驗資料若取樣間隔不固定，也不能拿同一個 Δx 乘每筆資料。此時仍要回到有號貢獻與實際分段寬度。

可以把曲線下的區域想成要用窄長矩形鋪滿的地板：矩形越窄，頂端與曲線之間的縫隙越小。但這只是幾何比喻；精確地說，定積分（Definite integral） ∫ab f(x) dx 是黎曼和在分割寬度趨近 0 時的極限，它累加的是有號貢獻 f(x) dx，因此曲線在 x 軸下方的部分會帶負號，不是自動取絕對值的幾何面積。

不定積分（Indefinite integral） ∫ f(x) dx = F(x) + C 是尋找所有滿足 F′ = f 的反導函式，C 表示導數無法辨認的常數差。它與定積分不是同一類結果：前者是一族函式，後者在 a、b 確定後是一個數。

微積分基本定理（Fundamental Theorem of Calculus, FTC）把累積與瞬間變化連在一起：若 F′ = f，且 f 在區間上滿足適當的連續條件，則 ∫ab f(x) dx = F(b) − F(a)。這表示可以不必真的把區間切成無限多片，只要找到反導函式並計算端點差，就能得到同一個累積量。

來源：01-微積分 §4–§6。

推導：從分割、取樣到四種黎曼和

平均分割後，第 i 段的左右邊界分別是 a+(i−1)Δx 與 a+iΔx，兩者相減確實得到 Δx；因此用「高度乘寬度」才具有函式單位乘上 x 單位的量綱。Σ 只是把每段局部貢獻逐項相加，取 n 趨近無限則等價於讓固定總寬下的 Δx 趨近零。

若跳過邊界與量綱這一步，常會誤以為 Σ f(xi) 本身就是積分，導致取樣率提高時總和反而任意變大。另一個常見誤解是把中點法的對稱抵消當成永遠成立；它依賴每段附近足夠平滑與取樣點真正位於中央，遇到跳躍或遺失樣本就必須重新估計誤差。

將區間 [a, b] 平均切成 n 段，每段寬度為 Δx = (b − a)/n。第 i 段選一個取樣點 xi，用高 f(xi) 乘上寬 Δx 代表該段的局部貢獻，全部相加得到黎曼和（Riemann sum）：

S = Σi=1n f(xi) Δx

左端點法令 xi = a + (i−1)Δx；右端點法令 xi = a + iΔx；中點法令 xi = a + (i−0.5)Δx。梯形法不只取一點，而是對每段左右端高度取平均：(f(a+(i−1)Δx) + f(a+iΔx))/2，再乘上 Δx。這四種都是同一個極限定義的有限分割近似。

若 f 在每段夠平滑，左、右端點用單邊高度代表整段，每段會留下與斜率相關的單邊偏差。累加後總誤差與 Δx 同階，由於 Δx = (b − a)/n，所以誤差 ∝ 1/n，稱為一階收斂；n 加倍時誤差約減半。

中點法在每段中央取樣，局部線性項左右對稱抵消；梯形法用兩端平均，也能正確積分局部一次變化。因此兩者總誤差主項與 Δx² 同階，即誤差 ∝ 1/n²，稱為二階收斂；n 加倍時誤差約變為 1/4。在相同平滑條件與等寬分割下，中點誤差約是梯形誤差的一半，且符號相反；這是誤差主項的關係，不是對任意不連續函式的無條件保證。

解析積分的兩個常用技巧也可由微分規則反向理解。變數變換（Substitution）是連鎖律的反向；分部積分（Integration by parts） ∫ u dv = uv − ∫ v du 是乘法律的反向。它們改變算法，但不改變「局部貢獻的極限累加」這個本質。

數值實例：f(x) = x² 在 [0, 1]、n = 4

表中的每一列都先用四個代表高度形成括號內的和，再乘共同段寬。左端點列從區間起點開始取樣而不含終點，右端點列則不含起點而包含終點；中點列把每一段的中央位置代入。梯形列等價於把相鄰兩端高度平均後逐段累加，因此能利用曲線兩側的資訊。

這組數字不只在比較誰較接近精確值，也揭露誤差方向與曲線形狀的關係。x² 在此區間遞增且向上彎，左、右端點的偏差主要來自單邊取樣，中點與梯形的偏差則反映直線近似如何落在曲線上下。看到正負誤差時，應先解讀取樣幾何，而不是只挑絕對值最小的方法。

精確值由 FTC 得 ∫01 x² dx = [x³/3]01 = 1/3 = 0.333333。預設 n = 4，所以 Δx = 0.25。四種法則的計算全部列如下：

法則計算值誤差
左端點0.25 ⋅ (0² + 0.25² + 0.5² + 0.75²) = 0.25 ⋅ 0.8750.218750−0.114583
右端點0.25 ⋅ (0.25² + 0.5² + 0.75² + 1²) = 0.25 ⋅ 1.8750.468750+0.135417
中點0.25 ⋅ (0.125² + 0.375² + 0.625² + 0.875²) = 0.25 ⋅ 1.31250.328125−0.005208
梯形0.25 ⋅ (0.5 + 0.0625 + 0.25 + 0.5625) = 0.25 ⋅ 1.3750.343750+0.010417

x² 在 [0, 1] 單調遞增，每一段的左端點都是該段最小值，所以左端矩形總和低估；右端點都是最大值，所以右端高估。中點與梯形利用區間內更平衡的資訊，因而在同一 n 下已明顯接近 1/3。n 加倍到 8 時，左端點誤差約減半，中點誤差約變為 1/4，這就是一階與二階收斂可實際比對的預測。

自由實驗：比較四種黎曼和

這個實驗示範有限分割如何逼近定積分。選函式與取樣法則，再拉高 n，觀察有號誤差、高估或低估，以及 n 加倍的誤差預測。

為什麼／不要混淆

  • 不定積分與定積分結果不同：不定積分是帶 +C 的反導函式族；定積分在端點確定後是一個累積數值。
  • 定積分是有號面積：f(x) 在 x 軸下方時貢獻為負；若要幾何總面積，要積分 |f(x)| 或依符號分段。
  • FTC 是計算紐帶，不是反導函式表保證：它告訴我們找到 F 就可用 F(b) − F(a)，但 e−x² 等函式沒有可用初等函式寫出的反導函式。
  • 低估或高估取決於單調性：對遞增函式，左端低估、右端高估；對 1/x 在 [1, 2] 這種遞減函式，結論正好對調。
  • 收斂階不等於這次一定較準：二階是 n 變大時的漸近誤差縮減率，實際小 n、不平滑點或入參誤差都可影響單次結果。
  • 樣本相加不等於時間積分：離散資料必須乘上各自代表的取樣間隔；若時間戳不等距，還要逐段使用實際時間差。

可觀察證據

可用示波器同時擷取負載電壓與電流，匯出帶時間戳的樣本後逐點相乘，再以相鄰時間差做梯形累加。把所得能量與儀器內建的功率積分功能比較，並縮短擷取間隔；兩者逐漸接近可支持數值積分流程，但儀器頻寬與探棒誤差仍需另外校核。

程式中應印出段號、左右時間、兩端功率、局部梯形面積與累積值。刻意漏掉一筆樣本或改成不等距時間戳，就能檢查演算法是否真的使用每段寬度；若只乘固定週期，錯誤會在累積欄持續放大。

家用電表的度數是功率對時間的累積；功率即使不斷變化，電表仍會持續把每個短時段的耗能加進總量。數位量測的程式版本就是把每筆功率樣本乘上取樣週期再累加；若取樣週期縮短且量測足夠可靠，結果會趨近連續時間積分。

在數值程式中，將 n 由 4 調到 8、16，可以直接看到近似值走向精確值。左端點法的誤差約每次減半，中點法則約每次變為四分之一；比較誤差比值，就能將「一階」與「二階」從名詞變成可觀察的計算證據。

連到哪門課

在電路學，積分出現在電荷、磁鏈與能量的計算；信號與系統用它定義連續時間卷積、相關與訊號能量；數位訊號處理則把同一概念改寫成離散求和。通訊原理在由功率頻譜求總功率、由機率密度求錯誤事件機率時會再次使用，電磁學則以線積分、面積分與體積分把局部場量連到路徑、通量與總電荷。

電路學用功率的時間積分求能量，也由電流積分得電荷；信號與系統用積分定義卷積與內積，拉氏與傅立葉轉換本身也是加權積分。通訊與機率課用機率密度的區間積分求事件機率。本章在機器人數學基礎課沒有獨立對應章，但這裡的累積觀念會直接供第 08 章拉氏、第 10 章傅立葉與第 12 章機率使用。
