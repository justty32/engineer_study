13・從有限資料推回未知世界

統計推論與隨機過程：估計真值，也描述雜訊如何隨時間走

機率從模型推結果，統計則從有限資料反推模型。當資料還按時間排列時，只看單點分布不夠，還要描述前後樣本的關係與能量落在哪些頻率。

這章假設已懂：12 機率與隨機變數、10 傅立葉分析。

痛點：一個平均值沒有說明它有多可信

量到 25 筆資料，平均為 5，不代表母體真實平均恰好就是 5。若單次量測標準差很大，樣本平均仍可能偏離真值；若樣本彼此相關，增加筆數也未必像獨立樣本那樣有效。工程決策必須同時交代估計值、抽樣不確定度與採用的模型假設，否則「平均是 5」無法支撐元件是否合格、接收器是否偵測到訊號等判斷。

另一個痛點是時間結構。兩段雜訊可能有相同平均與變異數，一段卻快速抖動，另一段緩慢漂移；它們對濾波器與控制迴路的影響完全不同。這要求我們把單一隨機變數（random variable）擴展成隨機過程（stochastic process） {X(t)}，不只問某時刻的分布，也問相隔 τ 的樣本彼此多像，以及功率分布在哪些頻率。

白話直覺：區間是會晃動的網，過程是一整疊可能波形

可先把信賴區間（confidence interval）想成用資料撒出的一張網：每次重抽樣本，網的位置都會變，但製作方法的覆蓋率可以校準。精確地說，95 % 信賴是指在相同條件下重複抽樣並依同一程序造區間，長期約有 95 % 的區間覆蓋固定的母體參數；資料已經觀察後，不能把它改述成「真值有 95 % 機率落在這個已算出的區間」。

參數估測有不同準則。最大似然估測（Maximum Likelihood Estimation, MLE）選使已觀察資料最可能出現的參數；最大後驗估測（Maximum A Posteriori, MAP）再乘上先驗，選後驗最大的參數；最小均方誤差（Minimum Mean Square Error, MMSE）選使 E[(θ̂−θ)²] 最小的估計。三者問法不同，不應只因名稱都含「估測」便視為同一答案。

隨機過程可想成一整疊可能波形，每次實驗抽出其中一條。精確地說，若統計性質不隨時間平移而改變，稱為平穩（stationary）；若一條足夠長的時間軌跡所算出的平均等於跨許多可能軌跡的集合平均，稱為遍歷（ergodic）。平穩不自動保證遍歷，遍歷性才讓我們能用一筆長時間紀錄代表整體。

來源：04-機率與統計 §8–§10。

推導：樣本數、區間半寬與雙尾檢定如何接起來

（a）標準誤的來歷。令 X1, …, Xn 為獨立同分布樣本，每個變異數都是 σ²，樣本平均 x̄ = (X1+⋯+Xn)/n。獨立使總和的變異數可以相加，因此：

Var(x̄) = Var((X1+⋯+Xn)/n) = (1/n²)⋅n⋅σ² = σ²/n

開根號便得到標準誤（standard error, SE） SE = σ/√n。它描述樣本平均在重複抽樣間的波動，不是原始資料本身的標準差。因為 n 躲在平方根內，若要把區間半寬減半，必須讓 √n 加倍，也就是把 n 變成原本的 4 倍；資料量與精度並非線性兌換。

（b）信賴區間的意義。中央極限定理讓 n 足夠大時的 x̄ 近似常態。若母體 σ 已知，標準化量 (x̄−μ)/(σ/√n) 約服從標準常態。把中央 1−α 的面積用臨界值 zα/2夾住，再解回 μ，得到 x̄ ± zα/2⋅σ/√n。常用值是 90 % 對 1.645、95 % 對 1.960、99 % 對 2.576；提高信賴水準會用更大的 z，因此在相同資料下區間更寬。

這個推導的隨機量是 x̄，因此區間端點隨樣本改變；μ 在頻率學派解讀中是固定未知常數。95 % 是造區間程序的長期覆蓋率，不是把固定 μ 當作抽籤結果。若 σ 未知且樣本小，通常要改用樣本標準差與 t 分布；本章互動明確假設母體 σ 已知，所以使用 z 值。

（c）雙尾檢定與區間的等價。考慮假設檢定（hypothesis testing）中的虛無假設 H0: μ = μ0。雙尾檢定在 |x̄−μ0|/SE > zα/2 時拒絕 H0。兩邊同乘 SE 得 |x̄−μ0| > zα/2SE，等價於 μ0 不在 [x̄−zSE, x̄+zSE] 中。於是同一顯著水準下，雙尾檢定拒絕的那些 μ0，正是相對應信賴區間沒有涵蓋的值。

假設檢定不是證明 H0 真或假，而是在控制風險下作決策。把沒有訊號時誤判成有訊號稱假警（false alarm），把有訊號時漏掉稱漏報（miss）。奈曼—皮爾遜準則在限制假警率的前提下最大化偵測率；通訊接收器在「送 0」與「送 1」間選擇，本質就是這類檢定。

數值實例：用同一組資料同時造區間與做檢定

自由實驗預設 x̄ = 5、已知母體 σ = 2、n = 25、信賴水準 95 %。標準誤 SE = 2/√25 = 2/5 = 0.400000；臨界值 z = 1.960，所以半寬 = 1.960 × 0.4 = 0.784000。信賴區間為 [5−0.784, 5+0.784] = [4.216000, 5.784000]。這些數字同時顯示樣本平均的位置與因有限樣本造成的不確定度。

再檢定 H0: μ = 4。檢定統計量 z = (5−4)/0.4 = 2.500000，其絕對值大於 1.960；同時 μ0 = 4 也落在信賴區間下界 4.216000 之外，因此在 5 % 雙尾顯著水準下拒絕 H0。這是「資料與 μ = 4 不相容到超過門檻」，不是宣告任何替代值已被證明。

若其他設定不變而把 n 從 25 加到 100，SE = 2/√100 = 0.2，半寬 = 1.960 × 0.2 = 0.392，正好是 0.784 的一半；樣本數從 25 變 100，正是原本的 4 倍。若改成 99 % 信賴水準，z 從 1.960 增至 2.576，區間會變寬；若 σ 變大，SE 與半寬也按比例變大。

自由實驗：信賴區間與雙尾檢定

這裡示範已知母體標準差時的平均數推論。調整平均、σ、樣本數、信賴水準與 μ0，觀察標準誤、區間端點、z 統計量與是否拒絕 H0如何同步改變。

為什麼／不要混淆

  • 資料的標準差 σ 描述單筆觀測的散布；標準誤 σ/√n 描述樣本平均的抽樣波動。增加 n 會縮小後者，不會讓原始資料突然變得集中。
  • 95 % 信賴不是「這個固定真值有 95 % 機率在已得到的區間內」。它是相同程序長期重複時的覆蓋率。
  • 沒有拒絕 H0不等於證明 H0為真。資料可能不足以區分，也可能檢定力太低；結論必須連同樣本數與門檻解讀。
  • 統計顯著不等於工程效果很大。樣本很多時，很小的差異也可能跨過檢定門檻；仍要看差異量與實務容許值。
  • 平穩與遍歷不是同義詞。平穩談統計量是否隨時間漂移，遍歷談一條長軌跡的時間平均能否代表集合平均。
  • 白雜訊不是每個時間點都等於零，也不是時間波形看起來一定白色。它的理想定義是功率譜密度（Power Spectral Density, PSD）對頻率為常數，等價的自相關在非零延遲為零。
  • 相關不等於因果。自相關描述同一過程在不同延遲的線性相似程度，不能單獨證明某時刻造成另一時刻。

可觀察證據

固定量測流程，重複抽取多組 n = 25 的樣本並各自造 95 % 區間，長期約 95 % 的區間會涵蓋真實平均；單一區間是否涵蓋則只有是或否。若把樣本數由 25 增到 100，軟體輸出的標準誤會從 0.400000 降到 0.200000，區間半寬從 0.784000 降到 0.392000，直接驗證 1/√n 的縮減律。

對時間序列計算自相關函數（autocorrelation function） RX(τ) = E[X(t)X(t+τ)]，可以看到不同延遲的相似程度。其傅立葉轉換是 SX(ω)，這就是 Wiener–Khinchin 定理與第 10 章的連接。理想白雜訊的 SX(ω) 為常數，RX(τ) 則集中成 τ = 0 的脈衝 δ(τ)：不同時刻不相關，但每一頻帶都有相同功率密度。實際儀器頻寬有限，因此量到的是有限頻帶內近似平坦，而非無限頻寬的理想模型。

在通訊接收器可掃描判決門檻並記錄假警率與漏報率：門檻移動通常讓兩者此消彼長。頻譜分析儀上，白雜訊底在使用頻帶內近似平坦；若出現窄峰，表示週期干擾，若低頻隆起則可能是漂移或有色雜訊。這些都是模型能被量測直接反駁或支持的證據。
