04・把一組數當成一個物件

向量與矩陣：把方向、資料與轉換一次管好

單一數字只能描述一個量；工程系統常同時有多個輸入、狀態與輸出。這章把一組數收進向量，再把整套線性搬動規則收進矩陣，讓多變數問題仍能用一致的運算處理。

這章假設已懂：03 級數與泰勒、基本四則運算與平面座標。

痛點：式子一多，逐項追蹤就失去全貌

想像一個雙輸入雙輸出的通訊通道：第一個接收器同時收到兩個發射器的訊號，第二個接收器也收到不同強度的混合訊號。若每個量都各寫一條式子，兩個尚可，幾十個天線便會被索引淹沒。更麻煩的是，我們不只想算一次答案，還想知道整個系統把哪些方向放大、哪些方向壓縮，以及先後串接兩個系統會發生什麼事。

向量與矩陣的價值，不是把很多數字排得整齊，而是提供一套可合成、可檢查的語言。輸入向量進入矩陣所代表的規則，得到輸出向量；同一個規則可以重複作用在任意輸入上。於是電路節點電壓、多輸入多輸出通道、機器人的座標與資料表中的特徵，都能共享同一套線性代數操作。

具體卡關常發生在通訊實驗：學生從示波器或軟體無線電取得多路同相與正交取樣，想追查某一路輸出為何出現串音，卻把每個取樣與每條耦合路徑各寫一個變數。式子雖然都對，輸入順序一換便接錯係數，也看不出是哪一欄代表某支發射天線。先固定向量分量的意義，再把耦合係數排成矩陣，才能從維度、列與欄立即檢查模型是否接對。

白話直覺：向量是配方，矩陣是搬動規則表

可以先把向量想成一張配方卡：每個位置寫一種材料的份量；矩陣則像機器的設定表，告訴每個輸出要從各輸入拿多少。這個比喻只用來建立入口，精確地說，向量（vector）是有序數組 v = (v1, …, vn)，次序不可任意交換；矩陣（matrix）是按列與欄排列的數表，而 y = Ax 定義一個從輸入空間到輸出空間的線性轉換（linear transformation）。

「線性」有明確條件：若 T(x) = Ax，則 T(cu + dv) = cT(u) + dT(v)。也就是先把向量做線性組合（linear combination）再轉換，與先各自轉換再用相同係數組合，答案相同。所有 c1v1 + c2v2 + ⋯ 能到達的集合叫生成（span）；若只有所有係數皆為 0 才能組出零向量，這組向量便線性獨立（linear independence）。

一組既線性獨立又能生成整個空間的向量叫基底（basis），可把它理解成「最少而剛好夠用的座標方向」；基底向量數就是維度（dimension）。基底不是唯一的，但同一有限維空間的任何基底都有相同數量。換基底不是改變實際物件，而是換一套座標描述它，正如同一位置可用地圖座標或機體座標表示。

配方與機器的直覺會在非線性元件上失效。例如放大器飽和、二極體截止或量化器截斷時，把兩個輸入先相加再通過元件，未必等於兩個輸出相加；這時不能只因資料仍排成矩陣外觀，就宣稱整個系統是線性的。精確判準始終是加法與純量乘法都被保留，而矩陣只是選定輸入、輸出基底後，線性轉換的有限維表示。

來源：02-線性代數 §1–§2。

推導：每一列算一個輸出，每一欄說一個輸入的貢獻

令 A = [[a11,a12],[a21,a22]]，x = (x,y)。矩陣乘向量的定義是把 A 的每一列與 x 對應相乘再相加，因此第一列給第一個輸出：

y1 = a11x + a12y

第二列同樣給第二個輸出：

y2 = a21x + a22y

所以 Ax = (a11x + a12y, a21x + a22y)。改用欄視角，把 A 的第一欄記為 c1 = (a11,a21)，第二欄記為 c2 = (a12,a22)，同一結果可重寫成 Ax = x c1 + y c2。這一步揭示輸出必定落在矩陣各欄所生成的空間中，也說明 x 與 y 正是兩欄的混合係數。

這裡的「對應相乘再相加」不是任意規則：每一列列出同一個輸出對全部輸入的權重，所以列長必須等於輸入分量數；每算完一列只產生一個純量，所有列的結果再依原順序排成輸出向量。若跳過尺寸與順序的理由，很容易誤以為矩陣乘法是同位置元素逐格相乘，也會忽略 A 的欄數必須等於 x 的維度。

現在串接兩個轉換。先令 z = Bx，再令 y = Az；代入便有 y = A(Bx)。為了用一張新規則表直接描述整個串接，我們把它定義成 (AB)x = A(Bx)。因此 AB 的第 j 欄，就是 A 作用在 B 第 j 欄上的結果。括號表示實際作用次序：最靠近 x 的 B 先做，A 後做；通常 AB ≠ BA，因為先投影再旋轉與先旋轉再投影不是同一件事。

單位矩陣（identity matrix） I = [[1,0],[0,1]] 滿足 Ix = x，代表什麼都不做。對角矩陣（diagonal matrix） [[d1,0],[0,d2]] 只沿兩個座標軸各自伸縮。若 QTQ = I，Q 稱為正交矩陣（orthogonal matrix）；因為 |Qx|² = (Qx)T(Qx) = xTQTQx = xTx = |x|²，所以它只做旋轉或反射，不改變長度。這不是憑圖形猜測，而是由代數等式直接保證。

長度推導中，第一個等號使用 |u|² = uTu 的定義；接著把 (Qx)T 改寫為 xTQT，使用乘積轉置會反轉次序；再代入 QTQ = I，最後才得到原長度。若直接從正交矩陣跳到「一定是旋轉」，會漏掉反射也保長，並把保長性錯當成只靠矩陣外觀判斷。

數值實例：同一答案的列視角與欄視角

取 A = [[2,1],[0,3]]，第一列是 2、1，第二列是 0、3；輸入 x = (1,2)。列視角逐項計算：y1 = 2⋅1 + 1⋅2 = 4，y2 = 0⋅1 + 3⋅2 = 6，因此 y = Ax = (4,6)。這正是下方自由實驗的預設值。

欄視角則把輸出拆成 1⋅(2,0) + 2⋅(1,3) = (2,0) + (2,6) = (4,6)。兩種視角必須一致：列視角適合直接算每個輸出，欄視角適合理解輸出如何由各欄生成。

輸入長度 |x| = √(1² + 2²) = √5 = 2.236068；輸出長度 |y| = √(4² + 6²) = √52 = 7.211103，長度比為 3.224903。一般矩陣會同時改變方向與長度，不能把所有矩陣都當旋轉。行列式 det A = 2⋅3 − 1⋅0 = 6，表示任意平面面積經此轉換後放大 6 倍；正值也表示方向性沒有翻轉。

逐步看這組數字：第一個輸出把輸入第一分量取兩份、第二分量取一份；第二個輸出完全不取第一分量，只把第二分量取三份，因此兩列各自完成一條輸出規則。欄視角又顯示，輸入的第一分量只貢獻 (2,0)，第二分量則貢獻兩倍的 (1,3)，相加才抵達 (4,6)。這組數字告訴你，輸出變長不是單一共同倍率造成，而是方向與各欄貢獻共同決定；面積倍率不能拿來替代某一向量的長度倍率。

自由實驗：看矩陣如何搬動向量

這裡示範 2×2 矩陣把輸入向量變成輸出向量。調整矩陣四個元素或向量兩個分量，觀察輸出、長度與行列式如何一起改變。

為什麼／不要混淆

  • 向量不是只有幾何箭頭。它也可代表一段取樣訊號、一組節點電壓或一列模型參數；關鍵是分量有固定次序與共同解釋。
  • 矩陣不是資料表本身，而是線性轉換的座標表示。同一轉換換基底後矩陣元素會改變，轉換所做的事沒有改變。
  • AB 的作用順序不是從左到右讀；(AB)x = A(Bx)，所以 B 先作用。矩陣乘法通常不可交換，不能擅自把 AB 改成 BA。
  • 一般矩陣不一定保持長度。只有滿足 QTQ = I 的正交矩陣保長；對角矩陣通常沿不同軸給不同伸縮量。
  • 線性獨立不等於向量彼此垂直。垂直一定獨立，但不垂直的向量也可能獨立；只要沒有一個能由其他向量線性組合而成即可。
  • det A 描述有向面積縮放，不是輸出向量的長度倍率。不同方向通常有不同長度倍率，但所有面積的倍率共同等於 det A。
  • 向量的列寫法或欄寫法是表示慣例，真正關鍵是運算時尺寸一致；在 Ax 中通常把 x 視為欄向量，不能只為排版方便便悄悄改變乘法方向。

可觀察證據

多輸入多輸出（Multiple Input Multiple Output, MIMO）通道直接寫成 y = Hx + n：H 的每一欄描述某一發射天線對所有接收天線的影響。數位訊號處理（Digital Signal Processing, DSP）的有限脈衝響應濾波可把連續取樣排成向量，讓卷積成為矩陣乘法。電路的節點分析把未知節點電壓排成 x，導納係數排成 A，最後得到 Ax = b。

程式輸出也提供可驗證證據：對相同 A 與 x，用逐列點積和用各欄線性組合，應得到相同的 (4,6)。若把 A 調成正交矩陣，輸入與輸出長度應相同；若把兩欄調成同一直線方向，det 會變成 0，表示整個平面被壓到一條線上。

動手驗證時，可在程式中分別印出每列與輸入的點積、每欄乘上對應輸入分量的中間向量，再印出兩者差值；差值應只剩浮點誤差。儀器端則可對雙通道系統輪流只開啟一個輸入，量到的完整輸出正好對應傳輸矩陣的一欄；兩個輸入同時開啟後，量測結果若符合兩欄的線性組合，才支持工作區採用的線性模型，卻不能因此證明所有振幅下都不會飽和。

連到哪門課

更具體地說，電路學在節點電壓法會把導納排成係數矩陣；數位通訊在通道估測與等化主題會把發射符號經 H 映到接收向量；自動控制在狀態空間章節用矩陣同時更新多個狀態；數位訊號處理則在濾波器與離散卷積中把一段取樣視為向量。先熟悉列、欄、基底與合成次序，後續才不會只會按函式庫求答案，卻無法檢查模型維度和物理意義。
