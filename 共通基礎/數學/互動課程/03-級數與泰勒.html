03・用有限個多項式項逼近複雜函式

級數與泰勒：在展開點附近用多項式取代函式

指數、正弦與對數看起來彼此不同，卻都能在一個展開點附近用多項式近似。泰勒展開的工程價值不只是好算：每個階數對應一種局部變化，截斷階數、距離與收斂區間則告訴我們近似能信到哪裡。

這章假設已懂：01 極限與導數的高階導數觀念、02 積分的累積與無限逼近直覺。

痛點：非線性函式難算，只留有限項又怎麼知道錯多少

類比電子學做二極體或電晶體小訊號分析時，學生常在工作點旁畫一條切線，便把整個輸入擺幅都當成線性。小擾動時量測與預測接近，振幅拉大後卻出現增益壓縮與諧波，讓人以為元件參數突然改變。真正被忽略的是二階以上項；截斷不是把非線性消失，而是宣告在指定工作範圍內暫不計它們。

程式裡可以直接呼叫 exp 或 sin，但處理器最終執行的仍是有限個基本運算；電路與控制的分析也常希望把複雜非線性元件暫時改寫為線性模型。真正的難題不是「能不能用多項式代替」，而是「在哪個點附近、保留多少階、誤差可否控制」。

如果只說「階數越高越準」，會遺漏兩個關鍵限制。第一，計算位置離展開點越遠，冪次項被放大，同一階數的近似通常越差。第二，有些無限級數只在有限距離內收斂，一旦超出收斂半徑，加更多項不只沒幫助，反而可能越來越大。所以泰勒多項式必須與截斷誤差與收斂區域一起學。

白話直覺：在一個工作點附近量形狀，再逐階補轉彎細節

精確地說，n 階泰勒多項式是唯一一個在展開點與原函式具有相同函式值，且直到 n 階導數都相同的多項式。每個係數除以階乘，是為了抵消對冪次反覆微分時產生的乘積，使該階導數在展開點恰好回到 f 的對應導數值。

「逐階補細節」的直覺在函式不夠光滑、離展開點太遠或級數不代表原函式時會失效。即使所有階導數都存在，也不能只靠外觀斷言無限展開等於原函式；有限精度計算還可能讓巨大正負項相減而遺失有效位數。因此階數、距離、收斂與數值穩定性必須一起判斷。

可以把泰勒展開想成在工作點量曲線的形狀：函式值告訴你高度，一階導數告訴你斜率，二階導數告訴你彎曲，更高階導數再逐層補上細節。但這是幾何比喻；精確的泰勒級數（Taylor series）在展開點 a 寫成

f(x) ≈ f(a) + f′(a)(x−a) + f″(a)(x−a)²/2! + f‴(a)(x−a)³/3! + …

截斷到有限階時是泰勒多項式；若無限級數收斂且其和等於 f(x)，才可將近似號換成等號。a = 0 的特例稱為麥克勞林級數（Maclaurin series）。

三個必記的麥克勞林展開是 ex = Σk=0∞ xk/k!、sin x = x − x³/3! + x5/5! − …與 cos x = 1 − x²/2! + x4/4! − …。它們不只是計算表：ex 每階導數仍是 ex，在 0 的導數值全是 1；sin 與 cos 的導數四次循環，因此只留下奇次或偶次並交錯正負。

收斂半徑（Radius of convergence）指從展開點出發，級數可收斂的距離範圍。ex、sin x、cos x 的麥克勞林級數對所有有限 x 收斂；ln(1+x) = x − x²/2 + x³/3 − … 的收斂半徑為 1，主要收斂條件是 |x| < 1，邊界必須分別判斷。

來源：01-微積分 §7。

推導：將 ejθ 的奇、偶次項收成歐拉公式

代入 jθ 之所以可以逐項進行，是因為指數級數對有限複數輸入收斂；每個冪次再拆成 j 的冪與 θ 的冪。j 的冪以四次為一個循環，所以偶次項不帶 j、構成實部，奇次項保留一個 j、構成虛部。分組後兩串係數與 cos、sin 的麥克勞林級數逐項相同，才得到歐拉公式。

若跳過收斂與逐項對照，容易把歐拉公式誤解成只憑符號相似湊出的恆等式，或以為任何無限級數都能任意重排。對不絕對收斂的級數，重排可能改變和；這裡能安全分出奇偶項，是因為指數級數具有足夠強的收斂性。

從指數函式的麥克勞林級數出發：ex = 1 + x + x²/2! + x³/3! + x4/4! + x5/5! + …。把 x 換成 jθ，前六項必須逐項寫出：

ejθ = 1 + jθ + (jθ)²/2! + (jθ)³/3! + (jθ)4/4! + (jθ)5/5! + …

由 j² = −1、j³ = −j、j4 = 1、j5 = j，上式化為

ejθ = 1 + jθ − θ²/2! − jθ³/3! + θ4/4! + jθ5/5! + …

接著不是憑空套公式，而是依實數與虛數部分重新分組。偶次項全在實數部：1 − θ²/2! + θ4/4! − … = cos θ。奇次項都帶 j：j(θ − θ³/3! + θ5/5! − …) = j sin θ。因此得到歐拉公式（Euler's formula） ejθ = cos θ + j sin θ。

這次代數操作把指數與三角函式連在一起：複指數的實部是 cos，虛部是 sin，而乘上 ejθ 可解讀為在複平面旋轉角度 θ。第 09 章會用它建立複數相量，第 10 章會用它把訊號寫成複指數的疊加。

截斷後的誤差可由第一個未保留項理解。對項的絕對值逐步下降且越近 0 的交錯級數（Alternating series），截斷誤差的絕對值不超過第一個被丟掉項。sin、cos，以及收斂區間內的 ln(1+x) 在滿足項大小遞減時可用這個判準。ex 在 x > 0 時各項同號累加，下一項只是同數量級估計，不是嚴格上界。

數值實例：x = 1、截斷階數 n = 3

ex 的部分和是依次累加常數、一次、二次與三次貢獻；增加截斷階數時，前面已算的項保持不動，只補入更高次項。sin x 則因偶次係數為零，只累加一次與三次項，下一個可能影響結果的是五次項。這正是為什麼相同的 n 不代表不同函式使用相同數量的非零項。

這組數字告訴我們，誤差大小不能只由階數判斷：還要看函式的係數符號、第一個遺漏項以及計算點是否位於收斂範圍。指數例的後續項同號，遺漏量會繼續累加；正弦例的項交錯，誤差受到下一項控制；對超出半徑的對數展開，增加項數則根本不是改善策略。

預設函式為 ex，x = 1，保留到 x³，即 n = 3。部分和為 1 + 1 + 1/2 + 1/6 = 2.666667；真值 e = 2.718282，絕對誤差為 0.051615。下一項 1/4! = 0.041667 與誤差在同一數量級，可當作誤差尺度的提示，但因為後面還有其他正項，不能宣稱它是嚴格上界。若增加到 n = 5，部分和為 2.716667，誤差降到 0.001615。

換成 f(x) = sin x，x = 1、n = 3，只保留奇次項，所以部分和是 1 − 1/6 = 0.833333。真值 sin 1 = 0.841471，誤差為 0.008138。第一個被丟掉項的絕對值是 1/5! = 0.008333，確實大於實際誤差，符合交錯級數的截斷誤差判準。

最後改選 f(x) = ln(1+x)、x = 1.5。儘管真值 ln 2.5 有定義，但以 0 為中心的級數只有收斂半徑 1；|1.5| > 1，所以任何 n 下的部分和都不會透過「多加幾項」收斂到 ln 2.5。這個例子把「函式本身有定義」與「某個展開式在這裡收斂」明確分開。

自由實驗：調整距離與截斷階數

這個實驗示範泰勒部分和如何近似真值。選函式、改變 x 與 n，比較誤差和下一項，特別觀察離 0 越遠時的惡化與 ln(1+x) 的收斂半徑。

為什麼／不要混淆

  • 泰勒多項式是局部近似：它在展開點附近配對函式值與多階導數，不代表用同一有限多項式就能全域保持精度。
  • 級數收斂不自動代表和等於原函式：還需證明餘項趨近 0；工程常用的解析函式通常良好，但這不是所有無限可微函式的普遍結論。
  • 階數越高不一定越準：超出收斂半徑時會發散；在電腦中，高次冪、階乘與正負項相消也會引入浮點誤差。
  • 函式有定義與此級數收斂是兩件事：ln(2.5) 存在，但 ln(1+x) 在 0 的麥克勞林級數於 x = 1.5 不收斂。
  • 下一項不總是嚴格誤差上界：交錯、項大小遞減且趨近 0 時才能用交錯級數判準；ex 在 x > 0 的同號級數不滿足這個條件。
  • 展開點不是裝飾參數：改變工作點會改變所有導數係數與有效近似距離；在遠處硬用同一個麥克勞林多項式，通常比重新展開更不可靠。

可觀察證據

可對非線性元件施加逐漸增大的正弦小訊號，用示波器比較輸入與輸出，並以頻譜功能觀察原本沒有的倍頻成分。擺幅很小時一次模型預測增益，擺幅增加後二次、三次效應轉成諧波；這能看見被截斷項的影響，但不能單靠一個諧波峰值反推出全部高階係數。

程式中可逐項印出索引、當前項、部分和、真值與誤差，並同時記錄相鄰部分和是否持續縮小。對 ln(1+x) 分別選在收斂範圍內外執行，部分和的穩定與振盪會形成直接對照，也能避免只看最後一列而誤判暫時接近是真正收斂。

在計算程式中固定 x = 1，依次把 ex 的 n 由 0 增加到 3、5，可看到部分和由 1 走到 2.666667，再到 2.716667，逐步靠近 2.718282。固定 n = 3 再將 |x| 拉大，相同多項式與真函式的差會增加，這是「離展開點越遠，同階近似越差」的可觀察結果。

對 ln(1+x) 將 x 調到 1.5，然後不斷增加 n，部分和不會穩定靠近真值，這是超出收斂半徑的直接證據。另一個工程現象是小訊號模型：非線性元件在固定工作點附近只保留常數與一次項，小擾動時預測很準，輸入擺幅大時卻出現諧波與失真，這正是高階項不再可忽略的量測證據。

連到哪門課

在電子學，二極體與電晶體的偏壓工作點、小訊號跨導及失真分析直接對應不同截斷階；控制系統以 Jacobian 做非線性狀態方程的局部線性化，再檢查工作點附近穩定性。信號與系統用歐拉公式推導正弦特徵函式，通訊系統則在相量、調變頻譜與相位表示中使用複指數；數值方法也會用泰勒餘項評估演算法的局部截斷誤差。

電路學與電子學用一階泰勒截斷建立小訊號模型；控制系統用局部線性化分析非線性系統在工作點附近的行為；信號與系統、通訊系統則由歐拉公式得到複指數與正弦波之間的連結，為複數相量與傅立葉分解做準備。本章在機器人數學基礎課沒有獨立對應章，但導數與梯度的應用可回看 機器人數學基礎 11；下一個分析主幹則是第 09 章複變與第 10 章傅立葉。
