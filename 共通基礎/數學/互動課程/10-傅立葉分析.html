10・把波形拆成一組可量測的頻率成分

傅立葉分析：看弦波如何疊成方波，以及跳變為何難逼近

同一段訊號可在時間域看波形，也可在頻率域看它由哪些弦波組成。這章從方波係數親手積分，辨認收斂速度、吉布斯現象、取樣摺疊與 FFT 的工程位置。

這章假設已懂：03 級數與泰勒、09 複變入門。

痛點：時間波形看得見形狀，卻看不出頻寬與濾波後果

示波器上的方波看似只有高、低兩個電位，但送進頻寬有限的放大器後邊緣會變圓；通訊脈衝越短，佔用頻寬越寬；取樣不足時甚至會看到不存在的低頻。只在時間軸上看，這些現象像是彼此無關的故障。若把訊號拆成頻率成分，它們就成為「哪些成分存在、系統保留哪些、取樣把哪些成分折回來」的同一個問題。

依訊號型態有四種工具：連續週期訊號用傅立葉級數（Fourier series, FS）並得到離散頻率；連續非週期訊號用傅立葉轉換（Fourier transform, FT）並得到連續頻率；離散非週期序列用離散時間傅立葉轉換（Discrete-Time Fourier Transform, DTFT）；有限長離散資料用離散傅立葉轉換（Discrete Fourier Transform, DFT），實作常用快速傅立葉轉換（Fast Fourier Transform, FFT）。選錯工具會誤解頻率軸是否離散、是否週期。

頻譜不是另一份無關資料，而是同一訊號換一組座標。時間域適合定位事件何時發生，頻率域適合判斷能量落在哪些頻帶；轉換可逆時，兩邊保存同等資訊。工程上選擇哪一域工作，取決於系統關係在哪一邊較簡單：微分和卷積在頻域變乘法，短暫故障與延遲則常在時間域更直觀。

白話直覺：弦波是訊號的頻率積木

可以先把波形想成由許多不同音高、振幅與相位的純音疊成。比喻到此為止；精確地說，週期 T 的訊號用 x(t) = Σn=−∞∞ cnejnω0t 表示，ω0 = 2π/T 是基頻，係數 cn = (1/T)∫0T x(t)e−jnω0t dt 是把訊號投影到第 n 個複指數基底的結果。

非週期訊號改用 X(ω) = ∫−∞∞ x(t)e−jωt dt，反轉換為 x(t) = (1/(2π))∫−∞∞ X(ω)ejωt dω。七個核心性質把工程操作翻譯到頻域：線性保持線性；時移造成相位因子 X(ω)e−jωt0；頻移搬動頻譜；時間縮放反向改變頻寬；微分變 jωX(ω)；時間卷積變頻率相乘；時間相乘變頻率卷積再除 2π。濾波器以卷積作用，因此頻域只需把輸入頻譜乘系統頻率響應。

巴塞瓦定理（Parseval's theorem）表達時間域與頻率域的能量一致。δ(t) ⇔ 1 說明理想脈衝包含所有頻率；常數 ⇔ 2πδ(ω) 表示直流只在零頻；矩形脈衝 ⇔ sinc，高斯 ⇔ 高斯。時頻不確定性 Δt⋅Δω ≥ 1/2 則說明訊號在時間越集中，就不可能同時在頻率也任意集中。

取樣定理（sampling theorem）指出頻寬 W 的訊號需以 fs ≥ 2W 取樣，才存在理想重建的可能。這個界線假設訊號確實限頻，且取樣時刻理想；實際 ADC 還需留轉換帶與抗摺疊濾波器餘量。DFT 則以 X[k] = Σn=0N−1 x[n]e−j2πkn/N 計算有限資料，直接算法需約 N² 次運算，FFT 利用對稱與分治降到約 N log N。

來源：03-工程數學-中 第 4 章 §4.1–§4.9。

推導：方波為何只留下奇次正弦

取週期 T = 1、幅度 ±1 的方波：0 < t < 0.5 時 x(t) = 1，0.5 < t < 1 時 x(t) = −1。選擇等價的奇對稱週期延拓後，平均值與所有餘弦係數為 0，只需算正弦係數。第 k 次係數為：

bk = 2∫01 x(t)sin(2πkt)dt

在跳變點拆積分：

bk = 2[∫00.5 sin(2πkt)dt − ∫0.51 sin(2πkt)dt]

因 ∫ sin(2πkt)dt = −cos(2πkt)/(2πk)，第一段為 (1 − cos(kπ))/(2πk)，第二段在前方已有負號，貢獻同樣為 (1 − cos(kπ))/(2πk)。乘外面的 2，得到 bk = 2(1 − cos(kπ))/(πk)。當 k 為偶數，cos(kπ) = 1，所以 bk = 0；當 k 為奇數，cos(kπ) = −1，所以 bk = 4/(πk)。因此：

x(t) = (4/π) Σk 為奇數 sin(2πkt)/k

偶次諧波消失可由半週對稱 x(t+0.5) = −x(t) 理解：偶次弦波跨半週不換號，正負兩半的投影互相抵消。係數只按 1/k 下降，代表跳變需要很多高頻才能描出陡邊。

在不連續點，左右極限不同，傅立葉部分和收斂到兩者平均；本例在跳變點收斂到 0。跳變附近會出現約跳幅 9 % 的超越，增加項數只讓超越區域變窄，峰值比例不消失，這叫吉布斯現象（Gibbs phenomenon）。它不是計算錯誤，而是用有限個連續弦波逼近不連續函式的結構性結果。

數值實例：在正半週中央看交錯逼近

觀察方波 t/T = 0.25，目標值為 1。此時 sin(2πk⋅0.25) 對奇數 k 交替為 1、−1。只保留 N = 1 時，部分和 (4/π)(1) = 1.273240，有號誤差 +0.273240。保留到 N = 3 時，(4/π)(1 − 1/3) = 0.848826，誤差 −0.151174。

繼續到 N = 5，(4/π)(1 − 1/3 + 1/5) = 1.103474；到 N = 7，加入 −1/7 後為 0.921583。部分和上下交錯靠近 1，誤差大致按 1/N 縮小，遠慢於係數按 1/k² 衰減的連續三角波。下方預設 N = 1、t/T = 0.25，會重現第一個數值。

自由實驗：疊加諧波逼近三種週期波

這裡示範方波、鋸齒波與三角波的部分和及收斂速度。選波形、調整最高諧波 N 與 t/T，觀察誤差、實際非零項和跳變附近的吉布斯警語。

為什麼／不要混淆

  • 傅立葉級數處理週期訊號並產生離散譜線；傅立葉轉換處理非週期訊號並產生連續頻譜。
  • DFT 的時間與頻率索引都離散，且隱含輸入區段週期延拓；端點接不起來時會產生頻譜洩漏。
  • 摺疊（aliasing）由取樣率不足造成，高頻折成低頻後無法靠事後數位濾波唯一還原；取樣前須限制頻寬。
  • 振幅頻譜與相位頻譜同樣重要。保留振幅卻丟掉相位，時域形狀通常會完全改變。
  • 吉布斯超越不會因增加項數而按高度消失，只會向跳變點擠窄；不能把它誤認成單純浮點誤差。
  • FFT 是高效率計算 DFT 的演算法，不是另一種數學轉換；輸入與輸出定義仍是 DFT。

可觀察證據

把方波接到頻譜分析儀，可看到基頻 1f 與 3f、5f 等奇次譜線，幅度約按 1/k 下降；示波器的 FFT 功能也能比較邊緣變慢前後高頻成分的減少。ADC 取樣率低於訊號最高頻率兩倍時，畫面會出現頻率較低但原訊號不存在的假波。程式對同一筆資料做 DFT，時移只改相位而不改振幅，也可直接驗證轉換性質。

可再比較方波與三角波：兩者都有半週對稱而缺少偶次諧波，但三角波連續、係數約按 1/k² 下降，所以高次譜線更快沉入儀器雜訊底。這項差異同時出現在頻譜斜率與部分和誤差，提供彼此獨立的觀察證據，也說明波形越平滑通常頻譜衰減越快。

連到哪門課

傅立葉分析直接服務信號與系統、數位訊號處理、通訊系統、濾波器、音訊、影像與頻譜估計；取樣定理是 ADC 與數位通訊的入口。下一章的 PDE 會用傅立葉級數配合邊界條件疊加空間模態，說明這套工具為何最早就從熱與弦振動問題長出來。

一個可靠的頻譜分析流程會先辨認訊號是否週期、連續與有限長，再選 FS、FT、DTFT 或 DFT；接著確認取樣率、觀察長度與窗函數造成的限制，最後才解讀譜峰。譜峰的位置指出頻率，複係數的模與角分別保留振幅和相位，頻率解析度則受觀察時間約束。若量到意外低頻，應比較不同取樣率以排除摺疊；若能量散到鄰近槽，應先檢查截取區段能否首尾相接。這些診斷把數學性質轉成儀器與程式上可執行的檢查，也能避免把窗函數副瓣誤判成系統真正產生的新頻率。
