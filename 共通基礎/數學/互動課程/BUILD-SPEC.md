## 0. 鐵律（違反即失敗）

1. **純原生 HTML／CSS／JavaScript，完全離線**。不得有圖片、外部字型、CDN、遠端 API、第三方腳本、分析碼、`fetch`、`XMLHttpRequest`。唯一允許的外部 URL 是每頁頂端 `main-site-link` 的 `https://justty32.github.io/engineer_study/`。
2. **`styles.css` 由 `專題/機器人數學基礎/互動課程/styles.css` 原樣複製，一個位元組都不改**。所有版面只用既有 class：`main-site-link`、`topbar`、`eyebrow`、`lead`、`prereq`、`note`、`warning`、`workspace`、`controls`、`output`、`grid`、`card`、`chapter-list`、`chapter-card`、`number`、`flow`、`term-list`、`term-card`、`dictionary-tools`、`pager`、`site-footer`，以及原生 `table`／`details`／`summary`／`pre`／`code`。**不得新增 class、不得寫 inline `style`、不得加 `<style>` 區塊。**
3. **公式一律純文字 HTML，嚴禁 LaTeX**：不得出現 `\(` `\)` `\[` `\]` `$` `$$`，不得引入 MathJax／KaTeX／任何算式引擎。轉寫規約見第 3 節。
4. **禁止 `Math.random()`**。所有數值必須可重現。
5. **每頁 UTF-8（無 BOM）**，`<html lang="zh-Hant">`，`<meta charset="utf-8">`。
6. **不得修改 `共通基礎/數學/*.md`** 或任何 `專題/` 下的既有檔案。
7. **不得寫計分、進度百分比、解鎖、倒數、強制答對**。自我檢核可無限重做且不阻擋瀏覽。
8. **HTML 頁面不連 `.md` 檔**。來源以文字標註（例：「來源：01-微積分 §2」）。

## 3. 公式轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。**積分／級數的上下限一律用 `<sub>`／`<sup>`，不要用 Unicode 下標數字（₀₁₂）**，避免不同字型高度不一。
- Unicode 數學符號（限這份清單）：`∫ Σ Π √ ∂ ∇ ∞ ± × ⋅ · ≈ ≠ ≤ ≥ → ⇒ ⇔ ∈ ∪ ∩ ∅ ∠ ° ′ ″ ⌊ ⌋ | ‖`
- 希臘字母：`α β γ δ ε ζ η θ λ μ π ρ σ τ φ χ ψ ω Δ Σ Φ Ω ∆`
- **負號一律用 U+2212 `−`，不要用半形連字號 `-`**（連字號只用在檔名與 CSS class）。
- 導數撇號用 `′`（U+2032）與 `″`（U+2033），不要用 ASCII 單引號。
- 上標數字可直接用 `²` `³`（常見且對齊良好）；其餘次方用 `<sup>`。

### 3.2 排版規則

1. **分數**：單行寫成 `(分子) / (分母)`，例如 `(f(x+h) − f(x)) / h`。分子分母都是單一符號時可省括號：`1/s`、`ω/(s²+ω²)`。
2. **多行分式**只在必要時用 `<pre>`，以 `─` 畫橫線，前後留一空行。
3. **極限**寫成 `lim(h→0)`，不用堆疊排版。
4. **指數中還有下標時，把下標壓平**：`e<sup>jnω0t</sup>`，並在同一段文字說明「ω0 是基頻 2π/T」。不得寫巢狀 `<sup><sub>`。
5. **矩陣**用巢狀方括號寫成一行：`A = [[2,1],[0,3]]`，並在旁邊用文字說明「第一列 2、1；第二列 0、3」。2×2 以上才可用 `<table>`。
6. **向量**寫成 `(x, y)` 或 `v = (v<sub>1</sub>, …, v<sub>n</sub>)`；粗體用 `<strong>` 而非數學粗體字元。
7. **函式名**（sin、cos、exp、ln、Re、Im、arg、det、rank、Var、Cov、E）用一般半形英文，不加標記。
8. 公式所在段落用 `<p>`；需要凸顯時可用 `<code>`（`styles.css` 已設 `overflow-wrap:anywhere`）。

### 01 `01-極限與導數.html`

**目標**：把導數從「查公式」變成「輸入動一點，輸出變多少」，並親手看到極限是怎麼逼近的。

**要點**：極限 lim(x→a) f(x) = L 的白話；連續 ⇔ lim(x→a) f(x) = f(a)；導數定義 f′(x) = lim(h→0) (f(x+h) − f(x)) / h；切線斜率＝瞬時變化率；乘冪律 d/dx x<sup>n</sup> = n x<sup>n−1</sup>、乘法律 (fg)′ = f′g + fg′、連鎖律 d/dx f(g(x)) = f′(g(x)) g′(x)；線性近似 f(x+Δx) ≈ f(x) + f′(x) Δx（工程「小訊號近似」的根本）；極值候選 f′(x) = 0。來源：01-微積分 §1–§3。

**推導必寫**：把 f(x) = x² 代進定義式，((x+h)² − x²)/h = (2xh + h²)/h = 2x + h，令 h → 0 得 2x。這一步要完整寫出來，讓讀者看到「h 沒有被丟掉，是被取極限」。再說明前向差商殘留的 h 就是誤差主項，而中央差商 (f(x+h) − f(x−h)) / (2h) 的一次項互相抵消，誤差降到 h² 等級。

**數值實例**：f(x) = x²，x<sub>0</sub> = 1，h = 0.1。前向差商 = (1.1² − 1²) / 0.1 = (1.21 − 1) / 0.1 = **2.100000**；解析值 f′(1) = 2；誤差 0.100000，正好等於 h。中央差商 = (1.1² − 0.9²) / 0.2 = (1.21 − 0.81) / 0.2 = **2.000000**，對二次函式剛好無誤差。換 f = sin x、x<sub>0</sub> = 1、h = 0.1：前向 0.497364（誤差 0.042939 ≈ h/2 ⋅ |f″|），中央 0.539402（誤差 0.000900 ≈ h²/6 ⋅ |f‴|）。

### 02 `02-積分.html`

**目標**：把定積分從「反微分公式表」變成「一堆小矩形加起來」，並看到不同求和法則的收斂速度差異。

**要點**：不定積分 ∫ f(x) dx = F(x) + C（F′ = f）；定積分 ∫<sub>a</sub><sup>b</sup> f(x) dx ＝曲線下面積＝累積量；微積分基本定理 ∫<sub>a</sub><sup>b</sup> f(x) dx = F(b) − F(a)；變數變換（連鎖律的反向）；分部積分 ∫ u dv = uv − ∫ v du（乘法律的反向）；工程意義：能量＝功率對時間的積分。來源：01-微積分 §4–§6。

**推導必寫**：把 [a, b] 切成 n 段，Δx = (b − a)/n，第 i 段取樣點 x<sub>i</sub>，黎曼和 S = Σ<sub>i=1</sub><sup>n</sup> f(x<sub>i</sub>) Δx。左端點取 x<sub>i</sub> = a + (i−1)Δx，右端點取 a + iΔx，中點取 a + (i−0.5)Δx，梯形＝(左端 + 右端)/2。說明左／右端點誤差 ∝ 1/n（一階），中點與梯形誤差 ∝ 1/n²（二階），而且中點誤差約為梯形誤差的一半且符號相反。

**數值實例**：f(x) = x² 在 [0, 1]，精確值 1/3 = 0.333333。n = 4、Δx = 0.25：

| 法則 | 計算 | 值 | 誤差 |
| --- | --- | --- | --- |
| 左端點 | 0.25 ⋅ (0² + 0.25² + 0.5² + 0.75²) = 0.25 ⋅ 0.875 | **0.218750** | −0.114583 |
| 右端點 | 0.25 ⋅ (0.25² + 0.5² + 0.75² + 1²) = 0.25 ⋅ 1.875 | 0.468750 | +0.135417 |
| 中點 | 0.25 ⋅ (0.125² + 0.375² + 0.625² + 0.875²) = 0.25 ⋅ 1.3125 | 0.328125 | −0.005208 |
| 梯形 | 0.25 ⋅ (0.5 + 0.0625 + 0.25 + 0.5625) = 0.25 ⋅ 1.375 | 0.343750 | +0.010417 |

n 加倍到 8 時左端點誤差約減半，中點誤差約變 1/4。

### 03 `03-級數與泰勒.html`

**目標**：把「用多項式逼近任意函式」變成可操作的東西，並看見截斷階數、離展開點距離、收斂半徑三者的關係。

**要點**：泰勒展開 f(x) ≈ f(a) + f′(a)(x−a) + f″(a)(x−a)²/2! + ⋯；麥克勞林（a = 0）的三個必記式 e<sup>x</sup> = Σ x<sup>k</sup>/k!、sin x = x − x³/3! + x⁵/5! − ⋯、cos x = 1 − x²/2! + x⁴/4! − ⋯；把 x 換成 jθ 並分開實虛部就得到歐拉公式 e<sup>jθ</sup> = cos θ + j sin θ（第 09 章要用）；收斂半徑（ln(1+x) 只在 |x| < 1 收斂）；交錯級數的截斷誤差不超過第一個被丟掉的項。來源：01-微積分 §7。

**推導必寫**：把 e<sup>jθ</sup> 的級數逐項寫開，j² = −1、j³ = −j、j⁴ = 1，偶次項收成 cos θ、奇次項收成 j sin θ。這是本課最重要的一次代數操作，必須把前六項寫出來。

**數值實例**：f = e<sup>x</sup>，x = 1，截斷到 x³（n = 3）：1 + 1 + 1/2 + 1/6 = **2.666667**；真值 e = 2.718282；誤差 0.051615；下一項 1/4! = 0.041667（同數量級，可作誤差估計）。n = 5 時部分和 2.716667，誤差 0.001615。f = sin x、x = 1、n = 3：1 − 1/6 = 0.833333，真值 0.841471，誤差 0.008138。f = ln(1+x)、x = 1.5、任何 n：發散，因為 |x| > 1 超出收斂半徑。

### 04 `04-向量與矩陣.html`

**目標**：把「一組數」變成一個可運算的物件，把矩陣看成「一張搬動規則表」，並用兩種等價視角算 Ax。

**要點**：向量 v = (v<sub>1</sub>, …, v<sub>n</sub>)；線性組合 c<sub>1</sub>v<sub>1</sub> + c<sub>2</sub>v<sub>2</sub> + ⋯；生成（span）；線性獨立（沒有一個向量能由其他向量組出來）；基底（最少而剛好夠用）；維度；矩陣＝線性轉換的座標表，y = Ax；矩陣乘法＝轉換的合成 (AB)x = A(Bx)；單位矩陣 I 什麼都不做；對角矩陣沿各軸獨立拉伸；正交矩陣 Q<sup>T</sup>Q = I 代表旋轉／反射、不改變長度。來源：02-線性代數 §1–§2。

**推導必寫**：兩種等價算法。**列視角**：y 的第 i 個分量＝A 的第 i 列與 x 的內積。**欄視角**：y = x<sub>1</sub>⋅(A 的第一欄) + x<sub>2</sub>⋅(A 的第二欄)，也就是「A 的欄向量的線性組合」。要明講欄視角才是「span、線性獨立、秩」這一整組概念的入口，第 05、06 章都靠它。

**數值實例**：A = [[2,1],[0,3]]，x = (1,2)。列視角：y<sub>1</sub> = 2⋅1 + 1⋅2 = 4，y<sub>2</sub> = 0⋅1 + 3⋅2 = 6，得 **y = (4, 6)**。欄視角：1⋅(2,0) + 2⋅(1,3) = (2,0) + (2,6) = (4,6)，一致。|x| = √5 = 2.236068，|y| = √52 = 7.211103，長度比 3.224903 —— 一般矩陣會同時改變方向與長度。det A = 2⋅3 − 1⋅0 = 6，代表面積被放大 6 倍。

### 05 `05-線性方程組與逆.html`

**目標**：用秩判斷解的型態（唯一／無限多／無解），並看懂 det = 0、rank 不足、奇異三個詞在講同一件事。

**要點**：Ax = b 的三種解型態；高斯消去法化到列梯形再回代；秩 rank(A) = 獨立列／欄的數量；判準 rank(A) = rank([A|b]) = 未知數個數 → 唯一解；rank(A) = rank([A|b]) < 未知數個數 → 無限多解；rank(A) < rank([A|b]) → 無解；行列式的幾何意義是體積（面積）縮放倍率；det ≠ 0 ⇔ A 可逆 ⇔ 唯一解；2×2 反矩陣公式；實務上不真的算 A<sup>−1</sup>，用 LU 分解或直接解；資料多於未知數時用最小平方 x̂ = (A<sup>T</sup>A)<sup>−1</sup>A<sup>T</sup>b，幾何上是把 b 投影到 A 的欄空間。來源：02-線性代數 §3–§5、§10。

**推導必寫**：對 2×2 手動消去一次。從 a<sub>11</sub>x + a<sub>12</sub>y = b<sub>1</sub>、a<sub>21</sub>x + a<sub>22</sub>y = b<sub>2</sub>，第二式減去 (a<sub>21</sub>/a<sub>11</sub>) 倍第一式，得到 (a<sub>22</sub> − a<sub>21</sub>a<sub>12</sub>/a<sub>11</sub>) y = b<sub>2</sub> − a<sub>21</sub>b<sub>1</sub>/a<sub>11</sub>，兩邊乘 a<sub>11</sub> 後左邊係數正是 det = a<sub>11</sub>a<sub>22</sub> − a<sub>12</sub>a<sub>21</sub>。**det 不是被定義出來的神秘量，它就是消去到最後卡在分母的那個數。** 再寫出 A<sup>−1</sup> = (1/det) ⋅ [[a<sub>22</sub>, −a<sub>12</sub>], [−a<sub>21</sub>, a<sub>11</sub>]]，並驗證 A A<sup>−1</sup> = I。

**數值實例**：2x + y = 5、x − y = 1。A = [[2,1],[1,−1]]，b = (5,1)。det = 2⋅(−1) − 1⋅1 = **−3** ≠ 0 → 唯一解。兩式相加得 3x = 6、**x = 2**，代回得 **y = 1**。反矩陣 A<sup>−1</sup> = (1/−3)[[−1,−1],[−1,2]] = [[0.333333, 0.333333], [0.333333, −0.666667]]；A<sup>−1</sup>b = (0.333333⋅5 + 0.333333⋅1, 0.333333⋅5 − 0.666667⋅1) = (2, 1)，一致。
對照組：把第二式改成 4x + 2y = 10（即 a<sub>21</sub>=4、a<sub>22</sub>=2、b<sub>2</sub>=10，把 a<sub>11</sub>=2、a<sub>12</sub>=1、b<sub>1</sub>=5 乘 2）→ det = 0、rank(A) = rank([A|b]) = 1 → 無限多解，解集是整條直線 2x + y = 5。若改成 4x + 2y = 7 → rank(A) = 1 < rank([A|b]) = 2 → 無解，兩條平行線。

### 06 `06-特徵值與分解.html`

**目標**：找出「矩陣作用後方向不變的那些方向」，並理解為什麼控制系統看特徵值就知道穩不穩。

**要點**：定義 Av = λv（v ≠ 0）；特徵多項式 det(A − λI) = 0，2×2 展開成 λ² − (跡)λ + det = 0；判別式決定實根／重根／共軛複根；對角化 A = P D P<sup>−1</sup>，D 裝特徵值、P 的欄是特徵向量；用途 A<sup>k</sup> = P D<sup>k</sup> P<sup>−1</sup>、e<sup>At</sup> = P e<sup>Dt</sup> P<sup>−1</sup>；穩定性：ẋ = Ax 穩定 ⇔ 所有特徵值實部為負；振動分析中特徵值＝自然頻率的平方；內積 u⋅v = Σ u<sub>i</sub>v<sub>i</sub>、正交＝內積為 0、投影＝取分量；傅立葉分析就是把訊號投影到一組正交弦波基底；QR 分解 A = QR 用於最小平方；SVD A = U Σ V<sup>T</sup>（任意矩陣都能分解，PCA／影像壓縮／MIMO 預編碼都用它）。來源：02-線性代數 §6–§9。

**推導必寫**：從 Av = λv 移項成 (A − λI)v = 0，要有非零解就必須 det(A − λI) = 0；對 2×2 展開 (a<sub>11</sub>−λ)(a<sub>22</sub>−λ) − a<sub>12</sub>a<sub>21</sub> = λ² − (a<sub>11</sub>+a<sub>22</sub>)λ + (a<sub>11</sub>a<sub>22</sub> − a<sub>12</sub>a<sub>21</sub>) = λ² − Tλ + D。求根公式 λ = (T ± √(T² − 4D)) / 2。再說明特徵向量的求法：把 λ 代回 (A − λI)v = 0，取 v = (a<sub>12</sub>, λ − a<sub>11</sub>)（a<sub>12</sub> ≠ 0 時）。

**數值實例**：A = [[2,1],[1,2]]。跡 T = 4，det D = 3，判別式 T² − 4D = 16 − 12 = 4 > 0。λ = (4 ± 2)/2 → **λ<sub>1</sub> = 3、λ<sub>2</sub> = 1**。λ = 3 的特徵向量 (a<sub>12</sub>, λ−a<sub>11</sub>) = (1, 1)；驗證 A(1,1) = (3,3) = 3⋅(1,1)。λ = 1 → (1, −1)；A(1,−1) = (1,−1)。兩者內積 1⋅1 + 1⋅(−1) = 0，正交（對稱矩陣必然如此）。測試向量 v = (1,0)：Av = (2,1)，與 v 的夾角 = acos(2/(1⋅√5)) = **26.565°** ≠ 0，所以 (1,0) 不是特徵向量。

### 07 `07-常微分方程.html`

**目標**：讀懂「未知數是一個函式」的方程，抓住時間常數 τ 的意義，並看到最簡單的數值解法（Euler 前向法）怎麼逼近、什麼時候會爆掉。

**要點**：ODE 定義與分類（階數／線性／常係數／齊次）；一階線性標準型 dy/dt + p(t)y = q(t) 與積分因子 μ(t) = e<sup>∫p dt</sup>；電機原型 RC 充電 RC dv/dt + v = v<sub>s</sub>，解 v(t) = v<sub>s</sub> + (v<sub>0</sub> − v<sub>s</sub>) e<sup>−t/τ</sup>，τ = RC；二階常係數 ay″ + by′ + cy = f(t) 的特徵方程 aλ² + bλ + c = 0 與三種根（過阻尼／臨界阻尼／欠阻尼）；標準型 y″ + 2ζω<sub>n</sub>y′ + ω<sub>n</sub>²y = ω<sub>n</sub>²u(t)，ζ 與 ω<sub>n</sub> 的物理意義；完整解 = 齊次解（自然響應）+ 特解（強迫響應）；狀態空間 ẋ = Ax + Bu、y = Cx + Du，解 x(t) = e<sup>At</sup>x(0) + ∫<sub>0</sub><sup>t</sup> e<sup>A(t−τ)</sup>Bu(τ) dτ，A 的特徵值決定穩定性（接回第 06 章）。來源：03-工程數學-上 第 1 章 §1.1–§1.5。

**推導必寫**：（a）RC 電路用分離變數：dv/(v<sub>s</sub> − v) = dt/τ，兩邊積分得 −ln|v<sub>s</sub> − v| = t/τ + C，指數化並代入 v(0) = v<sub>0</sub>，得 v(t) = v<sub>s</sub> + (v<sub>0</sub> − v<sub>s</sub>)e<sup>−t/τ</sup>。（b）Euler 前向法：把 dv/dt ≈ (v<sub>k+1</sub> − v<sub>k</sub>)/Δt 代進原式，整理成 v<sub>k+1</sub> = v<sub>k</sub> + (Δt/τ)(v<sub>s</sub> − v<sub>k</sub>)。這正好是「導數就是差商」的直接應用（回接第 01 章）。（c）穩定性條件：把遞迴寫成 v<sub>k+1</sub> − v<sub>s</sub> = (1 − Δt/τ)(v<sub>k</sub> − v<sub>s</sub>)，誤差每步乘上 (1 − Δt/τ)。所以 Δt/τ < 1 單調收斂、1 < Δt/τ < 2 振盪收斂、Δt/τ > 2 發散——**這是數值方法自己的穩定性，和電路本身穩不穩定無關。**

**數值實例**：τ = 1 s、v<sub>0</sub> = 0 V、v<sub>s</sub> = 5 V。解析解 v(t) = 5(1 − e<sup>−t</sup>)。t = 1 s（即 t = τ）時 v = 5 ⋅ 0.632121 = **3.160603 V**，也就是走完全程的 **63.2 %**；t = 5τ 時達 99.3 %。用 Δt = 0.1 s 走 10 步的 Euler 前向法：誤差因子 (1 − 0.1)<sup>10</sup> = 0.9<sup>10</sup> = 0.348678，v = 5(1 − 0.348678) = **3.256608 V**，比真值高 0.096005 V。把 Δt 減半到 0.05 誤差約減半（Euler 是一階方法）。二階範例：ζ = 0.5、ω<sub>n</sub> = 2 rad/s → λ = −ζω<sub>n</sub> ± ω<sub>n</sub>√(ζ²−1) = −1 ± j1.732051，欠阻尼、會振盪衰減。

### 08 `08-拉氏轉換.html`

**目標**：理解「微分變乘 s」為什麼把微分方程變成代數方程，並把極點位置直接讀成時域行為。

**要點**：定義 F(s) = ∫<sub>0</sub><sup>∞</sup> f(t) e<sup>−st</sup> dt，s = σ + jω 為複數；收斂域（Region of Convergence, ROC）通常是 Re(s) > σ<sub>0</sub>；核心性質表（f′ → sF(s) − f(0)、f″ → s²F(s) − sf(0) − f′(0)、∫ → F(s)/s、時移 → e<sup>−as</sup>F(s)、頻移 → F(s−a)、卷積 → F(s)G(s)）；常見轉換對表（1 → 1/s、t → 1/s²、e<sup>−at</sup> → 1/(s+a)、sin ωt → ω/(s²+ω²)、cos ωt → s/(s²+ω²)、δ(t) → 1）；解 ODE 四步驟（取拉氏 → 解代數 → 部分分式 → 反查表）；轉移函數 H(s) = Y(s)/U(s)；極點＝分母為零的 s，就是齊次解的指數速率；穩定性⇔所有極點在左半平面；終值定理 f(∞) = lim(s→0) sF(s)、初值定理 f(0⁺) = lim(s→∞) sF(s)；電路在 s 域：電容變 1/(sC)、電感變 sL，整個電路變成歐姆定律。來源：03-工程數學-上 第 2 章 §2.1–§2.7。

**推導必寫**：（a）微分性質的分部積分推導：∫<sub>0</sub><sup>∞</sup> f′(t)e<sup>−st</sup> dt = [f(t)e<sup>−st</sup>]<sub>0</sub><sup>∞</sup> + s∫<sub>0</sub><sup>∞</sup> f(t)e<sup>−st</sup> dt = −f(0) + sF(s)（假設 e<sup>−st</sup>f(t) 在無窮遠趨於 0，這就是 ROC 的用處）。（b）完整解一題：y″ + 3y′ + 2y = 0、y(0) = 1、y′(0) = 0。取拉氏：(s²Y − s⋅1 − 0) + 3(sY − 1) + 2Y = 0 → Y(s² + 3s + 2) = s + 3 → Y(s) = (s+3)/((s+1)(s+2))。部分分式 A/(s+1) + B/(s+2)：A = (−1+3)/(−1+2) = 2，B = (−2+3)/(−2+1) = −1。反查表得 **y(t) = 2e<sup>−t</sup> − e<sup>−2t</sup>**。（c）從二階標準型導出極點與 ζ、ω<sub>n</sub> 的關係：s² + 2ζω<sub>n</sub>s + ω<sub>n</sub>² = 0 → s = −ζω<sub>n</sub> ± ω<sub>n</sub>√(ζ²−1)。所以給定一對複極點 σ ± jω，反推 ω<sub>n</sub> = √(σ² + ω²)、ζ = −σ/ω<sub>n</sub>。

**數值實例**：一對共軛極點 s = −1 ± j2。ω<sub>n</sub> = √(1 + 4) = √5 = **2.236068 rad/s**；ζ = 1/√5 = **0.447214**（欠阻尼）；時間常數 τ = 1/|σ| = **1 s**；振盪週期 2π/ω = **3.141593 s**。對應模態 e<sup>σt</sup>cos(ωt)，在 t = 1 s 時 = e<sup>−1</sup> ⋅ cos 2 = 0.367879 ⋅ (−0.416147) = **−0.153092**，包絡線 e<sup>−1</sup> = 0.367879。因為 σ < 0，系統穩定。

### 09 `09-複變入門.html`

**目標**：把複數乘法看成「旋轉＋伸縮」，接上歐拉公式與相量，理解為什麼交流電路可以用複數代數解。

**要點**：直角形式 z = x + jy（電機用 j 避開電流 i）與極形式 z = r e<sup>jθ</sup>，r = |z| = √(x²+y²)、θ = arg z = atan2(y, x)；歐拉公式 e<sup>jθ</sup> = cos θ + j sin θ 與衍生式 cos θ = (e<sup>jθ</sup> + e<sup>−jθ</sup>)/2、sin θ = (e<sup>jθ</sup> − e<sup>−jθ</sup>)/(2j)；乘法規則 |z w| = |z||w|、arg(zw) = arg z + arg w；d/dt e<sup>jωt</sup> = jω e<sup>jωt</sup>（微分變乘 jω，這是相量分析的根本）；相量 v(t) = V cos(ωt + φ) ↔ **V** = V e<sup>jφ</sup>；阻抗 Z<sub>R</sub> = R、Z<sub>L</sub> = jωL、Z<sub>C</sub> = 1/(jωC)；解析（analytic）與柯西—黎曼方程 ∂u/∂x = ∂v/∂y、∂u/∂y = −∂v/∂x；柯西積分定理 ∮<sub>C</sub> f(z) dz = 0、柯西積分公式；留數定理 ∮<sub>C</sub> f(z) dz = 2πj Σ Res(f, z<sub>k</sub>)，工程用途是反拉氏／反傅立葉的圍道積分；保角映射與史密斯圖。來源：03-工程數學-中 第 3 章 §3.1–§3.6。

**推導必寫**：（a）用極形式證乘法就是旋轉伸縮：(r<sub>1</sub>e<sup>jθ1</sup>)(r<sub>2</sub>e<sup>jθ2</sup>) = r<sub>1</sub>r<sub>2</sub>e<sup>j(θ1+θ2)</sup>；再用直角形式展開 (x<sub>1</sub>+jy<sub>1</sub>)(x<sub>2</sub>+jy<sub>2</sub>) = (x<sub>1</sub>x<sub>2</sub> − y<sub>1</sub>y<sub>2</sub>) + j(x<sub>1</sub>y<sub>2</sub> + y<sub>1</sub>x<sub>2</sub>)，指出這兩個式子必須算出同一個答案。（b）從 d/dt e<sup>jωt</sup> = jω e<sup>jωt</sup> 推出電感 v = L di/dt 在相量下變成 **V** = jωL **I**，也就是 Z<sub>L</sub> = jωL。

**數值實例**：z = 1 + j，w = 0 + j（即純 j）。極形式：|z| = √2 = **1.414214**、arg z = **45°**；|w| = 1、arg w = **90°**。直角展開：(1 + j)(0 + j) = 1⋅0 − 1⋅1 + j(1⋅1 + 1⋅0) = **−1 + j**。極形式驗證：|zw| = 1.414214 ⋅ 1 = 1.414214、arg(zw) = 45° + 90° = **135°**，而 −1 + j 的模確實是 √2、幅角確實是 135°。**乘以 j 就是逆時針轉 90°、長度不變。**

### 10 `10-傅立葉分析.html`

**目標**：親眼看到「方波是一堆弦波疊出來的」，並理解項數、收斂速度與吉布斯現象。

**要點**：四種工具的對照表（連續週期→傅立葉級數 FS／連續非週期→傅立葉轉換 FT／離散非週期→DTFT／離散有限→DFT 與 FFT）；級數 x(t) = Σ<sub>n=−∞</sub><sup>∞</sup> c<sub>n</sub>e<sup>jnω0t</sup>，ω0 = 2π/T，c<sub>n</sub> = (1/T)∫<sub>0</sub><sup>T</sup> x(t)e<sup>−jnω0t</sup> dt；轉換 X(ω) = ∫<sub>−∞</sub><sup>∞</sup> x(t)e<sup>−jωt</sup> dt 與反轉換；七大性質（線性、時移 → X(ω)e<sup>−jωt0</sup>、頻移、時間縮放、**微分 → jωX(ω)**、**卷積 → 相乘**、相乘 → 卷積/2π）；巴塞瓦定理（能量守恆）；重要轉換對（δ(t) ↔ 1、1 ↔ 2πδ(ω)、cos ω0t ↔ 兩個 δ、矩形 ↔ sinc、高斯 ↔ 高斯）；時頻不確定性 Δt ⋅ Δω ≥ 1/2；取樣定理 f<sub>s</sub> ≥ 2W 與摺疊（aliasing）；DFT X[k] = Σ<sub>n=0</sub><sup>N−1</sup> x[n]e<sup>−j2πkn/N</sup>，FFT 把 O(N²) 降到 O(N log N)。來源：03-工程數學-中 第 4 章 §4.1–§4.9。

### 11 `11-PDE與向量分析.html`

**目標**：把 ∇（nabla）三個算子變成可以用數值差分算出來的東西，並看懂三大經典 PDE 各自代表哪一種物理行為。

**要點**（向量分析）：純量場 φ(r) 與向量場 F(r)；梯度 ∇φ = (∂φ/∂x, ∂φ/∂y, ∂φ/∂z)，指向上升最快方向，E = −∇V；散度 ∇⋅F = ∂F<sub>x</sub>/∂x + ∂F<sub>y</sub>/∂y + ∂F<sub>z</sub>/∂z，代表「源」的強度，∇⋅E = ρ/ε<sub>0</sub>；旋度 ∇ × F，代表旋轉性，∇ × B = μ<sub>0</sub>J + μ<sub>0</sub>ε<sub>0</sub>∂E/∂t；拉普拉斯算子 ∇²φ = ∇⋅(∇φ)；兩個恆等式 ∇ × (∇φ) = 0（梯度場無旋，所以有電位）與 ∇⋅(∇ × F) = 0（旋度場無散，所以磁場無單極）；線／面／體積分；格林定理、高斯散度定理 ∮<sub>S</sub> F⋅dA = ∫<sub>V</sub> (∇⋅F) dV、史托克斯定理 ∮<sub>C</sub> F⋅dℓ = ∫<sub>S</sub> (∇ × F)⋅dA——這兩條就是馬克士威方程式積分形式與微分形式之間的橋；馬克士威四條方程式。
**要點**（PDE）：PDE 與 ODE 的差別（對多個變數求導）；定解需要 PDE ＋ 邊界條件 ＋ 初始條件；三大經典 PDE：熱／擴散 ∂u/∂t = α∇²u、波動 ∂²u/∂t² = c²∇²u（真空中 c = 1/√(μ<sub>0</sub>ε<sub>0</sub>)，光速就是這樣從電磁學冒出來的）、拉普拉斯 ∇²u = 0；判別式 B² − 4AC 分類（<0 橢圓／穩態、=0 拋物／擴散、>0 雙曲／傳播）；解法（分離變數＋疊加＋傅立葉級數定係數、積分變換、格林函數 u = G * f、有限差分／有限元素）；邊界條件三型（Dirichlet 指定值、Neumann 指定法向導數、Robin 混合）；弦振動例：u(x,t) = Σ [a<sub>n</sub>cos(nπct/L) + b<sub>n</sub>sin(nπct/L)] sin(nπx/L)，模態頻率 f<sub>n</sub> = nc/(2L)。來源：03-工程數學-下 第 5 章、第 6 章。

**推導必寫**：（a）用中央差分把三個算子寫成可計算的形式：∂F<sub>x</sub>/∂x ≈ (F<sub>x</sub>(x+h, y) − F<sub>x</sub>(x−h, y)) / (2h)，散度＝兩個這種項相加，二維旋度的 z 分量 = ∂F<sub>y</sub>/∂x − ∂F<sub>x</sub>/∂y。這直接接回第 01 章的中央差商。（b）驗證 ∇ × (∇φ) = 0：對 φ = x² + y²，∇φ = (2x, 2y)，旋度 z 分量 = ∂(2y)/∂x − ∂(2x)/∂y = 0 − 0 = 0。（c）弦振動的分離變數：設 u = X(x)T(t)，代入得 X″/X = T″/(c²T) = −k²（兩邊各自只含一個變數，所以必為常數）；配合 u(0,t) = u(L,t) = 0 得 X<sub>n</sub> = sin(nπx/L)，於是 f<sub>n</sub> = nc/(2L)。

**數值實例**：F = (x, y) 在點 (1, 1)、h = 0.01。F 值 = (1, 1)。∇⋅F：(1.01 − 0.99)/0.02 + (1.01 − 0.99)/0.02 = 1 + 1 = **2**（解析值 2，誤差 0）。旋度 z 分量 = (1 − 1)/0.02 − (1 − 1)/0.02 = **0**。順帶 φ = x² + y² 在 (1,1) 的數值梯度 = ((1.01² − 0.99²)/0.02, 同) = (2, 2)，解析 (2x, 2y) = (2, 2)。
對照組：F = (−y, x) 在 (1,1) → ∇⋅F = 0、旋度 = **2**（純旋轉，無源）。F = (xy, y) 在 (1,1) → ∇⋅F = y + 1 = **2**、旋度 = −x = **−1**（同時有源與旋）。
弦振動實例：L = 0.65 m、c = 200 m/s → f<sub>1</sub> = 200/(2⋅0.65) = **153.85 Hz**，f<sub>2</sub> = 307.69 Hz，泛音是基頻的整數倍。

**不要混淆**：散度是純量、旋度是向量（二維只剩 z 分量）；∇²φ 是純量到純量，不要和向量拉普拉斯混用；「無旋」是局部性質，全域是否有位勢還要看區域是否單連通；三大 PDE 的邊界條件需求不同，不能照搬（雙曲型要初值，橢圓型只要邊界值）。

**可觀察證據**：高斯定律用封閉曲面的通量量電荷；霍爾探棒沿封閉路徑積分測電流（安培定律）；有限元素模擬器輸出的場圖；吉他弦的泛音頻率就是 f<sub>n</sub> = nc/(2L)。

### 12 `12-機率與隨機變數.html`

**目標**：把「不確定」變成可以算的量：分布、期望值、變異數、PMF/PDF/CDF，並認得工程上最常見的幾個分布。

**要點**：樣本空間 Ω、事件 A、機率公設；條件機率 P(A|B) = P(A∩B)/P(B)；獨立 P(A∩B) = P(A)P(B)；貝氏定理 P(A|B) = P(B|A)P(A)/P(B)，通訊上 P(x|y) ∝ P(y|x)P(x)（最大後驗 MAP 檢測的核心）；隨機變數＝把結果對應到實數的函式；離散用機率質量函數（Probability Mass Function, PMF）、連續用機率密度函數（Probability Density Function, PDF），P(a<X<b) = ∫<sub>a</sub><sup>b</sup> f<sub>X</sub>(x) dx；累積分布函數（Cumulative Distribution Function, CDF）F<sub>X</sub>(x) = P(X ≤ x)；期望值 E[X]、變異數 Var(X) = E[X²] − E[X]²、標準差 σ；性質 E[aX+b] = aE[X]+b、Var(aX+b) = a²Var(X)；常見分布（伯努利、二項、幾何、卜瓦松、均勻、指數、高斯、瑞利、萊斯）；共變異數與相關係數 ρ ∈ [−1, 1]；獨立 ⇒ 不相關，反之不一定（高斯時等價）；大數法則與中央極限定理（CLT）。來源：04-機率與統計 §1–§7。

**推導必寫**：（a）Var(X) = E[X²] − E[X]² 的展開：E[(X−μ)²] = E[X² − 2μX + μ²] = E[X²] − 2μE[X] + μ² = E[X²] − μ²。（b）公正骰子：E[X] = (1+2+3+4+5+6)/6 = 3.5；E[X²] = (1+4+9+16+25+36)/6 = 91/6 = 15.166667；Var = 15.166667 − 12.25 = 2.916667 = 35/12。（c）BPSK 錯誤率的來歷：通道 y = x + n、n ~ N(0, σ²)、x ∈ {+A, −A} 等機率，最佳判決是看 y 的正負，錯誤發生在雜訊超過 A，機率 P<sub>e</sub> = Q(A/σ)，其中 Q(x) = 1 − Φ(x)。數字：A = 1、σ = 0.5 → Q(2) = 1 − 0.977250 = **0.022750**。

**數值實例**（與 widget 預設一致）：公正骰子。E[X] = **3.5**、Var = 35/12 = **2.916667**、σ = **1.707825**；P(X = 3) = 1/6 = **0.166667**、F(3) = P(X ≤ 3) = **0.5**。
其他錨定值：二項 n = 10、p = 0.5 → E = 5、Var = 2.5、σ = 1.581139、P(X=5) = 252/1024 = **0.246094**、F(5) = **0.623047**。卜瓦松 λ = 3 → E = Var = 3、P(X=2) = e<sup>−3</sup>⋅9/2 = **0.224042**。指數 λ = 3 → E = 1/3、Var = 1/9、f(1) = 3e<sup>−3</sup> = **0.149361**、F(1) = 1 − e<sup>−3</sup> = **0.950213**。常態 μ = 0、σ = 1 → f(1) = **0.241971**、Φ(1) = **0.841345**。

### 13 `13-統計推論與隨機過程.html`

**目標**：從資料反推模型：算出平均值的標準誤、信賴區間與檢定判決；並認得隨機過程的四個關鍵屬性。

**要點**（統計推論）：參數估測（最大似然 MLE 選讓觀測資料機率最大的參數；最大後驗 MAP 再加先驗；最小均方誤差 MMSE 使 E[(θ̂−θ)²] 最小）；樣本平均的標準誤 SE = σ/√n（由 Var(ΣX<sub>i</sub>/n) = σ²/n 得來）；CLT 保證 n 大時 x̄ 近似常態，所以 (1−α) 信賴區間為 x̄ ± z<sub>α/2</sub>⋅σ/√n；常用 z 值 90 % → 1.645、95 % → 1.960、99 % → 2.576；假設檢定 H<sub>0</sub> vs H<sub>1</sub>、假警率（false alarm）與漏報率（miss）、奈曼—皮爾遜準則；通訊接收器的符元檢測就是假設檢定。
**要點**（隨機過程）：隨機過程 {X(t)} 是隨機變數的時間序列；平穩（stationary）＝統計性質不隨時間漂移；遍歷（ergodic）＝時間平均 = 集合平均；自相關 R<sub>X</sub>(τ) = E[X(t)X(t+τ)]；功率譜密度 S<sub>X</sub>(ω) 是 R<sub>X</sub>(τ) 的傅立葉轉換（Wiener–Khinchin 定理，接回第 10 章）；白雜訊 S<sub>X</sub>(ω) = 常數、R<sub>X</sub>(τ) = 脈衝 δ(τ)，所有頻率等強度。來源：04-機率與統計 §8–§10。

**推導必寫**：（a）SE 的來歷：n 個獨立同分布樣本，Var(x̄) = Var((X<sub>1</sub>+⋯+X<sub>n</sub>)/n) = (1/n²)⋅n⋅σ² = σ²/n，開根號得 SE = σ/√n。**因為是開根號，半寬要減半必須把 n 變成 4 倍。**（b）信賴區間的意義：區間是隨機的、真值是固定的；「95 % 信賴」是指「這個造區間的程序，長期而言有 95 % 的區間會蓋住真值」，不是「真值有 95 % 機率落在這個區間」。（c）雙尾檢定與區間的等價：|x̄ − μ<sub>0</sub>|/SE > z<sub>α/2</sub> ⇔ μ<sub>0</sub> 落在信賴區間之外。

**數值實例**（與 widget 預設一致）：x̄ = 5、σ = 2（已知母體標準差）、n = 25、信賴水準 95 %。SE = 2/√25 = 2/5 = **0.400000**；半寬 = 1.960 × 0.4 = **0.784000**；信賴區間 = [**4.216000**, **5.784000**]。檢定 H<sub>0</sub>: μ = 4：z = (5 − 4)/0.4 = **2.500000** > 1.960，且 4 落在區間外 → **拒絕 H<sub>0</sub>**。若把 n 加到 100，SE = 0.2、半寬 = 0.392，寬度剛好減半（n 變 4 倍）。

## 10. 來源筆記缺口（僅列出，本案不回頭改寫筆記）

以下是撰寫本 spec 時發現、來源筆記沒有但本課需要的內容。builder **可以自行補上教學文字**（因為都是標準大學課綱內容且可由既有段落推得），但**不得回頭修改 `.md` 筆記**。Lead 可另案決定是否補進筆記。
