# 圖解工程數學：先看變化，再選工具

本課是新的獨立網站，發布 slug 為 `engineering-math-little-lab`，由中央發布者接入既有 GitHub Pages。依 root 最新排程，新站不建立 Sites 專案或 `.openai`；既有其他課的 Sites 鏡像由其專員維護。既有工程數學互動課程、微積分與線性代數網站保留。使用原生 HTML、CSS、JavaScript 與原創 inline SVG；不新增依賴、外部字型、點陣圖或執行期網路請求。

## 讀者基線

讀者軟體能力強，電機本科名詞可能認得，數學與物理基礎薄弱。可以把公式視為需要重新建立意思的記法，不假設會 ODE、複數、相量、Laplace 或 Fourier。微積分隊先教導數、積分、指數、正弦、級數、一階 RC／RL；本課提供短回顧與明確先備入口，避免重教整門微積分。

## 目標能力與 prerequisite gap

完成後能從位置與速度的兩張初始資料卡建立二階模型；分清自然響應、外力與完整響應；由串聯 RLC 的回路和儲能推得方程；在同一頻率的正弦穩態用複數計算大小與相位；以單邊拉氏保留初值解簡單 ODE；在零初值的 LTI 模型定義轉移函數；把週期波形拆成諧波並分清級數係數與轉換密度；讀懂簡單熱／波動／靜電 PDE 的初始與邊界條件，完成一個分離變數小例。

理解債依次為：二階需要兩個初值、負根與振盪、複數乘法、角頻率與赫茲、正弦穩態成立條件、收斂域、零初值、脈衝與卷積、頻譜單位、偏導與邊界資料。每一項都先有可追蹤的具體數值或圖，再介紹術語。

## 教學方式與深度

每章從一個小問題開始，以多幅有因果關係的步驟圖追蹤同一組數字，再進入同一例子的自由實驗。每幅圖要讓讀者取得下一步所需的資訊；不以裝飾圖或 SVG 數量充當教學。

依使用者最新回饋，圖解必須接到會計算：每課以具體題目的給定與求量開場，讓圖中物件與公式符號逐一對照；說清選式理由與條件，代入實際數值，逐行列出中間值、正負與單位，再用原條件檢查答案。核心跟算過程留在可見正文，不藏在 details，也不以另放公式表代替圖解。每課另有改一個條件的相近練習，提供分步提示與完整解答，不設解鎖考試。先完成 initial-values 一章 prototype，由隊長檢視能否照著算一題、研究者獨立核每步，再擴到全課。第一屏可以是明白可讀的步驟圖，完整教學後才出現滑桿與正式符號。

課綱鎖定 16 個教學頁與首頁、字典、來源頁。課綱、先備、後續對應及作者領地存於 [課綱與銜接.json](課綱與銜接.json)。原筆記只作範圍盤點，數學主張以核讀過的官方開放教材為依據。公式與單位、成立條件放在可見正文；較長代數可收合，不能把模型條件藏進收合區。

大學工程基礎是主範圍；不展開完整複變函數、留數、研究級 PDE、數值穩定理論或完整訊號處理課。這些方向在後續路線說清楚，不聲稱完成此站就已學會整門電磁或控制。

## 語言與名詞契約

繁體中文與臺灣慣用語，首次專有名詞附英文與白話動作。電機複數用 j，角頻率用 ω（rad/s）、頻率 f（Hz），相量先固定峰值慣例，其他慣例需明確換算。使用「訊號、卷積、拉氏轉換、傅立葉、常微分方程、偏微分方程、轉移函數」並在字典拆分名詞與因果概念。全文收尾掃描簡體與形近字。

本地來源為 `03-工程數學-上／中／下.md` 與舊工程數學互動課。官方教材查證逐批不超過四頁，由本隊唯一研究者串行進行，記錄章節、支持主張、條件與授權。教學圖和數字自作；不複製教材圖，不把來源索引當作逐頁驗證。
