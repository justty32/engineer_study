# 圖解工程數學建置規格

課綱與 16 個互動契約已經獨立官方教材及數學首輪核證；各課 DOM 已鎖定於 [互動契約.json](互動契約.json)。成品仍須正式 freeze 後的獨立數學及瀏覽器驗收。

## 檔案與共同結構

網站成品置於 `dist/`。`index.html` 提供可讀的課程地圖；`00-state.html` 是入口；每課有可見先備、逐步圖、小例、自由實驗、條件與反例、正式記法、後續連結與上一／下一頁。`glossary.html` 可搜尋白話名詞，`sources.html` 將每組主張連到已核讀教材。

共用 `lab.css`、`shared.js`；每課獨立 JavaScript，掛勾前確認 DOM 存在。不改舊站共用 styles 正本。無強制測驗解鎖、計分、倒數與外部執行期資源。具名外部教材超連結允許，使用者點擊才前往。

## 圖與互動契約

同一物件、同一數值、同一尺度貫穿分鏡與實驗。圖表有軸與單位、方向與文字替代，狀態不只靠顏色；需要換比例時明標。公式先介紹每個量的意思與單位。實驗須具教學問題、控制量範圍／級距／預設、狀態方程、數值判準、可觀察數值與 why、邊界案例、重設。

由建置隊依課綱與官方資料完成互動契約資料檔，獨立數學審查者重算初值、微分方程殘差、波形尺度與頻譜單位。二階 ODE 必須包含完整受迫／自然合成，不可只畫沒有初值的正弦。RLC 以電容電壓作狀態，避免微分步階源而漏掉脈衝與跳躍。

契約內供程式計算的簡寫採 SI 數值：例如 `e^-t` 的程式引數是以秒表示的數值，正文需寫清楚衰減率乘時間的乘積無量綱。涉及相加的初值係數不可混用有量綱的速度與位置；正文推導保留所需秒數或先定義無量綱時間，不能靠「數字算對」略過量綱。

相量只處理同頻率正弦穩態，複數單獨不代表完整時域暫態。單邊拉氏必須一致交代 0+ 常規初值與 0− 分布慣例的選擇；若不教原點脈衝，直接標明排除。轉移函數明確零初值、LTI、因果條件。Fourier 清楚區分 Hz 與 rad/s、週期功率與非週期能量，含不連續點與 Gibbs 現象限制。PDE 至少完成一個代回方程和邊界都成立的解。

## 圖解與完整跟算

每課先交代具體工程情境的已知量與欲求量，再把圖上的物件、方向、尺度與公式符號逐一對上。公式需交代來源與成立條件；用同一組真實數值逐行代入，保留中間值、正負號與單位，最後以初值／邊界／原方程或合理極限檢查答案。關鍵計算直接連在分鏡旁並可見，不只集中在公式表，也不藏於 details。

近題以只改一項條件為主，給分步提示與完整答案，讓讀者能對照哪張資料卡改了、哪一步因而改變。必要的額外推導與第二道延伸題可使用 details；閱讀與實驗不設強制答題。`initial-values.html` 是已獨立核可的跟算示範，但其他課按各自數學推理調整，不機械複製六格。

窄版靜態圖不能只縮成難讀的字：320 px 畫面下主要 SVG 標籤至少 12 px，入門圖完整呈現；複雜實驗圖若需要局部水平捲動，明示操作且主要數值先在圖外可見。拉氏變數斜體 s 與秒的正體單位 s 分清；數字近似用適當精度與近似記號。

## 共同 DOM 與版型（作者入口）

依 [互動契約.json](互動契約.json) 的 `page` 切片閱讀，每列 `dom` 是唯一契約。控制 `id` 不加頁名前綴；顯示值為 `id-value`。每頁只有一個 `drawing` 圖層、`result-primary` 與 `result-secondary` 讀值、`feedback` 即時文字、`reset` 重設。根容器是該列 `id`。數值輸入使用已鎖定範圍，選單值保留契約順序。

HTML 使用 `lang=zh-Hant`，`body data-page`；只載 `lab.css`、`shared.js` 及自身同名 JS，兩腳本加 `defer`。固定外殼為 `.site-header#site-header`、`nav#course-nav`、`main#main`、`.site-footer#site-footer`。`shared.js` 負責導覽、SVG工具與不含外力的二階實解分支。各頁互動先檢查 root 存在。

故事採 `.story-sequence` → `.story-step`（步號 `.step-label`），四至六組因果圖，SVG自繪並附 title/desc；圖中每一步只新增本步所需資料。實驗採 `.experiment`、`.experiment-top`、`.experiment-grid`、`.diagram-scroll`、`.controls`、`.readouts`、`.feedback`。`feedback` 使用 `role=status aria-live=polite`。`00-state` 原創入口為視覺 pilot，已由父隊檢視手機及座標映射，其他頁沿用節奏而非更換名詞。

`lab.css` 是此獨立圖解課產品樣式，不引用或改寫舊課 `styles.css` 正本；共用樣式正本同步閘門對本目錄不適用。來源章節與官方授權依 [教材與主張索引.json](教材與主張索引.json)，產品 sources 頁保留來源 id 錨點。作者與檔案狀態見 [產品作者狀態.json](產品作者狀態.json)，狀態不代表獨立驗收通過。

## 圖表尺寸與讀值

圖表採 SVG viewBox；00-state 依實際容器寬度重繪、完整顯示 −2 至 2 m。二階/RLC/摺積/PDE/Fourier 類有不同單位的兩圖時，以上下獨立座標繪製，不把不同量綱疊到同軸。複數平面每單位 x/y 同尺度。其餘坐標圖以 660×360 為基準；任何自動縮放須在圖標或可見回饋明說。各頁腳本所需 viewBox 與讀值意義已隨作者任務逐檔鎖定。
