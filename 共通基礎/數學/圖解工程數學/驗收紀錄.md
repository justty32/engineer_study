# 圖解工程數學 — 獨立瀏覽器驗收

2026-10-11，驗收者為 browser_qa，沒有參與產品實作。產品為 [dist/index.html](dist/index.html)，逐頁受審 SHA、案例、數值與證據索引收在 [瀏覽器驗收.json](瀏覽器驗收.json)（19 列）。

**判定：瀏覽器範圍通過，可納入最終交付候選。** 小車零速零時及摺積輸入停止時的兩處回饋缺陷，連同傅立葉級數的精確／近似等號記法，均已由作者修正並依新 SHA 獨立複驗。目前沒有本輪未結產品缺陷。

19 頁各在 1440×900、390×900、320×900 的既有無頭 Chromium 載入；初輪為 57 個完整頁面案例及 396 個端點、選項、組合與搜尋狀態。修後另跑三頁三尺寸的 9 個頁面案例、60 個控制狀態及 45 個精確邊界分支。每頁另關閉 JavaScript，確認教學文字、靜態步驟圖及備援導覽存在。未新增依賴、未使用 GUI、未部署。

- **介面與操作：通過。** 無頁面橫向溢出、重複 ID、未標示控制；預設、端點、案例切換、鍵盤與重設均有實際 DOM 證據。
- **可及性：通過本輪範圍。** 跳主文後的 Tab 從主文繼續；手機章節可用 Enter 展開；滑桿、選單、按鈕及水平圖面可鍵盤操作，焦點可見。
- **離線與技術：通過。** 離線 file 導覽可用，另測本地 HTTP 57 次；無外部執行期請求或 console/pageerror。38 檔嚴格 UTF-8、JavaScript 語法與 339 個靜態本地引用檢查通過。
- **圖面：通過。** 逐頁人工看三尺寸關鍵分鏡與算式、全部 16 實驗的窄螢幕水平捲動結果；234 個動態 SVG 端點／選項狀態未見文字超出圖框。
- **顯示數值：通過。** 用獨立公式比對 28 個實際 DOM 預設讀值，均在顯示精度容許範圍。完整教材、公式、幾何及教學審查分別由 [數學與圖形驗收](數學與圖形驗收.json)、[教學驗收](教學驗收.json)、[隊長教學複核](隊長教學複核.json) 負責。
- **回饋語意：通過。** 零速零時會說兩車保持原點；零時非零速會說下一個正時間位置不同。摺積明確分開停止前、停止當下及停止後，數值連續且回饋與輸入定義一致。修正歷史留在逐頁資料。
- **真實使用者學習與實體觸控：待人工。** 此輪為無頭瀏覽器與代理視覺審查，未做真人學習者或實體手機測試。
