# 圖解工程數學

[開啟課程地圖](dist/index.html)｜[零基礎入口](dist/00-state.html)｜[白話字典](dist/glossary.html)｜[官方教材與條件](dist/sources.html)

這是另建的獨立圖解課程，既有「共通基礎／數學／互動課程」保留。包含 19 個 HTML 頁面（16 個教學頁與首頁、字典、來源頁），發布 slug 為 `engineering-math-little-lab`；本站只發布至 GitHub Pages；發布與共享 Git 由中央發布者處理。

先從無外力小車的位置與速度兩張初值卡出發，再依序建立二階 ODE、受迫響應、RLC、複數、同頻正弦相量、單邊拉氏、初值、LTI 轉移函數、摺積、傅立葉與一維 PDE 邊界。每頁先以同一個例子的因果圖解說明，再以同預設的實驗觀察變化，最後介紹正式符號。每課將公式來源、逐行數值代入、正負與單位、驗算及只改一項條件的近題接回圖解；核心計算留在可見正文，補充推導可展開閱讀。

不含完整複變、留數、完整電磁／控制／機器人課、研究級 PDE 與數值穩定理論。其他課程的應用路線只表示銜接用途，不冒稱讀完本課即可完成整科設計。

成品僅用原生 HTML、CSS、JavaScript 與原創 inline SVG；無外部字型、點陣圖、CDN、API 或第三方執行期依賴，可直接用瀏覽器開啟 `dist/index.html` 離線閱讀與操作。只有點擊來源超連結時才需網路。

官方教材以 MIT OpenCourseWare 為主，補 University of Washington、University of Virginia 與 University of California, Berkeley 官方材料；實讀章節、主張與條件記在 [教材與主張索引](教材與主張索引.json)。MIT OCW 來源列明 CC BY-NC-SA 4.0；未確認可再製授權的其他官方來源只參考數學事實，不轉載文字或圖。敘事、教學數值、圖及程式均原創。

建置契約與頁面責任見 [BUILD-SPEC](BUILD-SPEC.md)、[PROJECT-BRIEF](PROJECT-BRIEF.md)、[互動契約](互動契約.json)、[課綱與銜接](課綱與銜接.json)。建置狀態見 [產品作者狀態](產品作者狀態.json)；正式驗收完成前不以頁數或圖數宣稱讀者已看懂。
