# 圖解微積分 — 立案

本次建立獨立的「微積分小小實驗室」，由圖像、操作與短句把變化及累積接起來。原始筆記是大學概論骨架，新站補齊必要前置，保留全部八個核心觀念，舊互動課程原地保留。使用者授權大量委派、搜尋查證、修正原文錯誤、push 與部署；本輪修訂微積分圖解，目標補足電磁學、電子學與電路學的數學銜接。

## 讀者基線

讀者熟悉軟體，但數學基礎不穩，不假設已懂座標、函數、斜率或積分符號。先用輸入與輸出、圖上的位置，以及有單位的變化建立模型。成果除了讀懂圖形與條件，還要能在拿到相似題目時，辨認已知與未知量、選擇適用公式、逐行計算並檢查答案。

## 語言與名詞契約

使用繁體中文、台灣慣用語；首次術語附英文，符號以 Unicode 或原生 HTML 呈現，不需要外部字型或數學渲染器。類比必須收回到真實數學關係；圖像具有標籤、數值及文字替代，不依賴顏色傳訊。

## prerequisite gap

補教座標軸、函數、正負號、比值與斜率。導數前先教割線與逼近；積分前先教小長條的寬乘高；多變數前先補等高線、方向與向量箭頭。頁首連回最低必要前置，字典可隨時回查。

## 概念依賴與教學邊界

零基礎 → 極限 → 導數 → 常用函數／微分規則／局部近似 → 積分與累積 → 電荷／一階動態 → 多變數 → 多重積分／座標尺度 → 向量場／線積分／電位／通量 → 散度旋度與 Gauss–Stokes。工程頁回收電容、功率與能量的單位。本輪擴成 23 個教學頁，加入局部線性化、電荷／電流、一階動態、座標尺度、線積分、通量、散度／旋度與 Gauss–Stokes。每章以一個可追蹤的小例子串起分步圖，再進入可重設且即時回饋的主實驗；不用考試或解鎖限制瀏覽。

完整涵蓋原筆記八節，仍屬大學概論，不聲稱取代證明課或完整題庫。明確交代連續與可微、極值候選及端點、有號面積、FTC 條件、泰勒收斂、梯度零向量、向量場與線面積分的邊界。

## 本地來源與查證

主要來源：上層 `01-微積分.md` 與 `中英名詞對照表.md`。既有工程數學互動課程僅唯讀參照。數學查證由獨立 audit agent 統一查官方教材，成果列在網站 sources.html；所有 SVG 與程式原創，不複製外站插圖。

## 交付與可延續性

成品共 53 檔：26 HTML、26 JavaScript、1 CSS；26 頁包含 23 教學章、首頁、50 詞字典與來源頁。互動契約共 25 列，包含 24 個參數實驗及字典搜尋；教材與銜接索引共 25 列，後續電子／電路接線共 2 列。

成品放在 dist/，原生 HTML/CSS/JS，不安裝依賴，無遠端執行資源，支援離線檔案開啟。首頁為課程地圖，00-start.html 為零基礎入口，glossary.html 為字典。完整互動與唯一作者紀錄分別見 BUILD-SPEC.md 所指的資料檔、派工計畫.json。驗收結果由獨立 QA 寫入驗收紀錄.md，未做的人工觸控檢查不冒充通過。GitHub Pages 路徑 calculus-little-lab；Sites 身分與發布由 root 管理。

讀者基線與為何從此開始在本檔；章節用途及導航在 dist/index.html；來源與數值契約在 BUILD-SPEC.md／互動契約.json；檢查結果在驗收紀錄.md。

## 本輪深度與終點

讀者應能區分儲存量與變化率、用局部斜率近似小改變、讀懂含初值的一階 RC／RL 方程、選擇線／面／體累積、追蹤方向與單位，並知道電位、梯度、通量與環流如何接到電磁公式。這是三門應用課的數學準備，不聲稱代替完整電磁學、電子學或電路學。工程例只採理想定值元件及明示的適用範圍。

分鏡必須維持同一物件、比例與預設數值；首屏可以先讀靜態圖，不強迫尚未建立模型的讀者先操作。數學條件、模型限制與完成核心例題所需的計算步驟維持可見，非必要證明可放可選延伸。
