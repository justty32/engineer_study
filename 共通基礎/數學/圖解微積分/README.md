# 微積分小小實驗室

[開啟線上課程](https://justty32.github.io/engineer_study/calculus-little-lab/)

課程有 26 頁，其中 23 個教學章節從座標、變化率與累積，走到局部線性化、電荷與一階動態，再走到梯度、線積分、電位、通量與 Gauss／Stokes。每章先追同一個小例子的逐步圖，再開放自由實驗；符號與條件接在圖後。另有 50 詞搜尋字典與官方教材來源。

電路路線接電荷、RC／RL、功率與儲能；電子路線接指數與局部線性化；電磁路線接座標尺度、場與線／面／體累積。二階 ODE、RLC、相量、Laplace、Fourier 與 PDE 留給後續工程數學課。所有章節自由閱讀，不計分、不解鎖。來源筆記與既有工程數學網站保持獨立；本課程的 lab.css 是圖解版專用設計。

成品共 53 檔：26 HTML、26 JavaScript、1 CSS；26 頁包含 23 教學章、首頁、50 詞字典與來源頁。互動契約共 25 列，包含 24 個參數實驗及字典搜尋；教材與銜接索引共 25 列，後續電子／電路接線共 2 列。

正式發布路徑為 `calculus-little-lab/`。桌面與手機自動檢查及部署證據見驗收紀錄，真實裝置的觸控與使用者教學體感另行確認。

全 23 課已補齊「看懂圖之後怎麼選公式、怎麼逐行計算」：同題圖式對照、適用條件、推導與代入、答案檢查，以及含提示與完整解答的遷移題均已完成。概念版與新增計算內容分開驗收；本輪獨立數學、教學與技術審查結果及受驗版本見[驗收紀錄](驗收紀錄.md)。本次完成版本等待發布，線上版本以部署紀錄為準；代理審閱不等同真人理解測試。
