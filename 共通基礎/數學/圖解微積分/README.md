課程分為主線 00–07（極限、微分、積分）與延伸 08–12（級數、多變數、向量場、工程）。所有章節自由閱讀，不計分、不解鎖。來源筆記與既有網站保持獨立；本課程的 lab.css 是圖解版專用設計。

正式發布路徑為 `calculus-little-lab/`。桌面與手機自動檢查及部署證據見驗收紀錄，真實裝置的觸控與使用者教學體感另行確認。
