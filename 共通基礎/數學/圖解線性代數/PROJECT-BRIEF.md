# 圖解線性代數 — 專案簡報

## 問題與成果

把原始概論變成可操作的線性代數入門：從一支箭頭開始，看懂「混合輸入 → 改變空間 → 解回輸入」，再走向投影、特徵方向與工程分解。讀者完成後能判斷兩支箭頭是否足夠描述平面、線性方程為何有一個／無限多／沒有解、行列式與資訊遺失的關係，並分辨投影、特徵分解及 SVD 的用途。

## 讀者基線

繁中使用者，軟體能力強，數學基礎不假定穩固。預設只會四則運算和負數，不預設懂矩陣、座標、向量或內積。所有頁面可自由進出；不考試、不計分、不要求先答對。

## 語言與名詞契約

臺灣術語與繁體中文；首次出現給中文及英文。橫向為列（row）、直向為欄（column）；維度是需要幾個獨立方向，與向量有幾個數字的差別要說清楚。圖中藍／珊瑚箭頭同時有文字或線型，不單靠顏色。公式前先解釋符號與角色。所有圖以原創 inline SVG 畫出；沒有外部圖片、字型或執行依賴。

## prerequisite gap

00 先教座標、正負方向、向量長度；01 教相加和純量倍數；02 教生成、獨立、基底、座標與向量空間最小條件。03 先把矩陣的每一欄看成基底箭頭的新位置；04 明示線性必須保留加法和倍數，平移通常是仿射而非線性。投影前補內積，最小平方前補殘差，特徵方向前補非零向量要求，QR/SVD 前補單位正交方向。工程頁不把實數示範誤說成完整複數通訊模型。

## 可延續性

讀者與目標在本檔；結構／DOM／分工在 BUILD-SPEC.md 與派工計畫.json；參數、公式與判準在互動契約.json；進度在建置進度.md（交付刪除）；獨立驗收在驗收紀錄.md。所有產品置於 dist/，直接開 index.html 可離線操作。GitHub 與 Sites 各自部署獨立新站，使用者已授權 push 與部署。

## 本輪教學修正

首版「一張主實驗圖加一張補圖」仍要求讀者先消化抽象名詞。新版把問題、分步圖、小數字、引導操作與命名分開：先看到怎麼走、怎麼混合、哪裡消失，再認識座標、矩陣、秩等名字。首頁先示範可直接讀出的路線；各章首屏讓圖承擔第一段解釋。每張圖的教學責任存於圖解改版計畫，獨立審查的是理解是否跳步，不是湊圖的數量。

## v3 計算與實際應用目標

使用者實看 v2 後指出，概念圖沒有充分帶到公式如何選、每項從哪裡來、如何逐行計算與驗算。本輪以「依範例能獨立算相似題」為教學審查目標：15 章各有題目已知／所求、公式與圖逐項對映、合理推導與條件、同例代入、中間值完整手算、圖像／代回驗算，以及有提示和詳解的近似遷移題。主要計算過程直接在正文，不要求打開附錄才能使用公式。已公開 v2 的概念圖保留並加上計算線索，不以再增加圖件數作為成效。
