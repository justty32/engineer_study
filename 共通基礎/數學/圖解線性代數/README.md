# 線性代數小小實驗室

從找禮物的路線、可重複的按鈕與最近落點開始，讓原創圖解帶著公式走：先辨認已知與所求，再對照圖上符號，逐行代入、計算、驗算。15 章各有完整算例與附提示、詳解的相似練習，連到自由實驗。這是獨立新站；原始筆記與舊互動課程仍有各自入口。

- [開啟課程首頁](dist/index.html)
- [從零開始：座標與箭頭](dist/00-start.html)
- [矩陣：從兩張卡算出 Ax](dist/matrices.html#worked-calculation)
- [投影：點積和分母怎麼用](dist/projection.html#worked-calculation)
- [名詞小字典](dist/glossary.html)
- [教材來源與模型邊界](dist/sources.html)
- [原始線性代數概論](../02-線性代數.md)
- [原有工程數學互動課程](../互動課程/index.html)

15 章加首頁、字典與來源頁，共 18 頁；16 個主要實驗與 48 個可搜尋名詞。主線先認識箭頭和空間，再延伸至資料擬合、特徵方向、QR、SVD 及工程應用。所有圖形為 inline SVG，能用鍵盤操作，直接開啟 `dist/index.html` 也能離線學習。

既有獨立站入口為 [GitHub Pages](https://justty32.github.io/engineer_study/linear-algebra-little-lab/) 與 [Sites](https://linear-algebra-little-lab.bronzetern2.chatgpt.site)。桌面版優先提供可依序閱讀的分鏡，完整實驗接在圖解後面；手機主圖可左右滑動，下方文字保留完整數值與原因。

教學基線見 [PROJECT-BRIEF.md](PROJECT-BRIEF.md)，結構與分工見 [BUILD-SPEC.md](BUILD-SPEC.md)。逐實驗的參數、公式及邊界保存在 [互動契約.json](互動契約.json)，逐章算例、圖式對映及遷移題保存在 [計算教學契約.json](計算教學契約.json)，作者狀態保存在 [派工計畫.json](派工計畫.json)。獨立驗收結果由驗收者另記 [驗收紀錄.md](驗收紀錄.md)。
