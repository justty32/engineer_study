# 線性代數小小實驗室

從一支箭頭開始，用原創圖解與自由實驗理解矩陣、解方程、投影與分解。這是獨立新站；原始筆記與舊互動課程仍有各自入口。

- [開啟課程首頁](dist/index.html)
- [從零開始：座標與箭頭](dist/00-start.html)
- [名詞小字典](dist/glossary.html)
- [教材來源與模型邊界](dist/sources.html)
- [原始線性代數概論](../02-線性代數.md)
- [原有工程數學互動課程](../互動課程/index.html)

15 章加首頁、字典與來源頁，共 18 頁；16 個主要實驗與 48 個可搜尋名詞。主線先認識箭頭和空間，再延伸至資料擬合、特徵方向、QR、SVD 及工程應用。所有圖形為 inline SVG，能用鍵盤操作，直接開啟 `dist/index.html` 也能離線學習。

發布目標為 [GitHub Pages](https://justty32.github.io/engineer_study/linear-algebra-little-lab/)。桌面版優先提供完整實驗工作台；手機主圖可左右滑動，下方文字保留完整數值與原因。

教學基線見 [PROJECT-BRIEF.md](PROJECT-BRIEF.md)，結構與分工見 [BUILD-SPEC.md](BUILD-SPEC.md)。逐實驗的參數、公式及邊界保存在 [互動契約.json](互動契約.json)，作者狀態保存在 [派工計畫.json](派工計畫.json)。獨立驗收結果由驗收者另記 [驗收紀錄.md](驗收紀錄.md)。
