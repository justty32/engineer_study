## 瀏覽器與操作

18 頁分別以桌機 1440×900、手機 390×844 載入，共 36 次頁面檢查；先斷言頁面標題屬於線性代數。592 條同站相對連結及片段、頁面結構與載入共 967 項檢查通過。沒有 console／JavaScript／HTTP 錯誤、外部自動請求、整頁橫向溢出、重複 id、未標記控制項或 SVG 文字超出自身圖框。參考資料的一般外部超連結允許，不等同外部執行資源。

導航與可及性另有 158 項檢查通過：15 章上一頁／下一頁串接、回首頁、鍵盤改動控制值、可見 focus、主圖鍵盤橫捲、reduced-motion、390／320px 手機導覽，以及字典繁中／不分大小寫英文／無結果／清空搜尋。字典搜尋不將輸入當作 HTML 執行。18 頁都能在離線 context 以 `file://` 載入，16 個實驗仍可操作，沒有 JavaScript 例外。各實驗重設皆精確恢復契約預設值。

手機主圖保留可讀尺寸並在圖框內橫捲；這不代表所有圖同時完整出現在窄視窗。結果與原因另有文字呈現。頁面沒有強制答對、計分或解鎖條件。

## 數學與因果互動

依互動契約建立 198 組獨立數值情境；桌機及手機各執行一次，共 396 次情境、2,740 項產品互動檢查全數通過。涵蓋每個控制的端點與預設、正負與零向量、18 種合成操作順序、唯一／無限多／無解、圖窗外的交點、秩 0／1／2、正負與零行列式、投影正負係數、最小平方最佳與非最佳線、實特徵方向、零次矩陣、退化 QR、SVD 四階段與秩不足，以及工程系統的收斂、增長、翻向與剪切。

expected 值在讀產品前建立，不呼叫產品計算函式。方程分類與最小平方法以獨立 pivot 消去求解；行列式以變換後四邊形的有號鞋帶面積交叉驗算；對角化與工程例逐次矩陣乘法；QR 從三維欄向量投影與正規化推導。SVD 以通用矩陣乘法依序計算 Vᵀ、Σ、U。

代表結果：原點向量長度為 0；(−4, 3) 長度為 5。最小平方 h=3、目前 m=1、c=1 時 SSE=1，最佳 c=4/3、SSE=2/3。SVD 預設輸出為 (2.5490381057, −1.0490381057)。QR 高度 0 時明確指出殘差不能單位化，沒有誤稱分解不存在。兩個特徵值都為 0、次數為 0 時仍回傳原向量 (2, 1)。剪切第 8 步為 (9, 1)，未將重複特徵值 1 誤判為必定有界。

所有情境的數值、分類、圖中有效座標與文字輸出未出現 NaN／Infinity／undefined。原因回饋皆存在；數值依頁面顯示精度比較，不要求浮點十進位完全相等。來源 audit 另完成 1,253 項規格代數斷言及 18 HTML／18 JS／48 詞的數學終審；該數字不加進上述產品測試數量。

## 審查修正與局部複驗

clarity／audit 審查使 5 個 HTML 補正：零基礎先說平方與根號，三維箭頭說前後；投影先說內積與有號係數；向量相加與特徵基底補圖統一座標比例；PCA 補圖採固定平移做中心化，並將圖名精確標示為中心化與主方向。主互動 JavaScript 與共用 CSS 未因此修改。

上述 5 頁最終版各以 1440、390、320px 載入，共 15 次局部複驗；149 條連結與視窗、文字、控制項等 299 項檢查通過，沒有新錯誤。五檔亦重新通過 UTF-8／異常字元／LaTeX 殘留檢查。更新後零基礎及投影 PC 首屏、特徵分解頁面經 QA 圖像檢視；root 另抽看首頁、零基礎、矩陣與 SVD 的 PC 截圖。QA 另抽看投影 PC 與 QR 手機頁面，未見遮擋或控制項重疊；這些是抽樣，不聲稱逐張人工看完全站。
