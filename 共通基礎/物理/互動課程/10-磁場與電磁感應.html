10・用磁通變化核對發電機的能量帳

磁場與電磁感應：你推得越用力，送出的電越多

電流能造磁場，磁場能改變運動電荷的方向，而變化的磁通又能推動電流。本章用移動導體棒把這個循環接起來，並以機械功率等於電功率檢查冷次定律的負號。

這章假設已懂：08 靜電學的電場、09 電流與電路基礎的電流，以及05 轉動與角動量的力矩。

痛點：磁場存在，不等於它會自動發電

把一個線圈靜放在強磁鐵旁，示波器不會持續讀到感應電壓；真正關鍵是穿過迴路的磁通是否隨時間改變。另一方面，移動電荷在磁場中受力，力卻與速度垂直，所以磁場本身不對單顆電荷做功。發電機輸出的能量究竟從哪裡來，必須回到推動轉子的外力。

本章採均勻磁場、剛性導體棒、固定迴路電阻且忽略摩擦與自感的模型。這足以呈現感應與能量守恆，但不能直接預測真實發電機的鐵損、銅損、渦電流分布或轉矩脈動。極端數值若要求十萬安培，也是在揭露模型與產生磁場方法的代價，不是設計建議。

白話直覺：磁通像穿過框面的總量，感應只對它的變化有反應

可以把磁通想成穿過線框的「磁場份量」；框面變大、磁場變強或角度改變，都會改變穿過量。比喻到此為止；精確定義為 ΦB = ∫ B ⋅ dA。ΦB 是磁通量、單位 Wb，B 是磁通密度向量、單位 T，A 是面積向量、單位 m²，粗體代表有方向的向量。

勞侖茲力（Lorentz force）為 F = q(E + v × B)。F 單位 N，q 單位 C，E 單位 V/m，v 單位 m/s，B 單位 T。外積使磁力垂直速度；載流導線受力 dF = I dℓ × B，F 單位 N，I 單位 A，ℓ 單位 m，B 單位 T。馬達轉矩從這個力與力臂而來。

電流產生磁場。畢歐—沙伐定律（Biot–Savart law）寫成 dB = (μ0/(4π)) ⋅ (I dℓ × r̂)/r²。B 單位 T，μ0 = 1.25663706212 × 10−6 T·m/A，I 單位 A，ℓ、r 單位 m，r̂ 無單位。對稱性高時可改用安培定律 ∮C B ⋅ dℓ = μ0I穿過；兩側單位皆為 T·m。

法拉第定律（Faraday's law）為 ε = −dΦB/dt。ε 是感應電動勢、單位 V，ΦB 單位 Wb，t 單位 s。冷次定律（Lenz's law）就是負號的物理內容：感應電流造成的磁場反抗原磁通的變化。它不阻止一切運動，而是要求外界付出功才能維持變化。

自然界尚未觀察到磁單極，因此 ∇ ⋅ B = 0；B 單位 T，而散度單位使左側為 T/m。磁力線因此形成閉合迴路。自感的元件關係可寫 vL = L(di/dt)；vL 單位 V，L 是自感、單位 H，i 單位 A，t 單位 s。RL 時間常數 τ = L/R；τ 單位 s，R 單位 Ω。

方向判斷可以分成因果鏈：先決定外加磁通正在增加或減少，再由冷次定律找出感應磁場要反抗哪個變化，最後以右手定則決定迴路電流。不要一開始就背順時針或逆時針，因為同一個轉向會隨觀察面、磁場方向與運動方向改變。負號固定的是反抗變化的關係，不是畫面上的固定旋轉方向。

自感也可理解為電流改變時的「電磁慣性」：電流增大會誘發反向電壓，電流減小也會試圖維持原流向。這個類比只描述抗拒變化；精確量仍是 L 與磁通鏈的比例，單位 H。線圈斷電時若沒有安全路徑，快速的 di/dt 可能產生很高電壓，能量來源則是先前儲存在磁場中的能量。

來源：01-普通物理-中 第 3 章與第 4 章。

推導：一根移動導體棒如何把機械功送進電阻

（a）兩條路得到同一感應電動勢。長度 L 的導體棒以速度 v 垂直切過均勻磁場 B。棒內電荷受磁力 F = qvB；F 單位 N，q 單位 C，v 單位 m/s，B 單位 T。平衡後等效電場 E = F/q = vB，E 單位 V/m，因此棒端電位差 ε = EL = BLv；ε 單位 V，L 單位 m。

改從磁通看，若磁場與迴路法線夾角 θ，ΦB = BA cos θ。ΦB 單位 Wb，B 單位 T，A 單位 m²，θ 無單位。棒每秒使面積增加 dA/dt = Lv，單位 m²/s，所以 |dΦB/dt| = BLv cos θ，仍得 ε = BLv cos θ。微觀磁力與巨觀磁通兩條路一致。

（b）冷次負號的能量意義。迴路電阻 R 時，I = ε/R = BLv cos θ/R；I 單位 A，ε 單位 V，R 單位 Ω。感應電流所在的棒受安培力 F = (B cos θ)IL，方向反抗運動；F 單位 N。維持等速需要等大外力，因此機械功率 P機 = Fv = B²L²v²cos²θ/R。P機 單位 W。

電功率 P電 = εI = (BLv cos θ)²/R，而焦耳熱 P熱 = I²R；三者單位皆為 W，代入 I 後完全相等。若感應方向幫助原運動，棒會自行加速又持續放電，等於無中生有；負號正是能量守恆要求的方向。

（c）直導線磁場。在無限長直導線外取半徑 r 的圓形安培路徑。對稱性使 B 沿圓周切向且大小固定，因此 ∮ B ⋅ dℓ = B ⋅ 2πr = μ0I。B 單位 T，r 單位 m，μ0 單位 T·m/A，I 單位 A。整理得 B = μ0I/(2πr)，也可反解 I = 2πrB/μ0。

（d）螺線管自感。長螺線管內 B = μ0NI/ℓ，B 單位 T，N 是匝數、無單位，I 單位 A，ℓ 單位 m。單匝磁通 Φ = BA = μ0NIA/ℓ，Φ 單位 Wb，A 單位 m²；總磁通鏈 NΦ。由 L = NΦ/I 得 L = μ0N²A/ℓ，L 單位 H。平方來自每一匝既參與造場，也各自鏈結磁通。

數值實例：零點三伏特如何對上零點零四五瓦特

採自由實驗預設值 B = 0.50 T、L = 0.20 m、v = 3.0 m/s、R = 2.0 Ω、θ = 0°，觀察距離 r = 0.05 m。感應電動勢 ε = 0.50 ⋅ 0.20 ⋅ 3.0 ⋅ cos 0° = 0.300000 V；電流 I = 0.300000/2.0 = 0.150000 A。B 單位 T，L、r 單位 m，v 單位 m/s，R 單位 Ω。

安培阻力 F = 0.50 ⋅ 0.150000 ⋅ 0.20 = 0.015000 N。機械功率 P機 = 0.015000 ⋅ 3.0 = 0.045000 W；電功率 P電 = 0.300000 ⋅ 0.150000 = 0.045000 W；焦耳熱 I²R = 0.150000² ⋅ 2.0 = 0.045000 W。三條路一致，能量來源是維持棒等速的外力。

若想靠單根長直導線在 0.05 m 處產生 0.50 T，I = 2π(0.05)(0.50)/(1.25663706212 × 10−6) = 124999.999932 A。I 單位 A。這個震撼數字說明實務會使用永久磁鐵、線圈與鐵芯集中磁通，而不以一根裸導線硬造強場。

另取 N = 100、ℓ = 0.1 m、A = 1 × 10−4 m² 的空心螺線管，L = 1.256637 × 10−5 H = 12.566371 µH。配 R = 2 Ω 時 τ = L/R = 6.283185 × 10−6 s = 6.283185 µs。N 無單位，ℓ 單位 m，A 單位 m²，L 單位 H，τ 單位 s。

自由實驗：移動導體棒發電

調整磁場、棒長、速度、迴路電阻、夾角與觀察距離。輸出會並排核對三種功率，並估算以單根直導線產生此磁場所需的電流。

不要混淆

  • 磁通密度 B 單位 T，磁通量 ΦB 單位 Wb；後者還包含面積與方向。
  • 磁場對靜止電荷沒有磁力，對運動電荷的磁力也垂直速度；發電機做功的是外力，不是磁場。
  • 安培定律右邊只算穿過選定面的電流，但路徑上的 B 是所有電流共同造成的。
  • 自感 L 是描述磁通鏈與電流關係的物理量、單位 H；電感器是利用此性質製成的元件。
  • 冷次定律不是另一個不相干的方向口訣，而是法拉第定律負號所表達的能量守恆。
  • 有很大的靜態磁通不保證有感應電壓；只有 dΦB/dt 不為零才會感應。

可觀察證據

用什麼儀器／實驗量：用高斯計的霍爾效應探頭量 B，單位 T；把線圈接示波器，快速插入與拔出磁鐵，量電壓 ε 隨時間的脈衝。脈衝面積 ∫ε dt 的單位 V·s，也就是 Wb，可與磁通變化 ΔΦB 比較。發電機端可同步量轉矩與轉速得到機械功率，再量 V 與 I 得電功率。

能證明什麼：改變磁鐵移動速度可檢查感應電壓峰值隨磁通變化率增加；插入與拔出得到相反極性，顯示冷次方向。機械輸入與電輸出在摩擦、銅損等效率折扣內相符，能支持能量守恆的量化預測。

不能證明什麼：有限精度的桌上量測不能證明自然界絕對沒有磁單極，只能繼續支持目前未觀察到它的結論。單看感應電壓也不能分辨磁通改變究竟來自 B、面積或夾角，必須另量幾何與運動；功率不相等時也不能只憑差額定位每一種損耗。
