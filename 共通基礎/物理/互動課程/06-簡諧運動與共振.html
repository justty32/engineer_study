06・用同一條二階方程理解彈簧與 RLC

簡諧運動與共振：頻率對上不夠，阻尼才決定放大多少

彈簧、建築、揚聲器與 RLC 電路看似不同，卻共享質量或電感儲能、彈性或電容回復、阻尼或電阻耗能的結構。讀懂這條二階方程，就能由係數預測振盪、衰減、相位與共振。

這章假設已懂：02 牛頓運動定律的彈簧力、03 功與能量。

痛點：看到振盪不等於知道自然頻率，更不等於理解共振

把砝碼掛上彈簧後拉開，它會來回運動；加入摩擦後振幅逐漸縮小；再週期性推動時，有些頻率幾乎推不動，有些卻產生大振幅。只說「頻率一樣所以共振」還不夠，因為阻尼會改變峰值高度、峰值位置與相位，無阻尼的理論極限甚至不再有有限穩態振幅。

工程上的麻煩是，同一個系統可能既有自由響應又有受迫穩態。自由響應由初始條件與特徵根決定，會衰減或持續；穩態由外力頻率決定，在暫態消失後留下。若把兩者混成一個「振動」，就無法由量測反推阻尼，也無法判斷啟動振鈴何時結束。

自然頻率也不是物體獨有且永遠不變的標籤，而是由當下邊界條件與參數共同決定。替彈簧加掛質量會降低自然頻率，改變固定方式或材料剛性也會改變 k。真實結構還可能有多個振動模態；單自由度模型只描述其中一個主導模態，適合建立第一層判讀，不代表所有頻率響應都只有一座峰。

白話直覺：儲能來回交換，損耗每圈抽走一部分

可把質量的動能與彈簧的位能想成兩個帳戶：運動到平衡點時動能最多，到端點時彈性位能最多；阻尼則每圈扣掉一部分。比喻到此為止；精確的簡諧運動（Simple Harmonic Motion, SHM）滿足 m(d²x/dt²) + kx = 0。m 的單位 kg，x 的單位 m，t 的單位 s，彈簧常數 k 的單位 N/m，兩項單位皆為 N。

自然角頻率 ω0 = √(k/m)，單位 rad/s；週期 T = 2π/ω0，單位 s；頻率 f0 = ω0/(2π)，單位 Hz。加入阻尼係數 c 後，方程是 m(d²x/dt²) + c(dx/dt) + kx = 0，c 的單位 N·s/m，使 c(dx/dt) 仍為 N。

阻尼比（damping ratio）ζ = c/(2√(km))，無單位；臨界阻尼 cc = 2√(km)，單位 N·s/m。ζ 小於 1 是欠阻尼，會振盪衰減；等於 1 是臨界阻尼，在不振盪的解中最快回到平衡；大於 1 是過阻尼，兩個衰減模式都不振盪。欠阻尼角頻率 ωd = ω0√(1 − ζ²)，單位 rad/s。

外力 F0 cos(ωt) 加入後，穩態振幅 X = F0/√((k − mω²)² + (cω)²)。F0 的單位 N，分母單位 N/m，所以 X 的單位 m。共振（resonance）是驅動與系統儲能交換形成顯著放大；品質因數 Q = 1/(2ζ)，無單位，低阻尼時表示峰值高且窄。

相位補上振幅沒有說完的資訊。低頻時彈簧有時間跟上外力，位移大致同相；自然頻率處位移落後約 90°；高頻時質量慣性主導，位移趨近反相。於是掃頻同時量振幅與相位，比只找最大讀值更能辨認模型參數，也能避開峰值受量測解析度影響的誤差。

來源：01-普通物理-上 第 6 章。

推導：特徵根分型，再由正弦係數求穩態振幅

第一步，解自由響應。試設 x = Aeλt，其中 A 的單位 m、λ 的單位 1/s。代入齊次方程後，每一項都有共同因子 Aeλt，除去它得到 mλ² + cλ + k = 0。二次公式給：

λ = (−c ± √(c² − 4km)) / (2m) = −ζω0 ± ω0√(ζ² − 1)

λ 單位 1/s。判別式 c² − 4km 的正、零、負分別產生兩實根、重根、共軛複根，也就是過阻尼、臨界阻尼、欠阻尼三型。無阻尼 c = 0 時 λ = ±jω0，取實部得到 x(t) = A cos(ω0t + φ)，其中相位 φ 無單位。

第二步，檢查能量。無阻尼時 K = (1/2)m(dx/dt)²，U = (1/2)kx²，兩者單位皆為 J。把 x = A cos(ω0t + φ) 與 dx/dt = −Aω0 sin(ω0t + φ) 代入，再用 mω0² = k，得到 K + U = (1/2)kA²，與時間無關。阻尼力做負功後，這個總和才逐圈下降。

第三步，求受迫穩態。設 x = X cos(ωt − φ)，代入 m(d²x/dt²) + c(dx/dt) + kx = F0 cos(ωt)。整理同相與正交分量，位移同相係數為 (k − mω²)X，正交係數為 cωX；兩者平方相加等於 F0²，因此：

X = F0 / √((k − mω²)² + (cω)²)，tan φ = cω/(k − mω²)

φ 是無單位角度。在 ω = ω0 時，k − mω0² = 0，只剩 X = F0/(cω0)。除以靜態位移 x靜 = F0/k，放大率為 k/(cω0) = 1/(2ζ) = Q。驅動力加倍會讓兩種位移都加倍，放大率不變；阻尼才控制這個比值。

第四步，翻譯成電路。串聯 RLC 的電荷方程 L(d²q/dt²) + R(dq/dt) + q/C = v(t)。逐項對照 m↔L、c↔R、k↔1/C、x↔q、dx/dt↔i、F↔v，就得 ω0 = 1/√(LC)，單位 rad/s。這是方程結構相同，不是說機械質量與電感具有相同物理單位。

極端條件能檢查公式。當 ω = 0，慣性項與阻尼項都消失，X = F0/k，放大率為 1；當 ω 遠大於 ω0，分母主要是 mω²，質量跟不上快速驅動，振幅約按 1/ω²下降。若 c = 0 且 ω = ω0，分母為零，所謂無限振幅是線性模型在持續輸入下能量無限累積的警告，不是任何真實裝置可達的數值。

數值實例：預設值正好驅動在自然頻率

取 m = 1 kg、k = 100 N/m、c = 2 N·s/m、ω = 10 rad/s、F0 = 1 N。ω0 = √(100/1) = 10.000000 rad/s；f0 = 10/(2π) = 1.591549 Hz；T = 2π/10 = 0.628319 s。

cc = 2√(100 ⋅ 1) = 20.000000 N·s/m，ζ = 2/20 = 0.100000，故為欠阻尼。ωd = 10√(1 − 0.1²) = 9.949874 rad/s。因驅動恰在 ω0，分母只剩 cω = 20 N/m，X = 1/20 = 0.050000 m；靜態位移是 1/100 = 0.010000 m，放大率與 Q 都是 5.000000，相位落後 90.000000°。

電路對照為 L = 1 H、R = 2 Ω、C = 1/k = 0.010000 F。1/√(LC) = 1/√(1 ⋅ 0.01) = 10.000000 rad/s，與機械自然角頻率相同。

若把驅動角頻率降到 0，公式回到 0.010000 m 的靜態位移；若提高到 30 rad/s，慣性項使分母顯著增加，振幅快速下降。這兩端與共振點形成完整趨勢，可用來檢查程式是否只在預設值算對，卻在邊界誤把角頻率或阻尼單位代錯。

預設的 ζ = 0.1 也說明「欠阻尼」不是故障名稱，而是響應型態。它會振鈴，卻可能比不振盪的過阻尼系統更快進入小誤差範圍。能否接受超越平衡點，取決於機械間隙、電壓上限與控制目標；物理模型提供時間尺度與峰值，工程規格才決定哪一型最合適。

自由實驗：阻尼與共振放大

調整質量、彈簧、阻尼、驅動頻率與驅動力。比較阻尼型態、穩態振幅、相位、品質因數與等效 RLC。

不要混淆

  • 角頻率 ω 的單位 rad/s，頻率 f 的單位 Hz，兩者相差 2π，不能把數值直接互換。
  • ω0、ωd與振幅峰值所在頻率不是同一量；只有阻尼很小時才彼此接近。
  • 臨界阻尼是「不振盪的解中最快回到平衡」，不代表在所有允許振盪的設計中時間最短。
  • 共振放大率由 ζ 決定；F0只按比例放大靜態位移與受迫振幅，不改變兩者比值。
  • 阻尼比 ζ 無單位，阻尼係數 c 的單位是 N·s/m；兩者數值與用途不同。

可觀察證據

用什麼儀器／實驗量：在彈簧掛已知砝碼，以碼表量十個週期取平均；用手機加速度計記錄自由振盪相鄰峰值；再以訊號產生器掃動致動器，量各驅動頻率的位移。電路端可用示波器與訊號產生器掃描串聯 RLC 的電壓振幅與相位。

能證明什麼：改變質量後 T 與 √m 成正比，可支持 ω0 = √(k/m)；峰值的指數包絡可反推 ζ，掃頻曲線則能驗證低阻尼帶來較高、較窄的共振峰，並核對機械系統與等效 RLC 共享自然頻率。

不能證明什麼：單一掃頻曲線不能證明阻尼一定線性，也不能單獨分辨空氣阻力、接觸摩擦與材料內耗。量到有限峰值更不能否定無阻尼模型的發散極限，因真實系統總有損耗、非線性與量測範圍限制。
