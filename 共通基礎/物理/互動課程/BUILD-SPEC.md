## 0. 鐵律（違反即失敗）

1. **純原生 HTML／CSS／JavaScript，完全離線**。不得有圖片、外部字型、CDN、遠端 API、第三方腳本、分析碼、`fetch`、`XMLHttpRequest`。唯一允許的外部 URL 是每頁頂端 `main-site-link` 的 `https://justty32.github.io/engineer_study/`。

3. **公式一律純文字 HTML，嚴禁 LaTeX**：不得出現 `\(` `\)` `\[` `\]` `$` `$$`，不得引入 MathJax／KaTeX／任何算式引擎。轉寫規約見第 3 節。
4. **禁止 `Math.random()`**。所有數值必須可重現。
5. **每頁 UTF-8（無 BOM）、換行 CRLF**，`<html lang="zh-Hant">`，`<meta charset="utf-8">`。**嚴禁用 PowerShell 的 `Set-Content`／`Out-File`／`>` 寫中文檔**（既有案例已證實會產生亂碼）；一律用 codex 直接寫檔或 python 以 `encoding="utf-8"` 寫入，收尾再由 Lead 用 python 位元組級 `\r\n` 正規化。
6. **不得修改 `共通基礎/物理/*.md`** 或任何既有檔案。發現的筆記缺口只列在第 10 節。
7. **不得寫計分、進度百分比、解鎖、倒數、強制答對**。自我檢核可無限重做且不阻擋瀏覽。
8. **HTML 頁面不連 `.md` 檔**。來源以文字標註（例：「來源：01-普通物理-上 第 3 章」）。
9. **每章正文（不含 `section.workspace` 內文字）2000–3000 個中文字**。低於 2000 視為未完成，高於 3000 要拆句精簡。這是硬門檻，開工前就寫死在此，不接受「先寫薄之後再加厚」。
10. **每章「可觀察證據」段必須寫滿三件事**：用什麼儀器／實驗量、這個量測**能證明什麼**、**不能證明什麼**。缺任何一項視為缺陷。
11. **每個公式後面必須交代符號與 SI 單位**。量綱不合的式子視為缺陷。

## 3. 公式轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。**積分／級數的上下限一律用 `<sub>`／`<sup>`，不要用 Unicode 下標數字（₀₁₂）**，避免不同字型高度不一。
- Unicode 數學符號（限這份清單）：`∫ ∮ Σ Π √ ∂ ∇ ∞ ± × ⋅ · ≈ ≠ ≤ ≥ → ⇒ ⇔ ∈ ∅ ∠ ° ′ ″ ⊥ ∥ Δ ⟨ ⟩ |`
- 希臘字母：`α β γ δ ε ζ η θ κ λ μ ν π ρ σ τ φ χ ψ ω Γ Δ Θ Λ Σ Φ Ω`
- **負號一律用 U+2212 `−`，不要用半形連字號 `-`**（連字號只用在檔名與 CSS class）。
- 上標數字可直接用 `²` `³`（常見且對齊良好）；其餘次方用 `<sup>`。

### 3.2 排版規則

1. **分數**：單行寫成 `(分子) / (分母)`，例如 `a = (v − v₀) / t` 寫成 `a = (v − v<sub>0</sub>) / t`。分子分母都是單一符號時可省括號：`v/r`、`I/A`。
2. **向量用 `<strong>` 表示粗體**：`<strong>F</strong> = m<strong>a</strong>`。純量寫一般字。同一段內第一次出現要說明「粗體代表向量，有方向」。
3. **向量運算**：內積寫 `⋅`（`<strong>F</strong> ⋅ d<strong>r</strong>`），外積寫 `×`（`<strong>v</strong> × <strong>B</strong>`）。乘號在純量相乘時也用 `⋅`，不用 `*`。
4. **單位一律半形英文＋中間點**：`m/s`、`m/s²`、`N·m`、`kg·m²`、`kg·m/s`、`J/K`、`W/m²`、`V/m`、`T`、`Ω`、`F/m`、`H`、`Wb`、`Hz`、`rad/s`、`eV`、`nm`。單位不加 `<sup>`，直接用 `²`。
5. **數量級**：一律寫成 `8.85 × 10<sup>−12</sup>`，不寫 `8.85e-12`（`e` 記法只出現在 `app.js` 程式碼與本 spec 的計算欄）。
6. **極限**寫成 `lim(Δt→0)`，不用堆疊排版。
7. **偏導數**寫 `∂E/∂t`；二階寫 `∂²y/∂t²`。
8. **函式名**（sin、cos、tan、arcsin、arctan、exp、ln、log₁₀ 寫成 `log`、Re、Im）用一般半形英文，不加標記。
9. 公式所在段落用 `<p>`；需要凸顯時可用 `<code>`（`styles.css` 已設 `overflow-wrap:anywhere`）。多行對照可用 `<table>`。

### 01 `01-運動學.html`

**目標**：先學會「只描述、不解釋」的語言：位置、速度、加速度三者的導數關係，並親手算出拋體會落在哪裡、什麼時候到最高點。

**要點**：位置 `<strong>r</strong>(t)`（m）、速度 `<strong>v</strong> = d<strong>r</strong>/dt`（m/s）、加速度 `<strong>a</strong> = d<strong>v</strong>/dt`（m/s²），三者都是向量；純量的「速率」與向量的「速度」不同。等加速度三式：`v = v<sub>0</sub> + at`、`x = x<sub>0</sub> + v<sub>0</sub>t + (1/2)at²`、`v² = v<sub>0</sub>² + 2a(x − x<sub>0</sub>)`。拋體運動＝水平等速 ＋ 垂直等加速度，兩個方向**互不干擾**（這是本章最重要的一句話）。圓周運動：向心加速度 `a<sub>c</sub> = v²/r = ω²r`，角速度 ω（rad/s）、角加速度 α（rad/s²）、`v = ωr`。來源：01-普通物理-上 第 1 章。

**推導必寫**：（a）由 `a = dv/dt` 為常數積分一次得 `v = v<sub>0</sub> + at`，再積分一次得 `x = x<sub>0</sub> + v<sub>0</sub>t + (1/2)at²`；把前式的 t 代進後式消掉 t，得 `v² = v<sub>0</sub>² + 2a(x − x<sub>0</sub>)`——所以第三式不是新知識，是前兩式消去時間的結果。（b）拋體：取 `a<sub>x</sub> = 0`、`a<sub>y</sub> = −g`，得 `x(t) = v<sub>0</sub> cos θ ⋅ t`、`y(t) = h<sub>0</sub> + v<sub>0</sub> sin θ ⋅ t − (1/2)gt²`。令 `dy/dt = 0` 得最高點時刻 `t<sub>peak</sub> = v<sub>0</sub> sin θ / g`；`h<sub>0</sub> = 0` 時令 `y = 0` 得飛行時間 `T = 2v<sub>0</sub> sin θ / g`，代回 x 得射程 `R = v<sub>0</sub>² sin(2θ) / g`——由 `sin(2θ)` 立刻看出 θ = 45° 射程最大，且 30° 與 60° 射程相同。（c）向心加速度：等速圓周時速度大小不變、方向每秒轉 ω 弧度，速度向量的端點自己也在畫圓，半徑是 v，所以速度的變化率大小為 `ωv = ω²r = v²/r`，方向指向圓心。

**數值實例**：`v<sub>0</sub> = 20 m/s`、`θ = 45°`、`h<sub>0</sub> = 0`、`g = 9.8 m/s²`。分量 `v<sub>0x</sub> = v<sub>0y</sub> = 20 ⋅ cos 45° = 14.142136 m/s`。飛行時間 `T = 2 ⋅ 14.142136 / 9.8 = 2.886150 s`；射程 `R = 400 ⋅ sin 90° / 9.8 = 40.816327 m`；最高點 `H = 14.142136² / (2 ⋅ 9.8) = 200 / 19.6 = 10.204082 m`，發生在 `t = 1.443075 s`。在 `t = 1 s` 時：`x = 14.142136 m`、`y = 14.142136 − 4.9 = 9.242136 m`、`v<sub>y</sub> = 14.142136 − 9.8 = 4.342136 m/s`、速率 `= √(200 + 18.854142) = 14.793720 m/s`。**能量自檢**：`v²/2 + g ⋅ y = 109.427071 + 90.572929 = 200.000000`，正好等於 `v<sub>0</sub>²/2 = 200`——每單位質量的機械能守恆（這條式子在第 03 章會正式登場）。

### 02 `02-牛頓運動定律.html`

**目標**：學會用自由體圖把「有哪些力」變成一條方程，並判斷斜面上的物體到底會不會滑動、滑動後加速度多大。

**要點**：第一定律（慣性）＝沒有淨外力就維持原速度，同時定義了「慣性座標系」；第二定律 `<strong>F</strong><sub>淨</sub> = m<strong>a</strong>`，更一般的寫法是 `<strong>F</strong> = d<strong>p</strong>/dt`（第 04 章會用到）；第三定律＝作用力與反作用力等大反向，且**作用在不同物體上**（所以不會互相抵消）。標準解法：畫自由體圖（free body diagram）→ 選座標軸（斜面問題把 x 軸沿斜面）→ 對每個軸列 `ΣF = ma`。常見的力：重力 `mg`（N）、正向力 N（接觸面的垂直反作用）、靜摩擦 `f<sub>s</sub> ≤ μ<sub>s</sub>N`（是不等式，不是等式）、動摩擦 `f<sub>k</sub> = μ<sub>k</sub>N`、彈簧力 `F = −kx`（虎克定律，k 單位 N/m）、繩張力 T。來源：01-普通物理-上 第 2 章。

**推導必寫**：（a）斜面分解：把重力 `mg` 分成沿斜面 `mg sin θ` 與垂直斜面 `mg cos θ`。垂直方向不加速，所以 `N = mg cos θ`。（b）滑不滑動的判準：沿斜面的驅動力 `mg sin θ` 與最大靜摩擦 `μ<sub>s</sub>N = μ<sub>s</sub>mg cos θ` 比大小。兩邊同除 `mg cos θ`，變成 `tan θ` 與 `μ<sub>s</sub>` 比大小——**質量與 g 全部消掉**，所以「會不會滑」只由角度與材質決定。臨界角 `θ<sub>c</sub> = arctan(μ<sub>s</sub>)`。（c）滑動後：`ma = mg sin θ − μ<sub>k</sub>mg cos θ`，兩邊除 m 得 `a = g(sin θ − μ<sub>k</sub> cos θ)`——**加速度與質量無關**。（d）順帶推一次量綱：`[μ] = [f]/[N] = N/N = 1`，摩擦係數無單位。

**數值實例**：`m = 2 kg`、`θ = 30°`、`μ<sub>s</sub> = 0.40`、`μ<sub>k</sub> = 0.30`、`g = 9.8 m/s²`。重力 `mg = 19.600000 N`；沿斜面分量 `mg sin 30° = 9.800000 N`；正向力 `N = 19.6 ⋅ cos 30° = 16.974098 N`；最大靜摩擦 `0.40 ⋅ 16.974098 = 6.789639 N`。因為 `9.800000 > 6.789639`，物體**會滑動**。改用動摩擦 `0.30 ⋅ 16.974098 = 5.092229 N`，淨力 `9.800000 − 5.092229 = 4.707771 N`，加速度 `a = 4.707771 / 2 = 2.353885 m/s²`；用公式驗算 `a = 9.8 ⋅ (0.5 − 0.3 ⋅ 0.866025) = 9.8 ⋅ 0.240192 = 2.353885 m/s²`，兩條路一致。臨界角 `θ<sub>c</sub> = arctan(0.40) = 21.801409°`，而 30° > 21.801409°，與上面的判斷相符。

### 03 `03-功與能量.html`

**目標**：學會用「能量」抄捷徑——不解運動方程，直接由高度差算出速率——並看清楚摩擦把能量吃到哪裡去。

**要點**：功 `W = ∫ <strong>F</strong> ⋅ d<strong>r</strong>`（J），內積代表**只有沿位移方向的力分量做功**（所以正向力永遠不做功、等速圓周運動的向心力不做功）。動能 `K = (1/2)mv²`（J）。功—動能定理 `W<sub>總</sub> = ΔK`。保守力對應位能（potential energy）：重力 `U = mgh`、彈簧 `U = (1/2)kx²`、靜電 `U = qV`。機械能守恆：只有保守力作用時 `K + U = 常數`。功率 `P = dW/dt = <strong>F</strong> ⋅ <strong>v</strong>`（W）。電機類比：`P = VI`、電容儲能 `(1/2)CV²`、電感儲能 `(1/2)LI²`，與 `(1/2)kx²`、`(1/2)mv²` 完全同形——位移對應電荷、速度對應電流。來源：01-普通物理-上 第 3 章。

**推導必寫**：（a）功—動能定理：`W = ∫ F dx = ∫ m(dv/dt) dx = ∫ mv dv = (1/2)mv² − (1/2)mv<sub>0</sub>²`，中間那步用了 `dx = v dt`——這就是「把 `<strong>F</strong> = m<strong>a</strong>` 對**距離**積分」的結果（對**時間**積分則得到第 04 章的動量）。（b）重力位能：把重力做的功寫成 `W = −ΔU`，得 `U = mgh`（h 相對某個任選零點；零點可任選，因為只有差值有意義）。（c）由 `K + U = 常數` 得從 `h<sub>0</sub>` 靜止滑到 h：`(1/2)mv² = mg(h<sub>0</sub> − h)`，兩邊消 m 得 `v = √(2g(h<sub>0</sub> − h))`——**與質量無關，也與路徑形狀無關**，這是本章最強的一句話。（d）有摩擦時把損耗寫進來：`(1/2)mv² = mg(h<sub>0</sub> − h) − E<sub>loss</sub>`。

**數值實例**：`m = 2 kg` 從 `h<sub>0</sub> = 5 m` 靜止（`v<sub>0</sub> = 0`）滑到 `h = 1 m`，無摩擦。總機械能 `E = (1/2)(2)(0)² + 2 ⋅ 9.8 ⋅ 5 = 98.000000 J`。在 h = 1 m：位能 `U = 2 ⋅ 9.8 ⋅ 1 = 19.600000 J`，動能 `K = 98 − 19.6 = 78.400000 J`，速率 `v = √(2 ⋅ 78.4 / 2) = √78.4 = 8.854377 m/s`；用 `v = √(2gΔh) = √(2 ⋅ 9.8 ⋅ 4) = √78.4` 驗算一致，且與 m 無關。若這段花了 `t = 1 s`，重力做功 `2 ⋅ 9.8 ⋅ 4 = 78.400000 J`，平均功率 `78.400000 W`。最高可達高度 `h<sub>max</sub> = E / (mg) = 98 / 19.6 = 5.000000 m`（回到出發點，正確）。若加入 `E<sub>loss</sub> = 40 J`：`K = 98 − 19.6 − 40 = 38.400000 J`，`v = √38.4 = 6.196773 m/s`。

### 04 `04-動量與碰撞.html`

**目標**：學會第二把守恆律的刀——碰撞過程中內力多複雜都不必管，只要總動量守恆就能把碰後速度解出來。

**要點**：動量 `<strong>p</strong> = m<strong>v</strong>`（kg·m/s，向量）；衝量 `<strong>J</strong> = ∫ <strong>F</strong> dt = Δ<strong>p</strong>`（N·s，與 kg·m/s 同單位）。動量守恆：系統不受外力時總動量不變——碰撞瞬間的內力再大也成對抵消（第三定律）。碰撞分三類：彈性碰撞（動量與動能都守恆）、非彈性碰撞（只有動量守恆，部分動能變熱與形變）、完全非彈性碰撞（碰後黏在一起，動能損失最大但動量仍守恆）。統一參數是**恢復係數**（coefficient of restitution）`e = −(v<sub>1</sub>′ − v<sub>2</sub>′)/(v<sub>1</sub> − v<sub>2</sub>)`，`e = 1` 彈性、`e = 0` 完全非彈性。質心速度 `v<sub>cm</sub> = (m<sub>1</sub>v<sub>1</sub> + m<sub>2</sub>v<sub>2</sub>)/(m<sub>1</sub> + m<sub>2</sub>)` 在碰撞前後**完全不變**。來源：01-普通物理-上 第 4 章（恢復係數是本課為了給互動判準而補上的標準參數，見第 10 節）。

**推導必寫**：（a）由 `<strong>F</strong> = d<strong>p</strong>/dt` 對時間積分得 `∫ <strong>F</strong> dt = Δ<strong>p</strong>`——這就是衝量，與第 03 章「對距離積分得能量」成對。（b）解一維碰撞：把「動量守恆」`m<sub>1</sub>v<sub>1</sub> + m<sub>2</sub>v<sub>2</sub> = m<sub>1</sub>v<sub>1</sub>′ + m<sub>2</sub>v<sub>2</sub>′` 與「恢復係數定義」`v<sub>2</sub>′ − v<sub>1</sub>′ = e(v<sub>1</sub> − v<sub>2</sub>)` 當成兩元一次聯立解，得
`v<sub>1</sub>′ = (m<sub>1</sub>v<sub>1</sub> + m<sub>2</sub>v<sub>2</sub> + m<sub>2</sub>e(v<sub>2</sub> − v<sub>1</sub>)) / (m<sub>1</sub> + m<sub>2</sub>)`、
`v<sub>2</sub>′ = (m<sub>1</sub>v<sub>1</sub> + m<sub>2</sub>v<sub>2</sub> + m<sub>1</sub>e(v<sub>1</sub> − v<sub>2</sub>)) / (m<sub>1</sub> + m<sub>2</sub>)`。
（c）動能損失：定義約化質量 `μ = m<sub>1</sub>m<sub>2</sub>/(m<sub>1</sub> + m<sub>2</sub>)`（kg），代入化簡得 `ΔK = (1/2)μ(1 − e²)(v<sub>1</sub> − v<sub>2</sub>)²`——一眼看出 `e = 1` 時損失為零、`e = 0` 時損失最大。（d）由此可證質心速度不變：`v<sub>cm</sub> = p<sub>總</sub>/M`，而 `p<sub>總</sub>` 守恆、M 不變。

**數值實例**：`m<sub>1</sub> = 2 kg`、`v<sub>1</sub> = 3 m/s`、`m<sub>2</sub> = 3 kg`、`v<sub>2</sub> = −1 m/s`、`e = 1`。總動量 `p = 2 ⋅ 3 + 3 ⋅ (−1) = 3.000000 kg·m/s`；總質量 5 kg；質心速度 `0.600000 m/s`。代入公式：`v<sub>1</sub>′ = (3 + 3 ⋅ 1 ⋅ (−1 − 3))/5 = (3 − 12)/5 = −1.800000 m/s`、`v<sub>2</sub>′ = (3 + 2 ⋅ 1 ⋅ (3 + 1))/5 = (3 + 8)/5 = 2.200000 m/s`。驗算動量：`2(−1.8) + 3(2.2) = −3.6 + 6.6 = 3.000000` ✔。驗算動能：碰前 `(1/2)(2)(9) + (1/2)(3)(1) = 10.500000 J`，碰後 `(1/2)(2)(3.24) + (1/2)(3)(4.84) = 3.24 + 7.26 = 10.500000 J` ✔。改成 `e = 0`：兩者共同速度 `3/5 = 0.600000 m/s`（等於質心速度），碰後動能 `(1/2)(5)(0.36) = 0.900000 J`，損失 `10.5 − 0.9 = 9.600000 J`；用公式 `ΔK = (1/2)(1.2)(1 − 0)(4²) = 9.600000 J` ✔。若 `e = 0.5`：`ΔK = (1/2)(1.2)(1 − 0.25)(16) = 7.200000 J`。

### 05 `05-轉動與角動量.html`

**目標**：把整套平移力學平行搬到轉動：質量換成轉動慣量、力換成力矩、動量換成角動量，並算出「收手會轉多快」。

**要點**：平移↔轉動對照表（質量 m ↔ 轉動慣量 I；力 F ↔ 力矩 τ；位移 x ↔ 角位移 θ；速度 v ↔ 角速度 ω；動量 `p = mv` ↔ 角動量 `L = Iω`；`F = ma` ↔ `τ = Iα`；動能 `(1/2)mv²` ↔ `(1/2)Iω²`）。轉動慣量 `I = ∫ r² dm`（kg·m²），描述「物體有多難轉」，同樣的質量離軸越遠 I 越大。力矩 `τ = rF sin φ`（N·m），或向量寫成 `<strong>τ</strong> = <strong>r</strong> × <strong>F</strong>`。角動量守恆：沒有外力矩時 `L = Iω` 不變——花式溜冰收手變快、陀螺不倒、行星面積速度定律都是它。來源：01-普通物理-上 第 5 章（常見形狀的 I 係數是本課補上的標準結果，見第 10 節）。

**推導必寫**：（a）由 `τ = Iα` 的來歷：質點繞軸 `F<sub>切</sub> = ma<sub>切</sub> = m(rα)`，兩邊乘 r 得 `rF<sub>切</sub> = mr²α`，把整個物體加總（積分）得 `τ = (∫ r² dm)α = Iα`——**I 就是這樣冒出來的，不是硬記的**。（b）薄圓環（所有質量都在半徑 R）：`I = ∫ R² dm = MR²`。（c）實心圓盤：把圓盤切成半徑 r、寬 dr 的圓環，面密度 `σ = M/(πR²)`，`dm = σ ⋅ 2πr dr`，`I = ∫<sub>0</sub><sup>R</sup> r² ⋅ σ2πr dr = 2πσ ⋅ R⁴/4 = (1/2)MR²`。（d）角動量守恆下收手：`I<sub>1</sub>ω<sub>1</sub> = I<sub>2</sub>ω<sub>2</sub>`，若半徑縮成 k 倍則 `I<sub>2</sub> = k²I<sub>1</sub>`，所以 `ω<sub>2</sub> = ω<sub>1</sub>/k²`，動能 `K<sub>2</sub> = (1/2)I<sub>2</sub>ω<sub>2</sub>² = K<sub>1</sub>/k²`——**動能變大了，多出來的能量是收手的人做的功**，不是憑空生出來的。

**常見形狀的轉動慣量係數（builder 照抄）**：薄圓環／薄圓筒 `I = MR²`；實心圓盤／實心圓柱 `I = (1/2)MR²`；實心球 `I = (2/5)MR²`；細桿繞中心 `I = (1/12)ML²`；細桿繞端點 `I = (1/3)ML²`。

**數值實例**：實心圓盤 `M = 2 kg`、`R = 0.5 m`、`ω = 10 rad/s`、外加力矩 `τ = 1 N·m`、收縮倍率 `k = 0.5`。轉動慣量 `I = (1/2)(2)(0.25) = 0.250000 kg·m²`；角動量 `L = Iω = 2.500000 kg·m²/s`；轉動動能 `K = (1/2)(0.25)(100) = 12.500000 J`；角加速度 `α = τ/I = 1/0.25 = 4.000000 rad/s²`（一秒後 ω 會增加 4 rad/s）。收縮到 `R′ = 0.25 m`：`I′ = (1/2)(2)(0.0625) = 0.062500 kg·m²`（正好是 `k²I = 0.25 ⋅ 0.25`）；角動量守恆 `ω′ = L/I′ = 2.5/0.0625 = 40.000000 rad/s`（＝ `ω/k²`）；新動能 `K′ = (1/2)(0.0625)(1600) = 50.000000 J`，比原來多 `37.500000 J`——這正是收手時手臂做的功。同樣參數換成細桿繞中心（L = 0.5 m）：`I = (1/12)(2)(0.25) = 0.041667 kg·m²`。

### 06 `06-簡諧運動與共振.html`

**目標**：把彈簧—質量—阻尼系統徹底解剖，並當場把它翻譯成 RLC 電路——這是全課對電機最有槓桿的一章。

**要點**：無阻尼 `m(d²x/dt²) + kx = 0`，解 `x(t) = A cos(ω<sub>0</sub>t + φ)`，`ω<sub>0</sub> = √(k/m)`（rad/s），週期 `T = 2π/ω<sub>0</sub>`（s），頻率 `f<sub>0</sub> = ω<sub>0</sub>/(2π)`（Hz）。加阻尼 `m(d²x/dt²) + c(dx/dt) + kx = 0`，定義阻尼比 `ζ = c / (2√(km))`（無單位）與臨界阻尼 `c<sub>c</sub> = 2√(km)`（N·s/m）：`ζ > 1` 過阻尼、`ζ = 1` 臨界阻尼、`ζ < 1` 欠阻尼（振盪衰減，阻尼自然頻率 `ω<sub>d</sub> = ω<sub>0</sub>√(1 − ζ²)`）。加驅動 `F<sub>0</sub> cos(ωt)` 後穩態振幅 `X = F<sub>0</sub> / √((k − mω²)² + (cω)²)`，`ω → ω<sub>0</sub>` 時放大——這就是共振（resonance）。品質因數 `Q = 1/(2ζ)`。力—電類比：m↔L、c↔R、k↔1/C、x↔q、dx/dt↔i、F↔v。來源：01-普通物理-上 第 6 章。

**推導必寫**：（a）把 `x = Ae<sup>λt</sup>` 代入 `m(d²x/dt²) + c(dx/dt) + kx = 0` 得特徵方程 `mλ² + cλ + k = 0`，`λ = (−c ± √(c² − 4km)) / (2m) = −ζω<sub>0</sub> ± ω<sub>0</sub>√(ζ² − 1)`——判別式的正負就是三種阻尼型態的分界，這與工程數學先修第 07 章是同一條方程。（b）無阻尼時 `λ = ±jω<sub>0</sub>`，取實部得 `cos(ω<sub>0</sub>t)`；能量在動能 `(1/2)m(dx/dt)²` 與彈性位能 `(1/2)kx²` 之間來回換，總和不變。（c）穩態解：設 `x = X cos(ωt − φ)` 代入有驅動的方程，比較 cos 與 sin 係數得 `X = F<sub>0</sub>/√((k − mω²)² + (cω)²)`、`tan φ = cω/(k − mω²)`。在 `ω = ω<sub>0</sub>` 時 `k − mω<sub>0</sub>² = 0`，只剩 `X = F<sub>0</sub>/(cω<sub>0</sub>)`；除以靜態位移 `F<sub>0</sub>/k` 得放大率 `k/(cω<sub>0</sub>) = 1/(2ζ)`——**共振有多高完全由阻尼決定，跟驅動力大小無關**。（d）類比驗證：`L(d²q/dt²) + R(dq/dt) + q/C = v(t)`，令 `L = m`、`R = c`、`C = 1/k`，兩條方程逐項相同，所以 `ω<sub>0</sub> = 1/√(LC)`。

**數值實例**：`m = 1 kg`、`k = 100 N/m`、`c = 2 N·s/m`、驅動頻率 `ω = 10 rad/s`、`F<sub>0</sub> = 1 N`。自然角頻率 `ω<sub>0</sub> = √(100/1) = 10.000000 rad/s`；`f<sub>0</sub> = 10/(2π) = 1.591549 Hz`；週期 `T = 0.628319 s`。臨界阻尼 `c<sub>c</sub> = 2√(100) = 20.000000 N·s/m`，所以 `ζ = 2/20 = 0.100000`——欠阻尼。阻尼自然頻率 `ω<sub>d</sub> = 10√(1 − 0.01) = 9.949874 rad/s`。驅動在 `ω = ω<sub>0</sub>` 時 `k − mω² = 0`、`cω = 20`，穩態振幅 `X = 1/20 = 0.050000 m`；靜態位移 `F<sub>0</sub>/k = 0.010000 m`；放大率 `5.000000`，正好等於 `1/(2ζ) = Q = 5`；相位落後 `90.000000°`。**電路對照**：`L = 1 H`、`R = 2 Ω`、`C = 1/100 = 0.01 F`，`ω<sub>0</sub> = 1/√(1 ⋅ 0.01) = 10.000000 rad/s`——與機械端同一個數字。

### 07 `07-熱學與流體.html`

**目標**：把「能量」從機械層推到統計層：溫度是什麼、為什麼熱機一定有效率上限、以及為什麼電阻在室溫下就會自己發出雜訊。

**要點**：熱量與比熱 `Q = mcΔT`（J；c 單位 J/(kg·K)）。熱力學三定律：第一＝能量守恆（`ΔU = Q − W`）、第二＝孤立系統的熵只增不減、第三＝絕對零度不可達。理想氣體 `PV = nRT`（P 單位 Pa、V 單位 m³、n 單位 mol、`R = 8.314462618 J/(mol·K)`、T 單位 K）。第二定律的工程後果：任何在 `T<sub>H</sub>` 與 `T<sub>C</sub>` 之間工作的熱機效率上限為卡諾效率 `η = 1 − T<sub>C</sub>/T<sub>H</sub>`。流體：靜壓 `p = p<sub>0</sub> + ρgh`（Pa）、連續方程（不可壓縮時 `A<sub>1</sub>v<sub>1</sub> = A<sub>2</sub>v<sub>2</sub>`）、白努利方程 `p + (1/2)ρv² + ρgh = 常數`（就是流體版的能量守恆）。電機關聯：晶片散熱、半導體載子的熱激發、以及**熱雜訊**——電阻在溫度 T 下的雜訊電壓均方根 `v<sub>rms</sub> = √(4k<sub>B</sub>TRB)`（V）、可用雜訊功率 `P<sub>n</sub> = k<sub>B</sub>TB`（W）。來源：01-普通物理-上 第 7、8 章與 01-普通物理-下 §3.6（卡諾效率與 `√(4kTRB)` 是本課補上的標準結果，見第 10 節）。

**推導必寫**：（a）由第一定律 `ΔU = Q − W`，對一次完整循環 `ΔU = 0`，所以 `W = Q<sub>H</sub> − Q<sub>C</sub>`，效率 `η = W/Q<sub>H</sub> = 1 − Q<sub>C</sub>/Q<sub>H</sub>`。（b）由第二定律，可逆循環的熵變化為零：`Q<sub>H</sub>/T<sub>H</sub> = Q<sub>C</sub>/T<sub>C</sub>`，代回上式得 `η<sub>Carnot</sub> = 1 − T<sub>C</sub>/T<sub>H</sub>`——**這個上限只由兩個溫度決定，跟工作物質、機構設計完全無關**，這是第二定律最有力的一句話。（c）白努利：對一小段流體用功—動能定理，壓力差做的功等於動能與位能的變化，兩邊除以體積得 `p + (1/2)ρv² + ρgh = 常數`。（d）熱雜訊的量級由來：由能量均分定理，每個自由度平均帶 `(1/2)k<sub>B</sub>T` 的能量；在頻寬 B 內電阻可交出的最大功率是 `k<sub>B</sub>TB`，若把它送進匹配負載（`R` 對 `R`），開路電壓的均方值就是 `4k<sub>B</sub>TRB`。

**數值實例**：（i）加熱：`m = 0.50 kg` 鋁（`c = 900 J/(kg·K)`）升溫 `ΔT = 50 K`，`Q = 0.5 ⋅ 900 ⋅ 50 = 22500.000000 J`。（ii）卡諾：`T<sub>H</sub> = 600 K`、`T<sub>C</sub> = 300 K`，`η = 1 − 300/600 = 0.500000 = 50.000000 %`；若輸入 `Q<sub>H</sub> = 22500 J`，最多輸出功 `11250.000000 J`，必定排掉 `11250.000000 J`。（iii）理想氣體：1 mol 在 300 K、101325 Pa 下 `V = 1 ⋅ 8.314462618 ⋅ 300 / 101325 = 0.024617 m³ = 24.617210 L`。（iv）熱雜訊：`R = 1000 Ω`、`B = 10000 Hz`、`T = 300 K`。`4k<sub>B</sub>TRB = 4 ⋅ 1.380649 × 10<sup>−23</sup> ⋅ 300 ⋅ 1000 ⋅ 10000 = 1.6567788 × 10<sup>−13</sup> V²`，`v<sub>rms</sub> = 4.070355 × 10<sup>−7</sup> V = 407.036 nV`（也就是常聽到的「1 kΩ 大約 4 nV/√Hz」）；可用雜訊功率 `k<sub>B</sub>TB = 4.141947 × 10<sup>−17</sup> W`，換成 dBm 是 `−133.827955 dBm`。（v）流體：水深 10 m 的壓力 `101325 + 1000 ⋅ 9.8 ⋅ 10 = 199325 Pa = 1.967185 atm`；水管截面由 4 cm² 縮到 1 cm²、`v<sub>1</sub> = 1 m/s` 時 `v<sub>2</sub> = 4 m/s`，壓差 `Δp = (1/2)(1000)(16 − 1) = 7500 Pa`。

### 08 `08-靜電學.html`

**目標**：把「電」從國中的模糊印象變成三個層層相扣的量——力、場、電位——並用疊加原理親手算出任意點的電場與電位。

**要點**：電荷單位庫倫（C），基本電荷 `e = 1.602176634 × 10<sup>−19</sup> C`。庫倫定律 `F = (1/(4πε<sub>0</sub>)) ⋅ (q<sub>1</sub>q<sub>2</sub>/r²)`（N），同號相斥、異號相吸；`k<sub>e</sub> = 1/(4πε<sub>0</sub>) = 8.9875517874 × 10<sup>9</sup> N·m²/C²`。電場 `<strong>E</strong> = <strong>F</strong>/q`（V/m，也等於 N/C），點電荷 `E = k<sub>e</sub>q/r²`；**疊加原理**：多個電荷的電場直接向量相加（寫成程式就是一個累加迴圈）。電通量與高斯定律 `∮<sub>S</sub> <strong>E</strong> ⋅ d<strong>A</strong> = Q<sub>內</sub>/ε<sub>0</sub>`，微分形式 `∇ ⋅ <strong>E</strong> = ρ/ε<sub>0</sub>`；有球、柱、面對稱時幾乎不用積分就能算出場。電位 `V`（V）＝單位電荷的位能：`V<sub>B</sub> − V<sub>A</sub> = −∫<sub>A</sub><sup>B</sup> <strong>E</strong> ⋅ d<strong>ℓ</strong>`，反過來 `<strong>E</strong> = −∇V`；點電荷 `V = k<sub>e</sub>q/r`。電容 `Q = CV`（F），平行板 `C = ε<sub>0</sub>A/d`，儲能 `U = (1/2)CV² = (1/2)Q²/C`。介電質使電容變成 `C = ε<sub>r</sub>C<sub>0</sub>`。來源：01-普通物理-中 第 1 章 §1.1–§1.6。

**推導必寫**：（a）由庫倫定律除以試驗電荷 q 得電場定義，強調「場是把力從『兩個電荷之間』改寫成『空間的一個性質』」——這一步是為了讓第 11 章的波成為可能。（b）用高斯定律推點電荷的場：取半徑 r 的球面，由對稱性 E 在球面上大小相同且垂直球面，所以 `E ⋅ 4πr² = q/ε<sub>0</sub>`，得 `E = q/(4πε<sub>0</sub>r²)`——與庫倫定律一致，**兩者是同一件事的兩種寫法**。（c）由 `V = −∫ E dr` 對點電荷積分（取無窮遠為零點）得 `V = k<sub>e</sub>q/r`；反過來 `E<sub>r</sub> = −dV/dr = k<sub>e</sub>q/r²` ✔。（d）平行板電容：兩板間 `E = σ/ε<sub>0</sub> = Q/(ε<sub>0</sub>A)`，電位差 `V = Ed = Qd/(ε<sub>0</sub>A)`，所以 `C = Q/V = ε<sub>0</sub>A/d`。（e）儲能：把電荷一點一點搬上去，`U = ∫<sub>0</sub><sup>Q</sup> (q/C) dq = Q²/(2C) = (1/2)CV²`。

**數值實例**：`q<sub>1</sub> = +5 nC` 放在 x = 0、`q<sub>2</sub> = −3 nC` 放在 `x = d = 0.30 m`，真空 `ε<sub>r</sub> = 1`。兩者的作用力 `F = 8.9875517874 × 10<sup>9</sup> ⋅ (5 × 10<sup>−9</sup>)(3 × 10<sup>−9</sup>) / 0.09 = 1.497925 × 10<sup>−6</sup> N`（吸引）。在中點 `x = 0.15 m`：`q<sub>1</sub>` 造成 `E<sub>1</sub> = 8.9875517874 × 10<sup>9</sup> ⋅ 5 × 10<sup>−9</sup> / 0.0225 = 1997.233731 V/m`（指向 +x）；`q<sub>2</sub>` 造成 `E<sub>2</sub> = 1198.340238 V/m`（也指向 +x，因為負電荷吸引正試驗電荷）。合成 `E = 3195.573969 V/m`，**兩者同向所以相加**。電位是純量直接相加：`V = k<sub>e</sub>(5 × 10<sup>−9</sup>)/0.15 + k<sub>e</sub>(−3 × 10<sup>−9</sup>)/0.15 = 299.585060 − 179.751036 = 119.834024 V`。零場點：解 `5/x² = 3/(x − 0.3)²` 得 `2x² − 3x + 0.45 = 0`，`x = (3 + √5.4)/4 = 1.330948 m`——**在絕對值較小的電荷外側**，不在兩者之間。電容範例：`A = 0.01 m²`、`d = 0.001 m`、真空 → `C = 8.8541878128 × 10<sup>−12</sup> ⋅ 0.01/0.001 = 8.8541878 × 10<sup>−11</sup> F = 88.541878 pF`；加到 12 V 時 `U = (1/2)(8.8541878 × 10<sup>−11</sup>)(144) = 6.375015 × 10<sup>−9</sup> J`。

### 09 `09-電流與電路基礎.html`

**目標**：把靜電學接上會動的電荷：電流是什麼、電阻從哪來、以及為什麼長導線會偷走你的功率。

**要點**：電流 `I = dQ/dt`（A ＝ C/s），慣例方向是正電荷流動方向（金屬裡實際移動的是電子，方向相反）。電流密度 `<strong>J</strong>`（A/m²）。歐姆定律的兩種寫法：巨觀 `V = IR`（R 單位 Ω）與微觀 `<strong>J</strong> = σ<strong>E</strong>`（σ 是電導率，單位 S/m；電阻率 `ρ = 1/σ`，單位 Ω·m）。導線電阻 `R = ρℓ/A`（長度越長越大、截面越粗越小）。功率 `P = VI = I²R = V²/R`（W）。直流電路兩條規則：克希荷夫電壓定律（Kirchhoff's Voltage Law, KVL）＝任一閉迴路電壓和為零（能量守恆）；克希荷夫電流定律（Kirchhoff's Current Law, KCL）＝節點流入等於流出（電荷守恆）。串聯 R 相加、並聯 `1/R` 相加。來源：01-普通物理-中 第 2 章 §2.1–§2.4（各材料的電阻率數值是本課補上的標準值，見第 10 節）。

**推導必寫**：（a）由 `<strong>J</strong> = σ<strong>E</strong>` 推 `V = IR`：均勻導線內 `E = V/ℓ`、`J = I/A`，代入得 `I/A = σV/ℓ`，整理 `V = I ⋅ (ℓ/(σA)) = I ⋅ (ρℓ/A)`——**歐姆定律不是基本定律，是材料的線性近似**，`R = ρℓ/A` 就是這樣冒出來的。（b）功率：把電荷 dQ 從高電位搬到低電位，損失位能 `dW = V dQ`，除以 dt 得 `P = VI`；代入 `V = IR` 得 `P = I²R`。（c）串聯分壓：同一電流 I 流過 `R<sub>線</sub>` 與 `R<sub>負載</sub>`，`I = V/(R<sub>線</sub> + R<sub>負載</sub>)`，負載得到 `V<sub>負載</sub> = V ⋅ R<sub>負載</sub>/(R<sub>線</sub> + R<sub>負載</sub>)`，傳輸效率 `η = R<sub>負載</sub>/(R<sub>線</sub> + R<sub>負載</sub>)`。（d）順帶量綱檢查：`[ρ] = [R][A]/[ℓ] = Ω·m²/m = Ω·m` ✔。

**各材料的電阻率（builder 照抄，20 °C）**：銅 `1.68 × 10<sup>−8</sup> Ω·m`、鋁 `2.65 × 10<sup>−8</sup> Ω·m`、鐵 `9.71 × 10<sup>−8</sup> Ω·m`、鎳鉻合金 `1.10 × 10<sup>−6</sup> Ω·m`。

**數值實例**：銅線 `ρ = 1.68 × 10<sup>−8</sup> Ω·m`、長度 `ℓ = 10 m`、截面積 `A = 1 mm² = 1 × 10<sup>−6</sup> m²`，`R<sub>線</sub> = 1.68 × 10<sup>−8</sup> ⋅ 10 / 10<sup>−6</sup> = 0.168000 Ω`。把它串在 `V = 12 V` 電源與 `R<sub>負載</sub> = 10 Ω` 之間：總電阻 `10.168000 Ω`，電流 `I = 12/10.168 = 1.180173 A`。負載上的電壓 `1.180173 ⋅ 10 = 11.801731 V`，導線上掉了 `0.198269 V`（兩者相加正好 12.000000 V ✔）。功率：總 `12 ⋅ 1.180173 = 14.162077 W`，負載得到 `I² ⋅ 10 = 13.928085 W`，導線白白發熱 `I² ⋅ 0.168 = 0.233992 W`；傳輸效率 `10/10.168 = 0.983478 = 98.347758 %`。把導線換成同尺寸的鎳鉻合金（`ρ` 大 65.5 倍）：`R<sub>線</sub> = 11.000000 Ω`，效率掉到 `10/21 = 47.619048 %`——這就是為什麼電線要用銅、電熱絲要用鎳鉻。

### 10 `10-磁場與電磁感應.html`

**目標**：把磁場從「磁鐵會吸鐵」升級成一組可計算的規則，並親手驗證發電機裡「機械功率 ＝ 電功率」這件事。

**要點**：磁通密度 `<strong>B</strong>`（T ＝ Wb/m²）。勞侖茲力 `<strong>F</strong> = q(<strong>E</strong> + <strong>v</strong> × <strong>B</strong>)`；載流導線受力 `d<strong>F</strong> = I d<strong>ℓ</strong> × <strong>B</strong>`，大小 `F = BIL sin θ`——**馬達的轉矩就是從這裡來的**。電流產生磁場：畢歐—沙伐定律（Biot–Savart law）`d<strong>B</strong> = (μ<sub>0</sub>/(4π)) ⋅ (I d<strong>ℓ</strong> × r̂)/r²`；安培定律 `∮<sub>C</sub> <strong>B</strong> ⋅ d<strong>ℓ</strong> = μ<sub>0</sub>I<sub>穿過</sub>`，微分形式 `∇ × <strong>B</strong> = μ<sub>0</sub><strong>J</strong>`（靜態）。無限長直導線 `B = μ<sub>0</sub>I/(2πr)`；長螺線管 `B = μ<sub>0</sub>NI/ℓ`。磁通量 `Φ<sub>B</sub> = ∫ <strong>B</strong> ⋅ d<strong>A</strong>`（Wb）；`∇ ⋅ <strong>B</strong> = 0`＝沒有磁單極，磁力線必閉合。法拉第定律 `ε = −dΦ<sub>B</sub>/dt`（V），微分形式 `∇ × <strong>E</strong> = −∂<strong>B</strong>/∂t`；冷次定律＝負號的物理意義，感應電流方向永遠反抗磁通的變化。自感 `v<sub>L</sub> = L(di/dt)`（H），互感 M＝變壓器的原理。RL 時間常數 `τ = L/R`、RC 時間常數 `τ = RC`（s）。來源：01-普通物理-中 第 3 章與第 4 章。

**推導必寫**：（a）移動導體棒的感應電動勢：長度 L 的棒以速度 v 垂直切過磁場 B，棒內每個電荷受 `F = qvB`，等效電場 `E = vB`，兩端電位差 `ε = BLv`。同一件事用磁通算：迴路面積每秒增加 `Lv`，`dΦ/dt = BLv`，兩條路一致 ✔（若磁場與迴路法線夾角 θ，則 `Φ = BA cos θ`，`ε = BLv cos θ`）。（b）冷次定律的能量意義：感應電流 `I = ε/R` 在磁場中受安培力 `F = BIL`，方向**反抗**運動。要維持等速就必須施加同樣大的外力，機械功率 `P<sub>機</sub> = Fv = B²L²v²/R`；電功率 `P<sub>電</sub> = εI = (BLv)²/R`——**兩者恆等**。若冷次定律的符號相反，這台裝置會自己加速並無中生有地產生能量，違反能量守恆。（c）由安培定律推直導線的場：取半徑 r 的圓形路徑，由對稱性 B 沿路徑大小相同，`B ⋅ 2πr = μ<sub>0</sub>I`，得 `B = μ<sub>0</sub>I/(2πr)`。（d）螺線管自感：`Φ = BA = μ<sub>0</sub>NIA/ℓ`，總磁通鏈 `NΦ`，`L = NΦ/I = μ<sub>0</sub>N²A/ℓ`。

**數值實例**：導體棒 `B = 0.50 T`、`L = 0.20 m`、`v = 3.0 m/s`、迴路電阻 `R = 2.0 Ω`、`θ = 0°`。感應電動勢 `ε = 0.5 ⋅ 0.2 ⋅ 3 = 0.300000 V`；感應電流 `I = 0.3/2 = 0.150000 A`；安培阻力 `F = BIL = 0.5 ⋅ 0.15 ⋅ 0.2 = 0.015000 N`；維持等速的機械功率 `P<sub>機</sub> = Fv = 0.045000 W`；電功率 `P<sub>電</sub> = εI = 0.045000 W`，也等於 `I²R = 0.0225 ⋅ 2 = 0.045000 W` ✔ 三者一致。**磁場要多難產生**：若這個 0.5 T 要靠一根長直導線在 `r = 0.05 m` 處產生，需要 `I = 2πrB/μ<sub>0</sub> = 2π(0.05)(0.5)/(1.25663706212 × 10<sup>−6</sup>) = 124999.999932 A`——十二萬五千安培，所以實務上一律用鐵芯或永久磁鐵，不用裸導線。**自感範例**：螺線管 `N = 100` 匝、`ℓ = 0.1 m`、`A = 1 × 10<sup>−4</sup> m²`，`L = μ<sub>0</sub>N²A/ℓ = 1.256637 × 10<sup>−5</sup> H = 12.566371 µH`；配 `R = 2 Ω` 時 `τ = L/R = 6.283185 × 10<sup>−6</sup> s = 6.283185 µs`。

### 11 `11-馬克士威與電磁波.html`

**目標**：看懂四條方程各自在說哪一條守恆，並親眼看到光速 c 是怎麼從電與磁的常數裡「自動冒出來」的。

**要點**：位移電流的必要性——靜態的安培定律在時變情形自相矛盾（同一條迴路，取平面得到穿過電流、取繞過電容器的曲面得到零），馬克士威加入 `μ<sub>0</sub>ε<sub>0</sub> ∂<strong>E</strong>/∂t` 補上。真空四式（微分形式）：`∇ ⋅ <strong>E</strong> = ρ/ε<sub>0</sub>`（電荷是電場的源）、`∇ ⋅ <strong>B</strong> = 0`（沒有磁單極）、`∇ × <strong>E</strong> = −∂<strong>B</strong>/∂t`（變動磁場生電場）、`∇ × <strong>B</strong> = μ<sub>0</sub><strong>J</strong> + μ<sub>0</sub>ε<sub>0</sub> ∂<strong>E</strong>/∂t`（電流與變動電場生磁場）。無源真空下可導出 `∇²<strong>E</strong> = μ<sub>0</sub>ε<sub>0</sub> ∂²<strong>E</strong>/∂t²`，波速 `c = 1/√(μ<sub>0</sub>ε<sub>0</sub>) = 2.99792458 × 10<sup>8</sup> m/s`。電磁波性質：橫波（`<strong>E</strong> ⊥ <strong>B</strong> ⊥` 傳播方向）、`E<sub>0</sub>/B<sub>0</sub> = v`、波阻抗 `η = √(μ/ε)`（真空 `η<sub>0</sub> = 376.730314 Ω`）、能流密度（坡印廷向量，Poynting vector）`<strong>S</strong> = (1/μ<sub>0</sub>)<strong>E</strong> × <strong>B</strong>`（W/m²），正弦波的時間平均 `S<sub>avg</sub> = E<sub>0</sub>²/(2η)`。介質中 `v = c/n`、`n = √(ε<sub>r</sub>μ<sub>r</sub>)`。頻譜：無線電、微波、紅外、可見光、紫外、X 射線、伽馬射線——同一種波，只是頻率不同。來源：01-普通物理-中 第 5 章 §5.1–§5.3。

**推導必寫**：（a）位移電流的矛盾：對正在充電的電容器，取穿過導線的平面 `∮B ⋅ dℓ = μ<sub>0</sub>I`，取繞過極板之間的曲面則 `I<sub>穿過</sub> = 0`——同一條迴路兩個答案。加上 `ε<sub>0</sub> dΦ<sub>E</sub>/dt`（極板間電場正在變強）後兩者相等。（b）波動方程：對 `∇ × <strong>E</strong> = −∂<strong>B</strong>/∂t` 再取旋度，用恆等式 `∇ × (∇ × <strong>E</strong>) = ∇(∇ ⋅ <strong>E</strong>) − ∇²<strong>E</strong>`，無源時 `∇ ⋅ <strong>E</strong> = 0`，右邊代入第四式得 `∇²<strong>E</strong> = μ<sub>0</sub>ε<sub>0</sub> ∂²<strong>E</strong>/∂t²`。與標準波動方程 `∂²y/∂t² = v²∂²y/∂x²` 比對，得 `v = 1/√(μ<sub>0</sub>ε<sub>0</sub>)`。（c）把數字代進去：`μ<sub>0</sub>ε<sub>0</sub> = 1.25663706212 × 10<sup>−6</sup> ⋅ 8.8541878128 × 10<sup>−12</sup> = 1.112650056 × 10<sup>−17</sup>`，開根號取倒數得 `2.99792458 × 10<sup>8</sup> m/s`——**這兩個常數都是從靜電、靜磁實驗量出來的，跟光完全無關，卻算出了光速**。（d）波阻抗：由 `E<sub>0</sub>/B<sub>0</sub> = v` 與 `H = B/μ` 得 `E/H = μv = √(μ/ε)`；真空 `η<sub>0</sub> = μ<sub>0</sub>c = 376.730314 Ω`。

**數值實例**：`f = 1 GHz`（`log₁₀f = 9`）、真空（`ε<sub>r</sub> = 1`、`μ<sub>r</sub> = 1`）、`E<sub>0</sub> = 1 V/m`。折射率 `n = 1`，波速 `v = 299792458 m/s`；波長 `λ = v/f = 0.299792 m ≈ 30 cm`；四分之一波長天線 `λ/4 = 0.074948 m ≈ 7.5 cm`（這就是 Wi-Fi 天線那麼短的原因）。波阻抗 `η = 376.730314 Ω`；磁場振幅 `B<sub>0</sub> = E<sub>0</sub>/v = 3.335641 × 10<sup>−9</sup> T`（極小，所以量電磁波幾乎都量 E 不量 B）；平均能流 `S<sub>avg</sub> = 1/(2 ⋅ 376.730314) = 1.327209 × 10<sup>−3</sup> W/m²`。單顆光子能量 `hf = 6.62607015 × 10<sup>−25</sup> J = 4.135668 × 10<sup>−6</sup> eV`（第 15 章會用到）。頻段判讀：1 GHz 屬於**無線電**（微波的下界通常畫在 3 GHz）。若把介質換成 `ε<sub>r</sub> = 4`：`n = 2`、`v = 1.498962 × 10<sup>8</sup> m/s`、`λ = 0.149896 m`、`η = 188.365157 Ω`——**波長在介質中變短，這是印刷電路板走線長度要換算的原因**。

### 12 `12-波動與駐波.html`

**目標**：把第 06 章的「一個點在振」擴展成「一整條線在振」，並算出為什麼弦只在特定幾個頻率上會共鳴。

**要點**：波的基本量：波長 λ（m）、頻率 f（Hz）、週期 `T = 1/f`（s）、角頻率 `ω = 2πf`（rad/s）、波數 `k = 2π/λ`（rad/m）；波速 `v = fλ = ω/k`（m/s）。行進波 `y(x, t) = A cos(kx − ωt + φ)`，往 +x 方向以速度 v 行進。波動方程 `∂²y/∂t² = v²(∂²y/∂x²)`——**所有線性波（弦、聲、電磁、傳輸線）都滿足這一條，只有 v 由介質決定**。弦上的波速 `v = √(T/μ)`（T 是張力，單位 N；μ 是線密度，單位 kg/m）。疊加原理：兩波在同一點直接相加；同相加強（建設性干涉）、反相抵消（破壞性干涉）。駐波（standing wave）＝兩個反向行進的同頻波疊加，形狀 `y(x, t) = 2A sin(kx) cos(ωt)`，只振盪不傳播；兩端固定的弦必須讓兩端都是節點，所以 `λ<sub>n</sub> = 2L/n`、共振頻率 `f<sub>n</sub> = nv/(2L)`，`n = 1, 2, 3, …`。來源：01-普通物理-下 第 1 章 §1.1–§1.3（`v = √(T/μ)` 是本課補上的標準結果，見第 10 節）。

**推導必寫**：（a）由 `y = A cos(kx − ωt)` 驗證波動方程：`∂²y/∂t² = −ω²y`、`∂²y/∂x² = −k²y`，代入得 `ω² = v²k²`，即 `v = ω/k = fλ`。（b）駐波的形成：`A cos(kx − ωt) + A cos(kx + ωt) = 2A cos(kx) cos(ωt)`（用和差化積）；若改用兩端固定的邊界條件，取 sin 形式 `2A sin(kx) cos(ωt)`——空間部分 `sin(kx)` 與時間部分 `cos(ωt)` **完全分離**，所以節點的位置不隨時間移動。（c）量子化條件：兩端固定要求 `sin(kL) = 0`，所以 `kL = nπ`，`λ<sub>n</sub> = 2π/k = 2L/n`，`f<sub>n</sub> = v/λ<sub>n</sub> = nv/(2L)`——**「只有特定頻率能存活」這件事完全來自邊界條件**，第 15 章的能階量子化用的是同一個邏輯。（d）節點與波腹：`sin(nπx/L) = 0` 的地方是節點（含兩端共 n+1 個），`\|sin(nπx/L)\| = 1` 的地方是波腹（共 n 個）。

**數值實例**：弦長 `L = 1.00 m`、張力 `T = 100 N`、線密度 `μ = 1.0 g/m = 0.001 kg/m`。波速 `v = √(100/0.001) = √100000 = 316.227766 m/s`。基頻（n = 1）：`λ<sub>1</sub> = 2L/1 = 2.000000 m`、`f<sub>1</sub> = 316.227766/2 = 158.113883 Hz`；驗算 `f<sub>1</sub>λ<sub>1</sub> = 158.113883 ⋅ 2 = 316.227766 = v` ✔。在 `x/L = 0.5`：`sin(1 ⋅ π ⋅ 0.5) = 1.000000`，是**波腹**，振幅最大。換成 n = 2：`f<sub>2</sub> = 316.227766 Hz`、`λ<sub>2</sub> = 1.000000 m`，同一位置 `sin(2π ⋅ 0.5) = 0.000000`，變成**節點**。張力調成 4 倍（400 N）時 `v = 632.455532 m/s`、`f<sub>1</sub> = 316.227766 Hz`——**張力 4 倍只讓頻率變 2 倍**（吉他調音時轉一大圈只升一點點的原因）。線密度 4 倍時 v 減半（低音弦比較粗的原因）。

### 13 `13-反射折射與都卜勒.html`

**目標**：回答「波遇到界面時，能量為什麼會被彈回來」，並把同一個道理一次用在傳輸線匹配、都卜勒測速與分貝上。

**要點**：波從介質 1 進入介質 2 時，一部分反射、一部分透射，比例由兩端的**波阻抗**（wave impedance）決定。反射係數 `Γ = (Z<sub>2</sub> − Z<sub>1</sub>)/(Z<sub>2</sub> + Z<sub>1</sub>)`（無單位），反射功率比 `\|Γ\|²`，透射功率比 `1 − \|Γ\|²`。`Z<sub>1</sub> = Z<sub>2</sub>` 時 `Γ = 0`＝**阻抗匹配**（impedance matching），能量全部過去、沒有反射。工程上用兩個衍生量描述：駐波比 `VSWR = (1 + \|Γ\|)/(1 − \|Γ\|)`、回波損耗 `RL = −20 log(\|Γ\|)`（dB）。這是天線與傳輸線要做成 50 Ω 的原因。都卜勒效應（Doppler effect）：`f′ = f<sub>0</sub> ⋅ (v + v<sub>觀</sub>)/(v − v<sub>源</sub>)`（靠近取正），雷達測速、超音波、衛星定位、5G 都在用。聲波：縱波，空氣中約 340 m/s；聲強級 `L = 10 log(I/I<sub>0</sub>)`（dB，`I<sub>0</sub> = 10<sup>−12</sup> W/m²`）；拍頻（beat）＝兩個接近頻率疊加產生 `\|f<sub>1</sub> − f<sub>2</sub>\|` 的包絡，和通訊的混頻同源。來源：01-普通物理-下 第 1 章 §1.4–§1.6（VSWR 與回波損耗是本課補上的標準工程量，見第 10 節）。

**推導必寫**：（a）反射係數：界面兩側必須滿足「位移連續」與「力（或電壓電流）連續」兩個邊界條件，寫成 `1 + Γ = τ`（透射係數）與 `(1 − Γ)/Z<sub>1</sub> = τ/Z<sub>2</sub>`，兩式聯立解得 `Γ = (Z<sub>2</sub> − Z<sub>1</sub>)/(Z<sub>2</sub> + Z<sub>1</sub>)`。（b）能量檢查：反射功率比 `\|Γ\|²`、透射功率比 `1 − \|Γ\|²`，兩者相加為 1 ✔。（c）極端情形：`Z<sub>2</sub> = 0`（短路）→ `Γ = −1`，全反射且相位反轉；`Z<sub>2</sub> → ∞`（開路）→ `Γ = +1`，全反射不反相；`Z<sub>2</sub> = Z<sub>1</sub>` → `Γ = 0`。（d）都卜勒（波源移動）：波源每個週期前進 `v<sub>源</sub>T`，所以前方的波長被壓縮成 `λ′ = (v − v<sub>源</sub>)/f<sub>0</sub>`，觀察到的頻率 `f′ = v/λ′ = f<sub>0</sub>v/(v − v<sub>源</sub>)`；觀察者移動則改變的是相對波速，`f′ = f<sub>0</sub>(v + v<sub>觀</sub>)/v`——**兩者機制不同，公式不對稱**，只有在速度遠小於 v 時才近似相同。（e）dB 的來歷：人耳對強度的感受近似對數，所以用 `10 log(I/I<sub>0</sub>)`；強度 10 倍＝ +10 dB、2 倍＝ +3.010300 dB。

**數值實例**：（i）阻抗：`Z<sub>1</sub> = 50 Ω` 接 `Z<sub>2</sub> = 75 Ω`。`Γ = (75 − 50)/(75 + 50) = 25/125 = 0.200000`；反射功率比 `0.040000`＝ **4 %**，透射 **96 %**；`VSWR = 1.2/0.8 = 1.500000`；回波損耗 `−20 log(0.2) = 13.979400 dB`。（ii）都卜勒：`f<sub>0</sub> = 1000 Hz`、`v = 340 m/s`、波源以 `30 m/s` 靠近、觀察者靜止。`f′ = 1000 ⋅ 340/(340 − 30) = 1000 ⋅ 340/310 = 1096.774194 Hz`，升高 96.774194 Hz。若改成波源靜止、觀察者以 30 m/s 靠近：`f′ = 1000 ⋅ (340 + 30)/340 = 1088.235294 Hz`——**同樣是 30 m/s 的接近速度，答案不一樣**。（iii）dB：`I = 10<sup>−6</sup> W/m²`（`log₁₀I = −6`），`L = 10 log(10<sup>−6</sup>/10<sup>−12</sup>) = 10 log(10<sup>6</sup>) = 60.000000 dB`（一般談話的量級）。

### 14 `14-幾何光學與波動光學.html`

**目標**：先用「光是射線」算透鏡與光纖，再用「光是波」算干涉與繞射，並說清楚兩套模型各自在什麼尺度下才有效。

**要點**：**幾何光學**（把光當射線，適用於孔徑遠大於波長時）：反射定律（入射角＝反射角）；司乃耳折射定律（Snell's law）`n<sub>1</sub> sin θ<sub>1</sub> = n<sub>2</sub> sin θ<sub>2</sub>`，折射率 `n = c/v`（無單位）；全反射（total internal reflection）——從光密到光疏（`n<sub>1</sub> > n<sub>2</sub>`）且入射角超過臨界角 `θ<sub>c</sub> = arcsin(n<sub>2</sub>/n<sub>1</sub>)` 時光全部被彈回，**光纖就是用纖芯與包層的折射率差把光鎖在裡面**；薄透鏡公式 `1/f = 1/s<sub>o</sub> + 1/s<sub>i</sub>`，橫向放大率 `M = −s<sub>i</sub>/s<sub>o</sub>`（負號代表倒立）。**波動光學**（孔徑接近波長時必須用）：楊氏雙狹縫干涉亮紋間距 `Δy = λD/d`；繞射（diffraction）＝波繞過障礙物，孔徑越小繞射越強，Fraunhofer 繞射圖樣就是孔徑形狀的傅立葉轉換；解析力極限 `θ<sub>min</sub> ≈ λ/D`（望遠鏡、顯微鏡、雷達天線方向性的根本限制）；偏振（polarization）＝電場的振動方向，有線性、圓、橢圓三種。相干（coherence）＝相位關係穩定，雷射是高度相干的光源，光纖長距傳輸的同調檢測就靠它。來源：01-普通物理-下 第 2 章 §2.1–§2.3（放大率公式與符號約定是本課補上的標準結果，見第 10 節）。

**推導必寫**：（a）折射率的物理意義：`n = c/v`，光在介質中變慢；由波在界面兩側「頻率不變、波長改變」＋「相位在界面必須連續」可導出 `n<sub>1</sub> sin θ<sub>1</sub> = n<sub>2</sub> sin θ<sub>2</sub>`。（b）臨界角：令折射角 `θ<sub>2</sub> = 90°`（sin = 1），得 `sin θ<sub>c</sub> = n<sub>2</sub>/n<sub>1</sub>`；只有 `n<sub>1</sub> > n<sub>2</sub>` 時這個角才存在。（c）雙狹縫：兩條路徑的光程差 `δ = d sin θ`；亮紋條件 `δ = mλ`。小角度時 `sin θ ≈ tan θ = y/D`，代入得 `y<sub>m</sub> = mλD/d`，相鄰亮紋間距 `Δy = λD/d`——**間距與波長成正比，所以白光會分色**。（d）符號約定（builder 必須照抄，否則放大率會算錯）：物距 `s<sub>o</sub> > 0`（實物）；`s<sub>i</sub> > 0` 代表**實像**（在透鏡另一側），`s<sub>i</sub> < 0` 代表**虛像**（與物同側）；`f > 0` 凸透鏡（會聚），`f < 0` 凹透鏡（發散）；`M < 0` 倒立，`M > 0` 正立；`\|M\| > 1` 放大。

**數值實例**：（i）透鏡：`f = 10 cm`、`s<sub>o</sub> = 30 cm`。`1/s<sub>i</sub> = 1/10 − 1/30 = 2/30 = 1/15`，`s<sub>i</sub> = 15.000000 cm`；`M = −15/30 = −0.500000`——倒立、縮小、實像。把 `s<sub>o</sub>` 調到 20 cm（= 2f）：`s<sub>i</sub> = 20.000000 cm`、`M = −1.000000`（等大倒立）。調到 5 cm（< f）：`1/s<sub>i</sub> = 1/10 − 1/5 = −1/10`，`s<sub>i</sub> = −10.000000 cm`、`M = +2.000000`——正立放大虛像（放大鏡）。（ii）折射：`n<sub>1</sub> = 1.50`（玻璃）→ `n<sub>2</sub> = 1.00`（空氣），`θ<sub>1</sub> = 30°`。`sin θ<sub>2</sub> = 1.5 ⋅ 0.5/1.0 = 0.750000`，`θ<sub>2</sub> = 48.590378°`（折射線偏離法線）。臨界角 `θ<sub>c</sub> = arcsin(1/1.5) = 41.810315°`；30° < 41.810315° 所以還有折射光。把 `θ<sub>1</sub>` 調到 45° 就會**全反射**。（iii）雙狹縫：`λ = 500 nm`、`d = 100 µm`、`D = 1.00 m`。`Δy = (500 × 10<sup>−9</sup>)(1)/(100 × 10<sup>−6</sup>) = 5.000000 × 10<sup>−3</sup> m = 5.000000 mm`；第一亮紋的角度 `θ<sub>1</sub> = λ/d = 5.000000 × 10<sup>−3</sup> rad = 0.286479°`。若把 `d` 縮到 10 µm，間距變成 50 mm——**縫越窄，圖樣越散開**，這正是繞射越強的意思。（iv）解析力：`λ = 500 nm`、口徑 `D = 0.10 m` 的望遠鏡，`θ<sub>min</sub> ≈ 5.000000 × 10<sup>−6</sup> rad`。

**可觀察證據**：**用什麼量**——用光具座＋凸透鏡＋光屏，量物距與像距畫 `1/s<sub>o</sub>` 對 `1/s<sub>i</sub>` 的直線，截距就是 `1/f`；用半圓形玻璃磚＋雷射筆量折射角，並慢慢增大入射角直到折射光消失，那個角就是 `θ<sub>c</sub>`；用雷射筆照雙狹縫片，在牆上量條紋間距反推 λ。**能證明什麼**——能證明 `n<sub>1</sub> sin θ<sub>1</sub> = n<sub>2</sub> sin θ<sub>2</sub>` 在整個角度範圍成立，也能由條紋間距量出雷射波長到三位有效數字。**不能證明什麼**——條紋實驗不能證明「光子逐一通過」（那要靠單光子干涉實驗，本課不做）；透鏡成像實驗也不能證明薄透鏡近似有效（厚透鏡與像差在大孔徑下就會顯現，公式會失準）。

### 15 `15-量子與半導體.html`

**目標**：看懂經典物理在哪裡撞牆、量子化怎麼補上，並一路推到「為什麼矽是半導體、為什麼光纖偵測器不能用矽」。

**要點**：經典物理解不掉的四件事：黑體輻射的紫外災難、光電效應、原子光譜的離散線、電子繞射。普朗克的解法：能量一份一份給，`E = hf`，`h = 6.62607015 × 10<sup>−34</sup> J·s`。光電效應：光子能量 `E = hf` 打出電子，`K<sub>max</sub> = hf − W`（W 是功函數，work function，單位 eV）；`hf < W` 時**無論光多強都打不出電子**——這是光的粒子性最直接的證據；截止電壓 `V<sub>stop</sub> = K<sub>max</sub>/e`。波粒二象性：物質也有波性，德布羅意波長 `λ = h/p`；被 V 伏特加速的電子 `p = √(2m<sub>e</sub>eV)`。海森堡不確定性 `Δx ⋅ Δp ≥ ħ/2`（`ħ = h/(2π) = 1.054571817 × 10<sup>−34</sup> J·s`），與訊號的時頻不確定性同源。原子結構：拉塞福（核很小很重）→ 波耳（電子在離散軌道）→ 量子力學（Schrödinger 方程描述機率波）。固態：能帶論——固體中允許的電子能量形成能帶，帶與帶之間是能隙（band gap）`E<sub>g</sub>`；導體能帶部分填滿、絕緣體能隙大、半導體能隙小（矽約 1.12 eV），可用熱激發或摻雜控制導電性；n 型／p 型與 PN 接面是所有半導體元件的基礎。雷射＝受激輻射產生的相干光源；半導體雷射是光纖通訊的光源，光二極體把光轉回電。雜訊的物理起源：熱雜訊（Johnson–Nyquist，第 07 章已算過）、散粒雜訊（電子的離散性）、1/f 雜訊。來源：01-普通物理-下 第 3 章 §3.1–§3.6。

**推導必寫**：（a）由 `E = hf` 與 `c = fλ` 得 `E = hc/λ`；換成實用單位 `hc = 1239.841984 eV·nm`，所以「波長（nm）乘上能量（eV）永遠等於 1240」——這個口訣本章要背下來。（b）光電效應的能量帳：光子把 `hf` 全部給一個電子，電子要先付 W 才能離開金屬，剩下的是動能：`K<sub>max</sub> = hf − W`。畫 `K<sub>max</sub>` 對 f 的圖是一條直線，**斜率就是 h、截距就是 −W**——密立根就是這樣量出 h 的。截止波長 `λ<sub>max</sub> = hc/W`。（c）加速電子的物質波：`eV = p²/(2m<sub>e</sub>)` → `p = √(2m<sub>e</sub>eV)` → `λ = h/√(2m<sub>e</sub>eV)`；把常數代進去得實用式 `λ(nm) ≈ 1.226426/√(V)`。（d）能隙與吸收邊：半導體只能吸收 `hf ≥ E<sub>g</sub>` 的光子，對應波長上限 `λ<sub>g</sub> = hc/E<sub>g</sub>`；比 `λ<sub>g</sub>` 長的光直接穿過去。（e）駐波與能階的類比：第 12 章「兩端固定的弦只有特定頻率活得下來」與「被侷限的電子只有特定能量活得下來」是**同一個數學**（邊界條件造成量子化）。

**數值實例**：（i）光子能量：`λ = 400 nm` → `E = 1239.841984/400 = 3.099605 eV`（＝ `4.966115 × 10<sup>−19</sup> J`）。（ii）光電效應：功函數 `W = 2.30 eV`（鈉的量級）。`K<sub>max</sub> = 3.099605 − 2.30 = 0.799605 eV`，截止電壓 `0.799605 V`；截止波長 `λ<sub>max</sub> = 1239.841984/2.30 = 539.061732 nm`——比這更長的光（例如 600 nm 的橘光）**照多強都打不出電子**。（iii）光子流量：1 mW 的 400 nm 雷射每秒送出 `10<sup>−3</sup>/(4.966115 × 10<sup>−19</sup>) = 2.013647 × 10<sup>15</sup>` 顆光子——量子化在日常光強下完全看不出來，這是經典物理能撐那麼久的原因。（iv）物質波：`V = 100 V` 的電子，`λ = 1.226426/√100 = 0.122643 nm`——與矽的晶格常數 0.543 nm 同量級，所以電子會被晶體繞射（這就是電子顯微鏡與 LEED 的原理）。（v）半導體：矽 `E<sub>g</sub> = 1.12 eV` → `λ<sub>g</sub> = 1239.841984/1.12 = 1107.001771 nm`。可見光（380–780 nm）能量都高於 1.12 eV，所以矽對可見光不透明、可以做太陽能板與相機感光元件；但光纖用的 1310 nm 與 1550 nm 能量低於 `E<sub>g</sub>`，矽看不見——**所以光纖接收端要改用能隙更小的 InGaAs**。

### 7.5 JavaScript 規則

- 只用 ES2017 以內語法（`const`／`let`／箭頭函式／樣板字串／`Object.keys`）。不用模組、不用 `class`、不用 optional chaining（保守相容）。

- **`Infinity` 與 `NaN` 一律不得出現在使用者看到的字串裡**：所有可能發散的量（無阻尼共振振幅、完全匹配的回波損耗、物在焦點時的像距、觀察點壓在點電荷上）都必須走各章「邊界情形」欄指定的文字分支。verifier 會用 `grep -c 'NaN\|Infinity'` 掃輸出字串常數。

## 10. 來源筆記缺口（僅列出，本案不回頭改寫筆記）
