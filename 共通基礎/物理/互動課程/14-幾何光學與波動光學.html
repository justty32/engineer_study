14・射線負責成像，波負責條紋與極限

幾何光學與波動光學：先選對尺度，再選對光的模型

透鏡與光纖常可把光當成射線追蹤，但狹縫、解析力與偏振必須回到電磁波。本章把兩套模型接在一起：用折射與薄透鏡算方向和像，再用相位差算干涉條紋，並說清楚各自何時失效。

這章假設已懂：12 波動與駐波、13 反射折射與都卜勒，以及11 馬克士威與電磁波的橫波概念。

痛點：光有時走直線，有時卻繞過邊緣

用光線畫鏡片成像很成功，容易讓人以為光永遠沿無限細的直線前進；但把孔徑縮到接近波長，光會向陰影區散開，兩條路徑還能互相增強或抵消。反過來，若任何鏡片問題都從完整電磁場開始算，又會把簡單的方向關係埋在不必要的數學裡。

真正要學的是模型選擇。幾何光學是波動光學在波長遠小於元件尺度時的近似，不是另一種互相排斥的真理。折射、全反射、透鏡與雙狹縫也不是四張公式卡：它們都受界面相位連續、光程差與邊界條件控制。符號約定若沒有先固定，像距與放大率的正負還會讓同一題出現相反解讀。

量測上也要區分「沒有折射光」與「儀器沒看到」。全反射是理想平滑界面的邊界解；粗糙表面、吸收介質或把另一材料貼近界面，都可能讓能量以散射或漸逝場耦合離開。課內公式建立第一層門檻判讀，不保證任何光纖彎折與接頭都零損耗。

白話直覺：大尺度追方向，小尺度追相位

可把幾何光學想成只記錄光束中心的路線，波動光學則連每條路徑累積多少相位都記下來。比喻到此為止；折射率（refractive index）定義為 n = c/v，無單位，其中真空光速 c 與介質相速度 v 的單位都是 m/s。n 較大表示相速度較慢，不表示光的頻率在界面改變。

司乃耳定律（Snell's law）為 n1 sin θ1 = n2 sin θ2，角度由法線量起且無單位。從 n1 > n2 的光密介質射向光疏介質時，若入射角超過臨界角 θc = arcsin(n2/n1)，會發生全反射（total internal reflection）。這是光纖以纖芯、包層折射率差限制光路的基礎，但真實光纖仍有彎曲與材料損耗。

薄透鏡使用 1/f = 1/so + 1/si，橫向放大率 M = −si/so。焦距 f、物距 so、像距 si 的 SI 單位都是 m，M 無單位。本頁 widget 以 cm 輸入但比例不變。約定 f > 0 是凸透鏡、f < 0 是凹透鏡；si > 0 是另一側的實像，si < 0 是同側虛像；M < 0 倒立，M > 0 正立。

繞射（diffraction）與干涉都來自波的疊加。楊氏雙狹縫的相鄰亮紋間距 Δy = λD/d，其中波長 λ、屏幕距離 D、縫距 d 與 Δy 的 SI 單位都是 m。偏振（polarization）描述橫波電場的振動方向；相干（coherence）表示相位關係在觀察期間穩定。相干光才會留下穩定條紋，單色卻不保證兩束光一定相干。

來源：01-普通物理-下 第 2 章 §2.1–§2.3；放大率與像距符號採本課規格的標準約定。

推導：界面相位連續，路徑差決定亮暗

第一步，折射。光跨過靜止界面時頻率 f 不變，但速度從 v1 改成 v2，所以 λ1 = v1/f、λ2 = v2/f。沿界面的相位必須處處連續，使波向量的平行分量相等：k1 sin θ1 = k2 sin θ2。用 k = 2π/λ 與 λ = c/(nf) 代入，消去共同的 2πf/c，便得 n1 sin θ1 = n2 sin θ2。

第二步，臨界角。折射角最大為 90°，令 sin θ2 = 1，司乃耳定律給 sin θc = n2/n1。只有 n1 > n2 時右側小於 1，臨界角才存在；若方向反過來，就不可能靠增加角度得到全反射。

第三步，雙狹縫。兩縫相距 d，遠方角度 θ 處兩條路徑的光程差近似 δ = d sin θ。建設性干涉要求 δ = mλ，其中 m 是整數。屏幕距離 D 遠大於條紋位置 y 時，小角度近似 sin θ ≈ tan θ = y/D，代入得 ym = mλD/d，相鄰 m 相差 1，因此 Δy = λD/d。δ、d、λ、y、D 皆以 m 表示，角度為無單位。

這個推導也給出比例檢查：λ 或 D 加倍，Δy 加倍；d 加倍，Δy 減半。若角度不小、屏幕太近或狹縫本身不夠窄，小角近似與忽略單縫包絡的模型會失準。孔徑 Da 的解析角極限量級 θmin ≈ λ/Da，單位 rad；口徑不可能在固定波長下提供無限解析力。

第四步，讀透鏡符號。由 1/si = 1/f − 1/so 解得 si = 1/(1/f − 1/so)，再以 M = −si/so 判斷方向與大小。當 so = f，分母為零，出射光平行而像在無窮遠；這是物理邊界，不應顯示成程式錯誤值。

對凸透鏡而言，so > 2f 產生倒立縮小實像，so = 2f 產生等大倒立實像，f < so < 2f 產生倒立放大實像，so < f 則產生正立放大虛像。凹透鏡 f < 0 時，在本頁實物約定下總是得到正立縮小虛像。這些分類不是另背五條規則，而是 si 與 M 的符號、絕對值共同翻譯。

數值實例：同一組預設值走過三種模型

透鏡模式取 f = 10 cm、so = 30 cm。1/si = 1/10 − 1/30 = 1/15，所以 si = 15.000000 cm；M = −15/30 = −0.500000，即倒立、縮小、可投到光屏的實像。若 so = 20 cm，像距 20 cm 且 M = −1；若 so = 5 cm，像距 −10 cm、M = +2，成為正立放大虛像。

折射模式取 n1 = 1.50、n2 = 1.00、θ1 = 30°。sin θ2 = 1.5⋅0.5 = 0.750000，θ2 = 48.590378°；臨界角 θc = arcsin(1/1.5) = 41.810315°。因 30° 尚未超過臨界角，所以仍有折射光；調到 45° 則全反射。

雙狹縫模式取 λ = 500 nm、d = 100 µm、D = 1.00 m。換成 SI 後 Δy = (500×10−9)(1)/(100×10−6) = 0.005000 m = 5.000000 mm；第一亮紋小角度 θ1 = λ/d = 0.005000 rad = 0.286479°。三組數字都與 widget 預設一致。

若把 d 加倍為 200 µm，Δy 會精確減半為 2.500000 mm；若只把 D 加倍為 2.00 m，Δy 則加倍為 10.000000 mm。另以 λ = 500 nm、口徑 0.10 m 估算，θmin ≈ 5.000000 × 10−6 rad，說明放大影像不能突破孔徑已失去的角度細節。

自由實驗：透鏡、折射與雙狹縫

選擇模型後調整控制量，觀察像的正倒與虛實、是否全反射，或條紋間距如何依比例改變。所有控制保留，方便比較三套模型的變數。

不要混淆

  • 折射率 n 是速度比且無單位，本身不是速度，也不是光強度。
  • 全反射只可能從光密到光疏；從光疏到光密沒有臨界角。
  • Δy 式中的 d 是兩縫中心距，縫寬控制的是單縫繞射包絡。
  • 幾何光學是波長遠小於元件尺度的近似，不是與波動光學互斥的理論。
  • 繞射與干涉都源於疊加，只是對有限波源或連續孔徑的慣用名稱不同。
  • 偏振是橫波電場方向；空氣中的縱向聲波沒有這種偏振。
  • 單色只表示頻譜窄，相干還要求兩束光的相位關係穩定。

可觀察證據

用什麼儀器／實驗量：用光具座、凸透鏡與光屏量物距及像距；用半圓玻璃磚、雷射筆與量角器量入射角、折射角和折射光消失的臨界角；用雷射照雙狹縫片，以尺量牆上的多個條紋總距離再除以間隔數。

能證明什麼：多組 1/so 與 1/si 可支持薄透鏡關係，角度資料可支持司乃耳定律與全反射門檻；條紋間距隨 D、λ、d 的比例變化，能支持光的相干疊加並反推出雷射波長。

不能證明什麼：雙狹縫條紋本身不能證明光子逐顆通過哪一縫，那需要單光子實驗與更嚴格的偵測。薄透鏡量測也不能證明任何鏡片都沒有厚度或像差；大孔徑、厚透鏡與寬頻光會偏離這個近似。

條紋清晰也只能支持兩路光在量測時間內具有足夠相干性，不能證明光源在所有時間尺度上完全單色；任何波長反推都要納入縫距、屏距與尺讀值的不確定度。

連到哪門課

全反射與相干直接服務光纖通訊、光電工程和同調接收；繞射與解析力也銜接天線、雷達與成像系統。孔徑如何形成頻域圖樣，見工程數學先修 10 傅立葉分析；光纖模態、像差修正與光學系統設計留給後續專業課。
