12・從一個點的振動走向整條線的波

波動與駐波：邊界條件挑出能留下來的頻率

振動描述一個位置隨時間往返，波則讓相同狀態依序傳到鄰近位置。這章從行進波的速度與方程出發，再看兩個反向波如何形成固定的節點，最後算出弦為何只能在離散頻率共鳴。

這章假設已懂：06 簡諧運動與共振、01 運動學的週期與頻率。

痛點：看見波形移動，卻分不清究竟是什麼在前進

甩動繩端時，凸起沿繩前進，但每一小段繩只在原位置附近上下動。若把「波前進」誤當成「物質整批前進」，聲波、電磁波與傳輸線上的訊號便會全部混在一起。真正沿空間傳遞的是擾動、相位與能量；介質質點的瞬時速度是另一個物理量。

另一個難點是駐波看似不動，卻不是沒有運動。每個波腹仍在振盪，只是節點永遠不動，整個空間圖樣不向左或向右搬移。吉他弦為何只出現基頻與整數倍諧波，也不是驅動器任意規定，而是固定端要求位移永遠為零。若不把邊界條件寫進方程，就只會背答案而看不出量子能階的相同邏輯。

軟體直覺可幫忙拆開兩層狀態：把每個位置 x 想成陣列索引，每格都有自己的 y 與速度；更新規則卻會讀取鄰近格的曲率，因此局部變化逐格傳開。只看某一格的時間序列會看見振動，只看同一時刻的全部格才看見波形。這個說法只是離散化提示，連續模型仍由位置與時間的偏導數描述。

白話直覺：像接力傳遞狀態，而不是搬運整條繩子

可以把波想成觀眾依序起身的人浪：圖樣繞場前進，個人只在座位處上下。比喻到此為止；精確的行進波（traveling wave）可寫成 y(x,t) = A cos(kx − ωt + φ)。y 與振幅 A 的 SI 單位是 m，位置 x 是 m，時間 t 是 s，相位 φ 無單位；波數 k 的單位 rad/m，角頻率 ω 的單位 rad/s。

波長 λ 是相位重複一次的空間距離，單位 m；頻率 f 是每秒循環數，單位 Hz；週期 Tp = 1/f，單位 s。定義 k = 2π/λ、ω = 2πf，因此波速 v = fλ = ω/k，單位 m/s。這裡用 Tp 表示週期，避免與弦張力 T 混淆。

弦上波速 v = √(T/μ)。張力 T 的單位 N，線密度 μ 的單位 kg/m，所以 T/μ 的單位是 m²/s²，開根號後正是 m/s。這個模型假設弦均勻、細而柔軟、振幅小且張力近似固定；粗硬弦、高振幅或張力隨時間明顯變動時，高階頻率會偏離理想整數倍。

疊加原理（superposition principle）說線性介質中各波的位移直接相加。同相時形成建設性干涉，反相時形成破壞性干涉。它並不表示兩波碰面後消失；相遇期間總位移可能為零，分開後兩個行進波仍各自延續。

來源：01-普通物理-下 第 1 章 §1.1–§1.3；弦波速採本課規格補充的標準結果。

推導：從二階偏導數到固定端的離散模態

第一步，驗證波動方程。先忽略相位，令 y = A cos(kx − ωt)。對時間微分兩次得 ∂²y/∂t² = −ω²y；對位置微分兩次得 ∂²y/∂x² = −k²y。代入 ∂²y/∂t² = v²∂²y/∂x²，兩側消去 −y，得到 ω² = v²k²，因此 v = ω/k = fλ。y 與 A 是 m，兩個二階導數單位皆為 m/s²，等式量綱一致。

第二步，讓兩個反向波相加。A cos(kx − ωt) + A cos(kx + ωt) 由和差化積變為 2A cos(kx)cos(ωt)。若固定端選擇空間原點為節點，等價地寫成 y = 2A sin(kx)cos(ωt)。空間因子 sin(kx) 與時間因子 cos(ωt) 完全分離，所以 sin(kx) = 0 的位置在任何時刻都保持零，這些位置稱節點（node）；絕對振幅最大的地方稱波腹（antinode）。

第三步，施加邊界條件。弦長為 L，兩端固定要求 y(0,t) = 0 且 y(L,t) = 0。第一條已由 sin 形式滿足；第二條要求 sin(kL) = 0，故 kL = nπ，其中 n = 1, 2, 3, …。由 k = 2π/λ 得 λn = 2L/n，再由 v = fλ 得 fn = nv/(2L)。L 與 λn 單位為 m，fn 單位為 Hz。第 n 模態有 n + 1 個節點與 n 個波腹；能留下的頻率離散，完全是固定端篩選的結果。

節點數可以直接從解讀出。sin(nπx/L) 在 x/L = 0, 1/n, 2/n, …, 1 時為零，端點也算在內，所以共有 n + 1 個；相鄰零點之間各有一次絕對值最大，共 n 個波腹。這是空間位置的陳述，與某一瞬間 cos(ωt) 恰好為零、整條弦同時通過平衡位置不同。

極端檢查也很有用：L 加倍而 T、μ、n 不變時，fn 減半；T 加四倍時 v 與 fn 只加倍；μ 加四倍時兩者減半。驅動頻率可以連續改動，但不在 fn 附近時，來回反射的波無法穩定同相累積。

真實弦受到短暫撥動時通常不是單一正弦，而是多個允許模態同時存在。線性方程讓各模態分別演化後再相加，因此音色由各階振幅與衰減率決定，音高主要由基頻決定。這也把本章連到傅立葉分析：複雜形狀可以拆成允許的空間正弦成分，但邊界先決定有哪些基底可用。

數值實例：一公尺弦的基頻與第二諧波

取 widget 預設值 L = 1.00 m、T = 100 N、μ = 1.0 g/m = 0.001 kg/m、n = 1、x/L = 0.5。波速 v = √(100/0.001) = √100000 = 316.227766 m/s。基頻波長 λ1 = 2L = 2.000000 m，頻率 f1 = 316.227766/2 = 158.113883 Hz；驗算 f1λ1 = 316.227766 m/s，與 v 相同。

週期 Tp = 1/f1 = 0.006325 s，角頻率 ω = 2πf1 = 993.458827 rad/s。觀察位置的空間因子 sin(nπx/L) = sin(π⋅0.5) = 1.000000，所以中央是波腹。改為 n = 2 時，λ2 = 1.000000 m、f2 = 316.227766 Hz，而 sin(2π⋅0.5) = 0.000000，中央變成節點。若張力改為 400 N，v = 632.455532 m/s，基頻成為 316.227766 Hz；張力四倍只使頻率兩倍，符合開根號關係。

若只把弦長增到 2.00 m，其餘維持預設，波速仍是 316.227766 m/s，因為 v 只由 T 與 μ 決定；基頻波長改為 4.000000 m，基頻降到 79.056942 Hz。這組對照把「介質中的波速」與「特定邊界容許的頻率」分開：改長度不會讓局部介質傳得更慢，只是完整往返路徑變長。

自由實驗：弦上的駐波模態

調整弦長、張力、線密度、諧波與觀察位置。比較波速、共振頻率、節點數，以及同一位置在不同模態中為何改變身分。

不要混淆

  • 頻率 f 的單位是 Hz，角頻率 ω 的單位是 rad/s，數值相差 2π。
  • 波長 λ 是空間週期，波數 k = 2π/λ 是每公尺累積的相位，不只是 1/λ。
  • 波速是擾動的傳播速度；弦上質點只上下振動，並未以 v 沿弦奔跑。
  • 駐波的平均淨能流為零，不代表弦上各點沒有動能與彈性位能的交換。
  • 共振頻率由介質與邊界條件決定；驅動源只選擇並激發模態。
  • 第 n 諧波有 n 個波腹；第 n 個泛音通常對應第 n + 1 諧波，編號不可混用。

可觀察證據

用什麼儀器／實驗量：把均勻弦的一端接振動器，另一端用砝碼提供可計算的張力，以訊號產生器掃頻；用頻率計讀 f1、f2、f3，再用尺量相鄰節點距離以取得 λ/2。更換粗細不同且已量出單位長度質量的弦，可比較 v 對 μ 的變化。

能證明什麼：量到各階共振頻率成整數比、節點距離配合 v = fλ，且張力四倍時波速約兩倍，可在實驗誤差內支持 fn = nv/(2L) 與 v = √(T/μ)。同一位置隨 n 改變而成為節點或波腹，也支持空間因子 sin(nπx/L)。

不能證明什麼：單一模態不能證明所有線性波都服從同一波動方程，也不能證明真實弦完全柔軟。弦的抗彎剛度、支點損耗與非均勻線密度會使高階頻率略偏離整數倍；量到偏差時，不能立刻把它歸因於公式錯誤。

實驗還必須記錄張力、有效弦長與線密度的不確定度，否則頻率接近整數比只是一致性線索，無法判斷微小偏差是否超出量測誤差。
