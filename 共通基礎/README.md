# 共通基礎

本目錄收錄**多個工程與科學領域共用**的數理與科學基礎筆記。這些科目不專屬於任何單一學科，而是電機、電子、機械、大氣科學等領域都會先用到的共同底層，因此從各領域抽出、集中於此，由各科的學習計畫連結過來。

風格與其他學科一致：繁體中文、概論重點式、以文字為主不放圖、公式使用 LaTeX。
