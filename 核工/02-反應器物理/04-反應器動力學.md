# 反應器動力學（Reactor Kinetics & Dynamics）

> 名詞對照見 [中英名詞對照表 → 反應器動力學](../中英名詞對照表.md#反應器動力學)。

## 0. 本科定位

反應器動力學研究反應器功率如何隨時間變化——啟動、停機、功率調整與事故情境。核心方程是**點動態方程（Point Kinetics Equations, PKE）**——一組耦合常微分方程描述中子密度與延遲中子先驅核（delayed neutron precursors）濃度的動態演化。

**沒有延遲中子的世界**：每次分裂的瞬發中子平均壽命在熱中子反應器中約 $10^{-4}$ 秒。如果反應度增加 0.1%（$\rho = 0.001$），在沒有延遲中子的情況下，功率將以 $e^{t/\tau}$（$\tau = \Lambda/\rho = 10^{-4}/0.001 = 0.1$ s）的時間常數暴升——僅 1 秒就增長 $e^{10} \approx 22,000$ 倍。任何機械控制系統（控制棒從接到訊號到完全插入需要 ~1–2 秒）都來不及反應。

**延遲中子是自然的禮物**：分裂碎片中有幾種原子核（如 Br-87 半衰期 55.6 s、I-137 半衰期 24.5 s）在 β⁻ 衰變後處於激態中子發射能態——它們的衰變半衰期從 0.2 秒到 55 秒不等。這些延遲中子雖然只佔所有分裂中子的 0.65%（$\beta = 0.0065$），但它們把反應器的動力學時間尺度從微秒拉長到秒級，使機械控制成為可能。這 0.65% 的微小比例，是所有人類控制核反應的物理基礎。

## 1. 點動態方程

### 1.1 方程推導的物理

將反應器視為空間中一個「點」——假設中子通量的空間分布形狀不隨時間改變（只有振幅變），這種點反應器模型對大多數非事故暫態的準確度足夠。

$$\frac{dP}{dt} = \frac{\rho - \beta}{\Lambda}P + \sum_i \lambda_i C_i,$$

$$\frac{dC_i}{dt} = \frac{\beta_i}{\Lambda}P - \lambda_i C_i.$$

- $P$：功率（正比於中子密度），MW 或相對值
- $\rho = (k-1)/k$：反應度（reactivity），無因次，常用 pcm（$10^{-5}$）或「元」（dollar）表示
- $\beta = \sum\beta_i$：延遲中子總分率（對 U-235 熱分裂 ~0.0065 = 650 pcm）
- $\beta_i$：第 $i$ 組延遲中子的分率（通常分為 6 組擬合實驗數據）
- $\lambda_i$：第 $i$ 組先驅核的衰變常數（= $\ln 2/t_{1/2}$）
- $\Lambda$：中子平均世代時間（mean generation time = 從中子出生到被吸收前存活的平均時間。對熱中子反應器 $\Lambda \sim 10^{-4}$ s——主要花在減速過程中被散射但未被吸收的時間。注意：$\Lambda$ 與中子平均壽命 $l$ 的關係為 $\Lambda = l/k$）

### 1.2 反應度的「元」

反應度 $\rho$ 與 $\beta$（延遲中子分率）的比值定義了反應度的自然單位——**元（dollar）**與**分（cent）**：

$$\text{反應度 (元)} = \frac{\rho}{\beta}, \quad \text{反應度 (分)} = 100 \times \frac{\rho}{\beta}.$$

**$\rho = \beta$ = 1 元 = 瞬發臨界（prompt critical）**——單靠瞬發中子就達到 $k=1$。此狀態下，延遲中子不再主導動力學 → 中子密度以瞬發中子的時間尺度暴升。這是所有反應器操作必須絕對避免的禁區——Chernobyl 災難的本質就是反應器短暫進入瞬發臨界。

正常操作中，反應度的變化非常小——控制棒全行程的反應度價值約數千 pcm（數元），但日常功率調整的反應度變化僅數十 pcm（十分之幾元）。反應器操作員在反應度上是非常謹慎的。

### 1.3 瞬發跳升（Prompt Jump）

當反應器處於次臨界延遲狀態（$0 < \rho < \beta$），注入一個小幅正反應度後的動態：

1. **瞬發跳升**（~毫秒）——瞬發中子立即反應，功率快速跳到一個由延遲中子先驅核存量決定的新「準穩態」水平。跳升幅度 $\approx 1/(1 - \rho/\beta)$——當 $\rho$ 趨近 $\beta$ 時跳升倍數趨近無限大
2. **延遲主導的緩慢上升**——之後功率的增長速率由先驅核的衰變節奏控制（秒級），操作員有充足時間觀察並調整控制棒位置

瞬發跳升的物理：瞬發中子從一個平衡跳到另一個更高的準平衡只需數毫秒——這不是危險的（只要 $\rho < \beta$，準平衡後的增長仍是緩慢的延遲主導），但操作員會在儀表上看到功率在數毫秒內跳升了一小截。

## 2. 反應度回饋——自然的煞車

反應器的功率不會隨著反應度增加而無限制上升，因為存在**固有的負回饋**機制——功率上升觸發的物理效應自動降低反應度。這些回饋是反應器**固有安全**的基礎——不依賴控制系統或操作員的介入。

### 2.1 都卜勒回饋（Doppler Feedback）——最重要、最快

燃料溫度升高 → 原子核的熱運動速度增加 → **都卜勒拓寬（Doppler broadening）**：U-238 的共振吸收峰的寬度隨溫度增加（峰的形狀變矮變胖）。關鍵是：峰的**面積**（共振積分）不變，但形狀變矮胖 → 在共振峰邊緣的中子（原本能量剛好偏離峰中心而不被吸收）現在落入拓寬後的峰內 → 吸收增加 → 反應度下降。

都卜勒回饋的時間常數極短（~0.1–1 s——燃料溫度隨功率上升的速度），且**永遠是負的**（燃料溫度不可能隨功率上升而下降）。它是反應器最立即、最可靠的固有安全煞車。所有輕水反應器都依賴都卜勒回饋作為事故瞬態的第一道防線。

### 2.2 冷卻劑溫度/密度回饋

冷卻劑（水）的溫度上升 → 水密度下降 → 水分子數減少 → 中子減速（慢化）效果變差 → 中子譜變硬（平均能量上升）→ 反應度變化。

- **PWR**：設計保證**負冷卻劑溫度係數**。水密度下降→減速變差→熱中子較少被有效減速→吸收增加（共振吸收）→淨反應度下降。但需注意：PWR 的硼酸化學補償會使溫度係數趨近零甚至偏正（水密度下降→水中硼濃度也下降→吸收減少→部分抵銷負回饋）。運轉中必須監控硼濃度以確保整體溫度係數為負
- **BWR**：空泡係數（void coefficient——冷卻劑沸騰產生的蒸氣氣泡對反應度的影響）是 BWR 設計最關鍵的安全參數之一。BWR 正常操作於空泡狀態（爐心上部沸騰），空泡的淨效應是降低反應度（氣泡→減速劑減少→中子譜變硬→共振吸收增加），因此 BWR 的空泡係數設計為負——功率上升→更多沸騰→更多空泡→反應度自動下降，形成穩定的負回饋

### 2.3 Chernobyl RBMK 的正空泡係數——設計的致命缺陷

正常的輕水反應器（PWR/BWR）中，水既是冷卻劑也是中子減速劑——水沸騰→氣泡取代水→減速劑減少，而水本身對熱中子有顯著的吸收（氫的散射截面雖然大，但水的吸收截面也不可忽略）。在 PWR/BWR 的燃料棒緊密排列幾何下（水與燃料的體積比偏小→水是相對稀缺的減速劑），水沸騰的淨效應是減速不足→中子譜變硬→共振吸收增加→反應度下降（負回饋）。

RBMK 的石墨慢化+水冷卻設計：石墨是主要減速劑（水只是冷卻劑，減速角色次要，但吸收角色仍然存在）。水沸騰→水密度下降→水中氫對中子的吸收**減少**更多（相對於減速損失，在石墨已提供大量減速的背景下，水的額外減速貢獻有限），淨效應是反應度**增加**（正空泡係數）。在低功率下此效應更強——Chernobyl 事故的初始條件就是反應器被刻意壓到極低功率進行實驗，此時冷卻水幾乎不沸騰（空泡極少），加上操作員為維持功率而抽出大量控制棒（反應度極高），一旦冷卻水開始沸騰形成空泡，正回饋迅速將空泡係數效應放大。

## 3. 碩士層級延伸

### 3.1 空間相關動力學

點動態模型假設中子通量的空間分布形狀保持不變——這在控制棒快速移動、或反應器局部（如一個燃料束）發生不正常暫態時不成立。空間動力學將反應器離散為三維網格，每一格點都有各自的點動態方程並與相鄰格點通過中子擴散（或輸運）耦合。此耦合大幅增加了計算量——從解數個 ODE 變成解數萬個耦合 PDE——但對某些事故（如控制棒彈出事故 REA——一根控制棒在壓力下被機械性彈出爐心，瞬間移除大量反應度，局部功率暴衝）的準確分析不可或缺。

### 3.2 事故容錯燃料（ATF）的瞬態行為

Fukushima 後催生的 ATF 研發不只是提高護套的高溫蒸汽氧化抗性，還需重新評估其對反應器動力學的影響——不同護套材料的中子吸收截面不同（例如 FeCrAl 對熱中子的吸收截面比鋯合金大），為了維持相同的燃料週期長度，需要提高 U-235 濃縮度，這反過來改變了 $\beta$（不同分裂核種的延遲中子分率不同——Pu-239 的 $\beta = 0.0021$，只有 U-235 的 1/3）。ATF 燃料的動力學安全分析必須重新驗證所有設計基準事故下的瞬態行為。

## 4. 博士層級研究方向

- 多物理耦合的動態分析（中子動力學 + 熱流 + 燃料熱傳導 + 冷卻劑熱水力——全耦合的時域模擬以精準預測 RIA 控制棒彈出事故中燃料護套的應變。不同物理之間的時間尺度差異達十個數量級——中子 ~10⁻⁴ s、熱傳 ~10⁻¹ s、流體 ~1 s——對數值方法而言極具挑戰性）
- 先進反應器的動力學特殊性（熔鹽反應器 MSR：液態燃料循環意味著中子先驅核的一部分會隨燃料流動而被帶出爐心→爐心外的管線中也有中子源→傳統的點動態方程必須加入燃料對流項。鈉冷快中子反應器 SFR：中子平均壽命 ~10⁻⁷ s，比熱中子反應器短千倍——控制需求更為嚴格，但延遲中子仍然主導，因為 $\beta/\Lambda$ 才是關鍵比的分子）
