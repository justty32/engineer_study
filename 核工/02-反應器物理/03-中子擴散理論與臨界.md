# 中子擴散理論與臨界（Neutron Diffusion Theory & Criticality）

> 名詞對照見 [中英名詞對照表 → 中子擴散理論](../中英名詞對照表.md#中子擴散理論)。

## 0. 本科定位

這是反應器物理的入門核心課。把反應器內數以兆計的中子視為一個「族群」，用擴散方程描述其空間–能量分布，並回答核工最根本的問題：**鏈鎖反應能不能自我維持（臨界）？**

核心類比：中子在介質中的行為與**熱傳導**或**質量擴散**的數學結構完全相同——中子從密度高處往密度低處擴散、同時被吸收、並由核分裂產生新的中子。在熱傳課學到的所有 PDE 解法在這裡直接適用。

## 1. 中子擴散方程的推導

### 1.1 從中子守恆出發

對任意體積內的單能中子：

$$\frac{\partial n}{\partial t} = \text{產生率} - \text{吸收率} - \text{洩漏率}.$$

產生來自核分裂（$\nu\Sigma_f\phi$）與外加中子源 $S$。吸收 $=\Sigma_a\phi$。洩漏 = 從體積表面淨流出的中子數。假設中子流 $\mathbf{J}$ 大致正比於中子通量的負梯度（Fick 定律的類比：$\mathbf{J} = -D\nabla\phi$），得到擴散方程：

$$\frac{1}{v}\frac{\partial\phi}{\partial t} = D\nabla^2\phi - \Sigma_a\phi + \nu\Sigma_f\phi + S.$$

- $\phi = nv$：中子通量（neutrons/cm²·s）——每 cm² 每秒通過的中子數
- $D = 1/(3\Sigma_{tr})$：擴散係數（$\Sigma_{tr}$ 為傳遞截面——考慮散射的方向偏好後的有效截面）
- $\Sigma_a$：巨觀吸收截面（= $N\sigma_a$，$N$ 為原子密度），cm⁻¹
- $\nu\Sigma_f$：每 cm³ 分裂產生的中子數（$\nu$ = 每次分裂的平均中子產量 ~2.43 對 U-235）

### 1.2 穩態無源的簡化——Helmholtz 方程

穩態無外加源時，方程簡化為：

$$D\nabla^2\phi + (\nu\Sigma_f - \Sigma_a)\phi = 0,$$

或寫成 $\nabla^2\phi + B^2\phi = 0$，其中 $B^2 = (\nu\Sigma_f - \Sigma_a)/D$ 稱為**幾何曲率（geometric buckling）**。$B^2$ 僅取決於反應器的幾何形狀與邊界條件——這是特徵值問題：給定反應器尺寸與形狀，存在唯一的 $B^2$ 使上式有非零解。

### 1.3 臨界條件

無窮大介質（無洩漏）的增殖因數 $k_\infty = \nu\Sigma_f/\Sigma_a$。有限介質中，洩漏使有效增殖因數下降：

$$k_{\text{eff}} = \frac{k_\infty}{1 + L^2 B^2},$$

其中 $L^2 = D/\Sigma_a$ 為擴散長度（diffusion length）——中子在被吸收前平均淨位移的平方的 1/6。$L^2 B^2$ 是洩漏損失的無因次量。臨界條件 $k_{\text{eff}}=1$ 給出**臨界大小**——小於此的反應器無法達到臨界。

對球形反應器（最省中子的形狀——表面積/體積比最小）：$\nabla^2\phi + B^2\phi = 0$ 在球座標下的解 $\phi(r) \propto \sin(Br)/r$，要求通量在推斷邊界處為零 → $B = \pi/\tilde{R}$（$\tilde{R}$ = 實際半徑 + 推斷長度）。結合 $k_{\text{eff}}=1$ 的條件可以反推球形反應器的最小臨界半徑。

## 2. 增殖因數的六因子分解

對熱中子反應器，$k_{\text{eff}}$ 可分解為六個物理因子的乘積——這是反應器物理最經典的公式：

$$k_{\text{eff}} = \eta \varepsilon p f P_{FNL} P_{TNL}.$$

- **$\eta$（eta）**：燃料每吸收一個熱中子所產生的平均分裂中子數。$\eta = \nu\sigma_f/(\sigma_f + \sigma_c)$，其中 $\sigma_c$ 為捕獲截面（U-235：$\eta \approx 2.07$；Pu-239：$\eta \approx 2.11$——Pu-239 的 $\eta$ 略高，這就是它作為滋生燃料的基礎）
- **$\varepsilon$（快中子分裂因子，fast fission factor）**：快中子（分裂後約 2 MeV）在減速前能引發 U-238 分裂（U-238 對快中子有少量分裂截面）的放大倍數。通常 $\varepsilon \approx 1.02$–$1.08$——效應不大但不是可忽略的
- **$p$（共振逃脫機率，resonance escape probability）**：中子在減速過程中沒有被 U-238 的強共振吸收峰（主要在 6.7 eV、20.9 eV 等）捕獲的機率。這是對 U-238 含量最敏感的因子——燃料中 U-238 愈多（濃縮度愈低），$p$ 愈小。$p$ 通常在 0.7–0.9 範圍內。**都卜勒拓寬**使高溫下的共振峰變寬（面積不變但形狀變矮胖），增加共振吸收的機率 → $p$ 隨溫度下降。都卜勒回饋是反應器最重要的固有安全機制
- **$f$（熱中子利用因數，thermal utilization factor）**：熱中子被燃料吸收的比例（剩下的被慢化劑、結構材料、控制棒等吸收）。$f = \Sigma_a^{\text{fuel}}/(\Sigma_a^{\text{fuel}} + \Sigma_a^{\text{other}})$
- **$P_{FNL}$、$P_{TNL}$（快/熱中子不洩漏機率）**：中子還沒被吸收就從反應器邊界逃出的機率。大型反應器（洩漏相對小）這兩個因子接近 1。反應器愈小（例如研究用小型反應器），洩漏損失愈顯著，必須提高燃料濃縮度來補償

## 3. 反應度與反應器控制

### 3.1 反應度

$$\rho = \frac{k-1}{k} \quad \text{（無因次，常用 pcm = $10^{-5}$ 或「元 dollar」表示）}.$$

反應度是所有反應器操作的核心參數——控制棒進出、可燃毒物消耗、燃料燃耗、氙毒累積，全部用反應度來量化。

### 3.2 控制棒

含強中子吸收體（硼 B₄C、銀-銦-鎘 Ag–In–Cd 合金、鉿 Hf——鉿的每個同位素都有連續的大吸收截面，不像銀-銦-鎘只有幾條孤立共振峰）。控制棒插入 → 增加吸收 → $k$ 下降。**控制棒價值**（rod worth）表示控制棒從全抽出到全插入能帶走多少反應度（以 pcm 計）。控制棒價值受其在反應器中的位置影響——靠近中子通量峰值處（反應器中心附近）的控制棒價值最高。

### 3.3 可燃毒物（Burnable Poison）

新鮮燃料的過剩反應度最大（所有燃料都是新的，分裂產物尚未累積），隨著燃耗反應度逐漸下降。可燃毒物（Gd₂O₃ 釓氧、Er 鉺、硼）在燃料中隨著中子照射逐漸被消耗——其消耗速率與燃料反應度損失速率匹配，使整週期的控制棒位置保持合理範圍。沒有可燃毒物的話，壽命初期的控制棒必須插入很深，造成中子通量分布不均勻（控制棒周圍的燃料使用率低）。

### 3.4 氙毒（Xenon Poisoning）

Xe-135 是分裂產物 I-135（半衰期 6.6 hr）的 β 衰變子核，擁有所有核種中已知最大的熱中子吸收截面（$\sigma_a \approx 2.65\times 10^6$ barns——比 U-235 的分裂截面還大 4500 倍）。反應器功率變動後，I-135 的累積與衰減、Xe-135 的產生（來自分裂直接 + I-135 衰變）與消耗（中子吸收使其嬗變為 Xe-136 + 天然衰變半衰期 9.2 hr），這四個速率的動態交互作用使 Xe-135 濃度在功率下降後約 10 小時達到峰值——**氙毒峰值（xenon peak）**可大到使反應器無法重啟，必須等待 Xe-135 自然衰變（數十小時）。這是反應器操作中必須持續追蹤的關鍵考量——Chernobyl 事故的導火線之一就是操作員在氙毒暫態期間試圖強行提升功率，將過多的控制棒抽出。

## 4. 碩士層級延伸

### 4.1 多群擴散理論

單群模型假設所有中子能量相同——這對熱中子反應器只是粗略近似。多群擴散將中子能譜分成數個能量群（典型 2–10 群）——快中子群（> 1 MeV）、中速群、熱中子群（< 1 eV）。各群之間有散射耦合矩陣，從高能群往低能群散射（減速），解聯立擴散方程組。這大幅提升了對非均勻反應器（燃料+慢化劑交錯排列）的準確度。

### 4.2 中子輸運理論

擴散理論假設中子流正比於通量梯度（Fick 定律）——這在強吸收體附近、邊界附近、或真空界面處不成立。中子輸運方程（Boltzmann 方程）直接追蹤中子在空間、能量、角度三個維度的分布函數，不放棄角分布資訊。求解方法：
- **離散座標法 $S_N$**：將角度變數離散化為有限個方向（$S_2, S_4, S_8, \ldots$），把輸運方程轉成一組耦合 PDE
- **蒙地卡羅法**：隨機抽樣大量中子的個別歷史（從出生、散射、到吸收或洩漏），統計得到通量分布。MCNP、OpenMC、Serpent 等蒙地卡羅碼是反應器設計與屏蔽分析的主力。蒙地卡羅法的收斂速度是 $1/\sqrt{N}$（中央極限定理）——要提升十倍精度需要一百倍的粒子數

## 5. 博士層級研究方向

- 高傳真多物理耦合（中子輸運 + 熱流 CFD + 燃料性能——不同物理之間透過隨時間變化的溫度場與密度場耦合，精準模擬事故暫態）
- 先進反應器（熔鹽反應器 MSR 的液態燃料循環——中子先驅核會隨燃料流動而重新分布，傳統的點動態模型必須修正以包含燃料對流項）
- 蒙地卡羅法的變異數降低技術與 GPU 加速
