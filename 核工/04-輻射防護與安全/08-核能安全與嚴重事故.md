# 核能安全與嚴重事故（Nuclear Safety & Severe Accidents）

> 名詞對照見 [中英名詞對照表 → 核能安全與嚴重事故](../中英名詞對照表.md#核能安全與嚴重事故)。

## 0. 本科定位

核安是核工與社會對話的最重要語言——一次事故就足以凍結一個國家的核能發展數十年。核安的核心哲學是**深度防禦（defense-in-depth）**——多層獨立保護屏障以確保任何單一失效（設備故障、人為錯誤、外部事件）都不會導致放射性物質釋放。每一層防護都必須獨立於其他層（避免共因失效 common cause failure——一個事件同時打穿多層保護）。

三道實體屏障（由內而外）：燃料護套（鋯合金管包住 UO₂ 芯塊——保留 99% 以上的分裂產物）→ 反應器冷卻劑壓力邊界（反應器壓力槽 RPV + 一次側管路——高溫高壓水的最後圍堵）→ 圍阻體（containment——鋼筋混凝土結構 + 鋼內襯，設計壓力足以容納 LOCA 事故中瞬間閃蒸為蒸汽的大量冷卻水而不破裂）。

## 1. 設計基準事故（DBA）

設計基準事故是反應器設計時必須用確定論分析證明能安全承受的事故情境——在最壞的單一失效假設下，加上最保守的初始條件，仍能滿足安全接受準則。

**LOCA（冷卻水流失事故）**：一次側大管破口（guillotine break，雙端完全斷裂——假設最大口徑的管線完全斷開），高溫高壓冷卻水急速流失，爐心水位下降 → 燃料裸露 → 衰變熱無法帶走 → 護套溫度上升。

緊急爐心冷卻系統（ECCS）的自動保護序列：
1. **高壓注水 HPSI**：反應器冷卻水泵仍在運轉（破口初期，壓力仍高），從蓄壓槽注入硼水（硼是中子吸收體→確保次臨界，雖然控制棒已自動插入）
2. **蓄壓槽（accumulator）**：大型氮氣加壓水槽——壓力降至 ~4 MPa 時被動注入（不需電力、不需泵，純靠氣體壓力驅動）
3. **低壓注水 LPSI**：壓力降至足夠低後，低壓泵從圍阻體集水槽吸水循環注入爐心

安全接受準則（PWR 的標準）：燃料護套最高溫度 < 1204°C（超過此溫鋯–水反應急劇加速，產生大量氫氣）；護套最大氧化 ≤ 總厚度的 17%（避免護套過度脆化，即使在冷卻恢復後也無法維持燃料棒完整性）；爐心保持可冷卻幾何（無熔融坍塌堵塞冷卻劑流道）。

## 2. 三件改變核安歷史的事故

### 2.1 TMI-2（1979，美國三哩島）

一連串的設備故障 + 控制室儀表設計誤導 + 操作員誤判（以為穩壓器水位過高關閉了高壓注水，實際上水位過高是因蒸汽在穩壓器頂部而非液態水——操作員被儀表誤導而手動關閉了正在拯救爐心的自動安全系統）→ 爐心部分裸露 → 燃料過熱破損 → 爐心部分熔毀。結果：圍阻體成功包容幾乎所有放射性物質（只有微量惰性氣體與碘釋放），無人員傷亡，但爐心完全摧毀。後果：全面檢修控制室人因工程（儀表的資訊呈現必須讓操作員一眼就能判斷爐心水位與冷卻狀態而非推理間接參數）、建立緊急操作程序（EOPs）、成立 INPO（美國核能運轉協會——業界自我監管與經驗分享）。

TMI-2 的核心教訓不是設備設計，而是**人機介面與操作員訓練**——安全系統按設計運作，但操作員基於錯誤資訊取消了自動保護。

### 2.2 Chernobyl（1986，蘇聯烏克蘭）

RBMK 反應器的兩個致命設計缺陷：(1) **正空泡係數**——冷卻水沸騰產生蒸氣氣泡（void）→減少中子吸收（水是中子減速劑也是吸收體，氣泡讓減速變差但吸收也減少——在 RBMK 的石墨慢化+水冷卻設計下，淨效應是反應度**增加**，形成正回饋）；(2) **控制棒設計缺陷**——控制棒尖端有石墨隨動體（graphite follower），插入初期反而**擠掉**下方水道中的水（水的吸收截面大），**短暫增加反應度**後才開始吸收中子。兩個致命特質疊加 + 深夜測試（操作員對低功率下的反應器行為不熟悉、關閉多個安全系統以進行實驗）→ 功率暴升 → 燃料碎裂 → 蒸汽爆炸摧毀反應器 → 石墨慢化劑暴露於高溫空氣中燃燒（石墨大火持續 10 天，將放射性核種帶到高空擴散到全歐洲）。

Chernobyl 的核心教訓：(1) **本質安全設計**——反應器的物理特性必須保證在任何操作狀態下都有負回饋（而不是仰賴操作員的判斷與控制系統的介入）；(2) **安全文化**——操作人員絕不應為了完成實驗而關閉安全系統。Chernobyl 後全球所有 RBMK 反應器都進行了設計改良（降低空泡係數、控制棒提速、增加額外的快速停機系統），但這種設計已在新建反應器中被永久放棄。

### 2.3 Fukushima Daiichi（2011，日本）

外部事件超越設計基準——9.0 地震自動停機（控制棒插入→成功），但海嘯（14–15 m，遠超設計海嘯高度 5.7 m）淹沒所有備用發電機與配電盤。全廠停電（station blackout）→ 喪失所有冷卻能力（連電池供電的儀表也逐漸耗盡）→ 爐心熔毀（三座反應器）→鋯–水反應產生大量氫氣→氫氣洩漏至反應器廠房頂部累積→爆炸摧毀廠房上部結構（氫氣爆炸不是核爆——核反應早在停機時就終止了，爆炸是化學反應）。放射性釋放主要來自：(1) 圍阻體洩壓過程中排出的氣體（刻意排氣以避免圍阻體超壓破裂，但排氣帶著微量放射性）；(2) 用過燃料池冷卻喪失後的燃料升溫（幸未達鋯火點火溫度）。

Fukushima 的衝擊：全球重新評估極端外部事件（地震+海嘯+洪水+極端氣候）超越設計基準的可能性與後果。催生了**被動安全系統**的大規模部署——AP1000 壓水反應器在停機後 72 小時內不需任何電力或操作員介入（所有冷卻來自重力、自然循環、與蒸發冷凝），非能動餘熱排除熱交換器（PRHR HX）利用爐心與圍阻體內大水池之間的密度差驅動自然循環。

## 3. 嚴重事故緩解策略（Severe Accident Mitigation）

爐心已熔毀時仍有一套策略減輕後果：
- **爐內熔融物滯留 IVR（In-Vessel Retention）**：刻意將反應器壓力槽外側淹水（圍阻體淹水），利用壓力槽外壁的池沸騰冷卻將熔融爐心保留在槽內——避免熔融物穿出壓力槽與混凝土反應。AP1000、APR1400 設計具此能力
- **爐心捕集器（core catcher）**：在壓力槽下方設置一個犧牲性容器（氧化鋯 + 氧化鐵 + 混凝土的特殊配方），熔融物從壓力槽落入捕集器被冷卻與稀釋。EPR（歐洲壓水式反應器）採用
- **過濾式圍阻體排氣**：若圍阻體壓力超過設計值被迫排氣，排氣先經過濾器（如金屬纖維 + 活性碳）去除大部分放射性粒徑小的氣膠與碘後才釋放到大氣

## 4. 機率安全評估（PSA）

確定論分析只能針對預設的情境，PSA（Probabilistic Safety Assessment）用機率量化「任何可能的」事故序列的發生機率與後果。工具：**事件樹（Event Tree）** 從初始事件（如 LOCA）出發，沿系統的成功/失敗分岔追蹤所有可能的結果；**故障樹（Fault Tree）** 從頂事件（如「ECCS 注入失敗」）向下追溯所有可能的原因組合（泵失效 + 閥卡住 + 操作員未及時啟動備援 OR …）。

PSA 的三級：Level 1（爐心損壞頻率 CDF——安全系統全數失效導致爐心熔毀的機率，現代反應器目標 < $10^{-5}$/爐年）；Level 2（放射性從圍阻體釋放的頻率與量——考慮圍阻體的行為與可能的失效模式）；Level 3（公眾健康後果——釋放後的擴散、劑量、健康效應與疏散措施的效果）。PSA 的成果用於排定風險管理資源的優先級、識別設計中的脆弱環節、並向法規單位證明風險符合安全目標。

## 5. 碩士/博士層級延伸

碩士：**嚴重事故管理指引 SAMG**（在所有預防措施都失敗後，操作員仍有一套科學依據的策略來減輕後果——如刻意淹水圍阻體、啟動氫重組器、控制排氣時機）、**氫氣管理**（被動自催化氫重組器 PAR——鉑或鈀塗層的陶瓷基材可在常溫下將 H₂ + O₂ → H₂O 而無火焰，安裝在圍阻體內防止氫氣累積到爆炸濃度）。博士：**熔融物–混凝土交互作用 MCCI** 的機制模型（高溫熔融物與混凝土底板接觸→混凝土分解產生 CO₂ 與 H₂O→與金屬反應產生 H₂ 與 CO——這些可燃氣體進一步增加圍阻體壓力，若能準確定量可導出更好的 IVR 與捕集器設計）、**多單元 PSA**（Fukushima 教訓——傳統 PSA 只分析單一反應器，但極端外部事件可能同時打擊廠區內多座反應器與共用設施如用過燃料池，風險不是獨立相加而是可能互相牽連）。
