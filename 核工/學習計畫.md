# 核工（Nuclear Engineering）學習計畫

## 本系簡介與學習脈絡

核工（核子工程，Nuclear Engineering）研究的是：如何理解原子核層級的能量釋放與輻射，並把它安全、可控地用在發電、醫療、工業與科學上。它不是單一學科，而是把幾個工程支柱「縫」在一起：

- **物理面**：原子核怎麼分裂／融合、釋放多少能量、放出哪些粒子（中子、γ、β、α）。
- **中子面（反應器物理）**：把大量中子在材料裡的行為當成一個族群來描述，問「鏈鎖反應能不能維持？臨界條件是什麼？功率怎麼分佈？」這是核工最核心、也最獨特的部分。
- **熱流面（核熱流）**：分裂放出的能量是熱，必須靠流體把它帶走，否則燃料會熔毀。這牽涉熱傳、流體力學與兩相沸騰。
- **輻射與防護面**：輻射怎麼跟物質作用、怎麼偵測它、怎麼量化它對人的劑量、怎麼屏蔽防護。
- **系統與安全面**：把上面所有東西組成一座電廠，並回答「最壞情況會怎樣、怎麼防」。

### 給擁有者的脈絡提醒

擁有者背景是電機／通訊，數理工具（微積分、微分方程、線代、機率）熟，但物理（尤其熱力學、流體、近代物理）基礎不扎實。因此本計畫的安排原則是：

1. **先補近代物理與核物理的直覺**，因為整個領域建立在「原子核會放能、會放輻射」這件事上。
2. **反應器物理（中子學）是重頭戲**，它本質上是「中子的輸運與擴散方程」，數學形式上跟擁有者熟悉的偏微分方程、特徵值問題很像——可以用這個類比切入，但物理意義要講清楚。
3. **核熱流需要先有熱傳與流體的基本盤**，所以核熱流一科會先把必要的熱傳與流體觀念就地補足。
4. 軟體／數值方法相關（蒙地卡羅、確定論數值解）可講得精簡，因為擁有者程式能力強。

### 深度分層

- **大學層級**：本計畫主體，完整涵蓋標準必修，從基礎講起。
- **碩士層級**：在各科末尾以「延伸」小節簡短介紹子領域。
- **博士層級**：以「研究方向列表」呈現，不展開長篇。

### 共通基礎說明

純數學（微積分、線性代數、工程數學／微分方程、機率與統計）與普通物理屬**共通基礎**，本計畫不另開科目重寫；在各科需要時只薄薄提一句它扮演的角色，必要時標註「詳見 共通基礎/」。例如：中子擴散方程是一個含吸收項與源項的擴散型偏微分方程，求解工具屬共通基礎；蒙地卡羅抽樣的機率背景屬共通基礎。

## 各階段與科目清單

### 階段 01：核物理與輻射基礎

打底用。先把「原子核會怎樣」這條主線的最基本觀念建立起來，並把「輻射怎麼跟物質作用」講透——後面的反應器物理、劑量學與屏蔽全都靠它。

- [x] [01-近代物理與核物理導論](01-核物理與輻射基礎/01-近代物理與核物理導論.md)
  範圍：波粒二象性、波函數與能階、原子結構與量子數等進入核物理所需的量子直覺；核子組成、質量欠缺與結合能、核力與核模型、放射性衰變（α/β/γ）與衰變律、核分裂與核融合的能量學；並涵蓋中子截面（微觀／巨觀）、散射與吸收、共振與反應率的物理意義與量綱。
- [x] [02-輻射與物質作用](01-核物理與輻射基礎/02-輻射與物質作用.md)
  範圍：帶電粒子的阻擋本領與射程、光子的光電／康普頓／成對效應與衰減係數、中子與物質作用，建立屏蔽與偵測的物理基礎；末段附「偵檢器物理的交互作用基礎」選讀。

### 階段 02：反應器物理

核工的核心心臟。把中子當成一個族群，用方程描述它能不能維持鏈鎖反應、功率怎麼分佈，以及功率如何隨時間變化。

- [x] [03-中子擴散理論與臨界](02-反應器物理/03-中子擴散理論與臨界.md)
  範圍：中子流與費克定律、單群擴散方程、邊界條件、擴散長度；增殖係數 $k$、四因子與六因子公式、臨界方程與幾何挫率、反應度與反應器控制，為反應器計算建立解析骨架。
- [x] [04-反應器動力學](02-反應器物理/04-反應器動力學.md)
  範圍：緩發中子與其關鍵作用、點動力學方程、反應度與週期、反應度回饋與溫度係數、氙毒與燃耗、控制棒與反應器控制。

### 階段 03：核熱流與材料

分裂能是熱，必須安全帶走；同時支撐反應器運轉的材料，在輻射與高溫下會逐步劣化。這一階段把熱傳、流體、兩相沸騰應用到燃料棒與反應器迴路，並處理材料的物質面。

- [x] [05-核熱流與兩相流](03-核熱流與材料/05-核熱流與兩相流.md)
  範圍：反應器熱源與燃料棒內溫度分佈、冷卻劑流道熱平衡與單相對流熱傳、兩相流與沸騰熱傳、臨界熱通量（CHF/DNB）、熱限值與安全裕度，以及事故熱流與安全系統；必要的流體與熱傳基礎於本科就地補足。
- [x] [06-核反應器材料](03-核熱流與材料/06-核反應器材料.md)
  範圍：燃料（UO₂）、護套（鋯合金）、壓力容器與結構材料、冷卻劑相容性、輻射損傷（位移、腫脹、脆化）、高溫腐蝕與材料壽命，以及未來爐型的材料挑戰。

### 階段 04：輻射防護與安全

把「輻射對人的傷害」量化並防住，再把視野拉到整座電廠：最壞情況會怎樣、怎麼防。

- [x] [07-輻射劑量學與屏蔽](04-輻射防護與安全/07-輻射劑量學與屏蔽.md)
  範圍：吸收劑量、等效劑量與有效劑量、劑量當量與權重因子、生物效應、ALARA、外部屏蔽計算與內輻射劑量學、環境輻射監測、法規限值與輻射安全。
- [x] [08-核能安全與嚴重事故](04-輻射防護與安全/08-核能安全與嚴重事故.md)
  範圍：縱深防禦與多重屏障、設計基準事故與嚴重事故（如 LOCA、爐心熔毀）、三哩島／車諾比／福島等歷史事故案例與監管、嚴重事故緩解策略、機率安全評估（PSA／PRA）。

### 階段 05：核能系統與燃料循環

把所有東西組成一座電廠，並補上物質面的來龍去脈：燃料從哪來、用完怎麼辦。

- [x] [09-核反應器類型與電廠系統](05-核能系統與燃料循環/09-核反應器類型與電廠系統.md)
  範圍：PWR/BWR/PHWR/氣冷／快中子反應器與第四代爐型概觀、一次與二次迴路、蒸氣產生器、圍阻與深度防禦、停機與衰變熱移除、效率與可用率、SMR，以及整體電廠系統與運轉概念。
- [x] [10-核燃料循環與廢料管理](05-核能系統與燃料循環/10-核燃料循環與廢料管理.md)
  範圍：鈾礦開採與轉化、濃縮、燃料製造、爐內燃耗、用過燃料、開放式與封閉式循環、再處理與最終處置，前端與後端整體流程及核擴散考量。
