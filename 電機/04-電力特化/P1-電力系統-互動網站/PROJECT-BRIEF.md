# 電力系統互動學習網站專案簡報

← [上篇](../P1-電力系統-上.md)｜[下篇](../P1-電力系統-下.md)｜[互動網站工作流](../../../wf/workflows/interactive-study-site/README.md)

## 目標

把 P1 上下篇轉成一個可操作、可立即得到工程回饋的靜態學習工作台。讀者應能從「為何升壓」一路走到潮流、故障、保護、穩定、調度與現代電網，而不是只背名詞。

## 讀者與深度

- 讀者有電機背景，但電力系統基礎不穩；公式前後要說清楚物理意義。
- 以大學核心課綱為主；數值模型保持小型、可手算、可核對。
- 軟體實作細節不做教學主體，介面只呈現電力系統決策與證據。

## 內容來源

- `P1-電力系統-上.md`：架構、高壓、標么、三相、潮流。
- `P1-電力系統-下.md`：故障、保護、穩定、頻率、調度、可靠度與現代電網。
- 不進行外部研究；不加入本地筆記未支撐的法規值、事件資料或標準曲線常數。

## 8 個學習模組

1. 高壓輸電：固定功率下比較電流與 $I^2R$ 線損。
2. 標么制：基準量、實際值轉換與阻抗換基準。
3. 三相與功因：電流、無功補償及線損相對變化。
4. DC 潮流與 N-1：三母線潮流、線路限額與單線跳脫。
5. 故障序網：三相、單相接地與線間故障的序網連接及故障電流。
6. 保護協調：主保護、後備保護、拾取門檻與時間裕度。
7. 穩定與頻率：等面積近似、清除時間、慣性、RoCoF 與 droop。
8. 經濟調度：兩機增量成本、出力限制、再生能源與儲能後的淨負載。

## 交付物

- 執行期：`index.html`、`styles.css`、`app.js`。
- 規格與驗收：`BUILD-SPEC.md`、`派工計畫.md`、`README.md`、`驗收紀錄.md`。
- GitHub Pages 路徑：`/power-systems/`；入口頁在完成驗收前維持「製作中」。

## 硬性限制

- 純 HTML/CSS/JavaScript、UTF-8、繁體中文、零套件、零外部資產。
- 不使用圖片、CDN、外部字型、分析碼、遠端 API 或網路服務。
- 手機寬度以 `390px` 為主要約束；頁面本身不可水平溢位。
- 所有簡化模型必須顯示假設；不得把教學結果稱為正式系統研究、電驛整定或市場出清結果。

## 完成定義

- 8 個模組皆可自由切換、重設並標記進度。
- 控制值改變會立即更新數值、狀態與原因；非法輸入有明確錯誤回饋。
- 預設案例與本規格數值一致，JavaScript、HTML、相對連結與 Pages 組裝檢查通過。
- 若環境沒有瀏覽器，真實桌機與手機渲染必須列為未驗證，不能標示通過。
