03・內快外慢，三層才不會互相絆腳

速度與位置迴路串級：用頻寬分離讓內層先完成工作

電流迴路比速度迴路快 10 倍時，速度步階的超越量是 4.352513 %，已很接近理想二階的 4.321392 %。若兩層同頻寬，超越量會跳到 24.621566 %；這章要找的就是三層控制之間的頻寬分離（bandwidth separation）。

這章假設已懂：02 電流迴路 PI 設計的閉迴路一階模型。前置：見〈二階閉迴路與極點位置〉控制系統的二階響應。

痛點：每層 PI 都各自設好，為什麼合起來還會振

單看每一層，電流能跟命令，速度也能回到設定值，但是串在一起後，速度卻可能衝過頭。原因是外層以為內層立刻完成指令，內層實際上還在追。當兩層反應時間太接近，內層的落後就進入外層動態，原本以二階設計的參數，會在三階系統裡呈現另一種結果。

第二個痛點是負載突然增加。積分器最後能把穩態誤差消掉，卻不表示速度過程不會掉。掉多深取決於轉動慣量 J 與速度迴路頻寬的乘積，因此步階跟得好和擾動擋得住是兩件需分開觀察的事。

白話直覺：裡層先站穩，外層才有可靠的基礎

可以暂時把三層想成三個速度不同的工作者：最裡面的人先完成快指令，外面的人才據此修正較慢的目標；比喻到此為止。真實機制是串級控制（cascade control）：位置 P 產生速度命令，速度 PI 產生電流命令，電流 PI 再產生電壓命令。

從物理因果走一遍：直流鏈供應相對參考點的電壓；逆變器開關決定哪條實體回路導通，電流流進繞組建立定子磁場；磁場與轉子作用產生轉矩，慣量把轉矩累積成速度與位置。電流、速度、位置各自回授到對應層，示波器最後看到的是速度命令、速度回授與負載加入時的瞬態。

串級系統的核心量是頻寬分離倍數 N = ωc / ωs。N 夠大，外層所看到的內層就接近即時；N 變小，電流動態就不能從速度模型裡省略。

來源：P3 上 §4.1；P3 下 §9.1。

推導：由二階設計看見第三個極點

機械受控體為 ωm / T = 1 / (J × s)，J 的單位是 kg·m²。選 Kp = J × ωs、Ki = J × ωs2 / 2，若電流迴路理想，特徵式為 J × s2 + Kp × s + Ki。因此 ωn = ωs / √2，而 ζ = Kp / (2 × √(Ki × J)) = 1 / √2 = 0.707107。前置濾波器（reference prefilter）取 τf = Kp / Ki = 2 / ωs，用來抵消 PI 零點造成的額外超越量。

電流迴路實際是 1 / (s / ωc + 1)，特徵式因而變成 (s / ωc + 1) × J × s2 + Kp × s + Ki。N 越小，第三個極點越靠近原來的二階極點，超越量便上升。位置迴路取 Kp,pos = ωp = ωs / 10，近似為時間常數 1 / ωp 的一階系統。

三層時間尺度分別是電流 50 µs 中斷、速度 1 ms、位置 10 ms。這些是取樣時間，控制頻寬還要更低。本課用的是線性教學模型，真實驅動器不完全如此：模型忽略電流限幅、摩擦與取樣，數值結果以固定步長的四階 Runge Kutta 法（fourth order Runge Kutta, RK4）積分得到。負載轉矩 TL 加入後，穩態誤差為 0，但最大掉速約與 TL / (J × ωs) 同量級。

把前置濾波器放在命令端，只改命令到輸出的分子，不會移動閉迴路極點。因此它能消除零點帶來的額外峰值，卻不能補救內層太慢。若第三個極點已靠近主要極點，真正要做的是拉開頻寬分離，而不是靠濾波器修飾波形。負載則從機械端直接進入，前置濾波器對它沒有作用；這也解釋了命令追蹤漂亮時，受擾恢復仍可能很差。調機時應分開做命令步階與負載步階，前者檢查極點配置，後者檢查慣量與速度迴路剛性。

判讀：分離足夠，超越量 4.352513 % 與理想二階 4.321 % 相差不到 0.1 個百分點，內迴路可視為理想。

穩態誤差 0：積分器把負載扛起來。位置迴路 ωp = ωs / 10 = 31.415927 rad/s，時間常數 31.830989 ms。為什麼：N = 10 讓電流的一階落後遠快於速度動態，因此三階結果幾乎重合理想二階。邊界提醒：N = 1 時內外迴路同頻寬，超越量 24.622 %，這不是 PI 調錯，是結構錯；TL = 0 時沒有負載擾動，掉速 0；J = 0.001 時同樣負載使掉速超過 200 %。

不要混淆

  • 頻寬分離是倍數，不是某個固定頻率。fc 提高後，ωs 也可在保留倍數下提高。
  • 4.321392 % 是 ζ = 0.707107 的設計結果，不是馬達的物理定律；改設計目標就會改變。
  • 掉速深淺看 J × ωs，不看超越量。相同步階形狀不代表負載剛性相同。
  • 位置迴路用 P 就夠，邊界是內層速度迴路已含積分器，使整體為型式 1。

可觀察證據：拿什麼量、量到什麼

用什麼量。用示波器或驅動器的內建示波功能，同時記錄速度命令、速度回授與電流命令。對速度下步階命令，峰值高度就給出超越量；速度穩定後突然掛上負載，谷底就是最大掉速。

能證明什麼。步階峰值能驗證頻寬分離是否足夠，負載谷底與恢復時間能驗證負載剛性。

不能證明什麼。單看速度波形不能確認電流限幅是否介入；必須同時查看電流命令或電流回授有沒有貼住上限。

連到哪門課

這套串級架構用在伺服驅動器、機器人關節與數值控制機床。二階極點與 ζ 的意義見二階閉迴路與極點位置；J 與摩擦的模型見建模從微分方程到轉移函數；積分器為何消除穩態誤差見穩態誤差與系統型式。

韌體那一端：速度 PI 跑在 1 ms 中斷，位置 P 跑在 10 ms 中斷；三個增益是三個獨立參數，調機順序由內而外。
