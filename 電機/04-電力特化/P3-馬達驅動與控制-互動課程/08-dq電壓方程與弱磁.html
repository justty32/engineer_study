08・電壓有上限，高速要用電流換餘裕

dq 電壓方程與弱磁：反電動勢逼近上限後，負 id 如何把基速推高

300 V 直流鏈的空間向量脈寬調變（space-vector PWM, SVPWM）線性區上限是 173.205081 V；本章預設在 3000 rpm、iq = 10 A 時需要 133.058855 V，尚有餘裕。若速度升到 6000 rpm，需求變成 261.209420 V；注入 −10 A 的 id 可把基速由 3939.828277 推到 4837.738908 rpm，但仍要付出額外電流與銅損。

這章假設已懂：07 Clarke 與 Park 轉換的 d、q 軸與 id、iq。前置：見〈直流機轉矩轉速線〉電機機械的直流機轉矩轉速線，先理解反電動勢隨速度上升，以及弱磁升速的取捨。

痛點：電流命令沒有變，馬達為什麼高速時突然推不動

低速時 PI 多加一點電壓，就能把 iq 拉回命令；高速時即使數值繼續加，逆變器也不可能輸出超過直流鏈所容許的電壓向量。這不是 PI 不努力，而是可用電壓已經碰到幾何上限。

更反直覺的是，控制器會故意加入不直接產生轉矩的負 id。它看似浪費電流，實際上是在削弱定子所見的總磁鏈，降低隨速度上升的反電動勢，換取繼續加速的電壓餘裕。代價是電流向量變長、銅損增加，而且電流上限迫使 iq 讓出空間。

白話直覺：高速時先替電壓上限騰出空間

可以暫時把 173.205081 V 想成固定大小的行李箱，電阻壓降、交叉耦合與反電動勢都要塞進去；比喻到此為止，真實機制是 dq 電壓向量必須落在 SVPWM 線性區的圓內，圓半徑由 Vdc / √3 決定。

沿實體因果走一次。直流鏈相對負端供電，逆變器切換導通路徑，使三相電流流經定子繞組並建立磁場；iq 與永磁磁場作用產生轉矩，旋轉磁場同時形成反電動勢。電流感測器把三相值回授，控制器轉成 dq 後，PI 輸出 vd、vq，再受電壓極限夾住。示波輸出可看到 |v| 是否貼住上限，直流電壓表則確認 Vdc。

去耦（decoupling）以前饋方式抵銷 ±ωe L i 的交叉項；弱磁（field weakening）則用負 id 降低 Ld id + ψf。兩者都修改 dq 電壓需求，但前者為了讓兩軸互不干擾，後者為了在高速留出電壓。

來源：P3 上 §2.3–2.5、§5.2；P3 下 §7、§9.2、§9.3。

推導：旋轉座標多出的耦合項，如何決定基速

（a）穩態方程。把 v = R i + L di/dt + E 寫進旋轉座標，座標本身旋轉會多出 ωe 乘磁鏈的項。穩態令電流導數為 0，得到 vd = R × id − ωe × Lq × iq，vq = R × iq + ωe × (Ld × id + ψf)，電壓單位 V。

（b）速度把電壓吃掉。ωe = p × ωm，單位 rad/s。id = 0 時，vq 高速近似 ωe × ψf；它隨速度線性增加，而 |v| = √(vd² + vq²) 必須 ≤ Vdc / √3。

（c）基速由二次式求出。把極限平方後寫成 aωe² + bωe + c = 0，其中 a = (L iq)² + (L id + ψf)²，b = 2 × [−R id L iq + R iq (L id + ψf)]，c = R²(id² + iq²) − Vdc² / 3。取正根 ωe = (−b + √(b² − 4ac)) / (2a)，再換成 rpm。

（d）弱磁的交換。負 id 使 L id + ψf 變小，a 下降，基速上升；但 |i| = √(id² + iq²) 不能超過 20 A，故高速時必須降低 iq，由定轉矩區進入定功率區。本課用的是線性教學模型，真實驅動器不完全如此；假設穩態、表面式 Ld = Lq = 2 mH，忽略鐵損、飽和與切換非理想。

（e）電流與功率的代價。表面式模型的 T = 1.5 × p × ψf × iq = 0.6 × iq，所以負 id 不直接增加轉矩；機械功率 Pm = T × ωm，銅損則為 1.5 × R × (id² + iq²)。當總電流碰到 20 A，繼續加深弱磁就必須減少 iq，轉矩下降而速度上升，這才形成近似定功率區。

電壓圓與電流圓要同時滿足。弱磁把電壓需求往圓內拉，卻把電流向量往極限推；所以控制器不能只看電壓是否飽和。若電流已到上限，更多負 id 必須由較少 iq 換來，轉矩隨之下降。這個取捨也說明基速以上只能近似維持功率，不代表速度能無限提高。

不要混淆

  • 弱磁削弱的是定子所見總磁鏈，不等於把永磁體消磁；本課的負 id 範圍用來算電壓餘裕，不代表任一實機都允許同樣大小。
  • 基速不是只由馬達銘牌決定，而是馬達參數、直流鏈與電流命令共同決定；同一顆馬達由 300 V 改成 400 V，基速會成為 5291.400674 rpm。
  • 電壓飽和時，電流迴路仍會執行，只是輸出被限制；第 02 章的反積分飽和必須避免積分項繼續累積，卻不能憑空增加可用電壓。
  • 表面式馬達的每安培最大轉矩（maximum torque per ampere, MTPA）在 id = 0；內藏式因 Ld ≠ Lq 另有磁阻轉矩，這個結論不直接適用。
  • 去耦與弱磁不是同一功能：去耦補回 ωe L i 的交叉影響，弱磁則主動改變 d 軸磁鏈，兩者只是在電壓方程裡同時出現。

可觀察證據：拿什麼量、量到什麼

用什麼量。把驅動器內部的 vd、vq、|v| 與工作週期送到示波輸出，以示波器觀察是否貼住限制；另以直流電壓表量 Vdc，並同步讀取轉速與 dq 電流。

能證明什麼。|v| 貼到 Vdc / √3、工作週期貼到 100 %，同時 iq 開始追不到命令，能證明電壓飽和與基速邊界；加入負 id 後邊界上移，能驗證弱磁效果。

不能證明什麼。這些內部變數不能直接證明 ψf 是否因溫度下降，也不能證明永磁體健康；要在已知速度下量空轉反電動勢，才可估算 ψf。

連到哪門課

直流機用場電流減少磁通、換取更高速度，是同一取捨的直流版本，見電機機械的直流機轉矩轉速線；Vdc / √3 為何是線性區上限，接到本課第 09 章的 SVPWM 作用時間。這套計算用在電動車、高速壓縮機與主軸驅動器。韌體那一端：去耦前饋是兩行加法；弱磁通常是一個「電壓餘裕 → id 命令」的外層 PI。
