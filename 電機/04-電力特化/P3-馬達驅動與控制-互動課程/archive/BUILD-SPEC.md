## 3. 公式與符號轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元與寫法

- 上下標用 `<sup>`／`<sub>`；`²` `³` 可直接用。
- 數學符號限：`× ÷ ± ≈ ≤ ≥ ≠ → √ ∞ ∠ ° ∝`；希臘字母限 `ω θ ψ α β γ ζ τ π Φ η Ω µ φ`。
- 乘號 `×` 前後各一空格；除號半形 `/` 前後各一空格；負號 U+2212。
- 單位緊接數字後空一格：`24 V`、`7.528024 A`、`0.752802 N·m`、`3141.592654 rad/s`、`50.000000 µs`。
- 百分比 `<數字> %`。三角函數寫 `sin γ`、`cos 30°`（度）。

### 3.2 轉寫範例（章節作者照此風格）

| 概念 | 網頁純文字 HTML |
| --- | --- |
| 轉矩與夾角 | `T = K<sub>t</sub> × I × sin γ` |
| 平均電壓（單極性） | `V<sub>avg</sub> = D × V<sub>dc</sub>`；（雙極性）`V<sub>avg</sub> = (2D − 1) × V<sub>dc</sub>` |

| 穩態電流 | `I = (V<sub>avg</sub> − K<sub>e</sub> × ω<sub>m</sub>) / R` |
| 電流迴路 PI | `K<sub>p</sub> = L × ω<sub>c</sub>`，`K<sub>i</sub> = R × ω<sub>c</sub>`，閉迴路 `I / I* = 1 / (s / ω<sub>c</sub> + 1)` |

| V/f 磁通比 | `Φ / Φ<sub>rated</sub> = [(V − I × R<sub>s</sub>) / f] / 3.583333` |
| Clarke | `i<sub>α</sub> = (2/3) × (i<sub>a</sub> − i<sub>b</sub> / 2 − i<sub>c</sub> / 2)`，`i<sub>β</sub> = (i<sub>b</sub> − i<sub>c</sub>) / √3` |

### 00 `00-驅動器世界觀與轉矩夾角.html`

**目標**：不假設任何驅動知識，建立三件事：（a）驅動器 = 功率級（開關）＋感測（電流、位置）＋控制器（三層迴路）三塊；（b）所有馬達的轉矩都來自定子磁場與轉子磁場的夾角 γ，`T = K<sub>t</sub> × I × sin γ`，γ = 90° 最大；（c）「控制」的本質就是持續把 γ 維持在 90° 附近——有刷直流機靠換向器機械地做、無刷直流馬達靠霍爾碼每 60° 切一次、永磁同步馬達靠 Park 轉換連續地做。並用一個數字讓讀者記住六步換相的代價：γ 只能在 60°–120° 之間擺，平均轉矩只有 90° 時的 3 / π = 95.493 %。

**要點**：馬達驅動（motor drive）、轉矩常數（torque constant, K<sub>t</sub>）、磁場夾角 γ（本課符號）。三層迴路由內到外：電流迴路（current loop，數百 Hz–kHz，每個 PWM 週期跑一次）、速度迴路（speed loop，數十 Hz）、位置迴路（position loop，數 Hz）；本課量級：20 kHz 切換、電流迴路 500 Hz、速度迴路 50 Hz、位置迴路 5 Hz。馬達家族只列名字與換相方式：有刷直流（機械換向）、步進（開迴路走步）、無刷直流 BLDC（六步）、永磁同步 PMSM（FOC）、感應機 IM（V/f 或 FOC）；家族比較與本體見電機機械課。來源：P3 上 §1.1、§1.2、§4.1。

**推導必寫**：（a）兩磁場的作用力像兩根磁棒：對齊（γ = 0°）或反向（γ = 180°）只有拉力沒有轉矩，垂直時全部是轉矩，所以 `T ∝ sin γ`；比喻收回：真正的機制是定子電流產生的磁動勢與轉子磁通的向量外積。（b）把定子磁場強度用電流 I 代表、其餘常數收進 K<sub>t</sub>（N·m/A），得 `T = K<sub>t</sub> × I × sin γ`。（c）六步換相：定子磁場只能停在 6 個方向，轉子每轉 60° 才切一次，γ 從 120° 掃到 60°，平均 `(1 / 60°) × ∫ sin γ dγ = (3 / π) × (cos 60° − cos 120°) = 3 / π = 0.954930`，最低點 sin 60° = 0.866025，漣波 `(1 − 0.866025) / 0.954930 = 14.029787 %`。假設：K<sub>t</sub> 為常數（無飽和）、轉子磁場強度固定。

### 01 `01-H橋與平均電壓.html`

**目標**：有刷直流馬達接在 H 橋（H-bridge）上，四個開關以工作週期 D 反覆通斷，馬達繞組的電感把它濾成平均電壓；讀者要看懂：（a）`V<sub>avg</sub> = D × V<sub>dc</sub>`（單極性）或 `(2D − 1) × V<sub>dc</sub>`（雙極性）；（b）穩態電流由 `(V<sub>avg</sub> − E) / R` 決定，E = K<sub>e</sub> × ω<sub>m</sub> 是反電動勢；（c）漣波 `ΔI = V<sub>dc</sub> × D × (1 − D) / (f<sub>sw</sub> × L)`（雙極性 ×2），平均值模型成立的條件是 τ<sub>e</sub> = L / R ≫ T<sub>sw</sub>；（d）電壓與電流的正負決定四象限（電動／再生煞車）。全課直流馬達：**R = 1 Ω（固定）、L = 2 mH、K<sub>e</sub> = K<sub>t</sub> = 0.1 V·s/rad、V<sub>dc</sub> = 24 V、f<sub>sw</sub> = 20 kHz**。

**要點**：H 橋四個開關（上 A、下 A、上 B、下 B），同一臂上下不得同時導通；脈寬調變（pulse-width modulation, PWM）本課只用平均值模型一句話（PROJECT-BRIEF 第 2 節第 8 條）。單極性（unipolar）切換：一臂固定、另一臂 PWM，繞組看到 0 與 +V<sub>dc</sub>；雙極性（bipolar）：對角兩開關同時 PWM，繞組看到 −V<sub>dc</sub> 與 +V<sub>dc</sub>，D = 0.5 是零電壓。四象限（four-quadrant）：Q1 正轉電動（V<sub>avg</sub> ≥ 0、I ≥ 0）、Q2 正轉再生煞車（V<sub>avg</sub> ≥ 0、I < 0）、Q3 反轉電動（V<sub>avg</sub> < 0、I ≤ 0）、Q4 反轉再生煞車（V<sub>avg</sub> < 0、I > 0）。堵轉（stall）電流 V<sub>avg</sub> / R。來源：P3 上 §1.2（有刷 DC）、§3。

**推導必寫**：（a）繞組回路 `V<sub>avg</sub> = E + I × R + L × dI/dt`，穩態平均 dI/dt = 0 → `I = (V<sub>avg</sub> − E) / R`。（b）開關導通 D × T<sub>sw</sub> 期間電感看到 `V<sub>dc</sub> − V<sub>avg</sub>`（單極性），電流線性上升 `ΔI = (V<sub>dc</sub> − V<sub>avg</sub>) × D × T<sub>sw</sub> / L = V<sub>dc</sub> × D × (1 − D) / (f<sub>sw</sub> × L)`；雙極性導通期間電感看到 `V<sub>dc</sub> − (2D − 1) × V<sub>dc</sub> = 2 × (1 − D) × V<sub>dc</sub>`，所以漣波是單極性的 2 倍。（c）D = 0.5 時 D × (1 − D) 最大，漣波最大。（d）平均值模型的假設：τ<sub>e</sub> / T<sub>sw</sub> ≥ 10，本課 2 ms / 50 µs = 40。（e）能量：P<sub>elec</sub> = V<sub>avg</sub> × I、P<sub>mech</sub> = E × I、P<sub>cu</sub> = I² × R；I < 0 時 P<sub>mech</sub> < 0，機械能變電能回直流鏈（第 11 章）。

### 02 `02-電流迴路PI設計.html`

**目標**：把第 01 章的繞組 `I / V = 1 / (L × s + R)` 當受控體，用零極點抵消的 PI 讓閉迴路變成一階 `1 / (s / ω<sub>c</sub> + 1)`，增益直接算出來：`K<sub>p</sub> = L × ω<sub>c</sub>`、`K<sub>i</sub> = R × ω<sub>c</sub>`。再看兩件真實驅動器一定撞到的事：（a）取樣＋PWM 更新的純延遲約 1.5 T<sub>s</sub>，吃掉相位裕度 `ω<sub>c</sub> × 1.5 T<sub>s</sub>`；（b）PI 第一拍要求的電壓 `K<sub>p</sub> × ΔI` 常超過 V<sub>dc</sub>，電壓飽和後迴路變慢，需要反積分飽和。

**要點**：比例—積分控制器（PI controller）`C(s) = K<sub>p</sub> + K<sub>i</sub> / s = K<sub>p</sub> × (s + K<sub>i</sub> / K<sub>p</sub>) / s`；零點放在 `K<sub>i</sub> / K<sub>p</sub> = R / L` 剛好抵消受控體極點，迴路增益變成 `K<sub>p</sub> / (L × s) = ω<sub>c</sub> / s`，閉迴路一階、頻寬 ω<sub>c</sub>、無超越量。取樣週期 T<sub>s</sub> = 1 / f<sub>pwm</sub>；延遲 1.5 T<sub>s</sub>（取樣 1 拍＋PWM 零階保持半拍）；相位裕度（phase margin, PM）= 90° − 延遲相位。反積分飽和（anti-windup）：電壓被限幅時停止累積積分。來源：P3 上 §5.3、下 §9.1、§9.2。

**推導必寫**：（a）迴路增益 `L(s) = C(s) × G(s) = K<sub>p</sub> × (s + R / L) / s × 1 / (L × (s + R / L)) = K<sub>p</sub> / (L × s)`，令 `K<sub>p</sub> / L = ω<sub>c</sub>`。（b）閉迴路 `L / (1 + L) = ω<sub>c</sub> / (s + ω<sub>c</sub>)`，時間常數 τ = 1 / ω<sub>c</sub>，10–90 % 上升時間 `ln 9 × τ = 2.197225 τ`，2 % 整定 `ln 50 × τ = 3.912023 τ`。（c）純延遲 T<sub>d</sub> 在 ω<sub>c</sub> 的相位 `ω<sub>c</sub> × T<sub>d</sub>`（rad），乘 180 / π 化成度，PM = 90° − 它。（d）步階 ΔI 的瞬間，積分器還是 0，PI 輸出 `K<sub>p</sub> × ΔI`；不飽和的最大步階 `ΔI<sub>max</sub> = V<sub>dc</sub> / K<sub>p</sub>`（堵轉、E = 0 時）。假設：受控體是理想 RL、K<sub>e</sub> 項當成可前饋的干擾、延遲用純延遲近似。

**數值實例**：R = 1 Ω、L = 2 mH、f<sub>c</sub> = 500 Hz、f<sub>pwm</sub> = 20 kHz、步階 ΔI = 10 A、V<sub>dc</sub> = 24 V。

### 03 `03-速度與位置迴路串級.html`

**目標**：把第 02 章的電流迴路當成一階落後 `1 / (s / ω<sub>c</sub> + 1)`，外面包一個速度 PI，再外面包一個位置 P；讀者要看懂**頻寬分離倍數 N = ω<sub>c</sub> / ω<sub>s</sub>** 怎麼決定外迴路能不能把內迴路當理想：N ≥ 10 時速度步階響應與理想二階（ζ = 0.707，超越量 4.321 %）幾乎相同，N = 2 超越量翻倍到 8.147 %，N = 1 變 24.622 %。同時看負載擾動：速度迴路頻寬越低，負載一加速度掉得越深。

**要點**：串級控制（cascade control）：位置命令 → 位置 P → 速度命令 → 速度 PI → 電流命令 → 電流 PI → 電壓 → PWM。機械受控體 `ω<sub>m</sub> / T = 1 / (J × s)`（忽略摩擦）；速度 PI 設計：`K<sub>p</sub> = J × ω<sub>s</sub>`、`K<sub>i</sub> = J × ω<sub>s</sub>² / 2`，若電流迴路理想則閉迴路特徵式 `J × s² + K<sub>p</sub> × s + K<sub>i</sub>`，`ω<sub>n</sub> = ω<sub>s</sub> / √2`、`ζ = 0.707107`；PI 零點會造成額外超越量，本課用一階前置濾波器（reference prefilter）`τ<sub>f</sub> = K<sub>p</sub> / K<sub>i</sub> = 2 / ω<sub>s</sub>` 抵消它。位置迴路只用 P：`K<sub>p,pos</sub> = ω<sub>p</sub> = ω<sub>s</sub> / 10`，位置閉迴路近似一階、時間常數 1 / ω<sub>p</sub>。本課 K<sub>t</sub> = 1 N·m/A（電流命令即轉矩命令，簡化）。來源：P3 上 §4.1、下 §9.1。

**推導必寫**：（a）三層時間尺度：電流 50 µs 中斷、速度 1 ms、位置 10 ms（來源 §9.1 的 10–20 kHz／1–4 kHz／≤ 1 kHz 只是取樣率，頻寬再低 10 倍）。（b）ζ 的計算：`ζ = K<sub>p</sub> / (2 × √(K<sub>i</sub> × J)) = J ω<sub>s</sub> / (2 × √(J² ω<sub>s</sub>² / 2)) = 1 / √2`。（c）前置濾波器把閉迴路分子的零點 `(s + K<sub>i</sub> / K<sub>p</sub>)` 除掉，剩純二階。（d）內迴路不理想時特徵式變三階 `(s / ω<sub>c</sub> + 1) × J × s² + K<sub>p</sub> × s + K<sub>i</sub>`，N 越小第三個極點越靠近，超越量上升。（e）負載擾動 T<sub>L</sub>：穩態誤差 0（積分器），暫態最大掉速大約與 T<sub>L</sub> / (J × ω<sub>s</sub>) 同量級。模型：忽略電流限幅、摩擦與取樣，用 RK4 固定步長積分（見 widget）。

**數值實例**：J = 0.01 kg·m²、f<sub>c</sub> = 500 Hz、N = 10、負載步階 T<sub>L</sub> = 1 N·m（在速度穩定後加入）。速度命令步階正規化為 1（單位任意，線性系統）。

### 04 `04-步進馬達與微步.html`

**目標**：步進馬達（stepper motor）是唯一「不量位置也能定位」的家族：每來一個脈衝轉一個步距角，控制器只要數脈衝。讀者要看懂四件事：（a）步距角 `360° / N<sub>spr</sub>`、微步（microstepping）把它再切 m 份；（b）微步的「增量轉矩」只有保持轉矩的 `sin(90° / m)`，m = 16 只剩 9.8 %；（c）轉速上去後繞組電流爬不到額定值，轉矩掉——轉折速度 `ω<sub>corner</sub> = 2π × V / (N<sub>spr</sub> × L × I + 2π × K<sub>e</sub>)`；（d）負載一加，轉子會靜態偏離命令位置 `asin(T<sub>L</sub> / T<sub>avail</sub>)` 個電氣度，0.1 N·m 就偏 2.574 個微步。全課步進馬達：**保持轉矩 T<sub>h</sub> = 0.4 N·m、K<sub>e</sub> = 0.05 V·s/rad（固定）**，其餘可調。

**要點**：混合式步進馬達 200 步／圈（1.8°），50 齒轉子，4 個全步 = 1 個電氣週期（電氣頻率 f<sub>e</sub> = rev/s × 50）。保持轉矩（holding torque）、失步（step loss）、斬波驅動（chopper drive，固定電流，本課採用）。轉矩–角度曲線為正弦：命令位置與實際位置差 θ<sub>err</sub>（電氣度）時 `T = T<sub>avail</sub> × sin θ<sub>err</sub>`。微步增量轉矩 `T<sub>inc</sub> = T<sub>h</sub> × sin(90° / m)`。來源：P3 上 §1.2（步進一行）；其餘由本課補。

**推導必寫**：（a）開迴路走步：控制器發 f 個微步脈衝/秒，轉速 `rev/s = f / (N<sub>spr</sub> × m)`。（b）每個全步繞組電流要換一次方向，電流從 0 爬到 I 需要 `t<sub>rise</sub> = L × I / (V − E)`（E = K<sub>e</sub> × ω<sub>m</sub> 是反電動勢），全步週期 `T<sub>full</sub> = m / f`；若 t<sub>rise</sub> > T<sub>full</sub>，電流只到 `T<sub>full</sub> / t<sub>rise</sub>` 的比例，可用轉矩同比例下降（教學近似）。（c）令 t<sub>rise</sub> = T<sub>full</sub> 解出轉折速度的閉式解（第 3.2 節）。（d）E = V 時電流再也推不進去，`ω<sub>max</sub> = V / K<sub>e</sub>`。（e）靜態誤差 `θ<sub>err</sub> = asin(T<sub>L</sub> / T<sub>avail</sub>)` 電氣度，換成機械角乘 `θ<sub>step</sub> / 90°`，換成微步數再除 θ<sub>µ</sub>。假設：正弦轉矩曲線、忽略共振與鐵損、斬波器理想。

**數值實例**：N<sub>spr</sub> = 200、m = 16、f = 16000 微步/s、V = 24 V、L = 3 mH、I = 2 A、T<sub>L</sub> = 0.1 N·m。

### 05 `05-BLDC六步換相與霍爾.html`

**目標**：無刷直流馬達（brushless DC motor, BLDC）沒有換向器，靠三個霍爾感測器告訴驅動器轉子在六個 60° 扇區的哪一個，再查表決定哪兩相通電；讀者要看懂：（a）霍爾碼 → 扇區 → 通電相的整張表；（b）為什麼定子磁場永遠領先轉子 60°–120°，轉矩在 86.6 %–100 % 之間擺，平均 95.493 %；（c）霍爾裝歪 δ 度時平均轉矩變 `(3 / π) × cos δ`、漣波變大。全課 BLDC：**K<sub>t</sub> 可調、電氣角 θ 為轉子北極相對 A 相霍爾的角度**。

**要點**：霍爾感測器（Hall sensor）H<sub>A</sub>、H<sub>B</sub>、H<sub>C</sub> 相隔 120° 電氣角，轉子北極在感測器 ±90° 內輸出 1。定子相軸：A 在 0°、B 在 120°、C 在 240°；「A+ B−」表示電流從 A 流入、B 流出、C 浮接，產生的定子磁場方向 = 兩相軸向量差的方向。極對數 p：機械一圈 = p 個電氣圈，本課舉例 p = 7（14 極無人機馬達）一機械圈換相 42 次。**鎖定的六步表（電氣角 θ，逆時針）**：

| 1 | 330° ≤ θ < 30° | `100` | B+ C− | 90° |

### 06 `06-感應機Vf純量控制.html`

**目標**：感應馬達最便宜的調速法：把電壓與頻率一起調，讓 V / f 定值 ≈ 定磁通，不量轉子角、不做電流迴路。讀者要看懂：（a）為什麼 V / f 定值等於定磁通（E ≈ 4.44 × f × N × Φ）；（b）低頻時定子電阻壓降 I × R<sub>s</sub> 吃掉一大塊電壓，磁通掉、轉矩掉，要加補償電壓 V<sub>0</sub>；（c）超過基頻 V 封頂、磁通 ∝ 1 / f，進入定功率區，拉出轉矩 ∝ 1 / f²；（d）純量控制是開迴路：負載造成的滑差沒人補，轉速就是差那幾十 rpm。全課感應機：**相電壓額定 220 V、基頻 60 Hz、4 極、額定電流 10 A、額定滑差 3 %（額定滑差轉速 54 rpm）、拉出轉矩 2.5 倍額定**。

**要點**：純量控制（scalar control，V/f）、變頻器（variable-frequency drive, VFD）、低頻補償（torque boost）、定轉矩區／定功率區、滑差（slip）。教學模型：`V = V<sub>0</sub> + (220 − V<sub>0</sub>) × f / 60`（f ≤ 60），f > 60 時 V = 220；`E = V − I × R<sub>s</sub>`，`I = 10 × T / T<sub>rated</sub>`（教學近似：電流與負載成正比）；磁通比 `Φ<sub>r</sub> = (E / f) / 3.583333`（3.583333 = 額定點 (220 − 10 × 0.5) / 60）；同步速 `n<sub>s</sub> = 120 × f / 4 = 30 × f`；線性區滑差轉速 `n<sub>slip</sub> = 54 × (T / T<sub>rated</sub>) / Φ<sub>r</sub>²`；`n = n<sub>s</sub> − n<sub>slip</sub>`；拉出轉矩 `2.5 × Φ<sub>r</sub>²`（倍額定）。來源：P3 上 §4.2；滑差與轉矩曲線引用電機機械課。

**推導必寫**：（a）感應電勢 `E = 4.442883 × f × N × Φ<sub>max</sub>`（電機機械課）→ 固定 E / f 就固定 Φ。（b）端電壓 V 比 E 多了 I × R<sub>s</sub>，f 高時可忽略、f 低時佔比大：3 Hz 時 V 只有 11 V，2.5 V 的壓降就是 23 %。（c）小滑差線性區：轉矩 ∝ Φ² × n<sub>slip</sub>，所以同一負載下 n<sub>slip</sub> ∝ 1 / Φ²。（d）拉出轉矩 ∝ Φ²（電機機械課戴維寧式的結論），弱磁區 Φ ∝ 1 / f → ∝ 1 / f²。（e）開迴路：n<sub>slip</sub> 沒人補，速度誤差 = n<sub>slip</sub> / n<sub>s</sub>。假設：s ≤ 0.2 線性、鐵心不飽和（Φ<sub>r</sub> > 1.1 即明說飽和）、忽略漏抗壓降。

**數值實例**：f = 30 Hz、V<sub>0</sub> = 3 V、負載 0.5 倍額定、R<sub>s</sub> = 0.5 Ω。

### 07 `07-Clarke與Park轉換.html`

**目標**：三相電流 i<sub>a</sub>、i<sub>b</sub>、i<sub>c</sub> 是三個隨轉子角變的正弦，沒辦法用 PI 追；Clarke 變換（Clarke transform）先把它壓成兩個正交的 α、β，Park 變換（Park transform）再用轉子角 θ 把座標轉到跟轉子一起旋轉的 d、q。讀者要親眼看到：拉 θ，i<sub>a</sub>、i<sub>b</sub>、i<sub>c</sub> 在變、i<sub>α</sub>、i<sub>β</sub> 也在變，但 i<sub>d</sub>、i<sub>q</sub> 不動——這就是「把交流變直流」；再看角度錯 δ 的代價：`i<sub>q</sub> = I<sub>m</sub> × cos δ`，多出假的 i<sub>d</sub> = I<sub>m</sub> × sin δ。全課永磁同步馬達：**p = 4、ψ<sub>f</sub> = 0.1 Wb、L<sub>d</sub> = L<sub>q</sub> = 2 mH（表面式）**。

**要點**：振幅不變式 Clarke：`i<sub>α</sub> = (2/3) × (i<sub>a</sub> − i<sub>b</sub> / 2 − i<sub>c</sub> / 2)`、`i<sub>β</sub> = (i<sub>b</sub> − i<sub>c</sub>) / √3`（平衡時 i<sub>α</sub> = i<sub>a</sub>）；Park：`i<sub>d</sub> = i<sub>α</sub> cos θ̂ + i<sub>β</sub> sin θ̂`、`i<sub>q</sub> = −i<sub>α</sub> sin θ̂ + i<sub>β</sub> cos θ̂`，θ̂ = θ + δ 是控制器以為的角度。電流向量定義：`i<sub>a</sub> = I<sub>m</sub> cos(θ + φ)`、`i<sub>b</sub> = I<sub>m</sub> cos(θ + φ − 120°)`、`i<sub>c</sub> = I<sub>m</sub> cos(θ + φ − 240°)`，φ 是電流向量領先 d 軸的角度，φ = 90° 就是純轉矩電流。轉矩（表面式）`T = 1.5 × p × ψ<sub>f</sub> × i<sub>q</sub> = 0.6 × i<sub>q</sub>`。d 軸（direct axis）指向轉子磁通、q 軸（quadrature axis）領先 90°。來源：P3 上 §2.1、§2.2、§5.1。

**推導必寫**：（a）三相平衡 i<sub>a</sub> + i<sub>b</sub> + i<sub>c</sub> = 0 → 三個數只有兩個自由度，Clarke 只是把「三支相隔 120° 的軸」投影到「兩支相隔 90° 的軸」。（b）代入定義式化簡得 `i<sub>α</sub> = I<sub>m</sub> cos(θ + φ)`、`i<sub>β</sub> = I<sub>m</sub> sin(θ + φ)`：αβ 平面上一支長 I<sub>m</sub>、角 θ + φ 的向量。（c）Park 把座標轉 θ̂：`i<sub>d</sub> = I<sub>m</sub> cos(φ − δ)`、`i<sub>q</sub> = I<sub>m</sub> sin(φ − δ)`——θ 消掉了，這就是直流。（d）δ ≠ 0 時轉矩 `∝ sin(φ − δ)`，φ = 90° 時損失 `1 − cos δ`。（e）第 00 章的 γ 就是這裡的 φ：FOC 用軟體把 γ 鎖在 90°。假設：三相平衡、θ 由感測器精確給出（無感測時 δ 就是估測誤差）。

### 08 `08-dq電壓方程與弱磁.html`

**目標**：有了 dq 電流，電流迴路要輸出 v<sub>d</sub>、v<sub>q</sub>；穩態 dq 電壓方程告訴你三件事：（a）`v<sub>d</sub> = R i<sub>d</sub> − ω<sub>e</sub> L<sub>q</sub> i<sub>q</sub>`、`v<sub>q</sub> = R i<sub>q</sub> + ω<sub>e</sub>(L<sub>d</sub> i<sub>d</sub> + ψ<sub>f</sub>)`，交叉項 ±ω<sub>e</sub> L i 是 d、q 互相耦合，要前饋去耦；（b）電壓向量長度 `√(v<sub>d</sub>² + v<sub>q</sub>²)` 不能超過 SVPWM 線性區上限 `V<sub>dc</sub> / √3`，反電動勢 ω<sub>e</sub> ψ<sub>f</sub> 隨速度線性長，撞到上限的速度就是基速；（c）注入負 i<sub>d</sub> 讓 `L<sub>d</sub> i<sub>d</sub> + ψ<sub>f</sub>` 變小 → 弱磁（field weakening），基速往上推，代價是多出來的電流與銅損。全課 PMSM 同第 07 章：**R = 0.5 Ω、L<sub>d</sub> = L<sub>q</sub> = 2 mH、ψ<sub>f</sub> = 0.1 Wb、p = 4、電流上限 20 A**。

**要點**：電氣角速度 `ω<sub>e</sub> = p × ω<sub>m</sub>`；反電動勢 `ω<sub>e</sub> × ψ<sub>f</sub>`；去耦（decoupling）與前饋；電壓極限圓（voltage limit circle）`|v| ≤ V<sub>dc</sub> / √3`；電流極限圓 `|i| ≤ I<sub>max</sub>`；基速（base speed）；定轉矩區／定功率區；每安培最大轉矩（maximum torque per ampere, MTPA）表面式即 i<sub>d</sub> = 0；內藏式 L<sub>d</sub> ≠ L<sub>q</sub> 有磁阻轉矩 `1.5 p (L<sub>d</sub> − L<sub>q</sub>) i<sub>d</sub> i<sub>q</sub>`（只提公式，不做互動）。功率 `P<sub>m</sub> = T × ω<sub>m</sub>`、銅損 `1.5 × R × (i<sub>d</sub>² + i<sub>q</sub>²)`。來源：P3 上 §2.3–2.5、§5.2；下 §7、§9.2、§9.3。

**推導必寫**：（a）把第 01 章的 `v = R i + L di/dt + E` 寫在旋轉座標裡，旋轉座標的「di/dt」多出一項 `ω<sub>e</sub> × (磁鏈)`，d 軸磁鏈 `L<sub>d</sub> i<sub>d</sub> + ψ<sub>f</sub>`、q 軸 `L<sub>q</sub> i<sub>q</sub>`，穩態去掉 di/dt 得方程。（b）i<sub>d</sub> = 0 時 `v<sub>q</sub> ≈ ω<sub>e</sub> ψ<sub>f</sub>`：反電動勢佔了 v<sub>q</sub> 幾乎全部。（c）基速：解 `|v|² = (V<sub>dc</sub> / √3)²` 的二次式 `a ω<sub>e</sub>² + b ω<sub>e</sub> + c = 0`，`a = (L i<sub>q</sub>)² + (L i<sub>d</sub> + ψ<sub>f</sub>)²`、`b = 2 × [−R i<sub>d</sub> L i<sub>q</sub> + R i<sub>q</sub> (L i<sub>d</sub> + ψ<sub>f</sub>)]`、`c = R² (i<sub>d</sub>² + i<sub>q</sub>²) − V<sub>dc</sub>² / 3`，取 `ω<sub>e</sub> = (−b + √(b² − 4ac)) / (2a)`。（d）負 i<sub>d</sub> 讓 a 變小 → 基速變高；但 `|i| = √(i<sub>d</sub>² + i<sub>q</sub>²)` 撞電流極限時 i<sub>q</sub> 就得讓出來，轉矩下降——定功率區。假設：穩態、表面式、忽略鐵損與飽和、SVPWM 線性區。

### 09 `09-SVPWM扇區與作用時間.html`

**目標**：電流迴路算出 v<sub>d</sub>、v<sub>q</sub>，反 Park 得到 αβ 平面上一支參考向量 V<sub>ref</sub>∠α；三相逆變器只做得出 6 個非零向量（開關狀態 100、110、010、011、001、101）與 2 個零向量（000、111）。空間向量脈寬調變（space-vector PWM, SVPWM）：找 V<sub>ref</sub> 落在哪個扇區、用相鄰兩個向量各作用 T<sub>1</sub>、T<sub>2</sub>、剩下 T<sub>0</sub> 給零向量，平均起來就是 V<sub>ref</sub>。讀者要看懂：扇區判定、`T<sub>1</sub> = √3 T<sub>s</sub> (V<sub>ref</sub> / V<sub>dc</sub>) sin(60° − θ)`、`T<sub>2</sub> = √3 T<sub>s</sub> (V<sub>ref</sub> / V<sub>dc</sub>) sin θ`、三相工作週期，以及線性區上限 `V<sub>ref</sub> ≤ V<sub>dc</sub> / √3`（T<sub>0</sub> ≥ 0）——比 SPWM 的 V<sub>dc</sub> / 2 多 15.470054 %。**本章不講開關波形怎麼生成、不講死區**（電力電子課）。

**要點**：開關狀態碼 `S<sub>a</sub>S<sub>b</sub>S<sub>c</sub>`，1 = 該相上開關導通（相接 +V<sub>dc</sub>）。六個基本向量長度 (2/3) V<sub>dc</sub>，方向 V<sub>1</sub>(100) 0°、V<sub>2</sub>(110) 60°、V<sub>3</sub>(010) 120°、V<sub>4</sub>(011) 180°、V<sub>5</sub>(001) 240°、V<sub>6</sub>(101) 300°。扇區 k = floor(α / 60°) + 1，扇區內角 θ = α − (k − 1) × 60°，第一向量 V<sub>k</sub>、第二向量 V<sub>k+1</sub>（V<sub>7</sub> 回到 V<sub>1</sub>）。調變指數 `m = V<sub>ref</sub> / (V<sub>dc</sub> / √3)`；m ≤ 1 線性區，m > 1 過調變（overmodulation，T<sub>0</sub> < 0）。七段對稱式：零向量拆兩半放頭尾（000）與中間（111）。**鎖定的三相上開關導通時間表**（T<sub>a</sub>、T<sub>b</sub>、T<sub>c</sub>；工作週期 = 除以 T<sub>s</sub>）：

### 10 `10-編碼器與速度估測.html`

**目標**：所有迴路的角度與速度從增量編碼器（incremental encoder）來：N 線的 A/B 兩相正交訊號經四倍頻得 4N 計數/圈；速度不是量來的，是算來的——M 法在固定取樣週期 T<sub>s</sub> 內數脈衝、T 法量兩個邊緣之間的時間。讀者要看懂：M 法量化步距 `60 / (4N × T<sub>s</sub>)` rpm，低速時計數太少誤差大；T 法誤差 `1 / (f<sub>clk</sub> × 邊緣間隔)`，高速時間隔太短誤差大；兩者相等的交叉速度 `60 × √(f<sub>clk</sub> / T<sub>s</sub>) / (4N)`；還有：速度量化乘上速度迴路 K<sub>p</sub> 就是轉矩抖動——第 03 章的 K<sub>p</sub> = 3.141593 時，15 rpm 的量化變成 4.934802 N·m。

**要點**：A/B/Z 三相（Z 每圈一個索引脈衝）；正交（quadrature）：B 領先或落後 A 90° 決定方向；四倍頻（4× decoding）：A、B 的每個上升與下降邊緣都計數；解析度 `360° / (4N)`；絕對編碼器（absolute encoder）與解角器（resolver）只列名字。M 法（脈衝計數法）：`n = 計數 × 60 / (4N × T<sub>s</sub>)`；T 法（週期量測法）：`n = 60 / (4N × t<sub>edge</sub>)`，t<sub>edge</sub> 用 f<sub>clk</sub> 的計時器量，誤差 1 個 tick。M/T 混合法只提名字。來源：P3 下 §10。

**推導必寫**：（a）四倍頻：一個光柵週期有 A 上、B 上、A 下、B 下四個邊緣，所以計數是 4N。（b）M 法：T<sub>s</sub> 內計數 `c = 4N × (n / 60) × T<sub>s</sub>`，計數只能是整數，量化誤差 1 計數 = `60 / (4N T<sub>s</sub>)` rpm，相對誤差 `1 / c`。（c）T 法：邊緣間隔 `t<sub>edge</sub> = 60 / (4N × n)`，計時器 tick 數 `f<sub>clk</sub> × t<sub>edge</sub>`，相對誤差 `1 / ticks`。（d）令 `c = ticks` 得交叉速度。（e）轉矩抖動：速度迴路把 1 個計數的跳動 Δω = 2π / (4N T<sub>s</sub>) 乘 K<sub>p</sub> 送進電流命令，`ΔT = K<sub>p</sub> × Δω`。假設：刻線等距、無抖動、T<sub>s</sub> 與邊緣不同步的 ±1 計數誤差取 1。

**數值實例**：N = 1000 線、T<sub>s</sub> = 1 ms、n = 300 rpm、f<sub>clk</sub> = 10 MHz。

### 11 `11-再生煞車與能量.html`

**目標**：馬達減速時動能往哪去？逆變器是雙向的（第 01 章的 Q2／Q4），能量流回直流鏈；但直流鏈電容能吸的能量 `0.5 × C × (V<sub>trip</sub>² − V<sub>dc</sub>²)` 通常只有動能的百分之一，電壓幾毫秒就衝到跳脫值，所以要煞車斬波器（brake chopper）把能量丟進煞車電阻（brake resistor），或直流鏈本身是電池才能真正回收。讀者要算：動能、平均與峰值再生功率、電容能吸多少、沒有斬波器時電壓會衝到多少、電阻功率夠不夠。並在最後一段「去向」用一句話各交代直接轉矩控制、無感測、EMI、軸承電蝕、功能安全。

**要點**：再生煞車（regenerative braking）、動態煞車（dynamic braking，電阻燒掉）、直流鏈電容（DC-link capacitor）、煞車斬波器、跳脫電壓 V<sub>trip</sub>（過電壓保護門檻）、回收效率 η（馬達與逆變器兩段損耗合併）。動能 `E<sub>k</sub> = 0.5 × J × (ω<sub>1</sub>² − ω<sub>2</sub>²)`；等減速的煞車轉矩 `T<sub>b</sub> = J × |ω<sub>1</sub> − ω<sub>2</sub>| / t`；回到直流鏈的能量 `E<sub>b</sub> = η × E<sub>k</sub>`；峰值再生功率 `P<sub>peak</sub> = η × T<sub>b</sub> × max(ω<sub>1</sub>, ω<sub>2</sub>)`（減速開始那一刻）；電容能吸 `E<sub>cap</sub> = 0.5 × C × (V<sub>trip</sub>² − V<sub>dc</sub>²)`；沒有斬波器的終電壓 `V<sub>free</sub> = √(V<sub>dc</sub>² + 2 × E<sub>b</sub> / C)`；到跳脫的時間 `E<sub>cap</sub> / P<sub>peak</sub>`；電阻在 V<sub>trip</sub> 時的功率 `V<sub>trip</sub>² / R<sub>b</sub>`，要 ≥ P<sub>peak</sub>。來源：P3 上 §3（驅動硬體）、下 §11、§12；再生能量的計算由本課依 principles-first「能量去向」補。

**推導必寫**：（a）第 01 章 I < 0 時 P<sub>mech</sub> < 0：機械功率變電功率，經上臂開關或二極體流回 V<sub>dc</sub>。（b）動能公式與等減速下的轉矩、功率（功率在高速端最大）。（c）電容儲能 `0.5 C V²`，從 V<sub>dc</sub> 充到 V<sub>trip</sub> 只多存那一點差。（d）斬波器：V > V<sub>trip</sub> 就把電阻接上，電阻功率 V² / R，要能吃掉峰值功率，平均功率再依煞車佔空比決定電阻的熱額定。（e）電池直流鏈：E<sub>b</sub> 真的回收，換算 Wh = J / 3600。假設：η 常數、電容理想、減速等加速度、忽略摩擦。

| 正確性判準 | ① Ek > 0 → 「判讀：減速，X J 動能有 Y J 回到直流鏈」；Ek < 0 → 「加速：能量從直流鏈流向馬達，這一段不是再生」；Ek = 0 → 「等速，沒有能量交換」；② Ek > 0 且 Eb > Ecap → 「電容只吃得下 X %，Y ms 後電壓到跳脫值，剩下的必須進電阻或電池；沒有斬波器時電壓會衝到 Z V」；Eb ≤ Ecap → 「電容吃得下全部，不會跳脫」；③ PR ≥ Ppeak → 「電阻 X W ≥ 峰值 Y W，斬波器撐得住」；否則「電阻功率不足，電壓仍會爬升，需要更小的 R_b 或更長的煞車時間」；④ 每次寫「若直流鏈是電池，這 X Wh 可以真正回收」 |
| 邊界情形 | n1 = n2 → 等速訊息；vtrip ≤ vdc → 斬波器一直導通訊息；t = 0.1 且 J 大 → 峰值功率極大、電阻不足；不得輸出 `NaN` |

**不要混淆（至少四條）**：「再生」是能量回直流鏈，「動態煞車」是燒在電阻上——斬波器＋電阻的系統其實是後者，只是經過直流鏈；電容是「緩衝」不是「儲能」，1000 µF 在 300 V 只存 45 J；煞車轉矩由減速率決定，與煞車方式無關；回收效率 η 不是馬達效率，是整條鏈（馬達→逆變器→直流鏈）的乘積。

**可觀察證據**：直流鏈電壓表（或示波器）在減速時看到電壓上升、到 V<sub>trip</sub> 時斬波器動作電壓被夾住；電流探棒看直流鏈電流反向。**能證明**能量方向與斬波器門檻；**不能證明** η 的值（要同時量軸功率與直流鏈功率）。

**連到哪門課**：電容儲能 0.5 C V² 見 `../../02-電機核心/電路學-互動課程/06-電容與電感.html`；四象限與 I < 0 見本課第 01 章。**去向（各一句，不展開）**：直接轉矩控制（direct torque control, DTC）不做電流迴路、直接用轉矩與磁鏈誤差查表選向量；無感測控制（sensorless control）用反電動勢或高頻注入估角度，取代第 10 章的編碼器；高 dv/dt 帶來 EMI 與長纜反射；共模電壓經軸承放電造成軸承電蝕；功能安全（IEC 61800-5-2 的 STO）要求能可靠地切斷轉矩。**韌體那一端**：斬波器通常是硬體比較器加一個 PWM 通道，門檻是一個參數；再生限制常以「直流鏈電壓 → 允許的負 i<sub>q</sub>」的外層迴路實作。
