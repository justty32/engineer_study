# 電機工程 學習計畫

> 風格：概論重點式（每科一篇，抓核心觀念與直覺說明，公式適量）。
> 語言：繁體中文。每科核心名詞收錄於 [中英名詞對照表](中英名詞對照表.md)。
> 重點：依大學課綱從基礎紮實重建；通訊為特化領域，亦從基礎重寫。

## 進度

### 第一階段 — 數理基礎（共通基礎）
數理基礎為工程學科之基石，詳細內容詳見 [共通基礎/](../共通基礎/)。

- [x] **微積分（Calculus）**：詳見 [共通基礎/數學/01-微積分.md](../共通基礎/數學/01-微積分.md)。電機工程中用於電路分析、電磁波傳遞與信號處理的連續變化描述。
- [x] **線性代數（Linear Algebra）**：詳見 [共通基礎/數學/02-線性代數.md](../共通基礎/數學/02-線性代數.md)。系統建模、狀態空間分析與數位信號處理的矩陣工具。
- [x] **工程數學（Engineering Mathematics）**：詳見 [共通基礎/數學/03-工程數學-上.md](../共通基礎/數學/03-工程數學-上.md)。包含 ODE、PDE、複變與傅立葉分析，為電機分析必備。
- [x] **機率與統計（Probability and Statistics）**：詳見 [共通基礎/數學/04-機率與統計.md](../共通基礎/數學/04-機率與統計.md)。通訊雜訊分析、資訊理論與感測資料處理的核心。
- [x] **普通物理（General Physics）**：詳見 [共通基礎/物理/01-普通物理-上.md](../共通基礎/物理/01-普通物理-上.md)。建立電磁學、量子力學與半導體物理的直覺基礎。
