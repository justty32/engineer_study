# M4 生醫晶片與穿戴式裝置（BioMEMS / Wearables）概論

> 醫電特化第 4 科。
> 名詞對照見 [中英名詞對照表 → 生醫晶片](../中英名詞對照表-3.md#生醫晶片)。

## 這科在學什麼

把半導體與 MEMS 技術用在「**體外生醫感測平台**」與「**體內植入式 / 穿戴式生醫晶片**」上。內容含 BioMEMS 製程、微流控、CMOS 生醫前端 IC、植入晶片無線供電 / 通訊、穿戴系統設計。是 M1（訊號處理）+ M2（感測 / 儀器）的「硬體實作層」。

## 第 1 章　BioMEMS 概念

### 1.1 什麼是 BioMEMS
微機電系統用在生物醫學：感測、致動、流體操控、組織介面、植入。

四大技術支柱：
- **微影 / 微加工**：把感測 / 致動結構縮到 µm 級。
- **微流控**：在 µL–nL 體積內精確操控液體。
- **CMOS 整合**：感測前端電路同晶片做出來。
- **包裝 / 生物相容**：保證在體液中能長期工作。

### 1.2 商業範例
- 連續血糖儀（CGM）。
- 數位 PCR / dPCR（液滴 / 微井陣列）。
- COVID-19 抗原試紙 / 微流控檢測卡匣。
- 微針陣列（microneedle）給藥 / 採血。
- 視網膜植入晶片（Argus II 系列，已於 2019 年停產）。
- DNA / RNA 定序晶片（Illumina、Oxford Nanopore）。

例：一個微電極陣列有 $100\times100$ 個感測點，中心間距為 $50\ \mu\text{m}$。步驟：感測點總數為 $100\times100=10{,}000$；忽略邊界餘量時，單邊長約 $100\times50\ \mu\text{m}=5$ mm。答案：約可在 $5\text{ mm}\times5\text{ mm}$ 範圍排列一萬個感測點。

## 第 2 章　微加工與材料

### 2.1 主流製程
- **體型微加工**：對 Si 用 KOH / TMAH 各向異性蝕刻、DRIE 深蝕。
- **表面微加工**：在 Si 上沉積 / 蝕刻多層膜形成懸臂、薄膜。
- **軟微影**：PDMS 鑄模製作微流道。
- **3D 列印**：雙光子聚合（two-photon polymerization）可達 µm 級結構。
- **薄膜彈性電子**：把電子做在可延展基板上，貼附皮膚 / 器官。

### 2.2 常用材料
- **Si、SiO₂、Si₃N₄**：基板 + 絕緣。
- **金屬**：Au、Pt（生物相容）、Ti（封裝）。
- **聚合物**：PDMS（微流道）、Parylene（薄膜封裝）、PI（柔性）、PEDOT:PSS（神經電極）。
- **奈米材料**：石墨烯、奈米線、奈米管（高靈敏感測）。

例：DRIE 以平均 2 µm/min 的速率蝕刻 50 µm 深的矽結構。步驟：時間 $=50/2=25$ 分鐘。答案：理想蝕刻時間為 25 分鐘；實際製程還要校正負載效應與起停過渡。

## 第 3 章　微流控（Microfluidics）

### 3.1 流體物理在 µm 尺度
- **雷諾數低（Re < 1）**：$Re=\rho vL/\mu$，故層流為主、無湍流，混合靠擴散。例如水的 $\rho\approx1000$ kg/m³、$\mu\approx10^{-3}$ Pa·s，在 100 µm 通道以 1 mm/s 流動時，$Re\approx0.1$。
- **表面張力主導**：毛細現象重要。
- **電動驅動**：電泳、介電泳、電滲。

### 3.2 元件
- **微泵 / 微閥**：壓電、熱氣動、磁致動。
- **混合器**：被動（曲折通道、3D 結構）、主動（聲流、磁攪拌）。
- **液滴生成（droplet generator）**：T 形或流動聚焦結構產生單一分散液滴 → 數位 PCR / 數位 ELISA 基礎。
- **分離 / 濃縮**：磁珠、聲音波（acoustofluidics）、介電泳。

### 3.3 應用
- **POCT 卡匣**：把採樣 → 試劑混合 → 反應 → 偵測整合在一片塑膠卡匣裡。
- **器官晶片（Organ-on-a-chip）**：動物實驗替代方案。
- **單細胞分析**：每個液滴包一個細胞做 RNA / DNA 定序。
- **連續血糖 / 連續生化**：皮下微通道採樣。

## 第 4 章　CMOS 生醫前端晶片

### 4.1 為什麼要客製 IC
- 大通道數（EEG/ECoG 32–1000+）。
- 極低雜訊（< 1 µV rms）。
- 極低功耗（穿戴 / 植入電池或無線供電）。
- 整合感測器 + AFE + ADC + 數位 → 單晶片。

### 4.2 經典模組
- **低雜訊放大器（LNA）**：chopper 放大器先將低頻訊號調變到高頻，避開 1/f 雜訊主導區後放大，再解調回基帶；CMRR > 120 dB。
- **可程式增益 / 可調截止頻率**：適應不同訊號類型。
- **低功耗 ADC**：SAR、Sigma-Delta；常數 µW–數百 µW / 通道。
- **數位處理區塊**：濾波、特徵擷取、壓縮、加密。
- **無線通訊**：BLE、UWB、近場感應。

### 4.3 多通道神經記錄晶片
- Intan RHD2000 系列、Neuropixels（IMEC）、Blackrock Cereplex。
- Neuropixels：384 同時記錄通道 + 960+ 可選通道，整合 ADC，矽探針 1 cm 長。
- 設計挑戰：通道間串擾、時序對齊、大量資料介面（LVDS、Serializer）。

### 4.4 心電 / 生命徵象 SoC
- 整合 ECG + PPG + IMU 介面、低功耗 MCU、藍牙、PMU、心律辨識加速器。
- 實作常是多晶片組合，例如 nRF5340 藍牙 MCU + MAX30001 ECG AFE，或 MAX32664 生物辨識感測器中樞再外接 PPG / IMU；單一晶片不一定同時整合所有介面。

### 4.5 影像感測器（生醫專用）
- **X 光平板偵測器**：直接式以 a-Se 光導層配 a-Si TFT 主動矩陣讀出；間接式以閃爍體配 a-Si TFT 或結晶矽 CMOS 偵測器。
- **CMOS 影像感測器**內視鏡（5×5 mm 微相機）：膠囊內視鏡（PillCam）。
- **時間相關單光子計數（TCSPC）**：螢光壽命影像、TOF-PET 前端。

例：384 通道神經記錄晶片每通道以 30 kS/s、10 bit 取樣。步驟：原始資料率為 $384\times30{,}000\times10=115.2$ Mbit/s。答案：尚未加入框架與錯誤檢查前就需 115.2 Mbit/s，因此晶片端常先做事件偵測或壓縮。

## 第 5 章　穿戴式裝置系統設計（複習 + 深入）

感測、電池、duty-cycling 與 OTA 的完整系統脈絡見 [M2 下篇第 12 章](M2-生醫感測與儀器-下.md#第-12-章-穿戴式裝置)；本章從晶片平台與邊緣 ML 部署角度補充。

### 5.1 SoC 平台
- 低功耗 MCU + BLE：Nordic nRF52/53、Apollo、Dialog DA1469x、STM32WB。
- 部分平台加上 ML 加速能力；例如 STM32N6 含 Neural-ART NPU，其 Cortex-M55 支援 Helium 向量處理。STM32U5 為 Cortex-M33，不含 Helium。
- Wear OS 等級平台：Qualcomm Snapdragon W5、Apple S 系列。

### 5.2 演算法 deployment
- 模型壓縮：量化、剪枝、Knowledge Distillation。
- 框架：TFLite Micro、X-CUBE-AI、Edge Impulse、NanoEdge AI。
- 部分模型在邊緣推論（心律分類），部分傳到手機 / 雲端。

例：穿戴平台使用 300 mAh 電池，平均電流為 3 mA。步驟：理想續航 $=300/3=100$ 小時，換算為 $100/24\approx4.17$ 天。答案：約 4.2 天；若目標是一週，平均電流須再降到約 1.79 mA 以下。

## 第 6 章　植入式生醫晶片

### 6.1 主要場景
- 心律調節器 / ICD / CRT（複習 [M2 下](M2-生醫感測與儀器-下.md)）。
- 神經調節（DBS、SCS、VNS）。
- 腦機介面（BCI）。
- 人工耳蝸、人工視網膜。
- 智慧型藥物泵（胰島素）、植入式肺動脈壓感測（CardioMEMS）。
- 連續血糖（CGM 半植入）。

### 6.2 共通子系統
- **生物相容封裝**：鈦罐 + 玻璃饋通；新一代用柔性聚合物（Parylene、PI）封裝。
- **生物相容電極**：Pt、PtIr、IrOx、PEDOT:PSS、石墨烯（為了低阻抗 + 長期穩定）。
- **記錄 / 刺激 ASIC**。
- **無線通訊**：MICS、ISM、UWB、近場感應；植入式天線設計受人體環境影響大。
- **無線供電**：感應耦合 (~MHz) + 整流 + LDO；或植入可充電電池 + 無線充電（如 Medtronic Activa RC）。
- **安全機制**：通訊加密、防 EMI 干擾、MRI 條件相容性。

### 6.3 設計重點
- **熱**：植入物表面溫升不可超過約 2°C，避免組織損傷。
- **長期可靠**：10–15 年無故障；不像消費電子可隨時換機，植入物故障往往就要開刀取出或更換。
- **故障安全**：感測 / 致動冗餘；通訊失聯下仍能基本運作。

例：植入物的感應供電輸入為 100 mW，線圈到整流後的總效率為 40%，晶片負載需要 25 mW。步驟：可用功率為 $100\times0.40=40$ mW，裕量為 $40-25=15$ mW。答案：供電足夠，理想功率裕量為 15 mW。

## 第 7 章　核酸定序與數位 PCR 晶片

### 7.1 高通量定序（NGS）
- Illumina：橋式擴增 + 螢光合成 + 大型 CMOS 感測器陣列。
- 一次數十 GB–TB 級資料。

### 7.2 奈米孔定序（Nanopore）
- 單分子穿過奈米孔產生電流變化 → 推測鹼基。
- Oxford Nanopore MinION：USB 大小、即時定序。
- 適用 COVID 變異株現場快速定序。

### 7.3 數位 PCR / 數位 ELISA
- 微井 / 液滴陣列分割樣本 → 計算「有 / 無」陽性 → 絕對定量。
- 罕見變異偵測（液態切片）、ctDNA、低濃度感染源檢測。

例：數位 PCR 將樣本分到 20,000 個微井，其中 2,000 個呈陽性，陽性比例為 0.10。步驟：用 Poisson 校正，平均拷貝數 $\lambda=-\ln(1-0.10)\approx0.105$ copy/井；總拷貝數約 $0.105\times20{,}000=2107$。答案：約有 2,107 個目標分子，不宜直接把 2,000 個陽性井當作分子數。

## 第 8 章　生醫晶片的安全與規範

- **FDA**：依風險分類（Class I、II、III）；高風險 PMA、中風險 510(k) / De Novo。
- **MDR / IVDR（歐盟）**：MDR 規範一般醫療器材，IVDR 另規範體外診斷器材；兩者依風險分類決定符合性評估與公告機構介入程度，不可直接對應美國 FDA 或台灣 TFDA 的分級。
- **TFDA**：台灣，依國際標準參照。
- **ISO 10993**：生物相容性試驗。
- **ISO 14708**：植入醫材。
- **IEC 62304**：軟體生命週期。
- **ISO 13485**：品質管理系統。

例：假設某植入晶片每年的無故障率為 99.9%，且各年失效機率獨立。步驟：10 年無故障率為 $0.999^{10}\approx0.990$。答案：10 年可靠度約 99.0%；高風險醫材仍須分析失效模式，不能只看單一平均值。

## 第 9 章　產業 / 研究地景速覽

- **學術圈**：CMU、Stanford、MIT、Caltech、Imperial、IMEC、Tokyo、台灣的台大 / 清華 / 陽明交大；生醫工程系與電機系共同推動。
- **公司**：Medtronic、Abbott、Boston Scientific、Johnson & Johnson、Stryker、Edwards、新創（Neuralink、Synchron、Verily、Owlet）。
- **台灣強項**：晶圓代工、封裝、感測器、台大電機 / 醫工系跨領域團隊。

例：某跨領域計畫有 12 個團隊，其中 5 個做感測器、4 個做晶片、3 個做臨床驗證。步驟：感測器團隊比例為 $5/12\times100\%\approx41.7\%$。答案：三類比例約為 41.7%、33.3%、25.0%，可據此初估共同設備與審查人力的配置。

## 第 10 章　跨領域 / 未來方向

- **生物相容軟性電子**：與器官界面無縫整合。
- **AI 加速整合進醫材**：Neural Engine in pacemaker / hearing aid。
- **多模態穿戴**：PPG + EEG + EMG + 呼吸一站式。
- **自驅動 / 能量收集醫材**：免電池植入。
- **數位孿生 + AI 個人化**：模擬病人對藥物 / 刺激的反應。
- **腦機介面（無線、高頻寬）**：Neuralink、Synchron 等臨床試驗中。

例：能量收集器平均提供 $50\ \mu\text{W}$；晶片啟動時耗 5 mW、占空比 1%，休眠時耗 $5\ \mu\text{W}$。步驟：平均功耗為 $5000\times0.01+5\times0.99=54.95\ \mu\text{W}$。答案：平均仍短缺 $54.95-50=4.95\ \mu\text{W}$，必須降低占空比、功耗或加入儲能。

## 碩士層級延伸（簡短）

- **微尺度輸送現象（Microscale Transport Phenomena）**：用擴散、對流、表面張力與電動力學分析微流道中的混合、分離及反應時間。
- **低雜訊生醫積體電路（Low-Noise Biomedical Integrated Circuits）**：從雜訊效率因子、輸入阻抗、電極偏移與功耗限制設計記錄前端。
- **植入式遙測與供電（Implant Telemetry and Power）**：比較感應、背向散射與射頻鏈路，並納入組織損耗、線圈錯位及溫升限制。
- **生醫封裝與可靠度（Biomedical Packaging and Reliability）**：研究水氣阻隔、饋通、加速壽命試驗與材料在體液中的退化機制。
- **晶片實驗室系統（Lab-on-a-Chip Systems）**：整合樣本前處理、流體控制、反應與讀出，並以回收率和檢測極限評估整體效能。
- **轉譯式生醫工程（Translational Biomedical Engineering）**：把原型的性能指標連到臨床需求、製造驗證、風險管理與試驗設計。

## 博士研究方向（列表）

- 電極—組織界面的多物理模型：預測電荷轉移、發炎反應與長期阻抗變化
- 微流控單細胞動力學：在可控微環境中追蹤細胞異質性與藥物反應
- 抗生物沾附封裝：延緩蛋白吸附、纖維包覆與水氣滲透造成的失效
- 超低雜訊、近感測運算架構：在資料產生處完成壓縮、特徵擷取與異常偵測
- 植入式系統的熱—電—磁協同最佳化：同時限制組織溫升、供電損耗與通訊誤碼
- 數位微流體的大規模控制與容錯：讓數百至數千液滴操作可校正、可追蹤
- 生醫晶片的加速壽命模型：由短期應力試驗推估多年植入可靠度

上述研究題目著重基礎機制與可驗證方法；較廣的應用走向見[第 10 章](#第-10-章-跨領域--未來方向)。
