# M1 生醫訊號處理（Biomedical Signal Processing）概論

> 醫電特化第 1 科。
> 名詞對照見 [中英名詞對照表 → 生醫訊號處理](../中英名詞對照表-3.md#生醫訊號處理)。

## 這科在學什麼

把人體量到的生理訊號（心電、腦電、肌電、呼吸、血氧……）做雜訊抑制、特徵擷取、辨識診斷。
DSP 學過的觀念（濾波、FFT、自適應、小波）+ 機率統計 + 一點生理學就能做大部分事。

## 第 1 章　常見生醫訊號（速覽生理基礎）

### 1.1 心電圖（ECG / EKG）
- 心肌細胞動作電位的體表投影。
- 頻寬：0.05–150 Hz；振幅 0.5–4 mV。
- 標準 12 導程；穿戴式常用 1–3 導程。
- 主要波形：P 波（心房去極化）、QRS 群（心室去極化）、T 波（心室再極化）。
- 應用：心律不整偵測、心肌梗塞診斷、HRV（心率變異）。

### 1.2 腦電圖（EEG）
- 大腦皮質神經元同步活動的頭皮投影。
- 頻寬：0.5–100 Hz；振幅 10–200 µV（極小！）。
- 國際 10–20 電極擺放系統。
- 頻帶：δ（< 4 Hz，深睡）、θ（4–8，淺睡 / 冥想）、α（8–13，閉眼放鬆）、β（13–30，清醒思考）、γ（> 30，高階認知）。
- 應用：睡眠分期、癲癇偵測、BCI（腦機介面）。

### 1.3 肌電圖（EMG）
- 肌肉收縮產生的電位。
- 頻寬：20–500 Hz；振幅 mV 級。
- 表面 EMG（sEMG）vs 針極 EMG。
- 應用：義肢控制、復健、運動分析。

### 1.4 其他重要訊號
- **PPG（光體積描記法）**：手錶手環的「綠光」量心跳，也可估血氧（PulseOx / SpO₂）、血壓（PWV）。
- **呼吸**：阻抗呼吸描記由 ECG 電極量測胸廓阻抗變化；胸帶多用感應式呼吸體積描記（RIP）量測伸縮。
- **EOG（眼電圖）**：眼球運動偵測。
- **GSR / EDA（皮膚電反應）**：交感神經活動。
- **體溫、血壓、血糖（CGM）**。

例：若要保留最高 150 Hz 的 ECG 成分，Nyquist 條件要求取樣率至少 $2\times150=300$ Hz；選用 500 Hz 取樣 10 秒，樣本數為 $500\times10=5000$ 點。答案：最低取樣率為 300 Hz，實際以 500 Hz 取樣會得到 5000 點。

## 第 2 章　量測與訊號條件（Signal Conditioning）

### 2.1 生醫電極
- **Ag/AgCl 凝膠電極**：黃金標準，但易脫水。
- **乾電極**：穿戴式長期監測。
- **侵入式（針極、植入電極）**：神經科學、植入裝置。

### 2.2 儀器放大器（Instrumentation Amp）
高 CMRR、高輸入阻抗、低雜訊。
- 標準三 op-amp 結構或單晶 IC（INA128、AD8221）。
- 共模電壓 50/60 Hz 抑制是關鍵。
體表電極拾取的 50/60 Hz 共模干擾可達伏特級，ECG 差模訊號卻只有毫伏特級；高 CMRR 可先壓低兩輸入端共有的干擾。高輸入阻抗則可減少電極接觸阻抗造成的訊號衰減與不平衡。

### 2.3 干擾源與對策
- **電源頻率（50/60 Hz）**：陷波濾波器 + 屏蔽 + 共模驅動（right-leg drive in ECG）。
- **動作偽影（motion artifact）**：高通 + 自適應濾波。
- **EMG 干擾到 ECG**：低通 + 形態學濾波。
- **基線漂移（baseline wander）**：監測模式可用約 0.5 Hz 高通；診斷模式應低至約 0.05 Hz，以免扭曲 ST 段。

### 2.4 ADC 與隔離
- 高解析（16–24 bit Sigma-Delta ADC）。
- **電氣隔離**：保護病人與儀器（IEC 60601 安規）；常用光耦合、變壓器、電容耦合。

例：儀器放大器的差模增益為 500、CMRR 為 100 dB，輸入含 1 mV ECG 與 1 V 共模干擾。步驟：ECG 輸出為 $500\times1\text{ mV}=0.5$ V；$100\text{ dB}$ 對應振幅比 $10^{100/20}=10^5$，共模干擾的輸入端等效殘值為 $1/10^5=10\ \mu\text{V}$，輸出端為 5 mV。答案：訊號約 0.5 V，共模殘值約 5 mV。

## 第 3 章　濾波與雜訊抑制

### 3.1 標準濾波器
ECG 監測模式常用 0.5–40 Hz 帶通，著重心律與 QRS 偵測；診斷模式常保留約 0.05–150 Hz，才能觀察 ST 段與高頻細節。兩者均可依電源頻率加入 50/60 Hz 陷波。

### 3.2 自適應濾波（複習 DSP）
- 心電中除去動作偽影：以加速度計當參考輸入，LMS 估計與動作相關的雜訊，再從 ECG 主輸入扣除。
- 胎兒 ECG 從母體 ECG 中分離：自適應 + 多通道。

### 3.3 小波去噪
- DWT 分解 → 小波係數閾值化（軟閾值將係數向零收縮，硬閾值將未過門檻者歸零）→ 逆轉換。
- 對突波（QRS）保留好，又能去除高頻雜訊。

### 3.4 EMD（經驗模態分解）
非線性 / 非平穩訊號分解成多個 IMF（本質模態函數）。對 ECG、PPG、HRV 有用。

例：用一階 RC 濾波器近似 ECG 監測模式的 0.5–40 Hz 帶通。步驟：由 $f_c=1/(2\pi RC)$，高通端取 $C=1\ \mu\text{F}$ 得 $R\approx318\text{ k}\Omega$；低通端取 $C=100\text{ nF}$ 得 $R\approx39.8\text{ k}\Omega$。答案：可先選約 318 kΩ 與 39.8 kΩ，再依標準阻值與實測微調。

## 第 4 章　特徵擷取（Feature Extraction）

### 4.1 時間域特徵
- 心率、RR 間期、QRS 寬度、QT 間期、PR 間期。
- 峰值、過零率、能量、形狀因子。

### 4.2 頻率域特徵
- 功率譜密度、各頻帶能量比（如 EEG 的 α/β 比）。
- 主頻、頻譜質心、譜熵。

### 4.3 時頻域特徵
- 短時傅立葉、Wigner-Ville、小波尺度圖。
- 對非平穩訊號（癲癇發作、心律不整）特別有用。

### 4.4 非線性 / 複雜度
- 樣本熵與近似熵量測時序的不規則性，模糊熵則用模糊相似度降低短訊號的門檻敏感性。
- Hurst 指數量測長程相關性；DFA（去趨勢波動分析）在移除局部趨勢後估計尺度律。
- HRV 分析的標準工具。

例：某段 EEG 的 α 頻帶功率為 $12\ \mu\text{V}^2$、β 頻帶功率為 $4\ \mu\text{V}^2$。步驟：$α/β=12/4=3$。答案：α/β 功率比為 3，表示這段訊號的 α 頻帶功率是 β 的三倍；生理解讀仍須配合量測狀態。

## 第 5 章　典型應用

### 5.1 QRS 偵測（Pan–Tompkins 演算法）
經典：帶通 → 微分 → 平方 → 移動平均 → 自適應門檻 → R 峰偵測。
1985 年提出至今仍是入門標準。

小算例：取樣率 200 Hz、帶通 5–15 Hz 時，150 ms 移動積分窗對應 $0.15\times200=30$ 點。若兩個過門檻的 R 峰相隔 160 點，則 RR 間期為 $160/200=0.8$ s，心率約 $60/0.8=75$ bpm。

### 5.2 心律不整分類
- 規則 / 不規則、寬 / 窄 QRS 分類。
- 心房顫動：RR 不規則、無 P 波（或變成 f 波）。
- 室速 / 室顫：寬 QRS 持續發作 → 急救。
- 現代：CNN / RNN 端到端 ECG 分類在特定資料集可達心臟科醫師水準，但不代表能直接外推至所有臨床情境。

### 5.3 睡眠分期
EEG + EOG + EMG（多通道睡眠多項生理檢查 PSG）。
分期：Wake、N1、N2、N3（深睡）、REM。
自動分期是熱門 ML 主題。

### 5.4 癲癇偵測
- 譜功率、譜熵、相位同步、小波。
- 即時長期 EEG 監測（病房 / 穿戴）。

### 5.5 腦機介面（BCI）
- **運動想像（motor imagery）**：分類想像動作。
- **P300、SSVEP**：事件相關電位 / 穩態視覺誘發電位。
- 從訓練資料學分類器；現代 BCI 開始用深度學習。

### 5.6 血氧 / 血壓
- **SpO₂**：兩波長（紅光 660 nm + 紅外 940 nm）PPG 的比值之比
  $$R=\frac{AC_{660}/DC_{660}}{AC_{940}/DC_{940}}$$
  再經個別設備的經驗校正曲線換算。線性近似 $SpO_2\approx110-25R$；例如 $R=0.8$ 時約為 90%。
- **血壓估測**：PWV（脈波速度）與 PTT（脈波傳導時間）多仍用於無袖帶連續血壓研究；PAT（脈波到達時間）還包含心臟射血前期。Huawei Watch D 系列是以微型氣囊作單次量測；Apple Watch 的高血壓功能是趨勢通知，並非連續輸出血壓數值。

## 第 6 章　機器學習在生醫的應用

### 6.1 傳統 ML
特徵 + SVM / Random Forest / Boosting。
仍是嵌入式 / 醫療裝置（運算受限）的主力。

### 6.2 深度學習
- 1D CNN：直接吃原始 ECG / PPG。
- RNN / LSTM / Transformer：時間序列。
- 自監督預訓練：BENDR、wav2vec for EEG。
- 缺資料 / 不平衡的對策：合成資料、遷移學習、Self-supervised。

### 6.3 臨床部署的挑戰
- **資料偏差**：訓練集多為健康年輕人 → 老年人 / 病患外推差。
- **可解釋性**：醫師需要理解模型決策（SHAP、Grad-CAM）。
- **法規**：FDA、CE、TFDA 認證、SaMD（軟體即醫材）。
- **連續學習**：模型更新 vs 監管。

例：一個心律不整分類器得到 TP = 90、FN = 10、FP = 20、TN = 80。步驟：靈敏度 $=90/(90+10)=90\%$，特異度 $=80/(80+20)=80\%$，精確率 $=90/(90+20)\approx81.8\%$。答案：三項指標依序為 90%、80%、81.8%，不能只用整體正確率描述臨床表現。

## 第 7 章　即時 / 嵌入式生醫處理

完整的穿戴式硬體、電池與更新設計見 [M2 下篇第 12 章](M2-生醫感測與儀器-下.md#第-12-章-穿戴式裝置)；本章著重訊號處理如何落到即時平台。

### 7.1 平台
- 穿戴：低功耗 MCU（STM32L、Nordic、Apollo），常含 DSP / NN 加速器。
- 居家：手機 / 樹莓派級邊緣裝置。
- 醫院：工作站 / 雲端。

### 7.2 設計挑戰
- 電池壽命 vs 取樣率 / 演算法。
- 與藍牙 / Wi-Fi / NB-IoT 整合。
- 醫療等級 EMC、生物相容性。
- 韌體 OTA + 安全更新。

例：三通道裝置以每通道 500 Hz、每筆 24 bit 連續取樣，平均電流為 2 mA、電池容量為 200 mAh。步驟：原始資料率為 $3\times500\times24=36{,}000$ bit/s；理想續航為 $200/2=100$ 小時。答案：資料率為 36 kbit/s，未計轉換損失與待機餘量時約可用 4.17 天。

## 第 8 章　訊號處理與生理的接合一例：HRV

心率變異性（HRV）：相鄰心跳 RR 間期的變化。反映自律神經平衡。
- **時間域指標**：SDNN、RMSSD、pNN50。
- **頻率域指標**：LF（0.04–0.15 Hz）、HF（0.15–0.4 Hz）、LF/HF。
- **非線性**：Poincaré plot、樣本熵。
應用：壓力評估、睡眠品質、心臟病風險、運動恢復。
這個案例同時用到 DSP（FFT、譜估測）、機率統計、非線性分析、機器學習、生理學——是生醫訊號處理的縮影。

小算例：5 個 RR 間期為 800、820、790、810、780 ms，平均為 800 ms；以樣本標準差計算，$SDNN\approx15.8$ ms。相鄰差為 20、−30、20、−30 ms，故 $RMSSD=\sqrt{(20^2+30^2+20^2+30^2)/4}\approx25.5$ ms。

## 與其他科目的銜接

- DSP：本科的工具箱。
- 機率與統計：分類、特徵分布。
- 控制：植入裝置（如人工胰臟、心律調節器）的閉迴路控制。
- 通訊：藍牙 / Wi-Fi 傳輸到雲端 / 手機。
- 嵌入式 / 計算機架構：穿戴 MCU 平台。

## 碩士層級延伸（簡短）

- **進階生醫訊號處理（Advanced Biomedical Signal Processing）**：研究多通道、非平穩與非高斯訊號的估測方法，並比較時頻、小波與盲源分離的適用條件。
- **統計訊號估測（Statistical Signal Estimation）**：以貝氏推論（Bayesian inference）、狀態空間模型與 Kalman 濾波器（Kalman filter）描述生理狀態及量測不確定性。
- **計算神經科學（Computational Neuroscience）**：把神經放電、群體編碼與神經動力系統連到 EEG、ECoG 與單細胞記錄。
- **臨床機器學習（Clinical Machine Learning）**：聚焦跨院資料偏移、校準、不確定性與可解釋性，並把模型指標連到臨床決策成本。
- **多模態生理融合（Multimodal Physiological Fusion）**：聯合 ECG、PPG、呼吸、IMU 與臨床資料，提高事件辨識的穩健性與可追溯性。

## 博士研究方向（列表）

- 自監督生理表徵學習：利用大量未標註波形建立可跨任務遷移的模型
- 個人化生理模型與數位生物標記：區分個體基準差異與真正病理變化
- 跨醫院、跨裝置的領域泛化：降低量測協定與族群差異造成的效能衰退
- 可信任臨床 AI：研究校準、不確定性估計、因果解釋與失效偵測
- 即時閉迴路神經訊號處理：在低延遲與低功耗限制下同步完成感測、判讀與刺激
- 隱私保護式生醫學習：結合聯邦學習、差分隱私與安全聚合處理敏感資料
