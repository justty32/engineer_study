# 圖解電磁學：專案定位

## 讀者基線

讀者會寫程式、有電機與通訊背景，但電磁與數學基礎不穩。從正負電荷、力、SI 單位與方向開始，00–02 自足補齊量、向量及微積分。目標是能從示意圖建立物理模型，選式，手算一組完整典型例，再用近題驗證轉移。

## 語言與名詞契約

全站繁體中文，首次名詞給繁中與英文；採庫侖、介電常數、磁導率、羅倫茲力、畢歐—沙伐、安培、法拉第、冷次、馬克士威、坡印廷、偏振。以圖及白話建立角色後才列公式。英文相量慣例固定 exp(jωt)，波的振幅均為峰值；平均功率出現 1/2。向量以粗體或向量字樣與 x̂/ŷ/ẑ 明示，正方向不能只靠顏色。

## prerequisite gap

主要理解債是電場不是力、通量不是流量、D 不等於 E、H 不等於 B、導體與介電質、導數積分的量與單位、相量與瞬時量、入射反射的方向、阻抗與電阻。依序由00–02補底，03–10靜電與導電，11–17磁場與感應，18–22波與界面，23–27傳輸線及導波輻射。

## 內容與教學邊界

同版三冊19章全部小節映射到28頁，完整地圖在章節規格與來源員的課綱對照。每頁遵循具體問題→解釋圖→符號角色→選式與推導條件→完整代入→單位與合理性→附提示近題→參數實驗→量測與限制。主例直接可見；近題可折疊但完整詳解自由開啟。章節作者唯讀三冊；來源線另依核准提案局部修訂，舊站保留；本課不教碩博士等級邊值解法或天線設計最佳化。

## 資產與持續性

公開檔全在 dist；僅本地 HTML/CSS/JS 與 inline SVG，無圖片下載、CDN、字型或執行依賴。關閉 JavaScript 仍可讀圖、主例、練習詳解與導覽。零基礎入口、主線與進階一窺在 index.html；符號與名詞在 glossary.html；公式查證在 sources.html；互動與算例契約在章節規格.json；驗收證據由獨立線維護。下一位 agent 依 PROJECT-BRIEF、BUILD-SPEC、派工資料與驗收紀錄即可延續。
