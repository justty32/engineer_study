# 圖解電磁學

以三冊電磁學筆記全部19章為骨架，28教學頁依序建立電荷、向量與微積分、靜電磁場、波、介面、傳輸線、波導與天線的模型。每頁有解釋圖、可跟做主例、分步提示近題、即時參數實驗及量測限制。
