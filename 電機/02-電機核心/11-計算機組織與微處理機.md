# 計算機組織與微處理機（Computer Organization & Microprocessors）概論

> 電機核心第 6 科。風格：概論重點式（擁有者軟體能力強，可較精簡，但要扣到硬體角度）。
> 名詞對照見 [中英名詞對照表 → 計算機組織與微處理機](../中英名詞對照表-2.md#計算機組織與微處理機)。

## 這科在學什麼

寫程式跑在 CPU 上，這科把 CPU 拆開來看：怎麼用邏輯閘 + 暫存器組成一台「會跑指令」的機器。內容包含 ISA、資料路徑、控制路徑、管線、記憶體階層、I/O、效能評估。
身為軟體強項者，重點放在「跟軟體的對應」與「為什麼硬體要這樣做」。

## 第 1 章　計算機抽象層

從上而下：
1. 應用程式（C++、Python）
2. OS、編譯器
3. 組合語言 / 機器碼
4. 微架構（管線、執行單元）
5. RTL（暫存器轉移層）
6. 邏輯閘
7. 電晶體
8. 物理（半導體）

**ISA**（Instruction Set Architecture）是第 3 層軟體與第 4 層微架構之間的契約。

## 第 2 章　數值表示

- 整數：補數表示（無號 / 有號）。
- 浮點數：**IEEE 754**，sign + exponent + mantissa；單精度 32 bit、雙精度 64 bit。注意非正規數、NaN、Inf 等特例。
- 字元：ASCII / Unicode。
- 大小端（endianness）：little vs big。

## 第 3 章　指令集架構（ISA）

### 3.1 分類
- **RISC**（精簡指令集）：少而簡單、固定長度。例：MIPS、RISC-V、ARM（AArch64 偏 RISC）。
- **CISC**（複雜指令集）：指令多、長度不固定。例：x86 / x86-64。現代 x86 內部解碼為 micro-ops，跑在類 RISC 微架構上。

### 3.2 主要指令類型
- **資料搬移**：load / store / move
- **算術 / 邏輯**：add、sub、and、or、shift
- **控制流**：branch、jump、call、return
- **特權 / 系統指令**：interrupt、syscall

### 3.3 定址模式
- **立即**：`addi x5, x0, 10`，常數 10 直接寫在指令內。
- **暫存器**：`add x3, x1, x2`，操作數都在暫存器。
- **絕對**：x86 `mov eax, [0x00401000]`，指令直接給記憶體位址。
- **相對**：RISC-V `beq x1, x2, label`，目標由目前 PC 加上位移量得到。
- **間接**：RISC-V `jalr x0, 0(x1)`，目標位址放在暫存器 `x1`。
- **基址 + 偏移**：`lw x4, 12(x5)`，有效位址為 `x5+12`。
- **索引**：x86 `mov eax, [rbx+rcx*4]`，適合以 `rcx` 索引 4 位元組陣列。

## 第 4 章　資料路徑與控制

### 4.1 單週期 CPU
一個時脈完成一條指令：取指 → 解碼 → 執行 → 存回。
資源使用率低、時脈受最慢指令拖累。

### 4.2 多週期 CPU 與控制單元
多週期 CPU 把取指、解碼、執行、記憶體存取與寫回分散到數個時脈，讓不同指令只走需要的步驟並重用 ALU 等硬體。**硬線控制（hardwired control）**直接用組合／序向邏輯產生控制訊號，速度快但修改困難；**微程式控制（microprogrammed control）**以控制儲存器中的微指令依序驅動資料路徑，較彈性但多一層解碼。

### 4.3 五階段管線（pipeline）
最經典的 MIPS 結構：
1. **IF**（取指）
2. **ID**（解碼 + 讀暫存器）
3. **EX**（執行 / ALU）
4. **MEM**（記憶體存取）
5. **WB**（寫回）

每個時脈周期都能「啟動」一條指令，吞吐量大增。

### 4.4 管線冒險（Hazards）
- **結構冒險**：資源衝突。
- **資料冒險**：相依（RAW）。解法：旁路（forwarding）、stall（插入泡）。
- **控制冒險**：分支。解法：分支預測（branch predictor）、延遲槽（早期 RISC）。

例如 `add x1, x2, x3` 後緊接 `sub x4, x1, x5`，第二條要讀取第一條尚未寫回的 `x1`，形成 RAW；旁路可把 ALU 結果直接送到下一條的輸入。若是 `lw x1, 0(x2)` 後立刻使用 `x1`，資料通常到 MEM 階段才產生，即使有旁路仍需停一拍，稱為 load-use hazard。

### 4.5 現代高階特性
- **超純量（superscalar）**：多條管線並行。
- **亂序執行（out-of-order）**：依資料相依重排，配合 register renaming。
- **推測執行（speculative）**：先猜後驗，效能高但有安全議題（Spectre/Meltdown）。
- **SIMD**（SSE、AVX、NEON）：向量化指令一次處理多個資料。

除了真正相依的 RAW，亂序執行還會遇到 WAR（後寫覆蓋前讀）與 WAW（兩次寫入順序顛倒）這兩種名稱相依；暫存器重新命名為不同實體暫存器可消除它們。

## 第 5 章　記憶體階層

### 5.1 階層
暫存器 < L1 cache < L2 < L3 < 主記憶體 < SSD/HDD < 網路儲存。
越上層越快越貴越小。

典型延遲的數量級可先記成：暫存器小於 $1\ \text{ns}$、L1 約 $1\ \text{ns}$、DRAM 約 $100\ \text{ns}$、SSD 約 $100\ \mu\text{s}$；實際值依處理器與工作負載而異。DRAM 比 L1 慢約百倍，正是快取利用區域性避免每次都等主記憶體的原因。

### 5.2 快取（Cache）
利用**時間 / 空間區域性**：
- **直接對映、組相聯、全相聯**。
- **替換策略**：LRU、LFU、Random。
- **寫策略**：write-through vs write-back；write-allocate vs no-write-allocate。
- **快取失誤類型**：強制失誤（compulsory）、容量失誤（capacity）、衝突失誤（conflict）。

**位址切分算例**：32 位元位址、32 KiB、8-way、每列 64 B 的快取共有 $32\text{ KiB}/(8\times64\text{ B})=64$ 組，因此 offset 為 $\log_2 64=6$ 位、index 為 $\log_2 64=6$ 位、tag 為 $32-6-6=20$ 位。

平均記憶體存取時間為
$$\mathrm{AMAT}=t_\text{hit}+m\,t_\text{miss},$$
其中 $m$ 是失誤率、$t_\text{miss}$ 是失誤額外代價。例如命中需 $1\ \text{ns}$、失誤率 5%、代價 $80\ \text{ns}$，則 AMAT 為 $1+0.05\times80=5\ \text{ns}$。

### 5.3 虛擬記憶體
- **頁式（paging）**：把虛擬位址空間與實體記憶體都切成固定大小的頁（如 4 KiB），用頁表把虛擬頁對映到實體頁框。
- **TLB**（Translation Lookaside Buffer）：快取 page table 翻譯。
- **頁缺失（page fault）**：訪問未在 RAM 的頁，OS 從磁碟載入。

### 5.4 一致性（Cache Coherence）
多核心系統下要保證所有核心看到一致的記憶體。常用 **MESI 協定**（Modified / Exclusive / Shared / Invalid）。

## 第 6 章　I/O 與匯流排

### 6.1 I/O 方式
- **輪詢（polling）**：CPU 不斷查狀態。簡單但浪費。
- **中斷（interrupt）**：硬體事件觸發 CPU 跳轉處理。
- **DMA（直接記憶體存取）**：另一個控制器代搬資料，CPU 只下指令。

### 6.2 匯流排
- 系統匯流排（CPU ↔ 記憶體）
- 周邊匯流排：PCI / PCIe、USB、SPI、I²C、UART、CAN。
  - 嵌入式系統用 SPI/I²C/UART 與感測器、IC 溝通。
  - PCIe 是現代高速擴充（GPU、SSD、網卡）。

## 第 7 章　效能評估

### 7.1 衡量
$$\text{執行時間}=\dfrac{\text{指令數}}{\text{程式}}\times\dfrac{\text{時脈周期}}{\text{指令}}\times\dfrac{\text{時間}}{\text{時脈周期}}=\text{IC}\times\text{CPI}\times T_c$$
（CPI = Cycles Per Instruction）

### 7.2 Amdahl 定律
若程式中某段佔比例 $p$ 被加速 $s$ 倍：
$$\text{總加速} = \dfrac{1}{(1-p)+\dfrac{p}{s}}$$
意義：不能被加速的部分最終會主導。

例如 $p=0.9$ 的部分加速 $s=10$ 倍，總加速為 $1/(0.1+0.9/10)=1/0.19\approx5.26$ 倍，而非 10 倍。

### 7.3 平行架構
- **指令級平行（ILP）**：超純量、亂序。
- **資料級平行（DLP）**：SIMD、GPU。
- **執行緒級平行（TLP）**：multi-core、SMT（hyperthreading）。
- **任務級平行**：分散式系統。

## 第 8 章　典型微處理器與微控制器

- **通用 CPU**：x86、ARM、RISC-V。
- **MCU（微控制器）**：STM32（Cortex-M）、AVR、ESP32、PIC ——含 CPU + 記憶體 + I/O，用於嵌入式系統。
- **DSP**：TI C6000、ADI SHARC，最佳化 MAC 等運算。
- **GPU**：高度平行向量處理器；現代 AI 加速主流。
- **NPU / TPU**：專用於神經網路推論的加速器。
- **FPGA**：可重組邏輯，介於 CPU 與 ASIC 之間。

## 第 9 章　組合語言與 CPU 的對應（極簡）

範例（RISC-V）：
```
add  x3, x1, x2     # x3 = x1 + x2
lw   x4, 0(x5)      # x4 = *(x5 + 0)
sw   x4, 4(x6)      # *(x6 + 4) = x4
beq  x1, x2, label  # if x1 == x2 jump to label
```
所有高階程式經編譯器後，都會落到這種層級的指令序列。

## 第 10 章　微控制器內部：記憶體映射 I/O、中斷向量與計時器

前九章談的是「CPU 怎麼執行指令」；台灣「微處理機」課綱還要求看懂一顆 MCU（如 8051、Cortex-M）怎麼把 CPU 接到外面的世界。本章以 ARM Cortex-M 為例給出最小骨架，細節見 [E1 嵌入式系統基礎](../09-嵌入式特化/E1-嵌入式系統基礎.md)。

### 10.1 MCU 內部方塊
一顆 MCU 在同一晶片上整合：
- **CPU 核心**（含 NVIC 中斷控制器）
- **Flash**（放程式與常數）與 **SRAM**（放變數與堆疊）
- **匯流排矩陣**：讓 CPU 與 DMA 同時存取不同記憶體與周邊
- **周邊**：GPIO、計時器、UART／SPI／I²C、ADC、看門狗（watchdog）
- **時脈樹**：振盪器、PLL 與各周邊的時脈開關（不用的周邊關時脈省電）

### 10.2 記憶體映射 I/O（Memory-Mapped I/O）
周邊的控制暫存器被分配在位址空間裡，CPU 用一般的 load／store 指令讀寫它們，不需要專用 I/O 指令（x86 另有 `in`／`out` 的**埠映射 I/O**，8051 則用特殊功能暫存器 SFR）。Cortex-M 的位址空間有固定分區：
- `0x0000_0000` 起：Code（Flash）
- `0x2000_0000` 起：SRAM
- `0x4000_0000` 起：周邊暫存器
- `0xE000_0000` 起：核心私有周邊（NVIC、SysTick）

在 C 裡寫周邊暫存器必須加 `volatile`，告訴編譯器每次都真的讀寫該位址，不可快取在暫存器或省略：
```c
#define GPIOA_ODR (*(volatile uint32_t *)0x48000014)
GPIOA_ODR |= (1u << 5);   /* PA5 輸出高電位 */
```
（實際位址依晶片手冊為準；此例取自 STM32F3／L4 系列的 GPIOA：基址 `0x48000000`、ODR 偏移 `0x14`。）

### 10.3 中斷向量表
第 6.1 節的「中斷」在硬體上靠**中斷向量表**落實：一張放在固定位址的函式指標陣列，每個中斷源對應一格。Cortex-M 重置後向量表位於位址 0：
- 第 0 格：堆疊指標初值
- 第 1 格：Reset handler（開機後第一個執行的函式）
- 其後：NMI、HardFault 等例外，再來是各周邊中斷（IRQ）

中斷發生時，硬體自動把部分暫存器壓入堆疊、從向量表取出 ISR 位址跳過去；**NVIC** 依優先序決定能否搶占正在執行的 ISR（巢狀中斷）。ISR 應短小、只設旗標或搬資料，重活留給主迴圈。

### 10.4 計時器（Timer）
計時器是一個由時脈驅動的計數器：時脈先經**預除頻器**（prescaler, PSC）分頻，再由計數器數到**自動重載值**（ARR）後歸零並觸發更新事件或中斷：
$$f_\text{update}=\frac{f_\text{clk}}{(\text{PSC}+1)(\text{ARR}+1)}$$
例如 $f_\text{clk}=72$ MHz、PSC $=7199$、ARR $=9999$：$72\times10^6/(7200\times10000)=1$ Hz，即每秒中斷一次。

同一計時器加上**比較暫存器**（CCR）即可輸出 PWM：計數值小於 CCR 時輸出高、否則輸出低，工作週期 $=\text{CCR}/(\text{ARR}+1)$；上例若 CCR $=1000$，工作週期為 $10\%$。計時器也能做**輸入捕捉**（記下外部邊緣發生時的計數值，用來量頻率或脈寬）。

### 10.5 與前面章節的對應
- 10.2 的 load／store 就是第 3 章 ISA 的記憶體指令；在有資料快取的處理器上（如 Cortex-M7），周邊區域必須設為不可快取，否則讀到的是第 5 章快取裡的舊值而非硬體當下的狀態。
- 10.3 是第 6.1 節「中斷」的硬體實作；第 6.1 節的 DMA 在 MCU 上也是一個透過匯流排矩陣存取記憶體的周邊。
