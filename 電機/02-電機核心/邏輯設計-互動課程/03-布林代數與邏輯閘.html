03・真值表與代數式是同一個函數的兩種寫法

布林代數與邏輯閘：把「窮舉所有情況」寫成可以化簡的式子

一個邏輯函數可以用表描述，也可以用式子描述。這章先把兩種寫法接成雙向通道，再證明只用一種閘就能做出全部邏輯——這件事決定了整個 CMOS 產業長成今天的樣子。

這章假設已懂：00 數位世界觀的「0 與 1 是電壓區間」，以及01 數值系統與編碼的位元與位元寬度。

痛點：表我看得懂，為什麼還要學一堆定律

很多人第一次看到真值表（truth table）都覺得沒什麼難的：把每一種輸入組合的答案逐列列出來就好了。既然表已經把函數講完，為什麼還要背交換律、吸收律、狄摩根定律這一大串？直接查表不行嗎？

不行，理由有兩個。第一，表會爆炸。n 個輸入有 2n 列，每列答案各自可以是 0 或 1，所以一共有 22n 種可能的函數：2 個輸入 16 種、3 個輸入 256 種、4 個輸入 65536 種。表能描述函數，卻不告訴你「做出它要花幾個閘」。第二，表沒有可操作的化簡程序，式子有：有幾個乘積項、每項幾個字面，就大致對應要幾個閘、疊幾層延遲。

第二個痛點更實際：晶片手冊裡最便宜、最常見的元件是反及閘與反或閘，不是看起來最直觀的及閘與或閘。為什麼？答案不在數學裡，在 CMOS 的結構裡。

來源：10-邏輯設計 §2.1、§2.2。

白話直覺：一層閘就是一次「所有輸入同時投票」的決定

可以暫時把一個閘想成一台投票機：輸入是選票，輸出是開票結果；比喻到此為止，收回精確定義——閘是一組電晶體構成的電路，輸出電壓由輸入電壓連續決定，是我們約定把電壓區間讀成 0 與 1，才有「函數」這個離散說法。

依因果順序走一次。輸入從哪來：上一層閘的輸出電壓，已經落在高位準或低位準區間裡。這一層做了什麼決定：閘內的電晶體網路依輸入高低導通或截止，把輸出節點接到電源或接地；對外看起來，就是「查了一次真值表」。花掉多少代價：一顆 2 輸入反及閘（NAND gate）在 CMOS 裡是 4 顆電晶體，傳播延遲量級 1.0 ns；及閘（AND gate）不是更基本的東西，它是反及閘再串一個反相器，6 顆電晶體、延遲約兩倍。邊界在哪：輸入若落在禁區，輸出就不保證是合法的 0 或 1，布林代數的整套推理在那一刻失效；本課另假設同類閘延遲相同、不隨輸入組合變化，真實電路不是這樣。儀器量到什麼：邏輯分析儀只告訴你取樣時刻是 0 還是 1，看不到禁區，也看不到切換過程的電壓斜率。

所以布林代數不是「一堆要背的規則」，而是「在不改變任何一列輸出的前提下，把電路換成比較便宜的接法」的合法動作清單。寫成程式的話：真值表就是一張查表陣列，代數式就是把它壓縮成條件式。

推導：先證恆等式，再證一種閘就夠

（a）用真值表證狄摩根定律（De Morgan's laws）。布林代數的「證明」就是窮舉，因為輸入只有有限多種。取 A、B 兩個輸入共 4 列：左式 ¬(A + B) 在 00 這一列是 ¬0 = 1，在 01、10、11 三列都是 ¬1 = 0；右式 ¬A · ¬B 在 00 是 1 · 1 = 1，在 01 是 1 · 0 = 0，在 10 是 0 · 1 = 0，在 11 是 0 · 0 = 0。四列逐列相同，第一式成立。第二式同法：¬(A · B) 依序是 1、1、1、0，而 ¬A + ¬B 依序是 1、1、1、0，也逐列相同。

（b）反及閘的通用性（universal gate）。只要能用一種閘做出 NOT、AND、OR，就能做出任何函數——因為任何函數都寫得成這三種運算的組合。三個構造如下。NOT A = A NAND A：兩隻輸入接同一條線，等於算 ¬(A · A)，而 A · A = A（等冪律），所以結果就是 ¬A。A AND B = (A NAND B) NAND (A NAND B)：內層算出 ¬(A · B)，外層對它做剛剛那個「兩腳併一腳」的反相，得到 ¬¬(A · B) = A · B（雙重否定律）。A OR B = (A NAND A) NAND (B NAND B)：兩個內層先做出 ¬A 與 ¬B，外層算 ¬(¬A · ¬B)，由狄摩根第一式反過來讀，這就是 A + B。

（c）反或閘（NOR gate）也是通用閘，構造對稱：NOT A = A NOR A，因為 A + A = A 之後再反相；A OR B = (A NOR B) NOR (A NOR B)，內層做出 ¬(A + B)，外層再反相一次；A AND B = (A NOR A) NOR (B NOR B)，內層做出 ¬A 與 ¬B，外層算 ¬(¬A + ¬B)，由狄摩根第二式反過來讀就是 A · B。

（d）互斥或（XOR, exclusive OR）用四個反及閘組出來。構造是 A ⊕ B = (A NAND (A NAND B)) NAND (B NAND (A NAND B))。令 P = A NAND B，逐列驗證 4 列：A B = 00 時 P = 1，兩個內層分別是 ¬(0 · 1) = 1、¬(0 · 1) = 1，最外層 ¬(1 · 1) = 0；01 時 P = 1，內層是 ¬(0 · 1) = 1 與 ¬(1 · 1) = 0，最外層 ¬(1 · 0) = 1；10 時對稱得 1；11 時 P = 0，兩個內層都是 ¬(1 · 0) = 1，最外層 ¬(1 · 1) = 0。得到 0、1、1、0，正是互斥或。

（e）吸收律為什麼成立，逐步標明用了哪一條定律。要證 A + A · B = A。第一步 A + A · B = A · 1 + A · B（單位律，因為 A = A · 1）；第二步 = A · (1 + B)（分配律，把 A 提出來）；第三步 = A · 1（用 1 + B = 1，這是布林代數獨有的，算術沒有）；第四步 = A（單位律）。四步都各自對應一條公理，沒有一步是「看起來就是這樣」。

來源：10-邏輯設計 §2.2、§4.1。

NOT 只有一個輸入：¬0 = 1、¬1 = 0。本章與互動元件的預設輸入是 A = 0、B = 1、C = 0，選定的閘是 XOR，所以落在上表第二列，XOR 輸出 1（該列加粗處）。同列其他閘順手對照：AND 0、OR 1、NAND 1、NOR 0、XNOR 0。

分配律那 8 列的順序是 ABC = 000, 001, 010, 011, 100, 101, 110, 111。A = 0 的前 4 列兩邊都是 0，因為左式被 A 乘掉、右式兩個乘積項都含 A。A = 1 的後 4 列兩式都退化成 B + C，依序為 0、1、1、1。兩邊逐列相同，分配律成立。

量級對照：恆等式左右兩邊功能相同，成本不同。以共識律 A + ¬A · B = A + B 為例，左邊要 1 個反相器、1 個及閘、1 個或閘共 3 個閘，右邊只要 1 個或閘；單閘傳播延遲取 1.0 ns 時，左邊兩層約 2.0 ns，右邊一層約 1.0 ns。這就是化簡的全部意義：輸出逐列不變，閘數與延遲雙雙變少。

自由實驗：切閘看真值表，切恆等式看逐列比對

場景是一顆兩輸入的閘接在指撥開關上：A、B 是兩隻輸入，C 只有驗證分配律時才會用到。上半區顯示選定閘的完整真值表並標出目前落在哪一列，下半區把選定恆等式的左右兩式對全部輸入組合各算一遍。要看的是：切換輸入時輸出怎麼跳，以及恆等式兩邊是不是每一列都一致。

這個 widget 有兩區：上面看閘（用到 A、B，NOT 只用 A），下面驗恆等式（狄摩根／吸收／共識用 A、B，分配律才會用到 C）。閘 = XOR，真值表 00 → 0、01 → 1、10 → 1、11 → 0；目前 A = 0、B = 1，落在第 1 列，輸出 1。恆等式 = 狄摩根一 ¬(A + B) = ¬A · ¬B：00 列 1 = 1、01 列 0 = 0、10 列 0 = 0、11 列 0 = 0，四列全部相同，這條恆等式在全部 4 種輸入下都成立——布林代數的「證明」就是把全部情況窮舉一遍，因為只有有限多種。C 的勾選對這條恆等式沒有影響。XOR 不是基本閘，它是 A · ¬B + ¬A · B，用 4 個 NAND 可以組出來：A ⊕ B = (A NAND (A NAND B)) NAND (B NAND (A NAND B))。真值表與代數式是同一個函數的兩種寫法；能互相轉換，是後面所有化簡的前提。

不要混淆

  • XOR 不是「或」的一種寫法。邊界在兩個輸入都是 1 的那一列：1 ⊕ 1 = 0，而 1 + 1 = 1。互斥或問的是「兩者不同嗎」，或問的是「至少有一個嗎」。
  • NAND 不是「AND 的相反用途」，它是 ¬(A · B) 這個獨立的函數。在 CMOS 裡它反而比 AND 便宜：AND 等於 NAND 再串一個反相器。
  • 布林代數的 + 與 · 不是算術的加與乘。邊界有兩處：1 + 1 = 1（算術會進位），以及兩個運算對彼此都有分配律，A + B · C = (A + B) · (A + C) 也成立，算術只有乘對加有。
  • 「通用閘」是說用它能組出所有函數，不是說用它最省。用純 NAND 實作往往比混用閘多花層數；真實的合成工具會依照標準元件庫混用各種閘與各種驅動強度。

可觀察證據：拿什麼量、量到什麼

最便宜的驗證方式是在麵包板上插一顆 7400（內含四個 2 輸入反及閘），把兩隻輸入接到指撥開關、輸出接一顆 LED，把 4 種輸入組合逐一撥過，用萬用電表量輸出電壓確認落在高位準或低位準區間。接著用其中三顆反及閘按上面的構造接成 AND，與一顆現成的及閘晶片對照。

能證明：這顆晶片的真值表確實是 ¬(A · B)；以及用三顆反及閘組出來的 AND，其四列輸出與單顆及閘晶片完全相同——功能等價這件事被量出來了。不能證明：兩者的延遲相同。三顆串起來的路徑會慢大約三倍，而萬用電表與 LED 完全看不到這件事，要換示波器抓輸入邊緣到輸出邊緣的時間差才量得到。也證明不了「布林代數對所有情況都成立」——你只驗了 4 列；只是這次輸入組合恰好只有 4 種，窮舉正好等於完整證明。

連到哪門課

本章結論在真實裝置上的落點，是任何一顆數位晶片的標準元件庫：合成工具拿到你的式子後，會把它對映成庫裡實際存在的閘。只用反及閘造出整套邏輯的完整過程，見計算機組織的「只用反及閘造邏輯」；為什麼 CMOS 天生做出來的就是反及閘與反或閘，見電子學的 MOSFET 原理與三個工作區。下一章把真值表機械地翻成兩種標準型。
