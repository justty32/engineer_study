04・任何真值表都能機械地翻成式子

標準型 SOP 與 POS：一定寫得出來的起點，也一定不是最省的終點

拿到一張真值表，不必靈感也不必試誤，照兩條固定規則就能寫出電路的式子。這章給的是那兩條規則，以及一個同樣重要的壞消息：機械產生的式子必然比最短的答案貴。

這章假設已懂：03 布林代數與邏輯閘的真值表，以及 ¬、·、+ 三種基本運算。

痛點：表寫完了，然後呢

把規格翻成真值表通常不難：三個感測器至少兩個回報異常就發警報，這句話直接對應 8 列的 0 與 1。難的是下一步——這張表要怎麼變成一張可以交給工廠的接線圖？很多人在這裡卡住，因為前一章學到的恆等式只教你「怎麼把式子變短」，沒教你「第一個式子從哪來」。

更麻煩的是，如果沒有一套機械程序，每個人看同一張表寫出來的式子都不一樣，就沒辦法比較誰的比較省，也沒辦法把這件事交給工具做。這章要的正是「不必想」的程序：兩條規則，逐列掃過去，式子就出來了。代價是這個式子把每一列都當成獨立的一項，所以它幾乎永遠比最短答案貴——但它保證存在，這件事本身就有價值：它證明了任何布林函數都做得出來。

來源：10-邏輯設計 §2.3。

白話直覺：把「哪幾列是 1」直接翻成「哪幾條線並聯」

可以暫時把標準型想成一份逐列的清單：函數等於「第 3 列成立，或第 5 列成立，或第 6 列成立，或第 7 列成立」；比喻到此為止，收回精確定義——所謂「第 i 列成立」是一個具體的乘積項，它由全部輸入變數各出現一次組成，只有在那一列的輸入組合下才等於 1。

依因果順序走一次。輸入從哪來：n 條訊號線，以及它們各自的反相版本，共 2n 條可用的字面。這一層做了什麼決定：每一個乘積項用一個及閘去偵測「是不是正好落在我這一列」，最後用一個或閘把所有被偵測到的列並起來，得到輸出。花掉多少代價：若函數有 k 列為 1、有 n 個輸入，就是 k 個 n 輸入的及閘 + 1 個 k 輸入的或閘，再加上被用到的反相器；延遲固定是三層，反相器一層、及閘一層、或閘一層，單閘傳播延遲取 1.0 ns 時約 3.0 ns。邊界在哪：k 很大時或閘的輸入數會爆掉，真實元件庫沒有 32 輸入的或閘，必須拆成樹狀多層，延遲就不再是三層；此外 k = 0 或 k = 2n 時函數退化成常數，一個閘都不用。儀器量到什麼：邏輯分析儀掃過全部 2n 種輸入，可以逐列驗證輸出與表相同，但看不出你用了幾個閘。

寫成程式的話：真值表是一張查表陣列，標準型就是把這張陣列展開成一長串「或起來的條件」；下一章的化簡則是把這串條件合併成比較少、比較短的條件。

推導：兩條相反的規則，以及閘數怎麼算

（a）最小項（minterm, mi）為什麼只在自己那一列為 1。以三變數的 m5 為例，索引 5 的二進位是 ABC = 101，規則是「變數為 1 取原變數、為 0 取反相」，所以 m5 = A · ¬B · C。這個乘積只有在三個因子同時為 1 時才是 1，也就是 A = 1、B = 0、C = 1，正好是第 5 列。其他任何一列至少有一個因子為 0，整個乘積就是 0。

（b）最大項（maxterm, Mi）為什麼只在自己那一列為 0。同樣取索引 5，ABC = 101，但規則相反：「變數為 1 取反相、為 0 取原變數」，所以 M5 = ¬A + B + ¬C。這個和只有在三項同時為 0 時才是 0，也就是 A = 1、B = 0、C = 1，同樣是第 5 列；其他列至少有一項為 1，整個和就是 1。最大項的取反規則與最小項相反，這是本章最常錯的地方，不是筆誤。可以這樣記：最小項用「等於這一列」去偵測，最大項用「不等於這一列」去否決。

（c）為什麼 Σm 與 ΠM 的索引互補。真值表的每一列非 0 即 1，沒有第三種可能。積之和（sum of products, SOP）把為 1 的列全部或起來，和之積（product of sums, POS）把為 0 的列全部且起來；一個索引若在 Σm 裡，就不可能在 ΠM 裡，反之亦然。所以兩個集合的元素個數相加必定是 2n，三變數就是 8。

（d）本課的閘數計法（互動元件用同一套）。SOP：每個乘積項一個及閘（單一字面的項不需要閘）、輸出一個或閘（只有一個項時不需要）、每個被用到的反相輸入一個反相器（同一個變數的反相只算一次）。POS 完全對稱：每個和項一個或閘、輸出一個及閘、反相輸入同上。字面數的計法更簡單：把式子裡出現的變數符號個數加總，標準型就是項數乘以變數數。

最簡 SOP 要逐列驗證才算數：ABC = 000 → 0 + 0 + 0 = 0；001 → 0；010 → 0；011 → B · C = 1 → 1；100 → 0；101 → A · C = 1 → 1；110 → A · B = 1 → 1；111 → 1。與上面的真值表逐列相同。8 個閘變 4 個閘，而且不再需要任何反相器。以單閘 1.0 ns 估算，標準 SOP 是反相器、及閘、或閘三層約 3.0 ns，最簡 SOP 只有兩層約 2.0 ns。

邊界對照有三組。全部 8 列都是 1 → Σm(0…7)，SOP 寫出來是 8 個乘積項，但函數其實就是常數 F = 1，一個閘都不用；POS 是空集合（沒有任何最大項），本課約定顯示 F = 1。全部 8 列都是 0 → SOP 是空集合，顯示 F = 0；POS 則是 8 個和項。只有 m0 是 1 → SOP 只有一項 ¬A · ¬B · ¬C，3 個 NOT + 1 個 AND + 0 個 OR = 4 個閘，POS 卻有 7 個和項——這時候 SOP 明顯划算，這就是為什麼兩種標準型都要會：先數一數為 1 的列多還是為 0 的列多，挑短的那一種當起點。

自由實驗：改真值表的 F 欄，看兩種標準型同步長出來

不要混淆

  • 最大項的取反規則與最小項相反。邊界就在同一個索引上：索引 5 的 m5 = A · ¬B · C，而 M5 = ¬A + B + ¬C，兩者不是把符號換一換就好，連 0 與 1 該取誰都反過來。
  • Σ 與 Π 不是加總與連乘的算術符號。它們是簡記：Σm 讀作「把這些最小項或起來」，ΠM 讀作「把這些最大項且起來」，裡面的索引是列號，不是被加起來的數值。
  • 標準型不等於最簡型。同一個函數的標準 SOP 只有一種寫法，是唯一的；最簡型卻可能有好幾個一樣短的答案，不保證唯一。
  • ΠM(0, 1, 2, 4) 裡的索引指的是函數為 0 的那幾列，不是為 1 的列。看到 Π 就要換一套讀法，否則會把函數讀成它的補數。
  • 字面數少不等於閘數少。單一字面的乘積項不需要及閘，多輸入的閘在真實元件庫裡又要拆成多層；字面數只是第一層近似。

可觀察證據：拿什麼量、量到什麼

把這張真值表輸入任何一套 EDA 工具或線上邏輯化簡器，可以驗證它產生的標準 SOP 與這裡逐項相同；再把標準型與最簡型分別合成，用測試向量掃過全部 8 種輸入，在模擬器裡逐列比對兩個電路的輸出。實體上也可以做：把兩種接法各接一遍在麵包板上，指撥開關掃 8 種組合，用 LED 或邏輯分析儀對照。

能證明：兩個電路對全部 8 種輸入的輸出完全相同，也就是功能等價；以及各自用掉幾顆晶片、幾個閘——這是數得出來的。不能證明：哪一種在真實晶片上比較快。閘數少不代表延遲短，實際延遲還要看繞線長度、負載電容、每個閘的驅動能力與扇出；那要靠佈局後的靜態時序分析報告，不是靠數閘數。

連到哪門課

標準型是起點，把它壓到最短是下一章的卡諾圖與 Quine–McCluskey；另一條完全不化簡的路，是拿一顆多工器把真值表當查表直接查，見本課06 多工器、解碼器與編碼器。這些組合邏輯在一台真實處理器裡的位置——控制訊號怎麼由指令欄位算出來、算術單元怎麼接——見計算機組織的組合邏輯與算術。
