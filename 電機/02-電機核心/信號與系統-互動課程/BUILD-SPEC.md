## 0. 鐵律（違反即失敗）

1. **純原生 HTML／CSS／JavaScript，完全離線**。不得有圖片、外部字型、CDN、遠端 API、第三方腳本、分析碼、`fetch`、`XMLHttpRequest`。唯一允許的外部 URL 是每頁頂端 `main-site-link` 的 `https://justty32.github.io/engineer_study/`。
2. **`styles.css` 由正本 `專題/機器人運動學/互動課程/styles.css` 原樣複製，一個位元組都不改**。只用既有 class：`main-site-link`、`topbar`、`eyebrow`、`lead`、`prereq`、`note`、`warning`、`workspace`、`controls`、`output`、`grid`、`card`、`chapter-list`、`chapter-card`、`number`、`flow`、`term-list`、`term-card`、`dictionary-tools`、`pager`，以及原生 `table`／`details`／`summary`／`pre`／`code`。**不得新增 class、不得寫 inline `style`、不得加 `<style>` 區塊。**（註：頁尾一律寫 `<footer class="site-footer">`——**正本 `styles.css` 裡並沒有 `.site-footer` 規則**，它是 A 家族所有課程共用的無樣式慣例，verifier 不得因此判為「使用了不存在的 class」。）
3. **公式一律純文字 HTML，嚴禁 LaTeX**：不得出現 `\(` `\)` `\[` `\]` `$` `$$`，不得引入 MathJax／KaTeX／任何算式引擎。轉寫規約見第 3 節。
4. **禁止 `Math.random()`**。所有數值必須可重現。禁止 `setTimeout` 動畫、`localStorage`、`fetch`、`document.write`。
5. **每頁 UTF-8（無 BOM）**，`<html lang="zh-Hant">`，`<meta charset="utf-8">`。**行尾一律 CRLF**（`\r\n`）。
6. **嚴禁用 PowerShell 寫檔**（`Set-Content`／`Out-File`／`>` 重導向都會產生編碼壞損）。用 Write 工具直接寫，收尾以 Python 位元組級把 `\n` 正規化成 `\r\n`；**`styles.css` 是 `cp` 來的且靠位元組比對驗收，不得做 CRLF 轉換。**
7. **不得修改 `電機/02-電機核心/*.md`、`電機/中英名詞對照表-2.md`** 或任何既有檔案。本案只新增本資料夾內的檔。
8. **不得寫計分、進度百分比、解鎖、倒數、強制答對**。自我檢核可無限重做且不阻擋瀏覽。
9. **HTML 頁面不連 `.md` 檔**。來源以文字標註（例：「來源：09-信號與系統-下 §13.2」），且一律寫**筆記的章號**，不得寫成本課章號。
10. **每章正文（不含 `section.workspace` 內容）2000–3000 個中文字**（計法＝漢字＋全形標點）。低於 2000 視為未完成，高於 3000 要拆段但不得刪推導。
11. **不畫圖**。波形、頻譜、波德圖、零極點圖一律用數值與判讀句替代。
12. **用語鎖定（PROJECT-BRIEF 第 2 節，Lead 裁決）**：一律寫「摺積」「混疊」「轉移函數」「取樣」「脈衝響應」「步階」「極點／零點」。
    - **全課「卷積」恰好允許 2 處**：字典的「摺積」卡 1 處、`index.html` 的「用語說明」段 1 處，用途只是告訴讀者對照表寫的是哪個詞。**必須明碼書寫，不得使用 HTML 數字實體或字元實體規避掃描。**
    - **全課「摺疊」恰好允許 1 處**：字典的「混疊」卡。同樣必須明碼。
    - 「捲積」「採樣」「抽樣」「傳遞函數」「衝激」「階躍」**全課 0 處，無例外**。
13. **連續時間一律 `x(t)`（圓括號）、離散時間一律 `x[n]`（方括號）**，全課不得混用。虛數單位一律 `j`。
14. **微符號一律 U+00B5 `µ`，全檔 0 個 U+03BC `μ`**；歐姆一律 U+03A9 `Ω`，0 個 U+2126；公式中的負號一律 U+2212 `−`。
15. **`<option>` 內只能放純文字**（HTML 內容模型限制）。**不得放 `<sub>`／`<sup>`／`<b>`／`<strong>`**，下標一律寫成底線形式：`f_c`、`f_s`、`x[n]`、`T_1`、`omega_n`。本規格自己列出的 option 顯示文字也已照此寫，builder 照抄即可。
16. **本課不寫安全警語**。`p.warning` 只出現在 `index.html`（本站不畫圖的聲明）與第 12 章（混疊不可逆的提醒）兩處。verifier 不得以「缺安全警語」判為缺陷。

## 3. 公式轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。不要用 Unicode 下標數字（₀₁₂），避免不同字型高度不一。
- Unicode 數學符號（限這份清單）：`∫ ∮ ∑ ∞ √ ± × ⋅ ≈ ≠ ≤ ≥ ≪ ≫ ∝ ∈ ∠ ° → ⇒ ⇔ ∗ | ‖ ⟨ ⟩`
- 希臘字母：`α β γ δ ε ζ η θ λ π ρ σ τ φ χ ψ ω Δ Γ Σ Φ Ω`
- **摺積符號一律用 `∗`（U+2217 asterisk operator）**，例 `y(t) = x(t) ∗ h(t)`。**正文與公式中不得用半形星號 `*`**（會和乘號、Markdown 強調混淆）。**唯一例外：`<option>` 顯示文字**——內容模型只允許純文字，所以那裡用半形 `*` 當乘號、`^` 當次方、底線當下標（例 `A*cos(2*pi*f*t)`、`y(t) = x(t)^2`、`f_c`）。verifier 掃描半形 `*` 時要排除 `<option>` 行。
- **微符號一律用 `µ`（U+00B5 micro sign）**，含 µs、µV。**全檔不得出現 U+03BC 的 `μ`。**
- **負號一律用 U+2212 `−`**，不要用半形連字號 `-`（連字號只用在檔名與 CSS class）。
- 上標數字可直接用 `²` `³`；其餘次方用 `<sup>`。
- 歐姆符號用 `Ω`（U+03A9），不要用 U+2126。
- 單位一律半形英文緊接數字後空一格：`8000 Hz`、`44.1 kHz`、`125.000000 µs`、`−3.010300 dB`、`0.128000 s`、`5.000000 倍`。
- **樣本序號一律寫 `n`、bin 序號一律寫 `k`、諧波序號一律寫 `n`**（三者在不同章不得互換）。

### 3.2 排版規則

1. **連續時間與離散時間的括號不得混用**：`x(t)`、`h(t)`、`y(t)`、`X(jω)`、`H(s)` 用圓括號；`x[n]`、`h[n]`、`y[n]`、`X[k]` 用方括號；`X(e<sup>jω</sup>)`（DTFT）與 `X(z)`（Z 轉換）是連續變數的函數，用圓括號。
2. **分數**：單行寫成 `(分子) / (分母)`，例如 `(1) / (1 + j f/f<sub>c</sub>)`。分子分母都是單一符號時可省括號：`ω/ω<sub>n</sub>`、`f<sub>s</sub>/N`。
3. **多行分式**只在必要時用 `<pre>`，以 `─` 畫橫線，前後留一空行。
4. **導數**寫成 `dx/dt`、`d∠H/dω`；二階寫 `d²y/dt²`。不要用點記號。
5. **積分**：`∫<sub>−∞</sub><sup>∞</sup> x(τ)h(t − τ) dτ`。積分變數一律用 `τ`（連續）與 `k`（離散求和）。
6. **求和**：`∑<sub>k=−∞</sub><sup>∞</sup> x[k]h[n − k]`；有限長寫 `∑<sub>n=0</sub><sup>N−1</sup>`。
7. **指數中還有下標時，把下標壓平**：`e<sup>−t/τ</sup>`、`e<sup>jkω₀t</sup>` 寫成 `e<sup>jkω0t</sup>` 是**錯的**——正確寫法是 `e<sup>jkω</sup><sup>0</sup>` 也**不允許**；一律改寫成 `e<sup>j k ω0 t</sup>` 亦不允許。**本課的統一作法：把基頻寫成 `ω<sub>0</sub>` 時，指數整體改用 `exp( )` 函式形式**，例 `exp(j k ω<sub>0</sub> t)`、`exp(−j 2π k n / N)`、`exp(−αt)`。**指數內含下標時一律用 `exp( )`，不含下標時才可以用 `e<sup>…</sup>`**（例 `e<sup>−t/τ</sup>`、`e<sup>jωt</sup>`、`e<sup>st</sup>`）。
8. **複數**寫成直角式 `X = a + jb` 與極式 `X = |X|∠θ`。**虛數單位一律寫 `j`**，首次出現要說明「數學課寫 i，電機寫 j，因為 i 留給電流」。
9. **函式名**（sin、cos、tan、arctan、arccos、exp、ln、log、sinc、Re、Im、rms、max、min、round、ceil）用一般半形英文，不加標記。
10. **sinc 一律是歸一化版本**：`sinc(x) = sin(πx) / (πx)`，`sinc(0) = 1`。首次出現要寫出這個定義並註明「有些教科書用 sin(x)/x，本課全程用歸一化版」。
11. 公式所在段落用 `<p>`；需要凸顯時可用 `<code>`（`styles.css` 已設 `overflow-wrap:anywhere`）。
12. **系統描述用文字格式固定**：`輸入 x(t) → 系統 h(t) → 輸出 y(t)`，箭頭用 `→`。

### 00 `00-訊號與系統世界觀.html`

**目標**：先講清楚這門課在描述什麼——**訊號是一個函數，系統是把函數變成另一個函數的機器**——並且說明「什麼時候非用這套觀點不可」：當系統**有記憶**，輸出不再是輸入乘上一個固定倍數的時候。

**要點**：訊號（signal）＝把一個量指派給時間（或空間）的函數；系統（system）＝把輸入訊號對應到輸出訊號的算子 T，寫成 `y(t) = T{x(t)}`；本課骨架五步（訊號分類 → 系統分類 → LTI 的脈衝響應與摺積 → 傅立葉分析 → 拉氏／Z 轉換 → 取樣與還原，來源：09-信號與系統-上「這科在學什麼」）；**無記憶系統**的輸出只是輸入乘一個數，一個乘法就講完了；**有記憶系統**（電容要充電、機械有慣性）的輸出取決於過去，於是同一個振幅的輸入在不同頻率下得到不同的輸出振幅與相位——這就是**頻率響應**；一階系統的頻率響應 `H(jf) = 1 / (1 + j f/f<sub>c</sub>)`，`f<sub>c</sub>` 是轉角頻率（corner frequency，又稱 −3 dB 頻率）；增益 `|H| = 1/√(1 + (f/f<sub>c</sub>)²)`、相位 `∠H = −arctan(f/f<sub>c</sub>)`；dB 換算（振幅用 20 log<sub>10</sub>、功率用 10 log<sub>10</sub>）；相位延遲 `t<sub>p</sub> = |∠H| / (360°·f)` 與群延遲 `τ<sub>g</sub> = −d∠H/dω`。

**推導必寫**：（a）為什麼「有記憶」就必須換域：對一個線性非時變系統，輸入 cos(2πft) 出來一定還是同頻率的 cos(2πft + φ)，只有**振幅與相位**被改——這是弦波作為「本徵函數」的特權，也是整門課要把訊號拆成弦波的唯一理由。（b）一階系統的 |H| 怎麼來：`H = 1/(1 + jr)`，`r = f/f<sub>c</sub>`，取模得 `1/√(1 + r²)`，取幅角得 `−arctan r`。（c）−3 dB 的來歷：`r = 1` 時 `|H| = 1/√2 = 0.707107`，`20 log<sub>10</sub>(0.707107) = −3.010300 dB`，功率剛好剩一半。（d）群延遲的閉合式：`∠H = −arctan(ω/ω<sub>c</sub>)`，微分得 `τ<sub>g</sub> = (1/ω<sub>c</sub>) / (1 + (ω/ω<sub>c</sub>)²)`——**相位延遲與群延遲不是同一個數**，這是第 09 章的伏筆。

**數值實例**：f = 1000 Hz、f<sub>c</sub> = 1000 Hz、A = 1 V。

### 01 `01-訊號的分類.html`

**目標**：把訊號的五組分類從「背名詞」變成「拿到一個訊號能算出它屬於哪一類」，重點放在**能量訊號與功率訊號**——因為它決定了後面該用傅立葉轉換還是傅立葉級數。

**要點**：連續時間 x(t) 與離散時間 x[n]（**本課用括號形狀區分，圓括號連續、方括號離散**）；類比與數位的差別是**值**連不連續（量化），不是時間；週期訊號滿足 x(t) = x(t + T)，最小的正 T 是基本週期，`f<sub>0</sub> = 1/T`；**能量訊號** `E = ∫|x(t)|² dt < ∞` 且 P = 0；**功率訊號** `P = lim<sub>T→∞</sub> (1/T)∫<sub>−T/2</sub><sup>T/2</sup> |x(t)|² dt` 有限且 E = ∞；**所有週期訊號都是功率訊號、所有有限長且有界的訊號都是能量訊號**，但兩者都不是的訊號存在（例 t·u(t)）；奇訊號 x(−t) = −x(t)、偶訊號 x(−t) = x(t)，**任何訊號都能唯一拆成奇部＋偶部**：`x<sub>e</sub>(t) = [x(t) + x(−t)]/2`、`x<sub>o</sub>(t) = [x(t) − x(−t)]/2`；rms 值 `x<sub>rms</sub> = √P`。來源：09-信號與系統-上 第 1 章。

**推導必寫**：（a）為什麼要分能量與功率：`∫|x|²dt` 在物理上是「訊號在 1 Ω 電阻上放掉的總能量」，對永遠持續的弦波它會發散，所以只好改問「平均每秒放多少」——這就是功率。（b）衰減指數的能量：`E = ∫<sub>0</sub><sup>∞</sup> A²e<sup>−2t/τ</sup> dt = A²τ/2`（把指數的積分做出來，不要只給結果）。（c）弦波的功率：`P = (1/T)∫<sub>0</sub><sup>T</sup> A²cos²(2πft) dt = A²/2`，用 `cos² = (1 + cos2)/2` 這一步要寫出來；因此 `x<sub>rms</sub> = A/√2 = 0.707107A`——**與市電「110 V 是 rms、峰值 155.6 V」是同一件事**。（d）奇偶分解為什麼唯一：兩式相加得 x(t)、相減得 x(−t)，聯立唯一解。

**數值實例**：衰減指數 x(t) = A·e<sup>−t/τ</sup>·u(t)，A = 2 V、τ = 0.5 s。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 能量 | E = A²τ/2 = 4 × 0.5 / 2 | **1.000000 V²·s** |
| 平均功率 | P（能量有限 ⇒ 平均功率為 0） | **0.000000** |
| 分類 | E 有限、P = 0 | **能量訊號** |
| 奇偶 | x(−t) ≠ ±x(t)（t < 0 恆為 0） | **非奇非偶** |

邊界對照：弦波 A = 1 V → **E = ∞、P = 0.500000 V²、rms = 0.707107 V、功率訊號、偶函數**（cos 是偶的）；A = 3 V → **P = 4.500000 V²、rms = 2.121320 V**。矩形脈衝（以 t = 0 為中心，高 A = 1、寬 T = 1 s）→ **E = 1.000000 V²·s、能量訊號、偶函數**；A = 2、T = 0.5 → **E = 2.000000 V²·s**。單位步階 A·u(t)、A = 1 → **E = ∞、P = 0.500000 V²、功率訊號**（只有一半的時間軸有值）。衰減指數 A = 0.5、τ = 0.1 → **E = 0.012500 V²·s**；A = 5、τ = 5 → **E = 62.500000 V²·s**。

### 02 `02-基本訊號與訊號運算.html`

**目標**：把六個基本訊號變成「可以拿來組裝任何東西的積木」，並且把三種時間軸運算（平移、反轉、縮放）的**順序陷阱**一次講清楚。本章的核心是 **δ(t) 的篩選性**，它是下一章摺積的唯一地基。

**要點**：單位步階 u(t)（t < 0 為 0、t ≥ 0 為 1）；單位脈衝 δ(t)（`∫δ(t)dt = 1`，寬度 → 0、高度 → ∞、面積恆為 1，**它不是函數而是分布**）；**篩選性（sifting property）** `∫ f(t)δ(t − t<sub>0</sub>) dt = f(t<sub>0</sub>)`——δ 像一支「取值針」，把整條曲線壓成一個數；`δ(t) = du/dt`、`u(t) = ∫<sub>−∞</sub><sup>t</sup> δ(τ)dτ`；斜坡 `r(t) = t·u(t)`；指數 e<sup>at</sup>（a 實數決定增衰、a 複數則同時給振盪）；弦波 cos(ωt + φ)；離散版 δ[n]（**n = 0 時為 1，就是普通的數列，沒有無限高的問題**）與 u[n]、a<sup>n</sup>；三種運算：時間平移 x(t − t<sub>0</sub>)（t<sub>0</sub> > 0 是**延後**）、時間反轉 x(−t)、時間縮放 x(at)（|a| > 1 是**壓縮變快**）；一般式 `y(t) = A·x(a(t − t<sub>0</sub>))`。來源：09-信號與系統-上 第 2 章。

**推導必寫**：（a）為什麼 δ 只能用「積分後的效果」定義：任何在單點無限高、其他地方為 0 的普通函數積分都是 0，所以 δ 只能靠「與別的函數配對後給出什麼數」來定義。（b）篩選性怎麼來：`f(t)δ(t − t<sub>0</sub>)` 只在 t = t<sub>0</sub> 附近非零，那裡 f 可以視為常數 f(t<sub>0</sub>) 提出來，剩下 `∫δ = 1`。（c）**複合運算的順序陷阱**：`y(t) = x(2(t − 1))` 與 `y(t) = x(2t − 1)` **不是同一個訊號**。統一作法是先把式子整理成 `x(a(t − t<sub>0</sub>))` 的標準形，`t<sub>0</sub>` 就是真正的平移量；`x(2t − 1) = x(2(t − 0.5))`，平移的是 0.5 不是 1。（d）為什麼離散的縮放要小心：`x[2n]` 是丟掉一半樣本（降取樣，資訊真的沒了），`x[n/2]` 只在 n 為偶數時有定義，中間要靠內插——**這是第 15 章多速率的起點**。

**數值實例**：x(t) = e<sup>−t</sup>·u(t)，做 y(t) = A·x(a(t − t<sub>0</sub>))，取 A = 1、a = 1、t<sub>0</sub> = 1 s、觀測 t = 2 s。

| --- | --- | --- |
| 內部引數 | arg = a(t − t<sub>0</sub>) = 1 × (2 − 1) | **1.000000** |
| 輸出值 | y = A·e<sup>−arg</sup>（arg ≥ 0） | **0.367879** |
| 篩選性 | ∫ x(τ)δ(τ − 1) dτ = x(1) | **0.367879** |
| 意義 | 訊號被**延後 1 秒**，所以 t = 2 秒看到的是原本 t = 1 秒的值 | — |

邊界對照：a = **−1**、t<sub>0</sub> = 1、t = **0** → arg = **1.000000**、y = **0.367879**（**時間反轉後，t = 0 看到的是原本 t = 1 的值**）。a = **2** → arg = **2.000000**、y = **0.135335**（**壓縮成兩倍快，同樣的 1 秒走完原本 2 秒的路**）。a = **0.5** → arg = **0.500000**、y = **0.606531**。t = **0.5**（arg = **−0.500000**）→ y = **0.000000**（**u(t) 在負引數處是 0**）。A = 2 → y = **0.735759**。換成斜坡且 arg = 1 → y = **1.000000**；換成弦波 cos(2π·arg) 且 arg = 1 → y = **1.000000**，arg = 0.25 → y = **0.000000**。

### 03 `03-系統的六個性質.html`

**目標**：把六個性質從「定義背誦」變成「拿一個系統來，逐條測給你看，違反時算得出殘差」。本章的產出是一張判定表，也是下一章「為什麼只有 LTI 能用 h 描述」的前提。

**要點**：系統是算子 T，`y(t) = T{x(t)}`；**線性（linear）**＝可加性＋齊次性，合起來就是疊加 `T{a·x<sub>1</sub> + b·x<sub>2</sub>} = a·T{x<sub>1</sub>} + b·T{x<sub>2</sub>}`；**時不變（time-invariant）**＝輸入平移則輸出跟著平移，`T{x(t − t<sub>0</sub>)} = y(t − t<sub>0</sub>)`；**因果（causal）**＝輸出只依現在與過去的輸入；**BIBO 穩定**＝有界輸入必產生有界輸出；**無記憶（memoryless）**＝輸出只依現在這一刻的輸入；**可逆（invertible）**＝存在反系統把輸入還原（等價於「不同輸入必給不同輸出」）；六個性質**彼此獨立**，可以任意組合；工程上絕大多數分析對象是 **LTI（linear time-invariant）系統**，整門課大半圍繞它。來源：09-信號與系統-上 第 3 章。

**推導必寫**：（a）為什麼 `y = x + 3` **不是**線性的：它滿足「畫出來是直線」但不滿足疊加——代 a = 2、b = 3、x<sub>1</sub> = x<sub>2</sub> = 1，左式 `(2×1 + 3×1) + 3 = 8`、右式 `2(1 + 3) + 3(1 + 3) = 20`，差 12。**「線性」在本課專指疊加，不是「圖形是直線」**，這是最常見的誤解。（b）為什麼 `y = x²` 不線性：左式 `(2 + 3)² = 25`、右式 `2×1² + 3×1² = 5`，殘差 20；平方把交叉項 2·a·b·x<sub>1</sub>x<sub>2</sub> 生出來，那正是疊加被破壞的地方。（c）為什麼 `y(t) = x(2t)` **時變**：把輸入延後 t<sub>0</sub> 得 `x(2t − t<sub>0</sub>)`，把輸出延後 t<sub>0</sub> 得 `x(2(t − t<sub>0</sub>)) = x(2t − 2t<sub>0</sub>)`，兩者差一倍。（d）為什麼積分器**不 BIBO 穩定**：輸入 u(t)（有界，上限 1）→ 輸出 r(t) = t·u(t)（無界）。（e）可逆與「一對一」的關係：y = x² 把 +1 與 −1 送到同一個輸出，無法還原。

**數值實例**：疊加測試，取 a = 2、b = 3、x<sub>1</sub> = 1、x<sub>2</sub> = 1（皆為常數輸入）。

| 系統 | 左式 T{a·x<sub>1</sub> + b·x<sub>2</sub>} | 右式 a·T{x<sub>1</sub>} + b·T{x<sub>2</sub>} | 殘差 | 線性？ |
| --- | --- | --- | --- | --- |
| y = 2x | **10.000000** | **10.000000** | **0.000000** | 是 |
| y = x² | **25.000000** | **5.000000** | **20.000000** | **否** |

邊界對照：改成 x<sub>1</sub> = 2、x<sub>2</sub> = 1 → y = x² 的左式 **49.000000**、右式 **11.000000**、殘差 **38.000000**（**殘差隨振幅變大，因為交叉項是二次的**）；y = x + 3 的左式 **10.000000**、右式 **22.000000**、殘差 **−12.000000**（**殘差不隨輸入變，因為那個 3 是固定的偏移**）——**這兩種「不線性」的機制完全不同**。a = 0 且 b = 0 → 三個系統的殘差分別是 **0.000000**、**0.000000**、**3.000000**（`bias` 的殘差通式是 3 − 3(a + b)，**連零輸入都藏不住那個偏移**）。

**可觀察證據**：疊加測試在實驗室做法是：先量 x<sub>1</sub> 單獨輸入的輸出，再量 x<sub>2</sub> 單獨的，最後量兩者同時輸入的，比較「和」與「同時」的差；時不變測試就是把同一個訊號在不同時刻重放，看輸出波形是否只是平移。**能證明**：某個系統在某個振幅範圍內**不**線性（放大器一過載就會露出來）。**不能證明**：系統**是**線性的——任何有限次測試都只能沒推翻它；也證明不了時不變（元件會老化、溫度會漂移）。

### 04 `04-線性非時變與摺積.html`

**目標**：講清楚這門課最重要的一句話——**一個 LTI 系統完全由它的脈衝響應 h(t) 決定**——並且把摺積積分從「一個嚇人的符號」變成「把輸入切成無限多根脈衝，各自被延遲、被加權，再全部疊起來」。

**要點**：脈衝響應（impulse response）h(t)＝LTI 系統對 δ(t) 的響應；摺積積分 `y(t) = x(t) ∗ h(t) = ∫<sub>−∞</sub><sup>∞</sup> x(τ)h(t − τ) dτ`；代數性質：可交換 `x ∗ h = h ∗ x`、可結合、對加法分配；系統互聯：串聯 `h<sub>eq</sub> = h<sub>1</sub> ∗ h<sub>2</sub>`、並聯 `h<sub>eq</sub> = h<sub>1</sub> + h<sub>2</sub>`、負回授 `H/(1 + HG)`（在轉換域才好寫，第 07 章補上）；因果條件 `h(t) = 0, t < 0`；BIBO 穩定條件 `∫|h(t)| dt < ∞`；**面積性質**：`∫y dt = (∫x dt)(∫h dt)`——這是驗算摺積最好用的檢查；離散版摺積和 `y[n] = ∑<sub>k</sub> x[k]h[n − k]`（第 11 章展開）。來源：09-信號與系統-上 第 4 章 §4.1–§4.4。

**推導必寫**：（a）四步導出摺積：① 篩選性把輸入寫成 `x(t) = ∫ x(τ)δ(t − τ)dτ`（**把 x 拆成無限多根加權延遲脈衝**）；② 時不變 ⇒ `δ(t − τ) → h(t − τ)`；③ 線性（齊次）⇒ `x(τ)δ(t − τ) → x(τ)h(t − τ)`；④ 線性（可加）⇒ 對 τ 積分。**每一步都要點名用到六個性質裡的哪一條**——這是本課「為什麼只有 LTI 有這個特權」的完整答案。（b）為什麼是 `h(t − τ)` 而不是 `h(τ)`：`t − τ` 是「這根脈衝發生在 τ、我現在站在 t，所以它已經過了 t − τ 這麼久」。（c）交換律的證明：換元 `λ = t − τ`。（d）本章實例的閉合式：x 是高 A、寬 T<sub>1</sub>、從 t = 0 開始的矩形，h(t) = e<sup>−t/τ</sup>u(t)，令 m = min(t, T<sub>1</sub>)，則 `y(t) = A·τ·e<sup>−t/τ</sup>(e<sup>m/τ</sup> − 1)`；展開成兩段：`0 ≤ t ≤ T<sub>1</sub>` 時 `y = Aτ(1 − e<sup>−t/τ</sup>)`（**充電**），`t > T<sub>1</sub>` 時 `y = Aτ(e<sup>−(t−T1)/τ</sup> − e<sup>−t/τ</sup>)`（**放電**）。（e）面積驗算：`∫x = A·T<sub>1</sub>`、`∫h = τ`、`∫y = A·T<sub>1</sub>·τ`。

**數值實例**：A = 1 V、T<sub>1</sub> = 1 s 的矩形脈衝，通過 τ = 0.5 s 的一階系統（h(t) = e<sup>−t/0.5</sup>u(t)），觀測 t = 1 s。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 分段判定 | t = 1 ≤ T<sub>1</sub> = 1 → 充電段 | — |
| 輸出 | y(1) = Aτ(1 − e<sup>−1/0.5</sup>) = 0.5(1 − 0.135335) | **0.432332** |
| 峰值 | 峰值一定在 t = T<sub>1</sub>（脈衝結束的瞬間） | **0.432332，發生在 t = 1.000000 s** |
| 輸入面積 | ∫x dt = A·T<sub>1</sub> | **1.000000** |
| 脈衝響應面積 | ∫h dt = τ | **0.500000** |
| 輸出面積 | ∫y dt = 1.000000 × 0.500000 | **0.500000 ✓（三者相符）** |

邊界對照：t = **0.5 s** → y = **0.316060**（充電到 63.2 % 需要一個 τ，這裡才走了一個 τ）；t = **1.5 s** → y = **0.159046**；t = **2 s** → y = **0.058510**；t = **3 s** → y = **0.007918**（**放電段每過一個 τ 掉到 36.8 %**）；t = **0.1 s** → y = **0.090635**。A = **2** → y(1) = **0.864665**（**線性：輸入乘 2、輸出乘 2**）。T<sub>1</sub> = **2**、t = 1 → y = **0.432332**（**還在充電段，結果與 T<sub>1</sub> = 1 完全相同——因為系統還沒「知道」脈衝什麼時候結束，這就是因果性**）。τ = **2**、t = 1 → y = **0.786939**（**系統變慢，同一時刻累積得更多**）。

### 05 `05-傅立葉級數.html`

**目標**：回答「為什麼要把訊號拆成弦波」——因為弦波是 LTI 系統的**本徵函數**，進去什麼頻率出來還是什麼頻率，只有振幅與相位變。本章處理**週期訊號**，用傅立葉級數（Fourier series）把它拆成基頻與諧波，並用帕塞瓦看每個諧波佔多少功率。

**要點**：週期 T 的訊號可寫成 `x(t) = ∑<sub>k=−∞</sub><sup>∞</sup> a<sub>k</sub>·exp(j k ω<sub>0</sub> t)`，`ω<sub>0</sub> = 2π/T`（基頻角頻率）、`f<sub>0</sub> = 1/T`；係數 `a<sub>k</sub> = (1/T)∫<sub>T</sub> x(t)·exp(−j k ω<sub>0</sub> t) dt`；**幾何直覺：a<sub>k</sub> 是 x 在正交基底 {exp(j k ω<sub>0</sub> t)} 上的座標**，那個積分就是內積；實訊號可改寫成三角式 `x(t) = a<sub>0</sub> + ∑<sub>n=1</sub><sup>∞</sup> [A<sub>n</sub>cos(nω<sub>0</sub>t) + B<sub>n</sub>sin(nω<sub>0</sub>t)]`；第 n 諧波的頻率是 n·f<sub>0</sub>；**帕塞瓦（週期版）**：平均功率 `P = ∑<sub>k</sub>|a<sub>k</sub>|²`，三角式下 `P = ∑<sub>n</sub> B<sub>n</sub>²/2`（本課的三個波形都是奇函數、無直流）；對稱性省一半工：**奇函數只有 sin 項、偶函數只有 cos 項、半波對稱只有奇次諧波**；吉布斯現象（Gibbs phenomenon）——在不連續點附近，無論取多少項都會有約 9 % 的過衝，只是愈來愈窄。來源：09-信號與系統-上 第 5 章。

**推導必寫**：（a）正交性：`∫<sub>T</sub> exp(j k ω<sub>0</sub> t)·exp(−j m ω<sub>0</sub> t) dt` 在 k = m 時是 T、否則是 0——**係數公式就是把這個性質拿來「篩」出第 k 個座標**，和第 02 章 δ 的篩選性是同一種思路。（b）方波的係數：奇函數＋半波對稱 ⇒ 只有奇次 sin 項，`B<sub>n</sub> = 4A/(nπ)`（n 奇數）。這個積分要寫出來。（c）為什麼方波的諧波掉得慢（1/n）而三角波掉得快（1/n²）：**波形愈不連續，高頻愈多**——方波有跳躍（不連續），三角波只有斜率跳躍（一階不連續），這條規律在第 06 章會變成「時域愈尖銳、頻域愈寬」。（d）帕塞瓦驗算：方波總功率 `P = A²`（因為 |x| 恆等於 A），三角波與鋸齒波都是 `A²/3`。

**數值實例**：方波，A = 1 V、基頻 f<sub>0</sub> = 100 Hz、保留到第 N = 5 諧波。

### 06 `06-傅立葉轉換.html`

**目標**：把第 05 章的「離散諧波」推廣到非週期訊號的「連續頻譜」，並且拿到本課最重要的那一條性質：**時間域的摺積等於頻率域的相乘**。這一條讓第 04 章那個嚇人的積分變成一個乘法。

**要點**：`X(jω) = ∫<sub>−∞</sub><sup>∞</sup> x(t)e<sup>−jωt</sup> dt`，反轉換 `x(t) = (1/2π)∫ X(jω)e<sup>jωt</sup> dω`；**週期趨於無限大時，傅立葉級數的離散譜線靠攏成連續譜**；七大性質（線性、時移、頻移、縮放、微分、摺積、相乘）；**摺積定理 `x ∗ h ⇔ X·H`**——所以「頻率響應」`H(jω)` 直接告訴你系統對每個頻率做什麼；**相乘定理 `x·g ⇔ (1/2π)X ∗ G`**（第 10 章調變的基礎）；**時移只改相位不改振幅**：`x(t − t<sub>0</sub>) ⇔ X(jω)·exp(−jωt<sub>0</sub>)`，相位是 ω 的**線性函數**（斜率 −t<sub>0</sub>）；**縮放的倒數關係** `x(at) ⇔ (1/|a|)X(jω/a)`——**時域壓縮＝頻域展寬**，這是不確定性原理的工程版；帕塞瓦 `∫|x|²dt = (1/2π)∫|X|²dω`；五組必背轉換對：`δ(t) ⇔ 1`、`1 ⇔ 2πδ(ω)`、`cos(ω<sub>0</sub>t) ⇔ π[δ(ω − ω<sub>0</sub>) + δ(ω + ω<sub>0</sub>)]`、`矩形 ⇔ sinc`、`高斯 ⇔ 高斯`。來源：09-信號與系統-上 第 6 章。

**推導必寫**：（a）矩形脈衝的轉換：高 A、寬 T、以 t = 0 為中心，`X(jω) = ∫<sub>−T/2</sub><sup>T/2</sup> A·e<sup>−jωt</sup>dt = A·T·sinc(fT)`，其中 `sinc(x) = sin(πx)/(πx)`。**兩步都要寫**（積出指數、用 sin 的定義收成 sinc）。（b）為什麼 `X(0) = A·T`：頻率 0 的分量就是訊號的**總面積**。（c）第一個零點在 `f = 1/T`：`sin(πfT) = 0` 的第一個非零解。（d）3 dB 頻寬：解 `|sinc(x)| = 1/√2` 得 `x = 0.442946`，所以 `f<sub>3dB</sub> = 0.442946/T`。（e）摺積定理的證明骨架：把 `y(t) = ∫x(τ)h(t − τ)dτ` 代進轉換，換元 `λ = t − τ` 後兩個積分分離。（f）時移只改相位：`|X·exp(−jωt<sub>0</sub>)| = |X|`，相位多了 `−ωt<sub>0</sub>`；換成度數是 `−360°·f·t<sub>0</sub>`。

**數值實例**：矩形脈衝 A = 1 V、寬 T = 1 ms（以 t = 0 為中心），時移 t<sub>0</sub> = 0.5 ms，觀測 f = 500 Hz。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 直流分量 | X(0) = A·T = 1 × 0.001 | **1.000000 × 10<sup>−3</sup> V·s** |
| sinc 值 | sinc(fT) = sinc(0.5) = sin(π/2)/(π/2) | **0.636620** |
| 頻譜值 | \|X(j2π·500)\| = 0.001 × 0.636620 | **6.366198 × 10<sup>−4</sup> V·s** |
| 第一個零點 | f = 1/T = 1/0.001 | **1000.000000 Hz** |
| 3 dB 頻寬 | f<sub>3dB</sub> = 0.442946/T | **442.946000 Hz** |
| 時移造成的相位 | −360° × 500 × 0.0005 | **−90.000000°** |
| 訊號能量 | E = A²T | **1.000000 × 10<sup>−3</sup> V²·s** |

邊界對照：f = **250 Hz** → sinc = **0.900316**、\|X\| = **9.003163 × 10<sup>−4</sup>**、時移相位 **−45.000000°**（**相位與頻率成正比，斜率就是 −t<sub>0</sub>**）；f = **1000 Hz** → sinc = **0.000000**（**第一個零點**）；f = **1500 Hz** → sinc = **−0.212207**（**負號代表相位翻 180°**）、\|X\| = **2.122066 × 10<sup>−4</sup>**。T = **2 ms**、A = **2** → X(0) = **4.000000 × 10<sup>−3</sup>**、第一個零點 **500.000000 Hz**（**脈衝變寬一倍，頻譜窄一半——倒數關係**）。

### 07 `07-拉氏轉換與轉移函數.html`

**目標**：把傅立葉推廣成拉氏——多給一個實部 σ，就能處理會指數成長的訊號，也能把「初始條件」與「暫態」一起算進來。本章的產出是**轉移函數 H(s)**，以及「極點位置決定系統的自然行為」這條規律。

**要點**：`s = σ + jω`（σ 是每秒的指數成長／衰減率，單位 1/s；ω 是角頻率，rad/s）；單邊拉氏 `H(s) = Y(s)/X(s) = ∫<sub>0</sub><sup>∞</sup> h(t)e<sup>−st</sup> dt`；**收斂域（region of convergence, ROC）**＝讓這個積分收斂的 s 範圍，`e<sup>at</sup>u(t)` 的 ROC 是 Re{s} > a；**H(jω) 是 H(s) 在虛軸上的切片**——所以只要虛軸在 ROC 內，拉氏就退化成傅立葉；轉移函數是有理式時，分母的根是**極點**、分子的根是**零點**；極點決定自然響應：左半平面（σ < 0）**衰減**、右半平面（σ > 0）**發散**、虛軸上（σ = 0）**等幅振盪**；一對共軛極點 `s = σ ± jω<sub>d</sub>` 對應的自然響應是 `h(t) = K·e<sup>σt</sup>·cos(ω<sub>d</sub>t)`；時間常數 `τ = 1/|σ|`（σ < 0 時），**5τ 後剩 0.674 %，工程上視為結束**；零點不改變自然行為，只**改變各模態被激發的權重與頻率響應的形狀**（某些頻率被壓下去）；波德圖就是畫 `|H(jω)|`（dB）與 `∠H(jω)`（第 08 章展開）。來源：09-信號與系統-上 第 7 章 §7.1–§7.3。

**推導必寫**：（a）為什麼要多一個 σ：傅立葉積分要求 `∫|x|dt` 收斂，`e<sup>2t</sup>u(t)` 根本沒有傅立葉轉換；乘上 `e<sup>−σt</sup>` 讓它收斂，就得到拉氏。（b）ROC 為什麼重要：同一個 X(s) 配不同 ROC 對應不同的時間訊號（一個右側訊號、一個左側訊號），**只有 X(s) 是不夠的**。（c）極點與自然響應的對應：`1/(s − p)` 反轉換是 `e<sup>pt</sup>u(t)`；p 是複數時，共軛成對的兩項合起來給 `e<sup>σt</sup>cos(ω<sub>d</sub>t)`（歐拉公式那一步要寫）。（d）為什麼「左半平面＝穩定」：σ < 0 ⇒ `e<sup>σt</sup> → 0`；而 BIBO 穩定要求 `∫|h|dt < ∞`，指數衰減剛好滿足。（e）微分方程 ⇒ 轉移函數：對 `a<sub>2</sub>y″ + a<sub>1</sub>y′ + a<sub>0</sub>y = b<sub>0</sub>x`（初始靜止）逐項取拉氏，`d/dt → s`，直接得 `H(s) = b<sub>0</sub>/(a<sub>2</sub>s² + a<sub>1</sub>s + a<sub>0</sub>)`——**微分方程變成代數式，這就是換域的全部好處**。

**數值實例**：一對共軛極點 s = −2 ± j10（單位 1/s 與 rad/s），K = 1，觀測 t = 0.5 s。

### 08 `08-極零點與二階系統.html`

**目標**：把標準二階系統的兩個參數（ζ 與 ω<sub>n</sub>）與四個工程指標（超越量、峰值時間、整定時間、共振峰）綁死，讓讀者看到 ζ 就知道波形會怎麼動。這是控制系統所有暫態規格的共同語言。

**要點**：標準式 `H(s) = ω<sub>n</sub>² / (s² + 2ζω<sub>n</sub>s + ω<sub>n</sub>²)`（**直流增益為 1**）；ω<sub>n</sub> 是自然頻率（natural frequency，rad/s）、ζ 是阻尼比（damping ratio，無單位）；極點 `s = −ζω<sub>n</sub> ± jω<sub>n</sub>√(1 − ζ²)`，阻尼振盪頻率 `ω<sub>d</sub> = ω<sub>n</sub>√(1 − ζ²)`；四種阻尼：ζ > 1 過阻尼（兩個實極點，不振盪但慢）、ζ = 1 臨界（最快的不振盪）、0 < ζ < 1 欠阻尼（振盪＋超越）、ζ = 0 無阻尼（等幅振盪）；步階響應的暫態指標：**超越量** `M<sub>p</sub> = exp(−πζ/√(1 − ζ²))`、**峰值時間** `t<sub>p</sub> = π/ω<sub>d</sub>`、**整定時間**（2 % 準則的常用近似）`t<sub>s</sub> ≈ 4/(ζω<sub>n</sub>)`；頻率響應 `|H(jω)| = ω<sub>n</sub>² / √((ω<sub>n</sub>² − ω²)² + (2ζω<sub>n</sub>ω)²)`；**共振峰只在 ζ < 0.707107 時存在**：`ω<sub>r</sub> = ω<sub>n</sub>√(1 − 2ζ²)`、`M<sub>r</sub> = 1/(2ζ√(1 − ζ²))`；`ω = ω<sub>n</sub>` 處 `|H| = 1/(2ζ)`、相位恆為 **−90°**（**這是量 ω<sub>n</sub> 最可靠的方法**）；與電路學的換算 `Q = 1/(2ζ)`。來源：09-信號與系統-上 第 7 章 §7.3–§7.4。

**推導必寫**：（a）極點怎麼來：對 `s² + 2ζω<sub>n</sub>s + ω<sub>n</sub>²` 用公式解，判別式 `4ω<sub>n</sub>²(ζ² − 1)` 的正負就是四種阻尼的分界。（b）欠阻尼步階響應：`y(t) = 1 − e<sup>−ζω<sub>n</sub>t</sup>[cos(ω<sub>d</sub>t) + (ζ/√(1 − ζ²))sin(ω<sub>d</sub>t)]`。（c）M<sub>p</sub> 的來歷：對 y 微分令零得 `t<sub>p</sub> = π/ω<sub>d</sub>`，代回化簡得 `M<sub>p</sub> = exp(−πζ/√(1 − ζ²))`——**M<sub>p</sub> 只跟 ζ 有關，跟 ω<sub>n</sub> 完全無關**（ω<sub>n</sub> 只決定快慢，不決定形狀）。（d）t<sub>s</sub> 的來歷：包絡 `e<sup>−ζω<sub>n</sub>t</sup>` 掉到 2 % 要 `ln(50)/(ζω<sub>n</sub>) = 3.912/(ζω<sub>n</sub>)`，工程上取整成 4。（e）ζ = 0.707107 這個門檻：對 `|H(jω)|²` 的分母求極值，`ω<sub>r</sub>² = ω<sub>n</sub>²(1 − 2ζ²)`，`1 − 2ζ² ≤ 0` 時沒有峰。（f）過阻尼與臨界的步階響應式（widget 要用）：ζ = 1 時 `y = 1 − (1 + ω<sub>n</sub>t)e<sup>−ω<sub>n</sub>t</sup>`；ζ > 1 時兩個實極點 `s<sub>1,2</sub> = −ζω<sub>n</sub> ± ω<sub>n</sub>√(ζ² − 1)`，`y = 1 − (s<sub>2</sub>e<sup>s<sub>1</sub>t</sup> − s<sub>1</sub>e<sup>s<sub>2</sub>t</sup>)/(s<sub>2</sub> − s<sub>1</sub>)`。

**數值實例**：ζ = 0.5、ω<sub>n</sub> = 10 rad/s，觀測 ω = 10 rad/s、t = 0.5 s。

**不要混淆（至少四條）**：ω<sub>n</sub>、ω<sub>d</sub>、ω<sub>r</sub> 是**三個不同的頻率**（本章預設值分別是 10.000000、8.660254、7.071068 rad/s），只有 ζ → 0 時三者才靠攏；「阻尼比 ζ」與「衰減率 σ」不同，σ = ζω<sub>n</sub> 才是每秒衰減多少；共振峰 M<sub>r</sub> 與超越量 M<sub>p</sub> 都叫「峰」但一個在頻域一個在時域，數值不相等（1.154701 vs 1.163034，接近純屬巧合）；ζ ≥ 0.707107 沒有共振峰**不代表**沒有超越——ζ = 0.7 的步階響應仍然超越 4.598791 %。

### 09 `09-濾波器與群延遲.html`

**目標**：把「濾波器」從「可以濾掉不要的頻率」講成一組**可以算的規格**：要多陡就要多少階、代價是相位不線性、相位不線性的代價是波形變形（群延遲不平坦）。

**要點**：四種理想濾波器（低通、高通、帶通、帶阻）在通帶 `|H| = 1`、阻帶 `|H| = 0`、相位線性——**理想濾波器不可實現**（它的 h(t) 是無限長的 sinc，而且在 t < 0 有值，違反因果）；可實現的作法是用有理式 H(s) 逼近；四個設計家族：**巴特沃斯**（通帶最平坦）、**柴比雪夫**（通帶或阻帶允許漣波，換更陡的下降）、**貝索**（群延遲最平坦，波形最不失真）、**橢圓**（兩邊都有漣波，最陡）；巴特沃斯的振幅式 `|H(f)| = 1/√(1 + (f/f<sub>c</sub>)<sup>2n</sup>)`，**每階每十倍頻 20 dB**；階數公式（由通帶邊緣 f<sub>c</sub>、阻帶邊緣 f<sub>s</sub>、阻帶要求 A<sub>s</sub> dB 反算）`n<sub>min</sub> = log<sub>10</sub>(10<sup>A<sub>s</sub>/10</sup> − 1) / (2·log<sub>10</sub>(f<sub>s</sub>/f<sub>c</sub>))`，取上整；**群延遲** `τ<sub>g</sub> = −d∠H/dω`（單位 s）——它是「這個頻率成分被延後多久」；**線性相位 ⇔ 群延遲為常數 ⇔ 所有頻率延後一樣多 ⇔ 波形只平移不變形**；相位不線性時不同頻率延後不同，方波的角會被磨圓、通訊上造成**符際干擾（intersymbol interference, ISI）**。來源：09-信號與系統-上 第 8 章。

**推導必寫**：（a）為什麼理想濾波器不可實現：對理想低通做反轉換得 `h(t) = 2f<sub>c</sub>·sinc(2f<sub>c</sub>t)`，它在 t < 0 有值（未卜先知）且無限長。（b）階數公式怎麼來：要求 `10·log<sub>10</sub>(1 + (f<sub>s</sub>/f<sub>c</sub>)<sup>2n</sup>) ≥ A<sub>s</sub>`，兩邊取對數解 n。（c）為什麼「每階 20 dB/decade」：高頻時 `|H| ≈ (f<sub>c</sub>/f)<sup>n</sup>`，取 dB 得 `−20n·log<sub>10</sub>(f/f<sub>c</sub>)`。（d）一階系統群延遲的閉合式：`∠H = −arctan(ω/ω<sub>c</sub>)`，微分得 `τ<sub>g</sub> = (1/ω<sub>c</sub>)/(1 + (ω/ω<sub>c</sub>)²)`——在直流是 `1/ω<sub>c</sub>`，在 ω<sub>c</sub> 掉到一半，**這個「不平坦」就是波形失真的來源**。（e）四個家族的取捨要用一句話各講完，不給係數表。

**數值實例**：巴特沃斯低通，通帶邊緣（−3 dB）f<sub>c</sub> = 1000 Hz、阻帶邊緣 f<sub>s</sub> = 3000 Hz、阻帶要求 A<sub>s</sub> = 40 dB，實際採用 n = 5，觀測 f = 2000 Hz。

### 10 `10-調變與頻譜搬移.html`

**目標**：把第 06 章的「頻率平移性質」兌現成一個真實系統：AM 廣播。讀者要能算出一個電台佔多少頻寬、功率花在哪裡、為什麼包絡檢波這麼便宜、以及為什麼過調變會讓聲音破掉。

**要點**：頻率平移性質 `x(t)·cos(ω<sub>c</sub>t) ⇔ (1/2)[X(j(ω − ω<sub>c</sub>)) + X(j(ω + ω<sub>c</sub>))]`——**乘一個載波，等於把整個頻譜複製兩份搬到 ±ω<sub>c</sub>**；標準 AM（含載波）`y(t) = A<sub>c</sub>[1 + m·x<sub>n</sub>(t)]cos(ω<sub>c</sub>t)`，其中 x<sub>n</sub> 是歸一化訊息（峰值 1）、m 是**調變指數（modulation index）**；單音調變時的頻譜有三根線：載波 f<sub>c</sub>、上邊帶 f<sub>c</sub> + f<sub>m</sub>、下邊帶 f<sub>c</sub> − f<sub>m</sub>；**佔用頻寬 B = 2f<sub>m</sub>**（與 m 無關）；功率：載波 `P<sub>c</sub>`、每個邊帶 `m²P<sub>c</sub>/4`、總功率 `P<sub>t</sub> = P<sub>c</sub>(1 + m²/2)`；**功率效率** `η = (m²/2)/(1 + m²/2)`，**m = 1 時也只有 33.333333 %**——三分之二的發射功率花在完全不帶資訊的載波上；**包絡檢測**（一個二極體加 RC）只在 m ≤ 1 時有效，m > 1 是**過調變**，包絡在零附近折返、聲音失真；同步檢測不怕過調變但要在接收端重建載波（貴）；由波形量 m 的公式 `m = (E<sub>max</sub> − E<sub>min</sub>)/(E<sub>max</sub> + E<sub>min</sub>)`；DSB-SC 與 SSB 省掉載波與一個邊帶（效率高但接收機貴）；FM／PM 把訊息編進頻率或相位，抗雜訊但佔更多頻寬——**細節留給通訊系統**。來源：09-信號與系統-上 第 9 章。

**推導必寫**：（a）三根線怎麼來：`cos(ω<sub>c</sub>t)·cos(ω<sub>m</sub>t) = (1/2)[cos((ω<sub>c</sub> − ω<sub>m</sub>)t) + cos((ω<sub>c</sub> + ω<sub>m</sub>)t)]`，積化和差那一步要寫。（b）功率怎麼分：載波振幅 A<sub>c</sub>、每個邊帶振幅 mA<sub>c</sub>/2，功率正比於振幅平方的一半，得 `P<sub>c</sub> = A<sub>c</sub>²/2`、每邊帶 `m²A<sub>c</sub>²/8 = m²P<sub>c</sub>/4`。（c）效率式與「為什麼還要送載波」：載波讓接收機可以用一顆二極體解調——**這是 1920 年代用功率換成本的工程決策，不是笨**。（d）為什麼 m > 1 會破：包絡 `A<sub>c</sub>[1 + m·cos(ω<sub>m</sub>t)]` 在 m > 1 時會變負，二極體只認絕對值，於是波形被折回去。（e）頻寬與電台間隔：AM 廣播頻道間隔 10 kHz，所以 f<sub>m</sub> 上限只有 5 kHz——**這就是 AM 廣播聽起來悶的原因**。

**數值實例**：f<sub>c</sub> = 1000 kHz、f<sub>m</sub> = 5 kHz、m = 0.5、P<sub>c</sub> = 100 W。

### 11 `11-離散時間訊號與差分方程.html`

**目標**：把前十章的觀念整批搬到 x[n] 的世界，並且讓讀者親手算出**摺積和**與**差分方程的遞迴**——同時看到 FIR 與 IIR 這兩種數位濾波器的原型。

**要點**：離散時間訊號 x[n]，n 是**整數**（**不是「時間很小」，是根本沒有 n = 0.5 這件事**）；連續時間的觀念幾乎全部有對應：平移 x[n − n<sub>0</sub>]、反轉 x[−n]、奇偶、能量 `∑|x[n]|²`、功率；**縮放要小心**：x[2n] 是丟樣本（降取樣，資訊真的沒了）、x[n/2] 只在偶數 n 有定義（要內插）；摺積和 `y[n] = ∑<sub>k=−∞</sub><sup>∞</sup> x[k]h[n − k]`，**結構與連續版完全一樣，積分換成求和**；因果 `h[n] = 0, n < 0`；BIBO 穩定 `∑|h[n]| < ∞`；**線性常係數差分方程** `∑<sub>k=0</sub><sup>N</sup> a<sub>k</sub>y[n − k] = ∑<sub>m=0</sub><sup>M</sup> b<sub>m</sub>x[n − m]`——這就是 DSP 裡 FIR 與 IIR 的標準形；**FIR（有限脈衝響應）**：h[n] 只有有限項，例如 M 點移動平均 `h[n] = 1/M（0 ≤ n ≤ M − 1）`，`y[n] = (1/M)∑<sub>k=0</sub><sup>M−1</sup>x[n − k]`，**沒有回授**；**IIR（無限脈衝響應）**：有回授，例如 `y[n] = a·y[n − 1] + x[n]`，`h[n] = a<sup>n</sup>u[n]`，只要 |a| < 1 就穩定；直流增益＝`∑h[n]`（IIR 是 `1/(1 − a)`、移動平均是 1）；等效時間常數 `n<sub>τ</sub> = −1/ln a` 個樣本。來源：09-信號與系統-下 第 10 章。

**推導必寫**：（a）摺積和的來歷與連續版**逐字對應**：`x[n] = ∑<sub>k</sub>x[k]δ[n − k]`（篩選性的離散版，**這裡的 δ[n] 就是一個普通數列，沒有無限大**）→ 時不變 → 線性 → 求和。（b）一階 IIR 的 h[n]：對 `y[n] = a·y[n−1] + x[n]` 打入 δ[n]，逐步展開得 1, a, a², a³, …，即 `h[n] = a<sup>n</sup>u[n]`。（c）步階響應的閉合式：`y[n] = ∑<sub>k=0</sub><sup>n</sup>a<sup>k</sup> = (1 − a<sup>n+1</sup>)/(1 − a)`（**幾何級數求和，這一步要寫**），n → ∞ 時趨近 `1/(1 − a)`。（d）穩定條件：`∑|a<sup>n</sup>| = 1/(1 − |a|)` 在 |a| < 1 時收斂——**這就是第 14 章「極點要在單位圓內」的雛形**。（e）移動平均的步階響應：`y[n] = min(n + 1, M)/M`，**M 個樣本後就到終值，一步不多**——這是 FIR「有限」的具體意義。（f）兩者的成本比較：M 點 FIR 每個輸出要 M 次乘加，一階 IIR 只要 2 次。

**數值實例**：一階 IIR `y[n] = 0.8·y[n − 1] + x[n]`，輸入單位步階 u[n]，觀測 n = 5。

### 12 `12-取樣與混疊.html`

**目標**：把連續與離散兩個世界接起來，並且把「取樣率不夠會發生什麼」從一句口號變成一個算得出來的頻率。本章是整門課**唯一不可逆的損失**發生的地方。

**要點**：理想取樣 `x[n] = x(nT<sub>s</sub>)`，`T<sub>s</sub> = 1/f<sub>s</sub>`；**取樣定理（Nyquist–Shannon）**：頻寬 W 的訊號若 `f<sub>s</sub> > 2W` 則可由樣本**完美還原**，`f<sub>N</sub> = 2W` 稱為奈奎斯特速率、`f<sub>s</sub>/2` 稱為奈奎斯特頻率（折疊頻率）；**混疊（aliasing）**：`f > f<sub>s</sub>/2` 的成分會摺進 `[0, f<sub>s</sub>/2]`，視在頻率 `f<sub>a</sub> = |f − k·f<sub>s</sub>|`（k 取最接近 f/f<sub>s</sub> 的整數）；**混疊不可逆**——樣本本身完全相同，任何後處理都分不出來；工程對策：取樣**前**用**抗混疊低通濾波器（anti-aliasing filter）**限制頻寬，這一步在類比域，事後補做沒有用；理想還原是 sinc 內插 `x(t) = ∑<sub>n</sub>x[nT<sub>s</sub>]·sinc((t − nT<sub>s</sub>)/T<sub>s</sub>)`——不可實現（sinc 無限長且非因果）；實務用**零階保持（zero-order hold, ZOH）**＋重建低通，ZOH 的頻率響應是 `|H<sub>ZOH</sub>(f)| = |sinc(f/f<sub>s</sub>)|`，在高頻造成可預期的下垂（**droop**），可以事後用數位等化補償；完整鏈：類比 → 抗混疊濾波 → ADC → 數位處理 → DAC → 重建濾波 → 類比。來源：09-信號與系統-下 第 14 章。

**推導必寫**：（a）為什麼取樣會讓頻譜週期化：取樣等於乘上脈衝串，時域相乘 ⇒ 頻域摺積（第 06 章的相乘定理），脈衝串的頻譜還是脈衝串（間隔 f<sub>s</sub>），摺積的結果就是把原頻譜**每隔 f<sub>s</sub> 複製一份**。（b）混疊條件：複製品的裙邊互相重疊當且僅當 `W > f<sub>s</sub> − W`，即 `f<sub>s</sub> < 2W`。（c）視在頻率公式與**兩個頻率給出完全相同樣本**的證明：`cos(2π(f<sub>s</sub> − f)nT<sub>s</sub>) = cos(2πn − 2πfnT<sub>s</sub>) = cos(2πfnT<sub>s</sub>)`——**這一行就是混疊不可逆的全部理由**。（d）ZOH 的頻率響應：把每個樣本撐成寬 T<sub>s</sub> 的方塊，等於與寬 T<sub>s</sub> 的矩形摺積，由第 06 章矩形 ⇔ sinc 直接得到。（e）f = f<sub>s</sub>/2 這個臨界為什麼危險：取樣點可能剛好全落在零交越上，量到一整排 0。

**數值實例**：f = 3000 Hz 的弦波（振幅 A = 1 V）以 f<sub>s</sub> = 8000 Hz 取樣，觀測第 n = 3 個樣本。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 取樣週期 | T<sub>s</sub> = 1/8000 | **1.250000 × 10<sup>−4</sup> s ＝ 125.000000 µs** |
| 奈奎斯特頻率 | f<sub>s</sub>/2 | **4000.000000 Hz** |
| 判定 | 3000 < 4000 | **未混疊** |
| 視在頻率 | f<sub>a</sub> = \|3000 − 0 × 8000\| | **3000.000000 Hz（就是它自己）** |
| 第 3 個樣本 | A·cos(2π × 3000 × 3/8000) | **0.707107** |
| ZOH 衰減 | \|sinc(3000/8000)\| = \|sinc(0.375)\| | **0.784213（−2.111316 dB）** |

**可觀察證據**：把 5000 Hz 訊號送進 8000 Hz 取樣的系統，用 FFT 會在 3000 Hz 看到一根線——**而且它和真的 3000 Hz 訊號長得一模一樣**；老式數位示波器在取樣率不足時，螢幕上會出現緩慢飄移的假波形。**能證明**：混疊後的視在頻率、抗混疊濾波器裝上去之後假線消失。**不能證明**：某根譜線「是真的還是混疊來的」——**單靠一次量測絕對分不出來**，標準做法是改變 f<sub>s</sub> 再量一次：真訊號不動，混疊來的會跟著跑。

### 13 `13-離散頻譜分析.html`

**目標**：把 DTFT、DFT、FFT 三個名字一次分清楚，並且讓讀者算得出 **FFT 到底能看到多細的頻率、看不到的時候會發生什麼（洩漏）、加窗與零填充各買到了什麼**。這是本課最貼近日常工具的一章。

**要點**：**DTFT**（discrete-time Fourier transform）`X(e<sup>jω</sup>) = ∑<sub>n=−∞</sub><sup>∞</sup>x[n]e<sup>−jωn</sup>`——輸入離散、輸出**連續且以 2π 週期**（**這是與連續時間最大的不同，週期性正是第 12 章頻譜複製的直接後果**）；有意義的頻率範圍只有 `[−π, π]`，對應 `[−f<sub>s</sub>/2, f<sub>s</sub>/2]`；**DFT**（discrete Fourier transform）`X[k] = ∑<sub>n=0</sub><sup>N−1</sup>x[n]·exp(−j2πkn/N)`——輸入有限長、輸出離散，**這是電腦真正能算的版本**；DFT 隱含假設「這 N 點是一個週期，前後無限重複」；**頻率解析度 Δf = f<sub>s</sub>/N**，第 k 根 bin 的中心頻率是 `k·Δf`，窗長 `T<sub>win</sub> = N/f<sub>s</sub>`——**解析度只由窗長決定，`Δf = 1/T<sub>win</sub>`**；**譜洩漏（spectral leakage）**：訊號頻率不落在 bin 中心（也就是窗內不是整數個週期）時，能量會散到鄰近所有 bin；**加窗（windowing）**：用 Hann／Hamming／Blackman 把兩端壓到 0，主瓣變寬（解析度變差）換旁瓣變低（洩漏變小）；**零填充（zero-padding）**：把 N 點補 0 到更長再做 FFT，得到更密的取樣點，**但不會帶來任何新的頻率資訊**——它是內插，不是解析度；**FFT** 利用對稱性把 O(N²) 降到 O(N log N)，最有名的是 Cooley–Tukey 蝶形運算（要求 N 為 2 的冪次）。來源：09-信號與系統-下 第 11、12 章。

**推導必寫**：（a）DTFT 為什麼 2π 週期：`e<sup>−j(ω+2π)n</sup> = e<sup>−jωn</sup>e<sup>−j2πn</sup>`，而 n 是整數所以第二項恆為 1——**離散時間的頻率本質上就只有一個 2π 寬的範圍**。（b）Δf 的來歷：N 點涵蓋 `T<sub>win</sub> = N/f<sub>s</sub>` 秒，最低能分辨的頻率差就是「一個週期剛好塞滿這個窗」，即 `1/T<sub>win</sub> = f<sub>s</sub>/N`。（c）為什麼洩漏：DFT 把窗外當成週期延拓，訊號在窗邊接不上就出現跳躍，跳躍在頻域是寬頻的。（d）為什麼零填充不增加解析度：補的 0 沒有帶來新的觀測時間，`T<sub>win</sub>` 的**有效**長度沒變。（e）FFT 的運算量：直接 DFT 要 N² 次複數乘法，基 2 FFT 是 `(N/2)log<sub>2</sub>N` 次。

**四個窗函數的固定數值（查表常數，builder 照抄，不得改成別的版本）**

| 窗 | 主瓣寬度（bin） | 最高旁瓣（dB） | 一句話 |
| --- | --- | --- | --- |
| `rect`（矩形／不加窗） | 2 | **−13.3** | 解析度最好、洩漏最嚴重 |
| `hann` | 4 | **−31.5** | 通用首選，兩端平滑歸零 |
| `hamming` | 4 | **−42.7** | 主瓣與 hann 同寬，最近的旁瓣壓得更低 |
| `blackman` | 6 | **−58.1** | 洩漏最小，代價是主瓣寬三倍 |

**數值實例**：N = 1024（2<sup>10</sup>）、f<sub>s</sub> = 8000 Hz、訊號 f = 1000 Hz、窗選 `hann`。

| 正確性判準 | ① `Math.abs(kexact - k) < 1e-9` → 「**整數週期，無洩漏**：訊號頻率正好落在第 k 根 bin 的中心，窗內剛好裝 k 個完整週期，頭尾接得上，能量集中在一根線上。」② `Math.abs(kexact - k) >= 1e-9` → 「**會洩漏**：訊號頻率離 bin 中心差 X Hz，窗內不是整數個週期，接縫處的跳躍讓能量散到鄰近的 bin。**這時候加窗才有意義。**」③ `f >= fs/2` → 「**先處理混疊**：f 已超過奈奎斯特頻率 Y Hz，這根線在 FFT 上會出現在別的位置——回第 12 章。」④ 每次都要附因果句：「**解析度只由窗長決定**：Δf = 1/T<sub>win</sub>。要分辨相差 1 Hz 的兩根線，就得量滿 1 秒，沒有捷徑。」⑤ 每次都要寫加窗的取捨：「選了 X 窗：主瓣 A 個 bin（＝B Hz，解析度變差），最高旁瓣 C dB（洩漏被壓低）。**沒有一個窗兩邊都贏。**」⑥ 每次都要寫零填充那一句：「把 N 補 0 到兩倍只會讓譜線看起來更密（內插），T<sub>win</sub> 沒變，**真正能分辨的最小頻率差完全不變**。」⑦ 每次都要顯示量級對照：「N = 1024、f<sub>s</sub> = 8000 就是 0.128 秒的窗，Δf = 7.8125 Hz；要達到 1 Hz 解析度得量滿 1 秒。」 |
| 邊界情形 | `dft-nexp = 4`（N = 16）→ 加速只有 8.000000 倍，要寫「N 小的時候 FFT 沒什麼好處」。`dft-nexp = 14` ＋ `dft-fs = 1000` → T<sub>win</sub> = 16.384000 s，要寫「要等超過 16 秒才有一張頻譜」。`dft-f = 10` ＋ `dft-fs = 48000` ＋ `dft-nexp = 4` → Δf = 3000.000000 Hz，`kexact` = 0.003333、k = 0，要寫「訊號頻率遠低於一根 bin 的寬度，整個掉進直流 bin 裡」。`dft-f = 20000` ＋ `dft-fs = 1000` 走判準③。任何情形下輸出不得出現 `NaN`、`Infinity`、`undefined`。 |

**不要混淆（至少四條）**：DTFT、DFT、FFT 是三件事——DTFT 是理論（輸出連續）、DFT 是它的取樣版（輸出離散）、**FFT 只是算 DFT 的快速演算法，不是另一種轉換**；「解析度」與「顯示點的密度」不同（前者靠窗長、後者靠零填充）；加窗不是「讓訊號變好看」，它是拿解析度換洩漏的一筆交易；bin 中心頻率 `k·f<sub>s</sub>/N` 與訊號真實頻率不一定相等，用 FFT 讀頻率天生有 ±Δf/2 的量化誤差（要更準得用內插估計）。

**可觀察證據**：任何頻譜分析軟體或示波器的 FFT 功能都能直接看到這些效應——把訊號頻率從 bin 中心慢慢移開，會親眼看到一根線裂成一團；換窗會看到裙邊高度整片變化。**能證明**：Δf 與窗長的倒數關係、洩漏的存在、不同窗的旁瓣高度。**不能證明**：兩根靠得比 Δf 還近的譜線是不是「其實有兩根」——**這是解析度的物理極限，不是儀器不夠好**；也證明不了訊號的相位是否穩定（單張 FFT 只是一個快照）。

### 14 `14-Z轉換與單位圓.html`

**目標**：把第 07 章的 s 平面整套搬到離散世界。讀者要能看著一個極點的**半徑與角度**就說出：這個系統穩不穩定、會在哪個頻率共振、衰減要幾個樣本、差分方程長什麼樣。

**要點**：`X(z) = ∑<sub>n=−∞</sub><sup>∞</sup>x[n]z<sup>−n</sup>`，`z = r·exp(jω)` 是複數；**收斂域（ROC）**通常是 `|z| > r<sub>0</sub>`（右側訊號）或 `|z| < r<sub>1</sub>`（左側訊號）的環形區域，**同一個 X(z) 配不同 ROC 對應不同的 x[n]**；**單位圓 |z| = 1 就是 DTFT**：只要單位圓在 ROC 內，把 `z = e<sup>jω</sup>` 代進去就得到 DTFT——**這是 z 平面上最重要的一條線**；`z = e<sup>sT<sub>s</sub></sup>` 把 s 平面映到 z 平面：左半平面 → 單位圓內、虛軸 → 單位圓、右半平面 → 單位圓外；轉移函數 `H(z) = (∑b<sub>m</sub>z<sup>−m</sup>)/(∑a<sub>k</sub>z<sup>−k</sup>)`；**因果系統穩定 ⇔ 所有極點落在單位圓內**；一對共軛極點 `p = r·exp(±jθ)` 對應 `h[n] = r<sup>n</sup>·sin((n + 1)θ)/sin θ`（θ = 0 或 180° 時 sin θ = 0，取極限得 `r<sup>n</sup>(n + 1)cos(nθ)`），差分方程是 `y[n] = 2r·cos θ·y[n − 1] − r²·y[n − 2] + x[n]`；共振頻率 `f<sub>peak</sub> = (θ/360°)·f<sub>s</sub>`；衰減到 1/e 需要 `n<sub>τ</sub> = −1/ln r` 個樣本；`r → 1` 時峰愈尖（Q 愈高）；頻率響應大小的實數式 `|H(e<sup>jω</sup>)| = 1/√((1 − 2r·cos(θ − ω) + r²)(1 − 2r·cos(θ + ω) + r²))`；四種反轉換：長除法、部分分式＋查表、圍道積分（留數，連回複變）。來源：09-信號與系統-下 第 13 章。

**推導必寫**：（a）為什麼是 `z<sup>−n</sup>` 而不是 `z<sup>n</sup>`：因為 `z<sup>−1</sup>` 代表「延遲一個樣本」，差分方程裡的 y[n − 1] 直接變成 `z<sup>−1</sup>Y(z)`——**Z 轉換之於差分方程，就像拉氏之於微分方程**。（b）`z = e<sup>sT<sub>s</sub></sup>` 的映射：`|z| = e<sup>σT<sub>s</sub></sup>`，σ < 0 ⇒ |z| < 1；`∠z = ωT<sub>s</sub>`，ω 每增加 `2π/T<sub>s</sub>` 就繞回原點——**s 平面的無限長虛軸被捲成一個圓，這就是離散頻譜週期性的幾何解釋**。（c）共軛極點的 h[n]：對 `H(z) = 1/((1 − pz<sup>−1</sup>)(1 − p*z<sup>−1</sup>))` 做部分分式，得 `h[n] = (p<sup>n+1</sup> − p*<sup>n+1</sup>)/(p − p*)`，用歐拉公式化簡成 `r<sup>n</sup>·sin((n + 1)θ)/sin θ`。**不是 `r<sup>n</sup>cos(θn)`**——後者是兩個模態直接相加除以 2，對應的初始條件不是 δ[n]；拿差分方程對 δ[n] 遞迴一遍即可分辨（h[2] 應為 r²，cos 式卻給 0）。（d）差分方程係數怎麼來：`(1 − pz<sup>−1</sup>)(1 − p*z<sup>−1</sup>) = 1 − 2r cos θ·z<sup>−1</sup> + r²z<sup>−2</sup>`。（e）`|H|` 的幾何意義：分母的兩個因式各是「單位圓上的觀測點到兩個極點的距離」，**距離愈近，值愈大**——所以 r 愈接近 1，峰愈高愈尖。（f）n<sub>τ</sub> 的來歷：`r<sup>n</sup> = 1/e` ⇒ `n = −1/ln r`。

**數值實例**：一對共軛極點 r = 0.9、θ = 45°，f<sub>s</sub> = 8000 Hz，觀測 n = 5。

### 15 `15-數位濾波器與多速率.html`

**目標**：收線。把 FIR 與 IIR 的取捨從「名詞」變成一組可以算的數字（增益、群延遲、運算量、−3 dB 頻率），並補上兩件實務上一定會遇到的事：**雙線性變換的預扭曲**與**抽取／內插**。

**要點**：**FIR**（有限脈衝響應）h[n] 有限長，**本質穩定**（極點全在原點），係數對稱時**嚴格線性相位**，群延遲恆為 `(M − 1)/2` 個樣本；M 點移動平均的頻率響應 `|H(e<sup>jω</sup>)| = |sin(Mω/2) / (M·sin(ω/2))|`（ω = 0 時取 1），**零點在 f = k·f<sub>s</sub>/M**；FIR 設計三法：**窗口法**（對理想響應反 DTFT 取截斷再加窗）、頻率取樣法、**Parks–McClellan**（Remez 演算法，最小最大誤差，**同樣規格下階數最省**）；**IIR**（無限脈衝響應）含回授，**同樣規格下係數少得多**，但可能不穩定、相位非線性；一階 IIR `y[n] = a·y[n−1] + (1 − a)x[n]` 的 `|H| = (1 − a)/√(1 − 2a·cos ω + a²)`，−3 dB 頻率由 `cos ω = (4a − 1 − a²)/(2a)` 解出（**餘弦值超出 ±1 時代表 −3 dB 點高過奈奎斯特頻率**）；IIR 常用**雙線性變換**由類比原型映射：`s = (2/T<sub>s</sub>)·(1 − z<sup>−1</sup>)/(1 + z<sup>−1</sup>)`，它把整條虛軸壓進單位圓（**不會混疊**）但把頻率軸扭曲，所以要**預扭曲（prewarping）**：`f<sub>類比</sub> = (f<sub>s</sub>/π)·tan(πf<sub>數位</sub>/f<sub>s</sub>)`；實作架構：直接型 I／II、轉置型、**級聯二階節**（高 Q 時必須用）、平行、格狀；定點實作要注意量化誤差與極限循環；**多速率**：抽取（decimation）每 M 個取一個，**取樣率變成 f<sub>s</sub>/M，抽取前一定要先低通到新的奈奎斯特頻率 f<sub>s</sub>/(2M)**；內插（interpolation）插 L − 1 個 0 再低通；多相分解讓兩者只算「用得到的那些乘法」。來源：09-信號與系統-下 第 15、16 章。

**推導必寫**：（a）移動平均頻率響應的閉合式：`H(e<sup>jω</sup>) = (1/M)∑<sub>n=0</sub><sup>M−1</sup>e<sup>−jωn</sup>`，用等比級數和得 `(1/M)·(1 − e<sup>−jωM</sup>)/(1 − e<sup>−jω</sup>)`，提出半角後取模得上式。（b）為什麼群延遲是 `(M − 1)/2`：相位是 `−ω(M − 1)/2`（線性），微分取負得常數——**線性相位就是這樣來的，而且對任何對稱 FIR 都成立**。（c）零點位置：`sin(Mω/2) = 0` 且 `sin(ω/2) ≠ 0` ⇒ `ω = 2πk/M` ⇒ `f = k·f<sub>s</sub>/M`。（d）一階 IIR 的 −3 dB 條件：令 `|H|² = 1/2` 解出 `cos ω`。（e）預扭曲為什麼必要：雙線性把 `ω<sub>類比</sub> = (2/T<sub>s</sub>)tan(ω<sub>數位</sub>T<sub>s</sub>/2)`，低頻時 tan ≈ 自變數（誤差小），接近奈奎斯特時偏差極大——所以設計類比原型時要先把目標頻率「反扭」過去。（f）抽取為什麼要先濾波：抽取等於用 f<sub>s</sub>/M 重新取樣，第 12 章的規則原封不動適用。

**數值實例**：M = 8 點移動平均 FIR，f<sub>s</sub> = 8000 Hz，觀測 f = 500 Hz。

邊界對照：f = **1000 Hz** → \|H\| = **0.000000**（**剛好在零點上，完全被濾掉**）；f = **1500 Hz** → \|H\| = **0.224994（−12.956579 dB）**（**旁瓣，只剩兩成多**）；f = **250 Hz** → **0.901764（−0.898140 dB）**。M = **4** → 第一個零點 **2000.000000 Hz**、f = 500 處 \|H\| = **0.906127（−0.856214 dB）**、群延遲 **1.5 樣本**（**短的濾波器比較不濾也比較不延遲**）；M = **32** → 第一個零點 **250.000000 Hz**、f = 500 處 \|H\| = **0.000000**、群延遲 **15.5 樣本**。換成**一階 IIR**（a = 0.8、f<sub>s</sub> = 8000）：f = 500 → \|H\| = **0.497222（−6.068991 dB）**、**−3 dB 頻率 285.301514 Hz**、每個輸出只要 **2 次乘加（16000 次／秒，只有 FIR 的四分之一）**；a = **0.5** → −3 dB 頻率 **920.213825 Hz**；a = **0.95** → **65.322974 Hz**（**a 愈接近 1 濾得愈狠**）；a = **0.05** → −3 dB 點的餘弦值算出來是 **−8.025000**（超出 ±1）→ **−3 dB 頻率高過奈奎斯特頻率，這個 a 幾乎不濾波**。**抽取**：M = 8、f<sub>s</sub> = 8000 → 新取樣率 **1000.000000 Hz**、抽取前必須先低通到 **500.000000 Hz**；M = 4 → **2000.000000 Hz** 與 **1000.000000 Hz**。**雙線性預扭曲**（f<sub>s</sub> = 8000）：目標 1000 Hz → 類比原型要設在 **1054.786175 Hz**（**差 5.478618 %**）；目標 3000 Hz → **6147.744354 Hz**（**差超過一倍，接近奈奎斯特時扭曲極嚴重**）；目標 100 Hz → **100.051436 Hz**（**低頻幾乎不用扭**）。

**不要混淆（至少四條）**：FIR 的「有限」講的是 h[n] 的長度，不是「輸出有限」；線性相位是**對稱 FIR** 的特權，一般 IIR 做不到（可以用零相位的前後兩次濾波在離線情況下換到，代價是不能即時）；移動平均是低通但**不是好低通**（旁瓣只低 −13 dB，跟矩形窗一樣，因為它就是矩形窗）；抽取不是「把資料丟掉」這麼單純——**丟之前沒濾波，丟掉的資訊會變成混疊污染留下來的部分**。

**可觀察證據**：在 DSP 板或任何能跑迴圈的環境實作這兩種濾波器，掃頻量 \|H\|，並用邏輯分析儀量每個輸出樣本的處理時間，可以直接看到 M 次乘加 vs 2 次乘加的差別；把方波打進去看輸出的角，FIR 對稱地圓、IIR 不對稱（前緣與後緣不一樣），這就是相位非線性的時域證據。**能證明**：實作濾波器的實際頻率響應、群延遲、每個樣本的運算時間。**不能證明**：定點實作的「係數量化後真正的極點在哪」（要靠專門分析）；也證明不了「這個設計是最省的」——那要與 Parks–McClellan 的理論下限比較。

  - 脈衝響應：「h(t) 不是『系統的輸出』，它是系統對 δ(t) 這個**特定輸入**的輸出；它之所以特別，是因為有了它就能用摺積算出所有其他輸入的輸出。」
  - 收斂域：「ROC 不是附註。同一個 X(s) 或 X(z) 配不同的 ROC，對應到完全不同的時間訊號（一個右側、一個左側），穩定性判斷也相反。」
  - 極點：「極點是分母的根，不是『系統的頻率』。它的**實部管衰減多快、虛部管振多快**；離散系統要看的是**半徑與角度**。」
  - 頻率解析度：「Δf = f<sub>s</sub>/N 看起來像『點數愈多愈細』，但真正決定它的是**窗長** T<sub>win</sub> = N/f<sub>s</sub>，Δf = 1/T<sub>win</sub>。零填充讓點變密**不會**改善它。」
  - 群延遲：「群延遲 −d∠H/dω 與相位延遲 −∠H/ω 是兩個不同的量，只有相位嚴格線性時才相等。前者決定波形變不變形。」
  - 線性：「線性專指**疊加**，不是『圖形是直線』。y = x + 3 畫出來是直線但不線性，它叫仿射。」
  - FIR：「FIR 的『有限』講的是 h[n] 的長度，不是輸出的長度。它天生穩定是因為**沒有回授**，不是因為短。」
  - 奈奎斯特：「奈奎斯特**速率** 2W 是訊號的性質，奈奎斯特**頻率** f<sub>s</sub>/2 是取樣系統的性質，中文常常都叫『奈奎斯特頻率』，講數字時務必說清楚是哪一個。」
- 每張卡的「位置／角色」要寫**它在本課哪一章、在哪門後續課或哪個真實裝置用到**。
- 符號（δ、∗、∑、∫、ω、σ、ζ、τ、Γ 之外的本課符號如 Δf、n<sub>τ</sub>、f<sub>s</sub>、T<sub>win</sub>）出現時要在卡內寫出讀法。
- 首次出現的英文縮寫要展開全名（LTI、ROC、DTFT、DFT、FFT、FIR、IIR、ZOH、ISI、AM）。

- HTML 的選項顯示文字與 `Q` 的解釋必須指向同一個答案，builder 交付前逐題核對。

### 7.5 JavaScript 規則

- 只用 ES2017 以內語法（`const`／`let`／箭頭函式／樣板字串／`Object.keys`）。不用模組、不用 `class`、不用 optional chaining（保守相容）。
- 不得使用 `Math.random`、`setTimeout` 動畫、`localStorage`、`fetch`、`document.write`。
- **不得使用複數類別或第三方數學庫**。第 06、08、14、15 章的複數運算一律以「大小／相位」的實數式手寫，公式已在第 4 節鎖死（例如 `zplane` 的 `|H|` 用兩個餘弦因式相乘再開根號，**不需要任何複數運算**）。
- 所有寫入 DOM 的字串用 `innerHTML`（內容全部由本檔常數與數字組成；使用者輸入只以 `Number()` 轉數字後格式化，不得原樣塞回 `innerHTML`）。
- **所有除法與超越函式都要先擋非法輸入**：`sysmap` 的 `f`（滑桿最小 1，安全）、`sigclass`／`sampling` 的 `sinc` 在 x = 0 取 1、`filterorder` 的 `Math.log10(fs/fc)`（`fs <= fc` 時走保護路徑）、`digfilter` 的 `Math.sin(w/2)`（w = 0 時取 1）與 `Math.acos`（引數絕對值 > 1 時走保護路徑）、`dtsystem`／`zplane` 的 `Math.log(a)`（a = 0 時走保護路徑）、`zplane` 的 `Hmag`（分母乘積 < 1e−12 時輸出文字）、`ammod` 的 `pt`（m = 0 時效率直接給 0）。**不得讓 `NaN`、`Infinity`、`undefined`、`null` 洩漏到畫面上**；該顯示無限大時一律輸出中文文字（例「無限大」「不適用（發散）」「無限大（不衰減）」「ZOH 在這個頻率剛好是零點」）。
- **大數精度（本課特有）**：`filterorder` 的 `Math.pow(f/fc, 2*n)` 在滑桿極端值（`f/fc` 最大 200、2n 最大 20）會來到 10<sup>46</sup> 量級。這**不會**溢出成 `Infinity`（double 上限約 1.8 × 10<sup>308</sup>），但 `1 + x` 會完全吃掉那個 1，而且 `1/Math.sqrt(x)` 會掉到 10<sup>−24</sup> 量級。**dB 一律用對數式算** `db = -10*Math.log10(1+Math.pow(ratio,2*n))`；當 `ratio > 100 && n >= 5` 時直接用漸近式 `db = -20*n*Math.log10(ratio)`（誤差遠小於顯示位數）。`att` 同樣處理。倍數欄位在絕對值小於 1e−4 時依 `num6` 規則自動轉指數格式。
- **單位換算集中在讀值處**：`ms → s` 乘 `1e-3`、`µs → s` 乘 `1e-6`、`kHz → Hz` 乘 `1e3`、`匝數／點數` 不換算。換算後的變數名加 `SI` 後綴以免混用。
- **數字格式化的統一規則**：絕對值落在 `[1e-4, 1e7)` 用 `fmt(x,6)`；否則用 `exp(x,6)`。零一律顯示 `0.000000`。這條要寫成一個 helper（**必須命名為 `num6`**）並全檔使用，避免各章格式不一。
- 檔尾 `if(typeof module!=="undefined")module.exports={fmt,num6,sinc,…};` 方便語法檢查與人工交叉驗算。

## 10. 來源筆記缺口（僅列出，本案不回頭改寫筆記）

以下是撰寫本 spec 時發現、來源筆記沒有但本課需要的內容。builder **可以自行補上教學文字**（都是標準大學課綱內容或可由既有段落推得），但**不得回頭修改 `.md` 筆記**。Lead 可另案決定是否補進筆記。

1. **兩份筆記完全沒有任何數值範例**，全篇是符號式。本課所有數值實例都是依標準公式自行算出並列在本 spec 第 4 節，verifier 應以本 spec 的數字為準交叉驗算。
2. **筆記沒有任何量測儀器**。本課每章的「可觀察證據」段落全部是為了滿足 QUALITY-GATES 而補寫的標準實驗室實務。
3. **筆記沒有「為什麼要換域」的動機段**，直接從分類開始講。本課 00 章補上「系統有記憶 ⇒ 輸出不再是輸入乘一個數 ⇒ 弦波是本徵函數 ⇒ 所以要拆成弦波」這條完整動機鏈，這是零基礎讀者能讀懂後面所有內容的前提。
4. **筆記沒有給摺積的閉合式範例**（只給定義與代數性質）。本課 04 章補上「矩形通過一階系統」的兩段閉合式與**面積相乘**的驗算技巧。
5. **筆記沒有給傅立葉級數的具體係數與帕塞瓦百分比**。本課 05 章補上方波／三角波／鋸齒波三組係數與累積功率百分比，並用「1/n vs 1/n²」把「波形平滑度決定高頻含量」講成一條可算的規律。
6. **筆記沒有給 sinc 的定義版本**（歸一化與否）與 3 dB 頻寬係數 0.442946。本課 06 章鎖定歸一化版並補上這個常數。
7. **筆記沒有給二階系統的暫態指標公式**（只列出四種阻尼的名稱）。本課 08 章補上 M<sub>p</sub>、t<sub>p</sub>、t<sub>s</sub>、ω<sub>r</sub>、M<sub>r</sub> 五個閉合式與 ζ = 0.707107 這個門檻，並補上與電路學 Q = 1/(2ζ) 的換算。
