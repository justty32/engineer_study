00・系統一旦有記憶，就不能再當成一個放大倍數

訊號與系統世界觀：這門課到底在描述什麼

訊號（signal）是一個函數，系統（system）是把函數變成另一個函數的機器。只要系統有記憶，同一個振幅的輸入在不同頻率下會得到不同的輸出，這時候「一個放大倍數」就不夠用了——整門課存在的理由就是這一句。

這章假設已懂：無前置章節。只假設你會讀數字與單位，並且知道「頻率」與「dB」大概是什麼意思。

痛點：既然電路學已經會算了，為什麼還要一門「信號與系統」

讀完電路學的人常有一個疑惑：電阻分壓算得出來、RC 充放電也算得出來，那再開一門課要幹嘛？更常見的挫折是課本第一頁就丟出一堆積分、希臘字母與「域」，卻沒先說清楚要解決什麼問題。於是名詞全背起來了，卻答不出最基本的一句話：這門課在描述什麼對象、什麼時候非用它不可。

先把答案講完再回頭補細節。這門課只處理兩種東西：訊號與系統。訊號是把一個量指派給時間（或空間）的函數，系統是把輸入訊號對應到輸出訊號的算子 T，寫成 y(t) = T{x(t)}。而「什麼時候非用不可」的判準只有一條：系統有沒有記憶。沒有記憶的系統，輸出就是輸入乘上一個固定的數，一個乘法講完，不需要這門課；有記憶的系統（電容要充電、機械有慣性、房間會迴音），現在的輸出取決於過去發生過什麼，於是同一個振幅的輸入換一個頻率送進去，出來的振幅與相位就不一樣了。這個「隨頻率而變的振幅與相位」就叫做頻率響應（frequency response），也是整門課的主角。

來源：09-信號與系統-上「這科在學什麼」。

白話直覺：資訊從哪來、被搬到哪個域、代價是什麼

把整條因果鏈走一次。訊號從哪來：麥克風把聲壓變成電壓、感測器把溫度變成電壓、天線把電磁場變成電壓，得到的都是一個隨時間變化的數，也就是函數 x(t)。系統對它做了什麼：這個函數經過放大器、電纜、濾波器或一段程式，出來另一個函數 y(t)。系統無記憶時，y 只是 x 的每一點各自乘一個數，看時間軸就夠了；一旦有記憶，y 的某一點由 x 的一整段過去共同決定，在時間軸上就變成一個難算的積分。

這件事在哪個域最好描述：這時候換一個座標系。對一個線性非時變（linear time-invariant, LTI）系統，送進去 cos(2πft)，出來一定還是同一個頻率的 cos(2πft + φ)——頻率不會變，只有振幅與相位被改。這個性質讓弦波成為 LTI 系統的「本徵函數」，也是整門課要把訊號拆成弦波的唯一理由：在頻率域裡，難算的積分退化成每個頻率各乘一個複數。可以暫時把它想成換一種座標把矩陣對角化，比喻到此為止；精確的說法是弦波是 LTI 算子的本徵函數，頻率響應就是對應的本徵值。

換域的代價是什麼：頻率域把「什麼時候發生」這件事藏進相位裡，你再也不能一眼看出事件的先後；而且要得到完整的頻譜，理論上需要無限長的觀測時間。儀器量到什麼：示波器給你時間軸上的波形，頻譜分析儀給你各頻率的振幅但通常不給相位，網路分析儀（vector network analyzer, VNA）才同時給振幅與相位。也就是說，這門課的兩個域各對應一類儀器，兩邊都看才拼得出全貌。

本課骨架照這條鏈走：訊號分類 → 系統分類 → LTI 的脈衝響應與摺積 → 傅立葉分析 → 拉氏與 Z 轉換 → 取樣與還原。前段把對象講清楚，中段把難算的積分換成好算的乘法，末段把連續世界搬進電腦。

推導：從「有記憶」推到一階系統的增益、相位與延遲

（a）為什麼有記憶就必須換域。設系統是線性非時變的，輸入 x(t) = cos(2πft)。線性保證疊加成立，非時變保證把輸入延後多久、輸出就延後多久。把弦波寫成複指數 ej2πft（虛數單位在數學課寫 i，電機一律寫 j，因為 i 留給電流），送進系統後，輸出必定是同一個複指數乘上一個只跟頻率有關的複數 H：輸出 = H·ej2πft。取模得振幅倍率 |H|，取幅角得相位平移 ∠H。頻率沒有被改變，這就是弦波的特權。既然每個頻率各自只被乘一個複數，那把任意訊號拆成弦波之後，系統的作用就變成逐頻率相乘——這是換域唯一的動機。

（b）一階系統的增益怎麼來。最簡單的有記憶系統（電容充放電、機械一階慣性）的頻率響應是 H(jf) = 1 / (1 + j f/fc)。這裡 f 是訊號頻率（單位 Hz），fc 是轉角頻率（corner frequency，又叫 −3 dB 頻率，單位 Hz），假設系統線性、非時變、初始靜止。令頻率比 r = f/fc，則 H = 1/(1 + jr)。複數取模是「分子的模除以分母的模」，分母的模是 √(1² + r²)，所以 |H| = 1/√(1 + r²)。複數取幅角是「分子的幅角減分母的幅角」，分子是實數 1、幅角 0，分母的幅角是 arctan(r)，所以 ∠H = −arctan(r)，單位可用 ° 或 rad。

（c）−3 dB 是怎麼跑出來的。dB 是比值的對數：振幅比用 20 log10、功率比用 10 log10。當 r = 1（f 剛好等於 fc）時，|H| = 1/√2 = 0.707107，換算成 20 log10(0.707107) = −3.010300 dB。功率正比於振幅平方，0.707107² = 0.5，剛好剩一半。所以「−3 dB 點」就是功率減半的那個頻率，全業界拿它當頻寬的定義門檻；它的振幅是 70.7 %，不是「掉 3 %」。

（d）兩種延遲不是同一個數。相位延遲（phase delay）問的是「這個弦波整體被推遲了多久」，把相位換算成時間：tp = |∠H| / (360°·f)，單位 s。群延遲（group delay）問的是「一包窄頻訊號的包絡被推遲了多久」，定義是相位對角頻率的負斜率：τg = −d∠H/dω，單位 s（∠H 用 rad、ω 用 rad/s）。把 ∠H = −arctan(ω/ωc) 對 ω 微分，用 arctan 的導數公式 d(arctan u)/du = 1/(1 + u²) 加上鏈鎖律，得到閉合式 τg = (1/ωc) / (1 + (ω/ωc)²)。只有當相位對頻率成正比（一條過原點的直線）時，這兩個數才會相等；一階系統的相位不是直線，所以兩者不同——這件事會在第 09 章造成波形變形。

數值實例：f = 1000 Hz、fc = 1000 Hz、A = 1 V

取訊號頻率 f = 1000 Hz、系統轉角頻率 fc = 1000 Hz、輸入振幅 A = 1 V。這組數字就是本章互動元件的預設值。

邊界對照。f = 10 Hz（r = 0.01）→ |H| = 0.999950、相位 −0.572939°——這個系統在這裡就是一個乘以 1 的常數，不需要本課。f = 20000 Hz（r = 20）→ |H| = 0.049938（−26.031444 dB）、相位 −87.137595°。fc = 20 Hz、f = 20000 Hz（r = 1000）→ |H| = 0.001000（−60.000004 dB）、相位 −89.942704°——每 10 倍頻掉 20 dB，這就是「一階」的意思。

量級對照：市電 50 Hz、電話語音取樣率 8000 Hz、CD 44.1 kHz、人耳上限約 20000 Hz。fc = 1000 Hz 的一階系統對市電幾乎沒有作用（r = 0.05），對人耳上限卻已壓掉 26 dB——同一個系統是不是「只是一根電線」，取決於送進去的頻率落在哪裡。

自由實驗：把訊號頻率與系統轉角頻率分開調整

場景是一個一階系統（例如一段 RC 低通，或任何有一個時間常數的機構），輸入是振幅 A 的單一弦波。你可以分別移動訊號的頻率、系統的轉角頻率與輸入振幅，觀察增益、相位與兩種延遲怎麼變。重點是看 r = f/fc 落在哪一區。

頻率比 r = 1.000000；增益 |H| = 0.707107（−3.010300 dB）；輸出振幅 = 0.707107 V；相位 ∠H = −45.000000°；相位延遲 tp = 1.250000 × 10−4 s ＝ 125.000000 µs；群延遲 τg = 7.957747 × 10−5 s ＝ 79.577472 µs。動態區：增益與相位都在明顯變化，同一個系統對不同頻率的處理不同，這就是整門課要處理的事。系統之所以會「挑頻率」，是因為它有記憶（要充放電），輸出取決於過去而不只是現在。量級對照：−3 dB 就是掉到 70.7 %，功率剩一半；這是全業界定義頻寬的門檻。輸入振幅只縮放輸出振幅，不影響 |H|、相位與兩種延遲。

不要混淆

  • 訊號不是「電壓」。它是一個函數——同一個函數今天可以是電壓，明天可以是聲壓、股價或影像亮度；本課的結論對這些對象一體適用，換的只是單位。
  • 「系統」不等於「電路」。一段程式、一條機械軸、一個房間的迴音、一條光纖都是系統；判準是「有沒有把一個輸入函數對應成一個輸出函數」，不是有沒有零件。
  • 增益是倍數、dB 是它的對數，兩者不是同一個數。−3 dB 不是「掉 3 %」而是掉到 70.7 %；−20 dB 是掉到 10 %，−60 dB 是掉到 0.1 %。
  • 相位延遲與群延遲是兩個不同的量。本章預設值分別是 125.000000 µs 與 79.577472 µs，差了將近 1.6 倍；只有當相位對頻率成正比時兩者才相等。

可觀察證據：拿什麼量、量到什麼

最土法的做法是函數產生器加示波器：設在某個頻率，量輸入與輸出的振幅比得到 |H|，量兩條波形的時間差 Δt，換算 ∠H = −360°·f·Δt，就得到那個頻率上的一個點；一個頻率一個頻率掃過去，就能把 |H| 與 ∠H 描出來。網路分析儀（vector network analyzer, VNA）自動做同一件事，只是快得多、準得多。

能證明什麼：某個系統在某個特定頻率的增益與相位、−3 dB 點落在哪裡、高頻的衰減斜率是不是每 10 倍頻 20 dB（也就是它是不是一階）。這些都是可以直接讀數字的。

不能證明什麼：量到一組漂亮的 |H| 與 ∠H，並不能證明這個系統是線性非時變的——掃頻本身已經預設了系統只會改振幅與相位。要驗證線性與非時變，得另外做疊加測試與時移測試，那是第 03 章的事。它也證明不了「這個系統的 h(t) 長什麼樣」——脈衝響應要靠脈衝或步階激發才反推得出來。掃頻量的還是穩態，量不到開機瞬間的暫態。

連到哪門課

一階系統在真實世界最常見的樣子是 RC 低通電路，元件那一側（fc = 1/(2πRC) 怎麼來）見電路學的一階濾波器與頻率響應；本課的角度則是「那只是 h(t) 與 H(jω) 的一個特例」。喇叭分頻網路、感測器前端的抗混疊濾波、馬達控制迴路的頻寬、接收機的中頻選擇性，用的都是同一組量。

本章用到的指數函式、arctan 與對數見工程數學先修的極限與導數，特別是群延遲那一步的微分。下一章先把訊號這個對象分清楚：它是能量訊號還是功率訊號，這個判斷決定後面該用傅立葉轉換還是傅立葉級數。
