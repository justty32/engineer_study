11・積分換成求和，系統變成一個帶狀態的迴圈

離散時間訊號與差分方程：把前十章整批搬到 x[n]，順便認識 FIR 與 IIR

離散時間的觀念幾乎全部是連續時間的複製貼上，只有兩個地方會咬人：縮放與穩定。這章把摺積和推一次、把一階遞迴的脈衝響應逐格展開一次，看清 FIR 與 IIR 各自買到什麼、付出什麼。

這章假設已懂：04 線性非時變與摺積的摺積與 BIBO 條件、02 基本訊號與訊號運算的 δ[n] 與 u[n]，以及工程數學先修的幾何級數與收斂。

痛點：換成方括號以後，哪些東西原封不動，哪些會悄悄壞掉

寫過程式的人看到 x[n] 通常比看到 x(t) 還安心：那不就是一個陣列嗎。麻煩正是這份安心，它會讓人把連續時間的規則直接抄過來，卻沒發現其中一條在離散世界的意思完全變了。平移、反轉、奇偶分解、能量、功率確實可以照抄；但只要碰到縮放，直覺立刻出錯，因為陣列裡根本沒有第 0.5 格這種東西。

第二個坎是差分方程（difference equation）。課本把 ∑k=0N aky[n − k] = ∑m=0M bmx[n − m] 端出來，說「這就是數位濾波器的標準形」，讀者卻看不出它和摺積是什麼關係，也看不出為什麼有些系統寫得出把舊輸出拿回來用的遞迴，有些只能寫成一串固定係數的加權和。

第三個坎是穩定。「無限脈衝響應的 I 是 infinite，既然無限長，怎麼可能穩定？」這句話問得很合理，這章要用一個手算得完的例子把它按死：h[n] 每一項都不為零，但 ∑|h[n]| 是明確的有限數字，而穩定與否看的是後者。

白話直覺：系統就是一個帶狀態的迴圈，狀態留多久決定它屬於哪一種

訊號從哪裡來？從一個把類比電壓每隔固定時間記錄一次的裝置來，記錄下來的就是一串數字，第 n 個數字叫 x[n]。系統對它做了什麼？系統是一段迴圈：每讀進一個新樣本，就用它和手上還留著的舊資料算出一個新的輸出。這件事在哪個域最好描述？在樣本域看得見因果順序，每個輸出來自哪幾格輸入一清二楚；但要判斷這個迴圈會不會愈滾愈大，時間域只能一格一格試，換到第 14 章的 z 域就變成看極點在不在單位圓內。換域的代價是必須接受複變函數與收斂域這一整套語言。儀器量到什麼？邏輯分析儀只量得到一串實際輸出的數字。

離散時間訊號（discrete-time signal）寫成 x[n]，n 是整數。這裡要立刻收掉一個常見的誤解：離散不是「時間切得很細」，而是根本沒有 n = 0.5 這件事——它不是精度問題，是定義域問題。索引 n 是樣本序號，沒有單位；要換成秒必須乘上取樣週期 Ts，而 Ts 要等第 12 章才會出現。

連續時間學過的運算幾乎都能照搬：平移寫 x[n − n0]，反轉寫 x[−n]，奇偶分解一樣是 xe[n] = (x[n] + x[−n])/2 與 xo[n] = (x[n] − x[−n])/2，能量寫 E = ∑n=−∞∞ |x[n]|²。唯獨縮放要小心：x[2n] 是降取樣（downsampling），它把奇數格整個丟掉，資訊是真的沒了；x[n/2] 只在 n 為偶數時有定義，中間那些格要靠內插補出來，補出來的值是猜的。

系統這一側只有兩種迴圈寫法。第一種不回頭看自己的輸出，只把最近 M 個輸入平均；它的脈衝響應只有 M 項，之後永遠是零，所以叫有限脈衝響應（finite impulse response, FIR）。第二種把上一次的輸出乘一個係數再加回來，例如 y[n] = a·y[n − 1] + x[n]；一根脈衝進去之後，回授讓它衰減卻永遠除不盡，所以叫無限脈衝響應（infinite impulse response, IIR）。可以暫時把它想成一個漏水的水桶，每個樣本漏掉固定比例、永遠漏不完；比喻到此為止，精確的說法是 h[n] = anu[n]，一個公比為 a 的幾何數列。

來源：09-信號與系統-下 §10.1–§10.3。

推導：從篩選性到摺積和，再從遞迴展開出脈衝響應

第一步，離散版的篩選性。任何序列都可以寫成 x[n] = ∑k=−∞∞ x[k]δ[n − k]。這一行看起來和連續版一樣，意思卻樸素得多：δ[n] 就是一個普通數列，n = 0 時值為 1、其餘為零，沒有無限大、不需要極限。整條式子只是在說「把陣列每一格單獨挑出來再加回去」。

第二步到第四步，逐字對應連續版。系統對 δ[n] 的響應叫脈衝響應 h[n]；由時不變，系統對 δ[n − k] 的響應是 h[n − k]；由線性的齊次性，乘上權重 x[k] 之後響應是 x[k]h[n − k]；由線性的可加性，把所有 k 加起來就得到摺積和 y[n] = x[n] ∗ h[n] = ∑k=−∞∞ x[k]h[n − k]。與第 04 章唯一的差別是積分號換成求和號。因果條件 h[n] = 0（n < 0），BIBO 穩定條件 ∑n|h[n]| < ∞。

一階 IIR 的脈衝響應要用手展開一次。對 y[n] = a·y[n − 1] + x[n] 打入 x[n] = δ[n]，假設初始靜止（y[−1] = 0）。n = 0 時 y[0] = a·0 + 1 = 1；n = 1 時 y[1] = a·1 + 0 = a；n = 2 時 y[2] = a²；n = 3 時 y[3] = a³。於是 h[n] = anu[n]，每一項都不為零，這就是「無限」的字面意思。

步階響應要用幾何級數收尾。把 x[n] = u[n] 代進摺積和，n ≥ 0 時 y[n] = ∑k=0n ak。這是首項 1、公比 a、共 n + 1 項的幾何級數，套公式得 y[n] = (1 − an+1)/(1 − a)。|a| < 1 時 an+1 → 0，所以終值是 1/(1 − a)，它就是直流增益，也正好等於 ∑nh[n]。

穩定條件與時間常數。取絕對值再求和：∑n=0∞|an| = 1/(1 − |a|)，只要 |a| < 1 就收斂，系統 BIBO 穩定；|a| ≥ 1 時級數發散。這個「|a| 要小於 1」就是第 14 章「極點必須落在單位圓內」的雛形。衰減速度可借用連續時間的說法：令 an = exp(−n / nτ) 兩邊取自然對數，得等效時間常數 nτ = −1/ln a，單位是樣本而不是秒。

移動平均的步階響應是一條斜線接一條水平線。M 點移動平均的 h[n] = 1/M（0 ≤ n ≤ M − 1），其餘為零，所以 y[n] = (1/M)∑k=0M−1 x[n − k]。打入步階時，視窗裡有幾個 1 就加幾個，於是 y[n] = min(n + 1, M)/M：前 M 個樣本線性爬升，第 M 個樣本剛好到 1，之後完全停住，一步不多。它的 Σ|h[n]| 恆等於 1，所以沒有回授的系統不可能不穩定。

成本比較。M 點 FIR 每算一個輸出要 M 次乘加；一階 IIR 只要 2 次，而且不管衰減拖多長都還是 2 次。這就是 IIR 在嵌入式系統裡受歡迎的理由。

數值實例：一階 IIR，a = 0.8、步階輸入、觀測第 5 個樣本

邊界對照：n = 0 → y = 1.000000（第一個樣本就是 x[0]）；n = 1 → y = 1.800000；n = 40 → y = 4.999468（幾乎到終值）。a = 0.5 → y[5] = 1.968750、直流增益 2.000000、nτ = 1.442695（快但增益小）；a = 0.95 → y[5] = 5.298162、直流增益 20.000000、nτ = 19.495726（慢但增益大）；a = 0.99、n = 40 → y = 33.771796、直流增益 100.000000（離終值還很遠）。換成 M = 8 點移動平均、步階輸入：n = 5 → y = 0.750000；n = 7 → y = 1.000000（恰好 M 個樣本後到達終值，一步不多）；n = 20 → y = 1.000000。M = 16、n = 5 → y = 0.375000。

量級對照：這些樣本數要有感覺，得先借一下下一章的取樣頻率。以電話品質的 fs = 8000 Hz 換算，一個樣本是 125 µs，M = 8 的移動平均剛好涵蓋 1 ms，a = 0.8 的等效時間常數 4.481420 樣本約 0.56 ms。相對地，市電 50 Hz 的一個週期是 20 ms，也就是 160 個樣本——想用移動平均把它濾乾淨，成本立刻從 8 次乘加變成 160 次。

自由實驗：同一個輸入，兩種系統原型

系統可以選一階遞迴 IIR 或 M 點移動平均 FIR，輸入可以選單位步階或單位脈衝，觀測樣本 n 可以滑到 40。要看三件事：這一格的輸出值、脈衝響應的絕對值總和是不是有限、以及達到終值需要幾個樣本。

這個模式只用到「遞迴係數 a」與「觀測樣本 n」兩個滑桿，「平均點數 M」不影響結果。y[5] = 3.689280，h[5] = 0.327680，Σ|h[n]| = 5.000000，直流增益 5.000000，nτ = 4.481420 個樣本，已達終值 73.785600 %。IIR：h[n] = an 永遠不會真的到 0，只是愈來愈小。Σ|h[n]| = 1/(1 − a) = 5.000000 < ∞，所以 BIBO 穩定；每個輸出只要 2 次乘加，很便宜。IIR 用回授換效率（少量係數就能做出很窄的濾波），FIR 用長度換保證（沒有回授就不可能不穩定，而且可以做到嚴格線性相位）——第 15 章會用頻率響應把這個取捨算給你看。把 a 滑到 0 會看到遞迴整個消失、系統退化成 y[n] = x[n]；把 a 滑到 0.99 再把 n 拉到 40，會看到直流增益衝到 100.000000 而輸出才走到 33.771796，離終值還有很長一段。

不要混淆

  • x[n] 的 n 是樣本序號，不是秒。同一串樣本在 8000 Hz 與 48000 Hz 底下代表的實際時間差六倍，要換成秒必須乘上 Ts。
  • δ[n] 與 δ(t) 不是同一種東西。δ[n] 是一個值為 1 的數列項，可以直接寫進陣列；δ(t) 是面積為 1、高度無限的分布，只能活在積分裡。
  • 「IIR 因為無限所以不穩定」是錯的。無限長講的是 h[n] 的項數，發散講的是 ∑|h[n]|；只要 |a| < 1，項數無限而總和有限，系統照樣 BIBO 穩定。
  • FIR 的「有限」講的是 h[n] 的長度，不是輸出的長度。輸入若是永不結束的步階，移動平均的輸出也永遠有值，只是從第 M 個樣本起不再變化。
  • 降取樣 x[2n] 與內插 x[n/2] 不是互為反運算。前者丟掉的樣本無法從留下的樣本推回來，後者補出來的值是模型算的、不是量到的。

可觀察證據：拿什麼量、量到什麼

這一章不需要昂貴儀器，連試算表都行：一欄填滿 1 當作步階輸入，另一欄寫「本格輸入加上 0.8 乘前一格輸出」，往下拉四十列，就能一格一格印出 y[n]，再和閉合式 (1 − an+1)/(1 − a) 逐格對照；兩者若在第五格都給出 3.689280，代表遞迴實作與級數求和一致。想量真實硬體，就把差分方程燒進 DSP 開發板，用邏輯分析儀在每次輸出時翻轉一支腳位，讀出每個樣本的運算時間：FIR 的耗時隨 M 線性上升，一階 IIR 幾乎是一條平線。

能證明什麼：某個差分方程的實際輸出序列、達到終值需要幾個樣本、每個輸出花掉多少運算量與時間。

不能證明什麼：h[n]「真的」無限長。真實實作用有限字長，an 小到低於量化位階就變成 0，機器上看到的 IIR 其實是被截斷的序列。也證明不了「這個系統是 LTI」——量出一條輸出序列只說明它對這個輸入的反應，要斷定線性與時不變，仍得回到第 03 章另外做疊加測試與時移測試。

連到哪門課

幾何級數的求和公式與收斂條件見工程數學先修的級數與泰勒，本章兩條閉合式都是它的直接應用；連續版的摺積與 BIBO 條件見本課04 線性非時變與摺積，兩者可以逐行對照著讀。這兩種系統的頻率響應會在第 15 章算給你看，而「|a| < 1」為什麼等價於「極點在單位圓內」則是第 14 章的主題。真實裝置這一側，感測器讀值的去抖動、數位音量的平滑、電池電量的估計，用的幾乎都是本章這個只要兩次乘加的一階遞迴。下一章要把類比與數位兩個世界接起來，回答一個更尖銳的問題：這串樣本到底夠不夠還原原本那條連續曲線。
