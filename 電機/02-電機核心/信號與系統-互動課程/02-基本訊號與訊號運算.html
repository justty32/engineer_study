02・六個積木，加上三種會互相打架的時間軸運算

基本訊號與訊號運算：δ 的篩選性是下一章的唯一地基

這章把六個基本訊號變成可以拿來組裝任何東西的積木，並且把平移、反轉、縮放三種運算的順序陷阱一次講清楚。核心只有一件事：δ(t) 的篩選性，它是第 04 章摺積唯一站得住腳的地基。

這章假設已懂：01 訊號的分類裡的能量／功率與奇偶判斷，以及訊號就是一個函數這件事。

痛點：δ 到底是什麼，還有 x(2t − 1) 到底移了多少

兩個最常見的卡點。第一個是 δ(t)：課本說它「寬度趨近 0、高度趨近無限、面積恆為 1」，聽起來像在描述一個很誇張的脈衝，於是讀者把它想成「一個很大的數」。可是接著又說它不是函數而是分布，而且它的高度沒有意義——前後好像在打架。第二個是運算的順序：把 x(t) 變成 x(2t − 1)，到底是先壓縮再平移、還是先平移再壓縮？移的是 1 還是 0.5？兩種做法會得到不同的訊號，而大多數人只是照著代數硬推，推完也不確定對不對。

這兩件事其實是同一種毛病：把符號當成圖形去記，而不是當成定義去用。δ 的定義從頭到尾只有一句「和別的函數配對後給出什麼數」；訊號運算的定義從頭到尾只有一句「把哪個數餵給原函數」。只要每次都回到「內部引數是多少」，兩個卡點都會消失。

來源：09-信號與系統-上 §2。

白話直覺：先有量測針，再有可以組裝的積木

訊號從哪來：真實訊號千奇百怪，但工程上習慣用少數幾個標準形狀去描述它們——開關一按是步階、雷擊或敲擊是脈衝、電容放電是指數、旋轉機械是弦波。系統對它做了什麼：系統看到的永遠只是「某一時刻的輸入值」，所以我們需要一種工具，能把「某一時刻的值」單獨挑出來——那就是 δ。可以暫時把 δ 想成一支取值針，插在時間軸的某一點，把整條曲線壓成一個數；比喻到此為止，精確的說法是 δ 是一個線性泛函，它把函數 f 映射到 f(t0) 這個純量。

這件事在哪個域最好描述：這一章全部留在時間域。理由是所有換域的工具都要先有「把訊號拆成一堆延遲脈衝的加權和」這個表示法，而那個表示法就是篩選性的直接推論。換域的代價是什麼：δ 在頻率域是一條平坦到無限高頻的直線，也就是它需要無限頻寬。這件事的實務代價是——真正的 δ 不可能被產生出來，只能用「寬度遠小於系統時間常數」的窄脈衝去近似。儀器量到什麼：函數產生器打一個很窄的方波、示波器接在輸出端，量到的就是一條近似的脈衝響應；窄到什麼程度才算夠，由系統自己的時間常數決定。

六個積木分成連續與離散兩組。連續：單位步階 u(t)（t < 0 為 0、t ≥ 0 為 1）、單位脈衝 δ(t)、斜坡 r(t) = t·u(t)、指數 eat（a 是實數時只有增長或衰減，a 是複數時同時帶來振盪）、弦波 cos(ωt + φ)。離散：δ[n]、u[n]、幾何序列 an。要特別注意的是離散的 δ[n] 完全沒有無限大的問題——它就是一個 n = 0 時值為 1、其餘為 0 的普通數列。連續的 δ(t) 才是分布。

推導：從 δ 的定義推到篩選性，再推到運算的標準形

（a）為什麼 δ 只能用積分後的效果定義。假設有一個普通函數 g，它在 t = 0 以外都等於 0，只在 t = 0 有值（哪怕是很大的值）。單點是零測度集，所以 ∫g(t)dt = 0，不管那個值多大都一樣。但我們要的 δ 必須滿足 ∫−∞∞ δ(t) dt = 1。矛盾說明：沒有任何普通函數能當 δ。出路是不去問 δ 在每一點等於多少，改成只規定它「與別的函數配對後給出什麼數」。這種物件叫做分布（distribution），δ 的「高度」從此不是一個可以談的量，只有面積是。

（b）篩選性怎麼來。看 ∫−∞∞ f(t)δ(t − t0) dt。δ(t − t0) 只在 t = t0 的無限小鄰域內非零，在那個鄰域裡 f 是連續的，所以可以視為常數 f(t0) 提到積分外面，剩下的 ∫δ(t − t0)dt = 1。於是 ∫ f(t)δ(t − t0) dt = f(t0)，這就是篩選性（sifting property）。假設條件是 f 在 t0 處連續。順帶一提，δ 與 u 是一對微積分關係：δ(t) = du/dt、u(t) = ∫−∞t δ(τ)dτ，而 r(t) = ∫−∞t u(τ)dτ，三個積木其實是同一條鏈上的三格。

（c）複合運算的順序陷阱。y(t) = x(2(t − 1)) 與 y(t) = x(2t − 1) 不是同一個訊號：前者在 t = 1 時內部引數為 0，後者在 t = 0.5 時內部引數才為 0。本課的統一作法是先把式子整理成標準形 x(a(t − t0))，整理完的 t0 才是真正的平移量。把 2t − 1 提出 2 得 2(t − 0.5)，所以 x(2t − 1) = x(2(t − 0.5))——平移的是 0.5 不是 1。記法很簡單：課本寫 x(at − b) 時，真正的平移量是 b/a。

（d）離散的縮放為什麼要小心。連續時間的 x(at) 只是把時間軸拉伸或壓縮，資訊原則上還在。離散時間就不一樣：x[2n] 是把偶數項留下、奇數項丟掉，這叫降取樣，被丟的樣本真的沒了；而 x[n/2] 只在 n 是偶數時有定義，奇數位置是空的，必須靠內插補出來，補出來的值是猜的、不是量到的。這一組不對稱正是第 15 章多速率處理的起點。

數值實例：x(t) = e−t·u(t) 做 y(t) = A·x(a(t − t0))

取 A = 1、a = 1、t0 = 1 s、觀測時刻 t = 2 s。這組數字是本章互動元件的預設值。

邊界對照。a = −1、t0 = 1、t = 0 → arg = 1.000000、y = 0.367879（時間反轉後，t = 0 看到的是原本 t = 1 的值）。a = 2 → arg = 2.000000、y = 0.135335（壓縮成兩倍快，同樣的 1 秒走完原本 2 秒的路）。a = 0.5 → arg = 0.500000、y = 0.606531。t = 0.5（arg = −0.500000）→ y = 0.000000（u(t) 在負引數處是 0）。A = 2 → y = 0.735759。換成斜坡且 arg = 1 → y = 1.000000；換成弦波 cos(2π·arg) 且 arg = 1 → y = 1.000000，arg = 0.25 → y = 0.000000。

量級對照：要用窄脈衝去近似 δ，寬度必須遠小於系統的時間常數。上面這個系統的時間常數是 1 s，那麼 1 ms 的脈衝就綽綽有餘（差 1000 倍）；但如果系統是電話語音鏈路，取樣週期只有 125.000000 µs，同樣一個 1 ms 的脈衝反而已經算「寬」了。窄不窄從來不是絕對值，是比值。

自由實驗：把縮放、反轉、平移拆開來看引數

場景是拿一個基底訊號 x，做標準形變換 y(t) = x(a(t − t0))，再在某個觀測時刻 t 讀值。三個滑桿分別控制縮放係數、平移量與觀測時刻；四種基底都會用到全部三個滑桿，沒有哪個模式會讓滑桿失效。重點是盯著內部引數 arg，因為輸出值完全由它決定。

這個模式三個滑桿都會用到：縮放、平移與觀測時刻共同決定內部引數。內部引數 arg = 1.000000；輸出 y(t) = 0.367879；篩選性 ∫x(τ)δ(τ − t0)dτ = x(t0) = 0.367879。目前的變換是：先把時間軸壓縮 1 倍，再延後 1.0 秒。δ 不是一個很高很窄的脈衝而已——它的用途是把一條曲線在某一點的值挑出來，第 04 章的摺積就是靠這件事把任意輸入拆成無限多個延遲脈衝。本實驗算的是 x(a(t − t0))；如果你在課本看到 x(at − b)，真正的平移量是 b/a 不是 b。把 a 調成 0 會走退化路徑，把觀測時刻調到讓 arg 變負時，因果訊號的輸出會是 0，那不是壞掉，是 u( ) 的定義。

不要混淆

  • δ(t) 不是「一個很大的數」。它的高度沒有意義，只有面積有意義：2δ(t) 是面積為 2 的脈衝，不是高度為 2 的脈衝。看到 δ 就想像一根箭頭，箭頭旁邊標的永遠是面積。
  • δ[n] 與 δ(t) 是兩種不同的東西。離散的 δ[n] 就是一個值為 1 的數列項，是不折不扣的普通函數，完全沒有無限大的問題；只有連續的 δ(t) 才需要分布理論。
  • x(t − 2) 是往右移、也就是延後，不是往左。初學者最常記反。驗算法：原本在 t = 0 發生的事，現在要 t = 2 才讓內部引數等於 0。
  • x(2t) 是變快不是變慢。因為要讓內部引數達到同一個值，只需要一半的時間，整個訊號被擠進一半的時間長度裡。
  • 連續的縮放與離散的縮放不對稱。x(at) 原則上可逆，x[2n] 卻真的丟掉了樣本；把離散縮放當成「拉一下時間軸」會直接踩到第 12 章的混疊。

可觀察證據：拿什麼量、量到什麼

函數產生器可以輸出很窄的方波脈衝來近似 δ：只要脈衝寬度遠小於系統的時間常數，系統的響應就近似脈衝響應。實務上會拿兩個不同寬度的脈衝各打一次，如果輸出波形形狀不變、只有幅度按面積等比例縮放，就代表已經進入「夠窄」的區間。時間平移這件事在儀器上也是直接可見的：示波器的觸發延遲設定就是在把顯示的時間軸做平移，兩通道之間的延遲游標讀的就是 t0。

能證明什麼：系統對一個具體窄脈衝的實際響應曲線、兩個訊號之間的時間差（可到次奈秒等級）、以及脈衝變窄時響應是否收斂到固定形狀。

不能證明什麼：量不到真正的 δ(t)——它不存在於物理世界，寬度為 0 的訊號需要無限頻寬與無限峰值功率，任何產生器都做不到。也證明不了「篩選性」本身：那是定義，不是實驗結論，實驗只能顯示「近似得夠好時，結果與定義推出的預測一致」。同樣地，儀器量不到「時間縮放」這個運算，只能量到縮放後那個新訊號的樣子。

連到哪門課

δ 作為極限與微分的觀點（為什麼它是 u(t) 的導數、為什麼要用分布才嚴謹）見工程數學先修的極限與導數；篩選性那一步的積分技巧與「積分＝面積」的直覺見積分。

真實裝置那一側，雷達與超音波量測就是打一個近似脈衝再看回波、房間的殘響量測用的是脈衝或掃頻訊號、數位音訊的取樣可以看成一連串加權的 δ。下一章把焦點從訊號換到系統，用六個性質逐條檢測一個系統，並在違反時算出殘差；那六條裡的線性與非時變，正是第 04 章能用一條 h(t) 描述整個系統的前提。
