第一組｜訊號與系統的基本語彙（第 00–03 章）

訊號（signal）

白話：訊號就是「一個量隨著時間（或空間）怎麼變」的紀錄。數學上它是一個函數：給它一個時刻，它回你一個數。麥克風把聲壓變成電壓、感測器把溫度變成電壓、天線把電磁場變成電壓，拿到手上的都是同一種東西。

位置／角色：本課第 00 章開宗明義的第一個對象，之後每一章都在處理它。寫成程式，它就是一個陣列，或一個吃時間、回傳浮點數的函式。

機制：連續時間寫 x(t)（t 是實數，單位 s），離散時間寫 x[n]（n 是整數，沒有單位，只代表第幾個樣本）。本課全程用這個括號差別區分兩個世界。訊號本身不做任何事，是系統對它做事。

不要混淆：訊號不等於「波形圖」。圖只是它的一種呈現方式；同一個訊號在頻率域有另一套完整描述，兩邊資訊等量。也不要把「訊號」與「資訊」畫上等號：帶資訊的是訊號的變化，一條固定不動的直流電壓是合法訊號，卻幾乎不帶資訊。

系統（system）

白話：系統是把一個訊號變成另一個訊號的機器，寫成算子 T：y(t) = T{x(t)}。放大器、電纜、房間、一段程式都算系統。

位置／角色：第 00 章與第 03 章。真實對應物：喇叭分頻網路、感測器前端、馬達控制迴路、接收機的中頻級。

機制：判斷「要不要用這門課」只有一條線：系統有沒有記憶。無記憶時 y 的每一點只由 x 的同一點決定，一個乘法就講完了；有記憶時 y 的某一點由 x 的一整段過去共同決定，時間域上變成一個難算的積分，這才需要換域。

不要混淆：系統不是「電路」。電路只是系統的一種實現，一段做移動平均的程式同樣是系統。也不要把「系統」與「轉移函數」當成同義詞：只有線性非時變、初始靜止的系統才寫得出單一個轉移函數。

連續時間與離散時間（continuous-time & discrete-time）

白話：時間軸是連綿不斷的，還是一格一格的。

位置／角色：第 01 章的第一組分類；第 11 章起是整個離散世界；第 12 章是兩者之間的橋。

機制：連續時間訊號寫 x(t)，t 可以是任意實數；離散時間訊號寫 x[n]，n 只能是整數，兩個樣本之間沒有定義任何值。取樣週期 Ts（讀作「T sub s」，單位 s）把兩者接起來：x[n] = x(nTs)。本課參考取樣率 fs = 8000 Hz（電話品質），對應 Ts = 1.250000 × 10−4 s。

不要混淆：離散不等於數位。離散只說時間軸被切開了，樣本值仍可以是無限精度的實數；數位是連「值」也被切成有限層級。這兩件事由 ADC 的兩個步驟分別負責，可以只做其中一件。

類比與數位（analog & digital）

白話：訊號的「值」是連綿的，還是被切成有限階的。

位置／角色：第 01 章；真實裝置是 ADC 與 DAC，它們的電路實現留給電子學與混合訊號設計。

機制：類比訊號的值域是連續區間；數位訊號的值域是有限集合，量化把每個樣本對到最近的一階，差額就是量化雜訊。ADC 做的是「取樣＋量化」兩件事：取樣切時間軸（第 12 章），量化切值軸。

不要混淆：CD 的 44.1 kHz 說的是取樣率，講的是時間軸；決定它是不是數位的是 16 位元的量化，講的是值軸。也不要以為量化誤差可以靠提高取樣率補回來——過取樣配合雜訊整形能改善等效位元數，但那是另一套機制，不是「取樣快就比較準」。

週期訊號（periodic signal）

白話：把訊號沿時間軸平移一個固定量之後，跟原來一模一樣。

位置／角色：第 01 章的分類，也是第 05 章傅立葉級數成立的前提。量級對照：市電 50 Hz 是最常見的週期訊號。

機制：連續時間的條件是存在 T > 0 使 x(t + T) = x(t) 對所有 t 成立，最小的那個 T 叫基本週期，對應基頻 ω0 = 2π/T（ω0 讀作「omega zero」，單位 rad/s）。離散時間要求 x[n + N] = x[n]，而 N 必須是整數。

不要混淆：週期訊號必然是功率訊號而不是能量訊號，因為總能量發散。另外離散弦波 cos(ωn) 只有在 ω/(2π) 是有理數時才是週期的，連續世界沒有這個限制——同一個弦波取樣之後可能就不週期了。

能量訊號與功率訊號（energy & power signal）

白話：問的是這個訊號一輩子累積的總能量是有限的，還是每秒平均功率有限、但總量無窮。

位置／角色：第 01 章最核心的判斷，決定後面該用傅立葉轉換（能量型）還是傅立葉級數（功率型）。

機制：E = ∫−∞∞ |x(t)|² dt；P = lim (1/T)∫−T/2T/2 |x(t)|² dt。E 有限且非零叫能量訊號，此時 P = 0；P 有限且非零叫功率訊號，此時 E 發散。錨定實例：A = 2、τ = 0.5 s 的衰減指數 x(t) = 2·exp(−t/τ)·u(t)，E = 1.000000（V²·s）、P = 0，是能量訊號；振幅 A = 1 的弦波 P = 0.500000、rms = 0.707107，是功率訊號。

不要混淆：這裡的「能量」是數學定義的 ∫|x|² dt，不是焦耳；要換成焦耳得先講清楚 x 是電壓還是電流、負載電阻多大。還有第三種可能：兩個都發散（例如 t·u(t)），那它兩類都不是，不要硬歸類。

奇函數與偶函數（odd & even function）

白話：偶函數對原點左右對稱（x(−t) = x(t)），奇函數是反對稱（x(−t) = −x(t)）。

位置／角色：第 01 章的第五組分類；第 05 章用它預先判斷傅立葉係數只剩餘弦項或只剩正弦項，省一半計算。

機制：任何訊號都能唯一拆成偶部 xe(t) = [x(t) + x(−t)]/2 與奇部 xo(t) = [x(t) − x(−t)]/2。偶訊號的傅立葉係數是實數，奇訊號的是純虛數。方波是奇對稱的，所以它只有正弦項，錨定值 |b1| = 1.273240 而沒有對應的餘弦分量。

不要混淆：對稱性是相對於「原點」講的。把同一個訊號往右平移一點，對稱性就沒了，係數也不再是純實或純虛。看到係數變成複數不代表算錯，可能只是時間原點沒選在對稱中心上。

單位脈衝（unit impulse, δ）

白話：一根寬度趨近 0、高度趨近無限、面積剛好等於 1 的「針」。它是拿來敲系統、量系統的標準槌子。

位置／角色：第 02 章定義，第 04 章用它定義脈衝響應 h(t)。真實世界的近似物是很短的電壓脈衝，或一聲拍手。

機制：δ 讀作「delta」。連續時間的 δ(t) 不是普通函數而是廣義函數，它只由兩條性質定義：∫−∞∞ δ(t) dt = 1 與篩選性。離散時間的 δ[n] 則是老老實實的序列：n = 0 時為 1、其餘為 0，沒有任何病態。任何離散訊號都能寫成 x[n] = ∑k=−∞∞ x[k]δ[n − k]。

不要混淆：δ(t) 的「高度」沒有意義，有意義的只有面積（強度）。也不要把 δ(t) 與 δ[n] 當成同一個東西：前者的單位是 1/s（因為積分才等於 1），後者沒有單位，它就是一個值為 1 的樣本。

篩選性（sifting property）

白話：把 δ 放進積分裡，它會從整條函數裡「挑」出一個時刻的值，其餘全部歸零。

位置／角色：第 02 章；第 04 章的摺積能成立、第 12 章的理想取樣能寫成乘上一串脈衝，靠的都是這一條。

機制：∫−∞∞ f(t)δ(t − t0) dt = f(t0)。因為 δ 只在 t = t0 那一點非零、而且面積為 1，積分就把 f 在該點的值原封不動取出來。錨定實例：x(t) = exp(−t)·u(t)、t0 = 1，∫x(τ)δ(τ − 1) dτ = 0.367879（τ 讀作「tau」，是積分變數）。

不要混淆：篩選性是「取值」，不是「相乘」。x(t)δ(t − t0) 本身仍然是一個脈衝，只是強度變成 f(t0)；一定要加上積分，它才會塌成一個數。

單位步階（unit step, u）

白話：t < 0 為 0、t ≥ 0 為 1 的開關函數，代表「在某個時刻把電源打開」。

位置／角色：第 02 章；第 08 章的暫態指標（超越量、峰值時間、整定時間）全都是對步階輸入定義的。

機制：u(t) 與 δ(t) 是微積分關係：du/dt = δ(t)，而 ∫−∞t δ(τ) dτ = u(t)。再積一次得到斜坡 r(t) = t·u(t)。u(t) 最常見的用途是把式子的有效範圍寫進式子本身，例如 exp(−t/τ)·u(t) 就表示「t < 0 沒有訊號」。

不要混淆：步階響應不是脈衝響應，兩者差一次微分：h(t) 等於步階響應對時間的導數。實驗上量步階遠比量脈衝容易（脈衝很難做得又短又強），所以常見的做法是先量步階再微分，而不是硬做一根針。

線性（linearity）

白話：兩個輸入分別送進去、結果加起來，等於先把兩個輸入加起來再送進去。

位置／角色：第 03 章六個性質之一，也是第 04 章之後一切工具的前提。電路學把疊加當成解題技巧，本課把它當成系統的定義性質。

機制：條件是 T{a·x1 + b·x2} = a·T{x1} + b·T{x2}，這一條同時涵蓋齊次性與可加性。錨定實例：y = x²、a = 2、b = 3、x1 = x2 = 1，左式 25、右式 5、殘差 20，違反；y = x + 3 時左式 8、右式 20、殘差 −12，同樣違反。

不要混淆：線性專指疊加，不是「圖形是直線」。y = x + 3 畫出來是直線但不線性，它叫仿射（affine）。另外線性與時不變是兩個彼此獨立的性質，兩個都成立才叫 LTI，只有一個成立不能用摺積。

時不變（time invariance）

白話：今天做實驗和明天做實驗結果一樣，只是輸出跟著整體平移。

位置／角色：第 03 章；第 04 章要能寫出摺積，必須同時具備線性與時不變。

機制：條件是若 x(t) → y(t)，則對任意 t0 都有 x(t − t0) → y(t − t0)。檢驗做法是算兩條路：「先延遲再送進系統」與「先送進系統再延遲」，兩者必須完全相同。係數會隨時間改變的系統（例如增益被自動增益控制持續調整）就不是時不變。

不要混淆：時不變不是「輸出不隨時間變」——輸出當然會變。它講的是系統的規則不隨時間變。取樣、調變、抽取這些運算都不是時不變的，這正是它們不能用單一個 h 描述的原因。

第二組｜LTI 與時間域（第 04 章）＋週期頻譜（第 05 章）

線性非時變系統（linear time-invariant system, LTI）

白話：同時滿足疊加與時間平移不變的系統。它是本課唯一能被一個 h 完全描述的對象。

位置／角色：第 04 章的主角；之後所有轉換、頻率響應與濾波器設計都預設它成立。

機制：LTI 是 linear time-invariant（線性非時變）的縮寫。因為線性，輸入可以拆成一堆脈衝的加權和；因為時不變，每個脈衝的響應都是同一個 h，只是位置不同。兩者合起來，輸出必定是 y(t) = x(t) ∗ h(t)。弦波是 LTI 的本徵函數：送進 cos(2πft)，出來一定是同頻率的 cos(2πft + φ)，頻率不會被改變。

不要混淆：LTI 不是「大部分系統」。放大器一飽和就不線性，混波器與取樣器不時不變。工程上說的「小訊號線性化」是在工作點附近把系統近似成 LTI，一離開工作點這套工具就全部失效。

脈衝響應（impulse response, h）

白話：拿 δ 敲系統一下，量到的那個輸出。房間的脈衝響應就是你拍一次手、錄下來的整段迴音。

位置／角色：第 04 章的核心。電路學的 RC 充放電曲線，從本課角度看就是一個 h(t)。

機制：h(t) = T{δ(t)}。它之所以值錢，是因為有了它，任何輸入的輸出都能用摺積算出來：y(t) = x(t) ∗ h(t)。因果性、穩定性、頻率響應也全部可以從 h 讀出來——H(jω) 就是 h(t) 的傅立葉轉換。

不要混淆：h(t) 不是「系統的輸出」，它是系統對 δ(t) 這個特定輸入的輸出；它之所以特別，是因為有了它就能用摺積算出所有其他輸入的輸出。也不要把 h(t) 與步階響應搞混，兩者差一次微分。

摺積（convolution）

白話：把 h 反過來、滑過 x，每滑到一格就算一次加權和——這就是有記憶的系統在時間域算輸出的方式。比喻到此為止，精確定義看下一段。

位置／角色：第 04 章；寫成程式就是兩層迴圈的乘加，DSP 晶片的乘加指令就是為它而生的。

機制：y(t) = x(t) ∗ h(t) = ∫−∞∞ x(τ)h(t − τ) dτ。符號 ∗ 讀作「摺積」（asterisk operator），不是乘號；τ 讀作「tau」，是積分變數。h(t − τ) 裡的負號同時做了「反轉」與「平移」兩件事。性質上交換律、結合律、分配律都成立，而且面積相乘：輸出的面積等於兩者面積的乘積。錨定實例：A = 1、T1 = 1 s 的矩形脈衝通過 τ = 0.5 s 的一階系統，y(1) = 0.432332（峰值）、y(2) = 0.058510，三個面積分別是 1.000000／0.500000／0.500000。

不要混淆：摺積不是相乘。x(t)h(t) 是逐點相乘（對應頻域的摺積），x(t) ∗ h(t) 是滑動加權積分（對應頻域的相乘）。本課一律寫「摺積」；電機/中英名詞對照表-2.md 寫的是「卷積」，兩者是同一個 convolution 的兩種譯法，不是打錯字。

摺積和（convolution sum）

白話：摺積的離散版本，把積分換成求和。

位置／角色：第 11 章；第 15 章的 FIR 濾波器每一拍跑的就是這條式子。

機制：y[n] = x[n] ∗ h[n] = ∑k=−∞∞ x[k]h[n − k]，k 是求和用的樣本序號。長度 Lx 的訊號摺上長度 Lh 的脈衝響應，輸出長度是 Lx + Lh − 1。M 點移動平均等價於 h[n] 是 M 個值為 1/M 的矩形序列。

不要混淆：摺積和不是「相關」。相關不把其中一個序列反轉，用途是找相似度；摺積要反轉，用途是算系統輸出。對稱的 h[n]（線性相位 FIR）反不反轉結果一樣，這常讓人誤以為兩者是同一件事。

因果性（causality）

白話：輸出只能取決於現在與過去，不能偷看未來。

位置／角色：第 03 章與第 04 章；即時處理的系統一定要因果，離線處理（整個檔案已經在硬碟上）就不必。

機制：對 LTI 系統，因果 ⇔ h(t) = 0（t < 0）、h[n] = 0（n < 0）。這讓摺積的積分下限從 −∞ 收成 0，也是單邊拉氏轉換寫成 ∫0∞ 的理由。

不要混淆：因果不等於穩定，兩者互相獨立：h(t) = etu(t) 是因果的卻不穩定。另外非因果不代表無法實作——只要允許整體延遲，把 h 往右移就能變成因果，代價是輸出晚一點出來，線性相位 FIR 就是這樣做的。

BIBO 穩定（bounded-input bounded-output stability）

白話：只要輸入不爆，輸出就不會爆。

位置／角色：第 03 章與第 04 章的判準；第 07、08 章看極點、第 14 章看單位圓，講的都是同一件事的不同座標。

機制：BIBO 是 bounded-input bounded-output（有界輸入有界輸出）。充要條件是脈衝響應絕對可積或絕對可加：∫−∞∞ |h(t)| dt < ∞、∑n=−∞∞ |h[n]| < ∞。錨定實例：一階 IIR a = 0.8 時 ∑|h[n]| = 5.000000（同時也是直流增益），有限，所以穩定。

不要混淆：穩定看的是 h 的絕對積分，不是「輸出會不會振盪」。一個持續振但振幅不長大的系統（極點落在虛軸上）是臨界情形，不算 BIBO 穩定。也不要把「模擬跑一段沒發散」當成證據，可能只是還沒跑夠久。

系統互聯（series, parallel & feedback interconnection）

白話：把好幾個小系統接起來之後，整體的 h 長什麼樣。

位置／角色：第 04 章；喇叭分頻網路是並聯、多級放大器是串聯、控制迴路是回授。

機制：串聯 heq = h1 ∗ h2（頻域就是 H1·H2 相乘）；並聯 heq = h1 + h2；負回授的閉迴路轉移函數是 H/(1 + HG)。串聯可以交換順序，因為摺積有交換律，但前提是每一級都真的是 LTI。

不要混淆：串聯的等效不是 h1·h2。時間域相乘對應的是頻域摺積，那是調變在做的事。實務上兩級電路直接接起來也常常不等於兩個轉移函數相乘，因為後級的輸入阻抗改變了前級的工作條件——「可交換」只在理想 LTI 假設下成立。

傅立葉級數（Fourier series）

白話：任何週期訊號都能寫成基頻與其整數倍頻率的弦波疊加起來。

位置／角色：第 05 章；電力品質的諧波分析、樂器音色分析用的都是它。

機制：x(t) = ∑k=−∞∞ ak·exp(j k ω0 t)，係數 ak = (1/T)∫T x(t)·exp(−j k ω0 t) dt，其中 ω0 = 2π/T。這條係數式其實是「投影」：把 x 投影到第 k 根複指數軸上。錨定實例：振幅 A = 1 的方波，|b1| = 1.273240、|b3| = 0.424413、|b5| = 0.254648。

不要混淆：傅立葉級數只對週期訊號成立；非週期訊號要用傅立葉轉換。兩者的關係是 T → ∞ 時離散的譜線靠攏成連續的頻譜，級數給的是「一根一根的譜線」，轉換給的是「密度」，單位並不相同，不能直接比大小。

基頻與諧波（fundamental & harmonics）

白話：基頻是週期訊號裡最低的那個頻率，諧波是它的整數倍。

位置／角色：第 05 章；電力品質的總諧波失真、樂器音色判斷都用這一組詞。市電 50 Hz 的第 3 次諧波就在 150 Hz。

機制：基本週期 T 對應基頻 f0 = 1/T（Hz）與 ω0 = 2π/T（rad/s）。第 n 次諧波的頻率是 n·f0，本課諧波序號一律寫 n。方波只有奇次諧波，振幅按 1/n 遞減：|b3|/|b1| = 0.424413/1.273240，正好是 1/3。

不要混淆：「基頻」不是「最大的那一根」。有些訊號的基頻分量很小甚至為零，耳朵照樣聽得出音高。也不要把諧波與邊帶混為一談：諧波是波形本身或非線性造成的整數倍頻率，邊帶是調變把頻譜搬移之後產生的和頻與差頻。

帕塞瓦定理（Parseval's theorem）

白話：訊號的能量（或功率）在時間域算和在頻率域算，是同一個數。

位置／角色：第 05 章與第 06 章；要回答「前幾次諧波抓到多少能量」就靠它。

機制：週期版 P = ∑k |ak|²；能量版 E = ∫|x(t)|² dt = (1/2π)∫|X(jω)|² dω。它保證換域不會憑空生出或吃掉能量。錨定實例：方波取到 N = 5 次諧波，累積功率 0.933056，佔總功率 93.305552 %；只取基頻是 81.056947 %。

不要混淆：帕塞瓦講的是能量守恆，不是「波形一樣」。取前 5 次諧波已經抓到 93.305552 % 的功率，波形卻仍有明顯過衝（吉布斯現象）——能量對了不代表形狀對了，這兩件事要分開評估。

正交基底（orthogonal basis）

白話：一組互不干擾的「方向」。任何訊號都能沿這些方向分解，而且每個方向的分量可以各自算，互不影響。

位置／角色：第 05 章；它把傅立葉級數從「魔術」變成線性代數。

機制：兩個訊號正交的意思是內積為 0。對複指數而言，∫T exp(j k ω0 t)·exp(−j m ω0 t) dt 在 k ≠ m 時為 0、在 k = m 時為 T。正因為正交，係數 ak 才能用一條積分單獨算出來，不必解一大堆聯立方程。

不要混淆：正交不是「無關」，也不是統計上的「獨立」。正交是內積為 0 的幾何性質，獨立是機率性質，兩者不能互推。另外弦波不是唯一的正交基底（小波、DCT 也是），選弦波的理由是它剛好是 LTI 系統的本徵函數。

吉布斯現象（Gibbs phenomenon）

白話：用有限多項傅立葉級數去逼近有跳躍的波形時，跳躍處旁邊一定會冒出一個約 9 % 的過衝，項數加再多也不會消失。

位置／角色：第 05 章；第 15 章用窗口法設計 FIR 時的旁瓣、影像壓縮邊緣的振鈴，都是同一回事。

機制：過衝高度趨近跳躍量的 8.949 %，不隨項數 N 減小；增加 N 只讓過衝變窄、往跳躍點擠過去。原因是截斷級數等於在頻域乘上一個矩形窗，時域對應摺上一個 Dirichlet 核（週期化的 sinc），而 sinc 的旁瓣衰減得不夠快。

不要混淆：吉布斯過衝不是計算誤差，也不是取樣造成的，它是「用有限頻寬表示無限陡的邊緣」的必然結果。加窗可以壓下它，代價是過渡帶變寬——這是同一個取捨在第 05 章與第 13 章的兩次現身。

第三組｜連續頻域與 s 平面（第 06–08 章）

傅立葉轉換（Fourier transform）

白話：把非週期訊號攤開成連續的頻率成分，看它由哪些頻率、各佔多少組成。

位置／角色：第 06 章；頻譜分析儀螢幕上顯示的東西，就是它的量值。

機制：X(jω) = ∫−∞∞ x(t)e−jωt dt，反轉換 x(t) = (1/2π)∫ X(jω)ejωt dω。ω 讀作「omega」，是角頻率，單位 rad/s，與 Hz 的換算是 ω = 2πf。虛數單位在數學課寫 i，電機一律寫 j，因為 i 留給電流。錨定實例：A = 1、寬 T = 1 ms 的矩形脈衝，X(0) = 1.000000 × 10−3、|X(500)| = 6.366198 × 10−4、第一零點在 1000.000000 Hz。

不要混淆：X(jω) 一般是複數，有大小也有相位。頻譜分析儀只給大小、量不到相位，這代表「頻譜看起來一樣」不等於「訊號一樣」——時移只改相位、完全不改大小。

頻譜（spectrum）

白話：訊號裡各個頻率各有多少、相位各是多少。

位置／角色：第 06 章定義，第 10 章講怎麼搬移它，第 13 章講怎麼用 DFT 估它。

機制：週期訊號的頻譜是一根根離散的譜線（傅立葉級數的 ak），非週期能量訊號的頻譜是連續的密度函數 X(jω)。振幅譜 |X(jω)| 與相位譜 ∠X(jω)（∠ 讀作「相角」，單位 rad 或 °）合起來才是完整資訊。

不要混淆：頻譜圖上的一根線可能是真的訊號，可能是譜洩漏的裙擺，也可能是混疊搬進來的假頻。分辨的方法是換一個取樣率再看一次：真訊號的位置不動，混疊產生的假頻會跟著移動。

頻寬（bandwidth）

白話：訊號或系統「有效佔用」的頻率範圍有多寬。

位置／角色：第 06 章、第 09 章與第 10 章。量級對照：AM 廣播一個頻道 10 kHz、電話語音用 8000 Hz 取樣。

機制：最常用的定義是 −3 dB 頻寬：增益掉到 0.707107（功率剩一半，−3.010300 dB）的那個頻率。另一種是第一零點頻寬。錨定實例：寬 1 ms 的矩形脈衝，第一零點在 1000.000000 Hz、3 dB 頻寬 442.946000 Hz。

不要混淆：頻寬的定義不只一種（−3 dB、第一零點、佔用頻寬、雜訊等效頻寬），比較兩個數字之前要先確認是同一種定義。另外「頻寬大」不等於「訊號強」，它只描述頻率佔得寬。

摺積定理（convolution theorem）

白話：時間域裡難算的摺積，換到頻率域就變成單純的相乘。

位置／角色：第 06 章；這是整門課「為什麼要換域」的最終答案。

機制：x ∗ h ⇔ X·H；反過來 x·g ⇔ (1/2π)X ∗ G。也就是說一個域的摺積等於另一個域的相乘，兩邊是對偶的。第 10 章的調變（時間域乘上 cos）之所以在頻域造成搬移，正是這條定理。

不要混淆：這個定理不是「摺積等於相乘」，而是「一個域的摺積等於另一個域的相乘」。漏掉指明是哪個域，就會推出「調變是摺積」這種錯誤結論。另外 DFT 的逐點相乘對應的是循環摺積、不是線性摺積，長度不夠時要先補零。

sinc 函式（sinc function）

白話：矩形脈衝的頻譜長相：中間一個主瓣，兩邊一串愈來愈小的旁瓣。

位置／角色：第 06 章；第 12 章的理想還原公式也是它。

機制：本課一律用歸一化版 sinc(x) = sin(πx)/(πx)，sinc(0) = 1。有些教科書用 sin(x)/x，本課全程不用那一版。寬 T 的矩形脈衝，其轉換為 A·T·sinc(fT)，第一零點在 f = 1/T。理想低通的脈衝響應也是 sinc，這正是理想濾波器非因果的根源。

不要混淆：sinc 的旁瓣衰減得很慢（大約與 1/f 同階），所以矩形窗「在時域好切、在頻域很糟」。看到旁瓣不要當成雜訊或算錯，它是矩形邊緣的必然產物。

拉氏轉換（Laplace transform）

白話：傅立葉轉換的擴充版，多給一個「衰減」的自由度，讓會發散的訊號也算得動。

位置／角色：第 07 章；電路學的 Z(jω) 是單一元件的比值，本課的 H(s) 是整個系統的比值。

機制：拉氏（Laplace，全名拉普拉斯）單邊轉換 H(s) = ∫0∞ h(t)e−st dt，其中 s = σ + jω（σ 讀作「sigma」，是實部，單位 1/s，代表指數衰減率）。把 s 限制在虛軸 s = jω 就退回傅立葉轉換，所以頻率響應是 H(s) 在虛軸上的一道切片。

不要混淆：拉氏轉換不是「換個字母的傅立葉」。σ ≠ 0 的那一整塊帶來收斂域的問題，而且單邊版本天生把 t < 0 丟掉、把初始條件吃進來——這正是它適合解常微分方程，而傅立葉不適合的原因。

收斂域（region of convergence, ROC）

白話：那個積分（或級數）究竟在 s 平面／z 平面的哪一塊才收斂。

位置／角色：第 07 章與第 14 章。

機制：ROC 是 region of convergence（收斂域）。對右側訊號（因果），ROC 是某條垂直線的右邊（s 平面）或某個半徑的外面（z 平面）；左側訊號則相反。系統穩定 ⇔ ROC 包含虛軸（連續）或包含單位圓（離散）。

不要混淆：ROC 不是附註。同一個 X(s) 或 X(z) 配不同的 ROC，對應到完全不同的時間訊號（一個右側、一個左側），穩定性判斷也相反。只寫代數式而不寫 ROC，等於題目沒寫完。

轉移函數（transfer function）

白話：輸出與輸入在 s 域（或 z 域）的比值，一個式子就裝下整個系統。

位置／角色：第 07 章定義，第 08、09、14、15 章一路使用。

機制：H(s) = Y(s) / X(s)，它同時也等於 h(t) 的拉氏轉換。寫成有理式時，分母的根是極點、分子的根是零點。離散版是 H(z) = Y(z) / X(z)。把 s = jω 代進去就得到頻率響應 H(jω)。

不要混淆：轉移函數只對線性非時變且初始靜止的系統有意義。初始條件不為零時，Y(s) 還多一項與 X 無關的自然響應，比值就不再是 H(s)。本課一律寫「轉移函數」這個譯名，全課不換詞。

極點（pole）

白話：讓轉移函數變成無限大的那些 s（或 z）。它們決定系統自己會怎麼振、怎麼衰減。

位置／角色：第 07 章與第 08 章（s 平面），第 14 章（z 平面）。

機制：極點是分母的根。連續系統的極點 s = σ + jω 中，σ 決定衰減速度（時間常數 τ = 1/|σ|），ω 決定振盪角頻率；穩定要求所有極點的 σ < 0。錨定實例：極點 s = −2 ± j10、K = 1，τ = 0.500000 s、5τ = 2.500000 s、振盪 1.591549 Hz、h(0.5) = 0.104353、包絡 0.367879。

不要混淆：極點是分母的根，不是「系統的頻率」。它的實部管衰減多快、虛部管振多快；離散系統要看的是半徑與角度——r = 0.9、θ = 45°、fs = 8000 Hz 時共振落在 1000.000000 Hz，半徑愈接近 1 衰減愈慢。

零點（zero）

白話：讓轉移函數變成 0 的那些 s（或 z）。它們決定哪些頻率會被吃掉。

位置／角色：第 08 章；第 15 章的移動平均濾波器就靠零點做出凹口。

機制：零點是分子的根。零點落在虛軸上（或單位圓上）時，該頻率的增益正好為 0，形成凹口。錨定實例：M = 8 的移動平均在 fs = 8000 Hz 下第一零點在 1000.000000 Hz，那個頻率被完全濾掉。零點也會改變相位斜率，因此連帶影響群延遲。

不要混淆：零點不決定穩定性，穩定只看極點。但零點跑到右半平面（或單位圓外）會造成非最小相位：相位落後遠大於大小所暗示的量，控制迴路裡特別麻煩——這是「零點無害」這個直覺失效的地方。

頻率響應（frequency response）

白話：對每一個頻率，系統把振幅乘多少、把相位推多少。

位置／角色：第 00 章就出場，是整門課的主角；網路分析儀量的就是它。

機制：把 s = jω 代入 H(s) 就得到 H(jω)，它同時也等於 h(t) 的傅立葉轉換。一階系統 H(jf) = (1) / (1 + j f/fc)，|H| = 1/√(1 + r²)、∠H = −arctan(r)，其中 r = f/fc。錨定實例：f = fc = 1000 Hz 時 |H| = 0.707107（−3.010300 dB）、相位 −45.000000°、相位延遲 125.000000 µs、群延遲 79.577472 µs。

不要混淆：頻率響應是穩態的描述，量不到暫態。網路分析儀掃頻給的是每個頻率穩定之後的比值，開機瞬間的行為要看步階響應或極點。也不要只比較 |H| 就下結論，漏掉相位就漏掉波形變形。

阻尼比與自然頻率（damping ratio & natural frequency）

白話：二階系統振得多兇（ζ）、振得多快（ωn）。

位置／角色：第 08 章；電路學的 RLC 用 α 與 ω0，本課用 ζ 與 ωn，兩套符號可以互相換算。

機制：ζ 讀作「zeta」，是阻尼比，沒有單位；ωn 讀作「omega n」，是自然頻率，單位 rad/s。標準式 H(s) = ωn² / (s² + 2ζωns + ωn²)，極點 s = −ζωn ± jωn√(1 − ζ²)。錨定實例：ζ = 0.5、ωn = 10，極點 −5 ± j8.660254、ωd = 8.660254、超越量 Mp = 16.303353 %、tp = 0.362760 s、ts = 0.800000 s、共振 ωr = 7.071068、Mr = 1.154701。

不要混淆：自然頻率 ωn、阻尼振盪頻率 ωd 與共振頻率 ωr 是三個不同的數（同一組參數下分別是 10、8.660254、7.071068）。只說「這個系統的頻率是多少」而不指明是哪一個，多半會對不起來。另外 ζ 夠大時頻率響應根本沒有共振峰。

第四組｜濾波、調變與離散系統（第 09–11 章）

理想濾波器（ideal filter）

白話：通帶完全不衰減、阻帶完全擋掉、過渡帶寬度為零的濾波器——它不存在。

位置／角色：第 09 章的起點，用來說明「為什麼真的濾波器一定有取捨」。四種基本型：低通、高通、帶通、帶止。

機制：理想低通的 H(jω) 是一個矩形，對應的 h(t) 是 sinc；而 sinc 在 t < 0 也不為零，違反因果性。把它截斷再往右移可以變成因果的，代價是通帶出現漣波、過渡帶展開成有限寬度。

不要混淆：理想濾波器不可實現，原因不是「做得不夠好」而是數學上非因果，再貴的元件也做不出來。實務上談的永遠是逼近：要陡峭度就犧牲相位線性，要相位線性就犧牲陡峭度。

巴特沃斯濾波器（Butterworth filter）

白話：通帶最平坦的那一族，代價是過渡帶不夠陡。

位置／角色：第 09 章；感測器前端的抗混疊濾波常選它。

機制：|H(jf)|² = (1) / (1 + (f/fc)2n)，n 是階數，每加一階阻帶斜率多 20 dB/decade。錨定實例：fc = 1000 Hz，要求在 3000 Hz 衰減 40 dB，算出 nmin = 4.191761，取 5 階；5 階在 3000 Hz 實際衰減 47.712199 dB、在 2000 Hz 為 −30.107239 dB；4 階只有 38.170362 dB，不合格。

不要混淆：「最平坦」只講通帶的大小，完全不保證相位好，巴特沃斯的群延遲在轉角附近仍會起伏。另外階數必須無條件進位：4.191761 要取 5，取 4 就差了 1.829638 dB 而不合格。

柴比雪夫／貝索／橢圓濾波器（Chebyshev / Bessel / elliptic filter）

白話：三種與巴特沃斯互補的取向：更陡但有漣波、相位最線性但最不陡、最陡但兩邊都有漣波。

位置／角色：第 09 章的設計家族比較。

機制：柴比雪夫（Chebyshev）第一型容許通帶有等漣波，換來比同階巴特沃斯更陡的過渡帶；貝索（Bessel）以最大平坦群延遲為目標，波形保真度最好但衰減最慢；橢圓（elliptic，又稱 Cauer）通帶阻帶都有漣波，同階陡峭度最高。同一組規格下所需階數大致是橢圓 < 柴比雪夫 < 巴特沃斯 < 貝索。

不要混淆：這四族比的是「同一組規格要幾階」與「相位好不好」，不是誰比較高級。傳輸方波或脈衝時貝索最好，做抗混疊擋帶時橢圓最省階數。本課人名一律寫柴比雪夫與貝索，同一個人的其他中譯不在本課使用。

群延遲（group delay）

白話：一包窄頻訊號的「包絡」被系統推遲了多久。

位置／角色：第 09 章；音訊、雷達與高速數位鏈路都盯著它看。

機制：τg = −d∠H/dω，單位 s（∠H 用 rad、ω 用 rad/s）；τg 讀作「tau sub g」。一階系統的閉合式是 τg = (1/ωc) / (1 + (ω/ωc)²)。錨定實例：f = fc = 1000 Hz 時群延遲 79.577472 µs，而相位延遲是 125.000000 µs；M = 8 的移動平均群延遲恰為 3.5 樣本（4.375000 × 10−4 s）。

不要混淆：群延遲 −d∠H/dω 與相位延遲 −∠H/ω 是兩個不同的量，只有相位嚴格線性時才相等。前者決定波形變不變形，後者只描述單一弦波被推遲多久。

線性相位（linear phase）

白話：相位對頻率是一條直線，所有頻率成分被延遲一樣久，波形形狀完全不變。

位置／角色：第 09 章與第 15 章；FIR 做得到，IIR 做不到（除非離線正反各跑一次）。

機制：相位寫成 ∠H(ω) = −ω·τg 且 τg 為常數時就是線性相位。係數對稱（或反對稱）的 FIR，h[n] = h[M − 1 − n]，天生給出嚴格線性相位，群延遲固定為 (M − 1)/2 樣本；M = 8 時就是 3.5 樣本。

不要混淆：線性相位不是「零相位」，它一定有延遲，只是每個頻率延遲一樣多。也不要以為線性相位一定比較好：同規格下它需要的階數比 IIR 高得多，而且即時系統裡那個固定延遲往往才是真正的成本。

調變（modulation）

白話：把低頻的訊息搬到某個高頻載波上，好讓天線做得出來、也好讓很多台共用同一片空氣。

位置／角色：第 10 章；AM 廣播、對講機、Wi-Fi 都是同一件事的不同版本。

機制：時間域乘上載波：y(t) = x(t)·cos(ωct)。依摺積定理，頻域就是把 X 搬到 ±ωc（ωc 讀作「omega c」，是載波角頻率）。調幅（amplitude modulation, AM）的完整式是 A[1 + m·xn(t)]·cos(ωct)，xn 是歸一化後的訊息。

不要混淆：調變不是 LTI 運算——它不時不變（把輸入延後，輸出不是單純延後同樣時間），所以不能用單一個 h 描述。也不要把它與濾波混為一談：濾波只能拿掉既有的頻率成分，調變會生出原本沒有的新頻率。

調變指數（modulation index）

白話：訊息把載波振幅「壓」得多深，通常寫成 m。

位置／角色：第 10 章；它決定 AM 發射機的功率效率與失真。

機制：m = 訊息峰值 / 載波振幅。總功率 Pt = Pc(1 + m²/2)，每個邊帶的功率是 Pc·m²/4。錨定實例：Pc = 100 W、m = 0.5 時 Pt = 112.500000 W、每邊帶 6.250000 W、功率效率 11.111111 %。

不要混淆：m > 1 叫過調變，包絡檢測會解出失真的訊息，這是波形被切壞而不是「音量太大」。另外即使 m = 1，效率也只有三分之一，AM 大部分功率永遠花在不帶資訊的載波上——這是它被單邊帶與數位調變取代的原因。

邊帶（sideband）

白話：調變之後，載波兩側各長出一份訊息的頻譜。

位置／角色：第 10 章；AM 廣播一個頻道 10 kHz 就是這樣定出來的。

機制：訊息最高頻率為 fm 時，上邊帶落在 fc + fm、下邊帶落在 fc − fm，佔用頻寬 2fm。錨定實例：fc = 1000 kHz、fm = 5 kHz，邊帶落在 1005 kHz 與 995 kHz，頻寬 10 kHz。

不要混淆：對實數訊息而言兩個邊帶帶的是同一份資訊，所以單邊帶可以砍掉一個、省一半頻寬。邊帶也不是諧波：諧波是整數倍頻率，邊帶是加減出來的和頻與差頻。

包絡檢測（envelope detection）

白話：用一顆二極體加一組 RC，把 AM 訊號的「外框」描出來，直接還原訊息。

位置／角色：第 10 章；最便宜的 AM 收音機就是這樣做的。

機制：整流之後接一個時間常數適中的 RC 低通：要比載波週期長（濾掉載波），又要比訊息最快的變化短（跟得上包絡）。條件寫成 1/fc ≪ RC ≪ 1/fm。

不要混淆：包絡檢測只在 m ≤ 1 且載波仍在時才正確。抑制載波的雙邊帶或單邊帶必須用同步檢測（乘上本地同頻同相載波再低通），拿包絡檢測去解只會得到整流過的殘骸。

差分方程（difference equation）

白話：離散系統的「遞迴公式」：用過去的輸出、加上現在與過去的輸入，算出現在的輸出。

位置／角色：第 11 章；寫成程式就是一個帶狀態的迴圈。

機制：∑k=0N aky[n − k] = ∑m=0M bmx[n − m]。錨定實例：一階 IIR y[n] = 0.8y[n − 1] + x[n]，步階輸入下 n = 5 時 y = 3.689280、h[5] = 0.327680、直流增益 5.000000、nτ = 4.481420 樣本（nτ 讀作「n sub tau」，指振幅衰減到 1/e 所需的樣本數）。第 14 章的二階例是 y[n] = 1.272792y[n − 1] − 0.810000y[n − 2] + x[n]。

不要混淆：差分方程不只是微分方程的離散近似，它本身就是離散系統的完整描述。另外回授項全部消失就變成 FIR，只要有一個非零回授項就是 IIR——這一條直接決定要不要檢查穩定性。

FIR 濾波器（finite impulse response filter）

白話：脈衝響應只有有限多項的濾波器，算完就結束，不吃自己的輸出。

位置／角色：第 15 章；音訊等化、通訊接收機的匹配濾波常用它。

機制：FIR 是 finite impulse response（有限脈衝響應）。y[n] = ∑m=0M−1 bmx[n − m]，沒有回授。因為只有有限項，∑|h[n]| 必然有限，所以恆穩定；係數對稱時相位嚴格線性。錨定實例：M = 8 的移動平均在 fs = 8000 Hz 下，500 Hz 處 |H| = 0.640729（−3.866514 dB）、第一零點 1000.000000 Hz、群延遲 3.5 樣本。

不要混淆：FIR 的「有限」講的是 h[n] 的長度，不是輸出的長度。它天生穩定是因為沒有回授，不是因為短。同規格下 FIR 需要的階數常常是 IIR 的十倍以上，運算量才是它真正的代價。

IIR 濾波器（infinite impulse response filter）

白話：有回授的濾波器，脈衝響應理論上永遠拖著尾巴不歸零。

位置／角色：第 11 章與第 15 章；即時控制與低功耗場合常選它。

機制：IIR 是 infinite impulse response（無限脈衝響應）。因為有回授項，少少幾階就能做出很陡的過渡帶；代價是必須檢查穩定性（極點要在單位圓內），而且相位一定非線性。錨定實例：一階 IIR a = 0.8 在 fs = 8000 Hz 下，500 Hz 處 |H| = 0.497222（−6.068991 dB）、−3 dB 頻率 285.301514 Hz、∑|h[n]| = 5.000000。

不要混淆：IIR 的「無限」是理論上的，實際上 h[n] 衰減到量化位階以下就等於 0 了。也不要以為「IIR 比較省」是無條件的：定點實作時係數量化可能把極點推出單位圓，通常得拆成二階節串接才安全。

第五組｜取樣、離散頻譜與 z 平面（第 12–15 章）

取樣定理（sampling theorem, Nyquist–Shannon）

白話：只要取樣得夠快，離散的樣本就完整保存了原本連續訊號的全部資訊，可以一點不差地還原回去。

位置／角色：第 12 章；CD 用 44.1 kHz、電話用 8000 Hz，都是照這一條定出來的。

機制：訊號頻寬上限為 W 時，條件是 fs > 2W（fs 讀作「f sub s」，取樣頻率，單位 Hz）。還原用 sinc 內插：x(t) = ∑n x[nTs]·sinc((t − nTs)/Ts)。錨定實例：f = 3000 Hz、fs = 8000 Hz 時未混疊，Ts = 1.250000 × 10−4 s、x[3] = 0.707107。

不要混淆：定理要求的是嚴格頻寬受限，而真實訊號沒有一個嚴格頻寬受限，所以取樣前一定要放抗混疊濾波器。另外「取樣夠快就沒事」只保證資訊還在，不保證你在示波器螢幕上看得懂——顯示的曲線是儀器內插畫出來的。

奈奎斯特速率與奈奎斯特頻率（Nyquist rate & Nyquist frequency）

白話：兩個都叫「奈奎斯特」，一個是訊號要求的最低取樣率，一個是取樣系統能表示的最高頻率。

位置／角色：第 12 章；規格書上最常被混用的兩個字。

機制：奈奎斯特速率 = 2W，單位 Hz，由訊號頻寬決定。奈奎斯特頻率 = fs/2，單位 Hz，由取樣率決定。fs = 8000 Hz 時奈奎斯特頻率是 4000 Hz；若訊號頻寬 3400 Hz，奈奎斯特速率就是 6800 Hz。

不要混淆：奈奎斯特速率 2W 是訊號的性質，奈奎斯特頻率 fs/2 是取樣系統的性質，中文常常都叫「奈奎斯特頻率」，講數字時務必說清楚是哪一個。

混疊（aliasing）

白話：取樣不夠快時，高頻會偽裝成低頻，而且一旦發生就再也分不出來。

位置／角色：第 12 章；示波器螢幕上那條「漂亮的低頻波」常常就是它。

機制：頻率 f 的訊號在取樣率 fs 下，會與 f ± k·fs（k 為整數）的所有頻率產生完全相同的樣本，折算回 0 到 fs/2 之間的那一個就是視在頻率。錨定實例：f = 5000 Hz、fs = 8000 Hz 時視在頻率為 3000.000000 Hz。

不要混淆：混疊不是雜訊，它是確定性的假頻率：5000 Hz 在 8000 Hz 取樣下產生的樣本，與真正的 3000 Hz 訊號一模一樣。本課一律寫「混疊」；電機/中英名詞對照表-2.md 寫的是「摺疊」，指的是同一件事 aliasing。

抗混疊濾波器（anti-aliasing filter）

白話：在 ADC 前面先把超過奈奎斯特頻率的成分擋掉，因為它們一旦進去就救不回來了。

位置／角色：第 12 章的取樣鏈；每一顆 ADC 前面都應該有一個。

機制：它是一個類比低通，轉角頻率設在略低於 fs/2，阻帶衰減要壓到量化雜訊之下。需要的階數可用巴特沃斯的估算式反算（第 09 章的做法）。提高取樣率（過取樣）能讓這顆類比濾波器輕鬆很多，剩下的交給數位濾波器處理。

不要混淆：抗混疊濾波器一定要在取樣之前，而且必須是類比的。取樣之後再用數位濾波器擋沒有用：混疊已經發生、假頻已經和真訊號疊在同一個頻率上，任何後處理都分不開——這是本課少數幾件真正不可逆的事。

零階保持（zero-order hold, ZOH）

白話：DAC 把每個樣本值「撐住」一整個取樣週期，畫出來是階梯狀。

位置／角色：第 12 章的還原端；所有實際的 DAC 都是這樣輸出的。

機制：ZOH 是 zero-order hold（零階保持）。它等效於摺上一個寬 Ts 的矩形，因此頻率響應是 sinc 的形狀，高頻會被額外壓低。錨定實例：f = 3000 Hz、fs = 8000 Hz 時 ZOH 衰減 0.784213（−2.111316 dB）。

不要混淆：ZOH 不是理想還原。理想還原用 sinc 內插，ZOH 用矩形保持，兩者差一個 sinc 的下垂，實務上要在後面補一個補償濾波器。階梯的稜角也帶來映像頻率，需要重建濾波器擋掉。

離散時間傅立葉轉換（discrete-time Fourier transform, DTFT）

白話：對一串無限長的離散樣本做的傅立葉轉換，結果是一個以 2π 為週期的連續頻率函數。

位置／角色：第 13 章；理解「離散頻譜為什麼是週期的」的關鍵。

機制：DTFT 是 discrete-time Fourier transform（離散時間傅立葉轉換）。X(ejω) = ∑n=−∞∞ x[n]e−jωn，ω 的單位是 rad/sample，週期為 2π。這個週期性正是取樣造成頻譜週期複製的直接後果。

不要混淆：DTFT 的輸入離散、輸出連續，所以電腦算不出來，能算的是它的取樣版本 DFT。另外它寫成 X(ejω) 用圓括號，因為 ω 是連續變數，這與 x[n] 用方括號並不衝突。

離散傅立葉轉換（discrete Fourier transform, DFT）

白話：拿有限的 N 個樣本，算出 N 個頻率點的成分——這是電腦真正在算的東西。

位置／角色：第 13 章；所有頻譜分析軟體背後都是它。

機制：DFT 是 discrete Fourier transform（離散傅立葉轉換）。X[k] = ∑n=0N−1 x[n]·exp(−j 2π k n / N)，k 是 bin 序號（本課 bin 序號一律寫 k）。它等價於一個 N × N 的矩陣乘法，複雜度 O(N²)：N = 1024 時是 1048576 次運算。

不要混淆：DFT 隱含「這 N 個樣本會一直週期重複」的假設，所以首尾接不起來就會產生譜洩漏。另外 X[k] 用方括號（k 是整數），DTFT 的 X(ejω) 用圓括號，這個區別在本課全程一致。

快速傅立葉轉換（fast Fourier transform, FFT）

白話：算 DFT 的快速演算法，把 O(N²) 降成 O(N log N)。

位置／角色：第 13 章；它是整個數位訊號處理能商用化的原因。

機制：FFT 是 fast Fourier transform（快速傅立葉轉換）。作法是把 N 點 DFT 遞迴拆成兩個 N/2 點 DFT，重複利用旋轉因子。錨定實例：N = 1024 時直接 DFT 需 1048576 次運算、FFT 約 5120 次，加速 204.800000 倍。

不要混淆：FFT 與 DFT 算出來的是同一個東西，FFT 不是「另一種轉換」，也不會比較準，它只改變運算次數。基 2 的 FFT 要求 N 是 2 的次方，這才是「為什麼大家都用 1024 點」的真正理由。

頻率解析度（frequency resolution）

白話：兩根靠得多近的譜線還分得開。

位置／角色：第 13 章；它決定你能不能把市電 50 Hz 與旁邊 51 Hz 的干擾分開。

機制：Δf = fs/N（Δf 讀作「delta f」，單位 Hz）。錨定實例：N = 1024、fs = 8000 Hz 時 Δf = 7.812500 Hz、窗長 Twin = 0.128000 s（Twin 讀作「T sub win」，是觀測窗的時間長度）。f = 1000 Hz 剛好落在 k = 128，整數週期、無洩漏；f = 1010 Hz 落在 k = 129、bin 中心 1007.812500 Hz、誤差 2.187500 Hz。

不要混淆：Δf = fs/N 看起來像「點數愈多愈細」，但真正決定它的是窗長 Twin = N/fs，Δf = 1/Twin。零填充讓點變密不會改善它：曲線變平滑了，能分辨的兩根線並沒有變近。

譜洩漏與加窗（spectral leakage & windowing）

白話：訊號在觀測窗裡沒有剛好切在整數個週期上，能量就會漏到旁邊的 bin；加窗是把窗的兩端壓下去，換取少漏一點。

位置／角色：第 13 章；第 15 章用窗口法設計 FIR 用的是同一組工具。

機制：截斷等於乘上一個窗函數，頻域對應摺上窗的頻譜，窗的旁瓣就是洩漏的來源。本課固定使用這一組最高旁瓣值：矩形（rect）−13.3 dB、漢寧（Hann）−31.5 dB、漢明（Hamming）−42.7 dB、布拉克曼（Blackman）−58.1 dB。錨定實例：f = 1000 Hz 在 N = 1024、fs = 8000 Hz 下是整數週期，無洩漏；1010 Hz 就不是。

不要混淆：加窗買到的是旁瓣壓低，賣掉的是主瓣變寬（解析度變差），它不是「免費變準」。也不要把洩漏的裙擺當成那些頻率真的存在：換一個窗再看一次，裙擺會變，真的譜線不會。

Z 轉換與單位圓（Z-transform & unit circle）

白話：離散世界的拉氏轉換；s 平面的虛軸在這裡變成一個單位圓。

位置／角色：第 14 章；數位濾波器的穩定性與頻率響應都在這張圖上讀。

機制：X(z) = ∑n=−∞∞ x[n]z−n，z = r·exp(jω)。把 z 限制在 |z| = 1（單位圓）就得到 DTFT。穩定 ⇔ 所有極點 |z| < 1。極點的半徑 r 決定衰減多快、角度 θ 決定共振在哪個頻率。錨定實例：r = 0.9、θ = 45°、fs = 8000 Hz 時共振 1000.000000 Hz、h[5] = −0.835079、nτ = 9.491222 樣本（1.186403 ms）、|H| 峰值 7.432941、直流 1.861477、4000 Hz 處 0.324381。

不要混淆：單位圓對應的是「繞一圈等於 fs」，走到 180° 就是奈奎斯特頻率 4000 Hz，再走下去是負頻率的鏡像，不是更高的頻率——這就是離散頻譜週期性在圖上的樣子。另外 X(z) 用圓括號（z 是連續複變數），x[n] 用方括號。

多速率處理（multirate processing：抽取與內插）

白話：在同一條處理鏈裡用不同的取樣率，該慢的地方就慢下來，省運算也省功耗。

位置／角色：第 15 章；音訊 44.1 kHz 與 48 kHz 之間的轉換、通訊接收機的降頻鏈都靠它。

機制：抽取（decimation）先低通、再每 M 點取 1 點，低通是必要的，否則直接製造混疊；內插（interpolation）先在每兩點之間補 L − 1 個零、再低通，低通用來去掉補零產生的映像。有理倍率 L/M 的轉換就是先內插再抽取。

不要混淆：抽取不是「直接丟掉樣本」，少了前面那顆低通就等於製造混疊。內插也不是「把點連起來」，補零之後的那顆低通才是真正在做內插的那一步。

隨機過程與功率譜密度（random process & power spectral density）

白話：訊號本身是隨機的（雜訊、語音、通道衰落），只能談統計性質；功率譜密度說的是「平均而言每個頻率上有多少功率」。

位置／角色：本課不展開，留給通訊系統／控制系統／數位訊號處理。字典留這張卡，是因為讀者在筆記與規格書上一定會撞到它。

機制：隨機過程是「每個時刻都是一個隨機變數」的集合。廣義平穩時，功率譜密度 S(f)（單位 W/Hz）是自相關函數的傅立葉轉換；LTI 系統對它的作用是 Sy(f) = |H(f)|²·Sx(f)。

不要混淆：功率譜密度不是「做一次 FFT 的結果」。單次 FFT 的量值只是一個方差很大的估計，要靠多段平均才會收斂。也不要把它和確定訊號的頻譜混用，兩者單位不同（W/Hz 對上 V/Hz）。

狀態空間（state space）

白話：不寫一個高階的轉移函數，改用一組一階方程描述系統內部的狀態怎麼演化。

位置／角色：本課不展開，留給通訊系統／控制系統／數位訊號處理，主要歸控制系統（可控性、可觀測性、極點配置）。

機制：連續版寫成 dx/dt = Ax + Bu、y = Cx + Du，x 是狀態向量。它與轉移函數的關係是 H(s) = C(sI − A)−1B + D。優點是天生支援多輸入多輸出，也比較容易推廣到時變與非線性。

不要混淆：狀態空間不是「另一種轉移函數」。同一個轉移函數對應無限多組狀態空間實現（彼此差一個座標變換）；而且轉移函數只看得到既可控又可觀測的那一部分，被抵消掉的內部模態在 H(s) 上看不見，卻可能正在發散。

多相分解（polyphase decomposition）

白話：把一個濾波器的係數按「第幾個相位」拆成幾組，讓抽取與內插不必浪費力氣去算那些反正要丟掉的結果。

位置／角色：本課不展開，留給通訊系統／控制系統／數位訊號處理；實作細節屬於數位訊號處理專科，第 15 章只點名。

機制：把 h[n] 依 n 對 M 的餘數拆成 M 個子濾波器 hm[n] = h[mM + n]，抽取時先分流再各自濾波，運算量降為原本的 1/M。內插同理，省掉所有對補零樣本的乘法。

不要混淆：多相分解不改變輸出，它只是重排運算順序，不是另一種濾波器設計法。也不要以為它能省掉抗混疊低通——低通照樣要設計，多相只是把它拆開來算。
