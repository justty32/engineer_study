08・兩個參數綁死四個工程指標

極零點與二階系統：看到 ζ 就知道波形會怎麼晃

上一章把系統的個性交給極點位置，這章把最常用的那一型收成兩個參數：阻尼比 ζ 與自然頻率 ωn。超越量、峰值時間、整定時間與共振峰全部由它們決定，而且分工乾淨得驚人：形狀只看 ζ，快慢只看 ωn。

這章假設已懂：07 拉氏轉換與轉移函數的極點與轉移函數，以及電路學的二階 RLC 暫態那三種放電行為。

痛點：超越量、整定時間這些規格到底從哪裡冒出來的

控制課的規格表寫得很硬：超越量不得超過 10 %、整定時間要小於 0.5 秒、共振峰不得高於 1.3。可是這些數字看起來彼此獨立，改一個好像會動到全部，於是設計變成試誤。真正的問題是沒有人先說清楚：這四個指標其實只由兩個參數決定，而且分工是固定的。

第二個痛點是名字太像。ωn、ωd、ωr 全部叫「某某頻率」，符號只差一個下標，數值又都在同一個量級，講快一點就分不清誰是誰。同一組參數下這三個數字明明不一樣（本章預設值是 10.000000、8.660254、7.071068 rad/s），卻常被當成同一件事。

第三個痛點是「有沒有共振峰」與「會不會超越」被混為一談。頻率響應平坦不代表步階響應不會衝過頭，這兩件事分屬頻域與時域，門檻也不同：ζ ≥ 0.707107 就沒有共振峰，但要 ζ ≥ 1 才沒有超越，中間那一段是最容易誤判的區域。

白話直覺：一個會回彈的系統，回彈多用力由阻尼決定

訊號從哪來？就當它是一個突然給到位的命令：電源開機、馬達收到新的位置目標、喇叭收到一個直流階。系統對它做了什麼？系統有慣性也有阻力，它不會直接停在新位置，而是衝過去一點再彈回來，來回幾次才安頓。這件事在哪個域最好描述？兩邊都要：時域看衝過頭多少、多久安頓；頻域看在哪個頻率被放大、放大多少。同一組極點同時決定這兩張臉。

可以暫時把 ζ 想成阻尼器的黏度，ωn 想成彈簧的硬度；比喻到此為止，精確的定義是 H(s) = ωn² / (s² + 2ζωns + ωn²)，其中 ωn 是自然頻率（natural frequency），單位 rad/s，ζ 是阻尼比（damping ratio），無單位。分子刻意寫成 ωn² 是為了讓直流增益等於 1，也就是最後一定停在輸入值上，不多不少。

換域的代價是什麼？在時域看得到超越與整定，卻看不出哪個頻率被放大；在頻域看得到共振峰，卻看不出第一個峰發生在第幾毫秒。而且兩邊的「峰」不是同一個數字：本章預設值下共振峰 Mr = 1.154701、超越後的峰值 1.163034，接近純屬巧合。儀器量到什麼？示波器給第一個峰的高度與時間，網路分析儀給振幅與相位曲線；把兩者拼起來才是完整的二階描述。

來源：09-信號與系統-上 §7.3–§7.4。

推導：從公式解到四個指標

（a）極點怎麼來。對分母 s² + 2ζωns + ωn² 用公式解，判別式是 4ζ²ωn² − 4ωn² = 4ωn²(ζ² − 1)。它的正負就是四種阻尼的分界：ζ > 1 判別式為正，兩個相異實根，過阻尼，不振盪但慢；ζ = 1 判別式為零，重根，臨界阻尼，是所有不振盪情形裡最快的；0 < ζ < 1 判別式為負，一對共軛複根 s = −ζωn ± jωn√(1 − ζ²)，欠阻尼，會振盪也會超越；ζ = 0 極點落在虛軸，無阻尼，等幅振盪。共軛極點的虛部就是阻尼振盪頻率 ωd = ωn√(1 − ζ²)，實部 −ζωn 就是上一章的衰減率 σ。

（b）欠阻尼的步階響應。簡化假設是線性、非時變、初始靜止、單位步階輸入。反轉換後得 y(t) = 1 − exp(−ζωnt)[cos(ωdt) + (ζ/√(1 − ζ²))sin(ωdt)]。第一項 1 是終值，中括號那一團是衰減中的振盪，前面的指數就是包絡。

（c）超越量的來歷。對 y 微分令零，中括號裡的項化簡後只剩正弦，第一個非零解落在 ωdt = π，於是峰值時間 tp = π/ωd。把它代回 y，指數項變成 exp(−ζωnπ/ωd)，而 ωn/ωd = 1/√(1 − ζ²)，所以超越量 Mp = exp(−πζ/√(1 − ζ²))。式子裡完全沒有 ωn：Mp 只跟 ζ 有關，ωn 只決定快慢，不決定形狀。

（d）整定時間的來歷。用 2 % 準則，要求包絡 exp(−ζωnt) 掉到 0.02，解得 t = ln(50)/(ζωn) = 3.912/(ζωn)。工程上把 3.912 取整成 4，寫成 ts ≈ 4/(ζωn)。這個 4 是慣例不是定理，換成 5 % 準則就變成 3。

（e）共振峰與 0.707107 這個門檻。把 s = jω 代進去得 |H(jω)| = ωn² / √((ωn² − ω²)² + (2ζωnω)²)。要找峰就對分母內那一團求極值，得 ωr² = ωn²(1 − 2ζ²)。當 1 − 2ζ² ≤ 0，也就是 ζ ≥ 1/√2 = 0.707107 時根本沒有實數解，沒有共振峰，振幅從直流開始就單調下降。有峰時峰值 Mr = 1/(2ζ√(1 − ζ²))。另外在 ω = ωn 這一點，分母第一項歸零，|H| = 1/(2ζ)，而相位恆為 −90°，與 ζ 無關——這是實驗室量 ωn 最可靠的方法。電路學那一側的品質因數換算是 Q = 1/(2ζ)。

（f）不振盪的兩個分支。ζ = 1 時重根落在 −ωn，步階響應是 y(t) = 1 − (1 + ωnt)·exp(−ωnt)。ζ > 1 時兩個實極點 s1,2 = −ζωn ± ωn√(ζ² − 1)，步階響應 y(t) = 1 − (s2·exp(s1t) − s1·exp(s2t))/(s2 − s1)。兩個實極點差很遠時，靠近原點那個衰減慢，整條曲線由它主導。

自由實驗：把 ζ 與 ωn 的分工看清楚

系統是標準二階式 H(s) = ωn² / (s² + 2ζωns + ωn²)，輸入是單位步階。前兩個滑桿決定系統本身，後兩個滑桿決定你站在哪個頻率、哪個時刻觀測。要看的是：只動 ωn 時超越量一格都不動，只有時間軸被拉伸或壓縮；ζ 跨過 0.707107 時共振峰整個消失，但步階響應還在超越。

欠阻尼：極點 −5.000000 ± j8.660254、ωd = 8.660254 rad/s、Q = 1.000000。會超越 16.303353 %，第一個峰在 tp = 0.362760 s，大約 ts = 0.800000 s 後穩定下來。共振頻率 ωr = 7.071068 rad/s、共振峰 Mr = 1.154701。目前 |H(jω)| = 1.000000（0.000000 dB）、∠H = −90.000000°、y(0.500000) = 1.074591。現在剛好站在 ωn 上：|H| = 1/(2ζ) = 1.000000，相位一定是 −90.000000°——這是實驗室量 ωn 最可靠的方法，因為相位比振幅好認。Mp 只由 ζ 決定，ωn 只決定快慢：把 ωn 加倍，波形形狀一模一樣，只是時間軸壓縮一半。Q = 1/(2ζ)，所以 ζ = 0.5 就是 Q = 1；電路學的 RLC 共振講的是同一件事。把 ζ 滑到 0.05 會逼近振盪器，滑到 1 是臨界阻尼、不超越且最快，滑過 1 之後變成兩個實極點、由慢的那個主導；ζ 一旦到達 0.707107 以上就不再有共振峰。t 滑到 0 時 y 一定是 0.000000。

不要混淆

  • ωn、ωd、ωr 是三個不同的頻率。本章預設值分別是 10.000000、8.660254、7.071068 rad/s，只有 ζ → 0 時三者才靠攏成同一個數。
  • 「阻尼比 ζ」與「衰減率 σ」不是同一個量。ζ 無單位，σ = ζωn 才是每秒衰減多少，單位 1/s；同樣的 ζ 配不同的 ωn，衰減速度差很多。
  • 共振峰 Mr 與超越量 Mp 都叫「峰」，但一個在頻域、一個在時域，數值不相等（1.154701 對 1.163034，接近純屬巧合）。
  • ζ ≥ 0.707107 沒有共振峰不代表沒有超越。ζ = 0.7 的頻率響應已經單調下降，步階響應仍然超越 4.598791 %；要完全不超越得等到 ζ ≥ 1。
  • 整定時間公式裡的 4 是 2 % 準則的工程近似，精確值是 ln(50) = 3.912。換成 5 % 準則會變成 3，報數字前要先講清楚用哪個準則。

可觀察證據：拿什麼量、量到什麼

時域這一側：用函數產生器送一個低頻方波當步階，示波器量第一個峰比終值高出的比例就是 Mp，量峰出現的時刻就是 tp。由 Mp 反解得到 ζ，再由 tp = π/ωd 得到 ωd，兩者合起來就得到 ωn。頻域這一側：用網路分析儀掃頻，找相位穿過 −90° 的那一點，那就是 ωn，而且這個判準不受增益校正誤差影響，比找振幅峰值可靠得多。

能證明什麼：ζ 與 ωn 的實際值、共振峰的高度與位置、直流增益是不是真的等於 1。改一個元件再量一次，就能看到極點確實照公式移動。

不能證明什麼：這個系統真的是二階。真實裝置一定有更多極點與寄生零點，只是被主導的那一對蓋住；量到的曲線與二階模型吻合，只說明二階是好用的近似，不說明高階項不存在，而高頻段的偏離通常就是它們露出的馬腳。也證明不了整定時間公式裡的「4」——那是準則的選擇，不是量出來的物理量。此外網路分析儀給的是穩態頻率響應，量不到暫態；示波器給的是暫態，量不到相位曲線，兩台儀器缺一不可。

連到哪門課

這一章的四個指標就是控制系統寫規格的語言：伺服迴路的超越量上限、電源迴授的相位裕度、機械手臂的整定時間，全都是在挪 ζ 與 ωn。元件那一側，RLC 的 α 與 ω0 版本見電路學的二階 RLC 暫態，換算是 α = ζωn、ω0 = ωn；品質因數 Q 與共振見RLC 共振與品質因數，換算是 Q = 1/(2ζ)。至於怎麼設計控制器把 ζ 挪到想要的位置，那是控制系統的題目。下一章把同一組工具轉向濾波器，看看「要多陡」與「相位要多線性」怎麼互相衝突。
