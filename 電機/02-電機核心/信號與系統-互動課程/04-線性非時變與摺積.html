04・一條脈衝響應決定整個系統

線性非時變與摺積：把輸入切成無限多根脈衝，各自延遲加權再疊起來

這門課最重要的一句話是：一個 LTI 系統完全由它的脈衝響應 h(t) 決定。這章把這句話推出來，順便把摺積積分從一個嚇人的符號，拆成「切碎、延遲、加權、疊加」四個動作。

這章假設已懂：03 系統的六個性質的線性與時不變、02 基本訊號與訊號運算的 δ 篩選性，以及工程數學先修的積分即累積。

痛點：那個積分到底在加什麼，為什麼要把 h 反過來

第一次看到 y(t) = ∫−∞∞ x(τ)h(t − τ) dτ 的人，通常有兩個過不去的坎。第一個是：這個積分在累加什麼？式子裡有兩個時間變數 t 與 τ，一個在跑一個被固定，光看符號完全看不出誰是誰。第二個是：為什麼是 h(t − τ) 而不是 h(τ)？課本說要「翻轉再平移」，聽起來像是一個為了讓公式成立而發明的技巧。

還有一個更根本的疑問：憑什麼一條曲線就能代表整個系統？系統可以吃進任何輸入，輸入有無限多種，怎麼可能用單一個響應把全部答案存起來。這個問題的答案不在積分技巧裡，而在上一章的六個性質裡——線性讓「拆開算再加回去」合法，時不變讓「同一個響應可以搬到任何時刻重用」合法。少掉任何一條，這個特權就沒了。

這章把三件事一次做完：導出摺積、看懂 h(t − τ) 的物理意義、拿一個能手算的例子驗證，並學會用「面積相乘」這個一秒鐘的驗算法。

白話直覺：先把輸入敲碎成一排釘子，再看系統對一根釘子怎麼反應

訊號從哪裡來？就當它是一個電壓脈衝，例如感測器被敲了一下、或是通訊系統送出的一個符號。系統對它做了什麼？系統把這個輸入抹開了：輸入結束的瞬間輸出不會跟著歸零，因為系統有記憶，它會把之前存進去的東西慢慢吐出來。可以暫時把摺積想成滑動加權平均；比喻到此為止，精確的說法是：把輸入寫成無限多根加權延遲脈衝的疊加，每一根脈衝各自引發一份被延遲的 h，再把所有份數加總。

這件事在哪個域最好描述？在時間域，摺積是一個積分，計算量大但看得見因果順序；同一件事到了頻率域會變成單純的相乘（第 06 章），代價是你必須先接受複數與相位，而且失去「現在的輸出來自哪幾個過去時刻」的直觀。儀器量到什麼？示波器量到的是 y(t) 這條曲線本身，量不到摺積這個運算；h(t) 只能靠打一個夠窄的脈衝去逼近，或是打步階再對輸出微分。

脈衝響應（impulse response）h(t) 的定義是：LTI 系統對單位脈衝 δ(t) 的響應，單位是輸出單位除以秒（本章例子是 1/s，因為 δ 本身的單位是 1/s）。它之所以特別，不是因為 δ 特別，而是因為 δ 是「拆訊號的最小零件」，任何輸入都拆得成它的加權延遲組合。

來源：09-信號與系統-上 第 4 章 §4.1–§4.4。

推導：四步導出摺積，每一步都點名用到哪一條性質

第一步，用篩選性把輸入拆開。δ 的篩選性給我們 x(t) = ∫−∞∞ x(τ)δ(t − τ) dτ。這一步還沒用到系統的任何性質，它只是把 x 重寫成「一大堆發生在各個時刻 τ、強度 x(τ)dτ 的脈衝」的疊加。τ 是積分變數（單位 s），代表「這根脈衝發生在什麼時候」。

第二步，用時不變把 h 搬過去。系統對 δ(t) 的響應是 h(t)。時不變說規則不隨時間變，所以系統對延遲了 τ 的脈衝 δ(t − τ) 的響應，就是延遲了同樣時間的 h(t − τ)。這一步用掉的是時不變。

第三步，用線性的齊次性乘上權重。那根脈衝的強度是 x(τ)（一個常數，因為對系統來說 τ 是固定的），輸入乘常數則輸出乘同一個常數，於是 x(τ)δ(t − τ) 的響應是 x(τ)h(t − τ)。這一步用掉的是線性的齊次性。

第四步，用線性的可加性把所有份數加起來。輸入是無限多根脈衝的疊加，輸出就是無限多份響應的疊加，把離散的求和推到極限就是對 τ 積分：y(t) = x(t) ∗ h(t) = ∫−∞∞ x(τ)h(t − τ) dτ。這一步用掉的是線性的可加性。四步下來，六個性質裡剛好只動用了線性與時不變，這就是「為什麼只有 LTI 有這個特權」的完整答案。

為什麼是 h(t − τ)。把 t 固定，站在觀測時刻 t 往回看：一根發生在 τ 的脈衝，到現在為止已經過了 t − τ 這麼久，所以它此刻貢獻的是 h 在「已經過了 t − τ」這個位置上的值。所謂「翻轉」只是把這個引數畫成圖時的樣子，本質上是「經過了多久」這個減法。因果條件在這裡也一目了然：若 h(t) = 0 對所有 t < 0 成立，未來的脈衝（τ > t）就貢獻不了任何東西。

代數性質與互聯。摺積可交換、可結合、對加法分配。交換律的證明只要換元 λ = t − τ：dτ = −dλ，上下限跟著交換，積分變成 ∫−∞∞ h(λ)x(t − λ) dλ，正是 h(t) ∗ x(t)。由結合律可得串聯系統 heq = h1 ∗ h2，由分配律可得並聯 heq = h1 + h2；負回授要寫成 H/(1 + HG)，那要等第 07 章換到轉換域才好表達。穩定條件是 ∫|h(t)| dt < ∞（BIBO），它與因果條件互相獨立。

本章實例的閉合式。輸入是高 A（V）、寬 T1（s）、從 t = 0 開始的矩形，系統是 h(t) = e−t/τu(t) 的一階系統（假設初始靜止）。令 m = min(t, T1)，積分只在 x 不為零的區間內做，得 y(t) = A·τ·e−t/τ(em/τ − 1)。展開成兩段：0 ≤ t ≤ T1 時 y = Aτ(1 − e−t/τ)，這是充電；t > T1 時 y = Aτ[exp(−(t − T1)/τ) − exp(−t/τ)]，這是放電。面積驗算：∫x dt = A·T1、∫h dt = τ、∫y dt = A·T1·τ——摺積把兩條曲線的面積相乘。

自由實驗：把脈衝與系統的快慢分開調整

輸入是高 A、寬 T1、從 t = 0 開始的矩形脈衝，系統是時間常數 τ 的一階系統，觀測時刻 t 可以滑到脈衝結束之後。要看三件事：目前落在充電段還是放電段、輸出值與峰值差多少、以及三個面積是否始終滿足相乘關係。

y(1.000000) = 0.432332 V，目前在充電段：輸入還在，輸出朝 A·τ 爬升，每過一個 τ 走完剩餘距離的 63.2 %。峰值 0.432332，發生在 t = 1.000000 s。輸入面積 1.000000、脈衝響應面積 0.500000、輸出面積 0.500000，輸入面積 × 脈衝響應面積 ＝ 輸出面積。摺積把兩條曲線的面積相乘，這是最好用的驗算：如果你算出來的 y 面積不等於 A·T1·τ，一定有地方錯了。目前 τ 與 T1 同量級，輸出既保留了脈衝的輪廓也被明顯抹圓；把 τ 拉到遠小於 T1 時輸出幾乎複製輸入的形狀，把 τ 拉到遠大於 T1 時形狀會被抹平到只剩總面積，那就是低通濾波在時間域的樣子。把 t 滑到 0 會看到輸出 0.000000，因果系統不會提前反應。

不要混淆

  • 摺積不是相乘。x(t)h(t) 是逐點相乘，那對應到頻率域的摺積（第 06 章）；x(t) ∗ h(t) 是滑動加權積分，兩者是完全不同的運算。
  • h(t) 不是「系統的輸出」，它是系統對一個特定輸入 δ(t) 的輸出。它之所以特別，是因為由它可以生出所有其他輸入的輸出。
  • 「翻轉」不是為了好玩。h(t − τ) 的引數本來就是「這根脈衝到現在經過了多久」，減法是物理意義，翻轉只是畫圖時看到的樣子。
  • ∫|h| dt < ∞（穩定）與 h(t) = 0, t < 0（因果）是兩條互相獨立的條件。一個可以成立而另一個不成立，判斷時要分開檢查。
  • 輸出的峰值不等於輸入的峰值乘上系統增益。本例輸入高 1 V，輸出峰值只有 0.432332，因為系統在脈衝結束前根本來不及充滿。

可觀察證據：拿什麼量、量到什麼

要量 h(t)，實務上有兩條路。第一條是用函數產生器送一個很窄的方波脈衝（寬度遠小於 τ），用示波器錄下輸出，再把整條曲線除以那個脈衝的面積，得到的就是 h(t) 的近似。第二條是送步階，錄下步階響應，再對它做數值微分，因為步階響應的導數就是脈衝響應。第二條路對雜訊比較友善，因為步階的能量大得多。

能證明什麼：系統 h(t) 的實際波形、時間常數（從輸出爬到終值 63.2 % 的時刻讀出）、峰值大小與出現時刻，以及是否有明顯延遲。也能用面積相乘直接驗算量到的資料自洽不自洽。

不能證明什麼：系統是 LTI。摺積只在 LTI 前提下成立，而這個前提要靠上一章的疊加測試與時移測試另外驗證，量 h(t) 本身驗證不了它。也證明不了理想的 h(t)——真實脈衝有寬度，量到的其實是「窄脈衝響應」，寬度愈窄才愈接近；探棒頻寬與示波器取樣率也會把快速的細節磨掉。

連到哪門課

本章那條 e−t/τ 的曲線，在元件層次就是電容充放電，RC 與 RL 的完整算法見電路學的一階暫態；電路學給的是「這個電路的充放電曲線」，本課給的是「那就是 h(t)，任何輸入都用它摺積」。積分作為累積的直覺見工程數學先修的積分。真實裝置這一側，音響的房間殘響量測、雷達的匹配濾波、影像的模糊與去模糊，全都是同一個摺積在不同維度上的應用。下一章開始換域：既然摺積這麼難算，那就找一組輸入，讓系統對它們的作用單純到只剩下振幅與相位。
