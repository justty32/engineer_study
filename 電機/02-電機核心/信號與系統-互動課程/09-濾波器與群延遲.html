09・要多陡就要多少階，代價寫在相位上

濾波器與群延遲：把「濾掉不要的頻率」變成一組可以算的規格

濾波器不是一個開關，它是一份預算表：通帶邊緣在哪、阻帶要壓多低、過渡帶留多寬，這三個要求一填，最小階數就被決定了。而每加一階就多一對極點，相位轉得更多、群延遲更不平坦，波形也就更走樣。

這章假設已懂：08 極零點與二階系統的頻率響應與共振峰，以及電路學的一階濾波器與頻率響應那個 −3 dB 轉角。

痛點：為什麼濾波器不能「直接把不要的頻率設成零」

直覺上這件事應該很簡單：想要的頻率乘 1、不想要的乘 0，寫成程式就是一行判斷式。可是真的照這樣做出來的濾波器不但做不出來，連數學上都違反因果。課本會說「理想濾波器不可實現」，卻很少把「為什麼不可以」講到讓人服氣。

第二個痛點是階數。規格書寫「五階巴特沃斯」，聽起來像是「用了五顆元件」，於是有人以為多加一顆電容就多一階。階數其實是 H(s) 分母的次數，也等於極點的個數，跟元件數量沒有固定換算；更重要的是，階數不是隨便挑的，它是被通帶邊緣、阻帶邊緣與阻帶要求三個數字反算出來的。

第三個痛點是群延遲。振幅曲線漂亮不等於波形不變形。方波打進一個振幅規格完美的濾波器，出來的角被磨圓、還帶振鈴，這件事在振幅圖上完全看不出來，因為它藏在相位裡。這章要把「相位不線性」翻譯成一個有單位、可以量、可以比較的量：群延遲，單位是秒。

白話直覺：濾波器是預算表，陡峭度要用相位去換

訊號從哪來？就當它是一路混著雜訊與干擾的量測訊號，或一串要送進取樣器之前必須先削掉高頻的類比訊號。系統對它做了什麼？系統把每個頻率成分乘上一個複數 H(jω)：大小決定留多少，角度決定延後多久。這件事在哪個域最好描述？當然是頻率域，因為濾波在那裡就是逐點相乘。

換域的代價是什麼？代價全部記在相位上。振幅要在很短的頻率跨距內從 1 掉到很小，相位就必須在同一段裡轉很多圈；相位轉得急，各頻率成分被延後的時間就不一樣，合起來的波形自然變形。這就是本章的核心交換：陡峭度、通帶平坦度、相位線性，三者不能同時最好。儀器量到什麼？網路分析儀掃頻給出 |H| 與 ∠H 兩條曲線，群延遲則由相位曲線的斜率算出來。

群延遲（group delay）的定義是 τg = −d∠H/dω，單位是秒（∠H 用 rad、ω 用 rad/s）。它的白話意思是「這個頻率附近的一團成分整體被延後多久」。如果所有頻率的 τg 都一樣，代表整個波形只是被平移，形狀完全不動，這就是線性相位；一旦 τg 隨頻率變化，低頻與高頻不同步抵達，方波的角就被磨圓，通訊上前後符號互相踩線，叫做符際干擾（intersymbol interference, ISI）。

來源：09-信號與系統-上 第 8 章。

推導：從理想的破產推到階數公式

（a）為什麼理想濾波器不可實現。理想低通在 |f| < fc 內 |H| = 1、之外為 0，相位線性。把這個矩形做反轉換，得到 h(t) = 2fc·sinc(2fct)，其中 sinc(x) = sin(πx) / (πx)、sinc(0) = 1；有些教科書用 sin(x)/x，本課全程用歸一化版。這個 h(t) 有兩個致命問題：它在 t < 0 有值，代表系統要在輸入到達之前就先反應，違反因果；而且它兩側衰減得很慢，無限長，永遠截不完。所以理想濾波器只能當參考，可實現的作法是用有理式 H(s) 去逼近它。

（b）四個設計家族的取捨。巴特沃斯（Butterworth）通帶最平坦，代價是過渡帶不夠陡；柴比雪夫（Chebyshev）允許通帶或阻帶出現漣波，換來同階數下更陡的下降；貝索（Bessel）放棄陡峭度，換群延遲最平坦、波形最不失真；橢圓（elliptic）兩邊都放漣波，同階數最陡但相位最糟。要最平坦選巴特沃斯，要最陡選橢圓，要波形不變形選貝索，要在陡與階數之間妥協選柴比雪夫。

（c）巴特沃斯的振幅式與每階 20 dB。n 階巴特沃斯的振幅是 |H(f)| = 1/√(1 + (f/fc)2n)，其中 fc 是通帶邊緣，定義成 |H| 掉到 1/√2 ＝ 0.707107（也就是 −3.010300 dB）的那個頻率。f 遠大於 fc 時分母的 1 可以忽略，|H| ≈ (fc/f)n，取 dB 得 −20n·log10(f/fc)。頻率每差十倍，log 項加 1，所以衰減 每階每十倍頻 20 dB，n 階就是 20n dB/decade。

（d）階數公式怎麼來。規格要求在阻帶邊緣 fs 至少衰減 As dB，也就是 10·log10(1 + (fs/fc)2n) ≥ As。兩邊先化成 (fs/fc)2n ≥ 10As/10 − 1，再取以 10 為底的對數並解 n，得 nmin = log10(10As/10 − 1) / (2·log10(fs/fc))，取上整就是實際要用的階數。階數只能是整數，所以幾乎一定會多給一點餘裕。

（e）一階系統群延遲的閉合式。一階低通的相位是 ∠H = −arctan(ω/ωc)，其中 ωc = 2πfc。對 ω 微分再取負號，得 τg = (1/ωc)/(1 + (ω/ωc)²)。在直流時 τg = 1/ωc，在 ω = ωc 時剛好掉到一半。同一顆濾波器，直流成分與轉角頻率成分被延後的時間差了一倍，這個「不平坦」就是波形失真的來源，而且階數愈高，相位轉得愈多，群延遲的起伏就愈大。

自由實驗：把規格與階數的帳算給自己看

系統是 n 階巴特沃斯低通。前三個滑桿是規格（通帶邊緣、阻帶邊緣、阻帶要求衰減），第四個滑桿是你實際打算採用的階數，第五個滑桿決定站在哪個頻率觀測。程式會算出規格反推的最小階數、採用階數在阻帶邊緣的實際衰減、觀測頻率的增益與 dB，以及一階系統的群延遲。要看的是：把阻帶邊緣往通帶拉近，最小階數會跳得多快。

fs/fc = 3.000000、nmin = 4.191761 → 取上整需要 5 階。規格達成：採用 5 階在 fs 給 47.712199 dB，超過要求的 40.000000 dB。目前 |H(2000.000000 Hz)| = 0.031235（−30.107239 dB），下降斜率 100 dB/decade。階數愈高愈陡（每階 20 dB/decade），但每加一階就多一對極點，相位轉得更多、群延遲更不平坦、元件容差的影響也更大。同樣是 fc = 1000.000000 Hz 的一階系統，直流成分被延後 159.154943 µs，fc 處只延後 79.577472 µs——兩個頻率的成分不同步抵達，方波的角就是這樣被磨圓的。要最平坦選巴特沃斯、要最陡選橢圓、要波形不變形選貝索、要在陡與階數之間妥協選柴比雪夫。把阻帶邊緣滑到低於通帶邊緣時規格就不成立，因為沒有過渡帶可言；把階數滑到小於所需值時會直接告訴你差幾 dB，而補救只有加階數、放寬阻帶邊緣、降低要求三選一。

不要混淆

  • 「階數」不是「幾個元件」。它是 H(s) 分母的次數，也等於極點的個數；同一個階數可以用不同的電路拓樸實現，元件數量不固定。
  • −3 dB 是通帶邊緣的定義，不是「濾波器開始起作用的地方」。5 階在 500 Hz 已經掉到 0.999512，在 fc 之前很久增益就不是 1 了，只是掉得很少。
  • 相位延遲（−∠H/ω）與群延遲（−d∠H/dω）是兩個不同的量，單位雖然都是秒。只有相位嚴格線性時兩者才相等；本課錨定的一階系統在 fc 處是 125.000000 µs 與 79.577472 µs，差很多。
  • 巴特沃斯的「最平坦」指的是通帶振幅最平坦，它的群延遲並不平坦。群延遲最平坦是貝索的專長，而貝索的振幅下降很慢，兩者不能兼得。
  • 阻帶衰減達標不代表相位可以接受。規格表若只寫振幅，等於默許波形被磨圓；要保波形就得另外寫群延遲的容許起伏。

可觀察證據：拿什麼量、量到什麼

網路分析儀掃頻可以直接畫出 |H| 與 ∠H 兩條曲線：由 |H| 讀出 −3 dB 點與各頻率的實際衰減，由 ∠H 的斜率算出群延遲隨頻率的變化。另一個更直觀的做法是把方波打進濾波器，用示波器看輸出：上升緣被磨圓的程度反映高頻被削掉多少，緣後的振鈴則反映通帶邊緣附近的相位急轉與過衝。這兩種量測互相印證，一個在頻域一個在時域。

能證明什麼：這顆濾波器的實際衰減曲線、−3 dB 點的真實位置、群延遲曲線的形狀與起伏幅度，以及它有沒有達到規格書上的阻帶要求。

不能證明什麼：它「是」幾階。斜率可以拿來估階數，但元件容差與寄生效應會讓高頻段偏離理論的 20n dB/decade，估出來的數字往往不是整數。也證明不了「通帶完全平坦」——量測本身有雜訊底線，低於底線的起伏根本量不到，只能說「在解析度內看不出不平坦」。此外網路分析儀給的是穩態頻率響應，量不到暫態；要看暫態得回去用步階或脈衝。

連到哪門課

抗混疊濾波器、音訊分頻網路、電源的輸出濾波、量測前端的帶通，全都是在填這章的預算表。一階 RC 的頻率響應與 fc = 1/(2πRC) 見電路學的一階濾波器與頻率響應；共振與品質因數見RLC 共振與品質因數，高階濾波器通常就是把多個二階節串起來，每一節有自己的 Q。數位版的 FIR 與 IIR 取捨見本課第 15 章，那裡的線性相位是真的可以做到嚴格線性，代價是延遲更長。下一章換個用途：同樣是頻率域的操作，這次不是刪掉頻率，而是把整段頻譜整體搬家。
