07・多給一個實部 σ，暫態與發散就都算得動了

拉氏轉換與轉移函數：極點的位置就是系統的個性

傅立葉只肯處理不會爆掉的訊號，可是真實系統一開機就有暫態，設計錯了還會發散。這章把 jω 換成 s = σ + jω，多買一個實部，就把「會不會炸」「多久穩下來」「振多快」三件事一起收進同一張圖裡。

這章假設已懂：06 傅立葉轉換的頻率響應與摺積定理，以及工程數學先修的常微分方程與拉氏轉換本體。

痛點：為什麼還要學一個看起來跟傅立葉一樣的轉換

學到這裡最容易出現的抱怨是：既然已經有 X(jω) 了，為什麼要再背一個只差把 jω 寫成 s 的東西？課本通常只說「拉氏是傅立葉的推廣」，然後就跳到查表，於是整章變成純代數練習，看不出它在系統裡代表什麼。

第二個痛點是收斂域。表格裡每一列右邊都掛著一行「Re{s} > a」，看起來像註腳，於是大部分人直接跳過。可是少了它，同一個 X(s) 可以對應兩個完全相反的時間訊號，一個往右衰減、一個往左存在。

第三個痛點是「極點」。所有人都聽過「極點在左半平面就穩定」，但被追問「那極點到底是什麼？為什麼它決定系統的行為？」時，多半只能回答「分母等於零的地方」。這章要把這句話還原成可以量的東西：極點的實部就是包絡衰減得多快，虛部就是振盪得多快，兩者互不干涉。

白話直覺：先給訊號套一件指數外衣，再看系統的自然振動

訊號從哪來？就當它是一次開機、一次負載突變、或敲一下機構的那一下。系統對它做了什麼？系統不會立刻到位，它會用自己的方式晃一陣子才安頓下來，這段自由晃動叫自然響應，跟輸入長什麼樣沒有關係，只跟系統本身有關。這件事在哪個域最好描述？在 s 域，因為在那裡整個系統縮成一個有理式 H(s)，而它分母的根就直接寫著「系統會怎麼自己動」。

拉氏轉換（Laplace transform，全名拉普拉斯轉換）做的事可以想成給訊號穿一件指數外衣：先把 x(t) 乘上 e−σt 壓住，再做傅立葉。比喻到此為止，精確的說法是 X(s) = ∫0∞ x(t)e−st dt，其中 s = σ + jω 是一個複數，σ 的單位是 1/s（每秒指數成長或衰減的速率），ω 的單位是 rad/s（角頻率）。σ 選得夠大，本來發散的訊號就被壓成可積分的。

換域的代價是什麼？第一，X(s) 不再是唯一的答案，必須連同收斂域（region of convergence, ROC）一起講，否則反轉換不唯一；第二，s 域裡的量沒有物理表頭可以直接讀，要換算回時間域或虛軸上才有意義；第三，單邊拉氏假設 t < 0 的東西都不算，初始條件必須另外交代。儀器量到什麼？示波器量得到自然響應的包絡與振盪週期，於是可以反推出主導那對極點的 σ 與 ωd；虛數單位在本課一律寫 j，數學課寫 i，電機寫 j，因為 i 留給電流。

來源：09-信號與系統-上 §7.1–§7.3。

推導：從積分收斂一路推到「微分方程變成代數式」

（a）為什麼要多一個 σ。傅立葉轉換要能算，前提是 ∫|x(t)| dt 收斂。拿 x(t) = e2tu(t) 來試：這個積分是發散的，所以它根本沒有傅立葉轉換，畫不出頻譜。但只要先乘上 e−σt 且 σ > 2，指數的淨效果變成 e(2−σ)t，積分立刻收斂。把「壓一下再做傅立葉」寫成一步，就得到 X(s) = ∫0∞ x(t)e−st dt。同一個式子，只是把 jω 升級成 σ + jω。

（b）ROC 為什麼不能省。eatu(t) 的轉換是 1/(s − a)，收斂條件是 Re{s} > a；而左側訊號 −eatu(−t) 的轉換也是 1/(s − a)，收斂條件卻是 Re{s} < a。兩個時間上完全相反的訊號共用同一個代數式，唯一的區別就寫在 ROC 裡。所以「只有 X(s) 是不夠的」，X(s) 加 ROC 才唯一決定 x(t)。順帶一提，只要虛軸（σ = 0）落在 ROC 內，把 s = jω 代進去就退化成傅立葉轉換——H(jω) 是 H(s) 在虛軸上的切片，這是本章最該記住的一句話。

（c）極點與自然響應的對應。轉移函數寫成有理式時，分母的根叫極點（pole），分子的根叫零點（zero）。單一項 1/(s − p) 的反轉換是 eptu(t)，所以每一個極點 p 就送出一個時間上的模態。p 是複數時一定共軛成對，設 p = σ ± jωd，先把指數拆開：exp((σ + jωd)t) = eσt·exp(jωdt)。再用歐拉公式收尾，exp(jωdt) + exp(−jωdt) = 2cos(ωdt)，於是兩個共軛項相加後虛部互相抵消，剩下實數的 h(t) = K·eσt·cos(ωdt)。實部 σ 跑到指數上管衰減，虛部 ωd 跑到餘弦裡管振盪，這兩件事在數學上就是分開的。

（d）為什麼左半平面等於穩定。σ < 0 時 eσt 隨 t 增加趨近 0，響應愈晃愈小；σ > 0 則愈晃愈大。更嚴格的判準是第 03 章的 BIBO 穩定：要求 ∫|h(t)| dt < ∞。指數衰減乘上有界的餘弦，積分當然收斂，所以左半平面極點滿足 BIBO；右半平面極點的積分發散，不滿足。σ = 0 是邊界，積分也不收斂，所以虛軸上的極點不算穩定。衰減快慢用時間常數 τ = 1/|σ| 描述（σ < 0 時），工程上以 5τ 當作「結束」，因為那時包絡只剩 e−5 ＝ 0.674 %。

（e）微分方程變成代數式。取二階微分方程 a2y″ + a1y′ + a0y = b0x，簡化假設是線性、非時變、初始靜止（t = 0 時輸出與其導數都是 0）。逐項取拉氏時，微分對應乘 s，也就是 d/dt → s、d²/dt² → s²，於是整條式子變成 (a2s² + a1s + a0)Y(s) = b0X(s)，移項得 H(s) = Y(s)/X(s) = b0/(a2s² + a1s + a0)。微積分變成四則運算，這就是換域的全部好處。零點在這個例子裡沒有出現（分子是常數）；一旦分子有 s，零點就會改變各個模態被激發的權重，也會在頻率響應上壓出凹陷，但它不改變極點，所以不改變穩不穩定。

數值實例：一對共軛極點 s = −2 ± j10 的自由振盪

取 K = 1，極點 s = −2 ± j10（σ 的單位 1/s、ωd 的單位 rad/s），觀測時刻 t = 0.5 s。這對應的自然響應是 h(t) = K·eσt·cos(ωdt)。

邊界對照：t = 0 s → h = 1.000000（h(0) 就是 K）；t = 1.0 s → h = −0.113556（負值：振盪已經走過半個週期）；t = 2.5 s → h = 0.006679（包絡 0.006738，已經剩不到 0.7 %）。σ = 0 → h(0.5) = 0.283662、包絡恆為 1.000000（虛軸：等幅振盪，永遠不停）；σ = +2 → h(0.5) = 0.771074、包絡 2.718282（右半平面：發散）。ωd = 0、σ = −2 → h(0.5) = 0.367879（純指數，沒有振盪——這就是實極點）。σ = −10 → h(0.5) = 0.001911（極點愈往左，衰減愈快）。

量級對照：這對極點的振盪頻率只有 1.591549 Hz，比市電的 50 Hz 還慢三十倍，是機構或電源迴路那種肉眼看得見的晃動，而且要 2.5 秒才安頓下來。把 ωd 換成 6283.185307 rad/s，振盪就落在本課的參考轉角頻率 1000 Hz，那已經是喇叭聽得見的音高。

自由實驗：把極點在 s 平面上拖來拖去

系統只有一對共軛極點 s = σ ± jωd，增益是 K，自然響應是 h(t) = K·eσt·cos(ωdt)。滑桿直接決定極點的位置與觀測時刻，程式算出響應值、包絡、時間常數、5τ 與振盪頻率。要看的是：把 σ 往左推只會讓包絡掉得更快，振盪頻率一動也不動；把 ωd 拉高只會振得更密，衰減速度完全不變。

極點 s = −2.000000 ± j10.000000；h(0.500000) = 0.104353、包絡 0.367879、時間常數 τ = 0.500000 s、5τ = 2.500000 s、振盪頻率 1.591549 Hz（週期 0.628319 s）。穩定：極點在左半平面，自然響應以 eσt 衰減，時間常數 τ = 0.500000 s，大約 5τ ＝ 2.500000 s 後就看不到了。極點的實部管衰減有多快、虛部管振多快，這兩件事完全獨立——這就是為什麼工程師看到零極點圖就知道系統會怎麼動。H(jω) 是 H(s) 在虛軸上的切片：把 s 換成 jω 就從「這個系統會怎麼自己動」變成「它對每個頻率怎麼反應」。把 σ 滑到 0 會停在虛軸上，振幅永遠不變；滑到正值就進入右半平面，響應指數成長，真實系統會撞到飽和或燒掉；把 ωd 滑到 0 則變成實極點，純指數而沒有振盪。t 滑到 0 時，不管其他滑桿怎麼放，h 一定等於 K。

不要混淆

  • s 不是頻率，它是複頻率。實部 σ 管「多快衰減」，單位 1/s；虛部 ω 才管「多快振盪」，單位 rad/s。把 s 直接當成 ω 用，會把衰減與振盪混為一談。
  • 收斂域不是可有可無的附註。1/(s − a) 配 Re{s} > a 是右側的衰減訊號，配 Re{s} < a 卻是左側訊號；沒有 ROC，X(s) 不唯一決定 x(t)。
  • 「極點在左半平面」是連續時間的穩定條件。離散時間的對應版本是「極點在單位圓內」（第 14 章），兩套判準各有各的平面，不能互相套用。
  • 零點不影響穩定性，但會影響頻率響應與暫態的形狀。「沒有零點的系統」與「零點很遠的系統」不是同一回事，前者的分子是常數，後者只是零點的效應暫時看不出來。
  • 時間常數 τ 與振盪週期是兩個不同的時間尺度。本例 τ = 0.500000 s 而週期是 0.628319 s，兩者接近純屬巧合；把 σ 加倍時 τ 減半，週期卻完全不動。

可觀察證據：拿什麼量、量到什麼

把系統接上函數產生器送一個步階，或乾脆用手敲一下機構，再用示波器錄下之後的自由振盪，就可以直接讀出兩個數字：一是相鄰兩個峰之間的時間，倒數就是振盪頻率 f，乘 2π 得到 ωd；二是峰值高度隨時間下降的比例，取對數除以時間差就得到 σ。把這兩個數字拼成 s = σ ± jωd，就是實驗量到的極點位置，完全不必知道系統內部是什麼電路或什麼機構。

能證明什麼：主導極點的位置、時間常數、振盪頻率與週期，以及系統目前是衰減、等幅還是發散。把系統參數改一格再量一次，就能驗證極點確實往左或往右移動。

不能證明什麼：所有的極點。真實系統通常有好幾對極點，衰減快的那些在幾個時間常數內就消失了，示波器上留下的幾乎只有衰減最慢的那一對，所以量到的是「主導極點」而不是完整的極點集合。也證明不了零點的位置——零點不出現在自然響應裡，只能靠掃頻時頻率響應上的凹陷去猜，而凹陷的深淺又會被量測雜訊底線蓋住。虛軸上的等幅振盪在實驗室也量不到：任何一點損耗都會把極點推進左半平面。

連到哪門課

轉移函數是控制系統與濾波器設計的共同語言：馬達驅動器的迴路補償、開關電源的迴授設計、麥克風前級的高通轉角，全都在挪極點的位置。拉氏轉換本身的收斂與反轉換技巧見工程數學先修的拉氏轉換；把它套回微分方程的解法見常微分方程。元件那一側，電路學的阻抗 Z(jω) 就是本章 H(s) 在單一元件上的特例，見電路學的阻抗與交流穩態。下一章把極點收斂成 ζ 與 ωn 兩個參數，讓「看到數字就知道波形會怎麼晃」變成規格。
