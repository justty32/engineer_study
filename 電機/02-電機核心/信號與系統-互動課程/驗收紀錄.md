### P1 — 必修

#### P1-1｜ch14 的 h[n] 與同一例子的差分方程／\|H\| 屬於兩個不同的系統

- **檔名與行號**
  - `14-Z轉換與單位圓.html:30`（數值實例表，`h[5] = 0.9⁵·cos(225°)` → **−0.417539**）
  - `14-Z轉換與單位圓.html:40`（邊界對照：r=0.99→−0.672452、r=1.0→−0.707107、r=1.05→−0.902467、h[20]=−2.653298）
  - `14-Z轉換與單位圓.html:51`（widget 預設輸出，同時列出 h[5] 與差分方程）
  - `app.js` `zplane()`：`h = Math.pow(r,n)*Math.cos(th*n)`
  - `名詞與概念字典.html:507`（Z 轉換與單位圓卡，錨定 h[5] = −0.417539）
  - `自我檢核.html` q14-1 題幹 ＋ `app.js:777`（`ans:-0.417539, tol:0.002`）
  - 規格源頭：`BUILD-SPEC.md:857`（`h[n] = rⁿcos(θn)（乘上常數）`）、`:865`、`:875`、`:1279`、§6.3 q14-1
- **原值 → 應為值**：`h[5] = −0.417539` → **`h[5] = −0.835079`**（其餘 h 值連動）
- **證據（我自己跑的，非推論）**：把產品自己在同一段列出的差分方程 `y[n] = 1.272792·y[n−1] − 0.810000·y[n−2] + x[n]` 打入 δ[n]、初始靜止，逐步遞迴得
  `h = 1.000000, 1.272792, 0.810000, 0.000000, −0.656100, −0.835079, −0.531441, 0.000000`
  閉合式 `rⁿ·sin((n+1)θ)/sinθ` 逐項完全吻合。規格採用的 `rⁿ·cos(θn)` 給
  `1.000000, 0.636396, 0.000000, −0.515481, −0.656100, −0.417539, −0.000000, 0.338207`
  兩序列在 n = 1, 2, 3, 5, 6, 7 **全都不同**；spec 的「（乘上常數）」不成立（比值 n=0 為 1、n=5 為 2、n=2 為無限大）。
- **為什麼是必修**
  1. `自我檢核.html` 的 q14-1 與 q14-2 是「承上」連鎖：q14-1 宣稱該極點對的脈衝響應是 rⁿcos(θn)，q14-2 立刻要讀者寫出**同一對極點**的差分方程 —— 同一頁自相矛盾。
  2. ch14「可觀察證據」段明文叫讀者「打一個 δ[n] 進去印出 h[n]」，照做會得到 −0.835079，與課本數字對不上。
  3. `zplane` widget 在同一個 output 區塊同時印出 h[n] 與差分方程，矛盾直接呈現在畫面上。
- **建議修法（須 Lead 先裁決規格）**：改 `h[n] = rⁿ·sin((n+1)θ)/sinθ`（h[5] = −0.835079），\|H\| 與差分方程係數**不動**（已獨立驗證正確），改動面最小；教學論點（r 管衰減、θ 管振盪頻率）完全不受影響。替代方案是把差分方程與 \|H\| 改成含零點 `z = r·cosθ` 的系統，但要改的地方多得多。**連動項：q14-1 的 `ans` 與 `tol=0.002` 要一起改。**

### 7.6 Lead 指定單獨列出的兩項知識錯誤

**（一）字典吉布斯卡的機制句 — `名詞與概念字典.html:211`**

- **原文**：「原因是截斷級數等於在頻域乘上一個矩形窗，時域對應**摺上一個 sinc**，而 sinc 的旁瓣衰減得不夠快。」
- **錯在哪**：截斷傅立葉**級數**是在**離散**諧波序號 k 上乘矩形窗，時域對應的是與 **Dirichlet 核**（週期化的 sinc）`D_N(t) = sin((2N+1)ω₀t/2) / sin(ω₀t/2)` 摺積。純 sinc 是截斷**連續傅立葉轉換**（rect(ω) ⇔ sinc(t)）才會出現的核。本卡講的是第 05 章的週期方波級數，用錯了核。
- **應為值**：「時域對應**摺上一個 Dirichlet 核（週期化的 sinc）**」，或退一步寫「摺上一個**週期化的** sinc」。

- **來源**：`BUILD-SPEC.md` 未規定此機制句（§5 只要求建卡），屬**產品層原生錯誤**，改產品即可，不必動規格。

**（二）相位延遲的符號 — 3 處（2 產品 ＋ 1 規格）**

- **原文**：`名詞與概念字典.html:351`「群延遲 −d∠H/dω 與相位延遲 **∠H/ω** 是兩個不同的量」；`09-濾波器與群延遲.html:58` 同句式；規格 `BUILD-SPEC.md:1004` 與 `:663` 同錯。
