13・DTFT 是理論、DFT 是取樣版、FFT 只是快速演算法

離散頻譜分析：解析度只由窗長決定，其餘都是交換條件

按下「FFT」之後螢幕上那張圖，能看到多細的頻率、為什麼一根線會裂成一團、加窗與零填充各自買到了什麼——這章把三個名字分清楚，並且把每一項都算成具體的數字。這是本課最貼近日常工具的一章。

這章假設已懂：12 取樣與混疊的取樣與頻譜複製、06 傅立葉轉換的頻譜概念，以及工程數學先修的複數與極式。

痛點：DTFT、DFT、FFT 三個名字，工具列上只有一個按鈕

做過訊號分析的人幾乎都遇過同一組挫折。名字先有三個：DTFT、DFT、FFT，課本輪流出現，但軟體只給一顆按鈕，看不出差在哪。接著是解析度：明明取樣率很高，兩根靠得很近的譜線就是分不開，把取樣率再調高也沒用。然後是那個奇怪的現象——訊號頻率稍微動一點點，原本乾淨的一根線就散成一整片裙邊，看起來像壞掉了。

最後是兩個看起來很像的補救動作：加窗與零填充。兩者都會讓圖變好看，但只有一個真的增加了資訊，另一個純粹是內插。分不清楚的人會誤以為「補很多 0 就能看得更細」，然後在報告裡寫下一個根本不存在的頻率差。這章要把每一項都變成可以用滑桿驗證的數字。

白話直覺：頻譜分析是拿一段有限長的錄音去問「裡面有哪些頻率」

訊號從哪裡來？從上一章的 ADC 來，是一串以 fs 取樣的樣本。系統對它做了什麼？其實不是系統做的，是你做的：你從這串樣本裡截一段長度 N 的視窗送進 FFT。這件事在哪個域最好描述？當然是頻率域，但要付出兩個代價：一是輸出只在離散的幾個頻率上有值，二是截斷本身會在頻譜上留下痕跡。換域的代價因此是「看得到頻率、但看不清時間」，而且窗長直接決定了看得多細。儀器量到什麼？頻譜分析儀給你的是每根 bin 的振幅，它量不到 bin 與 bin 之間發生了什麼。

離散時間傅立葉轉換（discrete-time Fourier transform, DTFT）寫成 X(ejω) = ∑n=−∞∞ x[n]e−jωn。它的輸入是離散的無限長序列，輸出卻是連續且以 2π 為週期的函數。這個週期性不是巧合，正是上一章「取樣讓頻譜每隔 fs 複製一份」的直接後果，所以有意義的頻率範圍只有 [−π, π]，對應實際的 [−fs/2, fs/2]。

離散傅立葉轉換（discrete Fourier transform, DFT）寫成 X[k] = ∑n=0N−1 x[n]·exp(−j 2π k n / N)。輸入有限長、輸出離散，這才是電腦真正能算的版本；用軟體的語彙說，它就是一個 N×N 的複數矩陣乘上一個長度 N 的向量。快速傅立葉轉換（fast Fourier transform, FFT）不是第四種轉換，它只是把這個矩陣乘法的對稱性用光的演算法，最有名的是 Cooley–Tukey 蝶形運算，要求 N 是 2 的冪次。

來源：09-信號與系統-下 §11、§12.1–§12.3。

推導：週期性、解析度、洩漏、零填充、運算量

DTFT 為什麼是 2π 週期。把 ω 換成 ω + 2π：e−j(ω+2π)n = e−jωne−j2πn。因為 n 是整數，第二項恆等於 1，所以 X(ejω) 的值原封不動。換句話說，離散時間的頻率本質上只有一個 2π 寬的範圍，超出去的都是同一件事重複——這正是上一章混疊的頻域說法。

解析度 Δf 的來歷。N 點樣本涵蓋的實際時間是 Twin = N/fs 秒。要分辨兩個頻率相差多少，最起碼要能在這段時間內看到它們之間的一個完整拍差，也就是「一個週期剛好塞滿這個窗」，於是最小可分辨的頻率差是 Δf = 1/Twin = fs/N。第 k 根 bin 的中心頻率是 k·Δf。解析度只由窗長決定，跟你用什麼演算法、補多少 0 都無關。

為什麼會洩漏。DFT 隱含一個假設：這 N 點就是一個週期，前後無限重複。若訊號在窗內不是整數個週期，把窗尾接回窗頭時會出現一個跳躍；跳躍在頻域是寬頻的，能量因此散到鄰近所有 bin，這就是譜洩漏（spectral leakage）。加窗（windowing）的做法是先把序列乘上一條兩端平滑歸零的曲線（Hann、Hamming、Blackman），接縫消失，裙邊跟著下降；代價是主瓣變寬，也就是解析度變差。

為什麼零填充不增加解析度。零填充（zero-padding）是把 N 點補 0 到更長再做 FFT。補進去的 0 不含任何觀測資訊，有效的 Twin 完全沒變，所以 1/Twin 也沒變。它做的事是在同一條 DTFT 曲線上多取幾個樣本點，屬於內插；圖會變平滑、峰值位置讀起來更順眼，但兩根本來分不開的線還是分不開。

運算量。直接算 DFT 要做 N 次求和、每次 N 項，共 N² 次複數乘法。基 2 FFT 遞迴地把長度對半拆，共 log2N 層、每層 N/2 個蝶形，因此是 (N/2)log2N 次。兩者相除就是加速倍率，N 愈大差距愈懸殊。

邊界對照：f = 1010 Hz → 精確位置 129.280000、最近 bin k = 129（中心 1007.812500 Hz）、誤差 2.187500 Hz → 有洩漏，能量散到鄰近 bin。N = 256（28）→ Δf = 31.250000 Hz、Twin = 0.032000 s、加速 64.000000 倍（窗短了 4 倍，解析度就差 4 倍）。N = 16384（214）→ Δf = 0.488281 Hz、Twin = 2.048000 s、加速 2340.571429 倍（要看得細就得等得久，這是硬性交換）。N = 16 → Δf = 500.000000 Hz、加速只有 8.000000 倍（小 N 時 FFT 的優勢不明顯）。零填充 1024 → 4096：顯示間隔從 7.812500 Hz 變成 1.953125 Hz，但 Twin 仍是 0.128000 s，真正的解析度沒有改變。

量級對照：N = 1024 配 fs = 8000 Hz 就是 0.128 秒的窗，Δf = 7.8125 Hz；要達到 1 Hz 的解析度就得量滿 1 秒，要分辨市電 50 Hz 與 51 Hz 也是同一個代價。CD 的 44100 Hz 配 1024 點則是 0.023 秒的窗、Δf 約 43 Hz——同樣的點數，取樣率愈高解析度反而愈粗。

自由實驗：把窗長、訊號頻率與窗形分開調整

取一段長度 N ＝ 2 的某個次方的樣本，取樣率 fs，裡面有一個頻率 f 的弦波，再選一種窗。要看三件事：這個 f 有沒有落在 bin 中心（決定會不會洩漏）、窗長換來多少解析度、以及選的窗把旁瓣壓低了多少、主瓣又賠掉多寬。

N = 1024，Δf = 7.812500 Hz，窗長 0.128000 s；精確 bin 位置 128.000000，最近 bin k = 128（中心 1000.000000 Hz），誤差 0.000000 Hz。N² = 1048576 次複數乘法，(N/2)log2N = 5120 次，加速 204.800000 倍。整數週期，無洩漏：訊號頻率正好落在第 128 根 bin 的中心，窗內剛好裝 128 個完整週期，頭尾接得上，能量集中在一根線上。解析度只由窗長決定：Δf = 1/Twin。要分辨相差 1 Hz 的兩根線，就得量滿 1 秒，沒有捷徑。選了 Hann 窗：主瓣 4 個 bin（＝31.250000 Hz，解析度變差），最高旁瓣 −31.5 dB（洩漏被壓低）。沒有一個窗兩邊都贏。把 N 補 0 到兩倍只會讓譜線看起來更密（內插），Twin 沒變，真正能分辨的最小頻率差完全不變。量級對照：N = 1024、fs = 8000 就是 0.128 秒的窗，Δf = 7.8125 Hz；要達到 1 Hz 解析度得量滿 1 秒。把點數指數滑到 4 會看到加速只剩 8.000000 倍，N 小的時候 FFT 沒什麼好處；把 f 推過 fs/2 則要先回第 12 章處理混疊。

不要混淆

  • DTFT、DFT、FFT 是三件事。DTFT 是理論，輸出連續；DFT 是它在頻率軸上的取樣版，輸出離散；FFT 只是算 DFT 的快速演算法，不是另一種轉換，算出來的數字與直接 DFT 完全相同。
  • 「解析度」與「顯示點的密度」不同。前者由窗長 Twin 決定，後者可以靠零填充任意加密。圖上點很多不代表你分得開兩根線。
  • 加窗不是「讓訊號變好看」。它是一筆明碼標價的交易：主瓣變寬（解析度變差）換旁瓣變低（洩漏變小），rect 與 blackman 分別站在這條軸的兩端。
  • bin 中心頻率 k·fs/N 與訊號的真實頻率不一定相等。用 FFT 直接讀頻率天生有 ±Δf/2 的量化誤差，要更準得對峰值附近做內插估計。
  • 提高取樣率不會提高頻率解析度。Δf = fs/N，fs 變大而 N 不變時 Δf 反而變粗；真正有用的是把 N 加大，也就是量久一點。

可觀察證據：拿什麼量、量到什麼

這一章不需要特殊設備，任何頻譜分析軟體或示波器的 FFT 功能都能直接重現。用函數產生器輸出一個乾淨的正弦波，先把頻率調到剛好落在 bin 中心，畫面上是一根細線；再把頻率慢慢往旁邊移幾 Hz，會親眼看到那根線裂成一團裙邊，而訊號本身一點都沒變。接著切換窗函數，裙邊的高度會整片跟著升降，主瓣的胖瘦也同時改變——那就是上面那張表在畫面上的樣子。最後把 FFT 點數從 1024 改成 16384，會看到峰值變窄、更新速度變慢，因為每張圖要等 2.048 秒的資料。

能證明什麼：Δf 與窗長成倒數的關係、洩漏確實存在且與「是否整數週期」有關、不同窗的旁瓣高度差異、FFT 相對於直接 DFT 的加速。

不能證明什麼：兩根靠得比 Δf 還近的譜線是不是「其實有兩根」。這是解析度的物理極限，不是儀器不夠好，換更貴的機器、補更多 0 都沒用，唯一的辦法是量久一點。也證明不了訊號的相位是否穩定——單張 FFT 只是一個快照，要看穩定性得連續算很多張再比較。

連到哪門課

連續版的傅立葉轉換與矩形對 sinc 的轉換對見本課06 傅立葉轉換；離散頻譜為什麼是週期的，根源在12 取樣與混疊的頻譜複製。式子裡 exp(−j 2π k n / N) 的複數運算、極式與尤拉公式見工程數學先修的複變入門。FFT 的蝶形細節與定點量化誤差留給數位訊號處理專科。真實裝置這一側，音訊軟體的頻譜圖、振動診斷的階次分析、通訊接收機的載波搜尋，用的都是本章這幾個數字。下一章要把 DFT 的頻率軸捲成一個圓，讓第 07 章的極點觀點整套搬到離散世界。
