12・兩個世界的橋，也是全課唯一不可逆的一步

取樣與混疊：取樣率不夠不是變差，是變成另一個頻率

前十一章丟掉的東西都還救得回來，這一章不行。取樣把連續曲線換成一串數字，若取樣率不夠，兩個不同頻率會產生一模一樣的樣本，事後任何演算法都分不出來。這章把這件事算成一個具體的頻率。

這章假設已懂：11 離散時間訊號與差分方程的 x[n] 與樣本序號、06 傅立葉轉換的頻譜與相乘定理，以及工程數學先修的傅立葉分析。

痛點：「取樣率要大於兩倍」這句口號背後到底發生了什麼

取樣定理是全世界最常被背誦、最少被理解的一句話。多數人記得「兩倍」這個數字，卻答不出三個問題：為什麼剛好是兩倍而不是三倍或十倍？不夠的時候會發生什麼，是雜訊變大、波形變醜，還是別的？既然事後可以用很強的數位濾波器處理，為什麼一定要在類比端先放一顆抗混疊濾波器？

第三個問題最要命，因為它的答案違反軟體工程師的本能。寫程式的人習慣「先把資料收進來，之後再慢慢處理」，但取樣是唯一一個資訊真的離開系統的環節：混疊之後的樣本，與另一個頻率產生的樣本逐位元完全相同，沒有任何殘留線索可以還原。這章要把那組相同的樣本直接列出來給你看。

白話直覺：每隔固定時間拍一張快照，快門太慢就會拍出倒轉的輪子

訊號從哪裡來？從麥克風、天線或感測器來，它是一條連續曲線 x(t)。系統對它做了什麼？取樣器每隔 Ts 秒讀一次值，得到 x[n] = x(nTs)；中間發生的事完全沒被記錄。這件事在哪個域最好描述？時間域只看得到一堆點，看不出問題；換到頻率域，取樣的作用變得極為乾淨——原頻譜每隔 fs 複製一份。換域的代價是必須接受「複製品會互相重疊」這個純頻域的說法，而且重疊之後就分不開了。儀器量到什麼？頻譜分析儀會在混疊後的位置量到一根紮實的譜線，它看起來和真訊號毫無差別。

可以暫時把取樣想成拍電影：快門每秒開 24 次，輪子若轉得比快門快，螢幕上就會看到輪子倒著轉。比喻到此為止，精確的說法是：混疊（aliasing）不是誤差也不是雜訊，而是高於 fs/2 的成分被確定性地對映到 [0, fs/2] 裡的另一個頻率上，這個新頻率叫視在頻率 fa。

取樣（sampling）的理想模型是 x[n] = x(nTs)，Ts = 1/fs（單位 s），假設取樣瞬間完成、時間點完全準確。取樣定理（Nyquist–Shannon sampling theorem）說：若 x(t) 的頻寬是 W（Hz，指最高頻率成分），且 fs > 2W，則這串樣本足以完美還原原訊號。fN = 2W 叫奈奎斯特速率，是訊號的性質；fs/2 叫奈奎斯特頻率，是取樣系統的性質。兩者中文常被混為一談，看到這個詞務必先問「講的是訊號還是取樣器」。

來源：09-信號與系統-下 §14.1–§14.4。

推導：從頻譜複製到不可逆，再到 DAC 的下垂

為什麼取樣會讓頻譜週期化。理想取樣等於把 x(t) 乘上一列間隔 Ts 的脈衝串。第 06 章的相乘定理說時域相乘對應頻域摺積，而脈衝串的頻譜還是脈衝串（間隔 fs）。與一列脈衝摺積等於把原頻譜搬到每根脈衝的位置各放一份，於是取樣後的頻譜就是原頻譜每隔 fs 複製一份，無限延伸。

混疊條件。原頻譜佔 [−W, W]，第一份複製品佔 [fs − W, fs + W]。兩者不重疊的條件是 W < fs − W，也就是 fs > 2W。「兩倍」這個數字就是這樣來的——它不是經驗值，是兩段區間不相交的幾何條件。

不可逆的那一行。取 fs − f 這個頻率的餘弦，在取樣點上算一次：cos(2π(fs − f)nTs) = cos(2πn − 2πfnTs) = cos(2πfnTs)。中間那步用到 n 是整數所以 2πn 可以整個丟掉，最後一步用到餘弦是偶函數。結論是 f 與 fs − f 這兩個不同的訊號，在所有取樣點上給出完全相同的數值。既然樣本一模一樣，就不存在任何演算法能把它們分開——這一行就是混疊不可逆的全部理由。推廣到任意 k 便得視在頻率 fa = |f − k·fs|，k 取最接近 f/fs 的整數。

還原與 ZOH。理想還原是 sinc 內插 x(t) = ∑n x[nTs]·sinc((t − nTs)/Ts)，其中 sinc(x) = sin(πx)/(πx)、sinc(0) = 1（本課全程用這個歸一化版本，有些教科書寫 sin(x)/x，兩者的零點位置不同，不可混用）。這條式子不可實現，因為 sinc 無限長且非因果。實務用零階保持（zero-order hold, ZOH）：把每個樣本撐成寬 Ts 的方塊，等於與寬 Ts 的矩形摺積，再由第 06 章「矩形 ⇔ sinc」直接得到 |HZOH(f)| = |sinc(f/fs)|。它在高頻造成可預期的衰減，稱為下垂（droop），因為完全可算，所以能事後用數位等化補回來。

臨界點為什麼危險。f 恰為 fs/2 時，取樣點每半個週期落一次；相位若剛好對準零交越，量到的會是一整排 0，訊號完全消失。定理寫的是 fs 嚴格大於 2W，等號不算數。完整鏈因此是：類比 → 抗混疊濾波 → ADC → 數位處理 → DAC → 重建濾波 → 類比。

量級對照：電話系統用 8000 Hz 取樣，所以只留 3400 Hz 以下的語音，s 與 f 這兩個高頻擦音因此聽起來很像；CD 用 44100 Hz，剛好讓 20000 Hz 的人耳上限留有餘裕；專業錄音用 48000 Hz。至於市電 50 Hz，用 8000 Hz 取樣等於一個週期取 160 點，遠遠過剩。

自由實驗：把訊號頻率推過奈奎斯特頻率

一個振幅 A 的餘弦訊號以 fs 取樣，觀測第 n 個樣本。把 f 慢慢往上推過 fs/2，看視在頻率怎麼折返、前六個樣本何時與較低頻率的那一組重合，以及 ZOH 的高頻衰減有多嚴重。

Ts = 1.250000 × 10−4 s＝125.000000 µs；奈奎斯特頻率 4000.000000 Hz；視在頻率 3000.000000 Hz；第 3 個樣本 0.707107 V。前 6 個樣本：1.000000、−0.707107、0.000000、0.707107、−1.000000、0.707107。ZOH 衰減 0.784213（−2.111316 dB）。沒有混疊：f = 3000.000000 Hz < fs/2 = 4000.000000 Hz，這些樣本足以完美還原原訊號（理論上用 sinc 內插）。取樣把頻譜每隔 fs 複製一份；fs 不夠大時複製品的裙邊互相重疊，重疊的部分就永遠分不開了。DAC 用零階保持把樣本撐成方塊，等於與一個寬 Ts 的矩形摺積，所以高頻被 sinc 壓下去（現在是 −2.111316 dB）——這叫 droop，可以事後用數位等化補回來。量級對照：電話 8000 Hz、CD 44100 Hz、專業錄音 48000 Hz；電話只留 3400 Hz 以下的語音，所以聽不出 s 與 f 的差別。把 f 推到 5000 Hz 就會看到視在頻率掉回 3000.000000 Hz 而樣本一字不差；把 n 滑到 0，樣本恆為 A，任何頻率皆然。

不要混淆

  • 奈奎斯特速率（2W，訊號的性質）與奈奎斯特頻率（fs/2，取樣系統的性質）是兩個不同的量，中文卻常常都叫「奈奎斯特頻率」。看到這個詞先確認在講哪一個。
  • 混疊不是「訊號變差」，而是「變成另一個頻率」。它不是雜訊，是完全確定性的假訊號，取樣一百次會得到一百次相同的結果。
  • 抗混疊濾波器（anti-aliasing filter）一定裝在 ADC 之前的類比域。數位濾波器再強也只能處理已經進來的樣本，而該丟的資訊在取樣那一刻就不在樣本裡了。
  • 提高取樣率能把混疊推遠，但不能取代抗混疊濾波器。世界上永遠有比你的 fs/2 更高頻的東西——射頻干擾、開關電源的切換雜訊——它們照樣會折回來。
  • ZOH 的下垂與混疊是兩回事。下垂是可算、可補償的振幅誤差，混疊是不可逆的頻率錯位；把 droop 補平不會讓混疊消失。

本章的損失是不可逆的：一旦取樣率不足，資訊就不在樣本裡了，再貴的 DSP 也救不回來。這是整門課唯一一個「做錯就沒救」的環節。

可觀察證據：拿什麼量、量到什麼

把 5000 Hz 的正弦波送進一台 8000 Hz 取樣的擷取卡，對取到的樣本做 FFT，會在 3000 Hz 看到一根紮實的譜線——而且它和真的 3000 Hz 訊號所產生的譜線長得一模一樣，高度、寬度、相位全都對得上。老式數位示波器在取樣率不足時也很容易重現這件事：螢幕上會出現一條緩慢飄移的低頻波，看起來很乾淨，其實整條都是假的。把抗混疊濾波器接上去再量一次，那根線就消失了。

能證明什麼：混疊之後的視在頻率是多少、抗混疊濾波器裝上去之後假線是否消失、ZOH 造成的高頻衰減有多少 dB（用網路分析儀掃 DAC 的輸出即可）。

不能證明什麼：眼前這根譜線「是真的還是混疊來的」。單靠一次量測絕對分不出來，因為兩者的樣本完全相同。標準做法是改變 fs 再量一次：真訊號的頻率不會動，混疊來的假線會跟著 fs 跑。也證明不了「訊號頻寬確實低於 fs/2」——你的量測系統本身就是用同一個 fs 取樣的，它看不見自己看不見的東西。
