# 電機核心

本目錄是電機[學習計畫](../學習計畫.md)的第二階段：大學電機系必修的八門核心科目（06–13）。數理先修見 [共通基礎](../../共通基礎/README.md)，核心名詞收錄於 [中英名詞對照表](../中英名詞對照表.md)。

風格與其他學科一致：繁體中文、概論重點式、以文字為主不放圖、公式使用 LaTeX。多數科目另有零基礎互動課，把筆記重寫成可操作的章節頁，附名詞字典與自我檢核。
