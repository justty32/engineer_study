06・增益一轉，三個極點沿規則移動

06 根軌跡：從三個起點追到虛軸穿越

在 L(s) = K / (s(s + 2)(s + 4)) 中，K ＝ 10 時三個根是 −4.760818 與 −0.619591 ± j1.310186；K 增至 48.000000，共軛對正好抵達虛軸。本章不用畫圖，改用座標與階段表讀完整路徑。

這章假設已懂：05 Routh 穩定度判別的虛軸穿越，以及04 二階閉迴路與極點位置的 ζ。前置：見〈08 極零點與二階系統〉信號與系統的極零點與二階系統，ζ 與極點的公式已在該頁證明。

痛點：我只轉一個 K，三個根為什麼走不同方向

直接代入某一個增益，只能得到三個孤立座標；它沒有回答下一格增益會把哪一個根推向哪裡，也看不出「開始振盪」與「開始發散」其實是不同時刻。工程上真正關心的是整條參數路徑：哪裡分離、阻尼比 ζ 如何下降、何時碰到虛軸，以及還能把 K 加到多大。

根軌跡（root locus）把特徵方程式 1 + KP(s) = 0 的根，依 K 從 0 增到 ∞ 排成軌跡。它的起點是 K ＝ 0 時的開迴路極點，終點是開迴路零點或無窮遠；因此它畫的是閉迴路極點的位置，不是輸出波形。

只靠「增益越大、反應越快」這句話會漏掉最重要的代價。K 增加初期，靠近原點的實極點向左移，慢模態確實加快；兩個實根相遇後卻離開實軸，開始形成振盪。再繼續增加，這對根的實部向右移、ζ 下降，最後穿越虛軸。速度、振盪程度與穩定範圍不能各自獨立調整，必須放在同一條參數路徑上比較。

白話直覺：三名旅客沿固定出口離站

可以暫時把三個極點想成旅客：由 0、−a、−b 三個月台出發，最後沿三個出口離開；比喻到此為止。精確規則是軌跡必須同時滿足角度與增益條件；沒有零點時，三條分支都走向無窮遠，其漸近角固定為 ±60° 與 180°。

因果鏈從參考命令開始：誤差由比例增益 K 放大，控制量 u 送入受控體，K 只改變特徵多項式常數項，三個閉迴路極點便沿軌跡移動。K 小時有三個實根，輸出不振盪；過了分離增益 Kb 後出現共軛對，ζ 逐漸下降，超越程度增加；K 到 Kcrit 時實部成為 0，示波器量到等幅振盪；再加大便進入右半平面。

這件事在你的程式裡長什麼樣：先用封閉公式算重心、分離點與臨界值，再用牛頓法找最左實根，將三次式降成二次式求共軛對，最後依 K 所在區間產生判讀。

來源：13-控制系統 §5.3；畫法規則為本課補上。

推導：從特徵式得到重心、分離點與臨界值

特徵多項式。L(s) = K / (s(s + a)(s + b)) 配單位回授時，1 + L(s) = 0，整理為 s3 + (a + b)s2 + abs + K = 0。K ＝ 0 時根是 0、−a、−b。實軸上一點若位於軌跡，該點右側的實極點與實零點總數必為奇數；當 0 ＜ a ＜ b，區段 (−a, 0) 與 (−∞, −b) 在軌跡上，(−b, −a) 不在。

漸近線。極點數 n ＝ 3、零點數 m ＝ 0，所以有 n − m ＝ 3 條。重心 σ = (Σ極點 − Σ零點) / (n − m) = (0 − a − b) / 3；角度是 (2k + 1) × 180° / 3，整理為 ±60° 與 180°。兩條漸近線朝右，說明 K 持續變大後必有兩根進入右半平面。

分離點。沿實軸把 K 寫成 K = −s(s + a)(s + b)，對 s 微分得 dK / ds = −(3s2 + 2(a + b)s + ab) = 0。兩個候選根中，只取落在 (−min(a, b), 0) 的根 sb；再代回原式得到 Kb。

虛軸穿越。沿用上一章，三階 Routh 的 s1 列在 (a + b)ab − K = 0 時成為零，因此 Kcrit = ab(a + b)。輔助多項式是 (a + b)s2 + Kcrit = 0，所以 ωcrit = √(ab)。任一 K 的主導共軛對若寫成 Re ± jIm，阻尼比 ζ = −Re / √(Re² + Im²)。a、b 的單位為 1/s，K 為 1/s³，角度用度；假設 K ≥ 0 且沒有零點。本課用的是教學用的簡化模型，真實系統不是這樣：額外極點、零點、延遲與飽和都會改變路徑。

四段判讀。K ＜ Kb 時有三個實根；Kb ＜ K ＜ Kcrit 時是一個實根加一對共軛根；K ＝ Kcrit 時共軛對在虛軸；K ＞ Kcrit 時其實部為正。若 b 小於 a，名稱次序改變但數學不變，分離點仍取落在 (−min(a, b), 0) 的候選根，不能僵硬地只檢查 (−a, 0)。

任一 K 的座標。數值程式先在最左側搜尋三次式的實根，以牛頓法反覆修正到收斂；再用已知實根將三次式除成二次式，由判別式取得另外兩根。判別式大於或等於零時得到三個實根，小於零時得到共軛對。這個求根步驟只負責回報座標，軌跡規則仍由上述解析式決定。

自由實驗：用三個數字追蹤極點

受控體有三個開迴路極點 0、−a、−b，比例控制器只改 K。調整極點距離與增益，觀察重心、分離點、臨界值、三根座標及主導對 ζ 如何一起變。

不要混淆

  • 根軌跡是閉迴路極點隨 K 的路徑；只有 K ＝ 0 的起點等於開迴路極點。
  • 分離點表示兩個實根合併後成為共軛對，亦即開始振盪；它不是開始不穩定的點。
  • 漸近線重心是極點和與零點和之差除以分支數，不是物體的質心，也不一定有根停在那裡。
  • Kcrit = ab(a + b) 與上一章 Routh 算出的臨界增益是同一件事；兩種方法若不一致，應先查公式或數值程式。

可觀察證據：逐步增益與方波測試

用什麼量。把比例增益由小到大逐步增加，每一步輸入一次方波，以示波器記錄是否超越、振盪週期與是否衰減。先是不超越的三實根響應，再出現衰減振盪，最後於某個 K 形成等幅振盪。

能證明什麼。量測能確認分離與臨界兩個轉折存在，並取得 Kcrit 與 ωcrit 的實際值。不能證明什麼。只看波形不能得到三個極點的精確座標；由 Mp 與 tp 反推的也只是主導對，且不能證明受控體真的沒有零點。
