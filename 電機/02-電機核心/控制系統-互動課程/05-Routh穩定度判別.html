05・不解根也能數出危險極點

05 Routh 穩定度判別：把高階求根改成逐列交叉相乘

一個係數全為正的四階多項式，仍可能有 2 個右半平面極點。本章用固定規則填表，直接從第一欄的符號變化判斷結果，並處理首元為零與整列為零兩個邊界。

這章假設已懂：02 方塊圖化簡與閉迴路轉移函數的特徵方程式。前置：見〈07 拉氏轉換與轉移函數〉信號與系統的極點判準，極點為何決定響應已在該頁證明，本章不重推。

痛點：係數都正，為什麼還可能越跑越遠

看到 s4 + 2s3 + 3s2 + 4s + 5，每一項都沒有負係數，很容易直覺認定它安全。然而「係數全同號且沒有缺項」只是必要條件，不是完整保證。真正要判斷的是每一個根的實部是否小於零；四階以上若直接求根，手算既長又容易失去結構。

另一個痛點是參數 K。設計時通常不是只問某一個 K 能不能用，而是要找出整段允許範圍。若每換一次 K 就重解全部根，既慢也看不出臨界點為何出現。Routh–Hurwitz 準則（Routh–Hurwitz criterion）正是把這兩個問題改寫成係數表格。

判別結果還必須區分三種狀態：所有根都嚴格位於左半平面才是穩定；有根落在右半平面就是不穩定；根剛好落在虛軸則是臨界情形。最後一種雖然沒有立即增長，卻不會自行衰減，實際裝置受到雜訊、摩擦與限幅後也不會永遠維持理想弦波。因此「符號變化 0 次」之外，還要檢查是否出現全零列。

白話直覺：只看守門員換邊幾次

可以暫時把表格第一欄想成一排守門員：符號每換一次方向，就有一個根越過到右半平面；比喻到此為止。精確說法是，Routh 定理保證第一欄由上而下的符號變化次數，等於右半平面根的個數，這不是圖形猜測。

因果鏈要完整看：參考命令進入回授迴路，誤差經控制器放大成控制量 u，控制量送進受控體；增益改變特徵多項式的係數，閉迴路極點因此被搬動。右半平面極點數若由 0 變成 2，輸出會由收斂轉成增長振盪，示波器最後常看到飽和或撞到限制。Routh 表告訴我們轉折發生在哪個係數組合，卻不提供極點座標。

這件事在你的程式裡長什麼樣：建立一個確定性的二維陣列，先交錯放入係數，再用上一列與上上列交叉相乘，逐格填到常數列，最後只掃第一欄計數。

來源：13-控制系統 §3.1、§3.2。

推導：四階表、三階範圍與兩個特殊情形

一般四階。令特徵多項式為 a4s4 + a3s3 + a2s2 + a1s + a0。前兩列交錯填成 s4 列 [a4, a2, a0] 與 s3 列 [a3, a1, 0]。接著 b1 = (a3a2 − a4a1) / a3，b2 = (a3a0 − a4 × 0) / a3 = a0；下一列 c1 = (b1a1 − a3b2) / b1，最後 d1 = b2。第一欄全同號才有 0 個右半平面根。

三階參數。對 s3 + a2s2 + a1s + a0，全部係數必須大於 0，且 a2a1 ＞ a0。套進 s3 + 3s2 + 3s + K，s1 列是 (9 − K) / 3，因此允許範圍是 0 ＜ K ＜ 9。K ＝ 9 時整列為零，上一列形成輔助多項式 3s² ＋ 9 ＝ 0，得到 ±j√3。

首元為零。某列第一格是零、後面卻不是零時，用極小正數 ε 暫代首元。當 ε → 0+，下一列可能出現負的極大數，仍照其符號計數。若整列為零，則由上一列係數建立輔助多項式，對它微分後填回；這代表存在關於原點對稱的根。

讀表順序。先確認最高次係數非零；若全部係數皆負，可整個多項式同乘 −1，根的位置完全不變。接著檢查係數是否同號與有無缺項，這一步只會提前指出必要條件失敗，不能取代建表。表格完成後由上往下忽略數值大小，只記每次正負切換；遇到零首元或全零列，必須先依上述規則補正再計數。

充分必要條件必須說完整：在沒有虛軸根的前提下，第一欄所有非零元素同號，才代表全部根都位於左半平面。若表中出現全零列，即使補列後沒有符號變化，也只能判為至多臨界，不能直接把它和會衰減的情形放在一起。

符號、單位與假設。a4 到 a0 是特徵多項式係數，依原物理模型可帶不同單位；本頁為判別方便視為已正規化。ε ＝ 10−6 是教學取值，根的數量不應依其精確大小改變。本課用的是教學用的簡化模型，真實系統不是這樣：飽和、延遲與未建模動態都可能讓實測提早偏離。

邊界對照：s3 + 3s2 + 3s + 10 的 s1 列是 −0.333333，有 2 次變化；常數改為 8 時該格為 0.333333，變化 0 次；改為 9 時以導數 6s 補列，第一格為 6.000000，並有虛軸極點 ±j1.732051。另取 s4 + s3 + 2s2 + 2s + 3，ε 法得到 2 − 3 / ε ≈ −2.999998 × 106，仍是 2 次變化。

自由實驗：逐格建立 Routh 表

選三階或四階，再改各項係數。輸出會列出完整表格、第一欄、符號變化與特殊情形；這是係數判別器，不會顯示根的座標。

不要混淆

  • Routh 表只告訴你右半平面有幾個極點，不告訴你它們的精確位置；要座標仍需數值求根。
  • 係數全正只是必要條件；本章預設多項式的係數全正，第一欄仍有 2 次符號變化。
  • 整列為零不必然等於發散；它指出有關於原點對稱的根，常見情形是一對純虛根與等幅振盪。
  • ε 法是維持除法可算的極限技巧，不是替模型加入真的小係數；必須取 ε → 0+ 來讀符號。

可觀察證據：示波器量臨界增益與頻率

用什麼量。在具有安全限幅的實驗台上逐步增加比例增益，以示波器觀察輸出。當衰減振盪轉為等幅振盪，記下增益與振盪頻率；前者應對上表格算出的臨界增益，後者應對上輔助多項式的純虛根。

能證明什麼。它能驗證臨界增益與臨界頻率的實際值，也能揭露真實元件讓臨界點偏移多少。不能證明什麼。它不能從飽和波形分辨右半平面究竟有一個還是兩個極點，也不能證明所有未測增益都符合簡化模型。

連到哪門課

極點與連續系統判準見信號與系統的拉氏轉換與轉移函數；離散系統改看單位圓，入口在Z 轉換與單位圓。馬達控制與電力轉換器設計常先用這張表圈出可用增益，再以時域量測縮小範圍。下一章會把 K 從 0 增加到臨界時，極點走過的整段路徑攤開來看。
