3. **公式一律純文字 HTML，嚴禁 LaTeX**：不得出現 `\(` `\)` `\[` `\]` `$` `$$`，不得引入 MathJax／KaTeX。轉寫規約見第 3 節。
4. **`<option>` 內只能放純文字**。`<option>` 與自我檢核選項的顯示文字**不得含 `<sub>`／`<sup>`／任何標籤**，一律用底線寫法：`K_p`、`K_v`、`omega_n`、`t_s`。**Unicode 字元（ζ、ω、τ、²）例外允許**，因為它們不是標籤。
5. **禁止 `Math.random()`**。所有結果必須可重現。禁止 `setTimeout` 動畫、`localStorage`、`fetch`、`document.write`。**禁止 `Date`。**
6. **每頁 UTF-8（無 BOM）**，`<html lang="zh-Hant">`，`<meta charset="utf-8">`。**行尾一律 CRLF**（`\r\n`；作者寫 LF 也可以，Lead 收尾會位元組級正規化）；**`styles.css` 例外，不得轉**。

8. **不得修改 `電機/02-電機核心/*.md`、`電機/中英名詞對照表-2.md`** 或任何本資料夾以外的檔案。本案只新增本資料夾內的檔。

10. **HTML 頁面不連 `.md` 檔**。來源以文字標註（例：「來源：13-控制系統 §3.2」），且一律寫**筆記的章號（1–9）**，不得寫成本課章號（00–11）。
11. **每章正文（不含 `section.workspace` 內容與 `nav`）1800–2600 個中文字**（計法＝漢字＋全形標點）。低於 1800 視為未完成，高於 2600 要拆段但不得刪推導。
12. **不畫圖**。步階響應、根軌跡、波德圖、奈奎斯特圖一律用表格、數值與判讀句替代。

規則：

- 頁面自己那一項在 `topbar` 加 `aria-current="page"`（章節頁只有 00 會標在「00 起點」上；01–11 不標）。
- **七段教學骨架每章都要有**，`h2` 順序固定，且 `h2` 文字必須以「痛點：」「白話直覺：」「推導：」「數值實例：」「不要混淆」「可觀察證據：」「連到哪門課」開頭（verifier 用這七個前綴機械檢查）：
  1. **痛點** — 讀者原話的 why（例：「我把增益調高，穩態誤差變小了，為什麼系統反而開始晃？」），不可寫成考綱標題。
  2. **白話直覺** — 比喻只能出現一次且立刻收回精確定義；本段必須走完一次 principles-first 因果鏈：`命令從哪來 → 誤差怎麼被放大 → 控制量往哪裡去 → 極點被搬到哪 → 指標變成多少 → 儀器量到什麼`。
  3. **推導** — 關鍵步驟寫出來，不可只給結論。每個公式要標明每個符號的意思、單位與假設，且必須明說「本課用的是教學用的簡化模型，真實系統不是這樣」。**既有課已推導的公式只引用，不重推。**
  4. **數值實例** — 數字必須與該章互動元件的預設值**完全一致**，且照本規格第 4 節逐字照抄，**不得自行重算或改寫**。每章至少一個 `<table>` 列出「量／算式／結果」。
  5. **不要混淆** — `<ul>` 至少 4 條，每條指出**邊界**而非同義詞。
  6. **可觀察證據** — 至少一種工具、量到什麼、**能證明什麼、不能證明什麼**（三者缺一不可）。
  7. **連到哪門課** — （a）這章在哪個真實裝置或哪門後續課用到；（b）附 PROJECT-BRIEF 第 8 節指定的跨課相對連結。

- 術語首次出現寫 `繁中（English, 縮寫）`。
- 每章正文至少標註一次來源，格式：`<p class="note">來源：13-控制系統 §3.2。</p>`。
- **每章必須有一句「這件事在你的程式裡長什麼樣」**（放在白話直覺或推導段皆可）。

### 2.3 `workspace` 統一格式

```html
<section class="workspace"><h2>自由實驗：實驗名</h2>
<p>先用兩三句把場景講完（受控體是什麼、控制器長什麼樣、要看什麼）。</p>
<div class="controls">
  <label for="控制id">控制名（單位）<input id="控制id" type="range" min=".." max=".." step=".." value=".."></label>
  <label for="選擇id">選擇名<select id="選擇id"><option value="v1">顯示文字</option></select></label>
  <label for="數字id">數字名<input id="數字id" type="number" step=".." value=".."></label>
</div>
<div id="XXX-output" class="output" aria-live="polite"></div>
</section>
```

- 每個控制都必須包在 `<label for="…">` 裡。`number` 型控制的 `<input>` 放在 label 文字之後。
- `output` 一律 `class="output"` ＋ `aria-live="polite"`，**HTML 內留空**（由 `app.js` 進頁面時填入）。
- **每章只有一個 `section.workspace`。**
- 回饋內容必須包含四件事：**目前算出的數值**（`<table>`）、**判讀句**（`<strong>` 起頭，例「判讀：閉迴路極點已跨到右半平面，系統不穩定」）、**為什麼**（一句因果句，以「為什麼：」起頭）、**邊界提醒**（推到極端值時要換一段文字）。
- 進頁面就要先跑一次，`output` 不得留白。
- **模式切換型 widget（有 `select` 決定用哪些控制）必須在回饋開頭寫一句「這個模式只用到 X、Y，其餘控制不影響結果」**。本課有 4 個模式型 widget：`block`（`bk-config`）、`sserr`（`se-type`、`se-input`）、`lead`（`ld-type`）、`state`（`ss-preset`，預設會改寫數字欄位）。
- **數值格式**：時間、增益、比例一律 6 位小數（helper `num6`）；角度 6 位小數加 `°`；百分比 `<數字> %`；絕對值大於 10<sup>6</sup> 或小於 10<sup>−6</sup>（非零）時用科學記號 `m × 10<sup>e</sup>`（helper `sci`）；無限大寫「∞（無限大）」；不適用寫「不適用」。**任何情況下不得出現 NaN、Infinity、undefined、null 字樣。**

## 3. 公式與符號轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。不要用 Unicode 下標數字（₀₁₂）。上標 `²` `³` 例外允許。

### 00 `00-回授的價值.html`

**目標**：用一個沒有動態的靜態模型，把「回授買到什麼、付出什麼」講成三個數字：迴路增益 L、靈敏度 S ＝ 1 / (1 + L)、以及開迴路與閉迴路面對增益漂移與干擾時各自的誤差。讀者看完要能說出：回授不是免費的——模型準、沒干擾時開迴路反而更準；回授買到的是「對不準的模型與外來干擾不敏感」，代價是需要高增益，而高增益在有動態的系統會惹出穩定度問題（後面整門課都在處理這件事）。

**要點**：控制系統在做什麼（把動態系統的行為塑造成想要的樣子：追蹤、穩定、抗干擾、夠快）；開迴路（open-loop）＝命令直接進受控體、不看結果；閉迴路（closed-loop）＝量輸出、與命令比較、用誤差驅動受控體；四個角色 r、C、G、H、y 與誤差 e ＝ r − y；受控體（plant）這個譯名的裁決；四類性能指標（暫態、穩態、穩定度、強健）只在這章列表點名，各自在哪一章展開。**前置：什麼叫系統，見既有課〈03 系統的六個性質〉。** 來源：13-控制系統 §1.1、§1.2。

**推導必寫**：（a）靜態開迴路：設計者依標稱增益 G<sub>0</sub> 放一個前饋增益 F ＝ 1 / G<sub>0</sub>，理想上 y ＝ F × G<sub>0</sub> × r ＝ r。實際受控體增益漂移成 G ＝ G<sub>0</sub>(1 + δ)，輸出干擾 d 直接加在輸出上：`y<sub>open</sub> = (1 + δ) r + d`，誤差 `e<sub>open</sub> = r − y<sub>open</sub> = −δ r − d`——漂移與干擾**原封不動**進到輸出。（b）靜態閉迴路（單位回授、控制器增益 K）：`y = K G (r − y) + d` ⇒ `y<sub>cl</sub> = L / (1 + L) × r + 1 / (1 + L) × d`，其中 `L = K G` 是迴路增益（loop gain）。（c）靈敏度（sensitivity）`S = 1 / (1 + L)`：命令誤差是 `S × r`，干擾被縮成 `S × d`，受控體增益變化 δ 對輸出的影響也被縮成大約 `S × δ`。（d）代價：L 要大，S 才小；但 L 大代表控制量 u ＝ K e 大，而且**本章沒有動態**，真實受控體有慣性與延遲，L 大會讓極點跑進右半平面——這是 04–08 章的主題。符號與單位：r、y、d 無單位（歸一化）；K、G、L、S 無單位；δ 用百分比。假設：全部靜態、線性、感測器 H ＝ 1 且無雜訊。

**數值實例**：K ＝ 50、增益漂移 δ ＝ +20 %、干擾 d ＝ 0.2、命令 r ＝ 1。

### 01 `01-建模從微分方程到轉移函數.html`

**目標**：用一顆忽略電樞電感的直流馬達，示範「寫物理方程 → 拉氏 → 整理成 G(s) ＝ K / (τs + 1)」的建模流程，讓讀者看到 K 與 τ 各由哪些物理參數決定，以及一階系統的步階響應、時間常數與 2 % 整定時間 4τ。

### 02 `02-方塊圖化簡與閉迴路轉移函數.html`

**目標**：把 01 章的一階受控體接上比例控制器與感測器，示範串聯、並聯、回授三條化簡規則，算出閉迴路轉移函數 `T(s) = CG / (1 + CGH)`，並看到回授做的第一件具體的事：**把極點從 −1 / τ 搬到 −(1 ＋ K<sub>c</sub>KH) / τ**，系統變快 (1 ＋ K<sub>c</sub>KH) 倍，代價是直流增益不到 1 / H。

**要點**：方塊圖（block diagram）三規則——串聯相乘、並聯相加、回授 `G / (1 + GH)`（負回授）；特徵方程式（characteristic equation）`1 + L(s) = 0` 是全課的主角，閉迴路極點就是它的根；梅森增益公式（Mason's gain formula）只點名「複雜訊號流圖的通用化簡法，本課不展開」；閉迴路時間常數 `τ<sub>cl</sub> = τ / (1 + K<sub>c</sub>KH)`；直流增益 `T(0) = K<sub>c</sub>K / (1 + K<sub>c</sub>KH)`，永遠小於 1 / H，這就是比例控制的穩態誤差（03 章展開）。**前置：系統互聯的定義見既有課〈04 線性非時變與摺積〉。** 來源：13-控制系統 §1.1、§2.2。

**推導必寫**：（a）從 `Y = G × U`、`U = C × E`、`E = R − H × Y` 三式消去 U 與 E，得 `Y(1 + CGH) = CGR`。（b）代入 C ＝ K<sub>c</sub>、G ＝ K / (τs + 1)、H ＝ h：`T(s) = K<sub>c</sub>K / (τs + 1 + K<sub>c</sub>Kh)`，分子分母同除以 (1 ＋ K<sub>c</sub>Kh) 得標準一階式，讀出 τ<sub>cl</sub> 與 T(0)。（c）極點 `s = −(1 + K<sub>c</sub>Kh) / τ`：迴路增益每加 1，極點就往左多搬 1 / τ。（d）為什麼 T(0) ＜ 1 / h：比例控制器需要非零誤差才有非零控制量，誤差 `e<sub>ss</sub> = 1 / (1 + K<sub>c</sub>Kh)`。符號與單位：K<sub>c</sub>、K、h 無單位，τ 與 τ<sub>cl</sub> 為 s。假設：線性、C 與 H 為常數、無飽和。

### 03 `03-穩態誤差與系統型式.html`

**目標**：把「比例控制追不到命令」推廣成一套規則：迴路增益 L(s) 在原點有幾個積分器（型式 N），就決定對步階、斜坡、拋物線三種命令的穩態誤差是零、常數還是無限大；常數的大小由誤差常數 K<sub>pos</sub>、K<sub>v</sub>、K<sub>a</sub> 決定。讀者看完要能對任一 L(s) 直接說出穩態誤差表。

**要點**：誤差轉移函數 `E(s) / R(s) = 1 / (1 + L(s))`（單位回授）；終值定理 `e<sub>ss</sub> = lim<sub>s→0</sub> s E(s)`（**既有課 07 已證明，只引用**，且只在閉迴路穩定時成立）；型式（system type）＝ L(s) 在 s ＝ 0 的極點數；三個誤差常數 `K<sub>pos</sub> = lim L(s)`、`K<sub>v</sub> = lim sL(s)`、`K<sub>a</sub> = lim s<sup>2</sup>L(s)`；穩態誤差表（型式 0／1／2 × 步階／斜坡／拋物線）；型式 2 的迴路 `K / (s<sup>2</sup>(s + a))` 本身不穩定（特徵多項式少一項），所以本課的型式 2 實驗固定加一個零點 (s ＋ 1)，變成 `K(s + 1) / (s<sup>2</sup>(s + a))`，Routh 條件 a ＞ 1。**位置誤差常數在本課寫 K<sub>pos</sub>，避免與 PID 的 K<sub>p</sub> 混淆。** **前置：終值定理見既有課〈07 拉氏轉換與轉移函數〉。** 來源：13-控制系統 §1.2；型式與誤差常數為本課補上（來源筆記缺口）。

**推導必寫**：（a）`E = R − Y = R − L E` ⇒ `E = R / (1 + L)`。（b）步階 R ＝ 1 / s：`e<sub>ss</sub> = lim s × (1/s) / (1 + L) = 1 / (1 + K<sub>pos</sub>)`；斜坡 R ＝ 1 / s²：`e<sub>ss</sub> = lim 1 / (s + sL) = 1 / K<sub>v</sub>`；拋物線 R ＝ 1 / s³：`e<sub>ss</sub> = 1 / K<sub>a</sub>`。（c）型式 0：K<sub>pos</sub> 有限、K<sub>v</sub> ＝ K<sub>a</sub> ＝ 0；型式 1：K<sub>pos</sub> ＝ ∞、K<sub>v</sub> 有限、K<sub>a</sub> ＝ 0；型式 2：K<sub>pos</sub> ＝ K<sub>v</sub> ＝ ∞、K<sub>a</sub> 有限。（d）對 `L = K / (s<sup>N</sup>(s + a))`：型式 0 的 K<sub>pos</sub> ＝ K / a；型式 1 的 K<sub>v</sub> ＝ K / a；型式 2（加零點）的 K<sub>a</sub> ＝ K / a。（e）閉迴路穩定的前提：型式 0 與 1 的特徵多項式 `s<sup>2</sup> + as + K` 對 K、a ＞ 0 恆穩定；型式 2 的 `s<sup>3</sup> + as<sup>2</sup> + Ks + K` 由 Routh 得穩定條件 a ＞ 1（05 章會算）。符號與單位：命令斜率 1 單位/s、加速度 1 單位/s²；e<sub>ss</sub> 與命令同單位。假設：單位回授、線性、閉迴路穩定。

### 04 `04-二階閉迴路與極點位置.html`

**目標**：把 03 章「加大 K 就能縮小穩態誤差」與「加大 K 會讓系統晃」放在同一個式子裡：單位回授 `G(s) = K / (s(s + a))` 的閉迴路是標準二階式，`ω<sub>n</sub> = √K`、`ζ = a / (2√K)`。讀者看完要能說出：K 同時決定快慢與晃動，a 只能靠設計極點來改；並會用主導極點比判斷第三個極點能不能忽略。

**要點**：閉迴路 `T(s) = K / (s<sup>2</sup> + as + K)` 與標準式對照；四個指標**只引用**既有課 08 的結論：`M<sub>p</sub> = e<sup>−πζ/√(1 − ζ²)</sup>`、`t<sub>p</sub> = π / ω<sub>d</sub>`、`t<sub>s</sub> ≈ 4 / (ζω<sub>n</sub>)`、`t<sub>r</sub> ≈ 1.8 / ω<sub>n</sub>`（來源筆記給的粗估，ζ 接近 0.5 時才準）；四種阻尼由 ζ 分界；斜坡穩態誤差 `e<sub>ss</sub> = a / K`（K<sub>v</sub> ＝ K / a）；主導極點（dominant poles）：第三個實極點 −p 與共軛對實部 −ζω<sub>n</sub> 的比值 ≥ 5 時可忽略；設計目標 ζ 0.4–0.8（M<sub>p</sub> 25 % 到 1.5 %）。**前置：四個指標的推導見既有課〈08 極零點與二階系統〉，本章不重推；RLC 的 α、ω<sub>0</sub> 見電路學〈08 二階 RLC 暫態〉。** 來源：13-控制系統 §4.2、§4.3。

**推導必寫**：（a）`1 + K / (s(s + a)) = 0` ⇒ `s<sup>2</sup> + as + K = 0`，對照 `s<sup>2</sup> + 2ζω<sub>n</sub>s + ω<sub>n</sub><sup>2</sup>` 得 `ω<sub>n</sub> = √K`、`2ζω<sub>n</sub> = a`。（b）**K 的雙面刃**：K 加 4 倍 → ω<sub>n</sub> 加 2 倍、ζ 減半、e<sub>ss</sub> 減 4 倍、M<sub>p</sub> 大幅上升；實部 −ζω<sub>n</sub> ＝ −a / 2 **與 K 無關**，所以 t<sub>s</sub> 不動——極點沿垂直線 s ＝ −a / 2 往上跑（這就是 06 章根軌跡的雛形）。（c）ζ ≥ 1 時兩個實極點 `−ζω<sub>n</sub> ± ω<sub>n</sub>√(ζ² − 1)`，慢的那個主導。（d）主導極點比 `p / (ζω<sub>n</sub>)`：第三極點的暫態衰減 e<sup>−pt</sup> 比共軛對快 p / (ζω<sub>n</sub>) 倍，比值 ≥ 5 時二階近似的誤差通常在幾個百分點內。符號與單位：K（1/s²）、a（1/s）、ω<sub>n</sub>（rad/s）、ζ 無單位、時間 s。假設：單位回授、無零點、第三極點只用來判主導。

**數值實例**：K ＝ 25、a ＝ 6、第三極點 p ＝ 30、觀測 t ＝ 0.5 s。

### 05 `05-Routh穩定度判別.html`

**目標**：不解根、只看特徵多項式的係數，逐列算出 Routh 表，數第一行符號變化次數＝右半平面極點數。讀者看完要能對三階與四階多項式手算 Routh 表、找出增益的穩定範圍、並處理首元為零與全零列兩種特殊情形。

**要點**：穩定的定義（所有閉迴路極點實部 ＜ 0；離散系統則在單位圓內，只點名）；必要條件（係數全同號且無缺項）；Routh 表的建表規則（前兩列由係數交錯填入，之後每列 `b<sub>1</sub> = (a<sub>1</sub>a<sub>2</sub> − a<sub>0</sub>a<sub>3</sub>) / a<sub>1</sub>` 的交叉相乘）；充分必要條件（第一行全同號）；符號變化次數 ＝ 右半平面極點數；特殊情形一：首元為零、該列不全零 → 以極小正數 ε 代入繼續算；特殊情形二：整列為零 → 用上一列的輔助多項式微分取代，且代表有對稱於原點的極點（常見是虛軸上一對）；「這件事在你的程式裡長什麼樣」：一個確定性的二維表格填充。**前置：極點在左半平面才穩定，見既有課〈07 拉氏轉換與轉移函數〉。** 來源：13-控制系統 §3.1、§3.2。

**推導必寫**：（a）四階 `a<sub>4</sub>s<sup>4</sup> + a<sub>3</sub>s<sup>3</sup> + a<sub>2</sub>s<sup>2</sup> + a<sub>1</sub>s + a<sub>0</sub>` 的表：s<sup>4</sup> 列 [a<sub>4</sub>, a<sub>2</sub>, a<sub>0</sub>]、s<sup>3</sup> 列 [a<sub>3</sub>, a<sub>1</sub>, 0]、s<sup>2</sup> 列 [b<sub>1</sub>, b<sub>2</sub>, 0]、s<sup>1</sup> 列 [c<sub>1</sub>, 0, 0]、s<sup>0</sup> 列 [d<sub>1</sub>]，其中 `b<sub>1</sub> = (a<sub>3</sub>a<sub>2</sub> − a<sub>4</sub>a<sub>1</sub>) / a<sub>3</sub>`、`b<sub>2</sub> = (a<sub>3</sub>a<sub>0</sub> − a<sub>4</sub> × 0) / a<sub>3</sub> = a<sub>0</sub>`、`c<sub>1</sub> = (b<sub>1</sub>a<sub>1</sub> − a<sub>3</sub>b<sub>2</sub>) / b<sub>1</sub>`、`d<sub>1</sub> = b<sub>2</sub>`。（b）三階 `s<sup>3</sup> + a<sub>2</sub>s<sup>2</sup> + a<sub>1</sub>s + a<sub>0</sub>` 穩定 ⇔ 全部係數 ＞ 0 且 `a<sub>2</sub>a<sub>1</sub> > a<sub>0</sub>`。（c）套用到 04 章的結構加一個極點：`s<sup>3</sup> + 3s<sup>2</sup> + 3s + K` 的 s<sup>1</sup> 列 ＝ (9 − K) / 3，穩定範圍 0 ＜ K ＜ 9；K ＝ 9 時 s<sup>1</sup> 列全零，輔助多項式 3s² ＋ 9 ＝ 0 給出虛軸極點 ±j√3——這就是臨界增益與臨界頻率。（d）ε 法的解讀：ε → 0<sup>+</sup> 時下一列會出現 −(大數)，符號變化照數。符號與單位：係數無單位（或依多項式的物理單位）。假設：係數為實數；ε ＝ 10<sup>−6</sup> 是本課的教學取值。

**數值實例**：s<sup>4</sup> + 2s<sup>3</sup> + 3s<sup>2</sup> + 4s + 5。

| 列 | 第 1 欄 | 第 2 欄 | 第 3 欄 |
| --- | --- | --- | --- |
| s<sup>4</sup> | 1 | 3 | 5 |
| s<sup>3</sup> | 2 | 4 | 0 |
| s<sup>2</sup> | (2 × 3 − 1 × 4) / 2 ＝ **1.000000** | (2 × 5 − 0) / 2 ＝ **5.000000** | 0 |
| s<sup>1</sup> | (1 × 4 − 2 × 5) / 1 ＝ **−6.000000** | 0 | 0 |
| s<sup>0</sup> | **5.000000** | | |

邊界對照：`s<sup>3</sup> + 3s<sup>2</sup> + 3s + 10` → s<sup>1</sup> 列 **−0.333333**，2 次變化，不穩定；`… + 8` → s<sup>1</sup> 列 **0.333333**，0 次，穩定；`… + 9` → s<sup>1</sup> 列全零，輔助多項式 3s² ＋ 9，導數 6s，s<sup>1</sup> 列改填 **6.000000**，0 次變化但有虛軸極點 ±j1.732051，**臨界穩定**；`s<sup>4</sup> + s<sup>3</sup> + 2s<sup>2</sup> + 2s + 3` → s<sup>2</sup> 列首元 0，以 ε 代入，s<sup>1</sup> 列 ＝ **2 − 3 / ε ≈ −2.999998 × 10<sup>6</sup>**，2 次變化，不穩定；`s<sup>4</sup> + s<sup>3</sup> + 3s<sup>2</sup> + 2s + 2` → s<sup>1</sup> 列全零，輔助多項式 s² ＋ 2，導數 2s，改填 **2.000000**，0 次變化，虛軸極點 ±j1.414214，臨界穩定；`s<sup>3</sup> + 6s<sup>2</sup> + 11s + 66` → s<sup>1</sup> 列全零（09 章 K<sub>u</sub> ＝ 60 的來源）；`0.001s<sup>3</sup> + 0.11s<sup>2</sup> + s + 120` → s<sup>1</sup> 列 **−0.090909**，不穩定（08 章 K ＞ 110 的來源）。

### 06 `06-根軌跡.html`

**目標**：對 `L(s) = K / (s(s + a)(s + b))`，把 K 從 0 加到臨界的整條路徑講清楚：三個閉迴路極點從開迴路極點出發、兩個在實軸上相遇後離開（分離點）、沿漸近線往右上與右下走、在 K<sub>crit</sub> 穿過虛軸。讀者看完要能算重心、漸近角、分離點、虛軸穿越，並對任一 K 求出三個極點與主導對的 ζ。

**要點**：根軌跡（root locus）＝ 特徵方程式 `1 + K P(s) = 0` 的根隨 K 從 0 到 ∞ 的軌跡；起點是開迴路極點（K ＝ 0）、終點是開迴路零點或無窮遠；實軸上某點在軌跡上 ⇔ 它右邊的實極點與實零點總數為奇數；漸近線條數 ＝ n − m，重心 `σ = (Σ極點 − Σ零點) / (n − m)`，角度 `(2k + 1) × 180° / (n − m)`；分離點（breakaway point）由 `dK / ds = 0` 求；虛軸穿越用 Routh（05 章）；K 對應 ζ 的讀法（主導共軛對的 ζ ＝ −Re / |s|）。**前置：ζ 與極點位置的關係見既有課〈08 極零點與二階系統〉。** 來源：13-控制系統 §5.3；畫法規則為本課補上（來源筆記缺口）。

**推導必寫**：（a）特徵多項式 `s<sup>3</sup> + (a + b)s<sup>2</sup> + abs + K = 0`。（b）n ＝ 3、m ＝ 0：三條漸近線，重心 `σ = (0 − a − b) / 3`，角度 60°、180°、300°（寫成 ±60° 與 180°）。（c）實軸區段：(−a, 0) 與 (−∞, −b) 在軌跡上、(−b, −a) 不在。（d）分離點：`K = −s(s + a)(s + b)`，`dK / ds = −(3s<sup>2</sup> + 2(a + b)s + ab) = 0`，取落在 (−a, 0) 的那個根；分離點的 K 值代回上式。（e）虛軸穿越：Routh 的 s<sup>1</sup> 列 `(a + b)ab − K = 0` ⇒ `K<sub>crit</sub> = ab(a + b)`，輔助多項式 `(a + b)s<sup>2</sup> + K<sub>crit</sub> = 0` ⇒ `ω<sub>crit</sub> = √(ab)`。（f）任一 K 的三個根：本課用牛頓法先找最左邊的實根，再降階解二次式（演算法見 7.3 節 `cubicRoots()`）。（g）四個階段：K ＜ K<sub>b</sub> 三個實根；K<sub>b</sub> ＜ K ＜ K<sub>crit</sub> 一實根加共軛對（ζ 隨 K 下降）；K ＝ K<sub>crit</sub> 共軛對在虛軸；K ＞ K<sub>crit</sub> 不穩定。符號與單位：a、b（1/s）、K（1/s³）、角度用度。假設：無零點、K ≥ 0。

**數值實例**：a ＝ 2、b ＝ 4、K ＝ 10。

### 07 `07-頻率響應與波德圖.html`

**目標**：把 s ＝ jω 代進迴路增益，在任一頻率算出振幅（dB）與相位，並學會用漸近線讀波德圖：每個極點在轉角頻率後多降 20 dB/十倍頻、多貢獻 −90° 相位，轉角處精確值比漸近線低 3.01 dB。讀者看完要能對 `L<sub>0</sub>(s) = 10 / (s(0.1s + 1)(0.01s + 1))` 手算任一頻率的讀值。

**要點**：頻率響應（frequency response）`L(jω)`（**既有課 09 已教「s ＝ jω」，只引用**）；分貝 `20 log<sub>10</sub>|L|`；波德圖（Bode plot）＝ 振幅 dB 對 log ω、相位度對 log ω 兩張圖；本課用**讀值表**取代圖；積分器 1 / s：−20 dB/十倍頻、−90° 固定；一階極點 1 / (τs ＋ 1)：轉角頻率（corner frequency）ω<sub>c</sub> ＝ 1 / τ，之前 0 dB、之後 −20 dB/十倍頻，相位從 0° 到 −90°，在轉角處 −45°；增益 K：整條線上移 20 log K；漸近線與精確值的誤差：轉角處 −3.010300 dB、一個十倍頻外約 −0.043 dB；頻寬與共振（來源 §5.2）只以文字點名——本章講開迴路 L 的讀值，閉迴路頻寬留待字典。**前置：s ＝ jω 與頻率響應見既有課〈09 濾波器與群延遲〉；一個極點降 20 dB 見電路學〈12 一階濾波器與頻率響應〉。** 來源：13-控制系統 §5.1、§5.2。

**推導必寫**：（a）`|L<sub>0</sub>(jω)| = 10 / (ω √(1 + (0.1ω)²) √(1 + (0.01ω)²))`、`∠L<sub>0</sub>(jω) = −90° − arctan(0.1ω) − arctan(0.01ω)`。（b）漸近線：ω ＜ 10 時 `20 log 10 − 20 log ω`（斜率 −20）；10 ≤ ω ＜ 100 時再減 `20 log(0.1ω)`（斜率 −40）；ω ≥ 100 時再減 `20 log(0.01ω)`（斜率 −60）。（c）為什麼是 −3.01 dB：ω ＝ 1 / τ 時 `√(1 + 1) = √2`，20 log √2 ＝ 3.010300。（d）相位比振幅「早動」：一階極點在 ω<sub>c</sub> / 10 已經有 −5.71°，在 10 ω<sub>c</sub> 才到 −84.29°，所以三個極點的相位會比振幅更早疊到 −180°——這是 08 章相位裕度的伏筆。（e）dB 的加法：串聯的振幅相乘變成 dB 相加，相位直接相加。符號與單位：ω（rad/s）、τ（s）、振幅 dB、相位度。假設：線性、穩態弦波、L 是最小相位。

### 08 `08-增益裕度相位裕度與奈奎斯特.html`

**目標**：從迴路增益的波德讀值找出增益交越頻率 ω<sub>gc</sub>（|L| ＝ 1）與相位交越頻率 ω<sub>pc</sub>（∠L ＝ −180°），算出增益裕度 GM 與相位裕度 PM，用奈奎斯特準則說明為什麼這兩個數字決定閉迴路穩不穩，並給出設計目標 PM 45°–60°、GM 6–12 dB 與 ζ ≈ PM / 100 的粗估。

**要點**：閉迴路極點是 `1 + L(s) = 0` 的根，等價於 `L(jω) = −1` 這一點；奈奎斯特準則（Nyquist criterion）：Z ＝ N ＋ P，P ＝ 開迴路右半平面極點數，N ＝ L(jω) 軌跡順時針環繞 −1 的次數，Z ＝ 閉迴路右半平面極點數；本課的 L<sub>0</sub> 是最小相位、P ＝ 0，所以 **穩定 ⇔ N ＝ 0 ⇔ 相位到 −180° 時 |L| ＜ 1**；GM ＝ −20 log|L(jω<sub>pc</sub>)|、PM ＝ 180° ＋ ∠L(jω<sub>gc</sub>)；臨界增益 K<sub>crit</sub> ＝ K × 10<sup>GM/20</sup>；本課的三極點結構有封閉解 `ω<sub>pc</sub> = 1 / √(τ<sub>1</sub>τ<sub>2</sub>)`、`K<sub>crit</sub> = (τ<sub>1</sub> + τ<sub>2</sub>) / (τ<sub>1</sub>τ<sub>2</sub>)`（與 05 章 Routh 一致）；ω<sub>gc</sub> 沒有封閉解，用二分搜尋；ζ ≈ PM / 100 只在 PM ＜ 60° 且系統近似二階時可用；「這件事在你的程式裡長什麼樣」：對 |L(jω)| − 1 做對數域二分搜尋。**前置：頻率響應見既有課〈09 濾波器與群延遲〉。** 來源：13-控制系統 §3.3、§3.4（PM 45°–60°、GM 6–12 dB 的設計目標出自 §3.4）。

**推導必寫**：（a）ω<sub>pc</sub>：`arctan(τ<sub>1</sub>ω) + arctan(τ<sub>2</sub>ω) = 90°` ⇔ `τ<sub>1</sub>τ<sub>2</sub>ω<sup>2</sup> = 1`。（b）代回振幅：`|L(jω<sub>pc</sub>)| = K τ<sub>1</sub>τ<sub>2</sub> / (τ<sub>1</sub> + τ<sub>2</sub>)`（用 `√(1 + τ<sub>1</sub>/τ<sub>2</sub>) √(1 + τ<sub>2</sub>/τ<sub>1</sub>) = (τ<sub>1</sub> + τ<sub>2</sub>) / √(τ<sub>1</sub>τ<sub>2</sub>)` 化簡）。（c）K<sub>crit</sub> ＝ (τ<sub>1</sub> ＋ τ<sub>2</sub>) / (τ<sub>1</sub>τ<sub>2</sub>)，與 Routh 對 `τ<sub>1</sub>τ<sub>2</sub>s<sup>3</sup> + (τ<sub>1</sub> + τ<sub>2</sub>)s<sup>2</sup> + s + K` 的 s<sup>1</sup> 列相同。（d）奈奎斯特的直覺（不畫圖）：軌跡從 ω → 0<sup>+</sup> 的 −90° 方向無窮遠處出發，順時針轉、穿過負實軸於 −|L(jω<sub>pc</sub>)|，最後在 −270° 方向收到原點；穿越點在 −1 右邊（|L| ＜ 1）就不環繞 −1。（e）PM 與 ζ：二階近似下 `PM = arctan(2ζ / √(√(1 + 4ζ⁴) − 2ζ²))`，PM ＜ 60° 時 ζ ≈ PM / 100，PM ＝ 47.4° 對應 ζ ≈ 0.47（精確式給 0.447398）。符號與單位：GM 用 dB、PM 用度、ω 用 rad/s。假設：最小相位、P ＝ 0、無延遲。

**數值實例**：L<sub>0</sub>(s) ＝ 10 / (s(0.1s ＋ 1)(0.01s ＋ 1))。

### 09 `09-PID控制器設計.html`

**目標**：對三階受控體 `G(s) = 1 / ((s + 1)(s + 2)(s + 3))` 加上 PID，用 Routh 判穩、用固定步長模擬算出超越量、上升時間、整定時間與穩態誤差，讓讀者親手體會 P、I、D 三項各買到什麼、付出什麼，並算出 Ziegler–Nichols 的 K<sub>u</sub>、T<sub>u</sub> 與建議參數，看到它為什麼超越量偏大。

**要點**：`u(t) = K<sub>p</sub>e + K<sub>i</sub>∫e dt + K<sub>d</sub> de/dt`；P 給基本響應但有穩態誤差（型式 0 受控體：e<sub>ss</sub> ＝ 6 / (6 ＋ K<sub>p</sub>)）；I 把型式加 1、消除步階穩態誤差，但多一個 −90° 相位、更容易振盪；D 加阻尼、預測趨勢，但放大雜訊——本課把 D 作用在輸出 y 上（derivative on measurement），避免步階命令的微分脈衝，特徵多項式不變；閉迴路特徵多項式 `s<sup>4</sup> + 6s<sup>3</sup> + (11 + K<sub>d</sub>)s<sup>2</sup> + (6 + K<sub>p</sub>)s + K<sub>i</sub>`（K<sub>i</sub> ＝ 0 時退化為三階 `s<sup>3</sup> + 6s<sup>2</sup> + (11 + K<sub>d</sub>)s + (6 + K<sub>p</sub>)`）；Ziegler–Nichols 閉迴路法：只用 P 加到等幅振盪得 K<sub>u</sub>、T<sub>u</sub>，建議 K<sub>p</sub> ＝ 0.6K<sub>u</sub>、T<sub>i</sub> ＝ T<sub>u</sub> / 2、T<sub>d</sub> ＝ T<sub>u</sub> / 8（K<sub>i</sub> ＝ K<sub>p</sub> / T<sub>i</sub>、K<sub>d</sub> ＝ K<sub>p</sub>T<sub>d</sub>）；內模原理（internal model principle, IMP）一段：要對常值命令強健地零誤差，控制器要含 1 / s（積分器就是常值訊號的模型），IMP 與內模控制（IMC）是不同術語；數位實作與積分飽和（anti-windup）只用一段文字點名留給後續課；「這件事在你的程式裡長什麼樣」：每個取樣週期算 e、累加、差分、乘三個係數。**前置：積分器就是累積電荷的電容，見電路學〈07 一階暫態 RC 與 RL〉；ζ 與指標見第 04 章。** 來源：13-控制系統 §6.1、§6.3、§8.3。

**推導必寫**：（a）狀態方程：`y''' + 6y'' + 11y' + 6y = u`，`u = K<sub>p</sub>(r − y) + K<sub>i</sub>z − K<sub>d</sub>y'`，`z' = r − y`，r ＝ 1；四個狀態 (y, y', y'', z) 從 0 出發。（b）特徵多項式：把 u 代入並乘 s：`s<sup>4</sup> + 6s<sup>3</sup> + (11 + K<sub>d</sub>)s<sup>2</sup> + (6 + K<sub>p</sub>)s + K<sub>i</sub>`；Routh：`b<sub>1</sub> = (6(11 + K<sub>d</sub>) − (6 + K<sub>p</sub>)) / 6`、`c<sub>1</sub> = (b<sub>1</sub>(6 + K<sub>p</sub>) − 6K<sub>i</sub>) / b<sub>1</sub>`，穩定 ⇔ b<sub>1</sub> ＞ 0、c<sub>1</sub> ＞ 0、K<sub>i</sub> ＞ 0；K<sub>i</sub> ＝ 0 時用三階條件 `6(11 + K<sub>d</sub>) > 6 + K<sub>p</sub>` ⇔ `K<sub>p</sub> < 60 + 6K<sub>d</sub>`。（c）K<sub>u</sub>：只用 P，`s<sup>3</sup> + 6s<sup>2</sup> + 11s + 6 + K<sub>p</sub>`，Routh 臨界 `6 × 11 = 6 + K<sub>u</sub>` ⇒ K<sub>u</sub> ＝ 60；輔助多項式 `6s<sup>2</sup> + 66 = 0` ⇒ ω<sub>u</sub> ＝ √11 ＝ 3.316625、T<sub>u</sub> ＝ 2π / ω<sub>u</sub> ＝ 1.894452 s。（d）Z–N：K<sub>p</sub> ＝ 36、T<sub>i</sub> ＝ 0.947226、T<sub>d</sub> ＝ 0.236806、K<sub>i</sub> ＝ 38.005721、K<sub>d</sub> ＝ 8.525032。（e）四個指標的定義（模擬用）：峰值 ＝ max y；M<sub>p</sub> ＝ (峰值 − 1) × 100（負值記 0）；t<sub>p</sub> ＝ 峰值時刻；t<sub>r</sub> ＝ 首次到 0.9 的時刻 − 首次到 0.1 的時刻；t<sub>s</sub> ＝ 最後一次 |y − 1| ＞ 0.02 的時刻（10 s 內未進帶則記 10.000000 並註明）；e<sub>ss</sub>（模擬）＝ 1 − y(10)；IAE ＝ Σ|1 − y| × h。（f）步階穩態誤差的理論值：K<sub>i</sub> ＞ 0 → 0；K<sub>i</sub> ＝ 0 → 6 / (6 ＋ K<sub>p</sub>)。符號與單位：時間 s，增益無單位（K<sub>i</sub> 1/s、K<sub>d</sub> s）。假設：線性、無飽和、無雜訊、D 作用在 y。

### 11 `11-狀態空間入門.html`

**目標**：用 2 × 2 的 `ẋ = Ax + Bu`、`y = Cx` 示範狀態空間的三件事：A 的特徵值就是極點；可控矩陣 `M<sub>c</sub> = [B, AB]` 滿秩才能用狀態回授 `u = −Kx` 把極點放到任何位置（Ackermann 公式）；可觀矩陣 `M<sub>o</sub> = [C; CA]` 滿秩才能從 y 估出 x（觀測器）。讀者看完要能對 2 × 2 系統手算特徵值、兩個行列式與 K。

### 7.3 演算法（唯一實作規範，不得偏離）

**`routhTable(coefs)`**（`coefs` 為由高次到低次的數字陣列，長度 n ＋ 1）：

```text
若 coefs[0] === 0 → 回 {error: "leading-zero"}
若全部係數 < 0 → 全部乘 −1，記 note "已同乘 −1"
w = ceil((n + 1) / 2)
rows[0] = coefs 的偶數索引元素（0, 2, 4…），補 0 到長度 w
rows[1] = coefs 的奇數索引元素（1, 3, 5…），補 0 到長度 w
for i = 2 .. n:
  prev2 = rows[i − 2], prev1 = rows[i − 1]
  若 prev1 全為 0（|x| < 1e-12）：
     power = n − (i − 2)   // 上一列對應的 s 次方
     aux = []；對 prev2 每個元素 c（索引 j）：pw = power − 2j；若 pw > 0 則 push(c × pw)
     prev1 = aux 補 0 到長度 w；rows[i − 1] = prev1；記 note "s^(n−(i−1)) 列全零，改用 s^power 列輔助多項式的導數"，並記輔助多項式 prev2（供顯示其根）
  若 |prev1[0]| < 1e-12：prev1[0] = 1e-6；rows[i − 1] = prev1；記 note "s^(n−(i−1)) 列首元為 0，以 ε ＝ 10^−6 代入"
  new = []；for j = 0 .. w − 2：a = prev2[j+1] || 0；b = prev1[j+1] || 0；new.push((prev1[0] × a − prev2[0] × b) / prev1[0])
  new.push(0)；rows.push(new)
first = rows 每列的第 0 個元素
changes = 相鄰 first 元素正負號不同的次數（0 視為正，因已被 ε 取代）
回 {rows, first, changes, notes, aux}
```

顯示時：|x| ≥ 10<sup>6</sup> 或（x ≠ 0 且 |x| ＜ 10<sup>−4</sup>）用 `sci`，其餘 `num6`；ε 本身顯示為「ε」。輔助多項式 `αs² + β`（取 prev2 前兩個非零元素）的根：β / α ＞ 0 → `±j√(β/α)`；β / α ＜ 0 → `±√(−β/α)`。

**`cubicRoots(b, c, d)`**（解 `s³ + b s² + c s + d = 0`）：

```text
f(s) = s³ + b s² + c s + d；fp(s) = 3s² + 2b s + c
s = −b − 1；重複 80 次：s = s − f(s) / fp(s)（fp 為 0 時跳出）
r1 = s
降階：s² + (b + r1) s + (c + b r1 + r1²) = 0 → p = b + r1、q = c + b r1 + r1²
disc = p² − 4q
disc ≥ 0：r2 = (−p + √disc) / 2、r3 = (−p − √disc) / 2，三個實根（im = 0）
disc < 0：re = −p / 2、im = √(−disc) / 2，共軛對
回 [{re: r1, im: 0}, {re, im: +}, {re, im: −}]
```

驗算：`cubicRoots(6, 8, 10)` → −4.760818、−0.619591 ± j1.310186；`cubicRoots(6, 8, 48)` → −6、0 ± j2.828427；`cubicRoots(6, 8, 0)` → −4、−2、0（實根順序不限）。

**`lmag(K, t1, t2, w)`** ＝ `K / (w × √(1 + (w t1)²) × √(1 + (w t2)²))`；**`lphase(t1, t2, w)`** ＝ `−90 − atan(w t1) − atan(w t2)`（度）。

**`bisectGain(magFn)`**（找 magFn(w) ＝ 1）：`lo = 1e-3, hi = 1e5`；重複 100 次：`mid = √(lo × hi)`；`magFn(mid) > 1 ? lo = mid : hi = mid`；回 `√(lo × hi)`。**`bisectPhase(phFn)`**（找 phFn(w) ＝ −180）：同上，條件 `phFn(mid) > −180 ? lo = mid : hi = mid`，`lo = 1e-2`。驗算：`bisectGain(w → lmag(10, 0.1, 0.01, w))` ＝ 7.844079。

**`pidSim(Kp, Ki, Kd)`**（RK4，h ＝ 0.001，T ＝ 10，n ＝ 10000 步）：

```text
狀態 x = [y, dy, ddy, z]，初值全 0，r = 1
f(x) = [x[1], x[2], u − 6 x[2] − 11 x[1] − 6 x[0], 1 − x[0]]，u = Kp (1 − x[0]) + Ki x[3] − Kd x[1]
古典 RK4：k1 = f(x)；k2 = f(x + h/2 k1)；k3 = f(x + h/2 k2)；k4 = f(x + h k3)；x += h/6 (k1 + 2k2 + 2k3 + k4)
ys[0] = 0；每步後 push x[0]（共 10001 個樣本，ys[i] 對應 t = i h）
peak = max(ys)；tp = argmax × h；Mp = max(0, (peak − 1) × 100)
t10 = 第一個 ys[i] ≥ 0.1 的 i × h；t90 = 第一個 ≥ 0.9 的 i × h；tr = t90 − t10（任一不存在 → 不適用）
ts = 最後一個 |ys[i] − 1| > 0.02 的 i × h（沒有任何一點超出 → 0；最後一點仍超出 → 10 並標 "未進帶"）
yfin = ys[10000]；ess = 1 − yfin；iae = Σ|1 − ys[i]| × h（i = 0..10000）
若過程中任一 |x[0]| > 100 或非有限 → 回 {diverged: true}
```

驗算：`pidSim(20, 10, 5)` → peak 1.170189、Mp 17.018937、tp 1.812、tr 0.782、ts 2.731、yfin 1.000340、iae 0.954804；`pidSim(10, 5, 0)` → Mp 7.887784、ts 5.742。

**Routh 判穩（09 章專用，不必跑 `routhTable`）**：`Ki > 0`：`b1 = (6 (11 + Kd) − (6 + Kp)) / 6`、`c1 = (b1 (6 + Kp) − 6 Ki) / b1`，穩定 ⇔ `b1 > 0 && c1 > 0`；`Ki === 0`：穩定 ⇔ `6 (11 + Kd) > 6 + Kp`（且 Kp ＋ 6 ＞ 0 恆成立）；`b1 === 0` 或（Ki ＝ 0 且等號成立）→ 臨界，不模擬。

**`stateSpace(A, B, C, d1, d0)`**（A ＝ [a11, a12, a21, a22]，B ＝ [b1, b2]，C ＝ [c1, c2]）：

```text
tr = a11 + a22；det = a11 a22 − a12 a21；disc = tr²/4 − det
eig = disc ≥ 0 ? [tr/2 ± √disc]（實）: [tr/2 ± j√(−disc)]
Mc = [[b1, a11 b1 + a12 b2], [b2, a21 b1 + a22 b2]]；detMc = Mc00 Mc11 − Mc01 Mc10
Mo = [[c1, c2], [c1 a11 + c2 a21, c1 a12 + c2 a22]]；detMo = Mo00 Mo11 − Mo01 Mo10
若 |detMc| ≥ 1e-9：
  A2 = A × A；phi = A2 + d1 A + d0 I
  inv = (1/detMc) [[Mc11, −Mc01], [−Mc10, Mc00]]；row = inv 第 2 列
  K = [row0 phi00 + row1 phi10, row0 phi01 + row1 phi11]
  Acl = [a11 − b1 K0, a12 − b1 K1, a21 − b2 K0, a22 − b2 K1]；eigCl = 同上特徵值公式
回 {tr, det, eig, Mc, detMc, Mo, detMo, K, eigCl}
```

驗算：預設 → K ＝ [48, 7]、eigCl ＝ −5 ± j5；`unobs` → K ＝ [41, −34]；`unstable` → K ＝ [52, 11]。

### 7.4 `dictionary()` 與 `selfcheck()`

- `dictionary()`：守衛 `term-search`；把輸入轉小寫去頭尾空白，對每張 `.term-card` 用 `data-search + textContent` 的小寫做 `indexOf`；不符者加 `hidden` 屬性；`term-count` 寫「顯示 n / 54 張卡」。
- `selfcheck()`：守衛 `quiz-reset`；`QUIZ` 陣列每題 `{id, t: "num"|"sel", ans, tol, why, err}`；`QUIZ_CH` 對應章號 → [檔名, 章名]；回饋規則照 6.4 節。

### 7.5 JavaScript 規則

- 每個守衛函式第一行檢查主控制 id 存在，否則 `return`。
