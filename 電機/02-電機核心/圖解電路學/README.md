# 圖解電路學

[GitHub Pages 公開版](https://justty32.github.io/engineer_study/circuits-little-lab/)｜[驗收與部署證據](驗收紀錄.md)

從電壓、電流與功率開始，循序練習直流分析、暫態、拉氏轉換、相量、運放、雙埠、磁耦合與三相。20 個教學頁各有完整主例、近題分步提示與詳解、參數實驗；另有課程地圖、33 項名詞字典與 47 項教材查證。

[開啟課程地圖](dist/index.html)｜[零基礎起點](dist/00-start.html)｜[字典](dist/glossary.html)｜[教材與查證](dist/sources.html)

直接開啟 dist/index.html 即可離線閱讀。dist/ 是原生 HTML/CSS/JavaScript 成品；發布 slug 為 circuits-little-lab。主例文字、圖與完整解答不依賴 JavaScript。所有插圖均為程式原創 inline SVG，沒有遠端執行期資源。外部教材連結僅在點擊時開啟。

[專案簡報](PROJECT-BRIEF.md) 記錄讀者基線與邊界；[建置契約](BUILD-SPEC.md) 連到各章公式、先修、互動參數、量測與近題數據；[派工計畫](派工計畫.md) 記錄互斥作者範圍。來源核對詳見 [教材查證](教材查證.md)。既有網站保持原樣；原筆記僅由來源線依獨立複核做八項局部條件修正。

獨立數學、教學與瀏覽器驗收分別記錄於 [數學驗收](數學驗收.md)、[教學驗收](教學驗收.md)、[驗收紀錄](驗收紀錄.md)。本地檢查工具放在 test/；瀏覽器檢查使用環境既有的 Playwright 與 Chromium，沒有新增依賴。
