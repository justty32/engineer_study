本課沿用電路聽課播放器；語音／音檔狀態機不另造。window.EMFIELD_AUDIO 與 window.EMFIELD_AUDIO_ASSETS，storageKey 為 emfield-listening-v1；圖與段落 ID 一律 emfield- 開頭。播放器既有通用控制 ID 保留。無音檔時顯示段落進度與系統朗讀限制，只有使用者操作才發聲。

## 算例與界線

全課採 k ≈ 9.00×10⁹ N m²/C²，使 Q=+1 nC 時 kQ=9 V m；為三位有效數近似，與精確常數約差 0.14%。真空、來源固定，觀測點不在源上，試驗電荷 q_t=±1 pC，忽略試驗電荷擾動。

第一堂主源在 O=(0,0)，P=(0.18,0.24) m，r=.30 m；單源 E=(60,80) V/m，大小100 V/m。圖二才加入 Q₂=+1 nC 於 (.36,0) m，E₂=(-60,80)，合場(0,160) V/m。圖三回到單源，量測方向沿+x與E方向，投影分別60與100 V/m；沿-x為-60，垂直E為0，移動方向與力方向不可混同。

第二、三堂均回到單源 Q。A=(.30,0) m、B=(.60,0) m；V∞=0，V(r)=9/r V（r以m代入），VA=30 V、VB=15 V。A到B場線積分=+15 V；ΔV=-15 V；正1 pC試驗電荷場功+15 pJ、位能變化-15 pJ。準靜態且無損耗時外力功=-15 pJ。負試驗電荷上述功與能量反號，場與電位不變。

第三堂等差電位30/25/20/15 V，半徑 .30/.36/.45/.60 m；徑向間距 .06/.09/.15 m。場Er=9/r²，r=.30時100 V/m，r=.60時25 V/m。A→B平均徑向場50 V/m；A→r=.33 m平均90.909 V/m；A→.303 m平均99.010 V/m。場箭頭若僅示方向必明標，所有座標圖長度同尺度。
