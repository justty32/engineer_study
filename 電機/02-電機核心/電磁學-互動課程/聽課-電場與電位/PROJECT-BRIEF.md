# 電場與電位聽課：製作摘要

服務邊玩遊戲邊聽的學習者，承接電路與電子學後，將空間中的電場、能量與電位接起來。每堂只回答一個問題：箭頭如何拆解與疊加；沿路的功如何得到電位差；等位線如何讀回方向與場強。工程數學依用途展開，向量、線積分、梯度各有完整敘事。

三堂各 4200–5000 可說漢字，每分鐘 240–280 字估算至少十五分鐘；每堂三次明確看圖停靠。九張程式繪製 SVG，以大圖短句呈現，細節摺疊。全部正文由 lesson-data.js 同源輸出完整口語稿.md。使用既有播放器，空音檔 manifest、無 sample、不自動朗讀、不生成音訊。
