06・從幾何與材料算出元件值與場能量

電容與電場儲能：能量其實在兩導體之間

電容不是神祕常數，而是導體幾何與介質共同決定的比例。從 Q = CV 出發，可以推得平行板、同軸與球形構型，並把元件儲能重新解讀為空間中的電場能量。

這章假設已懂：05 介電質與邊界條件的 ε、E 與 D。

痛點：電容器到底裝了什麼，為何換形狀就換數值

電路圖把 C 畫成一個固定數字，容易讓人以為電容器像容器般收納淨電荷。實際上兩片板分別帶 +Q 與 −Q，總電荷仍為零；外部做功把電荷分離，建立電場並把能量留在場中。電容量（capacitance）C 定義為 Q/V，單位法拉 F = C/V，表示每增加一伏特電位差需要分離多少庫侖電荷。

另一個困惑是同樣電壓下，板距變小為何 C 增大、場也增強。原因是 C 只問每伏特可分離多少電荷，而 E = V/d 問每公尺掉多少電位；兩者都可同時增大。要判斷安全性不能只看 C，還要看局部最大 E 是否越過介電強度。

白話直覺：電源搬開電荷，場替它保存做過的功

可暫把兩導體想成把正負電荷分居兩岸；比喻到此為止，精確狀態是兩導體間的電位差與場。源是電源搬運的自由電荷，正板到負板之間的 E 由正指向負；平行板遠離邊緣時近似均勻，同軸與球形的場則隨半徑變小，最大值都在內導體表面。

電源做的功存於電場覆蓋的空間，能量密度為 we = (1/2)E⋅D。加入高 ε 材料會極化並改變邊界電荷，因此相同幾何與 V 下能容納更多 Q；縮小間距也使 C 增大，但局部 E 上升，崩潰餘裕下降。LCR 表量到端口的交流電壓與電流相位，再回報該頻率的等效 C；它沒有直接看見場能。

空氣約在 3 MV/m 崩潰，FR−4 約 20 MV/m。本章預設 100 kV/m 是空氣門檻的 3.33 %；滑到 0.1 mm 與 1000 V 時則達 10 MV/m，真實空氣會先打火。常見 100 nF 陶瓷電容的等效 A/d 比本例大千倍以上，靠多層極薄陶瓷堆疊取得，不是靠一對巨大平板。

來源：08-電磁學-上 §6.1–§6.3。

推導：把高斯定律、電位差與充電做功接起來

平行板。忽略邊緣場，兩片無限大板各給 ρs/(2ε)，板間相加得 E = ρs/ε。又 V = Ed、ρs = Q/A，所以 V = Qd/(εA)，整理為 C = Q/V = εA/d。A 單位 m²，d 單位 m，ε 單位 F/m。假設介質線性、均質、等向且場靜態。

同軸與球形。同軸由柱對稱高斯面得 E(ρ) = ρℓ/(2περ)，積分 V = ∫ab E dρ = ρℓln(b/a)/(2πε)，因此每單位長度 C = 2πε/ln(b/a)。球形以球對稱積分得到 C = 4πε ⋅ ab/(b − a)。兩者必須 b > a，且內表面場最大；若幾何不合法，公式沒有物理意義。

儲能。充電途中已搬 q 時，瞬時電壓 v = q/C，再搬 dq 所需功為 dW = v dq。由 0 積到 Q，W = ∫0Q (q/C)dq = Q²/(2C) = (1/2)QV = (1/2)CV²。係數二分之一來自電壓從零線性升到終值，不是任意常數。

場能密度。平行板中 W = (1/2)(εA/d)(Ed)² = (1/2)εE²(Ad)。括號 Ad 是場所在體積，因此 we = (1/2)εE² = (1/2)E⋅D，單位 J/m³。對不均勻場要把 we 對全部空間積分，不能拿最大場乘整個體積。

還可用固定控制量分辨常見矛盾。電容器仍接著理想電壓源時，插入介質使 C 增大，電源補入電荷，W = (1/2)CV² 因而增加；先充電再斷開電源時 Q 固定，插入介質後 W = Q²/(2C) 反而下降，少掉的能量轉成把介質吸入的機械功。兩種答案都對，差別只在電源是否仍能交換電荷。

幾何也決定場的均勻程度。平行板公式忽略邊緣場，只有板寬遠大於間距時才準；同軸場隨 1/ρ 下降，球形場隨 1/r² 下降。這說明相同端口電壓不代表每處承受同樣電應力，絕緣設計必須查看尖角、內導體與材料交界的局部最大值。實務元件還有漏電阻、等效串聯電阻與寄生電感，理想 C 只在有限頻帶內成立。

若把板距減半而固定 V，理想 C 加倍、Q 加倍、W 加倍，E 也加倍；若固定 Q，C 加倍會讓 V 與 W 各減半。這組極端檢查能快速發現把控制條件混在一起的錯誤。當 d 接近表面粗糙度或材料厚度不均時，連續介質與均勻場假設也會先失效。

電容的尺度感也很重要：一法拉代表每一伏特就要分離一庫侖，對單層空氣平行板是極大的要求，所以本例只有皮法等級。商用微法與毫法元件靠高介電常數、極薄介質、巨大有效面積或電化學界面取得；數值大不代表體積中的每一處場都小，也不代表可承受更高電壓。

自由實驗：幾何、材料與電壓

兩導體之間填入均勻線性介質。切換平行板、同軸或球形構型，觀察幾何與 ε 如何決定 C，以及電壓如何決定 Q、W 與最大場。

不要混淆

  • 電容是每伏特分離多少電荷，不是最多能裝多少電；最大工作電壓由材料與幾何另行限制。
  • 兩片板總電荷為零，儲存的是電荷分離與場能，不是憑空增加淨電荷。
  • C 只由幾何與材料決定；在線性模型中改 V 會改 Q 與 W，不會改 C。
  • 平行板可用均勻 E = V/d；同軸與球形場不均勻，不能拿平均場判斷崩潰。
  • 電容並聯相加、串聯倒數相加，與電阻相反；根源是面積與距離的幾何關係。
  • LCR 表的 C 是指定頻率下的等效值，不保證在直流、高頻或接近崩潰時不變。

可觀察證據：端口讀值可驗幾何效應，不能直接看見場能

LCR 表在 1 kHz 或 100 kHz 等指定頻率量測交流端口關係，可比較板面積、間距與介質改變後的 C。兩片鋁箔隔紙即可量到數十 pF；若面積加倍而其他條件不變，讀值近似加倍，能支持 C ∝ A。

這能證明該頻率、該裝配下的等效電容與串並聯規則，不能直接證明能量位於場中；場能位置是由端口做功與空間能量密度積分得到同一 W 的理論與間接實驗結論。電表也不能單獨證明局部最大場或介電崩潰起點，邊緣場、漏電與寄生參數都會使理想模型偏離。

連到哪門課

電路學的電容與電感把 C 當集總元件並研究充放電；本章說明這個元件值從何而來。同軸每單位長度電容會與第 15 章的每單位長度電感共同決定 Z0 = √(L/C)，也是高速數位與射頻走線設計的入口。
