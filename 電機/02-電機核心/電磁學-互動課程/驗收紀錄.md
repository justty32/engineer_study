## 4. 缺陷清單

### P1（必修）

**P1-1｜`名詞與概念字典.html:20` 庫侖定律卡的對照句用了簡體「伦」**

- 原值：`對照表與普通物理課寫「&#24235;&#20262;」`
- `&#20262;` ＝ U+4F26 ＝ **伦（簡體）**；正體「倫」是 U+502B ＝ `&#20523;`
- 應為：`&#24235;&#20523;`
- 影響：瀏覽器實際渲染成「庫**伦**」（已用 Playwright 取得渲染後碼點確認：`5eab` `4f26`）。這是**全課唯一一個簡體字**
- 隱蔽性：因為寫成 HTML 數值實體，同時躲過了（a）位元組級「庫倫＝0」閘門、（b）位元組級簡體字掃描。純位元組掃描一律看不到，必須先 `html.unescape` 再掃
- 建議修法（sed 級）：`&#20262;` → `&#20523;`
- 附帶說明：builder 用實體規避「全課 0 個庫倫」閘門，是為了化解 spec 的**自我矛盾** —— BUILD-SPEC §5.3 要求這張卡引述「庫倫」二字，PROJECT-BRIEF 第 2 節與行 345 又規定「本課內出現『庫倫』就是錯字」。此解法本身可接受（意圖正確、渲染正確），但請 Lead 知悉「庫倫＝0」這道閘門目前只在位元組層成立，且建議把「掃描前先解碼 HTML 實體」寫回工作流踩雷清單
