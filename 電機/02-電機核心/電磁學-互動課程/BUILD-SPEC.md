## 3. 公式轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。不要用 Unicode 下標數字（₀₁₂），避免不同字型高度不一。
- Unicode 數學符號（限這份清單）：`∫ ∮ ∇ ∂ Σ √ ∞ ± × ⋅ ≈ ≠ ≤ ≥ ≪ ≫ ∝ ∥ ⊥ → ⇒ ⇔ ∈ ∠ ° ′ ″ | ‖`
- 希臘字母：`α β γ δ ε ζ η θ κ λ ρ σ τ φ χ ψ ω Δ Γ Θ Λ Σ Φ Ψ Ω π`
- **微符號一律用 `µ`（U+00B5 micro sign）**，含 µ<sub>0</sub>、µ<sub>r</sub>、µm、µT、µA、µF。**全檔不得出現 U+03BC 的 `μ`。**
- **負號一律用 U+2212 `−`**，不要用半形連字號 `-`（連字號只用在檔名與 CSS class）。
- 上標數字可直接用 `²` `³`；其餘次方用 `<sup>`。
- 歐姆符號用 `Ω`（U+03A9 希臘大寫 Omega），不要用 U+2126。
- **磁阻與磁動勢一律加下標 m：`R<sub>m</sub>` 與 `F<sub>m</sub>`**（避免和電阻 R、力 F 混淆；**不得只靠斜體區分**，斜體在不同字型下太隱晦）。帶第二層下標時併寫成一個下標，例如 `R<sub>m,鐵心</sub>`、`R<sub>m,氣隙</sub>`、`R<sub>m,總</sub>`，**不得寫成巢狀的 `R<sub>m</sub><sub>鐵心</sub>`**。首次出現要說明「下標 m 代表 magnetic，R<sub>m</sub> 是磁阻、F<sub>m</sub> 是磁動勢」。
- 單位一律半形英文緊接數字後空一格：`5 V`、`20 mA`、`1 kΩ`、`88.541878 pF`、`0.5 T`、`50 µT`、`376.730314 Ω`、`65.234115 µm`、`1.327209 × 10⁻³ W/m²`（指數用 `<sup>`）。

### 3.2 排版規則

1. **向量一律 `<b>`**：`<b>E</b>`、`<b>B</b>`、`<b>D</b>`、`<b>H</b>`、`<b>J</b>`、`<b>M</b>`、`<b>P</b>`、`<b>S</b>`、`<b>A</b>`、`<b>F</b>`、`<b>v</b>`、`<b>p</b>`、`<b>m</b>`。單位向量寫 `<b>a</b><sub>r</sub>`、`<b>a</b><sub>ρ</sub>`、`<b>a</b><sub>φ</sub>`、`<b>a</b><sub>z</sub>`、`<b>a</b><sub>n</sub>`。**非粗體的同一字母代表它的大小**（E = |<b>E</b>|）。
2. **複數相量一律 `<strong>`**：`<strong>E</strong>`、`<strong>Z</strong>`、`<strong>η</strong>`、`<strong>Γ</strong>`。14、15 章首次出現要點明它與 `<b>` 的差別。
3. **分數**：單行寫成 `(分子) / (分母)`，例如 `(µ<sub>0</sub>I) / (2πρ)`。分子分母都是單一符號時可省括號：`Q/(εA)`、`ℓ/(µA)`。
4. **多行分式**只在必要時用 `<pre>`，以 `─` 畫橫線，前後留一空行。
5. **導數**寫成 `dΦ/dt`、`∂<b>B</b>/∂t`；二階寫 `∂²<b>E</b>/∂t²`。不要用點記號。
6. **算子**：梯度 `∇V`、散度 `∇⋅<b>F</b>`、旋度 `∇×<b>F</b>`、拉普拉斯 `∇²V`。三者首次出現要各寫一次讀法（「讀作 del V／del dot F／del cross F」）。
7. **積分**：面積分 `∮<sub>S</sub> <b>E</b>⋅d<b>A</b>`、線積分 `∮<sub>C</sub> <b>B</b>⋅d<b>ℓ</b>`、體積分 `∫<sub>V</sub> ρ<sub>v</sub> dV`。封閉路徑或封閉面用 `∮`，開放的用 `∫`。
8. **指數中還有下標時，把下標壓平**：`e<sup>−αz</sup>`、`e<sup>j(ωt − kz)</sup>`。不得寫巢狀 `<sup><sub>`。
9. **複數**寫成直角式 `<strong>η</strong> = η′ + jη″` 與極式 `<strong>η</strong> = |η|∠θ`。**虛數單位一律寫 `j`**（電機慣例），首次出現要說明「數學課寫 i，電機寫 j，因為 i 留給電流」。
10. **函式名**（sin、cos、tan、exp、ln、log、arctan、Re、Im、rms、max）用一般半形英文，不加標記。
11. 公式所在段落用 `<p>`；需要凸顯時可用 `<code>`（`styles.css` 已設 `overflow-wrap:anywhere`）。
12. **幾何組態用文字描述**，格式固定：`點電荷 q<sub>1</sub> 在原點；q<sub>2</sub> 在 x 軸上距離 r 處；觀測點取兩者連線中點`。

### 00 `00-電磁世界觀.html`

**目標**：先講清楚電磁學到底在描述什麼——空間每一點都掛著四個場量（<b>E</b>、<b>D</b>、<b>B</b>、<b>H</b>），源是電荷與電流，四條馬克士威方程式把它們綁在一起——並且說明「什麼時候非用電磁學不可」：電路尺寸不再遠小於波長的時候。

**要點**：場（field）＝把一個量指派給空間每一點的函數，向量場每點掛一個向量；電磁學的五階段路線圖（靜電 → 靜磁 → 感應 → 完整時變 → 波與傳輸線，來源：08-電磁學-上「這科在學什麼」）；四個場量的分工：<b>E</b>（V/m，電場，作用在電荷上）、<b>D</b>（C/m²，電位移，只看自由電荷）、<b>B</b>（T，磁通密度，作用在動電荷上）、<b>H</b>（A/m，磁場強度，只看自由電流）；源＝電荷密度 ρ<sub>v</sub>（C/m³）與電流密度 <b>J</b>（A/m²）；c = 1/√(µ<sub>0</sub>ε<sub>0</sub>) ＝ 2.99792458 × 10<sup>8</sup> m/s，兩個「靜態實驗量到的常數」組合出光速，這是本課最重要的伏筆；介質中相速 v = c/√(ε<sub>r</sub>µ<sub>r</sub>)，折射率 n = √(ε<sub>r</sub>µ<sub>r</sub>)；波長 λ = v/f；集總近似的門檻 d < λ/20。

**推導必寫**：（a）量綱檢查 1/√(µ<sub>0</sub>ε<sub>0</sub>)：µ<sub>0</sub> 的單位 H/m、ε<sub>0</sub> 的單位 F/m，H⋅F = s²，所以 √(H⋅F/m²) 的倒數是 m/s——**光速不是硬塞進來的，是兩個電磁常數的單位自己約出來的**。（b）從 λ = v/f 推出「跨過整個電路的相位差 = 360° × d/λ」：訊號從一端傳到另一端要 t = d/v 秒，這段時間內源已經轉過 f⋅t 個週期。（c）門檻的來歷：取 d < λ/20（相位差 < 18°）作為集總近似可用的界線；這條在電路學 00 章出現過，本課是它的另一邊。

### 01 `01-向量場語言.html`

**目標**：把 ∇ 的三個用法（梯度、散度、旋度）從「符號」變成「可以讀出物理意義的儀表」，並用兩個積分定理把「每一點的微分性質」翻譯成「整塊區域的通量與環流」。

**要點**：梯度 ∇φ（純量場 → 向量場，指向上升最快的方向，大小是最大變化率）；散度 ∇⋅<b>F</b>（向量場 → 純量場，代表**單位體積的淨流出**，正值＝這裡有源、負值＝這裡有匯）；旋度 ∇×<b>F</b>（向量場 → 向量場，代表**單位面積的環流**，方向由右手定則給）；兩個恆等式：∇×(∇φ) = <b>0</b>（梯度場無旋——所以靜電場可以寫成 −∇V）、∇⋅(∇×<b>F</b>) = 0（旋度場無散——所以 <b>B</b> = ∇×<b>A</b> 自動滿足 ∇⋅<b>B</b> = 0）；散度定理 ∮<sub>S</sub> <b>F</b>⋅d<b>A</b> = ∫<sub>V</sub> (∇⋅<b>F</b>) dV；史托克斯定理 ∮<sub>C</sub> <b>F</b>⋅d<b>ℓ</b> = ∫<sub>S</sub> (∇×<b>F</b>)⋅d<b>A</b>；三種座標系與對稱性：直角（平板）、柱（同軸電纜、直導線）、球（點電荷、天線輻射）。來源：08-電磁學-上 §1.1–§1.3。

**推導必寫**：（a）散度的「小盒子」定義：取邊長 Δx、Δy、Δz 的盒子，x 方向淨流出 ≈ [F<sub>x</sub>(x+Δx) − F<sub>x</sub>(x)]ΔyΔz ≈ (∂F<sub>x</sub>/∂x)ΔxΔyΔz，三個方向加起來除以體積就是 ∇⋅<b>F</b> = ∂F<sub>x</sub>/∂x + ∂F<sub>y</sub>/∂y + ∂F<sub>z</sub>/∂z。（b）旋度的「小方框」定義：在 xy 平面取邊長 Δx、Δy 的方框，逆時針環流 ≈ (∂F<sub>y</sub>/∂x − ∂F<sub>x</sub>/∂y)ΔxΔy，除以面積就是 (∇×<b>F</b>)<sub>z</sub>。（c）散度定理的「相鄰面抵消」論證：把大區域切成很多小盒子，相鄰兩盒共用的那個面，通量一進一出剛好抵消，只剩最外層的面——所以體積分等於表面積分。史托克斯定理同理（相鄰小方框共用的邊，走向相反）。（d）本課的四條馬克士威方程式各用到哪一個：∇⋅<b>D</b> 與 ∇⋅<b>B</b> 用散度定理換成通量式，∇×<b>E</b> 與 ∇×<b>H</b> 用史托克斯定理換成環流式。

**數值實例**：取 <b>F</b> = (ax − ωy)<b>a</b><sub>x</sub> + (ay + ωx)<b>a</b><sub>y</sub> + bz<b>a</b><sub>z</sub>，a = 1、ω = 2、b = 1（單位 1/s），觀測半徑 r = 2 m。這個場是「向外擴張（a、b）＋繞 z 軸旋轉（ω）」的疊加。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 散度 | ∇⋅<b>F</b> = a + a + b = 2a + b = 2 + 1 | **3.000000 1/s** |
| 旋度 z 分量 | (∇×<b>F</b>)<sub>z</sub> = ∂F<sub>y</sub>/∂x − ∂F<sub>x</sub>/∂y = ω − (−ω) = 2ω | **4.000000 1/s** |

### 02 `02-庫侖定律與電場.html`

**目標**：從兩顆電荷的力出發，把「力」除掉試驗電荷變成「場」，並讓讀者算得出任一點的合成電場與電位。

**要點**：庫侖定律 <b>F</b> = q<sub>1</sub>q<sub>2</sub> / (4πε<sub>0</sub>r²) ⋅ <b>a</b><sub>r</sub>，同號相斥、異號相吸；ε<sub>0</sub> = 8.8541878128 × 10<sup>−12</sup> F/m，k = 1/(4πε<sub>0</sub>) = 8.9875517923 × 10<sup>9</sup> N⋅m²/C²；電場 <b>E</b> = <b>F</b>/q，單位 V/m ＝ N/C，**定義成「單位正試驗電荷受的力」**，所以電場方向＝正電荷會被推的方向；點電荷產生 E = kQ/r²；疊加原理：多個電荷的場直接**向量相加**（因為馬克士威方程式是線性的）；連續分布：線電荷密度 ρ<sub>ℓ</sub>（C/m）、面電荷密度 ρ<sub>s</sub>（C/m²）、體電荷密度 ρ<sub>v</sub>（C/m³），場由積分得到；三個經典結果——無限長線電荷 E = ρ<sub>ℓ</sub>/(2πε<sub>0</sub>ρ)（隨 1/ρ 衰減）、無限大面電荷 E = ρ<sub>s</sub>/(2ε<sub>0</sub>)（**與距離無關**）、均勻球殼殼外像點電荷在球心、殼內 E = 0。來源：08-電磁學-上 §2.1–§2.3。

**推導必寫**：（a）為什麼要引入「場」：庫侖定律描述的是**兩顆電荷之間**的力，一旦有第三顆就要重算所有配對；把「q<sub>1</sub> 在空間造出的東西」單獨拿出來叫 <b>E</b>，任何電荷放進去就受力 q<b>E</b>——這是「解耦」，和寫程式時把共用邏輯抽出來是同一個動作。（b）1/r² 的幾何來歷：從點源發出的通量固定，攤在半徑 r 的球面上，球面積 4πr² 隨 r² 長大，所以每單位面積的量隨 1/r² 掉。（c）疊加為什麼可以：庫侖定律對 q 是線性的，場方程也是線性的，所以兩個源的場就是各自場的向量和——**這條在非線性材料裡會失效**，要寫出來。（d）中點電場為什麼是相加不是相減：q<sub>1</sub> = +5 nC 在中點造出「離開 q<sub>1</sub>」的場，q<sub>2</sub> = −3 nC 在中點造出「指向 q<sub>2</sub>」的場，兩者**同方向**（都是從 q<sub>1</sub> 指向 q<sub>2</sub>），所以大小相加。

**數值實例**：q<sub>1</sub> = +5 nC 在原點、q<sub>2</sub> = −3 nC 在 x = 0.30 m、ε<sub>r</sub> = 1（真空），觀測點取兩者連線中點（x = 0.15 m）。

### 03 `03-高斯定律.html`

**目標**：讓讀者學會「挑一個對的高斯面，然後把積分變成乘法」，並理解高斯定律的微分形式就是「電場的源是電荷密度」。

**要點**：電通量 Ψ = ∮<sub>S</sub> <b>E</b>⋅d<b>A</b>（單位 V⋅m），意思是「穿過這個面的電場線總數」；高斯定律積分形式 ∮<sub>S</sub> <b>E</b>⋅d<b>A</b> = Q<sub>內</sub>/ε<sub>0</sub>——**只有封閉面內的電荷算數，外面的電荷貢獻淨通量為零**（進去多少出來多少）；微分形式 ∇⋅<b>E</b> = ρ<sub>v</sub>/ε<sub>0</sub>，由散度定理直接得到；使用條件：高斯面上 E 的大小要是常數、方向要與 d<b>A</b> 平行或垂直，這只有在球對稱、柱對稱、面對稱三種情形成立；含介電質的版本 ∇⋅<b>D</b> = ρ<sub>自由</sub>（第 05 章會用）。來源：08-電磁學-上 §3.1–§3.3。

**推導必寫**：（a）球對稱：以點電荷為心取半徑 r 的球面，面上 E 處處等大且處處法向，所以 ∮<b>E</b>⋅d<b>A</b> = E ⋅ 4πr² = Q/ε<sub>0</sub> → E = Q/(4πε<sub>0</sub>r²)。**庫侖定律不是假設，是高斯定律加球對稱的結果。**（b）柱對稱：以無限長線電荷為軸取半徑 ρ、長度 L 的圓柱面，兩個端面上 <b>E</b>⊥d<b>A</b> 貢獻 0，側面 E ⋅ 2πρL = ρ<sub>ℓ</sub>L/ε<sub>0</sub> → E = ρ<sub>ℓ</sub>/(2πε<sub>0</sub>ρ)。（c）面對稱：以無限大帶電平面為中心取一個「藥盒」，兩個底面各貢獻 EA，側面貢獻 0，2EA = ρ<sub>s</sub>A/ε<sub>0</sub> → E = ρ<sub>s</sub>/(2ε<sub>0</sub>)。**L 與 A 都消掉了，這就是「挑對面」的價值。**（d）從積分形式到微分形式：把封閉面縮小到一點，Q<sub>內</sub>/V → ρ<sub>v</sub>，左邊除以 V 依定義就是 ∇⋅<b>E</b>。（e）導體的靜電屏蔽：導體內部 <b>E</b> = 0（否則自由電荷會一直流動），所以完全包在導體殼裡的高斯面 Q<sub>內</sub> = 0——**法拉第籠不是把場擋住，是導體表面重新排列電荷把場抵消掉**。

**數值實例**：源強度 10（球：Q = 10 nC；線：ρ<sub>ℓ</sub> = 10 nC/m；面：ρ<sub>s</sub> = 10 nC/m²）、觀測距離 r = 10 cm = 0.10 m、ε<sub>r</sub> = 1。

### 04 `04-電位與電位梯度.html`

**目標**：讓讀者知道「先算純量 V、再取梯度得 <b>E</b>」幾乎永遠比直接算向量積分省事，並認識電偶極這個之後天線與介電質都會用到的基本模型。

**要點**：電位 V = −∫<sub>∞</sub><sup>P</sup> <b>E</b>⋅d<b>ℓ</b>，單位伏特 V ＝ J/C，物理意義是「把 1 C 正電荷從無窮遠搬到 P 點、外力要做的功」；<b>E</b> = −∇V，**負號代表場指向電位下降最快的方向**；點電荷 V = kQ/r（注意是 1/r 不是 1/r²）；電偶極（electric dipole）：±Q 相距 d，偶極矩 <b>p</b> = Q<b>d</b>（單位 C⋅m，方向由負指向正），遠場 V = p cos θ/(4πε<sub>0</sub>r²)、E 以 1/r³ 衰減，其中 E<sub>r</sub> = 2kp cos θ/r³、E<sub>θ</sub> = kp sin θ/r³；偶極在外加場中受力矩 <b>τ</b> = <b>p</b>×<b>E</b><sub>0</sub>；等位面（equipotential surface）：V 相同的點構成的面，<b>E</b> 與等位面**處處垂直**，導體在靜電平衡時整個是等位體；拉普拉斯方程 ∇²V = 0（區域內無自由電荷）與卜瓦松方程 ∇²V = −ρ<sub>v</sub>/ε<sub>0</sub>（有電荷），配合邊界條件就完全定解。來源：08-電磁學-上 §4.1–§4.5。

**推導必寫**：（a）為什麼 V 比 <b>E</b> 好算：<b>E</b> 是向量、多個源要做向量加法（三個分量各積一次）；V 是純量、多個源直接相加。算完 V 再取梯度，等於「先做簡單的加法、最後才做一次微分」。（b）路徑無關：靜電場是無旋場（∇×<b>E</b> = <b>0</b>），由史托克斯定理任何封閉路徑的環流為零，所以 ∫<b>E</b>⋅d<b>ℓ</b> 只跟起點終點有關——**這就是「電位」這個概念能存在的前提，第 11 章時變磁場出現後它就不再成立**。（c）點電荷電位：V = −∫<sub>∞</sub><sup>r</sup> (kQ/r′²) dr′ = kQ/r。（d）偶極遠場：兩個電荷到觀測點的距離差 ≈ d cos θ，V = kQ(1/r<sub>−</sub> − 1/r<sub>+</sub>) ≈ kQ ⋅ d cos θ/r² = kp cos θ/r²。（e）為什麼 <b>E</b>⊥等位面：沿等位面移動 dV = 0，而 dV = −<b>E</b>⋅d<b>ℓ</b>，所以 <b>E</b> 與該方向的 d<b>ℓ</b> 內積為零。

**數值實例**：Q = 10 nC、r = 10 cm = 0.10 m（點電荷模式）；偶極模式取同樣的 Q = 10 nC、間距 d = 10 mm = 0.010 m、θ = 0°、r = 0.10 m。

| 點電荷電位 | V = kQ/r = 8.9875517923 × 10<sup>9</sup> × 10<sup>−8</sup> / 0.10 | **898.755179 V** |
| 點電荷電場 | E = kQ/r² | **8987.551792 V/m** |
| 檢查 | E = V/r ？ 898.755179 / 0.10 | **8987.551792 ✓（僅對 1/r 型電位成立）** |

### 05 `05-介電質與邊界條件.html`

**目標**：講清楚 <b>D</b>、<b>E</b>、<b>P</b> 三者的分工，以及電場線穿過材料界面時為什麼會「折射」——這條規則之後在波導、反射、PCB 疊構裡都會再出現。

**要點**：極化（polarization）：材料在外加電場下內部正負電荷產生微小位移，形成一大堆排好方向的微小偶極，用極化向量 <b>P</b>（C/m²，單位體積的偶極矩）描述；電位移向量 <b>D</b> = ε<sub>0</sub><b>E</b> + <b>P</b>（C/m²）；線性等向介質 <b>P</b> = χ<sub>e</sub>ε<sub>0</sub><b>E</b>，所以 <b>D</b> = ε<b>E</b>，ε = ε<sub>0</sub>(1 + χ<sub>e</sub>) = ε<sub>0</sub>ε<sub>r</sub>，ε<sub>r</sub> 是純數；廣義高斯定律 ∇⋅<b>D</b> = ρ<sub>自由</sub>——**極化引發的束縛電荷自動藏在 <b>D</b> 裡，這就是引入 <b>D</b> 的全部理由**；束縛面電荷密度 ρ<sub>sb</sub> = <b>P</b>⋅<b>a</b><sub>n</sub>；邊界條件：E<sub>t1</sub> = E<sub>t2</sub>（切向連續，來自 ∮<b>E</b>⋅d<b>ℓ</b> = 0）、D<sub>n1</sub> − D<sub>n2</sub> = ρ<sub>s</sub>（法向差＝自由面電荷，來自高斯定律；無自由電荷時 D<sub>n</sub> 連續）；常見 ε<sub>r</sub>：真空 1、空氣 1.0006、PTFE 2.1、FR-4 約 4.4、玻璃 5–7、水 80。來源：08-電磁學-上 §5.1–§5.4。

**推導必寫**：（a）切向連續的來歷：跨界面取一個「扁長方形」路徑（長邊 Δℓ 貼著界面兩側、短邊趨近 0），靜電場環流為零 → E<sub>t1</sub>Δℓ − E<sub>t2</sub>Δℓ = 0。（b）法向條件的來歷：跨界面取一個「扁藥盒」（兩底面貼著界面兩側、側面趨近 0），高斯定律 → D<sub>n1</sub>A − D<sub>n2</sub>A = ρ<sub>s</sub>A。（c）折射律：把兩條件相除，tan θ<sub>2</sub>/tan θ<sub>1</sub> = ε<sub>r2</sub>/ε<sub>r1</sub>（θ 從法線量起）——**電場線往高介電常數那一側「躺平」**。（d）為什麼介質裡的場變小：外場把分子極化，分子在材料兩端造出與外場反向的束縛面電荷，這些束縛電荷的場把原場削弱到 1/ε<sub>r</sub>。（e）強調簡化假設：線性（P 正比於 E）、等向（各方向相同）、均質（處處相同）、無色散（ε 與頻率無關）。真實材料四條都會破，第 14 章會回頭處理色散與損耗。

**數值實例**：ε<sub>r1</sub> = 1（真空）→ ε<sub>r2</sub> = 4，入射角 θ<sub>1</sub> = 60°（從法線量起），介質 1 側的場 \|E<sub>1</sub>\| = 1000 V/m。

### 06 `06-電容與電場儲能.html`

**目標**：把電路學裡「C 是一個元件值」升級成「C = εA/d，由幾何與材料算出來」，並讓讀者知道能量其實存在**場**裡、不是存在「電容器」這個零件裡。

**要點**：一般定義 Q = CV（兩導體系統，一個帶 +Q、另一個帶 −Q），C 單位法拉 F ＝ C/V；三種常見構型——平行板 C = εA/d、同軸電纜每單位長度 C = 2πε/ln(b/a)、球形 C = 4πε ⋅ ab/(b − a)；儲能 W = (1/2)CV² = Q²/(2C) = (1/2)QV；場能量密度 w<sub>e</sub> = (1/2)<b>E</b>⋅<b>D</b> = (1/2)εE²（J/m³）——把 w<sub>e</sub> 對整個空間積分會得到同一個 W，**這證明能量是存在場裡的**；介電強度（dielectric strength）：空氣約 3 × 10<sup>6</sup> V/m、FR-4 約 2 × 10<sup>7</sup> V/m，超過就崩潰。來源：08-電磁學-上 §6.1–§6.3。

**推導必寫**：（a）平行板 C 的推導：板間為均勻場（來自第 03 章的面對稱結果，兩片板各貢獻 ρ<sub>s</sub>/(2ε)，相加得 ρ<sub>s</sub>/ε），V = Ed = ρ<sub>s</sub>d/ε = Qd/(εA)，所以 C = Q/V = εA/d。（b）同軸 C 的推導：由柱對稱高斯定律 E(ρ) = ρ<sub>ℓ</sub>/(2περ)，V = ∫<sub>a</sub><sup>b</sup> E dρ = ρ<sub>ℓ</sub>ln(b/a)/(2πε)，所以每單位長度 C = 2πε/ln(b/a)。（c）W 的推導：充電時把 dq 從一板搬到另一板要做功 v dq = (q/C)dq，積分得 W = Q²/(2C)。（d）能量密度：對平行板，W = (1/2)CV² = (1/2)(εA/d)(Ed)² = (1/2)εE² ⋅ (Ad)，而 Ad 正是板間體積——**係數 (1/2)εE² 就是每立方公尺的能量**。

**數值實例**：平行板 A = 100 cm² = 0.01 m²、d = 1 mm = 0.001 m、ε<sub>r</sub> = 1、V = 100 V。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 電容 | C = ε<sub>0</sub>ε<sub>r</sub>A/d = 8.8541878128 × 10<sup>−12</sup> × 0.01 / 0.001 | **88.541878 pF** |
| 電荷 | Q = CV = 8.8541878 × 10<sup>−11</sup> × 100 | **8.854188 nC** |
| 儲能 | W = (1/2)CV² | **442.709391 nJ** |
| 檢查 | W = Q²/(2C) | **442.709391 nJ ✓** |
| 板間場 | E = V/d = 100/0.001 | **100000.000000 V/m ＝ 100 kV/m** |
| 能量密度 | w<sub>e</sub> = (1/2)ε<sub>0</sub>E² | **0.044271 J/m³** |
| 檢查 | W = w<sub>e</sub> × (A × d) = 0.044271 × 10<sup>−5</sup> | **442.709391 nJ ✓（三種算法一致）** |
| 崩潰餘裕 | 100 kV/m ÷ 3000 kV/m | **3.33 %（安全）** |

邊界對照：同軸 a = 1 mm、b = 3.5 mm、ε<sub>r</sub> = 1 → ln(b/a) = **1.252763**、C = **44.407844 pF/m**；同一組尺寸換成 PTFE（ε<sub>r</sub> = 2.1）→ **93.256473 pF/m**。球形 a = 1 mm、b = 3.5 mm、ε<sub>r</sub> = 1 → **0.155771 pF**（**球形電容器小得驚人，這就是為什麼實務上不用它**）。把 ε<sub>r</sub> 從 1 拉到 4.4（FR-4）→ 平行板 C 變成 **389.584264 pF**。把 V 拉到 **1000 V** → E = 10<sup>6</sup> V/m，仍在空氣崩潰的 1/3。

### 07 `07-電流密度與焦耳熱.html`

**目標**：把電路學的 R = ρℓ/A 還原成場的語言 <b>J</b> = σ<b>E</b>，並用連續性方程埋下第 12 章位移電流的伏筆。

**要點**：電流密度 <b>J</b>（A/m²），I = ∫<sub>S</sub> <b>J</b>⋅d<b>A</b>；連續性方程 ∇⋅<b>J</b> = −∂ρ<sub>v</sub>/∂t（**這就是電荷守恆的微分形式**）；穩態下 ρ<sub>v</sub> 不隨時間變，所以 ∇⋅<b>J</b> = 0，電流線必為閉合迴路——**這正是 KCL 的來源**；場版歐姆定律 <b>J</b> = σ<b>E</b>，σ 是電導率（S/m），ρ = 1/σ 是電阻率（Ω⋅m）；焦耳熱功率密度 p = <b>J</b>⋅<b>E</b> = σE²（W/m³），對整體積分就是 I²R；電流的邊界條件：J<sub>n</sub> 連續（穩態電荷守恆），σ 不同的兩介質界面會積累自由面電荷直到平衡。來源：08-電磁學-上 §7.1–§7.4。

**推導必寫**：（a）從 <b>J</b> = σ<b>E</b> 推出 R = ρℓ/A：均勻導線裡 J = I/A、E = V/ℓ，代入得 I/A = σV/ℓ → V = I ⋅ ℓ/(σA) = IR，所以 R = ℓ/(σA) = ρℓ/A。**歐姆定律不是元件的性質，是材料性質加幾何積出來的。**（b）功率密度：p = <b>J</b>⋅<b>E</b> = (I/A)(V/ℓ)，乘上體積 Aℓ 得 IV ✓。（c）連續性方程的推導：對任一封閉面，流出的電流等於內部電荷的減少率，∮<b>J</b>⋅d<b>A</b> = −dQ<sub>內</sub>/dt，用散度定理縮到一點。（d）弛豫時間：把 <b>J</b> = σ<b>E</b> 與 ∇⋅<b>E</b> = ρ<sub>v</sub>/ε 代入連續性方程得 ∂ρ<sub>v</sub>/∂t = −(σ/ε)ρ<sub>v</sub>，解得 ρ<sub>v</sub> = ρ<sub>0</sub>e<sup>−t/τ</sup>，τ = ε/σ = ε<sub>0</sub>ρ（真空 ε 時）。銅的 τ ≈ **1.487504 × 10<sup>−19</sup> s**——**導體內部的淨電荷會在 10<sup>−19</sup> 秒內跑光，這就是「導體內部無淨電荷」的定量根據**。（e）漂移速度：I = nqv<sub>d</sub>A，銅的自由電子密度 n ≈ 8.5 × 10<sup>28</sup> /m³，1 A 流過 1 mm² 時 v<sub>d</sub> ≈ **7.342952 × 10<sup>−5</sup> m/s**——**電子每秒只爬 0.07 mm，但燈幾乎立刻亮，因為亮燈的是場不是電子**。

**數值實例**：銅線 ρ = 1.68 × 10<sup>−8</sup> Ω⋅m（σ = 5.952380952 × 10<sup>7</sup> S/m）、長度 ℓ = 10 m、截面積 A = 1 mm² = 10<sup>−6</sup> m²、I = 1 A。

### 08 `08-磁場與羅倫茲力.html`

**目標**：把磁場定義成「作用在**動**電荷上的那一部分力」，並用 ∇⋅<b>B</b> = 0（沒有磁單極）把它和電場徹底區分開。

**要點**：羅倫茲力 <b>F</b> = q(<b>E</b> + <b>v</b>×<b>B</b>)，磁力部分**永遠垂直於速度，所以磁場對粒子不做功、只改變方向**；<b>B</b> 稱磁通密度（magnetic flux density），單位特斯拉 T ＝ Wb/m² ＝ N/(A⋅m)；電流元受力 d<b>F</b> = I d<b>ℓ</b>×<b>B</b>，直導線在均勻場中 F = BIL sin θ——**這是馬達轉矩的源頭**；磁高斯定律 ∇⋅<b>B</b> = 0 ⇔ ∮<sub>S</sub> <b>B</b>⋅d<b>A</b> = 0，意義是**沒有磁單極**，磁力線必為閉合迴圈；帶電粒子在均勻 <b>B</b> 中做圓周運動，迴旋半徑 r = mv/(qB)、迴旋頻率 f<sub>c</sub> = qB/(2πm)（**與速度無關，這是迴旋加速器能運作的原因**）；量級：地磁約 50 µT、冰箱磁鐵約 5 mT、喇叭磁鐵約 1 T、醫用 MRI 1.5–3 T。來源：08-電磁學-中 §8.1–§8.2。

**推導必寫**：（a）為什麼磁力不做功：功率 P = <b>F</b>⋅<b>v</b> = q(<b>v</b>×<b>B</b>)⋅<b>v</b>，而 <b>v</b>×<b>B</b> 必然垂直於 <b>v</b>，內積為零。**所以磁鐵不能給粒子能量，只能轉向。**（b）迴旋半徑：圓周運動需要向心力 mv²/r = qvB → r = mv/(qB)。（c）迴旋頻率：f<sub>c</sub> = v/(2πr) = qB/(2πm)，**v 消掉了**。（d）導線受力：把 d<b>F</b> = I d<b>ℓ</b>×<b>B</b> 對整根直導線積分，均勻場下得大小 BIL sin θ。（e）∇⋅<b>B</b> = 0 的後果：磁通量對任何封閉面都是零 → 進去多少出來多少 → 磁力線不能有起點終點 → **不存在「磁荷」**。這和 ∇⋅<b>E</b> = ρ<sub>v</sub>/ε<sub>0</sub> 形成本課最重要的一組對照。

**安全警語（`p.warning` 必寫）**：釹鐵硼強磁鐵在幾公分距離就能互相吸合並夾傷手指；強磁場會干擾心律調節器、機械錶與磁卡；MRI 室內的鐵器會被吸成飛彈。

**數值實例**：質子（q = 1.602176634 × 10<sup>−19</sup> C、m = 1.67262192369 × 10<sup>−27</sup> kg）以 v = 1 × 10<sup>6</sup> m/s 垂直射入 B = 0.5 T 的均勻磁場（θ = 90°）。

| --- | --- | --- |
| 磁力 | F = qvB sin 90° = 1.602176634 × 10<sup>−19</sup> × 10<sup>6</sup> × 0.5 | **8.010883 × 10<sup>−14</sup> N** |
| 迴旋半徑 | r = mv/(qB) | **0.020879 m ＝ 2.09 cm** |

### 09 `09-畢歐沙伐與安培定律.html`

**目標**：讓讀者能從「電流的形狀」算出「磁場的分佈」，並看出安培定律與高斯定律是同一種「挑對路徑／挑對面」的技巧。

**要點**：畢歐—沙伐定律（Biot–Savart law）d<b>B</b> = (µ<sub>0</sub>/4π) ⋅ I d<b>ℓ</b>×<b>a</b><sub>R</sub>/R²，µ<sub>0</sub> = 4π × 10<sup>−7</sup> H/m；三個經典結果——無限長直導線 B = µ<sub>0</sub>I/(2πρ)（同心圓，右手定則）、圓形迴圈軸線上 B = µ<sub>0</sub>Ia²/(2(a² + z²)<sup>3/2</sup>)、無限長螺線管內部 B = µ<sub>0</sub>nI（**均勻，與位置無關**）、外部 ≈ 0；安培定律（Ampère's law，靜態版）∮<sub>C</sub> <b>B</b>⋅d<b>ℓ</b> = µ<sub>0</sub>I<sub>穿過</sub>，微分形式 ∇×<b>B</b> = µ<sub>0</sub><b>J</b>；磁偶極矩 <b>m</b> = I<b>A</b>（A⋅m²），遠場與電偶極同形；磁向量位（magnetic vector potential）<b>A</b>：由 ∇⋅<b>B</b> = 0 可定義 <b>B</b> = ∇×<b>A</b>，在庫侖規範下 ∇²<b>A</b> = −µ<sub>0</sub><b>J</b>，與 ∇²V = −ρ<sub>v</sub>/ε<sub>0</sub> 同形——**天線輻射的標準工具**。來源：08-電磁學-中 §9.1–§9.2、第 11 章。

**推導必寫**：（a）用安培定律算直導線：以導線為軸取半徑 ρ 的圓，由對稱性 B 在圓上處處等大且沿切向，∮<b>B</b>⋅d<b>ℓ</b> = B ⋅ 2πρ = µ<sub>0</sub>I → B = µ<sub>0</sub>I/(2πρ)。**和第 03 章球對稱算 E 是完全同一個動作。**（b）用安培定律算螺線管：取一個長方形路徑，一長邊在管內、另一長邊在管外（B ≈ 0），兩短邊與 <b>B</b> 垂直（貢獻 0），得 Bℓ = µ<sub>0</sub>(nℓ)I → B = µ<sub>0</sub>nI。（c）圓迴圈軸線上必須用畢歐—沙伐（**沒有對稱性可以讓安培定律用**）：每個 d<b>ℓ</b> 的貢獻中垂直軸的分量互相抵消，只剩沿軸分量，積分得 µ<sub>0</sub>Ia²/(2(a² + z²)<sup>3/2</sup>)。（d）安培定律「什麼時候不能用」：路徑上 B 大小不固定、或方向與 d<b>ℓ</b> 夾角會變時，∮ 拆不出 B——**定律仍然對，只是解不出來**。（e）<b>A</b> 存在的理由：∇⋅(∇×<b>A</b>) ≡ 0 恆成立，所以只要寫成 <b>B</b> = ∇×<b>A</b>，∇⋅<b>B</b> = 0 就自動滿足，不必再當條件檢查。

**數值實例**：I = 10 A。

| 組態 | 算式 | 結果 |
| --- | --- | --- |
| 無限長直導線，ρ = 5 cm | B = µ<sub>0</sub>I/(2πρ) = 4π × 10<sup>−7</sup> × 10 / (2π × 0.05) | **4.000000 × 10<sup>−5</sup> T ＝ 40.000000 µT** |
| 圓迴圈 a = 5 cm，軸心 z = 0 | B = µ<sub>0</sub>I/(2a) | **1.256637 × 10<sup>−4</sup> T ＝ 125.663706 µT** |
| 螺線管 n = 10 匝/cm（＝1000 匝/m） | B = µ<sub>0</sub>nI | **1.256637 × 10<sup>−2</sup> T ＝ 12.566371 mT** |
| 圓迴圈的磁偶極矩 | m = Iπa² = 10 × π × 0.0025 | **0.078540 A⋅m²** |

**量級對照必寫**：直導線在 5 cm 外只有 40 µT，**跟地磁 50 µT 同一個量級**——這就是為什麼指南針放在有電流的線旁邊會偏。螺線管把同樣的電流繞成 1000 匝/m，磁場放大 314 倍。

邊界對照：ρ 從 5 cm 縮到 **1 cm** → **200.000000 µT**（× 5，1/ρ）；拉到 **20 cm** → **10.000000 µT**。圓迴圈在軸上 z = **5 cm**（＝ a）→ **44.428829 µT**（掉到 35.4 %）；z = **10 cm** → **11.239704 µT**。螺線管 n = **50 匝/cm** → **62.831853 mT**。

### 10 `10-磁性材料與磁路.html`

**目標**：把 <b>B</b> 與 <b>H</b> 分清楚，並用「磁路類比」讓讀者能像算電路一樣算變壓器與馬達鐵心——順帶看見氣隙的破壞力有多大。

**要點**：磁化向量 <b>M</b>（A/m，單位體積的磁偶極矩）；磁場強度 <b>H</b> 的定義 <b>B</b> = µ<sub>0</sub>(<b>H</b> + <b>M</b>)，線性介質 <b>M</b> = χ<sub>m</sub><b>H</b> 所以 <b>B</b> = µ<sub>0</sub>(1 + χ<sub>m</sub>)<b>H</b> = µ<b>H</b>，µ = µ<sub>0</sub>µ<sub>r</sub>；**<b>H</b> 由自由電流決定（∮<b>H</b>⋅d<b>ℓ</b> = I<sub>自由</sub>），<b>B</b> 才是真正作用在電荷上的場**——這和 <b>D</b>／<b>E</b> 的分工完全對應；三類材料：抗磁性（diamagnetic，µ<sub>r</sub> 略小於 1）、順磁性（paramagnetic，µ<sub>r</sub> 略大於 1）、鐵磁性（ferromagnetic，µ<sub>r</sub> 很大且非線性、有磁滯）；磁滯曲線（B–H curve）：剩磁 B<sub>r</sub>（H = 0 時殘留的 B）、矯頑磁力 H<sub>c</sub>（把 B 拉回零所需的反向 H）、磁滯損耗每週期＝迴圈面積；渦流損：高頻時用矽鋼片疊層或鐵氧體降低；磁路類比 磁動勢 F<sub>m</sub> = NI ↔ EMF、磁阻 R<sub>m</sub> = ℓ/(µA) ↔ 電阻、磁通 Φ ↔ 電流、F<sub>m</sub> = ΦR<sub>m</sub> ↔ V = IR；串聯磁阻相加（鐵心＋氣隙）；電感 L = N²/R<sub>m,總</sub>；磁場邊界條件：H<sub>t1</sub> − H<sub>t2</sub> = K<sub>s</sub>（表面電流密度，無則連續）、B<sub>n1</sub> = B<sub>n2</sub>（法向連續）。來源：08-電磁學-中 §10.1–§10.5。

**推導必寫**：（a）磁路類比為什麼成立：對均勻鐵心用安培定律 ∮<b>H</b>⋅d<b>ℓ</b> = Hℓ = NI，而 Φ = BA = µHA，兩式相除得 NI = Φ ⋅ ℓ/(µA)——**形式與 V = IR 完全一樣**。（b）串聯磁阻：磁通在鐵心與氣隙裡是同一個 Φ（∇⋅<b>B</b> = 0 保證磁通連續、B<sub>n</sub> 連續），兩段的磁動勢降相加，所以 R<sub>m,總</sub> = R<sub>m,鐵心</sub> + R<sub>m,氣隙</sub>。（c）為什麼 1 mm 的氣隙就能主宰 300 mm 的鐵心：R<sub>m</sub> ∝ ℓ/µ，氣隙的 µ<sub>r</sub> = 1、鐵心的 µ<sub>r</sub> = 2000，所以 1 mm 空氣「等效」於 2000 mm 鐵心。（d）L = N²/R<sub>m</sub> 的推導：Φ = NI/R<sub>m</sub>，磁通連結 λ = NΦ = N²I/R<sub>m</sub>，L = λ/I = N²/R<sub>m</sub>。（e）磁路類比的**失效條件**必寫：漏磁（磁通不像電流那樣被絕緣體關住，空氣的 µ 不是 0）、飽和（µ<sub>r</sub> 不是常數，B 超過約 1.5 T 後急遽下降）、磁滯（B 不是 H 的單值函數）。**這三條是本章最重要的誠實聲明。**

**安全警語（`p.warning` 必寫）**：鐵心飽和後電感急遽下降、電流暴衝，是變壓器與返馳電源燒毀的典型原因；繞組長時間過流會過熱、絕緣劣化。

**數值實例**：環形鐵心 µ<sub>r</sub> = 2000、平均磁路長 ℓ = 0.30 m（固定）、截面積 A = 4 cm² = 4 × 10<sup>−4</sup> m²（固定）、N = 200 匝、I = 0.5 A、氣隙 g = 0。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 磁動勢 | F<sub>m</sub> = NI = 200 × 0.5 | **100.000000 A⋅匝** |

| 磁通 | Φ = F<sub>m</sub>/R<sub>m</sub> | **3.351032 × 10<sup>−4</sup> Wb** |

**不要混淆**：<b>H</b> 不是「<b>B</b> 除以 µ<sub>0</sub>」的簡寫——在磁性材料裡兩者差 µ<sub>r</sub> 倍，且**界面上連續的是 B 的法向與 H 的切向**；µ<sub>r</sub> 對鐵磁材料不是常數，寫「µ<sub>r</sub> = 2000」時必須說明是某個工作點附近的近似；磁阻的單位是 A/Wb 不是 Ω，磁路類比只是形式相同、物理完全不同（磁通不消耗能量，磁阻不是耗散元件）；磁滯損與渦流損是兩件事——前者正比於頻率、後者正比於頻率平方，所以高頻時渦流損主導。

**可觀察證據**：高斯計伸進氣隙可以直接量到氣隙裡的 B（**鐵心內部量不到，沒有探頭塞得進去**）；LCR 表量繞組電感，再由 L = N²/R<sub>m</sub> 反推 µ<sub>r</sub>；B–H 分析儀用一次側激磁、二次側積分感應電壓，畫出整條磁滯迴圈。**能證明**：氣隙磁通密度、繞組電感、磁滯迴圈面積（＝每週期損耗）、飽和點。**不能證明**：鐵心內部的 <b>M</b> 分佈；也量不到「磁阻」本身（那是由 Φ 與 F<sub>m</sub> 反推的模型量）。

### 11 `11-電磁感應.html`

**目標**：把法拉第定律的兩種面貌（動生與變生）講成同一件事，並讓讀者算得出感應電動勢、感應電流與**必然出現的反抗力**。

**要點**：法拉第定律 ε<sub>emf</sub> = −dΦ<sub>B</sub>/dt（**這裡的 ε<sub>emf</sub> 是電動勢，不是介電常數，本課一律加下標 emf**），微分形式 ∇×<b>E</b> = −∂<b>B</b>/∂t；**時變磁場讓 <b>E</b> 不再是無旋場，所以第 04 章的「電位」在這裡失效**——繞一圈回到原點，電位不再回到原值；冷次定律（Lenz's law）：感應電流的方向總是反抗磁通的變化，這就是負號的物理意義，根據是能量守恆（否則可以「免費」拿到功）；動生 EMF（motional）：導體在固定磁場中運動，ε<sub>emf</sub> = ∮(<b>v</b>×<b>B</b>)⋅d<b>ℓ</b>，直棒得 ε<sub>emf</sub> = BLv——**發電機原理**；變生 EMF：固定迴路、變化磁場，N 匝線圈 ε<sub>emf</sub> = −N dΦ/dt——**變壓器原理**；兩者是同一條定律的兩種情形；自感 Φ<sub>self</sub> = LI，互感 M<sub>12</sub> = M<sub>21</sub> = k√(L<sub>1</sub>L<sub>2</sub>)，k ∈ [0, 1] 是耦合係數；電感儲能 W = (1/2)LI²，場能量密度 w<sub>m</sub> = (1/2)<b>H</b>⋅<b>B</b> = B²/(2µ)；理想變壓器 V<sub>2</sub>/V<sub>1</sub> = N<sub>2</sub>/N<sub>1</sub>、I<sub>2</sub>/I<sub>1</sub> = N<sub>1</sub>/N<sub>2</sub>、阻抗轉換 Z<sub>ref</sub> = Z<sub>2</sub>(N<sub>1</sub>/N<sub>2</sub>)²；實務有銅損、鐵損（磁滯＋渦流）、漏感（k < 1）。來源：08-電磁學-中 §12.1–§12.5。

**推導必寫**：（a）動生 EMF 的來歷**不是新定律**：導體裡的自由電子隨棒以 v 移動，受羅倫茲力 q<b>v</b>×<b>B</b>，這個力沿棒的方向把電荷推到一端，等效電場 <b>v</b>×<b>B</b>，沿棒積分得 ε<sub>emf</sub> = BLv。（b）冷次定律的能量論證：若感應電流的磁場**協助**原來的變化，磁通會愈變愈快、電流愈來愈大，能量憑空產生。所以方向必須是反抗的。（c）反抗力的定量：感應電流 I = BLv/R 流過磁場中的棒，受力 F = BIL = B²L²v/R，方向與 v 相反；機械功率 Fv = B²L²v²/R，恰等於電功率 ε<sub>emf</sub>I = I²R——**你手上感覺到的阻力，就是電阻上發的熱**。這條等式必須算出來給讀者看。（d）變生 EMF：Φ(t) = B<sub>0</sub>A sin(2πft)，dΦ/dt = B<sub>0</sub>A ⋅ 2πf cos(2πft)，峰值 ε<sub>max</sub> = N B<sub>0</sub>A ⋅ 2πf。（e）自感 L 就是第 10 章的 N²/R<sub>m</sub>；互感的 k 由「有多少比例的磁通同時穿過兩個線圈」決定，鐵心變壓器 k ≈ 0.99，空心耦合線圈 k 可能只有 0.3。

**安全警語（`p.warning` 必寫）**：電感在電流被突然切斷時會產生極高的反電動勢（V = L di/dt），繼電器與馬達線圈務必並上續流二極體或緩衝電路；感應加熱設備與大型電感附近不要放金屬飾品。

### 12 `12-位移電流與馬克士威方程式.html`

**目標**：讓讀者親眼看見「靜態安培定律在時變時自相矛盾」，理解馬克士威補上的那一項為什麼非有不可，並把四條方程式收攏成一張表。

**要點**：靜態安培定律的缺陷：對 ∇×<b>B</b> = µ<sub>0</sub><b>J</b> 兩邊取散度，左邊恆為 0（旋度場無散），右邊得 µ<sub>0</sub>∇⋅<b>J</b>，但連續性方程說 ∇⋅<b>J</b> = −∂ρ<sub>v</sub>/∂t 在時變時不為 0——**方程式自己打自己**；馬克士威的補丁：位移電流密度 <b>J</b><sub>d</sub> = ε<sub>0</sub> ∂<b>E</b>/∂t，補成 ∇×<b>B</b> = µ<sub>0</sub><b>J</b> + µ<sub>0</sub>ε<sub>0</sub> ∂<b>E</b>/∂t，兩邊取散度後與連續性方程自洽；物理意義：**變化的電場也會產生磁場**，與法拉第定律「變化的磁場產生電場」對稱，兩者一起才能形成電磁波；完整的馬克士威方程式（微分形式）：∇⋅<b>D</b> = ρ<sub>自由</sub>、∇⋅<b>B</b> = 0、∇×<b>E</b> = −∂<b>B</b>/∂t、∇×<b>H</b> = <b>J</b> + ∂<b>D</b>/∂t；加上羅倫茲力與材料關係（<b>D</b> = ε<b>E</b>、<b>B</b> = µ<b>H</b>、<b>J</b> = σ<b>E</b>）就決定整個經典電磁世界；損耗角正切 tan δ = σ/(ωε)——**傳導電流與位移電流的比值**，第 14 章用它來分導體與介質。來源：08-電磁學-中 §13.1–§13.3。

**推導必寫**：（a）矛盾的具體場景：對一個正在充電的電容器，取一條繞著導線的安培路徑 C。若把 S 取成穿過導線的平面，I<sub>穿過</sub> = I；若把 S 取成鼓起來、從兩板之間穿過的曲面（**同一條 C，不同的 S**），I<sub>穿過</sub> = 0。同一個 ∮<b>B</b>⋅d<b>ℓ</b> 得到兩個答案——**這是災難**。（b）補丁怎麼救：板間雖然沒有傳導電流，但電場正在增加，ε<sub>0</sub> ∂E/∂t 乘上板面積剛好等於導線裡的 I。（c）**證明兩者相等**：E = Q/(εA)，所以 I<sub>d</sub> = εA ⋅ dE/dt = dQ/dt = I<sub>傳導</sub>。用元件語言看：I = C dV/dt，而 C = εA/d、V = Ed，代回去也是同一件事。（d）四條方程式的「讀法」逐條寫：第一條說電場的源是電荷；第二條說磁場沒有源（沒有磁單極）；第三條說變化的磁場繞出電場；第四條說電流**與變化的電場**都繞出磁場。（e）強調 ∂<b>D</b>/∂t 不是「真的有電荷在流」——它是一項「等效電流」，但它產生的磁場是真的。

**數值實例**：平行板 A = 100 cm² = 0.01 m²、d = 1 mm = 0.001 m、真空（ε<sub>r</sub> = 1、σ = 0）、外加 v(t) = 100 sin(2π × 1000 t) V。**幾何與第 06 章完全相同。**

### 13 `13-電磁波與平面波.html`

**目標**：把四條方程式在無源真空裡解成波動方程，看見光速自己跑出來，並讓讀者算得出平面波的每一個參數。

**要點**：無源真空（ρ = 0、<b>J</b> = 0）下對 ∇×<b>E</b> = −∂<b>B</b>/∂t 再取一次旋度，用恆等式 ∇×(∇×<b>E</b>) = ∇(∇⋅<b>E</b>) − ∇²<b>E</b> 與 ∇⋅<b>E</b> = 0，代入第四條得 ∇²<b>E</b> = µ<sub>0</sub>ε<sub>0</sub> ∂²<b>E</b>/∂t²——**波動方程**；波速 c = 1/√(µ<sub>0</sub>ε<sub>0</sub>) = 2.99792458 × 10<sup>8</sup> m/s，**光速自動出現，馬克士威在這裡把電、磁、光統一了**；平面波解（沿 +z、<b>E</b> 沿 x）：E<sub>x</sub> = E<sub>0</sub>cos(ωt − kz)、H<sub>y</sub> = (E<sub>0</sub>/η)cos(ωt − kz)；關鍵性質：<b>E</b>⊥<b>H</b>⊥傳播方向（**橫波**）、E/H = η（本質阻抗）、k = 2π/λ = ω/v；介質中 v = c/n、n = √(ε<sub>r</sub>µ<sub>r</sub>)、η = η<sub>0</sub>√(µ<sub>r</sub>/ε<sub>r</sub>)、η<sub>0</sub> = √(µ<sub>0</sub>/ε<sub>0</sub>) = 376.730314 Ω（**常見的「120π = 376.991118 Ω」是近似值，差 0.069 %**）；坡印廷向量 <b>S</b> = <b>E</b>×<b>H</b>（W/m²）代表能量流動的瞬時方向與密度，平面波的平均值 ⟨S⟩ = E<sub>0</sub>²/(2η)；偏振（polarization）：<b>E</b> 隨時間描出的軌跡——線性、圓（左旋／右旋）、橢圓，應用於 3D 眼鏡、衛星通訊、雷達。來源：08-電磁學-下 §14.1–§14.4。

**推導必寫**：（a）完整寫出取兩次旋度的過程與用到的兩個恆等式。（b）量綱檢查 1/√(µ<sub>0</sub>ε<sub>0</sub>)（與第 00 章呼應，這裡要把數字算出來：1/√(4π × 10<sup>−7</sup> × 8.8541878128 × 10<sup>−12</sup>) = 2.99792458 × 10<sup>8</sup>）。（c）為什麼是橫波：代入 ∇⋅<b>E</b> = 0，對 e<sup>−jkz</sup> 形式的解得 −jk E<sub>z</sub> = 0 → E<sub>z</sub> = 0，**沿傳播方向沒有分量**。（d）η 的來歷：把平面波解代入 ∇×<b>E</b> = −∂<b>B</b>/∂t 得 kE<sub>0</sub> = ωµH<sub>0</sub> → E<sub>0</sub>/H<sub>0</sub> = ωµ/k = µv = √(µ/ε) = η。（e）⟨S⟩ 的推導：S(t) = E<sub>0</sub>H<sub>0</sub>cos²(ωt − kz)，cos² 的時間平均是 1/2，所以 ⟨S⟩ = E<sub>0</sub>H<sub>0</sub>/2 = E<sub>0</sub>²/(2η)。（f）簡化假設必寫：無限大平面波是理想化（真實波源在遠場才近似成平面波）；線性、均質、等向、無損、無色散。

### 14 `14-介質中的波與界面.html`

**目標**：讓讀者算得出「某個材料在某個頻率下算導體還是介質」、屏蔽要多厚、以及波打到界面會反射多少——這一章是 EMC 與屏蔽設計的全部數學基礎。

**要點**：時諧場用相量寫成 <b>E</b>(<b>r</b>, t) = Re{<strong>E</strong>(<b>r</b>)e<sup>jωt</sup>}（**這裡的 `<strong>` 是複數相量，與空間向量的 `<b>` 不同**）；複介電常數 ε<sub>c</sub> = ε − jσ/ω，損耗比（損耗角正切）p = tan δ = σ/(ωε)；傳播常數 γ = α + jβ = jω√(µε<sub>c</sub>)，α 是衰減常數（Np/m）、β 是相位常數（rad/m）；波形 E = E<sub>0</sub>e<sup>−αz</sup>cos(ωt − βz)；良導體（σ ≫ ωε）：α ≈ β ≈ √(ωµσ/2)，**趨膚深度** δ = 1/α ≈ √(2/(ωµσ))，高頻訊號只在導體表面薄層流動；良介質（σ ≪ ωε）：α ≈ (σ/2)√(µ/ε)、β ≈ ω√(µε)；本質阻抗變成複數 <strong>η</strong> = √(µ/ε<sub>c</sub>)；垂直入射的反射係數 Γ = (η<sub>2</sub> − η<sub>1</sub>)/(η<sub>2</sub> + η<sub>1</sub>)、透射係數 T = 1 + Γ、功率反射率 |Γ|²、回波損耗 −20 log<sub>10</sub>|Γ|（dB）；斜入射要分 TE/TM 用 Fresnel 公式（**本課不做**），但兩個角度要記：布魯斯特角 θ<sub>B</sub> = arctan(n<sub>2</sub>/n<sub>1</sub>)（TM 波完全透射）、全反射的臨界角 sin θ<sub>c</sub> = n<sub>2</sub>/n<sub>1</sub>（只在密 → 疏時存在，**光纖通訊的核心原理**）；每一個趨膚深度衰減 8.685890 dB（＝20 log<sub>10</sub>e）。來源：08-電磁學-下 §15.1–§15.3。

**推導必寫**：（a）ε<sub>c</sub> 的來歷：把 ∇×<b>H</b> = σ<b>E</b> + jωε<b>E</b> 提出 jω 得 jω(ε − jσ/ω)<b>E</b>——**傳導電流被吸收進一個複數的 ε，之後所有無損公式原樣可用**。（b）**本課採用的實數化寫法（app.js 照這個做，不需要複數類別）**：令 q = arctan(p)、u = (1 + p²)<sup>1/4</sup>，則 γ = (ω/v)⋅u∠(90° − q/2)，所以 α = (ω/v)⋅u⋅sin(q/2)、β = (ω/v)⋅u⋅cos(q/2)，其中 v = c/√(ε<sub>r</sub>µ<sub>r</sub>)；同理 |η| = (η<sub>0</sub>√(µ<sub>r</sub>/ε<sub>r</sub>))/u、∠η = q/2。**這組式子對任意 p 都精確（不是近似），已用複數 `cmath` 獨立驗證到 9 位有效數字。**（c）良導體極限的檢查：p → ∞ 時 q → 90°、u → √p，α → (ω/v)√p/√2 = √(ωµσ/2) ✓。（d）為什麼趨膚：導體裡的波邊走邊被 σ 吃掉能量，每走 δ 振幅剩 1/e = 36.8 %、功率剩 13.5 %。（e）Γ 的來歷：界面上 E 的切向與 H 的切向都要連續，入射＋反射 = 透射，兩式聯立解出 Γ。（f）dB 換算：衰減 t/δ 個 Np，換成 dB 要乘 20 log<sub>10</sub>e = 8.685890。

### 15 `15-傳輸線與駐波.html`

**目標**：收線。把第 00 章「d/λ 太大就不能用電路學」這句話兌現成一套可算的工具：特性阻抗、反射係數、駐波比與輸入阻抗。

**要點**：訊號頻率高到波長與電路尺寸可比時集總假設失效，要用**分佈元件**：每單位長度的 L、C（無損）與 R、G（有損）；電報員方程（telegrapher's equations）∂V/∂z = −(R + jωL)I、∂I/∂z = −(G + jωC)V，解是**兩個反向行進的波**；特性阻抗 Z<sub>0</sub> = √((R + jωL)/(G + jωC)) →（無損）√(L/C)，傳播常數 γ = √((R + jωL)(G + jωC)) →（無損）jω√(LC)，相速 v<sub>p</sub> = 1/√(LC)；典型同軸 Z<sub>0</sub> ∈ {50, 75} Ω；負載反射係數 Γ<sub>L</sub> = (Z<sub>L</sub> − Z<sub>0</sub>)/(Z<sub>L</sub> + Z<sub>0</sub>)——**與第 14 章的界面反射是完全同一條式子，只是 η 換成 Z<sub>0</sub>**；Z<sub>L</sub> = Z<sub>0</sub> 無反射（匹配）、Z<sub>L</sub> = 0 或 ∞ 全反射（全駐波）；駐波比 VSWR = (1 + |Γ|)/(1 − |Γ|)，理想 1；輸入阻抗 Z<sub>in</sub>(ℓ) = Z<sub>0</sub>(Z<sub>L</sub> + jZ<sub>0</sub>tan βℓ)/(Z<sub>0</sub> + jZ<sub>L</sub>tan βℓ)——**阻抗會隨你站的位置改變，這是傳輸線最反直覺的地方**；λ/4 轉換器：βℓ = 90° 時 Z<sub>in</sub>Z<sub>L</sub> = Z<sub>0</sub>²，要把 Z<sub>L</sub> 變成 Z<sub>in</sub> 只要插一段 Z<sub>0</sub> = √(Z<sub>in</sub>Z<sub>L</sub>) 的線；史密斯圖是複阻抗平面到反射係數平面的保角映射（**本站不畫圖，只說明它是什麼**）；同軸走 TEM 模、沒有截止頻率，所以家用射頻幾乎都用它；波導與諧振腔留給微波課。來源：08-電磁學-下 §16.1–§16.7、第 17 章。

**推導必寫**：（a）為什麼會有兩個反向行進的波：把兩條電報員方程互相代入得 d²V/dz² = γ²V，通解 V(z) = V<sup>+</sup>e<sup>−γz</sup> + V<sup>−</sup>e<sup>+γz</sup>。（b）Z<sub>0</sub> 的意義：對**單一個行進波**，V<sup>+</sup>/I<sup>+</sup> = Z<sub>0</sub>，所以 Z<sub>0</sub> 不是一個電阻、也不消耗功率，它是「這條線願意接受的電壓電流比」。（c）Γ<sub>L</sub> 的來歷：在負載端 V(0) = V<sup>+</sup> + V<sup>−</sup>、I(0) = (V<sup>+</sup> − V<sup>−</sup>)/Z<sub>0</sub>，兩式相除等於 Z<sub>L</sub>，解出 V<sup>−</sup>/V<sup>+</sup>。（d）VSWR 的來歷：入射與反射疊加，最大處 |V<sup>+</sup>|(1 + |Γ|)、最小處 |V<sup>+</sup>|(1 − |Γ|)，相除。（e）λ/4 轉換器：把 βℓ = 90°（tan → ∞）代入 Z<sub>in</sub> 式，分子分母同除 tan βℓ 得 Z<sub>in</sub> = Z<sub>0</sub>²/Z<sub>L</sub>。（f）同軸的 Z<sub>0</sub>：用第 06 章的 C = 2πε/ln(b/a) 與 L = (µ/2π)ln(b/a)，Z<sub>0</sub> = √(L/C) = (η<sub>0</sub>/2π)ln(b/a)/√ε<sub>r</sub>——**電磁學的兩個結果在這裡合體**。

**數值實例**：Z<sub>0</sub> = 50 Ω、Z<sub>L</sub> = 75 + j0 Ω、電氣長度 βℓ = 0°（直接站在負載端）。**Γ 與 VSWR 這組數字與 `../../../共通基礎/物理/互動課程/13-反射折射與都卜勒.html` 完全相同。**

  - 偏振：「wave polarization（偏振，波的 <b>E</b> 軌跡）與 material polarization（極化，介質的 <b>P</b>）英文同字，本課刻意用兩個中文詞分開。」
  - 磁阻：「R<sub>m</sub> 的單位是 A/Wb 不是 Ω（下標 m 代表 magnetic，用來和電阻 R 區分）。磁路類比只是形式相同：磁通不耗能，磁阻不是耗散元件；而且磁通會漏（空氣的 µ 不是 0），電流不會。」
  - 位移電流：「它不是電荷在流動，是 ∂<b>D</b>/∂t 這一項；但它產生的磁場是真的。」
  - 反射係數：「Γ 是**振幅**比，|Γ|² 才是功率比。Γ = 0.2 代表反射 20 % 的振幅、4 % 的功率。」
- 每張卡的「位置／角色」要寫**它在本課哪一章、在哪門後續課或哪個真實裝置用到**。
- 符號（∇、∮、ε、µ、σ、η、α、β、δ、Γ、Φ、χ、Ω）出現時要在卡內寫出讀法。
- 首次出現的英文縮寫要展開全名。
- **庫侖定律那張卡必須加一句**：「本課一律寫『庫侖』；`中英名詞對照表-2.md` 與普通物理課寫『庫倫』，是同一個人 Coulomb 的兩種舊譯。」

### 7.5 JavaScript 規則

- 只用 ES2017 以內語法（`const`／`let`／箭頭函式／樣板字串／`Object.keys`）。不用模組、不用 `class`、不用 optional chaining（保守相容）。
- 不得使用 `Math.random`、`setTimeout` 動畫、`localStorage`、`fetch`、`document.write`。
- **不得使用複數類別或第三方數學庫**。第 14、15 章的複數運算一律以「實部／虛部」或「大小／角度」的實數式手寫，公式已在第 4 節鎖死。
- 所有寫入 DOM 的字串用 `innerHTML`（內容全部由本檔常數與數字組成；使用者輸入只以 `Number()` 轉數字後格式化，不得原樣塞回 `innerHTML`）。
- **所有除法都要先擋分母為 0 或負**：`capacitor` 的 `Math.log(b/a)` 與 `b−a`（`b <= a` 時走保護路徑）、`coulomb` 的 `r`（滑桿最小 1 cm，安全）、`tline` 的 `den` 與 `1−|Γ|`、`lossymedium` 的 `alpha`（σ = 0 時為 0）、`magcircuit` 的 `Rt`、`displacement` 的 `w*eps`。**不得讓 `NaN`、`Infinity`、`undefined`、`null` 洩漏到畫面上**；該顯示無限大時一律輸出中文文字（例「∞（全反射）」「開路」「無限大（無損材料沒有趨膚效應）」）。
- **單位換算集中在讀值處**：`nC → C` 乘 `1e-9`、`cm → m` 乘 `1e-2`、`mm → m` 乘 `1e-3`、`µm → m` 乘 `1e-6`、`cm² → m²` 乘 `1e-4`、`mm² → m²` 乘 `1e-6`、`MHz → Hz` 乘 `1e6`、`匝/cm → 匝/m` 乘 `100`。換算後的變數名加 `SI` 後綴以免混用。
- **數字格式化的統一規則**：絕對值落在 `[1e-4, 1e7)` 用 `fmt(x,6)`；否則用 `exp(x,6)`。零一律顯示 `0.000000`。這條要寫成一個 helper（建議名 `num6`）並全檔使用，避免各章格式不一。
- 檔尾 `if(typeof module!=="undefined")module.exports={fmt,num6,…};` 方便語法檢查與人工交叉驗算。

## 10. 來源筆記缺口（僅列出，本案不回頭改寫筆記）

以下是撰寫本 spec 時發現、來源筆記沒有但本課需要的內容。builder **可以自行補上教學文字**（都是標準大學課綱內容或可由既有段落推得），但**不得回頭修改 `.md` 筆記**。Lead 可另案決定是否補進筆記。

1. **三份筆記完全沒有任何數值範例**，全篇是符號式。本課所有數值實例都是依標準公式自行算出並列在本 spec 第 4 節，verifier 應以本 spec 的數字為準交叉驗算。
2. **筆記沒有給任何常數的完整位數**（只寫 ε<sub>0</sub> ≈ 8.85 × 10<sup>−12</sup>、c ≈ 2.998 × 10<sup>8</sup>、η<sub>0</sub> ≈ 377 Ω）。本課在 PROJECT-BRIEF 第 7 節統一了一組完整位數的常數，並刻意與普通物理課共用（ρ<sub>銅</sub>、η<sub>0</sub>、庫侖力那組電荷）。
3. **筆記沒有任何量測儀器**。本課每章的「可觀察證據」段落全部是為了滿足 principles-first 與 QUALITY-GATES 的硬體加驗條款而補寫的標準實驗室實務，verifier 應確認沒有出現危險或錯誤的操作建議（特別是 08、10、11 章的安全警語）。
4. **筆記沒有給集總／分布的量化門檻**（d < λ/20）。本課 00 章引入它是為了與電路學 00 章接軌，已在該章推導段落寫明來歷。
5. **筆記沒有給「散度／旋度的小盒子與小方框定義」**，直接給算子符號。本課 01 章補上，這是零基礎讀者能讀懂後面所有積分定理的前提。
6. **筆記缺兩條靜電的關鍵中間結果**：電偶極的遠場電場分量 E<sub>r</sub> = 2kp cos θ/r³、E<sub>θ</sub> = kp sin θ/r³（只給了電位；本課 04 章補上，讓互動能顯示「V = 0 但 E ≠ 0」）；電場線的折射律 tan θ<sub>2</sub>/tan θ<sub>1</sub> = ε<sub>r2</sub>/ε<sub>r1</sub>（只給了兩條邊界條件；本課 05 章由兩條件相除推出，是該章互動的判準來源）。
