15・當導線有長度，負載會把波送回源端

傳輸線與駐波：阻抗不只屬於元件，也會隨觀測位置改變

尺寸接近波長時，電壓與電流不能再假設整條線同時改變。傳輸線把每一小段的電感與電容串接成分布系統；負載不匹配時，為滿足線尾邊界條件而產生反射，入射與反射疊加便形成駐波。

這章假設已懂：14 介質中的波與界面的反射係數、13 電磁波與平面波的 β，以及電路學的阻抗。

痛點：明明接的是同一顆 75 Ω 負載，為什麼沿線看會變成複數阻抗

在低頻短導線裡，把一個節點視為處處同電壓很方便；但訊號傳過線需要有限時間。當線長不再遠小於波長，源端改變時，負載端尚未得知，線上各處的電壓與電流具有不同相位。此時「導線只是連接」的集總假設失效，必須追蹤向前與向後兩個行波。

反射也不是訊號碰壁後隨意彈回。單一行波在線上有固定的電壓電流比；負載若要求另一個比值，線尾只能加上一個反向波，使總電壓與總電流的比恰好等於負載阻抗。站在不同位置時，兩波相位差不同，總比值便改變，即使負載本身從未改變。

白話直覺：每小段線延遲下一段，線尾的不匹配再把能量送回來

可暫時把傳輸線想成一列相鄰狀態依序更新；比喻到此為止，真實機制是每單位長度 L、C，以及有損時的 R、G 所滿足的電報員偏微分方程。源在訊號產生器，正向電壓與電流波沿線前進；無損線的單一行波振幅不按距離下降，有損線才按 e−αz 衰減。

能量存在分布電場與磁場並沿線流向負載。當負載等於特性阻抗時，邊界接受原行波的電壓電流比，能量進入負載而不反射；不匹配時，反射波攜部分能量回源端，並與入射波形成位置固定的最大值與最小值。連接器、彎折、介電材料與幾何都會改變局部 Z0，造成額外反射。向量網路分析儀量到反射大小與相位，時域反射計量到回波時間與極性。因果鏈是：源送出行波，場受導體邊界導引，能量沿線流；負載與不連續處改變邊界條件並產生回波，儀器最後讀到 S11、延遲與駐波比。

來源：08-電磁學-下 §16.1–§16.7、第 17 章。

推導：兩條電報員方程如何長出行波、反射與輸入阻抗

先固定符號語言。時諧電壓與電流用複數相量 V(z)、I(z) 表示；<b> 是空間向量、<strong> 是複數相量，兩者不得互換。虛數單位一律寫 j；數學課寫 i，電機寫 j，因為 i 留給電流。傳輸線的 V、I 是兩導體之間與沿線方向定義的純量相量，不等同於空間場向量 E、H。

一般均勻線每單位長度有 R（Ω/m）、L（H/m）、G（S/m）、C（F/m）。電報員方程（telegrapher's equations）是 dV/dz = −(R + jωL)I 與 dI/dz = −(G + jωC)V。對第一式再微分並代入第二式，得到 d²V/dz² = γ²V，其中 γ = √[(R + jωL)(G + jωC)]。

二階方程的通解含兩個方向：V(z) = V+e−γz + V−e+γz。代回第一式可得正向波 V+/I+ = Z0，反向波則因電流參考方向相反而有負號；Z0 = √[(R + jωL)/(G + jωC)]。無損時 R = G = 0，Z0 = √(L/C)、γ = jω√(LC)、vp = 1/√(LC)。Z0 是單一行波願意維持的 V/I，不是一顆實體電阻，也不自行耗能。

把負載端設為 z = 0，則 V(0) = V+ + V−，I(0) = (V+ − V−)/Z0。令兩式相除等於 ZL，解得負載反射係數 ΓL = V−/V+ = (ZL − Z0)/(ZL + Z0)。它和第 14 章的界面反射完全同形，只是本質阻抗換成特性阻抗。

兩波同相處電壓振幅為 |V+|(1 + |Γ|)，反相處為 |V+|(1 − |Γ|)，所以電壓駐波比（voltage standing wave ratio, VSWR）= (1 + |Γ|)/(1 − |Γ|)。匹配時 |Γ| = 0、VSWR = 1；短路、開路或純電抗負載使 |Γ| = 1、VSWR 無限大。

距負載電氣長度 βℓ 處的總電壓除以總電流，整理為 Zin(ℓ) = Z0(ZL + jZ0tan βℓ)/(Z0 + jZLtan βℓ)。βℓ = 180° 時正反波相對相位重現，Zin = ZL；βℓ = 90° 時 tan 的極限給 Zin = Z0²/ZL。因此四分之一波長轉換器要在 50 Ω 與 75 Ω 之間匹配，選 Z0 = √(50 × 75)。

同軸線也把前面兩章合體：每單位長度 C = 2πε/ln(b/a)、L = (µ/2π)ln(b/a)，所以 Z0 = (η0/2π)ln(b/a)/√εr。同軸支援橫電磁模（transverse electromagnetic mode, TEM），理想 TEM 沒有截止頻率；波導的 TE、TM 模與諧振腔則留給微波課。

實際線路有 R 與 G，因而 Z0、γ 都隨頻率成為複數，反射往返時也持續衰減。無損式仍是建立方向感的基準，卻不能用來保證長纜末端的振幅。匹配消除的是負載端新增的回波；它不會消除導體損、介質損、輻射或串接元件本身的插入損耗。

自由實驗：沿線移動觀測點，看阻抗如何旋轉

訊號源接一條無損均勻傳輸線，負載位於線尾；四個控制設定線的特性阻抗、負載複阻抗與從負載往源端看的電氣長度。觀察反射量與輸入阻抗各自怎麼變。

Γ = 0.200000 + j0.000000；|Γ| = 0.200000；功率反射 4.000000 %、透射 96.000000 %；VSWR = 1.500000；回波損耗 13.979400 dB；Zin = 75.000000 + j0.000000 Ω。這是失配，4 % 功率回到源端；因 βℓ = 0°，輸入阻抗等於負載。|Γ| 不隨電氣長度改變，只有觀測位置的阻抗改變。這條式子和第 14 章的界面反射一模一樣，只是 η 換成 Z0；傳輸線就是被導引起來的平面波。短路或四分之一波長等極端位置需改用開路文字，不能輸出無效數值。

不要混淆

  • Z0 是單一行波的電壓電流比，不是一顆電阻；無損線本身不因標示 50 Ω 就消耗功率。
  • VSWR 與 |Γ| 一一對應，是同一反射程度的兩種尺度，不是互相獨立的品質指標。
  • 傳輸線匹配為消除反射，條件是 ZL = Z0；集總電路的最大功率傳遞著眼於源與負載取捨，不能把目的混為一談。
  • 電氣長度 βℓ 與物理長度 ℓ 不同；同一條線在不同頻率有不同 βℓ，半波與四分之一波條件也隨頻率移動。
  • 駐波是入射與反射的疊加圖樣，不是能量永遠在原地越積越多；有損耗與源端吸收時仍符合能量守恆。

可觀察證據：VNA 看複數反射，TDR 用回波時間定位不連續

向量網路分析儀（vector network analyzer, VNA）在校正參考面量 S11，直接給 Γ 的大小與相位，並可換算 VSWR、回波損耗與負載阻抗。改變纜線長度後，若負載與線保持不變，|Γ| 理想上不變而相位旋轉；這能證明反射量由終端失配決定，也能檢查半波阻抗重現與四分之一波轉換。

時域反射計（time domain reflectometer, TDR）送出快速階躍並量回波，到達時間配合相速可定位接頭、斷線或短路，回波極性可區分阻抗升高與降低。它能證明哪個位置有不連續並估計 Z0；不能在不擾動線路的情況下直接給出某點絕對電壓，也不能證明 Z0 是一個實體電阻。探棒、轉接頭與校正面本身都可能加入反射，量測前必須去嵌入或校正。

連到哪門課

集總模型的適用邊界回到電路學的電路世界觀，複阻抗則見阻抗與交流穩態；反射的光學對照見普通物理的反射折射與都卜勒。往後的波導截止頻率、諧振腔、史密斯圖圖解匹配、天線方向圖與陣列屬於微波與天線課；本課到此已把第 00 章的尺寸與波長判準收成可算的傳輸線工具。
