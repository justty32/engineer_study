12・補上會變動的電場，讓電流與磁場的帳一致

位移電流與馬克士威方程式：電容板間沒有導電路徑，磁場卻不能中斷

正在充電的電容器逼出一個尖銳矛盾：同一條安培迴路，選不同跨面竟會得到不同磁場。位移電流（displacement current）不是另一批穿越絕緣層的電荷，而是變化電場在安培定律中不可缺少的等效電流項。

這章假設已懂：07 電流密度與焦耳熱的連續性方程，以及11 電磁感應的法拉第定律。

痛點：電容中間明明是絕緣的，交流電流怎麼可能穿過去

直流穩態時，安培定律把電流視為磁場的旋渦源，直覺很乾淨；可是開關剛接通或交流電壓正在變化時，導線中的自由電荷流到電容板便停下，板間沒有傳導電流。若因此斷言板間不產生磁場，就會讓同一條封閉路徑的環流依解題者任選的曲面而改變。物理量不應服從畫面的選法，因此問題不是電流神祕地跳過間隙，而是靜態安培定律少算了一種源。

更抽象的症狀也一樣。對 ∇×B = µ0J 兩邊取散度，左邊因「旋度場無散」恆為零，右邊卻是 µ0∇⋅J。連續性方程 ∇⋅J = −∂ρv/∂t 告訴我們，只要電荷密度正在累積，右邊就不為零。這不是小誤差，而是方程式在時變問題裡自相矛盾。

白話直覺：導線的電荷流停在板上，變大的電場把磁效應接續下去

可暫時把位移電流想成接力棒；比喻到此為止，真正被接續的是安培環流方程中的源項，而不是電子穿越真空。源在外部導線的傳導電流與兩板間隨時間增加的電場。導線周圍的磁場依右手定則繞著電流，對理想圓對稱路徑其大小隨半徑約按 1/r 變小；進入板間後，變化的 D 仍繞出同方向磁場。

能量先由電源沿周圍電磁場流向電容，最後存進板間電場；介電材料會以 ε 改變 D、電容與位移電流，導電性 σ 又增加真正的傳導損耗，板緣則使理想均勻場失真。電流探棒量到兩端導線電流連續，LCR 表量到頻率相關的電容與損耗，磁感測器原理上可量板緣磁場。因果鏈因此完整：自由電荷在導線流動並堆到板面，場從正板指向負板且在理想板中央近似均勻，能量存於場中；材料與邊緣改變場分布，儀器最後讀到電流、相位與微小磁場。

來源：08-電磁學-中 §13.1–§13.3。

推導：同一條迴路只能有一個答案，缺項由電荷守恆決定

取一條繞著充電導線的封閉路徑 C。第一個跨面 S 穿過導線，傳導電流 I穿過 = I，靜態式給 ∮C B⋅dℓ = µ0I。第二個跨面仍以同一條 C 為邊界，卻鼓進兩片電容板之間；它不切到導線，因此 I穿過 = 0。左邊明明沿完全相同的路徑積分，右邊卻一個非零、一個為零，這就是必須修補的災難。

馬克士威加入位移電流密度 Jd = ∂D/∂t；在線性、均質、等向且 ε 不隨時間變的材料中，它是 Jd = ε∂E/∂t，單位 A/m²。積分形式成為 ∮C H⋅dℓ = I自由 + d/dt ∫S D⋅dA；真空微分形式則是 ∇×B = µ0J + µ0ε0∂E/∂t。

平行板中央忽略邊緣效應時，E = Q/(εA)。板間等效電流為 Id = εA ⋅ dE/dt = εA ⋅ d[Q/(εA)]/dt = dQ/dt = I傳導。用元件語言再驗一次：C = εA/d、V = Ed，所以 I = C dV/dt = (εA/d)d(Ed)/dt = εA dE/dt。兩條路得到同一結果，表示補項並非任意湊數。

也可直接檢查守恆。完整式 ∇×H = J + ∂D/∂t 取散度，得到 0 = ∇⋅J + ∂(∇⋅D)/∂t。再用 ∇⋅D = ρ自由，正好回到 ∇⋅J + ∂ρ自由/∂t = 0。電荷守恆不是額外條件，而是修正後方程式內建的結果。

四條馬克士威方程式在物質中的微分形式可逐條讀：∇⋅D = ρ自由 說自由電荷是電場的源；∇⋅B = 0 說磁場沒有起點終點，也就是沒有磁單極；∇×E = −∂B/∂t 說變化磁場繞出電場；∇×H = J + ∂D/∂t 說自由電流與變化電場都繞出磁場。配上 D = εE、B = µH、J = σE 及羅倫茲力，才是一個可求解的經典電磁模型。

令角頻率 ω = 2πf，傳導電流密度與位移電流密度的大小比是 tan δ = σ/(ωε)，稱損耗角正切（loss tangent）。這裡 δ 是角度符號，不是第 14 章的趨膚深度。比值遠小於一時位移電流主導，遠大於一時傳導電流主導；它也提醒我們材料分類會隨頻率改變。

上述平行板證明依賴中央場近似均勻、ε 不隨時間變，且外部導線可視為集總連接。頻率升高後，導線延遲、板的寄生電感、介電色散與輻射都會出現；位移電流項仍然成立，失效的是把整顆元件只用單一 C 表示的簡化模型。這個邊界能避免把基本方程與元件近似混成同一層。

自由實驗：比較傳導電流與位移電流

外部正弦電源替平行板充放電；觀測點在板間中央與等效圓板邊緣。切換材料與幾何，觀察哪一種電流主導，以及兩種算法是否接上。

f = 103 Hz；C = 88.541878 pF；E0 = 100000.000000 V/m；Jd = 0.005563 A/m²；Id = 55.632503 µA；Ic = 0 A；σ/(ωε) = 0；板緣 B = 1.972121 × 10−10 T。場的算法 Id = ε A ω E0 與元件的算法 I = C V0 ω 都得到 55.632503 µA，殘差小於 10−15；位移電流主導，因變化電場接續了導線電流。B 比地磁小約 25 萬倍；拉到極高頻或極高電場時，集總與不放電假設會失效。

不要混淆

  • 位移電流不是自由電荷穿越板間；它是 ∂D/∂t 的等效電流項，但產生的磁場是真實的。
  • 傳導電流 J = σE 涉及自由電荷漂移；位移電流可存在於真空，兩者機制不同而在安培定律中相加。
  • 損耗角正切的損耗既可能來自 σ，也可能來自介電極化的延遲；本章簡化模型只把前者放入比值。
  • 「電容在高頻像短路」是 1/(jωC) 變小的電路語言；場論說法是 dD/dt 變大，不代表絕緣層真的短路。
  • 四式中的 J 是自由電流；材料束縛響應已由 D、H 與材料關係整理，不能重複計入。

可觀察證據：量到電容兩端電流連續，仍不是直接看見位移電流

把電容器串入低失真正弦源，以兩支電流探棒同步量兩側導線，示波器會看到相同頻率、相同振幅的電流；再量電壓斜率，可驗證 I = C dV/dt。這能證明外部電流沒有在元件兩端憑空消失，也能在已知幾何與 ε 下支持位移電流模型。它不能證明有電子穿過介電層，更不能把同一個磁場拆成「傳導造成」與「位移造成」兩份。

LCR 表或向量網路分析儀（vector network analyzer, VNA）可在多個頻率量到等效電容與耗散因數，據此估計 tan δ；但單一頻點的等效值不能證明材料在所有頻率都具有相同 ε 與 σ。直接量預設板緣約 0.2 nT 的磁場，需要超導量子干涉儀（superconducting quantum interference device, SQUID）與磁屏蔽環境；即使量到，也只能支持總磁場與模型相符，不能單獨驗明抽象的 ∂D/∂t 項。
