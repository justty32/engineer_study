10・材料把磁通集中，氣隙卻常主宰整條磁路

磁性材料與磁路：分清 B、H，再像算電路一樣算鐵心

自由電流建立磁場強度，材料磁化再共同決定磁通密度。磁路類比能快速估算變壓器與電感，但漏磁、飽和與磁滯會讓它偏離理想值，氣隙更可能用千分之幾的長度吃掉大部分磁動勢。

這章假設已懂：09 畢歐沙伐與安培定律的安培定律，以及07 電流密度與焦耳熱的歐姆定律類比。

痛點：B、H 都叫磁場，氣隙又為何能打敗整塊鐵

在真空中 B = µ0H，兩者只差固定比例，很容易被誤認為同一個量。放入磁性材料後，原子磁偶極會重新排列，H 主要記錄自由電流的激磁，B 則把材料磁化也算進去，兩者角色才真正分開。羅倫茲力直接使用的是 B，而安培定律以 H 包圍自由電流。

磁化向量（magnetization）M 單位 A/m，表示單位體積的磁偶極矩；磁場強度（magnetic field strength）H 也用 A/m。關係為 B = µ0(H + M)。線性介質近似 M = χmH，所以 B = µ0(1 + χm)H = µH，且 µ = µ0µr。本課粗體代表向量，非粗體代表大小。

鐵心進入飽和後，有效磁導率與電感會急遽下降，線圈電流可能暴衝；這是變壓器與返馳電源燒毀的典型路徑。繞組長時間過流會過熱並使絕緣劣化，實作不可只相信線性計算值。

白話直覺：鐵心鋪路，氣隙設下一個昂貴關卡

可暫時把磁路想成電路：磁動勢像電壓、磁通像電流、磁阻像電阻；比喻到此為止，磁通並不搬運電荷，磁阻也不耗散功率。源是線圈中的自由電流 NI，它沿鐵心建立 H；材料磁化讓同一 H 對應更大的 B。封閉鐵心內磁通沿截面延續，而均勻段的磁場大小約由長度、截面積與磁導率決定。

磁場能量存在整個空間，但在有氣隙的儲能電感中，能量多集中於氣隙，因空氣需要比高磁導率鐵心大得多的 H 才維持同一 B。跨材料界面時，沒有表面電流便有 H 切向連續，而 B 法向連續；有限鐵心還會漏磁與產生邊緣擴散。高斯計可量氣隙 B，LCR 表可量端點電感，再由模型反推等效磁阻。

完整因果鏈是：自由電流在繞組中產生磁動勢，H 沿磁路方向分配；材料磁化使 B 集中，均勻鐵心內理想值近似不隨截面位置改變；能量主要存於低磁導率的氣隙；材料界面、氣隙、飽和與漏磁改變場；儀器最後量到氣隙 B、線圈 L 或感應電壓。量級對照是：地磁約 50 µT、喇叭磁鐵約 1 T，而矽鋼片約在 1.5 T 附近飽和；後兩者只差一半，工程裕量不能忽略。

來源：08-電磁學-中 §10.1–§10.5。

推導：安培定律如何變成磁路版歐姆定律

磁路類比。磁動勢（magnetomotive force）寫作 Fm = NI，磁阻（magnetic reluctance）寫作 Rm = ℓ/(µA)。首次出現時要釐清：下標 m 代表 magnetic，Rm 是磁阻，Fm 是磁動勢。Fm 單位 A⋅匝，Rm 單位 A/Wb，Φ 是磁通、單位 Wb，不能把磁阻單位寫成 Ω。

對均勻鐵心，安培定律 ∮C H⋅dℓ = I自由 化為 Hℓ = NI；又 Φ = BA = µHA。由第二式得 H = Φ/(µA)，代回第一式便有 NI = Φ ⋅ ℓ/(µA)，也就是 Fm = ΦRm。它與 V = IR 形式相同，假設是磁路截面均勻、材料線性且等向、漏磁可忽略。

串聯磁阻。由 ∇⋅B = 0 與界面 Bn1 = Bn2，理想同截面鐵心與氣隙承載同一 Φ。各段磁動勢降相加，因此 Rm,總 = Rm,鐵心 + Rm,氣隙。因 Rm ∝ ℓ/µ，µr = 2000 的鐵心中 1 mm 空氣等效於 2000 mm 鐵心，所以短氣隙可主宰總磁阻。

電感與能量。由 Φ = NI/Rm，磁通連結 λ = NΦ = N²I/Rm。電感定義 L = λ/I，因此 L = N²/Rm，單位 H。儲能 W = (1/2)LI²；線性介質的磁場能量密度 wm = (1/2)H⋅B。開氣隙會降低 L，卻能讓 B 在較大電流下仍不飽和，並把可逆能量放進近似線性的空氣。

材料邊界與損耗。抗磁性（diamagnetic）材料 µr 略小於 1，順磁性（paramagnetic）略大於 1，鐵磁性（ferromagnetic）很大且非線性。鐵磁材料的磁滯（hysteresis）使 B 不再是 H 的單值函數；剩磁 Br 是 H = 0 時殘留的 B，矯頑磁力 Hc 是把 B 拉回零所需的反向 H。磁滯迴圈面積代表每週期損耗；渦流損在高頻加劇，可用疊層矽鋼或高電阻率鐵氧體降低。

模型失效。磁通不像電流會被絕緣體完全限制，空氣磁導率不是零，故必有漏磁；接近飽和時 µr 下降，線性答案會高估 B 與 L；有磁滯時同一 H 可能對應不同 B。這三條限制決定磁路只能是工作點附近的工程模型。

數值實例：一毫米氣隙吃掉近七倍鐵心磁阻

環形鐵心 µr = 2000、平均磁路長 ℓ = 0.30 m、截面積 A = 4 cm² = 4 × 10−4 m²、N = 200 匝、I = 0.5 A、氣隙 g = 0。

自由實驗：看氣隙如何重分配磁阻與能量

固定平均磁路長 0.30 m、截面積 4 × 10−4 m²，線圈包住環形鐵心。調整材料、匝數、電流與氣隙，檢查磁通密度、電感和飽和風險。

Fm = 100.000000 A⋅匝；Rm,鐵心 = 2.984155 × 105 A/Wb；Rm,氣隙 = 0 A/Wb；Φ = 3.351032 × 10−4 Wb；B = 0.837758 T；H = 333.333333 A/m；L = 0.134041 H；W = 0.016755 J。線性區，µr 大致可視為常數。沒有氣隙時電感最大，但也最容易飽和；模型另假設沒有漏磁與磁滯，滑到高 B 時必須改用真實磁滯資料。

不要混淆

  • H 不是 B 除以 µ0 的簡寫；材料中兩者差 µr，界面連續條件也分別管切向 H 與法向 B。
  • 鐵磁材料的 µr 不是固定常數；標示 2000 只代表某個工作點附近的線性近似。
  • 磁阻單位是 A/Wb，不是 Ω；磁路類比只有代數形式相似，磁通不消耗能量，磁阻也不是耗散元件。
  • 磁滯損與渦流損不是同一機制；前者與迴圈面積及頻率相關，後者由鐵心內感應電流造成且高頻增加更快。
  • 開氣隙降低電感不代表設計變差；它可提高可承受電流並把可逆能量存入近線性的氣隙。

可觀察證據：量得到 B 與 L，量不到磁阻本身

霍爾高斯計探頭可伸入氣隙，直接量到該位置的 B；鐵心內部通常沒有空間容納探頭，因此內部 B 多由磁通連續與截面積推估。LCR 表在指定頻率與小訊號振幅下量到端點電感 L，再由 L = N²/Rm,總 反推等效磁阻。這能證明氣隙磁通密度、端點電感以及它們隨氣隙的變化，不能直接證明鐵心每一點的 M 分佈，也量不到作為模型量的 Rm 本身。

磁性分析儀可用一次側電流求 H，以二次側感應電壓積分求 B，逐點得到磁滯迴圈。它能證明剩磁、矯頑磁力、迴圈面積與飽和轉折；不能證明漏磁為零，也不能把單一頻率、小訊號所得 µr 無條件套到大訊號與所有頻率。

連到哪門課

磁路與變壓器端點模型連到電路學的變壓器與三相。在電機機械中，同一套 Fm、Rm 與氣隙分析用來估算馬達磁通；在電力電子中則決定儲能電感能否承受峰值電流。下一章會讓 Φ 隨時間變化，由此產生電動勢。
