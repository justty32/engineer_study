# 圖解電子學：從元件到訊號鏈

本課把三冊電子學筆記重建為 24 章可跟算的圖解課程，成品在 `dist/`。每章以具體裝置問題起步，沿「已知與未知 → 選模型 → 圖對式 → 代入 → 重驗 → 近題」完成一次推理。

## 讀者基線

讀者軟體能力強、曾讀電機與通訊，但電路與元件基礎不能假定扎實。00 章只補本課必要的電壓、電流、地、電阻、回路與單位，後續逐步建立載子、偏壓、局部斜率、回授與量化模型。目標是能手算典型例、指出假設、檢查工作區、用儀器驗證。

## 語言與名詞契約

繁體中文、臺灣慣用語；首次術語附英文與白話機制。直流量用大寫或 Q 下標，增量用小寫，總瞬時量明寫為工作點加增量。採被動符號約定；NPN 集極與 NMOS 汲極電流以流入為正。正弦振幅均是峰值，算交流功率才轉有效值。等號是模型內相等，四捨五入或近似用 ≈。β 是 BJT 電流增益，βf 是回授比例。

## 先修缺口（prerequisite gap）

認得名詞不代表會畫回路或選式。每章直接聲明最低前置並回連 00、上一章或字典；必要的 KVL、KCL、電容電荷與 RC 只在使用處搭短橋。不得把新電路學網站當已發布先修。名詞與概念分開呈現，字典供回查。

## 概念依賴與教學邊界

回路與量測 → 半導體及 PN → 二極體應用 → BJT／MOS 偏壓 → CMOS／小訊號 → 單級、頻率、多級、差動、鏡 → 回授與運放 → 濾波／比較／振盪 → 電源 → DAC／ADC。每章主例在正文完整顯示；自由實驗在主例後，近題含漸進提示與完整詳解，不設考試與解鎖。圖為原創 inline SVG，頁面無 JavaScript 仍可讀。

來源是同層三冊原筆記及已實讀的一手教材。來源對應、修正提案由來源查證線寫入專用資料檔；網站只引用可追溯主張，不改原筆記。官方來源超連結允許，執行期依賴皆本地。

## 交付與可延續性

首頁提供具體算圖與課程地圖；00 是起點；字典供速查；來源頁說明公式條件與教材出處。完整互動契約在逐章互動契約.json，檔案責任在派工計畫.json；BUILD-SPEC.md 定義共用教學與 DOM 格式。獨立驗收者建立驗收紀錄，真人理解與觸控保持待人工，不以自動測試冒充。
