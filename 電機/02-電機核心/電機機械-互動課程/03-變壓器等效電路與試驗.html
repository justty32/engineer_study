03・兩次安全試驗拆出四個內部參數

變壓器等效電路與試驗：不用拆機也能知道損耗與漏磁有多大

同一台 10 kVA、2400/240 V、60 Hz 變壓器，只靠開路與短路兩次試驗，就能得到激磁分支與串聯支路。預設讀數算得百分阻抗 2.498002 %，也為下一章的效率與電壓下降準備資料。

這章假設已懂：02 阻抗折算與自耦變壓器的匝比與阻抗折算。前置：見電路學的阻抗與交流穩態，先熟悉串聯阻抗與並聯導納。

痛點：看不到內部支路，怎麼知道電流花到哪裡

實際變壓器接上電源後，即使二次側沒有負載，功率計仍有讀數；負載加大後，端電壓又會下降。若只用理想匝比，這兩件事都解釋不了。問題是機器封著，難道要拆開逐段量嗎？工程上改用兩個刻意安排的工作狀態，讓某一半的效應很小，再由外部三個儀表反推參數。

一次與二次線圈各有電阻 R1、R2，未共同鏈結兩側的磁通表現成漏電抗（leakage reactance）X1、X2。鐵損電阻（core-loss resistance）Rc代表鐵損，激磁電抗（magnetizing reactance）Xm代表建立磁通所需的無功電流。

白話直覺：一次只讓半邊說話

可把兩次試驗暫時想成訪談時先請另一組人安靜；比喻到此為止，真實機制是阻抗與端電壓讓某條回路的影響遠小於另一條。開路試驗（open-circuit test）在低壓側加額定電壓，高壓側斷開，串聯支路電流很小，因此功率主要進入鐵損，總電流則分成鐵損電流與激磁電流。短路試驗（short-circuit test）在低壓側短接，只在高壓側慢慢加低電壓直到額定電流；激磁分支承受的電壓很低，因此功率主要成為銅損。

因果鏈是：電源以儀表共同參考點加到指定端子，開路或低壓短路回路決定電流路徑；電流建立磁通或流過線圈電阻，分別造成鐵損與銅損；穩態時端電壓、電流及輸入功率固定；電壓表、電流表與功率計就能提供反推資料。開路選低壓側，是因為額定電壓較小；短路由高壓側供電，是因為額定電流較小，兩者都讓儀表較安全。

來源：12-電機機械 §2.2、§2.3。

推導：開路求並聯支路，短路求串聯支路

開路讀數先化成 Gc = Poc / Voc² 與 |Y| = Ioc / Voc，單位都是 S。激磁電納 Bm = √(|Y|² − Gc²)，所以 Rc = 1 / Gc、Xm = 1 / Bm。這些先屬於低壓側，要乘 a² 才折算到高壓側。物理限制是 Poc ≤ Voc × Ioc，而 Ioc 不可小於鐵損電流。

短路讀數給 |Zeq| = Vsc / Isc、Req = Psc / Isc²，再由 Xeq = √(|Zeq|² − Req²) 分離電抗。折算後可寫 Req = R1 + a² R2、Xeq = X1 + a² X2。百分阻抗為 %Z = Zeq / Zbase × 100，且 Zbase = Vrated² / Srated。

這套分離法的關鍵不是把某個元件真的關掉，而是讓它對儀表讀數的貢獻小到可忽略。開路時，串聯支路只流過很小的空載電流，壓降與銅損因而很小；短路時，外加電壓遠低於額定值，主磁通與鐵損因而很小。兩個近似互補，才能用簡單量測拼回整體模型。若忘了量測側別，數字即使算得順也會差一個 a²，這是現場整理試驗報告最常見的單位層級錯誤。

模型邊界。本課用的是線性穩態教學模型，真實機器不完全如此；這裡採近似等效電路，並忽略試驗期間的溫升與被壓小的支路損耗。讀數若使功率大於視在功率，或平方根內小於等於零，應判為讀數不可能，不能硬算。

數值實例：六個讀數算回四個參數

取 a = 10。開路試驗在低壓側量得 Voc = 240 V、Ioc = 3.01 A、Poc = 60 W；短路試驗在高壓側量得 Vsc = 60 V、Isc = 4.17 A、Psc = 139 W。讀數由設計值 Req = 8 Ω、Xeq = 12 Ω、Rc = 96 kΩ、Xm = 8 kΩ 四捨五入到儀表刻度，所以算回去有小差異。

讀表時也要保留有效位數的觀念。這組資料先在儀表刻度上取整，再反算參數，因此結果不會精準回到設計值。差異小且方向合理時，應把它解讀為解析度與取整影響；若違反功率因數上限或讓電抗平方成為負值，就不是取整可以解釋，而是接線、量程或抄錄需要重查。

不要混淆

  • 開路試驗近似量到鐵損，但仍有極小的一次銅損；近似模型才把它忽略。
  • 短路試驗是刻意用低電壓建立額定電流，不是讓額定電壓直接造成故障。
  • Rc 是把鐵損表現成電阻的模型參數，不是藏在機器裡的一顆實體電阻。
  • 參數屬於量測所在側；跨到另一側要依方向乘或除 a²，不能只改電壓名稱。

可觀察證據：三表讀數能證明到哪裡

用什麼量。以功率計、電壓表、電流表量兩次試驗的六個讀數，另用紅外線溫度計追蹤鐵心溫度，避免溫升悄悄改變條件。能證明什麼。在近似模型成立時，可求四個合併參數與百分阻抗，溫度趨勢也能支持確有損耗。不能證明什麼。兩次試驗只給合併值，不能分辨 R1 與 a² R2 各佔多少；要拆開還得另量直流電阻。

連到哪門課

這套方法用於變壓器出廠試驗、保護整定與負載評估。串聯阻抗和並聯導納的算法見電路學的阻抗與交流穩態；本章得到的 Req、Xeq 與損耗會在下一章直接算電壓調整率與效率。
