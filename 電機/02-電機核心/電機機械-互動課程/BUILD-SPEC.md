### 00 `00-線性直流機與能量轉換.html`

**目標**：不假設任何機器知識，只用「一根導桿架在兩條導軌上、放進均勻磁場、接一顆電池」這個最簡單的機器，把三件事講成一個能算的模型：感應電壓 e<sub>ind</sub> = B × l × v、力 F<sub>ind</sub> = B × i × l、穩態時電功率 = 機械功率 + 銅損。同一台機器加負載力就是馬達，被外力推就是發電機——能量往哪邊流，機器就是哪一種。

**要點**：電機機械（electric machinery）＝ 電能與機械能互換的元件：馬達（motor）電→機械、發電機（generator）機械→電、變壓器（transformer）電→電。兩條原理：法拉第定律（磁通變化產生電壓）與安培力（載流導體在磁場中受力），**兩者的推導在電磁學課，本章只用結論**。線性直流機（linear DC machine）：電池 V<sub>B</sub>、迴路電阻 R、磁通密度 B（垂直紙面）、導桿長 l、導桿速度 v。回路：`電池 → 導軌 → 導桿 → 導軌 → 電池`。起動瞬間 v = 0、e<sub>ind</sub> = 0，電流 i = V<sub>B</sub> / R 最大（**這就是第 06 與第 11 章「起動電流」的來源**）；導桿受力加速，e<sub>ind</sub> 隨 v 上升，電流下降，直到 F<sub>ind</sub> = F<sub>load</sub> 為止。**前置：B、l、v 與 e<sub>ind</sub> 的關係見〈11 電磁感應〉，力的方向見〈08 磁場與羅倫茲力〉，本章不重講。** 來源：12-電機機械 §1.1、§1.3。

**推導必寫**：（a）穩態電流由負載力決定：F<sub>ind</sub> = B × i × l = F<sub>load</sub> ⇒ `i = F<sub>load</sub> / (B × l)`——**電流不是電壓決定的，是負載決定的**，這句話貫穿全課。（b）穩態電壓平衡：`e<sub>ind</sub> = V<sub>B</sub> − i × R`，速度 `v = e<sub>ind</sub> / (B × l)`。（c）能量平衡：電池輸出 `P<sub>in</sub> = V<sub>B</sub> × i`，銅損 `P<sub>cu</sub> = i² × R`，轉換功率 `P<sub>conv</sub> = e<sub>ind</sub> × i = F<sub>ind</sub> × v`——**e × i 與 F × v 是同一個數，這就是機電能量轉換**；效率 `η = e<sub>ind</sub> / V<sub>B</sub>`。（d）發電機：外力 F<sub>app</sub> 順著運動方向推，穩態 i = F<sub>app</sub> / (B × l) 反向流回電池，`e<sub>ind</sub> = V<sub>B</sub> + i × R`，機械輸入 e × i、電池收到 V<sub>B</sub> × i、效率 V<sub>B</sub> / e<sub>ind</sub>。（e）失速：F<sub>load</sub> 大到 e<sub>ind</sub> = 0 時 v = 0，i = V<sub>B</sub> / R，`F<sub>stall</sub> = B × l × V<sub>B</sub> / R`。假設：均勻磁場、無摩擦、導軌無電阻以外的損耗、忽略導桿電感的暫態。

**數值實例**：V<sub>B</sub> = 120 V、R = 0.5 Ω、B = 1.0 T、l = 1.0 m、F<sub>load</sub> = 10 N（馬達模式）。

### 01 `01-鐵心電壓與磁通.html`

**目標**：講清楚變壓器與交流機的鐵心裡「磁通由誰決定、激磁電流由誰決定」：接上弦波電壓 V、頻率 f 的 N 匝線圈，鐵心磁通峰值由 `Φ<sub>max</sub> = V / (4.442883 × f × N)` 定死，與鐵心好壞無關；鐵心與氣隙的磁阻只決定要多少激磁電流才撐得起這個磁通。由此得到兩個判準：B<sub>max</sub> 超過 1.5 T 就飽和、氣隙讓激磁電流暴增。

**要點**：法拉第定律 e = N × dΦ/dt，弦波下 `E<sub>rms</sub> = 2π × f × N × Φ<sub>max</sub> / √2 = 4.442883 × f × N × Φ<sub>max</sub>`（教科書寫 4.44）；磁通密度 `B<sub>max</sub> = Φ<sub>max</sub> / A`；磁路歐姆定律 `F<sub>m</sub> = Φ × R<sub>m</sub>`、`R<sub>m</sub> = l / (µ<sub>0</sub> × µ<sub>r</sub> × A)`（鐵心）、`R<sub>gap</sub> = g / (µ<sub>0</sub> × A)`（氣隙，µ<sub>r</sub> = 1）；激磁電流峰值 `I<sub>m,peak</sub> = Φ<sub>max</sub> × R<sub>m,總</sub> / N`、有效值除以 √2；激磁電感 `L<sub>m</sub> = N² / R<sub>m,總</sub>`、激磁電抗 `X<sub>m</sub> = 2π × f × L<sub>m</sub>`，檢查 `V / X<sub>m</sub>` 應等於 I<sub>m,rms</sub>。飽和（saturation）：矽鋼片約 1.5 T 以上 µ<sub>r</sub> 急降，線性模型失效。**前置：磁路歐姆定律的推導與氣隙儲能見〈10 磁性材料與磁路〉，本章不重講，只反過來用：先由電壓定磁通，再由磁阻定電流。** 來源：12-電機機械 §1.2、§2.1。

**推導必寫**：（a）為什麼磁通由電壓定：線圈電阻忽略時端電壓等於感應電壓，弦波 Φ = Φ<sub>max</sub> sin(2πft) 微分後幅值是 2πf N Φ<sub>max</sub>，除以 √2 得 rms——**電壓一接上去，Φ<sub>max</sub> 就被逼出來，鐵心不夠好只會多吃電流，不會少出磁通**。（b）為什麼 50 Hz 比 60 Hz 危險：同電壓下 Φ<sub>max</sub> 與 f 成反比，60 Hz 設計的鐵心接 50 Hz 磁通增加 20 %。（c）為什麼變壓器不留氣隙、馬達不得不留：1 mm 氣隙的磁阻 `g / (µ<sub>0</sub> A)` 是 40 cm 鐵心（µ<sub>r</sub> = 2000）的 5 倍，激磁電流跟著變 6 倍；馬達的轉子要轉，非留氣隙不可，所以馬達的激磁電流（也就是無功）遠大於同容量的變壓器。（d）V/f 定值的來源：要磁通不變，V 與 f 必須同比例調——**這是第 11 章變頻器的根本理由**。假設：線圈電阻與漏磁忽略、µ<sub>r</sub> 常數、無鐵損。

**數值實例**：V = 240 V、f = 60 Hz、N = 200 匝、A = 40 cm² = 4 × 10<sup>−3</sup> m²、鐵心磁路長 l = 40 cm = 0.4 m、µ<sub>r</sub> = 2000、氣隙 g = 0。

### 02 `02-阻抗折算與自耦變壓器.html`

**目標**：把理想變壓器從「電壓比匝比」推進到「阻抗看起來變了 a² 倍」：一次側看到的負載是 `Z′ = a² × Z<sub>L</sub>`，這是之後第 03 章把試驗參數搬到同一側、第 08 章把轉子搬到定子側的根據。再用同一組匝數講自耦變壓器（autotransformer）：共用一段繞組，繞組只承擔一小部分功率。

**要點**：理想變壓器 `V<sub>1</sub> / V<sub>2</sub> = N<sub>1</sub> / N<sub>2</sub> = a`、`I<sub>1</sub> / I<sub>2</sub> = 1 / a`，**匝比與 Y／Δ 的機制在電路學課，本章不重講**；折算（referral）：`Z′ = V<sub>1</sub> / I<sub>1</sub> = a V<sub>2</sub> / (I<sub>2</sub> / a) = a² × Z<sub>L</sub>`，電阻與電抗各乘 a²；自耦變壓器：共同繞組 N<sub>C</sub> 與串聯繞組 N<sub>SE</sub>，`V<sub>H</sub> / V<sub>L</sub> = (N<sub>C</sub> + N<sub>SE</sub>) / N<sub>C</sub>`，輸入輸出視在功率 S<sub>IO</sub> 與繞組視在功率 S<sub>W</sub> 之比 `S<sub>IO</sub> / S<sub>W</sub> = (N<sub>C</sub> + N<sub>SE</sub>) / N<sub>SE</sub>`，比值越大越省銅，但一二次側沒有隔離。儀器用變壓器：電流互感器（current transformer, CT）二次側**絕不可開路**、電壓互感器（potential transformer, PT）二次側不可短路——只講原則不算。來源：12-電機機械 §2.1、§2.6。

**推導必寫**：（a）折算的量綱：V 乘 a、I 除 a，比值乘 a²——功率 V × I 不變，所以折算是「換座標」不是「換能量」。（b）為什麼折算有用：把二次側的東西全搬到一次側後，整個電路變成同一個電壓層級的單一迴路，可以直接用 KVL。（c）自耦：負載電流 I<sub>H</sub> 從高壓側流出，共同繞組只流 `I<sub>C</sub> = I<sub>L</sub> − I<sub>H</sub>`，串聯繞組只承受 `V<sub>H</sub> − V<sub>L</sub>`，所以繞組功率 `S<sub>W</sub> = (V<sub>H</sub> − V<sub>L</sub>) × I<sub>H</sub>` 遠小於通過功率 `S<sub>IO</sub> = V<sub>H</sub> × I<sub>H</sub>`。假設：理想變壓器（無損、無漏磁、激磁電流零）。

**數值實例（折算模式）**：V<sub>1</sub> = 2400 V、N<sub>1</sub> = 1000、N<sub>2</sub> = 100、負載 Z<sub>L</sub> = 5 + j3 Ω。

### 03 `03-變壓器等效電路與試驗.html`

**目標**：把理想變壓器加上四個不理想：線圈電阻、漏電抗、鐵損、激磁電流，得到近似等效電路；再說明兩個試驗怎麼各自「關掉」一半電路，讓四個參數能從六個讀數算出來。全課用同一台變壓器：**10 kVA、2400/240 V、60 Hz**。

**要點**：實際變壓器：一二次線圈電阻 R<sub>1</sub>、R<sub>2</sub>；漏電抗（leakage reactance）X<sub>1</sub>、X<sub>2</sub>（沒穿過鐵心的那部分磁通）；激磁分支：鐵損電阻（core-loss resistance）R<sub>c</sub> 並聯激磁電抗（magnetizing reactance）X<sub>m</sub>。近似等效電路：把二次側折算到一次側後，激磁分支移到端點，串聯合併成 `R<sub>eq</sub> = R<sub>1</sub> + a² R<sub>2</sub>`、`X<sub>eq</sub> = X<sub>1</sub> + a² X<sub>2</sub>`。開路試驗（open-circuit test）：低壓側加額定電壓、高壓側開路，串聯支路幾乎沒電流，量到的功率就是鐵損、電流就是激磁電流；短路試驗（short-circuit test）：低壓側短路、高壓側加低電壓使電流達額定，激磁分支幾乎沒電壓，量到的功率就是銅損、阻抗就是 Z<sub>eq</sub>。百分阻抗 `%Z = Z<sub>eq</sub> / Z<sub>base</sub> × 100`，`Z<sub>base</sub> = V<sub>rated</sub>² / S<sub>rated</sub>`。來源：12-電機機械 §2.2、§2.3。

**推導必寫**：（a）開路：`G<sub>c</sub> = P<sub>oc</sub> / V<sub>oc</sub>²`、`|Y| = I<sub>oc</sub> / V<sub>oc</sub>`、`B<sub>m</sub> = √(|Y|² − G<sub>c</sub>²)`，`R<sub>c</sub> = 1 / G<sub>c</sub>`、`X<sub>m</sub> = 1 / B<sub>m</sub>`——在低壓側量到的值要乘 a² 才是高壓側的值。（b）短路：`|Z<sub>eq</sub>| = V<sub>sc</sub> / I<sub>sc</sub>`、`R<sub>eq</sub> = P<sub>sc</sub> / I<sub>sc</sub>²`、`X<sub>eq</sub> = √(|Z|² − R²)`。（c）為什麼開路試驗要在低壓側做：額定電壓小、儀表安全；短路試驗要在高壓側做：額定電流小、儀表安全。（d）讀數的物理限制：`P ≤ V × I`（功率因數不能大於 1）、`I<sub>oc</sub> ≥ I<sub>c</sub>`；違反即讀數有誤。假設：近似等效電路、線性、忽略試驗時的溫升。

**數值實例**：a = 10；開路試驗（低壓側 240 V）：V<sub>oc</sub> = 240 V、I<sub>oc</sub> = 3.01 A、P<sub>oc</sub> = 60 W；短路試驗（高壓側）：V<sub>sc</sub> = 60 V、I<sub>sc</sub> = 4.17 A、P<sub>sc</sub> = 139 W。（這組讀數來自設計值 R<sub>eq</sub> = 8 Ω、X<sub>eq</sub> = 12 Ω、R<sub>c</sub> = 96 kΩ、X<sub>m</sub> = 8 kΩ 四捨五入到儀表刻度；算回去會有小差異，正文要明說這是儀表取整造成的。）

| --- | --- | --- |
| 鐵損電導（低壓側） | 60 / 240² | **0.001042 S**，R<sub>c,LV</sub> = **960.000000 Ω** |

### 04 `04-電壓調整率與效率.html`

**目標**：用第 03 章那台變壓器的參數回答兩個實務問題：負載一接上去，二次電壓掉多少（電壓調整率）；能量進去多少出來多少（效率），以及**為什麼最大效率不在滿載，而在銅損等於鐵損的那個負載點**。

**要點**：以低壓側（240 V）為基準：R<sub>eq,LV</sub> = 0.08 Ω、X<sub>eq,LV</sub> = 0.12 Ω（第 03 章設計值折算）、鐵損 P<sub>core</sub> = 60 W、額定二次電流 41.666667 A。電壓調整率（voltage regulation, VR）：`VR = (|V<sub>1</sub>′| − V<sub>2</sub>) / V<sub>2</sub> × 100 %`，V<sub>1</sub>′ 是一次電壓折算到二次側；相量：`V<sub>1</sub>′ = V<sub>2</sub> + I<sub>2</sub>∠−θ × (R<sub>eq</sub> + jX<sub>eq</sub>)`（落後功因 θ 為正、領前為負）。效率 `η = P<sub>out</sub> / (P<sub>out</sub> + P<sub>cu</sub> + P<sub>core</sub>)`，`P<sub>out</sub> = x × S × pf`、`P<sub>cu</sub> = x² × P<sub>cu,fl</sub>`；最大效率條件 `P<sub>cu</sub> = P<sub>core</sub>` ⇒ `x* = √(P<sub>core</sub> / P<sub>cu,fl</sub>)`。來源：12-電機機械 §2.4。

**推導必寫**：（a）相量展開：`V<sub>1</sub>′ = [V<sub>2</sub> + I(R cos θ + X sin θ)] + j[I(X cos θ − R sin θ)]`（落後）；領前時 sin θ 變號，`X sin θ` 項變成減，所以**電容性負載可以讓 VR 變負（二次電壓反而升高）**。（b）為什麼最大效率在銅損 = 鐵損：η 對 x 微分，鐵損不隨 x 變、銅損隨 x² 變，導數為零時 x² P<sub>cu,fl</sub> = P<sub>core</sub>——**配電變壓器大部分時間輕載，所以設計成 x* 落在 0.5–0.7**。（c）功率因數對效率的影響：pf 低時 P<sub>out</sub> 小但銅損不變（電流一樣），效率下降。假設：近似等效電路、鐵損不隨負載變、忽略溫度對電阻的影響。

**數值實例**：x = 1.0（滿載）、pf = 0.8 落後、R<sub>eq,LV</sub> = 0.08 Ω、X<sub>eq,LV</sub> = 0.12 Ω、P<sub>core</sub> = 60 W、V<sub>2</sub> = 240 V、S = 10 kVA。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 二次電流 | 1.0 × 10000 / 240 | **41.666667 A** |
| 實部 | 240 + 41.666667 × (0.08 × 0.8 + 0.12 × 0.6) | **245.666667 V** |
| 虛部 | 41.666667 × (0.12 × 0.8 − 0.08 × 0.6) | **2.000000 V** |
| &#124;V<sub>1</sub>′&#124; | √(245.666667² + 2²) | **245.674808 V** |
| 電壓調整率 | (245.674808 − 240) / 240 | **2.364503 %** |
| 輸出功率 | 1.0 × 10000 × 0.8 | **8000.000000 W** |
| 銅損 | 41.666667² × 0.08 | **138.888889 W** |

邊界對照：pf 0.8 **領前** → |V<sub>1</sub>′| = **239.741759 V**、VR = **−0.107600 %**（二次電壓比空載還高）；pf = 1 → VR = **1.410291 %**、η = **98.049897 %**；x = 0.5 → VR = **1.181413 %**、η = **97.686724 %**（比滿載高）；x = 0.65 → η = **97.768609 %**（就在最大值旁）；x = 1.25（過載）→ VR = **2.956659 %**、η = **97.304529 %**；x = 0 → η = 0（只有鐵損 60 W 在燒）；P<sub>core</sub> 改 200 W → x* = **1.200000**（超過額定，這種設計不合理）；pf = 0.5 → η = **96.174396 %**（同樣電流、一半實功）。

### 05 `05-旋轉機共同語言.html`

**目標**：建立 06–10 章共用的語言：定子與轉子、氣隙、同步速 `n<sub>s</sub> = 120 × f / P`、轉矩與功率 `P = T × ω`、四種損耗（銅損、鐵損、機械損、雜散損）與功率流圖。做一個「輸出端反推輸入端」的算數實驗：給轉矩、轉速與四種損耗，算輸出、輸入與效率。

**要點**：定子（stator）不動、轉子（rotor）轉；氣隙（air gap）是磁路裡磁阻最大的一段（第 01 章）；換向器（commutator）與電刷（brush）是直流機特有；集電環（slip ring）給繞線式感應機與同步機。同步速：P 極的定子繞組接 f Hz 三相電，產生以 `n<sub>s</sub> = 120 × f / P` rpm 旋轉的磁場（P 是極數，不是極對數；筆記 §3.2 用極對數 p 寫成 60f / p，兩者一致）；`ω<sub>s</sub> = 2π × n<sub>s</sub> / 60`。轉矩 T（N·m）、角速度 ω（rad/s）、`P = T × ω`。功率流：`P<sub>in</sub> → 定子銅損 → 鐵損 → 氣隙 → 轉子銅損 → 機械損（摩擦、風阻）→ 雜散損 → P<sub>out</sub>`；本章把四種損耗當四個輸入，不分定子轉子。滑差先在這裡定義一次 `s = (n<sub>s</sub> − n) / n<sub>s</sub>`，第 07 章再深講。來源：12-電機機械 §3.1、§3.2、§3.3。

**推導必寫**：（a）為什麼是 120 f / P：三相電每個週期讓磁場走過一對極，每分鐘 60 f 個週期，P / 2 對極，所以 n<sub>s</sub> = 60 f / (P / 2) = 120 f / P。（b）為什麼 P = T × ω：力乘速度的旋轉版，量綱 N·m × rad/s = W；rpm 要先換成 rad/s。（c）效率 `η = P<sub>out</sub> / (P<sub>out</sub> + Σ損耗)`；固定損耗（鐵損、機械損）與可變損耗（銅損 ∝ 負載²）的關係與第 04 章相同，最大效率同樣在兩者相等處。（d）n 與 n<sub>s</sub> 的關係決定機器類型：n < n<sub>s</sub> 感應馬達、n = n<sub>s</sub> 同步機、n > n<sub>s</sub> 感應發電機。假設：穩態、損耗值給定不隨轉速變。

**數值實例**：f = 60 Hz、P = 4 極、n = 1750 rpm、T = 40 N·m、銅損 400 W、鐵損 200 W、機械損 150 W、雜散損 50 W。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 同步速 | 120 × 60 / 4 | **1800 rpm**，ω<sub>s</sub> = **188.495559 rad/s** |
| 軸角速度 | 2π × 1750 / 60 | **183.259571 rad/s** |
| 滑差 | (1800 − 1750) / 1800 | **2.777778 %** |
| 輸出功率 | 40 × 183.259571 | **7330.382858 W（9.826250 hp）** |
| 總損耗 | 400 + 200 + 150 + 50 | **800.000000 W** |

邊界對照：f = 50 Hz → n<sub>s</sub> = **1500 rpm**，1750 rpm 已超過同步速（s = **−16.666667 %**，感應機在發電）；P = 2 → n<sub>s</sub> = **3600 rpm**，s = **51.388889 %**（這麼大的滑差感應機根本跑不到，表示極數設錯）；n = 1800 → s = 0（只有同步機能在這裡出力）；n = 0 → 輸出 0、效率 0，**堵轉：全部輸入變損耗**；n = 1850 → s = **−2.777778 %**，感應發電機（風機）；T = 0 → 輸出 0，只剩損耗 800 W；P = 8、n = 850 → n<sub>s</sub> = 900、s = **5.555556 %**、輸出 **3560.471674 W**、效率 **81.653361 %**（同樣的損耗吃掉更大的比例）。

### 06 `06-直流機轉矩轉速線.html`

**目標**：把第 00 章的導桿捲成電樞，得到直流機的兩條方程 `E<sub>a</sub> = KΦ × ω`、`T = KΦ × I<sub>a</sub>`，推出他激／並激馬達的轉矩–轉速線 `ω = V<sub>t</sub> / KΦ − R<sub>a</sub> × T / (KΦ)²`，並讓讀者親眼看到：改電樞電壓整條線平移，改激磁電流截距與斜率一起變。全課直流機：**V<sub>t</sub> = 240 V、R<sub>a</sub> = 0.5 Ω、KΦ = 1.0 × I<sub>f</sub>（V·s/rad，線性）**。

**要點**：直流機（DC machine）結構：定子產生磁場（永磁或激磁繞組）、轉子是電樞（armature）、換向器把電樞裡的交流換成外部直流。反電動勢 `E<sub>a</sub> = KΦ × ω`（第 00 章 B l v 的旋轉版）、轉矩 `T = KΦ × I<sub>a</sub>`（B i l 的旋轉版）、電樞回路 `V<sub>t</sub> = E<sub>a</sub> + I<sub>a</sub> × R<sub>a</sub>`。激磁方式（excitation method）：他激（separately excited）、並激（shunt）、串激（series，KΦ 隨 I<sub>a</sub> 變，起動轉矩大、輕載會飛車）、複激（compound）；本章互動只做他激／並激（KΦ 由獨立的 I<sub>f</sub> 決定）。電樞反應與電刷壓降只提名字不算。來源：12-電機機械 §4.1、§4.2、§4.3。

**推導必寫**：（a）穩態電流由負載決定：`I<sub>a</sub> = T / KΦ`（第 00 章那句話）。（b）轉速：`ω = (V<sub>t</sub> − I<sub>a</sub> R<sub>a</sub>) / KΦ = V<sub>t</sub> / KΦ − R<sub>a</sub> T / (KΦ)²`——**這是一條直線**：截距（無負載速度）V<sub>t</sub> / KΦ、斜率 −R<sub>a</sub> / (KΦ)²。（c）改 V<sub>t</sub>：截距變、斜率不變 → 整條線平移，這是最常用的調速法（**電樞電壓控制**）。（d）改 I<sub>f</sub>（弱磁）：KΦ 變小，截距變大（升速）、斜率變陡（轉矩能力變差），同樣轉矩要更多電樞電流——**這就是第 00 章「B 減半電流加倍」**。（e）起動：ω = 0 時 E<sub>a</sub> = 0，`I<sub>start</sub> = V<sub>t</sub> / R<sub>a</sub>`；失速轉矩 `T<sub>stall</sub> = KΦ × I<sub>start</sub>`。假設：KΦ 與 I<sub>f</sub> 成正比（無飽和）、忽略電樞反應、電刷壓降與機械損。

**數值實例**：V<sub>t</sub> = 240 V、I<sub>f</sub> = 1.0 A（KΦ = 1.000000 V·s/rad）、R<sub>a</sub> = 0.5 Ω、T<sub>load</sub> = 20 N·m。

### 07 `07-感應機滑差與功率流.html`

**目標**：講清楚感應馬達為什麼一定要比旋轉磁場慢一點才有轉矩（滑差），轉子裡的電流頻率是多少，以及氣隙功率怎麼照 `1 : (1 − s) : s` 分成機械功率與轉子銅損——**滑差就是轉子銅損的比例**。全課感應機：**380 V（Y 接）、60 Hz、4 極**。

**要點**：三相感應馬達（induction motor, IM）：定子三相繞組接三相電，產生以 n<sub>s</sub> 旋轉的磁場（旋轉磁場，rotating magnetic field）；轉子（鼠籠式 squirrel-cage 或繞線式 wound-rotor）沒接電源，靠切割旋轉磁場感應出電壓與電流，再與磁場互動產生轉矩。轉子若追到 n<sub>s</sub>，相對運動為零，沒有感應、沒有轉矩——所以轉子永遠慢一點：滑差（slip）`s = (n<sub>s</sub> − n) / n<sub>s</sub>`，額定點 2 %–5 %，故稱非同步機（asynchronous machine）。轉子電壓與頻率都與 s 成正比：`f<sub>r</sub> = s × f`。功率流：氣隙功率（air-gap power）P<sub>AG</sub> 穿過氣隙進轉子，`P<sub>RCL</sub> = s × P<sub>AG</sub>`（轉子銅損）、`P<sub>conv</sub> = (1 − s) × P<sub>AG</sub>`（轉換成機械）、`P<sub>out</sub> = P<sub>conv</sub> − P<sub>mech</sub>`；感應轉矩 `T<sub>ind</sub> = P<sub>AG</sub> / ω<sub>s</sub> = P<sub>conv</sub> / ω`。單相感應馬達需要起動繞組或電容才有旋轉磁場（只講一句）。來源：12-電機機械 §5.1、§5.2。

**推導必寫**：（a）為什麼轉子頻率是 s f：轉子看到的磁場轉速是 n<sub>s</sub> − n = s n<sub>s</sub>，感應頻率照比例縮成 s f；起動時 s = 1、f<sub>r</sub> = 60 Hz，額定時 s = 0.033、f<sub>r</sub> = 2 Hz。（b）為什麼轉子銅損是 s P<sub>AG</sub>：轉子電阻 R<sub>2</sub> 上的損耗是 I<sub>2</sub>² R<sub>2</sub>，而氣隙功率是 I<sub>2</sub>² (R<sub>2</sub> / s)（第 08 章等效電路），兩者相除得 s。（c）為什麼 T<sub>ind</sub> = P<sub>AG</sub> / ω<sub>s</sub> 又 = P<sub>conv</sub> / ω：P<sub>conv</sub> / P<sub>AG</sub> = 1 − s = ω / ω<sub>s</sub>，兩條式子是同一個轉矩。（d）為什麼低滑差是效率的天花板：轉子效率上限就是 1 − s，s = 3 % 時轉子最多 97 %。假設：忽略定子銅損與鐵損（本章只看氣隙以後）。

**數值實例**：f = 60 Hz、P = 4、n = 1740 rpm、P<sub>AG</sub> = 8000 W、機械損 150 W。

### 08 `08-感應機轉矩曲線.html`

**目標**：把感應機畫成一個像變壓器的等效電路（轉子折算到定子側，轉子電阻寫成 R<sub>2</sub> / s），用戴維寧等效把定子與激磁分支收成一個電源，得到轉矩對滑差的公式與整條轉矩–滑差曲線：起動轉矩、崩潰（最大）轉矩、崩潰滑差；並讓讀者看到三件事——轉矩與電壓平方成正比、崩潰轉矩與 R<sub>2</sub> 無關、R<sub>2</sub> 只把崩潰點往高滑差推。

**要點**：等效電路（每相）：定子 R<sub>1</sub> + jX<sub>1</sub>，激磁 jX<sub>M</sub>，轉子折算 R<sub>2</sub> / s + jX<sub>2</sub>（本章忽略鐵損電阻）。戴維寧等效（Thévenin equivalent）：從轉子端看回去，`V<sub>TH</sub> = V<sub>φ</sub> × X<sub>M</sub> / √(R<sub>1</sub>² + (X<sub>1</sub> + X<sub>M</sub>)²)`、`Z<sub>TH</sub> = jX<sub>M</sub> × (R<sub>1</sub> + jX<sub>1</sub>) / (R<sub>1</sub> + j(X<sub>1</sub> + X<sub>M</sub>))`。轉矩 `T = 3 × V<sub>TH</sub>² × (R<sub>2</sub> / s) / (ω<sub>s</sub> × [(R<sub>TH</sub> + R<sub>2</sub> / s)² + (X<sub>TH</sub> + X<sub>2</sub>)²])`；崩潰滑差 `s<sub>max</sub> = R<sub>2</sub> / √(R<sub>TH</sub>² + (X<sub>TH</sub> + X<sub>2</sub>)²)`；崩潰轉矩（pull-out torque）`T<sub>max</sub> = 3 × V<sub>TH</sub>² / (2 × ω<sub>s</sub> × [R<sub>TH</sub> + √(R<sub>TH</sub>² + (X<sub>TH</sub> + X<sub>2</sub>)²)])`；起動轉矩 T<sub>start</sub> = T(s = 1)。鎖定參數：R<sub>1</sub> = 0.5 Ω、X<sub>1</sub> = 1.0 Ω、R<sub>2</sub> = 0.4 Ω、X<sub>2</sub> = 1.0 Ω、X<sub>M</sub> = 30 Ω（60 Hz 值；50 Hz 時三個電抗乘 50/60）、4 極。來源：12-電機機械 §5.2、§5.3。

**推導必寫**：（a）為什麼轉子電阻寫成 R<sub>2</sub> / s：轉子回路的電壓與電抗都與 s 成正比，整條除以 s 之後電壓變成定子頻率的固定值，代價是電阻變 R<sub>2</sub> / s；其中 R<sub>2</sub> 是真的銅損、`R<sub>2</sub>(1 − s) / s` 是機械功率（第 07 章的 1 : (1 − s) : s 由此而來）。（b）戴維寧為什麼好用：轉矩只看轉子電流，把前面收成一個 V<sub>TH</sub> 與 Z<sub>TH</sub>，公式就只剩一個迴路。（c）T<sub>max</sub> 為什麼與 R<sub>2</sub> 無關：最大功率轉移條件下 R<sub>2</sub> / s 等於源端阻抗大小，s 消掉了 R<sub>2</sub>——**R<sub>2</sub> 只決定在哪個 s 達到 T<sub>max</sub>**，繞線式感應機就是靠外加轉子電阻把 T<sub>max</sub> 推到起動點。（d）T ∝ V<sub>TH</sub>² ∝ V<sub>φ</sub>²：電壓掉 10 %，轉矩掉 19 %。假設：線性、穩態、忽略鐵損與機械損、參數不隨頻率與溫度變（除電抗按 f 縮放）。

### 09 `09-同步發電機功率角.html`

**目標**：講清楚同步機的等效電路 `V<sub>t</sub> = E<sub>f</sub> − jX<sub>s</sub> I<sub>a</sub>`，以及實功率為什麼由**內電勢與端電壓的相角差 δ（功率角）**決定：`P = 3 × V<sub>φ</sub> × E<sub>f</sub> × sin δ / X<sub>s</sub>`；δ = 90° 是靜態穩定極限，超過就脫步。同時看無功由 E<sub>f</sub> cos δ 與 V<sub>t</sub> 的差決定。本章鎖定：**V<sub>φ</sub> = 220 V、X<sub>s</sub> = 2.0 Ω**（每相，Y 接）。

**要點**：同步機（synchronous machine）：轉子由直流激磁（或永磁），轉速等於同步速；發電機時原動機推轉子、內電勢 E<sub>f</sub> 領前端電壓 δ；馬達時 E<sub>f</sub> 落後。等效電路（圓柱轉子、忽略電樞電阻）：`E<sub>f</sub>∠δ = V<sub>t</sub>∠0° + jX<sub>s</sub> I<sub>a</sub>`；同步電抗（synchronous reactance）X<sub>s</sub> 包含電樞反應與漏電抗。`P = 3 V<sub>φ</sub> E<sub>f</sub> sin δ / X<sub>s</sub>`、`Q = 3 V<sub>φ</sub> (E<sub>f</sub> cos δ − V<sub>φ</sub>) / X<sub>s</sub>`；P<sub>max</sub> 在 δ = 90°；同步化功率係數 dP/dδ = 3 V<sub>φ</sub> E<sub>f</sub> cos δ / X<sub>s</sub>（越接近 90° 越小，機器越「軟」）。原動機管實功（推 δ），激磁管無功與電壓（推 E<sub>f</sub>）——**這是電力系統頻率與電壓控制的根本**。來源：12-電機機械 §6.1、§6.2。

**推導必寫**：（a）從 KVL 到功率角：`I<sub>a</sub> = (E<sub>f</sub>∠δ − V<sub>φ</sub>) / (jX<sub>s</sub>)`，代入 `S = 3 V<sub>φ</sub> I<sub>a</sub>*`，實部得 P、虛部得 Q。（b）為什麼 δ 超過 90° 會脫步：P 隨 δ 上升到 90° 後反而下降，原動機的力仍在推、電磁轉矩卻減少，δ 只會越推越大——失去同步。（c）激磁與無功：E<sub>f</sub> cos δ > V<sub>φ</sub>（超激磁）供給無功、反之吸收；δ = 0 時 P = 0、Q = 3 V<sub>φ</sub>(E<sub>f</sub> − V<sub>φ</sub>) / X<sub>s</sub>，純無功。假設：圓柱轉子（無磁阻轉矩）、忽略 R<sub>a</sub>、穩態、端電壓由電網撐住（無限匯流排）。

**數值實例**：E<sub>f</sub> = 300 V、V<sub>φ</sub> = 220 V、X<sub>s</sub> = 2.0 Ω、δ = 20°。

**可觀察證據**：功率計量 P 與 Q（或相位計量 θ）；δ 要用轉子位置感測器與電壓過零比對才量得到（相量量測單元 PMU 就是做這件事）。**能證明**：P、Q 與功率因數。**不能證明**：δ 本身（一般廠內儀表沒有），也證明不了 X<sub>s</sub>（要空載與短路試驗）。

**連到哪門課**：發電機接上電網之後的頻率、電壓與潮流見 `../../04-電力特化/P1-電力系統-互動網站/index.html`；同一台機器當馬達用、固定 P 改激磁，就是第 10 章的 V 曲線。

### 10 `10-同步馬達V曲線.html`

**目標**：同一台同步機當馬達：實功由負載定死，改激磁只改 δ 與無功——電樞電流對激磁電流畫出來是一條 V 形曲線，最低點是單位功因；超激磁時馬達像一顆電容，可以幫廠內做功因修正。鎖定：**V<sub>φ</sub> = 220 V、X<sub>s</sub> = 2.0 Ω**。

**要點**：同步馬達（synchronous motor）：轉子直流激磁，鎖在同步速上跑（無滑差）；馬達慣例 `V<sub>φ</sub>∠0° = E<sub>f</sub>∠−δ + jX<sub>s</sub> I<sub>a</sub>`。固定實功 P：`sin δ = P × X<sub>s</sub> / (3 V<sub>φ</sub> E<sub>f</sub>)`；E<sub>f</sub> 越大 δ 越小；`I<sub>a</sub> = (V<sub>φ</sub> − E<sub>f</sub>∠−δ) / (jX<sub>s</sub>)`；電流領前（超激磁 overexcited，供給無功、電容性）或落後（欠激磁 underexcited，吸收無功、電感性）。V 曲線（V curve）：|I<sub>a</sub>| 對 E<sub>f</sub>（或 I<sub>f</sub>）的曲線，最低點在單位功因，`I<sub>a,min</sub> = P / (3 V<sub>φ</sub>)`、`E<sub>f,unity</sub> = |V<sub>φ</sub> − jX<sub>s</sub> I<sub>a,min</sub>|`。最小激磁：`E<sub>f,min</sub> = P X<sub>s</sub> / (3 V<sub>φ</sub>)`（sin δ = 1），低於它就脫步。永磁同步馬達（PMSM）：E<sub>f</sub> 由磁鐵定死，不能調激磁，功因靠變頻器的電流角控制（只講一句，不算）。來源：12-電機機械 §6.3、§6.4。

**推導必寫**：（a）為什麼固定 P 時改 E<sub>f</sub> 只動 Q：P = 3 V E sin δ / X<sub>s</sub> 固定，E 與 sin δ 反比；E cos δ 決定 Q 的正負。（b）電流相量：`I<sub>a</sub> = [V<sub>φ</sub> − E<sub>f</sub>(cos δ − j sin δ)] / (jX<sub>s</sub>)`，實部 `E<sub>f</sub> sin δ / X<sub>s</sub>` 恆等於 P / (3 V<sub>φ</sub>)（固定），虛部 `(E<sub>f</sub> cos δ − V<sub>φ</sub>) / X<sub>s</sub>` 隨 E<sub>f</sub> 從負變正——**這就是 V 形的來源**：實部不變、虛部過零。（c）功因修正：工廠裡感應馬達吸收無功，一台超激磁的同步馬達可以就地供給，減少從電網拉的無功。假設：同 09 章，另假設實功不含損耗。

### 11 `11-起動與速控.html`

**目標**：把第 06 與第 08 章的兩台機器拿來問兩個實務問題：怎麼起動才不會把電流拉到額定的好幾倍，怎麼調速。直流機：起動電阻、電樞電壓與弱磁；感應機：直接起動（DOL）、Y–Δ、自耦變壓器、變頻（VFD）四種起動方式的線電流倍數與起動轉矩倍數比較，以及 V/f 定值調速。互動只做感應機起動比較（直流機的數字在正文用第 06 章算）。

**要點**：直流機起動：ω = 0 時 I<sub>start</sub> = V<sub>t</sub> / R<sub>a</sub> = 240 / 0.5 = **480.000000 A**（額定 20 A 的 **24.000000 倍**）；串起動電阻限到 2 倍額定：`R<sub>start</sub> = V<sub>t</sub> / (2 × I<sub>rated</sub>) − R<sub>a</sub> = 240 / 40 − 0.5 = 5.500000 Ω`，隨 E<sub>a</sub> 上升分段切除；調速：電樞電壓（額定速以下，定轉矩）、弱磁（額定速以上，定功率）。感應機起動基準：直接起動（direct-on-line, DOL）線電流 k 倍額定（本課 k = 6）、起動轉矩 t 倍額定（t = 1.5）；Y–Δ 起動：起動時每相電壓變 1/√3，電流與轉矩都變 **1/3**；自耦變壓器起動（分接頭 x）：馬達端電壓 x V，馬達電流 x k，線電流 **x² k**，轉矩 **x² t**；變頻起動：V/f 定值、從低頻慢慢升，電流約 1.5 倍額定、轉矩約 1.0 倍額定（鎖定常數）。判準：起動轉矩 ≥ 1.1 × 負載轉矩才起得動。V/f 調速：`n<sub>s</sub> = 120 f / P`，60 Hz → 30 Hz 時 4 極 n<sub>s</sub> 1800 → **900 rpm**，電壓同比例 380 → **190.000000 V** 保持磁通（第 01 章）。來源：12-電機機械 §4.4、§5.4、§8。

**推導必寫**：（a）為什麼 Y–Δ 是 1/3：Y 接每相電壓是 Δ 接的 1/√3，相電流變 1/√3，Δ 接的線電流是相電流的 √3 倍而 Y 接相等，合起來線電流變 1/3；轉矩 ∝ V² 也是 1/3。（b）為什麼自耦是 x²：馬達電壓 x 倍 → 馬達電流 x 倍，變壓器把線電流再縮 x 倍。（c）為什麼變頻起動能用小電流拿到大轉矩：低頻時 R<sub>2</sub> / s 相對大、電流小，而磁通靠 V/f 維持，轉矩不掉——**其他三種都是「降壓換小電流、轉矩跟著平方掉」，只有變頻不是**。（d）直流機為什麼要起動電阻：E<sub>a</sub> = 0 時只剩 R<sub>a</sub> 限流。假設：起動倍數為固定常數、忽略暫態與電網電壓降。

### 12 `12-馬達家族與選型.html`

**目標**：把全課的機器排成一張表，用六項準則（效率、低成本、控制簡單、定位能力、功率密度、可調激磁）的加權分數比較六種馬達家族，讓讀者看到「電動車選永磁同步、泵浦選感應機、印表機選步進」不是口訣而是取捨。同時介紹筆記第 7、8 章的特殊馬達與驅動一窺。

**要點**：永磁同步馬達（PMSM）：轉子永磁、正弦反電動勢、需位置感測與變頻器、高效率高功率密度，電動車主流；無刷直流馬達（brushless DC motor, BLDC）：永磁＋電子換向、梯形反電動勢、驅動簡單，無人機、風扇、伺服；步進馬達（stepper motor）：每脈衝固定角度、開迴路定位，印表機、3D 印表機；伺服馬達（servo motor）：閉迴路位置控制，是「馬達＋編碼器＋驅動器」的系統名而不是一種機器；線性馬達：把旋轉拉直；繞線激磁同步機：可調激磁、大功率發電；有刷直流機：控制最簡單、要換電刷；三相感應機：最便宜最耐用、工業用量最大。驅動一瞥：整流器 AC→DC、逆變器 DC→AC（PWM）、變頻器 = 兩者合體；磁場導向控制（field-oriented control, FOC）把三相電流變到旋轉座標像直流機一樣分開控磁通與轉矩——**只講一句，公式留給馬達驅動課**。來源：12-電機機械 §6.4、§7、§8。

**推導必寫**：（a）為什麼 PMSM 效率高：轉子沒有激磁繞組也沒有感應電流，少掉一整塊轉子銅損（第 07 章的 s P<sub>AG</sub>）。（b）為什麼 BLDC 與 PMSM 是同一類機器、不同驅動：兩者都是永磁轉子＋定子繞組，差在反電動勢波形與換向方式。（c）為什麼步進馬達能開迴路：每個脈衝對應固定角度，只要不失步就不需要回授，代價是效率低與失步風險。（d）評分模型：`總分 = Σ 權重<sub>i</sub> × 分數<sub>i</sub>`，權重 0–5、分數 1–5，是一階教學模型，**不是工程選型依據**。
