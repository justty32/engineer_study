02・換電壓座標，功率保持不變

阻抗折算與自耦變壓器：a² 從哪裡來

2400 V、1000 匝對 100 匝形成 10.000000 的匝比，5 + j3 Ω 負載從一次側看成 500.000000 + j300.000000 Ω。改接自耦後，同一組繞組可用 909.090909 VA 承接 10 kVA 通過功率。

這章假設已懂： 01 鐵心電壓與磁通。前置：見〈14 變壓器與三相〉匝比與 Y／Δ，本章不重講其機制。

痛點：二次側的 5 Ω，為何一次側看見 500 Ω

變壓器不會憑空增加負載電阻，卻會讓電源端看到另一個阻抗。若只記 a²，常會把升壓、降壓方向顛倒，也會誤以為功率被平方放大。另一個疑問是：自耦接法為何可以用較小的繞組容量傳遞較大功率，而它省下材料時又犧牲了什麼？

白話直覺：折算像換一把刻度不同的尺

比喻只到這裡。精確因果鏈從一次側電源與共同參考端開始：理想磁通同時連結兩組繞組，使電壓按匝比改變、電流反比改變；負載回路導通後，其實功與無功仍由同一負載吸收，穩態輸入輸出視在功率相等。一次側電壓表與電流表的比值，就是折算後的入端阻抗。

自耦接法讓共同繞組與串聯繞組直接相連。共同段只承擔電流差，串聯段只承擔電壓差，所以繞組處理的是差額功率；但兩側也因此沒有電氣隔離。

來源：12-電機機械 §2.1、§2.6。

推導：電壓乘 a、電流除 a

理想關係為 V1 / V2 = N1 / N2 = a，I1 / I2 = 1 / a。因此 Z′ = V1 / I1 = a² × ZL。電阻與電抗都乘 a²，而 V × I 不變；折算只是換座標，不是換能量。搬到同一電壓層級後，就能用單一迴路直接列 KVL。

自耦升壓有 VH / VL = (NC + NSE) / NC。共同繞組電流 IC = IL − IH，串聯段承受 VH − VL，故 SW = (VH − VL) × IH，SIO / SW = (NC + NSE) / NSE。

假設無損、無漏磁且激磁電流為零。本課用的是線性穩態教學模型，真實機器不完全如此。儀器用變壓器另有安全邊界：CT 二次側絕不可開路，PT 二次側不可短路。

數值實例：同一組繞組的兩種接法

折算模式取 V1 = 2400 V、N1 = 1000、N2 = 100、ZL = 5 + j3 Ω。

匝比／二次電壓 10.000000／240.000000 V
負載大小／功率因數 5.830952 Ω／0.857493 落後
二次／一次電流 41.159660 A／4.115966 A
折算阻抗 500.000000 + j300.000000 Ω，大小 583.095189 Ω
檢查 2400 / 583.095189 = 4.115966 A ✓
S／P／Q 9878.318504 VA／8470.588235 W／5082.352941 var

自耦模式取 NC = 1000、NSE = 100、VL = 2400 V、SIO = 10 kVA：VH = 2640.000000 V，IH = 3.787879 A，IL = 4.166667 A，IC = 0.378788 A，SW = 909.090909 VA，優勢 11.000000。

量級對照。a = 1 時只隔離不變壓；a = 0.1 時 Z′ = 0.050000 + j0.030000 Ω，一次電流 41159.660434 A，理想模型不限流。自耦若 NSE = 1000，優勢降為 2.000000；NC = 100、NSE = 1000 時只剩 1.100000。

折算要整組一起做。把二次側移到一次側時，實部與虛部都乘 a²，電感性或電容性不會因換側而改變。功率因數也不變，因為阻抗角不變；一次與二次視在功率相等，只有電壓和電流採不同刻度。若只折算電阻、漏掉電抗，電流大小與相位都會錯。若 X = −3 Ω，Q = −5082.352941 var，代表電容性負載供給無功，負號不是故障。

自耦優勢有邊界。高低壓接近時，串聯段只承受小電壓差，共同段只承受小電流差，小型繞組便能傳遞較大通過功率。升壓比愈大，差額占比愈高，優勢逐漸接近 1。低壓端與高壓端有導電路徑，高壓故障可能直達低壓側，不能用於隔離。選型要一起比較材料、絕緣與故障保護，不能只看 11.000000 的容量優勢。

短路是模型警告。R 與 X 同為零時，理想模型給出無限電流，不能硬填有限數字。真實繞組電阻與漏阻抗會限流，但仍可能達危險量級，這正是下一章加入實際參數的理由。

用功率守恆查方向。預設負載的二次視在功率是 9878.318504 VA，一次側也應相同；電流縮小十倍時，電壓正好放大十倍。若折算後算出功率多了 a² 倍，表示只改了電壓或只改了電流，沒有成對變換。實功與無功也要一起保留，因為功率因數 0.857493 落後描述的正是兩者比例。

安全原則不能被理想公式遮住。CT 正常工作時二次側接近低阻抗量測回路；若突然開路，維持磁通所需條件會造成很高端電壓，危及人員與絕緣。PT 的危險方向相反，二次短路會帶來大電流。這兩條操作禁忌來自儀器用途，不等同自耦兩側沒有隔離，但三者都提醒使用者：算對匝比不代表接線就安全。

從本章走向下一章。折算讓所有參數回到同一側，下一步才能把繞組電阻、漏電抗與激磁支路放進同一張模型。控制器或保護電驛也採相同觀念，先依比例把感測值換回共同基準，再比較額定值與保護門檻。

最後要記得，折算方向由你選定的觀察側決定。從二次側搬到一次側乘 a²；反方向則除以 a²。先在紙上標明電壓側與匝比定義，再代數字，可避免把升壓與降壓顛倒。

自由實驗：折算或自耦升壓

同一組匝數可先作雙繞組折算，再切成自耦升壓。比較負載在一次側看起來的大小，以及繞組容量相對通過功率的優勢。

這個模式只用到 V_1、N_1、N_2、R、X，其餘控制不影響結果。
a／V_2 10.000000／240.000000 V
I_2／I_1 41.159660 A／4.115966 A
Z′ 500.000000 + j300.000000 Ω，大小 583.095189 Ω
S／P／Q 9878.318504 VA／8470.588235 W／5082.352941 var
功率因數 0.857493 落後
判讀：目前為降壓，折算後阻抗變為負載的 100.000000 倍。Z′ = a² × Z_L：電壓乘 a、電流除 a，所以阻抗乘 a²，功率不變。為什麼：同一磁通連結兩側，只改變電壓與電流的座標。邊界提醒：R 與 X 同為 0 時是短路，理想模型電流無限大，數值不適用；真實機器靠第 03 章的漏阻抗限流。

不要混淆

  • 折算改的是阻抗看起來的值，負載功率沒有改變。
  • a² 來自電壓與電流各變一次，不是功率平方律。
  • 自耦省的是繞組容量，不是通過容量。
  • CT 開路危險與自耦沒有隔離，是兩種不同邊界。

可觀察證據：拿什麼量、量到什麼

用鉗形表分別量 I1、I2，再用 LCR 表從一次側量入端阻抗。電流比與阻抗比能證明匝比及 a² 折算；它們不能證明機器完全理想，因為真實一次電流還包含激磁電流與損耗。

連到哪門課

匝比與接法見變壓器與三相。控制程式那一端會依 CT、PT 比例把量測值換回一次側單位；折算也會在後續參數估測中統一座標。
