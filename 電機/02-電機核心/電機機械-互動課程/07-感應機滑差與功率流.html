07・轉子必須落後旋轉磁場，才有感應與轉矩

感應機滑差與功率流：速度差如何決定頻率、銅損與轉換功率

60 Hz、4 極感應馬達的同步速是 1800 rpm；轉子跑在 1740 rpm 時，滑差為 3.333333 %，轉子頻率只有 2.000000 Hz。這一小段速度差，同時決定轉子能否產生轉矩，以及 8000 W 氣隙功率如何分配。

這章假設已懂：06 直流機轉矩轉速線的轉矩、角速度與功率關係，也要會05 旋轉機共同語言的同步速。本章直接採用三相旋轉磁場的結論，不另設跨課前置頁。

痛點：轉子為什麼不能剛好追上磁場

直覺容易以為，旋轉磁場拖著轉子跑，最後應該兩者同速。可是感應馬達一旦追到同步速，轉子與磁場之間就沒有相對運動，轉子導體不再切割磁場，感應電壓、電流與轉矩全都消失。要持續帶負載，轉子反而必須永遠慢一點。

這個「慢一點」也不只是速度誤差。它同時縮放轉子看到的電氣頻率，並決定穿過氣隙的功率有多少變成轉子銅損、多少變成機械功率。若把滑差只當成速度百分比，就看不出堵轉發熱與額定效率為何來自同一條比例。

白話直覺：滑差是轉子看見磁場掠過自己的速度比例

可以暫時把轉子想成追逐移動步道的人：人若和步道標記完全同速，就看不到標記從身旁通過。比喻到此為止；真實機制是定子三相電流建立旋轉磁場，轉子導體與該磁場有相對速度時才產生感應電壓與電流，兩者互動才形成電磁轉矩。

本課三相都以 Y 接每相量計算。三相電源在定子各相與中性參考點間建立週期電壓，三組繞組回路導通後形成旋轉磁場；磁場以 ns 掠過未接外部電源的轉子，在鼠籠式（squirrel-cage）導條或繞線式（wound-rotor）轉子內感應電流；該電流與磁場互動產生轉矩。穩態時，電磁轉矩與負載及損耗平衡，轉子停在略低於同步速的位置。轉速計量 n，電力分析儀量輸入功率；氣隙功率要由輸入扣除定子端損耗後估算。

三相感應馬達（induction motor, IM）因此又稱非同步機。單相感應馬達沒有天然的起動方向，需要起動繞組或電容建立起動轉矩；本章只處理三相機的穩態功率流。

來源：12-電機機械 §5.1、§5.2。

推導：一個速度比例串起頻率與三段功率

同步速與滑差。同步速 ns = 120 × f / P，其中 f 是電源頻率 Hz，P 是極數，ns 的單位是 rpm。滑差（slip, s）定義為 s = (ns − n) / ns，沒有單位。馬達區的轉子比磁場慢，所以 0 < s < 1；堵轉時 n = 0、s = 1；超過同步速時 s 為負，機器進入感應發電狀態。

轉子頻率為什麼是 s × f。轉子看到磁場掠過的相對轉速是 ns − n = s × ns。相對轉速縮為同步速的 s 倍，感應電壓變化的頻率也縮為 s 倍，因此 fr = s × f。起動時 s = 1，轉子頻率就是 60 Hz；額定點 s = 0.033333 時，轉子頻率只剩 2 Hz。

氣隙功率怎麼分。氣隙功率（air-gap power）PAG 是由定子磁場傳入轉子的功率。轉子電阻上的銅損 PRCL = s × PAG，剩下 Pconv = (1 − s) × PAG 轉換成機械功率，再扣機械損 Pmech 得軸輸出 Pout。所以比例可寫成 PAG : Pconv : PRCL = 1 : (1 − s) : s。

第 08 章會把轉子支路寫成 R2 / s。當轉子電流為 I2 時，氣隙功率對應 I2² × (R2 / s)，銅損是 I2² × R2，兩者相除就是 s。這也說明低滑差給出轉子效率的上限：s = 3 % 時，氣隙之後最多有 97 % 進入機械轉換。

兩種轉矩算法為何相同。感應轉矩 Tind = PAG / ωs，也等於 Pconv / ω。因為 Pconv / PAG = 1 − s，而且 ω / ωs = 1 − s，分子與分母同比縮小，所得轉矩一致。本課用的是線性穩態教學模型，真實機器不完全如此；本章忽略定子銅損與鐵損，只追蹤氣隙以後的功率。

判讀：目前位於馬達區，轉子落後旋轉磁場 3.333333 %。氣隙功率照 1 : (1 − s) : s 分：滑差就是轉子銅損的比例。轉子頻率 f_r = s × f ＝ 2.000000 Hz。為什麼：相對速度只剩同步速的 0.033333 倍，所以轉子電氣頻率與銅損占比也同時縮為這個比例。邊界提醒：s ＝ 1 是堵轉，全部氣隙功率變成轉子銅損；s ＝ 0 時沒有感應、沒有轉矩，數字只是照式子算，實機到不了；s 小於 0 是感應發電機，多出的轉換功率來自機械輸入；s 超過 10 % 且小於 1 時，轉子銅損占比太高，不是正常工作點；n ＝ 0 時軸轉矩不適用，若 P_out 小於 0，機械損比轉換功率還大，軸實際轉不動。

不要混淆

  • 滑差不是整台機器的效率損失；它只恰好等於氣隙功率中變成轉子銅損的比例，定子損耗與機械損另算。
  • 轉子頻率不是永遠等於電源頻率。只有堵轉時兩者相同，額定運轉時通常只剩約 1–3 Hz。
  • 用 PAG / ωs 與用 Pconv / ω 算的是同一個感應轉矩；軸轉矩則還要先扣機械損。
  • 非同步不是缺點，而是感應作用持續存在的條件；若轉子與旋轉磁場完全同速，轉矩反而為零。
  • 負滑差不是算錯。只要外部原動機把轉子推過同步速，能量方向就會反過來，進入感應發電區。

可觀察證據：速度、低頻轉子電流與輸入功率

拿什麼量。轉速計量 n，配合已知 f 與極數求出 ns 和 s。對繞線式轉子，可用鉗形表或電流探棒觀察轉子引線中的低頻電流；電力分析儀則量定子三相輸入功率。

能證明什麼。實測 n 與已知 ns 能直接證明實際滑差；轉子電流波形的頻率能驗證 fr = s × f。由不同負載點的速度與轉矩，也可觀察負載增加時滑差上升。

不能證明什麼。這些量測不能直接得到氣隙功率，因為儀器只能在端點量輸入；必須先估計並扣除定子銅損與鐵損。鼠籠式轉子也沒有外露引線，無法用一般鉗形表直接量它的電流。

連到哪門課

滑差模型用在泵浦、風機、輸送帶與感應發電設備的速度診斷。第 08 章會從轉子支路 R2 / s 算出完整轉矩曲線，第 11 章則用頻率和同步速的關係說明 V/f 調速。三相旋轉磁場的空間分布屬於交流機繞組分析，本章只採用其結論。

控制程式那一端：驅動器裡的馬達極數與基頻參數決定同步速估計，速度回授再換算滑差；參數設錯會讓轉矩補償與保護判斷一起偏移。
