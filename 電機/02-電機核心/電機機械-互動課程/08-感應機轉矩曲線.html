08・最大轉矩有多高，和它出現在哪裡是兩件事

感應機轉矩曲線：用戴維寧等效找出起動點與崩潰點

380 V、60 Hz 的預設機器在 s = 0.03 時產生 49.198730 N·m，起動轉矩為 61.626951 N·m，崩潰轉矩則是 143.556819 N·m。這章把三個工作點放回同一條轉矩–滑差曲線，判斷馬達能否起動與穩定帶載。

這章假設已懂：07 感應機滑差與功率流的滑差、氣隙功率與轉子銅損。前置：見〈05 戴維寧與最大功率〉電路學的戴維寧與最大功率，了解如何從端點把線性網路收成一個電壓源與串聯阻抗。

痛點：規格寫最大轉矩很高，為什麼負載仍可能起不來

一台感應馬達可能有很高的崩潰轉矩，卻在通電後停在原地發熱。原因是轉子起動時位於 s = 1，真正能用的是起動轉矩，不是曲線上稍後才出現的最大值。若起動轉矩不足以克服靜止負載，轉子就沒有機會加速到最大轉矩附近。

另一個容易誤判的地方是轉子電阻。增加 R2 能改善起動轉矩，卻不會抬高崩潰轉矩；它只是把崩潰點移向較高滑差。至於供電電壓，曲線高度按電壓平方改變，輕微壓降就可能吃掉明顯的起動餘裕。

白話直覺：先把定子網路折成轉子端看到的電源

可以暫時把戴維寧等效想成把一整排供電元件裝進同一個黑盒，只留下轉子端看到的電壓與內阻抗。比喻到此為止；真實做法是從轉子支路的端點向定子側看，把線性定子阻抗與激磁分支化成 VTH 和 ZTH，再用單一迴路求轉子電流。

本課三相都以 Y 接每相量計算，VLL = √3 × Vφ。三相電源在每相與中性參考點間建立 Vφ；定子 R1、X1 與激磁 XM 所成回路導通，建立旋轉磁場；磁場跨越氣隙，在轉子折算支路 R2 / s + jX2 推動 I2；轉子電流與磁場互動產生轉矩。穩態工作點由電磁轉矩和負載轉矩相等決定，動力計量到 T，轉速計量到 n，再由 n 求 s。

每相等效電路包含定子 R1 + jX1、激磁 jXM 及折算後的轉子 R2 / s + jX2。本章忽略鐵損電阻，目的是把轉矩曲線的主因留下，而不是重建所有輸入電流與損耗。

來源：12-電機機械 §5.2、§5.3。

推導：R2 / s 如何形成峰值

轉子電阻為什麼寫成 R2 / s。轉子實際感應電壓與漏抗都隨 s 成正比。把整個轉子回路除以 s，可把電源與電抗換成定子頻率下的固定形式，代價是電阻成為 R2 / s。拆開可得 R2 / s = R2 + R2 × (1 − s) / s；第一項代表真正的轉子銅損，第二項代表轉換成機械的功率效果，正好接回第 07 章的 1 : (1 − s) : s。

戴維寧量。VTH = Vφ × XM / √(R1² + (X1 + XM)²)。ZTH = jXM × (R1 + jX1) / (R1 + j(X1 + XM))，其實部為 RTH，虛部為 XTH。戴維寧等效讓轉矩只剩轉子端單一迴路的事。

轉矩方程。T = 3 × VTH² × (R2 / s) / (ωs × [(RTH + R2 / s)² + (XTH + X2)²])。分子含 VTH²，所以 T 與 Vφ²成正比；電壓降到 90 %，轉矩降到 81 %。

崩潰點。當 R2 / s = √(RTH² + (XTH + X2)²) 時轉矩達峰值，因此 smax = R2 / √(RTH² + (XTH + X2)²)。代回後，Tmax = 3 × VTH² / (2 × ωs × [RTH + √(RTH² + (XTH + X2)²)])，R2 被消去。所以 R2 決定峰值位置，不決定峰值高度。

起動轉矩就是 T(1)。本課用的是線性穩態教學模型，真實機器不完全如此；假設電抗只按頻率縮放，參數不隨溫度與轉子頻率改變，並忽略鐵損、機械損與磁性飽和。

不要混淆

  • 崩潰轉矩與 R2 無關，崩潰滑差才與 R2 成正比；改電阻是平移峰值位置，不是抬高峰值。
  • 額定點位於低滑差的近似直線段，不在崩潰點；長期貼近峰值運轉沒有足夠的負載擾動餘裕。
  • 轉矩與電壓平方成正比，不是一次方；供電剩一半時，曲線高度只剩四分之一。
  • 戴維寧等效是為了簡化轉子電流與轉矩計算，它不保留完整定子輸入電流資訊。
  • 最大轉矩不等於可起動的負載。起動必須比較 T(1) 與靜止負載，還要保留 1.1 倍餘裕。

可觀察證據：動力計、堵轉試驗與空載試驗

拿什麼量。用動力計施加可控負載，同步量轉矩 T 與轉速 n，換算各點滑差。堵轉試驗以降低的電壓限制電流，估計 Req 與 Xeq；空載試驗則用輸入電流與功率估計 XM。

能證明什麼。多組 (n, T) 量測點可以驗證曲線形狀、起動端趨勢、Tmax 與 smax。在不同電壓下重測，可檢查曲線高度是否近似按電壓平方縮放。

不能證明什麼。堵轉試驗只給 R1 + R2，不能單獨證明 R2 的值。鼠籠式轉子的有效 R2 還會因轉子頻率與集膚效應改變，本章固定參數模型無法由一次試驗確認這種變化。
