11・從輸入、輸出與共同端選出放大級性格

單級放大器三大組態：增益、驅動力與頻寬各有代價

同一顆電晶體只要換訊號進出端，就會呈現不同的電壓增益、相位與端口阻抗。共射要電壓增益，共集要低輸出阻抗，共基要低輸入阻抗與高頻能力；射極退化則用增益交換穩定與線性。

這章假設已懂：10 小訊號模型的 gm、rπ、ro，以及電路學 05 戴維寧與最大功率的端口與輸出阻抗。

痛點：三張增益表背完了，遇到負載還是不知道選哪一種

「共射、共集、共基只是把端點名字輪替嗎？射隨器增益小於一，為什麼還叫放大器？」組態的核心不是名稱，而是訊號從哪一端進、從哪一端出，以及哪一端在小訊號下固定。這三個選擇同時決定相位、輸入端要吸多少電流、輸出端能否推動負載，以及內部電容會不會被增益放大。

以雙極性接面電晶體為主：共射（Common Emitter, CE）由基極輸入、集極輸出、射極作共同端；共集（Common Collector, CC）由基極輸入、射極輸出、集極在小訊號下接地，也稱射極隨耦器（emitter follower）；共基（Common Base, CB）由射極輸入、集極輸出、基極作共同端。MOSFET 一一對應為共源（CS）、共汲（CD，源隨器）與共閘（CG）。

白話直覺：同一引擎，從不同端口接取不同能力

可暫時把三種組態想成同一函式暴露不同介面；比喻到此為止，精確差異是輸入電壓如何成為 vbe，以及相依電流 gmvbe 流過哪個輸出電阻。VCC 是能量來源，地是參考；偏壓先讓 BJT 留在作用區，耦合訊號只在 Q 點附近擾動。

共射拓樸為 VCC → RC → 集極 C；射極 E → RE → 地；基極 B 接偏壓與輸入；輸出取自集極。輸入升高使 vbe 增加，更多載子由射極注入並被集極收集，集極電流增加，RC 壓降變大，集極電壓下降，所以輸出反相。電源、RC、集射路徑與射極回路閉合，輸入控制由電源流向負載的能量。

共集仍由基極輸入，但輸出取射極，集極接 VCC 並在小訊號下視為接地。基極上升時射極也上升，直到 vbe 的變化只剩一小部分，因此輸出同相且電壓增益略小於一。射極電流可遠大於基極輸入電流，輸出端又由局部負回授維持低阻抗，所以它能隔離高阻抗訊號源與低阻抗負載；放大的是電流與驅動能力，不是電壓。

共基把基極固定在交流地，由射極輸入、集極輸出。射極電壓上升會減少 vbe，使集極電流下降，RC 壓降變小，集極電壓上升，因此輸出同相。射極端必須直接推動載子注入，輸入阻抗約 1/gm，很小；它適合電流型訊號與疊接。基極與集極之間沒有一個大反相增益，故高頻時米勒效應較弱。

射極退化電阻（emitter degeneration）讓共射電流增加時，射極電壓也升高，抵銷一部分 vbe 增量。這條局部負回授同時降低增益、提高輸入阻抗並改善線性與偏壓穩定；它不是免費修正，也不能只說其中一項好處而忽略其他端口一起改變。

來源：07-電子學-下 §9.1–§9.3。

推導：共同尺度都是 gm 乘輸出電阻

先忽略 ro、負載與偏壓網路，假設元件留在作用區、訊號足夠小、VCC 為交流地。共射且 RE = 0 時，ic = gmvbe，輸出 vout = −icRC = −gmvbeRC。因 vin = vbe，所以 Av = vout/vin = −gmRC。Av 無單位，負號只表示反相；Rin = rπ，Rout = RC。

加入 RE 後，射極小訊號電流 ie ≈ gmvbe，故 vin = vbe + ieRE ≈ vbe(1 + gmRE)。輸出仍為 −gmvbeRC，相除得 Av = −gmRC / (1 + gmRE)。若 gmRE ≫ 1，Av ≈ −RC/RE，增益由電阻比主導。輸入阻抗同時增為 rπ + (β + 1)RE。

共集的輸出 vout = ieRE，輸入 vin = vbe + vout。以 rπ = vbe/ib、ie = (β + 1)ib 代入，得到 Av = (β + 1)RE / [rπ + (β + 1)RE]，必小於一。Rin = rπ + (β + 1)RE；Rout = [rπ/(β + 1)]‖RE ≈ 1/gm。‖ 讀作「並聯」，不是絕對值也不是範數。

共基從射極看入的阻抗 Rin = rπ/(β + 1) ≈ 1/gm，集極輸出仍有電流變化乘 RC，但相位同向，所以 Av = +gmRC，Rout = RC。三者共同尺度都是跨導乘輸出端所見電阻；差別來自輸入是否完整落在 vbe、輸出取哪一端，以及局部回授如何重塑阻抗。

實際電路若保留 ro 與負載 RL，共射與共基的有效集極負載會是 RC‖ro‖RL，增益低於理想值。這也說明算出極大 Av 後還要檢查直流壓降、輸出擺幅與工作區，不能只讓公式回傳一個沒有電源餘裕的數字。

自由實驗：切換三大組態與射極退化

共射為 VCC → RC → 集極，射極經 RE 回地，基極輸入、集極輸出；共集由基極輸入、射極輸出；共基固定基極並由射極輸入、集極輸出。調整 Q 點與電阻，觀察增益、相位及兩端阻抗。

不要混淆

  • 共射 Av 的負號表示輸出反相，不表示品質較差；相位是多級串接與回授方向不可省略的資訊。
  • 射隨器電壓增益小於一不代表沒有放大作用；它提供電流增益、高輸入阻抗與低輸出阻抗，價值是驅動負載。
  • Rin 與 Rout 是指定 Q 點與頻率下的端口小訊號阻抗，不等於直流偏壓電阻，也不保證跨所有頻率固定。
  • 共基輸入阻抗小是適合電流驅動與疊接的特點；若訊號源是高阻抗電壓源，它才會成為嚴重負載。
  • 退化電阻降低的是局部電壓增益，同時提高線性與輸入阻抗；旁路電容若在工作頻率近似短路，交流退化效果會消失。

可觀察證據：同時量增益、相位與兩個端口

用訊號產生器串一顆已知 Rs 驅動輸入，示波器量 Rs 前後的電壓，可由分壓反推 Rin；再量輸入與輸出的振幅比及零交越方向，能證明 Av 大小與同相或反相。輸出端切換已知負載，觀察有負載與無負載振幅差，可由戴維寧分壓反推 Rout。更換 RE 後重測，能證明退化對增益的壓抑量。這些量測不能由單一 Av 分離 gm、RC、ro 與負載各自貢獻，也不能由 CE 電壓增益直接證明 β；必須配合直流工作點及多組端口量測。

連到哪門課

三大組態用在感測器前級、音訊、射頻與驅動緩衝。端口等效與負載效應可銜接電路學的戴維寧與最大功率，相依電流源的列式可回到疊加原理與相依源。第 12 章會說明共基與疊接為何能減少米勒效應，第 14 章再把退化推廣成負回授通式。
