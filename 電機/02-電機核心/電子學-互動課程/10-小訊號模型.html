10・把非線性元件編譯成 Q 點附近的線性模型

小訊號模型：先求工作點，再用局部斜率算增益

小訊號不是另一種電流，而是把總電壓與總電流拆成固定偏壓加微小變化。對非線性關係在 Q 點做一次泰勒展開，就能得到可用節點分析、疊加原理與相依源求解的線性等效電路。

這章假設已懂：06 BJT 原理與工作區、07 BJT 偏壓與 Q 點、08 MOSFET 原理與三區，以及導數與泰勒一次項。

痛點：電晶體明明非線性，放大器怎麼能直接算一個增益

「把 gm、rπ、ro 塞進等效電路就會算，但這些元件從哪裡冒出來？為什麼換了偏壓又要全部重算？」因為小訊號模型（small signal model）不是電晶體永久不變的替身，而是某個靜態工作點附近的切線。Q 點改變，切線斜率與等效阻抗就改變；訊號跨得太遠，曲率又會使線性近似失效。

用軟體語彙看，直流分析像先用非線性求解器得到狀態物件 Q；交流小訊號分析再對元件方程取雅可比矩陣，只保留一次項，建立一個只在 Q 附近有效的線性函式。省略第一步，就像在沒有初始化狀態時呼叫只接受局部座標的函式，數學可以跑，物理卻沒有對應工作區。

白話直覺：在彎曲道路的一小段用切線導航

可暫時把非線性曲線想成彎路，而小訊號模型是當前位置的切線；比喻到此為止，精確定義是把端口量寫成直流值加微小增量，並對元件方程作一階偏導。電源建立 Q 點，交流源只在其上擾動；分析小訊號時，理想直流電壓源視為交流接地。

以共射 BJT 為例，VCC 經 RC 到集極，射極接地，偏壓網路讓基極維持某個 VBE,Q。集射回路已由直流電源閉合，射極注入的載子穿過薄基極並被集極電場收集。小小的 vbe 改變注入量，形成 ic = gmvbe；RC 上壓降隨之改變，集極電壓朝相反方向變動。訊號能量主要仍由 VCC 提供，輸入只控制能量流。

MOSFET 則先由閘源偏壓形成反轉通道，汲源回路由電源與負載閉合。微小 vgs 改變通道電荷，使 id = gmvgs；閘極直流路徑仍開路，但高頻時必須對 Cgs 與 Cgd 充放電。輸出端有限斜率以 ro 表示，載子與能量的實際來源仍是偏壓電源。

端點結果可以分層看：直流值決定元件留在哪個工作區與可擺幅空間，小訊號值決定局部增益與阻抗，兩者相加才是儀器看到的總波形。若輸入太大，使瞬時工作點碰到截止或飽和邊界，線性相依源不再描述真實電流，輸出便削波或產生諧波失真。

來源：07-電子學-中 §8.1–§8.4、§6.4。

推導：一次泰勒項如何變成三個參數

一般非線性電流 I = F(V) 在 Q 點 VQ 附近可寫成 I(VQ + v) ≈ I(VQ) + [dI/dV]Qv。第一項是直流 IQ，第二項是小訊號 i；因此 i = gv，其中 g 是 Q 點局部斜率，單位 A/V。近似忽略二次以上項，要求擾動足夠小，而且元件不跨工作區。

BJT 作用區的 IC = IS ⋅ exp[VBE/VT]。對 VBE 微分，gm = ∂IC/∂VBE = IC/VT。VT = 25.851999786 mV，溫度固定 300 K。這表示 BJT 的跨導只由 Q 點集極電流決定；元件尺寸與製程會影響達到該電流所需偏壓，卻不出現在這個理想跨導式中。

因 ib = ic/β，而 ic = gmvbe，所以基極看進去的局部電阻 rπ = vbe/ib = β/gm。Early 效應使集極電流也隨 VCE 略變，等效輸出電阻 ro = VA/IC。混合 π 模型（hybrid pi model）因此是：基極到射極放 rπ，集極到射極放相依電流源 gmvbe，並聯 ro。‖ 讀作「並聯」，不是絕對值也不是範數。

MOSFET 在長通道飽和區有 ID = (1/2)kVOV²。對 VGS 微分得 gm = kVOV。由原式先解 VOV = √(2ID/k)，可得到另外兩個完全等價的寫法：gm = √(2kID) = 2ID/VOV。三式應算出同一數值，前提是忽略 λ 對跨導的修正並仍處於強反轉平方律區。

MOSFET 的 ro = 1/(λID)；若以 VA = 1/λ 表示，也可寫成 VA/ID。其小訊號電路在汲源間放 gmvgs 相依源並聯 ro，閘極直流輸入電阻視為無限大。高頻還須加入 BJT 的 Cπ、Cµ，或 MOSFET 的 Cgs、Cgd；第 12 章再處理米勒效應。

本徵增益（intrinsic gain）gmro 是單顆元件在理想高阻負載下可提供的局部增益尺度。BJT 為 (IC/VT)(VA/IC) = VA/VT，電流消去。MOSFET 為 2/(λVOV)；在固定 k 與等效 VA 下，提高 ID 會提高 VOV，反而降低本徵增益。

分析流程因此必須保留兩份帳。直流帳把訊號源設為零，求出每個端點的 Q 點並確認工作區；小訊號帳把直流電壓源設為交流地，以剛算出的參數替換電晶體，再解線性網路。最後把小訊號擺幅疊回 Q 點，檢查每個瞬時端點仍沒有跨入截止或飽和。這個回頭檢查相當於程式的事後條件，能抓出「線性方程算對，但假設已失效」的答案。

結果不是宣告 BJT 在所有場合都優勝。MOSFET 的閘極直流輸入阻抗極高、易於密集整合，且是 CMOS 數位電路核心；BJT 則在相同偏壓電流下提供較高跨導與常見的低雜訊優勢。元件選擇還要看輸入負載、電壓餘裕、頻率、匹配與製程。

自由實驗：同電流比較 BJT 與 MOSFET

兩種元件都先由偏壓電源建立指定靜態電流，輸出端經負載回到電源；BJT 以基射小電壓控制集極相依電流，MOSFET 以閘源小電壓控制汲極相依電流。切換主角並調參數，兩組結果仍會同時計算供比較。

不要混淆

  • 小訊號參數只屬於指定 Q 點；不先給 IC 或 ID，單問「這顆電晶體的 gm」沒有完整意義。
  • rπ 是基極的局部小訊號輸入電阻，不是直流比值 VBE/IB，兩者數值與用途都不同。
  • 相依源 gmvbe 或 gmvgs 在固定 Q 點模型內是線性元件，因此可用疊加；原始電晶體仍是非線性元件。
  • MOSFET 輸入電阻無限大只指理想直流；高頻時 Cgs 與 Cgd 使輸入阻抗有限且隨頻率下降。
  • 本徵增益是元件能力尺度，不等於接上有限負載、偏壓網路與源阻抗後的實際級增益。

可觀察證據：由受控小擾動反推局部參數

把放大器偏在固定 Q 點，用訊號產生器輸入 5 mV 小弦波，示波器量輸入與輸出振幅及相位；已知 RC 時，可由 Av = −gmRC 間接反推 gm，並與 IC/VT 比較。逐步把輸入增到 50 mV，若增益下降且頻譜分析儀看到諧波增加，就能證明小訊號近似開始失效。改變負載再看增益飽和，可估 ro。這些量測不能用單一增益值分離 gm、rπ 與所有負載效應，也不能直接看見等效相依源；必須改變源阻抗與負載做多組量測。

連到哪門課

小訊號模型是類比積體電路、射頻前端與感測器讀出電路的共同語言。一次線性化可銜接工程數學的級數與泰勒展開，等效相依源與疊加則銜接電路學的疊加原理與相依源。下一章把模型接上外部電阻，算三種單級放大器。
