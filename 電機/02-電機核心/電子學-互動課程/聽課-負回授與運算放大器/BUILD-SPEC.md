# 負回授與運算放大器：建置契約

五堂ef-feedback/ef-opamp/ef-bandwidth/ef-stability/ef-slew，各九段ef1/2/3/4/5-01..09、03/06/09停靠十五圖。正文4200–5000漢字/堂、MD同源，storageKey electronics-feedback-v1，空manifest、不自動朗讀。βf專指回授比例，不能混BJT β。低頻A為正的差動開迴路增益。

第一堂圖一ef-loop：x→誤差e=x−βf y→A→y，y回βf到負端，圖清楚能量由放大器電源供應、訊號箭頭非能流。圖二ef-algebra：y=A(x−βf y)→Af=A/(1+Aβf)，A1000、βf.1→Af1000/101≈9.900990，理想10。x=.1V則y≈.990099V，e≈.000990099V，不是誤差精確零；畫輸入、回授與差額條形對照，尺度不同要標。圖三ef-gain互動A range100..10000以log指數2..4 step.1 default3，βf.1固定，顯Af、目標10與相對誤差1/(1+Aβf)。快捷100/1000/10000；誤差9.0909%/.990099%/.0999001%。回授改善閉迴路增益對A的敏感度但消耗開迴路增益，不說消除一切噪聲失真。

第二堂圖四ef-noninverting：理想輸入無電流，非反相vin→+；輸出經Rf9k接−，−經Rg1k接參考；βf=.1，理想閉迴路10。有限A1000時精確9.900990，由y=A(v+−v−)推接近相等，『虛短』是線性穩態且穩定負回授與足夠A的近似，兩端未接導線；『虛斷』是理想輸入電流近零不等於端壓零。圖五ef-inverting：vin經Rin1k接−，Rf9k由輸出回−，+接參考；理想−9，節點KCL(vin−v−)/Rin+(vo−v−)/Rf=0。不能把非反相10套這裡。有限A1000，vo/vin=−A*Rf/(Rf+(A+1)*Rin)=−9000/1010≈−8.910891；回授因子1/10，雜訊增益10不是訊號增益9。圖六ef-rails互動：非反相理想閉迴路10，明示簡化輸出範圍±10V、供電±12V（不是所有真運放到此），vin range−1.5..1.5 step.1 default.5。vo=clip(10vin,−10,10)；v−=.1vo，線性時虛短成立，超幅時誤差剩下。圖只準靜態限幅模型不拿來預測恢復時間；快捷−1.5/.5/1.5，清楚顯飽和後不可繼續用虛短算輸出。

第三堂只問『精準增益與頻寬如何交換』。圖七ef-open-closed：單主極點A(s)=A0/(1+s/ωp)，A0=100000、fp10Hz，開迴路幅值與低頻點；另畫βf=.1閉迴路與直流Af0=A0/(1+A0βf)=9.9990001，不能把100000倍整段維持到1MHz。圖八ef-bandwidth：閉迴路fcl=fp(1+A0βf)=100010Hz，|Af|在此為低頻1/sqrt2；對數頻率圖明示低頻增益和−3dB相對差，unity約1MHz。圖九ef-feedback-ratio互動noisegain=1/βf range10..100 step10 default10，βf反算；顯Af0與fcl，調100時Af0≈99.9000999、fcl10010Hz。圖清楚低頻增益高時帶寬縮，GBW約固定是單主極點電壓回授近似；反相訊號增益9的上一堂仍用雜訊增益10估頻寬，不把所有運放都套乘積。必要公式推導逐步從y=A(s)(x−βy)來，不只公布結論。

第四堂只問『回授怎樣因相位延遲失去餘裕』。圖十ef-phase-loop：負端相減結構與回傳訊號，低頻回授抵消輸入誤差，額外相位接近180度時回傳可能同向；說明還需大小條件，不把任何延遲都稱不穩。圖十一ef-phase-fixed：雙極點例A0=100000、βf.1、fp1=10Hz、fp2=100000Hz，L=A0βf/[(1+jf/fp1)(1+jf/fp2)]；Bode幅相固定圖標|L|=1交越fu及相位，PM=180+phase。phase=−atan(fu/fp1)−atan(fu/fp2)，作者獨算fu/PM。圖十二ef-second-pole互動fp2=10000..1000000Hz（log4..6 step.1 default5），數值二分求交越fu，顯fu/PM與目前曲線；快捷10k/100k/1M。fp2降低額外相位增加、餘裕減少。這個簡單兩極模型在有限正參數時仍穩定，不宣稱低裕度即必發散；示意只談趨勢，不畫沒有時域模型的假真振鈴。相位裕度有開迴路穩定與交越結構等前提，完整奈奎斯特留控制課，不能以此判所有高階迴路。稿把−180與負端減法各自角色清楚分開。

第五堂只問『頻率還在帶寬內，為何大振幅已跟不上』。圖十三ef-slew-slope：輸出目標vo=Vpk sin(2πft)，微分最大斜率2πfVpk，Vpk2V/f10kHz時需求.125664V/μs；畫正弦零交越最大斜率、波峰斜率0，說電壓高不等於變得最快。簡化SR=.5V/μs，物理直覺用內部可用充電電流限制補償電容dv/dt，不指定未存在器件。圖十四ef-slew-frequency互動f1..100kHz step1k default10k，Vpk2固定，顯需求與SR條形，f=100k需求1.256637V/μs，允許fmax≈39788.736Hz；只畫目標正弦與斜率，不假裝算出真失真波形。圖十五ef-slew-amplitude互動Vpk .1..4V step.1 default2、f50k固定，Vpk,max=SR/(2πf)≈1.591549V，Vpk1V需求.314159、2V需求.628319V/μs；顯『小振幅可跟、大振幅超斜率』。單極小訊號帶寬100010Hz不保證2V/50kHz大訊號不失真；SR上限與±10V靜態擺幅是不同限制，使用同一張三條件檢查卡重建例子。不要稱剛好等於限制就零失真保證，實物還需資料/量測；不教授未建模的恢復時間或所有補償設計。
