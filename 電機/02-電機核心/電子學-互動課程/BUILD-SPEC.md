## 3. 公式轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。不要用 Unicode 下標數字（₀₁₂），避免不同字型高度不一。
- Unicode 數學符號（限這份清單）：`∫ Σ Π √ ∂ ∞ ± × ⋅ · ≈ ≠ ≤ ≥ ≪ ≫ ∝ → ⇒ ⇔ ∈ ∠ ° ′ ″ | ‖`
- 希臘字母：`α β γ δ ε ζ η θ λ π ρ σ τ φ χ ψ ω Δ Σ Φ Ω`（**µ 一律用 U+00B5，不用希臘 μ**）
- **負號一律用 U+2212 `−`，不要用半形連字號 `-`**（連字號只用在檔名、CSS class、HTML 屬性值如 `min="-100"`）。
- 上標數字可直接用 `²` `³`；其餘次方用 `<sup>`。
- **`‖` 在本課專指「並聯」**（`r<sub>o1</sub>‖r<sub>o2</sub>`），首次出現要在文中說明「‖ 讀作『並聯』，不是絕對值也不是範數」。
- 單位一律半形英文緊接數字後空一格：`0.7 V`、`20 mA`、`1 kΩ`、`470 µF`、`100 µH`、`1 pF`、`20 fF`、`500 µA/V²`、`38.681727 mA/V`、`85.729517 dB`。**微法拉／微安培用 `µ`（U+00B5 micro sign），不要用希臘字母 μ（U+03BC）**，全檔統一。**唯一例外**：物理量符號 µ<sub>n</sub>、µ<sub>p</sub>（遷移率）也用 U+00B5，保持全檔只有一種微符號。
- 歐姆符號用 `Ω`（U+03A9 希臘大寫 Omega），不要用 U+2126。
- **溫度只出現「300 K」一種寫法**，不得寫「室溫」以外的其他數值。

### 3.2 排版規則

1. **分數**：單行寫成 `(分子) / (分母)`，例如 `(V<sub>CC</sub> − V<sub>BE</sub>) / (R<sub>TH</sub> + (β + 1)R<sub>E</sub>)`。分子分母都是單一符號時可省括號：`β/g<sub>m</sub>`、`V<sub>A</sub>/I<sub>C</sub>`。
2. **多行分式**只在必要時用 `<pre>`，以 `─` 畫橫線，前後留一空行。
3. **導數**寫成 `dn/dx`、`dv/dt`；二階寫 `d²v/dt²`。不要用點記號。偏導用 `∂I<sub>D</sub>/∂V<sub>GS</sub>`。
4. **指數中還有下標時，把下標壓平**：`e<sup>V<sub>D</sub>/(nV<sub>T</sub>)</sup>` 寫成 `e<sup>V_D/(nV_T)</sup>` 是**錯的**；正確寫法是 `exp[V<sub>D</sub> / (nV<sub>T</sub>)]`——**指數含下標時一律改用 `exp[…]` 函式形式**，只有純量指數才用 `<sup>`（例 `10<sup>16</sup>`、`e<sup>−t/τ</sup>`）。
5. **絕對值**用半形直線 `|A<sub>v</sub>|`；在 Markdown 表格內要寫成 `\|A<sub>v</sub>\|`，但在 HTML 產品檔內寫 `|A<sub>v</sub>|`。
6. **矩陣／向量**本課用不到，不得出現。
7. **函式名**（exp、ln、log、sin、cos、tanh、sqrt、max、min、Re、Im）用一般半形英文，不加標記。
8. 公式所在段落用 `<p>`；需要凸顯時可用 `<code>`（`styles.css` 已設 `overflow-wrap:anywhere`）。
9. **元件端點拓樸**用文字＋端點清單，格式固定：`V<sub>CC</sub> → R<sub>C</sub> → 集極 C；射極 E → R<sub>E</sub> → 地；基極 B ← R<sub>1</sub>／R<sub>2</sub> 分壓點`。
10. **區域名稱一律用中文＋英文括號**：`截止區（cutoff）`、`作用區（active）`、`飽和區（saturation）`、`三極區／線性區（triode / linear）`。

### 00 `00-電子學世界觀.html`

**目標**：講清楚電子學與電路學的分界——元件不再線性了——並把全課的方法骨幹「先找工作點、再小訊號線性化」在第一章就交代完。

**要點**：線性元件（linear element）的定義是「電壓與電流成正比，疊加原理成立」；電阻是線性的，二極體與電晶體不是；非線性元件的 I–V 關係是曲線，**同一顆元件在不同偏壓下「等效電阻」完全不同**；工作點（operating point / quiescent point, Q 點）＝直流電源決定的那一個 (V, I) 座標；小訊號（small-signal）＝疊加在 Q 點上的微小變化量，小到可以把曲線用該點的**切線**取代；小訊號電導 g = dI/dV 在 Q 點的值，倒數叫小訊號電阻 r<sub>d</sub> = 1/g；三層結構：元件物理 → 等效電路模型 → 用模型組出整流器、放大器、振盪器、邏輯閘。來源：07-電子學-上「這科在學什麼」。

**推導必寫**：（a）以指數元件 I = I<sub>S</sub>{exp[V / V<sub>T</sub>] − 1} 為例，對 V 微分得 g = dI/dV = (I + I<sub>S</sub>) / V<sub>T</sub> ≈ I / V<sub>T</sub>——**小訊號電導正比於工作點電流**，這是整門電子學最常用的一條式子（第 10 章會看到它就是 g<sub>m</sub>）。（b）泰勒展開：I(V + Δ) = I(V) + gΔ + (1/2)(dg/dV)Δ² + …，只留一次項的條件是 Δ ≪ V<sub>T</sub>；二次項與一次項的比值是 Δ/(2V<sub>T</sub>)，所以 Δ = 5 mV 時誤差量級約 5/(2 × 25.852) ≈ 9.7 %——這是上界粗估，**實際誤差 1.645808 % 比它小，因為高階項互相抵銷了一部分**。（c）線性元件的對照：電阻 I = V/R，dI/dV = 1/R 與工作點無關，所以「電阻沒有工作點問題」。這一句就是電路學能把元件當黑箱的全部理由。

**數值實例**：二極體 I<sub>S</sub> = 1 × 10<sup>−15</sup> A、n = 1、V<sub>T</sub> = 25.851999786 mV；偏壓 V = 700 mV；疊加小訊號振幅 ΔV = 5 mV；對照用線性電阻 R = 100 Ω。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 二極體工作點電流 | I<sub>S</sub>{exp[0.7 / V<sub>T</sub>] − 1} | **0.574755 mA** |
| 二極體加 5 mV 後 | I<sub>S</sub>{exp[0.705 / V<sub>T</sub>] − 1} | **0.697395 mA（+21.337852 %）** |
| 小訊號電導 g | (I + I<sub>S</sub>) / V<sub>T</sub> | **22.232499 mA/V** |
| 小訊號電阻 r<sub>d</sub> | 1 / g | **44.979198 Ω** |
| 線性模型預測 | I + gΔV | **0.685917 mA（比真值低 1.645808 %）** |
| 電阻工作點電流 | 0.7 / 100 | **7.000000 mA** |
| 電阻加 5 mV 後 | 0.705 / 100 | **7.050000 mA（+0.714286 %）** |
| 電阻電導 | 1 / 100 | **10.000000 mA/V（與偏壓無關）** |

一句話結論：**同樣加 5 mV，電阻電流只多 0.714286 %，二極體電流多 21.337852 %**。電阻的電導在任何偏壓下都是 10 mA/V，二極體的電導在 700 mV 是 22.232499 mA/V、換個偏壓就換一個值。

### 01 `01-半導體與載子.html`

**目標**：解釋一塊矽為什麼可以「用摻雜調整導電性」，並把載子濃度、導電率、電阻率算成可驗證的數字。

**要點**：能帶（band）＝固體中電子容許的能量區間；價帶（valence band）是最高被填滿的、導帶（conduction band）是最低未填滿的，中間隔著能隙（band gap, E<sub>g</sub>）；導體能隙為零或重疊、絕緣體 E<sub>g</sub> > 3 eV、半導體介於中間（Si 1.12 eV、Ge 0.66 eV、GaAs 1.42 eV）；本徵半導體（intrinsic）＝純矽，熱激發讓電子跳進導帶並在價帶留下電洞（hole），n = p = n<sub>i</sub>，300 K 時 n<sub>i</sub>(Si) ≈ 1.5 × 10<sup>10</sup> cm<sup>−3</sup>；摻雜（doping）：摻 V 族（P、As）得 n 型、多數載子是電子；摻 III 族（B、Ga）得 p 型、多數載子是電洞；質量作用定律（mass-action law）np = n<sub>i</sub>² 在熱平衡下恆成立；漂移電流（drift）J = σE、σ = q(nµ<sub>n</sub> + pµ<sub>p</sub>)；擴散電流（diffusion）J<sub>n</sub> = qD<sub>n</sub> ⋅ dn/dx，由濃度梯度驅動；製程一窺：晶圓 → 氧化 → 微影 → 蝕刻 → 離子佈植摻雜 → 沉積 → 金屬連線，製程節點（7 nm、3 nm）與摩爾定律。來源：07-電子學-上 §1.1–§1.4、第 4 章。

**推導必寫**：（a）質量作用定律怎麼用：n 型摻 N<sub>D</sub>，電中性給 n ≈ N<sub>D</sub>（因為 N<sub>D</sub> ≫ n<sub>i</sub>），再由 np = n<sub>i</sub>² 得少數載子 p = n<sub>i</sub>² / N<sub>D</sub>。**注意這不是「電洞消失了」，是它們的濃度被壓到極低**。（b）導電率 σ = q(nµ<sub>n</sub> + pµ<sub>p</sub>) 的來歷：每種載子的漂移速度 v = µE，電流密度 J = qnv，兩種載子相加就得到 σ。單位檢查：C × cm<sup>−3</sup> × cm²/(V⋅s) = C/(V⋅s⋅cm) = S/cm。（c）為什麼摻雜這麼有效：本徵矽 σ = q ⋅ n<sub>i</sub>(µ<sub>n</sub> + µ<sub>p</sub>) = 4.397975 × 10<sup>−6</sup> S/cm，摻到 10<sup>16</sup> cm<sup>−3</sup> 後 σ = 2.162938456 S/cm——**每 500 萬個矽原子換一個雜質，導電率就漲了 49 萬倍**。（d）擴散與漂移的分工：漂移要外加電場，擴散只要濃度不均；PN 接面的全部行為就是這兩者的拉鋸（下一章）。

### 02 `02-PN接面與二極體方程.html`

**目標**：解釋 PN 接面為什麼單向導通，並把蕭克萊方程的每個符號講到能算數字。

**要點**：把 n 型與 p 型接在一起，電子往 p 側擴散、電洞往 n 側擴散，留下不可動的施體／受體離子 → 空乏區（depletion region）；離子形成內建電場，方向恰好阻止繼續擴散 → 平衡；內建電位（built-in potential）V<sub>0</sub> = V<sub>T</sub> ⋅ ln(N<sub>A</sub>N<sub>D</sub> / n<sub>i</sub>²)，矽典型值約 0.7 V；順向偏壓（forward bias）V<sub>D</sub> > 0（p 接正）→ 外電場抵消部分內建電場 → 空乏區變窄 → 擴散電流大幅增加；反向偏壓（reverse bias）→ 空乏區變寬 → 只剩極小的反向飽和電流 I<sub>S</sub>（由少數載子撐起）；反向電壓太大會崩潰（breakdown）：齊納崩潰（穿隧，低壓、負溫度係數）或雪崩崩潰（碰撞游離，高壓、正溫度係數）；理想二極體方程（蕭克萊方程）I<sub>D</sub> = I<sub>S</sub>{exp[V<sub>D</sub> / (nV<sub>T</sub>)] − 1}，V<sub>T</sub> = kT/q，理想因子 n 介於 1–2。來源：07-電子學-上 §2.1–§2.4。

**推導必寫**：（a）V<sub>0</sub> 的來歷：平衡時擴散電流與漂移電流恰好抵銷，把淨電流為 0 的條件積分過空乏區得 V<sub>0</sub> = V<sub>T</sub> ln(N<sub>A</sub>N<sub>D</sub> / n<sub>i</sub>²)。**注意 V<sub>0</sub> 只跟兩側摻雜濃度與溫度有關，跟接面面積無關。**（b）「每 60 mV 電流變 10 倍」的來歷：exp[ΔV / V<sub>T</sub>] = 10 ⇒ ΔV = V<sub>T</sub> ⋅ ln10 = 25.851999786 × 2.302585093 = **59.526429 mV**。這是實驗室裡判斷「這條 I–V 是不是指數」的手指規則。（c）為什麼順偏時可以把 −1 丟掉：V<sub>D</sub> = 0.7 V 時 exp[0.7 / V<sub>T</sub>] ≈ 5.75 × 10<sup>11</sup>，減 1 完全不影響 6 位有效數字。（d）為什麼反偏電流是常數：V<sub>D</sub> 夠負時 exp 項趨近 0，I<sub>D</sub> → −I<sub>S</sub>——**反向電流不隨反向電壓變大，因為它受限於少數載子的供應速率，不是受限於電場**。（e）V<sub>0</sub> 不能用電表量：把表棒接上去會在兩個金屬—半導體接面各產生一個抵銷的接觸電位差，總和為零（否則就能永動）。

**數值實例**：Si、300 K、n<sub>i</sub> = 1.5 × 10<sup>10</sup> cm<sup>−3</sup>、N<sub>A</sub> = 10<sup>17</sup> cm<sup>−3</sup>、N<sub>D</sub> = 10<sup>16</sup> cm<sup>−3</sup>、I<sub>S</sub> = 1 × 10<sup>−14</sup> A、n = 1、V<sub>D</sub> = 700 mV。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 內建電位 | V<sub>T</sub> ⋅ ln(10<sup>17</sup> × 10<sup>16</sup> / (1.5 × 10<sup>10</sup>)²) | **0.752879 V** |
| 順偏電流 | I<sub>S</sub>{exp[0.7 / V<sub>T</sub>] − 1} | **5.747546 mA** |
| 電流變 10 倍所需電壓 | V<sub>T</sub> ⋅ ln10 | **59.526429 mV** |
| 0 V 時 | I<sub>S</sub>(1 − 1) | **0.000000 mA（不是 I<sub>S</sub>）** |
| 反偏 −0.5 V | I<sub>S</sub>{exp[−0.5 / V<sub>T</sub>] − 1} | **−1.000000 × 10<sup>−14</sup> A ＝ −0.010000 pA** |
| 反偏 −1.0 V | 同上 | **−1.000000 × 10<sup>−14</sup> A（與 −0.5 V 完全相同）** |

### 03 `03-二極體工作點與模型.html`

**目標**：示範「非線性元件怎麼解電路」——負載線與三種模型——並量化每種模型的誤差，讓讀者知道什麼時候可以偷懶。

**要點**：負載線（load line）＝把外部線性電路的 KVL 寫成 I = (V<sub>s</sub> − V<sub>D</sub>) / R，它在 I–V 平面上是一條直線；工作點＝負載線與元件 I–V 曲線的交點；五種二極體模型：理想開關（順偏短路、反偏斷路）用於大致估算；恆壓降 V<sub>D</sub> = 0.7 V 用於手算；分段線性（0.7 V 串一個順向電阻 r<sub>f</sub>）用於含大電流的估算；完整指數用於精準分析；小訊號 r<sub>d</sub> = nV<sub>T</sub> / I<sub>D</sub> 用於動態行為；解完整指數要用迭代——牛頓法，或「先用 0.7 V 猜 I，再由 I 反推 V<sub>D</sub> = V<sub>T</sub> ln(I/I<sub>S</sub>)，回代直到收斂」。來源：07-電子學-上 §2.5。

**推導必寫**：（a）負載線就是 KVL：V<sub>s</sub> = I ⋅ R + V<sub>D</sub>，兩個未知數一條方程，另一條方程是元件本身的 I–V。**這是「元件方程 ＋ 電路方程」聯立，跟電路學解電阻電路是同一件事，只是元件方程變成非線性的。**（b）牛頓法：定義 f(V<sub>D</sub>) = I<sub>S</sub>{exp[V<sub>D</sub> / V<sub>T</sub>] − 1} − (V<sub>s</sub> − V<sub>D</sub>) / R，f′(V<sub>D</sub>) = I<sub>S</sub> ⋅ exp[V<sub>D</sub> / V<sub>T</sub>] / V<sub>T</sub> + 1/R，反覆做 V<sub>D</sub> ← V<sub>D</sub> − f/f′，從 0.7 V 起步 20 次以內就收斂到 12 位有效數字。（c）為什麼恆壓降模型這麼好用：二極體在 1–20 mA 這個常用範圍內，電壓只從約 0.65 變到約 0.72 V（每 10 倍電流才多 59.526429 mV），所以「當成 0.7 V」的誤差很小。（d）小訊號電阻 r<sub>d</sub> = V<sub>T</sub> / I<sub>D</sub> 與工作點反比：4.307456 mA 時 r<sub>d</sub> = 6.001686 Ω，0.042675 mA 時 r<sub>d</sub> = 605.787718 Ω——**同一顆二極體，動態電阻差了 100 倍**。

**數值實例**（**二極體主電路**）：V<sub>s</sub> = 5 V、R = 1 kΩ、I<sub>S</sub> = 1 × 10<sup>−14</sup> A、n = 1、V<sub>T</sub> = 25.851999786 mV。拓樸：`V_s 正端 → R → 節點 A；節點 A → 二極體陽極；二極體陰極 → 地；V_s 負端 → 地`。

| 理想開關 | 順偏 V<sub>D</sub> = 0 | **5.000000 mA** | 0.000000 V | **+16.077786 %** |
| 恆壓降 | V<sub>D</sub> = 0.7 V | **4.300000 mA** | 0.700000 V | **−0.173104 %** |

### 04 `04-整流與濾波.html`

**目標**：把「二極體單向導通」變成一台能用的直流電源，並把漣波算成數字，讓讀者知道電容要選多大。

**要點**：整流器（rectifier）把交流變直流；半波整流只取單邊，一個週期只導通一半；全波橋式整流（bridge）用四顆二極體把負半週翻正，一個週期導通兩次，**等效漣波頻率是輸入頻率的兩倍**；橋式的電流路徑上永遠串著**兩顆**二極體，所以壓降是 2 × 0.7 = 1.4 V，半波只有一顆、0.7 V；濾波電容（filter capacitor）在二極體導通時被充到峰值，在不導通時對負載放電，於是輸出在峰值與 (峰值 − ΔV) 之間鋸齒狀擺動，這個擺動叫漣波（ripple）；漣波近似 ΔV ≈ V<sub>pk</sub> / (f<sub>eff</sub>RC)，來源筆記寫成「漣波正比於 1/(RC)」；直流準位 V<sub>dc</sub> ≈ V<sub>pk</sub> − ΔV/2；再接穩壓器或齊納二極體就得到穩定 DC 電源（下一章）。來源：07-電子學-上 §3.1。

**推導必寫**：（a）ΔV 公式怎麼來：電容在不導通的期間對負載放電，近似為定電流 I ≈ V<sub>pk</sub>/R 放電時間 T<sub>eff</sub> = 1/f<sub>eff</sub>，由 ΔQ = IΔt 與 ΔQ = CΔV 得 ΔV = I/(f<sub>eff</sub>C) = V<sub>pk</sub>/(f<sub>eff</sub>RC)。**這條式子的前提是 RC ≫ 1/f<sub>eff</sub>**，也就是「幾乎沒放掉」；不成立時它會給出比 V<sub>pk</sub> 還大的荒謬答案。（b）為什麼全波比半波好兩次：f<sub>eff</sub> 變兩倍，同一個 C 的漣波直接砍半；代價是多兩顆二極體、多 0.7 V 壓降。（c）把 RC 放電接回電路學：這就是 `../電路學-互動課程/07-一階暫態RC與RL.html` 的指數放電，只是我們只取它最前面幾乎是直線的那一小段，所以能用線性近似。（d）二極體只在「輸入電壓高於電容電壓 + 壓降」的短暫時間導通，所以充電電流是又高又窄的脈衝——**這是整流器對電網造成諧波汙染、以及變壓器要選比平均電流大很多的原因**。

**數值實例**：全波橋式、輸入弦波峰值 V<sub>m</sub> = 12 V、f = 60 Hz、R<sub>L</sub> = 1 kΩ、C = 470 µF。

| 二極體總壓降 | 2 × 0.7（橋式串兩顆） | **1.400000 V** |
| 輸出峰值 | 12 − 1.4 | **10.600000 V** |
| 有效漣波頻率 | 2 × 60 | **120.000000 Hz** |
| 漣波電壓 | 10.6 / (120 × 1000 × 470 × 10<sup>−6</sup>) | **0.187943 V** |

### 05 `05-穩壓限幅與特殊二極體.html`

**目標**：把二極體的其他三種用法（穩壓、限幅／箝位、特殊材料）講完，並用齊納穩壓器示範「什麼叫脫出穩壓區」。

**要點**：齊納二極體（Zener diode）故意工作在反向崩潰區，崩潰電壓 V<sub>Z</sub> 相當穩定，可當電壓參考；基本齊納穩壓器拓樸：`V_in → R_s → 節點 OUT；節點 OUT → 齊納陰極、陽極接地；節點 OUT → R_L → 地`；電流關係 I<sub>s</sub> = I<sub>Z</sub> + I<sub>L</sub>；穩壓成立的條件是 I<sub>Z</sub> 必須大於最小維持電流（本課取 I<sub>Zmin</sub> = 5 mA），且 P<sub>Z</sub> = V<sub>Z</sub>I<sub>Z</sub> 不得超過封裝額定；限幅器（clipper）用二極體把超過某電壓的部分切掉，保護輸入端；箝位器（clamper）用電容 + 二極體把訊號的直流準位整段平移；倍壓器（voltage multiplier）用電容與二極體疊加，輸出可達輸入振幅的 2、3、4 倍；特殊二極體：LED（順偏發光，能隙決定波長）、光二極體（photodiode，光生載子，光纖接收端）、變容二極體（varactor，反偏改變空乏區寬度 → 可變電容，VCO 用）、蕭特基（Schottky，金屬—半導體接面，壓降低、切換快）；二極體—電阻邏輯是最早的 AND／OR 閘。來源：07-電子學-上 §3.2–§3.5。

**推導必寫**：（a）齊納穩壓器的解法：**先假設齊納導通**，此時 V<sub>out</sub> = V<sub>Z</sub>，於是 I<sub>L</sub> = V<sub>Z</sub>/R<sub>L</sub>、I<sub>s</sub> = (V<sub>in</sub> − V<sub>Z</sub>)/R<sub>s</sub>、I<sub>Z</sub> = I<sub>s</sub> − I<sub>L</sub>；**再檢查 I<sub>Z</sub> > 0**，若不成立就代表齊納根本沒崩潰，電路退化成純分壓 V<sub>out</sub> = V<sub>in</sub> ⋅ R<sub>L</sub>/(R<sub>s</sub> + R<sub>L</sub>)。這個「先假設、再驗證、不成立就換假設」的流程是電子學解非線性電路的通用手法，第 06、08 章判斷工作區用的是同一招。（b）為什麼齊納能穩壓：崩潰區的 I–V 幾乎垂直，電流變很多、電壓幾乎不變；等效上它是一個電壓源串一個很小的動態電阻 r<sub>z</sub>（本課理想化為 0）。（c）齊納的兩種崩潰機制：V<sub>Z</sub> < 5 V 主要是齊納穿隧（負溫度係數），V<sub>Z</sub> > 6 V 主要是雪崩（正溫度係數），**5–6 V 附近兩者抵銷，溫度係數最小**——這就是精密參考常用 5.6 V 與 6.2 V 的原因。（d）LED 的波長：光子能量 ≈ E<sub>g</sub>，波長 λ = hc/E<sub>g</sub>；能隙愈大波長愈短（愈藍），所以藍光 LED 需要 GaN 這種寬能隙材料。

**數值實例**：V<sub>in</sub> = 15 V、R<sub>s</sub> = 470 Ω、V<sub>Z</sub> = 5.1 V、R<sub>L</sub> = 1 kΩ、I<sub>Zmin</sub> = 5 mA。

### 06 `06-BJT原理與工作區.html`

**目標**：把 BJT 從「三隻腳的黑盒子」講成「兩個 PN 接面 ＋ 一個很薄的基極」，並用工作區判斷把 I<sub>C</sub> = βI<sub>B</sub> 的適用範圍講清楚。

**要點**：雙極性接面電晶體（Bipolar Junction Transistor, BJT）是三層半導體：NPN 或 PNP；三個端子：集極（Collector, C）、基極（Base, B，薄且輕摻雜）、射極（Emitter, E，重摻雜）；關鍵物理：兩個 PN 接面，**因為基極很薄，從射極注入的載子大部分來不及在基極複合就衝到集極**，只有一小部分變成基極電流——這就是電流放大的來源；四個工作區（以 NPN 為例）：截止（cutoff，兩接面都反偏，I<sub>C</sub> ≈ 0）、作用區（active，BE 順偏、BC 反偏，I<sub>C</sub> = βI<sub>B</sub>，放大用）、飽和（saturation，兩接面都順偏，V<sub>CE</sub> ≈ 0.2 V，當開關用）、反向作用（少用）；主要方程 I<sub>C</sub> = I<sub>S</sub> ⋅ exp[V<sub>BE</sub> / V<sub>T</sub>]、I<sub>C</sub> = βI<sub>B</sub>、I<sub>E</sub> = I<sub>C</sub> + I<sub>B</sub> = (β + 1)I<sub>B</sub>、α = β/(β + 1) ≈ 1；β 常見 50–500；Ebers–Moll 模型用兩個 PN 接面方程完整描述四區；Early 效應：作用區的 I<sub>C</sub> 對 V<sub>CE</sub> 有微弱依賴 I<sub>C</sub> = I<sub>S</sub> ⋅ exp[V<sub>BE</sub>/V<sub>T</sub>] ⋅ (1 + V<sub>CE</sub>/V<sub>A</sub>)，Early 電壓 V<sub>A</sub> 約 50–100 V，對應有限輸出阻抗 r<sub>o</sub> = V<sub>A</sub>/I<sub>C</sub>。來源：07-電子學-中 §5.1–§5.5。

**推導必寫**：（a）α 與 β 的關係：I<sub>E</sub> = I<sub>C</sub> + I<sub>B</sub>，定義 α = I<sub>C</sub>/I<sub>E</sub>、β = I<sub>C</sub>/I<sub>B</sub>，代入得 α = β/(β + 1)。β = 100 時 α = **0.990099**——**99.0099 % 的射極電流衝到了集極，只有 0.9901 % 變成基極電流**。（b）飽和的判準怎麼算：假設在作用區，I<sub>C</sub> = βI<sub>B</sub>，V<sub>CE</sub> = V<sub>CC</sub> − I<sub>C</sub>R<sub>C</sub>；若算出來的 V<sub>CE</sub> < 0.2 V 就代表假設錯了，實際上 BC 接面已經順偏、進入飽和，此時 V<sub>CE</sub> 被鎖在 0.2 V，I<sub>C</sub> = (V<sub>CC</sub> − 0.2)/R<sub>C</sub>，而且 **I<sub>C</sub> < βI<sub>B</sub>**（β 在飽和區不再成立）。（c）飽和的臨界基極電流：I<sub>B,sat</sub> = (V<sub>CC</sub> − 0.2)/(βR<sub>C</sub>)。（d）Early 效應與 r<sub>o</sub>：對 I<sub>C</sub> = I<sub>C0</sub>(1 + V<sub>CE</sub>/V<sub>A</sub>) 微分得 ∂I<sub>C</sub>/∂V<sub>CE</sub> = I<sub>C0</sub>/V<sub>A</sub>，倒數即 r<sub>o</sub> = V<sub>A</sub>/I<sub>C</sub>。**r<sub>o</sub> 是「電流源不夠理想」的量化**，第 10、11、13 章會一直用它。

**數值實例**：NPN、I<sub>B</sub> = 20 µA、β = 100、V<sub>CC</sub> = 12 V、R<sub>C</sub> = 1 kΩ、V<sub>A</sub> = 100 V。拓樸：`V_CC → R_C → 集極 C；射極 E → 地；基極 B 由定電流源 I_B 驅動`。

### 07 `07-BJT偏壓與Q點.html`

**目標**：示範一個能用的偏壓電路——分壓 ＋ 射極退化——並用數字證明它對 β 變化不敏感。

**要點**：靜態工作點（quiescent point, Q 點）＝沒有訊號時的 (I<sub>C</sub>, V<sub>CE</sub>)；好的 Q 點要滿足三件事：V<sub>BE</sub> 適當順偏（矽約 0.7 V）、V<sub>CE</sub> 遠離飽和（留給訊號擺動的空間）、**Q 點對 β 變化不敏感**；最常見的偏壓拓樸是分壓 ＋ 射極電阻（emitter degeneration）：`V_CC → R_1 → 基極節點 B；基極節點 B → R_2 → 地；V_CC → R_C → 集極 C；射極 E → R_E → 地`；分析法：把 R<sub>1</sub>、R<sub>2</sub> 與 V<sub>CC</sub> 做戴維寧化，得 V<sub>TH</sub> = V<sub>CC</sub>R<sub>2</sub>/(R<sub>1</sub> + R<sub>2</sub>)、R<sub>TH</sub> = R<sub>1</sub>‖R<sub>2</sub>；再對基極回路寫 KVL：V<sub>TH</sub> = I<sub>B</sub>R<sub>TH</sub> + V<sub>BE</sub> + I<sub>E</sub>R<sub>E</sub> = I<sub>B</sub>R<sub>TH</sub> + V<sub>BE</sub> + (β + 1)I<sub>B</sub>R<sub>E</sub>；射極電阻提供**直流負回授**：I<sub>C</sub> 想變大 → I<sub>E</sub>R<sub>E</sub> 變大 → V<sub>BE</sub> 被壓小 → I<sub>C</sub> 被拉回來。來源：07-電子學-中 §5.6。

**推導必寫**：（a）基極 KVL 解 I<sub>B</sub>：I<sub>B</sub> = (V<sub>TH</sub> − V<sub>BE</sub>) / [R<sub>TH</sub> + (β + 1)R<sub>E</sub>]。（b）**穩定性的關鍵在分母**：若 (β + 1)R<sub>E</sub> ≫ R<sub>TH</sub>，則 I<sub>C</sub> = βI<sub>B</sub> ≈ β(V<sub>TH</sub> − V<sub>BE</sub>)/[(β + 1)R<sub>E</sub>] ≈ (V<sub>TH</sub> − V<sub>BE</sub>)/R<sub>E</sub>——**β 從分子分母同時消失**，Q 點只由外部電阻決定。設計準則常寫成 (β + 1)R<sub>E</sub> / R<sub>TH</sub> ≥ 10。（c）為什麼固定基極偏壓（只用一顆 R<sub>B</sub> 從 V<sub>CC</sub> 拉到基極）是壞設計：I<sub>B</sub> = (V<sub>CC</sub> − V<sub>BE</sub>)/R<sub>B</sub> 與 β 無關，於是 I<sub>C</sub> = βI<sub>B</sub> **正比於 β**，β 加倍 I<sub>C</sub> 就加倍。（d）交流上要不要旁路 R<sub>E</sub>：直流要它穩定 Q 點，交流上它會把增益壓掉（第 11 章），所以實務上常在 R<sub>E</sub> 並一顆大電容——**直流看到 R<sub>E</sub>、交流看不到**，這是「同一顆元件在直流與交流有不同角色」的第一個例子。

**數值實例**：V<sub>CC</sub> = 12 V、R<sub>1</sub> = 47 kΩ、R<sub>2</sub> = 10 kΩ、R<sub>E</sub> = 1 kΩ、R<sub>C</sub> = 2.2 kΩ、β = 100、V<sub>BE</sub> = 0.7 V。

### 08 `08-MOSFET原理與三個工作區.html`

**目標**：講清楚閘極為什麼「不用電流也能控制電流」，並把三個工作區的判準與平方律算成數字。

**要點**：金氧半場效電晶體（Metal-Oxide-Semiconductor Field-Effect Transistor, MOSFET）以 NMOS 為例的結構：p 型基板、兩個 n+ 摻雜區當源極（Source, S）與汲極（Drain, D）、上方一層極薄氧化層（SiO₂）、氧化層上是閘極（Gate, G）；PMOS 把所有摻雜型別反過來；工作原理：V<sub>GS</sub> = 0 時 S 與 D 之間是背對背的反偏 PN 接面，不通；V<sub>GS</sub> > V<sub>th</sub>（門檻電壓）時閘極電場在氧化層下感應出反轉層（inversion layer，n 型通道），S 與 D 連通；**閘極與通道之間隔著絕緣層，所以閘極直流電流為零**——這是 MOSFET 輸入阻抗極高的原因；超驅動電壓（overdrive voltage）V<sub>OV</sub> = V<sub>GS</sub> − V<sub>th</sub>；三個工作區：截止（V<sub>GS</sub> < V<sub>th</sub>，I<sub>D</sub> ≈ 0）、三極／線性區（V<sub>DS</sub> < V<sub>OV</sub>，I<sub>D</sub> = k[V<sub>OV</sub>V<sub>DS</sub> − (1/2)V<sub>DS</sub>²]，當開關用）、飽和區（V<sub>DS</sub> ≥ V<sub>OV</sub>，I<sub>D</sub> = (1/2)kV<sub>OV</sub>²(1 + λV<sub>DS</sub>)，放大用）；k = µ<sub>n</sub>C<sub>ox</sub>(W/L)，單位 A/V²；λ 是通道長度調變（類似 BJT 的 Early 效應），r<sub>o</sub> = 1/(λI<sub>D</sub>)；體效應（body effect）V<sub>th</sub> = V<sub>th0</sub> + γ[√(V<sub>SB</sub> + 2φ<sub>F</sub>) − √(2φ<sub>F</sub>)]；短通道效應：通道長度調變變嚴重、漏電流增加、速度飽和，工業界改用 FinFET 與 GAA 三維結構。來源：07-電子學-中 §6.1–§6.3、§6.5–§6.7。

**推導必寫**：（a）三極區公式的來歷（定性即可，不要積分細節）：通道電荷密度正比於 (V<sub>GS</sub> − V<sub>th</sub> − V(x))，沿通道積分後得到 I<sub>D</sub> = k[V<sub>OV</sub>V<sub>DS</sub> − (1/2)V<sub>DS</sub>²]。**注意 V<sub>DS</sub> 很小時二次項可忽略，I<sub>D</sub> ≈ kV<sub>OV</sub>V<sub>DS</sub>，這時 MOSFET 就是一顆阻值由 V<sub>GS</sub> 控制的電阻**——這正是 CMOS 開關與類比開關的原理。（b）夾止（pinch-off）與飽和：把三極區公式對 V<sub>DS</sub> 微分並令為 0，得極值在 V<sub>DS</sub> = V<sub>OV</sub>；此後汲極端的通道被夾斷，電流不再隨 V<sub>DS</sub> 增加，把 V<sub>DS</sub> = V<sub>OV</sub> 代回去就得 I<sub>D</sub> = (1/2)kV<sub>OV</sub>²。**兩條公式在邊界上連續，這是檢查自己有沒有寫錯的第一招。**（c）跨導：g<sub>m</sub> = ∂I<sub>D</sub>/∂V<sub>GS</sub> = kV<sub>OV</sub>(1 + λV<sub>DS</sub>) = 2I<sub>D</sub>/V<sub>OV</sub> = √(2kI<sub>D</sub>)（λ = 0 時三式等價）。**g<sub>m</sub> 正比於 √I<sub>D</sub>，不像 BJT 的正比於 I<sub>C</sub>——這是第 10 章那張對照表最重要的一行。**（d）本徵增益 g<sub>m</sub>r<sub>o</sub>：把 g<sub>m</sub> = 2I<sub>D</sub>/V<sub>OV</sub> 與 r<sub>o</sub> = 1/(λI<sub>D</sub>) 相乘得 g<sub>m</sub>r<sub>o</sub> = 2/(λV<sub>OV</sub>)——**與電流無關，只由 λ 與 V<sub>OV</sub> 決定**。預設值代入：2/(0.02 × 1) = 100.000000。

**數值實例**：NMOS、V<sub>GS</sub> = 2 V、V<sub>th</sub> = 1 V、k = 500 µA/V²、λ = 0.02 V<sup>−1</sup>、V<sub>DS</sub> = 5 V。

| 正確性判準 | ① 截止區 → 「截止區：V<sub>GS</sub> 還沒到門檻，閘極電場不足以在氧化層下感應出反轉層，源汲之間仍是背對背的反偏 PN 接面。真實元件仍有次臨界漏電流，本互動不模擬。」② 三極區 → 「三極（線性）區：通道從源到汲都存在，V<sub>DS</sub> 小的時候 MOSFET 就是一顆阻值由 V<sub>GS</sub> 控制的電阻（目前 r<sub>DS</sub> = X Ω）。CMOS 開關與類比開關就用這一區。」③ 飽和區 → 「飽和區：汲極端的通道被夾斷，電流由 V<sub>GS</sub> 決定、幾乎不隨 V<sub>DS</sub> 變——這就是放大器要的定電流行為。**注意：MOSFET 的飽和區是放大區，跟 BJT 的飽和區（開關全開）意思相反。**」④ 每次都要附因果句：「I<sub>D</sub> 正比於 V<sub>OV</sub> 的平方，所以 V<sub>GS</sub> 多給一點，電流就多很多；但 g<sub>m</sub> 只正比於 √I<sub>D</sub>，所以靠加電流換增益的效率比 BJT 差。」⑤ `mo-lambda = 0` → r<sub>o</sub> 顯示「無限大（理想定電流源）」，**不得輸出 `Infinity` 或 `NaN`**，並寫一句「λ = 0 是教科書理想，真實元件永遠有通道長度調變」。⑥ 在 `vds` 恰等於 `VOV` 時要寫出「這裡是兩區的交界，兩條公式在此連續（差別只來自 λ 項）」。 |
| 邊界情形 | `mo-vds = 0` → 三極區且 I<sub>D</sub> = 0，`rds` 分母為 0，**必須顯示「V<sub>DS</sub> = 0：沒有電場推動載子，電流為零；此時 r<sub>DS</sub> 的極限值是 1/(kV<sub>OV</sub>)」而不是 `NaN`**；`mo-vgs = 0` → 截止；`mo-vgs = 5`、`mo-vth = 0.3`、`mo-k = 2000`、`mo-vds = 10` → I<sub>D</sub> 很大，要說「這個電流密度在真實元件會遇到速度飽和，平方律高估了電流——這正是短通道效應」。 |

**不要混淆（至少四條）**：**MOSFET 的「飽和區」是放大用的定電流區，BJT 的「飽和區」是開關全開、V<sub>CE</sub> ≈ 0.2 V 的區——兩者意思相反**，本課只要看到「飽和」就必須先確認是哪一種元件；閘極直流電流為零不代表閘極不用電流——高頻切換時要對閘極電容充放電，電流可以很大（第 09 章的動態功耗）；V<sub>th</sub> 不是固定值，體效應與製程漂移都會改變它；k = µ<sub>n</sub>C<sub>ox</sub>(W/L) 混合了製程（µ<sub>n</sub>C<sub>ox</sub>）與設計（W/L）兩件事，設計者能改的只有 W/L。

**可觀察證據**：曲線追蹤儀掃 I<sub>D</sub>–V<sub>DS</sub> 曲線族（每條對應一個 V<sub>GS</sub>），三極區是往上彎的曲線、飽和區是幾乎水平的平台，轉折點的軌跡就是 V<sub>DS</sub> = V<sub>OV</sub> 這條拋物線；把飽和區的曲線往左延伸交會處的橫軸座標是 −1/λ。用低壓小訊號量 r<sub>DS</sub> 可以驗證「V<sub>GS</sub> 控制電阻」。**能證明**：V<sub>th</sub>（由 √I<sub>D</sub> 對 V<sub>GS</sub> 作圖外插）、k、λ、三個工作區的邊界。**不能證明**：µ<sub>n</sub> 與 C<sub>ox</sub> 分別是多少（只能量到乘積）、通道的實際 W/L（要看版圖）、氧化層厚度。

### 09 `09-CMOS反相器與數位功耗.html`

**目標**：用 CMOS 反相器示範「互補」這個想法，並把數位 IC 的功耗算成可以驗證的數字。

**要點**：CMOS 反相器＝一顆 NMOS 與一顆 PMOS 共閘極、共汲極串接；拓樸：`V_DD → PMOS 源極；PMOS 汲極 → 輸出節點 OUT；OUT → NMOS 汲極；NMOS 源極 → 地；輸入 IN 同時接兩個閘極`；輸入 0 → NMOS 截止、PMOS 導通 → 輸出 = V<sub>DD</sub>；輸入 1 → NMOS 導通、PMOS 截止 → 輸出 = 0；**任何穩定狀態下只有一顆導通，所以靜態功耗極低**（只剩次臨界漏電與閘極穿隧漏電）；只有切換的瞬間兩顆同時導通，產生短路直通電流（short-circuit current），加上對負載電容充放電，才是功耗來源；切換閾值（switching threshold）V<sub>M</sub>＝輸入等於輸出的那一點，對稱設計時 V<sub>M</sub> = V<sub>DD</sub>/2；每次完整的充放電循環（0→1→0）耗能 C<sub>L</sub>V<sub>DD</sub>²，其中一半存進電容一半在充電時燒掉、另一半在放電時燒掉；動態功耗 P = C<sub>L</sub>V<sub>DD</sub>²f；雜訊邊限：輸入低於 V<sub>th,n</sub> 時 NMOS 保證截止，高於 V<sub>DD</sub> − |V<sub>th,p</sub>| 時 PMOS 保證截止。來源：07-電子學-中 第 7 章。

**推導必寫**：（a）V<sub>M</sub> 的公式：在 V<sub>M</sub> 時兩顆都在飽和區且電流相等，(1/2)k<sub>n</sub>(V<sub>M</sub> − V<sub>th,n</sub>)² = (1/2)k<sub>p</sub>(V<sub>DD</sub> − V<sub>M</sub> − |V<sub>th,p</sub>|)²，開根號整理得 V<sub>M</sub> = [V<sub>th,n</sub> + √k<sub>r</sub>(V<sub>DD</sub> − |V<sub>th,p</sub>|)] / (1 + √k<sub>r</sub>)，其中 k<sub>r</sub> = k<sub>p</sub>/k<sub>n</sub>。**k<sub>r</sub> = 1 且 V<sub>th,n</sub> = |V<sub>th,p</sub>| 時 V<sub>M</sub> = V<sub>DD</sub>/2**，這就是「PMOS 要做得比 NMOS 寬」的理由——電洞遷移率只有電子的約三分之一（回頭看第 01 章的 480/1350），要把 k<sub>p</sub> 拉到與 k<sub>n</sub> 相等就得加大 W。（b）每次切換的能量：把 C<sub>L</sub> 從 0 充到 V<sub>DD</sub>，電源送出 Q V<sub>DD</sub> = C<sub>L</sub>V<sub>DD</sub>²，電容只存了 (1/2)C<sub>L</sub>V<sub>DD</sub>²，**另外一半必然在 PMOS 的通道電阻上變成熱，與電阻值無關**；放電時電容裡那一半又在 NMOS 上燒掉。所以一個完整循環正好燒掉 C<sub>L</sub>V<sub>DD</sub>²。（c）P = C<sub>L</sub>V<sub>DD</sub>²f 的平方關係：**降壓是省電最有效的手段**——V<sub>DD</sub> 從 3.3 V 降到 1.0 V，功耗降到 (1.0/3.3)² = 0.091827 倍，也就是省了 90.8173 %。代價是速度變慢（V<sub>OV</sub> 變小，充放電電流變小）。

**數值實例**：V<sub>DD</sub> = 3.3 V、V<sub>th,n</sub> = |V<sub>th,p</sub>| = 0.7 V、k<sub>r</sub> = k<sub>p</sub>/k<sub>n</sub> = 1、C<sub>L</sub> = 20 fF、f = 100 MHz、V<sub>in</sub> = 1.65 V。

### 10 `10-小訊號模型.html`

**目標**：把「工作點附近的線性化」從第 00 章的口號變成可以直接拿去算增益的等效電路，並用同一個電流比較 BJT 與 MOSFET。

**要點**：小訊號模型（small-signal model）＝把非線性元件在 Q 點做泰勒展開只留一次項，得到的線性等效電路；適用條件：訊號振幅遠小於 V<sub>T</sub>（BJT）或 V<sub>OV</sub>（MOSFET）；BJT 混合 π 模型（hybrid-π）：g<sub>m</sub> = I<sub>C</sub>/V<sub>T</sub>、r<sub>π</sub> = β/g<sub>m</sub>、r<sub>o</sub> = V<sub>A</sub>/I<sub>C</sub>；等效電路是「基極到射極之間一顆 r<sub>π</sub>，集極到射極之間一顆相依電流源 g<sub>m</sub>v<sub>be</sub> 並聯 r<sub>o</sub>」；MOSFET 小訊號模型：g<sub>m</sub> = √(2kI<sub>D</sub>) = 2I<sub>D</sub>/V<sub>OV</sub>、r<sub>o</sub> = 1/(λI<sub>D</sub>)，閘極輸入電阻無限大（直流），汲—源之間是 g<sub>m</sub>v<sub>gs</sub> 並聯 r<sub>o</sub>；本徵增益（intrinsic gain）g<sub>m</sub>r<sub>o</sub>＝單顆元件能給的最大電壓增益；高頻模型要加 C<sub>π</sub>、C<sub>µ</sub>（BJT）或 C<sub>gs</sub>、C<sub>gd</sub>（MOSFET），米勒效應留給第 12 章；BJT 與 MOSFET 對照：控制變數、輸入阻抗、跨導對電流的依賴、數位用途、雜訊。來源：07-電子學-中 §8.1–§8.4、§6.4。

**推導必寫**：（a）g<sub>m</sub> = I<sub>C</sub>/V<sub>T</sub> 就是第 00 章那條 g = I/V<sub>T</sub>：對 I<sub>C</sub> = I<sub>S</sub> ⋅ exp[V<sub>BE</sub>/V<sub>T</sub>] 微分即得。**BJT 的跨導只由電流決定，跟元件尺寸、製程完全無關**——這是 BJT 最漂亮的性質。（b）r<sub>π</sub> 的來歷：i<sub>b</sub> = i<sub>c</sub>/β，而 i<sub>c</sub> = g<sub>m</sub>v<sub>be</sub>，所以 v<sub>be</sub>/i<sub>b</sub> = β/g<sub>m</sub>。（c）MOSFET 的 g<sub>m</sub> 三種寫法怎麼互換：由 I<sub>D</sub> = (1/2)kV<sub>OV</sub>² 得 V<sub>OV</sub> = √(2I<sub>D</sub>/k)，代進 g<sub>m</sub> = kV<sub>OV</sub> 得 √(2kI<sub>D</sub>)，也等於 2I<sub>D</sub>/V<sub>OV</sub>。**三式必須同時列出並驗證數值相同**，因為不同教科書用不同寫法。（d）本徵增益的比較：BJT 的 g<sub>m</sub>r<sub>o</sub> = (I<sub>C</sub>/V<sub>T</sub>)(V<sub>A</sub>/I<sub>C</sub>) = **V<sub>A</sub>/V<sub>T</sub>，與電流完全無關**；MOSFET 的 g<sub>m</sub>r<sub>o</sub> = 2/(λV<sub>OV</sub>)，也與電流無關但由 V<sub>OV</sub> 決定。用同一個 V<sub>A</sub> = 100 V：BJT 得 100/0.025852 = **3868.172707**，MOSFET（V<sub>OV</sub> = 2 V、等效 1/λ = 100 V）得 **100.000000**——**差 38.68 倍**。這就是為什麼精密類比放大器仍然愛用 BJT。

**數值實例**：靜態電流 I = 1 mA、β = 100、V<sub>A</sub> = 100 V（MOSFET 用同一個值當 1/λ）、k = 500 µA/V²、V<sub>T</sub> = 25.851999786 mV。

### 11 `11-單級放大器三大組態.html`

**目標**：把小訊號模型接上外部電阻，算出三種組態的增益與阻抗，並說清楚各自該用在哪裡。

**要點**：三種接法由「訊號從哪進、從哪出、哪一端接地」決定；BJT：共射（Common-Emitter, CE，基極進、集極出）電壓增益大且反相、輸入阻抗中等、輸出阻抗中等，通用放大與第一級；共集（Common-Collector, CC，射隨器 emitter follower，基極進、射極出）電壓增益約 1 同相、電流增益大、輸入阻抗大、輸出阻抗小，做緩衝與阻抗匹配；共基（Common-Base, CB，射極進、集極出）電壓增益大且同相、輸入阻抗小、輸出阻抗大，做高頻與低米勒效應；MOSFET 一一對應：共源（CS）↔ CE、共汲（CD，源隨器）↔ CC、共閘（CG）↔ CB；射極退化電阻 R<sub>E</sub> 把 CE 的增益從 −g<sub>m</sub>R<sub>C</sub> 壓成 −g<sub>m</sub>R<sub>C</sub>/(1 + g<sub>m</sub>R<sub>E</sub>)，當 g<sub>m</sub>R<sub>E</sub> ≫ 1 時趨近 −R<sub>C</sub>/R<sub>E</sub>——**增益變成只由兩顆電阻的比值決定，不再依賴 g<sub>m</sub>**，代價是增益變小；這是負回授的第一次登場（第 14 章會給通式）。來源：07-電子學-下 §9.1–§9.3。

**推導必寫**：（a）CE 無退化：v<sub>out</sub> = −g<sub>m</sub>v<sub>be</sub>R<sub>C</sub>、v<sub>in</sub> = v<sub>be</sub>，所以 A<sub>v</sub> = −g<sub>m</sub>R<sub>C</sub>；負號代表反相。R<sub>in</sub> = r<sub>π</sub>、R<sub>out</sub> = R<sub>C</sub>（忽略 r<sub>o</sub>）。（b）CE 加退化：v<sub>in</sub> = v<sub>be</sub> + i<sub>e</sub>R<sub>E</sub> ≈ v<sub>be</sub>(1 + g<sub>m</sub>R<sub>E</sub>)，所以 A<sub>v</sub> = −g<sub>m</sub>R<sub>C</sub>/(1 + g<sub>m</sub>R<sub>E</sub>)；R<sub>in</sub> = r<sub>π</sub> + (β + 1)R<sub>E</sub>——**退化電阻同時提高輸入阻抗、降低增益、改善線性度，三件事一起發生，不能只挑一件**。（c）CC：v<sub>out</sub> = i<sub>e</sub>R<sub>E</sub>、v<sub>in</sub> = v<sub>be</sub> + v<sub>out</sub>，得 A<sub>v</sub> = (β + 1)R<sub>E</sub>/[r<sub>π</sub> + (β + 1)R<sub>E</sub>] < 1；R<sub>out</sub> = [r<sub>π</sub>/(β + 1)]‖R<sub>E</sub> ≈ 1/g<sub>m</sub>——**極小的輸出阻抗就是它當緩衝的全部理由**。（d）CB：從射極看進去 R<sub>in</sub> = r<sub>π</sub>/(β + 1) ≈ 1/g<sub>m</sub>，非常小；A<sub>v</sub> = +g<sub>m</sub>R<sub>C</sub>，與 CE 同樣大但不反相。（e）三者的共同點：**電壓增益的量級都是 g<sub>m</sub> 乘上輸出端看到的電阻**，差別在輸入端怎麼接、以及電流增益是誰。

**不要混淆（至少四條）**：CE 的負號是**反相**不是「增益是負的所以比較差」，反相在多級串接與回授裡是有用的資訊；射隨器「增益約 1」不代表沒用——它的價值在電流增益與低輸出阻抗，把高阻抗訊號源接到低阻抗負載；R<sub>in</sub> 與 R<sub>out</sub> 是**小訊號**阻抗，不是直流偏壓電阻；共基的輸入阻抗小是特點不是缺點——用電流驅動（例如接在另一級的集極上）時，小輸入阻抗正好把電流原封不動接過來，這就是第 12 章疊接的關鍵。

**可觀察證據**：訊號產生器串一顆已知電阻 R<sub>s</sub> 進放大器輸入，量 R<sub>s</sub> 兩端與輸入端的電壓，就能由分壓反推 R<sub>in</sub>；輸出端接一顆可切換的負載電阻，比較有無負載時的輸出振幅，由分壓反推 R<sub>out</sub>；示波器同時看輸入與輸出可以直接看出反相與否。**能證明**：A<sub>v</sub>、相位關係（同相／反相）、R<sub>in</sub>、R<sub>out</sub>、退化電阻對增益的實際壓抑量。**不能證明**：g<sub>m</sub> 與 R<sub>C</sub> 各自的貢獻（只量到乘積）；也不能證明 β 的值（CE 的電壓增益根本不含 β）。

### 12 `12-米勒效應與頻寬.html`

**目標**：解釋放大器的頻寬是被誰吃掉的，並用數字證明疊接為什麼有效。

**要點**：跨接在輸入與輸出之間的電容（BJT 的 C<sub>µ</sub>、MOSFET 的 C<sub>gd</sub>）在反相放大時會被「放大」——因為它兩端的電壓變化是 v<sub>in</sub> 與 −|A<sub>v</sub>|v<sub>in</sub>，總擺幅是 (1 + |A<sub>v</sub>|)v<sub>in</sub>，於是從輸入端看進去等效電容變成 (1 + |A<sub>v</sub>|)C<sub>gd</sub>，這叫米勒效應（Miller effect）；輸入端的總等效電容 C<sub>in</sub> = C<sub>gs</sub> + (1 + |A<sub>v</sub>|)C<sub>gd</sub>，與訊號源阻抗 R<sub>s</sub> 形成一階低通，高頻 −3 dB 點 f<sub>H</sub> = 1/(2πR<sub>s</sub>C<sub>in</sub>)；共基／共閘沒有這個問題（輸入在射極／源極，跨接電容的另一端接地），但輸入阻抗太小；疊接（Cascode）＝CE ＋ CB（或 CS ＋ CG）疊起來：下面那顆的負載變成上面那顆的低輸入阻抗（約 1/g<sub>m</sub>），所以**下面那顆的電壓增益只剩約 −1，米勒效應幾乎消失**；總增益仍由上面那顆的集極負載決定，於是高增益與寬頻寬兼得，是高頻電路的標準招式；增益—頻寬乘積（Gain-Bandwidth Product, GBW）在單純的共射級裡近似不變，疊接則能突破這個限制。來源：07-電子學-下 §9.4。

**推導必寫**：（a）米勒等效的推導：跨接電容流過的電流 i = (v<sub>in</sub> − v<sub>out</sub>)/Z<sub>C</sub> = v<sub>in</sub>(1 + |A<sub>v</sub>|)/Z<sub>C</sub>，從輸入端看等效導納放大了 (1 + |A<sub>v</sub>|) 倍，也就是等效電容放大同樣倍數。**注意：這個推導假設 A<sub>v</sub> 在關心的頻段內是常數，所以它是低頻近似，不能拿來算很靠近 f<sub>H</sub> 的行為。**（b）f<sub>H</sub> 就是電路學的一階 RC 低通：τ = R<sub>s</sub>C<sub>in</sub>、f<sub>H</sub> = 1/(2πτ)，過了它每十倍頻掉 20 dB、相位 −45°——完全是 `../電路學-互動課程/12-一階濾波器與頻率響應.html` 那一章。（c）疊接的等效電容：下級的增益變成 −g<sub>m1</sub>/g<sub>m2</sub> ≈ −1（兩顆偏在同一電流），所以 C<sub>in</sub> = C<sub>gs</sub> + (1 + 1)C<sub>gd</sub> = C<sub>gs</sub> + 2C<sub>gd</sub>。（d）為什麼「增益愈大頻寬愈窄」：|A<sub>v</sub>| 進了 C<sub>in</sub>，而 f<sub>H</sub> 與 C<sub>in</sub> 成反比，所以在 C<sub>gd</sub> 主導時 |A<sub>v</sub>| × f<sub>H</sub> 趨近一個常數 1/(2πR<sub>s</sub>C<sub>gd</sub>)——這就是 GBW 近似不變的來歷。

**數值實例**：|A<sub>v</sub>| = 200、R<sub>s</sub> = 2 kΩ、C<sub>gd</sub> = 1 pF、C<sub>gs</sub> = 5 pF。

### 13 `13-差動對與電流鏡.html`

**目標**：解釋為什麼所有類比 IC 的第一級都是差動對，並把共模拒斥比算成可以驗證的 dB。

**要點**：差動對（differential pair）＝兩顆對稱的電晶體共射（或共源）接到同一個尾電流源；差模輸入 v<sub>id</sub> = v<sub>1</sub> − v<sub>2</sub> 會讓尾電流在兩邊重新分配；共模輸入（兩端一起動）理想上不改變任何電流，因為尾電流源鎖住總電流；差模增益 A<sub>d</sub>、共模增益 A<sub>cm</sub>、共模拒斥比（Common-Mode Rejection Ratio, CMRR）= |A<sub>d</sub>/A<sub>cm</sub>|，愈大愈好；**單端輸出時 CMRR = 2g<sub>m</sub>R<sub>oc</sub>，只由跨導與尾電流源的輸出阻抗決定，跟負載電阻無關**；電流鏡（current mirror）＝用配對的電晶體「複製」電流，I<sub>out</sub> ≈ I<sub>ref</sub>，兩個用途：提供穩定偏壓電流、當主動負載（active load）——用電流源代替電阻當集極／汲極負載，得到極高的 r<sub>o</sub> 並聯阻抗，於是單級增益暴增；多級串接時總增益是各級相乘（dB 相加），前級求高輸入阻抗與低雜訊、中段求增益、末級求低輸出阻抗。來源：07-電子學-下 §10.1–§10.3。

**推導必寫**：（a）差模半電路：對稱電路在差模訊號下，中間那一點（尾節點）是虛地，於是每一邊都退化成一個 R<sub>E</sub> = 0 的共射級，A<sub>d</sub>（單端輸出）= g<sub>m</sub>R<sub>L,eff</sub>，其中 g<sub>m</sub> 用**每一邊的**電流 I<sub>tail</sub>/2 去算。（b）共模半電路：共模訊號下兩邊同步變化，尾電流源的輸出阻抗 R<sub>oc</sub> 被兩邊平分，等效上每一邊都是一個帶 2R<sub>oc</sub> 退化電阻的共射級，A<sub>cm</sub> = −R<sub>L,eff</sub>/(2R<sub>oc</sub>)（用第 11 章的退化公式在 g<sub>m</sub> ⋅ 2R<sub>oc</sub> ≫ 1 時的極限）。（c）**CMRR = |A<sub>d</sub>/A<sub>cm</sub>| = g<sub>m</sub>R<sub>L,eff</sub> / [R<sub>L,eff</sub>/(2R<sub>oc</sub>)] = 2g<sub>m</sub>R<sub>oc</sub>——R<sub>L,eff</sub> 完全約掉了**。這是本章最重要的一條：**想提高 CMRR 只能改善尾電流源，換負載沒用**。（d）差動對的真實轉移特性是 ΔI = I<sub>tail</sub> ⋅ tanh[v<sub>id</sub>/(2V<sub>T</sub>)]，線性化只在 |v<sub>id</sub>| ≪ 2V<sub>T</sub> = 51.704000 mV 時成立；|v<sub>id</sub>| > 4V<sub>T</sub> = 103.407999 mV 時電流幾乎全部倒向一邊。

**數值實例**：I<sub>tail</sub> = 1 mA、R<sub>C</sub> = 10 kΩ、尾電流源輸出阻抗 R<sub>oc</sub> = 500 kΩ、V<sub>A</sub> = 100 V、v<sub>id</sub> = 10 mV、V<sub>T</sub> = 25.851999786 mV。每一邊的集極電流 = 0.5 mA。

### 14 `14-回授與穩定性.html`

**目標**：把第 07 章的射極退化與第 11 章的「增益換穩定」推廣成一條通式，並說明它為什麼會換來振盪風險。

**要點**：負回授（negative feedback）＝取一部分輸出回送到輸入做相減；閉迴路增益 A<sub>f</sub> = A/(1 + Aβ<sub>f</sub>)，A 是開迴路增益、β<sub>f</sub> 是回授比例（**注意：β<sub>f</sub> 不是 BJT 的 β**）；Aβ<sub>f</sub> 叫迴路增益（loop gain），若 Aβ<sub>f</sub> ≫ 1 則 A<sub>f</sub> ≈ 1/β<sub>f</sub>——**幾乎只取決於被動元件**；四大好處：增益精準穩定（不依賴 β、g<sub>m</sub>）、失真降低 (1 + Aβ<sub>f</sub>) 倍、輸入／輸出阻抗依拓樸調整、頻寬延伸 (1 + Aβ<sub>f</sub>) 倍且 GBW 不變；四種拓樸（取樣什麼、比較什麼）：串—並（電壓—電壓，R<sub>in</sub>↑ R<sub>out</sub>↓）、並—並（電壓—電流，R<sub>in</sub>↓ R<sub>out</sub>↓）、串—串（電流—電壓，R<sub>in</sub>↑ R<sub>out</sub>↑）、並—串（電流—電流，R<sub>in</sub>↓ R<sub>out</sub>↑）；代價：增益降低、可能振盪；穩定性判準：在 |L(jω)| = 1（0 dB）那一點，相位距離 −180° 要有足夠相位裕度（Phase Margin），典型設計目標 45°–60°；若在某頻率同時滿足 |L| = 1 與 arg L = 0°（巴克豪森準則 Barkhausen criterion），系統會自我維持振盪——**振盪器就是故意違反穩定條件的回授系統**。來源：07-電子學-下 §11.1–§11.3、§13.1。

**推導必寫**：（a）A<sub>f</sub> 的推導：x<sub>e</sub> = x<sub>in</sub> − β<sub>f</sub>x<sub>out</sub>、x<sub>out</sub> = Ax<sub>e</sub>，消去 x<sub>e</sub> 得 A<sub>f</sub> = A/(1 + Aβ<sub>f</sub>)。（b）靈敏度：對 A 微分得 dA<sub>f</sub>/A<sub>f</sub> = [1/(1 + Aβ<sub>f</sub>)] ⋅ dA/A——**開迴路增益變 50 %，閉迴路只變 50 %/(1 + Aβ<sub>f</sub>)**。（c）頻寬延伸：把 A(s) = A<sub>0</sub>/(1 + s/ω<sub>1</sub>) 代入通式，分母整理後極點變成 ω<sub>1</sub>(1 + A<sub>0</sub>β<sub>f</sub>)，而增益降為 A<sub>0</sub>/(1 + A<sub>0</sub>β<sub>f</sub>)，**兩者相乘完全不變**——這就是 GBW 守恆。（d）失真：非線性產生的誤差在迴路內被 (1 + Aβ<sub>f</sub>) 除掉。（e）為什麼會振盪：多極點系統在高頻會累積相位，當相位轉到 −180° 時 −β<sub>f</sub> 的負回授變成正回授，若此時 |Aβ<sub>f</sub>| 仍 ≥ 1，分母 1 + Aβ<sub>f</sub> 會趨近 0，增益發散。**射極退化不會振盪是因為它是單極點、相位最多轉 −90°。**

**數值實例**：A = 100 dB（A = 10<sup>5</sup>）、β<sub>f</sub> = 0.01、開迴路主極點 f<sub>1</sub> = 10 Hz、開迴路失真 5 %。

### 15 `15-運算放大器與電子系統.html`

**目標**：把前 15 章的積木組成真實系統——運算放大器、振盪器、電源、資料轉換——並各給一條可以算的量化判準。

**要點**：典型兩級運算放大器（operational amplifier, op-amp）的內部：輸入級是差動對 ＋ 電流鏡主動負載（大差模增益、高 CMRR）、第二級是高增益共源級 ＋ 米勒補償電容、輸出級是推挽射隨器（低輸出阻抗），外加電流鏡偏壓與補償網路；真實 op-amp 的非理想項：有限開迴路增益、固定的增益—頻寬乘積（GBW）、輸入偏壓電流、輸入失調電壓與失調電流、CMRR/PSRR、轉換速率（slew rate, SR，輸出最大變化速率）、雜訊；比較器把類比變數位，施密特觸發器（Schmitt trigger）用**正回授**製造遲滯（hysteresis），消除雜訊造成的抖動；主動濾波器用 op-amp + R + C 做出不需電感的濾波器，常見 Sallen–Key 與多回授（MFB）拓樸；振盪的巴克豪森準則：|L(jω<sub>0</sub>)| = 1 且 arg L(jω<sub>0</sub>) = 0°；振盪器五型：RC（Wien 橋、相移，低頻音頻）、LC（Colpitts、Hartley、Clapp，射頻）、晶體（石英高 Q，極高頻率穩定度）、VCO（頻率可由電壓調，PLL 核心）、多諧振盪器（方波，如 555）；電源管理：線性穩壓器 LDO（簡單、低雜訊，但效率 = V<sub>out</sub>/V<sub>in</sub>）、切換式（Buck 降壓、Boost 升壓、Buck–Boost/Flyback，效率可達 90 %+，但有切換雜訊）、PWM 用佔空比控制平均功率；資料轉換：DAC（R-2R 階梯、電流舵、Sigma-Delta）、ADC（Flash 最快但需 2<sup>N</sup> − 1 個比較器、SAR 最廣用、Pipeline 高速高解析、Sigma-Delta 超高解析低速、整合型精度高但慢），設計要點是取樣率、解析度（ENOB）、雜訊、量化誤差、SFDR。來源：07-電子學-下 第 12、13、14、15 章。

**推導必寫**：（a）LC 振盪頻率：迴路相位在 LC 諧振頻率轉為 0°，f<sub>0</sub> = 1/(2π√(LC))，與 `../電路學-互動課程/13-RLC共振與品質因數.html` 完全同一條式子；晶體之所以穩定是因為它的等效 Q 高達 10<sup>4</sup>–10<sup>6</sup>，共振點極銳利。（b）LDO 的效率：輸出功率 V<sub>out</sub>I<sub>out</sub>、輸入功率 V<sub>in</sub>I<sub>out</sub>（**串聯元件的電流進出相同**），所以 η = V<sub>out</sub>/V<sub>in</sub>，多出來的 (V<sub>in</sub> − V<sub>out</sub>)I<sub>out</sub> 全部變成熱。（c）Buck 的佔空比：理想 Buck 的輸出是輸入乘以佔空比，D = V<sub>out</sub>/V<sub>in</sub>；效率高是因為開關要嘛全通（壓降小）要嘛全斷（電流零），兩種狀態都幾乎不耗功——**這正是第 08 章 MOSFET 三極區與截止區的用法**。（d）量化 SNR：N 位元 ADC 的量化階 LSB = V<sub>ref</sub>/2<sup>N</sup>，量化誤差在 ±LSB/2 均勻分布、rms 為 LSB/√12，滿刻度弦波的 rms 是 (2<sup>N</sup>LSB/2)/√2，兩者相除取 20log<sub>10</sub> 得 **SNR = 6.02N + 1.76 dB**。（e）取樣定理：可重建的最高訊號頻率是 f<sub>s</sub>/2。

**數值實例**：三種模式各一組。

**振盪器**：L = 100 µH、C = 100 pF → f<sub>0</sub> = 1/(2π√(100 × 10<sup>−6</sup> × 100 × 10<sup>−12</sup>)) = **1591549.430919 Hz ＝ 1.591549 MHz**。
對照：L = 1 µH、C = 10 pF → **50329212.104487 Hz ＝ 50.329212 MHz**（射頻）；L = 1000 µH、C = 10000 pF → **50329.212104 Hz ＝ 50.329212 kHz**（音頻上緣）。

**電源**（V<sub>in</sub> = 12 V、V<sub>out</sub> = 3.3 V、I<sub>out</sub> 固定 0.5 A、Buck 實測效率取 90 %）：

| 量 | LDO | Buck |
| --- | --- | --- |
| 輸出功率 | **1.650000 W** | **1.650000 W** |
| 效率 | V<sub>out</sub>/V<sub>in</sub> = **27.500000 %** | **90.000000 %** |
| 輸入功率 | 12 × 0.5 = **6.000000 W** | 1.65/0.9 = **1.833333 W** |
| 損耗（發熱） | **4.350000 W** | **0.183333 W** |
| 輸入平均電流 | **0.500000 A** | **0.152778 A** |
| 佔空比 | 不適用 | D = 3.3/12 = **0.275000** |

**LDO 白白燒掉 4.35 W，是輸出功率的 2.64 倍；Buck 只燒 0.183333 W。壓差愈大，LDO 愈不能用。** 對照：V<sub>in</sub> = 5 V 時 LDO 效率升到 **66.000000 %**、損耗降到 **0.850000 W**——**LDO 只在小壓差時合理**。

**資料轉換**（V<sub>ref</sub> = 3.3 V、N = 12 位元、f<sub>s</sub> = 1000 kHz）：

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 量化階數 | 2<sup>12</sup> | **4096** |
| 量化階 LSB | 3.3 / 4096 | **805.664062 µV** |
| 理論 SNR | 6.02 × 12 + 1.76 | **74.000000 dB** |
| 可重建的最高頻率 | 1000 / 2 | **500.000000 kHz** |

位元數對照（V<sub>ref</sub> = 3.3 V）：N = 8 → LSB **12890.625000 µV**、SNR **49.920000 dB**；N = 16 → LSB **50.354004 µV**、SNR **98.080000 dB**；N = 24 → LSB **0.196695 µV**、SNR **146.240000 dB**（**這已經遠低於任何真實電路的雜訊底，所以 24 位元 ADC 的有效位元 ENOB 通常只有 20 出頭**）。

<p class="warning"> 安全警語（本章必寫）：切換式電源的輸入端可能直接來自市電整流，是致命電壓；電感與變壓器在斷開瞬間會產生遠高於輸入的感應電壓；輸出電容在斷電後仍帶電。所有實驗一律使用低壓隔離電源與現成模組，不要自行接市電。

**不要混淆（至少四條）**：op-amp 的「增益—頻寬乘積」是**開迴路**的性質，閉迴路頻寬 = GBW/閉迴路增益，這是第 14 章 GBW 守恆的直接應用；轉換速率（slew rate）與頻寬是**兩個不同的限制**——頻寬限制小訊號、SR 限制大訊號，大振幅方波看到的斜邊是 SR 造成的不是頻寬造成的；施密特觸發器用的是**正回授**，跟第 14 章的負回授方向相反，它故意讓系統有兩個穩態；LDO 的「壓差（dropout）」是它能正常工作的最小 V<sub>in</sub> − V<sub>out</sub>，跟效率是兩件事；ADC 的「位元數」與「有效位元 ENOB」不是同一個數字，資料手冊要看後者。

**可觀察證據**：頻譜分析儀看振盪器輸出，能量集中在單一頻率、旁邊的相位雜訊裙擺愈窄代表 Q 愈高；用示波器量 LDO 與 Buck 的輸入電流波形——LDO 是平的、Buck 是斷續的三角波，這就是切換雜訊的來源；用熱像儀或直接摸（低壓電路）比較兩者的溫度；把已知的滿刻度弦波送進 ADC，對輸出做 FFT，量到的 SNR 與 6.02N + 1.76 的差距就是實際損失的位元數。**能證明**：振盪頻率與相位雜訊、兩種電源的效率與損耗、ADC 的實際 ENOB 與 SFDR、op-amp 的 GBW 與 SR。**不能證明**：op-amp 內部各級的個別增益（封裝內部看不到）；也不能證明 Buck 的損耗分配（導通損、切換損、電感鐵損各佔多少，要靠拆解量測）。

- 「不要混淆」欄位必須指出**邊界**，不是同義詞。範例（builder 照這個密度寫）：
  - BJT 飽和區：「BJT 的飽和是**開關全開**、V<sub>CE</sub> ≈ 0.2 V、I<sub>C</sub> 由外部電路決定的意思。它跟 MOSFET 的飽和區（定電流、放大用）**意思完全相反**，也跟二極體的 I<sub>S</sub>『飽和電流』無關。看到『飽和』先問是哪一種元件。」
  - MOSFET 飽和區：「MOSFET 的飽和是**放大用的定電流區**（V<sub>DS</sub> ≥ V<sub>OV</sub>），跟 BJT 的飽和區意思相反。要當開關用的是三極區與截止區，不是飽和區。」
  - 負回授的 β<sub>f</sub>：「回授比例 β<sub>f</sub> **不是** BJT 的電流增益 β。兩個符號長得一樣、意義毫無關係，本課一律把回授的寫成 β<sub>f</sub>。」
  - 米勒效應：「米勒效應**只在反相放大時**發生。射隨器與共基組態沒有它，所以疊接才有效。它放大的是等效電容不是實體電容，實體 C<sub>gd</sub> 一點都沒變。」
  - 熱電壓 V<sub>T</sub>：「V<sub>T</sub> = kT/q ≈ 25.851999786 mV（300 K）是**熱電壓**，不是 MOSFET 的門檻電壓 V<sub>th</sub>。兩者符號接近、意義完全不同，本課一律把門檻電壓寫成 V<sub>th</sub>。」
- 每張卡的「位置／角色」要寫**它在本課哪一章、在哪門後續課或哪個真實裝置用到**。
- 符號（β、α、λ、γ、µ、σ、Ω、V<sub>T</sub>、V<sub>th</sub>、V<sub>OV</sub>、g<sub>m</sub>、r<sub>π</sub>、r<sub>o</sub>）出現時要在卡內寫出讀法。
- 首次出現的英文縮寫要展開全名。

### 6.4 回饋規則

- 答對：`<strong>答對</strong>` ＋ 一句**為什麼對**（不是只說「正確」）＋ 來源章節連結。
- 答錯：`<strong>再看一次</strong>` ＋ 正確答案 ＋ 一句**錯在哪裡的常見原因** ＋ 來源章節連結。**不得使用「錯誤」「失敗」「不及格」等字眼，不得用羞辱式語言。**
- 空白作答：提示「先填一個數字」或「先選一個選項」，不判對錯。
- `quiz-progress` 顯示 `已作答 N / 48 題（僅供參考，不影響瀏覽）`；`quiz-reset` 清空所有輸入與輸出並把計數歸零。
- 每題的解釋文字必須引用該章正文出現過的數字，確保兩處一致。
- **負號在 HTML 題目文字裡用 U+2212 `−`，但 `<input type="number">` 接受使用者打半形 `-`，判定用 `Number()` 轉換即可。**

- **單位換算集中在讀值處**：`µA → A` 乘 `1e-6`、`mA → A` 乘 `1e-3`、`kΩ → Ω` 乘 `1e3`、`pF → F` 乘 `1e-12`、`fF → F` 乘 `1e-15`、`µH → H` 乘 `1e-6`、`µF → F` 乘 `1e-6`、`MHz → Hz` 乘 `1e6`、`kHz → Hz` 乘 `1e3`。換算後的變數名加 `SI` 後綴以免混用。
