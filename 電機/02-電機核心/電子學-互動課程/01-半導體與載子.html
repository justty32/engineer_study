01・從能量位置算到一塊矽的電阻率

半導體與載子：用少量摻雜改寫導電性

純矽既不是好導體，也不是理想絕緣體；它的價值在於可用極少雜質精準改變可移動載子的數量。本章把能帶、電子、電洞與摻雜接到可驗算的導電率。

這章假設已懂：00 的非線性與模型觀念，以及原子含原子核與電子的基本圖像。

痛點：摻進一點雜質，為什麼電流能差幾十萬倍

「矽裡本來就有很多電子，為什麼還說純矽幾乎不導電？每幾百萬個原子只換一個雜質，又怎麼可能讓電阻率劇烈下降？」真正關鍵不是材料裡有多少電子，而是多少電子處在可以改變位置、能對外加電場產生淨移動的能量狀態。被化學鍵綁在價帶裡的電子很多，卻不能像自由載子一樣長距離搬運電荷。摻雜的作用是大幅改變可用載子濃度，而不是把整塊材料充成帶正電或帶負電。

能帶（energy band）是固體中電子容許佔據的能量區間。最高被填滿的區間稱價帶（valence band），最低未填滿或部分填滿的區間稱導帶（conduction band）；兩者間不容許穩態電子存在的區域是能隙（band gap, Eg）。導體的能隙為零或能帶重疊，絕緣體通常 Eg > 3 eV，半導體介於兩者；矽、鍺、砷化鎵分別為 1.12 eV、0.66 eV、1.42 eV。能隙決定熱激發有多難，不直接等於載子移動多快。

純淨材料稱本徵半導體（intrinsic semiconductor）。在固定 300 K，有些價帶電子獲得足夠熱能躍入導帶，留下可由鄰近電子依序填補的空位。這個空位稱電洞（hole），可當作帶 +q 的載子計算；每產生一個導帶電子也同時產生一個電洞，因此 n = p = ni。矽的本徵載子濃度 ni = 1.5 × 1010 cm−3，相對於原子密度仍極低。

白話直覺：載子數量是可調的資料欄位

可以把摻雜暫時想成替材料設定主要載子型別的組態值；比喻到此為止，真實機制是雜質原子的價電子數改變了低能量載子狀態。先在矽棒兩端接直流電源並選一端為地，形成電源正端 → 矽樣品 → 電源負端的閉合路徑。未加電場時，載子熱運動方向雜亂，平均電流為零；加上電位差後，電場建立，電子漂移方向與傳統電流相反，電洞的等效移動方向與傳統電流相同。載子從電源與材料的接觸端進出，沿樣品傳遞電荷，電源送出的能量最後轉成晶格熱。

摻五價的磷或砷稱摻雜（doping），多出容易游離的一個電子，形成 n 型材料；電子是多數載子，電洞仍存在但成為少數載子。摻三價的硼或鎵形成 p 型材料，缺少的一個鍵結電子表現為電洞，多數載子改成電洞。外加電壓不變時，更多載子可同時響應電場，所以導電率上升、樣品端點間電壓分布對應較大的電流。整體材料仍電中性：可移動電子的負電荷由固定施體離子的正電荷抵銷，電洞的正電荷也有固定受體離子對應。

載子有兩種驅動來源。漂移電流（drift current）由電場推動；路徑必須閉合，穩態電流才能維持。擴散電流（diffusion current）由濃度梯度推動，即使沒有外加電場，載子也會由高濃度區往低濃度區散開。兩者可能同向也可能反向。下一章把 n 型與 p 型接起來後，擴散先搬動載子並留下固定離子，固定離子再建立電場產生反向漂移，直到淨電流為零。

來源：07-電子學-上 §1.1–§1.4、第 4 章。

推導：從載子濃度走到電流密度

（a）少數載子沒有消失。熱平衡下的質量作用定律（mass action law）是 np = ni²。n 與 p 分別是電子與電洞濃度，單位 cm−3；ni 是本徵濃度，同單位。對 n 型材料，施體濃度 ND 遠大於 ni 時，電中性近似給 n ≈ ND，再得 p = ni²/ND。這表示天平被壓向電子一側，不是電洞變成絕對零。假設為完全游離、熱平衡、均勻摻雜，且忽略高濃度下的能帶與遷移率修正。

（b）導電率來自速度與數量。載子在低電場下的平均漂移速度 v = µE。v 單位 cm/s，µ 是遷移率，單位 cm²/(V⋅s)，E 是電場，單位 V/cm。單一載子的電流密度為 qnv，把電子與電洞兩項相加，得到 J = q(nµn + pµp)E = σE。J 是電流密度，單位 A/cm²；q = 1.602176634 × 10−19 C；σ 是導電率，單位 S/cm。單位相乘為 C × cm−3 × cm²/(V⋅s) = S/cm，與公式一致。電阻率 ρ = 1/σ，單位 Ω⋅cm。

（c）為什麼少量摻雜這麼有效。本徵矽的兩種載子都只有 1.5 × 1010 cm−3，所以 σ = qni(µn + µp) = 4.397975 × 10−6 S/cm。若 ND = 1016 cm−3，電子項直接增大近六個數量級，總導電率成為 2.162938456 S/cm，約上升 491803.278689 倍。雜質比例雖只有約五百萬分之一，卻是相對於原本極稀少的自由載子增加，不是相對於全部矽原子增加。

（d）擴散項保留不同資訊。電子擴散可寫 Jn = qDn ⋅ dn/dx。Dn 是電子擴散係數，單位 cm²/s；dn/dx 是濃度梯度，單位 cm−4，所以 Jn 的單位仍為 A/cm²。這裡只交代方向與量綱，不推導統計力學。漂移看 E，擴散看濃度斜率；兩個驅動量不能互相替代。

（e）製程把空間分布寫進晶圓。積體電路由矽晶圓開始，依序經氧化、微影、蝕刻、離子佈植摻雜、沉積與金屬連線，把不同濃度與型別安排在指定位置。製程節點如 7 nm、3 nm 是一組世代標稱，不等於每個幾何尺寸都恰為該數字；摩爾定律描述長期密度趨勢，也不是材料定律。本章只需要知道元件的 n 區、p 區與接觸不是自然長成，而是製程刻意建立。

數值實例：n 型矽在固定電場下的導電能力

自由實驗：切換載子型別與摻雜濃度

拓樸是直流電源正端接矽樣品一端，另一端回到電源負端並作為地，樣品內形成均勻電場與閉合電流路徑。選擇材料型別、摻雜濃度與電場，觀察電子、電洞、導電率、電阻率及漂移電流密度如何同步改變。

不要混淆

  • 電洞不是獨立基本粒子，而是價帶少一個電子的集體行為；計算邊界內它有 +q 電荷與明確遷移率，可當準粒子處理。
  • n 型表示電子是多數載子，不表示材料整體帶負電；固定施體離子與可動電子的電荷在巨觀上互相抵銷。
  • 摻雜濃度不是自由載子濃度在所有條件下的精確同義詞；只有完全游離、均勻、非退化且 ND ≫ ni 時才可用 n ≈ ND。
  • 能隙控制產生載子的難易，遷移率控制載子在電場下的漂移速度；一個材料能隙小，不代表載子必定移動較快。
  • 漂移需要電場，擴散需要濃度梯度；兩者都搬運電荷，但驅動條件與方向判讀不同。
  • 製程節點是技術世代名稱，不是所有電晶體尺寸的單一精確值；本章也不由節點推論良率或效能。

可觀察證據：電阻率、型別與濃度要分開量

四點探針（four point probe）讓外側探針送電流、內側探針量電壓，可降低接觸電阻影響並得到薄片電阻 Rs，配合厚度換算電阻率。霍爾效應量測（Hall measurement）在已知電流與磁場下量橫向霍爾電壓，其正負可判斷主要載子是電洞或電子，大小可推算載子濃度，再與導電率合併求遷移率。這些儀器能證明樣品在量測條件下的電阻率、主要載子型別、濃度與遷移率，並檢查「載子多使 σ 增大」的數值關係。它們不能直接證明能隙；能隙要靠光吸收邊緣或溫度相依性。它們也不能只憑載子型別辨認雜質究竟是磷還是砷，更不能證明微觀每個原子的位置。探針量到的是有限區域的平均，摻雜若不均勻，單一讀值不能代表整片晶圓。

連到哪門課

能帶、能隙與半導體的量子圖像見普通物理的量子與半導體；熱激發與濃度梯度造成擴散的巨觀圖像見普通物理的熱學與流體。本章的 σ 與 ρ 會直接用於積體電路走線、接觸及寄生電阻估算；下一章則把 n 型與 p 型接在一起，讓擴散與漂移自行建立一個單向元件。
