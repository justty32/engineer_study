08・用絕緣閘極建立可控制的導電通道

MOSFET 原理與三個工作區：先看通道是否存在

閘極不必持續吸收直流電流，仍能靠電場改變半導體表面的載子濃度。只要依序算超驅動電壓、比較汲源電壓，就能判斷它是關閉、像受控電阻，還是呈現放大器需要的定電流行為。

這章假設已懂：01 半導體與載子的摻雜、電子與電場，以及電路學 06 電容與電感的電場儲能。

痛點：閘極沒有直流電流，怎麼可能控制汲極電流

「沒有電流進控制端，控制作用從哪裡來？而且 MOSFET 的飽和區為什麼反而拿來放大？」把閘極當成必須供應載子的入口，就會錯過真正機制。金氧半場效電晶體（Metal Oxide Semiconductor Field Effect Transistor, MOSFET）的閘極隔著氧化層，控制量是電場，不是穩態閘極電流；外部電源供應汲極電流與能量，閘極只改變源極到汲極之間能不能形成通道。

以增強型 NMOS 為例，p 型基板內有兩個 n+ 摻雜區，分別作源極（Source, S）與汲極（Drain, D）；表面覆蓋極薄的二氧化矽，氧化層上方是閘極（Gate, G）。PMOS 將摻雜型別與電壓極性反轉。這不是把輸入與輸出用導線接起來，而是用一個近似電容的結構改造表面載子分布。

白話直覺：閘極是在鋪路，不是在供應車流

可暫時把閘極電場想成鋪出一條路；比喻到此為止，精確說法是正 VGS 排斥表面電洞並吸引電子，當表面電子足夠多時形成反轉層（inversion layer），也就是 n 型導電通道。源極接地作參考，汲極經負載接正電源，閘極由電壓源相對源極驅動。

當 VGS = 0 時，源極與汲極之間只剩背對背的反偏 PN 接面，汲源回路沒有可持續導通的通道，ID 近似為零。當 VGS 超過門檻電壓 Vth，閘極與基板之間的電場把電子吸到氧化層下，通道閉合；汲源電壓 VDS 再沿通道建立橫向電場，推動電子由源極往汲極移動，傳統電流方向則由汲極往源極。能量由汲極電源送入負載與通道，不是由閘極供應。

VDS 很小時，整條通道都存在，兩端壓差增加便增加載子漂移，MOSFET 表現成由 VGS 控制阻值的電阻，這是三極區／線性區（triode / linear）。提高 VDS 後，汲極端局部通道電位上升，使那裡的有效超驅動逐漸歸零；到 VDS = VOV 時汲極端通道夾止。再增加 VDS，額外電壓主要落在夾止區，電流幾乎不變，進入飽和區（saturation）。因此端點電壓的結果是：三極區電流明顯隨 VDS 變，飽和區則主要由 VGS 決定。

閘極直流電流近似零只代表氧化層不提供穩態導電路徑。改變閘極電壓時仍須對閘極電容充放電，驅動器會在切換瞬間提供電流並交換能量；頻率愈高，這筆成本愈不能忽略。第 09 章會把這件事放進 CMOS 功耗帳。

來源：07-電子學-中 §6.1–§6.3、§6.5–§6.7。

推導：從沿途通道電荷走到平方律

先定義超驅動電壓（overdrive voltage）VOV = VGS − Vth，單位 V。若 VOV ≤ 0，沒有強反轉通道，採截止區（cutoff）模型 ID ≈ 0。此處忽略次臨界漏電、接面漏電與閘極穿隧電流，溫度固定 300 K。

通道位置 x 的電位記為 V(x)。當地可移動電荷量與 VGS − Vth − V(x) 成正比；愈靠近汲極，V(x) 愈高，通道電荷愈少。把沿通道每一小段的電荷與漂移關係累加，得到三極區公式 ID = k[VOVVDS − (1/2)VDS²]。其中 k = µnCox(W/L)，單位 A/V²；µn 是電子遷移率，Cox 是單位面積閘氧電容，W/L 是通道寬長比。假設長通道、遷移率不隨電場變、接觸電阻可忽略。

若 VDS ≪ VOV，二次項遠小於一次項，ID ≈ kVOVVDS，所以小 VDS 下的等效電阻約為 1/(kVOV)。這就是 MOSFET 作 CMOS 開關與類比開關時使用三極區的理由；截止區負責開路，三極區負責低阻導通。

對三極區公式求 ∂ID/∂VDS = k(VOV − VDS)。令導數為零，得邊界 VDS = VOV；代回原式，得到理想飽和電流 ID = (1/2)kVOV²。邊界兩側公式給同一電流，可作程式斷言。真實通道的夾止點會隨 VDS 略移，通道長度調變（channel length modulation）以 (1 + λVDS) 修正，λ 單位 V−1，故 ro = 1/(λID)。

跨導（transconductance, gm）是 Q 點上 ∂ID/∂VGS，單位 A/V。飽和區有 gm = kVOV(1 + λVDS)；忽略 λ 時亦可寫成 2ID/VOV = √(2kID)。再與 ro 相乘，得本徵增益 gmro = 2/(λVOV)，顯示理想平方律下電流消去。

基板不與源極等電位時會有體效應（body effect）：Vth = Vth0 + γ[√(VSB + 2φF) − √(2φF)]。VSB 增加會使門檻升高。短通道元件還會出現更強的通道長度調變、漏電流與速度飽和，因此平方律是建立判區直覺的模型，不是所有製程的精密模擬器；FinFET 與環繞閘極結構用三維閘極改善靜電控制。

自由實驗：掃過 MOSFET 三個工作區

汲極由正電源經負載供能，源極與基板接地，閘極由獨立電壓源設定 VGS；汲源回路只有形成反轉通道後才閉合。調整端點電壓、門檻、k 與 λ，觀察工作區、電流、跨導及輸出阻抗如何同步改變。

不要混淆

  • MOSFET 的飽和區是放大用的定電流區；BJT 的飽和區是開關全開、VCE ≈ 0.2 V，兩者意思相反。請回看第 06 章 BJT 原理與工作區；MOSFET 當開關用的是三極區與截止區，不是飽和區。
  • 閘極直流電流近似零，不代表切換時完全沒有閘極電流；高頻驅動必須反覆搬運閘極電荷。
  • Vth 是形成強反轉的模型邊界，不是「輸出突然完全打開」的固定開關點；製程、體效應與偏壓都會改變它。
  • k = µnCox(W/L) 同時含製程參數與尺寸比；電路設計者通常能選 W/L，不能任意指定遷移率與氧化層電容。
  • 飽和區電流「幾乎不隨 VDS 變」不是完全不變；λ 造成有限 ro，短通道時偏離更明顯。

可觀察證據：用曲線追蹤儀量端口行為

曲線追蹤儀固定多個 VGS 並掃 VDS，可量得一族 ID 數值；低 VDS 段隨電壓上升、越過 VDS = VOV 後趨近平坦，能證明三極區、飽和區與轉折邊界。以低壓小訊號改變 VDS 可由斜率反推 ro，掃 VGS 則可外插 Vth 並估 k、λ。這些端口量測不能分別證明 µn 與 Cox 各是多少，也不能證明版圖 W/L、氧化層厚度或通道內部的空間分布；那些需要製程資料與結構量測。

連到哪門課

MOSFET 是積體電路的類比電流源、數位開關與電源開關。閘極電場與反轉層可銜接普通物理的靜電學，閘極充放電則銜接電路學的電容與電感。下一章把 NMOS 與 PMOS 互補串接，第 10 章再把飽和區工作點線性化。
