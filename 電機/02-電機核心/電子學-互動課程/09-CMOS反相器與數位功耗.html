09・用互補開關搬運電荷並計算每次切換成本

CMOS 反相器與數位功耗：穩態省電，切換付費

一顆 PMOS 拉高、一顆 NMOS 拉低，讓兩個穩定邏輯狀態都沒有理想的電源到地直流路徑。真正的功耗主要發生在輸出電容充放電與兩顆短暫同時導通時，而且電源電壓以平方進入成本。

這章假設已懂：08 MOSFET 原理與三個工作區，以及電路學 07 一階暫態的 RC 充放電。

痛點：CMOS 說靜態幾乎不耗電，晶片為什麼還會發燙

「穩定的 0 或 1 明明只有一顆電晶體導通，為什麼時脈一快功耗就暴增？降低電壓又為什麼比降低頻率有效？」答案不在穩態真值表，而在每次切換都要搬運輸出節點的電荷。互補式金氧半導體（Complementary Metal Oxide Semiconductor, CMOS）用相反極性的兩顆 MOSFET 避免穩態直通，但它不會消除電容，也不會讓轉態瞬間變成零時間。

反相器拓樸固定為：VDD → PMOS 源極；PMOS 汲極 → 輸出節點 OUT；OUT → NMOS 汲極；NMOS 源極 → 地；輸入 IN 同時接兩個閘極。負載電容 CL 從 OUT 接到地，代表下一級閘極、走線與接面電容的總和。輸入不是直接把電荷送到輸出，而是選擇哪顆電晶體提供輸出充電或放電路徑。

白話直覺：兩顆門將輪班，但交班仍有成本

可暫時把 NMOS 與 PMOS 想成只允許一方值班的兩扇門；比喻到此為止，精確機制是輸入電壓同時改變兩顆的 VGS，使輸出節點經 PMOS 接電源或經 NMOS 接地。地是 0 V 參考，VDD 是能量來源。

輸入為低準位時，NMOS 的 VGS 不到門檻而截止，PMOS 的閘源偏壓足以導通。電源到 OUT 的路徑閉合，電子與傳統電流方向相反地移動，CL 被充到 VDD；NMOS 路徑開路，所以沒有理想的 VDD 到地回路。端點結果是輸出為高準位。輸入為高準位時，PMOS 截止、NMOS 導通，OUT 經 NMOS 接地，CL 儲存的能量在通道中轉成熱，輸出降到 0 V；同樣沒有穩態直通路徑。

輸入停在中間時，兩顆可能同時導通，VDD → PMOS → NMOS → 地形成閉合回路，產生短路直通電流（short circuit current）。同時，輸出節點還在充放電，端點電壓尚未被明確判成 0 或 1。輸入邊緣愈慢，兩顆重疊導通的時間愈長，直通能量愈大；因此數位電路不只在乎邏輯值，也在乎邊緣速率。

穩定狀態仍有次臨界漏電與閘極穿隧漏電，所以「靜態功耗極低」不是零。製程縮小、門檻降低時，漏電可能成為重要比例。本章互動只算負載電容的動態功耗，不把直通、漏電、內部節點與短路故障混成一個假精確數字。

來源：07-電子學-中 第 7 章。

推導：切換閾值與 CVDD² 從哪裡來

切換閾值（switching threshold）VM 定義為 Vin = Vout 的工作點，不是輸入門檻 Vth。在兩顆皆以長通道飽和平方律工作、忽略 λ 與體效應時，電流大小相等：

(1/2)kn(VM − Vth,n)² = (1/2)kp(VDD − VM − |Vth,p|)²。

兩側取正平方根，令 kr = kp/kn，整理得 VM = [Vth,n + √kr(VDD − |Vth,p|)] / (1 + √kr)。所有電壓單位 V，k 比無單位。若 kr = 1 且兩個門檻絕對值相等，分子對稱，VM = VDD/2。

PMOS 的電洞遷移率低於 NMOS 的電子遷移率；第 01 章的錨定值是 480 對 1350 cm²/(V⋅s)。若兩顆幾何尺寸相同，PMOS 通常較弱，VM 被拉低。設計上加大 PMOS 的 W/L，使 kp 接近 kn，才得到對稱轉態。這個結果是電流匹配，不是規定兩顆外形一定相同。

再算能量。把 CL 從 0 充到 VDD，最後電荷 Q = CLVDD。電源送出的能量是 QVDD = CLVDD²；電容只儲存 (1/2)CLVDD²，另一半在 PMOS 通道電阻上變成熱，而且總量與電阻值無關。放電時，電容儲存的另一半又在 NMOS 通道變熱。因此完整的 0→1→0 循環耗能 E = CLVDD²。

若每秒完整切換 f 次，動態功耗 P = Ef = CLVDD²f。CL 單位 F、f 單位 Hz、E 單位 J、P 單位 W。這裡假設每循環確實翻轉一次；實際晶片常加活動率 α，成為 αCLVDD²f。VDD 從 3.3 V 降到 1.0 V，比例是 (1.0/3.3)² = 0.091827，也就是省 90.8173 %。代價是 VOV 與充電電流下降，延遲通常增加。

頻率與活動率也要分清楚。時脈可能每秒走很多週期，但某個資料節點若長時間保持原值，就沒有每週期都搬運完整的 CLVDD 電荷；時脈閘控正是讓不工作的區塊停止這種切換。另一方面，增加扇出會把更多下一級閘極接到 OUT，使 CL 上升，延遲與能量同時增加。因此軟體看到的運算率，必須經過實際翻轉次數、資料相關性與實體負載，才會成為晶片的動態功耗。

粗略邏輯安全區也能由門檻看出：Vin < Vth,n 時 NMOS 保證截止；Vin > VDD − |Vth,p| 時 PMOS 保證截止。兩界之間是轉態區。這不是正式雜訊邊限，因真正的 VIL 與 VIH 要由完整轉移特性曲線斜率為 −1 的兩點決定。

自由實驗：看反相狀態與切換成本

VDD 接 PMOS 源極，PMOS 與 NMOS 的汲極共接 OUT，NMOS 源極接地，IN 同時接兩個閘極，CL 從 OUT 接地。調整電源、輸入、門檻、強度比、頻率與負載，觀察導通路徑、輸出與能量帳。

不要混淆

  • 靜態功耗極低不等於零；次臨界與閘極漏電在先進製程可能占顯著比例，而本章平方式沒有包含它們。
  • CLVDD² 是完整 0→1→0 循環的能量；只看單邊翻轉時是其一半，必須先確認事件定義。
  • 直通電流與負載電容充放電電流是兩項不同損耗；前者依賴輸入邊緣與兩顆同時導通的時間，本互動只算後者。
  • VM 是 Vin = Vout 的切換閾值，不是 MOSFET 的 Vth，也不是完整定義的雜訊邊限。
  • 降低 VDD 依平方省動態功耗，但不能無限降低；若 Vth 沒同步調整，電晶體可能打不開且延遲暴增。

可觀察證據：同步量輸入、輸出與電源電流

用可調直流電源緩慢掃 Vin，以兩支三用電表或示波器量 Vin、Vout，並用高解析度電流表量電源電流，可得到轉移數值與直通電流峰值；峰值附近對應 VM，能證明兩顆重疊導通與靜態漏電不為零。以示波器量切換波形，再把電源電流流過取樣電阻轉成電壓，可看見每個邊緣的電流尖峰並積分估能量。這些量測不能把 CL 拆成閘極、走線與接面電容各自多少，也不能單靠總電流證明能量在兩顆電晶體間的瞬時分配。

連到哪門課

反相器是數位邏輯閘、記憶體與處理器的底層單元；本章只到 VM 與功耗，組合邏輯、正反器與時序留給數位邏輯設計。切換延遲可銜接電路學的一階暫態，每循環能量可回到普通物理的功與能量。
