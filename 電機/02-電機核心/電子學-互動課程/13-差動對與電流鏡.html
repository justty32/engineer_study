13・讓兩顆電晶體只回應輸入差值

差動對與電流鏡：把共同擾動拒於輸出之外

差動對不是兩個放大器相減而已，而是讓固定尾電流在兩支路間重新分配。電流鏡主動負載能把差模增益放大十倍，卻不會替尾電流源改善共模拒斥比。

這章假設已懂：11 的共射組態，以及10 的小訊號模型。

痛點：兩個輸入一起飄，為什麼理想輸出可以不動

「兩顆電晶體的基極電壓都升高，集極電流不是都該增加嗎？為何差動對卻說共模增益接近零？」單看各顆的指數關係會得到錯誤直覺，因為兩顆共用同一個尾電流源。總電流被鎖住後，一邊增加就必須由另一邊減少；兩邊一起升高時，尾節點會跟著升高，使各自的基射電壓近乎不變。

差動對（differential pair）接收 v1 與 v2，關心差模輸入 vid = v1 − v2。兩端一起變化叫共模輸入。差模增益 Ad 描述輸出對差值的反應，共模增益 Acm 描述輸出對共同變化的反應；共模拒斥比（Common Mode Rejection Ratio, CMRR）= |Ad/Acm|，常以 dB 表示。

白話直覺：尾電流是固定預算，差值只決定怎麼分配

可以暫時把尾電流想成兩個執行緒共享的固定運算配額；比喻到此為止，精確機制是尾電流源用高輸出阻抗限制兩支路電流總和。正電源各經負載接兩個集極，兩射極相連後經尾電流源到負電源或地，兩條集射路徑都閉合。

平衡時每邊取得 Itail/2。若 v1 相對 v2 升高，第一顆基射偏壓增加，更多載子由其射極注入並被集極收集；共用射極節點也上升，第二顆基射偏壓下降，因此尾電流從第二支路轉向第一支路。第一側負載壓降增加、集極電壓下降，另一側相反，輸入差值便轉成輸出電壓。

若兩輸入一起上升，尾節點跟隨上升，兩個 VBE 理想上不變，尾電流也不變，輸出便不動。真實尾電流源有有限輸出阻抗 Roc，尾節點電壓改變仍會漏成少量電流變化，所以 Acm 不為零。Roc 愈大，共同擾動愈難改變總電流，CMRR 愈高。

電流鏡（current mirror）用配對電晶體把參考電流複製到輸出，既能提供尾電流，也能作主動負載（active load）。作負載時，它在直流維持偏壓電流，在小訊號卻呈現很大的輸出阻抗，讓相同電流變化產生更大輸出電壓。這增加 Ad，但 Acm 也被相同負載倍數放大，所以比值 CMRR 不變。

來源：07-電子學-下 §10.1–§10.3。

推導：把差模與共模拆成兩個半電路

差模驅動時兩輸入大小相等、方向相反，對稱面沒有小訊號電流，尾節點成為虛地。每一半就是無射極退化的共射級。每邊靜態電流 IC = Itail/2，跨導 gm = IC/VT，單位 A/V；單端差模增益大小 Ad = gmRL,eff，無單位。此處固定 T = 300 K，VT = 25.851999786 mV，假設兩顆完全匹配且處於作用區。

共模驅動時兩邊同步，流入尾阻抗的增量相加。從任一半電路看，Roc 等效為 2Roc 的射極退化，因此在 gm ⋅ 2Roc ≫ 1 時，Acm = −RL,eff/(2Roc)。取大小相除，CMRR = gmRL,eff / [RL,eff/(2Roc)] = 2gmRoc。

RL,eff 在分子與分母完全約掉，因此 CMRR = 2gmRoc 與負載阻抗無關。主動負載買到的是差模增益，不是 CMRR。要提高此模型下的 CMRR，必須增加尾電流源輸出阻抗，或在相同 Roc 下提高 gm；換大集極電阻只會同時放大差模與共模。

主動負載若由兩顆相同電晶體輸出阻抗構成，RL,eff = ro‖ro = ro/2；‖ 讀作「並聯」，不是絕對值也不是範數。以 ro = VA/IC 計算，VA 單位 V，ro 單位 Ω。這裡忽略鏡像誤差、基極電流、有限順從範圍與元件失配。

大訊號時，電流重新分配遵循 ΔI = Itail ⋅ tanh[vid/(2VT)]。在零點線性化才有 ΔI ≈ gmvid；條件是 |vid| ≪ 2VT = 51.704000 mV。當 |vid| 超過 4VT = 103.407999 mV，電流幾乎全倒向一邊，差動對由放大器轉成比較器。

若把分析寫成程式，可先用共模與差模座標取代兩個原始輸入：vicm = (v1 + v2)/2，vid = v1 − v2。線性小訊號模型中，這兩個模式因對稱性互不混合，輸出可分別計算再疊加；真實元件一旦失配，模式便會耦合，共模的一部分轉成差模輸出。這也解釋為何晶片版圖要求兩顆輸入電晶體尺寸、方向與周圍環境對稱。

自由實驗：分開看差模增益與共模拒斥

正電源分別經負載接兩個集極，兩射極相連後經有限輸出阻抗的尾電流源回地，單端輸出取其中一個集極。調整尾電流、負載、尾源阻抗與差模輸入，觀察主動負載改變哪些量，又不改變哪些量。

不要混淆

  • 單端 Ad 的 gm 要用每邊 Itail/2 計算；把整個尾電流代入會多兩倍。
  • 本章做單端輸出；理想全差動輸出的共模增益趨近零，其 CMRR 主要由兩側不對稱決定，不能直接套同一結果。
  • 主動負載在直流是定電流偏壓，在小訊號是高阻抗；兩種模型回答不同問題，不可把高阻抗誤解成沒有直流電流。
  • CMRR 高只代表共模抑制好，不保證低雜訊、寬頻寬、低失真或足夠輸出擺幅。
  • 主動負載提高 Ad，也按相同比例提高 Acm；因此它不改善由 Roc 限制的 CMRR。

可觀察證據：分別注入差模與共模訊號

用雙通道訊號產生器先送等幅反相信號，示波器量單端輸出與 vid 得 Ad；再把兩輸入短接送同相信號，量 Acm，相除並取 20log10 得實測 CMRR。掃大 vid 可量輸出開始壓縮的線性範圍；把尾電阻換成高輸出阻抗電流鏡，CMRR 應提升。這些量測能證明端口的 Ad、Acm、CMRR 與線性範圍，不能單獨證明兩顆電晶體的失配量，也不能唯一反推出 Roc，因為輸入失調與負載不對稱也會汙染結果。

連到哪門課

差動對是運算放大器、ADC 比較器與通訊接收器前端的輸入核心。對稱半電路的節點推導可回到電路學的節點分析；本章的差動對與電流鏡會在第 15 章組成運算放大器輸入級。多級串接時，前級重視高輸入阻抗與低雜訊，中段取得增益，末級才負責低輸出阻抗與驅動負載。
