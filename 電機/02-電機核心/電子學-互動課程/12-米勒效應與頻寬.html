12・找出高頻訊號被哪顆等效電容吃掉

米勒效應與頻寬：用疊接保住增益也保住速度

一顆只有 1 pF 的跨接電容，為何能把高增益級拖成 206 pF？關鍵不是實體電容變大，而是反相輸入與輸出朝相反方向擺動，使輸入端必須供應更多充放電電流。

這章假設已懂：11 單級放大器三大組態，以及電路學的一階濾波器與 −3 dB。

痛點：電晶體直流正常，為什麼頻率一高增益就消失

「資料手冊的 Cgd 才 1 pF，訊號源也不算慢，為什麼共射或共源級到幾百 kHz 就掉增益？」只把閘源電容與跨接電容直接相加，會漏掉輸出也在動。共射／共源是反相級，輸入升高時輸出下降；跨在兩端的電容每次要跨越兩邊相反的位移，因此輸入端看到的充電需求遠大於實體電容量。

米勒效應（Miller effect）是跨接阻抗在有增益的兩節點之間，從單一端口看見的等效阻抗改變。這是電路等效，不是材料或幾何尺寸發生變化。BJT 的跨集電容 Cµ、MOSFET 的閘汲電容 Cgd 都會參與；只有兩端反向擺動時才得到明顯的 (1 + |Av|) 倍放大。

白話直覺：兩端反向移動，充電路徑被迫多搬電荷

可以暫時把跨接電容想成連著兩扇反向移動門的彈簧；比喻到此為止，精確定義是電容電流由兩端電壓差的變化率決定。以訊號源對地為參考，源經 Rs 驅動共源閘極，源極接交流地，汲極經負載到電源，Cgd 跨接閘極與汲極，所有交流回路都經電源旁路回地而閉合。

輸入上升時，閘極電場增強通道，汲極電流增加；負載壓降隨之增加，汲極電壓下降。能量由電源經負載與電晶體送往地，一部分同時用來替 Cgs 與 Cgd 重新分配電荷。若 vout = −|Av|vin，Cgd 兩端變化不是 vin，而是 (1 + |Av|)vin。訊號源經 Rs 必須供應放大的電容電流，輸入電壓來不及跟上，高頻增益便下降。

射隨器輸出與輸入同向，跨接電容兩端差值反而很小；共基／共閘的輸入在射極／源極，基極／閘極是交流地，也沒有大幅反相輸出跨回輸入端。因此米勒效應只在反相放大發生。疊接（Cascode）把共射加共基，或把共源加共閘：上方電晶體的低輸入阻抗把下方輸出節點箝在小擺幅，下級增益約 −1，跨接電容只剩兩倍等效值，而總輸出仍可在上方負載取得高增益。

更精確地說，共基的訊號從射極輸入，而跨集電容的另一端是固定在交流地的基極；共閘則由源極輸入，閘極固定在交流地。跨接電容因此位於輸出與交流地之間，沒有跨回輸入，也就沒有高增益反相節點把其端電壓差放大。疊接把共基或共閘放在共射或共源上方，正是利用這個端點配置隔離下方元件的輸入與最終輸出。

來源：07-電子學-下 §9.4。

推導：從電容電流推出米勒倍數與高頻極點

令跨接電容阻抗為 ZC，輸入端流入它的電流 i = (vin − vout)/ZC。在反相中頻增益 vout = −|Av|vin 下，i = vin(1 + |Av|)/ZC。同一輸入電壓引出的電流增為 (1 + |Av|) 倍，等效導納與等效電容也放大同樣倍數，所以 Cmil = (1 + |Av|)Cgd。

再加上直接對交流地的 Cgs，得到 Cin = Cgs + (1 + |Av|)Cgd。訊號源戴維寧電阻 Rs 與它形成一階低通，τ = RsCin，fH = 1/(2πτ)。τ 單位 s；Rs 單位 Ω；電容單位 F；fH 單位 Hz。到 fH 時振幅為中頻值的 0.7071 倍，即 −3.010300 dB，之後每十倍頻約再降 20 dB。

這個推導假設 Av 在關心頻段內為常數，故是低頻近似，不能拿固定中頻增益精算 fH 附近的完整多極點行為。輸出端的負載電阻與負載電容也會建立另一極點；本章只辨認輸入主極點，不宣稱真實頻率響應永遠只有一階。

例如輸出端等效電阻近似 RC、總負載電容為 CL 時，還會出現約由 RCCL 決定的時間常數。若這個輸出極點比輸入極點更低，它才是首先限制頻寬的主極點；若兩者接近，幅度斜率與相位會同時受多個極點影響，不能只取兩個截止頻率中較小者便宣稱得到完整響應。本章的數值表刻意只隔離輸入端機制。

也可從電荷量檢查同一結論。電容端電荷變化 ΔQ = CΔV；若輸入變化 Δvin，反相輸出同時變化 −|Av|Δvin，跨接電容所需電荷便是 Cgd(1 + |Av|)Δvin。把它除以輸入變化，正好得到等效電容。這種端口等效只保留訊號源必須提供多少電荷，不能用來推論電容兩端的實際能量分配；後者還要保留輸出端等效與受控源。

疊接時，下方電晶體看進上方共基／共閘輸入阻抗約 1/gm2，所以它的局部增益約為 −gm1/gm2 ≈ −1，假設兩顆偏在同一電流且跨導近似相等。於是 Cin = Cgs + 2Cgd。共射在 Cgd 主導時，|Av|fH 趨近 1/(2πRsCgd)；疊接改變局部增益分配，因此能超越這條單級近似上限。

數值實例：1 pF 經反相增益變成 201 pF

疊接把頻寬提高 29.428571 倍，實體 Cgd 仍是 1 pF。共射增益改為 10、50、200、500 時，fH 依序為 4973591.971622、1421026.277606、386298.405563、157267.730328 Hz；GBW 則為 49.735920、71.051314、77.259681、78.633865 MHz，逐步逼近 79.577472 MHz，而非嚴格固定。

因此「GBW 不變」只是 Cgd 主導且增益夠大時的漸近說法。低增益時，固定的 Cgs 仍占 Cin 顯著份額，所以增益提高時 GBW 會由 49.735920 MHz 緩慢上升到 78.633865 MHz；當米勒項遠大於 Cgs，它才趨近 1/(2πRsCgd)。這個趨勢不是放大器額外產生頻寬，而是被固定輸入電容拖累的比例逐漸變小。

這組數字還說明三個可直接採取的設計方向。降低 Rs 會等比例提高兩種拓樸的輸入極點，但前級必須供應更大充放電電流；縮小 Cgd 需要選較小元件或不同製程，可能犧牲跨導與雜訊；降低單級增益則可把總增益分配到多級。疊接的代價是堆疊電晶體吃掉電壓餘裕，低電源電壓下可能先失去輸出擺幅，不能只比較頻寬倍數。

自由實驗：比較共射與疊接的輸入主極點

訊號源經 Rs 接反相級輸入，Cgs 對交流地，Cgd 跨輸入與局部輸出；回路經電源旁路返回地。切換共射／共源與疊接，觀察同一組實體電容如何形成不同等效電容、頻寬與 GBW。

不要混淆

  • 米勒效應只在反相放大產生大倍數；射隨器同相，共基／共閘的控制端是交流地，都不適用 (1 + |Av|) 的說法。
  • 被放大的是輸入端所見的等效電容，不是實體 Cgd 或 Cµ 改變；拆下元件量電容不會讀到 201 pF。
  • (1 + |Av|) 使用中頻增益並假設它近似常數；接近 fH 時增益已下降，不能把此式當完整頻率響應。
  • 本章 fH 是輸入主極點；輸出負載與其他寄生電容仍可建立更低極點，屆時單極點模型失效。
  • GBW 近似不變只描述單純共射在 Cgd 主導時的趨勢；疊接重分配局部增益，不受同一米勒上限約束。

可觀察證據：改源阻抗與增益，找出是哪個極點

用訊號產生器掃頻，以雙通道示波器或網路分析儀同時量輸入與輸出，找輸出降至中頻值 0.7071 倍的 −3.010300 dB 點。這能證明 fH 與每十倍頻約 −20 dB 的主極點行為；把 Rs 換成不同值，若 fH 近似反比改變，能支持極點位於輸入端；再換負載電阻改變增益，若頻寬反向變化，能支持米勒效應主導。單次掃頻不能分別證明 Cgd 與 Cgs 的實際值，也不能直接證明疊接內部下級恰為 −1；要以多組條件解聯立，或量內部節點。

連到哪門課

高頻前端、示波器探棒緩衝與寬頻放大器都靠低源阻抗及疊接管理寄生電容。一階低通、−3 dB 與每十倍頻 −20 dB 見電路學的頻率響應；把極點寫成轉移函數則見工程數學先修的拉氏轉換。GBW 與相位裕度會在第 14 章接到回授穩定性。
