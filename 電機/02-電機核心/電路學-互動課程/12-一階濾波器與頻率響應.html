12・用頻率逐點詢問電路

一階濾波器與頻率響應：算出哪些頻率通過、衰減與延遲

同一個電路面對慢慢變化與快速變化的訊號，輸出不會相同。本章會把輸出與輸入的關係寫成複數函數，讓截止頻率、分貝、相移與波德斜率都能由一個 RC 電路算出來。

這章假設已懂：10 阻抗與交流穩態；對數與分貝的算法。

痛點：一顆電容為什麼知道訊號是高頻還是低頻？

電容沒有時鐘，也不會辨認音名或資料格式。它只依端電壓變化率產生電流，因此頻率改變時，容抗的大小跟著改變，整個分壓比例也就改變。真正要問的不是「電容把哪個頻率刪掉」，而是指定一個頻率後，輸出振幅剩多少、相位落後或超前幾度。若只有「低頻通、高頻擋」這句口訣，就無法判斷截止附近到底衰減多少，也無法估計下一級接上後的影響。

頻率響應（frequency response）就是逐一回答這些問題的工具。對線性、時不變、集總電路，以轉移函數（transfer function） H(jω) = Vout/Vin 表示輸出相量與輸入相量的比值。粗體代表相量；數學課常把虛數單位寫 i，電機寫 j，因為 i 留給電流。H 是複數，其大小是增益，其角度是相移，兩者缺一就不能完整描述輸出。

白話直覺：頻率改變的是分壓比例

可以暫時把 RC 低通想成「快速變化會找到一條較容易通往地的路」；比喻到此為止，精確機制是 ZC = 1/(jωC) 的大小等於 1/(ωC)，ω 愈大，電容阻抗愈小。電源以地為參考，Vs 正端 → R → 輸出節點；輸出節點 → C → 地；Vs 負端 → 地。訊號源與回路閉合後，交流電流經 R 與 C 回到源，能量一部分在電場暫存後送回，一部分在 R 轉成熱。

輸出取在電容兩端。低頻時電容支路阻抗大，輸出節點接近輸入電壓；高頻時阻抗小，節點被電容拉近地，輸出變小。這不是一道理想開關：任何有限頻率都有有限輸出。一階低通的相位則從接近 0°逐漸趨近 −90°，表示輸出相對輸入愈來愈落後。若改把輸出取在 R 上，就是高通；低頻時 R 分不到多少電壓，高頻時輸出接近輸入，相位由接近 +90°趨近 0°。

第 07 章在時間域問電容充電要多久，本章在頻域問它能跟上多快。兩者是同一個 RC：時間常數 τ = RC，而截止頻率 fc = 1/(2πτ)。τ 大表示反應慢，同時表示可通過的頻帶窄；「時域慢」與「頻域窄」是同一個儲能機制的兩種觀察。

再看兩個極端可檢查這個模型。當 ω 趨近 0，電容阻抗的大小趨近無限大，回路電流趨近零，R 上壓降也趨近零，所以低通輸出接近輸入；當 ω 趨近無限大，電容阻抗趨近零，輸出節點接近地。這兩句只描述弦波穩態，不表示電容在切換瞬間真的是開路或短路。有限頻率下，輸出永遠介於兩個極限之間，而且相位會連續轉動。

轉移函數還把振幅縮放與時間位移分開。若輸入是 1 V 有效值弦波，|H| = 0.5 就代表輸出是 0.5 V 有效值；若相位為 −30°，在同一頻率下輸出峰值比輸入晚到週期的 30/360。這種延遲以角度表示，換到另一頻率時相同角度對應的秒數會不同，所以「相移」不能直接當固定時間延遲。

來源：06-電路學-下 §7.1–§7.2、§7.4–§7.5。

推導：從阻抗分壓走到截止頻率與每十倍頻衰減

（a）轉移函數。低通輸出取自電容，所以直接套阻抗分壓：

H = ZC / (R + ZC) = [1/(jωC)] / [R + 1/(jωC)]

分子分母同乘 jωC，得到 H(jω) = 1 / (1 + jωRC)。其中 R 的單位是 Ω、C 是 F、ω 是 rad/s，因此 ωRC 無單位。假設元件理想、輸出端沒有額外負載，而且電路尺寸遠小於波長。

從更一般的角度看，分母 1 + jωRC 對應一個極點。它決定增益何時轉折，也決定相位最多轉過 90°；分子若再含 jωRC，則多出一個位於原點的零點，使高通在低頻端由零開始上升。極點與零點不是畫圖裝飾，而是分子分母中讓響應變小或改變斜率的代數結構。

（b）大小與相位。分母 1 + jωRC 的大小是 √(1 + (ωRC)²)，角度是 arctan(ωRC)，取倒數後：

|H| = 1 / √(1 + (ωRC)²)，∠H = −arctan(ωRC)。

高通輸出取自 R，得到 H(jω) = jωRC/(1 + jωRC)。它的大小為 ωRC/√(1 + (ωRC)²)，相位為 90° − arctan(ωRC)。

（c）截止頻率。令 ωRC = 1，可得 ωc = 1/(RC)，而 f = ω/(2π)，所以 fc = 1/(2πRC)。代回大小式得 |H| = 1/√2 = 0.707107。電壓增益的分貝（decibel, dB）是 20log10|H|，故 20log10(1/√2) = −10log102 = −3.010300 dB，相位為 −arctan(1) = −45°。因功率與電壓平方成正比，功率比用 10log10；兩個係數不同不是筆誤，這個點的功率正好剩一半。

（d）漸近斜率。當 ωRC ≫ 1，低通 |H| ≈ 1/(ωRC)。頻率乘 10 倍，大小變成 1/10，於是 20log10(1/10) = −20 dB。這就是一個極點在高頻端的 −20 dB/decade；它是遠離轉折點才準的漸近規則，不是截止附近的真值直線。

（e）時域與頻域的同一個極點。把電容電壓的微分方程除以 RC，齊次解留下 e−t/RC；在頻域中，同一個分母則是「一加上 jωRC」。因此 τ = RC 決定拖尾的衰減速度，而令 ωτ 等於單位量便得到截止角頻率，進一步回到前文的截止頻率公式。這不是兩條巧合公式，而是同一極點分別投影到時間與頻率。只要電路仍含該儲能狀態，指數尾端永遠趨近終值，理想一階響應不會在有限時刻突然完成。

自由實驗：移動 RC 截止頻率

Vs 正端 → R → 輸出節點；輸出節點 → C → 地；Vs 負端 → 地。選低通時輸出取電容兩端，選高通時輸出取電阻兩端；改變元件與相對截止位置，觀察同一個分壓回路如何改變增益與相位。

不要混淆

  • dB 對電壓比乘 20、對功率比乘 10；−3.010300 dB 同時代表 0.707107 倍電壓與 0.5 倍功率。
  • 截止頻率不是理想開關的邊界；通帶內已有小衰減，衰減帶也仍有非零輸出。
  • 波德圖折線是漸近線；在 fc 處真值比通帶基準低 3.010300 dB，不能直接拿折線當精確值。
  • 低通與高通可以是同一串聯 RC，只是輸出端點不同；不可只看元件清單判斷種類。
  • 一階 RC 的時域 τ 與頻域 fc 描述同一動態，不是兩套互不相干的參數。
  • 被動濾波器接上負載後會改變等效阻抗與 fc；空載公式不能保證帶載結果不變。
  • 低通的高頻輸出變小，是輸出節點在阻抗分壓中分不到電壓；能量可能回到來源或在電阻耗散，不能籠統說成被電容消滅。
  • 一個實極點最多貢獻四分之一週期的相位轉折；量到更大的總相移通常表示還有其他極點、零點或延遲。

可觀察證據：拿什麼量、量到什麼

用函數產生器輸入固定振幅弦波並逐點掃頻，以雙通道示波器同時量 Vin、Vout 的峰對峰值與過零時間差。振幅比能找出輸出降到 70.7 % 的 fc，相鄰十倍頻的 dB 差能檢查高頻斜率，時間差除以週期可換成相位。這些證據能證明實際電路的截止頻率、通帶增益、衰減趨勢與相移；卻不能證明R、C 各自的標稱值，因頻率響應主要給出乘積 RC，也不能保證理想模型涵蓋訊號源輸出阻抗與負載。

示波器探棒的輸入電容會並到被測節點；對 0.1 µF 影響通常很小，對 100 pF 級電路卻可能直接改變被測物。一般三用電表量不到相位，交流檔頻寬也不足以驗證高頻響應。若輸入不是弦波，還要逐一考慮其頻率成分，不能把單一頻率的 H 當成整段波形的直接讀值。

量測時還應先把訊號源設定為同一輸入振幅，並記錄源的 50 Ω 輸出阻抗是否與 R 串聯。若每個頻點的輸入本身都在變，只看 Vout 會把源的變化誤認為濾波器特性；應使用 Vout/Vin 的比值。反過來，即使比值吻合理論，也只支持小訊號線性範圍內的模型，不能證明元件在大振幅、溫度漂移或超過額定值時仍維持相同參數。

若要驗證拖尾，可把輸入改成週期足夠長的方波，觸發在上升緣並量輸出距終值的差如何逐次縮小；低通會呈充放電曲線，高通則在邊緣後回到基準。這能支持同一時間常數控制暫態，卻不能用單次方波證明整段頻率響應，也不能把示波器看似貼住終值的有限解析度誤認為數學上已完全到達。

連到哪門課

信號與系統把 H(jω) 擴充成系統頻率響應；控制系統用波德圖判斷增益裕度與相位裕度；通訊系統用濾波器限制頻道與雜訊頻帶。主動濾波器的緩衝、增益與高階近似留給電子學。轉移函數與極點的數學前置可回看工程數學 08 拉氏轉換；下一章則加入電感，觀察二階電路如何集中選取一段窄頻率。
