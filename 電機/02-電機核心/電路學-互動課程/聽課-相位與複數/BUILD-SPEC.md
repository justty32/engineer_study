# 相位與複數聽課：建置契約

本輪只做兩堂主課，各至少 4,500 個可說出的中文字量；首版第一堂 5,369 字、第二堂 5,852 字，按每分鐘 240–280 字估算約 19–22 與 21–24 分鐘；圖像停靠與人工暫停另計。繁中口語正文為唯一計時來源。

## 檔案與資料介面

`lesson-data.js` 與供人閱讀的 `完整口語稿.md` 由講稿作者唯一寫入；設定 `window.CIRCUIT_AUDIO = { lessons: [...] }`。每堂 `{id,title,summary,segments:[...]}`；段落 `{id,title,text,figure,checkpoint,audioSrc}`。text 為純口語字串；figure 為下列既定圖 id 或 null；checkpoint 為布林值，為 true 時朗讀結束必須停靠，按繼續才走下一段。audioSrc 預設空字串；有實際合成音檔時才填本機相對路徑。段落 ID 穩定使用 p1-01 等與 p2-01 等。每堂約 8–10 段；完整複數加減乘除為第二堂主課，不能藏到折疊詳解。

頁面 `index.html`、`audio-course.css`、`audio-course.js` 由建置者唯一寫入。使用原生 HTML/CSS/JS；原課 app.js/styles.css 不變。無遠端資源、點陣圖、外加依賴；所有圖使用 inline SVG。講稿可讀可複製，無語音也能學習。

## 圖與實驗契約

圖 1 `phase-time`：週期 20 ms、50 Hz；參考 cos(ωt)，比較 cos(ωt+φ)。相位滑桿 `phase-angle` 範圍 −180 至 180°，級距 15°，預設 +90°。顯示相對參考超前／落後與 Δt=−φT/360°；+90° 峰值向左移 5 ms、−90° 向右移 5 ms、0° 同相。座標橫軸時間（ms），縱軸歸一化振幅；兩條不同線型、文字標籤。

圖 2 `phase-angle-view`：一週 360° 與四分之一週的對照，餘弦慣例、時間向右、正角超前；參考零點可以平移但相位差不變。靜態圖，無輸入。

圖 3 `complex-plane`：實部水平、虛部垂直；z=3+j4，大小 5、角度 53.13°；j 為逆時針四分之一圈，j²=−1。靜態圖。

圖 4 `complex-add`：a=3+j4、b=1−j2；a+b=4+j2、a−b=2+j6。同分量加減，以首尾相接圖表示。靜態圖。

圖 5 `complex-multiply`：a=2∠30°、b=3∠20°；乘=6∠50°、除=(2/3)∠10°；展示縮放與轉角。補充直角乘除 (3+j4)(1−j2)=11−j2；(3+j4)/(1−j2)=−1+j2。靜態圖。

圖 6 `circuit-example`：同頻穩態、峰值慣例、V=10∠0° V，串聯 R=3Ω 與感抗 j4Ω；Z=3+j4=5∠53.13° Ω，I=2∠−53.13° A=1.2−j1.6 A，電流落後電壓。V_R=3.6−j4.8 V、V_L=6.4+j4.8 V，相加 10+j0 V。圖中標閉合回路、電流參考方向與電壓參考極性；折疊推導只補已在語音主課教過的細節。

## 播放器契約

首次手動開始；選堂與選段落停止舊聲音；支援開始、暫停、繼續、重播本段、下一段、語速 0.7–1.2（預設 0.9，記住使用者偏好，音檔播放亦套用 playbackRate）。語音段落結束若 checkpoint=true，狀態必須為看圖停靠，不能自動前進；提示圖 id 與看什麼。一般段落可自動連播。下一段是明確使用者導航。

有 audioSrc 時優先 HTMLAudioElement 播放；沒有時用 speechSynthesis。語音 voice 非同步載入，偵測 zh-TW 優先、其次中文；無中文 voice 或不支援時明確禁用開始並提供講稿。不可偷偷使用英文 voice。onerror、取消、暫停、重播需避免舊 callback 前進；繁中聲音不代表指定角色。聲音選項與狀態明示來源，生成音檔完成前不可聲稱已有角色音檔。

## 驗收

獨立驗收者驗五項：正文時長與概念完整；所有算例獨立重算；語音狀態/停靠與降級；連結/UTF-8/wf-lint/原課樣式同步；可用 headless 桌機與手機視覺及互動。不支援實際出聲或角色音檔的部分記待人工。

## 2026-10-14 音檔播放器增修

逐段真音檔採原生 audio controls，進度條與時間僅代表當前段實際檔案；段尾照原checkpoint停住，未按繼續不載下一段。拖到檔尾也必須停靠，不建立虛構全堂時間軸。瀏覽器朗讀語速維持0.7–1.2倍；真音檔獨立倍速提供0.75、0.9、1、1.1、1.25、1.5、1.75、2倍，保存偏好並套playbackRate與保留音高；每段可下載供外部播放器開啟。

新增audio-manifest.js設定window.CIRCUIT_AUDIO_ASSETS={sample:{src:'audio/sample.mp3',label:'官方音色短試音'},segments:{}}；segments之後按p1-01等穩定ID映射{src,duration}，duration僅實測秒。未有segment音檔維持瀏覽器TTS且明示無逐秒拖曳；有檔才顯示段落audio controls。短試音複製已產生的34.8秒sample.mp3到audio/，獨立控制、倍速與下載，不掛任何教學段ID。試音與主課互斥播放，停止一個再啟動另一個。整課生成已獲使用者授權；由隊長驗證每段有效MP3後原子更新manifest，完成數只算已存在且有效的19段ID，不計sample。

本機預覽需支援 HTTP byte Range，否則 Chromium 可能顯示音長卻不能seek。使用本課標準庫腳本，從repo根執行：

```sh
python3 '電機/02-電機核心/電路學-互動課程/聽課-相位與複數/preview_server.py'
```

預設8876，固定綁127.0.0.1且只服務本repo；網址沿用http://127.0.0.1:8876/電機/02-電機核心/電路學-互動課程/聽課-相位與複數/index.html。此服務支援GET/HEAD、單一bytes Range 206與無效範圍416；不可改用缺少Range的簡單HTTP伺服器替代此音訊預覽。直接以file開教材亦須經實測記錄，不用假定線上hosting行為。
