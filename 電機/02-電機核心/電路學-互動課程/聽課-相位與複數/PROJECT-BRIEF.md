# 相位與複數運算：邊玩邊聽試作

讀者已會歐姆定律及電容、電感等基礎；真正缺口是相位與複數運算。由時間差、參考基準建立相位，再教複數座標、大小角度、加減乘除，最後用串聯 RL 算例回到電路。工程數學於用到時插入；長期順序是電路分析 → 電子學 → 電磁學，本輪不擴做後兩門。

語音以慢講、具體例子、有意義回顧降低資訊密度。每個概念群至少 10–15 分鐘，首版兩堂分別約 19–22 與 21–24 分鐘，按正文計時而非停頓灌水。遊戲中聽，必要時明確指定圖號與觀察重點；停靠後須手動繼續。視覺頁大圖短句，完整符號演算可摺疊，但複數主概念與運算不列選讀。

本機來源：上層 09-弦波與相量.html（相位、同頻限制、峰值慣例），10-阻抗與交流穩態.html（阻抗與 RL），共通基礎數學互動課程 09-複變入門.html（複數）。原筆記 06-電路學-上 §4.1 為相量來源。數值為明示的教學選例，不是實際元件量測。術語採相位（phase）、相量（phasor）、複數（complex number）、實部／虛部、直角式／極式；首次出現附英文與白話，不預設讀者會歐拉公式。

可觀察成果：能用相同特徵點判斷超前／落後；選擇直角式做加減、極式做乘除；算出串聯 RL 電流與相位，說明限制。示波器雙通道可驗證同頻時間差，普通電表不能確認相位。0°、±90°、180° 為邊界。

使用者指定中文初音未來風格聲音，中文效果不佳可試胡桃；角色音檔依實際模型與參考素材，不以系統語音冒充。現有 Qwen3 官方音色 34.8 秒短試音，以獨立原生播放器提供拖曳、倍速與下載；它不是完整課程或角色配音。19 段完整課程暫用瀏覽器朗讀，未有實際音檔時不提供虛構逐秒時間軸；逐段音檔接點已備妥，整課生成已獲使用者授權，將逐段完成並接入。可離線閱讀，系統語音則依作業系統及瀏覽器服務；本課程增修不發布、不安裝依賴、不新增圖片。
