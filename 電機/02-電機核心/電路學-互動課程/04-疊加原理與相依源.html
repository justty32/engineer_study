04・把多個來源拆開算，再看清不能拆的量

疊加原理與相依源：線性讓多源問題可以分工處理

同一個節點同時被電壓源與電流源推動時，不必硬把所有作用一次看完。只要電路是線性的，就能逐一保留獨立源、求出電壓或電流響應，再做帶正負號的代數相加；但相依源不能關掉，功率也不能照樣相加。

這章假設已懂：02 KCL 與 KVL、03 節點與網目分析，以及線性的可加性與齊次性。

痛點：兩個源同時推同一個節點，到底誰造成多少？

節點法當然能一次解出答案，但它只告訴你總結果，不一定讓你看見每個來源各自貢獻多少。更麻煩的是，初學者常把「關掉其他源」理解成把元件刪除，或看到電壓可以相加，就順手把功率也相加。這些錯誤會在含有受控放大作用的電路中放大：一旦把相依源也歸零，原電路的內部關係已經被改壞，所得結果不再代表任何有效分量。

線性（linearity）同時包含齊次性與可加性。齊次性是輸入乘上一個常數 k，響應也乘 k；可加性是輸入一與輸入二同時存在的響應，等於兩個單獨響應的代數和。疊加原理（superposition）正是把這個數學性質拿來拆電路。它適用的是支路電壓與電流，不是所有從它們再算出的量。

白話直覺：先讓每個獨立源單獨發言

可以暫時把多源分析想成錄音混音：先聽每一軌，再把振幅相加；比喻到此為止，真實電路中所有來源始終同時作用，並沒有輪流通電。精確作法是保留一個獨立源，其他獨立源把「源值設為零」後換成其理想內阻：獨立電壓源為 0 V，所以成為短路；獨立電流源為 0 A，所以成為開路。

因果鏈從電源與地開始。Vs 的負端接參考地，正端經 R1 到節點 A；Is 向 A 注入電流；A 再經 R2 回到地。保留 Vs 時，電流沿 Vs 正端、R1、A、R2 與地形成閉合回路，A 由分壓決定。保留 Is 時，電荷由電流源注入 A，再分別經 R1 與 R2 流向地，兩條回路都閉合，A 的電位由並聯電阻承接的電流決定。兩個 A 電壓相加就是同時接上兩源的結果。

相依源（dependent source）是由電路內某個電壓或電流控制的源，不是外加的獨立輸入。電壓控制電壓源（voltage-controlled voltage source, VCVS）、電流控制電壓源（current-controlled voltage source, CCVS）、電壓控制電流源（voltage-controlled current source, VCCS）與電流控制電流源（current-controlled current source, CCCS）都必須保留。它們表達的是內部輸入與輸出的線性關係，也是電晶體小訊號模型與運算放大器模型的骨架。

做代數相加時還要保留方向。若某個來源把 A 拉向負電位，它的 VA 分項就是負值，不可先取大小再相加。電流也要先約定流入或流出為正；同一條參考方向必須用到底。這和程式中替變數保留正負號相同：分項可以互相抵消，總響應甚至可能為零，但零總響應不代表每個來源都沒在供能。兩個來源仍可能各自送出或吸收功率，只是它們對該觀察量的線性貢獻剛好抵銷。

來源：06-電路學-上 §1.2、§2.6。

推導：分別求兩個響應，再用節點方程驗算

（a）固定拓樸與方向。Vs 正端 → R1 → 節點 A；電流源 Is 注入節點 A；節點 A → R2 → 地；Vs 負端 → 地。VA 是 A 對地電壓，單位 V；Vs 是獨立電壓源，單位 V；Is 是注入 A 的獨立電流，單位 A；R1、R2 是線性定值電阻，單位 Ω。假設導線與來源皆理想、元件不隨溫度改變，並採集總電路近似。

（b）Vs 單獨作用。令 Is = 0 A，理想電流源支路成為開路。R1 與 R2 串聯，流過兩者的電流為 Vs/(R1 + R2)，所以：

VA,V = Vs ⋅ R2 / (R1 + R2)

（c）Is 單獨作用。令 Vs = 0 V，理想電壓源成為短路，於是 R1 與 R2 都從 A 接到地。符號 ‖ 讀作「並聯」，不是絕對值也不是範數。等效電阻為 R1‖R2 = R1R2/(R1 + R2)，因此：

VA,I = Is ⋅ (R1‖R2)

（d）相加並直接驗算。線性保證 VA = VA,V + VA,I。若不拆源，直接在 A 寫流出電阻的電流等於注入電流：

(VA − Vs)/R1 + VA/R2 = Is

移項後得到 VA(1/R1 + 1/R2) = Vs/R1 + Is。展開前述兩個分項會得到完全相同的式子，這就是疊加不是近似技巧，而是線性方程的另一種解法。

（e）功率不能疊加。R2 的功率 P 單位 W，且 P = VA²/R2。代入兩個響應：

P = (VA,V + VA,I)²/R2 = VA,V²/R2 + VA,I²/R2 + 2VA,VVA,I/R2

最後的交叉項通常不為零，所以兩個單源功率相加不等於總功率。只有某一分項為零，或兩分項恰好使交叉項為零時才碰巧相等；那是特例，不是新規則。

自由實驗：拆開兩個源並比較功率

Vs 正端經 R1 到節點 A，Is 向 A 注入電流，A 經 R2 回到地，Vs 負端接地。調整四個量，觀察兩個分項電壓如何相加，以及功率為何還多一個交叉項。

不要混淆

  • 電壓與電流是線性電路的響應，可以做帶方向的疊加；功率含平方與交叉項，不是同一類量。
  • 歸零獨立電壓源的結果是短路，歸零獨立電流源的結果是開路；邊界來自理想內阻，不是把兩種源都拆掉。
  • 相依源表達電路內部的控制關係，不能歸零；獨立源才是疊加時逐一保留的外部輸入。
  • 疊加只保證線性範圍內成立；二極體或進入飽和的電晶體具有非線性，不能把其大訊號響應照搬相加。
  • 疊加是分析技巧，不是來源輪流工作的物理過程；真實電荷與能量流由所有同時接上的來源共同決定。
  • 齊次性是縮放一個輸入，可加性是合併不同輸入；兩者共同成立才叫線性，不能只驗其中一項就下結論。

可觀察證據：用電表分三次量節點電壓

可用高輸入阻抗三用電表量 A 對地電壓。先把電流源支路開路，量得 VA,V；再恢復電流源並把電壓源以低阻短路替代，量得 VA,I；最後接回兩個源，量總 VA。三次量測中，接線前都要先斷電，且不能把真實電源輸出端在通電時直接短路。

能證明什麼：若前兩次讀值的代數和與第三次在儀器誤差內一致，就能證明這個電路在當下電壓、電流與溫度範圍內呈線性，也能驗證源歸零後的拓樸判斷。不能證明什麼：這不能證明元件在更高電壓或更大電流時仍線性，也不能證明功率可疊加。要驗證功率，必須同時量 R2 兩端電壓與流過它的電流再相乘，不能把兩個單源功率表讀值直接相加。

量測誤差也要用同一種相加方式評估。三次讀值各有電表解析度、來源內阻與接線接觸電阻造成的不確定度，不能要求末位數完全相等；應先估計容許差，再看殘差是否明顯超出。若殘差會隨來源幅度系統性變大，可能是電阻自熱、電流源順從電壓不足或來源進入限流，而不是疊加定理本身失效。這些現象正好指出理想線性模型的適用邊界。

連到哪門課

電子學用 VCCS 等相依源表示電晶體的小訊號增益，運算放大器也可先以 VCVS 建模；這章只教模型如何參與線性方程，不處理工作點、飽和與元件物理。信號與系統則把疊加提升為線性系統的共同語言，卷積可視為把輸入拆成許多微小成分後累加響應。控制系統的小訊號模型、交流分析與雜訊分析也會重用相同觀念。

若要補齊齊次性、可加性及矩陣表示，可回到工程數學先修的向量與矩陣。下一章會把線性端口行為濃縮成戴維寧等效，讓「多源先拆開」進一步變成「複雜內部只留下兩個參數」。
