13・讓電感與電容只在一個頻率互相抵消

RLC 共振與品質因數：選得愈準，振鈴也愈久

串聯 RLC 可以在一個特定頻率讓兩種電抗互相抵消，使電流達到最大。本章從阻抗推導共振、品質因數與半功率頻寬，也把頻域的窄峰接回第 08 章時域的低阻尼。

這章假設已懂：12 頻率響應、08 阻尼比。

痛點：加一顆電感，為什麼就能只挑一個頻率？

RC 濾波器會隨頻率單調改變，沒有一個「只有這裡最強」的中心。加入電感後，感抗隨頻率上升，容抗隨頻率下降；兩者在某一點大小相等、符號相反，串聯總阻抗的虛部恰好消失。這不是元件不再作用：電感與電容各自仍可能承受很大的電壓，只是從源端看，它們的相量電壓互相抵消。

工程上不只要知道中心在哪裡，還要問峰有多尖、可接受頻帶多寬、離開中心後電流降多少，以及元件會不會因內部電壓放大而超過耐壓。這些問題由品質因數（quality factor, Q）和頻寬（bandwidth）量化。Q 高不是單純「品質好」；它同時意味著選頻窄、損耗低、元件電壓放大大，而且暫態能量要更久才耗盡。

白話直覺：兩個儲能元件輪流交棒，電阻負責把能量吃掉

可以暫時把電感與電容想成兩個來回交接能量的儲存槽；比喻到此為止，真實機制是電感磁場能量 (1/2)Li² 與電容電場能量 (1/2)Cv² 週期性交換。電壓源以地為參考，Vs 正端 → R → L → C → 地；Vs 負端 → 地，形成單一閉合回路。源持續供應交流能量，電流依序流過三個元件，R 每一週期把部分能量轉為熱。

低於共振時，1/(ωC) 大於 ωL，總電抗為負，電路呈容性；高於共振時，ωL 大於 1/(ωC)，總電抗為正，電路呈感性。共振點兩者相等，節點間的 L、C 電壓大小相同、相位相反，源看到的阻抗只剩 R，因此電流最大且與源電壓同相。若輸出取 R 兩端，這就是帶通：只有接近共振的頻率能產生大輸出。

R 愈小，每輪損失愈少，能量能在 L、C 間交換更多次，Q 就愈高。這也說明 Q 與第 08 章阻尼比 ζ 的關係：Q = 1/(2ζ)。頻域上高 Q 是尖銳選擇性，時域上低 ζ 是長久振鈴；兩者源自同一個損耗，不能靠調同一顆 R 讓兩邊同時變好。

從電源端觀察，一個週期先把能量送進磁場與電場，之後部分能量又回到源，只有 R 上的熱成為不可逆損失。Q 所比較的正是「場內可來回交換多少」與「每輪被耗掉多少」。因此加大 L、縮小 C 或降低 R 都可能提高 Q，但它們也會改變中心頻率、元件額定電流與耐壓，不能只盯著單一比值選料。

兩個半功率點提供比「峰看起來很尖」更可重現的界線。電流幅值降到峰值的 70.7 % 時，R 上功率變為一半；這並不是總能量突然少一半，而是固定源電壓下，總阻抗大小增為 √2R。下限處總電抗為容性，上限處總電抗為感性，兩側相位符號相反，正好夾住共振中心。

來源：06-電路學-下 §7.3、§6.1。

推導：從虛部歸零得到中心、頻寬與電壓放大

串聯阻抗為 Z = R + j(ωL − 1/(ωC))。R 單位 Ω，L 單位 H，C 單位 F，ω 單位 rad/s；假設元件線性、集總，並把電感繞線電阻與其他損耗合併進 R。

（a）共振頻率。令 Im(Z) = 0：ω0L = 1/(ω0C) → ω0² = 1/(LC) → ω0 = 1/√(LC)。因此 f0 = ω0/(2π)。共振時 |Z| = R，是串聯電路的最小阻抗。

（b）Q 的三種寫法。先定義 Q = ω0L/R。代入 ω0 = 1/√(LC)，得到 Q = L/(R√(LC)) = (1/R)√(L/C)。又因共振時 ω0L = 1/(ω0C)，兩側同除以 R，得到 Q = 1/(ω0RC)。所以：

Q = ω0L/R = 1/(ω0RC) = (1/R)√(L/C)

（c）半功率頻率。電流降到最大值 1/√2 時，電阻耗散功率剩峰值一半。由 I = Vs/|Z|，這要求 |Z| = √2R，進而要求 |ωL − 1/(ωC)| = R，也就是 ωL − 1/(ωC) = ±R。解二次方程得：

ω = ω0[√(1 + 1/(4Q²)) ± 1/(2Q)]

上、下兩根相減，正好得到角頻寬 B = ω0/Q；以 Hz 表示則 B = f0/Q。兩個半功率點在線性頻率軸並不以 f0等距，但其差仍精確等於 B。

中間代數可再拆開：將前述帶正負號的半功率條件兩邊乘上 ωC，得到以 ω 為未知量的二次式；再除以 LC，把係數改寫成自然角頻率與 Q，二次公式便給出括號內的根號項與正負項。正號根是上限、負號根是下限，兩根皆為正；相減時共同根號項消去，只留下自然角頻率除以 Q。這說明閉合式沒有假設高 Q，而常見的「中心左右各半個頻寬」只是高 Q 時在線性頻率軸上的近似。

（d）元件電壓放大。共振時 I = Vs/R，因此 |VL| = Iω0L = Vsω0L/R = QVs；同理 |VC| = QVs。兩者相位相反，所以 KVL 仍成立，卻各自可能遠高於源電壓。

（e）接回阻尼。第 08 章 α = R/(2L)、ζ = α/ω0，所以 ζ = R/(2ω0L) = 1/(2Q)。這直接證明頻率響應的尖峰與暫態衰減是同一組參數。

也可用極端值驗證式子：R 趨近零時，理想模型給 Q 趨近無限大、B 趨近零，且元件電壓放大無上限；這表示理想無損模型缺少真實寄生損耗，不表示可製造無限電壓。R 很大時 Q 降低、頻寬變寬，峰值相對背景不再突出；當 ζ ≥ 1，時間域已無振盪，共振選頻的直覺也幾乎失去用途。

自由實驗：調整共振尖銳度

Vs 正端 → R → L → C → 地；Vs 負端 → 地，輸出可視為 R 上電壓。調整 L、C、總串聯電阻與相對共振頻率，觀察中心、頻寬、阻尼、阻抗與相對電流一起變化。

不要混淆

  • 外部弦波持續驅動的共振看穩態；自然振盪由初始能量自行衰減看暫態，兩者共用 ω0但不是同一實驗。
  • 串聯共振使 |Z| 最小、電流最大；並聯共振常使輸入阻抗最大，結論不能直接互換。
  • ω0 是無阻尼自然角頻率；欠阻尼暫態的 ωd = ω0√(1 − ζ²)，兩者並不相等。
  • 高 Q 代表窄頻與長振鈴，不代表所有用途都更好；快速安定與銳利選頻需要取捨。
  • 共振時總阻抗只有 R，不代表 L、C 電壓為零；它們可各達源電壓的 Q 倍。
  • 本章 Q 是整個串聯電路的品質因數，實際元件資料表的 Q 還包含各自損耗模型。
  • 半功率是指 R 上平均功率降為峰值的一半，不是 L 與 C 的瞬時儲能都同時減半。
  • 提高 Q 能改善選擇性，卻也縮窄容許頻率漂移並延長安定時間；接收機選頻與快速跳頻的需求邊界不同。

可觀察證據：拿什麼量、量到什麼

用函數產生器驅動串聯 RLC，以雙通道示波器量源電壓與 R 上電壓。掃頻找到 VR 最大處就是 f0；再找降到峰值 70.7 % 的兩個頻率，兩者相減得到 B，並由 Q = f0/B 反推實際 Q。這些量測能證明中心頻率、半功率頻寬、整體損耗形成的 Q，以及共振附近的選擇性；卻不能證明L、C 各自數值，因 f0只限制乘積 LC，也不能把量得的 R 全歸因於外接電阻。

量測 Q 往往低於理想值，因為電感繞線電阻、電容等效串聯電阻與訊號源輸出阻抗都被算進總 R。這個差距能揭露損耗，卻不能單靠一次掃頻分離每一項來源。共振時可另量 L 或 C 兩端電壓驗證 Q 倍放大，但先確認示波器接地方式與元件耐壓；探棒地夾接錯節點可能直接短路電路。

耐壓警告：先以低振幅驅動並估算 Q 倍後的元件端電壓，確認仍低於電容、電感絕緣與探棒額定值，再逐步增加輸入。量到 L、C 兩端大小相近且相位相反，能支持共振時的相量抵消；卻不能因源端電壓不高就宣稱元件安全，也不能以兩個大讀值直接相加成源電壓。

掃頻步距也會限制證據強度。若理論頻寬只有 15.92 Hz，卻每隔 100 Hz 才量一點，可能完全錯過峰值，量到的中心與 Q 都會偏差；應先粗掃定位，再在半功率區間細掃。同樣地，函數產生器的輸出振幅應保持不變，否則峰值變化可能來自訊號源，而不是 RLC。量到窄峰只能支持該振幅與溫度下的線性模型，不能證明磁芯未飽和或元件參數不隨頻率改變。

連到哪門課

共振選擇性用於收音機選台、無線充電線圈、EMI 濾波器與石英晶體；控制系統則把共振峰視為阻尼不足與相位裕度風險。二階微分方程、ζ 與暫態型態可回看工程數學 07 常微分方程。下一章的變壓器也使用耦合線圈，但目的轉為用共同磁通交換能量與轉換阻抗。
