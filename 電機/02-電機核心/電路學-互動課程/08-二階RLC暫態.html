08・兩個儲能狀態如何產生振鈴

二階 RLC 暫態：用阻尼比預測會不會振、振多久

電感與電容同時存在時，能量可以來回交換，響應不一定只會單調靠近終值。這章從串聯回路推到特徵根，再用阻尼比 ζ 把根的位置翻譯成可量測的振鈴、衰減與超越量。

這章假設已懂：07 一階暫態 RC 與 RL、二階常微分方程的特徵根，以及阻尼比 ζ 與自然頻率 ωn 的意義。

痛點：多放一個儲能元件，為什麼波形會來回越過終值？

一階 RC 或 RL 只有一個獨立狀態，差距通常沿單一指數縮小；加入第二個獨立儲能狀態後，電感電流與電容電壓必須同時滿足連續性。它們可能把能量互相交還，使電壓或電流越過終值再折返。只背「R 大衰減快」會在過阻尼區犯錯：R 超過臨界值後，兩個實根中的慢根反而靠近原點，尾巴拉得更長。

二階電路（second-order circuit）是具有兩個獨立儲能狀態、由二階方程描述的電路，不等於看到兩顆儲能零件就算二階。兩顆理想電容若直接並聯，被迫維持同一電壓，仍只有一個獨立狀態。本章假設元件線性、時不變且可用集總模型，來源切換後的自然響應由固定 R、L、C 決定。

白話直覺：L 與 C 交換能量，R 每次都扣掉一部分

可暫把 L 與 C 想成互相傳球，R 像每次傳遞都收過路費；比喻到此為止。精確地說，電感儲存磁場能量 WL = (1/2)Li²，電容儲存電場能量 WC = (1/2)Cv²，電阻以 i²R 將能量不可逆地轉成熱。會不會反覆交換，取決於交換速率相對於耗散速率，而不是元件有沒有「想振」。

因果鏈從電壓源與地開始：Vs 正端 → 開關 → R → L → 節點 A；節點 A → C → 地；Vs 負端 → 地。開關閉合後回路成立，來源先推動電流，L 的磁場能量增加，同時電荷到達 C 的極板使 A 點電壓上升。當 C 電壓增大到阻擋原電流時，L 已儲存的磁能仍維持同方向電流，於是 C 可能充過終值；接著 C 放電又把能量送回 L。R 在每次循環中耗能，波峰逐次縮小，最後節點電壓與電流抵達穩態。

無阻尼自然頻率 ω0 說明 L 與 C 若沒有耗散時交換得多快；衰減因子 α 說明包絡縮得多快；阻尼比 ζ = α/ω0 比較這兩種速度。ζ 小於 1，交換來得及發生，故振盪；ζ 等於 1，剛好不越界且最快；ζ 大於 1，耗散與限制太強，只剩兩種指數衰減。

來源：06-電路學-下 §6.1–§6.2。

推導：從 KVL 到特徵根與三種響應

（a）建立方程。串聯回路電流為 i，單位 A；來源 vs 與電容電壓單位 V；R 單位 Ω；L 單位 H；C 單位 F；t 單位 s。沿閉合回路寫克希荷夫電壓定律：

L ⋅ di/dt + Ri + (1/C)∫i dt = vs

第一項是電感電壓，第二項是電阻壓降，第三項是由電荷積分得到的電容電壓。兩邊對 t 微分，積分項變回 i，得到 L ⋅ d²i/dt² + R ⋅ di/dt + i/C = dvs/dt。求自然響應時令右側為 0；這表示研究來源固定後由初始儲能造成的部分，不表示實際電源被隨意刪除。

（b）求特徵式。令 i = Aest，其中 A 由初始條件決定，s 的單位是 1/s。代入齊次方程，公共因子 Aest 非零，可以約掉：

Ls² + Rs + 1/C = 0

除以 L 得 s² + (R/L)s + 1/(LC) = 0。對照標準型 s² + 2αs + ω0² = 0，可讀出 α = R/(2L)，單位 1/s；ω0 = 1/√(LC)，單位 rad/s；ζ = α/ω0，無因次。二次公式給 s1,2 = −α ± √(α² − ω0²)。

（c）判別式翻譯成波形。若 ζ > 1，根為兩個相異負實數，解為 i = A1es1t + A2es2t，只衰減不振盪。若 ζ = 1，根重合為 −α，解為 i = (A1 + A2t)e−αt。若 0 < ζ < 1，根為 −α ± jωd，解為 i = e−αt(A1cos ωdt + A2sin ωdt)，其中 ωd = ω0√(1 − ζ²)。數學課常寫虛數單位 i，電機寫 j，因為 i 留給電流。

（d）找臨界電阻。臨界條件 α = ω0，所以 R/(2L) = 1/√(LC) → R = 2L/√(LC) = 2√(L/C)。這也使 ζ = R/R臨界，因此只要比較實際 R 與臨界值就能分類。

（e）把 ζ 接到可見的超越量。標準欠阻尼步階響應的超越量 OS = e−πζ/√(1−ζ²)。ζ 愈小，負指數絕對值愈小，第一次超越愈大；ζ 靠近 1 時 OS 趨近 0。這個式子假設是標準二階、零點不顯著且初始條件符合步階模型，不能直接套到任意高階電路。

這個指數並非經驗擬合。把步階響應相對終值的誤差寫成衰減包絡乘弦波，對時間微分並令斜率為零，第一個峰值出現在 tp = π/ωd。把此時刻代回包絡 e−αt，再用 α = ζω₀ 與阻尼角頻率的關係，便得到上一行的超越量式。所以公式同時用了欠阻尼、標準步階、穩定系統與峰值確為第一個極值等前提；若初始能量改變峰的方向，仍須由完整解判讀。

（f）連到品質因數。串聯 RLC 的 Q = ω0L/R。將 ω0 = 1/√(LC) 與 ζ = R/(2Lω0) 代入，得到 Q = 1/(2ζ)。因此高 Q 的銳利選頻與小 ζ 的長振鈴，是同一組 R、L、C 在頻率域與時間域的兩種描述。

過阻尼時要看離原點最近的根，而不是只看 α。把慢根改寫成「負的自然角頻率平方，除以 α 加上根號項」後，可見 R 增大使 α 增大、分母變大，慢根的絕對值反而縮小；它所對應的指數項最晚消失，因而主宰安定時間。臨界阻尼只是所有不振盪解中最快，欠阻尼解若允許短暫越過終值，首次到達終值可以更早。

自由實驗：調整 R、L、C 並判讀阻尼

電壓源正端依序經 R、L 到節點 A，C 從節點 A 回到地，電源負端也接地。拉動元件值，觀察交換速度、衰減速度與臨界邊界如何一起改變。

不要混淆

  • ω0 是只由 L、C 決定的無阻尼自然頻率；ωd 是欠阻尼時真正看到的振盪頻率；外部驅動頻率則由訊號源決定，三者邊界不同。
  • ζ 是無因次的速度比；α 是包絡衰減率，單位 1/s。兩者相關但不是同義詞。
  • 電阻增大使 α 增大只描述包絡係數；跨過臨界點後慢根靠近原點，整體安定反而更慢。
  • 臨界阻尼是「不產生超越的前提下最快」，不是容許振盪時的絕對最快。
  • 兩顆儲能元件不必然形成二階；階數取決於獨立狀態數，直接並聯電容可能共享同一狀態。
  • 本章自然振盪靠初始儲能，會逐漸停止；第 13 章共振由外部弦波持續餵能量，兩者不是同一現象。
  • 首次到達時間與安定時間的邊界不同；較早穿越終值不代表之後已留在容許誤差帶內。

可觀察證據：用示波器從振鈴反推參數

以函數產生器的方波驅動串聯 RLC，示波器量節點 A 對地的電容電壓。相鄰波峰時間差 Td 可給 ωd = 2π/Td；相鄰同方向峰值相對終值的振幅 A1、A2 可給對數衰減率 δ = ln(A1/A2)，再以 ζ = δ/√(4π² + δ²) 反推阻尼比。量電流則要用電流探棒，或串接已知的小取樣電阻再由壓降換算。

能證明什麼：這些量測能支持主要響應具有衰減包絡，並估出 ωd、ζ 與超越量；改換 R 後也能驗證欠阻尼、臨界附近與過阻尼的轉換。不能證明什麼：只由 α 與 ω0 不能各自唯一求出 R、L、C，也不能證明實物嚴格只有二階；更高階寄生模式可能只在更短或更長時間窗出現。

真實電感的繞線電阻會加進總 R，電容的等效串聯電阻與探棒負載也會增加耗散，所以實測 ζ 往往比只用外接 R 計算的大。示波器頻寬不足還可能抹平第一個尖峰。要把模型與元件值連起來，需另以 LCR 表在相關頻率量 L、C 與等效電阻，不能靠單張波形做過度推論。

連到哪門課

控制系統用 ζ 與 ωn 設計超越量與安定時間；開關電源輸出濾波器、繼電器與馬達驅動的尖峰、數位線路寄生 L、C 造成的振鈴，也先以二階模型估算。第 13 章會把同一組參數改從頻率響應觀看，辨認 Q 與選頻寬度。

二階特徵根的數學細節見工程數學先修的常微分方程；把初始條件一起搬進代數域的標準工序見拉氏轉換。在 s 域中把 L 換成 sL、C 換成 1/(sC)，再做部分分式與反拉氏，仍要回頭檢查元件初值與能量是否合理。

實際設計還要在「快」與「不振」之間選擇，而不是永遠追求某個單一 ζ。量測前端可能寧可慢一點以免超越量觸發保護；伺服控制可能容許少量超越以縮短到達時間；數位電源則會同時限制峰值、安定時間與元件應力。二階模型提供共同語言，最終規格仍由裝置能承受的電壓、電流與誤判風險決定。
