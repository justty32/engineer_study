11・分清做功、來回搬運與設備容量

交流功率與功因：為什麼瓦特、var 與 VA 都不能少

交流負載可能一邊消耗能量，一邊把儲能送回來源，所以單看電壓乘電流不夠。實功描述真正轉換的能量，無效功率描述往返搬運，視在功率則決定線路與變壓器要承受多大電流。

這章假設已懂：10 阻抗與交流穩態，以及09 弦波與相量的有效值與相位。

痛點：無效功率既然平均為零，為什麼還會增加成本？

感性負載的電流與電壓不同相，瞬時功率 p(t) = v(t)i(t) 會上下起伏，部分時刻甚至為負。負號不是馬達突然免費發電，而是磁場或電場正在把先前儲存的能量送回來源。這部分一週期淨值為零，卻仍需電流在導線中往返；導線的 I²R 損耗、斷路器額定與變壓器容量都要為它付出代價。

實功（real power） P 的單位 W，表示平均轉成熱、光或機械功的速率；無效功率（reactive power） Q 的單位 var，表示來源與儲能元件間的往返交換尺度；視在功率（apparent power） S 的單位 VA，是有效值電壓與有效值電流之積。功率因數（power factor, pf） = P/S，說明設備電流中有多少比例對實功有用。

白話直覺：貨物沒送達，卡車仍佔道路並燒掉線損

可暫把 Q 想成在倉庫間來回但沒有淨交付的貨，車流仍佔道路；比喻到此為止。精確地說，L 與 C 每半週儲能、另半週釋能，平均能量轉換為零，但支路瞬時電流不為零。電阻上的耗損取決於總電流平方，所以 Q 不直接做功，仍會間接造成實際損耗。

因果鏈從交流電源與地開始：電源正端 → 配線電阻 → 感性負載 → 電源負端與地，形成閉合回路；校正電容則並聯在負載兩端。來源送出的電流一部分在負載電阻轉成熱或機械功，另一部分建立磁場後返回。並聯電容在相反半週提供方向相反的無效電流，使上游配線只需承擔兩者抵消後的電流；負載端電壓與原本的 P 不變，來源看到的 Q、S 與線電流下降。

若總負載感性，Q > 0，電流落後電壓，稱落後功因；若容性，Q < 0，電流超前電壓，稱超前功因。純阻時 θ = 0、Q = 0、pf = 1。功因校正不是創造能量，也不是讓負載少做功，而是讓無效電流在負載附近循環，不必一路經過上游導線與變壓器。

來源：06-電路學-上 §4.4。

推導：從瞬時功率展開到校正電容

（a）平均實功。令 v(t) = Vmcos(ωt)，i(t) = Imcos(ωt − θ)。Vm 單位 V、Im 單位 A、ω 單位 rad/s、θ 是電壓相對電流的相位差。利用 cos A cos B = [cos(A−B) + cos(A+B)]/2：

p(t) = (VmIm/2)[cos θ + cos(2ωt − θ)]

第一項是常數，第二項以兩倍頻率振盪且整週期平均為 0，因此 P = (VmIm/2)cos θ。又 Vrms = Vm/√2、Irms = Im/√2，所以 P = VrmsIrmscos θ。這裡假設電壓電流都是同頻純弦波且已達穩態。

（b）三個功率。定義 Q = VrmsIrmssin θ、S = VrmsIrms。cos 與 sin 互相正交，故：

S² = P² + Q²，pf = cos θ = P/S

複數功率寫成 S = P + jQ = VrmsIrms*。星號代表複數共軛，確保感性負載在本課被動符號慣例下得到正 Q。P、Q、S 雖量綱都等於 V⋅A，分別用 W、var、VA 是為了避免把正交成分直接算術相加。

（c）為什麼電容並聯。並聯元件共用負載電壓，不改變原負載端電壓，故理想電壓源下原負載自己的 P、Q 不變。電容 XC = 1/(ωC)，提供 QC = −Vrms²/XC = −ωCVrms²，從感性總 Q 中扣除。若串聯電容，負載電壓會改變，已不是單純校正上游電流。

（d）求校正元件。目標 pf2 給 θ2 = arccos(pf2)；目標 Q2 = P ⋅ tan θ2；所需補償量 QC = Q1 − Q2。感性負載需要電容：

C = QC/(ωVrms²)

C 單位 F，ω 單位 rad/s。容性負載若需反向校正，則並聯電感；實務須考慮電容容差、切換階級、諧波與共振，不能把理想公式當成固定萬用值。

（e）真正省下的量。校正前後 P 不變；新的 S2 = P/pf2，I2 = S2/V。配線損耗與 I² 成正比，因此損耗比 (I2/I1)² = (pf1/pf2)²。省下的是上游電流、配線損耗與設備容量，不是負載完成工作的能量。

自由實驗：調整負載與目標功因

有效值交流源經上游配線到負載，負載以 R + jX 表示並回到電源；補償元件並聯在負載兩端而共用同一電壓。調整負載與目標，觀察三種功率、校正元件及線損比例。

不要混淆

  • 無效功率平均為零，並非已浪費掉的功率；它佔用電流並間接增加 I²R 線損，邊界不同。
  • W、var、VA 量綱相同但角色不同；P 與 Q 是正交成分，S 由 √(P² + Q²) 合成，不能直接相加。
  • 低功因不是單純「耗電多」，而是電壓與電流相位不同，使相同 P 需要更大的 S 與電流。
  • 功因校正元件並聯以保持負載電壓；串聯補償會改變負載端條件，不是同一作法。
  • 補償到超前功因仍可能受罰，且負載變動會使固定電容補過頭；目標 1 不等於永遠最佳。
  • pf = cos θ 只完整描述純弦波位移功因；含諧波時還有失真因數，本章模型不涵蓋非弦波功因。

可觀察證據：功率計與電流勾表各自證明什麼

功率計或瓦特表同時取樣電壓與電流，可直接顯示 P、S 與 pf；具四象限或落後／超前標示的機型也能顯示 Q 的符號。能證明什麼：它能驗證實際實功、視在功率、功因，以及接入補償元件後 P 近似不變而 S、I 下降。不能證明什麼：沒有方向標示時，單一 pf 大小不能判斷負載感性或容性；儀表讀值也不能單獨證明內部是哪一顆 L 或 C 造成相位。

普通三用電表只能分別量有效值電壓與電流，兩者相乘得到 S，不是 P，因此完全量不到功因。夾式電流勾表可在不斷線下量同一條上游導線；在本例校正前後會由 17.6 A 降到約 14.8 A，直接支持上游電流下降，但單獨這個讀值仍不能證明 P 未變，必須與功率計的 P 讀值交叉核對。

也可用示波器量電壓與取樣電阻所代表的電流，再由時間差估 θ；然而波形若含諧波，單一過零相位不足以給真功因。實務電容櫃還可能與系統電感形成共振並放大諧波，因此「50 Hz 或 60 Hz 算對電容量」不能證明所有頻率都安全，需用電能品質分析儀檢查諧波與四象限功率。

連到哪門課

電力系統用 P、Q 調度電壓與容量；電機機械中的馬達是典型感性負載；變頻器、UPS、發電機與變壓器都以 VA 額定而不只看 W。第 14 章會把功率公式擴展到平衡三相，仍保留實功、無效功率與功因的區分。

這裡的積化和差來自三角函數恆等式，可回工程數學先修的級數與泰勒查閱相關三角工具。更進一步的電力電子學會處理整流器造成的非弦波電流、主動功因校正與諧波標準；本章只建立線性負載、同頻純弦波、穩態下的基準模型。

選補償設備時不能只把公式算出的 µF 四捨五入後永久接上。馬達負載會隨產量改變，固定電容可能在輕載時造成超前功因；分段投切的電容櫃會依量測 Q 增減級數，並保留避免頻繁切換的遲滯。若系統有大量變頻器，還要檢查電容與電網電感是否把某次諧波放大，必要時使用串聯電抗器或主動濾波。

帳務邊界也要分清：住宅電費常主要按實功電能計價，工業用戶則可能另受契約容量、需量與低功因條款影響。功因改善未必讓負載本身的度數明顯下降，卻可能釋放變壓器與饋線容量並降低廠內線損。是否划算必須用實際費率、負載週期與設備成本評估，不能從 pf 一個數字直接下結論。
