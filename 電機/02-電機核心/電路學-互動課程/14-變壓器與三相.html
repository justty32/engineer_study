14・用共同磁通換電壓，再用三個相位穩定送能量

變壓器與三相：從線圈耦合走到工業供電

變壓器不靠導線直接相連，而靠兩組線圈共享隨時間改變的磁通，把電壓、電流與阻抗依匝比轉換。三相系統再以三個相差 120° 的電源持續送出平穩功率，形成輸配電與馬達的共同語言。

這章假設已懂：10 阻抗、11 交流功率、06 電感。

痛點：兩邊沒有導通，功率怎麼跨過去，三條線又為何多出 √3？

看到變壓器一次側與二次側彼此絕緣，很容易把它誤想成無線「複製」電壓；其實一次側電流建立隨時間改變的磁通，磁通穿過二次側線圈後依法拉第定律感應電壓，負載接上才形成二次側閉合回路並取走能量。匝數只決定轉換比例，不會創造功率。

三相的 √3 也不是額外背誦規則。線電壓是兩個相差 120° 的相電壓之差，必須用相量相減；Y 接與 Δ 接因為線端接在不同位置，√3 分別出現在電壓或電流。若把線量與相量混用，計算會差 √3，功率甚至差三倍。

白話直覺：共同磁通是匯率，三相差值決定線端讀值

可把理想變壓器暫時想成只更換電壓與電流單位的匯兌站；比喻到此為止，真正機制是一次側交流電壓驅動激磁磁通，兩組匝數 N1、N2包圍同一個 Φ，磁通變化率在各匝感應電壓。一次側電源以其回線為參考，電源 → 一次線圈 → 回線形成閉合回路；二次線圈 → 負載 ZL → 二次回線形成另一個閉合回路，兩回路電氣隔離但以磁場交換能量。

負載接上後，二次側電流建立反向磁效應，一次側因此再吸取相應電流，使理想條件下輸入功率等於輸出功率。升高電壓必伴隨降低電流；同樣功率若以較高電壓輸送，線路 I²R 損失會下降。若輸入是穩定直流，穩態 dΦ/dt = 0，二次側就沒有感應電壓；變壓器只對變動磁通有效。

三相源提供三個等幅、彼此相差 120° 的弦波。Y 接時每相負載由線端接到共同中性點，線電流就是相電流，而兩線間電壓是兩個相電壓之差；Δ 接時每相負載直接跨在線與線之間，相電壓就是線電壓，而線電流是相鄰兩支相電流之差。平衡時三相瞬時功率互補成常數，使馬達轉矩比單相供電平順。

平衡是推導 √3 與簡潔功率式的重要前提：三相源等幅、相差正確，且三相負載相同。若某一相阻抗不同，各線電流不再等幅，Y 接中性點在沒有中性線時還可能漂移；此時要回到逐相相量與 KCL 計算，不能只套一條平衡公式。中性線提供不平衡電流的回路，但它不是理想平衡功率傳輸必須承載的第四相。

來源：06-電路學-下 第 10 章、06-電路學-上 §4.6。

推導：匝比來自法拉第定律，√3 來自 120° 相量相減

（a）匝比。同一束磁通 Φ 穿過兩個線圈，依感應電壓關係 v1 = N1dΦ/dt、v2 = N2dΦ/dt。兩式相除，公共的 dΦ/dt 消去，得到 v2/v1 = N2/N1。這完全來自法拉第定律，不是另外加上的變壓器規則。

（b）電流比。理想變壓器不儲存淨能量也不耗能，所以 v1i1 = v2i2。代入電壓比，得到 i2/i1 = N1/N2。電壓升幾倍，電流就降幾倍。

（c）阻抗轉換。令 n = N1/N2。一次側看入阻抗：

Zref = v1/i1 = nv2 / (i2/n) = n²(v2/i2) = n²Z2

阻抗按匝比平方轉換，原因是電壓比乘 n，而電流比除以 n。上述推導假設理想變壓器（ideal transformer）：耦合係數 k = 1、繞線電阻與鐵損為 0、激磁電流可忽略。真實互感滿足 k = M/√(L1L2)，且 0 ≤ k ≤ 1。

當 k < 1，並非所有一次側磁通都鏈結二次側，未共享部分可等效為漏感；繞線電阻造成負載電流相關的壓降與銅損，交變磁芯則有磁滯與渦流損失。於是實際一次功率會大於二次功率，空載也需要激磁電流。理想模型仍有用，因它先隔離匝比造成的主要比例，再把偏差留給等效電路修正。

（d）Y 接的 √3。以粗體表示相量，Vab = Va − Vb。兩個相電壓等幅且夾角 120°，相減大小為 2Vpsin(60°) = √3Vp，故 VL = √3Vp。Δ 接用同樣相減關係處理支路電流，得到 IL = √3Ip。

接線位置可防止口訣互換。Y 接的一條線只串著一相支路，所以線電流與相電流相同；但線電壓跨兩個線端，必須相減兩個相電壓，故根號三落在電壓。Δ 接的一相支路本來就跨兩條線，所以相電壓與線電壓相同；但一條線端同時銜接兩支路，依 KCL 取兩個支路電流之差，故根號三落在電流。相減還會帶來相位位移，只有問大小時才可只寫根號三。

（e）三相功率。每相實功是 VpIpcos θ，平衡三相總和 P = 3VpIpcos θ。Y 接代入 Vp = VL/√3、Ip = IL，得到 P = √3 ⋅ VL ⋅ IL ⋅ cos θ；Δ 接代入 Vp = VL、Ip = IL/√3，也得到同一式。V、I 使用有效值，θ 是負載阻抗角。

同一批相阻抗直接從 Y 切到 Δ 時，每相承受的電壓提高根號三倍，所以每相功率提高三倍，總功率也提高三倍。Y–Δ 啟動正是先用較低相電壓限制馬達起動電流與轉矩，再於轉速建立後切換；它不是一般性的省電模式，也不適用於銘牌接法與線電壓不匹配的馬達。

自由實驗：切換匝比與三相接法

變壓器模式中，一次側電源與線圈成一個閉合回路，二次線圈與負載成另一個回路，兩者以共同磁通耦合。三相模式則把三個等幅、相差 120° 的相源接成 Y 或 Δ，觀察線量、相量與總功率的差別。

不要混淆

  • 變壓器不能在穩態下變換直流，因 dΦ/dt = 0；短暫切換現象不等於可持續直流傳輸。
  • 電壓依匝比一次方轉換，阻抗依匝比平方轉換；漏掉平方會得到錯誤的一次側負載。
  • k = 1 是理想全耦合；真實元件另有漏感、繞線電阻、磁滯、渦流與激磁電流。
  • Y 接的 √3 出現在電壓，Δ 接的 √3 出現在電流；線量與相量不能混成同一個數。
  • 平衡三相瞬時總功率為常數，不表示每一相的瞬時功率不脈動。
  • 平衡基波下中性線電流為零；負載不平衡或含諧波時仍可能有中性線電流。
  • Y–Δ 啟動比較的是同一線電壓與同一相阻抗下的接法；若設備額定線圈電壓不同，三倍功率關係不能脫離條件套用。

可觀察證據：拿什麼量、量到什麼

在安全低電壓交流源上，用三用電表量變壓器一次、二次側空載有效值電壓，比值應接近匝比；以電阻檔量繞線可檢查直流電阻與斷線。帶上已知負載後再量 V2，通常會小於 V1/n，差額反映繞線壓降與漏感。這些量測能證明空載匝比是否合理、繞線是否導通、帶載電壓調整情形；卻不能證明耦合係數 k、漏感或鐵損各是多少，後者需要短路試驗、空載電流與功率量測。

三相系統可用鉤表分別量三條線電流；接近相等支持負載平衡的判斷，兩瓦特表法可取得三相總實功。這些讀值能證明指定操作點的線電流平衡與總功率，卻不能證明所有時刻都平衡，也不能單靠電流相等排除電壓不平衡或諧波。警告：市電三相是危險電壓，本段僅為知識性說明；實際接線與量測必須由合格人員使用額定量測設備、個人防護與正確隔離程序執行，學習者不可自行操作帶電配電盤。

更具體的安全邊界：量測前由合格人員依工作許可確認電壓類別、表筆與電表額定值，先斷電、上鎖掛牌、驗證測試器，再驗證確已無電；需要帶電診斷時，不得由學習者執行。鉤表只夾單一導線，夾住整條多芯電纜會讓各相磁場互相抵消。這能取得該線電流，不能取得相電壓、相序或絕緣狀態；相序與線間電壓須由具相應額定等級的專用儀器依程序量測。

連到哪門課

電機機械用變壓器模型理解感應馬達，電力系統用升降壓與 Y–Δ 配電控制電流與線損，通訊以射頻變壓器與巴倫做阻抗及平衡轉換，電源設計以耦合電感實作隔離式轉換器。磁通與法拉第定律留待電磁學深入；120° 複數相位可回看工程數學 09 複變入門。
