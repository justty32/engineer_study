## 3. 公式轉寫規約

來源筆記用 LaTeX，網頁**一律純文字 HTML**。

### 3.1 允許的字元

- 上下標：`<sup>` 與 `<sub>`。不要用 Unicode 下標數字（₀₁₂），避免不同字型高度不一。
- Unicode 數學符號（限這份清單）：`∫ Σ Π √ ∂ ∞ ± × ⋅ · ≈ ≠ ≤ ≥ ≪ ≫ ∝ → ⇒ ⇔ ∈ ∠ ° ′ ″ | ‖`
- 希臘字母：`α β γ δ ε ζ η θ λ μ π ρ σ τ φ χ ψ ω Δ Σ Φ Ω`
- **負號一律用 U+2212 `−`，不要用半形連字號 `-`**（連字號只用在檔名與 CSS class）。
- 上標數字可直接用 `²` `³`；其餘次方用 `<sup>`。
- **`‖` 在本課專指「並聯」**（`R<sub>1</sub>‖R<sub>2</sub>`），首次出現要在文中說明「‖ 讀作『並聯』，不是絕對值也不是範數」。
- **虛數單位一律寫 `j`**（電機慣例，`i` 已經是電流）。首次出現要說明「數學課寫 i，電機寫 j，因為 i 留給電流」。
- 單位一律半形英文緊接數字後空一格：`5 V`、`20 mA`、`1 kΩ`、`10 µF`、`10 mH`、`1591.549431 Hz`、`3097.6 W`、`2323.2 var`、`3872 VA`、`0.1 s`。**微法拉用 `µF`（U+00B5 micro sign），不要用希臘字母 μ（U+03BC）**，全檔統一。
- 歐姆符號用 `Ω`（U+03A9 希臘大寫 Omega），不要用 U+2126。

### 3.2 排版規則

1. **分數**：單行寫成 `(分子) / (分母)`，例如 `(V<sub>s</sub> − v<sub>C</sub>) / R`。分子分母都是單一符號時可省括號：`1/(jωC)`、`L/R`。
2. **多行分式**只在必要時用 `<pre>`，以 `─` 畫橫線，前後留一空行。
3. **導數**寫成 `dv/dt`、`di/dt`；二階寫 `d²i/dt²`。不要用點記號。
4. **指數中還有下標時，把下標壓平**：`e<sup>−t/τ</sup>`、`e<sup>jωt</sup>`。不得寫巢狀 `<sup><sub>`。
5. **複數**寫成直角式 `Z = R + jX` 與極式 `Z = |Z|∠θ`；共軛寫 `I*`（半形星號）。
6. **相量**用粗體 `<strong>V</strong>` 表示，或在文中明說「粗體代表相量」；不用數學粗體字元。
7. **矩陣**用巢狀方括號寫成一行：`G = [[1.5, −0.5], [−0.5, 0.833333]]`（單位 mS），並在旁邊用文字說明「第一列 1.5、−0.5；第二列 −0.5、0.833333」。
8. **函式名**（sin、cos、tan、exp、ln、log、Re、Im、arg、rms、max）用一般半形英文，不加標記。
9. 公式所在段落用 `<p>`；需要凸顯時可用 `<code>`（`styles.css` 已設 `overflow-wrap:anywhere`）。
10. **電路拓樸**用文字＋節點清單，格式固定：`V<sub>s</sub> 正端 → R<sub>1</sub> → 節點 A；節點 A → R<sub>2</sub> → 地；V<sub>s</sub> 負端 → 地`。

### 3.3 轉寫範例（builder 照這個風格，至少覆蓋這 20 組）

| 來源 LaTeX | 網頁純文字 HTML |
| --- | --- |
| `v=iR` | `v = iR` |
| `P=vi=i^2R=v^2/R` | `P = vi = i²R = v² / R` |
| `\frac{1}{R_\text{eq}}=\frac{1}{R_1}+\frac{1}{R_2}` | `1/R<sub>eq</sub> = 1/R<sub>1</sub> + 1/R<sub>2</sub>`，兩個並聯時 `R<sub>1</sub>‖R<sub>2</sub> = R<sub>1</sub>R<sub>2</sub> / (R<sub>1</sub> + R<sub>2</sub>)` |
| `v_k=v_\text{總}\cdot\frac{R_k}{\sum R_i}` | `v<sub>k</sub> = v<sub>總</sub> ⋅ R<sub>k</sub> / (R<sub>1</sub> + R<sub>2</sub> + …)` |
| `i=C\,\frac{dv}{dt}` | `i = C ⋅ dv/dt` |
| `v=L\,\frac{di}{dt}` | `v = L ⋅ di/dt` |

### 00 `00-電路世界觀.html`

**目標**：先講清楚電路學到底在描述什麼——電荷會動、動起來叫電流、推它的是電壓差、單位時間交換的能量叫功率——並且說明這一整套只在「電路遠小於波長」時才成立。

**要點**：電荷（electric charge）單位庫侖 C，1 個電子帶 −1.602176634 × 10<sup>−19</sup> C；電流（current）i = dq/dt，單位 A = C/s，方向定義為**正電荷流動方向**（與電子實際流向相反，這是歷史約定）；電壓（voltage）是單位電荷的位能差，v = dW/dq，單位 V = J/C，**電壓一定是兩點之間的差**，講「某點的電壓」時已經預設了一個參考點；參考地（ground reference）不是「地球」，是我們自己選的 0 V 基準；功率 P = vi，單位 W = J/s，被動符號規約（passive sign convention）：電流從 + 端流入元件時 P > 0 代表吸收能量；能量 W = ∫P dt；集總元件假設（lumped element assumption）：當電路最長尺寸 d ≪ 波長 λ 時，可以忽略訊號在空間中的傳播延遲，只用元件值與節點電壓、支路電流描述電路。來源：06-電路學-上「這科在學什麼」。

**推導必寫**：（a）從 i = dq/dt 反推 q = ∫i dt，定電流時 q = It；把 1 C 換算成電子個數 1/(1.602176634 × 10<sup>−19</sup>) ≈ 6.24 × 10<sup>18</sup> 個。（b）P = vi 的量綱檢查：V × A = (J/C) × (C/s) = J/s = W——**功率的定義不是背來的，是兩個定義相乘後單位自己約掉電荷**。（c）集總假設的判準：電磁波在真空中速度 c ≈ 3 × 10<sup>8</sup> m/s，波長 λ = c/f。訊號從電路一端傳到另一端要 d/c 秒，對應的相位差是 360° × (d/λ)。工程上取 **d < λ/20**（相位差小於 18°）作為集總近似可用的門檻。超過就必須改用傳輸線模型。

**數值實例**：V = 5 V、I = 20 mA、t = 60 s、f = 100 MHz、d = 0.1 m。

| 功率 | P = V ⋅ I = 5 × 0.02 | **0.100000 W** |
| 能量 | W = P ⋅ t = 0.1 × 60 | **6.000000 J** |
| 波長 | λ = c/f = 3 × 10<sup>8</sup> / 10<sup>8</sup> | **3.000000 m** |

### 01 `01-電阻與歐姆定律.html`

**目標**：把歐姆定律從一條公式變成「三個量互相決定」的工具，並用串並聯、分壓分流把一個電路化簡到能心算。

**要點**：電阻（resistor）v = iR，R 單位 Ω = V/A；電導（conductance）G = 1/R，單位 S（西門子）；功率 P = vi = i²R = v²/R，三種寫法在不同已知條件下用；串聯 R<sub>eq</sub> = R<sub>1</sub> + R<sub>2</sub> + …（同一個電流流過每一個）；並聯 1/R<sub>eq</sub> = 1/R<sub>1</sub> + 1/R<sub>2</sub> + …，兩個時 R<sub>1</sub>‖R<sub>2</sub> = R<sub>1</sub>R<sub>2</sub>/(R<sub>1</sub> + R<sub>2</sub>)（同一個電壓加在每一個）；分壓 v<sub>k</sub> = v<sub>總</sub> ⋅ R<sub>k</sub>/ΣR<sub>i</sub>；分流 i<sub>k</sub> = i<sub>總</sub> ⋅ G<sub>k</sub>/ΣG<sub>i</sub>；能量守恆的第一個驗算法：**所有元件的功率相加必須等於源送出的功率**。來源：06-電路學-上 §1.1、§2.1–§2.2。

**推導必寫**：（a）串聯為什麼相加：電流 i 相同，KVL 給 v = iR<sub>1</sub> + iR<sub>2</sub> = i(R<sub>1</sub> + R<sub>2</sub>)，所以從外面看等效電阻就是 R<sub>1</sub> + R<sub>2</sub>。（b）並聯為什麼倒數相加：電壓 v 相同，KCL 給 i = v/R<sub>1</sub> + v/R<sub>2</sub> = v(1/R<sub>1</sub> + 1/R<sub>2</sub>)，所以 1/R<sub>eq</sub> = 1/R<sub>1</sub> + 1/R<sub>2</sub>。**兩條化簡規則不是規則，是 KVL 與 KCL 的直接結果**（第 02 章會把這兩條律本身講清楚）。（c）分壓公式：把 i = v<sub>總</sub>/(R<sub>1</sub> + R<sub>2</sub>) 代回 v<sub>2</sub> = iR<sub>2</sub>，得 v<sub>2</sub> = v<sub>總</sub> ⋅ R<sub>2</sub>/(R<sub>1</sub> + R<sub>2</sub>)。（d）P = i²R 與 P = v²/R 由 P = vi 加上 v = iR 直接代換得到，**代換方向決定你要用哪一條**：已知電流用 i²R，已知電壓用 v²/R。

**數值實例**：V<sub>s</sub> = 12 V、R<sub>1</sub> = 1 kΩ、R<sub>2</sub> = 2 kΩ（**本課主電路**，02、04、05 章都會再用）。

### 02 `02-KCL與KVL.html`

**目標**：把兩條克希荷夫定律講回它們的物理根據（電荷守恆與能量守恆），並示範**用殘差驗算自己的解**這個一輩子有用的習慣。

**要點**：節點（node）＝被導線連在一起、電位相同的一整塊；支路（branch）＝兩節點之間的一個元件路徑；回路（loop）＝從某節點出發、不重複經過任一節點、回到原點的封閉路徑；**KCL（Kirchhoff's Current Law，克希荷夫電流定律）**：任一節點流入電流的代數和 = 0，物理根據是**電荷守恆**——節點是理想導體上的一個點，不會囤積電荷；**KVL（Kirchhoff's Voltage Law，克希荷夫電壓定律）**：任一封閉回路的電壓代數和 = 0，物理根據是**能量守恆**——電荷繞一圈回到原點，位能必須回到原值；符號規約：先給每條支路假設一個電流方向，算出來是負的就代表實際方向相反，**不用回頭改圖**。來源：06-電路學-上 §1.3。

**推導必寫**：（a）用 §1.3 的主電路示範。拓樸：`V<sub>s</sub> 正端 → R<sub>1</sub> → 節點 A；節點 A → R<sub>2</sub> → 地；節點 A → R<sub>3</sub> → 地；V<sub>s</sub> 負端 → 地`。（b）先用並聯化簡求 V<sub>A</sub>：R<sub>2</sub>‖R<sub>3</sub> = R<sub>2</sub>R<sub>3</sub>/(R<sub>2</sub> + R<sub>3</sub>)，再分壓 V<sub>A</sub> = V<sub>s</sub> ⋅ (R<sub>2</sub>‖R<sub>3</sub>)/(R<sub>1</sub> + R<sub>2</sub>‖R<sub>3</sub>)。（c）**用 KCL 驗算**：I<sub>1</sub> = (V<sub>s</sub> − V<sub>A</sub>)/R<sub>1</sub> 流入 A，I<sub>2</sub> = V<sub>A</sub>/R<sub>2</sub> 與 I<sub>3</sub> = V<sub>A</sub>/R<sub>3</sub> 流出 A，殘差 I<sub>1</sub> − I<sub>2</sub> − I<sub>3</sub> 必須為 0。（d）**用 KVL 驗算**：沿 `地 → V<sub>s</sub> → R<sub>1</sub> → A → R<sub>2</sub> → 地` 這一圈，V<sub>s</sub> − I<sub>1</sub>R<sub>1</sub> − V<sub>A</sub> = 0。（e）說明兩條律各自的失效條件：**KCL 在節點會囤積電荷時失效**（高頻下走線對地有寄生電容，電荷真的會暫存）；**KVL 在回路穿過變化磁通時失效**（法拉第定律會多出一項 −dΦ/dt，這是量測時把探棒線圈得太大會吃到雜訊的原因）。這兩句話不能省，否則讀者會以為它們是絕對真理。

**數值實例**：V<sub>s</sub> = 12 V、R<sub>1</sub> = 1 kΩ、R<sub>2</sub> = 2 kΩ、R<sub>3</sub> = 3 kΩ。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| R<sub>2</sub>‖R<sub>3</sub> | (2000 × 3000)/5000 | **1200.000000 Ω** |
| 節點電壓 V<sub>A</sub> | 12 × 1200/(1000 + 1200) | **6.545455 V** |
| I<sub>1</sub>（流入 A） | (12 − 6.545455)/1000 | **5.454545 mA** |
| I<sub>2</sub>（流出，經 R<sub>2</sub>） | 6.545455/2000 | **3.272727 mA** |
| I<sub>3</sub>（流出，經 R<sub>3</sub>） | 6.545455/3000 | **2.181818 mA** |
| KCL 殘差 | 5.454545 − 3.272727 − 2.181818 | **0.000000 mA** |

功率交叉驗算：源送出 12 × 0.005454545 = **0.065455 W**；R<sub>1</sub> 耗 **0.029752 W**、R<sub>2</sub> 耗 **0.021421 W**、R<sub>3</sub> 耗 **0.014281 W**，三者相加 **0.065455 W**，相符。

**可觀察證據**：**KCL 怎麼量**——把電流勾表夾在節點的每一條支路上，讀數相加應該是零（要注意方向極性）。**KVL 怎麼量**——把三用電表沿一圈量每個元件的壓降，代數和應該是零。**能證明**：這一組直流解在你量得到的精度內是自洽的。**不能證明**：KCL/KVL 本身（它們是守恆律，量測只能反覆沒有推翻它們）；也不能證明高頻下仍成立——把示波器地線圈成一個大迴路再靠近開關電源，你會在「應該是 0 V」的地方看到雜訊，那就是 KVL 的 −dΦ/dt 項在說話。

### 03 `03-節點與網目分析.html`

**目標**：把「憑直覺化簡」升級成「機械化列方程」，讓任何不能串並聯化簡的電路都有標準解法，並看見它就是一個線性方程組。

**要點**：節點分析法（nodal analysis）：選一個參考節點（地），對其餘每個節點寫 KCL，未知數是**節點電壓**，方程組寫成 G<strong>v</strong> = <strong>i</strong><sub>s</sub>，G 是電導矩陣（單位 S）；G 矩陣的組法（純電阻＋電流源時）——對角元 G<sub>kk</sub> = 接到節點 k 的所有電導總和，非對角元 G<sub>jk</sub> = −（節點 j 與 k 之間的電導），右手邊 = 流**入**該節點的電流源總和；網孔分析法（mesh analysis）：對每個平面網孔寫 KVL，未知數是**網孔電流**，方程組寫成 R<strong>i</strong> = <strong>v</strong><sub>s</sub>；選哪一種的實務準則——**電流源多、節點少就用節點法；電壓源多、網孔少就用網孔法**；被動電阻網路的 G 矩陣是對稱且正定的，所以**節點電壓必定唯一存在**。來源：06-電路學-上 §2.3–§2.4。

**推導必寫**：（a）拓樸：`節點 1 → R<sub>1</sub> → 地`；`節點 1 → R<sub>2</sub> → 節點 2`；`節點 2 → R<sub>3</sub> → 地`；電流源 I<sub>s1</sub> 注入節點 1、I<sub>s2</sub> 注入節點 2。（b）對節點 1 寫 KCL：流出 = v<sub>1</sub>/R<sub>1</sub> + (v<sub>1</sub> − v<sub>2</sub>)/R<sub>2</sub>，流入 = I<sub>s1</sub>，整理得 (G<sub>1</sub> + G<sub>2</sub>)v<sub>1</sub> − G<sub>2</sub>v<sub>2</sub> = I<sub>s1</sub>。（c）對節點 2 同理：−G<sub>2</sub>v<sub>1</sub> + (G<sub>2</sub> + G<sub>3</sub>)v<sub>2</sub> = I<sub>s2</sub>。（d）**指出這兩條式子的形狀就是 G 矩陣的組法規則**，之後任何電路都可以不推導直接填表。（e）2×2 的克拉瑪法則（Cramer's rule）：det = ad − bc，v<sub>1</sub> = (I<sub>s1</sub>d − bI<sub>s2</sub>)/det，v<sub>2</sub> = (aI<sub>s2</sub> − cI<sub>s1</sub>)/det。（f）說明為什麼被動電阻網路 det 永遠 > 0：對角元是所有連到該節點的電導和，一定大於非對角元的絕對值（對角優勢），所以矩陣可逆——**電路不會「無解」或「無限多解」，除非你把電流源接到開路上**。

**數值實例**：R<sub>1</sub> = 1 kΩ、R<sub>2</sub> = 2 kΩ、R<sub>3</sub> = 3 kΩ、I<sub>s1</sub> = 10 mA、I<sub>s2</sub> = 5 mA。用 mS 與 mA 當單位，算出來直接是 V（因為 mA/mS = V）。

### 04 `04-疊加原理與相依源.html`

**目標**：說清楚「線性」在電路裡到底換來什麼好處（多源可以一個一個算再相加），以及這個好處在哪裡會破功（功率、相依源）。

**要點**：線性（linearity）＝齊次性（輸入乘 k，輸出乘 k）＋可加性（兩個輸入的響應可以相加）；疊加原理（superposition）：線性電路中，多源的響應 = 各源單獨作用時響應的代數和；**源歸零規則**：算某個源時，其他**獨立電壓源短路**（因為理想電壓源的內阻是 0）、**獨立電流源開路**（因為理想電流源的內阻是 ∞）；**相依源（dependent source）永遠不歸零**，因為它不是獨立輸入，是電路內部的線性關係；四種相依源——VCVS（電壓控制電壓源）、CCVS（電流控制電壓源）、VCCS（電壓控制電流源）、CCCS（電流控制電流源），它們是電晶體小訊號模型與運算放大器模型的骨架；**功率不能疊加**，因為 P 是 v 或 i 的二次函式。來源：06-電路學-上 §1.2、§2.6。

**推導必寫**：（a）拓樸：`V<sub>s</sub> 正端 → R<sub>1</sub> → 節點 A`；`電流源 I<sub>s</sub> 注入節點 A`；`節點 A → R<sub>2</sub> → 地`；`V<sub>s</sub> 負端 → 地`。（b）**V<sub>s</sub> 單獨作用**（I<sub>s</sub> 開路）：純分壓，V<sub>A,V</sub> = V<sub>s</sub> ⋅ R<sub>2</sub>/(R<sub>1</sub> + R<sub>2</sub>)。（c）**I<sub>s</sub> 單獨作用**（V<sub>s</sub> 短路）：R<sub>1</sub> 與 R<sub>2</sub> 變成並聯，V<sub>A,I</sub> = I<sub>s</sub> ⋅ (R<sub>1</sub>‖R<sub>2</sub>)。（d）相加得 V<sub>A</sub>，再用節點法直接解一次當驗算：(V<sub>A</sub> − V<sub>s</sub>)/R<sub>1</sub> + V<sub>A</sub>/R<sub>2</sub> = I<sub>s</sub>。（e）**功率為什麼不能疊加**：P = V<sub>A</sub>²/R<sub>2</sub> = (V<sub>A,V</sub> + V<sub>A,I</sub>)²/R<sub>2</sub> = V<sub>A,V</sub>²/R<sub>2</sub> + V<sub>A,I</sub>²/R<sub>2</sub> + **2V<sub>A,V</sub>V<sub>A,I</sub>/R<sub>2</sub>**，多出來的交叉項就是差額。把這個展開式完整寫出來，讀者才會記住原因不是「規定」。

**數值實例**：V<sub>s</sub> = 12 V、R<sub>1</sub> = 1 kΩ、I<sub>s</sub> = 5 mA、R<sub>2</sub> = 2 kΩ。

| 量 | 算式 | 結果 |

**可觀察證據**：真的可以做這個實驗——把電流源那一支拔掉（開路）量 V<sub>A</sub>，再把電壓源換成一條短路線量 V<sub>A</sub>，兩次讀數相加應該等於兩個源都接上時的讀數。**能證明**：這個電路在你的操作範圍內是線性的。**不能證明**：它在更大的電壓下還是線性的（電阻會發熱、源會限流）；也不能用這個方法量功率——功率要各自量電壓與電流再相乘，不能把兩次的功率讀數相加。

**連到哪門課**：相依源是電子學裡電晶體小訊號模型的核心；疊加原理是信號與系統整門課的地基（卷積就是把輸入拆成無限多個脈衝再疊加）。線性的定義見 `../../../共通基礎/數學/互動課程/04-向量與矩陣.html`。

### 05 `05-戴維寧與最大功率.html`

**目標**：把任意複雜的線性電路從某兩端看進去濃縮成**一個電壓源串一個電阻**，並用它回答工程上最常見的問題：負載該用多大。

**要點**：戴維寧等效（Thévenin equivalent）＝V<sub>th</sub> 串 R<sub>th</sub>；諾頓等效（Norton equivalent）＝I<sub>N</sub> 並 R<sub>th</sub>，兩者用 I<sub>N</sub> = V<sub>th</sub>/R<sub>th</sub> 互換；三種求法——V<sub>th</sub> = 端點**開路電壓**、I<sub>N</sub> = 端點**短路電流**、R<sub>th</sub> = 把所有**獨立源歸零**後從端口看進去的電阻（含相依源時要改用「加一個測試源、量 v/i」的方法）；最大功率傳遞（maximum power transfer）：R<sub>L</sub> = R<sub>th</sub> 時 P<sub>L</sub> 最大，P<sub>max</sub> = V<sub>th</sub>²/(4R<sub>th</sub>)；**此時效率只有 50 %**——一半的功率燒在 R<sub>th</sub> 上；**匹配與效率是兩個目標，不能同時最佳**：通訊系統要匹配（訊號小，能拿多少是多少），電力系統要效率（不可能燒掉一半發電量）。來源：06-電路學-上 §2.5、§2.7。

**推導必寫**：（a）沿用主電路：`V<sub>s</sub> 正端 → R<sub>1</sub> → 端點 A`；`端點 A → R<sub>2</sub> → 地`；負載 R<sub>L</sub> 接在 A 與地之間。（b）V<sub>th</sub>＝把 R<sub>L</sub> 拿掉後 A 對地的電壓＝分壓 V<sub>s</sub>R<sub>2</sub>/(R<sub>1</sub> + R<sub>2</sub>)。（c）R<sub>th</sub>＝把 V<sub>s</sub> 短路後從 A 看進去：R<sub>1</sub> 與 R<sub>2</sub> 都接到地，所以是 R<sub>1</sub>‖R<sub>2</sub>。（d）I<sub>N</sub>＝把 A 對地短路後流過短路線的電流＝V<sub>s</sub>/R<sub>1</sub>（因為 R<sub>2</sub> 被短路掉了），驗證 I<sub>N</sub> = V<sub>th</sub>/R<sub>th</sub>。（e）**最大功率條件的推導必須完整寫出**：P<sub>L</sub> = I²R<sub>L</sub> = V<sub>th</sub>²R<sub>L</sub>/(R<sub>th</sub> + R<sub>L</sub>)²。對 R<sub>L</sub> 微分，令 dP<sub>L</sub>/dR<sub>L</sub> = 0：分子為 V<sub>th</sub>²[(R<sub>th</sub> + R<sub>L</sub>)² − R<sub>L</sub> ⋅ 2(R<sub>th</sub> + R<sub>L</sub>)] = V<sub>th</sub>²(R<sub>th</sub> + R<sub>L</sub>)(R<sub>th</sub> − R<sub>L</sub>)，所以 R<sub>L</sub> = R<sub>th</sub>。代回得 P<sub>max</sub> = V<sub>th</sub>²/(4R<sub>th</sub>)。（f）效率 η = P<sub>L</sub>/P<sub>總</sub> = R<sub>L</sub>/(R<sub>th</sub> + R<sub>L</sub>)，在 R<sub>L</sub> = R<sub>th</sub> 時是 50 %，且**隨 R<sub>L</sub> 單調遞增**——這就是兩個目標互相衝突的數學根源。

**數值實例**：V<sub>s</sub> = 12 V、R<sub>1</sub> = 1 kΩ、R<sub>2</sub> = 2 kΩ。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| V<sub>th</sub>（開路電壓） | 12 × 2000/3000 | **8.000000 V** |
| R<sub>th</sub>（源歸零後看入） | 1000‖2000 | **666.666667 Ω** |
| I<sub>N</sub>（短路電流） | 12/1000 | **12.000000 mA**（＝8/666.666667，相符） |
| P<sub>max</sub> | 8²/(4 × 666.666667) | **24.000000 mW** |

| --- | --- | --- | --- | --- | --- |
| 0.3 | 200.000000 | 9.230769 | 1.846154 | 17.041420 | 23.077 |

**不要混淆**：R<sub>th</sub> 是**等效**內阻，不是電路裡真的有那一顆電阻；**歸零獨立源、不歸零相依源**；戴維寧等效只對「這兩個端點外面看到的行為」等價，**內部的功率消耗完全不一樣**（等效電路算不出原電路每顆電阻各燒多少）；最大功率 ≠ 最高效率，兩者在 R<sub>L</sub> = R<sub>th</sub> 剛好衝突；「阻抗匹配」在交流是共軛匹配 Z<sub>L</sub> = Z<sub>th</sub>*（第 10 章），不是 Z<sub>L</sub> = Z<sub>th</sub>。

### 06 `06-電容與電感.html`

**目標**：把兩個「會記住過去」的元件講清楚——它們不遵守 v = iR，而是把電壓電流和**變化率**綁在一起，並因此能儲存能量。

**要點**：電容（capacitor）i = C ⋅ dv/dt，C 單位 F（法拉），儲的是**電場**能量 W<sub>C</sub> = (1/2)Cv²；電感（inductor）v = L ⋅ di/dt，L 單位 H（亨利），儲的是**磁場**能量 W<sub>L</sub> = (1/2)Li²；**對偶性（duality）**——把 v↔i、C↔L、串聯↔並聯對調，兩組公式完全一樣，記一個就等於記兩個；**連續性條件**：電容電壓不能跳變、電感電流不能跳變（除非有理想脈衝源），因為跳變需要無限大的電流／電壓；直流穩態下（所有量都不再變）電容 dv/dt = 0 → i = 0 → **電容等效開路**，電感 di/dt = 0 → v = 0 → **電感等效短路**；串並聯——電容並聯相加 C<sub>eq</sub> = ΣC<sub>i</sub>、串聯倒數相加（和電阻**顛倒**），電感串聯相加、並聯倒數相加（和電阻**同形**）。來源：06-電路學-上 §1.1、第 3 章。

**推導必寫**：（a）電容的定義是 q = Cv，兩邊對時間微分得 i = dq/dt = C ⋅ dv/dt——**這條不是實驗定律，是電容定義加上電流定義的結果**。（b）儲能：W = ∫P dt = ∫vi dt = ∫v ⋅ C(dv/dt) dt = C∫v dv = (1/2)Cv²。電感同理：W = ∫vi dt = ∫L(di/dt) ⋅ i dt = L∫i di = (1/2)Li²。（c）**連續性條件的量化證明**：要讓一顆 C 的電壓在 Δt 內跳 Δv，需要 i = CΔv/Δt。令 Δt → 0，i → ∞。真實電路裡沒有無限大的電流，所以電壓「跳不動」，只能連續地爬。（d）電容並聯為什麼相加：同一個電壓，總電流 i = C<sub>1</sub>dv/dt + C<sub>2</sub>dv/dt = (C<sub>1</sub> + C<sub>2</sub>)dv/dt。（e）為什麼電容和電阻的串並聯規則相反：因為電容的「阻礙能力」正比於 1/C（見第 10 章的 Z<sub>C</sub> = 1/(jωC)），倒數關係讓規則翻過來。

**數值實例**：C = 100 µF、L = 10 mH、變化率 = 1000（電容模式為 1000 V/s，電感模式為 1000 A/s）、狀態量 = 10（電容模式為 10 V，電感模式為 10 A）。

| 模式 | 量 | 算式 | 結果 |
| --- | --- | --- | --- |
| 電容 | 電流 | i = C ⋅ dv/dt = 100 × 10<sup>−6</sup> × 1000 | **0.100000 A ＝ 100 mA** |
| 電容 | 儲能 | W = (1/2) × 100 × 10<sup>−6</sup> × 10² | **0.005000 J ＝ 5 mJ** |
| 電感 | 電壓 | v = L ⋅ di/dt = 10 × 10<sup>−3</sup> × 1000 | **10.000000 V** |
| 電感 | 儲能 | W = (1/2) × 10 × 10<sup>−3</sup> × 10² | **0.500000 J ＝ 500 mJ** |

串並聯（兩顆相同元件）：C = 100 µF 兩顆 → 並聯 **200.000000 µF**、串聯 **50.000000 µF**；L = 10 mH 兩顆 → 串聯 **20.000000 mH**、並聯 **5.000000 mH**。

**跳變的代價**：要讓這顆 100 µF 的電壓在 1 µs 內跳 10 V，dv/dt = 10<sup>7</sup> V/s，需要電流 i = 100 × 10<sup>−6</sup> × 10<sup>7</sup> = **1000.000000 A**。同理要讓 10 mH 的電流在 1 µs 內跳 1 A，需要電壓 v = 10 × 10<sup>−3</sup> × 10<sup>6</sup> = **10000.000000 V**——這就是為什麼繼電器線圈斷電時會打火花，必須並一顆續流二極體。

### 07 `07-一階暫態RC與RL.html`

**目標**：回答「開關切下去之後，電壓是怎麼一步步爬到穩態的」，並讓時間常數 τ 從一個符號變成可以量、可以設計的東西。

**要點**：一階電路（first-order circuit）＝只含一個獨立儲能元件的電路，動態由一階常微分方程描述；通解形式 v<sub>C</sub>(t) = v<sub>C</sub>(∞) + [v<sub>C</sub>(0<sup>+</sup>) − v<sub>C</sub>(∞)]e<sup>−t/τ</sup>，**三個要素**——初值、終值、時間常數，缺一不可；**τ = R<sub>th</sub>C**（RC）或 **τ = L/R<sub>th</sub>**（RL），其中 R<sub>th</sub> 是**從儲能元件兩端看出去的戴維寧電阻**（第 05 章直接派上用場）；連續性條件決定 v<sub>C</sub>(0<sup>+</sup>) = v<sub>C</sub>(0<sup>−</sup>)、i<sub>L</sub>(0<sup>+</sup>) = i<sub>L</sub>(0<sup>−</sup>)；終值用「直流穩態下電容開路、電感短路」求；自然響應（natural response）＝源歸零後靠自己儲的能量衰減的部分，強迫響應（forced response）＝被源拉到的穩態部分。來源：06-電路學-下 §5.1–§5.2。

**推導必寫**：（a）拓樸：`V<sub>s</sub> → R → 節點 A`；`節點 A → C → 地`。列 KCL：(v<sub>C</sub> − V<sub>s</sub>)/R + C ⋅ dv<sub>C</sub>/dt = 0，整理成 RC ⋅ dv<sub>C</sub>/dt + v<sub>C</sub> = V<sub>s</sub>。（b）**用分離變數解出來**：dv<sub>C</sub>/(V<sub>s</sub> − v<sub>C</sub>) = dt/(RC)，兩邊積分得 −ln|V<sub>s</sub> − v<sub>C</sub>| = t/(RC) + K，指數化並代入 v<sub>C</sub>(0) = V<sub>0</sub>，得 v<sub>C</sub>(t) = V<sub>s</sub> + (V<sub>0</sub> − V<sub>s</sub>)e<sup>−t/(RC)</sup>。這一步要完整寫，不能只丟結論。（c）**τ 的量綱檢查**：Ω × F = (V/A) × (C/V) = C/A = C/(C/s) = s，確實是秒。RL 版：H/Ω = (V⋅s/A)/(V/A) = s。（d）**63.2 % 是怎麼來的**：t = τ 時 e<sup>−1</sup> = 0.367879，走完的比例是 1 − 0.367879 = 0.632121。t = 3τ → 0.950213；t = 5τ → 0.993262。這三個數字要當成常識背下來。（e）電流：i(t) = (V<sub>s</sub> − v<sub>C</sub>)/R = (V<sub>s</sub> − V<sub>0</sub>)/R ⋅ e<sup>−t/τ</sup>——**電流是純指數衰減，沒有常數項**，因為穩態時電容不吃電流。

**數值實例**：R = 10 kΩ、C = 10 µF、V<sub>0</sub> = 0 V、V<sub>s</sub> = 5 V → **τ = RC = 10<sup>4</sup> × 10<sup>−5</sup> = 0.100000 s**。

| t | v<sub>C</sub>(t)（V） | 走完比例（%） | i(t)（mA） |
| --- | --- | --- | --- |
| 0.5τ = 0.050000 s | **1.967347** | 39.3469 | 0.303265 |
| **1τ = 0.100000 s** | **3.160603** | **63.2121** | **0.183940** |
| 2τ = 0.200000 s | **4.323324** | 86.4665 | 0.067668 |
| 3τ = 0.300000 s | **4.751065** | 95.0213 | 0.024894 |
| 5τ = 0.500000 s | **4.966310** | 99.3262 | 0.003369 |

**和工程數學課對得上**：工程數學先修第 07 章用 τ = 1 s、v<sub>s</sub> = 5 V 得到 t = τ 時 3.160603 V。本課的 τ 是 0.1 s，但**百分比一模一樣**——因為 e<sup>−t/τ</sup> 只認 t/τ 這個比值，不認絕對時間。

RL 對照：L = 10 mH、R = 10 kΩ → τ = L/R = 10<sup>−6</sup> s = **1.000000 µs**；同樣的 R 換成 100 Ω → τ = **100.000000 µs**。**注意 RL 的 τ 和 R 成反比，RC 的 τ 和 R 成正比**，這是最容易記反的一組。

### 08 `08-二階RLC暫態.html`

**目標**：說明為什麼多加一個儲能元件，波形就從「單調爬升」變成「可能振鈴」，並讓讀者能用一個參數 ζ 預測會不會振、振多久。

**要點**：二階電路（second-order circuit）＝含兩個獨立儲能元件；串聯 RLC 的方程 L ⋅ d²i/dt² + R ⋅ di/dt + i/C = dv<sub>s</sub>/dt；特徵方程根 s<sub>1,2</sub> = −α ± √(α² − ω<sub>0</sub>²)；**衰減因子** α = R/(2L)（單位 1/s，也叫 neper frequency）；**無阻尼自然頻率** ω<sub>0</sub> = 1/√(LC)（rad/s）；**阻尼比** ζ = α/ω<sub>0</sub>（無因次）；三種響應——ζ > 1 過阻尼（兩相異負實根，純衰減不振）、ζ = 1 臨界阻尼（重根，不振的最快）、0 < ζ < 1 欠阻尼（共軛複根，振盪衰減），阻尼振盪頻率 ω<sub>d</sub> = ω<sub>0</sub>√(1 − ζ²)；臨界電阻 R<sub>臨界</sub> = 2√(L/C)；能量觀點——L 和 C 互相把能量丟來丟去就是振盪，R 是每次來回被扣掉的過路費；用拉氏轉換解暫態是標準工序（把 C 換成 1/(sC)、L 換成 sL，整個電路變成代數）。來源：06-電路學-下 §6.1–§6.2。

**推導必寫**：（a）串聯 RLC 迴路寫 KVL：L ⋅ di/dt + Ri + (1/C)∫i dt = v<sub>s</sub>，兩邊對 t 微分消掉積分號，得二階方程。（b）令 i = Ae<sup>st</sup> 代入齊次方程，得特徵方程 Ls² + Rs + 1/C = 0，除以 L 得 s² + (R/L)s + 1/(LC) = 0，對照標準型 s² + 2αs + ω<sub>0</sub>² = 0，讀出 α = R/(2L)、ω<sub>0</sub> = 1/√(LC)。（c）判別式 α² − ω<sub>0</sub>² 的正負決定三種情形，**寫出每一種的解形式**：過阻尼 i = A<sub>1</sub>e<sup>s1t</sup> + A<sub>2</sub>e<sup>s2t</sup>；臨界 i = (A<sub>1</sub> + A<sub>2</sub>t)e<sup>−αt</sup>；欠阻尼 i = e<sup>−αt</sup>(A<sub>1</sub>cos ω<sub>d</sub>t + A<sub>2</sub>sin ω<sub>d</sub>t)。（d）臨界電阻：令 α = ω<sub>0</sub> → R/(2L) = 1/√(LC) → R = 2L/√(LC) = 2√(L/C)。（e）欠阻尼步階響應的**超越量（overshoot）**公式 OS = e<sup>−πζ/√(1−ζ²)</sup>，這是「ζ 直接看得出振多兇」的定量橋樑。（f）指出 ζ 與第 13 章的品質因數 Q 是同一件事的兩面：**Q = 1/(2ζ)**。

**數值實例**：L = 10 mH、C = 1 µF（**這組值第 13 章會原封不動再用一次**）。

固定量：ω<sub>0</sub> = 1/√(10<sup>−2</sup> × 10<sup>−6</sup>) = 1/10<sup>−4</sup> = **10000.000000 rad/s**；f<sub>0</sub> = ω<sub>0</sub>/(2π) = **1591.549431 Hz**；R<sub>臨界</sub> = 2√(10<sup>−2</sup>/10<sup>−6</sup>) = 2 × 100 = **200.000000 Ω**。

| --- | --- | --- | --- | --- |
| 10 | 500.000000 | **0.050000** | 欠阻尼（振很久） | ω<sub>d</sub> = 9987.492178 rad/s；包絡時間常數 1/α = 2000.000 µs；超越量 **85.4468 %** |
| **100** | **5000.000000** | **0.500000** | **欠阻尼** | ω<sub>d</sub> = **8660.254038 rad/s**（f<sub>d</sub> = 1378.322239 Hz）；振盪週期 **725.520 µs**；包絡時間常數 **200.000 µs**；超越量 **16.3034 %** |

### 09 `09-弦波與相量.html`

**目標**：解釋一個看似魔術的動作——為什麼可以把時間變數丟掉、只留一個複數——並讓讀者親手做相量加法，看見「大小直接相加」是錯的。

**要點**：弦波（sinusoid）v(t) = V<sub>m</sub>cos(ωt + φ)，三個參數——振幅 V<sub>m</sub>、角頻率 ω（rad/s，ω = 2πf）、相位 φ（rad 或 °）；**線性時不變電路對弦波的關鍵性質**：輸入是某頻率的弦波，所有電壓電流也都是**同頻率**的弦波，只有振幅與相位不同——所以頻率是已知的、不必當未知數；歐拉公式 e<sup>jθ</sup> = cos θ + j sin θ，於是 V<sub>m</sub>cos(ωt + φ) = Re{V<sub>m</sub>e<sup>jφ</sup> ⋅ e<sup>jωt</sup>}；**相量（phasor）** <strong>V</strong> = V<sub>m</sub>∠φ 就是把 e<sup>jωt</sup> 這個「所有人共有的部分」省掉之後剩下的複數；**電機寫 j 不寫 i**，因為 i 已經是電流；**有效值（root-mean-square, rms）** V<sub>rms</sub> = V<sub>m</sub>/√2（僅對弦波成立），它的定義是「產生同樣平均功率的直流值」；相量相加＝複數相加＝**先化成直角座標再分別加實部虛部**；相量只在**同頻率**之間有意義。來源：06-電路學-上 §4.1。

**推導必寫**：（a）為什麼可以省掉 e<sup>jωt</sup>：線性電路對弦波的運算只有加、減、乘常數、微分、積分。微分 e<sup>jωt</sup> 得 jωe<sup>jωt</sup>，積分得 e<sup>jωt</sup>/(jω)——**e<sup>jωt</sup> 微分之後還是自己乘一個數**，所以每一項都帶著同一個 e<sup>jωt</sup>，可以整條式子約掉。這是相量法能成立的**唯一理由**，要寫清楚。（b）相量加法：<strong>V</strong><sub>1</sub> + <strong>V</strong><sub>2</sub> = (V<sub>1</sub>cos φ<sub>1</sub> + V<sub>2</sub>cos φ<sub>2</sub>) + j(V<sub>1</sub>sin φ<sub>1</sub> + V<sub>2</sub>sin φ<sub>2</sub>)，再化回極式：大小 = √(實² + 虛²)、角度 = atan2(虛, 實)。（c）**為什麼大小不能直接相加**：只有 φ<sub>1</sub> = φ<sub>2</sub> 時才成立。一般情況下 |<strong>V</strong><sub>1</sub> + <strong>V</strong><sub>2</sub>| ≤ |<strong>V</strong><sub>1</sub>| + |<strong>V</strong><sub>2</sub>|（三角不等式），而且可能小很多。（d）**有效值的推導**：P<sub>平均</sub> = (1/T)∫<sub>0</sub><sup>T</sup> (V<sub>m</sub>cos ωt)²/R dt = V<sub>m</sub>²/(2R)，令它等於 V<sub>rms</sub>²/R，得 V<sub>rms</sub> = V<sub>m</sub>/√2 = 0.707107V<sub>m</sub>。**注意這個 1/√2 只對弦波成立**，方波的 rms 等於峰值。

**數值實例**：<strong>V</strong><sub>1</sub> = 10∠30°、<strong>V</strong><sub>2</sub> = 6∠−45°（兩者同頻率）。

### 10 `10-阻抗與交流穩態.html`

**目標**：把歐姆定律升級成複數版 <strong>V</strong> = Z<strong>I</strong>，讓第 02–05 章的所有方法在交流電路上原封不動再用一次。

**要點**：阻抗（impedance）Z = <strong>V</strong>/<strong>I</strong>，單位 Ω，是複數但**不是相量**（它不對應時域的弦波）；三個元件的阻抗——Z<sub>R</sub> = R、Z<sub>L</sub> = jωL、Z<sub>C</sub> = 1/(jωC) = −j/(ωC)；電抗（reactance）X＝Z 的虛部，Z = R + jX；感抗 X<sub>L</sub> = ωL **隨頻率上升**、容抗 X<sub>C</sub> = 1/(ωC) **隨頻率下降**；導納（admittance）Y = 1/Z = G + jB；**KVL、KCL、串並聯、分壓分流、節點分析、網孔分析、疊加、戴維寧諾頓——全部在 Z 上照樣可用**，只是算術從實數換成複數；相位判讀——X > 0 感性、電流**落後**電壓；X < 0 容性、電流**超前**電壓；X = 0 純阻、同相；交流最大功率傳遞是**共軛匹配** Z<sub>L</sub> = Z<sub>th</sub>*（不是 Z<sub>L</sub> = Z<sub>th</sub>）。來源：06-電路學-上 §4.2–§4.3、§4.5。

**推導必寫**：（a）**Z<sub>L</sub> = jωL 是怎麼來的**：時域 v = L ⋅ di/dt。設 i(t) = Re{<strong>I</strong>e<sup>jωt</sup>}，微分得 di/dt = Re{jω<strong>I</strong>e<sup>jωt</sup>}，所以 v(t) = Re{jωL<strong>I</strong>e<sup>jωt</sup>}，比對 v(t) = Re{<strong>V</strong>e<sup>jωt</sup>} 得 <strong>V</strong> = jωL<strong>I</strong>。**微分變成乘 jω，這就是全部的魔術。**（b）Z<sub>C</sub> 同理由 i = C ⋅ dv/dt 得 <strong>I</strong> = jωC<strong>V</strong>，所以 Z<sub>C</sub> = 1/(jωC)。把分母的 j 有理化：1/(jωC) = −j/(ωC)，**所以電容的電抗是負的**。（c）j 的相位意義：乘上 j 等於逆時針轉 90°。所以電感電壓比電流超前 90°、電容電壓比電流落後 90°。（d）串聯 RLC 的總阻抗 Z = R + j(ωL − 1/(ωC))，虛部在某個頻率會歸零——**這就是第 13 章共振的伏筆**。（e）從 |Z| 與 ∠Z 讀電流：|<strong>I</strong>| = |<strong>V</strong>|/|Z|、∠<strong>I</strong> = ∠<strong>V</strong> − ∠Z。

**數值實例**：R = 50 Ω、L = 10 mH、C = 1 µF 串聯，f = 1000 Hz，V<sub>s</sub> = 10 V（有效值）。

### 11 `11-交流功率與功因.html`

**目標**：說清楚為什麼交流電路要用三個「功率」而不是一個，以及工廠為什麼要花錢裝電容櫃。

**要點**：瞬時功率 p(t) = v(t)i(t) 在交流下會**上下振盪甚至變負**（負代表能量正在從負載送回電源）；**平均（實）功率 P = V<sub>rms</sub>I<sub>rms</sub>cos θ**，單位 W，這是真正變成熱、光、機械功的部分；**無效功率 Q = V<sub>rms</sub>I<sub>rms</sub>sin θ**，單位 var，這是在源與儲能元件之間來回搬、平均為零但**確實佔用電流**的部分；**視在功率 S = V<sub>rms</sub>I<sub>rms</sub> = √(P² + Q²)**，單位 VA，這是線路與變壓器實際要承受的；**功率因數（power factor）pf = cos θ = P/S**，θ 是電壓相對電流的相位差；**複數功率** <strong>S</strong> = P + jQ = <strong>V</strong><sub>rms</sub><strong>I</strong><sub>rms</sub>*；感性負載 Q > 0（落後功因）、容性負載 Q < 0（超前功因）；**功因校正**——在感性負載旁**並聯**電容供給 −Q，抵消掉一部分感性 Q，讓 S 變小、線電流變小、線損變小。來源：06-電路學-上 §4.4。

**推導必寫**：（a）從 p(t) = V<sub>m</sub>cos(ωt) ⋅ I<sub>m</sub>cos(ωt − θ) 用積化和差展開：p(t) = (V<sub>m</sub>I<sub>m</sub>/2)[cos θ + cos(2ωt − θ)]。**第一項是常數（就是 P），第二項是兩倍頻的振盪且平均為 0。** 代入 V<sub>rms</sub> = V<sub>m</sub>/√2 得 P = V<sub>rms</sub>I<sub>rms</sub>cos θ。這個展開必須完整寫出，否則 cos θ 看起來像憑空冒出來。（b）功率三角形：P、Q 互相垂直（因為一個對應 cos、一個對應 sin），所以 S² = P² + Q²，θ 是 P 與 S 的夾角。（c）**為什麼並聯電容**：並聯不改變負載電壓，所以不改變負載自己的 P 與 Q；電容提供 Q<sub>C</sub> = −V<sub>rms</sub>²/X<sub>C</sub> = −ωCV<sub>rms</sub>²，直接從總 Q 扣掉。（d）**校正電容值的公式**：目標功因 pf₂ → θ₂ = arccos(pf₂) → 目標 Q₂ = P ⋅ tan θ₂ → 需要補償 Q<sub>C</sub> = Q₁ − Q₂ → **C = Q<sub>C</sub>/(ωV<sub>rms</sub>²)**。（e）**省下的是什麼**：P 完全沒變（負載該做的功一樣多），變小的是 S 與 I，而線損 ∝ I²，所以線損降的比例是 (I₂/I₁)² = (pf₁/pf₂)²。

**數值實例**：V<sub>rms</sub> = 220 V、負載 Z = 10 + j7.5 Ω（感性）、f = 60 Hz、目標功因 0.95。

### 12 `12-一階濾波器與頻率響應.html`

**目標**：把「電路對不同頻率的反應」變成一個可以逐點算出來的函數，並讓 −3 dB、−20 dB/decade 這些行話變成能自己算的數字。

**要點**：轉移函數（transfer function）H(jω) = <strong>V</strong><sub>out</sub>/<strong>V</strong><sub>in</sub>，是複數，同時帶著增益（大小）與相移（角度）；RC 低通 H(jω) = 1/(1 + jωRC)——輸出取自電容，因為高頻時 Z<sub>C</sub> 小、分壓分得少；RC 高通 H(jω) = jωRC/(1 + jωRC)——輸出取自電阻；**截止頻率** f<sub>c</sub> = 1/(2πRC)，定義是 |H| 掉到 1/√2 = 0.707107 的頻率，換成分貝是 **−3.010300 dB**，功率剛好剩一半（所以又叫半功率點）；**分貝（decibel, dB）** 對電壓是 20log<sub>10</sub>|H|、對功率是 10log<sub>10</sub>(P<sub>2</sub>/P<sub>1</sub>)，**兩個係數不同不是筆誤**，因為 P ∝ V²；波德圖（Bode plot）規則——一個極點在 f ≫ f<sub>c</sub> 時貢獻 **−20 dB/decade** 的斜率與趨近 −90° 的相移，零點相反；一階低通在 f<sub>c</sub> 的相位是 **−45°**（剛好是最終 −90° 的一半）。來源：06-電路學-下 §7.1–§7.2、§7.4–§7.5。

**推導必寫**：（a）**RC 低通的轉移函數怎麼來**：這就是分壓，只是電阻換成阻抗。H = Z<sub>C</sub>/(R + Z<sub>C</sub>) = [1/(jωC)]/[R + 1/(jωC)]，分子分母同乘 jωC 得 H = 1/(1 + jωRC)。（b）大小與相位：|H| = 1/√(1 + (ωRC)²)、∠H = −arctan(ωRC)。（c）**f<sub>c</sub> 為什麼是 1/(2πRC)**：令 ωRC = 1 → ω<sub>c</sub> = 1/(RC) → f<sub>c</sub> = ω<sub>c</sub>/(2π) = 1/(2πRC)。此時 |H| = 1/√2，20log<sub>10</sub>(1/√2) = −10log<sub>10</sub>2 = −3.010300 dB，∠H = −arctan(1) = −45°。（d）**−20 dB/decade 怎麼來**：當 ωRC ≫ 1，|H| ≈ 1/(ωRC)，頻率乘 10 倍則 |H| 變 1/10，20log<sub>10</sub>(1/10) = −20 dB。所以每十倍頻掉 20 dB。（e）**RC 低通與第 07 章是同一個電路**：τ = RC，而 f<sub>c</sub> = 1/(2πτ)。時域的「反應慢」與頻域的「高頻被砍掉」是同一件事的兩種說法，這句話要寫出來。

**數值實例**：R = 1 kΩ、C = 0.1 µF → RC = **0.000100000 s**（＝100 µs，也就是第 07 章的 τ）、f<sub>c</sub> = 1/(2π × 10<sup>−4</sup>) = **1591.549431 Hz**。

### 13 `13-RLC共振與品質因數.html`

**目標**：解釋為什麼加一顆電感就能讓電路「只挑一個頻率」，並讓 Q 這個字從形容詞變成可以算的數字。

**要點**：串聯 RLC 的阻抗 Z = R + j(ωL − 1/(ωC))，虛部歸零時 **共振（resonance）**發生，ω<sub>0</sub> = 1/√(LC)；共振時 |Z| = R **最小**、電流最大、電壓電流同相；**品質因數（quality factor, Q）** Q = ω<sub>0</sub>L/R = 1/(ω<sub>0</sub>RC) = (1/R)√(L/C)，物理意義是「每個週期儲存的能量 ÷ 每個週期損失的能量」× 2π；**頻寬（bandwidth）** B = ω<sub>0</sub>/Q（rad/s）或 f<sub>0</sub>/Q（Hz），定義是電流降到最大值 1/√2（半功率）的兩個頻率之差；半功率頻率的閉合式 ω = ω<sub>0</sub>[√(1 + 1/(4Q²)) ± 1/(2Q)]；**Q 與第 08 章的 ζ 互為倒數關係 Q = 1/(2ζ)**——高 Q ＝ 低阻尼 ＝ 選頻銳利 ＝ 振鈴久，**這是同一件事，不是取捨可以繞過的**；共振時 L 與 C 上的電壓各自是源電壓的 **Q 倍**（電壓放大），但兩者相位相反互相抵消，所以總和仍是源電壓。來源：06-電路學-下 §7.3、§6.1。

**推導必寫**：（a）令 Im(Z) = 0：ω<sub>0</sub>L = 1/(ω<sub>0</sub>C) → ω<sub>0</sub>² = 1/(LC) → ω<sub>0</sub> = 1/√(LC)。（b）**Q 的三種寫法互相等價**：Q = ω<sub>0</sub>L/R，代入 ω<sub>0</sub> = 1/√(LC) 得 Q = L/(R√(LC)) = (1/R)√(L/C)；再由 ω<sub>0</sub>L = 1/(ω<sub>0</sub>C) 可得 Q = 1/(ω<sub>0</sub>RC)。三條都要寫出來。（c）**半功率頻率**：電流降到 1/√2 表示 |Z| = √2R，即 |X| = R，也就是 ωL − 1/(ωC) = ±R。解這個二次方程得 ω = ω<sub>0</sub>[√(1 + 1/(4Q²)) ± 1/(2Q)]，兩根相減剛好是 ω<sub>0</sub>/Q = B。（d）**電壓放大**：共振時 I = V<sub>s</sub>/R，所以 |V<sub>L</sub>| = I ⋅ ω<sub>0</sub>L = V<sub>s</sub>ω<sub>0</sub>L/R = **QV<sub>s</sub>**。同理 |V<sub>C</sub>| = QV<sub>s</sub>。**這是元件電壓超過源電壓的合法情況**，設計時要注意耐壓。（e）**Q 與 ζ**：ζ = α/ω<sub>0</sub> = [R/(2L)]/ω<sub>0</sub> = R/(2ω<sub>0</sub>L) = 1/(2Q)。

**數值實例**：L = 10 mH、C = 1 µF（**與第 08 章同一組**）、R = 10 Ω、V<sub>s</sub> = 1 V。

**不要混淆**：**共振（外部驅動、持續餵能量、看穩態）與第 08 章的自然振盪（自己振完就停、看暫態）是不同現象**，只是共用 ω<sub>0</sub>；串聯共振是 |Z| **最小**、電流最大，並聯共振（本課只點名）是 |Z| **最大**、電流最小，兩者結論相反；Q 有兩個常見定義（元件的 Q 與電路的 Q），本課講的是電路的；ω<sub>0</sub> 與 ω<sub>d</sub> 不同（ω<sub>d</sub> 還要打 √(1−ζ²) 的折）；**共振時元件電壓可以超過源電壓**，這不違反能量守恆（能量是在 L 和 C 之間來回，不是憑空生出來的）；高 Q 不是「比較好」，要看你要選擇性還是要快速安定。

**可觀察證據**：掃頻量輸出電壓，找到峰值就是 f<sub>0</sub>，找到降到 70.7 % 的兩個頻率相減就是 B，Q = f<sub>0</sub>/B。**能證明**：f<sub>0</sub>、B、Q 三個量，而且**只用一台函數產生器加一台示波器就能全部量到**。**不能證明**：L 和 C 各自的值（f<sub>0</sub> 只給你乘積 LC）；也不能證明 R 就是你外接的那顆——**量到的 Q 幾乎一定比理論值低**，因為電感的繞線電阻、電容的等效串聯電阻（ESR）、以及訊號源的輸出阻抗都算進 R 裡。這個差距本身就是有用的資訊：它告訴你元件的實際損耗。共振時記得先確認元件耐壓，Q 倍放大是真的會炸電容的。

**連到哪門課**：收音機選台、無線充電的線圈設計、EMI 濾波器、石英晶體（Q 可達數萬）；控制系統的共振峰與相位裕度。二階系統的 ζ 見 `../../../共通基礎/數學/互動課程/07-常微分方程.html`。

### 14 `14-變壓器與三相.html`

**目標**：用「兩個線圈共用磁通」解釋變壓器為什麼能同時換電壓、換電流、換阻抗，並把電路學接到實際的三相供電。

**要點**：互感（mutual inductance）M——線圈 1 的電流變化在線圈 2 感應出電壓 v<sub>2</sub> = M ⋅ di<sub>1</sub>/dt；**耦合係數** k = M/√(L<sub>1</sub>L<sub>2</sub>) ∈ [0, 1]，k = 1 是全耦合（沒有漏磁）；**理想變壓器**假設 k = 1、繞線電阻為 0、鐵損為 0、激磁電流可忽略，此時 V<sub>2</sub>/V<sub>1</sub> = N<sub>2</sub>/N<sub>1</sub>、I<sub>2</sub>/I<sub>1</sub> = N<sub>1</sub>/N<sub>2</sub>——**電壓升幾倍，電流就降幾倍，功率不變**；**阻抗轉換** Z<sub>ref</sub> = Z<sub>2</sub>(N<sub>1</sub>/N<sub>2</sub>)²，這是變壓器最被低估的用途（阻抗匹配、喇叭變壓器、射頻巴倫）；電力用途——電壓升高則同樣功率下電流變小，線損 I²R 跟著平方下降，所以長距離輸電要升壓；**三相系統**——三個相差 120° 的弦波；Y 接（星型）線電壓 V<sub>L</sub> = √3 × 相電壓 V<sub>p</sub>、線電流 = 相電流；Δ 接（三角）線電壓 = 相電壓、線電流 I<sub>L</sub> = √3 × 相電流；兩種接法都適用 **P = √3 ⋅ V<sub>L</sub> ⋅ I<sub>L</sub> ⋅ cos θ**；平衡三相的瞬時功率是**常數**（不像單相會脈動），所以馬達轉得平穩，這是工業配電用三相的根本理由。來源：06-電路學-下 第 10 章、06-電路學-上 §4.6。

**推導必寫**：（a）**匝比從哪來**：同一束磁通 Φ 穿過兩個線圈，v<sub>1</sub> = N<sub>1</sub>dΦ/dt、v<sub>2</sub> = N<sub>2</sub>dΦ/dt，相除得 v<sub>2</sub>/v<sub>1</sub> = N<sub>2</sub>/N<sub>1</sub>。**這條完全來自法拉第定律，不是變壓器的額外規則。**（b）**電流比**：理想變壓器不儲能也不耗能，所以 v<sub>1</sub>i<sub>1</sub> = v<sub>2</sub>i<sub>2</sub>，代入電壓比得 i<sub>2</sub>/i<sub>1</sub> = N<sub>1</sub>/N<sub>2</sub>。（c）**阻抗轉換**：從一次側看進去 Z<sub>ref</sub> = v<sub>1</sub>/i<sub>1</sub> = (N<sub>1</sub>/N<sub>2</sub>)v<sub>2</sub> / [(N<sub>2</sub>/N<sub>1</sub>)i<sub>2</sub>] = (N<sub>1</sub>/N<sub>2</sub>)² ⋅ (v<sub>2</sub>/i<sub>2</sub>) = (N<sub>1</sub>/N<sub>2</sub>)²Z<sub>2</sub>。**注意是平方**。（d）**Y 接的 √3 怎麼來**：線電壓是兩個相電壓的差，<strong>V</strong><sub>ab</sub> = <strong>V</strong><sub>a</sub> − <strong>V</strong><sub>b</sub>，兩者等幅且夾角 120°，相減的大小 = 2V<sub>p</sub>sin(60°) = √3V<sub>p</sub>。這個推導要寫出來，不能只說「記住是 √3」。（e）**P = √3V<sub>L</sub>I<sub>L</sub>cos θ 的來歷**：三相總功率 = 3V<sub>p</sub>I<sub>p</sub>cos θ。Y 接時 V<sub>p</sub> = V<sub>L</sub>/√3、I<sub>p</sub> = I<sub>L</sub>，代入得 3(V<sub>L</sub>/√3)I<sub>L</sub>cos θ = √3V<sub>L</sub>I<sub>L</sub>cos θ。Δ 接時 V<sub>p</sub> = V<sub>L</sub>、I<sub>p</sub> = I<sub>L</sub>/√3，代入得同一個式子。**兩種接法用同一條公式，這才是它好用的原因。**

**數值實例（變壓器）**：N<sub>1</sub>:N<sub>2</sub> = 1000:100（匝比 n = 10）、V<sub>1</sub> = 220 V、負載 Z<sub>L</sub> = 8 Ω。

| 量 | 算式 | 結果 |
| --- | --- | --- |
| 二次側電壓 | 220/10 | **22.000000 V** |
| 二次側電流 | 22/8 | **2.750000 A** |
| 一次側電流 | 2.75/10 | **0.275000 A** |

耦合：若 L<sub>1</sub> = 10 mH、L<sub>2</sub> = 0.1 mH（感值比 = 匝比平方 = 100，符合 L ∝ N²），則 √(L<sub>1</sub>L<sub>2</sub>) = **1.000000 mH**；k = 0.98 時 M = **0.980000 mH**。k < 1 的那部分就是漏感，它是真實變壓器有壓降與頻寬限制的原因。

**數值實例（三相）**：線電壓 V<sub>L</sub> = 220 V、每相負載 8 Ω（純阻，cos θ = 1）。

| 接法 | 相電壓 V<sub>p</sub> | 相電流 I<sub>p</sub> | 線電流 I<sub>L</sub> | 總功率 P |

| **Y 接** | 220/√3 = **127.017059 V** | 127.017059/8 = **15.877132 A** | **15.877132 A**（＝I<sub>p</sub>） | √3 × 220 × 15.877132 = **6050.000000 W** |
| **Δ 接** | **220.000000 V**（＝V<sub>L</sub>） | 220/8 = **27.500000 A** | √3 × 27.5 = **47.631397 A** | √3 × 220 × 47.631397 = **18150.000000 W** |

**同一組負載、同一個線電壓，Δ 接拿到的功率剛好是 Y 接的 3 倍**（18150/6050 = 3），因為每相分到的電壓是 √3 倍，功率是它的平方。這就是為什麼馬達可以用「Y–Δ 啟動」：先用 Y 接降低啟動電流，轉起來再切到 Δ 接出全功率。

### 5.3 撰寫要求

- 「不要混淆」欄位必須指出**邊界**，不是同義詞。範例（builder 照這個密度寫）：

### 6.4 回饋規則

- 答對：`<strong>答對</strong>` ＋ 一句**為什麼對**（不是只說「正確」）＋ 來源章節連結。
- 答錯：`<strong>再看一次</strong>` ＋ 正確答案 ＋ 一句**錯在哪裡的常見原因** ＋ 來源章節連結。**不得使用「錯誤」「失敗」「不及格」等字眼，不得用羞辱式語言。**
- 空白作答：提示「先填一個數字」或「先選一個選項」，不判對錯。

## 10. 來源筆記缺口（僅列出，本案不回頭改寫筆記）

以下是撰寫本 spec 時發現、來源筆記沒有但本課需要的內容。builder **可以自行補上教學文字**（都是標準大學課綱內容或可由既有段落推得），但**不得回頭修改 `.md` 筆記**。Lead 可另案決定是否補進筆記。

2. **筆記沒有定義「電荷、電流、電壓、功率」四個基本量**，直接從「三個被動元件」開始。本課的 00 章是為零基礎讀者補的，來源只有「這科在學什麼」那一段的集總元件描述。
3. **集總假設的量化判準（d < λ/20）筆記沒有**，只說「當訊號波長遠大於電路尺寸時」。λ/20 是標準工程門檻，本課引入它是為了讓 00 章的互動有判準，已在該章推導段落寫明來歷。
4. **筆記沒有講被動符號規約（passive sign convention）**，也沒有講「假設電流方向算出負值代表方向相反」。本課在 00、02 章補上。
5. **筆記沒有講 KCL/KVL 的失效條件**（節點寄生電容囤積電荷、回路穿過變化磁通）。本課在 02 章補上，這是 principles-first 要求的「公式要附假設與極端案例」。
6. **筆記沒有給有效值對非弦波的說明**，只寫 V<sub>rms</sub> = V<sub>m</sub>/√2。本課在 09 章明確標示這條只對弦波成立，並在可觀察證據段落補上「True RMS 電表」的實務差異。
