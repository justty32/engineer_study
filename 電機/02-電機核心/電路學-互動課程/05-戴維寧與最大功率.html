05・從兩個端點濃縮整個線性電路

戴維寧與最大功率：先看來源有多硬，再選負載

負載不必知道上游有幾顆電阻、幾個來源；從指定的兩個端點看進去，任何線性電路都能用一個等效電壓源與一個串聯電阻描述。這個觀點不只縮短計算，也直接揭露最大功率與最高效率為何不是同一個設計目標。

這章假設已懂：03 節點與網目分析、04 疊加原理與相依源。

痛點：負載一直換，難道每次都要重解整個電路？

感測器、天線、喇叭或電源負載接在同一組端點時，上游內部不會因為換負載就值得重畫一次方程。真正需要的是一個端口模型：負載開路時能看到多少電壓，以及負載取電流後端電壓會下垂多少。初學者常把等效內阻當成原電路某一顆真實電阻，或把「功率最大」誤讀為「能源使用最有效率」，因此即使會套公式，也可能做出完全相反的工程選擇。

戴維寧等效（Thévenin equivalent）以 Vth 串聯 Rth 表示端口；諾頓等效（Norton equivalent）以 IN 並聯同一個 Rth 表示。兩者不是兩套不同電路，而是同一條端口電壓電流關係的兩種寫法，並由 IN = Vth/Rth 互換。

白話直覺：端口只需要一個空載高度與一個下垂程度

可以把等效模型暫想成替複雜來源做一張兩欄名片：空載電壓與內部阻力；比喻到此為止，Vth 是真正在指定端點量到的開路電壓，Rth 則是端口電流改變時電壓下垂的比例，不是憑印象寫出的「來源品質」。

因果鏈從 Vs 與地開始：Vs 正端經 R1 到端點 A，A 經 R2 回地，負載 RL 也接在 A 與地之間。RL 接上後回路閉合，能量由 Vs 經上游電阻送往負載；負載取得的電流愈大，Rth 上的壓降愈大，A 的端電壓便下降。開路時沒有負載電流，A 保持 Vth；短路時 A 被拉到地，電流達 IN。這兩個極端夾出完整的線性端口行為。

求 Rth 時，只有獨立源要歸零。若內部有相依源，控制關係仍須存在，不能只看電阻串並聯；應在端口加一個已知測試電壓或測試電流，用 Rth = vtest/itest 求得。這個方法也說明 Rth 的定義是「由端口看入的增量比值」。

端口等價的核心是：不論外面接哪一顆線性負載，原電路與等效電路都給出相同的端電壓與端電流。等價不要求內部支路相同，也不要求總耗能分布相同。若改看另一對端點，Vth 與 Rth 通常也會改變，所以每次分析都必須先明確標出端口與參考極性，不能把一組參數當成整台裝置唯一不變的身分。

來源：06-電路學-上 §2.5、§2.7。

推導：由開路、源歸零到最大功率條件

（a）端口拓樸。Vs 正端 → R1 → 端點 A；端點 A → R2 → 地；Vs 負端 → 地；負載 RL 接在 A 與地之間。Vs、Vth 單位 V，IN、IL 單位 A，R1、R2、Rth、RL 單位 Ω。假設所有元件線性、時不變、來源與導線理想，先限於直流電阻電路。

（b）求 Vth。把 RL 拿掉，端口沒有外流電流，只剩 R1、R2 分壓：

Vth = VsR2 / (R1 + R2)

（c）求 Rth。把獨立電壓源 Vs 歸零成短路，從 A 看向地，R1 與 R2 都接地，因此 Rth = R1‖R2。符號 ‖ 讀作「並聯」，不是絕對值也不是範數；兩個電阻時：

Rth = R1R2 / (R1 + R2)

（d）求 IN 並驗算。把 A 對地短路，R2 兩端為 0 V，短路電流只由 Vs 經 R1 提供，所以 IN = Vs/R1。把上兩式相除，可得 Vth/Rth = Vs/R1，正好等於 IN。

（e）完整推導最大功率。等效電路接上 RL 後，IL = Vth/(Rth + RL)。負載功率 PL 單位 W：

PL = IL²RL = Vth²RL / (Rth + RL)²

對 RL 微分。除以始終為正的分母後，決定零點的分子是 Vth²[(Rth + RL)² − RL ⋅ 2(Rth + RL)]。提出公因式後成為 Vth²(Rth + RL)(Rth − RL)。令 dPL/dRL = 0，在正電阻範圍唯一可行解是 RL = Rth；兩側功率都較小，所以此點是最大值。代回得：

Pmax = Vth² / (4Rth)

（f）效率。來源送進串聯回路的總功率由 Rth 與 RL 分擔，所以 η = PL/P總 = RL/(Rth + RL)。匹配時 η = 1/2 = 50 %；η 隨 RL 單調增加，但 PL 過了匹配點反而下降，這就是兩個目標衝突的數學根源。

也可從兩個極端檢查式子。RL → 0 時近似短路，負載電壓趨近 0，因此即使電流很大，PL 仍趨近 0，大多數功率耗在 Rth。RL → ∞ 時近似開路，電流趨近 0，負載功率同樣趨近 0；效率公式形式上趨近 100 %，只是分子與分母都趨近零，沒有實用輸出。功率曲線在兩端都為零，中間才必有最大值，這和微分所得的匹配點互相驗證。

自由實驗：掃描負載倍率

Vs 正端經 R1 到端點 A，A 經 R2 回地，Vs 負端接地；負載 RL 接在 A 與地之間。調整來源與負載倍率，觀察端口等效、負載功率和效率如何一起改變。

不要混淆

  • Rth 是由指定端口看到的等效內阻，不保證原電路內真的存在一顆同值電阻。
  • 獨立源歸零後可化簡電阻；相依源不能歸零，含相依源時應加測試源求端口的 v/i。
  • 戴維寧與原電路只在端口電壓電流關係上等價，不能用等效電路推回內部每顆元件的功率。
  • 最大功率傳遞不等於最高效率；匹配點效率只有 50 %，而接近開路時效率趨近 100 %、功率卻趨近 0 W。
  • 直流純電阻匹配是 RL = Rth；交流最大功率要做共軛匹配 ZL = Zth*，不能把兩式混用。
  • 開路電壓可安全量測；短路電流是理想模型的定義工具，不代表真實電源允許直接短路。

可觀察證據：用兩次端電壓反推等效內阻

先拆下負載，用高輸入阻抗三用電表量 A 對地的開路電壓 Voc，它近似 Vth；電表輸入阻抗必須遠大於 Rth，否則電表本身已成為負載。再接一顆已知電阻 R，量負載端電壓 V，由 Rth = R(Voc/V − 1) 反推。換幾個負載並記錄 V 與電流，可檢查端口關係是否為直線。

能證明什麼：這些量測能證明指定端口在量測範圍內具有某組 Vth 與 Rth，也能以負載功率掃描看見最大值落在 RL 接近 Rth。不能證明什麼：它們不能辨識內部拓樸，因為無限多種內部電路可有同一組端口參數；也不能證明更大電流下仍線性。不要直接短路量 IN，真實電源可能限流、過熱或損壞。

若電表輸入阻抗已知，也可把它視為第一個已知負載並校正讀值；若來源會限流或溫升，應從小電流開始逐步掃描，並比較端口直線是否彎曲。一旦 V 與 I 不再呈線性關係，單一常數 Rth 只能描述局部工作範圍，不能外推到保護動作之後。

選負載前還要先寫清楚任務。若目標是從高阻感測器讀出準確電壓，量測電路的輸入阻抗應遠大於 Rth，避免負載效應；若目標是從微弱通訊源取得最多可用訊號功率，匹配才有意義；若目標是供電，則希望來源等效內阻遠小於負載，使壓降、發熱與能量損失都小。相同的戴維寧參數沒有唯一「最佳」負載，最佳值永遠附著在功率、效率、電壓準確度或雜訊等明確指標上。

連到哪門課

電子學會用戴維寧模型描述偏壓網路與放大器輸出阻抗；射頻、天線與通訊系統關心匹配，因為微弱訊號需要盡可能送入下一級；電力工程與電源供應器則通常追求高效率與低壓降，不會把一半功率燒在來源內阻。感測器介面也會用端口模型估算負載效應與量測誤差。

最大功率條件的核心是對負載電阻做極值判斷，可回到工程數學先修的極限與導數。第 07 章還會從儲能元件兩端看出去求 Rth，再把它放進 RC 或 RL 的時間常數；因此這章的「端口視角」也是暫態分析的必要工具。

實務資料表常用負載調整率描述輸出電壓隨負載改變的程度，這可視為 Rth 觀念在有限工作範圍內的延伸。不過穩壓器含回授、限流與保護狀態，端口關係未必是一條跨全範圍的直線；只能在指定工作點附近使用線性等效，不能把保護區也硬塞進同一模型。
