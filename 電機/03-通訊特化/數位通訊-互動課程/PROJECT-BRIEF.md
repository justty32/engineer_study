## 1. 一句話定位

把 `電機/03-通訊特化/15-數位通訊-上.md`（135 行）與 `15-數位通訊-下.md`（167 行）做成一門**從「位元怎麼變成波形、再怎麼在雜訊裡被判回位元」開始蓋、每章一個可即時回饋自由實驗**的進階銜接互動課：訊號空間與正交基底、M 進制星座與最小距離、最佳接收機與 ML／MAP 判決、各調變的誤碼率公式、載波相位與同步、零強制與 MMSE 等化、LMS 自適應等化、(7,4) 漢明碼與症狀解碼、摺積碼與 Viterbi、交錯與突發錯誤、展頻與 CDMA、OFDM 與循環字首。全程繁體中文、純文字公式、完全離線、**不用亂數**。

課名（顯示於 index 的 `h1`）：**數位通訊（零基礎互動課）**

部署 slug：`digital-communications`（`.github/workflows/pages.yml` 課程表的目標目錄；掛站接線不屬本隊，由收尾 agent 處理）。

本課套用 **foundations-first**（零基礎入口、繁中／英文術語、名詞與概念分開、拆頁）＋ **principles-first**（每章先講為什麼、量與單位、簡化假設、儀器證據、易混概念拆開）。通訊主題依 principles-first 的規定向上接一層：**電氣現象 → 位元與時序 → 訊息意義**，不從協定名稱倒推物理。

**本課最大的特殊性**：它是「通訊系統」互動課（同一層目錄，剛完工）的**進階銜接層**。通訊系統課已教完星座圖入門、匹配濾波器、BER 入門、ISI／升餘弦、Shannon 極限——**那些是它的地盤，本課一行連回去、不重做**；本課從「為什麼星座點的距離可以算」（訊號空間）往下蓋，一路蓋到接收機、同步、等化、通道編碼入門、展頻與 OFDM。通道編碼只做入門（(7,4) 漢明碼、K ＝ 3 的摺積碼），深度（LDPC、Turbo、Polar、BCH、RS 的構造與解碼）留給「資訊理論與編碼」課。切分規則寫在第 8 節，是本課**最重要的驗收項**之一。

**配額詞的規則（踩過的雷，不得偏離）**：上表「恰好 1 處」的詞**只允許出現在 `名詞與概念字典.html` 對應卡片的「不要混淆」欄位**，作為「你在對照表或別的書會看到這個寫法」的對照，且**必須以明碼 UTF-8 字元寫出，嚴禁用 `&#NNNNN;` 之類的 HTML 實體或任何轉義規避掃描**。verifier 的掃描一律先 `html.unescape` 再計數。

其餘用語裁決：

1. **減號與負號一律 U+2212 `−`**；半形 `-` 只出現在檔名、CSS class、`<input>` 屬性值、`data-search` 與使用者輸入。dB 值為負時同樣用 `−`：`−1.249387 dB`。
2. **乘號一律 `×`（U+00D7）**，前後各一個半形空格。**全課 0 個 ASCII `*` 當乘號。**
3. **微符號一律 U+00B5 `µ`**，且只出現在 `µs` 這類單位前；希臘 mu（U+03BC `μ`）**只當 LMS 步長符號**用。機械判準：全課 `μs`（U+03BC 接 s）0 個；`µ`（U+00B5）後面一律緊接單位字母。
4. **希臘字母與符號固定**：α（滾降係數）、σ（每維雜訊標準差）、φ（相位誤差）、μ（LMS 步長）、ρ（相關係數）、τ（延遲）、γ（判決門檻）、Δf（子載波間距或頻率偏移）、π、Σ。ω 不出現，正文一律用 f（Hz）。
5. **dB 家族寫法固定**：`dB`（比值）。不寫 `db`、`DB`。
6. **符號寫法**：每位元能量對雜訊密度比寫 `E<sub>b</sub>/N<sub>0</sub>`（`<label>`、`<option>` 內寫 `E_b/N_0`）；每符元能量 `E<sub>s</sub>`；每編碼位元能量 `E<sub>c</sub>`；訊雜比寫 `SNR`；最小距離 `d<sub>min</sub>`、自由距離 `d<sub>free</sub>`；符元率 `R<sub>s</sub>`、位元率 `R<sub>b</sub>`、編碼率 `R`；處理增益 `G<sub>p</sub>`；子載波間距 `Δf`；有效符元時間 `T<sub>u</sub>`、循環字首長度 `T<sub>cp</sub>`。
7. **單位一律半形英文緊接數字後空一格**：`1000 kbit/s`、`312.500000 kHz`、`3.200000 µs`。位元率單位寫 `kbit/s`／`Mbit/s`，不寫 `kbps`；符元率單位寫 `kbaud`。
8. 術語首次出現寫 `繁中（English, 縮寫）`，例：`最大似然（maximum likelihood, ML）`、`循環字首（cyclic prefix, CP）`。
9. 人名譯法固定：**漢明**（Hamming）、**高斯**（Gauss）、**奈奎斯特**（Nyquist）、**傅立葉**（Fourier）；**Viterbi**、**Gray**、**Walsh**、**Barker**、**Costas**、**Shannon**、**Gardner**、**Rayleigh** 保留原文。
10. **二進位字串**：位元序列以半形數字直接連寫，需要分組時每 4 位一個半形空格（`1011 010`）；碼片序列以 `+1`／`−1` 或 `+`／`−` 寫。
11. **機率一律科學記號 `m × 10<sup>e</sup>`**（m 六位小數）；畫面 0 個 ASCII `e-5` 形式。

### 不做

- **不重做「通訊系統」教過的機制**（第 8.1 節）：dB 帳本、AM／FM、超外差、雜訊指數、取樣量化 PCM、ISI 與升餘弦、匹配濾波器推導、Q 函數定義、二元 BER（BPSK／ON-OFF／FSK）、五種星座的 d<sub>min</sub> 與最近鄰近似、Shannon 容量與極限、鏈路預算。本課一律一行 `p.prereq` 連回去。
- **不吃進「資訊理論與編碼」「數位信號處理」筆記**（`17-資訊理論與編碼.md`、`16-數位信號處理-*.md` 各自成課）：熵與互資訊、Huffman、通道容量定理的證明、LDPC／Turbo／Polar／BCH／Reed–Solomon 的構造與解碼、循環碼、FIR／IIR 設計、FFT 的蝶形運算。本課只在「連到哪門課」一句話點名。**全課 0 個 LDPC／Turbo／Polar 的公式或步驟**（只准在「留給資訊理論與編碼課」一句裡出現名稱）。

- **不改動 `電機/03-通訊特化/*.md`** 與 `電機/中英名詞對照表*.md`。筆記是唯讀來源。

1. **全課只有一把尺：距離除以雜訊標準差**。01 章把波形變成點之後，02 章的 d<sub>min</sub>、03 章的 ML 判決、04 章的所有誤碼率公式、05 章的相位旋轉、08／09 章的漢明距離與自由距離、11 章的處理增益，全部回到同一句話「誤判機率只看最近兩點的距離除以雜訊標準差」。
2. **每一招買到什麼、付了什麼**：高階調變買頻譜效率付 E<sub>b</sub>/N<sub>0</sub>；等化買零 ISI 付雜訊放大；通道編碼買編碼增益付頻寬（1/R 倍）與延遲；交錯買抗突發付延遲（深度 × 碼長）；展頻買抗干擾與多用戶付頻寬（G<sub>p</sub> 倍）；OFDM 買抗多徑付循環字首負擔與 PAPR。全課只有這一條取捨線。
3. **量級感是硬性要求**：BPSK 在 10 dB 的誤碼率 3.872108 × 10<sup>−6</sup>、16-QAM 追上 BPSK 要多付 3.846663 dB（誤碼率 10<sup>−5</sup>）、QPSK 相位誤差 10° 損失 1.817874 dB、回音 0.9 時零強制放大雜訊 7.212464 dB、(7,4) 漢明碼硬判決在 10<sup>−5</sup> 只賺 0.413375 dB、K ＝ 3 摺積碼 d<sub>free</sub> ＝ 5、Wi-Fi 的子載波間距 312.500000 kHz 與循環字首 0.800000 µs。讀者要能一眼判斷「這個數字合不合理」。
4. **比喻只能出現一次且立刻收回**。
5. **每章指出「軟體那一端可以做什麼」**。

## 5. 目標能力（學完能算什麼、能判斷什麼）

**能算**

1. 由 R<sub>b</sub>、編碼率 R、每符元位元數 k、滾降 α 算編碼後位元率、符元率、頻寬與頻譜效率，並說出 E<sub>s</sub>/N<sub>0</sub> ＝ k R E<sub>b</sub>/N<sub>0</sub>。
2. 由兩個訊號的能量與相關係數 ρ 算內積、訊號空間距離 d 與二元 ML 誤碼率 Q(d/√(2N<sub>0</sub>))，並判斷反極性、正交、ON-OFF 三種佈局的優劣。
3. 對 BPSK／QPSK／8-PSK／16-PSK／16／64／256-QAM 算歸一化 d<sub>min</sub>、平均最近鄰數、峰均功率比，並算出 Gray 映射與自然二進位映射下每次符元錯誤平均錯幾個位元。
4. 由先驗機率與 E<sub>b</sub>/N<sub>0</sub> 算 MAP 判決門檻，比較 ML 與 MAP 的錯誤率；對一個接收點算四個 QPSK 點的相關度量與距離平方並選出最近點。
5. 由 E<sub>b</sub>/N<sub>0</sub> 用九個誤碼率公式（BPSK／QPSK、8-PSK、16-PSK、16／64／256-QAM、DBPSK、非同調 BFSK、同調 BFSK）算誤碼率、期望錯誤數，並反解達到目標誤碼率所需的 E<sub>b</sub>/N<sub>0</sub>。
6. 由相位誤差 φ 算 BPSK 與 QPSK 的旋轉座標與誤碼率、等效 dB 損失；由歸一化頻率偏移算每符元轉幾度、幾個符元後跨過判決邊界。
7. 由回音係數 a 與輸入 SNR 算零強制等化器的雜訊放大倍數 1/(1 − a²)、輸出 SNR，與 MMSE 等化器的 MSE 與輸出 SNR，並指出何時兩者差距大。
8. 由步長 μ、回音 a、階數 L 跑 LMS 固定訓練序列，判斷是否收斂、e² 曲線在指定迭代的值、收斂後的抽頭與理想值差多少；算教科書上界 2/(L × P<sub>u</sub>)。
9. 對 (7,4) 漢明碼手算編碼、症狀與糾錯位置；判斷兩個錯誤為什麼會被誤糾；由 E<sub>b</sub>/N<sub>0</sub> 算硬判決編碼後誤碼率與編碼增益。
10. 對 K ＝ 3、率 1/2 的摺積碼手算編碼輸出、格狀圖轉移表，逐級寫出 Viterbi 路徑度量、回溯解碼，並說明 d<sub>free</sub> ＝ 5 為什麼保證糾 2 個錯。
11. 由交錯深度、碼長與突發長度算每個碼字被打到幾個位元、哪些碼字救不回來，以及交錯造成的延遲。
12. 由展頻因子 N、用戶數 K、干擾對訊號比 J/S 與熱雜訊 E<sub>b</sub>/N<sub>0</sub> 算處理增益、等效 E<sub>b</sub>/(N<sub>0</sub> ＋ I<sub>0</sub> ＋ J<sub>0</sub>) 與誤碼率，並比較同步 Walsh 碼與非同步隨機碼。
13. 由頻寬、子載波數、循環字首比例、最大多徑延遲與每子載波位元數算子載波間距、有效符元時間、循環字首長度、是否無 ISI、循環字首負擔、原始位元率、最壞 PAPR 與 1 kHz 頻率偏移佔子載波間距的百分比。

**能判斷**

- 同樣的 M，PSK 與 QAM 誰的 d<sub>min</sub> 大、大多少 dB；為什麼高階調變一定要 Gray 映射。
- 先驗不等時 ML 為什麼不是最佳；先驗差越大 MAP 賺越多。
- 為什麼 QPSK 對相位誤差比 BPSK 敏感得多；為什麼 Costas 迴路要配差分編碼或前導碼。
- 回音接近 1 時零強制為什麼崩潰而 MMSE 仍能用；步長太大為什麼發散、太小為什麼慢。
- 短碼的編碼增益為什麼小；低 E<sub>b</sub>/N<sub>0</sub> 時編碼為什麼反而更糟；硬判決與軟判決的差距。
- 突發長度超過交錯深度時哪些碼字會死；交錯的代價是延遲。
- 展頻不省功率也不省頻寬，它買的是抗干擾與多用戶。
- 循環字首不是浪費，它是「讓線性摺積變成圓形摺積」的代價；子載波間距太小為什麼對頻率偏移更敏感。

## 9. 教學邊界

| 簡化模型 | 在什麼範圍成立 | 超出會怎樣（正文必須明說） |
| --- | --- | --- |
| AWGN、理想同步（除 05 章外）、匹配濾波、等機率（除 03 章外） | 有線與視距鏈路的一階估計 | 衰落通道要再加裕度與分集；留給無線課 |
| 最近鄰近似 P<sub>s</sub> ≈ N<sub>avg</sub> Q(d<sub>min</sub>/(2σ)) | 高 E<sub>b</sub>/N<sub>0</sub> | 低 E<sub>b</sub>/N<sub>0</sub> 會算出 > 1，widget 夾在 1 以下並明說 |
| M-PSK／M-QAM 的誤碼率近似式（04 章） | Gray 映射、高 E<sub>b</sub>/N<sub>0</sub> | 低 E<sub>b</sub>/N<sub>0</sub> 誤差可達數十 %；精確式留給教科書 |
| 相位誤差 φ 固定不隨時間變（05 章） | 相位雜訊很慢 | 快變相位雜訊要用統計模型 |
| 兩抽頭通道 h ＝ [1, a]、無限長線性等化器（06 章） | a < 1（最小相位） | a ≥ 1 零強制不可實現；有限長等化器的結果會更差 |
| LMS 用固定 31 碼片訓練序列、無雜訊（07 章） | 教學示範 | 真實訓練序列更長、有雜訊，穩態 MSE 不會是 0 |
| 硬判決解碼、二元對稱通道（08、09 章） | 教學入門 | 軟判決可多賺約 2 dB；留給資訊理論與編碼課 |
| 突發錯誤＝連續 b 個位元全錯（10 章） | 突發模型 | 真實突發內部有隨機殘存，交錯的效果更好 |
| 展頻多用戶干擾用 (K − 1)/N 的簡單模型（11 章） | 等功率、非同步、隨機碼 | 功率控制失效時近遠效應會主導 |
| 循環字首只要 τ<sub>max</sub> ≤ T<sub>cp</sub> 就無 ISI（12 章） | 通道在一個符元內不變 | 都卜勒與相位雜訊會破壞子載波正交，留給無線課 |

**簡化不得講成工程保證。**
