## 第 1 章　離散時間訊號與系統（複習要點）

- 序列 $x[n]$。
- LTI 系統 → 卷積 $y[n]=\sum_k h[k]x[n-k]$。
- 差分方程 $\sum a_k y[n-k]=\sum b_m x[n-m]$。
- DTFT / Z 轉換：若單位圓在收斂域內，頻率響應為 $H(e^{j\omega})=H(z)|_{z=e^{j\omega}}$；因果 LTI 系統的所有極點都在單位圓內，當且僅當系統穩定。基礎推導見[信號與系統（下）](../02-電機核心/09-信號與系統-下.md)。

## 第 2 章　FIR 濾波器

### 2.1 性質
$$y[n]=\sum_{k=0}^{M-1}h[k]x[n-k]$$
$h[n]$ 有限長 → 本質穩定。
若 $h[n]=h[M-1-n]$（對稱，Type I／II）或 $h[n]=-h[M-1-n]$（反對稱，Type III／IV）→ **嚴格線性相位**；反對稱型常用於微分器與 Hilbert 轉換器。群延遲固定 = $(M-1)/2$ 樣本——通訊與聲音處理大優勢。

### 2.2 設計方法

**(a) 窗口法**
1. 對理想頻率響應做反 DTFT 得理想 $h_d[n]$。
2. 截斷到長度 $M$。
3. 乘上窗 $w[n]$ 降低旁瓣。

例如截止角頻率為 $\omega_c$ 的理想低通，在以零為中心的非因果形式中 $h_d[n]=\sin(\omega_cn)/(\pi n)$（$n\ne0$），且 $h_d[0]=\omega_c/\pi$；截斷後再平移成因果序列。

| 窗 | 旁瓣 (dB) | 過渡帶寬 |
| --- | --- | --- |
| 矩形 | $-13$ | 最窄 |
| Hann | $-32$ | 中 |
| Hamming | $-43$ | 中 |
| Blackman | $-58$ | 寬 |
| Kaiser | 可調 (β) | 可調 |

Kaiser 窗可用濾波器階數近似式 $M\approx(A-8)/(2.285\Delta\omega)$ 估長度；例如 $A=60$ dB、$\Delta\omega=0.1\pi$ 時，$M\approx72.4$，可先取 73 階再驗證規格。

**(b) 頻率採樣法**
在 $N$ 個等距頻率點指定振幅 / 相位 → IDFT。簡單但對中間頻率控制差。

**(c) Parks–McClellan（最佳等漣波）**
用 Remez 演算法在通帶 / 阻帶誤差等漣波下找最佳係數。長度最短達到指定規格的方法。

### 2.3 多相分解（Polyphase）
高速 FIR 在抽取 / 內插時，可以拆成多相子濾波器並行運算，省功又能在低時脈下做高速處理。

### 2.4 對稱性與運算節省
線性相位 FIR 可把對稱係數合併：長度 $M$ 的濾波器每個輸出只需 $\lceil M/2\rceil$ 個乘法器。

## 第 3 章　IIR 濾波器

### 3.1 結構
$$H(z)=\dfrac{\sum b_m z^{-m}}{1+\sum a_k z^{-k}}$$
含回授 → 可用較少係數達到陡峭頻率響應，但**可能不穩定**，且**相位非線性**。

### 3.2 設計：從類比原型轉換
1. 先在 $s$ 域設計（Butterworth、Chebyshev I/II、Elliptic、Bessel）。
2. 用**雙線性變換**：
   $$s=\dfrac{2}{T}\dfrac{1-z^{-1}}{1+z^{-1}}$$
   把整個左半 $s$ 平面映到單位圓內。映射關係 $\Omega=(2/T)\tan(\omega/2)$ 並非線性，因此需先做**頻率預扭曲（pre-warping）**。例如 $f_s=8$ kHz、數位截止 $f_c=1$ kHz 時，$\Omega_c=2f_s\tan(\pi f_c/f_s)\approx6627$ rad/s（約 1055 Hz）。

### 3.3 各家族特性

| 家族 | 通帶 | 阻帶 | 過渡帶 | 相位 |
| --- | --- | --- | --- | --- |
| Butterworth | 最大平坦 | 緩慢下降 | 寬 | 較好 |
| Chebyshev I | 等漣波 | 平滑 | 較窄 | 差 |
| Chebyshev II | 平滑 | 等漣波 | 較窄 | 差 |
| Elliptic（Cauer） | 等漣波 | 等漣波 | 最窄 | 最差 |
| Bessel | 平滑 | 緩慢 | 寬 | 最佳（接近線性） |

### 3.4 實作架構
- **直接型 I / II**：簡單但對係數量化敏感。
- **轉置型**：對某些量化情形較好。
- **級聯（cascade）二階節（biquad）**：把 IIR 拆成多個二階段串接；高階多項式的根對係數微小誤差很敏感，分成二階節可把量化影響限制在各節，因此實務上 IIR 幾乎都這樣實作。
- **平行（parallel）**
- **格狀（lattice）**：對應反射係數，常用於語音處理（LPC）。

### 3.5 定點實作議題
- **係數量化**：把極點推離原來位置，可能不穩。
- **訊號量化**：每次乘法後截斷產生雜訊。
- **溢位（overflow）**：要用飽和算術。
- **極限環（limit cycle）**：IIR 在無輸入時可能自我振盪。
- 解法：scaling、roundoff noise 分析、加抖動（dither）、選擇低靈敏度結構、用 Q 格式定點數規劃。

## 第 4 章　頻率變換

要從低通設計派生其他濾波器：
- 低通 → 高通、帶通、帶阻。
- $z$ 域的標準替換：
  - 高通：$z^{-1}\to -z^{-1}$
  - 帶通、帶阻：使用全通形式的有理頻率替換（Constantinides 變換）；例如低通轉帶通可用 $z^{-1}\to-z^{-1}(z^{-1}-\alpha)/(1-\alpha z^{-1})$，再由目標帶邊決定 $\alpha$。

## 第 5 章　線性相位 vs 最小相位

- **線性相位**：群延遲固定，但通常較長 → 高延遲。
- **最小相位**：所有零點在單位圓內，因此穩定可逆，且在相同幅度響應中能量最集中於前、延遲最小；代價是群延遲會隨頻率改變，造成相位失真。
- **全通（all-pass）**：$|H(e^{j\omega})|=1$，只影響相位 / 群延遲。

工程選擇：通訊 / 高保真音訊偏線性相位；即時控制 / 對話聲偏最小相位（低延遲）。

## 第 6 章　取樣前後端

### 6.1 ADC 前的抗摺疊濾波

ADC 取樣前要先用**類比抗摺疊濾波器（anti-aliasing filter）**把高於 $f_s/2$ 的能量壓低，否則高頻成分取樣後會摺回基頻，數位濾波已無法分辨它來自哪個頻率。實際設計會讓訊號通帶邊緣低於 $f_s/2$，把中間頻帶留給類比濾波器的過渡帶；提高取樣率可放寬這段過渡帶，但會增加 ADC 與後端運算負擔。

### 6.2 DAC 後的重建濾波與零階保持

DAC 常以**零階保持（zero-order hold, ZOH）**在一個取樣週期內維持輸出值，其頻率響應包絡為
$$|H_{\mathrm{ZOH}}(f)|=\left|\frac{\sin(\pi f/f_s)}{\pi f/f_s}\right|.$$
這個 sinc 包絡會造成高頻下垂，並在 $kf_s$ 周圍留下**頻譜映像（spectral images）**。DAC 後的類比**重建濾波器（reconstruction filter）**負責去除映像；若通帶下垂不可忽略，可在數位端先做近似 $1/H_{\mathrm{ZOH}}(f)$ 的 sinc 補償，但不能在 ZOH 零點附近強行反轉。

### 6.3 過取樣與 Sigma-Delta 的 DSP 角色

過取樣把 Nyquist 映像推遠，也讓類比抗摺疊／重建濾波器有較寬的過渡帶。Sigma-Delta ADC 再利用過取樣與雜訊整形，把大部分量化雜訊推到訊號頻帶外；DSP 端必須先用陡峭低通壓掉帶外雜訊，再以**抽取濾波（decimation filtering）**降低取樣率。Sigma-Delta DAC 的方向相反：數位內插與雜訊整形提高取樣率，再由簡單的類比低通平滑輸出。

### 6.4 數值例

若音訊通帶到 20 kHz、取樣率為 48 kHz，抗摺疊濾波器只有 $20\sim24$ kHz 的 4 kHz 過渡帶。ZOH 在 20 kHz 的振幅為
$$\left|\frac{\sin(\pi\cdot20/48)}{\pi\cdot20/48}\right|\approx0.738,$$
即下垂約 $-2.64$ dB，因此高保真 DAC 可在數位端做約 $+2.64$ dB 的帶邊補償。若 Sigma-Delta ADC 以 3.072 MHz 取樣，過取樣比為 $3.072\text{ MHz}/48\text{ kHz}=64$；抽取濾波器先保留 0～24 kHz 並壓掉帶外整形雜訊，再以 64 倍抽取輸出 48 kHz 資料。

## 第 7 章　實作平台與演算法骨架

| 面向 | 重點 |
| --- | --- |
| DSP 處理器 | MAC 每週期一次，配合環形緩衝、零開銷迴圈與 SIMD |
| FPGA | 客製化管線、平行 MAC 與 DSP slice |
| ASIC | 固定功能可達最高效能與最低功耗 |
| MCU | 成本低、效能有限；ARM Cortex-M4F／M7 提供 DSP 指令集 |
| GPU | 適合大量平行 FIR、影像卷積與神經網路運算 |
| MAC 迴圈 | FIR、相關器、匹配濾波器 |
| 遞迴更新 | IIR、滑動平均、指數平滑 |
| 轉換 | FFT、DCT、小波轉換 |
| 判決與回授 | PLL、DPLL、CDR、Sigma-Delta 環 |
| 迭代最佳化 | LMS、RLS、Newton 法等自適應／學習演算法 |

平台決定平行度、延遲、功耗與數值格式；演算法骨架則決定資料流與狀態。先辨認骨架，再映射到平台資源，能較快讀懂 DSP 程式與硬體架構。
