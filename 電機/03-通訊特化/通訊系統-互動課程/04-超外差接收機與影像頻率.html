04・所有電台搬到同一個中頻

超外差接收機與影像頻率：固定後級比較便宜，前級卻得先擋住另一台

想收 1000 kHz，配 455 kHz 中頻與高側注入，本地振盪器要在 1455 kHz，1910 kHz 也會落到同一個中頻。Q ＝ 50 的單調諧預選器提供 36.818324 dB 影像抑制。

這章假設已懂：02 抑制載波、單邊帶與同步解調的「相乘等於搬移」。前置：見〈濾波器與群延遲〉信號與系統 09及〈RLC 共振與品質因數〉電路學 13——過渡範圍與 Q 的機制在既有課，本章只用其結論算影像抑制。

痛點：轉動選台鈕，為什麼後面的濾波器不用跟著換

AM 廣播從 530 到 1700 kHz，一台接收機若直接在每個載波頻率上完成窄頻選台，所有後級都得精準同步調整，成本高又難維持一致。超外差接收機（superheterodyne receiver）把任何想收的電台先搬到固定中頻（intermediate frequency, IF），後面的帶通與放大便能只做一套。

便宜不是免費的。混頻器只認差頻的大小，不知道輸入位於本地振盪器上方或下方；兩個不同的射頻（radio frequency, RF）輸入可能產生同一個 IF。另一個會闖進來的頻率就是影像頻率（image frequency），它若已通過混頻器，後級再精密也拆不開。

白話直覺：先把不同樓層的人送到同一個櫃檯

可以把混頻想成電梯：不同樓層的電台都能被送到固定櫃檯處理；比喻到此為止。精確地說，本地振盪器（local oscillator, LO）與 RF 相乘產生和頻、差頻，IF 帶通只保留差頻。天線收到的訊號先經 RF 預選，再混頻，再由固定 IF 帶通選擇。

因果鏈如下：空中同時有許多電台，分頻多工（frequency-division multiplexing, FDM）讓每一路占一段頻譜；接收機選定 fLO，把目標 fRF 搬到固定 fIF，換到便宜且高選擇性的後級；代價是 fRF 另一側的頻率也可能給出相同差頻，必須在混頻前由預選器壓掉；頻譜分析儀在混頻器輸出會看見差頻與和頻，訊號產生器打入影像則可直接量抑制 dB。

分時多工（time-division multiplexing, TDM）讓各路占不同時間，分碼多工（code-division multiple access, CDMA）用正交碼共享，正交分頻多工（orthogonal frequency-division multiplexing, OFDM）把高速資料拆到多個子載波；OFDM 的 FFT 實作留給數位通訊課。軟體那一端，SDR 可把 IF 設為 0 直接轉換，原本的影像問題會改以 IQ 不平衡呈現。

選台旋鈕實際上同時驅動 LO 與 RF 預選器：前者保證目標永遠落在固定 IF，後者則跟著目標移動、在影像位置提供衰減。若兩者沒有對準，即使 IF 帶通本身非常窄，也可能收不到目標或擋不住影像。這種「同調追蹤」是超外差機械調諧最難校正的部分，也是後來多級轉換與數位校正出現的原因。

來源：14-通訊系統-上 §5、§6。

推導：為什麼目標與影像會落到同一個 IF

（a）混頻。信號與系統已證明相乘會搬移頻譜，因此 cos(2π fRFt) × cos(2π fLOt) ＝ ½ cos[2π(fRF − fLO)t] + ½ cos[2π(fRF + fLO)t]。IF 帶通只留 |fRF − fLO| ＝ fIF，頻率單位皆為 Hz。

（b）影像。高側注入令 fLO ＝ fRF + fIF。目標滿足 fLO − fRF ＝ fIF，而上方另一個頻率也可滿足 fimage − fLO ＝ fIF，所以 fimage ＝ fRF + 2fIF。低側注入則是 fLO ＝ fRF − fIF、fimage ＝ |fRF − 2fIF|。兩者進入 IF 後完全重疊，只能事前濾除。

（c）預選器。單調諧電路偏離共振後的幅度 |H| ＝ 1 / √(1 + Q²ρ²)，其中 ρ ＝ fimage / fRF − fRF / fimage 是歸一化失諧，Q 是無單位品質因數。故影像抑制比 IRR ＝ √(1 + Q²ρ²)，dB 值為 20 log10(IRR)。IF 越高，影像相距 2fIF 而較好濾；但在較高 IF 做窄帶通又更困難，455 kHz 的 AM 中頻與 10.7 MHz 的 FM 中頻都是取捨。

模型邊界。本課用的是單一預選器、單級轉換、理想乘法混頻的一階教學模型。真實接收機還有振盪器相位雜訊、混頻雜散，並可能採雙轉換或直接轉換。

數值實例：1000 kHz 電台、455 kHz 中頻、高側注入

量級對照。10 kHz 間距可排 118 台；換成 9 kHz 為 131 台。固定 455 kHz IF 讓影像與目標相隔 910 kHz，遠大於相鄰電台間距，但兩種干擾仍由不同濾波器處理。

邊界對照。低側注入時 fLO ＝ 545 kHz、影像 ＝ |1000 − 910| ＝ 90 kHz、抑制 54.823922 dB；影像更遠，但 LO 要從 75 調到 1245 kHz，比例 16.6 倍，比高側的 985–2155 難做。若 fIF ＝ 100 kHz，影像為 1200 kHz、在頻段內，抑制只剩 25.277731 dB；Q ＝ 10 時為 22.860555 dB，Q ＝ 200 時為 48.858677 dB。fRF ＝ 530 高側時，影像 1440 kHz、在頻段內，抑制 41.397100 dB。低側且 fRF ＝ 910 時影像 0 kHz，這組參數不成立。

自由實驗：選台、注入側與影像抑制

場景是一台 530–1700 kHz AM 接收機。選擇目標台、中頻、注入側、頻道間距與預選器 Q，觀察 LO、影像位置、可排台數與影像抑制。

不要混淆

  • 影像頻率不是鄰台干擾。鄰台由 IF 帶通分開，影像要由混頻前的 RF 預選器擋住。
  • IF 不是隨意挑一個中間數字；提高 IF 讓影像遠離，卻使窄帶 IF 濾波器更難製作。
  • 高側與低側只描述 LO 位於 RF 的哪一邊，兩者都能產生同一 IF，影像位置卻在相反方向。
  • FDM 是把許多電台排進頻譜；超外差是從其中選一台搬到 IF，一個描述共享資源，一個描述接收架構。
  • 高 Q 可提高單點影像抑制，但很難在整個 530–1700 kHz 範圍保持同步調諧，不能只追求最大值。

可觀察證據：拿什麼量、量到什麼

用什麼量。把頻譜分析儀接到混頻器輸出，可同時看見差頻與和頻；再用訊號產生器分別送入目標頻率及影像頻率，比較 IF 輸出功率差，就得到影像抑制 dB。掃動 LO 還可核對固定 fIF 與調諧範圍。

能證明什麼。量測能證明目標與影像確實落在同一 IF、預選器是否對準，以及 Q 與影像抑制的趨勢。

不能證明什麼。這組量測不能只靠單一讀值分離 LO 相位雜訊與其他混頻雜散；前者要看頻譜裙邊，後者要掃描更寬頻段。它也不能證明一階模型足以涵蓋真實多級接收機。

測影像時要維持目標源與影像源的輸入功率相同，並讓預選器停在同一調諧位置；若每次重新調到峰值，量到的會是兩個不同工作點，不再是本章定義的影像抑制比。

連到哪門課

濾波器過渡範圍的來源見信號與系統的濾波器與群延遲；品質因數的電路意義見電路學的 RLC 共振與品質因數。收音機、電視調諧器與頻譜分析儀都用到頻率轉換；鎖相迴路設計則接到控制系統課。
