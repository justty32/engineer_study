# 供應鏈管理（Supply Chain Management）

> 名詞對照見 [中英名詞對照表 → 供應鏈管理](../中英名詞對照表.md#供應鏈管理)。

## 0. 本科定位

供應鏈 = 從原料供應商 → 製造商 → 物流中心 → 零售商 → 最終顧客的整個物料/資訊/金流網路。工業工程師在供應鏈中的角色是**設計與最佳化這個網路**——倉庫設在哪裡才能以最低運輸成本在承諾時間內覆蓋所有顧客、每個節點要保有多少庫存才能在服務水準與持有成本之間取得平衡、需求波動時如何協調上下游避免缺貨或爆倉。

供應鏈管理的三個決策層次：(1) **策略層（年–數年）**——供應鏈網路設計（倉庫/工廠的數量、位置、規模）、自製 vs 外包；(2) **戰術層（月–季）**——需求預測、存貨政策（安全庫存水位、補貨頻率）、採購合約；(3) **作業層（日–週）**——每日出貨排程、庫存調撥、運輸路線。

## 1. 長鞭效應（Bullwhip Effect）——供應鏈的振盪

### 1.1 機制

終端消費者的需求波動（例如一週的尿布銷量因為促銷活動而增加 10%）→ 零售商為了補貨且加一點安全庫存（訂單增加 15%）→ 批發商看到零售商的訂單波動加上自己的安全緩衝（訂單增加 25%）→ 製造商看到批發商的訂單波動（訂單增加 40%）→ 製造商向原料供應商下單（訂單增加 60%）——**需求訊號沿供應鏈往上游逐級放大**，造成上游端的生產與庫存劇烈振盪。

長鞭效應的根因：
1. **需求訊號處理**：每一級用自己的訂單（而非終端實際需求）來做預測——訂單本身的波動比實際需求的波動更大（因為每一級加了安全庫存作為緩衝），然後下一級基於這個已放大的訊號再加一層緩衝
2. **批量訂購**：為了節省運輸成本或符合最小訂購量 MOQ，累積數天的需求一次下單 → 上游看到的是間歇的「大單」而非平穩的「小單」，誤判為需求暴增
3. **價格波動與促銷**：製造商年終折扣導致零售商提前大量囤貨（forward buying）→ 製造商誤以為需求大增而擴產 → 促銷結束後需求驟降 → 產能過剩
4. **短缺賽局（rationing game）**：當供應緊張時，零售商為了確保自己能分到貨而誇大訂單量（訂 100 個希望拿到 60 個）→ 製造商看到「需求暴增」→ 擴產 → 當供應恢復正常時各零售商紛紛取消誇大的訂單 → 製造商面對需求懸崖

### 1.2 對策

- **資訊共享**：讓所有層級看到終端 POS（銷售點）的實際銷售數據——而非用前一級的訂單來猜需求。這是 VMI（供應商管理庫存 Vendor-Managed Inventory）的核心邏輯——供應商直接管理零售商貨架上的庫存，看到的是實際消費速率而非放大後的訂單
- **減少前置時間**：前置時間愈短 → 預測期愈短 → 預測誤差愈小 → 安全庫存可以壓得愈低 → 訂單波動愈小
- **穩定定價**：減少人為促銷造成的需求集中（Every Day Low Price, EDLP——Walmart 的策略：不搞短期大促銷而是維持長期穩定的低價，需求模式平穩，供應鏈運作效率大幅提升）

## 2. 存貨管理——持有太多 vs 缺貨的永恆權衡

### 2.1 經濟訂購量（EOQ）

$$Q^* = \sqrt{\frac{2DS}{H}}.$$

$D$ = 年需求量、$S$ = 每次訂購的固定成本（下單處理費、運輸費）、$H$ = 每單位存貨的年持有成本（資金成本 + 倉儲費 + 保險 + 損耗）。EOQ 平衡兩個互相競爭的成本：訂購太頻繁 → 訂購成本高（每次下單都有固定費）；訂購太大量 → 持有成本高（平均庫存 = $Q/2$ 堆在倉庫裡佔空間、佔資金、會過期）。

EOQ 的穩健性：在 $Q^*$ 附近 ±20% 範圍內，總成本曲線的底部非常平坦——即使無法精確得知 $S$ 與 $H$，只要用合理估計值，實際成本與理論最優成本的差距通常只有個位數百分比。這讓 EOQ 在實務上極其有用——不需要極為精確的成本參數就能得到接近最優的訂購決策。

### 2.2 新聞男孩模型（Newsvendor）

單一銷售季、單次訂購機會——報攤老闆每天清晨決定今天要進多少份報紙（進太多→賣不完只能回收成廢紙價值，損失進貨成本−殘值；進太少→少賣一份損失利潤）。最適訂購量 $Q^*$ 滿足：

$$F(Q^*) = \frac{c_u}{c_u + c_o},$$

$c_u$ = 少賣一份的機會損失（underage cost = 售價 − 進貨成本）、$c_o$ = 多進一份的過剩損失（overage cost = 進貨成本 − 殘值）。左邊是需求 $\le Q^*$ 的累積機率——公式說的是「訂到滿足需求的累積機率 = 邊際利潤佔總邊際成本的比率（critical ratio）」。

這個公式的直覺：當 $c_u \gg c_o$（賣一個賺很多、丟一個賠很少——如軟體授權的邊際成本接近零、但少賣一個就是少掉高利潤）→ $F(Q^*) \approx 1$ → 大量庫存（寧願過剩也不願缺貨）。當 $c_o \gg c_u$（進貨成本極高、商品極易過期——如進口高級生魚片）→ $F(Q^*) \approx 0$ → 極保守庫存（寧願缺貨也不願過剩）。

新聞男孩模型應用在全通路零售（omnichannel retail）、時尚服飾、季節性商品（月餅、年菜、節慶裝飾）等需求高度不確定、前置時間長、只能下單一次的場景。

### 2.3 安全庫存

需求有變異性（標準差 $\sigma_D$）且前置時間 $L$ 有變異性 → 必須保有安全庫存來緩衝。週期服務水準（cycle service level, CSL = 在補貨週期內不缺貨的機率）：

$$SS = z_{\text{CSL}} \times \sigma_{D,L}.$$

$\sigma_{D,L}$ 是前置時間內需求的標準差（需求與前置時間的變異性以平方根和的方式組合）。$z_{0.95} = 1.645$（95% CSL——每 20 個補貨週期中有 1 次缺貨）。更高服務水準 → 安全庫存以非線性的方式增加（99%→$z=2.33$→比 95% 多 40% 的安全庫存）。

**安全庫存的集中效應（risk pooling）**：將多個獨立需求的零售點的庫存集中到一個中央倉庫——總需求的標準差 = $\sqrt{n}\sigma$（獨立隨機變數和的標準差），而非 $n\sigma$。集中化的安全庫存總量比分散化少（以平方根而非直接比例增長）。這就是 e-commerce 集中式巨型倉庫的數學基礎——Amazon 用少數巨型 FBA（Fulfillment by Amazon）倉庫覆蓋整個大陸，利用風險池集中效應以遠低於傳統分散式零售通路的總庫存量達成相同或更高的服務水準。

## 3. 碩士/博士層級延伸

碩士：**封閉式供應鏈與逆向物流**（報廢產品回收、拆解、再製造、材料回收——不僅是環保口號，歐盟 WEEE 與電池指令強制性要求製造商承擔產品報廢的回收處理責任。設計供應鏈時就內建逆向物流路徑：如何收集散落各處的報廢產品、如何檢測分類（可修復再售 vs 僅能材料回收）、如何經濟地運輸低密度的報廢產品）、**供應鏈韌性 Resilience**（COVID 後的重點課題——韌性與效率的取捨：JIT 將庫存壓到極低以最大化效率，但一個港口封鎖或一家供應商火災就讓整條產線停擺。韌性策略——多元供應源 multi-sourcing（不把所有雞蛋放在同一國家/供應商籃中）、策略性安全庫存（只在關鍵瓶頸物料儲備而非全面庫存）、區域化供應網絡（減少長途跨洋供應鏈的依賴）——如何在效率損失可控的前提下顯著提升抗衝擊能力）。

博士：**自主供應鏈**（數位孿生即時同步物理供應鏈的全狀態——從原料在礦場的開採進度、海上貨櫃的 GPS 位置與預計到港時間、海關清關的即時狀態、到工廠的每個機台的生產排程與成品庫存——即時模擬「如果這艘船因颱風延遲 3 天會發生什麼事」並自動觸發備援機制（調撥其他倉庫的庫存、重新最佳化生產排程、向客戶自動發送延遲通知），而不需一群供應鏈規劃師手動打電話）。**區塊鏈在供應鏈追溯的應用**（從礦場→冶煉廠→零件製造商→組裝廠→零售商→消費者，每個環節的交易資訊（批次號、時間戳、品質檢驗報告）以不可篡改的分散式帳本記錄。食品溯源——一批受大腸桿菌污染的生菜可以在數秒內追溯到源頭農場的特定田地而非耗時數天的傳統紙本追溯）。
