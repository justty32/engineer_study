# 線性規劃與網路最佳化（Linear Programming & Network Optimization）

> 名詞對照見 [中英名詞對照表 → 線性規劃](../中英名詞對照表.md#線性規劃)。

## 0. 本科定位

線性規劃（LP）是作業研究（OR）最基礎、最成熟、應用最廣泛的最佳化工具——任何可以表達為「在一組線性不等式約束下最大化/最小化一個線性目標函數」的問題都屬於 LP 的範疇。從煉油廠的原油採購決策、航空公司的機組排班、到物流公司的車輛路線——商業 LP 求解器（CPLEX、Gurobi）可以在數分鐘內解出含有數百萬個變數與約束的 LP。對擁有者（軟體背景）而言，最佳化演算法（simplex、內點法、對偶性）是你熟悉的電腦科學工具在工業決策中的直接應用。

---

## 1. Simplex 法——在可行域邊界上走捷徑

### 1.1 幾何直覺

LP 的約束條件定義一個**凸多面體**（線性不等式的交集 = 凸集合——凸多面體任何兩點的連線都在其中），目標函數是一個方向向量 $\mathbf{c}$。最大化解必定發生在可行域的某個**頂點**（extreme point——這是 LP 的關鍵洞察，單純法就是利用這個性質沿邊界移動）。Simplex 法從一個可行頂點出發，沿邊界移動到相鄰的「改善」頂點（新頂點的目標值 > 舊頂點），重複直到無法再改善——此時已達全域最優解（因為凸集合的局部最優就是全域最優）。

### 1.2 代數實作

標準形式 $\min \mathbf{c}^T\mathbf{x}$ s.t. $A\mathbf{x} = \mathbf{b}, \mathbf{x} \ge 0$（將不等式約束透過添加鬆弛變數 slack variable 轉為等式）。基矩陣（basis matrix）選取 $m$ 個線性獨立的行（基變數 basic variable），其餘為非基變數（nonbasic = 0——對應頂點的代數描述：將 $n-m$ 個變數設為 0，解剩下 $m$ 個變數的線性方程組→得到頂點的座標）。Pivot 步驟：將一個非基變數提升為基變數（進入基），同時將一個基變數降為非基變數（離開基）——從一個頂點沿邊界移動到相鄰頂點。選擇進入基的規則（哪個變數進入能讓目標值改善最快）與離開基的規則（哪個基變數首先被推向零）是 simplex 的核心。

最壞情況複雜度：指數級（可構造出需要走遍幾乎所有頂點的病態案例，如 Klee–Minty 立方體）。但實務上，simplex 的效能通常與 $m$ 或 $n$ 成線性或低次多項式關係——數百萬變數的 LP 在現代商用求解器上數分鐘內收斂。

## 2. 對偶性——每個 LP 都有一個鏡像

每個原始 LP 存在一個**對偶問題**。原始是極小化，對偶就是極大化；原始約束的不等式方向反轉、目標係數與右端常數互換。

**弱對偶定理**：原始問題任何可行解的目標值 $\ge$ 對偶問題任何可行解的目標值（對極小化原始）。**強對偶定理**：若原始有最優解，對偶也有最優解，且兩者的最優目標值**相等**——零對偶間隙。

對偶變數的經濟意義：原始 LP 的約束對應某種資源限制（機台可用時數、原料庫存量），**對偶變數 = 該資源的影子價格（shadow price）**——該資源如果增加一個單位，目標函數（成本/利潤）會改善多少。供應鏈模型的影子價格直接告訴決策者「多買一噸鋼捲對總利潤的貢獻是多少」——如果供應商的報價低於影子價格，就值得採購。

## 3. 網路最佳化——結構帶來效率

許多實際問題有天然的網路結構——供應鏈、運輸路線、通訊網路、電力網。網路的 LP 矩陣是**全單模（totally unimodular）**——每個子方陣的行列式值為 0 或 ±1。後果：LP 的最優解自動是整數——不需要整數規劃！對於運輸問題（$m$ 個工廠各生產 $a_i$、$n$ 個需求點各需要 $b_j$，求最小化運輸總成本），即使變數是「從工廠 $i$ 到需求點 $j$ 的運輸量」（直覺應該要是整數），只要 $a_i$ 與 $b_j$ 都是整數，LP 解就會自動給出整數運輸量——不需整數規劃分支定界的任何開銷。

特殊演算法利用網路結構比通用 simplex 快數十倍——**網路 simplex 法**的 pivot 步驟簡化為在網路的生成樹上沿一個額外弧創造迴圈（cycle），並沿此迴圈調整流量分布直到某弧的流量被推向零。每個 pivot 的計算量極小（不需要全矩陣反轉，只需沿迴圈更新）。

## 4. 碩士/博士層級延伸

碩士：**內點法**（interior-point method——不沿邊界走，而是從可行域內部的一點出發，沿著一個「中心路徑」逼近最優解。每次迭代用 Newton 法解一個障礙問題 barrier problem——將「不得離開可行域」的硬約束以對數障礙函數 $-\mu\sum\ln x_j$ 軟化為目標函數的懲罰項，使搜尋點被「推離」邊界。內點法在最壞情況下是多項式時間 $O(n^{3.5})$——不像 simplex 在最壞情況下指數級——對於極大規模的稀疏 LP，內點法通常比 simplex 快）、**隨機規劃**（需求不是已知常數而是隨機變數——決策必須在知道需求實現之前就做出（here-and-now decision），但可以在需求實現之後採取補救行動（recourse action）。目標是最小化第一階段決策的成本 + 期望補救成本。應用：產能擴充——現在就要決定是否建新廠（固定成本極高），但未來需求不確定——建太大浪費、建太小缺貨）。

博士：**分解法**（Dantzig–Wolfe 分解——LP 的約束矩陣有區塊對角 + 少量耦合約束的結構（如多工廠聯合生產——每家工廠有各自的產能限制（區塊對角），但所有工廠的總產量必須滿足市場需求（耦合約束））。將問題分解為一個主問題（協調各子系統的資源分配）+ 多個子問題（各子系統在給定資源下的內部最佳化），兩者交替遞增更新直到收斂。Benders 分解——當問題有「設計變數」（0–1 變數：是否建工廠、建多大）+ 「操作變數」（連續變數：建好後每天怎麼運轉）的兩層結構時特別有效——設計是主問題（MIP）、操作是子問題（LP），利用子問題的對偶資訊生成「Benders 最優性切割」加入主問題以引導搜尋）。
