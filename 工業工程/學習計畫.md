# 工業工程與管理 學習計畫（Industrial Engineering and Management）

## 本系簡介與學習脈絡

工業工程（Industrial Engineering, IE）是「把系統做得更好」的工程：它的研究對象不是單一機械或電路，而是由**人、機器、物料、資訊、資金**共同組成的**生產與服務系統**。傳統工程問「這個東西能不能做出來、能不能運作」，工業工程則接著問「如何用最少的資源、最低的成本、最短的時間、最穩定的品質，把它做出來並持續運作」。因此 IE 同時橫跨**工程**與**管理**兩端，常被概括為四個支柱（交大稱之為 M-COS）：

- **M（Management，管理）**：生產管理、品質管理、供應鏈、工程經濟。
- **C（Computer，電腦／資訊）**：資料分析、系統模擬、製造資訊系統、自動化。
- **O（Operations Research，作業研究）**：以數學最佳化（線性規劃、整數規劃、網路流、排程）做決策。
- **S（Statistics，統計）**：工程統計、品質管制、實驗設計、可靠度。

對擁有者（電機／通訊背景、軟體強）的學習脈絡建議：

- 你最熟悉的「最佳化、機率、模擬、演算法」其實正是 IE 的數學核心（作業研究、排隊論、模擬），這部分可以學得很快，重點放在**問題建模**而非工具實作。
- 你比較陌生的會是**管理面與實體面**：生產排程的實務邏輯、品質管制的統計慣例、人因工程的人體與認知限制、設施規劃與物料搬運的空間思維、供應鏈的庫存與長鞭效應。這些章節會從基本觀念、直覺與典型決策講起。
- IE 的精神是**量化決策**：幾乎每個主題最後都會落到「定義目標函數與限制式，再求解或評估」。學習時請刻意把每個情境翻譯成數學問題。

**深度分層**：大學層級為主，完整涵蓋標準必修；碩士層級於各科末尾「進階方向」簡述；博士層級僅以研究方向列表呈現。

**共通基礎**：微積分、線性代數、工程數學、機率與統計、普通物理屬於跨領域共通基礎，本計畫不重寫；遇到時只說明它在 IE 中扮演的角色（例如線性代數是線性規劃的骨架、機率是排隊與品質的語言），必要時標註「詳見 共通基礎/」。其中**機率與統計**對 IE 特別關鍵，本計畫的「工程統計與機率」一科會把 IE 真正會用到的統計觀念重新組織、銜接共通基礎。

### 01-基礎與方法
建立對「系統觀」與「量化決策」的基本認識，並把 IE 真正會用到的統計語言準備好。

- [x] [01-工業工程導論](01-基礎與方法/01-工業工程導論.md)　範圍：IE 的定義、歷史（泰勒科學管理到現代）、與管理科學的關係、IE 工程師的工作面向與四大支柱全貌。
- [x] [02-工程統計與機率](01-基礎與方法/02-工程統計與機率.md)　範圍：機率基礎與常見分布、抽樣與抽樣分布、估計與信賴區間、假設檢定、迴歸與變異數分析在工程資料上的應用（銜接共通基礎機率統計）。

### 02-作業研究核心
IE 的數學引擎：用最佳化做決策、用隨機模型與模擬描述不確定。

- [x] [03-線性規劃與網路最佳化](02-作業研究核心/03-線性規劃與網路最佳化.md)　範圍：線性規劃建模與單體法、圖解與幾何觀點、對偶與敏感度分析、網路模型的共同骨架、運輸與指派問題、實務求解與模型驗證。
- [x] [04-整數規劃與非線性規劃](02-作業研究核心/04-整數規劃與非線性規劃.md)　範圍：整數規劃建模與分支界限／切割平面、典型 0-1 應用模式（選址、指派、排程）、非線性規劃的凸性與最適條件、常見求解法與其在 IE 的應用。
- [x] [05-隨機程序與模擬](02-作業研究核心/05-隨機程序與模擬.md)　範圍：隨機過程基礎、卜瓦松過程、馬可夫鏈、排隊理論（M/M/1 等）、蒙地卡羅與離散事件模擬原理、亂數與分布抽樣、模型驗證與輸出分析；對軟體實作可精簡，重點在建模與統計解讀。

### 03-生產與供應鏈
把決策從單一工廠的排程，放大到跨企業的供應網路。

- [x] [06-生產規劃與排程](03-生產與供應鏈/06-生產規劃與排程.md)　範圍：需求預測與總體規劃、主生產排程（MPS）、物料需求規劃（MRP）與 ERP、產能規劃、生產排程與派工、精實生產與 JIT、TOC。
- [x] [07-供應鏈管理](03-生產與供應鏈/07-供應鏈管理.md)　範圍：供應鏈結構與決策層級、長鞭效應、存貨管理（EOQ 與其延伸、再訂購點與安全存量、服務水準、報童模型）、配銷與運輸網路、採購與供應商管理、SCOR 與績效指標、風險與韌性。

### 04-品質與可靠度
把統計工具落實到品質保證與產品壽命，是 IE 最具代表性的傳統強項。

- [x] [08-品質管制與六標準差](04-品質與可靠度/08-品質管制與六標準差.md)　範圍：統計製程管制（SPC）、管制圖（X-bar/R、p、c 等）、製程能力指標（Cp、Cpk）、驗收抽樣、六標準差與 DMAIC、TQM 概念。
- [x] [09-可靠度工程](04-品質與可靠度/09-可靠度工程.md)　範圍：可靠度函數與失效率、浴缸曲線、指數與韋伯分布、串聯／並聯與 k-out-of-n 系統可靠度、冗餘設計、MTBF 與維護度。

### 05-人因與管理
讓系統適配人，並為所有工程決策裝上「值不值得」的金錢尺規。

- [x] [10-人因工程](05-人因與管理/10-人因工程.md)　範圍：人機系統、人體測計與生理工作負荷、顯示與控制設計、認知人因與人為失誤、職業安全與作業環境（噪音/照明/姿勢/抬舉）。
- [x] [11-工程經濟](05-人因與管理/11-工程經濟.md)　範圍：金錢的時間價值、現值/年金/利率與等值因子、方案評估（NPV、IRR、回收期）、MARR、折舊與稅後分析、通膨、汰換分析與不確定性下的決策。

### 06-進階與整合
把廠房空間與物料流動規劃好，最後以整合專題收斂全部工具。

- [x] [12-設施規劃與物流](06-進階與整合/12-設施規劃與物流.md)　範圍：設施需求與選址、廠房佈置（製程別/產品別/群組）、SLP 系統化佈置規劃、倉儲設計與揀貨、物料搬運系統設計、流程分析與線平衡。
- [x] [13-工業工程整合專題](06-進階與整合/13-工業工程整合專題.md)　範圍：IE 專案方法論六階段、系統思考與整合、常見專題類型與方法論組合、專案管理基礎（WBS、CPM/PERT、要徑與資源配置）、溝通呈現與專業倫理。
