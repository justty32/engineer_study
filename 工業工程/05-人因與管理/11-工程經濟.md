# 工程經濟（Engineering Economy）

> 名詞對照見 [中英名詞對照表 → 工程經濟](../中英名詞對照表.md#工程經濟)。

## 0. 本科定位

工程經濟是 IE 的財務語言——把工程方案換算成金額，用一致的財務指標比較。核心觀念是**金錢的時間價值**：今天的一塊錢比明年的一塊錢值錢（因為可以投資、有通膨、有不確定性）。

---

## 1. 基本工具

- **現值 P 與終值 F**：$F = P(1+i)^n$（複利計算）、$P = F/(1+i)^n$（折現）
- **年金 A 與現值**：$P = A[(1+i)^n - 1]/[i(1+i)^n]$
- **淨現值 NPV**：所有未來現金流的折現值總和扣除初始投資。NPV > 0 → 值得投資
- **內部報酬率 IRR**：使 NPV = 0 的折現率。IRR > 公司的資金機會成本（MARR, Minimum Attractive Rate of Return）→ 可行
- **回收期**：初始投資從淨現金流入中回收所需的年數。簡單但忽略回收後的現金流與金錢的時間價值

---

## 2. 折舊與稅後分析

折舊（depreciation——資產隨時間的價值減損）影響帳面利潤與所得稅（折舊是非現金支出但可抵扣稅額）。直線法（每年折舊 = (原始成本 − 殘值) / 年限）最簡單。加速折舊法（MACRS、定率遞減法）讓早期抵扣較大 → 稅後現金流更早實現 → 提升 NPV。

**自製 vs 外購決策**：比較內部製造的總成本（變動 + 分攤固定成本）與外包採購價格。若內部有閒置產能且變動成本低於外購價 → 自製。IE 經常處理這類決策。

---

## 3. 碩士/博士延伸

實質選擇權（real options analysis——保留「日後再擴建/轉換/放棄」的彈性是有價值的，傳統 NPV 計算不計入這個彈性價值因此可能低估策略性投資的價值）、生命週期成本分析 LCC（從購置、操作、維護到最終廢棄的全壽期成本）。
