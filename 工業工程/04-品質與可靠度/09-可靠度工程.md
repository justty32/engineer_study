# 可靠度工程（Reliability Engineering）

> 名詞對照見 [中英名詞對照表 → 可靠度工程](../中英名詞對照表-2.md#品質--可靠度)。

## 0. 本科定位

可靠度是「系統在指定的操作條件下、在指定的時間內、完成指定功能的機率」。本質上就是**一個機率問題**——每顆元件的失效時間是隨機變數，可靠度工程就是量化、預測、並提升這些機率。IE 不只在乎「東西做出來好不好」，更在乎「它能好多久」——品質是出貨當下的 snapshot，可靠度是整個生命週期的 story。

可靠度在工程經濟上的意義：一個產品在保固期內的失效（保固成本）、在關鍵基礎設施中的失效（停機損失——一座晶圓廠停機一小時可能損失數十萬美元）、或安全關鍵系統中的失效（人命損失——飛機、醫療器材、核反應器），這些風險全部量化為可靠度指標。

## 1. 基本可靠度函數

- **可靠度 $R(t) = P(T > t)$**：存活到時間 $t$ 的機率。$R(0)=1$（初始無失效）、$R(\infty)=0$（時間夠長所有元件終將失效）
- **失效機率密度 $f(t) = -dR/dt$**：在時間 $t$ 附近單位時間內發生失效的無條件機率
- **失效率 $\lambda(t) = f(t)/R(t)$**：**已經存活到 $t$** 的元件在下一瞬間失效的**條件機率**。這是可靠度工程最重要的診斷指標——失效是因為製造缺陷（早期高失效率）、隨機外部原因（恆定失效率）、還是磨耗衰老（晚期上升失效率）——看 $\lambda(t)$ 的形狀就知道

### 1.1 浴缸曲線（Bathtub Curve）

大多數複雜產品的失效率隨時間呈浴缸形：

- **早期失效期（infant mortality）**：失效率從高值快速下降——潛在的製造缺陷（冷焊點、晶片表面的微粒污染、連接器端子氧化）在使用初期暴露。對策：**燒入（burn-in）**——出廠前在高溫/高壓/高振動下運行數十小時以加速早期失效，讓缺陷在工廠內就爆發而非送到客戶手中。燒入本質上是在前段高失效率區中「過濾掉弱件」，將出廠後的失效率壓到接近恆定階段
- **有用壽命期（useful life）**：失效率低且恆定（底部平坦區）——只剩隨機的外部因素（突波、靜電放電 ESD、操作員失誤）造成失效。此時 $\lambda(t) \approx \lambda$（常數），對應指數分布 $R(t) = e^{-\lambda t}$。這階段的失效完全是隨機且不可預測的——預防性維護無法避免這類失效（因為它們不是累積磨耗造成的）
- **磨耗期（wear-out）**：失效率上升——材料疲勞、氧化、擴散、電遷移等累積機制終於到達臨界點。預防性維護（定時更換老化元件**在磨耗期開始前**）可以在 $\lambda(t)$ 開始上升之前就換掉，避免失效

### 1.2 壽命分布

- **指數分布**：$\lambda$ 恆定，$R(t) = e^{-\lambda t}$，MTTF = $1/\lambda$。**無記憶性**（memoryless）：一個已存活了 1000 小時的元件，其未來 1 小時內的失效機率與全新的元件相同（條件失效機率不隨年齡增加）。這適用於浴缸曲線的底部——失效完全由外部隨機因素決定，元件本身沒有「老化」。指數分布是電子元件可靠度最常用的模型，也是可靠度數學中最簡單的分布
- **Weibull 分布**：$R(t) = \exp[-(t/\eta)^\beta]$。Weibull 之所以是可靠度工程最靈活的分布——形狀參數 $\beta$ 決定了失效率的趨勢：$\beta < 1$ → 早期失效（失效率隨時間下降——缺陷逐漸被消耗）；$\beta = 1$ → 指數分布（失效率恆定——隨機失效）；$\beta > 1$ → 磨耗失效（失效率上升——累積損傷到達臨界）；$\beta = 3.4$ → 近似常態分布（疲勞壽命的自然變異）。只需調整 $\beta$ 一個參數，Weibull 就能涵蓋浴缸曲線的全部三階段——這就是它在可靠度分析中如此普遍的原因

## 2. 系統可靠度模型

### 2.1 串聯系統

任何一個元件失效 → 整系統失效：$R_s = \prod_i R_i$（可靠度相乘）。**系統可靠度永遠小於任何一個單一元件的可靠度**——一個由 10 顆可靠度各為 0.99 的元件串聯而成的系統，系統可靠度 = $0.99^{10} = 0.904$（每 10 個這樣的系統就有 1 個在元件壽命期間失效）。

### 2.2 並聯系統（冗餘）

所有元件都失效 → 整系統才失效：$R_s = 1 - \prod_i(1 - R_i)$。兩顆元件並聯可以將系統可靠度從 0.9（單顆）提升到 0.99——但實體成本、重量、體積都加倍。**並聯的邊際效益遞減**：從無冗餘到雙冗餘（1→2）的改善最大，從雙冗餘到三重冗餘（2→3）的額外改善相對微小（除非是安全關鍵系統如飛控電腦——這時三重冗餘提供的投票表決能力 voted redundancy 是必須的：三個通道的輸出經由 2-of-3 投票表決，任何單通道的亂數故障不會影響輸出）。

### 2.3 k-out-of-n 系統

$n$ 個元件中至少 $k$ 個正常運作 → 系統存活。這是串聯（$k=n$）與並聯（$k=1$）的一般化。例如四引擎的飛機（B747）只需兩個引擎即可安全飛行與降落——四發中兩發失效仍可飛行，這是 $k=2, n=4$ 的系統。

### 2.4 故障樹分析（Fault Tree Analysis, FTA）

從頂事件（例如「煞車系統失效」）往下追溯所有可能的故障路徑——是煞車液壓管路破裂？（機率 $P_A$）或是煞車踏板機構卡住？（機率 $P_B$）或是兩個獨立的煞車迴路同時失效？（機率 $P_C \times P_D$，並聯失效）。故障樹的每個邏輯閘（AND/OR）都對應一個機率計算——這是一個從元件可靠度「往上建構」系統可靠度的嚴格邏輯樹。FTA 被廣泛應用於航空、核能、醫療器材的安全性分析——它強迫工程師系統性地窮盡所有可能導致頂事件的路徑，而不是只思考最明顯的幾種。

## 3. 碩士/博士層級延伸

碩士：**加速壽命試驗 ALT**（在高於正常使用條件的應力下測試——提高溫度 Arrhenius 加速、提高電壓逆冪律加速、提高濕度 Peck 加速——將失效時間從數年壓縮到數週，再透過已知的物理失效模型外推回正常條件下的壽命）、**FMEA/FMECA**（失效模式與影響分析/失效模式影響與關鍵性分析——以表格形式系統性地列出每個元件的每種潛在失效模式、其對整系統的後果、嚴重性評級、發生機率、可偵測性，三者乘積為 RPN 風險優先數——優先改善高 RPN 項目。FMEA 是 FTA 的互補工具：FTA 從頂事件往下拆，FMEA 從元件往上建）。

博士：**預測性維護 PdM**（從機台感測器的振動頻譜、溫度趨勢、電流波形中提取退化特徵，用機器學習預測「還有多少時間會失效」Remaining Useful Life。不同於定時更換的預防性維護——定時更換不管元件實際狀態如何，時間到就換，可能換掉仍健康的元件（浪費）或太晚換（已失效）；PdM 只在退化特徵顯示即將失效時才安排更換——在更高的設備可用度與更低的維護成本之間取得平衡）。**軟體可靠度**（軟體沒有磨耗——失效來自設計階段就潛伏的 bugs 在特定的罕見輸入組合下被觸發。軟體可靠度成長模型 SRGM 用於追蹤測試過程中失效發生率的下降趨勢，並預測何時達到目標可靠度目標以便釋出軟體，但模型對不同團隊與不同軟體架構的通用性遠不及硬體可靠度的物理模型）。
