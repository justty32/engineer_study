# 品質管制與六標準差（Quality Control & Six Sigma）

> 名詞對照見 [中英名詞對照表 → 品質管制](../中英名詞對照表-2.md#品質--可靠度)。

## 0. 本科定位

品質是 IE 的三大支柱之一（另二為生產力與成本）。品質管制的本質是**管理變異（variation）**——任何製程都會有變異（原料的微小差異、機台的溫度漂移、操作員的手法、量測儀器的誤差），品質管制的任務是區分「正常的隨機變異」（common cause——製程天生就有的背景波動）與「異常的系統偏移」（special cause——機台故障、原料換批號、新手操作員），並在後者發生時及時警報。

## 1. 管制圖（Control Chart）——SPC 的核心工具

### 1.1 Shewhart 管制圖原理

Walter Shewhart（1924）發明了管制圖——將品質特性依時間序畫在圖上，加上中心線（CL = 製程平均值）與上下管制界限（UCL/LCL = $\mu \pm 3\sigma_{\bar{X}}$）。**任何落在 ±3σ 之外的點被視為「出界訊號」**——在製程穩定（只有隨機變異）假設下，±3σ 以外的機率僅約 0.27%（每 370 個點約 1 次誤警）。

### 1.2 主要管制圖類型

- **$\bar{X}$–$R$ 圖（平均值–全距管制圖）**：每個時間點抽 $n$ 個樣本（子組），計算子組平均值 $\bar{X}$ 與全距 $R$。$\bar{X}$ 圖監控製程平均是否偏移，$R$ 圖監控製程變異是否擴大。兩者必須一起看——$R$ 圖突然變大可能意味機台軸承磨損產生不穩定振動；$\bar{X}$ 圖逐漸偏移可能意味刀具磨耗
- **$p$ 圖（不良率管制圖）**：監控每批產品的不良率——適用於 go/no-go 的屬性數據。批次大小可以不固定（此時 UCL/LCL 隨每批的樣本大小而變）
- **$c$ 圖（缺點數管制圖）**：監控每單位產品的缺陷數（一輛車有幾個外觀瑕疵）——假設缺陷數服從 Poisson 分布

### 1.3 非隨機模式——管制圖的判讀

即使沒有點超過 ±3σ，以下模式也暗示製程偏離了隨機狀態（稱為「Western Electric Rules」——這些規則是從正常機率行為推導出來的）：
- 連續 7 點在中心線同一側（機率僅 ~0.78%——很不可能來自隨機波動）
- 連續 7 點遞增或遞減（暗示趨勢——如刀具逐漸磨損使尺寸單調增加）
- 連續 3 點中有 2 點落在 ±2σ 與 ±3σ 之間
- 點呈現規律的週期擺動（暗示某個週期性因素——如日夜溫差、換班交接）

這些規則的邏輯基礎：在純隨機過程中，觀察到這些特定模式組合的機率極低，因此比「單點出界」更有資訊量——它們可以提前預警，在問題惡化到出界之前就介入。

## 2. 製程能力分析

### 2.1 $C_p$ 與 $C_{pk}$

$$C_p = \frac{USL - LSL}{6\sigma}.$$

$C_p$ 衡量「規格寬度是製程自然變異（±3σ = 6σ）的多少倍」——$C_p > 1$ 表示規格寬度 > 6σ，製程變異「理論上」可以全部落在規格內。$C_p$ 的問題：**不考慮製程是否對中**——如果 $\mu$ 偏離規格中心，即使 $C_p$ 很大，仍有大量不合格品產生。

$$C_{pk} = \min\left(\frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma}\right).$$

$C_{pk}$ 補正了對中的問題——取「離規格上限多遠」與「離規格下限多遠」中較近的那邊除以 3σ。$C_{pk} = 1$ 代表平均值離最近的規格界限恰好 3σ（約 0.135% 不合格率——1350 DPMO）。**一般業界目標：$C_{pk} \ge 1.33$（4σ 水準，約 63 DPMO）；六標準差目標：$C_{pk} \ge 2.0$（平均值離規格界線的距離 = 6σ，假設長期偏移 1.5σ 後仍為 4.5σ = 3.4 DPMO）。**

### 2.2 製程能力與製程性能的區別

- $C_p, C_{pk}$ 使用**短期**（within-subgroup）標準差——反映製程的「潛在最佳能力」
- $P_p, P_{pk}$ 使用**長期**（overall）標準差——反映製程在長時間運轉下的真實表現（包含換班、換原料、季節效應等所有變異來源）。$P_{pk} < C_{pk}$ 的差距暗示製程有顯著的長期漂移

## 3. 六標準差方法論

### 3.1 DMAIC——改善既有流程的五步驟

1. **Define（定義）**：定義問題範圍、客戶需求（CTQ——關鍵品質特性）、專案目標與預期財務效益
2. **Measure（量測）**：建立量測系統（量測系統分析 MSA——先確認量具本身的變異遠小於製程變異——若量具不準，後面全白費）、收集基準數據、計算當前製程能力的 $C_{pk}$ 或 DPMO
3. **Analyze（分析）**：用統計工具找出根本原因——魚骨圖（Ishikawa 圖——人/機/料/法/環的系統性原因分解）、假設檢定（比較不同供應商的原料良率是否有統計顯著差異）、迴歸分析（溫度與壓力各別對產品尺寸的影響程度）、ANOVA（比較三個班次的產出是否有差異）
4. **Improve（改善）**：基於分析結果提出改善方案，用 DOE 實驗設計找出最適參數組合，試行驗證
5. **Control（控制）**：將改善成果標準化（SOP 更新、納入日常管制圖監控），確保持續維持

### 3.2 六標準差的組織角色

- **Champion**：高階主管，確保專案與公司策略一致、排除組織障礙
- **Master Black Belt**：六標準差的技術導師，輔導多個專案團隊、提供高階統計諮詢
- **Black Belt**：全職的六標準差專案領導者，具備深厚的統計與變革管理技能（需完成 4–6 週的密集訓練加上成功領導 2–3 個改善專案）
- **Green Belt**：兼職改善專案成員，在完成日常工作的同時參與專案

## 4. 碩士/博士層級延伸

碩士：**多變量統計製程管制 MSPC**（半導體製程有數十個互相關聯的品質參數——不能各自畫一張管制圖因為它們相關。主成分分析 PCA 降維 + Hotelling $T^2$ 管制圖同時監控整個參數向量）、**工程製程管制 EPC**（將自動控制與 SPC 整合——微調機台參數補償製程漂移，同時 SPC 持續監控調控後是否仍穩定）。博士：**Profile monitoring**（監控的不再是單一數值而是一條曲線或一個表面——例如注塑成型模穴內的壓力–時間曲線必須全程在管制帶內）、**深度學習在影像型 SPC 的應用**（用 CNN 直接監控產品外觀影像→偵測異常模式而非傳統的個別尺寸量測）。
