# 生醫感測器（Biomedical Sensors）

> 名詞對照見 [中英名詞對照表 → 生醫感測器](../中英名詞對照表.md#生醫感測器)。

## 0. 本科定位

生醫感測器是 BME 的「前端」——把生理量（壓力、溫度、流速、化學濃度、電位、光學吸收）轉換成可供後續電路處理的電訊號。與一般工程感測器的差異在於：(1) **生物相容性**——接觸人體的表面不可引發免疫反應或細胞毒性；(2) **微小化**——侵入式感測器必須極小（導管尖端、皮下植入）；(3) **低功耗**——植入式裝置的電池需維持數年；(4) **在潮濕、腐蝕性、充滿蛋白質吸附的環境中長期穩定**。

對擁有者（電機背景）而言，感測器的換能原理（壓阻效應→Wheatstone 電橋、光電二極體→轉阻放大器、電化學電極→恆電位儀 potentiostat）完全熟悉——本科技的重點在於「生理場景中的特殊考量」。

## 1. 物理感測器

### 1.1 壓力感測——血壓量測的工程原理

**壓阻式壓力感測器**：矽薄膜（微機電製程蝕刻出的薄矽膜——厚度數十 µm）在壓力差下彎曲→彎曲應變改變矽的電阻率（壓阻效應——半導體的壓阻係數比金屬應變規大數十倍，因為應變改變能帶結構→改變載子遷移率）→四個壓阻元件以 Wheatstone 電橋配置（兩個受拉伸、兩個受壓縮，最大化靈敏度同時抵銷溫度漂移），輸出 mV 級的差動電壓正比於壓力。

**血壓量測的臨床應用**：動脈導管尖端壓力感測器（動脈導管插入橈動脈→感測器直接浸在血液中量測即時的動脈壓力波形——收縮壓/舒張壓/平均動脈壓）。顱內壓 ICP 監測（創傷性腦損傷病患——顱骨鑽孔植入壓力度計於硬腦膜下，監測腦壓是否升高到危險水平）。

### 1.2 溫度感測——熱敏電阻與熱電偶

**熱敏電阻（thermistor）**：陶瓷半導體（過渡金屬氧化物燒結體），電阻對溫度極度敏感（負溫度係數 NTC——溫度升 1°C，電阻降 ~4%）。優點：靈敏度比熱電偶高數十倍、體積可做極小（導管尖端 < 0.5 mm 直徑）。缺點：非線性（需 Steinhart–Hart 方程校準 $1/T = A + B\ln R + C(\ln R)^3$）。

臨床應用：肺動脈導管熱稀釋法 Swan–Ganz catheter——注入已知溫度的冷生理食鹽水 → 下游的熱敏電阻量測血液溫度的稀釋降溫曲線 → 從降溫速率推算心輸出量（心臟每分鐘泵血量，正常 ~5 L/min）。

## 2. 生物電位電極——從離子流到電子流

### 2.1 電極–電解質界面的電化學

量測 ECG/EEG/EMG 時，電極與皮膚之間的界面是一個電化學半電池：金屬電極（Ag/AgCl 最常用）↔ 導電凝膠（含 Cl⁻ 離子的電解質凝膠，降低皮膚角質層的阻抗）↔ 皮膚角質層（高阻抗，~100 kΩ 在 60 Hz）。

Ag/AgCl 電極的非極化特性使其成為生醫電極的標準——電荷可以透過 Ag ↔ AgCl 的可逆電化學反應（$Ag + Cl^- \rightleftharpoons AgCl + e^-$）跨越金屬–電解質界面，不需依賴電雙層的充放電（後者會造成極化——電極電位隨通過的電流而漂移）。非極化電極的等效電路較接近純電阻，而極化電極（如不鏽鋼或金電極）的等效電路包含顯著的串聯電容（造成低頻衰減與相位偏移）。

此界面的等效電路：**半電池電位**（Ag/AgCl ~0.22 V——穩定的 DC 偏移，必須在放大器前端用 AC 耦合或直流伺服迴路去除）+ **電荷轉移電阻**（並聯）+ **雙層電容**（~0.1 µF/cm²——電極表面的水合離子層有如平行板電容器）+ 串聯的**凝膠與角質層歐姆電阻**（可變——隨皮膚出汗、角質層濕潤程度變化）。全電極阻抗在 60 Hz 約 5–50 kΩ——必須遠小於放大器的輸入阻抗（>10 MΩ）否則訊號衰減。

### 2.2 電極的雜訊來源

- **熱雜訊（Johnson noise）**：任何電阻都產生熱雜訊——$v_n = \sqrt{4kTRB}$。電極阻抗 50 kΩ 在 1 kHz 頻寬下的熱雜訊 ~0.9 µV RMS——與 EEG 訊號振幅（10–100 µV）相比不可忽略。降低頻寬是減少雜訊最直接的手段
- **移動雜訊（motion artifact）**：電極與皮膚之間的相對移動 → 改變雙層電容厚度 → 改變電極電位 → 產生低頻 (< 5 Hz) 的偽波。使用高順應性的凝膠與柔性電極（如織物電極 textile electrode）可減少移動雜訊，但無法完全消除
- **1/f 雜訊（flicker noise）**：半導體元件（放大器前端）的低頻雜訊——在 < 10 Hz 的生理頻段中尤其顯著。互補式金氧半導體 CMOS 的 1/f 雜訊比雙極性電晶體嚴重——所以 ECG 前端放大器通常採用雙極性輸入級，而非 CMOS

## 3. 光學感測——脈搏血氧儀

### 3.1 原理——分光光度法的工程應用

含氧血紅素 HbO₂ 與缺氧血紅素 Hb 對紅光（660 nm）與紅外光（940 nm）的吸收係數差異極大——660 nm 處 Hb 的吸收 >> HbO₂（缺氧血呈暗紅色——吸收更多紅光）；940 nm 處 HbO₂ 的吸收 > Hb（含氧血在此波長較不透明）。兩個 LED（紅光 + 紅外光）交替點亮穿透指尖（或耳垂——組織較薄、血管豐富），用一顆光電二極體接收穿透光。

接收到的光強度有兩個成分：**DC 成分**（恆定的——來自非脈動的組織吸收：皮膚、肌肉、骨骼、靜脈血——不隨心跳變化）+ **AC 成分**（脈動的——來自動脈血的容積隨心臟收縮/舒張而脹縮，動脈脹時血液厚度增加→光吸收增加→光電二極體接收到的光減少）。AC 成分只佔總訊號的 1–2%，但它是唯一反映**動脈**血氧的資訊。

**血氧飽和度 SpO₂** 由兩個波長的 AC/DC 比值之比（ratio of ratios）決定：

$$R = \frac{(AC_{\text{red}}/DC_{\text{red}})}{(AC_{\text{IR}}/DC_{\text{IR}})}.$$

$R$ 與 SpO₂ 之間的關係是**經驗校準曲線**——廠商在健康志願者身上以不同氧濃度混合氣誘導不同程度的低血氧（降到 SpO₂ ~ 70%），同時以 CO-oximeter（侵入式的金標準，直接量測動脈血樣本的各血紅素物種濃度）對照，建立 $R$→SpO₂ 的查找表。

### 3.2 誤差來源與限制

- **運動偽影**：手指移動 → 光路徑變化 → 光電二極體接收到的光強度變化（頻率與運動的頻率接近→可能與心跳的 AC 訊號重疊或混淆）。對策：Masimo 的 Signal Extraction Technology（SET——用多個波長 + 自適應濾波器分離運動雜訊與動脈脈動訊號）
- **低灌流（low perfusion）**：休克或低體溫病患的指尖血管收縮 → AC 脈動訊號極弱 → SNR 下降 → SpO₂ 讀數可能不穩定或完全消失（「無法鎖定訊號」）
- **指甲油 / 人工指甲**：深色指甲油吸收紅光與紅外光 → 光穿透不足 → 訊號微弱或完全阻塞。對策：將感測器轉向（光源從指尖側面入射而非指甲上方）或改用反射式（光源與偵測器在同一側——前額反射式探頭）
- **一氧化碳中毒**：HbCO（碳氧血紅素）在 660 nm 的吸收率與 HbO₂ 幾乎相同——脈搏血氧儀無法分辨 HbO₂ 與 HbCO，因此一氧化碳中毒病患的 SpO₂ 可能顯示為正常（~100%）但實際上血液的氧氣攜帶能力已被 CO 嚴重破壞。這是 SpO₂ 的盲點——需要 CO-oximeter（多波長—4 到 8 個波長—同時量測 HbO₂、Hb、HbCO、MetHb）才能區分

## 4. 碩士/博士層級延伸

碩士：**穿戴式光學心率**（智慧手錶用 PPG 光體積描記法——綠光 LED 照射手腕皮膚→光電二極體接收反射光→心律的脈動成分從反射光強度的微小變化中提取。綠光之所以被選用——血紅素對綠光的吸收峰較強 → AC/DC 比優於紅光或紅外光。但手腕處的血管密度遠低於指尖→訊號更微弱、更容易受到手臂擺動的運動偽影干擾——這就是為什麼手腕 PPG 心率在跑步時有時不準的原因）、**連續血糖監測 CGM**（皮下植入的微型酵素電極——葡萄糖氧化酶 GOx 催化葡萄糖 + O₂ → 葡萄糖酸 + H₂O₂，H₂O₂ 在鉑電極表面氧化產生的電流正比於組織間液葡萄糖濃度。電極壽命 ~7–14 天後需更換——不是因為葡萄糖氧化酶耗盡，而是因為植入點的局部發炎反應形成的纖維囊包覆電極，減緩葡萄糖擴散。無線傳輸至手機或胰島素泵→閉迴路人工胰臟的感測端）。

博士：**aptamer-based 連續監測**（適體——人工合成的單鏈 DNA/RNA 寡核苷酸，可摺疊成特定三維形狀來專一性結合特定的目標分子。與抗體相比，適體的優勢：無免疫原性、可化學合成（不須動物或細胞培養）、熱穩定性好、可設計成結合後改變構形→產生可量測的電化學或螢光訊號變化——不需要洗除未結合分子。目前正被研發用於即時監測化療藥物血中濃度、抗生素、荷爾蒙等）、**電子鼻**（多通道氣體感測器陣列——每個通道的敏感材料（金屬氧化物半導體、導電高分子、碳奈米管）對不同揮發性有機化合物的靈敏度不同→輸出一個「氣味指紋」圖案→機器學習分類。應用：呼氣診斷——呼出氣體中的特定揮發性有機物如丙酮（酮酸中毒）或一氧化氮（氣喘發炎）的非侵入式篩檢）。
