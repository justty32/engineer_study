# 生醫影像原理（Principles of Biomedical Imaging）

> 名詞對照見 [中英名詞對照表 → 生醫影像](../中英名詞對照表.md#生醫影像)。

## 0. 本科定位

生醫影像是 BME 最重要的領域之一——讓人能「看見體內」而不必切開。五大主要模態各自利用不同的物理原理提供互補的資訊：CT 看骨骼解剖、MRI 看軟組織對比、超音波看即時動態、PET 看代謝功能。對擁有者（電機/通訊背景），生醫影像的訊號處理層面（濾波反投影、傅立葉重建、k-space、都卜勒頻移）是你早已熟悉的工具的醫療應用版。

## 1. X 光與電腦斷層（CT）

### 1.1 投影物理

X 光穿透人體時，不同組織（骨骼、軟組織、空氣）的線性衰減係數 $\mu$ 不同，出射強度 $I = I_0\exp(-\int\mu\,dx)$。單一方向的投影就是把三維 $\mu(x,y,z)$ 沿 X 光路徑積分壓縮成一維或二維的陰影。CT 的關鍵突破：從多個角度的投影**重建**出斷層（切面）影像。

### 1.2 重建演算法——從投影到影像

**濾波反投影（Filtered Back-Projection, FBP）**是 CT 重建的經典方法。Radon 轉換描述投影與原函數的關係——二維函數 $f(x,y)$ 沿角度 $\theta$ 的線積分 $p_\theta(r)$（即投影數據）。**傅立葉切片定理**（Fourier Slice Theorem）：投影 $p_\theta(r)$ 的一維傅立葉變換等於原函數 $f(x,y)$ 的二維傅立葉變換在角度 $\theta$ 的徑向切片。因此——理論上可以從各角度的投影取傅立葉變換、填滿整個二維頻域（k-space）、再反傅立葉變換得到影像。但這個「直接傅立葉重建」在實務上因為極座標→直角座標的內插誤差而效果不佳。

FBP 在反投影之前先對投影數據進行**斜坡濾波（ramp filter）**，修正直接反投影造成的 $1/r$ 模糊。流程：投影 → 一維 FT → 乘上 |ω|（斜坡濾波器在頻域的斜率）→ 逆 FT → 反投影 → 得到斷層影像。可再加上低通濾波（如 Hamming 窗）抑制高頻雜訊（代價是空間解析度下降——平滑但模糊 vs 銳利但雜訊多）。

### 1.3 疊代重建（Iterative Reconstruction）

近代 CT 設備已從 FBP 轉向模型化疊代重建——建立完整的前向模型（X 光源→病患→偵測器，包含光子統計的 Poisson 雜訊模型），用最大似然期望最大化（ML-EM）或壓縮感知（compressed sensing——利用影像在特定變換域中的稀疏性，從少數投影重建高品質影像）來求解影像。疊代法輻射劑量可比 FBP 降低 30–50% 而維持相同影像品質——對降低病患輻射暴露（尤其是需要多次追蹤掃描的癌症病患）意義重大。

### 1.4 Hounsfield 單位

$$HU = 1000 \times \frac{\mu - \mu_{\text{water}}}{\mu_{\text{water}}}.$$

水的 HU = 0、空氣 = −1000、骨骼 = +300 到 +1000 以上、軟組織 = 20–60。醫師看的 CT 影像是 HU 值的灰階映射（windowing——只顯示特定範圍的 HU，例如肺窗 −1000 到 −200、縱膈窗 40–400，不同組織用不同窗寬與窗位）。

## 2. 磁振造影（MRI）

### 2.1 物理基礎——核磁共振

MRI 利用氫原子核（質子）的自旋磁矩。在強靜磁場 $B_0$（1.5T 或 3T——地磁的數萬倍）中，質子的自旋量子化為兩個能態：平行（低能）與反平行（高能）。兩態之間的能差 $\Delta E = \gamma\hbar B_0$ 對應的電磁輻射頻率稱為 **Larmor 頻率** $\omega_0 = \gamma B_0$。對氫核，$\gamma = 42.58$ MHz/T → 在 1.5T 場下 Larmor 頻率 = 63.87 MHz（落在射頻 RF 範圍）。以 $\omega_0$ 頻率的 RF 脈衝激發質子，使其從低能態跳到高能態（共振條件）。

### 2.2 弛豫與對比機制

RF 脈衝關閉後，質子系統回到熱平衡的過程有兩個特徵時間：
- **T₁（縱向弛豫／自旋–晶格弛豫）**：質子將多餘能量轉移給周圍分子（晶格），回到平行於 $B_0$ 的平衡磁化。不同組織的 T₁ 不同（脂肪 T₁ 短 ~250 ms——能量轉移快、訊號恢復快；水 T₁ 長 ~2500 ms——能量轉移慢）。**T₁ 加權影像**（短 TR、短 TE）凸顯 T₁ 對比——白質比灰質亮、腦脊髓液暗
- **T₂（橫向弛豫／自旋–自旋弛豫）**：各個質子的自旋失去相位一致性（沒有能量轉移給環境，純粹是自旋之間的去相位）。T₂ 總是 ≤ T₁。**T₂ 加權影像**（長 TR、長 TE）——腦脊髓液亮、白質較暗

T₁ 與 T₂ 是 MRI 軟組織對比的根本來源——不同的脈衝序列（spin echo、gradient echo、inversion recovery）透過選擇 TR（重複時間）與 TE（回訊時間）來加權 T₁、T₂ 或質子密度的貢獻。

### 2.3 空間編碼——如何知道訊號來自哪裡

這是 MRI 最巧妙的工程設計——透過三組梯度磁場（$G_x, G_y, G_z$）讓不同空間位置的質子有不同的共振頻率與相位：

- **切片選擇（slice selection）**：施加 $G_z$（沿頭腳方向的線性磁場梯度）+ 特定頻寬的 RF 脈衝 → 只有 Larmor 頻率落在脈衝頻寬內的切片被激發
- **頻率編碼（frequency encoding）**：訊號讀取時施加 $G_x$ → 沿此方向的質子共振頻率與位置成正比 → Fourier 變換可區分不同位置的訊號
- **相位編碼（phase encoding）**：在 RF 激發後、讀取前施加短暫的 $G_y$ → 不同位置的質子獲得不同的相位偏移。重複多次掃描、每次改變 $G_y$ 強度，得到一組不同相位編碼的訊號

所有這些原始數據填入 **k-space**（空間頻率域）——低空間頻率（k-space 中心）對應影像的大尺度對比、高空間頻率（k-space 邊緣）對應影像的細微邊緣。k-space 填滿後做二維反 Fourier 變換 → 影像。對你而言，**MRI 的核心數學就是多維 Fourier 變換**——和你通訊背景的信號處理完全同源。

### 2.4 功能性 MRI（fMRI）

大腦神經元活化時局部血流量增加 → 含氧血紅素濃度上升 → 去氧血紅素（順磁性 → 造成局部磁場不均勻 → T₂* 訊號衰減）比例下降 → T₂* 訊號微幅增強。這就是 **BOLD 對比**（Blood Oxygenation Level Dependent contrast）——fMRI 的基本訊號來源，也是認知神經科學的主要工具。典型 fMRI 的訊號變化只有 0.5–2%，需要大量統計處理（一般線性模型 GLM、多重比較校正）才能可靠地偵測活化區域。

## 3. 超音波

### 3.1 基本原理

壓電晶體（PZT）在電壓驅動下振動產生超音波脈衝（2–15 MHz）→ 聲波在組織中傳播 → 遇到聲阻抗不連續的界面（不同組織的交界）部分反射回探頭 → 同一壓電晶體接收回聲轉換為電壓。回聲的**到達時間**告訴你界面距離（$d = ct/2$，除以 2 是因來回）、**振幅**告訴你界面的聲阻抗差有多大。

### 3.2 影像模式

- **A-mode**：一維振幅 vs 深度（最早的形式——現在眼科量眼軸長度仍用）
- **B-mode**：將多條 A-mode 掃描線組合，回聲振幅轉為灰階亮度（hyperechoic 高回聲 = 白、hypoechoic 低回聲 = 暗、anechoic 無回聲 = 黑，如囊腫中的液體），構成二維斷層影像——產科超音波就是 B-mode
- **M-mode**：單一掃描線的 B-mode 隨時間的變化——心臟瓣膜運動的軌跡圖
- **都卜勒模式**：利用紅血球反射的都卜勒頻移 $\Delta f = 2f_0 v\cos\theta/c$ 來量測血流速度。彩色都卜勒將血流方向與速度以顏色編碼疊加在 B-mode 影像上（紅色=朝向探頭、藍色=遠離探頭）

### 3.3 優劣與限制

優點——即時成像（可觀察胎兒活動、心臟搏動）、無游離輻射（產科首選）、可攜帶（急診床邊超音波 POCUS）、相對便宜。限制——氣體與骨骼後方有聲影（聲音無法穿透→看不到後方結構）、肥胖病患影像品質差（超音波頻率愈高空間解析度愈好但穿透深度愈淺——3.5 MHz 深達 15 cm 但解析度 ~1 mm，7.5 MHz 解析度 ~0.4 mm 但只能看淺部數 cm）、操作者依賴性高。

## 4. 核醫影像（PET / SPECT）

PET 的核心：注射正子發射核種標記的示蹤劑（最常用 FDG——氟化去氧葡萄糖，F-18 標記，半衰期 110 分鐘）。癌細胞代謝旺盛 → 攝取更多葡萄糖 → 局部累積較多 FDG。F-18 衰變放出正子 → 與鄰近電子互毀（annihilation）→ 放出兩個 511 keV 背向 γ 光子 → 環形偵測器陣列捕捉符合事件（coincidence detection——兩個偵測器同時收到光子才算一個有效事件，因為兩個互毀光子從同一點往相反方向飛出）。符合事件連線（line of response, LOR）的交點就是放射源的位置。重建演算法從數百萬條 LOR 重建出三維示蹤劑分布。

PET/CT 融合掃描——同一台機器先做 CT（解剖結構）、再做 PET（功能代謝），兩者疊合讓醫師同時看到「腫瘤在哪裡」（CT）與「腫瘤有多活躍」（PET SUVmax——標準化攝取值）。這對癌症分期與治療反應評估至關重要。

## 5. 碩士/博士層級延伸

碩士：**擴散張量影像 DTI**（追蹤水分子沿神經纖維束的優先擴散方向，無創繪製腦白質神經連接圖——tractography）、**AI 輔助診斷**（CNN 用於肺結節偵測、視網膜病變分級、中風 CT 的自動出血檢測——已達放射科醫師水準的特定任務）。博士：**7T 超高場 MRI**（更高的 SNR → 更高的空間解析度 → 可觀察皮質層狀結構，但 B₁ 場不均勻與 SAR 射頻加熱是挑戰）、**光子計數 CT**（用半導體偵測器直接將每個 X 光光子轉為電脈衝，可分辨光子能量→多能譜分解→材料鑑別——例如區分鈣化斑塊與碘造影劑）、**功能連接體**（fMRI 靜息態的跨腦區低頻同步——繪製全腦功能網路圖譜）。
