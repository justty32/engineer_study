# 神經工程與復健科技（Neural Engineering & Rehabilitation Technology）

> 名詞對照見 [中英名詞對照表 → 神經工程](../中英名詞對照表.md#神經工程)。

## 0. 本科定位

神經工程在神經系統與機電系統之間建立雙向介面——讀取神經訊號來控制外部裝置、或用電刺激來恢復失去的感覺與運動功能。對你（電機/通訊背景）而言，這是 BME 中最熟悉的領域——放大器、濾波器、ADC 轉換、微處理器、無線傳輸、回授控制，全都是你的日常工具。

神經工程的獨特挑戰：(1) **訊號極微弱**（皮層腦波 µV 級——埋在 50/60 Hz 雜訊與肌電干擾中）且需長期穩定（植入電極數月後的組織反應會改變阻抗與訊號品質）；(2) **生物相容性**——任何植入物必須不引起免疫排斥或慢性發炎，且封裝必須防止體液滲入腐蝕電子元件（植入式裝置的封裝是 BME 最艱難的工程之一）；(3) **安全**——刺激參數必須嚴格限制，不損傷神經組織，且雙向通訊的裝置不能把外部雜訊注入神經系統。

## 1. 神經刺激——恢復失去的功能

### 1.1 人工耳蝸（Cochlear Implant）

BME 最成功的植入式神經義肢，全球超過 70 萬人受惠。聽力的生理：聲波 → 耳蝸（cochlea——螺旋狀充滿液體的蝸牛殼）→ 基底膜（basilar membrane）上的毛細胞（hair cell）依頻率分布將機械振動轉為神經脈衝——高頻在耳蝸底部（base）、低頻在耳蝸頂端（apex），這稱為**音頻分布（tonotopic organization）**。感音性聽損通常是毛細胞死亡——但聽神經纖維（spiral ganglion cells）大多仍在，只是失去了機械→電的轉換。

人工耳蝸的解決方案：外部麥克風→語音處理器（分頻濾波器組將訊號分成 12–22 個頻帶，模擬耳蝸的頻率分析）→ 編碼 → 經皮膚的無線電感傳輸（transcutaneous inductive link——外部線圈與植入線圈之間靠磁場耦合傳送電力與資料，不需穿皮導線）→ 植入電極陣列沿耳蝸螺旋排列，高頻電極刺激底部神經元、低頻電極刺激頂部→大腦學習解讀這些電訊號為聲音。語音處理策略（如 ACE——Advanced Combination Encoder）決定哪些頻道同時刺激、以什麼速率——這是影響語音辨識率的關鍵演算法參數，需根據使用者的聽神經存活情況個別調校。

### 1.2 深腦刺激（DBS）

立體定位手術將直徑約 1.3 mm 的電極精準植入大腦深處核團（如視丘下核 STN 或蒼白球內側 GPi），以 ~130 Hz 的高頻電脈衝持續刺激。效果近乎魔幻——帕金森氏症病患的顫抖、僵硬、動作遲緩可在刺激開啟後數分鐘內顯著改善。**但機制至今仍未完全理解**——DBS 究竟是抑制了異常的神經振盪？還是用規律的電脈衝「蓋過」不規律的病理性放電模式（類似訊號處理中的 dithering）？還是驅動下游神經纖維的軸突並重置了整個基底核–視丘–皮質迴路的同步狀態？這仍是神經科學的熱門研究議題。

閉迴路 DBS（adaptive DBS）：傳統 DBS 是開迴路——設定好就 24/7 持續刺激，不管病患當下是否需要。閉迴路 DBS 即時偵測病理性神經振盪（例如 STN 的 β 波段 13–30 Hz 功率——震顫愈嚴重此波段功率愈高），只在需要時才刺激。好處：延長電池壽命（植入式脈衝產生器 IPG 的電池壽命從 3–5 年延長到 7–10 年意味著減少二次置換手術）、減少刺激引起的副作用（如構音異常或感覺異常）。

### 1.3 脊髓電刺激與硬膜外電刺激（EES）

脊髓電刺激（SCS, Spinal Cord Stimulation）已廣泛用於慢性疼痛管理——電極貼在脊髓背側（dorsal column），低強度電場刺激阻斷疼痛訊號經脊髓往上傳遞，將其取代為較可接受的麻刺感（paresthesia）。

硬膜外電刺激（EES, Epidural Electrical Stimulation）是脊髓損傷復健領域近年的重大進展——在脊髓腰骶部的後根進入區（dorsal root entry zone）植入多通道電極陣列，以精準的時空模式（spatiotemporal pattern）電刺激活化原本失去大腦輸入的運動神經元迴路。在合適的刺激參數（特定脈衝頻率、振幅、與電極組合的空間分布）下，受試者的腿部肌肉可在無意識控制下產生協調的踏步運動。合併密集的物理復健訓練後，部分完全癱瘓患者能在輔助下站立甚至行走——這歸功於脊髓本身含有節律性運動的中央模式產生器（CPG, Central Pattern Generator），EES 取代了原本應該由腦幹傳下的節律驅動訊號。

## 2. 腦機介面（BMI / BCI）

### 2.1 侵入式 BMI——Utah Array 與 Neuralink

Utah Array 是 10×10 的矽針陣列（每根針長 1–1.5 mm、尖端直徑 ~50 μm），植入大腦運動皮質的手區。每根針尖端的電極記錄周圍數個神經元的細胞外動作電位（extracellular action potential——電極離神經元細胞體愈近，棘波振幅愈大）。**棘波分類（spike sorting）**將混合的多神經元波形依其形狀（振幅、波寬、主峰後電位）分離歸屬到個別神經元，輸出「哪個神經元在何時放電」的序列。

神經解碼——從數十到數百個神經元的放電率（每秒放電次數）推斷運動意圖。最成功的框架：**Kalman 濾波器**——將神經放電率建模為手臂速度的線性函數加雜訊（觀測模型），將手臂速度建模為前一時刻速度 + 加速度（狀態轉移模型），即時預測手臂的意圖速度，驅動機械手臂或游標移動。對 BMI 受試者而言，看著機械手臂按照自己的意念移動→攫取咖啡杯→送到嘴邊，是一個極其深刻的經驗——「我沒有說服這隻機械手臂移動，我就是讓它移動。」

Neuralink（Elon Musk 創立，2024 首例人體植入）的路線是：用機器人外科醫生植入比頭髮還細的柔性電極絲（thread——比 Utah Array 的矽針更柔軟以減少組織損傷，但也更難插入——需要像縫紉機一樣的機器人輔助），數量提升到 1024 個通道。目標從運動 BMI（用念頭控制電腦游標）逐步擴展到感覺 BMI（將攝影機訊號轉為視覺皮質的電刺激→恢復盲人視覺）。

### 2.2 非侵入式 BCI——EEG 腦機介面

頭皮 EEG 的優點是零手術風險，缺點是訊號極為模糊——顱骨與頭皮的體積傳導將皮質神經元的同步突觸後電位在頭皮上「抹開」成一個模糊的電位分布，空間解析度極差（數公分級），且容易受肌電、眼動、心跳、電力線雜訊污染。

基於 EEG 的 BCI 主要應用：(1) **P300 拼字器**——螢幕上字母矩陣逐行逐列閃爍，當使用者注視的字母閃爍時，腦電圖約 300 ms 後出現一個正電位波峰（P300 事件相關電位——對稀有且被關注的刺激的大腦反應），偵測到 P300 即可推斷使用者注視哪個字母。拼一個字母約需 10–20 秒——慢但對完全閉鎖症候群（locked-in syndrome，全身癱瘓但意識清醒）病患來說這是唯一的溝通方法。(2) **運動想像 BCI**——想像移動左手 vs 右手，運動皮質對側的 μ 節律（8–12 Hz）發生事件相關去同步化（ERD——功率下降），分類左右手的 ERD 空間模式以控制二元輸出（游標左右移動、輪椅轉彎）。

## 3. 碩士/博士層級延伸

碩士：**功能性電刺激 FES**（用電極貼片刺激失神經支配的肌肉以產生功能性運動——例如中風後垂足的脛前肌刺激輔助行走。FES 結合 BCI→意念驅動的癱肢運動）、**人工視網膜**（Argus II——攝影機→影像處理→無線傳輸到視網膜上的微電極陣列→刺激視網膜神經節細胞→大腦感知光點圖案）。博士：**雙向閉迴路 BMI**（不只讀取運動意圖控制機械手臂，還將機械手臂指尖的觸覺感測器訊號轉為大腦體感皮質的微電刺激，讓使用者「感覺」到物體的質地——恢復觸覺）、**光遺傳學 BMI**（用基因工程使特定神經元群表達光敏感離子通道，以特定波長的光來興奮或抑制這些神經元——比電刺激精準數千倍但需解決基因輸送與光纖植入的長期生物相容性）、**記憶義肢**（海馬迴植入電極→即時解碼記憶編碼的神經活動→在記憶提取時用電刺激重現該活動模式以增強記憶）。
