# 土木工程概論（Introduction to Civil Engineering）

> 名詞對照見 [中英名詞對照表 → 土木工程概論](../中英名詞對照表-1.md#土木工程概論)。

## 0. 本科在本系的定位

- **它是什麼**：土木工程概論是土木系的入口課——建立對整個學門的鳥瞰視野，了解六大子領域各自做什麼、如何互相銜接，以及土木工程師在社會中的角色。
- **往上游銜接什麼**：無特定先修科目，但需要高中程度的物理常識（力、能量、流體的基本概念）。
- **往下游銜接什麼**：整個土木系的所有後續課程。本科建立的「這個問題屬於哪個子領域、該找誰合作」的宏觀架構會一路用到畢業。
- **核心心法**：土木工程的核心就是一句話——**讓構造物安全、經濟、耐久地抵抗自然與人為的各種作用**。

### 對擁有者的提醒

土木工程對你來說是全新的領域，但你會發現其中大量使用你在電機學過的**系統思維**——每個子領域都是一個子系統，它們之間有明確的輸入輸出關係（例如結構工程輸出「反力」給大地工程，大地工程回傳「沉陷」給結構工程）。本科筆記會把這個「子系統間的界面」特別標出來，幫助你用系統工程的思維理解土木。

## 1. 土木工程的六大子領域

### 1.1 結構工程（Structural Engineering）

**核心問題**：這棟建築/這座橋在各種載重下會不會垮、會不會變形太多？

結構工程師分析與設計承重骨架——房屋的梁柱系統、橋梁的主梁與橋塔、廠房的桁架。計算「外力 → 構件內力 → 斷面尺寸」是每天的工作。最主要的兩種材料是**鋼筋混凝土**和**結構鋼**。

結構工程對力學的倚賴最深：靜力學 → 材料力學 → 結構學 → 混凝土設計/鋼結構設計，是一條必須依序通關的單行道。

### 1.2 大地工程（Geotechnical Engineering）

**核心問題**：這塊地能不能承載這座建築？地基要挖多深？邊坡會不會滑動？

大地工程師研究土壤與岩石的力學行為。結構工程師算出來的柱子反力傳到基礎，基礎再傳到土壤——大地工程師的工作就是確保土壤不會因為受不了而發生過量沉陷或承載破壞。此外擋土牆、隧道、水壩的滲流、邊坡穩定也都歸大地工程管。

### 1.3 水利與水文工程（Water Resources / Hydraulics & Hydrology）

**核心問題**：這條河的洪水有多大？水管要多大口徑？降雨後多少水流到水庫？

水文學處理「降雨 → 逕流 → 河川流量」這個自然循環，水利工程則處理「怎麼用管線、渠道、堰壩來引導與控制水流」。給水（自來水）、排水（雨水下水道）、防洪、灌溉、水力發電都屬於這個範疇。

### 1.4 運輸工程（Transportation Engineering）

**核心問題**：這條路多寬、坡度多陡？路口號誌週期怎麼設？這條高速公路能容納多少車？

運輸工程涵蓋道路與鐵路的幾何設計、鋪面（路面）結構、交通號誌與控制、以及運輸規劃（預測未來交通需求）。它的上游輸入是都市計畫（哪裡要開發），下游交付給結構與大地（路面下的土與路面上方的橋）。

### 1.5 測量學（Surveying / Geomatics）

**核心問題**：設計圖上的點在真實世界的哪裡？建築有沒有蓋在正確的位置上？

測量是把設計圖從紙上搬到地面的學問。傳統用經緯儀與水準儀量角度/距離/高程，現代大量使用 GNSS（全球導航衛星系統，含 GPS）、光達（LiDAR）與無人機。測量是所有土木工程的第一步——沒有測量，連開工都不可能。

### 1.6 營建管理（Construction Management）

**核心問題**：這工程要花多少錢、多久完成、誰來做、怎麼確保品質與安全？

營建管理處理工程的「經營面」：估價（材料、人工、機具成本）、排程（要徑法 CPM）、合約、工地安全、品質管制。結構工程師設計出完美的斷面，但如果現場鋼筋綁錯、混凝土沒養護好，結構一樣會出問題。營管與設計同等重要。

## 2. 土木工程師的角色與倫理

### 2.1 從設計到完工的流程

一座建築從無到有大致經過：

```
業主需求 → 規劃/可行性 → 設計（結構/大地/水利/機電） → 發包招標 → 施工 → 監造驗收 → 使用維護
```

土木工程師參與從規劃到維護的每一個環節。**設計**是最核心的技術工作——但一個好的設計不只是算得對，還要能蓋得出來（施工性）、不超預算（經濟性）、維護方便（耐久性）。

### 2.2 安全係數與設計哲學

土木結構承受的載重永遠有**不確定性**——活載（人、車、家具）可能超重、材料強度有變異、施工品質不如理想、風與地震更是無法精確預測。因此設計時不取「平均值」，而是用兩道安全防線：

- **載重因子（Load Factor）**：把預期載重放大（例如 1.2 倍自重 + 1.6 倍活載）
- **強度折減因子（Strength Reduction Factor / Resistance Factor）**：把材料名目強度打折（例如鋼筋混凝土折減係數 0.9）

極限狀態設計法（Limit State Design）目前在台灣與國際上最通用：要求**放大後的載重 ≤ 折減後的強度**。在美國混凝土界稱「強度設計法（Strength Design）」，鋼結構稱 LRFD（Load and Resistance Factor Design）。

### 2.3 工程師的倫理責任

土木結構一旦出事就是大事——建築倒塌、水壩潰堤、橋梁斷裂，動輒數十甚至數千人命。因此土木工程師面對的矛盾是：業主希望愈省愈好，但安全沒有討價還價的餘地。**公眾安全、健康與福祉永遠優先**——這是全球所有土木工程師倫理規範的第一條。

## 3. 各科目的依賴關係（學習地圖）

土木系的課有非常明確的銜接順序，跳著學幾乎不可能。下面是簡化的先修關係：

```
靜力學 (02)
  ├→ 材料力學 (04)
  │    ├→ 結構學 (06)
  │    │    ├→ 鋼筋混凝土設計 (07)
  │    │    └→ 鋼結構設計 (08)
  │    └→ [間接支持所有設計課]
  ├→ 動力學 (03) → 結構動力 (09)
  ├→ 流體力學 (13) → 水文學 (14) → 水利工程 (15)
  └→ 土壤力學 (11) → 基礎工程 (12)  [另需工程地質 (10)]

相對獨立：工程材料 (05)、測量學 (16)、運輸工程 (17)、營建管理 (18)、施工法 (19)
```

**如果只能先讀一科，讀靜力學。** 整張圖從它開始分岔。

## 4. 規範與標準

土木工程不像電子業可以自由創新——每根梁、每根柱、每塊基礎的設計都必須遵守**國家規範（building code / design standard）**，這些規範是過去幾十年研究加上事故教訓的結晶，具有法律效力。

台灣依照的主要規範：
- 混凝土結構：**混凝土結構設計規範**（以 ACI 318 為藍本）
- 鋼結構：**鋼結構設計規範**（以 AISC 為藍本）
- 建築耐震：**建築物耐震設計規範**
- 基礎：**建築物基礎構造設計規範**

## 5. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 性能化設計（PBD） | 不再只檢查「會不會垮」，而是量化不同地震等級下的損壞程度（可立即使用/修復後可用/不倒）。是下一代耐震設計的趨勢。 |
| 智慧基礎設施監測 | 在橋梁、隧道、水壩安裝感測器（加速度計、應變計、傾斜計），即時監測結構健康，類似結構的「穿戴式裝置」。 |
| BIM（建築資訊模型） | 把設計、施工、維護的全部資訊整合在一個 3D 數位模型裡，顛覆傳統 2D 圖紙的工作流程。 |

## 6. 博士層級研究方向

- 基於可靠度的設計（reliability-based design）——用機率框架量化所有不確定性
- 先進材料在土木的應用（超高強度混凝土 UHPC、纖維強化複材 FRP 補強）
- 韌性城市（resilient city）——城市面對地震、洪水、氣候變遷的系統級抗災設計
- 結構受極端荷載（爆炸、衝擊、連續倒塌）的動力非線性行為
