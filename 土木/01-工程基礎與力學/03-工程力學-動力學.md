# 工程力學—動力學（Engineering Mechanics: Dynamics）

> 名詞對照見 [中英名詞對照表 → 動力學](../中英名詞對照表.md#動力學)。

## 0. 本科在本系的定位

- **它是什麼**：動力學研究「物體受力後如何運動」——當 $\sum\mathbf{F} \neq 0$ 時，剩餘的合力產生加速度。在土木中，動力學的主要應用場景是**地震**與**風**這類動態荷載——它們會讓結構產生振動，而振動可能導致破壞。
- **往上游銜接什麼**：靜力學（平衡概念、自由體圖）、微積分（位置→速度→加速度的微分關係）。
- **往下游銜接什麼**：**結構動力學**（結構在地震波下的振動反應）、**耐震設計**（反應譜、基底剪力）。
- **核心心法**：整個動力學的核心是牛頓第二定律 $\mathbf{F} = m\mathbf{a}$，土木版的重點是把它應用到振動問題上——因為地震力就是結構被迫振動時產生的慣性力。

### 對擁有者的提醒

動力學的核心數學工具——二階常微分方程——正是你在電路分析（RLC 電路）與控制系統中用到爛的。單自由度振動方程 $m\ddot{x} + c\dot{x} + kx = F(t)$ 與 RLC 電路的 $L\ddot{q} + R\dot{q} + q/C = V(t)$ 數學上完全同構。你的所有電路直覺（自然頻率、阻尼比、共振、頻率響應）可以無痛對應過來。

## 1. 質點運動學（Kinematics of Particles）

### 1.1 直線運動

位置 $x(t)$ → 速度 $v = dx/dt$ → 加速度 $a = dv/dt = d^2x/dt^2$。

三種最常見的運動模式：
- **等速**：$a = 0$，$x = x_0 + vt$
- **等加速度**：$v = v_0 + at$，$x = x_0 + v_0 t + \frac{1}{2}at^2$，$v^2 = v_0^2 + 2a(x - x_0)$
- **變加速度**：需要積分 $a(t)$ 來求 $v$ 與 $x$

### 1.2 曲線運動

在平面上，位置由向量 $\mathbf{r}(t) = x(t)\mathbf{i} + y(t)\mathbf{j}$ 描述。速度 $\mathbf{v} = d\mathbf{r}/dt$，加速度 $\mathbf{a} = d\mathbf{v}/dt$。

加速度可分解為兩個分量：
- **切線加速度** $a_t = dv/dt$：改變速率（在速度方向上）
- **法線加速度** $a_n = v^2/\rho$：改變方向（指向曲率中心，$\rho$ 為曲率半徑）

直覺：開車踩油門是切線加速度，轉方向盤造成的是法線加速度。

### 1.3 拋體運動

水平方向無力（等速），垂直方向受重力（等加速 $g$）。可拆成：

$$x = v_0\cos\theta\cdot t,\quad y = v_0\sin\theta\cdot t - \frac{1}{2}gt^2.$$

拋物線軌跡。最大射程發生在發射角 45°（無空氣阻力時）。

## 2. 質點動力學（Kinetics of Particles）

### 2.1 牛頓第二定律

$$\sum \mathbf{F} = m\mathbf{a}.$$

步驟與靜力學相同——先畫 FBD、再寫方程——只是右邊不再是零。已知力求加速度（再積分得速度與位置）是「正問題」，已知運動求所需的力是「逆問題」。

### 2.2 功能原理（Work & Energy）

**功** $U = \int \mathbf{F}\cdot d\mathbf{r}$（力沿路徑的積分）。保守力（重力、彈簧力）的功與路徑無關，可以定義**位能**。

動能 $T = \frac{1}{2}mv^2$。功能原理：

$$T_1 + U_{1\to 2} = T_2.$$

當一個問題「在乎某兩點之間的運動結果而非中間過程」，用能量法比直接積分運動方程更簡潔。

### 2.3 衝量與動量（Impulse & Momentum）

$$\int_{t_1}^{t_2} \mathbf{F}\,dt = m\mathbf{v}_2 - m\mathbf{v}_1.$$

衝量 = 動量的變化。碰撞、衝擊這類短時間大力的問題適合用動量法。

## 3. 剛體運動學與動力學

### 3.1 剛體平面運動

剛體上兩點的運動有約束關係（剛體不變形）。平面運動可分解為**平移 + 繞某點的旋轉**。角速度 $\omega = d\theta/dt$，角加速度 $\alpha = d\omega/dt$。

### 3.2 轉動慣量（Mass Moment of Inertia）

物體繞某軸旋轉時抗拒角加速度的能力，對應於平移運動中的質量：

$$I_O = \int r^2\,dm.$$

對簡單形狀可查表（細桿中心 $I = \frac{1}{12}mL^2$、圓盤 $I = \frac{1}{2}mR^2$）。平行軸定理：$I_O = I_G + md^2$。

### 3.3 剛體轉動的牛頓定律

$$\sum M_O = I_O\,\alpha.$$

合外力矩 = 轉動慣量 × 角加速度。對一般平面運動：$\sum F = m a_G$（平移）＋ $\sum M_G = I_G\alpha$（繞質心旋轉）。

## 4. 振動學基礎（Vibrations）

這是動力學中**與土木最相關的章節**，也是結構動力學的入口。

### 4.1 無阻尼自由振動

質量–彈簧系統：$m\ddot{x} + kx = 0$。解為簡諧運動：

$$x(t) = A\cos(\omega_n t) + B\sin(\omega_n t),$$

**自然頻率** $\omega_n = \sqrt{k/m}$（rad/s），自然週期 $T_n = 2\pi/\omega_n$，自然頻率（Hz）$f_n = \omega_n/(2\pi)$。

「結構的勁度 $k$ 越大，$\omega_n$ 越高（越硬越難振動）；質量 $m$ 越大，$\omega_n$ 越低（越重振動越慢）」。

### 4.2 阻尼自由振動

加入阻尼器：$m\ddot{x} + c\dot{x} + kx = 0$。定義**阻尼比** $\zeta = c/(2m\omega_n) = c/c_{\text{cr}}$：

- $\zeta < 1$（欠阻尼）：振盪衰減，土木結構大多屬此（$\zeta \approx 0.02 \sim 0.10$）
- $\zeta = 1$（臨界阻尼）：最快回到平衡而不振盪
- $\zeta > 1$（過阻尼）：慢速單調衰減

### 4.3 強制振動與共振

外加簡諧力 $F_0\sin(\omega t)$ 作用在質量上。穩態響應的振幅：

$$X = \frac{F_0/k}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}},\quad r = \frac{\omega}{\omega_n}.$$

當 $r \approx 1$ 時，分母極小，振幅可以極大——這就是**共振（resonance）**。阻尼愈小，共振峰愈尖銳。

對土木結構而言，**地震的破壞力在很大程度上來自於地震波的頻率成分接近結構的自然頻率**——這就是為什麼同樣的地震，高樓（$f_n$ 低）與低矮建築（$f_n$ 高）受損模式不同。

## 5. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 多自由度系統 | 實際結構不只一個振動模式（模態），每個模態有各自的頻率與形狀。模態分析是結構動力學的核心工具。 |
| 隨機振動 | 地震與風不是簡單的簡諧波，而是隨機過程。用功率譜密度（PSD）描述其頻率組成，類似訊號處理中的頻譜分析。 |
| 隔減震技術 | 在結構中加入特殊裝置（鉛心橡膠隔震支承、液態黏滯阻尼器），把結構與地面的振動隔開，或用阻尼消耗地震輸入的能量。 |

---

## 6. 博士層級研究方向

- 非線性動力分析（幾何非線性、材料非線性、邊界條件非線性）用於極限狀態下的結構行為
- 流固耦合（風與橋梁、波浪與離岸結構）的大規模模擬
- 自適應隔減震系統（半主動控制、磁流變阻尼器的即時調節）
