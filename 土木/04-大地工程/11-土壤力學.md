# 土壤力學（Soil Mechanics）

> 名詞對照見 [中英名詞對照表 → 土壤力學](../中英名詞對照表.md#土壤力學)。

## 0. 本科在本系的定位

土壤力學是大地工程的核心理論課。如果說「大地工程」這棟房子有地基，那地基就是土壤力學——後續的基礎工程、邊坡穩定、擋土結構、地盤改良，全部建立在土壤力學的理論框架之上。

Karl Terzaghi（1883–1963）被公認為土壤力學之父。在 Terzaghi 之前，土壤的工程設計靠的是經驗公式與直覺判斷。Terzaghi 在 1925 年出版《Erdbaumechanik》（土壤力學），以**有效應力原理**為基石，把土壤從一種「說不清楚的混合物」變成一個可以用力學分析的工程材料。他的洞見極簡但極深刻：「土壤的強度與變形，全由有效應力控制，而非總應力。」

本科的學習曲線：先搞懂土壤的組成與分類（你在跟什麼材料打交道），引入有效應力原理（這個材料力學行為的核心機制），然後圍繞兩個主軸展開——滲流（水如何在土壤中流動）與變形/強度（土壤受力後如何壓縮、滑移、最終破壞），最後把這些知識整合到側向土壓與邊坡穩定的工程應用中。

## 1. 土壤的組成與分類

### 1.1 三相體系（Three-Phase System）

土壤不是單一材料——它由**固體顆粒 + 水 + 空氣**三相組成。這三個相的相對比例控制著土壤的所有物理性質。建立三相圖（將固體、水、空氣的體積與重量關係整理在一張圖上）是土壤力學的基本功。

**基本定義**：

- **含水量（water content）**：$w = \dfrac{W_w}{W_s} \times 100\%$——水的重量與固體顆粒乾重的比值。天然含水量範圍可從砂的數%到軟弱黏土的 100% 以上。
- **孔隙比（void ratio）**：$e = \dfrac{V_v}{V_s}$——孔隙體積與固體體積的比值。$e$ 是大地工程最常用的密度參數（而非孔隙率），因為在計算沉陷時，固體體積不變，只有 $e$ 改變。
- **孔隙率（porosity）**：$n = \dfrac{V_v}{V} \times 100\%$——孔隙體積佔總體積的百分比。$n = \dfrac{e}{1+e}$。
- **飽和度（degree of saturation）**：$S = \dfrac{V_w}{V_v} \times 100\%$。$S = 100\%$ 為完全飽和，$S = 0\%$ 為完全乾燥。地下水面以下通常假設飽和（$S = 100\%$）。

**三相關係的核心公式**（已知 $G_s$、$w$、$e$ 可推導所有其他量）：

$$\gamma = \frac{G_s(1+w)}{1+e}\gamma_w \quad\text{（總單位重）}$$

$$\gamma_d = \frac{G_s}{1+e}\gamma_w \quad\text{（乾單位重）}$$

$$\gamma_{sat} = \frac{G_s + e}{1+e}\gamma_w \quad\text{（飽和單位重）}$$

其中 $G_s$ 為土粒比重（specific gravity of solids），大多數礦物土壤的 $G_s \approx 2.65$–$2.75$。

### 1.2 粒徑分布（Grain Size Distribution）

粗粒土（礫石、砂）的粒徑用**篩分析（sieve analysis）**：一疊標準篩從大到小疊起，震動後稱各篩上的殘留重量。細粒土（粉土、黏土）的粒徑用**比重計分析（hydrometer analysis）**：利用 Stokes 沉降定律——顆粒在懸浮液中沉降速度與粒徑平方成正比。

粒徑分布曲線的兩個關鍵參數：
- **有效粒徑 $D_{10}$**：通過百分率 10% 對應的粒徑——與滲透係數相關（Hazen 公式 $k \approx C D_{10}^2$，適用於均勻砂）。
- **均勻係數（uniformity coefficient）**：$C_u = D_{60}/D_{10}$——$C_u < 4$ 為均勻級配（poorly graded），$C_u > 6$ 為良好級配（well graded）。
- **曲率係數（coefficient of curvature）**：$C_c = D_{30}^2/(D_{10} \times D_{60})$——良好級配的砂質土需滿足 $1 < C_c < 3$。

### 1.3 Atterberg 界限（Atterberg Limits）

細粒土（粉土和黏土）的行為隨含水量改變而劇烈變化——從固體到半固體、塑性體、最後變成液體。Atterberg 界限定義了這些轉折點：

- **液限（liquid limit, LL）**：土壤從塑性狀態過渡到液態的含水量。用 Casagrande 液限儀（標準銅杯落下試驗）或落錐法測定。
- **塑限（plastic limit, PL）**：土壤從半固體狀態過渡到塑性狀態的含水量——將土搓成直徑 3 mm 的細條時開始碎裂的含水量。
- **塑性指數（plasticity index）**：$PI = LL - PL$——土壤表現塑性行為的含水量範圍。PI 愈大，土壤的塑性範圍愈寬，通常黏土含量愈高、脹縮性愈大。
- **縮限（shrinkage limit, SL）**：含水量低於此值後，土壤體積不再隨水分蒸發而縮小。

**液性指數（liquidity index, LI）**：$LI = \dfrac{w - PL}{PI}$——描述土壤當前的稠度狀態。LI ≈ 0 → 土壤處於塑限附近（硬稠），LI ≈ 1 → 土壤處於液限附近（軟稠），LI > 1 → 土壤呈液態流體狀態（靈敏黏土受擾動後常達此狀態）。

**活性（activity, A）**：$A = \dfrac{PI}{\text{黏土含量（< 2 μm）\%}}$——描述黏土礦物的種類：
- $A < 0.75$：不活性（高嶺土 kaolinite 為主）
- $0.75 < A < 1.25$：正常活性（伊利石 illite 為主）
- $A > 1.25$：活性（蒙特石 montmorillonite / smectite 為主——膨脹性極強、工程上最頭痛的黏土礦物）

### 1.4 統一土壤分類法（USCS）

USCS（Unified Soil Classification System）是全球大地工程界的共通語言。分類邏輯：

1. 粗粒土（通過 #200 篩 < 50%）：依粒徑分為礫石（G, gravel——粒徑 > 4.75 mm）與砂（S, sand——4.75 mm > 粒徑 > 0.075 mm）。再依級配或細粒含量加上後綴 W（well graded, 良好級配）、P（poorly graded, 不良級配）、M（silty, 含粉土）、C（clayey, 含黏土）。
2. 細粒土（通過 #200 篩 ≥ 50%）：依 Casagrande 塑性圖（plasticity chart）——以 LL 為橫軸、PI 為縱軸，落在 A-line 上方為黏土（C, clay），下方為粉土（M, silt）。再依 LL 高低分為高塑性（H，LL > 50%）與低塑性（L，LL < 50%）。

例如：**SP-SM** = 不良級配砂含粉土；**CH** = 高塑性黏土（膨脹性強）；**CL** = 低塑性黏土（工程性質較穩定）。

### 1.5 黏土礦物學簡述

黏土礦物是矽酸鹽片狀礦物，粒徑 < 0.002 mm（2 μm）。三種最常見的黏土礦物：

- **高嶺土（kaolinite）**：雙層結構（矽氧四面體片 + 鋁氧八面體片），層間以氫鍵連結——鍵結力強，水分子不易進入層間，膨脹性低，工程上最「聽話」的黏土。
- **伊利石（illite）**：三層結構，層間以鉀離子連結——鍵結力中等，膨脹性中等。
- **蒙特石（montmorillonite / smectite）**：三層結構，但層間以極弱的凡得瓦力連結——水分子大量進入層間，體積可膨脹至乾燥時的數倍。**蒙特石是「災難性黏土」**——其上的輕型建築會因土壤反覆吸水膨脹/失水收縮而開裂。

## 2. 土壤中的水流（Seepage）

### 2.1 Darcy 定律

Darcy（1856）通過砂柱實驗發現，通過土壤的流量與水力梯度成正比：

$$q = k i A.$$

- $q$：單位時間流量（體積/時間）
- $k$：滲透係數（hydraulic conductivity，單位 cm/s 或 m/s）——不是一個材料常數，而是取決於土壤（粒徑、孔隙比、飽和度）與流體（黏滯度 = f(溫度)）兩者的性質
- $i$：水力梯度（hydraulic gradient）$i = \Delta h / L$——水頭損失與流徑長度之比
- $A$：垂直於流向的總截面積（包含固體顆粒截面積，而非僅孔隙截面積）

**典型滲透係數範圍**：礫石 $k \sim 10^{-1}$–$10^1$ cm/s；砂 $k \sim 10^{-3}$–$10^{-1}$ cm/s；粉土 $k \sim 10^{-6}$–$10^{-3}$ cm/s；黏土 $k \sim 10^{-9}$–$10^{-6}$ cm/s。黏土與礫石之間的 $k$ 可差到 $10^{10}$ 倍——這就是為什麼黏土層可以作為天然的不透水屏障，而礫石層的地下水一天可以流動數十米。

**Darcy 定律的適用範圍**：Darcy 定律是層流（laminar flow）條件下的經驗定律。當流速過高時（礫石、岩塊中的湍流），Darcy 定律不再成立——雷諾數 $Re = v D_{10} / \nu$ 超過約 1–10 時進入非 Darcy 流範圍。但對大多數土壤（粉土、砂、甚至細礫石），流速極低，Darcy 定律完全適用。

### 2.2 流線網（Flow Net）

二維穩態滲流的控制方程是 Laplace 方程：

$$\frac{\partial^2 h}{\partial x^2} + \frac{\partial^2 h}{\partial z^2} = 0.$$

這方程描述的是「無源無匯、均質、不可壓縮」條件下的穩態滲流——與熱傳導穩態方程完全同構。解 Laplace 方程可以得到兩種曲線族：

- **流線（flow line）**：水流質點的路徑。
- **等勢能線（equipotential line）**：水頭相等的點的連線。

流線與等勢能線**處處正交**（這是 Laplace 方程的性質）。手繪流線網的基本規則：
1. 上游面與下游面是等勢能線（水頭沿邊界均勻）
2. 不透水邊界是流線（水不能穿過）
3. 流線與等勢能線正交
4. 每個「方格」（flow channel × equipotential drop）的面積大致相等（形成「曲線正方形」）

**流線網的應用**：
- 計算滲流量：$q = k \cdot \Delta h \cdot \dfrac{N_f}{N_d}$（$N_f$ = 流槽數，$N_d$ = 等勢能降次數）
- 計算任一點的孔隙水壓力：從該點的水頭減去高程水頭
- 評估管湧風險：出口處的水力梯度最大，若超過臨界值則可能發生管湧

### 2.3 有效應力原理——Terzaghi 的天才洞見

這是整科最重要的一個公式：

$$\sigma' = \sigma - u.$$

- $\sigma$：總應力（上面所有材料的重量除以面積）
- $u$：孔隙水壓力（pore water pressure）
- $\sigma'$：**有效應力**——固體顆粒骨架實際承受的應力

物理意義：總應力由「顆粒間的接觸力」和「孔隙水的壓力」共同分擔。水是流體，不能承受剪力——所以土壤的強度、變形、體積變化，**全部由有效應力控制**。水壓變高 → 有效應力變低 → 土壤變弱、體積可能膨脹；水壓變低 → 有效應力變高 → 土壤變強、體積壓縮。

一個經典的直覺：把一塊海綿放在水中施加外壓——水也承受了壓力，海綿骨架幾乎不受力。這就是有效應力原理的物理圖像。

**有效應力原理的工程後果無處不在**：
- 地下水位下降（抽水）→ 有效應力增加 → 地層壓密沉陷
- 豪雨後邊坡中的孔隙水壓力上升 → 有效應力降低 → 剪力強度降低 → 邊坡可能滑動
- 開挖面的滲流出口 → 水壓梯度向上 → 有效應力趨近於零 → 流砂（quick condition）
- 地震振動 → 鬆砂中的孔隙水壓力急遽上升 → 有效應力趨近於零 → 液化

### 2.4 流砂與管湧

**流砂（quick condition / boiling）**：當向上的滲流力等於土壤的水中單位重時，有效應力降為零，土壤顆粒不再有接觸力——此時的土壤行為像流體而非固體，稱為流砂狀態。臨界水力梯度：

$$i_{cr} = \frac{G_s - 1}{1 + e} = \frac{\gamma_{sat} - \gamma_w}{\gamma_w}.$$

對於一般砂土，$i_{cr} \approx 1.0$（即每公尺流徑損失一公尺水頭）。開挖面底下的向上滲流是工程上最常見的流砂場景——板樁圍堰內的開挖若排水不當，坑底會突然隆起湧砂，這在實務上是極危險的施工災害。

**管湧（piping / internal erosion）**：當滲流力足以將細顆粒從土壤骨架中帶走時，形成管狀通道，從下游往上游逐漸掏空——這是土石壩潰壩最常見的機制。防止管湧的方法是設置**過濾層（filter）**——粒徑分級設計使得粗顆粒（濾料）的孔隙小到足以攔阻被保護土的細顆粒（Terzaghi 過濾準則：$D_{15(\text{filter})} / D_{85(\text{soil})} < 4$–$5$）。

## 3. 土壤的壓縮與壓密（Compressibility & Consolidation）

### 3.1 壓密的物理過程

飽和黏土受力時並不會立刻壓縮——因為水幾乎不可壓縮，而黏土的滲透係數極低，水需要時間才能從孔隙中擠出。這個「應力增加 → 孔隙水壓力暫時升高（超額孔隙水壓力 excess pore water pressure） → 水慢慢排出 → 有效應力逐漸增加 → 土壤逐漸壓縮」的時變過程稱為**壓密（consolidation）**。

關鍵區分：
- **壓密**是體積減小的「過程」（含時間因素）
- **壓縮性（compressibility）**是體積減小的「量」（時間無關的終態關係）

砂土的壓密極快（$k$ 大，水幾乎立即排出）——工程上通常只考慮其最終沉陷量，不關心率（rate）。黏土的壓密極慢（$k$ 小，水排數十年）——必須同時考慮沉陷量與沉陷速率。

### 3.2 壓密試驗（Oedometer / Consolidation Test）

在實驗室中，將不擾動土樣放入剛性環中，施加逐級增加的垂直應力，記錄每級應力下的壓縮量與時間。實驗結果繪成兩條曲線：

1. **$e$–$\log\sigma'$ 曲線**：在正常壓密範圍內呈直線（正常壓密線，NCL），斜率為 $C_c$（壓縮指數，compression index）。卸載–再加載段較平緩，斜率為 $C_r$（再壓縮指數，recompression index），$C_r \ll C_c$（通常 $C_r \approx (0.05$–$0.1) \times C_c$）。
2. **壓密曲線（時間–壓縮量）**：用於求壓密係數 $c_v$。

**預壓密壓力（preconsolidation pressure, $\sigma'_p$）**的決定——Casagrande 圖解法：在 $e$–$\log\sigma'$ 曲線上找曲率最大點，做切線與水平線的角平分線，該線與 NCL 延伸線的交點即為 $\sigma'_p$。

### 3.3 正常壓密與過壓密

$$OCR = \frac{\sigma'_p}{\sigma'_0}.$$

- **正常壓密（normally consolidated, NC）**：$OCR = 1$——土壤目前承受的有效應力等於歷史上曾經承受過的最大有效應力。此時土壤「正好」在 NCL 上。
- **過壓密（overconsolidated, OC）**：$OCR > 1$——土壤歷史上曾經承受過比現在更大的應力（原因：冰河覆蓋後退去、上方土層被侵蝕剝除、過去的地下水位比現在低、人為預壓）。過壓密土比正常壓密土更硬、強度更高、沉陷更小。
- **欠壓密（underconsolidated）**：$OCR < 1$——仍在壓密過程中（如新填土、河口淤泥），尚未達到平衡。

### 3.4 沉陷計算

黏土層的總壓密沉陷量：

$$S_c = \frac{C_c}{1 + e_0} H \log\frac{\sigma'_0 + \Delta\sigma'}{\sigma'_0}\quad\text{（正常壓密）}$$

$$S_c = \frac{C_r}{1 + e_0} H \log\frac{\sigma'_p}{\sigma'_0} + \frac{C_c}{1 + e_0} H \log\frac{\sigma'_0 + \Delta\sigma'}{\sigma'_p}\quad\text{（過壓密，且 }\sigma'_0 + \Delta\sigma' > \sigma'_p\text{）}$$

其中 $H$ 為黏土層厚度，$e_0$ 為初始孔隙比，$\Delta\sigma'$ 為外加荷載造成的有效應力增加。

### 3.5 Terzaghi 一維壓密理論

Terzaghi 推導了飽和黏土一維壓密的控制偏微分方程：

$$\frac{\partial u_e}{\partial t} = c_v \frac{\partial^2 u_e}{\partial z^2}.$$

其中 $u_e$ 為超額孔隙水壓力（excess pore water pressure），$c_v$ 為**壓密係數（coefficient of consolidation）**：

$$c_v = \frac{k}{m_v \gamma_w} = \frac{k(1+e_0)}{a_v \gamma_w}.$$

$m_v$ 為體積壓縮係數，$a_v$ 為壓縮係數。$c_v$ 的物理意義是「黏土層排水壓密的快慢」——$c_v$ 愈大，壓密愈快完成。

**壓密度（degree of consolidation, $U$）**：定義為「時間 $t$ 時的沉陷量 ÷ 最終沉陷量」。$U$ 是時間因子 $T_v = c_v t / H_{dr}^2$（無因次時間）的函數：

$$U = 1 - \sum_{m=0}^{\infty} \frac{2}{M^2} e^{-M^2 T_v}, \quad M = \frac{\pi}{2}(2m+1)$$

實用近似：$U < 60\%$ 時 $T_v \approx \frac{\pi}{4}U^2$；$U > 60\%$ 時 $T_v \approx -0.933\log(1-U) - 0.085$。

**$c_v$ 的實驗決定方法**：
- **Casagrande 對數時間法（log-time method）**：在壓縮量–$\log t$ 曲線上找 $U = 50\%$ 的對應時間 $t_{50}$，$c_v = 0.197 H_{dr}^2 / t_{50}$。
- **Taylor 根號時間法（root-time method）**：在壓縮量–$\sqrt{t}$ 曲線上找 $U = 90\%$ 的時間，$c_v = 0.848 H_{dr}^2 / t_{90}$。

### 3.6 二次壓縮（Secondary Compression）

在超額孔隙水壓力消散完畢（$U \approx 100\%$）之後，沉陷仍在繼續——這是土壤顆粒骨架本身的潛變（creep），稱為二次壓縮。二次壓縮量：

$$S_s = C_{\alpha} H \log\frac{t}{t_p}.$$

$C_{\alpha}$ 為二次壓縮指數（$C_{\alpha} = \Delta e / \Delta \log t$）。有機質土與泥炭（peat）的 $C_{\alpha}$ 極大，二次壓縮可能佔總沉陷的主要部分。

## 4. 土壤的剪力強度（Shear Strength）

### 4.1 Mohr–Coulomb 破壞準則

土壤的破壞以剪力形式發生（顆粒之間的滑移與重新排列）。最重要的破壞準則是 Mohr–Coulomb：

$$\tau_f = c' + \sigma'_f \tan\phi'.$$

- $\tau_f$：破壞面上的剪力強度
- $\sigma'_f$：破壞面上的有效正交應力
- $c'$：有效凝聚力（apparent cohesion）——顆粒之間的「黏結」力。對乾淨砂，$c' \approx 0$；對黏土，$c'$ 可為非零值，但多數情況下 $c'$ 非常小
- $\phi'$：有效內摩擦角——土壤的「摩擦」性質，來自顆粒間的咬合（interlocking）與滑動

注意符號：$c'$ 與 $\phi'$ 帶有撇號（$\prime$）代表以**有效應力**為基準的有效強度參數。這些是土壤的「真實」材料性質，與排水條件無關。

### 4.2 排水與不排水——核心概念

土壤是二相（飽和時為固+水）材料。當荷載施加時，有兩個極端情況：

- **排水（drained）**：加載速率極慢，水有足夠時間進出孔隙，超額孔隙水壓始終為零（$\Delta u = 0$）→ 總應力的增加完全轉化為有效應力的增加。**砂土通常處於排水條件**（滲透性高）。
- **不排水（undrained）**：加載速率極快，水完全來不及排出，體積保持不變（constant volume）→ 總應力的增加由孔隙水壓力承擔，有效應力不變。**飽和黏土在不排水條件下，有效應力不變 → 強度不變**。

這就是為什麼黏土地基上的快速填土可能導致災難性破壞——填土速度太快 → 不排水 → 黏土強度來不及隨有效應力增加而增加 → 承載力不足。

### 4.3 三軸試驗（Triaxial Test）

三軸壓縮試驗是量測土壤剪力強度的標準室內方法。圓柱形土樣在圍壓（$\sigma_3$）下，施加軸向壓力（$\Delta \sigma$）直至破壞。

三種標準試驗程序：

- **CD（Consolidated Drained，壓密排水）**：壓密階段排水閥開啟 → 剪切階段排水閥保持開啟，速率極慢確保 $\Delta u = 0$。測得 $c_d'$、$\phi_d'$——**有效強度參數**，費時最長，但得到的強度參數最「正宗」。
- **CU（Consolidated Undrained，壓密不排水）**：壓密階段排水 → 剪切階段排水閥關閉不排水，同時量測孔隙水壓力。測得總應力參數（$c_{cu}$、$\phi_{cu}$）以及孔隙水壓力參數，可推算有效應力參數。**最常用**，因為比 CD 快得多，又能得到有效應力參數（若量測孔壓）。
- **UU（Unconsolidated Undrained，不壓密不排水）**：全程排水閥關閉。對飽和黏土，不同圍壓下的 Mohr 圓直徑相同 → $\phi_u = 0$，$c_u = s_u = \Delta\sigma_f/2$（不排水剪力強度）。這是最快速的試驗，適用於飽和黏土的不排水加載分析（$\phi = 0$ 法）。

### 4.4 典型強度參數

- **砂土**：$c' \approx 0$，$\phi' \approx 30$°–$40$°（鬆砂偏低，緊砂偏高）。緊砂剪切時體積膨脹（dilatancy）——顆粒必須翻越彼此才能滑移，表現出較高的摩擦角；鬆砂剪切時體積收縮。
- **正常壓密黏土**：$c' \approx 0$，$\phi' \approx 20$°–$30$°（塑性愈高，$\phi'$ 愈低）。
- **過壓密黏土**：$c' > 0$（由於歷史最大應力產生的膠結效應），$\phi'$ 與正常壓密黏土相近。
- **不排水剪力強度 $s_u$**：對正常壓密黏土，$s_u/\sigma'_v \approx 0.2$–$0.3$（Skempton 的 $s_u/p$ 比）。$s_u$ 不是一個常數——它隨有效應力與取樣擾動而變化。

### 4.5 應力路徑概念（Stress Path）

將三軸試驗中的應力狀態畫在 $p$–$q$ 平面上（$p = (\sigma_1 + \sigma_3)/2$，$q = (\sigma_1 - \sigma_3)/2$），可以追蹤加載過程中應力狀態的演變——稱為**應力路徑（stress path）**。排水與不排水路徑不同：排水路徑的斜率為 3（$dq/dp = 3$），不排水路徑從初始狀態往左上方走（因為 $\Delta u$ 增加 → $p'$ 減少而 $q$ 增加）。應力路徑的終點落在破壞線（$K_f$ line）上，其斜率 $M = 6\sin\phi'/(3-\sin\phi')$。

### 4.6 Skempton 孔隙水壓力參數

在不排水條件下，由於總應力變化而引起的孔隙水壓力變化：

$$\Delta u = B[\Delta\sigma_3 + A(\Delta\sigma_1 - \Delta\sigma_3)].$$

- $B$：等向壓力的孔隙水壓力係數。對飽和土 $B \approx 1$（水幾乎不可壓縮），非飽和土 $B < 1$（孔隙中有可壓縮的空氣）。
- $A$：偏差應力的孔隙水壓力係數。對正常壓密黏土 $A_f \approx 0.5$–$1.0$；對過壓密黏土 $A_f \approx 0$–$0.5$（甚至可為負值——過壓密土不排水剪切時有膨脹趨勢，產生負孔隙水壓力 suction）；對鬆砂液化 $A_f$ 極高。

## 5. 側向土壓力（Lateral Earth Pressure）

擋土結構背後的土壤壓力不是流體的靜水壓（$K = 1$），而是取決於牆是否可以移動以及移動的方向與大小。

### 5.1 靜止土壓（At-Rest Earth Pressure）

牆完全不動時（如地下室的外牆、橋台的胸牆），土壤中的側向應力與垂直應力之比值：

$$K_0 = \frac{\sigma'_h}{\sigma'_v}.$$

- **正常壓密土**：Jaky 經驗公式 $K_0 \approx 1 - \sin\phi'$。
- **過壓密土**：$K_{0(OC)} \approx K_{0(NC)} \times OCR^{\sin\phi'}$——過壓密土的 $K_0$ 可能大於 1（因為卸載時側向應力釋放較垂直應力慢），這是高度過壓密黏土與壓實填土中可能出現高側壓的原因。

### 5.2 Rankine 土壓理論

Rankine 理論適用於牆面光滑（無牆土間摩擦力）、填土面水平、牆背垂直的理想情況。

- **主動狀態（active）**：牆往外移，土壤側向伸張 → 側向應力逐漸降至最低值（再低就破壞）。主動土壓係數：

$$K_a = \tan^2\!\left(45° - \frac{\phi'}{2}\right) = \frac{1 - \sin\phi'}{1 + \sin\phi'}$$

主動土壓力分布為三角形（對無凝聚性土壤），合力作用於牆底以上 $H/3$ 處。

- **被動狀態（passive）**：牆往內推，土壤側向壓縮 → 側向應力逐漸升至最高值（再高就破壞）。被動土壓係數：

$$K_p = \tan^2\!\left(45° + \frac{\phi'}{2}\right) = \frac{1 + \sin\phi'}{1 - \sin\phi'}$$

$K_a < K_0 < K_p$，且 $K_p = 1/K_a$（對 Rankine 理論）。典型數值：$\phi' = 30$° → $K_a = 0.33$，$K_p = 3.0$——被動區的抵抗力約為主動區推力的 9 倍（因為牆前的被動區通常只用到較淺的深度）。

**凝聚性土壤的 Rankine 土壓**：黏土的凝聚力 $c'$ 使主動土壓減小、被動土壓增大。主動土壓可能在淺層出現負值（張力），理論上形成**張力裂縫（tension crack）**——但工程上保守假設張力區的土壓為零（裂縫可能被水填充產生額外水壓）。

### 5.3 Coulomb 土壓理論

Coulomb 理論考慮**牆–土之間的摩擦**（牆面非光滑），以滑動土楔（sliding wedge）的力平衡求土壓力。Coulomb 公式比 Rankine 更一般化（可處理傾斜牆面與傾斜填土面），但數學形式更複雜。

**Coulomb 主動土壓係數**：

$$K_a = \frac{\sin^2(\beta + \phi')}{\sin^2\beta \sin(\beta - \delta)\left[1 + \sqrt{\frac{\sin(\phi' + \delta)\sin(\phi' - \alpha)}{\sin(\beta - \delta)\sin(\alpha + \beta)}}\right]^2}$$

其中：$\beta$ = 牆背與水平面的夾角，$\alpha$ = 填土面與水平面的夾角，$\delta$ = 牆–土之間的摩擦角（通常取 $\delta \approx (1/2$–$2/3)\phi'$）。

### 5.4 土壓力的影響因素

- **牆的移動量**：要達到主動狀態，擋土牆頂需要往外移動約 0.001 $H$（$H$ 為牆高）；要達到被動狀態，移動量約 0.01–0.05 $H$——被動需要相當大的位移才能完全激發。
- **地下水位**：水壓力疊加在土壓力上（水的 $K_w = 1$）。在擋土牆設計中，排水是至關重要的——牆後的排水不良比土壓力計算誤差危險得多。
- **地表荷載（surcharge）**：緊貼牆後的地表均勻荷載 $q$ 產生額外的水平土壓 $\Delta\sigma_h = K q$（$K$ 為對應的主動、被動、或靜止係數）。

## 6. 邊坡穩定（Slope Stability）

### 6.1 邊坡破壞型態

- **無限邊坡（infinite slope）**：滑動面平行於坡面，且滑動體的長度遠大於深度——適用於淺層風化層的平面滑動分析。
- **有限邊坡（finite slope）**：滑動面通常為圓弧形（均質土體）或沿既有不連續面（岩坡）。圓弧破壞是最常見的土坡破壞型態。

### 6.2 無限邊坡分析

對無凝聚性乾砂坡（$c' = 0$，無滲流）：

$$FS = \frac{\tan\phi'}{\tan\beta}.$$

安全係數只取決於坡角 $\beta$ 與摩擦角 $\phi'$ 的關係——只要 $\beta \leq \phi'$，邊坡就穩定（FS ≥ 1）。這就是為什麼砂土堆的自然安息角（angle of repose）等於 $\phi'$。

對有滲流平行於坡面的情況（最危險的水文條件——豪雨後坡面飽和）：

$$FS = \frac{\gamma'}{\gamma_{sat}} \frac{\tan\phi'}{\tan\beta} \approx 0.5 \times \frac{\tan\phi'}{\tan\beta}.$$

$\gamma'/\gamma_{sat} \approx 0.5$——滲流平行於坡面時，安全係數大約只有乾燥時的一半。這就是為什麼暴雨過後邊坡大量滑動。

### 6.3 有限邊坡——切片法（Method of Slices）

對一般形狀的滑動面（通常假設為圓弧），將滑動體上方的土體切成若干垂直薄片，逐片計算其不平衡力矩。

**安全係數定義**（對圓弧滑動）：

$$FS = \frac{\sum \text{抵抗力矩}}{\sum \text{下滑力矩}} = \frac{\sum (c'\ell + N'\tan\phi')}{\sum W\sin\alpha}.$$

其中 $\ell$ 為每一切片的滑動面長度，$N'$ 為滑動面上的有效正交力（$N' = N - u\ell$），$W$ 為每一切片重量，$\alpha$ 為每一切片滑動面的傾角。

各種切片法的差異在於如何處理切片的側向力（interslice forces）：

- **一般切片法（Ordinary / Swedish Circle / Fellenius）**：忽略所有側向力。雖最簡單但對於深層滑動或高孔隙水壓的情況誤差可能達 10–50%（保守側）。
- **Bishop 簡化法（Bishop's Simplified Method）**：假設切片兩側的豎向側向力相等（忽略豎向側向力差），僅考慮水平側向力。精度大幅提升誤差 < 5%，是**工程實務上最廣泛使用**的方法。需迭代求解（$FS$ 出現在公式兩邊）。
- **Spencer 法**：假設側向力的合力方向為一常數（滿足力與力矩平衡），精度最高。
- **Morgenstern–Price 法**：Spencer 法的推廣——側向力方向可沿滑動面變化，是最一般的切片法。

### 6.4 邊坡穩定分析的實務考量

- **臨界滑動面（critical slip surface）**：對圓弧破壞，需搜尋 $FS$ 最小的那個圓弧——通常用網格搜尋或優化演算法。
- **張力裂縫（tension crack）**：坡頂附近的張力區可能開裂，裂縫中若有水會有額外水壓力。
- **驟降（rapid drawdown）**：水庫或河道水位快速下降時，邊坡外側失去水壓支撐，但內側孔隙水壓力尚未消散——有效應力驟減，安全係數急遽降低。驟降常是水庫邊坡滑動的觸發條件。
- **地震**：擬靜力（pseudo-static）分析——在每一片加上水平地震力 $k_h W$ 與垂直地震力 $k_v W$，$k_h$ 取設計地震係數。

### 6.5 Taylor 穩定圖表

Taylor（1937）發展了均質黏土邊坡的穩定圖表——在已知坡角 $\beta$、土壤摩擦角 $\phi'$、與凝聚力參數的情況下，直接查圖得出穩定數（stability number）$N_s = \gamma H / c$。這些圖表對於初步設計與快速估算非常實用。

## 7. 碩士/博士層級延伸

### 碩士層級

- **臨界狀態土壤力學（Critical State Soil Mechanics, CSSM）**：由 Roscoe、Schofield、Wroth 在劍橋大學發展的統一框架——以 $v$–$p'$–$q$（比容–平均有效應力–偏差應力）空間描述土壤的各種行為，核心模型為 Cam-Clay 與 Modified Cam-Clay。CSSM 的優雅之處在於它用同一個框架統一解釋排水與不排水、正常壓密與過壓密、壓縮與膨脹——這是土壤本構模型（constitutive model）的理論基礎，也是所有現代數值分析（FEM for geotechnics）的核心。
- **非飽和土壤力學（Unsaturated Soil Mechanics）**：引入基質吸力（matric suction, $u_a - u_w$）作為第二應力狀態變量（Bishop 有效應力或 Fredlund 雙應力變量架構），解釋膨脹土（expansive soil）的體積變化、殘積土（residual soil）的剪力強度、降雨引發邊坡滑動的機制（吸力喪失 → 有效應力驟降）。
- **土壤動力學（Soil Dynamics）**：地震波在土壤中的傳播、場址效應（site effect——軟弱土層對特定週期地震波的放大）、地盤反應分析（SHAKE, DEEPSOIL），以及液化評估的進階方法（Seed–Idriss 簡化法、有效應力動力分析）。
- **地工離心機模型試驗（Geotechnical Centrifuge Modeling）**：在離心機中以高重力模擬原型應力，用縮尺模型研究堤壩、隧道、邊坡、基礎的破壞機制——是驗證數值模型與簡化方法的重要手段。

### 博士層級

- **應變局部化與剪力帶（Strain Localization & Shear Band）**：土壤破壞前出現厚度僅數個粒徑的集中變形帶——這是材料失穩的前兆，但在傳統連續體力學中無法自然模擬（需引入非局部理論、Cosserat 連續體或正則化 technique）。
- **離散元素法（Discrete Element Method, DEM）**：將土壤視為個別顆粒的集合，計算每個顆粒的運動與接觸力——從微觀機制出發，直接模擬粒狀材料的宏觀行為（如剪力膨脹、應變軟化、顆粒破碎）。DEM 的瓶頸是運算量極大，目前僅能處理實驗尺度的問題。
- **液化後大變形行為**：液化後土壤從固態轉為流體狀態，產生數十米的側向擴張（lateral spreading）——模擬這種固–液轉變的大變形問題需要使用無網格數值方法（SPH, MPM）或 Eulerian 有限元素法。
- **多相耦合 THMC（熱–水–力–化）**：用於核廢料地質處置的長期安全評估——緩衝材料（膨潤土 bentonite）受到核廢料罐的熱、地下水滲流、應力、與化學作用的耦合影響，時間尺度長達數十萬年。
