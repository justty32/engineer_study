# 基礎工程（Foundation Engineering）

> 名詞對照見 [中英名詞對照表 → 基礎工程](../中英名詞對照表.md#基礎工程)。

## 0. 本科在本系的定位

基礎工程是土壤力學的直接應用——將結構物的荷載安全地傳遞到土壤或岩石中。如果結構工程關心的是「從梁到柱」的力量傳遞，基礎工程關心的是「從柱到地」的最後一哩路。

本科的核心問題只有兩個：

1. **承載力（bearing capacity）**——土壤會不會因承受不住基礎傳來的壓力而破壞？
2. **沉陷（settlement）**——基礎的下沉量是否在結構物能容忍的範圍內？

任何一個問題不通過，基礎就算失敗。實務上，**沉陷的限制往往比承載力更嚴格**——土壤還沒被壓壞，沉陷量已經大到讓建築傾斜、牆壁龜裂、管線受損。

### 學習地圖

本科圍繞基礎型式展開：先介紹最常見的淺基礎與其設計方法（承載力 + 沉陷）→ 當淺基礎不夠用時，引入深基礎（樁基礎）→ 討論基礎施工中必須同時處理的擋土問題 → 若原地土壤條件太差，介紹地盤改良技術 → 最後是施工中的監測——這是設計假設與現場實際之間的驗證手段。

## 1. 淺基礎（Shallow Foundation）

淺基礎定義為 $D_f / B \leq 1$（埋入深度 / 基礎寬度 ≤ 1）。常見型式：

- **獨立基腳（spread / isolated footing）**：支撐單根柱子，最常見的基礎型式。
- **聯合基腳（combined footing）**：兩根柱子共用一個基腳——當柱子太靠近或緊鄰地界線時使用。
- **連續基腳（strip footing / wall footing）**：支撐承重牆。
- **筏式基礎（raft / mat foundation）**：整棟建築底下的連續厚板。當獨立基腳面積超過建築面積約 50% 時，筏基更經濟，且能抵抗不均勻沉陷與上浮力。

### 1.1 承載力——Terzaghi 公式

Terzaghi（1943）提出了淺基礎極限承載力的經典公式，假設基礎下方形成三個區域的破壞機制：主動楔（Rankine active zone）+ 輻射剪力區（radial shear zone）+ 被動區（Rankine passive zone）。

**條形基礎的 Terzaghi 承載力公式**：

$$q_{ult} = c' N_c + q N_q + 0.5 \gamma B N_\gamma.$$

三項的物理意義：

| 項次 | 參數 | 物理意義 |
|------|------|----------|
| $c' N_c$ | $c'$ = 土壤有效凝聚力 | 土壤「黏結強度」的貢獻——對黏土為主導項 |
| $q N_q$ | $q = \gamma D_f$ = 基礎底面以上的覆土壓力 | 埋入深度的貢獻——等於把基礎「沉」越深，上面覆土的重量愈壓住滑動面 |
| $0.5 \gamma B N_\gamma$ | $\gamma$ = 基礎底面以下土壤單位重，$B$ = 基礎寬度 | 基礎寬度的貢獻——寬度愈大，滑動面愈長，土壤自重提供的阻抗愈大。對砂土（$c' \approx 0$），這項是主導項 |

三個承載力因子 $N_c$、$N_q$、$N_\gamma$ 都是 $\phi'$（有效內摩擦角）的函數。Terzaghi 給出的表達式（Terzaghi 版本，另有 Meyerhof、Hansen、Vesic 等修正版）：

$$N_q = \frac{e^{\pi\tan\phi'}}{2\cos^2(45° + \phi'/2)}$$

$$N_c = (N_q - 1)\cot\phi'$$

$$N_\gamma = \frac{2(N_q + 1)\tan\phi'}{1 + 0.4\sin 4\phi'} \quad\text{(Terzaghi 建議值)}$$

數值感受：$\phi' = 30$° 時，$N_c \approx 37$，$N_q \approx 22$，$N_\gamma \approx 20$；$\phi' = 40$° 時，$N_c \approx 95$，$N_q \approx 81$，$N_\gamma \approx 100$——可見摩擦角對承載力的影響極大（指數級）。

### 1.2 承載力修正因子

實際基礎通常不是無限長的條形，也不一定垂直加載。因此導入修正因子：

$$q_{ult} = c' N_c s_c d_c i_c + q N_q s_q d_q i_q + 0.5 \gamma B N_\gamma s_\gamma d_\gamma i_\gamma.$$

- **形狀因子（shape factors, $s$）**：方形或圓形基礎的承載力小於同等寬度的條形基礎。Meyerhof 建議 $s_c = 1 + 0.2(B/L)\tan^2(45° + \phi'/2)$，$s_\gamma = 1 - 0.4(B/L)$。
- **深度因子（depth factors, $d$）**：基礎埋入愈深，承載力愈高。$d_c = 1 + 0.4(D_f/B)$（當 $D_f/B \leq 1$）。
- **傾斜因子（inclination factors, $i$）**：基礎承受傾斜荷載（水平力 + 垂直力），承載力驟降。$i_c = i_q = (1 - \alpha/90°)^2$（$\alpha$ 為荷載與垂直線夾角）。

### 1.3 偏心荷載——有效寬度法

當荷載不通過基礎中心（偏心距 $e$），Meyerhof 的**有效寬度法（effective width method）**是標準做法：將偏心轉化為等效的中心荷載作用在較小的基礎面積上。

- $B' = B - 2e_B$，$L' = L - 2e_L$——有效面積只考慮受壓區。
- 極限承載力用 $B'$ 計算（代入公式），但 $q_{ult}$ 仍然乘以 $B' \times L'$ 得總極限力。
- 偏心距的限制：$e \leq B/6$——超過此值基礎底面出現張力（土壤不能承受張力），造成基礎部分翹起。

### 1.4 容許承載力

$$q_{all} = \frac{q_{ult}}{FS}.$$

大地工程的承載力安全係數 $FS \geq 3$——遠大於結構工程中鋼與混凝土的安全係數（約 1.5–2.0），原因是：
1. 土壤的空間變異性遠大於鋼或混凝土（同一場址的土層性質可大幅變化）
2. 鑽探只能看到點，兩個鑽孔之間的土層是推測的
3. 土壤的取樣擾動使室內試驗強度參數不準確
4. 承載力破壞是脆性破壞（無預警的突然下陷）

### 1.5 沉陷（Settlement）

沉陷分為三個分量：

**a) 瞬時沉陷（immediate settlement, $S_i$）**：荷載施加瞬間發生的彈性變形——砂土的主導沉陷型式（水瞬間排出）。可用彈性理論估算：

$$S_i = q B \frac{1 - \nu^2}{E_s} I_s.$$

$E_s$ 為土壤彈性模數（從 SPT-N、CPT、或壓力計試驗推估），$\nu$ 為 Poisson 比，$I_s$ 為形狀與勁度影響因子。

**b) 壓密沉陷（consolidation settlement, $S_c$）**：黏土層中的水慢慢排出，體積減小——見土壤力學第 3 節。這是黏土地基的主導沉陷，可持續數十年。

**c) 二次壓縮（secondary compression, $S_s$）**：有效應力穩定後的潛變——對有機質土特別重要。

**砂土沉陷估算——Schmertmann 法**：對砂土，無法取不擾動樣做壓密試驗，所以用 SPT 或 CPT 推估。Schmertmann（1970, 1978）提出基於 CPT 錐尖阻抗的應變影響因子法——對砂土基礎沉陷是最廣泛使用的半經驗方法。

### 1.6 容許沉陷量

沉陷控制往往比承載力更關鍵。典型容許值：

- 獨立基腳的總沉陷 ≤ 25 mm（砂土）或 ≤ 65 mm（黏土）
- 差異沉陷（differential settlement）≤ 角變量（angular distortion）$\approx 1/500$——這是結構物出現裂縫的門檻
- 對沉陷敏感的結構（如磚牆承重結構）差異沉陷限制更嚴格（角變量 ≤ 1/1000–1/2500）

### 1.7 從現地試驗推估承載力

實務上經常不經三軸試驗，直接從 SPT-N 值或 CPT 推估承載力：

- **SPT 經驗法**：Meyerhof 建議 $q_{all} \approx N/8$（kg/cm$^2$，對 $B \approx 1$ m 的砂土基礎，沉陷 ≤ 25 mm）。Terzaghi–Peck 給出不同 N 值與基礎寬度的容許承載壓力的經驗圖表。
- **CPT 直接法**：$q_{ult}$ 與 $q_c$（錐尖阻抗）的關係取決於基礎型式與土壤類型。

## 2. 深基礎（Deep Foundation）

當淺基礎承載力不足或沉陷過大時，使用**樁基礎（pile foundation）**——將荷載越過表層軟弱土，傳遞至深層的堅硬承載層。

### 2.1 樁的種類

**依施工方式**：
- **打入樁（driven pile）**：預鑄混凝土樁、鋼管樁或 H 型鋼樁用樁錘打入地層。打入過程擠壓周圍土壤（對砂土擠密效應有利，對黏土可能擾動），施工噪音和振動大。
- **鑽掘樁（bored pile / drilled shaft）**：先鑽孔再灌注混凝土。大口徑（可達 3 m 以上）、無施工振動，適合都會區。但孔壁穩定性（特別是軟弱土層或高地下水位）是施工關鍵，需用穩定液（皂土 bentonite slurry）或套管（casing）保護孔壁。
- **植入樁（jacked pile）**：用油壓千斤頂靜壓入土中，無噪音無振動，但適用土層受限於可壓入深度。

**依承力機制**：
- **點支承樁（end-bearing pile）**：樁尖座落在堅硬土層或岩盤上，大部分荷載由樁尖傳遞至承載層——需要確保承載層的真實連續性。
- **摩擦樁（friction pile / floating pile）**：樁身與周圍土壤的摩擦力承擔大部分荷載——當堅硬承載層太深時使用。
- **點承 + 摩擦混合**：大多數樁的實際行為介於兩者之間。

### 2.2 單樁軸向承載力

$$Q_u = Q_s + Q_p - W.$$

- $Q_s$：樁身表面摩擦力（shaft resistance / skin friction）
- $Q_p$：樁尖抵抗力（end bearing / point resistance）
- $W$：樁自身重量（通常遠小於 $Q_s + Q_p$，可忽略）

**樁身摩擦力估算——黏土中的總應力 α 法**：

$$f_s = \alpha \cdot s_u.$$

$\alpha$ 為折減係數（$\alpha \leq 1$），取值取決於 $s_u$ 大小、樁的型式（打入/鑽掘）、與施工擾動。對軟弱黏土（$s_u < 25$ kPa）$\alpha \approx 1.0$；對堅硬黏土 $\alpha$ 下降至約 0.4–0.5。

**樁身摩擦力估算——砂土中的有效應力 β 法**：

$$f_s = \beta \cdot \sigma'_v = K \tan\delta \cdot \sigma'_v.$$

- $K$：側向土壓係數（取決於樁的施工方式：打入樁擠土 → $K > K_0$；鑽掘樁鬆弛 → $K < K_0$）
- $\delta$：樁–土間的摩擦角（約 $0.6$–$0.8 \phi'$）
- $\beta = K \tan\delta$——通常在 0.2–1.0 之間

**樁尖抵抗力估算**：

$$Q_p = A_p \cdot q_p.$$

$q_p$ 類比淺基礎的極限承載力：$q_p = c' N_c^* + q N_q^* + 0.5 \gamma B N_\gamma^*$（用深基礎版本的 $N^*$ 因子，數值與淺基礎不同——深部的破壞機制受圍壓限制）。

### 2.3 樁載重試驗（Pile Load Test）

樁的承載力理論估算有不確定性（施工方式對承載力的影響遠大於計算公式間的差異），因此**重要工程的樁承載力必須用載重試驗驗證**。

- **靜載重試驗（static load test）**：在樁頂施加逐級增加的荷載，量測樁頂沉陷量。是最直接最可靠的方法。極限承載力的判讀準則（Davisson 法、Brinch Hansen 90% 法、Chin 法）。
- **Osterberg 細胞試驗（O-cell test）**：在樁身內部放置油壓千斤頂（O-cell），試驗時千斤頂同時往上推與往下推——分別量測樁身摩擦力與樁尖承載力。優點是不需要大型反力系統，且可以分離 $Q_s$ 與 $Q_p$。
- **動力樁載重試驗（PDA, Pile Driving Analyzer）**：在打樁過程中量測樁頂的加速度與應變（使用應變規與加速度計），通過波動方程分析（CAPWAP）推算靜態承載力。雖不如靜載重試驗精確，但快速、便宜，且可以每根樁都做。

### 2.4 群樁（Pile Group）

樁通常以群組使用（至少 2–3 根），透過樁帽（pile cap）將柱子的荷載分配給各樁。

**群樁效率（group efficiency）**：

$$\eta = \frac{Q_{u(g)}}{n \cdot Q_{u(s)}}.$$

- $Q_{u(g)}$：群樁的極限承載力
- $Q_{u(s)}$：單樁的極限承載力
- $n$：樁數

- **砂土中的打入樁**：群樁效率 $\eta > 1$（打入使砂土擠密，樁間土變緊）
- **黏土中的摩擦樁**：群樁效率 $\eta < 1$——各樁的應力區重疊，樁間的應力集中導致總承載力低於各樁相加。樁距小於約 3 倍樁徑時效率開始下降。

**塊狀破壞（block failure）**：當樁距極密時，群樁可能連同包圍的土體一起破壞——將群樁視為一個「巨型深基礎」來檢核區塊承載力。

### 2.5 群樁沉陷

群樁的沉陷大於單樁在相同平均荷載下的沉陷——因為群樁的應力影響深度更深。常用的沉陷估算方法是**等值筏式基礎法（equivalent raft method）**：將群樁等效為一個位於樁尖三分之二深度處的筏式基礎，然後用淺基礎的沉陷方法計算。

### 2.6 負摩擦力（Negative Skin Friction / Downdrag）

當樁周邊的土壤下沉量大於樁本身的下沉時，土壤對樁施加**向下的摩擦力**——這不是提供承載力，而是施加額外荷載！常見原因：

- 樁穿越正在壓密中的軟弱黏土層（填土、抽水引致壓密）
- 地面堆積填土增加上覆壓力
- 地下水位下降使有效應力增加

負摩擦力可能極大——某些案例中負摩擦力佔了樁容許承載力的 30–50%。減輕措施包括：在樁身上塗瀝青降低摩擦、使用套管隔離下沉土層、或預先處理下沉土層（預壓）。

### 2.7 側向承載樁

樁除了承受軸向力，也可能承受水平力（風、地震、船舶撞擊、橋梁制動力）。分析方法：

- **Broms 方法**：簡化極限分析法——區分短樁（剛性旋轉破壞）與長樁（塑性鉸破壞）。
- **$p$–$y$ 曲線法**：沿樁身以非線性彈簧（$p$–$y$ 曲線）代表土壤的水平阻抗——$p$ 為單位樁長土壤阻抗力，$y$ 為樁的側向位移。這是現代的標準方法，可處理分層土壤與非線性行為，需要計算機求解。

## 3. 擋土結構（Earth Retaining Structures）

### 3.1 擋土牆型式

- **重力式擋土牆（gravity wall）**：靠自身重量抵抗土壓——素混凝土、砌石或籠裝石（gabion）。適用於低至中等高度（< 5–8 m）。
- **懸臂式擋土牆（cantilever wall）**：鋼筋混凝土倒 T 形——牆身 + 底板（heel + toe），靠底板上的土重提供穩定性。經濟高度約 3–8 m。
- **扶壁式擋土牆（counterfort wall）**：在懸臂牆背面每隔一段距離加設垂直肋條（扶壁 counterfort），用於 > 8 m 的高擋土牆。
- **錨定式擋土牆（anchored wall）**：用鋼腱（tendon）鑽入岩層或穩定土層灌漿錨定，拉住牆面。適用於狹小空間（無法做寬底板的重力牆）。

### 3.2 擋土結構的穩定檢查

每種擋土牆都必須通過以下檢查（安全係數）：

1. **滑動（sliding）**：$FS = \dfrac{\text{基底摩擦力 + 被動土壓}}{\text{水平主動土壓}} \geq 1.5$
2. **傾覆（overturning）**：$FS = \dfrac{\text{抵抗力矩}}{\text{傾覆力矩}} \geq 2.0$（對重力牆）或 $\geq 1.5$（對懸臂牆，因為鋼筋混凝土有韌性）
3. **承載力（bearing capacity）**：底板下的最大接地壓力 ≤ 容許承載力
4. **整體穩定（global stability）**：包含擋土牆在內的整體邊坡不得滑動（用切片法分析）

### 3.3 版樁（Sheet Pile Wall）

版樁是打入地下的薄鋼板（U 型或 Z 型斷面相互鎖合），用於臨時開挖（如橋墩基礎施工、碼頭岸壁）的擋土擋水。

- **懸臂版樁（cantilever sheet pile）**：僅靠埋入土壤中的貫入深度（embedment depth）提供穩定性。適用於低開挖高度（< 5 m）。
- **錨定版樁（anchored sheet pile）**：在版樁上方加一道或兩道錨桿（tie rod）拉住牆面。錨定可分為自由端支承法（free earth support）與固定端支承法（fixed earth support）兩種力學模型。
- **版樁設計的關鍵**：貫入深度必須足夠防止底部隆起（heave）與滲流管湧。

### 3.4 支撐開挖（Braced Excavation）

都會區的深開挖（地下室、捷運站體）使用不同於版樁的支撐系統——開挖時逐步架設水平支撐（鋼支撐或 RC 支撐）對頂兩側壁體。

**視土壓力分布（apparent earth pressure diagram）**：支撐開挖中的土壓力分布不是三角形的 Rankine 分布——因為支撐施加的位移限制改變了土壓力分布。基於現場實測數據，Terzaghi–Peck 與 Tschebotarioff 提出了經驗性的視土壓力包絡線：

- 砂土：矩形分布 $\sigma_a \approx 0.65 \gamma H K_a$
- 軟弱至中等黏土：梯形分布
- 堅硬黏土：梯形或三角形分布

支撐開挖的穩定問題：
- **底面隆起（bottom heave / basal heave）**：開挖面以下軟弱黏土受到上方卸載而往上隆起——這是軟弱黏土深開挖最危險的破壞模式。
- **壁體側向位移**：壁體往開挖面內側變形 → 壁體後方的土壤沉陷 → 鄰近建築物損害。**台北捷運深開挖的壁體變形控制是亞洲都會區大地工程的經典課題。**

### 3.5 連續壁（Slurry Wall / Diaphragm Wall）

連續壁（在台灣也稱地下連續壁或 slurry wall）是都會區深開挖的標準壁體工法：

1. 用抓斗或銑削機在地下挖出狹長深槽溝（寬 0.6–1.5 m，深可達 50 m 以上）
2. 挖槽過程中以皂土穩定液（bentonite slurry）支撐槽溝壁（穩定液的液壓力平衡土壤壓力）
3. 鋼筋籠吊入槽溝
4. 從底部灌注混凝土，以特密管（tremie）進行水中混凝土澆置——混凝土將較輕的穩定液向上置換

連續壁單元（panel）之間以接頭（joint）連接，連續壁完成後可作為永久地下室外牆的一部分。

**台北捷運的深開挖經驗**：台北盆地為深厚的軟弱黏土層（松山層），地下水位高。捷運站體開挖深度 20–30 m，採用連續壁（壁厚 1.0–1.5 m）+ 多層水平支撐 + 底部地盤改良（深層攪拌或高壓噴射灌漿改良開挖面下的被動區土壤）的組合方案。**逆打工法（top-down construction）**——先施作連續壁與中間柱（king post），然後從地面層往下逐層開挖，每開挖一層即施作該層的樓板作為永久支撐——在上海、台北等高密度都會區廣泛使用，因為它比傳統順打工法（bottom-up）更能控制壁體變形與鄰房沉陷。

## 4. 地盤改良（Ground Improvement）

當原地土壤的工程性質不滿足設計要求時，與其以深基礎「穿越」問題土層，不如**改良土壤本身**。

### 4.1 夯實與振動密實（Compaction）

**適用土類**：砂土、礫石等粗粒土（黏土無法靠夯實有效改良——夯擊只會讓水壓升高而不會密實）。

- **淺層夯實**：震動壓路機（vibratory roller）、羊腳滾（sheepsfoot roller）、橡膠輪壓路機。現場用砂錐法或核子密度儀量測乾密度，控制標準為相對密度 $D_r$ 或壓實度（相對於 Proctor 試驗的最大乾密度）。
- **深層動力夯實（dynamic compaction）**：數十噸的重錘從 10–40 m 高度自由落下。衝擊波形向地下傳播，砂土液化後重新排列為更緊密的結構。處理深度可達 10–15 m，在沿海造地的砂土回填區非常有效。
- **振動夯實（vibro-compaction / vibro-flotation）**：振動探桿插入砂土層，水平振動使砂土顆粒重新排列密實。處理深度 5–30 m。

### 4.2 石柱（Stone Column）

在軟弱黏土或鬆砂中以振動方式置入壓密的碎石柱——石柱直徑 0.6–1.2 m，間距 1.5–3 m。

石柱的雙重作用：
1. **排水功能**：碎石的高滲透性提供排水路徑，加速周圍黏土的壓密速率（從數十年縮減至數月到數年）
2. **補強功能**：石柱分擔荷載（類似樁），同時對周圍土壤施加側向約束，提高整體承載力與抗液化能力

石柱特別適合用來處理液化潛勢土層——地震時碎石柱排水加速，抑制孔隙水壓力累積。

### 4.3 預壓與垂直排水（Preloading & Vertical Drains）

**原理**：在黏土地表施加預壓填土（surcharge），讓黏土層在結構物興建**之前**先完成大部分壓密沉陷。為了加速壓密過程，設置垂直排水通路：

- **砂排水井（sand drain）**：鑽孔填充砂形成垂直排水柱——縮短水的排水路徑（從垂直排至砂層的單向排水變成輻射狀排水至砂井）
- **預製垂直排水帶（PVD, Prefabricated Vertical Drain / wick drain）**：工廠預製的塑膠芯外包不織布濾層，用芯板插入機壓入軟弱黏土層。PVD 在 1980 年代後幾乎完全取代了傳統砂井——施工快、便宜、品質穩定
- **真空預壓（vacuum preloading）**：在密封的砂層中抽真空（大氣壓力約 80 kPa 的等效超載），配合 PVD 加速排水——無需堆填土，適用於鄰近既有結構物無法堆載的場址

**Barron 輻射狀壓密理論**：含砂井/排水帶的黏土層壓密控制方程（輻射狀排水）與 Terzaghi 一維理論類似，但時間因子用 $c_h$（水平向壓密係數，通常大於垂直向的 $c_v$）。

### 4.4 深層攪拌（Deep Soil Mixing, DSM）

在軟弱黏土中以旋轉攪拌葉片將水泥漿或石灰與原位土壤混合，形成**土壤–水泥柱（soil-cement column）**。攪拌方式分溼式（wet method——注入水泥漿）與乾式（dry method——噴入石灰或水泥乾粉）。

DSM 的應用：
- 形成格柵狀改良體（block improvement）——作為深開挖底部的被動區改良以防止底面隆起
- 連續壁式改良（形成不透水牆——cutoff wall）
- 群柱式改良——類似石柱但強度更高

**高壓噴射灌漿（jet grouting）**：用極高壓力（20–50 MPa）的水泥漿噴射切削土壤並即時混合，形成直徑 0.5–2.5 m 的改良柱體。可以在極有限的施工空間中進行——適合既有建築物下方的基礎補強與開挖底部改良。

### 4.5 灌漿（Grouting）

將液態或懸浮態的膠結材料注入地層中的孔隙或裂隙：

- **滲透灌漿（permeation grouting）**：低壓注入化學漿液（矽酸鈉、聚氨酯等）填充砂土孔隙——不改變土壤結構，只是填充孔隙。適用於中至粗砂，無法穿透粉土和黏土（漿液粒徑大於孔隙）。
- **壓縮灌漿（compaction grouting）**：高黏度坍度極低的砂漿注入土壤，形成球狀膨脹體擠壓周圍土壤——用於抬升已下沉的結構物（jacking / lifting）。
- **劈裂灌漿（fracture grouting / hydrofracture）**：高壓使漿液沿著劈裂面進入地層——適用範圍廣但難以精準控制。
- **帷幕灌漿（curtain grouting）**：在水壩壩基鑽孔灌漿形成垂直阻水幕——見工程地質第 3.2 節。

### 4.6 加勁土壤（Reinforced Earth / MSE Wall）

將金屬條帶、塑膠格網（geogrid）或地工織物（geotextile）分層埋入填土中，利用**土壤–加勁材之間的摩擦力**使加勁材承受張力、土壤承受壓力——復合材料的概念。加勁擋土牆（MSE wall, Mechanically Stabilized Earth wall）的面板可以預鑄混凝土面板或鋼面板。

MSE 牆的優點：造價低（相比鋼筋混凝土懸臂牆）、施工快、對基礎沉陷的容許度高（撓性結構）、震後性能優於剛性擋土牆。近年已成為道路與橋梁引道擋土結構的主流工法。

## 5. 基礎施工與監測

### 5.1 施工考量

基礎施工中常見的工程問題：

- **開挖降水（dewatering）**：降低開挖面以下的地下水位——若降水範圍過大，周圍地層的有效應力增加導致地面沉陷（鄰房損害）。都會區深開挖時往往選擇止水性連續壁 + 坑內降水，而非大範圍降水。
- **湧砂與隆起**：開挖面底下的向上滲流（見土壤力學 2.4 節）與卸載隆起（見 3.4 節）。
- **近鄰施工的互相影響**：一處深開挖對隔壁老舊建築基礎的影響——事前的地盤改良與施工中的監測不可或缺。

### 5.2 大地工程監測儀器

監測是設計假設與施工結果之間的驗證手段。Ralph Peck 倡導的**觀察法（observational method）**——「根據施工中量測到的實際行為，隨時調整設計與施工方案」——是大地工程的核心哲學。

常用監測儀器：

- **傾斜儀（inclinometer）**：在鑽孔內安裝帶有導槽的套管，用傾斜儀探頭量測套管沿深度的傾斜變化。**監測擋土壁體的側向位移**與邊坡的深層滑動面位置——是都會區深開挖最重要的監測項目。
- **沉陷觀測點（settlement marker / settlement plate）**：在基礎或地表設置基準釘或沉降板，以水準儀定期量測高程變化。
- **分層沉陷計（extensometer / settlement probe）**：在鑽孔中不同深度安裝錨定，量測各深度土層的壓縮量——用於判斷哪一層土正在壓密。
- **水壓計（piezometer）**：量測地層中的孔隙水壓力。型式包括：
  - **開放式水壓計（standpipe piezometer）**：簡單，但反應極慢（水量進出需時間）
  - **氣壓式水壓計（pneumatic piezometer）**：反應較快
  - **振弦式水壓計（vibrating wire piezometer）**：反應極快、長期穩定性好，是現代監測的標準選擇
- **荷重計（load cell）**：量測支撐軸力或地錨拉力——確保支撐不會超載。
- **土壓計（earth pressure cell）**：埋設在壁體背面或基礎底面，量測土壓力與接觸壓力。
- **裂縫計（crack meter）**：監測鄰近建築物的裂縫寬度變化——判斷損害是否持續惡化。

### 5.3 監測管理值

每個監測項目預先設定：
- **警戒值**：達到此值時增加監測頻率，檢討原因
- **行動值**：達到此值時停止施工，採取補救措施

管理值根據設計計算、數值分析、以及鄰近結構物的容許變形量來訂定。**「設計 → 預測 → 監測 → 比對 → 修正」的循環**是大地工程的安全保證機制。

## 6. 碩士/博士層級延伸

### 碩士層級

- **深開挖工程（Deep Excavation Engineering）**：軟弱黏土深開挖的壁體變形與地盤沉陷分析（有限元素法 PLAXIS / FLAC 的實務應用），支撐系統的預力與剛性設計，逆打工法的結構–大地耦合分析。
- **群樁基礎的進階分析**：群樁的交互作用係數（interaction factor）與沉陷比（settlement ratio），大規模群樁的等值連續體模型，承受地震側向力的群樁反應（p–y 彈簧動態分析）。
- **離岸基礎工程（Offshore Foundation）**：風機單樁（monopile）的 p–y 曲線（軟弱海床黏土的循環衰減效應）、重力式基礎（gravity base）、吸力式沉箱基礎（suction caisson）在台灣離岸風場的應用。
- **地工織物與加勁土壤**：加勁材的拉拔阻抗（pullout resistance）、長期潛變強度、加勁邊坡與加勁擋土牆的內部與外部穩定設計。

### 博士層級

- **循環荷載下土壤–結構互制**：離岸風機基礎承受數十萬次風浪循環荷載，引致土壤的剛性衰減（stiffness degradation）與累積變形——長期循環行為的本構模型與設計方法仍在發展中。
- **地震引致的大變形**：液化後側向擴張的無網格模擬（Material Point Method, MPM；Smooth Particle Hydrodynamics, SPH），以及液化引致樁基礎破壞的耦合分析。
- **可靠度大地工程（Reliability-Based Geotechnical Design）**：將土壤參數的空間變異性（spatial variability）納入設計——隨機場（random field）理論 + 有限元素蒙地卡羅模擬。LRFD（Load and Resistance Factor Design）在大地工程的應用在北美已進入規範（AASHTO），但土壤參數的統計特性（變異係數、相關長度）仍是活躍的研究課題。
- **能源大地工程（Energy Geotechnics）**：地源熱泵的熱–水–力耦合行為、核廢料地質處置的緩衝材料（膨潤土）長期行為、天然氣水合物（可燃冰）地層的開採誘發地層不穩定。
