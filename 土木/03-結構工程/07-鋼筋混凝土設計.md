# 鋼筋混凝土設計（Reinforced Concrete Design）

> 名詞對照見 [中英名詞對照表 → 鋼筋混凝土設計](../中英名詞對照表-1.md#鋼筋混凝土設計)。

## 0. 本科在本系的定位

- **它是什麼**：鋼筋混凝土設計是把結構分析算出的彎矩、剪力、軸力，轉換成「混凝土斷面要多寬多高、裡面要放幾根多粗的鋼筋、鋼筋放在哪個位置」，讓構件既安全又能施工。
- **往上游銜接什麼**：結構學（彎矩圖、剪力圖）、工程材料（混凝土的抗壓強度 $f_c'$、鋼筋的降伏強度 $f_y$）。
- **往下游銜接什麼**：橋梁設計、高層建築結構系統、耐震細節設計。
- **核心心法**：混凝土抗壓、鋼筋抗拉——RC 設計的本質就是**在拉力區放足夠的鋼筋來補償混凝土的弱項**。

### 對擁有者的提醒

鋼筋混凝土設計的公式看起來很多，但邏輯非常一致——每個斷面的計算都是同一套流程：(1) 假設斷面應變分布（平面保持平面）；(2) 從應變用材料律求應力；(3) 積分應力求合力；(4) 合力平衡 → 解出未知數。學習時重點放在理解這個邏輯鏈，而不是死記每個係數。

## 1. RC 設計的基本概念

### 1.1 為什麼需要鋼筋

混凝土抗壓強度優秀（$f_c'$ = 20–50 MPa），但抗拉強度只有約 1/10。一根素混凝土梁一彎就從底部裂開、瞬間斷掉。把鋼筋埋在拉力區（梁的底部、柱的外側），混凝土負責抗壓、鋼筋負責抗拉——各司其職。

### 1.2 強度設計法（Strength Design Method, SDM）

目前全球主流設計方法（ACI 318 規範），源自極限狀態設計哲學：

$$\phi R_n \ge U.$$

- $U$：含安全係數的**設計載重**（例如 $U = 1.2D + 1.6L$，$D$＝自重、$L$＝活載）
- $R_n$：**名目強度**（斷面理論可承受的最大內力）
- $\phi$：**強度折減係數**（< 1，考慮材料變異與施工誤差）

### 1.3 基本假設

RC 斷面分析的基石：
1. **平面保持平面**（Bernoulli 假設——斷面受力前為平面、受力變形後仍為平面）
2. **混凝土與鋼筋之間無滑動**（完全握裹，應變一致：$\varepsilon_s = \varepsilon_c$ 在同一位置）
3. **混凝土不承受拉力**（開裂後拉應力全由鋼筋承擔）
4. 混凝土的極限壓應變 $\varepsilon_{cu} = 0.003$（ACI，混凝土被壓碎的極限）

## 2. 梁的彎曲設計

### 2.1 矩形斷面之彎矩強度

單筋梁（只在拉力側配鋼筋）的彎矩強度計算步驟：

1. 從應變相容找中性軸深度 $c$：
   $$\frac{c}{d} = \frac{0.003}{0.003 + \varepsilon_s}.$$

2. 用等值矩形應力塊（Whitney stress block）取代真實的拋物線應力分布：等值應力 $0.85f_c'$，深度 $a = \beta_1 c$（$\beta_1 \approx 0.85$ 對 $f_c' \le 28$ MPa）

3. 水平合力平衡（$C = T$）：
   $$0.85 f_c'\, a\, b = A_s f_y \quad\Rightarrow\quad a = \frac{A_s f_y}{0.85 f_c' b}.$$

4. 彎矩強度（對拉力鋼筋取矩）：
   $$M_n = A_s f_y\left(d - \frac{a}{2}\right).$$

### 2.2 鋼筋比

$$\rho = \frac{A_s}{b d}.$$

- **平衡鋼筋比 $\rho_b$**：鋼筋降伏與混凝土壓碎同時發生時的 $\rho$。$\rho > \rho_b$ → 超筋 → 混凝土突然壓碎，沒有預警（脆性破壞，規範禁止）
- **最小鋼筋比 $\rho_{\min}$**：確保斷面不會因為配筋太少，混凝土一開裂就突然失效
- **實務設計**：$\rho$ 取在 $\rho_{\min}$ 與約 $0.5\rho_b$ 之間，確保鋼筋先降伏（韌性破壞，有明顯變形預警）

### 2.3 雙筋梁

當斷面因建築限制（梁高不可增加），單筋不足以提供所需彎矩強度時，在壓力側也加鋼筋。壓力鋼筋除了分擔壓力，還可以提高韌性並減少長期潛變撓度。

## 3. 梁的剪力設計

### 3.1 剪力破壞的模式

RC 梁的剪力破壞是**斜張裂縫**——從支承附近往加載點斜向發展（約 45°）。它不像彎曲破壞那樣有明顯預警（鋼筋先降伏、變形變大），而是相對脆性。因此規範對剪力設計特別謹慎。

### 3.2 剪力鋼筋（剪力筋 / 箍筋）

混凝土提供的剪力強度 $V_c$ 有限，不足的部分由**剪力鋼筋（箍筋 stirrups）**補足：

$$V_n = V_c + V_s.$$

箍筋垂直穿越潛在的斜張裂縫，像縫線一樣把裂縫兩側拉住。箍筋的間距 $s$ 愈密，$V_s$ 愈大。樑端（剪力最大處）箍筋最密。

## 4. 柱的設計

### 4.1 柱的行為

柱同時承受軸壓力 $P$ 與彎矩 $M$（因為梁傳來的彎矩，以及柱本身因施工誤差或側向力產生的偏心）。交互作用圖（$P$–$M$ 圖）是柱設計的核心工具——每一種斷面配筋量對應一條 $P$–$M$ 曲線，設計荷載組合必須落在曲線內。

### 4.2 柱的韌性需求

柱是建築抵抗地震側向力的最後防線，**柱必須比梁更強**（強柱弱梁設計）——讓地震破壞先發生在梁端（以裂縫與降伏消耗能量），而不是柱端（柱斷了整棟樓就垮）。這是耐震設計最重要的一條原則。

---

## 5. 握裹與錨定（Bond & Anchorage）

### 5.1 握裹應力

鋼筋要能發揮強度，必須與周圍混凝土緊緊握裹——鋼筋表面的**竹節（deformation / ribs）**就是為了提供機械咬合。握裹應力沿鋼筋的分布不均勻，在裂縫附近最大。

### 5.2 伸展長度（Development Length）

鋼筋必須埋入混凝土足夠的長度，才能透過握裹應力把鋼筋的拉力「傳遞」給混凝土而不被拔出：

$$L_d = \frac{f_y d_b}{\text{係數}}.$$

鋼筋直徑 $d_b$ 愈粗、強度 $f_y$ 愈高，需要的伸展長度愈長。梁的鋼筋伸入柱子必須滿足伸展長度要求，否則地震一來鋼筋就被拔出——這是耐震細節中常常出錯的環節。

## 6. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 預力混凝土（Prestressed Concrete） | 在荷載作用前先用高強鋼腱對混凝土施加壓應力，讓拉力區在使用階段不開裂。是橋梁大跨度梁、無樑版、核能圍阻體的標準工法。 |
| 韌性耐震細節設計 | 塑鉸區的箍筋加密、梁柱接頭的剪力補強、避免搭接落在塑鉸區。人命安全的關鍵就在這些「細節」——多數地震倒塌的主因不是算錯，而是細節沒做好。 |
| 纖維強化複材（FRP）補強 | 用碳纖維或玻璃纖維布以環氧樹脂黏貼在結構表面補強剪力或彎曲。既不加重量、不縮小空間、又耐腐蝕。 |

---

## 7. 博士層級研究方向

- 高強度鋼筋（SD 690, $f_y$ = 690 MPa）在耐震設計中的適用性與韌性限制
- 鋼筋混凝土的離散裂縫模型（discrete crack model）與連續損傷力學
- 機器學習預測既有 RC 建築的耐震能力（不需逐棟做精細 FEM）
