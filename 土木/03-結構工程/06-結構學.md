# 結構學（Structural Analysis）

> 名詞對照見 [中英名詞對照表 → 結構學](../中英名詞對照表.md#結構學)。

## 0. 本科在本系的定位

- **它是什麼**：結構學是把材料力學從「單一構件」擴展到「整座結構」——算出桁架、梁、剛架在各種載重下每一點的內力與變形。它是靜力學與材料力學之後的第三關，也是所有結構設計課的共同前處理器。
- **往上游銜接什麼**：靜力學（平衡方程、自由體圖）、材料力學（應力應變、Hooke 定律、梁的撓度公式）。
- **往下游銜接什麼**：**鋼筋混凝土設計**與**鋼結構設計**直接使用本科技巧算出的彎矩圖與剪力圖來設計斷面。
- **核心心法**：結構分析的本質是**求解聯立方程**——未知數是位移或內力，方程來自力平衡、變形協調、以及材料本構關係。所有分析方法（傾角變位法、彎矩分配法、矩陣勁度法）只是用不同策略組織這些方程。

### 對擁有者的提醒

如果把結構學的矩陣勁度法攤開來看——$[K]\{\mathbf{d}\} = \{\mathbf{F}\}$，勁度矩陣 $K$、位移向量 $\mathbf{d}$、外力向量 $\mathbf{F}$——你會發現這就是一個線性方程組。結構分析軟體（SAP2000、ETABS）的核心就是這個方程的不同規模版本。你在數值線性代數中學過的所有稀疏矩陣求解技巧在這裡都適用。

## 1. 靜定結構分析

### 1.1 靜定 vs 靜不定

- **靜定（determinate）**：只用平衡方程就能解出所有未知反力與內力。靜定結構不會因溫度變化或支承沉陷而產生額外內力（因為它可以自由變形）。
- **靜不定（indeterminate）**：反力數 > 平衡方程數。需要加入變形條件才能求解。靜不定結構通常更安全（因為有多重傳力路徑——一根桿件失效不會整座垮），但也對溫度變化與支承沉陷敏感。

### 1.2 影響線（Influence Lines）

影響線回答「當一個單位移動載重在結構上移動時，**某一特定點**的內力（或反力）如何變化」。例如橋梁的主梁——設計時需要知道卡車開到哪個位置會讓跨中彎矩最大。影響線就是這個問題的解答：畫一條線，$x$ 軸是載重位置，$y$ 軸是該特定點的內力值。

對靜定梁與桁架，影響線由直線段組成（這來自力的線性關係）。這個性質使得計算格外簡潔——只需算幾個關鍵點，中間連直線。

## 2. 變形能法（Energy Methods）

### 2.1 應變能（Strain Energy）

當結構受力變形時，外力對結構做功，這個功以**應變能**的形式儲存在結構中。對線彈性結構：

$$U = \int \frac{M^2}{2EI}\,dx + \int \frac{N^2}{2EA}\,dx + \int \frac{V^2}{2GA}\,dx.$$

大多數梁與剛架彎曲能主宰，軸向與剪力項可忽略。

### 2.2 單位力法（Unit Load Method / Virtual Work）

這是求結構某特定點撓度的最通用方法。原理：對結構施以一個虛擬的單位力（方向與欲求的撓度一致），寫出它對應的虛內力分布，對結構全長積分：

$$\Delta = \int \frac{M \cdot m}{EI}\,dx.$$

其中 $M$ 為真實載重下的彎矩分布，$m$ 為單位力產生的彎矩分布。**這是手算撓度的必備技能。**

### 2.3 Castigliano 定理

對線彈性結構，撓度等於應變能對力的偏導數：

$$\Delta_i = \frac{\partial U}{\partial P_i}.$$

特別適合求桁架節點位移（此時 $U = \sum_i N_i^2 L_i / (2E_i A_i)$，取微分變成簡單的代數和）。

## 3. 靜不定結構的古典解法

### 3.1 力法（Force Method / Flexibility Method）

選擇多餘的未知反力（稱為**贅力 redundants**），將原結構拆成「靜定基本結構 + 贅力作用」。利用「贅力處的變形必須與原結構一致」這個協調條件建立方程。

力法的優點是直覺清晰，缺點是對多次靜不定結構（高樓剛架）手算不實際——這是矩陣勁度法的使用場合。

### 3.2 傾角變位法（Slope-Deflection Method）

把所有節點的轉角與位移當作未知數，利用「桿端的彎矩可以用兩端位移表達」這個關係，在每個節點寫下彎矩平衡方程。方程數 = 未知節點位移數。這是最直觀的位移法入門。

### 3.3 彎矩分配法（Moment Distribution Method）

Hardy Cross（1930）在電腦發明前發展出來的反覆迭代法——先假設所有節點被鎖住，算出「固端彎矩」，然後逐個釋放節點、把不平衡彎矩按桿件勁度分配給相鄰桿件，並部分傳遞到遠端，重複直到不平衡量可忽略。

這個演算法的精妙之處在於：不需要解聯立方程，只需要反覆做簡單的乘除運算。在矩陣勁度法（電腦）普及之前，這是分析高層剛架的唯一實用方法。

## 4. 矩陣勁度法（Matrix Stiffness Method）

### 4.1 基本思想

矩陣勁度法 = 現今所有結構分析軟體的數學基礎。步驟：

1. **離散化**：把結構拆成有限個構件（桿元素、梁元素）
2. **建立元素勁度矩陣**：描述單一構件上節點力與節點位移的關係 $[k]$
3. **組裝**：把所有元素的 $[k]$ 按自由度編號「塞」進總體勁度矩陣 $[K]$
4. **加上邊界條件**（支承約束）與節點外載重 $[F]$
5. **求解** $[K]\{d\} = \{F\}$ 得位移，反推構件內力

### 4.2 為什麼矩陣法適合電腦

$[K]$ 是**對稱、稀疏、帶狀**矩陣（每個自由度只與少數幾個鄰近自由度耦合），這些性質讓大規模線性方程組的求解在計算上極其高效。一座幾十層樓的建築可能有數萬個自由度，但在現代電腦上解一次只要幾秒。

## 5. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 有限元素法（FEM） | 矩陣勁度法的延伸——將連續體（如混凝土壩體、土壤）切成大量微小元素，每個元素的位移場用形狀函數內插，是現代結構分析與設計的標準工具。 |
| 非線性結構分析 | 材料非線性（混凝土開裂、鋼筋降伏）、幾何非線性（大變形、P–Δ 效應）、邊界非線性（接觸、碰撞）。耐震性能評估必須考慮這些非線性。 |
| 逐步非線性歷時分析（NLTHA） | 對結構直接輸入地震加速度歷時（而非只用反應譜），一步步做時間域積分追蹤結構的動態非線性行為。 |

---

## 6. 博士層級研究方向

- 等幾何分析（isogeometric analysis）——CAD 模型直接進入分析，省去網格生成的繁瑣
- 隨機有限元素法（stochastic FEM）——考慮材料性質、幾何尺寸、載重的不確定性
- 結構健康監測中基於振動特徵的損傷識別演算法（damage identification from modal properties）
