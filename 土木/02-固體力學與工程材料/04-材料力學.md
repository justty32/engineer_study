# 材料力學（Mechanics of Materials / Strength of Materials）

> 名詞對照見 [中英名詞對照表 → 材料力學](../中英名詞對照表.md#材料力學)。

## 0. 本科在本系的定位

- **它是什麼**：材料力學是靜力學的下一關——靜力學算出構件承受多少內力（軸力 $N$、剪力 $V$、彎矩 $M$、扭矩 $T$），材料力學回答「這些內力在斷面上產生多大的應力、構件會變形多少、會不會壞」。
- **往上游銜接什麼**：靜力學（內力計算、形心與慣性矩）。
- **往下游銜接什麼**：**結構學**（從單一構件的變形推向整個結構的變形）、**鋼筋混凝土設計**（彎矩 → 梁斷面鋼筋量）、**鋼結構設計**（挫屈計算）。
- **核心心法**：材料力學的核心是**斷面分析**——沿構件切一刀，看斷面上應力如何分布。應力不是均勻的——彎曲時外側纖維應力最大、中性軸為零；扭轉時表面應力最大、軸心為零。

### 對擁有者的提醒

材料力學用到的數學非常簡單（一維積分為主），但**物理直覺**需要時間建立。關鍵是理解「應力」與「應變」這兩個概念：應力是單位面積上的內力（$\sigma = P/A$），應變是單位長度的變形（$\varepsilon = \Delta L/L$）。它們的關係 $\sigma = E\varepsilon$（Hooke 定律）就是彈性力學最基本的本構方程——類比電路中的 $V = IR$（Ohm 定律）。

## 1. 應力與應變

### 1.1 正向應力與正向應變

$$\sigma = \frac{P}{A}\ \mathrm{(Pa)},\quad \varepsilon = \frac{\Delta L}{L}\ \text{(無因次)}.$$

Hooke 定律（彈性範圍內）：$\sigma = E\varepsilon$，$E$ 為**楊氏模數（Young's modulus）**。鋼 $E \approx 200\ \mathrm{GPa}$，混凝土 $E \approx 25-35\ \mathrm{GPa}$，鋁 $E \approx 70\ \mathrm{GPa}$。

### 1.2 剪力應力與剪力應變

$$\tau = \frac{V}{A},\quad \gamma = \frac{\delta_s}{L},\quad \tau = G\gamma.$$

$G$ 為**剪力模數（shear modulus）**，與 $E$ 的關係：$G = E/[2(1+\nu)]$，$\nu$ 為 Poisson 比（金屬約 0.3、混凝土約 0.2）。

### 1.3 應力–應變曲線

典型的韌性材料（低碳鋼）拉伸曲線：
- **彈性區**：直線，卸載恢復原狀
- **降伏點（yield point）**：開始永久變形
- **應變硬化（strain hardening）**：強度繼續上升直到極限強度
- **頸縮（necking）**：斷面積局部縮小，最終斷裂

**降伏應力 $\sigma_y$** 是設計的關鍵參數——正常工作下應力必須遠小於它。

## 2. 軸向負載

### 2.1 均勻軸向變形

$$\delta = \frac{PL}{AE}.$$

長度 $L$、面積 $A$、模數 $E$ 的桿件在軸力 $P$ 下的伸長/縮短量。這是最基本的變形公式。

### 2.2 溫度變形

$$\delta_T = \alpha L \Delta T.$$

$\alpha$ 為熱膨脹係數。若溫度變形被約束（例如兩端固定的梁），會產生巨大的**溫度應力**——這就是為什麼橋梁需要伸縮縫、長管線需要膨脹彎管。

### 2.3 靜不定軸向問題

當未知反力數多於平衡方程數時，需引入變形協調（compatibility）條件。例如兩端固定桿受軸向力——兩端反力的和已知（平衡），但各自多少取決於兩端的彈性變形必須一致（協調）。

## 3. 扭轉（Torsion）

### 3.1 圓桿扭轉公式

$$\tau_{\max} = \frac{T r}{J},\quad \phi = \frac{T L}{J G}.$$

- $T$：扭矩
- $J$：極慣性矩（實心圓 $J = \pi r^4/2$，空心圓 $J = \pi(r_o^4 - r_i^4)/2$）
- $\phi$：扭轉角
- 剪應力從軸心為零線性增加到表面最大

### 3.2 非圓斷面扭轉

矩形、薄壁開口斷面的扭轉行為與圓斷面差異極大——**最大應力發生在長邊中點而非角落**。薄壁開口斷面（如工字鋼）的扭轉勁度很差，是設計中必須注意的弱點。

---

## 4. 彎曲（Bending）

### 4.1 撓曲公式（Flexure Formula）

梁受純彎曲時的正向應力分布：

$$\sigma = -\frac{M y}{I}.$$

- $M$：彎矩
- $I$：斷面對中性軸的慣性矩
- $y$：從中性軸往上（或往下）的距離

最大應力發生在離中性軸最遠的纖維（$y = c$）：$\sigma_{\max} = M c / I = M / S$，其中 $S = I/c$ 為**斷面模數（section modulus）**。

### 4.2 剪力應力

梁受彎曲的同時通常也受剪力。矩形斷面的剪力分布呈拋物線：$\tau = VQ/(Ib)$，其中 $Q = \int y\,dA$ 為斷面的一次矩。最大剪力應力在中性軸處，表面為零。對於細長梁（長度/高度 > 10），剪力效應相對於彎曲通常可忽略。

### 4.3 梁的撓度（Deflection）

計算撓度的主要方法：
- **二重積分法**：$EI\,d^2v/dx^2 = M(x)$，積分兩次得撓度 $v(x)$
- **彎矩面積法（moment-area method）**：用彎矩圖下面積與形心位置求特定點的撓度與轉角，適合快速手算
- **疊加法（superposition）**：梁的問題是線性的，多種載重的總撓度等於各自撓度的加總

## 5. 組合應力與莫爾圓（Mohr's Circle）

### 5.1 平面應力狀態

一個點上可能同時承受 $\sigma_x, \sigma_y, \tau_{xy}$。在不同方向上，這些應力的分量隨角度變化——就像向量在不同座標系下的分量不同，只是轉換公式更複雜。

### 5.2 莫爾圓

莫爾圓是分析平面應力狀態的圖解法：以 $(\sigma, \tau)$ 為座標，畫一個圓，圓與 $\sigma$ 軸的交點給出**主應力（principal stresses）** $\sigma_1, \sigma_2$（這兩點上剪應力為零），圓的最高點給出**最大剪應力** $\tau_{\max} = (\sigma_1 - \sigma_2)/2$。

對土木而言最關鍵的判據是——材料破壞通常是因為主應力或最大剪應力超過了材料的承受極限。

## 6. 柱的挫屈（Buckling）

### 6.1 Euler 挫屈公式

細長柱受壓時，在壓力達到材料降伏強度之前就可能**突然側向彎曲**——這就是挫屈。Euler 臨界載重：

$$P_{\text{cr}} = \frac{\pi^2 E I}{(K L)^2}.$$

- $KL$ 為**有效長度**：$K=1$（兩端鉸接）、$K=0.5$（兩端固定）、$K=2$（懸臂）
- 關鍵觀察：挫屈載重**與材料強度無關**、**與勁度 $EI$ 成正比**、**與長度平方成反比**

也就是說——把柱子做粗（$I$ 變大）抗挫屈，但換更強的鋼（$E$ 不變、$\sigma_y$ 變高）對挫屈幾乎沒幫助。這是挫屈最微妙的地方。

### 6.2 細長比與設計曲線

$$\lambda = \frac{KL}{r},\quad r = \sqrt{\frac{I}{A}}.$$

$\lambda$ 為**細長比（slenderness ratio）**。短柱（$\lambda$ 小）：材料降伏主導。長柱（$\lambda$ 大）：彈性挫屈主導。中間長度需用經驗公式（如 AISC 的柱設計曲線）連接兩端。

## 7. 碩士層級延伸

| 主題 | 簡介 |
|------|------|
| 薄壁桿件理論 | Vlasov 理論處理開口薄壁斷面（如槽鋼、工字鋼）在扭轉時的翹曲（warping）效應，對輕鋼構設計至關重要。 |
| 塑性分析與極限設計 | 考慮斷面完全塑性化時的極限彎矩 $M_p$（塑性彎矩），是鋼結構塑性設計的基礎。 |
| 疲勞與裂縫力學 | 反覆荷載（如橋梁的車輛來回）下微小裂縫逐漸成長至斷裂——Paris 定律描述裂縫成長速率。 |
