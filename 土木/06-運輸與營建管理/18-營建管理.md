# 營建管理（Construction Management）

> 名詞對照見 [中英名詞對照表 → 營建管理](../中英名詞對照表-3.md#營建管理)。

## 0. 本科在本系的定位

營建管理處理工程的經營面——如何在預算內、如期、安全地完成符合品質要求的工程。如果說結構設計回答「怎麼蓋才安全」，營管回答「怎麼蓋才不賠錢、不延誤、不出事」。實務上，營建管理涵蓋從投標階段的成本估算、簽約後的進度排程、施工中的成本與品質控制、到竣工後的結算與爭議處理——是一門必須同時面對技術、財務、法律與人因的整合性學科。

## 1. 專案管理基礎（Project Management Fundamentals）

### 1.1 鐵三角（Iron Triangle）

任何工程專案都必須在三個互相制約的維度上取得平衡：

- **成本（cost）**：不能超支
- **時程（schedule）**：不能延期
- **品質 / 範疇（quality / scope）**：不能偷工減料

三者之間不可能同時最優——壓縮工期需要加人加班（成本上升）、砍預算可能降低品質或縮小範疇。專案經理的責任就是在鐵三角內做出取捨決策，並清楚傳達給業主。

### 1.2 工作分解結構（WBS, Work Breakdown Structure）

**WBS** 是將專案範疇依階層分解成可管理的**工作包（work package）**的架構。範例結構：

```
橋梁工程
├── 下部結構
│   ├── 樁基礎
│   ├── 橋墩
│   └── 橋台
├── 上部結構
│   ├── 大梁
│   ├── 橋面版
│   └── 護欄
└── 附屬工程
    ├── 伸縮縫
    └── 排水設施
```

WBS 的原則是**100% 規則**——每一層的分解必須涵蓋上一層的全部範疇，不遺漏也不重複。工作包是最底層的分解單元，每個工作包應可獨立估算成本、指派負責人、排定工期。

### 1.3 實獲值管理（Earned Value Management, EVM）

**EVM** 是整合進度與成本的追蹤方法，用三個核心指標回答「我們現在在哪裡」：

| 指標 | 英文 | 舊稱 | 含義 |
|------|------|------|------|
| **PV**（計畫值） | Planned Value | BCWS | 到現在「應該完成」多少預算的工作 |
| **EV**（實獲值） | Earned Value | BCWP | 到現在「實際完成」的工作值多少預算 |
| **AC**（實際成本） | Actual Cost | ACWP | 到現在「實際花了」多少錢 |

從這三個指標可以計算出反映專案健康狀態的變異與指數：

**進度績效指數（SPI, Schedule Performance Index）**：
$$SPI = EV / PV$$
SPI > 1：進度超前；SPI < 1：進度落後。

**成本績效指數（CPI, Cost Performance Index）**：
$$CPI = EV / AC$$
CPI > 1：節省；CPI < 1：超支。

**預測完成時總成本（EAC, Estimate at Completion）**：
$$EAC = \frac{BAC}{CPI}$$
其中 BAC 為 Budget at Completion（原核定總預算）。這是在假設未來績效與過往相同的條件下，對最終總成本的合理預測。另一常用公式：$EAC = AC + (BAC - EV)$，適用於認為偏差為一次性事件。

EVM 的價值在於**早期預警**——在專案只完成 20% 時，若 CPI 持續低於 0.9，幾乎不可能在剩餘預算內完工。這給了管理階層在下半場做出調整的空間。

## 2. 排程（Scheduling）

### 2.1 要徑法（CPM, Critical Path Method）

CPM 是營建排程的核心工具。其運作步驟：

1. **定義作業（activity）**：拆解 WBS 工作包為可排程的作業項目
2. **建立邏輯關係**：作業之間的前後依賴（dependency）。常用關係類型：
   - FS（Finish-to-Start）：A 完成後 B 才能開始（最常見）
   - SS（Start-to-Start）：A 開始後 B 才能開始
   - FF（Finish-to-Finish）：A 完成後 B 才能完成
   - SF（Start-to-Finish）：A 開始後 B 才能完成（罕用）
3. **繪製網路圖**：通常採用**節點式（AON, Activity-on-Node）**，以節點代表作業、箭線代表依賴關係
4. **計算時程**：進行前推與後推計算

**前推計算（forward pass）**：
- 最早開始時間 ES = 前置作業中最大的 EF
- 最早完成時間 EF = ES + 工期

**後推計算（backward pass）**：
- 最晚完成時間 LF = 後續作業中最小的 LS
- 最晚開始時間 LS = LF − 工期

**浮時（float / slack）**：
$$Total\ Float = LS - ES = LF - EF$$

總浮時為零的作業構成**要徑（critical path）**——要徑上任一作業延遲一天，整體專案就延遲一天。要徑是專案經理最需要關注的作業鏈。

**自由浮時（free float）**：一個作業在不影響後續作業最早開始的前提下可以延遲的時間。自由浮時 $\leq$ 總浮時。

### 2.2 PERT（Program Evaluation and Review Technique）

CPM 假設每作業工期是確定值；**PERT** 加入機率觀點，每作業用三個時間估計值：

- $t_o$（optimistic, 樂觀）：一切順利的最短工期
- $t_m$（most likely, 最可能）：一般狀況下的工期
- $t_p$（pessimistic, 悲觀）：遇到最糟狀況的最長工期

**期望工期**：$t_e = (t_o + 4t_m + t_p)/6$（加權平均，最可能值權重 4）。

**工期變異數**：$\sigma^2 = ((t_p - t_o)/6)^2$

整條路徑的總期望工期為各作業 $t_e$ 之和，總變異數為各作業 $\sigma^2$ 之和（假設作業工期獨立）。若總期望工期為 $T$、總標準差為 $\sigma_T$，則在目標工期 $T_{target}$ 前完工的機率：

$$Z = \frac{T_{target} - T}{\sigma_T}$$

查標準常態分布表即得機率。PERT 的關鍵見解：**要徑由期望工期決定，但個別作業的變異性可能讓非要徑路徑成為真正的瓶頸**（merge bias 效應）。

## 3. 成本估算與控制（Cost Estimating and Control）

### 3.1 估算類型與精確度

隨著設計深化，估算精確度逐步提高：

| 類型 | 設計完成度 | 精確範圍（AACE） | 用途 |
|------|-----------|-----------------|------|
| 數量級估算（order-of-magnitude） | 0–2% | −30% ~ +50% | 可行性評估 |
| 概念估算（conceptual） | 1–15% | −20% ~ +30% | 預算編列 |
| 初步估算（preliminary） | 10–40% | −15% ~ +20% | 設計方案比較 |
| 細部估算（definitive） | 30–70% | −10% ~ +15% | 發包預算 |
| 詳細估算（detailed） | 50–100% | −5% ~ +10% | 投標/簽約 |

估算的基礎步驟：**工項拆解**（將工程拆成可計價項目清單）→ **數量計算**（從圖面算混凝土體積、鋼筋重量、模板面積）→ **單價分析**（每單位所需的材料費＋人工費＋機具費＋間接費＋利潤）。

### 3.2 預備金（Contingency）

**預備金**是為了應對設計不確定性、施工條件變化與市場波動而預留的彈性金額。一般分為：

- **設計預備金（design contingency）**：應對設計深度不足導致的數量變化。概念設計階段可能編列 20–30%，細部設計階段降至 5–10%
- **施工預備金（construction contingency）**：應對施工中不可預見的狀況（如地下障礙物）。通常為直接工程費的 5–10%
- **物價調整預備金（escalation contingency）**：因應通膨與原物料價格波動。台灣會引用營造工程物價指數

預備金不是「多編的錢」，而是基於過往專案統計資料，對不確定性的合理量化。

### 3.3 成本控制

成本控制的關鍵工具：

- **成本分解結構（CBS, Cost Breakdown Structure）**：與 WBS 對應的財務編碼，讓每一筆支出都有歸屬
- **成本帳戶（cost account）**：WBS 與組織分解結構（OBS）的交集——誰、負責什麼工作、花了多少錢
- **S 曲線（S-curve）**：累積預算支出對時間的曲線，造型為 S 形（前期動員慢、中期高峰、後期收尾緩），將實際支出疊加於 S 曲線上可視覺化成本偏差
- **估算完成（ETC, Estimate to Complete）**配合 EAC 的定期更新，做滾動式預測（rolling forecast）

## 4. 契約與採購（Contracts and Procurement）

### 4.1 契約類型

- **總價合約（lump-sum contract）**：以固定總價完成約定範疇，承包商承擔「做不完也要吞下去」的數量風險。適合設計完整、變更少的工程。
- **單價合約（unit-price contract）**：各工項有議定單價，依實際施作數量計價。業主與承包商共同分攤數量風險——業主付的就是「實際的數量 × 議定的單價」。適合土方工程、隧道等數量難以精確預估的項目。
- **成本加酬金（cost-plus contract）**：業主償付實際成本並外加一筆酬金，承包商幾乎無成本風險。變體包括：
  - 成本加固定酬金（cost + fixed fee）：酬金固定不隨成本波動
  - 成本加百分比酬金（cost + percentage）：酬金隨成本等比增加——**對業主最不利，會誘使承包商抬高成本**
  - 成本加激勵金（cost + incentive fee）：節省成本時承包商可分享節餘，超支時分擔損失
  - 保證最高成本（GMP, Guaranteed Maximum Price）：承包商保證不超過某金額，超過自付——實務上「GMP + 節餘分享」是 CM at Risk 的常見模式

- **統包（Design-Build, DB）**：設計與施工由同一團隊負責，單一窗口對業主負責。省去設計與施工之間的介面爭議，但業主失去設計顧問的獨立監督角色。
- **CM at Risk**：營建經理人在設計階段提供可施工性建議，並以 GMP 承擔施工風險——介於傳統 DB 與純 CM 之間。
- **整合專案交付（IPD, Integrated Project Delivery）**：業主、設計、施工三方風險共擔、利益共享的多方合約模式，仰賴高度協作與 BIM 平台。

### 4.2 招標與採購（Bidding and Procurement）

招標流程：資格預審（prequalification）→ 招標公告 → 廠商領標 → 投標 → 開標（公開/分段）→ 審標 → 決標（最低標或最有利標）。

**最低標**的陷阱：低價搶標後以變更設計追加預算、降低品質。**最有利標**可以綜合評估技術、經驗與價格，但需要更完善、更透明的評選機制。

**保證金體系**：
- **押標金（bid bond）**：防止得標後拒簽約
- **履約保證金（performance bond）**：確保承包商依約履行
- **保固保證金（warranty bond）**：確保保固期的修繕義務

### 4.3 變更設計與索賠（Change Orders and Claims）

工程變更幾乎不可避免。變更來源：設計疏漏、業主需求改變、工地條件與地質報告不符（**differing site condition**）、不可抗力。

**索賠（claim）**：因非可歸責於承包商的原因而增加的工期或成本，承包商向業主請求補償。工期展延（extension of time, EOT）的關鍵判斷是：延遲事件是否落在要徑上？若不在要徑上則展延不成立（因為不影響完工）。

索賠爭議的解決路徑（由低到高）：協商（negotiation）→ 調解（mediation）→ 仲裁（arbitration）→ 訴訟（litigation）。仲裁在工程界較受歡迎，因速度較快且仲裁人通常有工程背景。

## 5. 營建安全與風險管理（Construction Safety and Risk Management）

### 5.1 危害辨識（Hazard Identification）

營建業是全球工安死亡率最高的行業之一，四大主要危害（OSHA "Fatal Four"）：
- **墜落（falls）**：高架作業、開口邊緣
- **物體打擊（struck-by）**：吊掛物掉落、機具迴轉碰撞
- **夾壓（caught-in/between）**：被翻覆機具壓住、被旋轉機械捲入
- **感電（electrocution）**：接觸架空高壓線、臨時供電系統

危害辨識工具：**工作安全分析（JSA, Job Safety Analysis）**——將每項作業拆成步驟，逐一辨識危害並擬定防護對策。

### 5.2 安全文化（Safety Culture）

法規與制度（個人防護具 PPE、安全圍籬、每日工具箱會議）是安全的「硬體」，而**安全文化**是「韌體」——它決定制度是否真的被執行。良好安全文化的要素：管理階層的可見承諾（主管帶頭遵守）、不懲罰式的通報文化（讓工人願意說出未遂事故 near-miss）、持續教育訓練與行為觀察。

### 5.3 風險管理流程

**風險矩陣（risk matrix）**是定性的風險排序工具：以發生機率為縱軸、衝擊程度為橫軸，將風險事件標到 3×3 或 5×5 的格子中。紅色（高機率 × 高衝擊）需要立即的風險回應策略——迴避（取消該工法）、減輕（增加安全措施）、轉移（投保）或接受（編列預備金）。

完整的風險管理循環：**辨識** → **定性/定量分析** → **回應規劃** → **監控與審查**。在營建工程中，蒙地卡羅模擬常用於定量風險分析——將工期與成本的不確定性建模為機率分布，經大量模擬後得出完工日期與總成本的機率分布，提供比單點估計更真實的決策資訊。

營建保險的主要險種：營造綜合保險（CAR, Contractor's All Risks）、第三人責任險、雇主意外責任險、延遲完工保險（DSU, Delay in Start-Up）。

## 6. 碩士/博士延伸

**碩士層級**主題：

- **BIM 4D/5D**：3D 模型整合時間軸（4D）做施工排程模擬與衝突檢測（clash detection），整合成本資訊（5D）做自動化數量計算與即時成本追蹤
- **採購策略與風險分擔**：不同契約類型與風險分擔結構的賽局分析、最優激勵機制設計
- **供應鏈管理**：預鑄構件、鋼構與設備的長交期採購排程、JIT 管理
- **LEAN 營建**：借鑒製造業的精實生產原則——最後規劃者系統（Last Planner System）、拉式排程、減少浪費
- **國際工程管理**：FIDIC 國際契約條款的理解與應用

**博士層級**研究方向：

- **人工智慧在工地安全的應用**：電腦視覺即時偵測未戴安全帽/安全背心、危險區域人員入侵、機具周邊人員偵測；NLP 分析事故報告的自動分類與根本原因萃取
- **營建自動化與機器人**：3D 列印建築（輪廓工法 contour crafting）、砌磚機器人（SAM, Semi-Automated Mason）、鋼筋綁紮機器人（TyBot）、自主施工機具
- **數位孿生（digital twin）**：施工全過程的即時鏡像模擬——將感測器、無人機點雲、進度回報融合為虛擬工地，做預測性管理
- **資料驅動的營建風險預測**：以過往專案大數據訓練模型，預測成本超支、工期延誤與工安事故
- **區塊鏈在營建合約與金流之應用**：智慧合約自動化付款（依 IoT 確認進度後自動放款）
