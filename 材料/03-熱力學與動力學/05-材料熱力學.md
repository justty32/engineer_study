# 材料熱力學（Materials Thermodynamics）

> 名詞對照見 [中英名詞對照表 → 材料熱力學](../中英名詞對照表.md#材料熱力學)。

## 0. 本科定位

材料熱力學回答「為什麼材料會形成某種相（phase）而不是另一種」——用 Gibbs 自由能作為判據：給定溫度、壓力、成分下，系統會走向 $G$ 最小的狀態。Gibbs 自由能 $G = H - TS$，其中 $H$ 為焓（鍵結能、晶格能）、$S$ 為熵（組態熵、振動熵）。低溫時 $H$ 主導 → 有序、結晶相穩定；高溫時 $-TS$ 項變大 → 混亂結構（非晶、固溶體）變得有利。

---

## 1. 自由能與相穩定

材料熱力學的核心判據：**系統在定溫定壓下自發走向 Gibbs 自由能最低的狀態。** 自由能曲線：在不同溫度下畫出各相的 $G$ vs 成分曲線，公切線法則（common tangent rule）決定哪兩相共存。曲線最低點對應最穩定的單相成分，兩端與公切線切點之間 → 兩相共存區。

---

## 2. 溶液熱力學

真實材料幾乎都是混合物。**理想溶液**假設 A–B 交互作用與 A–A、B–B 完全相同（混合焓為零）。混合 Gibbs 自由能：$\Delta G_{\text{mix}} = RT(x_A\ln x_A + x_B\ln x_B)$（純粹熵驅動的混合）。

**正規溶液（regular solution）**加入混合焓：$\Delta G_{\text{mix}} = \Omega x_A x_B + RT(x_A\ln x_A + x_B\ln x_B)$。$\Omega > 0$（A–B 互斥）→ 低溫時自由能曲線中間凸起 → 出現混溶間隙（miscibility gap）→ 相分離。$\Omega < 0$（A–B 互相吸引）→ 傾向形成化合物或有序相。

---

## 3. 相律（Gibbs Phase Rule）

$$F = C - P + 2.$$（定壓時 $F = C - P + 1$）。$C$ = 成分數，$P$ = 共存相數。純金屬（$C=1$）三相點處 $F=0$——只有一個確定的溫度與壓力可讓固液氣三相共存。二元合金（$C=2$）在兩相共存區 $F=1$——可以自由選溫度，但兩相組成隨之確定。

---

## 4. 化學位能（Chemical Potential）

$\mu_i = (\partial G/\partial n_i)_{T,P,n_{j\neq i}}$ 是最核心的偏微分概念——加入微量成分 $i$ 對自由能的貢獻。平衡時，成分 $i$ 在所有共存相中的化學位能必須相等：$\mu_i^\alpha = \mu_i^\beta$。這就是**公切線法則的數學陳述**——兩相共存的組成由「化學位能在兩相中相等」這個條件決定，而非由自由能曲線的最低點。

---

## 5. 碩士/博士延伸

碩士：**CALPHAD**（計算相圖——用熱力學模型擬合實驗數據建立多成分系統的 Gibbs 自由能資料庫，是材料設計的核心工具）、**第一原理熱力學**（DFT 計算形成能 + 準簡諧近似聲子計算自由能）。博士：高熵合金的組態熵穩定效應、晶界相的熱力學（晶界是一層極薄的「非晶相」，可用 Gibbs 吸附方程分析其成分）。
