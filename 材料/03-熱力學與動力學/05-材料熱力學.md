# 材料熱力學（Materials Thermodynamics）

> 名詞對照見 [中英名詞對照表 → 材料熱力學](../中英名詞對照表-1.md#材料熱力學)。

## 0. 本科定位

材料熱力學回答一組根本問題：**給定溫度、壓力與成分下，哪個（或哪些）相是穩定的？** 為什麼鋼淬火會變硬？為什麼析出物會形成、又會粗化？為什麼某些合金在高溫是單相固溶體，冷卻後卻分離成兩相？

這些問題的核心判據只有一個：**Gibbs 自由能（$G$）。** 在定溫定壓條件下，系統自發走向 $G$ 最低的狀態。材料熱力學的任務，就是建立各相的 $G$ 作為溫度、壓力、成分的函數，然後透過「公切線法則」（common tangent rule）找出哪些相的組合能使整體自由能最低。

這裡要清楚區分**材料熱力學**與**機械熱力學**（工程熱力學）：機械熱力學關注熱機循環中的功、熱、效率——工作流體做多少功、排多少熱；材料熱力學關注的是**相的相對穩定性**——給定條件下哪個相存在、相的成分是多少、相變化會不會發生。兩者都用 $G$，但目的完全不同：機械熱力學問「能取出多少功」，材料熱力學問「這是什麼相、為什麼」。

## 1. 熱力學基本量回顧與材料視角

### 1.1 Gibbs 自由能

Gibbs 自由能的定義：

$$G = H - TS = U + PV - TS$$

其中 $H$ 為焓（enthalpy）、$S$ 為熵（entropy）、$U$ 為內能（internal energy）。

對凝聚態（固體、液體）而言，$PV$ 項在常壓下通常很小（固體莫耳體積約 $10^{-5}\ \mathrm{m^3/mol}$，$P\Delta V$ 只有約 $1\ \mathrm{J/mol}$，遠小於化學反應或相變的能量尺度 $\sim \mathrm{kJ/mol}$），因此對固態相變的定性討論，往往可以忽略 $PV$ 項。但要注意：在高壓（地質材料、高壓物理）下 $PV$ 項就不可忽略。

### 1.2 焓與熵的競爭：溫度作為裁判

$G = H - TS$ 這個形式說明了溫度如何決定相的穩定性：

- **低溫時，$H$ 主導。** 焓反映的是鍵結強度——原子間鍵結愈強（鍵能愈大、晶格能愈負），$H$ 愈低，相愈穩定。所以低溫下，有序、緻密的晶體結構（如低溫相的鐵是 BCC 的肥粒鐵）是最穩定的。
- **高溫時，$-TS$ 項主導。** 熵反映的是無序程度——愈混亂的狀態熵愈高。高溫下，系統願意犧牲一些鍵結能來換取更大的熵。這就是為什麼**所有物質在夠高溫度下都會熔化**（液體的組態熵大於固體），也是為什麼高溫相（如沃斯田鐵，FCC）的結構通常較「開放」——原子有更多振動自由度，振動熵也更大。

這種競爭是材料熱力學反覆出現的主題：**焓想讓原子留在最強的鍵結位置（有序），熵想讓原子分散（無序）。** 溫度決定誰贏。

### 1.3 化學位能——最核心的概念

化學位能（chemical potential）$\mu_i$ 定義為在定溫定壓下，加入微量成分 $i$ 對系統總自由能的貢獻：

$$\mu_i = \left(\frac{\partial G}{\partial n_i}\right)_{T, P, n_{j \neq i}}$$

在材料熱力學中，$\mu_i$ 是**最核心的量**，原因如下：

1. **原子流動的驅動力：** 原子從高 $\mu$ 處流向低 $\mu$ 處——就像熱從高溫流向低溫、電流從高電位流向低電位。擴散的本質就是化學位能梯度驅動的原子遷移。
2. **相平衡的條件：** 系統中若有多個相（$\alpha$, $\beta$, $\gamma$, ...）共存，平衡時，**每種成分在每個相中的化學位能必須相等：**

   $$\mu_i^\alpha = \mu_i^\beta = \mu_i^\gamma = \cdots \quad (\text{for every component } i)$$

   這就是「公切線法則」的數學根源，也是理解所有相平衡的關鍵方程式。

3. **化學位能是「部分莫耳 Gibbs 自由能」（partial molar Gibbs free energy）：** 對純物質，$\mu = G_m$（莫耳 Gibbs 自由能）。對溶液中的成分，$\mu_i$ 取決於成分的濃度與環境（其他成分的種類與含量）。

### 1.4 活性——有效濃度

真實溶液中，成分的「有效濃度」與其實際莫耳分率不同，因為原子間的交互作用改變了它的熱力學行為。**活性（activity）** $a_i$ 就是這個有效濃度：

- **理想溶液：** $a_i = X_i$（活性等於莫耳分率）
- **真實溶液：** $a_i = \gamma_i X_i$，其中 $\gamma_i$ 為**活性係數（activity coefficient）**

化學位能以活性表示為：

$$\mu_i = \mu_i^0 + RT \ln a_i$$

其中 $\mu_i^0$ 是標準狀態的化學位能（純物質在相同溫度下的參考值）。$\gamma_i > 1$ 表示成分 $i$ 比理想情況更「想離開」溶液（有效濃度被放大）；$\gamma_i < 1$ 則相反——成分 $i$ 被溶液「拉住」，比理想情況更穩定。

## 2. 溶液熱力學

大多數工程材料不是純物質，而是**溶液（固溶體合金、液態合金）。** 溶液熱力學處理的核心問題是：A、B 兩種原子混合後，自由能如何變化？

### 2.1 混合自由能的一般形式

$$\Delta G_{\text{mix}} = \Delta H_{\text{mix}} - T\Delta S_{\text{mix}}$$

- $\Delta H_{\text{mix}}$：混合焓——混合前後鍵結能的變化
- $\Delta S_{\text{mix}}$：混合熵——混合前後混亂度的變化
- **若 $\Delta G_{\text{mix}} < 0$，則混合自發進行（形成溶液）；若 $\Delta G_{\text{mix}} > 0$，則傾向分離。**

### 2.2 理想溶液（Ideal Solution）

理想溶液的假設：A–B 原子間的交互作用與 A–A、B–B 完全相同。這意味著：

$$\Delta H_{\text{mix}} = 0$$

混合熵純粹來自**組態熵（configurational entropy）**——原子在晶格點上排列方式的數量：

$$\Delta S_{\text{mix}} = -R \sum_i X_i \ln X_i$$

對二元系統（A–B）：

$$\Delta S_{\text{mix}} = -R\,(X_A \ln X_A + X_B \ln X_B)$$

由於 $X_A, X_B < 1$，$\ln X < 0$，所以 $\Delta S_{\text{mix}} > 0$——混合熵永遠為正，永遠有利於混合。

混合自由能：

$$\Delta G_{\text{mix}} = RT\,(X_A \ln X_A + X_B \ln X_B) < 0$$

結論：**理想溶液在任何溫度下都會完全互溶**——因為 $\Delta H_{\text{mix}} = 0$，只有熵在驅動混合，而熵永遠有利於混合。現實中接近理想溶液的例子：Au–Ag、Ge–Si（同族元素，原子尺寸與電負度相近）。

### 2.3 正規溶液（Regular Solution）

正規溶液放鬆了 $\Delta H_{\text{mix}} = 0$ 的假設，但保留了理想溶液的混合熵形式。混合焓用**交互作用參數（interaction parameter）** $\Omega$ 來描述：

$$\Delta H_{\text{mix}} = \Omega X_A X_B$$

$\Omega$ 的物理意義：

- **$\Omega > 0$：** A–B 鍵比 A–A、B–B 鍵的「平均」更弱（A 與 B 互相「排斥」）。系統傾向於讓 A 與 A 在一起、B 與 B 在一起 → **低溫下傾向相分離。**
- **$\Omega < 0$：** A–B 鍵比平均更強（A 與 B 互相「吸引」）。系統傾向於讓 A 旁邊是 B → **傾向形成有序化合物或有序相。**
- **$\Omega = 0$：** 回到理想溶液。

正規溶液的混合自由能：

$$\Delta G_{\text{mix}} = \Omega X_A X_B + RT\,(X_A \ln X_A + X_B \ln X_B)$$

### 2.4 焓與熵的競爭——混溶間隙的出現

這是材料熱力學最精彩的部分之一。分析 $\Delta G_{\text{mix}}$ 對成分的曲線形狀：

- **高溫時：** $-T\Delta S_{\text{mix}}$ 項主導 → $\Delta G_{\text{mix}}$ 曲線是下凹的（convex）→ 任何成分的單相溶液都比任何兩相組合的總自由能更低 → **完全互溶。**

- **低溫時（當 $\Omega > 0$）：** $\Delta H_{\text{mix}}$ 項變得重要。$\Delta G_{\text{mix}}$ 曲線在中央可能**凸起**（兩個極小值中間有一個極大值）。此時，對於中間成分，分成兩個不同成分的相（各自的自由能在兩個極小值附近）會比保持單相有更低的總自由能 → **相分離。**

- **臨界溫度（critical temperature）：** 自由能曲線從完全下凹到出現中央凸起的轉折點發生在：

  $$T_c = \frac{\Omega}{2R}$$

  - $T > T_c$：完全互溶（單相固溶體）
  - $T < T_c$：中間成分區會分離成兩相（出現**混溶間隙 miscibility gap**）

這就是為什麼 Cu–Ni 在所有溫度都能完全互溶（$\Omega \approx 0$），而 Au–Ni 在高溫互溶、低溫卻分離（$\Omega > 0$）。

### 2.5 從自由能曲線到相圖

把各溫度下的 $\Delta G_{\text{mix}}$（或各相的 $G$ vs $X$ 曲線）畫出來，對每個溫度找自由能最低的狀態（單相或兩相共存），就得到**相圖**。這就是相圖的熱力學根源——相圖不是憑空畫出來的，而是自由能曲線族的「投影」。

## 3. 相平衡與相圖基礎

### 3.1 公切線法則（Common Tangent Rule）

考慮兩個相 $\alpha$ 和 $\beta$（例如固相與液相），各自的自由能曲線為 $G^\alpha(X)$ 和 $G^\beta(X)$。系統的總自由能是兩相自由能的加權平均。**哪個組合使總自由能最低？**

答案：畫一條同時與 $G^\alpha(X)$ 和 $G^\beta(X)$ 相切的直線——**公切線（common tangent）。** 公切線的兩個切點就是兩相共存的成分（$X^\alpha$, $X^\beta$）。

為什麼是公切線？因為公切線的斜率在兩個切點處相等，而自由能曲線的斜率正是化學位能：$\partial G/\partial X \propto \mu_A - \mu_B$。公切線的條件保證了：

$$\mu_A^\alpha = \mu_A^\beta,\quad \mu_B^\alpha = \mu_B^\beta$$

——每個成分在兩相中的化學位能相等，滿足相平衡條件。

對於成分落在 $X^\alpha$ 和 $X^\beta$ 之間的任意整體成分 $X_0$，系統會分離成 $\alpha$（成分 $X^\alpha$）和 $\beta$（成分 $X^\beta$）兩相共存。

### 3.2 槓桿法則（Lever Rule）

在兩相共存區內，各相的**相對量（分率）** 由槓桿法則給出：

$$f_\alpha = \frac{X_\beta - X_0}{X_\beta - X_\alpha}, \qquad f_\beta = \frac{X_0 - X_\alpha}{X_\beta - X_\alpha}$$

其中 $X_0$ 是整體成分，$X_\alpha$、$X_\beta$ 是兩相的成分（由穿過 $X_0$ 的**連線 tie line** 與相邊界的交點決定）。這個簡單的關係源自質量守恆——兩相的量與它們離整體成分的「距離」成反比。

### 3.3 Gibbs 相律

Gibbs 相律給出了系統的自由度（可以獨立改變的變數數量）：

$$F = C - P + 2$$

- $C$：成分數（number of components）
- $P$：共存相數（number of phases in equilibrium）
- $F$：自由度（degrees of freedom）——可以在不改變相數的情況下獨立變化的強度變數（溫度、壓力、成分）數量

在**定壓**下（大多數冶金過程在大氣壓下進行，壓力固定），相律簡化為：

$$F = C - P + 1$$

相律對相圖的解讀：

- **單相區：** $P = 1$，二元系統 $C = 2$ → $F = 2$。可以在一定範圍內同時改變溫度**和**成分而不離開單相區。
- **兩相區：** $P = 2$，二元系統 → $F = 1$。若選定了溫度，兩相的成分就由連線決定了；若選定了某一相的成分，溫度也就確定了。在相圖上，兩相共存區內只有一個自由度。
- **三相共存（如共晶點）：** $P = 3$，二元系統 → $F = 0$。溫度與各相的成分都完全固定——這就是**不變點（invariant point）**。在定壓二元相圖上，共晶轉變發生在一個確定的溫度，三相的成分也都是確定的。

### 3.4 二元相圖的主要類型

#### (1) 完全固溶（Complete Solid Solubility）——Cu–Ni 型

兩種金屬在固態與液態都能以任意比例互溶。條件取決於 **Hume-Rothery 規則**：
- 兩者具有相同的晶體結構（例如都是 FCC）
- 原子半徑差小於約 15%
- 電負度相近
- 價電子數相近

滿足這些條件，則 $\Omega$ 小，$\Delta H_{\text{mix}}$ 接近零，固溶體在熱力學上有利。Cu–Ni、Au–Ag、Ge–Si 是經典例子。

#### (2) 共晶系統（Eutectic System）——Pb–Sn、Al–Si 型

共晶轉變：**一個液體在冷卻時同時析出兩個固體：**

$$L \xrightarrow{\text{冷卻}} \alpha + \beta \quad (\text{at } T_E)$$

共晶溫度 $T_E$（定壓下的不變點）低於各純組元的熔點——這是共晶合金的一個實用優勢：**共晶成分的合金熔點最低，流動性最好，適合鑄造。**（Pb–Sn 焊料就是利用共晶成分達到低熔點。）

共晶凝固的顯微組織有兩種典型型態：
- **層狀（lamellar）：** $\alpha$ 與 $\beta$ 交替排列成層狀結構——當兩相的體積分率相近且凝固前沿的擴散路徑短時形成。
- **棒狀（rod-like）：** 其中一相以棒狀嵌在另一相基材中——當某一相的體積分率很小時較常見。

#### (3) 共析系統（Eutectoid System）——Fe–C 型

共析轉變與共晶類似，但起點是**固體**而非液體：

$$\gamma \xrightarrow{\text{冷卻}} \alpha + \mathrm{Fe_3C} \quad (\text{at } 727^\circ\mathrm{C})$$

這是**鋼鐵熱處理的物理基礎。** 沃斯田鐵（$\gamma$-Fe, FCC）在 727°C 以下分解為肥粒鐵（$\alpha$-Fe, BCC）和雪明碳鐵（$\mathrm{Fe_3C}$）。這層狀的肥粒鐵 + 雪明碳鐵組織叫做**波來鐵（pearlite）**。透過控制冷卻速率，可以得到不同的顯微組織（波來鐵、變韌鐵、麻田散鐵），從而大幅調整鋼的機械性質。

#### (4) 包晶系統（Peritectic）與偏晶系統（Monotectic）

- **包晶（peritectic）：** 液體 + 一個固體在冷卻時反應生成**另一個不同的固體**：$L + \alpha \to \beta$。Fe–C 相圖中的包晶反應發生在 1495°C。
- **偏晶（monotectic）：** 液體冷卻時分解為**另一個液體 + 一個固體**：$L_1 \to L_2 + \alpha$。Cu–Pb 系統是典型例子——兩種液體不互溶，其中一相凝固時另一相仍為液態。

## 4. 相變化的熱力學驅動力

### 4.1 驅動力的定義

相變化的驅動力就是反應物與產物之間的 Gibbs 自由能差：

$$\Delta G = G_{\text{產物}} - G_{\text{反應物}} < 0$$

只有在 $\Delta G < 0$ 時轉變才會自發進行。問題是：**如果轉變溫度 $T_{\text{eq}}$ 上兩相的 $G$ 相等（$\Delta G = 0$），那轉變如何發生？**

答案：**過冷（undercooling）。** 在平衡轉變溫度 $T_{\text{eq}}$ 上，$\Delta G = 0$——沒有驅動力。必須冷卻到 $T_{\text{eq}}$ **以下**，使產物的自由能低於反應物（$\Delta G < 0$），才能驅動轉變。

過冷度 $\Delta T = T_{\text{eq}} - T$ 愈大，驅動力 $\Delta G$ 愈大。對凝固（液 → 固）：

$$\Delta G_v = \frac{\Delta H_f \cdot \Delta T}{T_{\text{eq}}}$$

其中 $\Delta H_f$ 為熔化潛熱（正值，凝固時釋出）、$\Delta G_v$ 為單位體積的自由能變化（負值，表示驅動力）。

### 4.2 成核的障礙——表面能的代價

即使有驅動力（$\Delta G_v < 0$），新相也不會立刻形成，因為形成新相需要創造**界面（interface）。** 界面有表面能 $\gamma$——創造界面需要能量。

對一個半徑 $r$ 的球形成核：

$$\Delta G(r) = \frac{4}{3}\pi r^3 \Delta G_v + 4\pi r^2 \gamma$$

- 第一項：體積自由能貢獻（負的，驅動轉變——隨 $r^3$ 增長）
- 第二項：界面能代價（正的，阻止轉變——隨 $r^2$ 增長）

兩個項的競爭導致 $\Delta G(r)$ 先升後降，存在一個極大值：

- **臨界半徑（critical radius）：** $r^* = -\dfrac{2\gamma}{\Delta G_v}$

  $r < r^*$ 的胚芽（embryo）傾向自行消融；$r > r^*$ 的晶核（nucleus）傾向繼續長大。

- **臨界成核障礙（critical nucleation barrier）：**

  $$\Delta G^* = \frac{16\pi \gamma^3}{3(\Delta G_v)^2}$$

  $\Delta G^*$ 隨 $\Delta G_v$（即過冷度 $\Delta T$）增大而減小——過冷度愈大，成核障礙愈低，成核愈容易。

### 4.3 均質成核與異質成核

- **均質成核（homogeneous nucleation）：** 在均勻液體內部隨機形成晶核。需要很大的過冷度（純金屬可到 $0.2\,T_m$ 的過冷），因為障礙高。
- **異質成核（heterogeneous nucleation）：** 在既有的表面（模具壁、雜質顆粒、晶粒邊界）上成核。表面降低了需要創造的新界面面積 → 障礙大幅降低。這是**工程實務中絕大多數成核的機制**——鑄造時在模壁上成核、析出物在晶界或差排線上成核。

異質成核的障礙為：

$$\Delta G^*_{\text{het}} = \Delta G^*_{\text{hom}} \cdot f(\theta)$$

其中 $f(\theta) = (2 + \cos\theta)(1 - \cos\theta)^2 / 4$，$\theta$ 為接觸角。$\theta = 180^\circ$（完全不潤濕）時 $f = 1$（等同均質成核）；$\theta$ 愈小，$f(\theta)$ 愈小，障礙愈低。$\theta$ 接近零（完全潤濕）時幾乎沒有障礙。

### 4.4 擴散的制約

即使有熱力學驅動力，原子還必須能夠**移動**才能形成新相。在高過冷度（低溫）下，驅動力巨大，但原子擴散極慢 → 轉變被擴散限制。這導致了**整體轉變速率在中等溫度下出現最大值**——就是下文 TTT 圖中 C 曲線的物理原因：

- 高溫（接近 $T_{\text{eq}}$）：擴散快，但驅動力 $\Delta G \approx 0$ → 轉變慢
- 中等溫度：驅動力適中、擴散也還夠快 → **轉變最快（C 曲線的鼻部）**
- 低溫（大幅過冷）：驅動力最大，但擴散極慢 → 轉變又變慢

## 5. 相變的動力學

### 5.1 Johnson-Mehl-Avrami (JMA) 方程

等溫相轉變的體積分率 $f$ 隨時間的變化可用 JMA 方程描述：

$$f = 1 - \exp(-k t^n)$$

其中 $k$ 為速率常數（取決於溫度——透過 Arrhenius 關係與擴散係數連結），$n$ 為 **Avrami 指數**。$n$ 的值包含了成核與成長機制的資訊：

| 條件 | 成核模式 | 成長維度 | Avrami 指數 $n$ |
|------|---------|---------|----------------|
| 界面控制 | 恆定成核率 | 3D | 4 |
| 界面控制 | 恆定成核率 | 2D | 3 |
| 界面控制 | 位置飽和（成核瞬間完成） | 3D | 3 |
| 擴散控制 | 恆定成核率 | 3D | 2.5 |
| 擴散控制 | 位置飽和 | 3D | 1.5 |

實驗中測量 $n$ 是推斷轉變機制的重要手段——畫 $\ln\ln(1/(1-f))$ vs $\ln t$（Avrami plot），斜率即為 $n$。

### 5.2 TTT 圖（Time-Temperature-Transformation Diagram）

TTT 圖是等溫轉變的「地圖」：在每個溫度下量測轉變開始（1%）和結束（99%）所需的時間，畫在溫度–時間對數坐標上，得到一組 **C 形曲線（C-curve）。**

- **高溫區（接近 $T_{\text{eq}}$）：** 驅動力極小 → 轉變極慢（曲線向右延伸）
- **中等溫度（C 曲線鼻部）：** 驅動力與擴散的平衡點 → 轉變最快
- **低溫區：** 擴散極慢 → 轉變又變慢（曲線再次向右延伸）

TTT 圖解釋了為什麼鋼可以透過不同熱處理得到截然不同的性質：快速冷卻繞過 C 曲線的鼻部 → 避開波來鐵轉變 → 得到麻田散鐵（硬而脆）；緩慢冷卻 → 穿過高溫區 → 得到波來鐵（較軟但韌）。

### 5.3 CCT 圖（Continuous Cooling Transformation Diagram）

TTT 圖是等溫的，但工業上大多數熱處理是**連續冷卻**，而非恆溫。CCT 圖就是對應連續冷卻的轉變圖——畫出不同冷卻速率下的冷卻曲線，標示各曲線與相轉變開始/結束的交點。

與 TTT 圖的關鍵差異：CCT 曲線相對於 TTT 曲線向右下方偏移（轉變發生在更低溫度、更長時間）——因為連續冷卻時系統在每個溫度停留的時間有限，轉變需要比等溫情況更多的累積時間。

**臨界冷卻速率（critical cooling rate）：** 要完全避開擴散型轉變（得到全麻田散鐵組織）所需的最小冷卻速率。CCT 圖上，冷卻曲線若完全避開所有擴散轉變產物的生成區，就能得到麻田散鐵。

### 5.4 擴散控制 vs 界面控制 vs 麻田散鐵型轉變

相變化的動力學取決於**速率控制步驟**：

- **擴散控制（diffusion-controlled）：** 原子的長程擴散是瓶頸——新相的成長速率取決於原子能多快透過擴散到達界面。多數固態析出轉變屬於此類。成長速率 $v \propto \sqrt{D/t}$（隨時間減慢，因為擴散距離增加）。

- **界面控制（interface-controlled）：** 原子跨越界面重新排列是瓶頸——當兩相成分相同（如多晶型轉變 polymorphic transformation）時，不需要長程擴散。成長速率 $v$ 為常數（不隨時間減慢）。

- **麻田散鐵型（martensitic / diffusionless）：** 原子以協同剪切的方式集體移動，沒有擴散——每個原子移動距離小於一個原子間距。極快（接近音速），不依賴擴散，因此也無法用 TTT/CCT 中的擴散區來描述。麻田散鐵轉變有自己特有的開始溫度 $M_s$（martensite start）和結束溫度 $M_f$（martensite finish）。

## 碩士層級延伸

- **CALPHAD（CALculation of PHAse Diagrams）：** 建立在材料熱力學之上的計算方法論——用熱力學模型（如正規溶液、次正規溶液、sublattice 模型）擬合實驗數據，建立多成分系統的 Gibbs 自由能資料庫。CALPHAD 是現代材料設計的核心工具：從資料庫就能計算任意溫度、成分下的平衡相組成，不必對每個成分逐一做實驗。Thermo-Calc、Pandat、FactSage 是主要軟體平台。

- **第一原理熱力學（First-Principles Thermodynamics）：** 從 DFT（密度泛函理論）計算形成能，結合準簡諧近似（quasi-harmonic approximation）計算聲子自由能，完全從量子力學出發預測相的穩定性與相圖。適合探索尚未有實驗數據的新合金系統。

- **高熵合金的熱力學：** 傳統合金以一個主元素為基，高熵合金（HEA）則以多個主元素等莫耳混合。關鍵在於「高組態熵能否穩定單相固溶體」——$\Delta S_{\text{mix}}$ 隨成分數增加而增大，但 $\Delta H_{\text{mix}}$ 的影響仍然不可忽略。熱力學分析需要同時考慮混合焓、混合熵、以及原子尺寸差異引起的彈性應變能。

## 博士層級研究方向

- 晶界相的熱力學——晶界可視為一層奈米級「非晶相」，用 Gibbs 吸附方程分析其成分與穩定性
- 輻射照射下非平衡相的熱力學（cascade-driven phase transformations）
- 機器學習勢函數（ML potential）加速自由能計算——結合分子動力學與熱力學積分
- 極端條件（超高壓、超高溫）下的相圖預測——行星內部材料
