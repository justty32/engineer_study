> 名詞對照見 [中英名詞對照表 → 相圖與相平衡](../中英名詞對照表-1.md#相圖與相平衡)。

## 0. 本科定位

相圖（phase diagram）是材料人的「地圖」。電路圖告訴電機工程師電壓與電流如何流動；相圖告訴材料工程師：給定合金成分與溫度，**有哪些相存在、各相的成分是什麼、各相的量有多少。** 這三個答案直接決定材料的微結構與最終性質。

鐵碳（Fe–C）相圖單獨支撐了整個鋼鐵冶金學——從古代鐵匠的淬火技藝到今日麻時效鋼的精準熱處理，全部建立在這張圖上。讀懂相圖是進入材料領域的通關技能：看不懂相圖，就無法設計熱處理、無法理解鑄造凝固、無法分析析出強化。

相圖背後是熱力學。前一章的 Gibbs 自由能與化學位能，在這裡化為具體幾何：自由能曲線的公切線投影成相界線、化學位能相等的條件決定了兩相區中的連線（tie line）。相圖就是把抽象的平衡條件「畫成看得見的圖」。

## 1. 一元相圖與二元相圖基礎

### 1.1 一元相圖：P–T 圖

一元系統只有一個成分，相律（Gibbs phase rule）為：

$$F = C - P + 2 = 3 - P$$

- **單相區**（$P=1$）：$F=2$——T 與 P 均可獨立變化，是二維區域。
- **兩相共存線**（$P=2$）：$F=1$——指定了 T，P 就被固定（如水的液–氣共存線）。
- **三相點（triple point）**（$P=3$）：$F=0$——T 與 P 都被鎖定在唯一值。水三相點：$T = 0.01\ \mathrm{^\circ C}$、$P = 611\ \mathrm{Pa}$，固液氣三者共存。
- **臨界點（critical point）**：液–氣共存線終點，以上液氣不分。水：$T_c = 374\ \mathrm{^\circ C}$、$P_c = 22.1\ \mathrm{MPa}$。

對材料而言，一元相圖的實用價值在於理解**同素異形體（allotrope）**。純鐵是最重要例子：室溫 BCC $\alpha$-Fe（肥粒鐵）$\xrightarrow{912^\circ\mathrm{C}}$ FCC $\gamma$-Fe（沃斯田鐵）$\xrightarrow{1394^\circ\mathrm{C}}$ BCC $\delta$-Fe。每次相變都伴隨體積變化，這些相變是鋼鐵熱處理的基礎。

### 1.2 二元相圖：T–x 圖（定壓）

絕大多數材料相圖是二元、定壓下的**溫度–成分圖**。大氣壓力固定，相律簡化為：

$$F = C - P + 1 = 3 - P \quad (\text{定壓})$$

- **單相區**（$P=1$）：$F=2$——T 與成分可自由變化。
- **兩相區**（$P=2$）：$F=1$——指定 T 則兩相成分鎖定。**兩相區是一個區域，不是一條線**（初學者最常見的誤解）。
- **三相共存**（$P=3$）：$F=0$——定壓下的不變反應，在圖上是水平等溫線。

### 1.3 液相線、固相線、連線、槓桿法則

- **液相線（liquidus）**：以上全為液體；冷卻時第一顆固體出現的溫度。
- **固相線（solidus）**：以下全為固體；冷卻時最後一滴液體凝固的溫度。

在兩相區中要知道兩相的成分與比例，需要兩個工具：

**連線（tie line）**：給定溫度，畫水平線交左右相界。左交點給出 $\alpha$ 相成分 $C_\alpha$，右交點給出液體成分 $C_L$。連線是水平的，因為平衡時 $\mu_i^\alpha = \mu_i^L$。

**槓桿法則（lever rule）**：以總體成分 $C_0$ 為支點：

$$f_\alpha = \frac{C_L - C_0}{C_L - C_\alpha}, \quad f_L = \frac{C_0 - C_\alpha}{C_L - C_\alpha}$$

離哪相愈近，那相的質量分率愈大。槓桿法則只適用於兩相區（單相區 $f = 1$，不需要）。

## 2. 重要二元相圖類型

### 2.1 完全互溶型（Isomorphous）——Cu–Ni

兩種成分在液固態均**完全互溶**，相圖呈「透鏡形」（lens-shaped）。Cu–Ni 是經典例子：FCC 的 Cu 與 Ni 在全成分範圍形成單一 FCC 固溶體，無中間化合物也無不變反應。

冷卻時，**第一顆固體富高熔點成分**（Ni）；隨溫度下降，固體成分沿固相線移動、液體沿液相線移動。實際鑄造中擴散來不及完成，導致**晶內偏析（coring / microsegregation）**：晶粒中心（先凝固）富 Ni，外圍富 Cu。通常以均質化退火消除。

### 2.2 共晶型（Eutectic）——Pb–Sn、Al–Si、Fe–C（1147°C）

$$L \xrightarrow{\text{冷卻}} \alpha + \beta$$

共晶成分是系統中**熔點最低的成分**。Pb–Sn 共晶焊料（Sn-37Pb，183°C）熔點遠低於純 Pb（327°C）或純 Sn（232°C），因此廣泛用於電子組裝。近年因環保法規（RoHS）轉向無鉛焊料如 Sn–Ag–Cu。

**共晶凝固微結構**：$\alpha$ 與 $\beta$ 兩相協同生長（coupled growth），形成層狀（lamellar）或棒狀（rod-like）組織。層間距 $\lambda$ 與過冷度成反比：

$$\lambda \propto \frac{1}{\Delta T}$$

過冷度愈大，$\lambda$ 愈小，組織愈細，強度愈高（相界面是差排障礙——界面愈密，差排運動愈難）。

**Al–Si 共晶**（Al-12.6Si，577°C）是鑄造鋁合金（如活塞合金）的基礎。近共晶成分流動性極佳，加入 Na 或 Sr **變質處理（modification）**可將粗大板狀 Si 轉化為細小纖維狀，顯著提高韌性。

**Fe–C 共晶**（1147°C，4.30 wt% C）：$L \to \gamma + \mathrm{Fe_3C}$。產物稱**萊氏體（ledeburite）**，是鑄鐵組織的特徵。

### 2.3 共析型（Eutectoid）——Fe–C（727°C，0.77 wt% C）

與共晶同形式，但反應物是**固相**：

$$\gamma \xrightarrow{\text{冷卻}} \alpha + \mathrm{Fe_3C}$$

Fe–C 系統中發生於 727°C（A₁ 溫度）、0.77 wt% C。產物**波來鐵（pearlite）**是 $\alpha$ + Fe₃C 交替排列的層狀組織——碳鋼最常見的微結構成分。軟韌的 $\alpha$ 層提供韌性，硬脆的 Fe₃C 層提供強化。層間距 $\lambda$ 同樣取決於冷卻速率：粗波來鐵（緩冷，$\lambda$ ~1 μm）較軟；細波來鐵（快冷，$\lambda$ ~0.1 μm）強度更高。

### 2.4 包晶型（Peritectic）——Fe–C（1495°C）、Cu–Zn

$$L + \alpha \xrightarrow{\text{冷卻}} \beta$$

液體與一個先凝固相反應生成新固相。Fe–C 中發生於 1495°C、0.16 wt% C：$L$（~0.53%C）$+ \delta$（~0.09%C）$\to \gamma$（~0.16%C）。包晶反應通常**不完全**——生成的 $\beta$ 包裹在 $\alpha$ 外圍形成擴散障壁。Cu–Zn（黃銅）系統含多個包晶反應，對應不同 Zn 含量的黃銅相。

### 2.5 偏晶型（Monotectic）——Cu–Pb

$$L_1 \xrightarrow{\text{冷卻}} L_2 + \alpha$$

液體冷卻時分解為另一個液體與一個固體——**液態相分離**。Cu–Pb 系統中，凝固後軟 Pb 顆粒散佈在硬 Cu 基體中，運轉時 Pb 提供**自潤滑（self-lubrication）**——這是 Cu–Pb 軸承合金的工作原理。

### 2.6 其他不變反應與快速判讀

- **包析（peritectoid）**：$\alpha + \beta \to \gamma$（較罕見）
- **合成（syntectic）**：$L_1 + L_2 \to \alpha$（極罕見，K–Zn 系統）

**判讀口訣**：不變反應水平線上必接觸三個單相區。中段單相區在上方 → 共晶或共析；中段單相區在下方 → 包晶或包析。

## 3. 鐵碳相圖深度解讀

鐵碳相圖是工程上最重要的相圖，同時包含共晶、共析、包晶三種不變反應，是理解所有鋼鐵材料的統一框架。

### 3.1 Fe–C 系統中的相

| 相 | 晶體結構 | 最大溶碳量 | 特性 |
|---|---------|-----------|------|
| $\alpha$-肥粒鐵 | BCC | 0.022 wt%（727°C） | 軟、有磁性。BCC 八面體間隙「扁」——溶碳量極低。 |
| $\gamma$-沃斯田鐵 | FCC | 2.14 wt%（1147°C） | 無磁性。FCC 八面體間隙較大，溶碳量約為肥粒鐵的 100 倍——**這是鋼能進行熱處理的根本原因。** |
| $\delta$-肥粒鐵 | BCC | 0.09 wt%（1495°C） | 僅存於 >1394°C，對常規熱處理無影響，對鋼凝固（尤其不鏽鋼焊接）重要。 |
| Fe₃C 雪明碳鐵 | 斜方晶 | 6.67 wt% C | 硬而脆的金屬間化合物。**介穩定相（metastable）**——石墨才是真正穩定相，但 Fe₃C 分解動力學極慢，工程尺度下可視為穩定。 |
| C 石墨 | 六方層狀 | 100% C | 真正穩定相。鑄鐵中若冷卻夠慢或含 Si，碳以石墨析出——區分灰口鑄鐵（片狀石墨）與白口鑄鐵（全為 Fe₃C）。 |

### 3.2 三個關鍵不變點

1. **包晶點**（1495°C，0.16 wt% C）：$L + \delta \to \gamma$
2. **共晶點**（1147°C，4.30 wt% C）：$L \to \gamma + \mathrm{Fe_3C}$（產物：萊氏體）
3. **共析點**（727°C，0.77 wt% C）：$\gamma \to \alpha + \mathrm{Fe_3C}$（產物：波來鐵）——**鋼熱處理的核心。**

以 0.77% C 為界：**亞共析鋼**（<0.77%）冷卻時先析出初析肥粒鐵，殘留 $\gamma$ 往共析點移動，至 727°C 變為波來鐵；**過共析鋼**（>0.77%）先沿晶界析出初析雪明碳鐵，同樣於 727°C 共析。

### 3.3 關鍵相界線：A₁、A₃、Acm

- **A₁**（727°C 水平線）：共析溫度
- **A₃**（$\gamma / (\alpha + \gamma)$ 相界）：冷卻時 $\alpha$ 開始析出的溫度線，隨碳含量增加而降低（純鐵 912°C → 共析 727°C）
- **Acm**（$\gamma / (\gamma + \mathrm{Fe_3C})$ 相界）：過共析鋼中 Fe₃C 開始析出的溫度線

### 3.4 微結構成分（Microconstituents）

關鍵區分：**相（phase）**是熱力學定義的均勻實體（只有 $\alpha$, $\gamma$, $\delta$, Fe₃C, C 五個），**微結構成分（microconstituent）**是這些相以特定形態排列的組織單元。

#### 3.4.1 波來鐵（Pearlite）

$\alpha$ + Fe₃C 層狀交替組織（$\alpha$ ~88 vol%、Fe₃C ~12 vol%），由 $\gamma$ 在 A₁ 共析分解而成。強度與層間距關係近似 $\sigma_y \propto \lambda^{-1/2}$（類似 Hall–Petch）。冷卻愈快，過冷度愈大，$\lambda$ 愈小，波來鐵愈硬。

#### 3.4.2 變韌鐵（Bainite）

$\gamma$ 冷卻至 250–550°C 恆溫保持，形成非層狀 $\alpha$ + Fe₃C。生成機制為切變＋擴散混合：$\alpha$ 以切變生長，但碳仍能擴散析出碳化物。

- **上變韌鐵**（~400–550°C）：板條間析出連續 Fe₃C，「羽毛狀」組織，韌性較差
- **下變韌鐵**（~250–400°C）：針狀肥粒鐵內部析出極細碳化物（與板條約 60°），韌性遠優，強度韌性兼具

產生變韌鐵的等溫熱處理稱為**沃斯回火（austempering）**。

#### 3.4.3 麻田散鐵（Martensite）

淬火至 $M_s$ 以下，碳來不及擴散，$\gamma$ 以**無擴散切變**直接轉變為麻田散鐵。它不是 BCC，而是 **BCT（體心正方）**——碳原子被困在 c 軸方向八面體間隙，強制拉長晶格，正方度 $c/a$ 隨碳含量增加。極硬（碳固溶強化 + 相變差排/雙晶）但極脆，淬火態不能直接使用。

#### 3.4.4 回火麻田散鐵（Tempered Martensite）

淬火後**必須回火（tempering）**——加熱至 A₁ 以下（150–650°C）使碳以碳化物析出。低溫回火（~150–250°C）：$\varepsilon$-碳化物析出，正方度下降；中溫回火（~250–400°C）：殘留沃斯田鐵分解；高溫回火（~400–650°C）：碳化物球化，肥粒鐵回復再結晶。

淬火＋高溫回火合稱**調質處理（Q&T）**，是構造用鋼標準路線。調整回火溫度可在很寬範圍內精確控制強度–韌性的取捨。

### 3.5 穩定系 vs. 介穩定系

- **介穩定系**：以 Fe₃C 為碳的存在形式——**鋼**的相圖（冷卻夠快，Fe₃C 來不及分解）
- **穩定系**：以石墨為碳的存在形式——**鑄鐵**的相圖（含 Si 高、冷卻慢時碳以石墨析出，即石墨化）

兩者結構相同，共晶/共析溫度與成分略有偏移。鑄鐵中得到石墨還是 Fe₃C，取決於 Si 含量與冷卻速率。

## 4. 三元相圖

實際工程合金幾乎不可能少於三成分——不鏽鋼是 Fe–Cr–Ni、鎳基超合金是 Ni–Cr–Al、無鉛焊料是 Sn–Ag–Cu。

### 4.1 Gibbs 三角形

三個頂點各代表純成分（100%）。三角形內任意點成分由其到三邊的垂直距離決定，三者之和恆為 100%。溫度是第四個變數，無法畫在三維紙面上，因此三元相圖以兩種截面呈現。

### 4.2 等溫截面（Isothermal Section）

定溫下切一刀，得到二維 Gibbs 三角形，標示該溫度下的各相區。單相區為封閉/半封閉區域；兩相區由連線連接（三元中連線不再水平，有兩個成分自由度）；**三相區**是一個三角形（tie triangle）——三個頂點各為三個共存相的成分（定溫定壓下 $F=0$，三成分在三相中的化學位能條件鎖死所有成分）。

### 4.3 垂直截面（Vertical Section）

固定兩個成分比例，畫溫度對第三成分的圖。看起來像二元相圖，但**不是真正相圖**——連線不一定在截面上，不能用槓桿法則。主要用於快速判斷某成分路徑上會發生什麼相變。

### 4.4 液相面、固相面與三元共晶

在三維 $T$–$x_A$–$x_B$ 空間中，**液相面（liquidus surface）**是液體與首個固相共存的曲面；**固相面（solidus surface）**是液相完全凝固的曲面。**三元共晶點**是液相面最低點：$L \to \alpha + \beta + \gamma$，四相共存（$P=4$）、$F=0$——固定 T 與所有成分。

### 4.5 工程實例

- **不鏽鋼（Fe–Cr–Ni）**：Ni 是沃斯田鐵穩定劑，Cr 是肥粒鐵穩定劑。18/8 不鏽鋼（Fe-18Cr-8Ni）在 1100°C 等溫截面上完全位於 $\gamma$ 單相區。
- **鎳基超合金（Ni–Cr–Al）**：$\gamma$ 基體 + $\gamma'$（Ni₃Al, L1₂）析出物的相平衡決定高溫強度。三元相圖指導成分設計以最大化 $\gamma'$ 體積分率並避免有害 TCP 相。
- **無鉛焊料（Sn–Ag–Cu, SAC）**：三元共晶成分（Sn-3.5Ag-0.9Cu，~217°C）直接源於三元相圖研究。

## 5. 相圖的實驗測定與計算

### 5.1 實驗方法

**熱分析（Thermal Analysis）**：記錄冷卻曲線。相變釋放潛熱使冷卻速率減緩，曲線上出現**熱停滯（thermal arrest）**。純金屬凝固出現平台（$F=0$）；合金凝固在液相線與固相線處各有一個斜率變化。

**DTA／DSC**：同時加熱樣品與參考物，記錄溫差（DTA）或熱流差（DSC）。相變峰位置給出相變溫度，峰面積給出焓變。

**金相法＋成分分析**：合金在不同溫度長時間平衡退火後淬火凍結高溫組織，用 SEM 觀察、EDS/WDS 分析各相成分，逐點畫出相界線。

**XRD**：淬火樣品各相晶體結構由 XRD 鑑定。晶格常數變化（Vegard 定律）可反推相成分。

**擴散偶法（Diffusion Couple）**：兩種金屬接觸後高溫長時間退火，界面形成成分梯度。用 EPMA 沿界面掃描，可一次得到整條相界線與多個兩相區的連線方向，極大加速多元相圖測定。

### 5.2 計算方法：CALPHAD

CALPHAD（**CAL**culation of **PHA**se **D**iagrams）是現代相圖研究支柱。核心思路：

1. 為每個相建立 Gibbs 自由能數學模型（以 $T$、$P$、成分為變數），包含純元素晶格穩定性、混合焓、混合熵（理想貢獻 + Redlich-Kister 多項式超額項）
2. 將已知實驗數據（相界溫度、相成分、活性、生成焓）擬合模型參數
3. 給定任意 $T$、$P$、成分，計算各相 $G$，找出最低自由能的相組合 → 預測相圖

真正威力在於**外推**：二元參數擬合完成後，透過幾何模型（如 Muggianu 模型）外推到三元甚至更高元系統。三成分的可能組合數以千計、更高元則天文數字，不可能全用實驗測量。

**主要軟體與資料庫**：

- **Thermo-Calc**：最廣泛使用的商業軟體，涵蓋鋼鐵、鋁、鈦、鎳、陶瓷等。工業界標準。
- **FactSage**：側重高溫化學冶金（熔渣、熔鹽、耐火材料）。
- **PANDAT**：以 PanEngine 引擎著稱，擅長凝固路徑模擬（Scheil–Gulliver）。
- **OpenCalphad**：開源替代方案（Bo Sundman 開發），適合學術與教學。

CALPHAD + 實驗驗證已成當代合金設計標準流程：電腦掃描大量成分與熱處理參數，篩選候選成分再實驗驗證，大幅縮短開發週期。

## 6. 碩士/博士延伸

### 碩士層級

- **三元液相面投影（liquidus projection）**：將三維液相面上等溫線投影到 Gibbs 三角形，標示初晶相區（primary phase fields）與不變反應流向（類似地形圖等高線與溪流），是分析鑄造合金凝固路徑的關鍵工具。
- **凝固路徑模擬**：結合 CALPHAD 與 Scheil–Gulliver 方程式，模擬非平衡凝固過程中液相成分變化軌跡，預測最終組織中各相比例與偏析程度。
- **CALPHAD 資料庫批判性使用**：理解商用資料庫的局限性（純粹外推 vs. 有實驗約束的三元建模），判斷何時需自行進行關鍵實驗驗證。

### 博士層級

- **準晶（quasicrystal）相圖**：長程有序但無平移對稱的準晶相（如 Al–Mn 二十面體準晶）與近似結晶相之間的競爭關係及熱力學建模。
- **高熵合金（HEA）相圖預測**：五種以上主要元素的相空間維度極高，目前策略依賴 CALPHAD + DFT 第一原理 + 機器學習混合方法——DFT 提供資料庫中不存在的三元/四元交互參數，機器學習加速成分空間掃描。
- **第一原理相圖計算**：純粹從 DFT 計算各相 Helmholtz 自由能（電子、振動、組態貢獻），透過集群展開（cluster expansion）與蒙地卡羅模擬預測相圖，在預測未探索新材料方面潛力巨大。
- **壓力作為額外維度**：高壓相圖（地球內部材料、超硬材料合成）。壓力可劇烈改變相穩定性（石墨 $\to$ 鑽石），壓力–溫度–成分綜合相圖是極端條件材料科學的核心。
