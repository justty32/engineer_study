# 複合材料（Composite Materials）

> 名詞對照見 [中英名詞對照表 → 複合材料](../中英名詞對照表.md#複合材料)。

---

## 0. 本科定位

複合材料不是「把兩種材料混在一起」——它是**工程設計的材料系統**。強化材（reinforcement）、基材（matrix）、界面（interface）三者是同時設計、互相配合的：

- **強化材**承受負載：高強度、高剛性的纖維是結構主力
- **基材**傳遞負載並保護纖維：透過界面剪力把應力傳給纖維，將纖維固定在位置上，隔絕環境
- **界面**決定負載能否有效傳遞：太弱 → 纖維拔出（pullout），強度浪費；太強 → 裂縫穿過纖維，毫無韌性。最佳界面是「剛好夠強，讓複材破壞時耗能最大」

這與合金（alloy）有本質差異：合金性質大致是各成分的平均，等向性（isotropic）；複合材料可以**刻意做成異向性（anisotropic）**——在受力方向放纖維，垂直方向幾乎不放。這是**設計自由度**：工程師可以「把材料放在需要的地方」。

自然界到處是複合材料：木頭（纖維素纖維 + 木質素）、骨骼（膠原蛋白 + 氫氧基磷灰石）、貝殼珍珠層（碳酸鈣片 + 蛋白質層，Bouligand 螺旋結構）。工程師只是把同樣的邏輯用人工材料實現在更大尺度上。

## 1. 複合材料的分類與組成

### 1.1 依基材分類

**高分子基複合材料（Polymer Matrix Composite, PMC）**

最常見，基材為熱固性或熱塑性高分子。優勢：低密度、易加工、成本低。

- **熱固性基材**：環氧樹脂（epoxy — 力學性能與黏著力最佳，航太主流）、聚酯（polyester — 便宜，船體／浴缸）、乙烯酯（vinyl ester — 耐化學腐蝕）、酚醛（phenolic — 耐火／低煙，飛機內裝）、雙馬來酰亞胺（BMI — 耐 ~230°C，軍機用）
- **熱塑性基材**：PEEK（耐 ~250°C、韌性極佳、可重複成型，高階航太）、PPS（耐化學性優）、聚碳酸酯（透明／耐衝擊）

**金屬基複合材料（Metal Matrix Composite, MMC）**

基材為金屬（鋁、鈦、鎂、銅），強化材為陶瓷顆粒或纖維。優勢：高比剛性／比強度、高溫性能、可控熱膨脹、可導電導熱。

- Al/SiC：最常見，煞車碟盤（散熱快、耐磨）、引擎活塞（低熱膨脹）
- Ti/SiC：噴射引擎環形構件（bladed ring），極高比強度
- Cu/W：高導熱 + 低熱膨脹，電子封裝散熱基板

挑戰：纖維與金屬在高溫製程中容易反應生成脆性介金屬化合物，需在纖維表面鍍阻障層（barrier coating）。

**陶瓷基複合材料（Ceramic Matrix Composite, CMC）**

基材為陶瓷（SiC、Al₂O₃），強化材為陶瓷纖維。核心目的：**克服陶瓷的脆性**。CMC 透過纖維橋接裂縫（fiber bridging）、裂縫偏轉（crack deflection）、纖維拔出等機制大幅提高韌性。

- SiC/SiC：渦輪外環、燃燒室襯墊。耐 ~1400°C，密度為鎳基超合金的 1/3
- C/SiC：高超音速熱防護、火箭噴嘴、陶瓷煞車碟盤
- C/C：F1 煞車、飛彈鼻錐。極高溫 ~3000°C，但 ~400°C 以上即氧化，需防氧化塗層
- Oxide/Oxide（Al₂O₃/Al₂O₃）：天生抗氧化，不需塗層

CMC 關鍵技術：纖維與基材之間的**弱界面**（BN 或碳介面層）——裂縫行進到界面時沿界面偏轉，不直接切斷纖維。這是 CMC 韌化的核心。

### 1.2 依強化材幾何分類

- **顆粒強化（particulate）**：大致等向性，強度提升中等。混凝土、瓷金（WC/Co 切削刀具）、填充高分子
- **晶鬚強化（whisker）**：單晶短纖維，直徑 ~1–10 μm，近無缺陷 → 強度接近理論值。SiC 晶鬚最著名，但因健康疑慮（吸入風險）與成本已被長纖取代
- **短纖強化（short fiber）**：切斷的纖維段，可射出成型，強度約為長纖的 50–70%。短玻纖強化熱塑性塑膠（家電外殼）
- **連續纖維強化（continuous fiber）**：性能最高、高度異向性、航太級。碳纖預浸布（prepreg）為代表
- **織物強化（woven fabric）**：平織（plain）、斜紋（twill）、緞紋（satin），0°/90° 雙向強化，較單向帶（UD tape）更容易鋪疊曲面

### 1.3 強化纖維材料

**玻璃纖維**：E-glass（電氣級，強度 ~3.5 GPa，便宜，PCB 基板 FR4／船體／風機葉片）、S-glass（高強度 ~4.6 GPa，軍用航太）。弱點：剛性偏低（$E \approx 70$–$85$ GPa）、疲勞潛變較明顯。

**碳纖維**：從聚丙烯腈（PAN）前驅物出發：氧化穩定化（200–300°C）→ 碳化（1000–3000°C，惰性氣氛）→ 選擇性石墨化（~3000°C，提升模數）。

- 高強度型（HS）：碳化 ~1500°C，強度 5–7 GPa，模數 ~230–300 GPa。T700、T800、T1100
- 高模數型（HM）：經石墨化，模數 ~900 GPa（鋼的 4 倍以上），強度較低 ~3–4 GPa，斷裂伸長率僅 ~0.3%。M55J、M60J
- 瀝青基（pitch-based）：模數更高、導熱極高，但強度低於 PAN 基。用於衛星結構

碳纖維的特殊性：沿軸向熱膨脹係數極低（~ -0.5 至 0 ppm/K，甚至負值），橫向則與基材接近 → 複材冷卻時產生顯著殘留應力。

**芳香族聚醯胺（Aramid: Kevlar / Twaron）**：比強度極高、韌性極佳（耐衝擊、防彈）、密度低（~1.44 g/cm³）。弱點：抗壓強度很低（~500 MPa，僅拉伸的 1/6），原因是微結構中分子鏈橫向靠氫鍵 → 壓縮時 fibril buckling；對 UV 敏感、吸濕。

**UHMWPE（Dyneema / Spectra）**：極低密度（~0.97 g/cm³，比水輕），比強度為所有纖維最高。弱點：熔點低（~150°C），使用上限 ~130°C；潛變明顯；表面能極低，與基材接著力差，需電漿或強酸表面處理。

**陶瓷纖維**：SiC 纖維（Nicalon、Hi-Nicalon，用於 CMC，耐 ~1400°C）、氧化鋁纖維（用於 Oxide/Oxide CMC）。

**天然纖維**：亞麻、大麻、黃麻、竹纖維。可再生、低碳足跡、低成本，但性能變異大、吸水、耐溫有限。用於汽車內裝、建築隔熱。

## 2. 連續纖維複合材料的微觀力學

### 2.1 縱向混合法則（Rule of Mixtures）

沿纖維方向受力，纖維與基材應變相同（isostrain）：

$$E_c = V_f E_f + V_m E_m, \qquad \sigma_c = V_f \sigma_f + V_m \sigma_m$$

$V_f$ 為纖維體積分率。典型 CFRP：$V_f \approx 0.55$–$0.65$。性質與 $V_f$ 呈線性關係。$V_f$ 上限約 0.8–0.91（取決於排列），實際製程能達到的通常 $\le 0.70$。前提是界面完美結合。

### 2.2 橫向模數——反混合法則

垂直纖維方向，纖維與基材承受相同應力（isostress，串聯模型）：

$$E_{c,trans} = \left[ \frac{V_f}{E_f} + \frac{V_m}{E_m} \right]^{-1}$$

以典型 CFRP 為例（$E_f$ = 230 GPa, $E_m$ = 3.5 GPa, $V_f$ = 0.6）：縱向 $E_c \approx 139$ GPa，橫向僅 ~8.5 GPa —— **差了 16 倍**。橫向是基材主導（matrix-dominated），纖維幾乎沒貢獻。更精確的半經驗公式是 Halpin-Tsai 方程式。

### 2.3 剪力延遲模型（Shear-Lag Model）

基材透過界面剪力把負載傳給纖維。沿纖維長度，纖維應力從端部為零逐漸增加到中間達最大值。

**臨界纖維長度**：

$$l_c = \frac{\sigma_f \, d}{2 \tau_i}$$

- $l < l_c$：纖維無法加載到斷裂強度 → 破壞時纖維拔出（韌性高但強度低）
- $l \gg l_c$（連續纖維）：纖維斷裂，強度最大

$\tau_i$（界面剪力強度）由三個機制貢獻：化學鍵結（偶合劑，如矽烷於玻璃纖維、碳纖表面氧化處理產生官能基）、機械互鎖（表面微觀粗糙度）、殘留壓縮應力（CTE 差異導致基材熱收縮夾緊纖維）。

界面設計是核心技術。太強反而不好——裂縫會穿過纖維，無增韌機制。最佳強度是**剛好讓拔出耗能，但能傳遞足夠負載**。

## 3. 積層板理論（Laminate Theory）

### 3.1 單層板（Lamina/Ply）

積層板的基本建構單元，一層連續纖維（~0.125 mm）以特定角度鋪設。本質為正交異向性（orthotropic）：沿纖維方向剛性 $E_1$ 遠大於垂直方向 $E_2$（$E_1/E_2 \approx 10$–$20$ 對 CFRP）。需四個獨立彈性常數：$E_1$、$E_2$、$G_{12}$、$\nu_{12}$。

### 3.2 古典積層板理論（Classical Lamination Theory, CLT）

將不同角度的單層板疊在一起。CLT 基本假設：Kirchhoff 薄板（垂直中面的線段變形後保持直線且垂直）、平面應力狀態（$\sigma_z = 0$）、層間完美結合。

核心結果：**ABD 矩陣**

$$\begin{pmatrix} N \\ M \end{pmatrix} =
\begin{pmatrix} A & B \\ B & D \end{pmatrix}
\begin{pmatrix} \epsilon^0 \\ \kappa \end{pmatrix}$$

- **N**：面內合力（拉伸／壓縮／剪力），**M**：彎矩合力
- **A 矩陣**（extensional stiffness）：面內拉伸剛性。單位 N/m
- **D 矩陣**（bending stiffness）：彎曲剛性。單位 N·m
- **B 矩陣**（coupling stiffness）：拉伸與彎曲的**耦合**。拉伸會彎曲，彎矩會伸縮

B 矩陣物理意義：積層板疊層不對稱 → 固化冷卻時不對稱熱收縮導致翹曲（warping）。**對稱疊層（symmetric laminate）→ B = 0**，幾乎所有實用積層板都是對稱的。

### 3.3 常見疊層設計

- **單向 [0]ₙ**：該方向強度最大化，垂直方向很弱。用於方向性明確的受力（葉片承受離心力）
- **正交 [0/90]ₛ**：雙向強化，但 ±45° 方向仍弱
- **準等向性 [0/±45/90]ₛ**：面內各方向剛性相同，像金屬但保有輕量優勢。至少 8 層，許多航太結構預設疊層
- **航太機翼蒙皮實例**：主要 0° 層（翼展方向拉／壓彎矩）+ ±45° 層（扭轉剪力）+ 少量 90° 層（翼肋間距、防橫向裂縫）。設計重點：**讓纖維方向對齊主應力方向**

### 3.4 層間破壞：脫層（Delamination）

積層板最致命的失效模式。兩層之間分離（基材破壞）。常見原因：

- **衝擊**：工具掉落、冰雹 → BVID（Barely Visible Impact Damage，幾乎不可見衝擊損傷）可以讓壓縮強度下降 40–60%！脫層在壓縮下引發子層板局部挫曲，快速擴展。CAI（Compression After Impact，衝擊後壓縮強度）是航太複材設計的關鍵允收試驗
- **自由邊緣效應（free edge effect）**：不同角度層的 Poisson 比差異在自由邊緣產生層間應力（$\sigma_z$, $\tau_{xz}$, $\tau_{yz}$）→ 脫層從邊緣開始。這是純力學效應，不需任何缺陷
- **製造缺陷**：固化殘留氣泡、預浸布層間汙染

## 4. 複合材料製造

### 4.1 預浸布 + 高壓釜（Prepreg + Autoclave）

預浸布（prepreg）：纖維已預浸部分固化樹脂（B-stage，黏性、可鋪疊、需冷凍儲存 ~ -18°C，有有限室溫操作壽命 out-life）。製程：手工鋪疊 → 真空袋封裝 → 高壓釜施加溫度與壓力（~6–7 atm）固化。壓力作用：壓實各層、擠出多餘樹脂、壓縮氣泡（目標空隙率 < 1%）。大多數航太結構（B787、A350 機身／機翼蒙皮）是此製程。缺點：成本極高、尺寸受限於高壓釜。

### 4.2 液態複合成型（Liquid Composite Molding, LCM）

乾纖維預形體放入模具 → 液態樹脂注入 → 加熱固化。

- **RTM（Resin Transfer Molding）**：雙面金屬模具加壓注膠。高 $V_f$（~55%）、雙面光滑、尺寸精度高。中小型結構件
- **VARTM（Vacuum Assisted RTM）**：單面模具 + 真空袋，靠真空吸入樹脂。成本低、適合大型件（船體、風機葉片 ~100 m），$V_f$ 較低（~45–50%），僅單面光滑
- **RFI（Resin Film Infusion）**：固體樹脂膜置於乾纖維預形體上方，加熱融化浸潤。適合厚截面、大型曲面

### 4.3 纖維纏繞（Filament Winding）

連續纖維束通過樹脂槽後纏繞在旋轉芯軸上。角度由芯軸轉速與送紗頭移動速度的比例決定。應用：管件、氫氣瓶（碳纖纏繞 + 塑膠內膽）、火箭發動機殼體。優點：$V_f$ 極高（~65–70%）、自動化、精確控制方向。限制：僅適用於凸形迴轉體。

### 4.4 拉擠成型（Pultrusion）

纖維被「拉」過樹脂槽再加熱模具固化 → 連續生產固定截面型材（桿、樑、橋面板）。類似金屬擠型但方向相反（拉 vs 推）。高生產率、低成本，截面必須等斷面。應用：玻纖橋梁面板、電纜橋架。

### 4.5 自動化纖維鋪放（AFP / ATL）

- **ATL（Automated Tape Laying）**：鋪放寬帶（~75–300 mm），適合大面積平坦或緩曲率表面（機翼蒙皮）
- **AFP（Automated Fiber Placement）**：使用多束獨立窄束（tow，~3–12 mm），每束可獨立切斷與重啟 → 可鋪放複雜曲面、可轉向鋪設（tow steering）。B787、A350 機身段使用此技術

大幅降低人工成本與材料浪費（從手工 ~30% 廢料降到 < 5%）。

### 4.6 製造挑戰

- **空隙（voids）**：目標 < 1%。空隙每增加 1%，層間剪力強度下降約 5–7%。來源：鋪疊帶入空氣、樹脂揮發物、水分汽化
- **纖維波紋（fiber waviness）**：纖維不直 → 壓縮強度大幅下降。方向偏離載荷軸幾度，壓縮強度可下降 30%+
- **殘留應力**：固化冷卻時 CTE 差異產生層間殘留應力，可能導致未受力即微裂縫
- **固化動力學**：環氧固化放熱，厚截面（> 25 mm）中心散熱不易 → 可能熱失控（thermal runaway）→ 溫度飆升超過降解溫度 → 中心燒焦。必須控制升溫速率與固化週期

## 5. 複合材料的失效與設計

### 5.1 破壞準則

金屬破壞準則相對單純（von Mises），複合材料因多種破壞模式而複雜得多：

- **最大應力／應變準則**：任一應力／應變分量超過容許值即破壞。簡單但不考慮交互作用
- **Tsai-Hill**：基於 Hill 異向性降伏準則的二次交互式公式。單一數值，簡單。缺點：不區分破壞模式
- **Tsai-Wu**：最通用的二次張量多項式，含線性項可區分拉伸／壓縮強度差異。仍不區分破壞模式
- **Hashin 準則**（現代 FEA 標準）：明確區分四種模式——纖維拉伸破壞、纖維壓縮破壞、基材拉伸破壞、基材壓縮破壞。每種有各自的失效指標。關鍵原因：破壞後殘留性能不同——纖維斷了完全失載；基材裂了，纖維仍在，可繼續承受纖維方向的拉伸
- **Puck 準則**：更物理導向，考慮基材破壞的斷裂面角度（fracture plane），對基材壓縮破壞預測特別準確

### 5.2 漸進損傷分析（Progressive Damage Analysis）

傳統設計看第一層破壞（first-ply-failure, FPF）。但複材在 FPF 後常還能承受更高負載（基材裂了但其他方向的纖維還在承擔）。漸進損傷分析：施加負載 → 檢查破壞指標 → 若破壞則依模式折減剛性 → 重分配負載 → 循環到最終破壞。更接近真實但依賴準確的剛性折減模型。

### 5.3 設計哲學

- 金屬靠裂縫停滯（crack arrest，尖端塑性區耗能）保證損傷容限；複合材料靠**檢測保證**（detectability-based）——脫層可快速擴展，不像金屬疲勞裂縫穩定成長
- **剛性設計往往比強度設計關鍵**：碳纖 $E$ ≈ 230 GPa（鋼 ≈ 210 GPa，差異不大），航太中為防顫振（flutter）和過度變形，剛性常是更嚴格的限制
- **熱濕（hot-wet）是最嚴苛的設計條件**——見下文

### 5.4 環境效應

**濕氣吸收**：環氧樹脂吸收空氣中水分，平衡約 1–2 wt%。塑化效應（plasticization）打斷高分子鏈間氫鍵 → $T_g$ 下降 20–40°C、基材軟化 → 橫向強度、層間剪力、壓縮強度全面下降。最嚴格的設計條件是熱濕（hot-wet）：高溫 + 飽和吸濕，基材性能最低點。濕氣吸收是擴散控制的，很慢（2 mm 厚室溫需數月到一年達飽和）。

**UV 降解**：影響限於表面（穿透深度淺），變黃失光澤。表面塗層含 UV 吸收劑即可解決。

**雷擊**：碳纖複材電阻率約為鋁的 1000 倍。雷擊電流（~200 kA）通過 → 焦耳熱 → 局部數千度 → 樹脂汽化、纖維燒損。飛機解決方案：外表面加**銅網（copper mesh）**或展開銅箔（ECF）導電層。

**伽凡尼腐蝕**：碳纖維相對於鋁是陰極（cathodic），兩者接觸 + 電解質（鹽水）→ 鋁被腐蝕。設計中必須嚴格隔離 CFRP 與鋁合金：使用玻纖隔離層、鈦合金緊固件（鈦與碳纖電位差很小）、或密封膠。

## 碩士延伸

- **夾層結構（sandwich structure）**：蜂窩芯（鋁、Nomex、泡沫）+ CFRP/GFRP 面板 → 極高彎曲剛性／重量比。失效模式：面板皺折（wrinkling）、面芯脫黏（debonding）、芯材剪切破壞、芯材壓潰
- **疲勞**：複材疲勞行為與金屬完全不同。沒有明確疲勞極限，但 S-N 曲線較平緩（疲勞敏感度低）。損傷累積是分散的（基材微裂縫 → 脫層 → 纖維斷裂），非單一裂縫
- **濕熱老化（hygrothermal aging）**：長期濕氣 + 溫度循環 → 不可逆微裂縫
- **3D 強化複材**：3D 編織、Z-pinning（垂直插入細針）、縫合（stitching）引入厚度方向強化以壓制脫層
- **纖維金屬積層板（FML）**：鋁薄板 + 玻纖／碳纖預浸布交替疊合。GLARE（GLAss REinforced aluminum）用於 A380 機身，兼具金屬抗衝擊／導電性與複材疲勞抗性／輕量

## 博士延伸

- **奈米複合材料**：CNT、石墨烯、奈米黏土為強化材。極低添加量（< 2 wt%）顯著提升性能。最大挑戰：分散均勻性——奈米材料凡德瓦力導致團聚
- **生物啟發複材**：貝殼珍珠層「磚泥結構」（brick-and-mortar）、螳螂蝦 Bouligand 螺旋結構 → 同時高剛性與高韌性。3D 列印製造此類仿生結構
- **多尺度模擬**：分子動力學（MD）→ 微觀力學 → 中尺度 → 結構 FEA，從化學配方預測結構性能
- **自我修復複材**：微膠囊或中空纖維含修復劑，裂縫經過時釋放並聚合。挑戰：修復劑長期穩定性、修復效率
- **4D 列印複材**：3D 列印 + 時間維度，不同區域不同膨脹率／剛性 → 受外界刺激發生預設形狀變化
- **織物複材多尺度分析**：織物微結構遠比單向帶複雜（纖維束 crimp、交織點應力集中），需專用 RVE（representative volume element）模型
