# 材料分析與檢測（Materials Characterization）

> 名詞對照見 [中英名詞對照表 → 材料分析與檢測](../中英名詞對照表.md#材料分析與檢測)。

## 0. 本科定位

材料四面體中，「結構」是核心但肉眼不可見——需要儀器從巨觀到原子尺度逐步揭露。每種分析技術回答一個特定的問題：XRD 告訴你「這是什麼晶體相、晶粒多大」、SEM 告訴你「長什麼樣子、元素分布」、TEM 告訴你「原子怎麼排列、差排長什麼樣」、XPS 告訴你「表面第一層原子的化學態」、APT 告訴你「每個原子在三維空間中的位置與種類」。

選擇分析技術的核心考量：(1) **空間解析度**（看到多小的特徵——從 mm 到 Å）；(2) **偵測極限**（能看到多少量的元素——從 % 到 ppb）；(3) **破壞性 vs 非破壞性**；(4) **表面 vs 體分析**。沒有任何單一技術能回答所有問題——材料分析的藝術在於組合互補的技術來拼湊出完整的結構圖像。

## 1. X 光繞射（XRD）——晶體結構的指紋

### 1.1 粉末 XRD 的多重資訊

- **相鑑定**：每個晶體相產生一組獨特的繞射峰（位置 + 相對強度）——PDF（粉末繞射檔案 Powder Diffraction File）資料庫收錄數十萬種已知相的繞射指紋，匹配搜尋即可鑑定樣品中含有哪些相
- **晶格常數**：繞射峰位置 → 晶面間距 $d$ → 晶格常數 $a, b, c$。晶格常數的微小變化反映固溶體成分（Vegard 定律——合金中晶格常數通常與溶質濃度成線性關係，因為原子半徑的差異線性疊加）、殘留應力（壓應力——晶面被擠壓——$d$ 變小——峰往高角度移；張應力——峰往低角度移）、或化學計量偏離
- **晶粒大小**：Scherrer 公式 $d_{\text{crystallite}} = K\lambda/(\beta\cos\theta)$ 從繞射峰寬度 $\beta$（排除儀器展寬後的物理展寬）推算晶粒大小。適用範圍約 10–200 nm——太大時峰寬以儀器極限為主，太小時非晶散射主導
- **織構（texture）**：繞射峰相對強度偏離無優選方位粉末的標準值→晶粒有優選方位（例如冷軋板的 {111} 織構）。XRD 逐傾角掃描繪製**極圖（pole figure）**顯示特定晶面的方位分布
- **殘留應力**：$\sin^2\psi$ 法——量測多個傾斜角 $\psi$ 下特定晶面的繞射峰位移量，推導表面平面應力狀態（原理：晶面間距的應變 × 彈性模數 = 應力）

### 1.2 同步輻射光源——X 光分析的終極工具

同步輻射加速器（如台灣新竹的國家同步輻射研究中心 NSRRC 的台灣光子源 TPS）提供亮度為實驗室 X 光管的十億倍以上的 X 光光束——超高亮度意味著即使極小的樣品量也能獲得足夠訊號。同步輻射的實驗能力遠超實驗室 XRD：(1) **原位實驗**——在電池充放電過程中即時追蹤電極材料的結構相變；在拉伸/加熱同時記錄 XRD——即時觀察相變態與晶格應變的動態演變；(2) **微米級繞射**——將 X 光聚焦到 µm 級的光點，掃描樣品表面逐點量測，繪製晶體方位、晶格常數、相分布的空間地圖。

## 2. 電子顯微鏡——從微米到原子的跨越

### 2.1 SEM（掃描式電子顯微鏡）

電子束（加速電壓 1–30 keV）聚焦成奈米級探針在樣品表面掃描。訊號種類：
- **二次電子 SE**（< 50 eV——來自樣品表層數奈米的低能量電子）：形貌對比最強——邊緣較亮（electron edge effect——邊緣處二次電子的逃逸面積較大）。解析度可達 ~1 nm
- **背向散射電子 BSE**（彈性散射回來的入射電子，能量接近入射能）：原子序對比——原子序高的區域產生較多 BSE → 較亮（gold = 亮、carbon = 暗）。可在不染色的情況下區分不同平均原子量的相
- **EDS（能量散布 X 光光譜）**：電子束擊出內層電子 → 外層電子躍遷填補空位 → 釋放特徵 X 光（能量為兩能階的差——反映了原子核的電荷數，即元素種類）。EDS 可做點的化學成分分析、線掃描（沿一條線的成分變化剖面——例如從基材穿過界面進入塗層，每點的 X 光譜記錄下來 = 一個擴散偶的濃度剖面）、或面掃描（二維元素分布圖——例如合金中析出物的元素富集一目了然）

### 2.2 TEM（穿透式電子顯微鏡）

樣品必須極薄（< 100 nm——用離子薄化 FIB 或電解拋光製作），電子束穿透樣品。TEM 的多種操作模式互相補足：(1) **明場 BF 影像**——讓穿透電子束通過物鏡光圈。差排呈現為暗線（差排周圍的晶格扭曲→電子在扭曲區域更易被散射→偏離穿透路徑→被物鏡光圈擋掉→在亮背景中顯為暗線。$\mathbf{g}\cdot\mathbf{b}=0$ 準則——當差排的 Burgers 向量 $\mathbf{b}$ 垂直於繞射向量 $\mathbf{g}$ 時差排不可見，利用這條準則可判定差排的 Burgers 向量方向）；(2) **高解析 TEM HRTEM**——讓穿透束與至少一束繞射束同時通過物鏡光圈彼此干涉→形成晶格條紋（直接看到原子列的投影——晶面間距 0.2–0.3 nm 清晰可辨）；(3) **掃描穿透 STEM + HAADF**（高角度環形暗場偵測器）——高角度散射的強度 $\propto Z^2$（原子序平方）→原子序對比極強，重原子（如 Pt）極亮、輕原子（如 C）極暗——單原子催化劑中每個 Pt 原子在載體上的位置清晰可見（single-atom catalyst imaging）。(4) **電子能量損失譜 EELS**——穿透電子的能量損失反映了樣品中的電子激發（電漿子 plasmon、內層電子激發 edge——不同元素有特徵的 edge 起始能量，可判斷化學態與鍵結——例如碳的 K-edge 形狀可分辨鑽石 sp³↔石墨 sp²↔非晶碳）。

## 3. 碩士/博士層級延伸

碩士：**EBSD（電子背散射繞射）**——SEM 中樣品傾斜 ~70°，背向散射電子在樣品表層數十奈米的晶體上發生繞射→形成 Kikuchi 繞射圖樣（一系列亮暗帶對應於晶面繞射）→電腦自動擷取圖樣並與該晶系的所有可能方位比對→確定該點的晶體方位。電子束逐點掃描→繪製**晶粒方位圖**（不同顏色的晶粒對應不同方位→晶粒大小、形狀、織構一目了然；晶界類型——小角度晶界 vs 大角度晶界 vs 雙晶界）、應變分布圖（Kikuchi 圖樣的品質隨晶格扭曲而下降——差排密度高的區域圖樣模糊）。

博士：**原子探針斷層掃描 APT（Atom Probe Tomography）**：將樣品製作成針尖（尖端半徑 < 100 nm），在超高真空（~10⁻¹¹ torr）與極低溫（~30–80 K）下對針尖施加高壓 DC 或雷射脈衝——針尖表面原子逐個被**場蒸發（field evaporation）**為離子、加速飛向位置敏感偵測器（飛行時間質譜 TOF——質量/電荷比決定飛行時間，hit position 決定原子在針尖表面的原始位置）。逐層蒸發→重建出針尖數百萬個原子的**三維空間分布 + 化學種類**——每個原子都有空間座標與元素標籤。APT 是少數能「看到」原子偏析到晶界的技術——在晶界面處的數奈米範圍內，溶質原子的濃度可能高達數十 %（遠超過晶粒內部的平均濃度——晶界偏析直接影響晶界的強度與腐蝕行為，在核反應器壓力槽鋼的輻射脆化中扮演關鍵角色），而 APT 可以精準地畫出跨晶界的單原子濃度剖面。APT 的樣品製備（用 FIB 從塊材中取出微米級柱子再 annular milling 削尖到 < 100 nm 針尖——需極高的技術避免離子損傷與非均勻削尖）與數據重建（場蒸發順序→空間重建的投影參數需校正——不同晶面的蒸發場不同造成局部放大率的變化，需用已知晶面間距做內部校準）是技術難點。
